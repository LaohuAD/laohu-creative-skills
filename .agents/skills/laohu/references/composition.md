# 按当前任务组合能力

仅在 `/laohu` 已判断单个入口不足、需要多个独立贡献时读取。候选来自本次动态扫描及已读取的 `SKILL.md`，不是本文件的示例或预设套餐。本文路径基准沿用入口定义的 `{SKILL_DIR}` 与 `{PROJECT_ROOT}`。

## 先证明每个成员有用

围绕已经明确的用户目标，逐项核对：

| 判断 | 处理 |
|---|---|
| 去掉这个成员，哪一项必要结果会缺失？ | 说不出具体缺口就移除；功能重叠时比较后保留适用者 |
| 能否由已选入口的正常流程完成？ | 能则保留内部调用，不重复推荐父子入口或目录收录能力 |
| 成员处理的是同一作品、材料或共同目标吗？ | 只是几个无关愿望，不强行统一主责，按用户优先顺序分开处理 |
| 输入从哪里来，输出给谁用？ | 输入可来自现有材料或前一步；缺来源且无法补齐的步骤不承诺执行 |
| 该入口真的负责这项专业工作吗？ | 核验正文和必要依赖；不能凭名称指定它承担越界任务 |

同一作品需要歌词和编曲，可能有两个独立贡献；一句“整理一下”可能指收录文件，也可能指调整文章结构，属于待澄清歧义。前者也必须先确认对应能力实际存在，后者按顶层判断规则询问，不同时做两件事。

## 明确主责和交接

选最能承接主要结果的 Skill 负责统筹：保留任务状态、接受各项产物、核对保护项，并汇总结果。主责不等于包办各专业判断，也不允许越过自身边界。没有兼容的负责人时，先说明冲突，建议缩小本轮目标或分成明确的任务，不临时虚构一个总导演。

每个成员至少确定：实际入口路径、必要贡献、输入与其来源、返回什么、返回给谁。只传目标、材料、已确认决定、约束、授权、作品目录和未解决问题，不让成员重新问一遍需求。没有文件也可以交接判断；已有路径必须原样传递，归属变化须先由用户决定。

同一目标可以交付多个相关文件，但多文件不等于必须组合。例如同一篇定稿需要离线阅读页和公众号粘贴版，若通用展示入口已明确负责双格式交付并调用公众号能力，就只推荐通用入口。只有现有入口不能完整承担、确需独立协作时才组合；两种成品都应从原始定稿取材，不能把浏览器交互页面误当公众号输入。该例用于检查重复贡献，不是永久指定某个入口的职责，实际仍以本次读取的正文为准。

## 顺序服从依赖

先做会改变后续方向、范围或高成本投入的必要判断，再取得专业制作所需的材料，随后制作并检查。已有结论直接承接；两个产物互不依赖时不强造前后转换，也不因组合就自动启动多 Agent 或新任务窗口。

首次落盘前，依顶层规则调用作品收录能力。已经确认的同一作品目录贯穿全部成员；新文件类型不是新建作品目录的理由。收录本身是用户主要目标时才把它作为推荐成员。

一个成员结束后只返回本次需要的结论、产物、依据、限制和下一步输入。主责检查是否满足下一步条件，再继续；检查失败交回最早出错的步骤，不能让两个成员反复要求对方先完成。用户已确认的内容若被新证据推翻，明确指出冲突，暂停依赖它的步骤。

## 停止与调整

- **关键决定未定**：按 `{PROJECT_ROOT}/docs/runtime.md` 给出建议并询问。等待相关决定；不把“先试着做”用于代替归属、方向或合并授权。
- **必要能力、材料或工具缺失**：区分未来可能的完整组合与现在可执行的部分。缺失环节决定最终结果时不能宣称整套可执行；用户已授权的独立部分可以继续，否则只提出收窄方案。
- **专业边界或用户要求冲突**：说明哪两项要求无法同时满足及具体影响；能在原授权内消除重复则直接调整，需要改变结果则由用户取舍。
- **越出权限**：推荐组合不增加发布、付费、外部通信或长期规则修改权限。只暂停越界部分，保留已有成果。

## 交付可使用的组合建议

先用简短的话说明：推荐谁负责、需要哪些协作、为何一个入口不够、先做什么、哪里需要用户决定。随后给一段自足提示词，省略无关字段，不强制用户填写任务表：

```text
请使用以下能力完成这个任务：{用户已明确的目标与相关交付物}。
主责：/{实际名称}，入口 {本次核验的实际路径}；负责 {统筹范围与主要结果}。
协作：/{实际名称}，入口 {实际路径}；负责 {必要贡献}，接收 {输入}，返回 {产物或判断} 给 {接收方}。
已有材料、决定和保护项：{沿用的内容与路径}。
作品目录：{已确认路径；未定则说明决定点，不编造路径}。
顺序：{根据输入输出关系安排}。
遇到 {本任务的未决条件或失败条件} 时，{询问、暂停或调整动作}。
本次授权范围：{已明确范围}。
完成时：{结果与验收条件}；由主责汇总各项交付，说明实际文件位置与未完成项。
```

协作项按必要贡献增减，不设置固定人数，也不把所有可用能力填进模板。组合只服务本轮任务，不自动保存成永久流程。推荐后按入口规则停止；已有“选好直接做”等明确授权时可交接执行，不再次索取同一授权。宿主不支持斜杠命令时读取实际路径进入对应流程；列出名字不等于已经加载或执行。
