# 老胡公众号排版技能

这个目录收录并接入了 [gzh-design-skill](https://github.com/isjiamu/gzh-design-skill) 的公众号排版能力，用于把 Markdown、Word、PDF 或纯文本整理成适合微信公众号发布的 HTML，并提供可复用的主题组件、格式归一化和校验脚本。

在支持 Skill 的 Agent 中可使用 `/laohu-htmlshow-gzh` 进入这项能力。它适合已经有文章或内容草稿、需要统一视觉层级和发布格式的场景；它负责排版与检查，不替代选题、写作和内容判断。

来源项目的完整规则、主题组件和脚本保留在本目录中。该第三方内容继续遵循原项目的 AGPL-3.0 许可证，详见本目录的 `LICENSE`；老胡造梦技能仓库的其他内容仍按仓库根目录的许可证执行。
