# 信息流独立短帖（X / 朋友圈）

若宿主直接命中本配置，先回 [laohu-writing 主文](../../SKILL.md) 承接四维八纲底座、唯一读者定盘与事实边界。本专项不复读通用总纲，只强化信息流短帖在**折叠线前活人破冰、单核带体温穿透与短锐金句收刀**上的专属杠杆。

## 一、折叠线前舒展破冰、单核穿透与短锐收刀

朋友圈与 X 在信息流中都会折叠长文，决定读者点不点展开的只有最前面一两行（约前 50–80 字）：

1. **无需小标题，折叠线前像活人聊天一样舒展破冰**：用普通人张嘴就说的最高频日常熟词，或直接甩一个极常见的生活画面，把最扎心的反差或真观察自然铺在折叠线前——**绝不为了硬凑极短字数把自然大白话压成发紧拗口的书面短语、让读者脑子拐弯**，也零寒暄暖场、零自夸预告、零训话腔。
2. **一条只打透一颗核，带体温走微起伏，短帖绝不硬塞生硬术语**：首句活人破冰 → 中段带体温落进贴身生活场景（切忌冷冰冰第三人称分析腔）→ 顺势拉高剥穿最硬一层现实因果（全程用透亮带劲的大白话讲透，**200 字短帖绝不为了显得有深度硬塞学术名词**）→ **末尾用一句 10–25 字极短、极脆、让人忍不住点赞转发的点睛金句干净收刀（严禁拖成四五十字长难复句泄气）**，不重背第一句，不喊求赞营销尾。
3. **极限精简不砍骨肉也不编造**：字数收紧时死保主语、因果、现实底线与大白话呼吸感，绝不把有据判断砍成悬浮鸡汤，也绝不编造虚构人名、金额或作者未经历的亲身案例。

## 二、按实际发布单元交付

- **单帖直交可发正文**：默认用干净代码块（或按用户指定纯文本）交付可直接复制发布的净稿，严格尊重目标字数与平台语境；限定一条就果断收窄材料，不擅自拆连载。
- **X 推文串（Thread）**：仅在用户明确要求串帖、或多步深内容确需分条且授权允许时使用。首条独立在折叠线前完成活人破冰与信息缺口钩子，中间每条只推进一层全新洞察且零复读，末条自然升维回扣并留余味。定稿短帖存入飞书时，由父级保住锁定原文并叠加飞书排版。
