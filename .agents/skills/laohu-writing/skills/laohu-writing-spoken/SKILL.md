# 口播与讲解稿（单文件自足专项）

若宿主直接命中本配置，先回 [laohu-writing 主文](../../SKILL.md) 承接四维八纲底座、三态需求判定、唯一听众定盘与材料授权。本专项聚焦**人张嘴一念就顺、听众靠耳朵一次就听透、且全程情绪有波峰波谷起伏**的听觉物理规律。只做录后 ASR 复盘时回父级走复盘流程；既要文章或短帖又要口播时，**必须按听觉顺序彻底独立重写，绝不把文字版改两处标点生搬进提词器**。

## 一、前 3 秒听觉强锚 ＋ 微型情绪波浪（零说教、零过门废话）

1. **前 3 秒听觉爆点**：
   - 第一句用贴脸你/我视角直接甩出最反直觉的现实反差或对事狠判断（严禁旁观第三人称开局、严禁软弱反问、严禁情绪总结垫话与自夸自叹）；若用户明确要克制平实的科普讲解或品牌旁白，则按其要求直给清晰引子、不强行制造焦虑反差；
   - **1 分钟左右的短口播绝不插博主过门废话**白白烧掉黄金 3 秒，冲突撞完下一句直接进具体场景。面向行业外听众时点明变化与切身选择的联系，缺据如实收口。
2. **短短一分钟同样走情绪波峰波谷，严禁一根弦硬怼到底**：
   - 开头甩钩拉高（波峰）→ 紧接放缓半拍体谅人之常情或带入真实现场（波谷，消除抵触）→ 陡然拉高挖穿底层人性或商业机制（主波峰，砸下听一遍就忘不掉的短锐金句）→ 给做法时放平语气并肩摊开边界与退路（波谷，绝不命令式训话）→ 最后收紧落刀余韵收官。
   - 全程不把开头举过的例子在中段炒冷饭。

## 二、首听语序、自然分段与按意图分流（朗读标注版 vs 配音纯净版）

1. **CDC 首听语序（听众无法回看）**：先报主角再说动作、一口气不叠多层前置定语或三层条件；陌生专词、英文缩写或概念首次出现时，先用外行秒懂的话交代用途再报词名，后文统一称呼不乱换。换层推进直接踩着上一句落下的反差或结果自然滑入，省去书面报幕词。数字、比例、年份、符号与常见缩写按实际念法展开（如写出百分之三十、三点五倍）。
2. **自然段落、无小标题、纯文本（零 Markdown、零情绪注释）**：
   - 口播稿像文章一样按语义与情绪推进自然分段（通常 1–4 句一段，关键转折或重锤金句可单句成段），**绝不加文章小标题**；默认使用纯 `text` 代码块交付，**绝不混入 Markdown 加粗/斜体/列表语法**，也**绝不插播**开场稍快、放缓交心、微笑、停顿一秒等任何括号或方括号导演状态注释；
   - 稿内绝不夹带 Markdown 链接、装饰双引号或时间码；原文拼写、读音提示、时长口径与画面提示全部放代码块之外。
3. **按用户意图自动分流两类可录形态（绝不混用）**：

| 用户真实意图与用途信号 | 交付形态 | 符号与排版细则 |
| --- | --- | --- |
| **真人朗读版**（真人出镜、自己念稿、口播录屏，或未指定配音/AI 克隆时的常规完整口播稿） | **自然段落纯文本 ＋ 克制播音四符标注版** | 借鉴专业播音停连、重音与语势法，克制点标不滥用：① `/` 句中短停微气口（仅标在无标点但须轻顿半拍处，常规逗号句号不叠加）；② `//` 长停留白 0.5–1 秒（仅标在反转前或金句前后）；③ `【重音词】` 核心重音（1 分钟稿全篇克制点标约 **8–12 处**真正要砸下去的反差词、数字或核心动词，忌每句塞满）；④ `↗` 尾音微扬提气 / `↘` 尾音下沉落稳（仅在关键转折与落定句尾适度点标） |
| **配音版 / 局部顺句**（明确用于配音、AI 克隆音色、TTS 合成、AI 语音跟读提词器、直接导字幕，或仅要求局部顺句改词不改全篇） | **零符号纯净配音净稿** | **彻底不加 `/`、`//`、`【】`、`↗`、`↘` 及任何辅助标记**，防止 AI 克隆音色或语音识别卡壳误读，纯粹靠顺口语序、精准标点与自然分段托住节奏 |

   - 若用户另行明确指定逐行短句提词版，按用户要求切行交付。
4. **改顺口不改事实范围**：调语序或补衔接后回查对象、范围与时态零走样；绝不编造虚假数据或作者未经历过的具体亲身案例；缺听觉范式参照时按需查阅 [本地资料库分层检索](../../../laohu-benchmark/references/library-retrieval.md)。

## 三、声画真互补与严格同步的竖屏卡片

- **纯声音稿**：听众闭着眼也能完整听懂全部对象、因果与关键条件。
- **带画面的视频讲解稿**：旁白负责情绪、故事感与锐度；竖屏侧边文字卡片每条压在 **约 5–8 字极简视觉锚点**（绝不搬长句复读旁白），且**卡片出现时机必须与第一条锚点对应旁白严丝合缝同步（绝不提前数句挂空框干等）**，多条随对应旁白逐条弹出、及时退场，安全区避开人脸五官、底部字幕区与右侧互动图标列；**无历史录音样本时，卡片只锚定旁白首字触发句与退场句，不虚标具体第几秒到第几秒**；未拍或未制画面如实标明待制作。

## 四、诚实语速口径与出声耳检终审

- **语速口径诚实透明**：仅用户锁定的时长或字数当硬约束。核字时**只统计真正念出口的汉字（朗读标注版必须剔除 `/`、`//`、`【】`、`↗`、`↘` 及标点与换行）**。估时优先用同一说话者相近题材的实际录音语速；**无历史录音样本时，明确标出核准后的精确发音字数与采用的经验语速假设（如每分钟约 230–260 字含自然换气停顿），绝不把经验估算装成个人实测**。超长先砍旁支保住钩子、根因与落点。
- **交稿前按真实语速出声顺读**：专抓七处真疤——前 3 秒有没有旁观腔/软弱反问/过门废话、通篇有没有情绪波浪且零说教训话、段落是不是自然分段无小标题且零 Markdown 与导演情绪注释、朗读版 vs 配音/AI 克隆版是否按意图分流正确（朗读版四符克制无滥标，配音版与局部顺句彻底零符号）、有没有书面压缩造成的动宾搭配别扭或拗口儿化词、画面卡片是否极简且只用首字同步无空框不虚标秒数、发音字数与语速口径是否剔除符号后诚实核准且事实完好。只获准交文稿时不触发语音生成。
