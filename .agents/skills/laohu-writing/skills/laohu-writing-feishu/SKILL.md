# 飞书文档创作与排版

若宿主先选中本配置，先回 [laohu-writing 主文](../../SKILL.md) 定任务、材料、授权和交付媒介。飞书是交付目标时使用本配置。飞书链接只用作资料时，父级按所需的读取范围接通来源，成稿走目标媒介。

输入沿用用途、读者、稿件与来源、编辑范围、锁定内容、展示偏好和写入授权。缺少会改变远端操作的链接、位置或企业归属时，只补相关项，先继续能做的起草和图文设计。飞书与公众号同时是成品，父级分别按各自读者和链接要求成稿。同稿存放则保留锁定字面，只改原生版式。口播用飞书存放时保持净稿和制作附注的职责。面向新手教程、实操指南或手册时，教学路径由父级组合教程专项，飞书负责阅读顺序与原生呈现。

## 先分清本轮交付什么

| 目标 | 处理与返回 |
| --- | --- |
| 在聊天里先看稿 | 按飞书阅读条件起草完整稿，交回可用正文和已要求的图文设计。已齐材料时跳过飞书运维 Reference 及全部远端动作。 |
| 只读飞书来源，为聊天稿取材 | 读取所需正文、图或附件后回到成文，远端权限止于需要的读取。 |
| 修改指定文档 | 核实实际版本和权限，按获准范围编辑，保留其余内容和资源，交还文档链接与实际验收范围。 |
| 新建并放入飞书 | 确认或沿用标题、目标空间/文件夹及归属，核对写权限后创建、写入和验收。用户未定位置且已有适用的默认个人空间时可沿用并告知归属。 |
| 只优化排版 | 保护原话、主张和章节决定，调整原生格式、分段和布局。内容疑义交回父级。 |

“帮我写进这个文档”等明确意图已覆盖相应写入。新建、修改、发布、分享及向成员通知各依用户本轮授权决定。需要读取、连接、上传、新建、差异写入、处理上次未明状态或恢复时，才按实际操作读取 [飞书远端操作](../../references/feishu-ops.md)，取得对应的真实版本、资源或返回状态后继续。

## 将内容关系落实为飞书原生格式

先沿用用户/团队已有版式和无障碍阅读需要。未给样式时，以中性色正文、少量**加粗与浅黄色行内底色**标关键动作或决定，蓝色优先保留给链接；颜色之外仍由文字、层级与加粗表达意义。用户另选配色时按其方案调整，保持同一颜色角色一致，不将该默认写成所有人的品牌规范。

| 内容关系 | 原生表现与使用条件 | 必须保留的阅读/编辑能力 |
| --- | --- | --- |
| 主标题、章节、局部操作 | 文档标题及真实 heading 层级；层级随内容从属，不用放大加粗的普通段落模拟 | 大纲导航和章节跳转；原有锁定标题不擅改 |
| 正文中的关键动作/条件 | 对有完整意义的短语加粗；少量关键短语叠加行内底色 | 重点与邻文连读完整，代码和关键值不能只高亮一半 |
| 有依赖的操作步骤 | 原生有序列表，每项一个可编辑动作；说明段与子项按层级附属 | 自动编号、起始值、跨备注/图表续号、嵌套关系；不手打序号模拟 |
| 并列选项或材料 | 原生无序列表；需要读者逐项完成时用待办/复选框 | 可逐项增删、调整、勾选；不把并列写成假顺序 |
| 补充说明和旁注 | 原生引用块，承载紧邻内容的解释/备注 | 真实引用结构，不用引号或左侧字符模拟；引用格式不代表内容是外部引文 |
| 独立且需要停下来看的提醒 | 原生高亮块，只放影响当前选择、费用、凭据或失败处理的必要提醒 | 与正文角色区分；不把全部重点或每个完成标志都装进彩色盒子 |
| 字段映射、条件/方案比较 | 原生表格，列名对应真实比较维度；长解释留在表外 | 单元格可改，横向关系准确；控制列数与长文本，不能只靠整页横滚读步骤 |
| 同层替代路线、图文对照 | 短内容可用原生两栏；超过两栏需有实际同屏比较收益 | 各栏有清楚标识与阅读顺序；长顺序教程单栏，检查窄屏后的顺序 |
| 命令、配置、原样复制文字 | 原生代码块/行内代码；整段提示词保留真实换行与完整选取范围 | 原值、缩进、字符及复制可用性；不把代码渲染成截图 |
| 下载、设置、章节入口 | 正文锚文本超链接；生成块后以真实 heading ID 建篇内链接 | 显示含义与目标一致；不能把本地预览 slug 当飞书块 ID |
| 截图、说明图、流程图 | 原生图片/适用的可编辑画板，准确锚点与必要图注 | 真实可访问资源、原比例、显示清晰度及文字替代路径 |

以上按当前段落职责选择，不要求把每种格式都用一遍。分栏、表格、引用、高亮分别表达不同关系，不能用更多格式替代更清楚的内容。原生组件操作以当前官方帮助和工具的实际支持为准；富文本接口支持与 Markdown 导入支持分开核对。必要格式未被转换器保留时，转用可用的原生块/样式接口完成，不能因为接口返回成功就把降级结果交付。


## 整合正文与图片

操作路径里的真实截图由父级按教程模块核图或取得。关系、结构、过程等图文按 [篇内图文](../../references/structure-and-argument.md#按读者任务安排篇内图文) 选载体，需要时由父级调用 Cover。保住已核图片的锚点与可操作的文字路径。命令和提示词仍可复制。若使用可编辑画板，验读序、关系与实际可读尺寸。新做图通过真实工具产出并核验，按工具回传区分实际工件、设计稿和待制作项。

远端图片必须可访问并绑定到正确块与目标文档，说明图注与正文位置。需要上传或修复媒体关联时按运维文件完成后读回。仅聊天交稿按父级格式交正文与需要的说明。远端写入完成，交可点击文档、已完成的范围与实际验收结果。格式、图片或客户端验收有缺项时只报告相应部分，继续交付已完成的工作。
