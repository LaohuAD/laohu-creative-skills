# 微信公众号文章

本配置只在用户明确把微信公众号文章/公众号稿件作为交付物时，由 `.agents/skills/laohu-writing/SKILL.md` 读取。它固定的是适合独立阅读、回看、跳读和复制访问的文章路径及平台边界，不固定营销、视频腔、情绪力度、标题套路或段落模板。只写一般文章时由宿主完整处理；只需将已有文章排成微信公众号 HTML 时走既有 `laohu-htmlshow-gzh`，不由本配置接管排版。

输入继承宿主已经确认的文章目的、读者、作者立场/声口、材料身份、事实与证据范围、编辑授权及用户锁定内容。按需读取宿主共享方法（以下路径均相对本文件）：有口述、ASR、讨论或来源材料时读 `../../references/materials-and-evidence.md`；完整创作/获准发展时读 `../../references/structure-and-argument.md`；写新开篇时读 `../../references/openings-and-reading.md`；实际成文或修订词句时读 `../../references/expression-and-density.md`；终审或录后内容复盘时读 `../../references/revision-and-review.md`。这些文件提供各自唯一的共享判断；本配置负责将它们接成公众号阅读顺序。完成后把完整文章及确有必要的待制作图文 brief 返回宿主，继续做事实、保护项、标题/图稿协作、交付格式和授权检查。

## 选文章目的与读者路径

先说明这篇文章要帮助读者理解、判断、体验或完成什么，再看读者已经知道什么、从哪处材料或关系进入、必须补足哪些前提，以及读完后应得到什么。按用户已定的体裁与作者声音选择入口：困难只有在材料与读者处境都支持时才做阅读理由；文章也可以从一个清楚答案、真实观察、具体差别、局部发现、经验或概念关系进入。让入口在前文中很快兑现，不以营销钩子、悬念、强情绪或“视频开场”替代内容。

据此安排一条可独立阅读的推进路径：当前语境先建立必要对象与关系，随后补充理解该判断所需的材料、解释、依据或操作，最后兑现本文承诺并限定结论范围。先看读者需要什么、材料承重在哪里，再决定是否分节；一节应带来不同的根据、关系、条件、动作或体验变化。并列知识、观察与操作依赖分别按真实关系组织，不将每篇套成“痛点—故事—方法—结果”、固定三幕或规定节数。读者能回看段落、标题、图表和链接，不等于可省去必要解释；也不要求在正文中重复已经清楚呈现的图面信息。
若文章目的或 reader path 的专业判断缺少具体作品处理，或用户指定已收录公众号文章，先按项目共用[本地作品方法库检索路径](../../../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)检索相同阅读任务下的入口、段间层级或回看路径；打开完整原子与来源后，回到本篇的材料顺序和承诺范围。已足以解决的结构无需另检索，来源也不替正文提供事实。

## 从另一种媒介改写时重建文章

口播/讲解稿转公众号文章时，沿用已确认的观点、事实、证据范围和作者声口，但按独立阅读需要重选开篇、背景、段落层次和解释量；不能只把口播逐句加长、补小标题或加一段引言。文章可以加入源材料中已有、读者理解所必需的上下文，但不能补造经历、论据、效果或作者未确认观点。

公众号文章转口播稿时，先回到听众要理解的中心关系与本次预算，重选听觉顺序，再交由宿主的 `laohu-writing-spoken` 执行口播方法；不能按字数比例缩短、照读小标题，或把文章中的链接/脚注默认塞进念稿。同选题双向各写一份时，复用已确认的观点、事实、证据范围和作者声音，但分别满足媒介任务；不强制建母稿或保存中间稿，除非用户明确要求。

## 区分篇内结构、平台字段和发布准备

文章内主标题/章节标题是正文的一部分；分享卡片、公众号发布标题、封面文字等平台字段是另一类交付。用户要求新写或修改标题字段时，按宿主契约调用 `laohu-title`，逐项明确字段类型、准确数量、用途、读者、正文/章节位置、材料、作者声音和锁定项；只交本次请求的字段，不因公众号媒介自动生成标题包或封面。章内标题依真实章节内容导航，不反向制造新主张或新小节。

若正文结构需要篇内图文协作，按宿主既有条件调用 `laohu-cover` 设计正文讲解图，说明准确锚点、读者此处已知什么、画面要帮助其辨认/对照/追踪什么，以及文字事实边界；正文图按正文阅读和理解需要决定，不因公众号媒介自动增加。封面视觉仅在用户明确要求封面创意、封面文字/图像或对应提示词时处理；不因文章采用图文就默认增加封面。实际图片、图稿提示词和待制作状态不可混称；静态图文任务不扩成动画。文章仍须有可独立理解的文字路径，除非用户明确指定了声画共同承载的特殊成品。

含外部项目或教程入口时，依据宿主材料 Reference 保留准确的完整 URL，使读者能看见并复制；若还有可点击文本，核对显示地址、复制地址与实际链接目标一致。引用放在读者能对应到具体判断的位置，说明来源支持什么及范围；写作时研究的来源不自动成为正文材料。

交付公众号文章正文而非 HTML 时，按用户指定方式交付 Markdown；只有明确要求可粘贴的微信公众号 HTML/排版时，才转交 `laohu-htmlshow-gzh` 处理展示层。未经明确保存授权不落盘；未经发布授权不提交、不登录或发布。返回宿主前从头连读，检查开头兑现、章节顺序、图文与正文关系、读者回看路径、来源范围、URL 和用户保护项；发现最早断点就直接修稿，不附无关制作或内部复盘清单。
