# 微信公众号文章

若宿主先选中本配置，先回 [laohu-writing 主文](../../SKILL.md) 定用途、材料、授权和交付媒介。这里把父级确认的读者任务、材料、观点/声音、证据与授权落实成公众号的独立阅读稿。教程可由父级组合通用教学方法。共享成文 Reference 的选择由父级负责，稿件、请求的发布字段及实际图稿状态交回父级。只委托已有稿排版或公众号 HTML 时交 [laohu-htmlshow-gzh](../../../laohu-htmlshow-gzh/SKILL.md)。

## 让离开聊天的读者也能接上

先确定读者此刻想理解、判断、体验或完成什么。以与这项任务直接相关的一处答案、观察、具体难处、差别或事实起笔，让没看过作者聊天和上一篇的人在前三段能认出对象、眼前问题及本文要交付什么。处境、数据或承诺在正文给出确切兑现位置。体验、观点、原理和教程各用与其目的相配的开头，力度来自材料与作者声口。

稿件可能由推荐、搜一搜或熟人转发抵达。通读时分别用“第一次遇见这篇文章”和“只收到一条转发消息”的位置看开头。 来自聊天的代词、上下篇简称或仅熟人知道的项目名，补到能独立理解即可。篇末可自然留下同主题一句可转述的判断；只有原文的关键表达确需专项凝练时，交回父级按标题契约处理。文章结尾完成读者任务即可。

完整改编自口播时，沿用已确认的观点、事实、证据和声音，重选书面开头、必要背景、章节和解释量。只添加原材料已有且能帮助读者理解的上下文。两种媒介都要时，父级分别给出可独立完成任务的文章与口播；听觉组织、是否存放母稿及是否保存由实际目标和授权决定。需要从真实作品找到与此处阅读任务相近的处理时，按 [项目方法库检索](../../../../../references/exemplar-study.md#从本地作品方法库检索并返回决定) 取用实际篇章、查回上下文后适配本稿。

## 排出手机可扫读也可细读的层级

1. **段落按理解任务换气。**从手机正文栏宽度查看段落，在语义转折、从理由到操作、从动作到结果等位置换段。连续多行且含多个判断时拆开，单一论证可以保留必要长度。手机的行数受屏宽字号影响，段长只是审读信号。
2. **抽出主标题和章内小标题连读。**一节承担新的根据、条件、动作或体验变化。用能指向这一变化的具体动词或判断拟小标题。已定章节需要专项标题或判断变化时，父级按 [成稿与标题交接](../../SKILL.md#成稿与标题交接) 送 Title。连读标题确认看得懂骨架，再返回正文核是否真正兑现。短文随内容决定要不要另起节。
3. **正文用少量关键短语帮助回看。**加粗只标这一段读完最值得记住的判断、动作或条件。若只扫标题和加粗仍看不出哪一节有用，先修标题层级或正文承重句。
4. **长密段先查读者卡点。**连续约 500–700 字的纯文字推导，若涉及多维对比、实际操作定位、多个依赖或流程分支，就按 [篇内图文](../../references/structure-and-argument.md#按读者任务安排篇内图文) 看能否通过可复制代码、对比表、真实截图或关系图减少反复回看。这里的字数是提醒精审，配图依据是读者具体要识别、比较或追踪什么。把图放在首次需要读图的位置，正文与图一起读通，并保留能独立理解或操作的文字。

## 核链接、原值和正文交付

可点入口采用能说明用途的锚文本。稿中明确保留的外部项目或教程入口，同时把完整 URL 作为可见独立行或代码块交付。有点击文本时核显示值、复制值和链接目标一致。API 地址、命令、配置和完整可复制指令保留原值，与入口链接区分。来源放在能对应实际判断处，写清支持的范围。

公众号稿同时采用教程模块时，章内小标题用于导航。检查最终可复制的 Markdown 正文，将同一节内必须依次完成的操作写成原生有序列表，将独立核对项写成原生无序列表。与某一步直接相关的异常处理、示例或完成标志，留在相应列表项内，保留其归属。

文章正文按父级采用的 Markdown 或用户指定格式返回。已明确要可粘贴的微信公众号 HTML 或排版时才推进对应排版。交稿前复查阶段承诺、章节顺序、理由与材料、回看路径、链接、锁定内容和所交媒体的实际状态。

## 按已授权字段交接发布准备

用户追加发布标题、头图或两者时，以定稿及明确的需求为准。文章主标题作为正文标题保留，单独收齐所请求的发布字段与图稿。

| 此轮需要 | 交父级调用及回接 |
| --- | --- |
| 公众号发布标题 | 送 Title 公众号字段、准确数量或适用默认、全文或核心材料、读者、搜索需求及锁定项。按 [Title 平台字段](../../../laohu-title/references/entry-psychology-and-platforms.md#平台字段与限额证据) 的项目预算核数，投稿端更严时从严。 |
| 头图带封面主标题 | 保留锁定文字，确需拟字时由 Title 返回完整字面、首要强调词、不可拆语义词组与建议断行、字图互补。将当前选中的文字、核心读者处境、正文承诺及可见证据交 Cover 的信息流封面路径，用同一正文理由选取主视觉。 |
| 头图版式与工件 | 按 [Cover 公众号横幅与方形裁切](../../../laohu-cover/references/layout-typography.md) 检查 2.35:1 完整横幅与中央 1:1 安全区。完整主标题字块和可识别主体在中央方形保留边距，横幅两侧按设计延展。若平台实际入口有独立方封或裁切方式改变，按真实预览检查。 |

在正文之外把发布标题、封面文字及图稿按请求交付。正文、发布标题与视觉应指向同一处境，检查文字承诺有正文支持。真实制图获授权且工具可用时，打开图或渲染预览核字面、强调、裁切和缩略辨识。只有设计、提示词或缺预览时，交可执行内容并报告相应状态。按当前授权处理刊发和保存。
