# 微信公众号文章

若宿主直接命中本配置，先回 [laohu-writing 主文](../../SKILL.md) 承接四维八纲底座、唯一读者定盘与材料授权。本专项不复读通用写作总纲，只强化微信公众号在**手机竖屏独立阅读、扫读呼吸、微信外链限制与发布交接**上的专属物理规律。仅要把现稿转成公众号可粘贴 HTML 时，直接交 [laohu-htmlshow](../../../laohu-htmlshow/SKILL.md)（按需进其内部 `laohu-htmlshow-gzh`），不在纯正文请求里越权出 HTML。

## 一、门内外严分与手机首屏进场

1. **正文内部默认绝不出现外部发布标题**：公众号读者从信息流、搜一搜或熟人转发点进正文前，外部发布标题已经完成了门外拉人；正文内部只留帮手机读者理清层次的内部结构小标题（仅当用户明确锁定要求正文首行放主标题时例外）。
2. **手机首屏按体裁顺畅进场**：观点剖析、痛点破局与故事解读类文章，按主文开头四拍在手机首屏稳稳立住活人破冰、贴脸画面、真实反证与实在回报；叠加教程或实操指南时结果先行、前置条件清楚、直入第一步；沉静人物随笔与平实复盘尊重其克制起手节奏。聊天或原始材料里的内部简称在首次出现处拆短句顺手交代清。改编自口播时，按公众号分层扫读重构开头、小标题与节奏，不照抄口语垫话。

## 二、手机竖屏扫读骨相与视觉呼吸

1. **带势能的递进内部小标题（严禁无分层文字墙）**：手机竖屏阅读极易疲劳，长文必须用清晰递进的内部结构小标题架起骨架。好的小标题像预告片，自带反差、悬念或层层剥开感，随所选经典叙事框架原生生长，绝不跨题材克隆固定模具词。未锁定小标题与核心点睛句需专项精锻时，由父级按 [成稿与标题交接](../../SKILL.md#成稿与标题交接) 走 `laohu-title` 嵌回。
2. **长短段大参差 ＋ 点睛硬句独立短行呼吸**：手机一屏容不下密密麻麻的大方块砖——叙事与展开按自然换气拆成轻快短段（通常 2–4 句），真正打到情绪或洞见高点的点睛硬句大方**独立成极短一行并适度加粗**（像电影特写停顿 1 秒，给读者留出划线转发的视觉抓手），同时让加粗随真实高点自然错落，绝不把全文涂花或与刚扫过的小标题复读。
3. **防 Markdown 列表断号与图文减负**：多步可选做法若每步含多段展开，优先用加粗小节头分节，避开无缩进有序列表复制到严格 Markdown 排版器里全被重置为 `1.`；叠加教程模块时守住有序/无序列表语义。连续多维对比、操作定位或复杂多节点流转，按 [篇内图文四分法](../../references/article-craft.md#按读者任务安排篇内图文) 选唯一对路载体，图放首次需要处且离图正文仍可读。

## 三、升维停笔、微信外链与单块交付

- **高点自然收官，绝不贴 PPT 圆点邮戳**：深度长文按主文双轨高点收官（新鲜跨界升维回扣，或回到本篇现场的克制微动作留白）在高点干脆收笔，绝不补官话蛇足；教程与清单类文章收在验收标志、排错入口或清晰下一步。任何体裁严禁套印分割线加复读小标题圆点，严禁硬喊点赞在看或求关注。
- **外部网址必须可见可复制**：微信公众号正文不支持点击跳转普通外部网页。凡留给读者访问的开源仓库、官网或资料入口，**绝不写点不动的 Markdown 外部超链接**，直接用清晰提示（如复制到浏览器打开）搭配**独立成行的完整纯 URL 或代码块**交付；命令、API 地址、配置和提示词保留原值。
- **单块洁净交付**：默认用单个 Markdown 代码块交完整正文（默认不含外部发布标题；正文含内层代码时外层围栏加长）；配套发布标题、采图单或说明放块外，用户只要正文时块外不堆表功废话。

## 四、按已授权字段交接发布准备（未要求时不追加）

只有用户明确追加发布标题、封面头图或发布包时，才在定稿正文之外按请求字段由父级调度回接：

| 追加请求 | 父级调度与核验要点 |
| --- | --- |
| 公众号发布标题 | 交 `laohu-title` 传公众号字段、准确数量、全文核心材料、唯一目标读者与锁定项；核对字数贴合 [平台字段限额](../../../laohu-title/references/entry-psychology-and-platforms.md#平台字段与限额证据) 且与正文开头四拍严丝合缝，放正文块外 |
| 封面头图与短字 | 保留锁定封面字；需新拟时由 `laohu-title` 回交短字、首要强调词与字图互补，连同读者处境和正文锚点交 `laohu-cover` 信息流封面路径 |
| 头图裁切与工件核验 | 按 [Cover 版式规格](../../../laohu-cover/references/layout-typography.md) 核 2.35:1 横幅与中央 1:1 安全区（字块和主视觉主体在中央方形留边距）。授权实图且工具可用时打开核字面与缩略辨识；未出实图交设计稿或提示词并标明状态 |
