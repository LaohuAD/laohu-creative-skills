# 开篇与阅读路径

主文第4组在新写、重写或修改开篇前读取；用户只改其他局部、无需重做开篇时跳过。输入是已确认的文章目的、读者情境、作者表达边界、体裁方法与真实材料。本 Reference 把它们变成开头和正文接入点，输出回主稿：选定的材料入口、可直接使用的首段、首句与下一句/正文的内容关系，以及需要调整的衔接位置。

## 先分清注意与继续价值

在写第一句前，分别找出两件事：材料里什么容易先被注意；读者继续读这篇文章能实际得到什么。两者可以是同一材料，也可以不同。显眼的数字、原话、异常行为、强观点或场景只是入口候选；如果它只是醒目，却与文章要交付的理解、方法、经验、故事或审美体验没有联系，不让它自动主导开篇。反过来，内容的价值也不必包装成痛点：一个准确答案、一项必要条件、一段可辨认的经历、一个新的观察，都可能足以让读者进入。

### 经验与方法分享从读者关切找到材料入口

对经验、技术、工具或方法分享，先辨认目标读者真正关心的对象、任务、判断或困难，再看材料里有什么能让本文具体回应它；读者所得优先于作者经历，但不等于每篇都要先讲痛点。若具体失败、阻力或代价确是材料支持的阅读理由，就让读者较早看见现象、影响和方法可能改变什么；若更有力的入口是同一对象上的关键差别、准确答案、真实观察或一段有分量的经历，也可从那里进入。作者经历、研究时长或成果用于说明根据、过程和产物，不自动成为开篇主线，也不与读者所得平铺成任选项。价值和对象已经清楚后就进入正文，停止重述同一种受挫或反复预告；不得为了开头制造读者预期、痛点或反转。其他体裁仍按其材料进入，不套这一分享路径。

从已选体裁与材料中找一个能同时接住读者兴趣、作者判断和正文支撑的入口。概念文章可以从目标读者已有的熟悉经验进入，再指出本文要澄清的新关系；Paul Graham《The Age of the Essay》以学生熟悉的学校作文经验引向对 essay 的重新理解，这里只借用“由可共享的已知进入新判断”的组织办法，不套用其英文声口、经历尺度或未核的效果主张。实用文章可先给问题答案、可做的第一步或适用边界；观点/解释可以较早亮出判断，并让附近内容给依据；叙事可以从真实人物、动作、选择或后果开始；观察可从作者实际看到的对象或变化进入；知识整理可从影响读者理解的关系或差异开始。它们是按当前材料选用的做法，不是每篇都要尝试的菜单，也不要求追求冲突或反常。

当真实差别确是本篇值得采用的入口时，先固定比较对象、任务或条件，再找出材料实际显示的具体差别及它改变了什么理解或选择；不要把“反差”“意外”当成解释，也不替读者虚构一种普遍预期。随后按读者已知道什么、还缺哪个前提，选择从材料、差别、判断或结果起笔；把所见根据和它为何关系到本文主题写进具体句段，而不是只命名反差。若没有矛盾或两端比较，准确观察、解释、经验或能回答读者关切的内容同样可以开篇；不为文章性制造反转。放回首段和后续正文中连读，核对材料支持范围、理解承接与作者声口是否成立。

## 让开头本身给出内容

开篇应让读者在文章自身的近处语境中恢复必要的对象与关系：知道正在谈谁/什么，以及发生、被观察或被判断的内容。所需背景按主文已确认的读者前提取舍；对外文章若首次出现私有项目名、简称或陌生角色关系，就在读者需要理解它的位置建立身份和关联，不依赖作者/委托者的内部知识。不要以项目名称、团队履历或经历规模代替读者继续阅读的理由，也不把开头写成背景档案或全文方法复述。首句可以从动作、意象、细节或有意义的省略开始，不必独自交代完整背景；后续紧邻线索可在首段内逐步建立指向。读者不能只靠标题、聊天背景或作者事后解释才知道所指，刻意留白也要让人感到有意而非失去理解入口。句子可以简洁、含蓄或有修辞，判断依据是实际开篇是否接住读者，不是每句填满主语和关系栏。

首段应让读者实际获得开头承诺的一小部分，而不是只说接下来会揭晓什么。判断型开头至少让读者看见判断及其讨论对象；结果型开头说清结果和范围；实用型开头交付答案或可用条件；场景型开头呈现足以定位人物、动作或处境的材料；观察型开头让具体对象或变化可感。需要背景时，保留读者理解核心关系必需的背景，不追求彻底零铺垫，也不把“马上进入主题”误写成必须用短句。

若要从真实方法经验、作品经历或现场观察建立可信度，只用用户已给、材料已有或经本轮授权核实的内容；让具体动作、选择或观察支撑这项经验。不要编数字、头衔、年限、成就或结果，也不默认追问收入、工作年限等背书。没有额外身份信息时，直接让材料与解释承担可信度。

开头形式服从文章本身。没有拍摄画面就不写成观众已经看见演示；读者不必是最大范围人群；不强迫每种材料采用问题、悬念、痛点、恐惧、反转、故事冲突或功利收益。标题已建立主题也不代表文章可以完全依赖标题补全对象；但无需为此把文章首句改成脱离语境的完整说明句，首段近处能够自然建立指向即可。标题与开篇各自承担表达，不逐字重复来填位置。

幽默和回返也从真实材料关系中取。若原话、实际行为或事实关系里确有落差，且符合作者声音，可用具体措辞、动作或并置让幽默显出来；不在事件上另加戏。若一个词句、物件或判断可能在后文获得新含义、对照或后果，先确定第一次出现承担什么、再次出现要改变读者看见什么，再安排位置并连读验证。重复若只为“文采”，或后文没有改变前文意义，就删去；不为工整强造回返或悬念。

对已选故事性的方法分享，可以先呈现材料支持的成果、阶段进展或关键认识，再回到原处境，交代目标、阻力及为何值得继续探索。结果先行只提前交付理解方向，不将尚未解决的问题说成已经彻底解决。选择首尾回环时，在起草阶段明确开头提出的目标、问题或意象，结尾须据正文新增的行动、证据或认识回应它，使含义得到推进；不以重复原句代替回应。开篇建立的主要问题继续约束正文，不因局部案例醒目而另换主线。

## 让下一句和正文继续向前

开篇已经提出对象或判断时，下一句应增加新的事实/证据、解释条件、具体动作、故事进展或观察细节；若首句先留白或从局部切入，紧邻句子可一边建立必要语境一边向前推进。需要数句建立背景时，每句都应补足读者还不清楚的对象、关系、条件或场景，不能用同义句重讲，也不能反复预告后文将有价值。首段之后进入正文时，直接接上开头所需的材料或方法，不重新讲一遍背景。

若开篇、章节转折或收束处的某句符合主文第3、4组所定的关键表达触发条件，就按主文第4组统一契约实际调用 `laohu-title`；不是每个首句、段尾或转折句都自动触发。读者能依靠上下文理解的句子不必独立复述主题或附带“进入理由”。本 Reference 只检查返回句放回开篇、相邻段落和后文后，是否由真实内容引出或回应，不以醒目替代自然的阅读路径。

把开头连同其后的段落放回全文阅读路径检查：

- 开头的判断、结果、问题、方法或体验，在正文中有实际承接位置；标出该位置，若材料不能承接，收窄开头或依授权改正文。
- 转折由新证据、场景、推理、动作或视角变化推动；章节问题只有在下一节确实回答时才保留。
- 叙事、观察和审美文章可以停留、回返或保持未解；每次回返都要能说清首次出现的作用及再次出现带来的新意义、对照或后果，不为结构整齐制造悬念。
- 主标题、小标题和篇内关键表达的字段、调用、返回与保护方式按主文第4组处理；这里不把开篇改造成独立发布标题任务，也不负责平台字段或封面预算。

写完后连读主标题、首段及其后的正文入口，再扫读每节标题与段首，确认读者能跟上从一项材料/判断到下一项的进展。开头若只自报主题、首段结束仍无法恢复必要指向、后续重复铺垫或承诺没有落到正文，就回主文更换材料入口、句段或顺序；不要把有意的留白一律判错，也不要只加解释替实际断裂辩护。

作者判断的语气、用词和节奏由[语言、密度与表达](expression-and-density.md)落实；终稿范围、保护项与质量结论由[修订与终审](revision-and-review.md)处理。只有真实读者反馈、发布观察或相称数据能支持实际阅读效果结论；文本中能指出的阅读理由与内容推进，不能冒称完成率、传播或点击验证。
