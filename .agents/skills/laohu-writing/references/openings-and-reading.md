# 开篇与阅读路径

Writing 在新写、重写或修订开篇前读取。由已确认的读者、目的、材料、体裁和作者声口，得出能直接写入成稿的首段及正文接入点。

## 先分清注意与继续价值

显眼的数字、原话、真实场景或鲜明判断可以引起注意。选择入口时再核读者会因此看清什么、获得什么体验或做成什么，以及材料能否承接。对经验、技术、工具或方法分享，先确认读者正在面对的对象、任务、选择或阻力，再让原材料里可以回答它的判断或差别露出来。失败和代价只有与真实处境和方法选择有关时才承担开篇，也可用准确答案、具体观察或有分量的经历进入。

Chris《粉丝锐评 火力全开》的给定转写先说“这辈子还没剪过一个让我满意的”，再提出怎样和理发师沟通才能剪出满意的发型（7666402441801239834，00:39–01:07）。所用方法是让作者经历引出读者能理解并处理的任务。Paul Graham《The Age of the Essay》从读者熟悉的学校作文经验引入对 essay 的新理解，展示了用共同经验建立讨论起点的做法。借用其中真实的组织关系，由本文材料决定经历、声口和结论。

## 写出开头的四步

1. **扫描陌生前提。** 找本篇最容易挡住理解的一至三个陌生概念、角色或内部名称，在第一次用它说明判断之前，用读者熟悉的工作、对象或动作交代它在什么位置、承担什么作用、解决哪个卡点。可以直接用准确的短定义。熟悉该术语的同行直接进入专业问题。
2. **按体裁选材料入口。** 下表列常见写法，选择能使当前正文继续推进的一项。有意从场景、意象或结果进入时，让首段紧邻线索自然建立对象和范围。
3. **遮掉标题和聊天背景。** 单看首段，检查读者是否知道在谈什么、发生什么或要解释什么、为什么可继续读。若代词、内部称谓或省略使指向无法恢复，补名称和具体关系。必要背景随首段推进，不另写履历式铺垫。
4. **定位兑现处。** 每个重要判断、问题、阅读期待或操作承诺都指向正文某节实际使用的事实、现场、步骤或推理。证据不足就在开头收窄承诺，有成品与反馈就核其实际状态。正文已能开始时，删去重复背景和反复预告。

| 文稿作用 | 开篇的可用材料 |
| --- | --- |
| 让读者完成操作 | 可核对的产物、适用前提和第一步。 |
| 经验、观点或方法 | 读者熟悉的处境与材料里的真实差别，或尽早给出有根据的判断。需要渐次揭示时，先展示具体问题及材料。 |
| 经历、故事性分享 | 可定位的人物动作、时刻、处境或选择；也可先让读者看见真实阶段成果，再返回起点。 |
| 观察或随笔 | 作者确实注意到的物件、细微变化、动作或关系，让体验本身成为阅读所得。 |
| 知识整理、对比或解释 | 会改变理解的分歧、疑问或关系，随后用过程、条件、对照或证据接住。 |

若选择材料里的反差，先固定比较对象、任务或条件，看记录确实支持哪项差别及它怎样改变认识或选择。推定读者预期时保留限定，避免替所有读者补同一种心理。开头所写的经历、数字、头衔、时长和结果，从作者提供或经授权核实的材料取用。

## 让下一句和正文继续向前

开头给出的判断、场景或任务常会自然带出原因、证据、条件或下一步，让紧接的句段推进它。需要设悬念时，留出读者能识别的问题并在正文兑现。选用回返时，在后文用新增认识、行动或材料改变开篇物件、原句或判断的含义。仅整理成熟材料时，先用原文给出的对象名、用途、现成细节与已有关系补开篇所需的理解桥。原材料能直接说明的问题就地说清；另设读者案例、对比、类比或额外规则需要有对应的写作授权。

连读标题、首段、正文入口和节标题。若开头只自报主题、段末仍无法恢复指向、紧邻段落原地复述，或正文找不到兑现位置，就更换相关材料、补出关系、收窄承诺或调整顺序。只有成稿的真实关键位确需专项凝练，才按[标题交接](../SKILL.md#成稿与标题交接)处理；写回开头后用相邻上下文检查。真实阅读、传播或点击结论需要接收证据。
