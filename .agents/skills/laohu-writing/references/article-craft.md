# 长文头身尾力学、经典叙事选框与篇内图文

本文件用于长文与深度内容的骨架锻造与节奏编排：怎么用开头四拍真魂在前 15 秒锁死读者、按核心目标选配经典叙事框架、用正文五重发动机与段落微闭环杜绝中段流失、用升维四拍稳接全篇并在最高点干脆收刀，以及按读者任务安排篇内图文与信息图交接。纯简单顺句或单条短帖不必加载本文件。

---

## 一、开头四拍真魂（前 15 秒签下读者的时间预算）

高潮前置既不是在第一句塞 60 字把答案剧透完，也不是为了硬凑短字数把大白话压成干巴巴的新闻标题。按关联理论（认知回报 ÷ 阅读费劲度）、滑梯第一句、承接既有欲望与信息缺口理论，顶级开头在 10–15 秒内走实四拍真魂：

| 节拍与耗时 | 读者潜意识拷问 | 必须干成的实战真动作 | 致命退化病灶 |
| --- | --- | --- | --- |
| **第 1 拍｜0–3 秒<br>松弛进门，一两句炸碎旧常识** | 费劲吗？跟我以为的一样吗？ | **像老朋友开口聊天一样松弛进门**，在 1–2 句内直接撞碎读者深信的因果信仰、或正面挑战读者的自以为懂。可以 1 句极松弛的生活/历史话头带入 ＋ 第 2 句狠狠引爆反常识炸雷，或直接 1 句带滚烫情绪词的狠断语——主语早早露面、零吞吐阻力 | 把题干现象换词平铺复述一遍零碰撞；硬压字数憋成拗口书面短语；40–50 字长串倒装定语糊脸；全网演烂的老套苦情吐槽或百科起手 |
| **第 2 拍｜3–6 秒<br>面对面活人对话 ＋ 切身反差画面** | 关我屁事？ | 立刻用贴脸对话口吻（像面对面拉着你往身边看）扣回读者脑子里本就在烧的钱、尊严、时间或时代好奇，甩出 1–2 组摸得着的滚烫反差画面把人一把拽进场 | 退回冷冰冰的无人称第三方科普概括；上来抛读者无感的冷术语或抽象背景流水账 |
| **第 3 拍｜6–10 秒<br>真实反证拍死借口，凿深信息缺口** | 按理说不该这样，到底怎么回事？ | 不只轻飘飘提一句大家常怪运气或外行，而是**甩出一句经得起现实推敲的硬反证当场拍死敷衍借口**（逼得大脑瞬间卡住：对啊，真不是这回事，那到底凭什么？！）。**只亮反常果、绝不提前泄光底层因** | 为了凑反证硬编站不住脚的假逻辑（如拿员工无权卸载的企业软件反证不难用）；嘴上提借口却没反驳原地打转；或把前因后果和结论全剧透完 |
| **第 4 拍｜10–15 秒<br>签下摸得着的硬回报** | 看完正文我能赚到什么？ | 一两句干脆亮明看穿这层暗线后能带走的**具体身家、饭碗、报价、选择或改写结果**（华尔街日报核段 Nut Graf），丝滑滑进第一节 | 落成温吞文青虚喻；念先看一再看二 PPT 目录；写我不灌鸡汤防御废话，或空喊这事意义重大 |

正文内部默认**不含外部发布标题**（仅用户明确锁定正文自带主标题，或独立教程/手册确需文档标题时保留）。

## 二、按核心目标选配经典叙事框架（严禁一套模具通吃一切）

动笔前按本篇核心目标选定唯一最匹配的经典骨架，小标题与转场随所选框架原生生长，绝不跨题材复用固定模具词：

| 本篇核心目标 | 经典权威框架 | 情绪波浪与推进主线 |
| --- | --- | --- |
| **痛点破局 / 解决卡点 / 给行动出路** | **SCQA（麦肯锡金字塔）＋ Sparkline 脉搏曲线 ＋ 自主建议收尾** | 刺眼反差破冰（波峰）→ 真实处境代入（降压）→ 硬气挖穿底层根因与横纵时代格局（冲顶）→ 平视体谅心理顾虑（波谷零指责）→ 摊开带门槛与代价的可选打法（放缓零说教）→ 升维收官 |
| **颠覆固有认知 / 犀利观点评论** | **破立辩证（Myth-Busting）＋ Toulmin 图尔敏论证** | 反常事实击穿旧常识（波峰）→ 温和还原常人为何深信旧账（波谷）→ 逐层举证重塑新规律与纵横视野（再冲顶）→ 划清成立边界、落定鲜明个人判断 |
| **科技、商业事件、人物与科学发现解读** | **华尔街日报特稿（In Medias Res 高潮切入 ＋ Nut Graf 核段）＋ ABT** | 极松弛切入颠覆性结果或反常识悬念 → 核段点破与普通人或时代的切身分量 → 沿死局、撞墙、反人性豪赌、破壁翻盘的故事线张弛翻牌 → 升维至历史/人类处境余韵 |
| **一线实战复盘 / 亲历沉淀** | **STAR-L 微缩英雄之旅** | 反差结果或惨痛代价钩子 → 还原真实约束与硬阻力低谷 → 触发拐弯的可定位细节与抉择拉升 → 坦诚交代适用边界与可迁移教训 |
| **教程、原理解释与查阅文档** | **Diátaxis 四分法** | 由父级叠加 [laohu-writing-tutorial](../skills/laohu-writing-tutorial/SKILL.md)，结果先行、按前置依赖零跳步推进 |

## 三、正文五重发动机、自然节拍与段落微闭环

长文 80% 的流失死在 30%–60% 的中段塌方。正文靠五重发动机持续供油：

1. **嵌套悬念链（Nested Open Loops）**：绝不在第一节把开头攒的悬念一次性答完泄气；每次快要解开当前这层疑问时，顺手掀开一层更深、更扎心的新疑问，像俄罗斯套娃把人一路拽到底。
2. **抽象阶梯上下高频穿梭（Hayakawa ＋ Sweller 认知负荷）**：工作记忆极易被连续抽象概念压垮。**抽象规律绝不连续裸奔超过两段**——高空硬判断 ↔ 地面滚烫具体的人、场景、实在算账或鲜活比喻高频切换，既不缺氧、也不嫌浅。
3. **倒三角挖深拉宽 ＋ 每节微顿悟 ＋ 2–3 处黄金记忆点**：绝不把用户的零散思考做 1 对 1 原地翻译；必须往根子上多掘一层第一性机制，横向切开生态位角色、纵向拉通时间演进，并主动拎出读者心里刚冒出的常见反驳当场击穿。**长文每一节切入时，优先从读者眼前的拧巴日常、具体算账或鲜活现场进门，再自然引出历史事件或专业概念**（绝不连续几节一开头就硬上历史课）。全篇集中锻造 **2–3 处留有半步认知空白的黄金记忆点硬句**（可自然选用熟语微拧、前扬后劈反转、反讽冷刀、跨界动词撞击或极简人性公理，顺滑无门槛、服务情绪痛感、单独截出自带传播力，绝不句句抖机灵），大方独立成短行把电路焊死（关键句按需联动 `laohu-title` 篇内关键句专项精锻）。
4. **自然呼吸节拍 ＋ 段落级微观四元闭环（RST 修辞结构理论）**：
   - 每节顺着**顺钩进场 → 具象与抽象上下穿梭 → 击穿反驳制造微顿悟 → 砸下点睛硬句（波峰）→ 依段落目标自然收口**推进，过渡手法和句式随本节情绪自由变换，不把各节写成一模一样的填空题；
   - 写每一段前明确其**目标、波峰/波谷语气**与**三类战术结果之一**：① **埋钩子（Open Loop）**把人无缝滑进下段；② **降压蓄水（Release）**放缓节奏给故事呼吸或平视共情，消灭大脑习惯化与心理抗拒；③ **一锤定音（Closure）**闭合当前一层认知。
5. **单次使用零复读 ＋ 写实与商业路径边界**：正文主体前面用过的例子、核心意象和道理，后续章节绝不换壳炒冷饭（Daneš 线性信息推进）。绝不编造虚构人名、虚假个人亲历或伪造统计；仅当文章明确承诺个人入行或商业赚钱路径时，须诚实写明具体需求方、替代方案与代价、付费条件、真实门槛与收益依据。

## 四、双轨高点收官力学（稳接全篇 ＋ 最高余韵处利落停笔）

依据 Daniel Kahneman 峰终定律、Morgan Housel 镜头拉远升维、Roy Peter Clark 环形回扣与 William Zinsser 高点停笔律，深度长文收尾严禁机械套印分割线加四条复读小标题的汇报圆点，也严禁硬喊点赞关注触发心理抗拒。按题材真气在两条高水准路径中择一自然收官（操作教程与内部协作文档则收于验证标志、排错入口或清晰下一步）：

- **路径 A · 广角升维四拍（最适合观点破局、商业/科技/历史解读与规律剖析）**：
  1. **停辩切阔境（选新鲜切片，避用烂老梗）**：正文彻底讲透后，收起说理刀锋，用一处**新鲜、贴切、没被该领域写烂的跨界旁征博引**（历史真实切片、另一行业底层规律、科学或人文瞬间、人类共通生命体验）把放大镜猛地换成广角望远镜；
  2. **四阶真升维**：借这处具体可触摸的跨界切片，一两句点透藏在漫长历史、时代潮水或人性深处的不变规律（严防脱离具体切片空喊宏大口号，也严防连叠两三个互相打架的比喻）；
  3. **环形回扣承接**：顺势把镜头轻轻摇回开头抛出的核心矛盾、年代、人物或悬念，让全篇血脉自然闭合；
  4. **高点即停 ＋ 未来窗口**：落在一两句极简、有体温、有骨气、带未来视野窗口的余味短句上**立刻收刀**——**一旦站上最高回响，绝不再往后补一段四平八稳的总结官话把余韵冲淡**。
- **路径 B · 原场微动作定格留白（最适合克制人物特写、亲历叙事与沉静观察随笔）**：
  - 不强行跳去毫不相干的宏大跨界故事，而是顺着前文积累的情感与事实，把镜头轻柔落回开头那个具体人、物件或生活角落的一处细微变化与安静动作上，用极克制的一两句实景留白稳稳收住，把回味空间交还给读者。

## 按读者任务安排篇内图文

文章骨架或初稿成形后，扫一遍读者在哪里容易卡壳（找真实界面、盯多条分支、横向对参数或复制命令、需要画面衬托体验）。**单靠文字或简短列表就能一眼看清时，绝不为了凑图硬配图**；确有明确读图任务时按四分法选唯一对路载体，并确保离图正文仍可读：

| 读者真实卡点与材料信号 | 唯一正确载体与分工 |
| --- | --- |
| 找菜单、点按钮、填表单、认软件/终端真实回显 | **真实操作截图**：按 [实操截图的三条路径](../skills/laohu-writing-tutorial/SKILL.md#实操截图的三条路径) 核验已有实图、授权实采脱敏，或正文外交付《实操采图执行单》。**AI 生成图与概念示意图绝不能冒充真实软件界面** |
| 至少三个相连节点、条件分支、跨角色交接、分层架构或循环机制 | **关系信息图**：明确读图任务后，按下节八字段实际调用 [laohu-cover](../../laohu-cover/SKILL.md) 信息图分支；简单两三步直接用列表 |
| 多对象同尺度参数对比，或需要复制命令、配置、字段名、提示词原值 | **原生 Markdown 表格、列表或代码块**：由 Writing 直接落成可编辑、可一键复制的真文本，绝不把代码截成图片 |
| 故事、随笔或观察需要画面承载处境与氛围，不含复杂逻辑解析 | **实拍素材或表现画面**：已有真实图片先核身份来源；需新设计纯氛围画面时调用 [laohu-image](../../laohu-image/SKILL.md) |

## 信息图交接与实图核验

确需篇内信息图且在当前授权范围内时，由 Writing 实际读取并调度 [laohu-cover](../../laohu-cover/SKILL.md)（走其内部信息图专项），直接从当前上下文填齐以下 8 项交接要素（不用用户另填表）：

1. **插入锚点与邻文**：所在准确章节、前后关键句，以及图和正文各自负责什么（不让图单纯复述正文）。
2. **读图任务**：读者看这张图到底要分辨哪几层组成、对比什么、追踪哪条分支，还是定位局部在整体的位置。
3. **已有前提**：前文已经交代过、图里无需重新解释的对象或概念。
4. **精确命题与物理可画关系**：全部可核对象、关系词、箭头方向、条件分支、顺序、单位与适用范围（附出处及待确认项）；把正文里的抽象概念翻译成画面里**看得见的对象、层级与流向**，绝不把抽象抒情句或文学比喻直接塞给生图/排版工具。
5. **锁定词与文字分工**：必须逐字锁定的专名、数字、标签与条件，以及哪些字放图内、哪些留在图注或正文。
6. **文字密度与制作路线建议**：核心标签数与全图必要字数。结构清爽、核心字较少（约 25–30 字内作参考）可试中文直出并实图逐字核验；标签长、节点多、含精确数据/代码/单位或必须逐字锁定时，建议走无字底图配精确贴字表，或走可用的 `laohu-htmlshow` 输出 SVG/HTML 矢量精排，由 Cover 依目标显示尺寸拍板。
7. **显示约束**：栏宽、手机/电脑阅读尺寸、画幅比例及需延续的视觉风格或品牌约束。
8. **本轮授权与工件状态**：明确是只出设计稿与提示词，还是已授权直接出实图。

**回接联合终审**：收到图稿后按正文 → 图 → 后文连读核对术语、数值、单位、箭头方向与证据边界。**只有实际生成并亲自打开核验过目标尺寸下清晰度与中文零错字的真图，才能以真实路径嵌入正文**；尚未出图时正文保持独立可读，把锚点、图注与可执行提示词或贴字规格放正文外并标明待制作，绝不伪造图片链接或 Markdown 占位图。
