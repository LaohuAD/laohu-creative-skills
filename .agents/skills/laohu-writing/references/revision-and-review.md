# 修订与终审

用于把用户反馈、事实核查和完整稿阅读转成针对当前文章的实际修改。审稿不能只增加清单、解释规则或为初稿辩护；发现差距后，直接修改造成差距的文字、材料次序或承诺。

## 先定位反馈影响的范围

把反馈落实到它要求改变的读者所得、作者判断、事实、材料关系、文章结构、具体词句或交付边界。只处理获准部分：局部改稿不顺手重写全文；事实纠错不自动改掉已确认态度。用户明确锁定或要求保留的原话与标题逐字保护，除非本轮授权改动或新证据确实冲突。对已确认的观点、立场、声音力度、事实及材料顺序，保留其原义、归属与关系；只有用户要求调整或证据冲突时才改动，并说明必要范围。

如果本次修改涉及新写或修改主标题/小标题，按主文第4组统一契约调用 `laohu-title`；本 Reference 不重列调用流程，只检查返回文字是否实际放回文章并发挥对应作用。已锁定或无关的标题字段不改写、不为该字段调用；这不阻断本轮获准且符合主文条件的另一处关键表达调用。普通局部说明仍由 writing 修订，不自动触发 title。

审稿若发现某个具体句子符合主文第3、4组的关键表达触发条件，就按主文第4组统一契约实际调用 `laohu-title`，不必等全文定稿。本 Reference 负责检查返回句是否放回其实际位置、是否保留必要上下文并与相邻段落和全文推进相合；writing 仍决定采纳、修改或舍弃，不按孤立金句评分。普通叙述、解释和衔接不因重要而自动调用。局部任务仍保护无关正文，不把协作扩成代写全文。

## 从成稿找最早的断点

重新读全文时，重点看文章到底有没有通过真实材料达成目标，而不只看小标题是否齐全：开头是否只是自报主题、没有让读者早些看见其阅读理由；材料是否只被摘要，未展开到足以看出差异或推理；作者本来能够承担的判断是否退成中性介绍；经历是否只有结论，没有让真实选择及后果参与文章；技术说明是否为了叙事或修辞牺牲任务步骤和判断边界。

对采用故事性方法分享的稿件，沿主要问题核对实际推进：读者是否知道目标及阻力，重要反馈是否改变了后续判断或行动，方法是否解释并指导了具体处理，成品和反馈是否回应前文。案例结束后检查主线是否仍在推进，方法段落是否只报名称、叙事段落是否只报经历。发现断点时修对应材料、解释或顺序，不靠增加挫折、悬念和情绪词补救；若采用回环，核对结尾是否增加了新的理解而非重复开头。

对技术或方法分享，先核对读者的真实疑问、关键主张和相称根据，再看正文有没有解释根据为何支持或限制该判断。作者学习写法的方法来源是否被误当成读者论据？若本篇目标包含让读者亲自应用方法或完成任务，输入材料、观察到的差异、选择依据、具体动作、中间/最终产物、结果核对和适用条件是否足以复现？前后比较是否保持同一任务尺度，观察到的变化是否被误写成因果效果？若目标是理解概念或关键关系，文章是否清楚解释关系及其边界，而没有强加教程动作？

按最终正文核对重要专名、缩写、内部项目简称、关键关系和文章依赖的读者前提第一次出现在哪里；确认它们已在读者需要理解的位置建立，而不是只对作者或委托者熟悉。熟悉程度高的读者不重复不必要的定义；陌生读者需要的身份、用途或关系则就地补足。

初稿完成后，从实际正文反做提纲，指出主要段落或章节新增的理解、根据、动作或体验，它依赖的前提，以及怎样承接上一部分并交给后文。对照本篇读者所得、中心主张及正文承诺，定位真正承担解释、处理或结果的文字：概念名称不能代替关系解释，处理要求不能代替实际处理，计划和流程不能代替文章承诺展示的产物。若只能找到这些替代内容，或出现缺背景、断推进、材料已有却未解释其作用的断点，回到对应材料和生成步骤补足，而不是仅改小标题或增加总结。找到最早断点后，修正受影响的文字与顺序，再连读相关上下文；内部核对过程不进入文章正文。

反向提纲还要落实到删改：记下各段实际表达的意思和作用，标出首次说明、后来新增的依据/应用/条件/动作/体验，以及只换说法重复的段落；跨段比较按[语言、密度与表达](expression-and-density.md#跨段检查重复并保留作者语气)执行。做一次删除比较，具体指出删去该处会损失什么；说不出可辨损失，就删去或合并。确有损失时只补回必要表达，不把同一观点换成更多句子再解释一次。若保留理由只是“这里有共鸣/情绪/过渡”，回到表达 Reference 核对这句话具体说中了什么、正文呈现了什么理解或体验变化；意图或功能标签本身不是文本效果。保留有依据的声口、停顿和费劲感，不把全文退成报告口气。

只有本篇目标包含亲自应用方法或完成任务时，收尾才需给出有材料支持且适用于本文范围的一步，以及可辨认的完成判断；概念性分享以读者理解关键关系为结果，不强加练习或教程式结尾。观点文、观察随笔和忠实整理若没有相应任务，也不强加教程步骤。找到最早断点就修实际材料、解释或动作，不用新增免责声明抵消仍成立的作者判断。

这些是定位常见断点的入口，不是每篇都要满足的配额。观点文可以不讲个人故事，观察文章不必给行动办法，指南也不需要强立场。如果文章的材料和目的确实支持清楚回答或平静描述，不为“有吸引力”添加对立、情绪或戏剧性。

找到最早的失效关系后，修改它以及受影响的后文：开头理由不足就换真实入口并调整兑现；主张没有根据就补材料、缩小主张或改变表述；材料被摘要就展开关键部分；语气被磨平就还原作者已确认的力度；过程缺少读者可执行信息就补齐输入、动作、检查或限制。不要只在失效处换一句口号。

## 保持模型和事实一致

把万能造梦框架继续用于修订：确认反馈改变了文章目标、所凭判断、具体选择或成文结果中的哪些关系，并让修订在实际稿件里可见。它贯穿前面的设计和后续修改，不是交稿前打勾，也不用向读者解释成十六个编辑栏位。

修订后核对事实、来源、原话归属、用户保护项和推论边界；确认修改未引入新的事实、改变了材料身份或削弱用户已经确定的立场。观点是否强由证据所能支持的程度决定，但不能把一项具体的范围限制扩展成全篇防御语气。

## 读回与交付

至少从头连读一次，再扫读主标题、关键表达、开篇、各段/节入口和结尾。确认开篇在文章自身的近处语境中能让读者恢复必要指向，而非只靠标题、聊天背景或作者补充；首句可以留白或先呈现局部材料，判断标准是首段实际能否接住读者。首段确实交付了内容，后续带来新的证据、解释、步骤、场景或故事进展，而非重复背景或重启预告。逐个看小标题是否对应实际章节内容、帮助读者在篇内导航并承接前后推进；它们不必成为独立广告，但也不能让读者误认本节将提供的内容。需要凝练的关键句要和相邻段落一起判断：作用是否真实、必要前提和材料关系是否保留、下文是否继续承接；不要求每个中心句都能脱离上下文独立成立，也不把金句感作为验收条件。判断中心主张是否可辨、关键材料是否真的被展开、明确承诺是否兑现，语言和结构是否适合本篇体裁。把引文、链接和用户提供的图文材料放回对应上下文，确认其来源身份与支持范围没有被改写。若改动之后出现新的断裂，就继续修整实际稿件。

再做一次针对本篇的语言复核：句群是否充分展开，作者态度与材料支持的情绪是否实际进入文字；若正文只剩概括或报告口气，回到原材料补出必要的具体动作、理解联系或态度。删修饰语、复沓或舒展表达前，先把它放回完整句群，确认它是否传达有效的费劲感、期待、珍惜、停顿或情绪承接；删改后连读，比较对理解、感受、重心和节奏的实际影响。只有找到本篇具体的偏离（如无作用的重复、关系不清、材料不支持或声口走样）才据此修改；不以假设性的“可能冗长”或“应当更克制”否定已服务本篇目标的表达，也不按长度单独判错。

有篇内图时，由 writing 做联合终审：站在第一次阅读的读者位置，按正文到图、再到后文的顺序检查锚点是否自然，图与正文的术语、关系和关键条件是否一致，图注与来源是否超出证据范围，以及图是否让关系更直接可见、更易比较或降低理解负担，而非仅复述。正文或图稿任一方变动，都重查受影响的邻接部分。只有实际打开并查看了真实图像/显示尺寸，才称图像身份、画面关系或目标尺寸可读性已核验；完整提示词本身不能证明成图可读。

没有真实接收者反馈、发布表现或独立评审时，只能报告文本中观察到的优点与差距，不把“结构通过”“已调用参考方法”或作者自评说成读者吸引力已经得到验证。已由接收者确认的质量失败仍保留为 `FAIL`；结构检查、稿件规则覆盖和新试写不能追溯性抹去失败，也不能单独证明新版本已通过。
