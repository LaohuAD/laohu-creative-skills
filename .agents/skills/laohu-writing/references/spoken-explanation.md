# 口播讲解的专项复查

口播基本流程由 [口播与讲解稿](../skills/laohu-writing-spoken/SKILL.md) 承担。复杂解释、多个独立判断、声画同步、实际估时和录后校对按对应小节读取。只复盘 ASR 时返父级按原音和已确认讲述目标判断证据，复盘结果随原请求交付。

## 按内容作用选择讲法

| 当前任务 | 进一步检查与修改 |
| --- | --- |
| 解释信息或机制 | 从实际疑问确定关键对象、先后、协作或因果关系。动作和条件紧挨其可见后果。公司、岗位和术语放入其承担的关系。缺关键事实由父级回 Analysis 核具体缺项，句法问题直接改稿。 |
| 推导观点 | 从 [结构与论证](structure-and-argument.md) 取主张、根据和连接理由。标出材料中确实支持作者判断的那一点，写进听众需要的位置。只有相关例子却需要猜其作用时，先补连接理由。 |
| 说明机会、选择或做法 | 查开头的具体许诺，再找本段能否说清客观条件、动作与所得。行业规模、机构或岗位名单只支撑其覆盖范围。材料有条件地支持读者作判断时，给当下能判断什么、下一步具体查什么。 |
| 承接体验和个人选择 | 从作者在意的对象、投入/期待及具体反馈找到态度来源，给必要的态度和节奏留空间。兼有解释任务时，先让听众听清真实过程，再自然接入反应或选择。 |
| 转换视角或接续内容 | 先复述两个句群实际怎样相连，再写能听出的承接。需要解释“接下来为什么讲它”时，用上段已建立的对象、结果或限制作为下一段起点。 |

一次口播里的早晚段落可各自承担多项作用。逐个检查承重段落能否在当前所知条件下听懂。决定展开还是删减时，先标独立认识及必需的材料、关系、条件与节奏承重。关键关系没说透则从来源补足，已讲明的背景轻带。重复能表现投入、态度、停顿或对比时保留其作用。数量和字数只是辅助核对。

### 生概念与不合适的例子

普通词替换完但首次听仍不知道所指时，找出听众需要的关系。材料有多种定义、框架或层级时，以实际资料给出每个名称的职责、相互搭配和变化的条件。试将专名换成实际作用复述。换完只能听出名词数量而解释不出关系，则需补用法或来自材料的具体过程。听众熟知的部分依真实背景处理，未知的含义由父级向用户核实或缩小讲解范围。

选案例看它的解释作用和理解成本。依据 [材料、来源与证据](materials-and-evidence.md#回到文章主线) 比较案例能否交代同一个对象、实际动作和关键后果。换对象可能使样本、技术类别或结论发生变化。有准确的直接过程时可省掉陌生案例。讲图像识别、图片生成等不同关系时，用同一准确称呼贯穿段落。分享式口播保留作者原有态度。少量吐槽用于节奏时，移除它复读一遍，主推导仍须完整。用于帮助理解的类比重点查物件之间真实共有的关系。

## 核对声画与可见条件

1. **对照实际媒体。**从声音文本圈出听众需要“看这里”的句子，定位实际可达的画面或字幕以及发生的时点。记录镜头、画面区域、可读字或可见状态。素材没到时标出需求和待验证对象，可以先成可用的内容稿。
2. **安排共同承重。**旁白给名词、比较口径或动作目的，画面给相应对象、操作位置、关系或状态。必须等待画面出现才能成立的一句，和画面同段定位。一次出现的信息较多时留够观看或操作时间。听觉自足任务中的关键关系一律能离开画面听懂。
3. **检验错位和移动。**把可用画面或字幕与净稿按实际顺序连看。先核旁白指到的位置、图片中文字、箭头与条件、画面出现的先后和清晰度，再核换镜后指代仍成立。缺少实时素材时明确对应待验处。有需要向制作端提供锚点、旁白中谁说什么、画面必须出现什么、预期状态、实际素材或待制作。实际录音、镜头和字幕以制作端检验后的版本为准。

## 把时长当作本次可调预算

同一说话者、相近难度和朗读方式的录音最适合做校准。按实际念法取有代表性的段落，时长含自然停顿。可用讲话时间为目标总时长减已知独立无声展示时间。用户只给语速或需要粗估时，写清本次假设的字符/分钟口径、哪些停顿已计入和有哪些独立静音。数字、缩写、网址等先展开为实际念法再算。有实读时用同一时点计开头、结尾和较密段。估计与实录分别呈现。

超出预算时，先指出听众可少听哪几项，再核剩下的独立认识、解释和作者方向是否完整。可按用户已接受的更快语速试读，验证清楚自然后采用。严格时限与必要内容冲突时，指出砍哪项会损失什么，问影响这项交付的最小选择。

## 试读与复核

试读时一人按正常速度念，听者首次接收只关注自己在哪一处失去对象、听混数字、没听到条件、需要看上一行，或在停顿前后感到语义断裂。编辑者从这些位置反做提纲，标清承诺在哪里兑现、证据怎样接到结论、听众此刻能理解什么。已有原始录音时用对齐的原音、文字和已确认目标复核漏讲、换序和停顿。ASR 可能漏字、误断句或听错名字，孤立 ASR 只能提供待核点。

对照原稿核成熟语气和承重解释。专名和数值必要时补真实读音提示，核字幕和附注是否误入净稿。对真实录音已标出卡顿或误解的句群，调整直接导致问题的措辞和邻句，再复查该处声画和必要下游。口播校对以目前实际取得的文本、试读、录音和画面为证。只读文本时报告文本检查和必要估时。此处试读方法参考 CDC《CDC Audio Script Writing Guide*》（2011 年 4 月修订）中按听觉组织、试读及发音提示的做法，并按普通话语序与本次目的调整。
