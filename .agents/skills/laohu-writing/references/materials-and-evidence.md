# 材料、来源与证据边界

本文件用于处理多源材料混排、外部研究引用、口述编辑深度边界及用户自带图文素材，守住每一条材料的真实身份与支持范围。简单单源短稿、纯顺句或已有核验内容设计时不必重复通读本文件。

---

## 一、分清材料五种身份，绝不混写

动笔前先把眼前的材料划进五个格子，各自归位、互不越界：
1. **作者原话、亲历与直接观察**：能支撑本次覆盖的对象与范围；单个亲历可以展示一种可能或机制，绝不单独吹成普遍行业定律。
2. **作者已确认的观点、立场与情绪**：明确属于作者的判断或约定，保留其锐度与态度，不因追求客观而暗中磨平。
3. **外部来源、访谈原话、公开数据与已有图文**：归属原出处，绝不写成作者亲历或作者原话。
4. **编辑推论**：在获准发展编辑时，基于材料真实差异推演出的联系或判断，须回核材料能否承受，不冒充实证事实，也不改写用户已锁定主张。
5. **未知与待核项**：材料里没有的对话、心理、次数、金额、年限、头衔或效果，**一律不凭空补编**。只有真正会改变核心主张、读者理解或操作结果的缺口才去核查、询问或收窄范围，其余未知坦然留白。

**内部聊天脱敏原则**：把聊天记录、访谈笔记或项目复盘改写成公开文章时，只挑真正帮读者理解主张、方法或操作的内容。聊天里提到的内部代号、团队拉扯或规则争论，若对陌生读者没解释价值就只当后台依据；确需保留的内部对象，在首次出现处交代清用途与身份。

**按实际用途归类**：沿用外部框架或用户自定义状态分类时，核准每类的定义、处理方式和结果，绝不因标签相似就把不同处理揉成一类。

## 二、口述、ASR 与现成稿的编辑边界

- **只授权整理、成文或一般润色（忠实编辑）**：当口述、ASR 或现成稿已经具备清楚主线与观点，且用户未授权发展重写时，只做媒介适配——删口头重复与绕圈、理顺语序、从原材料里就地补齐指代与必要衔接，保护有效原话和成熟判断。**绝不擅自新增案例、理论、新判断或跨出材料的对比**；ASR 里的歧义词若会改变事实或立场，不靠瞎猜定性，选更窄表述或标待核。
- **获准发展编辑与重写**：仅当用户明确要求深化论证、补解释桥、融合多源材料或重组主线时，才展开相应推理或核查；即使现成稿写得像成品，审查或发展时也要拿给定材料反核，收窄原稿里站不住的绝对断言和错位因果。
- **开篇可信依据不瞎编背书**：需要让读者知道作者凭什么这么说时，只能从本轮材料里挑实际做过的动作、观察、过程或可核记录；绝不编造从业年限、头衔、收入、成绩，也不默认追问背书，缺背书就靠材料本身硬推理立住。

*(注：录后 ASR 复盘的原音与预定目标双证据矩阵，唯一真源维护在 [revision-and-review.md](revision-and-review.md#录后-asr-复盘证据矩阵)，不在此重复。)*

## 外部研究、引用与可复制链接

- **什么时候该查、什么时候不查**：只要某项外部事实、数据或机制解释会影响核心判断或读者采用，且现有材料不足、本轮又允许核查，就查原始研究、官方文档或能交代条件限制的可靠一手源。现有材料已自足、或用户禁联网/只授权忠实整理时绝不扩权，改为用好现有材料或收窄主张。绝不为显得专业而给常识观点硬贴权威引文。
- **数字与对比必核同口径**：金额、比例、排名、产量等时变数据，必核原始来源、统计时间、单位、分母和定义；不同口径不强行并列比较；没有统计时不补编数字，没有对照时不把先后发生写成因果效果。
- **正文引用必须可定位且讲清关系**：
  - 凡正文依赖外部来源支撑关键判断，在对应判断旁给出足以定位的出处（作者/机构、文献名或有效链接），说明它支持哪一点、不覆盖什么，并把来源结论与作者自己的推论区分开；
  - 引文原文无法核实时，绝不加引号冒充原话——核实、改为明确转述或删掉；
  - 写作者用来选结构或挑写法的方法来源留给后台指导写作，除非用户要求或读者确需核对，不搬进正文当论据。
- **外部可复制链接规则**：
  - **微信公众号文章**中，面向读者继续访问的项目仓库、工具官网或教程入口，**必须把完整 URL 写成独立可见行或代码块供读者复制**；若同时保留可点击锚文本，确保显示地址、链接目标与可复制文本三者一致；
  - 普通文章、飞书或技术文档照常使用清晰锚文本链接，但命令、API 地址、配置和确需复制的网址一律保留完整原值。

## 四、用户自带图文与待制作图的真假边界

- **自带图文保真身份**：用户提供的截图、照片、图表或示意图，完整保留其来源、制作方、时间语境与锁定属性，绝不擅自改名、推断原作者未说的意图或把概念示意图改写成实测截图。文章只陈述画面本身可见或用户明确说明的事实——截图证明界面呈现，不自动证明画面外的商业效果或普遍规律。
- **真图与待制作方案彻底分开**：**只有本轮实际可访问、能打开核对过的真实图像才能写入正文图片路径**并配准确说明，不与图上已有文字重复。Cover 返回的设计稿、生图提示词或《实操采图执行单》均属于待制作方案，绝不写成已配图，绝不伪造图片地址或 Markdown 占位图。后续收到新实图时，先实际打开核清身份与内容仍贴合锚点再嵌入。
- **换例子先核关系等价**：获准替目标读者换一个更好懂的例子时，必须同时满足解释的是同一对象关系且理解成本更低；若原推论本身有错，先回修推论而不是换个例子蒙混过关。用户随口举例解释需求的片段，先判身份不自动塞进正文。
