# 写作前置内容设计与承重逻辑核查

本文件已由 `laohu-writing` 收回自治，仅在以下四类复杂情形触发（普通整理、润色、成熟材料成文、常规单帖与短说明 **0 加载**）：
1. 获准融合两类及以上散乱异质材料、重建多节长稿结构或深化复杂论证；
2. 文章明确承诺行业参与、岗位转行或商业赚钱路径，需要核穿现实门槛与闭环；
3. 需要核查可能推翻中心判断的承重外部事实或冲突来源；
4. 局部改稿发现两项核心判断之间缺少成立理由，或开放探索的新关键句实质动摇了全文主线。

遇到棘手的多方冲突、需要深度归因拆解或跨模块协同核查时，通过 [laohu-analysis](../../laohu-analysis/SKILL.md) 配合本文件完成拆解，定盘后再回到 `laohu-writing` 成文终审；材料清晰可直接在当前任务内算透时，按本文件直接完成轻量设计并起草，不额外走冗余表单。

---

## 一、先钉死本篇交付什么认识与承诺边界

1. **明确真问题与读者前提**：一句话说清文章到底回答什么、给哪类读者带来什么新理解或操作结果；标清读者已经懂什么、哪几个前提会卡住他。锁住原稿里已经成立的立场、亲历、声口和锁定原句（包括作者明确认可或拒绝过哪些有参考价值的原句及原因）。
2. **商业与行业路径硬核验**：如果只是解释行业构成或运行机制，讲清上下游即可；**一旦文章承诺读者个人参与、入行或商业变现路径**，必须先核清六个硬问题——谁有真实痛点需求、现在用什么办法且代价多大、掏钱条件是什么、个人需要什么能力与资源门槛、怎么交付与闭环收益、材料支持的现实下一步是什么。行业规模增长或存在某些岗位，本身绝不构成个人收益依据；材料撑不住就果断删缩承诺。

## 二、查清会改写判断的关键事实与承重因果桥

- **只查会改变判断的未知**：把可能推翻中心主张、读者决策或核心机制的疑点列出来，按授权查相称的一手来源，每条承重事实记清出处、适用时间、对象与条件。来源互相打架时，先比对时间、定义、样本口径和使用条件——条件不同就分划边界，同条件互斥再补查可裁决证据，未解时收窄依赖它的主张。
- **逐条搭牢承重因果桥**：对每项核心主张核清三件事——判断本身是什么、凭材料里哪条根据、凭什么这条根据在当前条件下能推出判断（跨度大或有明显反例时补足条件与边界）。**时间先后和同一话题只提供摆放线索，绝不自动等于因果或递进**；缺根据绝不硬凑逻辑，把结论收在材料能承受的范围，作者的愿望照实作为愿望表达。
- **选对讲述关系与提前扫图文缺口**：解释变化走过程线，拆组成走角色交接，做比较先对齐对象与尺度，选案例核清理解成本，挑出最值得原样保留的作者好原话。顺手扫一遍全文哪些位置需要读者辨认真实界面（标清已有图/待采图）、追踪复杂多节点关系（标清可核命题）或复制原值，记入设计备忘，此时不越权出图。

## 三、交付轻量内容设计包与成文前校验

设计完成即可直接进入写稿（已有可靠设计时直接复用，不重复重做，获授权范围内无需强等大纲审批）。**防反向散文污染铁律**：这份设计包是给下游写稿定盘的极薄白描卡片——只交大白话核心主张、硬核根据、纯实体事实与明确边界，**物理剥离气氛修饰形容词，绝不写成文艺散文详案，也绝不把背景材料当成正文必须逐条塞满的打卡清单**。动笔前用 5 项极简核对确认设计足够落地且无内部打架：

| 设计核对项 | 必须落到实处的判断 |
| --- | --- |
| 读者、媒介与承诺红线 | 谁看、看到哪一步为止、哪些延伸本篇不承诺 |
| 中心主张与证据边界 | 可发主张、承重出处、支持与限制条件、关键未知 |
| 承重单元与推进顺序 | 每节具体干什么（解释/论证/经历/步骤）、实际材料、前后依赖与开头兑现位 |
| 视觉与实操素材提示 | 真正需要的锚点、读者动作与实图/待核状态（不需要图文直接留空） |
| 锁定项与开放空间 | 锁定的标题、原句、立场与声音依据；其余段落留给写稿自由发挥 |

**写前硬复核**：若接回的设计本身存在主张打架、依据撑不住判断或吞掉了锁定项，**先停笔指出冲突并退回修准，绝不带着坏设计硬写**。

## 四、局部补桥与开放探索改主线的最小返工

- **局部缺逻辑桥**：只取争议那一段、两端已确认的判断与主语对象、手头根据和直接依赖。核清材料到底支持什么承接理由——只够支撑部分联系就如实限定范围；补桥时严守两端原有的称谓、泛称范围、动作与对象，绝不拿隔壁无关示例替原句擅自缩窄指称。
- **开放探索动摇主线**：若 `laohu-title` 或写作探索出的新句子真有洞见，但会改写文章核心主张或全篇架构，先核实质修改授权；获准后从最早需要调整的证据或前提改起，只同步联动受影响的开头承诺、直接依赖段与结尾，护住其余仍成立的正文与锁定项。仅授权改词句时，保留原主线，把这份可能改写主线的发现单独告知作者拍板。
