# 语言密度与修辞编辑

用户指出沟通或文章措辞不自然、判断太绕、抽象概念难懂、信息密度不足或修辞不合适时读取。聊天和文章遵循同一套现代汉语标准；依据表达任务、接收对象和材料调整背景、语气与解释多少。确定句子任务，检查词义搭配、对象关系、条件与节奏，完成必要修订后回到当前任务；修改文章时返回主文第六步。

## 1. 高信息密度的判断单位

**密度看一句话承载了多少有用关系，不看它压了多少生词。**

一条有效的凝练判断，通常让读者辨认出以下信息中的两个或多个：

- **对象**：谁、什么、哪类材料或处境；
- **关系**：影响、条件、冲突、选择、因果、包含、限制或变化；
- **判断**：作者认为这关系意味着什么；
- **范围**：对谁、何时、在哪些条件下成立；
- **后果**：读者应重新看什么、判断什么或如何行动。

不必每句填满所有项。只要句子省去一项会让关系无法理解，就把那项补回来。专业术语只有缩短共同理解的路径、且读者能准确理解时才增加信息密度；术语堆叠会提高解码成本，不能算密度。

## 2. 把概括句从材料中提出来

| 编辑动作 | 怎么做 | 产物 |
|---|---|---|
| 找重复关系 | 比较材料里的多个场景，找共用的对象、条件、选择和结果 | 关系清单，而非漂亮词语清单 |
| 选概括层级 | 判断需要写具体事件、同类经验，还是更上层原理 | 适合标题、段首或结尾的候选层级 |
| 写出主干 | 用常见名词作对象、明确动词说关系；限定词只在证据需要时加入 | 一句读者能复述的判断 |
| 对照反例 | 找材料中是否有相反情况；若有，缩小范围或说明区别 | 不会被一个明显反例推翻的范围 |
| 展开验证 | 让后文用材料说明对象、关系、机制和边界 | 能被正文逐项解释的概括句 |

从成熟口播中提炼标题、段首判断或总结句时，按这个顺序筛选：先保留作者已经成立的完整命题；再确认对象与关系准确、自然；再看句子是否承担本处需要的立论、过渡、总结或行动功能；再确认正文能用材料展开它；最后才看它有没有一个具体、可辨认、便于记住的指向。反差、冲突或新鲜表达可以承载这个辨识点，但不必每句都有。独立读标题或可摘出的总结句时，读者应能指出它说的是谁/什么以及关键关系；若必须依赖上一段的悬空代词或未交代的背景，就补明对象或缩短上下文依赖。不要为了记忆点换掉原意、制造生词、硬凑对偶或改成更像编辑本人会说的话。

Danescu-Niculescu-Mizil、Cheng、Kleinberg 与 Lee 在〈You Had Me at Hello: How Phrasing Affects Memorability〉（ACL 2012，892–901页）中，比较约 2200 组同一影片、同一角色且词数相同的对白，并以小规模英语母语者试验检查被标注句子的可识别性；研究报告记忆标注与不寻常词汇选择、常见句法骨架等特征相关。该研究是特定英语电影对白的观察与标注，不是随机传播实验，不能证明某种句式会导致文章被记住、认同或转发。本地只据此把“具体辨识点由常见自然句法承载、摘出时对象仍可辨”作为候选句检查；不把其英语词汇、代词或句法统计机械移植为中文规则，也不把记忆倾向当成流量保证。

工作句式可以是“哪类对象，在什么条件下，通过什么关系，产生什么后果”。它是内部拆解工具，不是要把每句话写成同一种语序。最终句子应听起来像自然中文。

## 3. 王国维原句的专业拆解

王国维《人间词话》相关删稿的常见文本作：“昔人论诗词，有景语、情语之别，不知一切景语，皆情语也。”正式引用应依所用版本核对篇次和标点。此句的专业作用不只是“很短”：

1. **对象和术语**：“景语”“情语”是诗词批评中可辨认的两个表达类别。读者先知道讨论对象，不必猜“景”是现实景色还是文字表达。
2. **关系判断**：“皆”把原先的类别区分改写成景与情可相通、景语能承载情感的判断。句子的核心不是形容词，而是对象之间的新关系。
3. **抽象层级**：从一处景物的写法上升到诗词表达的一般关系。它因此能统摄多个作品，但也因“一切”而承担较强的概括力度。
4. **读者认知动作**：读者从“这里写了什么景”转向“为何选这个景、这个动词和视角，它怎样形成情感效果”。判断改变了读作品的方法，后续可由作品细读展开。
5. **适用边界**：原命题属于诗词境界的批评语境；“一切”不能被搬成任何文字写景必然抒情的实证事实，也不能替普通文章证明观点。

迁移到材料型文章，只迁移其论述结构：命名熟悉的两个对象，指出它们之间容易被忽略的关系，再用材料检验关系。当前文章若没有对应对象和证据，就不仿写其形式。概括句须先从本篇材料发现，不能先定一句格言再找例子。

## 4. 先有意思，再选词

乔治·奥威尔在〈Politics and the English Language〉中写道：“let the meaning choose the word”。自译：“让意思来选择词语。”他的文章讨论英语散文和政治语言；本地只采用这个编辑次序：先辨清要表达的对象和关系，再选择能准确表达它的词。不是要求中文短词胜过专业词，也不是禁止抽象表达。

遇到“听起来高级但读者看不懂”的句子，按下列次序编辑：

1. 用读者熟悉的词语回答“这句话到底在说谁做了什么，为什么？”
2. 标出抽象名词背后的行为、对象或可见差异。
3. 对照上下句，补齐指代、因果、转折和条件。
4. 选择现代中文里自然的词语搭配；若专业名词更准确，保留并就地解释。
5. 朗读并逐句核对：停顿须符合句意，语气须与作者已确认表达相称；删去词语后若对象、关系、条件或结论发生变化，就恢复必要成分。
6. 对照材料复核证据强度；任何带条件的判断都保留适用范围，不因追求利落改成绝对句。

| 检查对象 | 出现什么问题 | 怎么修 |
|---|---|---|
| 词义和所指 | 读者看不出词语具体指谁、什么事或什么动作 | 点明对象和动作；抽象概念保留时补足它指向的事实或关系 |
| 主谓、动宾和修饰 | 词语搭配不符合常见词义，动作与对象或修饰与中心词对不上 | 保留原意，换成现代汉语中自然、准确的搭配 |
| 名词串 | 连续堆放名词，句中看不出谁在做什么 | 还原真实主体、动作及对象，必要时拆句 |
| 指代 | “这个”“这样”等词有多个可能所指 | 写明它指向的人、事、观点或做法 |
| 连接关系 | “所以”“但是”等连接词没有真实因果或转折 | 补出实际因果、对照关系，或换成准确的连接方式 |
| 条件 | 压缩句子时删掉会改变结论范围的条件 | 补回必要条件，并将结论限定在材料支持的范围内 |

允许使用新比喻和文学表达；先确认相似关系说得清，而且确实帮助读者理解。专业术语以准确为先，读者需要时再用熟悉的词语解释，不为追求通俗而换掉准确概念。

奥威尔反对套话和含混表达，并非反对所有比喻或文学语言。此处保留的是“意思先于惯用词组”和“读者能否准确理解”的检查，不照搬其针对英语写作的规则清单。

### 叶圣陶：用诚实与精密校准材料和表达

叶圣陶在《怎样写作》中把好文章的两个标准概括为“诚实与精密”。他区分自我表达与从旁描写：前者要与作者真实的思想、性情和处境相合；后者要以具体观察为据。“精密”是从材料中深入发现、切实感受到意义，再尽量不失真地表达出来；它不等于增加细节、修饰或微观参数。叶圣陶还把文章是否通顺落实到词语是否合适、篇章是否顺畅，提醒写作者检查连词与关系，并反复诵读来发现不顺处。

| 检查层 | 编辑动作 | 发现问题时 |
|---|---|---|
| 作者与经历归属 | 对照用户提供或确认的经历、原意、观点和态度强弱；确认第一人称是否确属作者 | 归属不清就询问；无法确认时改为有来源的转述或标明未知，不补成亲历 |
| 从旁观察 | 只写材料已提供或已核实的观察；找出能区分本次处境、解释判断的细节 | 细节缺失就补问或收窄叙述，不替他人添加动机、感受和动作 |
| 精密取舍 | 保留改变读者理解、说明因果或限定结论的细节；检查它是否准确呈现原意 | 细节虽生动但不推进判断时删去；删后会损失依据、条件或作者声音时恢复 |
| 词语与篇章 | 核实词义、搭配、指代和连词是否对应真实关系；诵读全文，标出句子不通或顺序不清处 | 先改错词或补关系，再调整句序；问题来自材料或推理时退回相应步骤，不靠修辞遮盖 |

本地采用顺序是先核事实归属和作者态度，再选择有辨识力的材料，最后校正词句与篇章。朗读用于发现问题，不是质量保证；发现的是真实材料缺口就回第一步，语言问题留在第六步处理。

## 5. 按句子任务使用句法

| 句子要做什么 | 让句子显出什么 | 编辑选择 |
|---|---|---|
| 叙事 | 主体、动作、时间和结果 | 把影响理解的动作放在前面；不为所谓紧凑省掉关键主体 |
| 说明 | 对象和定义、属性或分类关系 | 先命名对象，再说区别；首次出现术语时给可理解的解释 |
| 论证 | 判断、根据和推理关系 | 让根据紧邻判断，显式补足“为什么据此能得出结论” |
| 对照 | 同一比较尺度下的差别 | 两端用同一维度比较，不把原因和结果混列 |
| 限定 | 结论适用的对象、条件或程度 | 把限制放在读者容易误读的断言附近 |
| 抒情 | 感受由什么细节或关系触发 | 先让读者看见可感知材料，再给情绪判断；留白不能代替必要事实 |
| 指令 | 适用条件、动作、完成标准 | 动词明确，顺序对应依赖；并列动作不伪装成先后步骤 |

一句承担太多关系时，拆成“判断句＋解释句”通常比把条件挤进层层从句更清楚；两句讲同一意思时才合并。修订结果应让读者一次读懂，不靠第二遍猜连接词。

### 句子构造：先定关系，再落到常用词

写句子时先选它要完成的动作，再选主体、动词和对象。下面的骨架用于检查逻辑，不是固定句式；按段落功能取用，不把每句话都写成同一节奏。

| 句子功能 | 先确定什么 | 正向句式骨架 | 落笔检查 |
|---|---|---|---|
| 下判断 | 谁/什么是判断对象，判断到什么范围 | **对象 + 明确动作/关系 + 判断 + 必要条件** | 主语能定位；动词能说清“做了什么/发生什么”；把改变结论范围的条件贴近判断 |
| 给证据 | 材料来自谁、哪份输入、哪个时间或场景 | **来源/场景 + 可核对事实 + 与判断相关的细节** | 读者分得清事实与转述；数字、原话、时间不脱离来源；不把一个样本写成普遍规律 |
| 作解释 | 证据为什么支持、限制或不能支持判断 | **这项材料说明/限制了 X，因为 Y；因此本文只判断 Z** | 把推理桥写出来；“因此”只接真实推论，不用连词掩盖跳步 |
| 作对照 | 两端是否按同一尺度比较 | **在同一条件/尺度下，A 与 B 的差别是 X；这会导致/帮助判断 Y** | 比较对象和尺度明确；差异后接其意义，避免只列并排特征 |
| 给动作 | 谁在什么条件下做哪一步，怎样确认完成 | **当条件 X 成立，先做动作 A；看到标准 B 后，再做动作 C** | 动词写可执行动作；步骤顺序符合依赖；完成标准可观察，不承诺超出控制范围的结果 |
| 表达感受 | 哪个实际场景或选择引出作者什么感受 | **场景/动作/代价 + 作者确认的感受或判断 + 它改变了什么理解** | 情绪从经历中长出；第一人称不冒充用户心声；强烈表达保留，但不添加材料没有的心理 |
| 承接下一层 | 本段已回答什么、下一步因何必要 | **前一判断的结果/边界 + 仍未解释的具体关系** | 下一段补足真实缺口；能直接进入新内容就不加预告句 |

选词时优先“常见主体 + 常见动词 + 清楚对象”，再判断是否需要术语或修辞。以具体动词呈现行动和变化；把“进行、实现、开展、赋能、提升”等泛化动词替换成材料实际发生的动作。名词化表达只有在需要命名稳定概念时保留，连续名词串要还原成谁对什么做了什么。

连接词按关系选择：时间先后用“随后/此前”，原因用“因为/由于”，结果用“因此/于是”，转折用“但/然而”，让步用“即使/虽然”，递进用“还/进一步”，举例用“例如”。两个事实仅仅同时出现时用“同时/而”，不写成因果；只有比较对象和尺度相同才用“相比”。条件词“如果、当、只有”要和后文结论范围匹配。代词首次出现时让所指靠近，存在两个可能对象就改写为名词。

抽象概念按理解阶梯落地：**术语 → 一句熟悉语言的解释 → 它与相近概念的区别或内部步骤 → 一个材料里可观察的案例 → 结论适用范围**。概念本身已为目标读者熟知时，不重复百科定义；文章用到这个词会影响行动或判断时，至少说明它在本篇具体指什么。比喻可帮助理解关系，但随后仍要回到真实对象和证据。

一段里可以按其职责选择“入口句、材料句、解释句、条件/动作句、承接句”中的必要部分。叙事段可能由场景和变化带出判断；概念段可能先下定义再比较；过渡段只需接上前后关系。关键推理不能省，非必要句型不硬塞。若一段只有总结句，读者还不知道结论如何成立，就补材料和解释；若材料已能独立表达关系，不机械重复总结。

## 6. 修辞、节奏和活人感

| 手法 | 使用条件 | 具体做法 | 何时收住 |
|---|---|---|---|
| 比喻 | 抽象关系能对应到熟悉、准确的具体关系 | 点出相似点，让比喻之后回到本体 | 相似点需要长篇解释，或引入错误联想 |
| 对照 | 两个对象按共同维度可比较 | 先交代比较维度，再写差异及其意义 | 只有语气相反、对象不可比 |
| 反问 | 真实疑问需要推进读者注意 | 问句后立即作答或用材料展开 | 问句只重复已知立场或替读者预设错误 |
| 排比 | 并列项具有共同句法关系且各自增加意思 | 用并列节奏强化同一判断的不同面向 | 后续各项只是换词重复 |
| 留白 | 前文已给足事实和关系，读者能自行体会 | 在完整段落后停止解释 | 留白会使人物、时间或结论不明 |
| 短句 | 需要落下一个判断或形成自然停顿 | 在完整铺垫后作清楚收束 | 句子被切得零碎，连接关系消失 |

活人感来自具体观察、真实取舍、自然搭配和与事实相称的情绪，不来自强行加入口头语、感叹号、脏话或“我当时特别……”等未提供心理。作者若原本克制，保留克制；原话鲜明、幽默或带情绪时，也不磨平。事实范围和作者态度分开裁决：证据只支持一段个人经验，就把事实主语和范围留在“我这次/这几个例子”，不把作者的愤怒、认同或批评也改弱；外部核验得出的限定，贴在对应的事实判断旁，不把全文改成核验报告。

用户要求写本人经验分享时，视角按身份保持稳定：作者亲历与判断用“我”，读者的任务和动作直接用“你/如果你正在……”，外部研究或他人材料用清楚的来源归属。图注同样区分作者自己的录屏/作品与外部图表。用户未要求个人分享时，说明文、综述或观察文章可以采用更合适的客观叙述，不为统一人称而把编辑推论伪装成亲历。

口述改成文章后，句子按“意思—主语—动作—对象—关系—条件”定稿：先合并同义的几句口语，再按标题功能选择入口。主张型标题把具体对象和决定性关系写清，段首与正文展开材料、理由、推理桥和动作；作者选用的场景、人物/作品身份、意象、原句或局部发现型标题则以材料为锚，不强制压缩全文判断。标题可以高密度，不能直接承载整串口述；正文可以删重复，不能删到只剩结论。实操段依读者需要交代前提/输入、动作、判断标准、结果和适用限制；没有必要的字段不硬凑，决定读者能否理解或复现的字段不省略。

句子节奏也跟随内容：真实代价、转折或自我修正处可用短句落下作者态度；说明原理时把关系讲完整；方法步骤用明确动词和条件。作者尚未确定情绪力度时，可依据材料中的选择、后果或认识变化安排节奏，并检查其表达关系是否可信；作者已明确的愤怒、讽刺、痛感、喜悦或克制按其选择保留，不以事件规模自动换算强弱。需要补足可信度时，调整承载材料、节奏或叙述关系，不偷改态度力度。不加每段必有的金句、问句、感叹号或口头语；材料没有的痛苦、惊讶、羞愧和顿悟不替作者补写。

- 王国维：《人间词话》相关删稿，关于诗词“景语”“情语”关系一则；不同整理版本篇次、标点可能有异，引用前核对所用版本。此处对原句作局部文本分析，不把诗学判断扩大成一般传播定律。
- George Orwell, “Politics and the English Language,” Horizon, April 1946。短引为英文原文，自译单独标记。文章论英语散文，移用范围仅是选词前先明确意思、再从读者角度检查表达。
- William Strunk Jr.，《The Elements of Style》，1918年，第三章第十三则“删去不必要的词”（原文短句：A sentence should contain no unnecessary words）。本地应用为删除不增加判断、根据、解释或边界的部分；先确认意思、关系和条件完整，不把删冗误作句句都短。
- 叶圣陶：《怎样写作》，中华书局2007年版；中国作家网2021年2月1日刊载选文。选文明确区分自我表达与从旁描写，并讨论词语、连词、篇章和诵读检查；本地只采用这些编辑判断，不将诗歌或文言作品的表达方法机械移植到当代分享文章。
