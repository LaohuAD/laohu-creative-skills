# 活人汉语、零说教硬软分寸与成稿后轻扫疤

本文件是**放飞写活后的轻度耳检/眼检工具**（绝不异化成动笔前的数十条防错枷锁）：帮你在保住滚烫活人语感、大胆情绪词和锋芒呼吸的前提下，调准对事极硬对人极稳的分寸、理顺通俗与深度的自然起伏、轻扫五类失真真疤，并守住写实动词台阶与改稿保真。

---

## 一、双向之雅与零说教硬软分寸

一流非虚构语言的最高质地是**双向之雅**：向内洗净脏乱糙的粗鄙喊麦，向外撕掉圆滑端水、磨平痛感的防御壳，直击真相。语态严格遵循**对事极硬、对人极稳**（Jack Brehm 心理抗拒理论 ＋ 自主支持框架）：

| 所在情绪位与对象 | 正确句法与态度 | 失效陷阱（成稿后轻扫） |
| --- | --- | --- |
| **情绪波峰｜断客观规律、商业真相、历史转折、核心是非判断** | 主语直指规律、市场、账本或结构矛盾，用短促笃定的陈述句一刀见骨，**大胆使用准确传神的情绪词与强动词**，帮读者斩断犹豫 | 畏手畏脚加满大概、或许、某种意义上免责词，或把原意痛感磨软成谨慎端着的科普/公关腔 |
| **情绪波谷｜聊普通人委屈、心理包袱与现实顾虑** | 放缓节奏、退到读者身旁平视说清人之常情与现实惯性，让对方卸下防备、点头觉得被真正理解 | 指着读者鼻子教训、贴懒惰/愚蠢/自欺欺人等道德或智力标签，瞬间激起逆反 |
| **落地建议｜交付实操路径、改法与风险边界** | 把几条可走的路、各自的前置门槛、阵痛代价与回报平平摊在桌上，把选择权干脆交回读者手里 | 满篇命令式祈使句、绝对禁止口吻（必须、千万别、永远别）发号施令 |

## 二、通俗与深度的自然起伏（浅处舒展讲人话、深处讲透再点亮）

好文章既不是全程空转的闲聊口水，也不是端着腔调塞概念的教科书。耳检时只照这两条大白话标尺：

- **浅处绝不压扁、绝不装深**：凡是为了让普通人快速接纳、代入画面或卸下防备的位置（开头引入、200 字短帖、日常困局、共情段），读起来必须像老朋友坐对面说话——用最高频的日常熟词和活生生的生活画面**舒展铺开**，读完半秒直接进脑。凡是为了省字硬压成拗口偏正短语、让人脑子要拐个弯的句子，立刻摊开重写；短帖里更绝不为装专业硬塞生硬术语。
- **深处先讲浅、真需要再顺口点亮**：长文讲到硬核的商业账本、心理机制或工程原理时，先用滚烫大白话、实在算账或活比喻把底层逻辑彻底讲透；**真能立住专业深度且说出来自然顺口时**，再顺手亮出 1–2 个精准专业概念给它定名立骨，讲完立刻落回生活体感与活画面。一切服务于读者既觉得极顺口过瘾、又服气你有真体系，绝不为凑术语打卡而牺牲活人温度。
- **保住短行呼吸，高点停笔不添蛇足**：真正打到情绪或洞见高点的点睛硬句，大方独立成短行呼吸，让手机段落长短大参差、绝不挤成百字大方块砖；文章站上最高余韵处立刻收刀，删掉末尾多贴出来的四平八稳官话尾段。
- **实词承重与逆向落点（防凑短截肢与感觉标签偷懒）**：所有冷暖、急缓、痛感与克制，优先藏在具体实体名词、真实人的身体动作与平实事实里，不靠堆空洞的感觉形容词替读者下结论；写 10–30 字点睛硬句、短帖尾句或紧凑小标题时，先敲定现代汉语语法站得住脚的完整实词落点（具体名词、双音节动词或自然口语），再顺出前半句，绝不为了压短字数把名词截肢成生硬半文言缩写。

## 三、成稿后五类失真肌理轻扫疤

初稿放飞写活后，切回冷漠读者的眼睛和耳朵出声扫一遍，发现句子语法没错但读着发木、发飘、像机器或招人烦时，退回完整真意重写（**只修真疤，绝不靠死背长禁词表用怪词敷衍，更绝不把锐度与温度修平**）：

1. **说教命令与冷冰冰的旁观记者腔**：
   - 把居高临下的指责命令改为对客观规律的笃定断语，或平视摊开利弊的选择表达；
   - 观点剖析与实用内容用自然贴脸的人称对话（你/我），扫除冷冰冰置身事外的旁观报道口吻；发现叙事与事件解读保持平视共探的明白人口吻，绝不站在讲台训话。
2. **脱离日常口语的悬空套语、压缩名词团与卡嘴搭配**：
   - 扫除中国人现实聊天里极少说、一出现就有机器味的悬空体感/心理套词（例如生硬描写心里某种发虚、发紧或某器官发紧的模板句），换成真人张嘴会说的具体想法或动作；
   - 把硬压出来的抽象名词团摊开成主语动作贴紧的大白话，同时顺耳查一遍动宾搭配（绝不留下书面压缩导致的卡嘴病句），且**铺展时死保原意重量与锐度**。
3. **防御性公关词、官话运营黑话与贬义错词**：
   - 扫除空心互联网运营套话、官方报告腔以及为了避开常见直白词而绕弯造出的生硬替代词（能直说 AI 就直说 AI）；核实每个群体称呼的情感色彩不跑偏（绝不用带贬义的词称呼正面目标人群）。
4. **作者自夸元话语、塑料报幕缝与廉价地摊网梗**：
   - 依据 Pinker 古典平视原则，删光作者站到台前替自己贴标签、抢先规定读者感受的元话语（如抢先预告这话很刺耳、反常识、很扎心、最魔幻），也删光老师讲课式的塑料过渡报幕缝；
   - 靠洞察锋利度与真实反差打动人，远离快消营销号用烂的低俗地摊网词。
5. **长定语压主语、跨节炒冷饭与装饰双引号**：
   - 拆掉开头或句首二三十字压住主语的长串前置定语，让主语和动词尽早露面；
   - 确认正文主体每节都换全新论据与切片，零跨节复读；
   - 除逐字引语、真实对白、专门讨论词句或极少数拿掉会变味的反讽外，**装饰双引号彻底清零**。

## 四、选词不越级：事实到哪一步，动词就落到哪一步

写实论证里，看似近义的动词其实是完全不同的证据台阶（Fillmore 框架语义学），绝不为了显得有气势而偷升台阶：

| 材料实际支持到什么程度 | 准确选词 | 绝不能顺带偷换或夸大成什么 |
| --- | --- | --- |
| 看见异常、翻出线索或记录，还没比对定性 | 发现、查到 | 不等于记录完整、来源可靠或责任人已定 |
| 把一项说法或状态与现有记录逐项对照 | 核对、检查 | 查验动作本身不等于无误，也不覆盖未查范围 |
| 手头信息足以回答一个明确、有限的具体问题 | 确认（紧跟具体对象，如确认收到、确认口径一致） | 不能拿确认替代缺失的查验过程，也不能扩成完整因果 |
| 证据闭环支撑了某项事实或归责结论 | 证明（紧跟所证范围） | 单条记录不自动证明整条因果链或普遍规律 |
| 发出指令 vs 亲自实施 vs 被推出顶责 | 区分下令者 / 执行者 / 替罪者 | 动手执行不等于下令主谋，也不自动等于替人顶罪 |

**小词核前提再用**：对 `还 / 仍 / 再 / 才 / 却 / 只 / 都 / 会 / 要 / 愿` 先核实前提成立（用才要有门槛，用却要有前项预期，用还要有延续），不硬插虚词造波折。删改后连读确认未改变否定范围、数量、时态、语气或主动性。

## 五、留住真实温度与局部改稿语义保真

- **跨段去重看真损益，不按字数机械砍删**：讲同一层意思的重复段落合并到主展开位；凡要删一个口语词或看似啰嗦的表达，放回上下文连读对比——只要它承载着真实投入感、费劲感或自然呼吸节奏就果断保留，只删既不增理、又不载情和节奏的真废话。
- **局部改稿三项保真回查**：修改现成句段后放回前后句群连读，逐项核实：① 对象、数量与泛称范围零偏移；② 已完成的事实仍是已完成，绝不润成计划、意愿或建议，拒绝、提醒、承诺、暂缓各守原动作；③ 简洁是删废话，不是把限制条件和说话呼吸砍干。

仅需把某处核心论点句、点睛句、小标题或收束句专项凝练时，回主文按 [成稿与标题交接](../SKILL.md#成稿与标题交接) 走 `laohu-title`；日常普通过渡、论证展开与人话润色直接在本文件内修妥。
