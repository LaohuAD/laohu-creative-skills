# 语言、密度与表达

Writing 起草或修订实际句段时使用。先确定这段要让读者看到什么、作者怎样看待它，以及前后段已经给出的语境。需要调整语义关系或自然成句时，按[共享语言成文方法](../../../../references/language-realization.md)处理，再回到本段实际声口、节奏和表达密度。

## 选词与句法，把关系说出来

| 发现的具体问题 | 实际改写 |
| --- | --- |
| 句首突然换对象，读者需要返回上句找所指 | 对解释与论证，试将上一句已经建立的对象、结果或判断放到本句起首，再用它带出新信息。若首句有意用新场景或戏剧动作切换，让附近线索建立所指。 |
| 主语与动词中间夹着约十五至二十字以上的多层限定，或长条件使动作难找 | 先用前置条件分句立背景，再让短主语紧接核心动作。需要拆成两句时保持指代、条件范围和逻辑，专业专名和必要限定原样保全。 |
| 判断最重的词埋在套层、插语或无作用的尾巴里 | 确定这句让读者新增的认识。试把它移到合适的停顿前或句末，读回前后句和作者声音；原用倒装、动作先行、抑扬或先给结论能够实现当前任务时保留其节奏。 |
| 用抽象名词或笼统形容承诺效果，却看不到谁做了什么 | 按实际材料补施事、动作、对象及可见结果。只有意图、愿望或未核验反馈时照其身份写，并明确必要条件。 |

Gopen 与 Swan 的句首承接和焦点位置可用于诊断解释段；以中文句段实读判断主语、话题、停顿和强调。词义、搭配或指代有歧义时，先用平实说法写完整关系，再选自然准确的词。例如区分“学完一门课程”和“学会使用一种工具”实际表达的完成对象。熟悉术语可以直接保留；陌生概念第一次影响理解时，用短定义、同题对照、读者已知对象或过程关系搭桥。

## 让立场落在具体表达里

每个需要评价的地方核对三个决定。作者在评谁或什么，材料中哪项行为或条件承担评价，词的力度与适用范围是否一致。Appraisal 的评价语言可用于检查态度、说话立场与力度：关系明确后再用词、范围、比较或动作提高或降低分量。表达作者确有的认可、反感、兴奋、犹豫或遗憾，事实核查只调整与证据冲突的边界。

朋友圈式、讲课式、克制或有锋芒的声口由用户或作者确有材料决定。保留其实际选择、对谁说和为何在意，把空泛的态度落到发生过的事。比喻、反差、幽默和回返用来说明关系、呈现体验或留住有作用的节奏。若读者只能看见一句漂亮判断而无法回到材料，回到对象、动作和作者原来的意思。技术步骤的条件、状态和完成标准也要在改句后读得出来。

## 处理作者声音和已有文字

### 跨段检查重复并保留作者语气

先将承担同一判断或作用的句段放在一起，找最能展开它的地方，把他处确有的根据、条件或动作并入。再次经过同一关系时，检查是否新增应用或限定，作者态度是否推进，读者能否感觉到回环、停顿或叙事温度的改变。分别试读保留和删去的版本，以实际损益决定保留，不用字数和是否新增事实独立裁判。像“好不容易”承载了材料支持的费劲感时，可让读者感到作者真实投入。

Chris《我的自述》的给定转写写到通勤、吃饭、洗澡时都在想文案，接着说“当然，没有一条是能用的”（7671626930524917002，01:58–02:14.67）。结果与语气共同让前句的投入成了自嘲。修类似句段时先辨认两句之间成立的这个作用，再精简原话。

读口述、ASR 或尚未成文的片段时，先圈作者准确、有力度且可以承担本篇作用的原句、停顿或复沓。把它们放回有效位置，补材料允许的指代、承接、观察或选择后果。这样可沿用真实作者声音。纯填充语或只复述内容的部分，可在连读后删并；用其他说法解释作者时，把解释范围控制在作者实际给出的关系。

## 从局部候选回到全文

把原句和修改句放入同一语境，连读停顿、焦点、来源身份、下文指代和关系。检查引号是否有明确引用、词语讨论或语气职责，标点能否标出真实层次。旧句已经准确、自然而且位置相称时保留。确认新句的具体改善后再采用。

完整标题、题眼、收束、原则句或改变理解方向的定调句按[成稿与标题交接](../SKILL.md#成稿与标题交接)。局部句群、普通过渡、解释和叙述由 Writing 直接修订。主张或证据关系因新认识而改变时，走同一节的局部返工路径。
