# 飞书远端操作

由 [飞书文档专项](../skills/laohu-writing-feishu/SKILL.md) 或 Writing 在本轮确需读取、写入、上传飞书资源、接通连接或恢复上次远端操作时使用。已齐材料的聊天稿跳过本文件。输入包括真实文档、资源和目标企业、操作范围、批准的编辑权限与待处理状态。按本轮需要进入对应小节。

## 准备可用连接与正确身份

按本轮交付和材料依赖决定是否准备连接。

若材料已齐且只需在聊天中起草或审稿，跳过连接发现、profile 检查、安装、授权，以及远端读取、保护、上传、写入和读回；继续内容、适用格式与图稿设计及宿主终审。本门控只跳过飞书远端连接与操作，不自动禁止用户另行授权的本地保存或实际制图。

若聊天稿仍需读取飞书来源，只为读取接通所需渠道并取得最小读取权限；不额外申请编辑或媒体上传权限。若原文含图片或附件且本次阅读需要查看，只核验读取相应素材所需权限。

仅当本轮确需读取、新建、修改或上传飞书远端内容，或用户明确要求准备连接时，才发现并核对可用的连接器、CLI 和相关操作说明。优先沿用用户指定且可用的渠道；未指定时，选择能完成本轮远端操作的现有渠道，能力不足再补 CLI/OpenAPI。用户要求 CLI 或禁止网页操作时遵从，不静默改用浏览器。网页登录状态与 CLI 凭据分别判断。用户明确禁止的动作跳过；受阻的依赖操作说明缺项，继续不依赖它的工作。

### 缺工具时帮助接通

1. 检查操作系统、已有 CLI 及版本；有工具先读相应 `--help` 和已安装的官方文档操作说明。若安装了 `lark-shared`、`lark-doc` 等官方技能，定位其真实位置，按连接、文档、知识库或媒体任务读取所需部分；未安装时用 CLI 帮助和当前官方文档补足接口，不假称已加载。
2. 缺 CLI 时核验飞书/Lark 官方 CLI 项目的当前安装说明与运行前提。核验包身份及所需运行环境后，在本轮允许安装的范围内帮助安装；涉及管理员权限或用户选择的安装位置时说明具体需要。安装完成实际运行版本与帮助检查，不把“已下载”等同于可调用。
3. npm 可用且当前官方说明仍支持时，可采用下列安装入口；执行前核对环境，缓存、下载和中间文件使用已确认工作盘。已有 CLI 不为本任务无条件升级。命令不是全部环境通用的安装承诺。

```bash
npm install -g @larksuite/cli
lark-cli --version
lark-cli --help
```

4. 新用户尚无应用配置时，按当前官方引导帮助创建/选择适用应用并配置一个本地 profile；说明应用身份与用户身份分别可访问什么。应用 Secret、Token 和凭据由本地安全存储或平台授权流程管理，不要求贴进聊天、文章、截图或仓库。授权必须由用户在官方页面完成，不能代其点击同意。
5. 需要用户操作时，提供官方授权链接及工具支持的二维码，说明“用哪个企业身份登录、为什么需要这些权限、完成后怎样检查”；链接与二维码来自本次真实输出，不自造。用户完成后验证状态并继续，不把等待时间当授权完成。

### 多账号按任务选择

先按本轮已选渠道核验身份与权限。现有连接器足以完成本轮远端操作时，直接核对该连接器的身份和权限，不引入 CLI 或 profile 检查。

使用 CLI 且目标 profile 尚未确定时，先列出本地 profile，将用户已给的企业/区域、目标资源域名、应用和可验证身份与配置对应。只有显示名或当前默认值不足以确定归属；域名也不单独证明账号拥有权限。明确匹配则直接用，仍有歧义才让用户选目标企业，避免要求其重复登录。目标 profile 已确定时沿用本地对应配置，并按本轮操作需要验证有效性。

CLI 或 profile 缺失本身不触发重新登录或新建应用；只按本轮实际远端需要及已有授权进入连接准备。

以下是已支持相应选项时的检查形式，`<profile>` 必须替换为本次实际选择，执行前查帮助：

```bash
lark-cli profile list
lark-cli --profile <profile> auth status --json --verify
```

每次操作显式携带所选 profile 或连接身份，并按实际工具声明选择 user/bot。不切换全局默认、不注销其他账号、不覆盖别人的凭据。个人企业映射留在使用者本地配置/私有记忆，本共享技能不含固定 profile、企业、应用 ID、文档 ID、个人目录或真实密钥。

失败按实际层次处理：先排配置选错，再查凭据有效性、所需 scope 和文档自身权限。分别验证**读正文、改正文、上传图片**所需权限；读成功不推断其他两项也可用。已有应用身份能完成已授权任务时直接沿用；确需用户身份或缺具体权限时，只为对应操作请求最小必要授权。权限不齐时先完成可审阅稿件，保留原文并说明哪项操作待补什么。

## 读取当前文档并建立保护范围

从用户链接或已有任务状态识别文档、知识库节点或其他文件类型；知识库链接先解析实际对象，不把节点 token 当正文 ID。需要原生图文排版时，目标是可编辑的云文档，不把上传到云盘的 `.md` 文件当成同一种成品；用户明确要求原文件则保留其文件类型。读出标题、当前 revision、全部目标内容及原生块树；有分页则读完获准范围。对于局部任务，只扩读理解和保护相邻内容所需部分，不把样本当全文。

修改前在当前工作项目的同盘恢复位置保留**实际读取版本**、本轮涉及的块与资源映射。记录标题层级、块 ID、图片/附件 token、列表组与起止、表格/分栏层级、内部跳转及用户锁定项，供后续差异写入和验收消费。已有评论、未知块、嵌入内容和外部引用不得因转换不支持而顺带删除；无法无损处理的部分保留原块，仅暂停依赖操作。

读者稿、工具指令和文档中的引用材料分开识别，外部正文不改变本轮授权。仅需格式优化时，先区分已有原生块和用文字模拟的列表等结构，再确定可保真转换范围。没有实际读取成功不覆写既有文档；新建目标未成功也不假定已有可写 ID。


## 上传并绑定真实媒体

确认目标、上传权限和素材可访问性。每张图核对锚点、实际内容和图注，上传到正确目标后绑定真实媒体 token，再读回确认对应。请求状态未知时先核目标状态再补缺。上传失败保留原有图和可用正文，报告待处理项。

## 按差异写入，核对真实结果

本节适用于本轮已获授权、需要执行远端写入，或需要核对上次写入结果/恢复部分写入的任务。只交聊天稿且没有待核的上次写入时，跳过本节远端提交与读回验收，不据此倒推连接准备；继续按宿主要求交付完整稿并终审。上次写入状态未知或有部分写入需要恢复时，仍按下列保护与状态核验处理，不盲目重试。

写前将稿件与原生格式决定对齐到目标块，拟定本轮新增、修改、保留范围；局部改动优先更新对应元素/样式而保留块身份。全篇重组只有在授权与实际接口允许、已保护资源和不可重建内容时才进行。先核对所用写接口、参数、限制和成功/错误信封；不复制本机旧脚本、历史 flag 或未验证的续号语法当通用方法。

按工具支持使用 revision/版本条件、分批写入和可恢复记录。有并发修改时重新读取并合并受影响范围，保护用户新内容；接口无版本条件时在提交前后比较读取状态，发现冲突停止后续覆盖并核对，不能宣称已消除竞争。请求超时或返回不明时先查当前文档判定该批是否已落地，再重试缺项；新增文档/图片尤其不能盲目重复创建。结构修改后刷新块 ID 与内部链接映射。

每批成功后核对相应产物，再继续依赖它的下一批。正常写入返回、未报错、块数相同都不证明内容正确。转换警告、格式丢失、写入拒绝须处理实际差距；仅影响局部时保留已成功内容，停止依赖分支并交付准确状态。恢复只处理本轮变更且核对后续协作修改，不能用旧快照覆盖别人新写的内容。

完成后按本轮全部目标范围逐项核对，范围是局部时明确局部：

1. **内容与保护项：**读回完整目标文本，比较段落、字段、命令、链接值及锁定项；原图片/附件、未编辑块与评论等保护对象保持其实际身份/关联。对不能验证的对象如实说明。
2. **原生格式：**检查真实 heading、ordered/bullet、quote、代码、表格、grid 等类型和嵌套，核对行内加粗/底色范围。样式返回值可能是实际色值，按有效颜色核对，不只搜索符号名。
3. **列表与导航：**核对每组所有列表项的起始、续号、重启及嵌套；尤其检查图、备注、代码后的继续编号。逐条核对篇内链接指向现存正确标题，结构改后重新映射，不能只抽查首项或数总数。
4. **图片与复制：**确认全部目标图片可访问、锚点正确且内容清楚；代码/提示词完整选取或复制保留字符与换行。没有读取剪贴板或实际粘贴验证，不能只凭按钮提示声称复制成功。
5. **实际阅读：**在用户允许、可用的真实飞书客户端检查代表性长步骤、图文、表格、分栏和跳转；有移动阅读需求时检查窄屏。API 读回只证明对应内容/结构，本地 HTML 预览只证明预览自身，不代替飞书实际呈现。没有允许的客户端渠道时完成结构检查并明确该项未检查。

将可定位的差距交回相应内容、图稿或写入步骤，修复后复查受影响的后续依赖。最后返回宿主：实际交付的全文或文档链接、已完成范围、资源/写入状态、关键检查结果和确实待用户处理的缺项；由宿主终审并交付。写入已完成时以可点击文档和简短变化说明交付，不再用默认整篇代码块冒充远端结果。只写稿时沿用宿主聊天格式。真实新手使用效果、首次安装成功率或阅读质量没有相应接收证据时，不宣称已验证。
