# 老胡内容写作

> **好内容从来不是照模板填出来的平均说明文，也不是一根弦绷到底的说教硬怼稿；经得起时间与真实读者检验的高水准文字，共有四条硬底色——直击唯一读者的真痛点或认知盲区、骨力严密、实证或画面扎实、读完有真获得感与回味。一切方法都只为最终把这篇稿子写到最好服务，绝不反客为主束缚体裁与好方向。**

本入口作为二级通用写作底座，覆盖深度文章、教程手册、朋友圈/X 短帖、口播讲解与飞书文档。所有形态共享**灵魂（海拔、三态需求裁决与情绪分寸）→ 筋骨（按目标选框与推进法度）→ 血肉（冰山提纯、通俗深浅波与写实红线）→ 表皮（滚烫活人汉语、呼吸参差与轻扫疤）**四维纵深；对内凭跨题材原理定盘，对外 100% 解压为自然母语人话。

## 一、四维八纲写作引擎

### 1. 灵魂层：高水准标杆、三态需求裁决与波浪零说教

#### 总纲一 · 高水准标杆定位、穿透三态裁决与唯一读者
- **目标**：先认清当前体裁真正顶级的样子，再穿透用户表层表述挖出不变的核心情绪与读者获得感，围绕唯一目标读者写出不平庸、不迎合所有人的好内容，立意力求**返璞归真**（入口极轻极近，余韵极深极远），不停在流水账打卡、局域泄情吐槽或空大假拔高。
- **判断（显式理论与共存边界）**：依据 **人脑生理注意力（RAS / 预测编码误差 / 杏仁核情绪唤醒）**、**Kahneman 损失厌恶**、**Allan Bell 唯一受众设计** 与 **需求三态裁决**——
  - **先辨体裁与三态，再决定发力方式**（绝不把爆款观点腔硬套给所有体裁，也绝不盲从平庸流水账外壳）：
    1. **态一 · 同向且有明确独到方向**：用户明确指定了不违背写作规律的好方向、节奏或声口（例如沉静克制的人物特写、平实复盘、特定结构、操作教程或逐字锁定原句）→ **完全尊重并做到该方向的最高水准**，绝不强行掰成高张力爆款腔；
    2. **态二 · 表达模糊宽泛**：用户只给了粗略话题或零散想法 → 穿透表层挖出唯一目标读者此刻最在乎的利害或好奇，主动按该体裁顶级标杆补齐深度、张力与格局；
    3. **态三 · 字面外壳明显偏离好文章规律**：用户丢来一堆零散流水账，或随口要求百科起手、按一二三四全塞进去、结尾号召点赞加油 → **守住真实事实底线、合法逐字锁定项与忠实整理授权红线**，抽出其中不变的核心情绪与真实主张，果断重构换血带回高水准（若大幅改了用户顺口提的结构，交付外顺手用 1 句话点清为何这样排更能打动读者）。
  - 面向陌生受众的内容创作，必须先过情绪或切身利害关，读者才会打开理性大脑往深处看；迎合所有人必然写平写薄。
- **行动（后台极轻支点一前半）**：动笔前后台锁定体裁归属、用户三态判定、唯一目标读者与最反常规的一刀核心主张。
- **结果验真**：把自己当成毫无耐心的目标读者扫前两行——有没有立刻进入状态？遮掉署名能否感到背后站着一个看得透的活人？

#### 总纲二 · 情绪波浪曲线 ＋ 零说教硬软分家 ＋ 双向之雅
- **目标**：让文章和口播的情绪与语气张弛有度，既有帮读者斩断迷雾的底气，又彻底消灭说教味与逆反抵触。
- **判断（显式理论与共存边界）**：依据 **神经习惯化与张弛释放律**、**情绪弧线 / Nancy Duarte 脉搏曲线（Sparkline）**、**Jack Brehm（1966）心理抗拒理论**、**自主支持框架** 与 **双向之雅**——
  - **严禁情绪停在任何一条水平线上**：全程温和客气会沦为白噪音，一根弦从头硬怼到底三段就听觉疲劳。好节奏在**波峰（笃定断事 / 冲突反转）↔ 波谷（故事呼吸 / 平视体谅 / 摊开选择）**之间自然振荡（平静随笔与技术教程则按克制舒缓或清晰明快的本色呼吸，不硬造戏剧冲突）；
  - **任何时候严禁说教口吻——严格执行对事极硬、对人极稳**：刀口永远砍向客观规律、错位账本与旧时代规则（波峰硬气笃定，帮读者做是非判断）；聊到普通人的委屈、难处与给行动路子时，立刻放缓平视、并肩摊开选项、前提门槛与代价，把选择权交回读者（波谷零抵触）；
  - **双向之雅**：向内洗净粗鄙喊麦，向外撕掉客气端水防御壳，保住直击真相的锋芒。
- **行动（后台极轻支点一后半）**：在后台排清全篇波峰（硬断事）与波谷（缓交心）的自然交替。
- **结果验真**：读完有跌宕呼吸感，对底层判断拍案叫绝，对心理体谅与建议零抵触。

### 2. 筋骨层：按目标选经典框 ＋ 头身尾推进法度（不跨体裁硬套）

#### 总纲三 · 经典叙事选框与开头锁人（详法归位 [article-craft.md](references/article-craft.md)）
- **目标**：依本篇核心目标选最契合人脑阅读期待的经典框架，在前 15 秒签下读者的时间预算，彻底消灭长定语堵门、干瘪复述现象、提前剧透泄气与一套模具通吃一切。
- **判断（显式理论与共存边界）**：依据 **Sperber & Wilson 关联理论（认知回报 ÷ 阅读费劲度）**、**Sugarman 滑梯第一句**、**Schwartz 承接既有欲望**、**Loewenstein 信息缺口** 与 **Ogilvy 实质回报**——
  - **按目标选唯一匹配框架**：痛点破局用 **SCQA ＋ Sparkline ＋ 自主建议**；颠覆评论用 **破立辩证 ＋ Toulmin 论证**；科技、商业事件、人物与科学发现解读用 **华尔街日报特稿（高潮切入 ＋ 核段）＋ ABT**；一线复盘用 **STAR-L**；入门操作、实操指南与查阅文档走 **Diátaxis 四分法**（结果先行、前置条件清楚、直入第一步，绝不硬套悬念四拍）；
  - **深度观点/叙事内容开头四拍核心**：① 松弛像活人聊天一样进门，1–2 句内撞碎旧信仰或挑战自以为懂（绝不为凑短硬压成拗口短语）；② 面对面贴脸画面接通切身利害；③ 用经得起现实推敲的硬反证拍死敷衍借口、只亮反常果不提前泄光底牌（绝不硬编脆假反证）；④ 签下具体到钱、饭碗、选择或改写结果的硬回报。
- **行动（后台极轻支点二前半）**：锁定唯一匹配框架，定清前 15 秒如何让目标读者毫不费力滑进正文。
- **结果验真**：陌生读者扫完首屏立刻想往下滑，零吞吐阻力、零提前泄气。

#### 总纲四 · 正文持续供油、黄金记忆点与高点收官（详法归位 [article-craft.md](references/article-craft.md)）
- **目标**：消灭中段 30%–60% 流失，让读者一路顺滑读到底，合上文章那一刻心头留有余震或清晰收获。
- **判断（显式理论与共存边界）**：依据 **嵌套开环（蔡格尼克效应）**、**Hayakawa 抽象阶梯与 Sweller 认知负荷**、**Aha! 微顿悟**、**Daneš 线性零复读**、**RST 段落战术分工**、**认知空白记忆点** 与 **Kahneman 峰终定律 / Housel 镜头拉远 / Clark 环形回扣 / Zinsser 高点停笔律**——
  - **长文正文防流失五原则**：① 嵌套悬念链（解开一层顺手掀开更深一层，不提前泄气）；② 抽象阶梯上下高频穿梭（抽象规律绝不连续裸奔超两段，高空断语 ↔ 地面滚烫切片交替）；③ 倒三角挖深拉宽 ＋ 每节一次微顿悟（多掘一层根因、拉出横纵格局、击穿常见反驳，且优先从读者眼前活现场切入再自然引出历史或理论）；④ 段落级微闭环（明确本段负责埋钩、降压呼吸还是一锤定音）；⑤ 单次使用零复读，全篇集中锻出 **2–3 处留有认知空白的黄金点睛记忆锚点**（不句句抖机灵）；
  - **双轨高点收官（不强行凑老梗）**：观点与深度解读长文优先走**新鲜贴切的跨界广角升维 ＋ 环形回扣开篇 ＋ 未来视野窗口**；若题材本就重人物现场或沉静体悟，直接**回到本篇具体人/物的一处克制微动作定格留白**同样高级——**站上最高余韵立刻干脆停笔，绝不补四平八稳的官话尾段、PPT 复读圆点或硬求关注**（操作教程与内部协作文档则落到清晰的验证标志、排错入口或下一步动作）。
- **行动（后台极轻支点二后半）**：排清各节倒三角推进、节尾钩子与收官落点。
- **结果验真**：中段节节有推背感与可划线狠句，结尾余韵干脆利落或收口清晰实用。

### 3. 血肉层：冰山提纯、浅舒展深点亮与写实红线

#### 总纲五 · 冰山提纯、全篇均衡承重与通俗深度的自然起伏
- **目标**：用极少数画面滚烫、配得上立意海拔的具体切片托住全篇，让普通人读着既像老友聊天般丝滑顺口，又实实在在服气作者的专业深度。
- **判断（显式理论与共存边界）**：依据 **海明威冰山原则**、**四维同级共振** 与 **Karl Maton 语义波 / Oppenheimer 加工流畅度**（对内指导深浅起伏，对外绝不甩学术黑话）——
  - **冰山提纯与均衡承重**：原始材料是冰山底下的燃料而非打卡清单（忠实整理除外）；全篇前中后段血肉均衡，选 2–3 个高反差、有画面、有温度的真实切片或新鲜对照，绝不拿干瘪杂物、廉价寓言或论文式推理解释拖垮立意；
  - **按本段目的自然调深浅（浅不压扁装深、深要讲浅再点亮）**：开头引入、生活场景、平视共情与 200 字短帖（浅处），用最高频大白话和常见生活画面**舒展铺开**、半秒进脑，绝不为凑短压成拗口词团，也绝不在短帖硬塞生硬术语；长文深剖底层机制（深处）时，先用滚烫白话、实在算账或活比喻讲透，**真能立住深度且自然顺口时**再顺势亮出 1–2 个精准专业概念定锚，讲完立刻落回活人感受与现实画面。
- **行动（后台极轻支点三）**：挑定 2–3 处最具画面冲击力的核心切片排在承重位；深剖处先备大白话画面再决定是否点亮定锚概念。
- **结果验真**：从头读到尾无一处发木或脑子拐弯，既亲切过瘾，又扎实有骨头。

#### 总纲六 · 写实硬红线与证据台阶不越级
- **目标**：再强的故事张力与情绪锋芒，底盘都 100% 踩在真实事实与诚实边界上。
- **判断（显式理论与共存边界）**：依据 **Charles Fillmore 框架语义学（动词证据台阶）** 与 **写实底线**——绝不编造虚构人名、虚假精确统计、虚构采访或作者未经历过的亲身经历；普遍观察如实按普遍观察表达；守住发现/查到、核对/检查、确认、证明四级动词台阶与虚词前提；涉及赚钱、投资或个人破局路径时，诚实摊开前提门槛、阵痛代价与风险边界，绝不画空饼。
- **行动**：在真实事实框架内发挥洞察与张力，成稿扫疤单核全部事实、数字、年代、人名与边界。
- **结果验真**：被内行逐字查证时，事实口径与风险边界依然扎实无懈。

### 4. 表皮层：滚烫活人汉语、实词承重与放飞/扫疤物理分离

#### 总纲七 · 极致通俗、带情绪肌肉感与实词承重的活人汉语
- **目标**：剥掉文绉绉书面腔、官话黑话、科普作业感与 AI 假味，用一扫秒懂、该脆时脆、该柔时柔、带活人呼吸和温度的现代母语讲透深道理。
- **判断（显式理论与共存边界）**：依据 **Pinker 古典平视风格**、**Joseph Williams 清晰动作句**、**William Zinsser 真我人声** 与 **活人母语自然语法**——
  - 主语紧贴动词，把压缩抽象词团摊开成真人张嘴会说的日常汉语，**保住情绪肌肉感与锋芒，敢用准确有力、带画面感的情绪词与活人吐槽，绝不磨成防御公关词或端着的科普腔**；
  - 温度与痛感靠具体实体名词、真实人的动作和实在事实托起来，写短金句与收尾句时先钉死语法完整的现代实词落点再补前半句，绝不凑短截肢出伪古风缩写或贴空洞感觉标签；
  - 手机长文段落长短大参差，真正打到高点的点睛硬句大方独立成短行呼吸，绝不把整篇挤成密密麻麻的大方块砖；除逐字引语、真实对白、词句讨论或极少数拿掉会变味的反讽外，**装饰双引号彻底清零**（细则见 [expression-and-density.md](references/expression-and-density.md)）。
- **行动**：顺着每段情绪波峰波谷与体裁本色自然切换句长与语气温差，该舒展处舒展铺开，该亮剑处短行狠落。
- **结果验真**：出声顺读丝滑带劲，听得出活人呼吸、态度与深厚功底。

#### 总纲八 · 极轻 3 支点后台定盘 → 彻底放飞成稿 → 按体裁六关轻扫疤
- **目标**：保护强模型的自然联想力、故事灵气与鲜活语感，严防事前条框过密引发雕刻伤气。
- **判断（显式理论与共存边界）**：依据 **姜夔雕刻伤气律** 与 **殿堂真品定音律**——动笔前后台只锁 3 个极轻正向支点（体裁三态与唯一读者情绪波形 / 匹配框架与头身尾推进 / 2–3 处核心具象切片），随即**彻底放飞、一口气写活**，绝不在写初稿时背着几十条禁令缩手缩脚；题材陌生或输入偏散易滑向平庸套路时，先调用 1–2 篇同品类顶级真品或本地标杆库做四维定音，拆透立刻合上换本作血肉。成稿后再切目标读者的眼耳轻扫真疤——**只修真疤，绝不把锋芒、温度与呼吸修平**。
- **行动**：轻定盘 → 彻底放飞写活 → 按体裁走六关轻扫疤 → 洁净交付。
- **结果验真**：成稿既有鲜活灵气与呼吸，又贴合体裁、干净利落零硬伤。

### 2. 编辑深度与前置设计按需触发

- **创作、原创与深度展开**：从零写稿、展开零散思考或授权发展编辑 → 按总纲一完成三态判定后全开对应体裁引擎，主动深挖一层根因、拉出纵横格局并补全新具象对照（写实事实与个人亲历严守零编造红线）。
- **忠实整理与局部改稿**：材料已有成熟观点与经历线，用户只让整理口述、清理 ASR、局部润色或锁定了标题/原句/顺序 → **只理顺承接与呼吸、清掉假味与重复**，逐字锁死保护项，绝不私自编经历、加数据或塞未说过的观点。
- **复杂前置设计按需触发**：仅当融合多类散乱异质材料、承诺行业入行或商业赚钱路径、外部承重事实打架，或局部改稿出现承重因果缺桥与开放探索动摇主线时，才按需加载 [pre-design.md](references/pre-design.md)（棘手时联动 [laohu-analysis](../laohu-analysis/SKILL.md)；日常写作与短帖 0 加载）。

## 三、成稿后按体裁六关轻扫疤与洁净交付

彻底放飞写活后，切换成目标读者的眼耳走完以下六关（**只修真疤，绝不把活人锋芒、情绪温度与短行呼吸修平；操作教程、查阅手册、内部协作飞书、局部顺句与克制随笔按各自体裁标尺核验，绝不跨体裁硬套爆款模具**）：

1. **开头与需求对齐关**：是否精准承接了用户同向好方向（态一）或补齐/换血带回高水准（态二/三）？深度观点与叙事稿是否松弛讲人话、一两句立住张力、反证经得起推敲且回报实在？教程与协作稿是否结果先行、条件清晰？公众号正文是否未混入外部发布标题？
2. **情绪呼吸与零说教关**：是否有符合本篇体裁的情绪起伏或克制节拍？有没有任何居高临下的训话、命令或负面标签？建议有没有摊开前提代价、把选择权交回读者？
3. **正文供油与记忆点关**：长文抽象道理有没有连奔超两段？是否优先从活现场切入再自然引出概念？各节有没有新信息增量、独立短行呼吸与 2–3 处不过度堆砌的黄金记忆锚点？有没有跨节炒冷饭？教程步骤是否零跳步、有完成标志与排错闭环？
4. **收官高点停笔关**：深度长文结尾（无论新鲜跨界升维回扣，还是具体现场微动作留白）是否在最高余韵处干脆停笔，清掉多余官话尾段、PPT 总结圆点与硬求关注？功能文稿是否收在清晰验收或下一步？
5. **活人通俗度与事实红线关**：出声顺读查两头——浅处有没有被压缩得脑子拐弯或在短帖硬塞学术词，深处有没有不垫白话硬砸术语，短句落点有没有凑字截肢或感觉标签偷懒；扫清悬空 AI 套语、防御公关词、运营官话、自夸报幕缝、卡嘴动宾搭配与装饰双引号；单核全部数字、年代、人物、引文、动词台阶、锁定项与风险边界，确保零虚构造假。
6. **洁净一键复制交付关**：
   - 文章与教程默认用**单个 Markdown 代码块**交完整正文（内含代码时外层围栏加长至四反引号或更长），配套发布标题、采图单与说明放块外；用户只要正文时，块外尽量零废话或仅留 1 句必要提示；
   - 短帖直交可发正文；口播按意图直交真人朗读标注稿或配音/AI 克隆纯净净稿，附注与卡片提示单列其外；飞书远端写入交可点击链接与验收范围。命令、配置、已有占位符与面向微信读者的外部 URL 保留独立可见原值（详见 [materials-and-evidence.md](references/materials-and-evidence.md#外部研究引用与可复制链接)）。
