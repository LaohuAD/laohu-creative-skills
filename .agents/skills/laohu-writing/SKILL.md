# 内容写作

解析当前 `SKILL.md` 的真实目录为 `{SKILL_DIR}`，以 `{SKILL_DIR}/../../..` 为 `{PROJECT_ROOT}`，读取 `{SKILL_DIR}/../../../docs/runtime.md` 与[万能造梦框架](../../../references/universal-dream-framework.md)。当前已加载且未变化时复用。依作品目的选内容和成熟写法，再用实际稿件检查接收者能理解、感受、判断或完成什么。

## 0. 区分输入材料、本轮任务与交付媒介

先确认任务是探索、成稿、修订、排版还是录后复盘，并确定交付媒介与接收情境。ASR 可以整理成文章，书面资料也可以写成口播。仅在材料或讨论中提及媒介，或明确排除该媒介时，沿用户实际指定的目标处理。一般文章、解释或改稿由本级完成。

以下方法按真实交付或读者任务选用，局部工作完成后回到 Writing 整合事实、作者声音、授权和成品。

**教学组织。** [通用教程与技术文档](skills/laohu-writing-tutorial/SKILL.md)是父级方法模块。带读者当前能力、操作证据、版本范围与目标结果，选初学跑通、熟手操作、理解机制或按项查阅的文档形态。返回相应的步骤与完成标志、解释/查阅结构及采图项。只要核技术步骤或实操截图时，直接用对应小节。

**面向手机独立阅读。** 用户明确要公众号文章时读[公众号文章](skills/laohu-writing-gzh/SKILL.md)，沿读者、材料与声口安排扫读、图文和已获授权的发布字段。公众号 HTML 排版由 `laohu-htmlshow-gzh` 按委托执行。用户要在 X／朋友圈等发表单条可独立读懂的短文或 Thread 时，读[独立短帖](skills/laohu-writing-social/SKILL.md)，带材料、读者、长度、语气与平台条件，确定最早露出的对象和核心判断，返回正文或组帖。

**飞书文档。** 用户要飞书格式的草稿、原生文档优化或远端写入时读[飞书文档](skills/laohu-writing-feishu/SKILL.md)，带目标、已有稿件与保护项、读写范围及身份线索。聊天稿直接组织原生块。确需远端连接、读取、上传或写入时读[飞书连接与写入](references/feishu-ops.md)，回交实际文档和读回状态。仅以飞书资料为来源时仍按用户实际需要的媒介成稿。

**声音与动画。** 用户要可录口播、讲解或旁白时，读[口播讲解](skills/laohu-writing-spoken/SKILL.md)，带听众、作者声音、时长、实际语速和可用画面，返回可录净稿与必要声画附注。用户要解释性画面标题、标签、步骤、比较、数值或总结时，按需读[动画内屏显文字](references/screen-text.md)，带观看单元、材料锚点、事实或示意状态和读序。完整动画由 Analysis 编入唯一 `brief.md`，Motion 落实运动、布局和渲染；逐字字幕沿剪辑/字幕任务处理。

公众号、独立短帖、飞书和口播是由用户实际意图触发的选择型专项。

明确要两种媒介时，复用事实、作者主张和声口，分别组织、成稿及终审。把短帖存入飞书时，原帖内容的写作决定保留，飞书只处理获准的文档工作。把多条短观点合成长文时，先找共同问题及各条之间的真实关系，再重写成独立文章。教程的方法与媒介排版可以叠加，由本级安排次序，子级之间不递归调用。

录后复盘按[修订与终审](references/revision-and-review.md#录后-asr-复盘先分清问题再决定是否改稿)执行。断言实际录音漏讲，需要原音和预定目标两类证据。只有 ASR 时，可以检查转写里的结构、含混和缺少的前提，未体现的点仅归属于转写。只有原音时可以描述实际讲述。只委托复盘时交诊断与相称改法。

## 1. 确定内容要给谁什么，以及本轮能改到哪里

确定用户的具体目的、成品读者/听众、使用场景、材料能支持的结论、原稿基线、作者立场与声音及锁定项。区分作者和接收者已知的内容，在第一次影响理解的位置让读者认识必要对象、角色或条件。把第一眼能注意到的材料与继续读听能得到的具体理解、体验或任务结果分开判断。

成熟口述、ASR 或原稿只要求成稿、整理或一般润色时，做忠实编辑。按听读媒介去赘、重排句序、补必要衔接并维持原主线。读者所需的背景、指代或解释，先从原材料找准确名称、现成事实与已经表达的关系，就地说清。对照原稿检查新加句，若带出独立的新案例、比较、规则、理论、效果或判断，删去或先核相应的发展授权。材料缺少必要解释时沿现有范围表述，把确会影响理解的实质缺口留给作者决定。

以用户指定的稿件版本为编辑基线，延续已经认可且仍有效的决定。按[认可稿与锁定层次](references/revision-and-review.md#先确定认可稿基线和锁定层次)区分保义保声口、逐字锁定和限定范围修改。保留准确、有力度且在原位置奏效的原句。

把亲历、原话、外部材料、已认观点、编辑推论和未知各归其位。带引用、核查或材料身份疑点时，读[材料、来源与证据](references/materials-and-evidence.md)。材料能让观点更具体时保住它的分量。遇到会改变主张的未知，依据授权查证或把主张收窄，作者的判断与实际材料分别交代。局部真实体验不会自动证明普遍效果。

## 2. 选择适合目的与材料的内容方法

### 按复杂度决定是否调用 Analysis

先核用户允许改哪一层，再判断是否已有可靠设计。按下表处理受影响部分；多种情况共存时仅将尚需相应分析的范围送出。

| 档位 | 可见信号与动作 |
| --- | --- |
| **一档，直接成文** | 忠实整理成熟材料、校对、排版、局部词句修改，已有确认设计，或素材自足的独立短帖和短稿（常约 600 字以内）。直接写、直接审，保住锁定项。 |
| **二档，局部分析** | 单节缺事实或推导根据，或局部新发现会改变原判断。调 Analysis 核该主张与直接依赖。 |
| **三档，前置内容设计** | 获准融合两类及以上异质材料、核承重的外部事实或机制、设计行业参与或商业路径、组织散乱材料成多节长稿（约 800 字以上可提示），或深化论证、重建全文结构。先设计再成文。 |

字数用于提示工作量，授权、现有设计与证据决定实际走法。三档通过 [Analysis 主入口](../laohu-analysis/SKILL.md) 进入[写作前内容设计](../laohu-analysis/references/writing-design.md)，交媒介、读者、目的、材料、原稿、作者声音及可定位原句、主张、锁定项、授权和已有设计。

二档包括局部收尾或过渡。用户指出前一判断为何能支持后一判断没有说清，或实读原段发现两项判断间缺一条理由时，先读取并执行 [Analysis 主入口](../laohu-analysis/SKILL.md) 的写作局部分析。只交争议关系、原段、两端已确认的判断和对象、根据及直接依赖。原材料已有明确理由、本轮只要重排或顺句时，由 Writing 直接改。

只获准补桥时，将两端仍成立的原句先带入新稿，再插入或局部调整它们之间的句子。需要调整气口、句序或措辞时，守住两端的主语、称谓、范围和判断。材料未指定对象时沿用原称谓，附近的示例只说明例子本身。缺根据时保留各项已确认内容，作者愿望可另起一句过渡，由它承担愿望的作用。

委托完整重组的稿件若需要把几条未建立的商业因果、用户行为或未来项目目的接成一条主线，即使总篇幅较短，也先按三档核其材料与证据关系。已有充分设计，或主要关系已经由给定材料说明的技术短文，直接成文。权限不足时只对有据的内容起草，其余问题按授权收窄或留待确认。

Writing 接回设计时核对承重事实、材料到判断的桥、作者声音、视觉/实操素材缺口和各单元预期作用。不一致时指出冲突并从相应档位退回，修正后接续。写出来的段落应能承担各自的解释、证据、体验或动作，正文采用真实表述。已有充分设计则直接复用，范围内的成文无需再等大纲批准。

主线、论证、非虚构叙事或方法解释有实质取舍时，读[结构、论证与叙事](references/structure-and-argument.md)的适用段。复杂读者所得、长篇推进及情绪安排另按需读[读者价值与作品组织](../../../references/audience-value-and-structure.md)。解释、故事和指南分别沿真实材料的关系推进。文章可用章节导航，口播按听觉方法安排顺序。

起草或重构中若内容组织、声口或关键表达有尚未定的选择，按[共享取法](../../../references/exemplar-study.md#日常创作取法与方向)和[本地作品方法库检索](../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)核对当前决定所需的方法、材料卡及适用条件。把具体处理移到本文相应位置再回读。已有同目的详情可以复用；无新选择、纯整理或锁定文本修订沿既定写法。

## 3. 把材料写成成品的实际推进

1. 确认每个主要单元给接收者什么。组织承重材料，决定哪一处展开，哪些后续判断要用到它。修订现有内容时先按[修订与终审](references/revision-and-review.md)识别已成稿基线和反馈生效范围。

2. 新写或重做文章开头时读[开篇与阅读路径](references/openings-and-reading.md)，按熟悉对象、体裁入口、遮住标题复读和正文兑现四步决定开头。口播、短帖按各自的方法确定首次进入和过渡。

3. 按媒介起草实际成品。需判断句群的语义、自然成句或表达密度时，按需用[共享语言成文方法](../../../references/language-realization.md)及[语言、密度与表达](references/expression-and-density.md)，落实句首承接、主谓贴近、新信息位置、动作与结果。读回同一语境检查有无误删费劲感、态度或必要停顿。

4. 文章内容或教程结构已成形时，若有具体操作态、复杂可视关系、同尺比较/可复制内容或承载体验的场景，按[篇内图文四分规则](references/structure-and-argument.md#按读者任务安排篇内图文)选截图、信息图、原生表格/代码或表现画面。确有需要再制作或发采图单，每处依据真实读者任务和授权选择。

5. 初稿后从读者/听者位置反向审稿。按[反做提纲与删除损益](references/revision-and-review.md#从成稿找最早的断点)定位实际承诺、证据、因果和体验，再修最早断点。各角色各自核对谁做什么、购买或接收什么、对什么作判断。发现身份、评价目标或交易对象换位时回到原材料修正，再复核相应推论。删前检查原义、态度、节奏与理解所需的前提。

## 4. 按媒介选择入口、字段与终审

### 成稿与标题交接

Writing 读取并执行相应公开能力，由公开入口选择子级。带锁定词、实际上下文和作者意图，仅在本轮需完成的字段追加工作。

| 触发与去向 | 交给专业入口 | Writing 接回的工作 |
| --- | --- | --- |
| 未锁定的主标题或章内小标题要新拟/修改 → [Title](../laohu-title/SKILL.md) 的篇内导航。 | 字段、准确数量、实际各节正文与相互推进、作者声音和锁定项。 | 按原序嵌回，脱离正文扫读标题骨架，再核实际内容有无支撑。 |
| 题眼、收束、原则句等确需专项凝练 → [Title](../laohu-title/SKILL.md) 的核心表达。 | 媒介、职责与位置、相邻上下文（可用时前后各两句）、读者/听众既知、材料、作者声音及主张锁定或开放的范围。 | 放回原位置连读并按位置复审。从原稿确有独立认识处取材；日常过渡由 Writing 写。 |
| 用户另要平台发布标题、长短字段或共用封面主标题 → [Title](../laohu-title/SKILL.md) 的发布入口。 | 平台、字段、准确数量、正文/核心材料、目标读者、查询意图（若有）和锁定项。 | 校实际字段、承诺与正文，按要求在文章本体之外交付。锁定字面与用户指定格式优先。 |

篇内题眼和收束接回正文后，按 Title 的[位置复审](../laohu-title/references/title-value-and-review.md#篇内与歌词关键句按位置复审)检查作者声口、真实位置与前后承接。

| 触发与去向 | 交给专业入口 | Writing 接回的工作 |
| --- | --- | --- |
| 篇内图需让读者辨认、比较或追踪复杂关系 → [Cover](../laohu-cover/SKILL.md) 的信息图。 | [信息图交接八字段](references/structure-and-argument.md#信息图交接和实图核验)，包含文字密度、制作路线建议及授权。 | 把真正可访问且已打开核验的图接回锚点；待制作则正文仍可独立读懂，块外交准确图注位置和制作说明。 |
| 用户追加配套头图/封面 → [Cover](../laohu-cover/SKILL.md) 的社交封面。 | 定稿标题、Title 回交的八字封面文字及字图分工、核心读者处境、证据锚点、目标平台/比例和授权。公众号成图规格按 Cover 既有正式定义核对 2.35:1 横图及中央 1:1 安全核。 | 检查文字和图共同指向同一篇文章的真实处境。用户授权实图且工具可用时实际制作、打开并验收；否则交独立设计稿/提示词并注明工件状态。 |

开放探索的新句若会改变核心主张、证据推导或全篇组织，先核实质修改授权。授权覆盖时按二档把新旧主张、证据位置及受影响单元交给 [Analysis](../laohu-analysis/SKILL.md) 的[局部更新](../laohu-analysis/references/writing-design.md#接收成稿反馈并局部更新)，复核直接依赖后由 Writing 改稿、嵌回并终审。授权只及词句时，保留原主线，说明需作者决定的发现。

终审从实际成品复查标题、开头和每一节的增量。检查展示顺序、来源、保护项与调性。文章有图时沿正文、图、后文顺读，实图按目标尺寸核字与关系；口播按听觉方法试读，篇内说明与声画生产附注分别交付。已观测到的成品问题直接修，读者效果、点击和传播以真实接收证据判断。

一般文章默认在聊天以一个 Markdown 代码块交付完整正文，主、小标题归入本体；含内层代码时加长外层围栏。短帖默认直接交正文，口播交可录净稿，配套发布企划、采图执行单和提示词按需要置于文章之外。用户指定格式优先。阅读导航用可辨用途的链接文字；可复制的命令、配置、提示词和实际需复制的 URL 保留原值。公众号需复制访问地址时按[材料、来源与证据](references/materials-and-evidence.md#外部研究引用与方法)核显示、链接目标和可复制文本。

交付飞书聊天稿时直接返回草稿，远端操作依飞书配置和对应授权读取、写入和实测。用户明确要求本地保存或归档时调用 [Archive](../laohu-archive/SKILL.md)，用它返回的位置写用户实际要求的内容，保存时移去聊天外围围栏。链接、保存和写入分别如实报告实际状态和范围。
