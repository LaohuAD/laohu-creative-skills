# 老胡找茬

查明对象及其组成实际怎样处理材料、产生什么作用、与已确认的用途和接收条件差在哪里。被审对象为规则或流程时，也检查其内部机制和结果。跨环节复发原因、责任动机、修法取舍和正式实施随[三技能职责](../../../references/triad-handoff.md#1-三技能单一职责与交接红线)交接。

按[以解决问题推进审查与分析](../../../docs/runtime.md#以解决问题推进审查与分析)接住已有分析或方案的真实困难与有效发现，查它们还有哪些机制未落到结果。重要异议须说明怎样改变处理或后续判断。以适用标准核对实际材料，作者的投入、自信或局部规格通过都不能降低标准；语气默认直接、严格，讽刺或冷幽默可按用途选用；按证据说明事实与影响，不为气势凑问题、夸大后果或攻击作者。

## 建立审查基准

### 定位对象、版本与实际可见范围

1. 复用已确认的对象、版本、目标、保护项和授权。宽泛口语默认指最近的实质作品或规则；交付通知读其所指材料，明确指定优先。仅有会改变重要判据的同等合理对象时澄清；确无材料时索最小必要件。
2. 说明已读版本、片段、状态、上下文和抽样。作品起点若可在全文前独立取得，先记当时可见内容、主题/关系与承诺，再读全文；已看全文可分析开头但标明非盲读，中段片段不得冒作开头。未读部分只限制相应结论。
3. 从语义判断所点方向是整体审查的优先项，还是明确范围限制。普通整体审查覆盖用途相关作用；已限事实、格式、维度或局部的按其授权工作。不以宽泛的“弄好”推定新增交付或外部动作。

### 还原用途、角色与接收条件

按 [作者表达意图与成品保真](../../../docs/runtime.md#作者表达意图与成品保真)分清委托者、负责作者、作品接收者、报告读者及直接机器消费者，核机器输入/输出契约。对作品先按[承诺与接收进展范围](references/object-checks.md#先界定本作品承诺与接收进展范围)界定本次承诺，再选判据。把最终愿望与局部承担的进展分别说清。

已确认的立场、视角、声音、情绪力度、技法和优先级作为判据条件。日常审查核与本轮候选有关的决定；全仓意图审查、迁移或源头保真时回原请求、随后确认、源材料与所选方法。事实校正仅及不受支持的断言及直接依赖；事实、权限、安全或技术限制按实际条件触发。作者的本意须在真实交付中可观察，审查者个人偏好不足以判错。

### 按对象加载方法

各类审查复用开头运行约定，读取[万能造梦框架](../../../references/universal-dream-framework.md)，按[整体与局部分级](../../../references/triad-handoff.md#3-万能造梦框架的跨入口接力与分级深耕)确定覆盖、深度和重点。读完以下所需方法，回到[实际检查](#读取对象并发现候选)使用其判据与动作。

| 审查情形 | 读取与返回 |
|---|---|
| 作品、稿件或内容材料 | 读[实际材料检查](references/object-checks.md)中本轮匹配小节：承诺范围、双向核验、接收顺序或其他媒介动作；文字内容、组织与语言质量在范围内时，读[读者价值与作品组织](../../../references/audience-value-and-structure.md)及[语言成文](../../../references/language-realization.md)的有关小节，带可核判据做材料实查。 |
| Skill、Reference、运行规则、流程或提示词系统 | 读[规则与流程探针](references/rule-process-probes.md)，应用范围内适用探针；语义、力度、来源或本地闭合需专门核实时，按探针指向读对应规则小节，把证据带回候选确认。 |
| 复杂归因、反证、争点或不易识别的功能关系 | 读[问题发现与确认](references/question-discovery.md)的相应小节，用功能拆解、比较、论证、反证或推理标准深化；实证带回候选确认。 |
| 正式人类标尺对比、质量评分或校准 | 仅用户明确要求时，读[正式评估与 L/C/D/H](../../../references/exemplar-study.md#正式评估与-lcdh)及[验证协议](../laohu-analysis/references/validation.md)，核真实作品、来源与语境、可比条件、人类校准和等级边界，带证据与限制回候选确认。 |
| 已授权复查 | 读[问题复查](references/retest.md)，按原编号与证据层级回到[交接或复查](#只在授权范围内交接或复查)。 |

### 建立可执行的质量判据

1. 分别核交付契约、专业方法和用途效果。字段、长度、格式及保护项按约定；机制和材料关系按专业方法；接收用途按其实际可达内容。先看已有规范、接口和验收能否判断，足够则直接核。
2. 判据应明确作用、对象及条件、材料、执行动作、合法分支与哪些信号会改变结论。实际代入观察、比较或核验。区分方法未提供、未加载、未执行、执行后不足、适用条件不成立和证据不足。
3. 本地判据有关键缺口时按功能动态发现仓内或宿主明示可读的专业 Skill/Reference。先核专业职责和适用条件，仅取必要方法回本节，不启动其完整创作、写回或外部动作。若本地方法仍未覆盖关键功能，从任务提供的补充规范或相称可靠的专业来源补齐，核适用范围及其对本轮判断和动作的影响，遵守原有取证权限。
4. 口播首听和声画分工、会影响推论的技术分类、动画事实与开放视觉选择，分别调用实际承担这些判断的专业方法。技术类别影响结论时必须核定义及实际目的、处理、产物；视觉硬要求须有目标、来源必要条件或工程限制支持，素材名称和局部示例不能单独推广。缺口只限依赖的结论；关键用途足以改变判据而又不可区分时才询问。
5. 明确涉及来源或迁移时，取已选范围的实际片段、版本、必要上下文、适用条件、顺序、接口、依赖及例外，核对本地规则、实现与真实使用者。比较原作用是否保留、适配、有据替换或有意舍弃；词句相同或不同都不足以单独定性。

把每个关键作用、责任依据、所需材料位置、观察条件、适用判据和动作记作后续输入。局部职责以承诺、可证的分工/交接、委托、接口或相称专业规范为据。新材料推翻基准时先更新相应判断。

## 读取对象并发现候选

### 按目标、方法、材料和交付检查

1. 按已定范围检验每个重要作用如何通过事实、方法、条件、实际选择和可见结果承接。追踪选择、保留、删减、排序、转换和交接的贡献；核组合是否抵消，下一步是否取得应有材料。额外负担要能定位接收者因而多猜或多做了什么。
2. 文字内部关系在范围内时，先按[双向核验](references/object-checks.md#双向核验文本内部关键关系)提取全文约束和后续行动所需参与者及前态，交叉核对后给价值或风格判断；短文本全核，长文记抽样，所见入口只能作入口观察。并读实际可得且相关的前稿或来源，核同对象、版本和范围的冲突、未兑现解释或无据转换；只有当前稿仍查内部关系。报告中的专名、引语和称呼回核原值或有据别称。
3. 普通整体作品审查，或已指定体验、情绪、传播作用时，在基础关系之后按[接收顺序六步](references/object-checks.md#按接收顺序检查作品体验与传播条件)走实际材料。记录关键位置接收者已知、期待或经历的内容，后续如何增加、改变、维持、回返或结算，并说明与用途的关系。只列主题或说“接上了”时，回该方法补做。
4. 从最终接收者实际可见、可读、可听或可操作的产物判断，按可见词句、状态、动作等定位观察。证据只有规则、提示或中间产物时，范围限在该层。实际理解、情绪、点击与使用效果依真实接收观察；仍可判断材料支持的功能。

逐项记录材料位置、动作、观察条件及充分承接、局部不足、受限或不适用的理由，供确认和停止使用。在授权范围内继续尚有材料与方法可检验的作用。

### 只从有据的目标差距形成候选

候选来自明确要求未满足、必要作用缺项或不足、方法与条件错配、处理断开或抵消、结果无法交接，或相对用途的可避免负担。每项回到真实材料、对象职责和适用判据。被审对象为诊断报告时，其中对原对象的诊断只是待核材料，按报告自身的用途与证据判。

## 核实候选并确认差距

### 以图尔敏论证把观察接到结论

依次核可定位的原句/动作/状态及条件，承诺或分工怎样使对象承担该职责，适用判据怎样作用于眼前材料，以及三者是否共同支持结论。需要时写清依据背景、强度限定与例外；直接事实核对可简写。复杂论证时按[图尔敏方法](references/question-discovery.md#用图尔敏论证检验候选是否成立)补论证链。

### 核对会改变候选的实际反向材料

沿候选检查真实可达上下文、已确认设计、合法例外及相反事实。直接推翻前提、职责、适用条件或推理的，撤回或收窄该项。另一组成被声称承担同功能时才查它是否实际补足；其通过不替其余功能作证。假设风险、未被材料支持的读法、仅可行的不同处理和审查偏好不足以判错。复杂争点按[反证的两种作用](references/question-discovery.md#反证有两种不同作用)和[推理标准](references/question-discovery.md#用推理标准检查自己的判断)回到本步骤。

### 分开判断差距是否成立、影响多大和证据到哪一层

先确认条件、实际材料与适用判据共同支持差距，再按目标作用判断受影响范围、后果和接收成本。记录证据到规则、实际加载、执行轨迹、成品或真实接收哪一层，受抽样、缺失材料和方法条件影响的只限其结论。单处观察不外推全链。若已有适用严重度判据，按其定义使用；没有频率、持续性或损失材料时不猜概率、比例或必然后果。

## 组织问题包

### 依真实不足归组并保持问题可接手

给确认问题稳定编号。默认按目标影响排序，适合时标 **P0 阻断核心用途、P1 削弱主要作用、P2 局部损耗或隐患**。同一差距由多方向共同造成时归组；不同功能分别呈现，共同影响不等于同一根因。跨入口按[交接字段](../../../references/triad-handoff.md#2-统一追溯主线audit-id-交接契约)带上 AUDIT-ID、职责与判据、证据、保护项及覆盖状态。

开头简要交代对象、版本、检查范围和已确认用途。用逐项作用评估说明观察到的实际贡献、足够或有缺口的需要、材料依据及受限项。关键受众作用给出前后内容如何改变理解、体验或行动。单项可自然成段，按需保留用户要求的字段和接口。

### 每项按“明确批评—材料依据—本项结论”写清楚

1. **明确批评。**用通俗话定位原句或动作，说清目标作用少了什么、具体理解/体验/行动如何受阻，或接收者为何需要额外操作。
2. **材料依据。**说明真实职责、眼前处理、判据与差别出现处。多项独立依据各给其材料、适用检查及支持作用；单项已足够时直接写明。避免仅凭术语、泛评或换词复述。
3. **本项结论。**写清影响、适用条件和证据边界。面向人类读者的复杂或长问题包按[成句](../../../references/language-realization.md#成句把表达动作写出来)和[成段](../../../references/language-realization.md#成段让句子共同完成一项工作)回读措辞和承接，必要时按实际词义或结构问题读相关小节，改回读者可理解的完整意义。可恢复的含蓄、简称和有用重复保留；语气服从用户要求，事实与诊断力度继续按证据。

### 确认差距后给出同材料局部对照

确认已读材料有据差距后，按[报告内局部对照](../laohu-evolution/references/rule-expression.md#对已确认差距做报告内局部对照)取最小完整范围，给出实际改后内容。审规则先核[规则对照边界](references/rule-process-probes.md#审规则时的局部对照边界)。把改后放回上下文，重建真实语义关系并核首个直接下游，再回本节在问题及证据后交付变化、作用与保护项。

## 停止、授权交接与复查

### 完成实质覆盖后停止

交付前核对象及版本、范围和保护项，逐项验证材料、职责、判据与影响相互支持；局部反证仅影响其所及，语气和严重度与证据相称。普通整体作品覆盖基础关系、适用专业条件及用途相关接收任务。未检查且有依据的相关作用回去补查。

无已证差距时也说明主要作用看到了什么、材料依据与限制；不为配额加问题。存在已确认差距时交问题包，按适用条件附报告内对照。此入口只在当前交付报告结果，不擅改原件、代做整件修复或生成审计文件。

### 只在授权范围内交接或复查

已有问题需要跨环节定因、比较修法或写回时，按[授权连续性](../../../references/triad-handoff.md#4-授权流转与自然接续规则)与原委托接续，明确需分析时读取 `{SKILL_DIR}/../laohu-analysis/SKILL.md`；已选方案交已获授权的实施者。需用户选择后续入口时交 `/laohu`，沿已选入口继续时勿重复要求选择。仅本轮已要求或授权包含复查时读[问题复查](references/retest.md)，按原编号或稳定锚点报告状态与保护项，并在现有授权范围内停止。
