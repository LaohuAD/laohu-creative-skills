# 作品与内容材料实查方法

由 [laohu-audit 主文](../SKILL.md) 在审查文章、口播、剧本、小说、歌词、生图/视频/音乐提示词、前置简报（`brief`/计划/方案）或视觉/多模态材料时读取，查完带可定位观察回到主文筛选与交付。

## 1. 先辨工作形态、承诺范围与三态前提

动刀前先结合完整委托、体裁、原句与读者可达上下文，辨清两件事：一是这份材料属于**直出作品**、**提示词中继生成文本**还是**上游规划简报/方案**；二是它承诺把接收者推进到哪一步（吸引注意、理解原理、比较选择、驱动下游渲染还是照着执行）。

- **先查前提有没有偏离本领域殿堂级特征（三态裁决）**：若作者或用户给出的方向同向且独到，顺着该方向严审兑现度，绝不擅自换道；若目标宽泛模糊，主动按本领域殿堂级标杆补齐审查标准；若原件前提或外壳本身就违背本领域本质规律（如歌词硬塞琐碎生活杂物、封面塞满元素主体失焦），直接点出前提偏离、拎出必须守住的核心情绪与事实底线并建议换血，不只抠表皮字句。

- **严禁拿写实核查标尺误杀合法创作手法**：标题、封面、开头前几句或讲解段落为了抓住注意力、基于读者底层心理唤醒痛点与业务损失意识、或把晦涩方法讲得通俗好懂，而使用**强钩子、噱头、情景假设、故事化演绎、寓言类比或戏剧化对比**——只要它**不是伪装成真实新闻/真实受访对象/真实调研数据**，且**后文确有真干货兑现承诺、最终帮到读者**，就是高价值的传播与教学技巧，**绝不叫欺骗或编造**，严禁借事实审查把钩子削软、把好故事砍平。
- **真正要盯死的两种越界**：① **冒充写实证据的编造**（把虚构的经历、情绪、数字或第三方统计包装成真实亲历、真实受访者故事或权威调研）；② **货不对板的空心噱头**（开头用强钩子许诺了清单/实操/答案，后文却拿空话敷衍——毛病不在开头吸睛，而在后文违约）。
- 不抓孤立词把经验分享强行放大成绝对承诺，也不把明确的落地承诺放水成泛泛而谈；读到后文若发现原判断有偏差，立即更新审查基准并撤回基于旧基准的批评。

## 2. 全量事实账本与逻辑交叉核验（防顺读滑过）

审查文章、叙事、教程或论说材料时，最容易顺着流畅语气滑过隐蔽硬伤。先做一次彻底、不跳行的全要素交叉核验（短文全核，长文标明抽样边界）：

1. **全要素实体账本拉通**：顺着全文把**人物/案例序号、时间跨度、金额与成本承诺、各自最终结局、以及对象资格前提**拉成一条账本逐一核对——重点盯死：
   - **状态与时间线相容性**：后文结局或时长与前文定调（“全都/唯一/半年/下线”等）在同一对象下能否同时成立？是否出现序号断档或某个案例有头无尾？
   - **角色与动作资格前提**：文中写到的主体在现实逻辑里究竟具不具备那个动作或属性（例如原设定下某类用户本来就没有该项权限/账单/步骤，或前后把两拨不同人群搅成同一拨人）？
   - **前文立项与后文要素闭环**：前文承诺要拆解的案例/账单、重点抛出的成本项或核心痛点，后文有没有漏拆、漏算、缩水或悬空未结？
2. **概念归类、统计口径与因果链核查**：
   - **概念与业务归类边界**：文中举的具体例子或术语到底属不属于作者给它贴的类别（例如把前端交互问题错归成数据库瓶颈、把旧工具形态和当下新形态混为一谈）？
   - **数据与统计口径核验**：除核对“至少 80%”这类无来源伪精确数字外，更要追问**算术与统计口径本身能否成立**（例如百分比是相对涨幅还是绝对百分点、不同基线能否混均、计费周期与统计窗口是否自相矛盾）。收窄无据断言时只动该句及直接依赖，不误伤全文立场。
   - **相邻因果不跳步**：前因与后果、相邻两段（尤其“所以说/因此/好在”等转承句）能否直接推出？绝不在脑中替作者脑补过场；同时留意看似打架的两句话背后是否藏着值得点破的真实悖论。

## 3. 行业实操压力测试与首次接收走查

跳出纯文字校对，切入**目标行业一线从业者**与**目标发布平台首次读者**的真实眼光走一遍：

1. **行业实操压力测试（防纸上谈兵）**：把文中的论据和建议放进目标受众的真实日常里拷问——文中建议的前提在目标受众的人力、预算、时段或工具条件下**真能跑通吗**？有没有回避一线最要命的执行死结？商业算账上有没有把竞品/旧模式的共有成本错算成新模式的独有罪状？
2. **入口承诺与发布媒介检验**：结合目标载体（如公众号标题字数是否过长截断或重复用词、标题括注附赠物是否货真价实、口播首次听觉是否一次听懂、长图/表格在移动端是否易读）核对入口与交付。若是看完全文再回看开头，心里严格分清第一眼实际看到的和后文才补上的，不拿后文替开头免责。
3. **逐段推进、声口一致与自然母语人话**：沿接收顺序检查每段相对上段究竟新增了什么判断、证据或方法；重点揪出前半段锋利算账、后半段突然端水防御、换上放之四海皆准的空心套话或过度打包票的声口断崖与承诺违约；同时揪出三类典型 AI 腔——抽干虚词硬挤字数的电报缩略句与超长名词定语、违背母语习惯的生造动宾搭配或生搬规则比喻、以及满篇给普通词/自造绰号/转述套引号的写法，在改后对照里直接示范用真人自然顺嘴的句法把意思立起来。图文/视听成品只在真实读到对应媒介时评判视听效果，只有文稿时将结论自然限定在文本内容。
4. **创意与表达类作品的层级错位与质地检验（仅审创作/表达材料时启用，就地自足判断，日常审稿不额外加载外部治理文档）**：当一篇创意作品表面结构工整、零事实硬伤，但读起来总觉隔一层、假大空或没劲时，直接向上追两层根因：
   - **查立意海拔与层间错位**：作品是否困在流水账写事、原地情绪宣泄，或拿普通常识硬穿宏大词藻的假拔高（外壳大于思想）？反过来，核心洞见明明真实深刻，却在血肉或收尾滑向粗鄙泄洪、小聪明寓言，或像写论文一样列条推理、理性结案给高潮泼冷水（载体拖垮立意）？
   - **查审美质地与媒介留白**：是否掉进未经提纯的粗鄙失控，或掉进客气辩证、安全圆滑却把真实情感电压包死的防御性文雅（尤须保护高张力风格不被磨平）？在歌词、剧本、封面、短故事等协同留白媒介里，有没有把前因后果塞满造成窒息感，或用零度杂物与流水线塑料意象抢占核心母体？改后对照须守住原本打动人的真切片，既不靠堆华丽辞藻假拔高，也不滑向温吞端水，同时贴合目标平台（如手机端段落呼吸）让成稿直接可发。
5. **提示词中继文本与上游规划简报专检（仅审对应形态时启用，就地自足，0 加载外部框架）**：
   - **审提示词中继文本（生图、资产、封面出图、AI 视频分段、AI 音乐/声线）**：绝不拿散文文采判优劣，按四维物理转译直查：
     - **灵魂与筋骨**：宏观艺术风格、媒介质感与核心情绪有没有锁死（防飘成塑料 AI 味）；画幅布局、多视角结构、文字安全区或镜头起承转合清不清楚；
     - **血肉可渲染度与时空自洽**：是不是下游模型听得懂的具体主体动作、景别机位、前中后景、光影色温、材质或音色，有没有塞进不可渲染的抽象心理点评、故事前情、互相打架的物理/机位指令，或昼夜时空错位、超出窄景别空间容量的硬塞物件；
     - **表皮编码（正向主词零否定坑）**：单条是否独立自包含、参考附件绑定无错位、篇幅不过载；**正向主提示词须全部靠正面画面、光学构图或出画裁切达成效果，严禁在正向主词里塞入否定禁令反召禁区词**（排查与改后对照均严守此条，排除项统一单列到工具独立负向栏）；
     - **未实渲时的诚实边界与验片抓手**：无真实成图/成片/成音时，明确只对提示词文本下结论，绝不猜测或冒充渲染效果；同时顺手给 **2–3 条首版渲染后的肉眼/真耳硬验片动作及跑偏后的定点调词方向**，让创作者拿到就能落地迭代。
   - **审上游过程简报与方案（前置 `brief`、大纲、计划、选题）**：专查三关——① **是否锚定最终殿堂级成品**：有没有顺着平庸前提走形式填表，或用正确废话回避真正决定终稿上限的骨架与取舍？② **能否拦住最早断点**：大结构、情绪曲线、受众切口或媒介分工有没有硬伤？③ **交给下游时是否防反向污染**：如果这份简报会直接喂给下游创作或生成模型，有没有写成堆满文艺气氛形容词的散文详案，反而把下游成品染成端着架子的作文腔（必要时建议压缩为纯净白描交接卡）？
6. **表皮呈现分轨与用户固定格式硬契约专检**：
   - **审最终作品本体**：检查是否遵循该媒介原生专业格式、有无把中间分析、打分自查或过程废话混进成品本体；若用户或该领域已明确约定固定输出格式（如歌词英文中括号段标与句内空格气口、纯净独立代码块、指定 JSON/CSV/表格字段），核查是否严丝合缝执行——**擅改固定格式或混杂过程废话属明确硬伤**。
   - **审中间态方案、选题、简报或分析报告**：检查是否用清晰标题层级、分条、对照表、推荐排序与核心结论加粗让人 3 秒扫清重点，有没有堆成密不透风的大段紧凑文字墙把结论埋死。

## 4. 反向自检与真伪筛选

对查出的每条候选问题做两步核查：

- **查反证与合法设计**：上下文里有没有作者刻意留白、不可靠叙述、合法前提或后文补足？若反证直接推翻事实前提，立刻撤回或收窄；若声称由另一部分代偿，核实它是否真补足了同一作用。
- **区格局与局部**：每段文从字顺不代表兑现了整体承诺；一处局部瑕疵也不自动推翻全篇立意。把**全部经得起反证核验的真硬伤**按轻重分层带回主文——既不为了显得精简主动扔掉已发现的隐蔽硬伤，也不放进纯属个人口味的假挑刺。
