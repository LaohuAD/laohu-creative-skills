# 问题发现与确认

由 audit 主文“建立审查基准”在每次审查进入候选搜索前读取；复杂候选需要补充功能拆解、专业判断或反证方法时，在本 Reference 对应小节深入，随后返回主文“核实候选并确认差距”。主文承担完整审查主线和普通任务的可执行方法；本文件只深化怎样从实际用途与材料关系发现、论证候选，不另设全套流程、固定清单或输出格式。未确认的内部候选不进入问题包。

## 把对象用途拆成可检查的作用

### 从接收者需要的进展出发

1. 沿用主文已确认的对象、版本、授权、接收者和用途。用户只说“哪里不对”时，不要求其先命名缺陷或专业维度；本 Reference 帮检查者把已知用途转成当前材料上可观察的事情，不替用户虚构目标。
2. 先描述接收者在实际触点需要理解、判断、感受或完成的一个具体进展。再区分对象的主要作用、支撑该作用的必要材料，以及可能由其他组成或合法路径完成的工作。不要把整个任务的终点直接分派给其中一个局部。
3. 沿真实组成追踪“谁/什么在什么条件下承担哪项作用，凭什么完成，结果由谁或哪一部分接续”。定位责任时以主文建立的委托、对象承诺、功能分工/材料交接、接口或适用规范为依据；责任尚不清但会改变问题是否成立时，收窄或澄清。
4. 对每一步都问它给接收者提供了什么具体内容或可用状态、需要什么输入、受哪些条件影响、怎样连接下一步。局部可有独立作用，也可与其他组成共同完成整体功能；按实际可达组合判断，不强迫每个局部自足。

### 把功能关系化成可观察差别

- 选择问题：材料为何选择、强调、保留、删减或优先某项内容？它怎样改变当前用途下的取舍？
- 方法问题：当前判断或机制在什么前提下适用？何种输入、例外或状态变化会使其改变处理？
- 组织问题：材料的顺序、连接、转换或交接是否让下一部分得到完成其职责所需的内容？
- 呈现问题：最终接收者从实际可达的词句、界面、行为或媒介中能取得什么，哪里还需要作者说明或读者自行补足？

这些是候选观察路线，不是四种必错类别。材料可以已经完成作用、只在特定条件下不足、被另一处理抵消、组合后断开，或没有独立缺陷。若发现明显呈现问题，先记录它在什么实际词句/状态/媒介中出现，不把它一概解释成上游方向错误；某个候选也不能取代其余授权方向的检查。

## 从差别发现不同类型的候选

### 同时留意缺项、弱项、断点与多余负担

候选可来自：明确要求未满足；某项功能或必要材料没有承接；内容虽在但方法不适用或作用不足；局部材料彼此矛盾、抵消或未连接；一个已完成的局部结果没有交给应接手的部分；对象让接收者承担了相对于其用途可避免的额外理解或操作工作。每种情况都须能回到实际材料和当前对象的职责解释，不能因候选类别出现就判对象有错。

当对象由多个说明、规则、接口或引用共同承诺能力时，对照这些承诺与实际输入要求、处理动作、停止条件及下游接收方式。若当前规则文字在已承诺的请求或条件下明确排除、错分或无法形成约定产物，或实际执行结果与承诺不一致，或关键职责在交接处无人承接，可形成候选；缺少运行记录只限制对实际执行的结论，不证明运行已失败。术语或句式不同但行为和结果一致，不算冲突。

“有材料”不等于“完成作用”，“有方法名”不等于“按方法有效执行”，“局部规格通过”不等于“组合用途达成”。反过来，“没有某项内容”也不当然是缺陷：先判断当前对象是否承担该内容、它是否是完成作用的必要条件、现有其他组成或合法路径是否已提供同一功能。

### 用宽度找遗漏，用深度核实关键差别

宽度检查：在授权对象内，是否还有尚未查看的目的/取舍、专业方法、实际材料、接收呈现、直接依赖、条件或保护项？是否有关系相抵、互相矛盾或局部通过后仍断开的功能？

深度检查：表面顺畅或规格通过后，关键选择的依据和适用条件是否成立？材料是否真正承担目标作用？已有机制为何不足、在哪种组合或状态下变弱？接收者实际缺什么，或被迫额外猜测/操作什么？深度不等于追查对象之外的唯一上游原因、堆专业词或无限制造反事实。

宽度和深度都须有具体观察。多列材料不等于宽度充分，同一缺陷换词重复不等于深度；反例解释了一项差异，也不能使未查的方向自动免责。

## 取得方法后，把它用在眼前材料

本地专业入口和来源的发现顺序由主文“建立审查基准”规定。本节接收已选方法，将它变成当前材料上的检查，不重新搜索一套领域，也不把理论名或标准名当结论。

主文[“按目标、方法、材料和交付检查”](../SKILL.md#按目标方法材料和交付检查)确定本轮关键作用和检查范围；本节把每项作用转成可观察的质量条件，定位承担它的材料、选择或关系，按适用方法检查其对作用的实际贡献、已承接的关键需要、仍不足之处及成立条件。记录材料位置和实际检查动作，形成充分承接、局部不足或具体证据受限的作用评估，逐项交回主文[“核实候选并确认差距”](../SKILL.md#核实候选并确认差距)核实或停止；主题对应、元素在场或契约通过只支持其实际覆盖的条件，不替代未检查的其他作用。

1. 把方法要求转成明确的功能判断：它要检验什么作用、针对何种对象、依赖哪些条件/输入，什么情况会改变判据。
2. 从当前对象里定位承担该作用的材料、动作、选择或关系。依照方法实际要求，读取、比较、追踪或核对这些内容；不要把“要提高效果”“要判断充分性”当成操作。
3. 记录实际支持判断的观察，以及已出现或可取得、可能改变判断的反向观察；若没有相反材料，不编造反例，也不因反例缺席而削弱已有证据。单一事实足够时不强配第二种根据。方法允许多种实现时，不把某一种审查者偏好的形式当唯一答案。
4. 将观察连到接收用途：实际处理对每项作用贡献什么、哪些关键需要已承接、哪里仍不足或受限，以及在什么条件下成立。若候选本身来自“还能这样理解”或“还能补充内容”，用现有表达及接收者可达上下文核实这种读法是否有材料支持，再核对未明说内容是否属当前局部职责、读法或缺省具体削弱了哪项应承担的作用；能设想歧义或扩写得更完整，不等于对象已有差距。若方法或条件尚不清楚，只限制受影响的判断，继续其他有可用判据的检查。
5. 当关键选择是否造成差距仍不清楚，且比较能区分“目标作用确有不足”与“只是另一种可行实现”时，才在同一材料上对照现有处理与候选处理，或只改变一个决定条件，观察哪项关系、动作或交付随之变化。比较对象须是实际材料或明确标注的诊断性变体，不只比较作者解释；由审查者自行制作的变体不能证明真实接收者会有同样反应，也不能冒充盲评或已发生效果。比较若不改变相关功能判断，就不据此硬造问题。

专业方法若仅解释“可能有效”，不能直接证明眼前对象已经有效；名称、格式、主题对应、元素在场和过程有步骤，都不能代替对实际作用充分性的核验。若标准仅定义接口，它只支持接口判断；核心功能是否充分仍要用适用方法实际检查。判断专业来源或论证方式本身时，遵循主文的原始来源、适用范围与证据层级要求。

若论证依赖专业原文、正式范例或外部案例，核对来源身份、原始内容、版本、必要上下文和适用范围；不得把审查者自拟内容伪装成真实范例、引文、结果或接收反馈。无法核实时，只收窄依赖该来源的判断并说明证据限制。

## 用图尔敏论证检验候选是否成立

Stephen Toulmin（斯蒂芬·图尔敏）的论证模型来自《The Uses of Argument》（1958；2003修订版第Ⅲ章，第90—94页）。将它用于检查“从观察到结论所依赖的理由”，而非机械生成六栏：

1. **材料（data/grounds）**：指出真实可定位的内容、动作、条件或状态，以及它出现的上下文。
2. **结论（claim）**：明确要确认的是哪一项具体不足，不用问题名称倒推证据。
3. **理由（warrant）**：说明为什么这些材料按某个适用要求或专业方法能支持该判断；材料与结论之间缺的逻辑不能靠语气补上。
4. **职责前提**：对缺项/不足，另外说明当前对象为何承担此功能。责任依据与“材料显示做得不足”是两个分别需要成立的环节，不能用整体目标替局部职责，也不能用未展示的外部结果替眼前证据。
5. **依据（backing）、限定语/强度（qualifier）与反驳条件（rebuttal）**：结论依赖专业背景、强度限定或例外时，说明相应依据、结论把握程度及会改变判断的条件；直接而清楚的事实无需为了形式填满术语。结论仍限于当前对象、条件和证据。

适用方法须说明核查动作并真正代入材料；图尔敏模型只是把论证连接显出来，不替代领域判据，也不证明结论必然正确。职责来源、专业适用条件、材料事实任一未成立时，取最小必要证据或收窄候选。

### 反证有两种不同作用

以下处理的是已经有材料支持的候选受到反驳；不要把“可能存在另一种读法/补充内容”作为候选来源时的核实，与用替代读法否认既有差距混在一起。候选来源按上文核材料支持、局部职责和具体作用差别；对既有候选再分别核验：

- 如果反向材料直接推翻了候选的事实前提、方法适用条件或关键推理，即使它没证明整个对象很充分，也必须撤回或收窄被推翻的命题。
- 如果争点是其他组成或合法路径能否代替所指缺失功能，才检查该路径在实际条件下是否充分承担同一作用。若它确实足够，撤回/缩小对应候选；若只是“可能有用”或仅完成相邻作用，不足以免责。
- 一项反证只改变它直接覆盖的判断；继续检查仍在授权内且尚未看的其他作用与组合，不把反证门槛抬高到证明整个对象优秀。

## 用推理标准检查自己的判断

Richard Paul 与 Linda Elder 1997年《The Elements of Reasoning and the Intellectual Standards》中列出七项智识标准：清晰、准确、精确、相关、深入、广度与逻辑。将它们用于检查本次问题判断本身：

- **清晰、准确、精确**：问题句是否易懂、忠于材料，并把对象、条件和实际差别说到可复核，而不是只写“不清楚”“不专业”。
- **相关、深入、广度**：所列材料是否服务当前用途；是否进入决定判断的关系和条件；是否遗漏会改变结论的其他重要方向。
- **逻辑**：观察、适用理由和结论是否接得上；有没有把全局需要偷换成局部职责、把可能影响写成已发生结果。
- **公平核对其他立场**：考虑确实可能改变结论的作者已确认设计、合法例外、替代路径和相反材料；公平不是一见合理解释就停止，也不是给每项批评配一段替作品辩护。

这些标准用于校准审查者的推理清晰度和公允性，不替代对象领域的专业判据，也不要求逐项对外输出或为每个问题点名理论。

### 检查指标是否真的代表目标作用

当对象用数字、代理指标或验收项代表整体作用时，先确认指标观察的对象、条件，以及它与本轮目标的关系。指标可测不等于能代表整体质量；多个局部指标分别达标也不证明组合结果达成。若指标改善而完整产物仍未实现目标，分别记录指标结果与整体差距，并核对二者关系，不将整体失败平均成通过。没有适用量尺时，用可复核的材料比较和专业理由，不造精确分数。

## 区分作品表达目标、专业选择与审查者偏好

作品或创作规则的审查涉及表达目标时，按主文基准辨认：用户最初提出的目标或选择、用户后来确认的变更、负责作者在开放范围内作出的专业表达选择、实施者对规则的转写，以及最终成品的实际表现。对全仓意图审查、规则迁移或明确要求检查源头保真时，回核可取得的原请求、后续确认、源材料和实际选定的方法；日常审查只核与当前候选有关的选择。现行规则本身不能单独证明其忠实于用户锁定的目标，或已落实负责作者选定的方法。

检查“限定词、默认、例外、优先级”如何改变真实动作和成品，不按词面定罪。只有它们使已确认的动作变任选、挪走优先级、截断保护或让产物退离目标，才可作为偏差候选。判断事实时核对事实依据；事实错误只影响该断言及直接依赖内容，不自动否定仍成立的立场、视角或声音。若无法判断强度或方向是否已确认、且答案会改变问题成立，指出具体不确定处后回主文询问最小决定。

受众真实反应、点击、情绪、理解或行为须有相称的真实观察/测量。没有这些记录时，可用材料和专业方法判断功能关系或接收风险，但不能把可能反应说成已发生；作者的解释也不能替代最终成品实际传达的内容。

## 综合候选并交回主文

同一不足的多个观察可合并，独立作用差距应分别保留。是否合并依据事实关系：前一项是否是后一项成立条件、一个处理是否削弱/放大/抵消另一项、或两项是否独立影响目标。都影响“理解”不自动构成同一问题；反例不支持的因果联系不写。

候选进入核实时，交付可定位材料、对象职责依据、适用方法及条件、方法在实际材料上的检查动作和观察、可能改变结论的反证，以及当前未知。不要只交抽象问题名称或压缩后的结论。最终按主文“核实候选并确认差距”确认，再按“组织问题包”写给用户；Reference 不产生第二套输出格式，也不要求用户看到内部16方向清单。

如果要追查当前对象边界外的问题复发原因、责任或动机，或要比较/执行修复方案，回主文检查授权与交接条件。对象本身就是流程或运行规则时，仍须诊断其内部实际处理如何产生用途差距，不把对象内机制检查误当越界根因追查。
