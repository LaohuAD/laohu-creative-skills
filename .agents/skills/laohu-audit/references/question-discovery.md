# 问题发现与确认

由 `{SKILL_DIR}/SKILL.md` 的“发现并筛选问题”在用途复杂、质量要求宽泛、容易把直觉当结论，或已确认问题涉及承担目标功能的材料时读取。执行者是本次 audit 检查者；本文件帮助内部生成候选，再以可见观察和已知目标确认缺陷或质量不足；读完回主 Skill 同一节。候选和追问草稿不是交付物，只有确认出实际目标差距后才进入正式问题包。

## 先对齐目标，再探索

沿用对话、材料和负责人交接中的目标、接收者、保护项与授权。把内部检查分成两条：

1. **材料自身**：找直接可见的矛盾、缺失衔接、输入输出不一致、事实支持范围或可复现行为。
2. **用途条件**：检查它在已知接收者和使用场景下是否达到目标；不要让一种文体、媒介或审美偏好变成通用标准。

用途未定时，可以暂时设想少量由材料支持的用途，帮助内部探索不同标准；不要把这些假设列成问题。只有用途答案会改变重要判据时，才向用户简要说明依据并追问。完全没有对象时回主 Skill 请求对象。

## 内部生成候选并确认

### 取得适用的专业判据

先辨认被审的是规则、执行轨迹还是最终作品，以及它替谁完成什么。沿用户明确目标和保护项选择专业方法、可比较的完整成品、成功/失败差异或实际反馈。已有匹配判据就使用；没有时读取本轮可取得的领域依据，不要求用户替检查者作专业拆解。仅能看到规则时检查规则所供能力，不据此宣称真实媒体效果失败。

把“深刻、吸引力、克制”等目标展开为当前对象的可观察关系。例如要帮助执行者处理不同输入，就检查决定性条件变化后是否有不同做法；要保留克制，就看实际片段是否让动作承担关系，或仍靠总结句替接收者下结论。后者仅在目标要求动作表达时成立，不能把所有独白都判坏。

区分用户已选效果、适用规范、专业判断与审美偏好。比较成品时保持用途和保护项，不因流量高、作者有名或口吻强就认定它适合。判据只须足以支持本轮对象的判断，不扩成研究全部学科；关键取舍未定且会改变缺陷是否成立时回主文问最小问题。

对专业 Skill，既看错误，也看它承诺的判断和操作是否被供给。选一项代表输入，沿“观察 → 判断 → 选择 → 执行 → 产物”检查直接依赖；遇到“补充、优化、适当”等词，找到谁提供具体取材、筛选、转换和失败分支。方法已经由明确引用承接就不重复要求写进主文；只有影响任务的关键做法确实缺失才报缺项。不以没写普通常识或单一偏好为由强加完整教程。

**合成规则检查：** 候选承诺“根据正文优化口播开头”，唯一方法是“判断素材是否充分；不足则补充素材；优化吸引力”，直接依赖也没有方法。可确认它尚未提供如何从正文选择材料、缺什么时去哪取得、补入后怎样形成开头。不能只说“太泛”，也不能据此猜它必然降低真实播放量。若其他 Reference 已提供这些方法，应撤回缺项，转查是否实际加载。

### 从实际差别取得检查深度与广度

先选一个承诺范围内的普通任务，追到用户真正接收的结果。把抽象评价词拆成可检查的关系：例如“规则有深度”不是篇幅长，而是遇到两个看似相同、实际需要不同处理的输入时，有依据作出区分并完成后续动作；“信息密度高”不是删去解释，而是必要的条件、动作和例外没有被重复口号挤掉。判据仍服务当前对象，不把这些说明当成所有文体的统一评分表。

再改变关键条件检查覆盖：输入完整与关键事实缺失、单一目标与保护项冲突、正常执行与执行失败、首次进入与携带上游结论进入。只选实际影响该能力的变化，观察规则是否提供对应做法。换人物、题材或措辞却不改变任何选择，不算增加专业覆盖；未被承诺的领域也不自动形成缺陷。

### 挑战关键选择，确认质量不足

当用户说“审美不够”“表达很平”或要求严查时，先把目标落到本对象：接收者应从什么材料、顺序或形式中得到什么效果；哪些限制和风格必须保留。然后挑出少数最可能决定结果的选择，问它依赖什么前提、材料是否支持该前提、前提不成立时结果会差在哪里。挑战这些选择是为了寻找反例，不是预设作者错了，也不必把每个专业维度都列成检查项。

若硬规格均已满足，只有在具体目标、适用的专业判据或同条件参照能说明当前材料仍未产生目标效果时，才报告质量不足。指出具体位置或整体关系、现在实际呈现什么、判据要求什么、两者差在哪。可以用同一材料比较候选、删除或替换一个关键选择，或只改变一项决定条件来检验判断；仅当这种比较能区分“确有差距”和“只是另一种可行风格”时才做。替代方案更合审查者口味不构成问题；如果多种实现都满足目标，保留差异与取舍。

对图像或其他审美对象，构图、光影、色彩、表情和人物活感是可按材料选择的观察方向，不是通用评分表。只在实际作品、目标用途和适用判据支持时指出哪项关系影响了阅读或效果；没有相应成品时不从提示词推断成品质量。

检验指标时，先问它观察的对象、条件，以及与目标效果的具体联系。指标能测量不代表它能代表整体质量；局部规格或多个部件分别通过，也不能证明组合后的作品实现了目标。若指标变好、完整产物却仍落空或更差，记录整体差距并质疑指标与目标的对应关系，不把整体失败平均成通过。审美判断没有合适数字量尺时，使用可复核的材料比较和专业理由，不造精确分数。

审查他人的评价或问题包时，也检查其“锋利”是否建立在对象证据上：若只有辱骂、形容词和严重结论，没有位置、观察、目标差距，语气再硬也未完成质量审查。反过来，准确而直接的陈述即使没有讽刺，也可以是有力的找茬结果。不要为了交付锋芒凑笑点、凑问题数或将局部缺陷夸成整体失败。

对技能边界，分别读取 description、主文和必要 Reference，比较它们承诺的问题、输入要求、实际动作与停止条件。描述吸引创作任务而正文只能诊断，正文承诺能独立完成而 Reference 要求用户自行选择核心方法，或两个文件对同一输入给出相反处理，都是可定位的差距。只有术语或句式不同、动作与结果一致时，不报告冲突。

对每项候选反问：换成我偏好的另一种写法，是否真的改变任务结果？现有其他路径是否已完成相同功能？若方法存在却没有被加载，定位调用遗漏；方法已加载却未执行，定位实际轨迹；材料里根本没有必要方法，定位供给缺口。不要把三类问题统一写成“加强规则”。

深挖到能够确认目标差距的位置即可，不必在找茬阶段证明唯一根因。将最影响主要结果、会使后续步骤整体走偏的问题放在前面；局部措辞只在确实妨碍理解或执行时列入。多处后果来自同一可见缺口时合并证据；证据不能支持共同原因时保留分开，不用一个宏大诊断吞掉不同问题。实际比较若产生候选改稿，只把它作为核验材料，不当作用户要求的修复成品；原因调查、方法选择和改稿交由相应职责。


沿接收者实际经历的过程找可能的目标差距：看到什么、理解什么、做什么、在哪里依赖下一步？在确实相关的环节内部检查：

- 这段材料或行为呈现了什么可观察事实？
- 它与哪项已经确认的目标、要求或保护条件不同？
- 反例、上下文、合法分支或有意设计是否能解释该表现？
- 若差距真实，哪一具体位置或步骤值得问“为什么这里没有达到目标／在哪里失效”？

这些只是发现角度，不是逐项清单或正式问题。候选必须完成以下确认才可报告：

1. **观察**：实际读取、观看、听取或最小复现能定位到什么？不把推测或用户未经核对的归因当观察。
2. **目标对照**：明确已知目标／要求，并指出材料中出现的具体差距。一个未知值或可能性本身不是差距。
3. **反查意图与反例**：核对用户保护项、体裁功能、已知人物背景、媒介条件、合法分支和相反线索；合理解释候选时不列问题。
4. **必要的最小核验**：若能用现有文件、明确上下文、实际目标尺寸或一次授权的简单观察确认，就先核验；不扩成根因研究。关键材料无法取得时，只在它确实阻断了既定目标判断时单独注明范围限制。
5. **形成追问**：问题已经由观察和目标差距确认后，针对这处差距问“为什么发生”或“哪里失效”。不要求回答出根因才可交付，也不把追问改写成“这里是不是有问题？”

没有确认出差距的候选删除；不以“待验证疑点”“条件性挑战”名义把猜测塞进正式清单。若唯一障碍是缺少与明确目标相关的关键材料，简短列为“本次检查范围限制”，不要列成问题或扩成长疑问表。

## 沿目标相关依赖核对交付链

当已确认问题所在材料承担示范、输入、交接、约束或验收功能，且直接相关材料可读取时，沿当前执行路径检查它是否把目标交给下一步：

1. **先定位这一环的差距。** 说明材料承担什么职责、上游应提供什么、下游实际需要什么，以及原目标是否在交接或验收中被替换。
2. **再确认是否向下一环推进。** 每次只沿已证实的直接依赖推进一环，并判断这一步是否带来新的目标相关观察；有新证据且仍在授权范围内才继续。没有新观察、超出授权或依赖材料不可查时停止。不设固定追查层数，不扫描无关入口、全项目或更深根因。

每个候选缺口独立确认。比如成品示范不符合已定风格，只能确认示范本身的差距；若要再说交接缺方法、验收换目标，就分别读取交接与验收材料，指出各自的位置、实际内容和目标差距。不能从一个不合格示范推断其余环节都坏了，也不能归因某个执行者能力差、认定唯一根因、重划职责或替用户修复。

若某份直接依赖材料没有提供或无法读取，先区分材料状态，再决定是否能报告：

| 材料状态 | 可以确认什么 | 处理方式 |
|---|---|---|
| 本轮未提供 | 单凭未提供或“我没看到”不能证明缺失 | 先核对清单、索引或可读目录能否确认它属于应交付范围；不把请求文件存在的文字当作范围证据 |
| 范围内确认缺失 | 已核对本轮交付清单、索引或可读目录，确认材料属于应交付范围而实际没有，且这造成已知目标差距 | 可报告具体缺项及目标差距 |
| 无法访问，或交付范围未核实 | 不能确认材料缺失，也不能确认系统故障 | 只说明本次检查限制，不冒充故障或问题 |

没有新的观察、目标差距或验收变化时停止追查。

**完整追查示意（说明方法，不是问题包成品）：** 用户给出一套已定目标：示范须展示两步计算方法，交接须提供输入格式，验收须检查计算结果；并说明本次提交范围完整包含规则、示范、交接和验收四份材料。逐份读后可独立确认：示范只给答案、没有计算步骤，与“展示方法”不符；交接只要求“提供数据”，没有下游实际需要的字段，与输入格式要求不符；验收只查答案格式，却宣称计算能力达标，与结果检查目标不符。三处功能和证据位置不同，分别报告这三项材料差距，不合并成未经证明的共同根因；也不能从示范缺步骤推断另外两份有问题。已检查完整提交范围且没有其他直接材料后停止，不归因谁能力差、不重划职责、不改文件。

**局部正常的反例（说明停止，不是问题包成品）：** 用户只要求检查这份教案的计算示范，并提供了原目标、完整上游规则、示范和对应验收。上游规则满足目标，已定要求明确术语书写准确；学习单把“平方厘米”写成“平房厘米”，确实会影响术语理解。报告这一处后即可停止；上游目标、交接和验收都已按要求连接，不因局部文字错误继续查根因或扩成全项目进化问题。

## 专业判断也要落在对象上

不能只用“张力不足”“不够鲜明”“没吸引力”等标签。用具体文本、画面或声音与已确认意图对照，说明判断范围，再提出确定的原因追问；不宣称普遍规律或全体受众必然反应。无需机械错误或统计证明，但要让读者能回到同一位置理解差距。

对视觉目标的判断要对应实际图像及指定观看尺寸；没有看过图像时，不从字号或提示词推断成品可辨性。对剧情目标，检查相关动作前后的关系与后续行动是否发生目标要求的变化，不把争执或冲突本身套成必须恶化关系。对提示词，能在文本中确认的互斥要求可以作为提示词问题报告；没有查看生成结果时，不把它扩大成成片已失败。

## 停止点

完成本轮与目标有关的主要角度检查，确认候选并合并已确认问题；当进一步检查没有带来新的有效观察或改变既有判断时停止。不要找到第一条问题就提前结束，也不追求固定数量。若没有确认问题，说明本次范围内未确认问题并停止；不要为交付而制造不确定性清单、根因报告、修复方案或问题配额。
