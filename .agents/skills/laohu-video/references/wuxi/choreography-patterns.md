# 编舞模式——节拍模式及将其转写为提示词语言

## 将编舞转写为视频提示词的规则

AI 视频模型默认会生成“电影功夫”：大幅蓄势、高踢腿、没完没了的连招。若要得到 JKD，提示词必须主动压过这些默认倾向：

1. **明确肢体和目标。**不要只写“他出拳”→写成“他的前手右拳骤然击中下颌”。每一击都要写明是哪一肢体、沿什么轨迹、击向什么目标。武术术语（bai-jong、pak sao、side kick 之类的名称）不要写进提示词正文——只写几何动作（见 `moves-catalog.md` 中的片段）。
2. **用正向锁定去掉蓄势**（单独写“不要蓄势”这类禁令本身会唤起蓄势）：`手臂第一个可见的动作就是已经向前运行的击打，从双手在护势位休息的位置发动`。用锁定语句 `每次踢腿都保持在腰带高度以下` 去掉高踢腿。
3. **第一帧就交代站姿。**在交手开始前，于第一帧写明全身几何姿态（片段 S1）；后续画面用相同措辞重提“狭窄的侧身站姿”。
4. **反应物理。**每次击中都要描写对手身体的反应（见 `techniques.md` 中的表格）。没有这一项，模型会“漏掉”接触。
5. **节拍时长。**1 个节拍约等于 1–2 秒的银幕时间。8 秒的镜头最多 4–6 个节拍，其中包括 1–2 个站定／停顿节拍。不要硬塞 10 次击打。
6. **停顿也是打斗的一部分。**破节奏需要写出停顿定格：`他退回站姿，静止不动`——这就是这种风格。
7. **摄影机偏向侧面。**侧身站姿和直线出拳在侧面或四分之三视角中最易读；低踢需要能看见腿的画面（不能用胸部以上的近景）。
8. **一段交手 = 一个镜头。**多镜头段落在破节奏停顿处剪开——那是自然的剪辑点。

## JKD 打斗的戏剧弧线

这种风格的经典形式（以及李小龙在银幕上的呈现）是：**静止 → 挑衅／对手攻击 → 截击 → 爆发（1–3 个动作）→ 静止。**
英雄在动作爆发前后几乎一动不动。暴力是在两次停顿之间短暂闪现的一瞬。这使 JKD 场景有别于“绞肉机”。

## 可直接使用的节拍模式

### P1. 截击单次攻击（SDA 反击）——4–6 秒
1. 英雄摆出 bai-jong 姿势，一动不动。对手正面对着他，气势汹汹。
2. 对手发动横扫式大摆拳（有预兆）。
3. 截击：前手直拳在对手蓄势的**同一刻**击向下颌，同时跨步切入。对手的拳打到一半便停了。
4. 对手踉跄／倒下。英雄回到站姿，静止不动。

### P2. 踢转拳切入（远距 → 中距）——6–8 秒
1. 站定，在弧线上移动。
2. 对手踏步上前 → 用低位侧踢截击其膝盖。
3. 对手膝盖一软；身体向前扑。
4. 迎着下落动作接上——前手直拳或前手勾拳击向下颌。
5. 对手从英雄身旁跌过。英雄——静止不动。

### P3. 黏手连击（中距 → 近距）——6–8 秒
1. 对手打出直拳——英雄用拍手（pak sao，手部拨挡）并同时打出前手直拳。一个节拍，一个动作。
2. 对手摇晃，试图打出第二击 → 拉手（lop sao）：拉住手腕，同时迎面打出反手拳。
3. 对手被猛拉得向前、向下，越过英雄摔倒。英雄松开对方的手，静止不动。

### P4. 直线连击收尾（施压）——4–6 秒
1. 被截击／打懵的对手失去身体结构。
2. 直线连击（straight blast）：连续打出垂直拳；英雄向前推进，对手不断后退。
3. 收尾——侧踢身体，把对手踢向障碍物（板条箱、门、墙）。

### P5. 两名对手（2 对 1）——8–12 秒，2 个镜头
原则：不要同时和两个人交手。空间位置：移动到让两名对手排成一线（一个挡住另一个）。
1. 镜头 1：绕行 → 较近的对手进攻 → 采用 P1（截击）或 P2（踢膝）的模式；对手 #1 倒下，挡住 #2。
2. 镜头 2：#2 跨过／绕过倒下的对手 → 英雄用截踢迎击，或采用 P3。
给每名对手安排不同的模式；不要重复。

### P6. 对抗持刀者——6–10 秒
1. 刀进入画面——英雄立即拉开距离，双手抬起形成狭窄框架，身体转侧。
2. 刀刺来 → 斜向移出攻击线 + 朝持刀一侧膝盖踢出低位侧踢。
3. 双手抓住持刀手腕（lop sao），用肘击压向前臂——刀掉落。
4. 前手直拳／侧踢——拉开距离。静止不动。

## 反模式（编舞者内部检查——不要把它们转成提示词里的禁令！）

清单上的所有内容，都要通过提示词中的**正向措辞**排除（低踢腿 → “每次踢腿都保持在腰带高度以下”；以截击而非格挡迎敌 → 片段 T5/T6；斜向退出 → 片段 F5）。不要把“不要高踢”“不要旋转”或“不要格挡”写进提示词正文——说出被禁止的动作会把它唤出来。

- 踢头、旋转攻击、跳踢——这些都不是 JKD（除非用户明确要求）。
- “格挡—出拳—格挡—出拳”交手——JKD 是截击而不是格挡。
- 连续超过 4 个动作而中间没有停顿的组合。
- 正面朝前的拳击站姿、耸肩晃动。
- 英雄沿直线向后退——JKD 会斜向退出／用钟摆步退出。
- 蓄势、从腰部“蓄满力量”再打出的拳、空手道架势（kamae）。

## 编舞输出模板（打包成提示词之前）

```
场景：[人物／地点／时长／谁获胜]
模式：[P1–P6 或自定义]
节拍 1（0.0–1.5 秒）：[位置／站姿]
节拍 2（1.5–3.0 秒）：[对手的攻击 → 英雄的截击：肢体、技法、目标]
节拍 3（3.0–4.5 秒）：[身体反应 → 动作进展]
节拍 4（4.5–6.0 秒）：[收尾 + 静止]
摄影机说明：[侧面／四分之三视角，哪些部分必须留在画面中——踢腿时要看见腿]
```
然后按当前提示词引擎的格式打包；如果当前没有启用引擎，就写成清晰的英文散文提示词，并按节拍组织。
