# JKD 核心——原则、站姿、步法与距离

这是这种风格的核心。写在这里的每一项内容都必须能在**银幕上读出来**——每条原则都有一个视觉标志。

## 哲学 → 银幕上的可见表现

| 原则 | 核心含义 | 画面中的视觉标志 |
|---|---|---|
| **截击（Interception）** | 不要格挡后等待——要在对手发起攻击的**同一刻**出击。截拳道（Jeet Kune Do）=“截击之拳的道路” | 对手刚开始出拳 → 英雄已先击中；对手的拳打到一半便停了 |
| **动作经济（Economy of motion）** | 走最短的路线，不做多余动作 | 没有大幅横扫的弧线；走直线、短路径，用 2–4 个动作取胜 |
| **不显预兆（Non-telegraphed）** | 出击前不蓄势，肩、髋、面部都不泄露信号 | 拳头从护势位直接出发，不往回拉；击中前表情不变 |
| **最长武器 → 最近目标（Longest weapon → nearest target）** | 用最长的武器攻击最近的目标 | 前手打脸，前脚踢膝／胫骨——不要让后手绕过半个身体才打到目标 |
| **攻防同时（lin sil die dar）** | 防守和出击是同一个动作 | 一只手把攻击拨开，另一只手同时命中；不是“先格挡，**再**出拳” |
| **破节奏（Broken rhythm）** | 节奏不均，在半拍上出击 | 速度爆发 → 完全静止 → 再次爆发；对手在停顿时打空 |
| **像水一样（Be like water）** | 适应、不拘于固定形式 | 英雄不会重复同一套组合；而是在不同距离间流动 |

## 站姿——摆桩（Bai-Jong，警戒姿势）

这是这种风格**最容易辨认的**标志。在提示词中明确描述：

- **强侧朝前**（李小龙的强侧是右手和右脚朝前）。这能让它有别于拳击。
- 身体相对对手侧身／半侧身（轮廓狭窄），**不要**正面朝前。
- 双脚间距略宽于肩宽，后膝蓄有弹性，后脚跟抬起——像“击剑手”的姿势。
- 重心轻落在前脚掌上，身体微微有弹性。
- 前手在肩部高度略微伸出，后手靠近下巴／胸口。
- 下巴收起，目光越过前侧肩膀注视对手。

提示词短语：`狭窄的侧身右前手站姿，后脚跟抬起，前手略微伸出，重心在前脚掌上轻轻弹动`

## 步法

- **推滑步（Push shuffle）**——向前／向后的短促推进步；双脚不交叉，并保持站姿。这是切入攻击的基础。
- **钟摆步（Pendulum step）**——像钟摆一样：前脚收回到后脚的位置，并立即弹回；用来躲避低踢并立即反击。
- **绕行（Circling）**——用小幅滑步沿弧线移动，远离对手的强手一侧。
- **爆发步（快速前进，Burst）**——在一个节拍内爆发性地切入 1–1.5 米，通常同时打出前手直拳。
- **弧线／侧步（Curving/sidestep）**——离开攻击线的同时出击。

在银幕上，步法轻快、有弹性，像“击剑”——不是脚掌拖地地挪动。

## 四种距离

1. **踢击距离**——远距：低踢膝／胫骨（jeet tek）、斜踢、侧踢身体。
2. **出拳距离**——中距：前手直拳、插眼指刺、前手勾拳、反手拳。
3. **黏手距离**——近距：拍手（pak sao）／拉手（lop sao），控制对手双臂 + 沿开放线路头槌、肘击。
4. **缠斗距离**——抱缠／地面：JKD 的目标是**不要**在这里停留；摔倒／扫倒对手然后退出。

经典场景推进：从踢击距离切入 → 出拳距离 → 黏手距离，在 2–3 个节拍内结束。

## 五种攻击方式

1. **SDA（Simple Direct Attack，简单直接攻击）**——不做准备，直接打一记：突然打出前手直拳。
2. **ABC（Attack By Combination，组合攻击）**——简短的 2–3 拳组合：刺拳 → 后手直拳 → 低位勾拳。
3. **PIA（Progressive Indirect Attack，递进式间接攻击）**——在一条线上佯攻，在另一条线上出击：假装攻击脸部 → 击打身体。
4. **HIA/ABD（Attack By Drawing，引诱攻击）**——诱饵：露出一个空当，对手进攻 → 截击（截击拳）。
5. **HIA（Hand Immobilization Attack，手部制敌攻击）**——黏手：压住／移开对手的手，从空出的线路出击。

就场景戏剧性而言，高手英雄最常通过 ABD 获胜（截击被诱发的攻击）——这是最“聪明”、最有电影感的做法。

## 场景原型

- **JKD 高手**：表情平静，动作极少，爆发之间几乎一动不动，通过截击取胜。根据第 5 本书：表现得“像在普通日常生活中一样”——不瞪大眼睛，毫无怒意；目光呈“弥散式”的周边视野，而不是死盯对手的手。后脚跟像“上膛的扳机”。
- **学生**：使用同样的招式库，但节奏更均匀，ABC 组合更多，截击拳更少。
- **对手（非 JKD）**：横扫式大摆拳、正面站姿、动作有预兆——反差能凸显英雄的风格。第 1 本书（sources/03）列出约 15 种“不正确”的站姿，是给对手直接套用的姿势。
- **早期风格／传统派**（sources/08）：重心 70/30 落在后腿，以胸口中央打出立拳，有咏春结构——用于“年轻格斗者”的场景，或用于表现不同流派之间的对比。

## 假动作与时机（依据 sources/05、sources/07）

- 连续假动作不超过两个；第一个假动作会“吃掉”一半距离。
- “佯攻 → 出击”配对：低位佯攻 → 刺向眼睛；假装攻击脸部 → 击打身体。假动作必须让对手**看得见地**作出反应（手抽动着抬起防守）——这本身就是一个单独的微节拍。
- 愤怒和恐惧会让格斗者变慢——愤怒的对手会变得更容易预判。

## 摄影机（李小龙本人的电影摄影原则，第 5 本书）

拍决定性的一轮交手时，使用远距离、固定的长镜头，而不是蒙太奇式剪切：必须完整看清技法的速度和精准度，不能靠剪辑来“救场”。李小龙的三至四阶段照片序列（sources/07）是可直接套用的单项技法分镜模板。
