# 打斗风格：咏春

主题深度：站姿／基本手法／小念头 → [sources/13](../sources/13-wc1-perviy-uroven.md)；寻桥、转身、踢法、黐手、20 种反击、目标地图 → [sources/14](../sources/14-wc2-vtoroy-uroven.md)；木人桩（116 个动作中的 12 种套路、训练声音与节奏）→ [sources/15](../sources/15-wc-dummy-116.md)；标指、肘法、发力、28 种反击、10 套现成连招 → [sources/16](../sources/16-wc-vysshiy-uroven.md)。

咏春是 JKD 以外的独立打斗风格。用户写出“Wing Chun”“wing chun”“like Ip Man”“Ip Man's style”或“Wing Chun stance”时启用。默认风格是 JKD；两种风格可以在同一场景中并存（咏春高手对阵 JKD 格斗者——“流派对决”）。

## 咏春与 JKD 在银幕上的差异（对提示词至关重要）

| | JKD | 咏春 |
|---|---|---|
| 站姿 | 侧身，强侧朝前 | 正面朝前、站得窄、膝盖内扣 |
| 距离 | 切入后退出，共 4 种距离 | 紧贴不放 |
| 节奏 | 破节奏，爆发—静止 | 连续施压，像“缝纫机” |
| 击打 | 甩击与跨步活塞式出拳 | 从胸口发出的短促活塞式击打，手肘收紧 |
| 腿法 | 用脚外刃侧踢 | 用脚跟／整个脚掌直线向前踩踢 |
| 取胜方式 | 2–4 个节拍，以截击取胜 | 缠住对手的手 → 连续出击直至对手倒下 |

## 片段（适配 Seedance：几何动作、零术语、零禁令）

**WC-S1. 站姿（Yee Ji Kim Yeung Ma）**——咏春站姿、叶问站姿
`他正面直对对手站立，双脚间距很窄——只比髋部略宽——脚尖略微内扣，双膝相向压拢，骨盆压低、重心下沉。双手轻轻悬置，沿胸口正中的垂直线一上一下叠放：一只手臂伸出一半，指尖朝前，另一只手臂在后面弯折，停在胸骨处。手肘沉重地垂着，靠近肋部。他的脸静止不动，下巴平齐。`

**WC-S2. 问手／护手（Man Sao / Wu Sao，工作框架）**——试探性的前手
`他的前手臂沿中线轻轻悬置，伸出一半，指尖像天线一样探寻；后手掌张开，停在胸骨旁等待——两层栅栏守住一条垂直线。`

**WC-F1. 转步（Juen Ma）**——原地转动
`他的双脚保持踩地，整个身体以脚跟为轴转过四分之一圈，正面的框架像门绕铰链摆动——拳头从离他胸口一掌宽的地方滑过。`

**WC-F2. 压进步**——向前迈步
`他用短促平直的小步向前滑行，后脚推进，前脚掠地——每一步只有半个鞋长——直接走进对手的距离里，不让空隙出现。`

**WC-H1. 连环拳**——连环拳、“缝纫机”（= H7，咏春演绎）
`他的双拳轮流从胸口中央像活塞一样沿同一条直轨击出——指节竖直，手肘擦过自己的肋部；每只拳头都在另一只拳头出击时回到胸骨处，每秒三至四击——同时双脚以平直的小步不断吃进空间。对手的头和胸口在鼓点般的连续击打下向后震动，直到后背猛撞上墙。`

**WC-K1. 直线踩踢**——前踩踢
`他的膝盖沿中线抬起，脚掌平平地直线踩进对手大腿，力量一路推进，像用脚掌关上一只沉重的抽屉。那人的髋部猛然向后，躯干从腰部折起。`

**WC-T9. 摊手（Tan Sao，摊开掌）**——摊手
`他的前臂转动，掌心朝上，沿中线把打来的拳头从胸前向外顶开——同时后手在同一节拍里穿过同一个窗口击出。`

**WC-T10. 膀手（Bong Sao，翼）**——膀手
`受到击打压力时，他的手臂折起成高举的翅膀——手肘抬得高于手腕，前臂斜向下——击打像水从屋顶滑落般滚过手臂；他的身体随之转动，空出的手沿中线还击。`

**WC-T11. 伏手（Fook Sao，覆手）**——伏手
`他的手搭在对手前臂上方，手腕勾住前臂，手肘沉下——通过接触感知每一丝抽动，从上方控制整条线路。`

**WC-H2. 掌根击（Wun Jui）**——掌击
`他的掌根从胸骨处沿直线撞向下颌，手指朝上，整条手臂像活塞一样动作；对手的头向后一震，仿佛撞上了门框。`

**WC-H3. 标指（Biu Jee，发力刺指）**——指刺
`他的手臂柔软如布般伸出——就在最后一指宽的距离里，手臂突然绷紧，像鞭子抽响，指尖直刺喉咙。那人捂住喉咙，窒息般向后倒。`

**WC-E1. 肘法（Kup Jan / Gwoi Jan）**——下劈／横向肘击
`胸贴胸的距离里，他折起手臂，肘部沿着锁骨线斜向劈下——这是从身体框架本身发出的一记短促重劈，身后没有摆动蓄力，整个身体随击打下沉。`

**WC-G1. 合力（拉拽 + 迎击）**——将对手拉入击打
`他的左手扣住对手手腕，将它猛烈地拉向自己，同时右掌根向前猛击——那人的踉跄也给击打增加力量，两股速度在他的下巴处相撞。`

**WC-D1. 训练场景：木人桩**——木人桩（细节见 [sources/15](../sources/15-wc-dummy-116.md)）
`他围着木人桩的三根手臂，以快速而稳定的脉冲节奏练击——前臂碰撞木头，手掌拍击，低踢重重踢中弯曲的桩腿——拍、笃、轰；粗重的木桩在框架中震颤，节奏像鼓手切换套路一样断开又重启。`

黏手 T1–T8、黐手 T7 和稳固的 S2 框架都是与 JKD 招式目录共用的（咏春是它们的来源），从正面朝前的 WC-S1 站姿执行。咏春目标地图：喉咙、眼睛、太阳神经丛、腹股沟、膝盖——都在中线上。

## 咏春打斗的戏剧构成

经典形式（也是叶问的电影化规则）：对手绕行并蓄势——高手正面站立、几乎不动，双手摆成框架 → 前臂接触 → 2–3 个节拍的黏手结构重组（摊／膀／伏手、拍／拉手）→ 打开一条通道 → 连环拳连续出击，直到对手倒下 → 高手放下双手，恢复原本的框架并站定。胜利看起来像“穿过绞肉机”：对手在鼓点般的连续击打下不断后退，高手则用小步跟进。

## 咏春风格检查清单

- 第一帧采用狭窄、正面朝前的站姿（WC-S1）——后续重提“他的狭窄正面框架”
- 黏着接触：至少有一个节拍前臂互相接触，并能看清接触中的结构重组
- 连环拳（WC-H1）作为主要终结方式；连击伴随压进步 WC-F2
- 只用腰带以下的直线踩踢（WC-K1）
- 手肘**始终**靠近肋部——重提“手肘沉重地垂着，靠近肋部”
- 咏春版 FIGHT STYLE LOCK：`每次踢腿都保持在腰带高度以下；每次出拳都是从胸口中央打出的短促直线活塞拳，手肘靠近肋部；他保持正面、窄幅站姿，用平直的小步向前走；这场打斗只有一条垂直线和无情的向前施压。`
