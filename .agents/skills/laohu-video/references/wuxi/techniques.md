# JKD 技法——具有视觉标志的招式库

每项技法依次说明：力学原理 → 银幕上的表现 → 提示词短语草稿（英文）。
**重要：**本文件中的提示词短语是帮助理解动作力学的工作用标志。**最终提示词**使用 `moves-catalog.md` 中适配 Seedance 的片段：纯粹描述身体几何动作、零武术术语、零禁令，以及动作后果的物理表现。本文件解释“动作如何运作”；目录解释“该如何写”。

## 手部

### 前手直拳（Straight Lead，前手直拳）——本风格排名第一的击打
- 力学原理：前手拳不往回拉，从护势位沿中线直线出击；髋部和跨步增加力量；拳头竖直；用下方三根指节接触；手立即收回。
- 银幕上的表现：一道闪电般的“弹击”，没有蓄势；躯干几乎不打开。
- 提示词：`他的前手右拳沿中线直直击向下颌，拳头竖直，完全不蓄势，随即立即收回`

### 插眼指刺（Finger Jab，Bil Jee）
- 力学原理：和前手直拳相似，但手指指向眼睛／喉咙；距离更长、速度更快；用于截击。
- 银幕上的表现：“长矛”般的手；对手后仰，捂住脸。
- 提示词：`一道刺眼的指刺闪向攻击者的眼睛；他受惊后仰，护势被打乱`

### 前手勾拳（Lead Hook）
- 力学原理：前手直拳之后接一记短勾拳，手肘不高于拳头；通常打向下颌或肝脏。
- 提示词：`一记紧凑的前手勾拳猛甩着击向下颌，手肘下沉，躯干几乎不转动`

### 反手拳（Backfist，Gua Choy，以拳背甩出的击打）
- 力学原理：拳背从上方、侧面甩向太阳穴／鼻梁，常接在黏手之后。
- 提示词：`他的手从被控制的手臂上方甩过，反手拳擦过太阳穴`

### 直线连击（Straight Blast，Jik Chung Choy，连续直拳）
- 力学原理：双手沿中线连续打出一系列竖直直拳，同时持续向前施压；对手来不及恢复身体结构便向后退。
- 银幕上的表现：英雄被“带着”向前推进，对手向后倒下。
- 提示词：`一连串竖直拳沿中线像活塞一样打出，同时他猛然前冲，把那人打得踉跄后退`

### 一寸拳（One-Inch Punch，仅应要求时使用——标志性示范，不是标准格斗招式）
- 提示词：`从一英寸外打出一记短距离拳击，穿透胸口爆发而出；那人双脚离地，飞进货架`

## 腿部（除非另有明确要求，否则全部攻击低位）

### 截踢／侧踢膝盖或胫骨（Jeet Tek / Side Kick to the Knee-Shin）——本风格排名第一的踢击
- 力学原理：用前腿的脚刃踢向向前移动的对手膝盖或胫骨；常用于截踢——在对手迈步的同一刻截击。
- 银幕上的表现：腿被踢开时，对手向前扑倒。
- 提示词：`攻击者踏步切入时，前腿打出低位侧踢，直刺膝盖；他的腿一软，身体向前扑倒`

### 斜踢（Oblique Kick，Jeet Tek 向下、向前踢）
- 提示词：`一道向下的斜踢刮过攻击者的胫骨，并重重踩上他的脚背`

### 勾踢（Hook Kick，O'ou Tek，踢向身体／大腿的弧线踢）
- 提示词：`一记弹甩的前腿勾踢深深击入肋部，髋部几乎不抬起——不做蓄势`

### 侧踢身体（终结技）
- 力学原理：用爆发步使出有力的侧踢，踢向太阳神经丛／肋部；主要的“发射器”。
- 提示词：`一记推进式侧踢重重撞上胸骨，把那人向后抛出三米，撞进板条箱`

## 黏手（近距离）

### 拍手（Pak Sao，拍击并压住的手法）
- 力学原理：用掌心将对手的手向下、向内压住／拨开，同时另一只手穿过打开的线路出击。
- 提示词：`他的左手掌拍下攻击者的护手——拍手（pak sao）——同时他的右拳在同一个节拍里穿过空隙猛然打出`

### 拉手（Lop Sao，抓握并拉扯的手法）
- 力学原理：抓住手腕／前臂，将对手向自己方向猛拉并向下压，再迎击被拉近的脸部。
- 提示词：`他抓住手腕，把那人向前猛拉，使其撞向一记短拳——拉手（lop sao）——拉与击合成一个动作`

### 截击拳／截踢（Stop-Hit / Stop-Kick，截击——本风格的 DNA）
- 力学原理：在对手刚开始攻击的**同一刻**打出的任何直线拳击／踢击；对手等于是自己撞上了击打。
- 提示词：`攻击者刚把拳头蓄势举起——就迎面吃下一记动作打到一半便截住他的前手直拳；他自己的拳打到一半便停了`

## 对抗武器（刀／棍）

- 第一动作绝不能伸手去抓刀。拉开距离 + 低位踢击。
- 顺序：斜向移出攻击线 → 踢向持械一侧的膝盖／胫骨实施截踢 → 双手控制持械手臂（拉手式抓腕） → 击打／折断／缴械 → 拉开距离。
- 提示词：`他斜向移出刀的攻击线，低位侧踢重重击中持刀者的前侧膝盖；双手抓住持械的手腕——拉手（lop sao）——肘部砸向被控制的前臂，刀当啷一声掉开`

## 目标地图（依据 sources/04）

JKD 优先攻击不需力量的“低成本”目标：眼睛（指刺）、腹股沟（勾踢／低位击打）、膝盖与胫骨（侧踢／斜踢）。下颌／太阳穴是终结目标。击打要“穿过”目标，而不只是“打到”目标；拳头竖直，最终位置应“在自己鼻子前面”。

## 对手反应（物理——提示词中必须写明）

| 击打 | 反应 |
|---|---|
| 击向下颌的前手直拳 | 头向后猛甩，后退一两步，身体下沉 |
| 踢向身体的侧踢 | 整个身体向后飞出 2–3 米，撞上障碍物 |
| 踢膝 | 腿一软；对手向前扑倒／跪倒 |
| 刺向眼睛的指刺 | 身体后缩，双手捂脸，失明般停顿 1–2 秒 |
| 拉手 + 击打 | 身体被猛拉得向前、向下撞上击打，并越过英雄跌倒 |
| 直线连击 | 向后踉跄，双臂散乱，仰面倒下 |
