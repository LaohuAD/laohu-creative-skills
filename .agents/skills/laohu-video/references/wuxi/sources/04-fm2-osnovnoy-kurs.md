# 04 — JKD 移动与击打基础
**对编舞的补充：**JKD 动作精准的逐阶段力学（滑步、侧步、用逐渐缩小的步幅“穿过”距离）；基本手部／腿部击打的完整集合，包括轨迹和常见的“传统式”错误做法，可用于形成对比；三段距离系统与切入／退出时机；“格挡 = 一个动作中的反击”原则；易受攻击的目标地图。每组 2–4 帧的照片序列可直接作为分镜参考：准备 → 蓄力 → 接触 → 恢复。

## 全书内容（按连续编号列出的第 VI–XI 章）

第 VI 章 移动的艺术（距离、步法）——第 VII 章 出拳的艺术——第 VIII 章 踢击的艺术——第 IX 章 格挡——第 X 章 目标——第 XI 章 对练。文字连续排在一处（第 5–45 页），后面约有 70 页按编号引用的照片图版。

## 站姿（依据照片材料）

- 李小龙的警戒姿势：强侧（右侧）手和腿朝前；双脚略宽于肩，前膝弯曲，后脚跟抬起——后腿像“上紧的弹簧”。
- 躯干朝对手转过半侧，轮廓狭窄；下巴压向前侧肩膀。
- 前臂略微弯曲，在胸部／肩部高度朝向对手中线；后手在胸／下巴处护住身体。双手“活着”，持续略微移动。
- 双手都护住身体中线——这是与拳头收在髋部、躯干敞开的传统站姿之间最关键的视觉差异。
- 一张照片展示低位、紧凑的站姿（半蹲、躯干收拢）——是近距离／防守变体。
- 照片对比中展示的站姿错误：双手太低（上部暴露）、太高（下部和躯干暴露）、分得太开（脸部暴露）、胸口过度正对对手。

## 步法（第 VI 章，逐帧动作力学）

- 基础：格斗者**绝不站着不动**——持续小幅移动，防止对手判断距离；移动的格斗者比静止者反应快。
- **向前滑步：**先由前脚迈出短促、经济的一步，后脚跟上；重心不上下弹动，头部保持同一高度。向前迈步能加快击打并隐藏意图。
- **穿过距离（“渗入”、缓步切入）：**连续小步向前，每一步都比前一步**短**——对手失去距离感，突然发现自己已经进入击打范围。
- **后退：**快速向后并脚，退到击打差几厘米才会打中自己的距离；随即准备反击。反击的最佳时机——对手打空后落下脚步时（照片：李小龙从踢击下后退，立即用右手／侧踢还击）。
- **侧步：**应对直线攻击的战术；在攻击开始、对手已无法改向后，于**最后一刻**侧移。对手右侧在前的右撇子——向左侧步；JKD 更看重向右踏步（对手会转向你，没有时间进行第二个动作），但这需要技巧。不要倾身或丢失节奏——从侧步立即反击（高位侧踢、交叉拳）。
- **绕行：**以小步绕着对手移动，用前腿作为支点；用于闪避弧线踢并切入，出左手反击。
- **跑步／“掠过”步（练习）：**双脚平行，转移重心，后退一步 + 右侧踢；左右交替，不停顿，直到动作自动化。
- 时机技巧：后腿短促踢击 + 快速后退；对手追上来——重复：绕圈移动、前后踏步，再突然爆发，双手同时出击。
- 步法差的视觉标记：大幅“颠簸”的步子、双脚交叉、上下弹跳、站姿冻结、躯干提前“透露”移动。

## 距离与时机

- 三个区域：远距（够不到——安全移动）、中距（双方都能用跨步击打触及；主要交手距离）、近距（肘、膝、黏手；谁先动手谁赢）。
- 正确的交战距离：站在对手触及范围的边缘，用一小步切入。
- 距离取决于双方的速度；经验丰富的格斗者会在距离边界持续施压，“一步步压制”对手。
- 对手准备／改变动作、踩稳脚步、把手往回拉、吸气、或心理状态“不集中”时出击。太早或太晚出击都没有力量。
- 有力击打在接触时将重心转向前方；打空后——立即回到站姿。

## 手部击打（第 VII 章）

- **前手（右手）直拳——JKD 的主要武器：**从身体**中心**（不是髋／肩）出发，沿中线直线击出，拳头竖直，省力，平衡不受影响。到目标的路线最短 → 速度最快。
- 用下方三根指节接触，手腕挺直且稳固（手腕弯曲 = 受伤）；前臂像“棍棒的握柄”，拳头像击打端。只有接触时才握拳；此前手臂保持放松。
- 手沿原轨迹返回护势位——不“吊着”手臂（照片：手臂留在外面会给对手反击的机会）。
- 出击时后手**始终**护住身体：保护脸／躯干，随时准备格挡并继续组合拳。
- 与传统技法的对比（序列 A–C，1–4）：拳头收在髋部的传统出拳会暴露整个身体前面，路线也更长；JKD 拳更快，而且全程有防护。
- 组合拳：后手直拳 → 左拳 → 右手收尾（照片 45–49）；“格挡——立即用同一只／另一只手击打”。保持“中央”方向可占优势：对手必须绕过来。
- 勾拳（“锐利弧线拳击”）：手肘不收回、不蓄势，体重送进拳中，是直拳的延续；对付弯腰的对手用上勾拳。
- 不要“打电话预告”：不蓄势、不拉回拳头、不绷紧肩膀；从中立手位出击。
- 不要用拳击打坚硬表面（头骨）——从上方攻击脸部时，张开的手掌／手指更好；可在 makiwara（空手道打击桩）上练习指节。

## 腿部击打（第 VIII 章）

- 理念：腿部攻击低位（膝盖、胫骨、腹股沟）——目标更近、更难防守，而且你与反击的距离更远。“手更快；腿更有力、也更长。”
- **基本侧踢：**从警戒姿势起，后脚朝前滑约 10 厘米，前膝抬起，躯干向后倾以平衡身体，脚刃／脚跟朝目标击出；眼睛注视目标，头部保持直立。接触后立即收腿（否则可能被抓住）。在约 40 千克的重沙袋上练习。
- 前腿侧踢——最快的踢法，是一种“截停器”，可以突破格挡并将对手踢倒；不是佯攻，用于组合进攻，也用于防守对手切入。
- 高位／中位侧踢：使用相同步法，后脚落地的一刻出击；照片序列 A–D：手向脸部佯攻 → 对手抬手 → 侧踢躯干。
- **勾踢（“锐利的弧线踢”）：**比侧踢更快、更具欺骗性，且不会冒失衡风险；后脚后撤约 10 厘米，髋部旋转，小腿沿弧线甩出；弯曲的腿向前而非向后恢复（照片 41–44）。距离比侧踢近，但比手的攻击远。
- **旋身／后踢：**反击直线冲来的进攻者；以前脚掌为轴转身 180°，目光直到最后一刻仍留在目标上，躯干在接触时猛然转过，随后腿迅速收回，恢复平衡（对平衡要求最高——“先练几个小时，你才能刚刚打到目标”）。
- **反向弧线勾踢：**要求腿部柔韧；滑步约 15 厘米，腿沿近乎垂直的弧线，绕小圆由外向内运动；“擦过脸部”，穿鞋时危险。
- **内侧（垂直）腹股沟踢：**短促、向上，用脚背击打；用于对方站姿相反、侧踢够不到腹股沟的情况。
- 大幅弧线的回旋踢在 JKD 中几乎不用——路线短、力量有限。
- 画面中的训练目标：搭档在腰高处伸出的手掌、重沙袋、棍上护靶、纸靶。踢中沙袋后听声音：清脆的拍击声 = 正确；推挤声 = 错误。
- 热身前不要高踢；躯干向后、头部保持直立；对练时在搭档后退的瞬间踢击。

## 格挡（第 IX 章）

- 格挡属于辅助方法：“最好的防守是在攻击的同时进攻。”在最后一刻、对手已经不能取消击打时才格挡；太早格挡 = 对手会改变攻击方式。
- 四种基本掌／前臂拨挡：高位内侧拨挡（逆时针）、低位内侧拨挡（向下画半圆 + 重心移到后腿）、高位外侧拨挡（手横过躯干“去另一边”）、低位外侧拨挡。格挡只把击打**引开**——手保持在身体宽度以内，否则身体会暴露。
- JKD 核心原则：格挡和反击是**一个**动作（左手拨挡，右手同时击打脸部——照片 107–111；对付弧线拳——前臂截击 + 右手直拳）。传统格挡和反击需要两个节拍；JKD 恰好快一个节拍。
- 对付一连串攻击时，格挡的手与后脚后撤同步动作。
- 对付高踢——后退并倾身 + 抓住腿／低踢支撑腿膝盖。
- 对付低位击打——用弧线低位格挡，不要让身体跟着格挡转到后面。

## 目标（第 X 章，2 张“目标”图：正面和侧面）

- 主要目标（不需力量、没有肌肉保护）：眼睛、腹股沟、膝盖／胫骨。
- 膝盖和胫骨——最适合踢击的目标：触及距离最远，也能截停攻击；踢击伸出的腿，目标可选膝盖侧面、膝后或大腿。
- 太阳神经丛——敏感但通常有保护；下巴——优秀格斗者会将下巴藏向肩膀，并以移动“迎上”击打；喉咙——没有防护，用伸出的手指击打。
- 格斗中张开嘴 = 轻微击打也会使下颌骨折（照片示例）——这是业余者的标志。
- 击打接触面：脚刃／脚跟——侧踢和踢膝；脚背——腹股沟；脚趾——只攻击软目标；拳头指节——软／中等目标；掌心／手指——脸／眼／喉。

## 对练与欺骗动作（第 XI 章）

- “不会对练的格斗者，就像从没下过水的游泳者”：只有自由对练才能建立距离感、时机感，以及睁眼的习惯。
- 佯攻：向前踏步，同时让双手“活跃”；“长—短”“短—长—短”的节奏。佯攻必须看起来像真正攻击（有深度 + 有决心）；真正的击打要在对手恢复之前命中。最简单的序列：佯攻脸部 → 击打腹部；佯攻侧踢胫骨 → 勾踢头部；拳佯攻脸部 → 侧踢腹部；两拳击脸 → 拳击腹部。
- “引诱”：故意暴露身体某一部位，诱发对手攻击那里，再以反击迎上；后撤诱饵也有效。
- 对付不回应佯攻的“冻结”对手——直接以直线击打攻击。
- 心理：保持耐心，成功击中后不要急着向前冲；有信心的对手往往没准备好迎接第一记截击拳；对付狂暴的进攻者——边格挡边后退，抓住机会反击。

## 正确与错误（画面标记）

- **正确：**轮廓狭窄；双手守在中线上；拳头竖直；从站姿直接出击，不蓄势；躯干直立、膝盖弯曲；击打后肢体立即收回；眼睛始终看着对手（包括转身时）。
- **错误（书中刻意展示）：**拳头收在髋部（躯干敞开，“传统功夫”）；击打前蓄势／后拉（“打电话预告”）；出拳时后仰（拳上没有重心）；髋部转得过多（失去平衡）；手臂伸出后留在外面；防守时闭眼／转开头部；张开嘴；高位直腿站姿；格挡时“扫过超过身体宽度的范围”。
- 以成对画面形成风格对比：左侧，格斗者摆传统姿势（站得宽、拳在腰部）；右侧，李小龙摆警戒姿势——适合用在“老派对 JKD”的场景里。

## 其他编舞价值

- 照片序列结构：几乎每个技法都在中性背景（海滩／健身房墙面）前分成 2–4 阶段拍摄——可直接用作时间线模板：站姿 → 微小准备步 → 接触 → 回到站姿；不同阶段之间，对手只来得及开始作出反应。
- 李小龙反复被描述为：“轻松自信地完成每个动作，毫不费力地击打、轻松收回；看起来像能读懂对手”——英雄动画标尺：动作经济、不做准备、单拍爆发。
- 弱者：“动作不匀且颠簸，提前暴露意图，任由对手控制”——对手动画标尺。
- 道馆场景的训练背景：重沙袋、makiwara、杆上护靶、木人桩（咏春）、纸靶、搭档手持软垫；连续镜头表现“击沙袋—沙袋摆动—按节奏再击一次”。
- 本书基于距离的打斗结构：远距离移动 → 佯攻 → 单步爆发切入 → 1–3 次击打 → 立即分开或近距离黏手控制。
