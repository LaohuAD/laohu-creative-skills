# 08 — 早期传统功夫方法

**时期：**JKD 之前的李小龙——西雅图，20 世纪 60 年代初；基础来自叶问的咏春 + 南派传统拳术。

**对编舞的补充：**早期李小龙动作的精准“语法”：狭窄的咏春摆桩，沿中线出竖拳，手肘不动，近身黐手格斗，同时格挡出击，低位截踢。提供具体的技法词汇（拍手、拉手、膀手、摊手），用于抱缠时手部的微型编舞。确立了“连续的河流”这一视觉原则：动作没有停顿，防守流进进攻。适合“年轻传统派格斗者”的场景、木人桩训练，以及“早期风格 vs 成熟 JKD”的对比。

---

## 站姿与结构（摆桩）

- 基本预备姿势——**摆桩**：半正面，站姿**狭窄**（比拳击站姿窄），重心**70% 在后腿、30% 在前腿**（踢击时后腿最多承受 80%）。前腿可以自由防守低踢，并立即打出截击。
- 身体：胸口略微内收，背部稍稍弯曲（但不佝偻）——“内家拳派”；腹式呼吸；肩膀和手肘放松、下沉。
- 前手伸向对手的鼻子，手肘弯曲约 45°，手指朝上；后手在前手肘对面提供防护。始终有一只手护住中线。
- **腰部是一切动作的轴心**：四肢是“小轴”，腰是“大轴”；转一次髋部 = 转动手臂数百次。击打把身体重量送到目标；双手只是传递身体力量（手臂力量只有躯干力量的四分之一）。
- 移动：小幅快速滑步；前脚前进 20–30 厘米，后脚快速跟上；横移时交叉踏步并立即恢复摆桩；膝盖始终保护腹股沟。
- 对手的“七星”（需要监视的武器）：手、腿、肘、头、肩、膝、髋。“三面”攻击目标：眼前、手前、脚前。

## 中线与黏手（咏春传承）

- **中线理论（jong sin lei）：**从头顶中央延伸至双腿之间的一条想象垂直线。攻防的基础；击打沿这条线进行，整个身体的重量都沿线投入。李小龙的公式：“确立中线——牢记中线——忘掉中线” （= 学会规则、遵循规则、打破规则）。
- **不动肘法则（bat doan jang）：**前手肘离躯干 7–8 厘米，**不移动**——像龙卷风的静止中心；前臂和手围绕它灵活转动。防守矩形：腹股沟—眉毛—双肩。
- **四门：**矩形被分成 4 个区域（上／下 × 外／内）。外门由内向外挡，内门由外向内挡；从摆桩姿势可有八种基本防守位置。
- **黐手（chi sao，“黏手”）：**叶问的方法。搭档以前臂接触，手肘**不外展**，双手柔软但不退让——“强而不僵”。转动手臂时像转动大客车的方向盘。格斗者寻求保持在中线，使对手围着自己转。力量像溪流一样不停流动；注意力一停就是“气断”，会被击中。心无所住，则无所不在（无为，“做一个没有自我的木偶”）。
- 黐手组合：交叉双臂，缠住对手双手；击打中线；外侧击打；从手臂下方击打；从黐手接直拳、反手拳、掌刀、“凤眼拳”。
- 经典黏手技法：**拍手**（掌击拨挡）、**拉手**（抓住并拉扯手臂，同时截击）、**抖手**（迅速一拉以打乱对手）、**摊手**（掌心向上）、**膀手**（高位肘部格挡）、**伏手**（覆盖式格挡）、**耕手**（低位外侧腕部格挡）。

## 技法

- **咏春直拳（chun chui）**——首要拳法：拳头竖直，从胸口**正中**出发（不是髋部或肩膀！），沿直线飞出，最后停在对手鼻子前方的中线上。用下方三根指节击打；接触时手腕转过去。拳头放松地向目标移动，击打要“穿透”——目标在可见表面后方数厘米处，击打穿过对手。
- **连环拳：**在中线上一拳接一拳地流畅击打——迫使对手只能防守；可与指刺、反手拳、踢胫骨结合。
- 其他手法：指刺眼睛、“凤眼拳”（一根指节击打）、劈拳 choy（拳背）、掌刀、劈拳 chop choy（指节）、平拳 pin chui、弧线拳 ou choy。
- 一只手击打时，另一只手**始终**留在出拳手肘下方，护住中线／胸部。
- **腿——最有效的武器**（比手臂更长、更有力），但这一时期的踢腿都在**低位**：不高于对手腰部。目标：腹股沟、膝盖、胫骨、对手弯腰时的下巴。咏春经典踢法：脚跟踢、后脚跟踢、低位脚刃侧踢、低位踩踏式侧踢。
- 对着向前移动的对手踢前侧胫骨／膝盖进行预先截击——是后来 JKD 截踢的原型。
- 高踢和跳踢**只用于**柔韧性与平衡训练，“实战中不用”（重要说明：早期李小龙本人在照片中就摆出高位侧踢姿势）。
- 击打目标：太阳神经丛、鼻梁／鼻根、躯干、眼睛、下颌、腹股沟、腹部、膝盖。
- 常见序列（供对练编排）：对手向右侧出拳——抓住他的手臂 + 同时用左手击打太阳穴；掌击格挡 + 同一只手掌击胸；拉手拉扯 + 截击直拳；在对手双腿间扫腿 + 最后击打头部；拨开手臂向上／向外 + 直线踢腹股沟；格挡出拳 + 蹲下并击打肋部。
- **套路：**小念头（Sil Lum Dao）——108 个动作、3 段；手肘靠近中线，第一段动作慢而顺滑，做等长训练。马步——其他传统拳派的基础。鹤形套路——姿势宽阔、优美（与实用主义咏春形成对比）。
- 健身房场景训练器材：悬挂重沙袋、装豌豆的方形墙靶（鼻子高度）、装在松木板上的护靶、**木人桩（传统 108 式木人桩）**、金属护臂圈、打击球、头部模型、哑铃、跳绳。吊在天花板上的纸张——训练直拳准确度。

## 运动原则（阴阳、柔刚）

- 阴（柔、顺从、防守）和阳（刚、攻击）是一个整体，而非对立面：“一只手击打时，另一只手格挡”——同时格挡与击打是这种风格的标志性视觉特征。
- “纯阳／纯阴”错误：一只手击打时另一只手却收回 = 动作断裂。格挡要藏刚，击打要藏柔。
- **适应法则：**不要以力对力——利用对手的动作和力量对付他；移动的人如同风中的竹子。
- **动作如河流：**技法彼此衔接，毫无停顿；“防守即进攻”；动作像一串珍珠：技法是珍珠，连续性是串珠的线。
- 柔软 = 柔韧的芦苇、弹簧、影子、流动的水：“现在，水既可以流动，也可以冲击。做水吧，我的朋友”（这里已经出现了！）。
- 对练中的移动质感：内心平静，头抬起，胸口内收，肩膀／手肘下沉，半蹲，每个身体部位协调；“动作源于腰部，不是四肢。”
- “感觉有空当——就打直线。”“刚不能长久称王；柔不能防守”——两种主导特质交替。
- 对抗人群时：注意力像看足球比赛的观众——同时看到整个场地，心思不会“黏”在某个对手上，无需思考便切换目标（千手观音的形象）。

## 与成熟 JKD 的区别（用于“早期风格”场景）

- **站姿：**传统狭窄的咏春摆桩，70/30 重心落在**后腿**，躯干半正面——对比 JKD 较宽、灵活、类似拳击警戒姿势的站姿及其弹性移动。
- **距离：**早期李小龙是**近身格斗**高手（黐手、黏手、胸高抱缠）；成熟时期的 JKD 增加远距离、步法、切入时截击。
- **手法：**严格使用从胸口中央打出的竖直拳；JKD 后来加入拳击勾拳、上勾拳、佯攻、从肩部出发的拳。
- **腿法：**只用低位实用踢法；JKD 则有中位甩击式侧踢、勾踢，以及像刺拳一样使用前腿。
- **套路／仪式：**仍练习传统套路（小念头、108 式木人桩）、马步和按门派课程表训练；成熟时期的 JKD 明确反对套路（“第一是技法，第二是姿势——你不能那样定义攻击”）。
- JKD 的种子已经可见：“学规则——打破规则”、简化、“没有漂亮手套的赤手空拳”，以及蔑视增加额外步骤和绕圈的“花哨”风格。
- “传统派对 JKD”的视觉场景：早期格斗者站着不动或只走小步，双手持续接触对手手臂，在贴身距离打出短促竖直拳；JKD 格斗者拉开距离、弹动，然后以一次长距离击打爆发。
- 早期时期场景：在西雅图的院子／街道训练，穿黑色功夫服或背心 + 深色裤子、穿类似布鞋的运动鞋；木人桩；与叶问练黐手（书中照片）；摆拍直拳照片里穿条纹裤。
