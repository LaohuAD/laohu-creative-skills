# 07 — JKD 佯攻与反击方法
**对编舞的补充：**分步照片序列“佯攻 → 对手反应 → 真正击打”，精确标明肢体、技法和目标——可直接用于打斗场景的微型节拍。此外还有 JKD 战术逻辑：截击拳、对手蓄势时截击、相反站姿的应对，以及格斗者的心理类型（机械／思考型、紧张／冷静、高／矮）——可用于人物塑造和场景节奏。

完整课程（“高级技法”卷）的第 XII–XVI 章：手部攻击（I 和 II）、腿部攻击、防守与反击、身体素质和战术。对练照片中，格斗者穿深色制服、对手戴头盔——李小龙没有戴护具（这本身就是一种画面风格决定）。

## 手部攻击，第一部分（第 XII 章）

- 原则：攻击要简单、直接；JKD 技法几乎都是间接的——佯攻后出击，或作为反击。趁对手手部动作“打开线路”时攻击。佯攻必须打乱对手的计划，并让他进入你的触及范围。
- **指刺眼睛**——“攻防的基础”：可将触及距离延长 7.5–10 厘米，并且路线最短。伸直时，手指直接停在自己鼻子前方——不要暴露上方区域。
- 序列：稍微蹲下，向下佯攻（模拟攻击身体）→ 对手放低护手 → 立即指刺眼睛；将右脚放在对手脚边——挡住他的反踢。
- 对付左侧在前的对手：右手做出欺骗性动作，拨开对手的前手（移除路线上的“障碍”）→ 快速击眼；低踢胫骨也可用作佯攻。
- **右侧前手直拳**——截拳道的“面包”：锐利、精准、快速；力量来自“几分之一秒内”的髋部转动；拳头竖直；拳头停在自己鼻子前，后手保护头部；转动肩膀多增加约 10 厘米的触及距离。
- 同步／时机：先把节奏强加给对手，再打破它；“改变同步”——击打前稍微放慢，在弓步中停顿会打开防线。趁对手准备攻击、移动、改变格斗线路时出击——他必须先完成已经开始的动作，才能改向。
- 动作经济：紧张是刹车；放松、毫不费力的运动员更快。
- **前手击打身体：**躯干下沉到目标高度，拳头略微向上／近乎水平；目标——太阳神经丛；左手同时格挡对手的高位击打。
- 组合拳（第 XII／XIII 章）：头部 → 身体；直拳 → 勾拳；右勾拳 → 左直拳；三击序列；“安全三连击”——第一击和第三击打同一区域（身体—下颌—身体）。

## 手部攻击，第二部分（第 XIII 章）

- **左手直拳击身体：**身体前倾时出拳——较安全；对付正面相向、右侧在前的对手时是最佳反击；重心落在前腿，前肩抬起以防反勾拳。
- 序列：大幅假攻击 → 对手抬手 → 下潜，用向前穿入的左拳击打身体中线，头靠在左肩上（防止对手反击）。
- **反手拳：**迅速、利落、难以捉摸；从前手后方直接沿垂直半圆弧、由下向上出击；最佳目标——太阳穴。黏手序列：右手控制对手肘部 + 你的前脚踩住他的脚（压制踢击）→ 双手交换：左手固定住他的手臂，右手迈步打出反手拳。
- **短促前手拳（刺拳）：**没有太大力量，但会打乱平衡；连续打出短拳能让对手蜷缩成防御姿势，“喘不过气”；后一拳遮护前一拳。
- **勾拳：**幅度不大——轻快、有力；手臂由躯干转动带出，跟着身体走，“像弓上射出的箭”；手肘角度越收紧，击打越锐利；后手遮护脸部，后手肘保护身体侧面。重心转移到后腿，前脚跟抬起，髋部逆时针转动。序列：后手直拳佯攻 → 对手放低前手格挡 → 高位勾拳击下颌；近距离勾拳击身体／腹股沟——腹股沟比下颌更难格挡。
- **上勾拳：**对付低头者和“乱挥拳者”的近战技法；屈膝后随击打伸直，重心落在前脚掌上；前手收回保护头部。

## 腿部攻击（第 XIV 章）

- 诗歌题词“强劲的腿”：踢胫骨能截住攻击；侧踢会“打断后背”；旋踢会出其不意地把对手踢倒；扫踢在电影里看起来很壮观，但实际力量不大（这是对原意的直接陈述——可用于“电影效果 vs 真实感”）。
- 在对手建立防守前踢击。协调膝盖与髋部；高踢、低踢、贴地踢；移动和转身时也能踢击。
- **前手侧踢胫骨／膝盖：**第一次交手时的第一击；一击就能踢断膝盖。序列：前手大幅向上挥动（分散注意力）→ 向前弓步 → 低踢膝盖；随后李小龙仍在对方触及范围之外。
- **前腿侧踢**——JKD 最有力的击打：“即使格挡也救不了你”；从远距离踢更有力——动量有时间累积。手向上挥动 → 侧踢膝盖；看对手的脸，不看目标——隐藏意图。踢肋部的变体：把对手向后抛（带有腾空镜头的照片序列——可作为击打—反应标尺）。
- 若对手对佯攻没有反应——换战术：高位侧踢越过防守的双手，直击脸部。
- **回旋踢**——使用最频繁：快速、灵活，可踢头部／身体／腹股沟。序列：佯装踢膝 → 对手放低手 → 高位回旋踢脸（包括躯干倾斜、俯视角——表现击打角度）；抬手打开中线 → 回旋踢左侧；假装低位回旋踢 → 对手放低左手 → 高位回旋踢头。
- 佯攻规则：不超过两次；第一次佯攻缩短一半距离；佯攻只持续到引发对手反应为止，不能给他格挡时间。
- **旋踢：**谨慎使用——可能会把背部暴露给对手；通常作为截击。手向上挥动 → 踏步到对手右侧 → 迅速以右腿为轴转身，同时不让对手离开视线 → 旋踢身体中部或脸，将他向后踢出；在 JKD 中，这是朝目标正面推进的踢击，而不是大幅横向“掌掴”。这是警戒姿势下少数从左（后）腿打出的踢击之一；能穿透防守将对手踢倒。
- **扫踢（反向／脚跟勾踢）：**少见——对手的手总会护住脸；踢击从高处经过，不太可能把对手扫倒；对付粗心的对手有效：伪装成前踢，绕过低位格挡，沿半圆弧从左向右扫过（书中附有“腿部路径”图）。

## 防守与反击（第 XV 章）

- 理念：“拨开击打看起来像防守，但它是最高形式的进攻”；反击几乎不会挨打——对手会在接近时撞上反击。用佯攻引诱对手攻击，比等待更好。
- **手指截击：**在对手攻击成形前截击——对手还没打到你，就先被击中眼睛；这会打击进攻者的士气。
- 截击序列：对付摆拳——向前踏步 + 前手直拳打脸（直线比摆拳短）；对付直拳——在蓄势时用右手指刺眼。
- **胫骨／膝盖截踢：**截停任何手部或腿部攻击；对付后腿向前迈步——用踢腿迎上对方的击打腿；对付低姿势攻击者——闪过拳头并以踢击迎上胫骨；对付左侧在前的对手——闪身 + 同时用前膝踢击（“腿比手伸得更远——这是完全安全的回应”）。
- **截踢侧踢：**在中／远距离时力量最强——一击足够；对付迎面冲来的对手——踢胸的有力侧踢能截停他并把他踢倒；对付后腿踢击——在对方支撑腿着地时用滑步踢回应。
- 闪避后，在对手“冲刺后身体紧绷”或正在恢复时击打——这时他的腿是静止的。
- 擒拿序列：用右拳向脸部假冲 → 对手全力打出右直拳 → 一个动作内拨挡并抓住手腕 → 回旋踢腹股沟。
- 以迎击回旋踢打脸，应对压制式攻击：以后腿为支撑轴转动，闪避来袭方向，同时保持稳定平衡。

## 身体素质与战术（第 XVI 章）

- 速度类型：感知、思考、执行、改变（动作中途改变方向）。情绪、疲劳、缺乏训练和注意力不集中都会延长反应时间。
- 心态：赢家自信、放松；执念会让肌肉紧绷；伟大运动员能节省能量，动作利落轻快。
- 场景人物类型：“机械型”格斗者——重复、自动的击打；“思考型”格斗者——有策略、会分析、会适应敌人。对付紧张的对手——用短佯攻并保持冷静；对付冷静而坚持的对手——佯攻引出截击拳，再用黏手控制；矮个格斗者冲向突出的目标，高个格斗者移动慢、保持距离——不要从他面前后退，要切入他的攻击。
- 战术手段：对手收回手／腿时再次攻击；一连串高位佯攻会打开低位目标（膝盖、胫骨）；中断攻击——击打前停顿会瓦解防守；新手混乱的节奏本身会骗过高手——保持距离并截击；对付对手的战术（对付反击者——佯攻；对付佯攻者——截击拳；“用摔跤手的方式对付拳击手，用拳击手的方式对付摔跤手”）。
- 结尾：高手“会用上全部招式库，一个接一个创造空当，直到打出强力的压倒性一击”——这是打斗场景的高潮公式。

## 与四卷本《李小龙格斗方法》的重叠

**几乎完全重复。**这个俄文版 = 同一套《李小龙格斗方法》的第 4 卷“高级技法”（导言明确指出第 XII–XVI 章，接续《自卫技法》《基础训练》《技法精进》）。如果四卷本系列已经做过批注，技法和照片就是相同的。

本扫描件／译本独有的内容：

- 20 世纪 90 年代俄文译本的术语（“leg hook”“rear fist strike”“safety triple”“short lead”）——有利于统一知识库词汇。
- 压缩式编排：只讲进阶内容（攻击、反击、战术），不含基础体能训练——可作快速查找序列的参考。
- 植原的导言包含 1966 年背景与琳达·李的立场；诗歌式章节题词（包括“电影里的踢法”看重场面而非实用性）——直接说明技法的电影化特质。
- 独特的照片场景细节：对手总戴头盔，李小龙没有护具；背景中性，序列分为 3–4 阶段——可直接作为“佯攻 → 反应 → 击打 → 腾空”的分镜模板。
