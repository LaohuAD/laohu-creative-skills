# 03 — JKD 站姿、移动与自卫技法
**对编舞的补充：**“李小龙如何站立和移动”的基础——精准的 JKD 站姿、完整的移动词汇（滑步、冲刺、爆发、侧步）、力量力学（从髋部和后腿发力，击打“穿过”目标），以及速度力学（不显预兆的击打、破节奏）。这是第 2–4 本书中每种场景序列的基础：任何“李小龙风格”的角色都必须在银幕上按这些规则移动，否则这种风格就无法辨认。

## 1. 总体原则（摘自引言——可直接用于角色说明）

- 本书拍摄于 1966 年；李小龙不想把技法变成个人崇拜：技法是工具，不是教条。训练时要“把对手当作真的就在眼前”——成为高手的唯一方法：每一击都全力投入。
- 优秀格斗者 = 速度 + 力量 + 距离感 + 读懂意图的能力；持续训练决定一切，而不是“神秘主义”。
- 最好的防守是保持距离和机动，而非硬格挡：用脚闪避比用手拨挡容易。
- 放松是基础：肩膀紧绷、拳头紧握会“吃掉”速度；只有在接触瞬间才迸发力量。

## 2. JKD 格斗站姿（警戒）——将人物摆入画面

- 半屈膝、富有弹性的姿势：强侧手和强侧腿（李小龙的右侧）朝前——“强侧承担大部分工作”。
- 下巴收起／压向锁骨，前侧肩膀略微抬高——护住下颌；眼睛始终看着对手。
- 前手位于自己与目标之间的连线上，略低于肩；后手靠近躯干，遮住肋部／身体侧面，张开的手掌靠近下巴。双手作微动作（像蛇一样上下移动）——不给对手的眼睛任何可以“锁定”的东西。
- 双脚自然分开一步，后脚跟略微抬起（像弹簧）；重量大致落在双腿之间，身体与前腿对齐——形成狭窄轮廓，尽量少暴露空当。
- 膝盖放松，站姿不宽不窄：太宽 = 稳但慢，腹股沟暴露；太窄 = 快但受击后会垮。
- 本章分析约 15 种**错误**站姿（照片 26–40）——为临演／对手准备的现成姿势目录：双手贴在身体两侧（上半身完全敞开）、双手举高（腹部暴露）、“伸展式”弓步站姿（起动慢）、胸口正对对手（所有目标都暴露）、双腿交叉（没有支撑底座）、躯干压在前腿上方（无法用后手出拳）等。李小龙的对手在银幕上就该这样站——“站错”。

## 3. 平衡

- 平衡是站姿的核心元素：身体各部分相对位置正确，重心处于双腿之间，前膝放松。
- 只有在击打或迈步时，重心才在双腿间流动；攻击时移到前腿，闪避／防守时向后移动。
- “脚下轻盈”：双脚仿佛刚好浮在地面上方，用小幅滑步移动，不跳跃、不交叉；每个动作后立即回到站姿。
- 优秀格斗者可以从任何运动阶段启动任何方向的动作；失去平衡 = 被击中的瞬间（在银幕上表现挨击后的戏剧逻辑）。

## 4. 步法——动画中的移动词汇

- **前滑步／“移动”：**前脚向前滑约 10 厘米，后脚跟上同样距离；躯干和双臂保持原有位置。向后滑步时动作镜像反转（后脚先动）。双脚离地不得超过几厘米。
- **快速前进：**连续短促滑步，同时维持站姿；每秒最多移动三个“距离段”；不作上下起伏，双腿共同发力。
- **快速后退：**向后使用相同机制；李小龙的第一步很长，能后撤 2 米以上——对手会“扑进”空处。
- **前冲／爆发切入：**覆盖距离最快的方式：前腿猛然跨步（约 3/4 秒前进 2.5 米），重心越过前腿向前飞，后腿跟上；同时以前手向上拍击／佯动（仿佛在对手脸前拉绳），打乱其注意力，再同步踢出侧踢。单腿落地后，立即恢复站姿。
- **后退爆发：**镜像式后撤，一次爆发退过两个普通步幅的距离；用于应对摆击／抱缠。
- **侧步：**向右——远离“闭合”的一侧；向左——离开直拳攻击线 50–80 厘米；双脚迈步但不交叉，躯干转向对手，进入防守姿势。向侧面移动不是逃跑，而是在对手攻击打空时击中对手的方法。
- 原则：对付左撇子，向右移动（远离他的右侧）；对付右撇子，向左移动；这门艺术的要点是移到这样一侧：你的击打能够到达他，而他的击打不再能够到达你。

## 5. 力量力学——在银幕上表现击打的力量

- 力量不是来自手臂：出拳是整个身体协同工作的结果；手臂只是“握住”髋部和后腿产生的力量。击打线路是从自身中心到目标的一条想象直线；拳头从身体中心出发，不是从肩膀出发。
- 拳头竖直，用下方三根指节接触；接触时手腕、手肘、肩膀对齐；击打要“穿过”目标，注意力落在对手头部／身体后方，而不是表面。
- 髋部横向旋转 90–180° 是主要的增力来源；用一张纸（20–30 厘米，悬挂在胸高）和重沙袋练习。
- 著名的“2.5 厘米拳”（一寸拳）：不蓄势，从放松的手出发，在最后 10 厘米内爆发；接触后拳头上扬——对手是飞出去，而不是“被轻弹了一下”。只适用于近距离。
- “能量流动”／黐手（黏手，咏春）：手肘“固定”，力量从躯干流入前臂下段；双臂放松，却无法被推开——搭档近距离站立，前臂旋转，每个人都在寻找中线的空当。这是“交织双手”优秀的近战参考。
- 侧踢——李小龙最强的击打：他把一块 5 厘米木板抛起，并在空中踢断；力量 = 速度 + 体重，脚跟“穿过”目标，眼睛看着目标，双臂不乱挥。大范围撞击力：踢击会“把对手整个身体向后抛”，而不是只切入一个点。
- 弱击打（适合银幕上的对手）：只用手臂出拳、身体不参与；肩部蓄势；身体失衡时出击；躯干扭转过度且无法恢复。

## 6. 速度与无形攻击

- **不会“打电话预告”的击打：**没有准备性微动作——不把拳头往回拉、不卸掉重心、眼中不闪露预兆；手先于躯干启动。哪怕一个厘米的抽动都会警告对手。电影表现：李小龙的攻击应该“凭空出现”，从完全中立的姿势中出手。
- **反手拳（以前手拳背击打）**——最快的击打：近距离出手，放松的手从几厘米外“发射”；目标是头部。经典序列：黐手接触 → 向下打出的反手拳。
- **前手直拳打头部**——主要武器；可从腰部与肩部之间的任何姿势打出。
- **腿部速度：**李小龙的侧踢和弧线踢几乎与刺拳一样快；“看他抬腿追着对手踢，而另一个人完全失去平衡，很有意思。”
- **破节奏：**改变一组动作的速度和节奏，停顿后再爆发；比预期早或晚半拍的击打能够干净利落地命中。
- **反应／攻击感知：**训练方式——观察一个随机路人并“预测”其动作；“草叶与狗”的伎俩（在它抓到之前先躲开）；搭档在手掌上放一枚硬币。场景中看起来就像“李小龙在对手攻击成形之前就开始反击”。
- 大步之后连续完成五次快速动作（一组动作最多十次快速移动）——这是场景最后一轮“交手”的范本。

## 7. 踢击招式库（速度／力量章节 + 照片）

- **侧踢：**既可作为截击，踢向伸出的腿之膝盖／胫骨，也可像攻城槌一样踢向身体。编排：抬起前膝 + 旋转支撑脚，躯干为平衡而后倾，用脚刃／脚跟击打。低位踢膝变体：“对手全部体重都压在前腿上；这一击不可能无力，并且会限制移动。”
- **勾踢／弧线踢：**快速向前踏一步（10 厘米）后出击，用脚背／前脚掌，通常击向肋部／身体侧面或头部；膝盖“甩动”，击打必须“穿过”目标，否则声音／效果会很弱。若对手很近，可使用踢向腹股沟的膝击变体。
- **旋踢／旋身后踢：**对手从侧面反应并切近时使用；由于躯干旋转，力量比侧踢更强，但要求时机完美——“不建议第一次格斗就用：一旦失去平衡，对手就有足够时间。”
- **正面踢腹股沟／膝盖：**最准确的向前踢击；脚从对手双腿之间踢出。
- 训练目标（李小龙训练镜头的参考）：纸张、重沙袋、搭档手持的脚靶／盾牌、木人桩（木人桩，muk jong）、顶端包有垫子的棍子、被抛向空中的盾牌。

## 9. 可直接采用的编舞序列（根据可读文字重建）

1. **截击踏步进攻：**对手踏步并蓄势 → 李小龙不动躯干，用脚刃侧踢对手前侧膝盖／胫骨 → 对手的腿“卡住”，躯干向前倾 → 最后以反手拳／直拳击头。结尾：对手沉倒在弯曲的腿上。
2. **佯攻后爆发前冲：**距离 2–2.5 米 → 前手在对手脸前向上闪动佯攻（“拉绳子”）→ 在同一瞬间向前爆发，并侧踢身体 → 对手向后飞，李小龙单腿落地后立即恢复站姿。
3. **侧步反击：**对手打出直拳／摆拳 → 左侧步（50–80 厘米），双脚不交叉，躯干完全转向对手 → 攻击打空 → 前手直拳沿短线路击中下颌。结尾：对手的动量带着他从身旁经过，并在经过时被击中。
4. **后仰 + 侧踢（对付举起武器蓄势）：**棍棒／短棍从上方、侧面举起蓄势 → 李小龙将重心转到后腿，躯干向攻击半径之外倾斜 → 用一个动作恢复重心并侧踢腹部 → 对手弯下腰，武器掉落。
5. **以黐手切入近身格斗：**双手在中线上交锋 → 李小龙借流动的压力“穿过”空当 → 从几厘米外向下打出反手拳 → 立即用另一只手打出直拳。结尾：对手后退并护住脸。
6. **旋踢对付切近的对手：**对手对佯攻作出反应，从侧面冲近 → 以支撑脚为轴转动，旋踢身体 → 对手被扫得向后飞出 2 米以上。（李小龙认为这是高风险技法——可作为高潮中的“王牌”。）
7. **后退陷阱：**连续快速后退（对手加速并失去站姿）→ 突然停住，同时向后—向前转移重心 → 在对手迈步时以截击直拳或前踢踢向腹股沟。结尾：对手以自己的速度撞上击打。

## 10. 文字中的“摄影机”规则（用于提示词）

- 李小龙的轮廓始终狭窄、侧身；对手正面朝前且“门户大开”。
- 李小龙攻击前——没有任何准备动作；对手必须蓄势／卸掉重心（显露预兆）——这是“谁是高手”的视觉规则。
- 每次击打都“穿过”目标：接触后继续沿原轨迹运动，对手身体整体被打离原位，而不只是头部抽动。
- 每个动作后，李小龙在 2–3 帧内回到站姿；只有对手会显出不稳定。
