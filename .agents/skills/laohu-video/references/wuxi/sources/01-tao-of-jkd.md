# 01 — 截拳道之道

**对编舞的补充：**
以第一人称呈现 JKD 的完整动作力学：站姿、步法、所有手部和腿部击打的轨迹与目标、五种攻击方式、时机和破节奏。确立了这种风格的视觉规则：极简主义、不蓄势或显露预兆、从任何姿势出击、持续小幅移动、总比对手早半拍爆发。编排场面的关键：JKD 格斗者几乎从不正面硬攻——他截击、佯攻并反击；面容平静，动作像“眼镜蛇出击”。李小龙的术语（截击拳、破节奏、SAA/HIA/PIA/ABC/ABD）可直接用作镜头清单语言。

---

## 站姿（警戒姿势；JKD 传统中的摆桩）

- “屈膝、细小而有动势的站姿”：半蹲，步幅窄而舒服，持续循环微动作——不是静态姿势。重心略向前、向下。
- 较强的一侧朝前（右撇子使用右侧前手）。前手和前腿完成约 80% 的击打——它们已经“走完了去往目标的一半路程”。
- 头部：下巴降低 2–3 厘米，前侧肩膀抬高 2–3 厘米——它们“在半路相遇”。只暴露头顶，下巴尖受到保护。
- 前手：放松、略低，不断移动以迷惑对手——“像准备出击的蛇信一样前后闪动”“像闪电一样”。伸出再收回的动作像花剑刺击。
- 后手／护手：手肘降低，置于下方肋部前；前臂遮住太阳神经丛；张开的手掌朝向对手，位于前侧肩膀延伸出的线上；可作绕圈般的波浪动作。
- 躯干与前脚对齐：脚尖内转——形成窄目标（防守）；脚尖外转——转为正面朝前（用于某些攻击）。
- 后脚跟抬起——“整部格斗机器的活塞”；重心在前脚掌上。前脚跟几乎贴地。
- 双脚自然分开一步，始终位于身体下方，绝不交叉。
- 紧凑性：“手肘、前臂、拳头和额头合成一团……你像一只拱背、准备扑出的猫”；“像眼镜蛇一样——放松但紧凑的姿势”。
- 站姿不泄露意图：“姿势透露动作的程度，不会超过一位优秀扑克玩家的脸透露手牌的程度。”
- 识别性画面：“好格斗者总是像裤子快要掉下来一样移动”（膝盖一直半屈）。

## 步法

- “格斗的精髓在于移动的艺术。”移动能力高于一切：JKD 不需要“连续三年站在 kiba-dachi（骑马立）里”；要在活的移动中寻找稳固。
- 四种基本移动：前进、后退、向右绕行、向左绕行。
- 前后滑步：连续的小步，双脚贴着地面滑动、不抬起，身体始终保持警戒姿势。
- 快速前进：跨一大步 + 另一只脚立即跟上复位；身体与地面平行地移动，不上下弹跳——这不是跳跃。
- 快速后退；前进—后退步——用身体佯动打开对手的防线。
- 侧步：向右／左移动约 40 厘米；躲开击打，而不是躲开冲刺；在最后一刻、击打几乎已经到达时执行。最靠近移动方向的脚总是先动。
- “向前扑”：横向移动，同时躯干前倾、头收起、双手抬高——切入近身格斗。
- 规则：步幅短而快（两个中等步幅胜过一个大跨步）；控制重心；手部攻击时，手要先于脚启动；前脚要等拳头碰到目标后才落地。
- 移动质感：“像优雅的交际舞舞者一样移动——给人的感觉是他滑过地面”；“双脚是弹簧”；躯干是“一座承载火炮的炮塔”，不论底座如何移动都保持稳定。
- 闪避（不离开“火线”）：向内／向外闪身（对手的拳从肩上方掠过；关键是转动对应侧脚跟并移动重心）；下潜（从腰部弯身，躲过摆拳或勾拳）；后仰急闪（突然移动躯干，让拳打空）；顺势化解（随着击打移动来吸收冲击：直拳来时向后，勾拳来时向侧，上勾拳来时向后，锤拳来时沿弧线向下）；摇闪（把头部当作移动目标；秘诀在于放松；不要像钟摆一样有节奏地晃动）。
- 直拳来时向外闪身最安全，也能空出双手反击。“往里移动，而不是向后仰：让对手的勾拳从你脖子后方掠过。”

## 手法

- 核心原则：“出拳要调动全身”——力量从地面经由双腿、腰部、背部、肩膀和手腕传递。力量来自以伸直的前腿（“轴心”）为轴转动腰部，而不是摇摆身体。
- “拳不是推。真正的拳击像鞭子抽响”；加速穿过终点，接触时才握紧拳头，将注意力放在“目标后方几英寸”——打穿对手。
- 前手直拳——“JKD 手法的脊梁骨”。从胸口中部沿鼻子连线出击，拳头竖直，手腕略微“拧转”。不蓄势，不往后拉到髋部／肩膀，从手当时所在的任意位置出击；沿原路收回，手保持在高位。这是最快、最准确的拳。
- 前手刺拳：“以攻为守的侦察”，“像鞭子，不像棍棒”；阿里说：“像拿苍蝇拍打苍蝇一样抽打。”锐利、带刺，立即收回。
- 指刺：“JKD 最长、最快的手部武器”，目标是眼睛。“像不用剑的击剑”；“看起来像眼镜蛇出击——对手应该先感到它，再看见它。”
- 后手交叉拳：“重型火炮”，严格走直线，大幅转腰，肩膀与脚跟一起转——“关门原理”；接触时重心转移到前腿。
- 后手直拳打身体：蹲低到目标高度进行反击；头部移到出拳手臂的线路上。
- 前手勾拳：最好的反击拳；绝不大幅挥摆——“放松、轻巧、锐利”；不蓄势，手肘在最后一刻抬起；前脚跟朝外转，身体以前脚掌为轴转动；手腕坚实，拳头和前臂像“一根末端加粗的棍棒”。这是近距离武器，能绕过护手，“常从对手视野之外”击入。
- 铲勾拳：最短、最具爆发力；手肘贴着骨盆，拳头呈 45 度，髋部随“铲击”般的推进而抬起——拳头穿透防线。
- 螺旋勾拳：像直拳，但接触前手腕会突然转动，前臂与地面平行；从对手护手后方打向下颌。
- 上勾拳：只适用于极近距离；屈膝后猛然伸直，把力量送进拳中；对付低头和“远距离出拳者”。对快速、直立的格斗者无用。
- 其他武器：掌勾拳、反手拳（高位／中位／低位／垂直）、缩短弧线的摆拳、锤击、反向弧线击打（用拳底、前臂、肘部），肘击（向上、向下、向后、从右侧／左侧“粉碎式”击打）、头槌。
- 组合拳：“一二”（右刺拳—左交叉拳）、刺拳—上勾拳、刺拳—勾拳；三连击：两拳打身体，第三拳打头；“安全三连击”——身体—头部—身体（最后一击打回第一击的同一目标）。每组总以一记前手击打收尾；高低、高低交替。
- 双连击（双刺拳）打乱对手节奏并打开组合进攻。

## 腿法

- 作用：最长的武器，先在远距离出手；“踢击应该像眼镜蛇出击——对手应该能感觉到它，却看不见它。”
- 每种踢击都必须有以下特质：有力且易于执行、准确、突然、经济、流畅而无抽动、能与其他技法协调、形成反射动作。
- 侧踢：JKD 的主要踢法。变体——向下踢胫骨／膝盖／大腿（低位、最安全，“实战中最好向下踢”）、水平踢肋部／腹部／肾脏、高踢、滑步踢、跳踢、支撑腿旋转踢。“对手压在某条腿上的重量越大，踢他的膝盖就越危险。”
- 胫骨／膝盖踢：直踢、向下踢、由内向外、由外向内；“有很强的打击士气效果，让对手攻击时不那么自信”；拉开距离；常在指刺或直拳前用作烦扰性佯攻。
- 勾踢（由外向内）：高位／中位／低位；用脚背、前脚掌或胫骨接触；主要用于快速踢击腹股沟和头部。反向勾踢（由内向外）。
- 前踢：踢膝盖或腹股沟；用脚背踢腹股沟——力量向上；垂直勾踢——沿中线向上踢。
- 源自萨瓦特：膝盖和躯干固定，以脚跟接触——“极快、有力，而且最难格挡”。
- 膝部驱动的弹击（腹股沟勾踢、反向勾踢、向上弹踢、前踢）——要把力量送进去；髋部驱动的推踢（侧踢、后踢、正面踢）——要把速度送进去。
- 旋转踢：旋身后踢（高位／中位／低位、跳跃）、360° 旋风踢；弧线脚跟踢（腿部绷紧并弯曲）；向下踩踢（踢胫骨／脚，近距离使用时“用于致残”）。
- 膝击：向上、向内，用前腿或后腿出击——近身格斗。
- 下蹲扫腿——在格斗开始时、组合进攻中、作为反击；击打倒地对手——“准确、重击”。
- 高手能同样轻松地“从高处、低处或地面”踢出；许多踢法（勾踢、侧踢、垂直踢）不需要改变手部防守姿势——双手保持护势。
- 擒拿层（用于严酷场景）：摔投、扫腿、关节锁（手腕、肘、腿、背部）、绞技（背后、侧面）、摔倒、黏手控制；“禁用技法”——抓头发（控制）、跺脚（致残）、咬／捏（脱身）、抓裆。
- 击打目标：眼睛、腹股沟、胫骨／膝盖——JKD 的三个“便宜”目标；脆弱部位：太阳穴、喉咙、太阳神经丛、肋骨、腹股沟、肾脏、尾骨、膝盖。

## 截击与时机（JKD 的核心——“截击之拳”）

- 截击拳：与对手的攻击同时出手；预判攻击、封闭攻击线路，并沿着能打断对方击打的轨迹出手。机会包括：对手正准备切入时，他的手臂尚未伸直时，佯攻过程中，组合拳的两个动作之间，以及他迈步出击时。常让躯干向前移动——迎着对手切入。
- 对手身体正在前进时，对胫骨／膝盖踢出截踢——这是对付横扫式攻击的标志性截击。
- 预先截击／第二意图攻击：诱发对手打出截击拳（用邀请、明显佯攻、假攻击）——再同时应对并拨开他的截击。
- 攻其准备：在对手仅仅准备自己的攻击时出手——他的双手和注意力都忙于进攻。
- 攻防同时： “闪避时总要试着出击——切入拳内侧出击，比格挡后再打更有力”；同一节拍内完成拨挡 + 出击。
- 对手施展完技法后、吸气时、注意力分散时、或失去平衡时，反应时间都会立即增加——这些都是攻击窗口。
- 破节奏：势均力敌的格斗者会以共同节奏移动；稍微摇摆或做出意料之外的移动来打破节奏的人就能命中——对手会自动沿用旧节奏继续动作。“脱离节奏的一击会趁对手暴露时打中。”
- 半拍出击：趁对手动作尚未完成时攻击。踢击型 PIA 使用“ONE—and…”的节奏：第一击深入而隐蔽；后半拍是爆发性踢击。
- 用放慢动作作为武器：击打在半途停下，等对手已经移动去格挡后再继续，是极其有效的节奏变化。
- 节奏：“节奏中的一个拍点”——对手心理和身体无助的一刻；趁他注意力下滑时攻击。

## 五种攻击方式（李小龙的最终分类）

1. **SAA——简单角度攻击**（SAA/SDA）：从意料之外的角度打一记攻击，有时先佯攻；用步法预备距离。“用简单动作击中对手，是最高技艺的表现。”
2. **HIA——手部制敌攻击**（HIA，黏手）：在接触时控制对手的头（头发）、手臂或腿；控制会限制该肢体，并打开安全的击打区域。前臂控制是一种“破坏性武器”。
3. **PIA——递进式间接攻击**（PIA）：佯攻或未完成的击打将防守引向错误方向；真正的攻击不后退，而是用**一个动作**向前打入打开的线路。佯攻消耗一半距离；趁对手的手正朝相反方向移动时出击。
4. **ABC——组合攻击**（ABC）：沿多条线路自然衔接、不断流转的击打；这一系列动作会为最后的击倒重击“铺路”（三连击、“安全三连击”）。
5. **ABD——引诱攻击**（ABD）：提供一个空当／可读出的动作，引诱对手进攻——再利用对方的动量和无法护住自己的状态反击。

## 距离与节奏

- 格斗距离：对手若不大力冲刺，就无法触及彼此；每个人都有自己的距离。持续移动 = 玩弄对方对距离的感觉，同时保持自己的距离。
- 朝着“对手将会出现的地方，而不是他现在所在的地方”攻击。
- 胫骨是最近、持续暴露的目标：对付踢腿者时，距离按“胫骨对胫骨”衡量。
- 远距离：踢击、指刺、前手刺拳、后手交叉拳。近身格斗：勾拳、铲勾拳、上勾拳、肘击、膝击、黏手、摔投；切入时——“像跳舞般滑行绕着对手移动，交织使用闪身、下潜和摇摆”。
- 视线：远距离时看对手的眼睛；近距离时看他的腿或腰。绝不眨眼或闭眼。
- 节奏：速度要和对手匹配；强加自己的节奏意味着“带领”他。速度过快有害：攻击者会“自己挡住自己”，追上自己的防守动作。
- 佯攻：“长／短”节奏；两次佯攻的攻击——“长／短／长”；完善后的版本——“短／长／短”。第一次佯攻要深入、具有穿透力（诱发格挡），最后一击要短促果断。“长”不等于“慢”。佯攻超过两次很危险。
- 佯攻触发：挥手、跺脚、突然喊叫——反射性地分散注意力。“JKD 风格以佯攻及与佯攻相连的动作作为基础。”
- 拨挡与格挡：拨挡是轻快地向内／向外突然移动，把击打引开；“成功取决于时机，而不是力量”；在最后一刻执行，手移动的距离不超过必要范围。格挡是最后手段：“会削弱身体、浪费能量、破坏平衡。”拨挡类型：简单拨挡、半圆拨挡（高位—低位）、圆形拨挡（抓住手腕并将它移出攻击线）。后退式拨挡要与跨步同时开始。
- 操控对手手臂（准备攻击）：拍击——对手臂快速锐利地击打；束缚——将其从高线斜向移到低线；下压——从同侧向下移动；包绕——绕圈移动后回到起点；施压。这些都是“在间接攻击前引诱对方落入陷阱”。

## 特质与美学（引文）

- 五种速度：感知速度、思维速度、启动速度（开始动作而不泄露预兆）、执行速度、改变动作速度。“本能动作——最简单的动作——最快也最准确。”
- 力量 = 力气 × 速度；动作快速的轻量级格斗者打出的拳就像重量级选手。多阶段加速：脚趾蹬地 → 膝盖 → 躯干 → 肩膀 → 前臂 → 手腕 → 拳头；“击打的最后阶段应该最快。”
- 经济性：不蓄势、不做多余动作；“动作经济而突然，像一枚落下的硬币。”
- 好的形式 = 以最少的动作和能量取得最大效果；“有经验的运动员最重要的品质，是即使竭尽全力，也能轻松移动。”
- 面部表情：“格斗中的行为不应该与日常行为有任何区别……面部表情不应改变。任何事都不该透露一个人正在为生死而战。”目光不固定在某一点，眼睛不因愤怒而燃烧。
- 表达这种风格美学的关键词：
  - “动作时，模仿水；静止时，像镜子；回应时，像回声。”
  - “对手应该先感觉到你的击打，再看见它。”
  - “该出拳时出拳；该踢腿时踢腿。”
  - “简洁是两点之间最短的距离。”
  - “以无招为招，以无限为限。”
  - “在运动中找到静止，如同波浪中的月亮。”
  - “拥有鹰的眼睛、狐狸的狡黠、猫的敏捷与谨慎、豹子的攻击性与凶猛、眼镜蛇闪电般的击打力，以及猫鼬的耐力。”
  - “如果我们能用眼睛出击就好了！从眼睛经过手臂再到拳头的漫长旅程中，损失了多少力量。”
  - “截拳道修习者的动作像一道闪电。”
  - “让对手撕破你的皮肤——你就撕开他的血肉；让他毁掉你的血肉——你就打断他的骨头。”
  - “最好的防守是进攻”；“格斗永远要用头脑，而不是用手脚。”
