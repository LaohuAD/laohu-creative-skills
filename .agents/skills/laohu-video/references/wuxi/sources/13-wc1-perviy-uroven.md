# 13 — 咏春基础技法

**对编舞的补充：**
- 诠释“二字钳羊马”与前置格斗站姿的精确几何关系——用于在银幕上呈现正确的**咏春**轮廓。
- 基本手法的完整词汇（摊／膀／伏／拍／耕／枕／标／圈／按／截／护手），包含每种手法的动作力学与工作区域。
- 典型戏剧模式：抓握—拉扯 + 同时出击（拉手）、“一个动作阶段内格挡 + 出击”的序列、黐手滚动。
- 小念头的视觉阶段——可直接用于训练场景（包括单腿站立）。
- 分区防守和离开攻击线的规则——说明哪只手负责保护什么。

## 站姿与结构

**二字钳羊马（正面训练站姿）：**
- 重心各 50% 落在双脚。膝盖略微弯曲并向**内**夹（“钳羊”）。
- 双脚形成三角形：脚尖内扣，脚跟分开；两脚中点之间相距 35–40 厘米。
- 骨盆略微前送，大腿略微绷紧。躯干直立，头部与身体对齐。
- 训练姿势中，拳头放在腋下，手肘弯曲。进入站姿：双脚并拢 → 脚尖向外转 30° → 屈膝并将脚跟分开。
- 视觉上：站姿狭窄、收拢、“钳住”——与宽阔的功夫站姿完全相反。

**前置格斗手位（问手／护手）：**
- 前臂沿中线向前伸出，手掌张开，手指朝前、朝上；手肘离身体 15 厘米。
- 后手（护手）——掌心张开，手指朝上，更靠近胸部，也位于**中线**上。
- 双手都在身体中心前方的同一条垂直线上。右撇子格斗者通常左手在前（强手在后）。

**前置格斗站姿：**
- 重心转移到**后腿**；前腿几乎不承重（方便快速迈步和截踢）。
- 双脚几乎平行，膝盖弯曲并向内收（保护腹股沟）。身体转动 30–45°。
- 躯干挺直，头略低，目光向前。进入方法：从正面站姿出发——重心移到后腿，前腿沿弧线向前。
- 银幕上“不正确”格斗者的错误：躯干摇摆、脚跟抬起、膝盖间距丢失。

**中线（一切的关键）：**
- 将身体平分的一条想象垂直线。保护自己的中线；攻击对手中线上的要害。
- 所有拳和肘都沿着这条线移动；从起点到目标，拳头绝不离开这条线。

## 步法

- **原地转身（yun ma）：**从正面站姿出发，转身 45° 或 90°；重心移到一条腿上，双脚保持平行并转动；双膝间距离不变。转身 = 离开攻击线 + 让击打获得冲力（不是后退！）。身体旋转让攻击“打入空处”，沿切线拨开攻击。
- **踏步并滑（基础）：**从脚跟到脚尖滑步，贴近地面。向前：前脚滑动 → 后脚跟上。向后／侧面：离移动方向最近的脚先动，另一只脚跟上。站姿不变。
- 躯干**不**摇晃、升高或下沉——头部始终沿同一高度移动（这是这种风格重要的视觉标志）。
- 步幅短而相等；移动时手位保持不变。
- 击打与踏步的时机：单拳——后脚跟上时出拳；两拳组合——第一拳配合前脚踏步，第二拳配合后脚跟进。

## 手部（防守位置与动作力学）

- **拍手（Pak Sau，拍掌）：**从外向内的张掌拨挡，手沿水平方向从身体中心朝对侧肩膀移动（不超出）。用于对付击向头／胸的直线攻击。
- **摊手（Tan Sau，摊开手）：**以手臂内侧拨挡，由内向外；前臂沿自身轴线旋转，掌心朝**上**打开，手肘在中线上、离身体 15 厘米。用于对付直击头部／上躯干的攻击。
- **膀手（Bong Sau，翼手）：**用前臂外侧拨挡；手臂上抬并沿自身轴线转动——手肘高于手，前臂形成独特的“弯翼”轮廓。手肘与肩膀紧密连接，不要抬肩，手腕在中线上。对付直击头／躯干的攻击——咏春最容易辨认的手势。
- **伏手（Fook Sau，覆盖／搭桥手）：**以手臂内侧由外向内格挡，然后通过弯曲的手腕控制对手手臂（“钩手”搭在上面）。手肘在中线平面内向前／向后弹动；压力始终向前，不向下。
- **耕手（Gan Sau，向下劈手）：**以外侧前臂边缘由内向外、向下拨挡／截停，掌心转向下方。用于对付中段和下段躯干的攻击。
- **枕手（Jum Sau，下沉手）：**用前臂外侧向下拨挡，停在太阳神经丛高度。用于对付打向身体的直拳 + 控制对手双臂。
- **标手（Biu Sau，穿指出手）：**伸直手肘，前臂旋转至掌心朝下，由内向外拨挡。用于对付直击头部的拳；同时也可将手指直刺眼睛（一个动作完成格挡和击打）。
- **圈手（Huen Sau，环手）：**手腕从内向外画小圈——绕过接触点、摆脱抓手腕；是不同手位之间的衔接动作。
- **护手（Wu Sau，保护手）：**竖直手掌位于中线胸前——备用，可随时抓握；双手护手并用时可格挡弧线攻击（包括踢头）。
- **按手（Gum Sau，压掌）：**用掌心向下施压（套路中会朝侧面、后方、前方移动）。
- **截手（Jut Sau，抖手）：**前臂短促向下抖动，停在太阳神经丛高度。
- **拉手（Lap Sau，抓拉手）：**抓住对手手腕 + 向下、朝自己拉，把对方拉到失衡。
- **双手配合规则：**一只手在高位工作时，另一只手在低位防守（反之亦然）；空闲手始终靠近身体、守在中线上。
- 手臂状态：外表柔软，内部“充实”；只有在格挡或击打最后阶段的几分之一秒内才绷紧。

## 击打

- **日字冲拳（Yat Chi Kuen，竖直直拳）**——本风格的主要出拳。拳头从胸口中央起步，严格沿中线打到下巴高度；以最下方三根指节的根部接触（小指／无名指／中指）。手臂全程放松，只在最后几分之一秒爆发绷紧；手肘完全伸直。连环拳：右—左不停顿，一拳替代另一拳（一只手收回时另一只手打出）。
- **正掌根击（Yan Jeung）**与**向前上方的掌根击（Wun Jeung）**，套路中也有**护掌（Wu Jeung）**——掌击“穿入”目标，用于伤及内脏；常常用同一只手在格挡后立即接掌击。
- **指刺（标）**——刺向眼睛或喉咙；最快的武器，常用于截击。
- **反手拳**——打向太阳穴／头部，通常接在拉手（拉动手臂）之后，或在控制对手手臂时使用。
- 击打动能：从脚开始，身体旋转 → 髋 → 下背 → 肩 → 经由手释放；原地转身可增强击打。
- 击打要“穿过”目标：注意力落在表面后方数厘米处的某个点。
- 偏好的出击时机：迎着对手的移动出击——对手被拉拽后，头部向前移动时。

## 腿部

- 第一阶段中，腿主要负责移动。踢击少见：**踢膝盖和腹股沟**，以及绊倒、扫腿、踢开双腿——全部在低位，不踢高腿。
- 不承重的前腿 = 截停和预先截击的工具，也可格挡低位腿部攻击。
- 防守踢向头部的回旋踢：转身 + 双手抬起做护手，然后立即向内踏步并击打肝脏。

## 黏着接触（黐手）

- 核心：双手“黏”在对手的手臂上；持续的切线接触能**不靠视觉**读取攻击的时机和方向——做出即时反射。
- **单黐手（Dan Chi Sau，一只手）：**基本循环——一只手在上方用伏手控制，另一只手在下方用摊手；掌击 → 向下拨挡 → 反击拳 → 上升到膀手。攻防交替的传送带式动作，全程不断开接触。
- **盘手（Poon Sau，“滚手”，双手）：**搭档以圆圈滚动前臂；一人双臂做伏手，另一人做膀手 + 摊手，手位滚动（膀↔摊），接触不变。带领者设定速度，另一方跟随。
- **关键戏剧节拍：**接触断开或压力消失 = 立即击向打开的区域（胸、眼）。“感觉到了空处——手自己就打了出去。”
- 控制对手中线是所有接触的目标。不使用多余力量：顺着压力走，保持触碰。
- **拉手（对练场景循环）：**手腕接触 → 抓住手臂 + 另一只手同时打直拳 → 防守者用膀手化解 → 反过来抓住手腕、向下拉并出拳 → 再用膀手……无尽滚动的“风车”——抓—拉—拳—翼，适合动态中景。

## 小念头——训练场景用

- “小小意念套路”。从头到尾**在正面站姿中完全静止**演练，双脚不动——只有双臂移动。目视前方，鼻子呼吸，每次击打时呼气。
- 节奏：缓慢、令人专注得如同催眠（特别是前三分之一）；只有在动作终点一闪而过地绷紧。进阶变化——单腿站立，抬起的大腿与地面平行。
- 三段：1）摊手 + 伏手；2）按手 + 标手；3）摊／耕／膀手。
- 镜头动作骨架：
  1. 开始：双脚并拢 → 双拳收到胸口 → 屈膝 → 脚尖分开 → 脚跟分开（进入站姿）。
  2. 双臂在低位交叉（左臂在右臂上方）→ 抬起 → 双拳收到腋下。
  3. 左手慢打日字冲拳，沿中线向下 → 张掌向上 → 圈手（转腕）→ 握拳 → 收回胸前。右手重复。
  4. 核心动作（最慢）：摊手向前 → 圈手 → 护手 → 伏手收到胸前 → 再向前——每只手**三次**；手肘沿中线缓缓移动，停在离身体 15 厘米处。
  5. 拍手朝对侧肩膀移动 → Yan Jeung 掌击沿中线向下 → 圈手 → 收回。
  6. 按手向侧面、向下、绕到背后、再向前；双臂向两侧张开 → 双手同时摊手 → 向下截手 → 双手标手向前、向上。
  7. 护掌击，摊→耕→摊→圈→Wun Jeung 组合，膀手→摊手→Yan Jeung（每只手都做）。
  8. 结束：双手同时耕手 → 两次连环日字冲拳（左—右）→ 圈手 → 收回 → 收脚、双手放下、呼气。

## 原则公式（供编舞者笔记使用）

1. **不用力对抗力量：**拨开／顺势让攻击掠过，而不是僵硬地挡住；用踏步或转身离开攻击线。
2. **中线：**攻击对手中线，护住自己的中线；最短的直线始终胜过弧线。
3. **同时性（lin siu dai da）：**格挡与反击是**一个**动作阶段，中间没有停顿；格挡手本身就可以是击打（标手 = 刺眼）。
4. **整身发力：**脚 → 髋 → 下背 → 肩 → 手；身体转动增加击打力量。
5. **经济性：**动作短促，不蓄势，出拳前不把手拉回；接触之前放松，最后一瞬间爆发。
6. **控制对手的手臂：**抓住／压住一只手臂，同时控制另一只手（将手臂往对手中线拉，会使他的肩膀转向你）；在对方双臂都被“绑住”时打出最后一击。
7. **先用假第一击：**第一击看起来完全真实 → 对手反应并格挡 → 立即打入暴露的区域。
8. **外侧：**闪避击打时，移到攻击手臂的**外侧**——从这里，对手没有其他部位可以继续攻击。
9. **四个防守区域：**身体分成左上／右上／左下／右下；上方区域由拍／摊／膀／标／护手防守，下方区域由耕／枕手防守；一只手在上，另一只手就必须防下方。
10. **80% 用手：**近身格斗；腿负责踏步，偶尔低踢膝盖／腹股沟，以及绊腿。
