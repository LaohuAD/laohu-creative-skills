# 咏春基本技术，第2部分（Wing Chun Basic Techniques part 2；9:36）

**核心内容：**咏春基础的第二部分：剩余格挡（护手 Wu Sau、伏手 Fook Sau、拍手 Pak Sau、枕手 Jum Sau、耕手 Gan Sau、膀手 Bong Sau）、低踢、架势和步法（滑步／绕圈步）、沙袋训练，以及第一套拳“小念头”（Siu Lim Tau）。这是用于打戏编排的一本完整咏春防守“词典”。

**按时间码排列的技术**
- 0:00–0:43 — 护手（Wu Sau，检查格挡）：用手掌或掌缘格挡；手在胸前以“祈祷”姿势收尾；这是后手辅助防守，当拳穿过前手防线时使用；用手缘向外格挡，或用掌心向内格挡。
- 0:50–1:20 — 伏手（Fook Sau，弯腕格挡）：以前臂内侧格挡；最后肘部保持固定（离中线一拳距离）；是黏手（Chi Sau）的关键元素。
- 1:21–1:40 — 拍手（Pak Sau，交叉掌格挡）：用掌根拍挡并配合手腕弹击；经常与出拳组合（拍手＋出拳在同一拍内完成）。
- 1:41–2:10 — 枕手（Jum Sau，内侧下压格挡）：以掌缘／前臂斜向下砍；动作幅度很小——肘部留在中线；身体旋转会增加效果。
- 2:11–2:40 — 耕手（Gan Sau，下斜格挡）：以向下的前臂动作防守腹股沟／低位攻击与踢击；利用肘部转动＋重心转移；通常用来对付踢击。
- 2:41–3:05 — 膀手（Bong Sau，翼形格挡）：一种“非传统”格挡——唯一偏离固定肘位置的格挡；像翼一样滚转：前臂做滚动动作（前臂是格挡面），必须配合躯干旋转。
- 3:06–4:40 — 腿部攻击：踢击用于“骚扰”对手或缩短距离，始终配合手部攻击；动作快、低、直接——目标是腹股沟、膝盖、胫骨。正面脚跟踢——由地面直接起踢，膝盖弹击，踢击高度不超过躯干。交叉踩踏踢——用脚底踢，破坏对手平衡后用手收尾。低位侧踢——以脚跟／脚底踩踢。组合：交叉踩踏 → 对方躲开踩踏时侧踢躯干；正踢 → 扫腿／绊摔（对方格挡后借用其力量——顺着格挡方向跟进）。
- 4:42–5:40 — 架势：基本架势——肩宽或略宽，膝盖微弯；身体像“盘绕蓄力”——压缩的弹簧，兼顾稳定性和机动性。滑步：向前——前脚迈约15 cm，后脚跟上；向后——反向移动；向前由后脚推进，向后则以前脚推进。
- 5:42–6:06 — 绕圈步：左右架势切换；后脚沿弧线向前滑动；用于封住角度，并给正在后退的对手施压。
- 6:06–6:48 — 靠墙沙袋训练：用拳和手掌击打墙上沙袋；练习“力量穿透感”、强化皮肤和骨骼；要慢慢练、循序渐进。
- 6:49–9:30 — 小念头（Siu Lim Tau，“小小的想法套路”）：咏春只有三套拳，包含这个流派的全部理论和技术。第一套包含几乎所有基础元素（架势、转身、格挡、出拳、指击）和原则（中线、肘部、四门）。从静止架势开始慢练——训练身体左右两侧的手部协调。练习方法：先学理论 → 单独练习各个动作 → 组合动作 → 分段练套路 → 与师傅一起一气呵成、不间断地打完整套拳。
- 9:34 — 标题：“小念头（套路分解）”——分解套路（下集继续）。

**咏春编排用视觉细节**
- 护手看起来像下巴前的一面“掌盾”——咏春架势里辨识度很高的后手剪影；前手问手（man sau）＋后手护手（wu sau）就是基础防守架。
- 所有格挡都很短，肘部几乎不动；整个动作的“距离”来自身体旋转；镜头上看起来是极小的前臂弹动加躯干转身。
- 膀手最有电影感：肘部抬起，前臂翻转着把攻击手臂向外拨——这是衔接捋手／黏手的经典“桥”。
- 腿部动作：所有踢击都在腰线以下，从架势中直接起脚，不做蓄势；踩踏膝盖／胫骨会打断手部组合的节奏；踢击始终与手部相连（同一拍内踢＋出拳）。
- 步法：短促滑步（约15 cm）——练习者“顶进去”接近对手；绕圈步——用弧形架势变化封住后退路线。
- 以书法为背景演练小念头：单手缓慢、催眠般移动，躯干不动——是“冥想式”训练场景的理想参考。
- 搭档练习：攻击者穿白衣，师傅穿黑衣；前臂交叉，接触始终不断。

**引述**
- “Wu Sau 是后手防守手；当对手的拳穿过你的前手防线时，它就会发挥作用。”
- “咏春踢击……始终辅助双手：动作快速、低位，直接踢向腹股沟、膝盖或胫骨。”
- “你应该盘绕蓄势，准备向正在进攻或撤退的对手爆发。”
- “膀手很特别，因为它偏离了固定肘的位置……必须配合躯干旋转。”
