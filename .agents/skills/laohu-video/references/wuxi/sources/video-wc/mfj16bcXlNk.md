# 咏春初学者，第6部分：咏春基本技术——标手（Biu Sao）（Wing Chun For Beginners Part 6: Basic Wing Chun Techniques - Biu Sao；9:37）

自动生成的文字稿噪音很大（biu sao 被识别成“biu／buzhi／Pugh saw”，bong sao 被识别成“pong so”）。

**核心内容：**标手／标指（biu sao／biu jee，“射出的手指”／矛形手）来自第三套拳《标指》；它是传统上不传给外人的“关门”技术。用手指戳眼睛／喉咙：比拳头快，伸得远几英寸，可走直线，也可绕过格挡打弧线；对于正在“落下风”或体型较小的格斗者，它是主要武器。

**按时间码排列的技术**
- 0:00–0:15 — 预告：一连串快速指插，介绍为“咏春中最致命、最隐蔽的技术之一”。
- 0:46–1:11 — 背景：标手来自第三套拳《标指》（Biu Jee）；这是传给高级内门学生的“关门”技术。
- 1:11–1:30 — 比喻：“矛式指戳”，像矛一样的手指；这是“蛇”（蛇／眼镜蛇）式的隐蔽技术。
- 1:32–2:03 — 轨迹：咏春普通技术是直线，标手可以走直线，也可以划弧线；对镜头演示直线、向内弧线、向外弧线。
- 2:06–2:37 — 选择角度：如果对方手臂封住直线，就从上方／侧面斜向切入，“像一支矛”（慢速张手演示，搭档没有戴护目镜）。
- 2:37–3:09 — 如果格挡在另一侧，标手就绕着手臂划弧线；“这不是拳头，是手指——它让我多出几英寸距离”。
- 3:13–3:26 — 进阶层次：不要绕过去，而是直接从上方越过，通过空隙出手——一个动作就能“把他向后打昏”。
- 3:30–4:14 — 连续标手：第一记被挡住 → 从另一个角度打出第二记 → 第三记；像蛇一样连续改变角度，动作一波接一波，目标始终是眼睛和喉咙。
- 4:15–4:45 — 战略作用：第二套和第三套拳（《寻桥》《标指》）用于你**正在落下风**的时候。连接上一课的膀手：受惊时本能防守 → 立即向上盲目标手。
- 4:49–5:18 — 利用“盲点”：视觉容易捕捉大幅移动，却不容易看见沿中线刺来的细矛；运用敏感度快速连续出标手。
- 5:25–6:24 — 标手也可作为防守式拦截（感受这边／那边、内侧和外侧线路）；其理念是：“咏春没有被动动作——我就是一直打、一直打、一直打”；把障碍拨离线路，继续击打。
- 6:33–7:13 — 感觉空隙：有空隙就打；有东西挡路就把它拨开再打；“一直打，直到他不再动”；咏春被称为“暗杀术”。
- 7:18–7:56 — 体型较小者对付体型较大者：既然有一记出乎拳击手意料、直击喉咙的矛刺，为什么还要跟他互换拳头？接着演示一系列出乎意料的攻击角度。
- 7:59–8:20 — 训练安全：与搭档练习时，双方只能戴防碎护目镜；实际发生过眼部受伤的案例。

**咏春编排用视觉细节**
- 矛形手：手指伸直、绷紧，像矛头一样朝眼睛高度快速刺出；在搭档脸前几厘米处停住——搭档躯干向后仰。
- 镜头中的轨迹：沿中线直刺＋用S形弧线从格挡手臂的内侧／外侧绕过——能清楚看出“蛇形”手部动作。
- 连续攻击：连续2–3记标手并改变角度（上方 → 侧面 → 上方），每次都从前一记被偏转的位置继续出手——像波浪一样，不把手收回身体。
- 距离：贴近、前臂接触；标手比拳头多出几英寸距离——不用切入也能打到对方。
- 架势／节奏：躯干几乎不动，双脚留在原地；动态都在双手；慢速时动作“丝滑”，实战速度下则是弹射般爆发。
- 同系列的场景：明亮阁楼（Dan 的总部），全景窗户俯瞰港湾和城市，两人都穿黑色T恤。
