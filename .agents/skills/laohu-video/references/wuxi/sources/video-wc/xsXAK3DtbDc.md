# 咏春初学者，第2部分：咏春基本格挡——摊手（Tan Sao）（Wing Chun For Beginners Part 2: Basic Wing Chun Block - Tan Sao；11:32）

**核心内容：**详细拆解摊手（tan sao，“摊开之手”）——咏春应对勾拳／偷袭拳的基础“格挡”。重点：摊手**不是**被动格挡，而是沿中线向前进攻的身体结构；动作都从肘部发起，不是手部；肩膀要完全放松。ASR 文字稿里把“Yip Man”写成了“He-Man”。

**按时间码排列的技术**
- 00:43–01:05 — 背景：摊手用来对付勾拳／偷袭拳（“最常见的攻击之一”）；搭档从侧面挥拳，Dan 用手掩护。
- 01:14–02:10 — 从架势开始练摊手机制：掌心旋转向上（“像托着盘子”），手臂不是向侧面移动，而是向**中线**移动；注意力放在肘部，不是手（“专注看手的人是外行”）；肘部向内驱动，朝中线移动；手臂放松，“不紧张，也不松垮”。
- 02:08–02:25 — 画面：Dan 缓慢沿中线伸出摊手，展示前臂如何覆盖中线。
- 02:25–03:20 — 身体结构错误：如果摊手向侧面／外侧移动（肘部向外漏），搭档一推就能带动整个身体；正确结构（肘部内收）则能让躯干不被推走。画面：Shin 推前臂，Dan 扎根站稳。
- 03:05–03:15 — “正确的摊手是攻击，不是防守”：手臂向前推，搭档感到胸口受到压力。
- 03:28–04:00 — 手指：手指不要“松懈”；手像托盘，拇指**收进来**（否则没打中目标时手指会受伤）；手像“矛”。
- 04:07–04:25 — 角度：前臂约45°，肘部与躯干的距离如同“肋骨下的一只拳头”；这是身体结构的固定距离。
- 04:35–05:10 — 压力测试：肘部／手部角度稍微调整，稳定性就会立刻改变（“只是这么一点点，已经会有差别”）；画面：Shin 推击，Dan 只调整几厘米的角度。
- 05:13–05:40 — Yip Man 曾经极慢地练摊手，一练就是一小时——像冥想（与小念头的训练类似）。
- 05:41–06:35 — 逐节放松：先放松手指，再放松前臂、肩膀、髋部、躯干——“像竹子一样：有弹性，但不紧绷”；肩膀紧张时，即使手形正确，身体结构也会垮掉。
- 06:50–07:20 — 指导 Shin：“放松手指，注意肘部，放开肩膀”——一层一层调整动作。
- 07:26–08:40 — 应对直拳：摊手穿过攻击者手臂，同时施加反向压力；如果只是“防守性地”举起手，就会被突破。时机：太晚就会挨打，太早就接触不到；把对方前臂想成一条需要**横跨**并切穿的“横木”。
- 08:42–08:55 — 搭档全力出拳（“尽你最大力气”）——摊手保持放松，不因冲击而退缩。
- 09:10–09:40 — 两种变化：经典掌心向上的摊手，以及“翻转”后盖住对方的变化；Dan 更喜欢直接的版本——手已经蓄势，可以继续打向脸部（“直接性”）。
- 09:41–10:10 — 双人练习：一人打直拳，另一人用摊手迎击，然后换边；“试试不同角度，自己感觉。”
- 10:20–11:10 — “抛硬币”：从摊手位置不蓄势，直接做收尾拍击／打击——手像抛硬币一样弹出去，不是推；“只用手指……力量却很足”。画面：从接触位置迅速拍击。

**咏春编排用视觉细节**
- 架势：正面、窄幅，膝盖向内；双方几乎胸口相贴——肘部距离，比拳击距离更近。
- 黏手接触：前臂对前臂接触，通过推击测试压力——身体不会后退；由身体结构承受冲击，而不是肌肉。
- 肘部带出动作：肘部朝中线**向内、向前**滑动；手像托盘，拇指收进来。
- 实战中，摊手看起来像“楔入”打来的拳头，同时另一只手回应（格挡＝攻击，一个节拍，而非两个）。
- 节奏：极慢、冥想式的教学；应用时，则是毫无蓄势、短促爆发的一击（从接触位置像抛硬币一样弹出的拍击）。
- 屏幕对照中的错误版本：肘部向外漏，手臂向侧面移动，身体被推得失去平衡——适合呈现“受害者”。

**引述**
- “始终专注肘部。”
- “这是攻击，不是防守。”
- “像竹子一样——放松，却有韧性。”
- “像抛硬币一样。”——从摊手位置直接击打，不做蓄势动作。
