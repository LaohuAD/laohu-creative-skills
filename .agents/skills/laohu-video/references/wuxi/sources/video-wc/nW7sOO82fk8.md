# 咏春基本技术，第3部分：中国格斗艺术（Wing Chun Basic Techniques part 3 Chinese Fight Art；7:13）

**核心内容：**把第一套拳小念头的动作解读成实战应用：套路里的每个手势都对应格挡、绕圈、拉拽或击打。然后介绍黏手（Chi Sau）——为什么需要前臂敏感度，以及单黏手（Dan Sau）循环如何运作。这是编排咏春动作时掌握“黏手”语言的核心资料。

**按时间码排列的技术**
- 0:07–0:30 — 摊手（Tan Sau）的实战应用：前臂末端快速拧转，使格挡更有力；始终配合同时出拳（tan da）。
- 0:31–0:52 — 圆手（Huen Sau，绕圈掌）：格挡后绕过对手手臂；一只手同时格挡和进攻；绕圈之后自然接掌击。
- 0:53–1:10 — 拍手（Pak Sau，掌击）：用手掌拍挡防守上门；最好结合闪头／躲身（闪避＋拍手）。
- 1:11–1:40 — 向下拍掌格挡：应对下门攻击、踢击和膝击；变化版——挣脱对手试图施加的肘锁。
- 1:40–1:55 — 肩膀＋前臂耸动：肩部和前臂一同“耸起”，把攻击者甩开（来自套路中的释式动作）。
- 1:56–2:15 — 双手向后掌击：双手同时向后拍击——主要用于防守从后方抱住身体的熊抱；随后接摔法。
- 2:16–2:35 — 双手刀手：用两侧掌缘同时做手刀劈击；主要目标是喉咙。
- 2:36–3:12 — 掌部牵拉格挡：以掌格挡并拉拽——同一只手既格挡，又把对手猛拉过来，让他撞上反击。
- 3:12–3:45 — 高位手腕格挡 → 单手低位掌格挡：演示“拳可以立刻变成格挡，格挡也可以变成拳”（同一肢体动作不间断）。
- 3:42–4:03 — 耕手（Gan Sau，低位格挡）的实战应用：防守下门＋另一只手同时用刀手击打。
- 4:04–4:30 — 膀手（Bong Sau）→ 双掌推：做完翼形手后，以双掌推击，对手向后飞。
- 4:30–5:10 — 掌部牵拉后向喉部掌击——挣脱对手抓握；套路中的交替指击另有一种用途：挣脱抓握后立即击打。
- 5:11–5:45 — 黏手（Chi Sau）：“黏手”练习：两人练习手部协调（一人格挡，另一人击打）和强烈的前臂敏感度；训练本能地判断对手发力的方向，并以最小动作转移力量。
- 5:45–7:12 — 单黏手（Dan Sau）：基础循环。搭档A：摊手 → 低位掌击 → 膀手。搭档B：枕手（Jum Sau）→ 直拳 → 伏手（Fook Sau）。搭档B的伏手“搭在”搭档A的摊手上；摊手转成低位掌击，由枕手接住；圆手／摊手转成膀手，应对搭档B的直拳。双方根据彼此技术循环，以“有力却放松的力量流动”互相应对。片尾标题：盘手（Poon Sau，滚动黏手）——下集继续。

**咏春编排用视觉细节**
- 黏手是咏春的标志：两名练习者面对面，前臂黏在一起，双手如波浪般滚动（摊手—膀手—伏手），躯干几乎不动——像是在“用手交谈”。
- 本部分全程都是贴身距离：肘对肘；套路里的每个动作先单独慢速示范，再由搭档迅速演示——适合采用“套路 → 应用”的剪辑模式。
- 一只手＝两种动作：格挡直接连成绕圈（圆手）、拉拽（牵拉）或击打，不把手抽回来——编排时看起来像手臂连续旋转。
- 掌部牵拉：把对手手臂拉向自己 → 接拦截式掌击——形成醒目的“拉过来并迎面打中”节拍。
- 从背后抓握的防御（双手向后掌击＋摔法）——是对付抱缠者的现成舞台动作节拍。
- 双人节奏：攻击和回应发生在同一拍；没有“击打—停顿—再击打”的来回。
