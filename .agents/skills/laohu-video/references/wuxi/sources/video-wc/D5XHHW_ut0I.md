# 咏春初学者，第5部分：咏春基本技术——护手（Wu Sao）（Wing Chun For Beginners Part 5: Basic Wing Chun Techniques - Wu Sao；7:21）

**距离条件：**整节课的距离都在一臂之内。

**核心内容：**护手（Wu Sao，護手，“保护手”）——在自己与对手之间、位于中线上的竖直张掌，掌心朝向对手脸／喉部。关键点：力量来自**肘部**，不是手指；手指并拢，拇指收进掌内。手掌角度正确时，架势无需绷紧就会“结实”。护手不只用于防守：手掌握拳并伸展肘部，就能立刻转成击打。

## 按时间码排列的技术
- 0:06–0:24 — 开场：Wu Sao＝护手；突然遇袭时，是“放在你和对手之间的东西”。
- 0:44–1:03 — 手型：手掌放在搭档脸／喉前；重点放在肘部，不是手指——“想象把你的肘部直接推入他的身体。”
- 1:08–1:26 — 用连环直拳检验：故意做错的护手是“软的，什么都挡不住”；正确的护手放在对手面前，“很难被穿透”，并能遮挡躯干的大部分区域。
- 1:30–1:59 — 手指错误：“手指别松懈”——手指不要张开，拇指收进掌内；手指露出来会被折断／抓住（演示：搭档抓住露出的手指，说“这样不行”）。
- 2:00–2:32 — 手掌角度：要倾斜，不要“平平地朝上”；搭档测试后发现，角度正确时同一格挡会感觉“更结实”，动作机制“扎实得多”；“差一点点，动作机制就不一样。”
- 2:49–3:10 — “意念／劲”（原文此处的英语说法含混，注为中文词，约指 jin／neijin）：不是蛮力，而是稍微“充实”一下——然后护手就能“穿过”攻击。
- 3:11–3:38 — 进攻版本：“这不只是防守”；把张开的手掌握成拳头＋稍微伸展肘部＝击打；格挡转成出拳时无需重设姿势。
- 3:47–3:54 — 入身：缓慢向前伸出护手；接触后“我可以直接从这里切进去”——从接触线路切入并击打。
- 3:56–4:50 — 应对连环直拳：搭档以实战速度打连环拳；一只手在他脸前做护手，封住他的进攻线路——“不容易”穿透；用单手做极小幅度动作，偏转这一组出拳。
- 4:51–5:03 — 双手：护手＋另一只手＝“现在你就相当安全了”（不包括踢击）。
- 5:05–5:31 — 口诀：“中线、肘部、推”；侧面观察：肘部不能伸得太外（会挨打），也不能太低（会被向下拉），要处在“紧密”的位置。
- 5:36–6:13 — 身体结构与力量：“不是力量，是我的动作机制，角度正确”；感受对手压力中的小“窗口”，立刻切入：“只要一点点……然后你就能进去。”
- 6:16–6:49 — 结尾：慢慢练习，找一位教练；衔接到李小龙／截拳道。
- 7:18 — “朋友，像水一样。”

## 咏春编排用视觉细节
- 架势：两名练习者几乎正面对站，双脚与肩同宽，站着不动——所有动作都在手上；距离约一条弯曲手臂长，前臂几乎一直接触。
- 护手手臂：前臂竖直放在中线上，张开的手掌倾向对方面部，手指并拢向上、拇指收进掌内；肘部下沉并朝胸口中央内收。
- 黏手接触：护手掌／前臂贴在搭档出拳的手臂上，并“引导”它；连环直拳通过单手极小的变化化解，无需后退。
- 格挡→击打切换：逐帧呈现——对着对方脸部的张掌握成拳头，肘部伸展完成攻击；没有蓄势，读起来像一个节拍（适合拍手部特写的咏春标志性瞬间）。
- 错误动作作为初学者戏剧化呈现：手指张开（对手抓住并弯折手指——一个小幅关节锁节拍）；手掌平放时会被击打“压垮”。
- 节奏：慢速解释手位 ↔ 爆发式连打1–2秒；声音是手掌拍前臂的清脆声响（文字稿中的“拍击声”）——这是咏春有代表性的音效设计。
