# 咏春初学者，第3部分：咏春基本技术——膀手（Bong Sao）（Wing Chun For Beginners Part 3: Basic Wing Chun Techniques - Bong Sao；10:48）

**核心内容：**拆解膀手（bong sao，“翼手”）的动作机制——咏春最容易辨认的防守动作。重点：膀手**不是**像“鸡翅膀”那样把肘部向上拍动，而是维持固定角度，肘部留在原位，意图朝前指向对手。膀手被介绍为“最后一道防线”——攻击来得太晚、已经快打中时的反射性防守，而不是首选技术。

**按时间码排列的技术**
- 0:52–1:09 — 典型错误：从肘部发力做膀手，像鸡翅膀一样向上拍动（常见于电影里摊手之后接膀手的动作）。
- 1:14–1:37 — 正确机制：肘部几乎不动，手指始终“碰到一面看不见的墙”；前臂围绕稳定的肘部旋转。
- 1:40–2:30 — 搭档施压测试：手太近／太远，或肘部过高时，对方施压（向下推／转动）就会压垮身体结构，让练习者失去平衡。
- 2:32–2:50 — 检查要点：肩部下沉，手指朝向对方喉咙（摊手也一样）——“力量朝前”。
- 2:53–3:24 — 中线：肘部不能越过中线（否则身体侧面会暴露），但也不能停在中线前（否则胸部会露出来）。角度约45°，手指朝向对手。
- 3:24–4:03 — 摊手 → 膀手转换，侧面镜头；正确的膀手有“弹簧般的力量”：持续向前施压，而不是僵硬地顶住。
- 4:05–4:57 — 批评“膀手＋捋手”应对直拳的组合：电影里看起来不错，但用三个动作对付一记拳太慢。个人更喜欢先用拍手／捋手防守。
- 5:00–6:19 — 起源：膀手是身体受到物体飞向脸部时，自然受惊闪避动作的“精细化”形式；它是最后手段，供处于下风的格斗者防守。
- 6:52–7:53 — 关键细节：力量意图放在**肘部**，肘部“推入”对手——膀手就变成带有进攻性的动作，几乎是在攻击，而不是被动盾牌。
- 7:55–8:44 — 应对肘部向外张开／摊平：只能通过接触感受来检查动作是否正确（与教练／搭档练黏手）。
- 8:46–9:43 — 在持续接触中纠正搭档：“抬太高了”、“偏得太外了”、“太高了”；完全凭触觉找到空隙——“他没告诉我，都是敏感度在起作用”。
- 9:44–10:20 — 练习方法：反复慢练摊手 → 膀手，对着镜子练很多次；“看起来简单，实际上不简单”。

**咏春编排用视觉细节**
- 架势：两人正面相对，站幅窄，膝盖放松；所有手部动作在上方，脚几乎不动——像“用手交谈”。
- 距离：始终有肘部接触，两人相隔一条前臂；用**压力**检查动作，不用出拳——身体结构不正确时，躯干会被压力带着摇晃（很好用的节拍标记：“身体结构垮掉 → 躯干塌下去”）。
- 黏手接触：不用说话就能纠正——Sifu 按压手臂，学生调整角度；一出现空隙，就立即轻拍胸部／喉部。
- 镜头中的几何关系：肘部作为固定支点，手沿弧线移动；矛形手指指向喉咙；前臂角度45°；肩部始终下沉。
- 节奏：演示慢而延展（按压／滑动），爆发动作很短——“砰，空隙出现”只要一个节拍。
- 场景：明亮阁楼工作室，全景港湾窗户（背景可见游轮）；两人穿黑色T恤，手臂轮廓在明亮背景前很清晰。

**引述**
- “看我的肘部。它几乎一直在同一个位置……我只是在碰那面墙，距离不变。”
- “这只是比较难看的膀手形式”——谈自然受惊反射。
- “这就是你的膀手，朋友。这是最后手段。”
- “这不只是被动防守——我是在把肘部推向你。”
- “等我看见的时候……已经太慢了。你要去感觉，一切都是触觉反射。”
- “生活中最简单的事情，有时却最难掌握。”
