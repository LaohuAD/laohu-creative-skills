# 咏春初学者，第4部分：咏春基本技术——耕手（Guan Sao）（Wing Chun For Beginners Part 4: Basic Wing Chun Techniques - Guan Sao；6:35）

**核心内容：**耕手（Guan Sao）——咏春用于防守上勾拳、身体拳和低踢的低位“格挡”。重点：它既不是空手道式的劈砍格挡，也不是“接住”击打，而是让手臂从肘部沿中线向下**下沉**（“把手朝口袋放下”）＋转移对方力量，不与力量相撞。耕手之后立刻接一拳——基础练习“耕手 → 出拳”。

**按时间码排列的技术**
- 00:00–00:06 — 冷开场：搭档练习中快速连续打出一组连环拳（快速拳击齐发）。
- 00:29–00:45 — 背景：摊手和膀手防守上方角度；耕手用来对付上勾拳和低位攻击；所有内容都来自小念头套路（“小小的想法”）。
- 00:51–01:10 — 错误示范：不要“像劈砍一样”移动，也不要做大幅度的空手道扫挡。
- 01:13–01:28 — 动作机制：手臂从当前姿势直接**向下走**；动作不是从手掌或手腕发起，而是由**肘部**带动；想象“几乎碰到我的口袋”。画面：前臂缓慢地沿身体向下、向内移动。
- 01:28–01:32 — 对付出拳和踢击都有效。
- 01:34–02:06 — 常见错误：向侧面大幅格挡会留下很大空档，也可能挡空；正确做法——“我不是要接住这拳，我只是把手**放下来**”（下沉，而不是接住），放下手后更容易立即进攻。画面：Shin 打 Dan 的腹部，Dan 短暂地把拳向下压开。
- 02:06–02:20 — 左右两侧：手本来就在中线，只要镜像重复同样的下沉动作；耕手之后立即反击出拳。
- 02:30–03:00 — 力量测试：搭档逐渐加重出拳力量——“我没有用力，只是把一个障碍放在他面前”（身体动作机制、结构、完全放松）。
- 03:00–03:40 — 对付踢击：Shin 出正踢，Dan 用耕手把踢击“切”向下方；慢速演示：力量向内传递——不要迎面撞上去（会造成受伤），而要把力量向下、向侧面**转移**。画面约185–195秒：搭档抬腿，Dan 用前臂把胫骨扫下去。
- 03:45–04:15 — 动作幅度：肘部下沉，手臂做一个“大的扫动”，同时覆盖较大区域——上面是脸、下面是腹部；不要夸张到把手放得太低。
- 04:15–05:00 — 真正的打斗“一片模糊”：你无法分清拳头和手掌；高位用膀手防守，低位用耕手；覆盖身体较大区域，因此即使时机不完美也能容错；“就算我的时机不准，我还是能挡住一些东西”；刀具另当别论，这里只讲徒手。
- 05:17–05:31 — 训练：耕手 → 出拳、耕手 → 出拳（循环交替双手，一只手下沉，另一只手出拳）。
- 05:31–05:55 — 自由出拳练习：自由组合拳和下沉动作，“我只用三分之一的力量，让动作保持流动”。画面：双手持续滚动接触。
- 06:25–06:33 — 结尾：“朋友，像水一样。”

**咏春编排用视觉细节**
- 耕手：肘部带动，沿身体做短促的**向下**前臂动作，手最后停在髋部／口袋旁；没有大幅度蓄势动作。
- 对付踢击时，看起来像以前臂把胫骨向下、向侧面“切”开；躯干保持直立，距离不变。
- 防守和出拳在一个节拍内完成：一只手向下沉，另一只手同时／紧接着沿直线打向脸部。
- 连环拳：连续打出短促垂直拳，中间不停顿（00:00开场画面）；肘部下沉，拳头沿中线滚动。
- 训练节奏：连续“下沉—出拳—下沉—出拳”，全身放松，使用三分之一的力量；实战中则是一次爆发式下沉＋回应。
- 用于对比的错误动作：“受害者”向侧面大幅劈砍式格挡，身体门户打开，最后格挡落空。

**引述**
- “不是从我的手掌，也不是手腕——而是肘部。”——动作由肘部发起。
- “我不是想接住它，只是把手放下去。”——不是接住击打，而是让手臂下沉。
- “转移力量，不要跟力量对抗。”
- “真正的打斗是一片模糊。”——真实打斗模糊不清；技术必须覆盖一个区域。
