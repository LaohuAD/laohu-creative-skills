# 李小龙截拳道黏手技术——捋手（Lap Sao）训练（Bruce Lee's Jeet Kune Do Trapping Techniques - Lap Sao Drill；2:44）

**核心内容：**两人短时练习捋手敏感度（手部触觉敏感度）：在持续接触中循环滚动手臂，并可在任意一个“拍点”突然拉拽＋击打。目标是消除思考——“感觉到什么，就动起来”（感到压力，就作出反应）。

**按时间码排列的技术**
- 00:02–00:19 — 开场：承诺会展示技术、训练方法和敏感度训练。画面：Dan 独自站在围栏旁，双手保持滚动姿势。
- 00:21–00:31 — 训练起始姿势：两人相对而站，“双脚并拢”（双脚并拢，保持中性站姿——动作都由手臂和躯干完成）。前臂在中线接触。
- 00:31–00:46 — 基础循环：两人滚动手臂（rolling，类似 lok sao／chi sao 的模式），练习“只是这个角度”——拉拽角度。可听到“砰、砰”的节奏——击打／拉拽像节拍器一样规律。
- 00:46–00:57 — 训练关键点：可以在**任意一个**节拍发出拉拽——“第一下、第二下、第三下……然后才做完整动作”。先“慢下来”，再做全幅度动作。
- 01:02–01:15 — 演示：“就在这里拉——这就是一次击打。”拉拽和击打是同一个动作。数“一、二——啪——三、四”：双方在循环中互换角色，剥离对方手臂看起来像突然打破稳定节奏。
- 01:23–01:35 — 训练理念：重复数千次来消除思考——“感觉到什么，就动起来”。这是触觉反应，不是视觉反应。
- 01:35–01:50 — 根据压力动作：“我给他压力——你就动。如果我不给你压力——……”如果对手没有推压，手就直接向前（沿开放线路打击）；如果对手推压，就把压力转化成捋手。
- 01:50–01:59 — “不要思考”：不要走“他推我 → 我想一下 → 我再动手”这条思考链。由双手直接作出判断。
- 01:59–02:12 — 细节：如果已经有空档，就不要增加多余动作——直接打直拳。演示两种不同接触角度下的捋手变化（“这也是捋手……这里也是捋手”）。
- 02:12–02:20 — 结尾：“练习，好好练习，经常练习。”

**编排用视觉细节**
- 距离：很近的黏手距离；整个训练过程中前臂交叉并持续接触。
- 架势：中性站姿，双脚几乎并拢，躯干直立——这是刻意搭建的“实验室”情境，戏剧性都集中在手上。
- 动作模式：前臂持续绕圈滚动（像波浪般、催眠般）→ 突然打破节奏：向下拉拽＋另一手从上方出拳。
- 节奏：稳定循环约每秒一拍；在不可预测的某一拍突然爆发——非常适合营造“冥想 → 闪击”的电影反差。
- 拉拽距离短（15–25 cm），不蓄势；另一只手沿中线朝脸部／胸部出拳，在离目标几厘米处停下（控制力度）。
- 搭档反应：手臂被拨开时，躯干向前／向下低伏，然后回到循环动作中——训练不会中断。
- 拍摄：固定中景，从侧面／四分之三角拍摄；两人侧身面对镜头——双手始终可见。
