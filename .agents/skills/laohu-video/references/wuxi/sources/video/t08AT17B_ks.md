# 李小龙截拳道训练与等长练习（Bruce Lee JKD Workout And Isometrics；12:14）

**核心内容：**介绍李小龙的等长练习：五种锻炼“腱力”的动作——不增加大量肌肉也能提高爆发性击打力量。采用健身房谈话式演示，两名讲解者穿李小龙T恤，第三位参与者 Jack 用于演示深蹲架练习。

**按时间码排列的技术**
- 00:22 — 开场：解释等长练习的作用。李小龙把等长练习＋重量训练＋耐力训练结合起来；等长练习能同时提升速度与力量、握力和击打时的稳定性（两人站立中景，对着镜头讲话）。
- 01:10 — 练习1：皮带／绳索等长拉动（来自 Jerry Poteet）。把皮带压在脚下，在3个位置做拉动／出拳：中距离 → 几乎完全伸展（“伸到这里”）→ 再回到中距离。每个位置保持10秒，并大声计数。画面：练习者把皮带拉到胸部高度，肘部下沉，保持垂直拳结构。
- 02:42 — 将绳索缩短后练第三个位置＝“出拳结构”，手臂完全伸展——“这确实有助于提高手臂出拳力量”。
- 02:57 — 练习2：垂直拳俯卧撑（用三节指骨支撑，拳头放在肩膀下方，肘部内收——“我们不是那样出拳，我们是这样出拳”）。静止保持：底部10–20秒 → 稍微抬高 → 中段 → 爆发式起身（“向上爆发”）。约5次。画面：在底部／中段保持姿势，跪着的搭档讨论角度。
- 04:26 — 手掌变化（拳头较弱者可用），再逐步进阶到手指；强调三头肌参与和肌腱训练，而不是单纯做“俯卧撑”。
- 05:17 — 练习3：静态哑铃保持（10–15–20磅），手臂放在出拳高度。要点：膝盖弯曲，脚跟像“拧紧”一样压在地上，核心收紧——“我不是只站在这里”。然后双臂完全向前伸，保持10–30秒。不要拿着哑铃出拳——会伤关节。
- 07:02 — 练习4：在深蹲架上做杠铃等长推举（杠铃固定）。Jack 躺在杠铃下方：杠铃放在斜方肌上（不要压在颈部，可以垫毛巾），股四头肌收紧，向上施压10秒，做3组，缓慢放低。锻炼踢击力量。画面：三人在深蹲架旁，一人位于杠铃下方，另两人纠正动作。
- 08:56 — 练习5：推固定在胸部高度的杠铃（姿势取自李小龙的著名照片）。向**前**推，不要向上推：脚跟压进地面，全身保持一条直线，三角肌和核心参与。每组保持20秒。额外动作——用杠铃练前臂力量。
- 10:34 — 哲学：“你是用整个身体在击打”；肌肉必须“记住”不同方向的发力脉冲，以便适应各种情况。
- 11:31 — 结尾：Bruce 身材清瘦，“体重并不大”，但靠“腱力”打得很重——依靠肌腱，而不是肌肉力量。

**编排用视觉细节**
- 地点：小型健身房（深蹲架、一排哑铃、健身球、沙袋），灰墙，均匀的顶部照明。
- 等长出拳架势：半蹲、膝盖弯曲、脚跟压进地面、垂直拳放在中线上、肘部下沉。
- 所有出拳位置都分为手臂伸展的三个阶段（靠近躯干／中距离／完全伸展）——可作为分镜时呈现截拳道动作阶段的参考。
- 场景节奏：静止发力时出现10–20秒的紧绷颤抖，随后“向上爆发”——适合训练蒙太奇的风格对比。
- 距离：练习者单独示范，或搭档站在侧面半步处，给出评价并触碰练习者的手臂／肘部。
