# 李小龙截拳道纪录片（Bruce Lee's Jeet Kune Do - Documentary；55:35）
官方训练影片《Bruce Lee's Jeet Kune Do》（Legacy Productions，约1990年代制作，由 Bruce Lee Estate 支持）。旁白包括李小龙本人的档案录音，以及 Brandon Lee、Dan Inosanto、Ted Wong；画面包括李小龙私人训练、学生访谈、红墙武馆、后院里的豆袋，以及作为学生的 James Coburn。字幕为自动生成（英语 ASR），部分姓名／术语识别失真（“Jeet kundo”、“baijong”）。

**核心内容：**唯一一部由李小龙私人训练影像和笔记整理而成的截拳道“训练影片”：包括哲学（无招胜有招、像水一样）、体系结构（拦截、距离）、步法（白种、滑步、蹬步滑步、绕圈）、拳法／腿法、速度，以及通过武术表达自我。

**按时间码排列的技术与章节**
- 00:34–01:06 — 序幕：“这不是一部关于李小龙的电影……而是由李小龙亲自制作的第一部、也是唯一一部截拳道训练影片”；素材来自私人档案。画面：档案片段、“第一章：起源”标题。
- 02:01–02:47 — 李小龙原声：截拳道＝“拦截之拳之道”（ASR 误识为“拦截之鱼”），体系约于1965年形成。
- 03:58–05:58 — 咏春基础及其后续发展：黏手与擒拿结合（“32种不同的黏手方法”）、腹股沟击打、“手刀指击”；例子：拳头打过来——接触并转移方向（黏手反制）。
- 07:35–12:54 — 学生谈论这套方法：与空手道／合气道／柔道练习者对练；李小龙的参考来源包括西洋击剑和拳击书籍；拒绝“中式”或“日式”格斗方式——格斗只有人的方式。
- 14:31–16:31 — 反对流派教条（“各人分开……各自有自己的教条”）；著名的“像水一样”独白：“你把水倒进杯子里，它就变成杯子的形状……”（李小龙访谈影像）。
- 17:05–17:48 — 李小龙的问题：“如何在不牺牲巨大出拳力量的前提下，保持闪电般的速度？”基本防守示范：交叉格挡＋同时击打；“接住就出击，格挡就出击，或者两者同时做”（防守与进攻同时进行——截拳道的核心）。
- 18:54–19:55 — “菲律宾拳击”组合（Inosanto）：闪身—交叉拳—勾拳—交叉拳、刺拳—格挡—交叉拳—勾拳；纠正：“只有手臂和肩膀……肩膀太紧”——逐渐把腿部动作加入出拳。
- 21:40–22:31 — 不同距离之间的流动（武馆影像）：savate 式切入 → 咏春距离 → 西洋拳击 → 锁技／摔法、“柔术／合气道／卡利”。教练明确说“这里可以用在电影里”——这是一组编排用组合。
- 22:55–24:02 — “截拳道像一条铁链，链上挂着一个铁球”；科学测试（Hayward Nishioka）：截拳道拳比传统空手道拳更有力量；动作机制：“把整个髋部用进去，再弹出去……把这拳变成武器”。
- 24:43–24:55 — 拦截的关键：“你必须朝我移动才能碰到我……你的攻击给了我拦截的机会”；“在搏斗中，距离是一种持续变化的关系”。
- 25:06–27:20 — **步法章节**（Ted Wong，1964年起跟随李小龙学习）：白种架势——后（左）脚跟抬起，脚尖内收；滑步（前／后／左／右，左右架势都练）；蹬步滑步——“你是蹬地再向后推，而不是迈一步”；绕圈／四分之一转身——顺着对手的绕圈方向移动。画面：红色健身房、单人移动练习、木板图示、“第四章：步法”标题、“攻击的目的”列表。
- 27:44–29:25 — 踢击组合：组合拳脚中的距离和踢法会变化；“投入式踢击”（commitment kick）——身体重心向前移动并贯穿目标；错误做法是身体后仰；“你会把自己往前送”——先练动作，之后再加快速度。
- 30:21–33:22 — 李小龙在影片中纠正学生的原声：“你想练拳就出拳，想练踢就踢”；谈他对 Ken Knudson 的侧踢：“速度快得……他的眼球还留在原地”；纠正：“踢击结束并撞击目标的瞬间，脚还悬着没落地。”
- 35:13–36:48 — James Coburn 训练（黑白后院影像）：从控制动作时的紧张 → “别管那些，直接做——砰，正中目标”；“把踢击练成武器”；谈起始速度：“你的攻击要突然”；纠正：踢完后不要让腿掉下来。
- 43:05–46:04 — 功能性体能训练：用跑步／骑自行车代替孤立肌肉训练；豆袋练习：“踢豆袋，把推力给我”；纠正：“结束动作时身体别转那么多——尽量继续面对他”；练习时机：“还没到……还没到”（踢击正在回摆的豆袋）。
- 47:12–48:07 — 李小龙谈速度（“快得致命”）；速度训练：基因＋“肌肉记忆”，以千分之一秒计的时机判断，以及对着焦点手靶上的红灯作出反应。
- 49:50–53:14 — 最后一章“思考这些问题”：武术是自我认识——面对恐惧、局限、成功与失败的障碍；“截拳道的艺术就是化繁为简”；“我不相信体系……我找到了自己的无知从何而来”。
- 53:39–55:35 — 片尾字幕：李小龙旁白；其他旁白 Brandon Lee、Dan Inosanto、Ted Wong；特别训练者 James Coburn；影片献给 Bruce 与 Brandon Lee。

**编排用视觉细节**
- 三种画面质感：（1）8毫米黑白档案——后院、与 Coburn 训练、豆袋；（2）1990年代在红墙和红柱武馆中的彩色访谈／示范；（3）李小龙手写笔记和木板图表——非常适合作为插入镜头／切出镜头。
- 白种架势：窄幅、半正面的剪影，后脚跟抬起，像一支“弹簧”；整个移动体系依靠滑行而不是迈步——躯干始终浮在同一高度。
- 蹬步滑步看起来像短促的“推—弹回来”——很适合表现中距离对决中紧张的脉搏感。
- 拦截（jeet）：对手的前进动作就是起始信号；戏剧化呈现时——“攻击者自己撞上拳头”。
- 场景中的距离流动：踢击距离（savate 式切入）→ 黏手（咏春手法）→ 拳击 → 锁技／摔法——影片明确说这是电影里的组合。
- 踢击组合：第一脚短促、试探性；“投入式踢击”则能明显看到全身向前移动；踢完后腿要受控地收回，躯干继续面向目标。
- 影片节奏：长时间沉思式独白（像水、各种障碍），与1–2秒爆发式档案击打交替——可作预告片／蒙太奇的节奏参考。
