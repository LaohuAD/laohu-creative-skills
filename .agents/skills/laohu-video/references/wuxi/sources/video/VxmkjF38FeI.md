# 截拳道全部27门（JKD ALL 27 GATES；19:19）

**核心内容：**完整展示27种“门”（Gates／Fon Sao 黏手制动动作）——从手部接触（双手相触）开始的截拳道基础黏手组合。“门”是供拦截的“门路”／空档：如果对手挡住你的击打，手不要收回，而是“破门”——制住对方格挡的手并继续击打。27这个数字是为了纪念李小龙的生日（1940年11月27日）。

**按时间码排列的技术：**
- 00:04 — 概念：三种入门线路——上门／中门／下门，加外门。中线上的目标包括眼睛、鼻子、喉咙、太阳神经丛、腹股沟、锁骨、肋骨、膝盖、胫骨。
- 01:52 — 始终从双手相触开始（摊手对摊手／护手（wu sao）），采用白种架势；通过组合，27门可以“变成2000种”。
- 03:18 — 第1门：拍手（pak sao，推开）＋直拳，立即收回。这是整个体系的核心：“至少把第1门练好，练到成为你自己的一部分。”
- 03:49 — 第2门：你被挡住 → 向外做捋手（lop sao）＋挂拳（gua choy，反背拳）：推开—出拳、重新制手、击打（数1—2—3—4）。
- 04:25 — 第3门：对手从内侧抓住你的手臂 → 转入膀手（bong sao）；从内侧入手：推开出拳、拉回、击打——“你没法从内侧格挡”。
- 05:19 — 第4门（PIA——渐进间接攻击）：低—高假动作、重新制手、击打；变化：低位 → 向下制手 → 转向外门。
- 05:56 — 第5门：抓握 → 拉拽＋出拳 → 重新制手 → 出拳（变化版是用指插代替拳头）。
- 06:29 — 第6门，“漏洞”：防守线路全被封住 → 看到防线之间的空隙 → 拳头翻转向上，沿空档直穿而入，重新制手、击打。
- 07:16 — 第7门，“跑手”（jao sao）：推开出拳 → 绕过对方肘部做一个小圈 → 击打；绕圈幅度很小，肘部始终靠近中线。
- 07:54 — 第8门：手臂弯曲，以肘击打脸部；在肘关节处压住双方手臂（不是手腕——要控制整条手臂），再用后手击打。
- 08:30 — 第9门：与第6门类似，但先做高位假动作——诱使对方抬手 → 向下击打腹部，重新制手、击打。
- 09:00 — 第10门：“空手道手刀”：推开出拳、重新制手并击打、压制、再用后手击打。
- 09:30 — 第11门：从内侧进入，拳头向下打入空隙，重新制手、击打；“要打穿目标，不要有所保留”。
- 10:11 — 第12–13门（成对演示）：从内侧推开 → 抓握 → 后手绕过对方肘部反手击打 → 击打 → 向下压制 → 击打。会从两侧展示（为配合摄影机而改变站位）。
- 10:54 — 第14门：头槌——从内侧勾住对方，把他拉向自己的头槌（1—2—3—击打）。
- 11:48 — 第15门：一—二，重新制手，再击打（快速组合；提醒高速练习会造成受伤）。
- 12:08 — 第16门：转身＋击打，重新制手，从下方打铲勾拳；同一位置也可用来折断手臂并把对方摔到地上，最后击打。
- 12:44 — 第17门：一—二 → 转身（在肘部折断）→ 手刀 → 重新制手 → 击打。
- 13:16 — 第18门：格挡 → 移到外侧、击打、重新制手、再击打（1—2—3—4）。
- 13:47 — 第19门：与第7门相似，但停止绕圈 → 向下折压对方手臂，制住双臂，再击打。
- 14:15 — 第20门：肘部完全向下折，压住，再从下方打上勾拳，击打下巴。
- 14:57 — 第21门：以肘部制手把对方往下拉，向内踏步，击打喉咙。
- 15:22 — 第22门：向下压住颈部，把对方手掌直接按到他自己的脸上，再把他拉向膝击。
- 16:01 — 第23门：把对方拇指压向他的肘部，重新制手，再往下拉向膝击。
- 16:33 — 第24门：拉拽＋指插 → 从肘部内侧上锁 → 锁住（“他哪里也去不了”）→ 控制倒地对手（约16:50–17:30，搭档躺在垫子上，最后从上方压制）。动作做慢一点，以确保安全。
- 17:16 — 第25门：推开出拳、重新制手，用标指（biu gee）击打：一只手“遮住视线”，另一只手出击。
- 17:46 — 第26门：以指插阻挡、重新制手并击打、再重新制手并击打（与第5门有关）。
- 18:17 — 第27门（“我的宝贝”）：无限连击——拉拽出拳、重新制手并击打、外侧手刀、重新制手并击打、再重新制手并击打……“直到对方完蛋”。以闪电般的速度收尾。

**编排用视觉细节：**
- 场景：两名穿黑色T恤、赤脚的练习者；红蓝拼接垫子；白墙上有大型阴阳标志和“拦截之拳之道”字样。
- 距离：前臂始终搭接（黏手距离，躯干相隔约30–50 cm）——视频几乎全程两人的手都“黏在一起”。
- 白种架势：右手、右脚在前，后脚跟抬起（每次击打前都准备向前启动）。
- 节奏：每一门先慢速演示两次，再以“正常速度”练2–3次——爆发0.5–1秒，然后恢复为双手接触状态。节奏是“敲—敲—爆发—停顿”。
- 正确动作像整个身体短促向前一冲，手部快到模糊（他说：“我为了摄影机才放慢，不然你们看不清手”），击打后立即收回；没有蓄势，所有动作都从中线开始。
- 每组动作后双方交换角色（“轮到你了”）；最后彼此注视、不移开视线地鞠躬。

**引述与表述：**
- “练完这些门之后，你的截拳道拳会‘在被看见之前先被感觉到’。”
- “每次拍手（Pock Sow）都会变成按手（Gum Sow）——速度够快时，两者就合而为一。”
- “如果你不练这些门，就不算在练截拳道；这是截拳道的脊梁。”
- “即使鞠躬，也绝不要把视线从对手身上移开。”
