# 李小龙截拳道刺拳（Bruce Lee JKD Jab；11:14）

**核心内容：**讲解截拳道刺拳与直线前手拳的区别：前手拳——前进靠近对手时，整个身体充分伸展；刺拳——“像鞭子一样甩出并伸到位”，在轨迹末端划出鞭子般的弧线。力量沿后脚 → 髋部 → 肩膀 → 手的传递链前进；最后在目标上“啪”地爆发，然后立即收回。后半段教练指导 Jack：采用静止、不弹跳的架势，单独练习动作机制，并通过拍掌练习速度。

**按时间码排列的技术**
- 00:24–00:56 — “刺拳和直线前手拳有什么区别？”这个问题：直线前手拳——“你正朝对手前进……要完全伸展才能够到对手”，需要朝目标移动。
- 00:59–01:34 — 刺拳：动作类似，但“弧线出现在轨迹的最后阶段”——结束时像鞭子一样抽出弧线；Octavio 在画面上夸张演示这个弧线（“如果我要把动作夸大，就会这样”），实际轨迹几乎看不出来。
- 01:34–02:13 — 关于前手拳机制的警告：只使用“前侧的力量”，等于只用了整块力量拼图中的一部分；面对冲来的身体质量，“用肩膀吸收它”——要产生震撼力，需要重新对齐、力量和向前推进。
- 02:13–02:38 — 刺拳＝“像鞭子一样甩出并伸到位”，相对于对手当下的位置来出拳；谈到对练：“如果你还没准备好使用这些工具，我就不会进行对练。”
- 02:38–02:59 — 关键动作机制：肘部内收；“利用后脚蹬地的动量或加速度”，蹬地＋髋部参与＝在最后一刻像鞭子一样甩出。
- 03:00–03:41 — “秘诀”（Dan Lok：“把这段看10遍”）：关键不在拳，而在“架势和步法”；后腿像上好劲的弹簧；逐点展示力量传递链：脚 → 髋部（“看髋部？砰、砰、砰，有三个点、四个点”）→ 肩膀 → 手。
- 03:42–04:25 — “在目标上打出啪的一声”并收回；先演示错误的刺拳（“特意做错给你看”）——只用手臂、完全伸展、躯干暴露；正确版本——“向上剜……啪”，所有动作同时发生，“砰，然后马上收回来”。
- 04:27–05:01 — 初学者单独练习髋部和腿部动作；常见错误——只转动肩膀（“人们开始在这里拧转”）——身体中段转向侧面，左手后续出拳失去力量。
- 05:04–05:29 — 目标：“打穿目标”（出拳穿过／越过目标）；收回到架势＝快速恢复。常见错误：手往下掉、“收拳慢”、“动作幅度大”（身体打开）。“打出啪的一声才是最好。”
- 05:42–06:02 — 连续快打：每一记跟进的拳都要“打在前一拳的后面”——砰，这记拳来了，砰。
- 06:05–06:43 — 安全与递进：鞭子般快速收拳可能会拉伤肌肉——先热身；初期可以夸大动作，之后逐渐缩到“A点到B点……距离很短”——用短距离动作发力；“从这里到那里，很容易产生力量；但只有这么一小段距离，就不容易了”。
- 06:44–06:59 — 坦率观察：很多截拳道练习者“技术背后的实质力量不足”；“Bruce 用直线前手拳能把人打得很重。但那是 Bruce。”
- 07:00–08:15 — Jack 对着手靶练习（原地、不踏步）：“不要跳……像石头一样完全站定，然后再出击”；先动手，再动髋，最后动腿；“不用担心能不能打重——专注于动作正确。动作做对了，拳自然会打得重。”
- 08:15–08:57 — 为了不暴露意图（出拳前先往回收手），先把手放在胸前开始练习。口令：“放松。放松。放松……动作之间停一下，集中注意力。”
- 08:58–10:08 — 听觉训练：听到拍掌声就出拳；“不要预判”；增加难度——拍掌的人站在出拳者视线之外（“如果他看不见 Sifu，就更难了”）；“不要弹跳”。
- 10:10–11:14 — 训练搭档的角色：当镜子／教练并给出反馈（“手掉下来了”、“转得太多”、“弹得太多”）；与拳击的区别——使用垂直拳；“朋友，像水一样”。

**编排用视觉细节**
- 架势：右手在前，肘部内收，后腿蓄力；出拳前身体像石头一样静止——完全不弹跳（与拳击的弹跳式移动相反）。
- 出拳动作：动作幅度短到几乎看不见，最后几厘米手腕“啪”地弹出一个极小的弧度；收手比出拳更快；在画面上，只有手靶和肩部的回弹能显示击打发生了。
- 动作传递链：后脚 → 髋部 → 肩膀 → 手，以“3–4个点”形成向上的波浪；错误示范（作为场景对照）：大幅扫动、手下垂、肩膀转动。
- 距离／节奏：原地在离手靶一臂长处练习；连续刺拳每一拳都“跟在”前一拳之后，形成频闪式节奏；拍掌练习则从完全静止状态听声起动。
- 场景：暗色健身房，Octavio 的白色手靶在画面上形成明亮目标；教练在学生视线之外拍掌——现成的“盲目反应”调度方式。
