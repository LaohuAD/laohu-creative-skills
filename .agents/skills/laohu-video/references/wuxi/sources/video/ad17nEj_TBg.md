# 李小龙截拳道黏手技术——捋手（Bruce Lee's Jeet Kune Do Trapping Techniques - Lap Sao；5:11）

**核心内容：**解析捋手（Lap Sao，“拉手”）——一种截拳道黏手技术：把对手手臂向下／向侧面拉，同时用另一只手击打。关键：力量来自躯干旋转，而不是手臂；目的是让对手失去平衡，而不只是把他的手臂“移开”。

**按时间码排列的技术**
- 00:01 — 开场：比较捋手和拍手。捋手＝拉手，拍手＝拍击／压手。两者都出现在李小龙电影中，但“电影里的样子≠实际应用”。
- 00:26–00:45 — 对方僵硬抵抗时，拍手会失败（“给我全力抵抗”）；转移对方的压力——不要推，而要沿着对方施力的方向拉。画面：前臂接触，Dan 抓住对方手腕并向下拨开手臂。
- 00:50–01:11 — 动作机制：不要只用手臂拉（“看肌肉——这样不行”）。把肘部朝自己的躯干拉，同时转动身体。画面：髋部明显转动，肘部拉向肋部。
- 01:11–01:31 — 同步：拉拽＋另一只手直拳同时完成，两个动作方向相反，“像两列火车相撞”。不是“先拉、再打”，而是整合为一个动作。
- 01:36–01:53 — 拉拽后的控制：搭档无法挣脱（“Shin，试着动一下”），对方手臂被封在自己的躯干上。
- 02:00–02:20 — 常见错误：做完捋手后还中性地面对面对峙——双方五五开（“他能打我，我也能打他”）。正确做法：拉到对手失衡，转动他的躯干，打开进攻线路。
- 02:25–02:36 — 步法：必须旋转身体；如果不转，双方仍处在彼此的攻击线路上。
- 02:40–03:09 — 最佳变化：对付左势在前的对手。拉对方远侧手臂——自己的头离开攻击线路，对手空着的手离你很远；运用“骨骼力学”（骨骼结构，而不是肌肉）。拉开后，对方整个侧身都暴露出来。
- 03:09–03:46 — 搭档训练：交替左右练捋手，轮流当进攻方。常见错误——像“风车”一样浪费太多力量（“你会看到很多咏春练习者整天这样转”）。拉拽要短促有力，同时保持身体结构。
- 03:55–04:33 — 木人桩：如果训练动作能推动木人桩，你就能推动一个人。拨开手臂后，先击打，再朝颈部做手刀——画面约以30%力量演示；加上躯干旋转的完整动作后，可以“把人打飞”。
- 04:42 — 结尾：“练习”——只有通过重复，技术才能真正掌握。

**编排用视觉细节**
- 距离：黏手距离——前臂持续接触，胸口相隔约50–70 cm。
- 架势：窄幅、半正面，双手保持在中线上（截拳道继承的咏春架势）；拉拽前重心略在后腿。
- 拉拽的关键视觉：拉拽手的肘部朝自己的肋部收，髋部与肩膀旋转45–90°；对手向前／向下“点头”，肩部转过躯干。
- 同步性：一只手拉拽，另一只手同时出拳——视觉上像一把“剪刀”。
- 训练节奏：循环往复、像节拍器一样稳定（每秒约拉一次），并穿插突然爆发的实战动作演示。
- 正确完成捋手后的搭档会呈现失衡剪影：向前倾、重心轴线偏移，空着的手够不到目标。
- 拍摄：固定中景，两名练习者以四分之三角度面对镜头，背景中性——动作轮廓清晰可见。
