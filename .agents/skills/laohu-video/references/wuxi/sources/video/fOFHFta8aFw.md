# 李小龙截拳道格挡技术（Bruce Lee JKD Blocking Techniques；10:15）

**核心内容：**截拳道本质上没有“格挡”：不是僵硬地挡停攻击，而是拍挡／偏转（转移对方力量）并同时出击。核心原则：每个动作都是攻击；防守只是击打带来的附带结果。整部视频都在小型健身房里以搭档对练方式进行，距离为出拳范围。

**按时间码排列的技术**
- 00:23 — 哲学：截拳道是一种“进攻／主动攻击的武术”，目标是尽可能快速、直接地结束打斗；“每一个动作都在打击”，没有所谓格挡。
- 01:04 — 格挡＝“僵硬地把攻击挡停”（用力阻止对方的动量）——我们**不是**这样做。我们使用拍挡——“转移力量／转移压力”。画面：搭档打直拳，另一人保持架势，用手掌轻轻将对方手臂往内拨开。
- 01:53 — 反例：僵硬的格挡会产生“空档”——Dan 立刻“朝身体开火”。演示：格挡 → 在对方手臂下方立即打击身体。
- 02:03 — 从内侧偏转：击打顺着格挡手臂滑过去——“他刚才是绕过去了”。水的比喻：“你从那块石头旁绕过去……像流水一样穿过去，找到裂缝。”
- 03:12 — 拍挡机制：动作幅度短，“手不要离开身体周围的范围”——只把攻击稍微拨开，再反击。这是“一—二”两个动作，已经属于妥协。
- 03:29 — 理想情况是一个节拍内完成：不是先拍挡、再打，而是直接打。“我的格挡其实就是这条手臂……也就是这记击打。”不要“一—二”，而是“一，砰”：自己沿中线出拳，同时以前臂偏转对方的攻击。
- 04:07 — 身体动作机制：咏春结构——肘部内收、下沉。如果像典型刺拳那样把肘抬起来，自己就会挨打。因此使用垂直拳或略微旋转的拳。
- 04:27 — 手臂长度和身体支撑：手臂较长、支撑更稳的一方会赢得交手；向前踏步可以“消散”对方手臂的力量，并在切入时控制对方手臂。
- 04:55 — 对付后手拳：同样的原理——“我的格挡就是这把剑”（前臂侧缘）；变化包括从上方压下以取得杠杆优势，或从内侧拨开；对付两只手时都有内外侧角度：“这里、这里、这里，或这里”。
- 05:52 — 关键心态：不要想着“我在偏转”，要想着“我在击打”；偏转自然会发生。“这还是一次击打。”
- 06:20 — 低位打击（低位拳、上勾拳）：向下／向内拨开，立刻用击打还击；支撑稳固时可以“迎着对方打”——同时迎击（停击逻辑）。
- 07:02 — 四个角：咏春门路（高／低门、前／后）正面相对；截拳道的“刀刃”会让躯干侧转——半侧身架势使角度改变。
- 07:37 — 训练练习：搭档“喂”出沿中线的直拳，防守方用交叉手拍挡，同时把回应动作对准鼻子；慢速练习，同时使用双手：主手偏转，另一只手作为辅助。
- 08:49 — 递进练习：先练直拳（现实中不常见，但能建立基础），再练弧线拳——相同动作加离线步（侧步）和后续击打。
- 09:45 — 结论：“它始终都是一次攻击。”打斗持续越久（“一、二、三”），风险就越高。

**编排用视觉细节**
- 地点：狭窄健身房——墙上的绿色绳子、加拿大国旗、沙袋、健身球；两名男子几乎始终面对面对峙，固定双人中景。
- 距离：始终保持伸臂出拳距离，不留空隙；所有手部动作都在身体轮廓内——幅度**非常**短，拍挡幅度为10–15 cm。
- 架势：侧身，前手领先，肘部下沉，垂直拳放在中线上。
- 节奏：缓慢讲解 → 突然快速打出一个节拍（“一，砰”）——很适合场景中的“静止交谈／突然爆发”反差。
- 关键编排模式：防守者的击打沿着中线穿过对手的攻击，以前臂偏转攻击——两个动作在同一节拍完成。
