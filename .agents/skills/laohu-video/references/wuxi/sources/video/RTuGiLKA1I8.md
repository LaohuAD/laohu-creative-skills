# 李小龙速度出拳练习——解析《精武门》（Bruce Lee's Speed Punching Exercise - Fist Of Fury Explained；6:08）

**核心内容：**解析截拳道前手拳（“最快的前手攻击”）——截拳道最重要的前手击打。要点：不要让躯干完全旋转（会暴露身体，也让拳头只用上半身的一部分）；用全身切入，击中时下沉身体重量；像“鞭子”一样击打，并立刻收回。

**按时间码排列的技术**
- 00:04–00:29 — 介绍：前手拳是截拳道的主要击打，因为截拳道把强侧放在前面（“前面：前手、前脚”）。这也是最容易被误解的技术：“是弹出去还是推过去？力量从哪儿来？”
- 00:42–01:05 — 错误一：躯干完全旋转（拳击式拧转）。问题：身体下方的线路暴露（“这里下面会暴露”），只有“肩膀的延伸部分”在发力，并且只有半个身体进入这记拳。
- 01:13–01:28 — 过度旋转后如果打空，头部、侧身和低位线路都会暴露；身体“失去层次”与“视线”（眼睛离开对手）。画面：Sifu 示范过度旋转的身形，视线也随之偏离。
- 01:30–02:00 — 正确机制：“向前推进”——整个躯干向前切入；接触时，“身体重量往下落”；“把另一只脚拖进来”——后脚跟上，而不是扭身离开；通过“正确的髋部”传递力量。
- 02:13–02:41 — 重心转移：从外表几乎看不出来（“你得自己感觉”）；出拳经过的“距离很短”——加速距离短，身体姿势仍保持扎根；“能量向前进”，而不是向侧面移动。
- 02:43–02:52 — 优势：如果对手闪开，你仍然可以“改变攻击”，而且第二击会更快。过度旋转的拳只是“一次出手”，无法连续跟进。
- 02:53–03:16 — 长距离、完全伸展的拳只用于对练距离和“杂志式摆拍”：“手伸得太开了，伸得过头。”
- 03:23–03:44 — 分析李小龙的照片：即使在“摆姿势”，他也会运用身体和“脚跟的根基”——强调脚跟位置和扎根，而不是单纯伸出手臂。
- 03:49–04:33 — 手和拳头：手始终保持在中间；用“下面三节指骨”（下方三节指关节）击打，即截拳道的垂直拳。动作机制：“像鞭子——一接触目标就划出弧线，然后马上收回来”——接触后划出弧线，像沿着对手向上剜击。不要过度投入，向目标短促地“砰”一下：“这就够了——只要能打进去并接上后续攻击就行。”
- 04:41–05:24 — 速度训练：夸大动作——力量来自后腿，“学会像鞭子一样挥出拳头”。另一只手向相反方向拉回：“击打时就像撕纸一样”（双手朝相反方向把纸撕开）。
- 05:26–05:56 — 训练方法：每种变化重复10次，改变脚位和出拳侧；学习阶段“暴露出手意图——我不在乎”；逐步缩短动作并拉近距离。
- 05:57–06:04 — 步法是基础（提到另一个步法视频）。

**编排用视觉细节**
- 架势：半正面（截拳道戒备架），强侧手在前，后脚跟抬起；躯干**不会**完全旋转——肩膀几乎保持正对。
- 出拳：垂直拳，严格沿中线出拳；视觉上是短促的“射击”，配合全身踏步，并在击中时明显沉下重心。
- 收拳：手沿着向上／向后的弧线反弹，速度比出拳时更快——像“鞭子”一样；这种鞭打式动作很适合快速剪辑。
- 步法：后腿蹬地＋后脚跟进（拖步），不以脚掌前部为轴转动。
- 两人动作的戏剧性对照：“错误”的过度旋转拳（漂亮、电影感强、动作很长）对比“正确”的短促扎根拳——现成的摆拍／实效性对照（参见“杂志式摆拍”）。
- “撕纸”训练：双手向相反方向运动——适合训练场景的动态、易读手势。
- 地点／拍摄：固定摄影机，中景；白天透过全景窗户打入日光，背景为城市天际线；部分画面使用焦点手靶。
