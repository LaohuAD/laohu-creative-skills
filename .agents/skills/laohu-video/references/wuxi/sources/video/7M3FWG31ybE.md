# 李小龙的截拳道——反背拳（Bruce Lee's Jeet Kune Do – The Backfist；8:10）

**核心内容：**三种截拳道反背拳：简单型（采用直线前手拳的力学）、甩鞭／弹击型（手腕像鞭子一样甩动，髋部反向转动，立刻接下一击），以及全身旋转的重型终结反背拳，“像挥棒球棒”。反背拳是李小龙最喜欢的技术：它不是终结技，而是闪电般快速、让对手短暂失去反应的击打。

**按时间码排列的技术**
- 00:03–00:30 — 开场：反背拳是李小龙最喜欢的技术（《龙争虎斗》《截拳道之道》《李小龙技击法》）；“这不是用来一击终结对手的，而是用快速击打让对手发懵。”
- 00:46–01:14 — 目标和击打面：用食指和中指的前两节指骨击打，拳头略微旋转；目标包括太阳穴、耳朵、颈侧、腹股沟（指着搭档的目标部位说“就在这里，就在这里”）。
- 01:16–02:14 — 第一种反背拳，简单型（标题“第一种反背拳：简单反背拳”，约 1:30）：不要只甩动手臂——“不是只甩胳膊……要用整个身体”；动作机制类似直线前手拳，但用拳背击打；髋部向前送（“看我怎么把髋部送进去”）；出拳距离出奇地远。画面：踏步向圆手靶击打。
- 02:17–03:07 — 第二种反背拳，弹击／甩鞭型（标题约 2:25）：手在身前甩动，髋部转动方向与第一种相反（“第一种的髋部这样动，另一种则相反”）；目的是弹击后立即接另一击（“现在我可以很快接别的击打”）。画面：用短促甩动打手靶，随即换另一只手击打。
- 03:09–03:36 — 第三种反背拳，重型／终结型（标题约 3:10）：躯干与髋部充分旋转——“我转髋。砰……这是威力很大的击打。”
- 03:42–03:52 — 警告：不要从背后摆臂打反背拳——“你会骨折”；沿这条轨迹应改用锤拳（画面：手臂抬过肩膀蓄势，用拳头肉厚的一侧击打）。
- 03:53–04:10 — 街头情境（电影片段中有人摔到草地上）：“你看到一道模糊的影子……他冲过来，砰”——从侧面迎击来袭者时，以全身发力打锤拳。
- 04:11–04:33 — 主动进攻用途：用反背拳打开／拨开对方持械的手，再击打；经过训练后，“就连这种动作也会让人痛”（用前臂／拳背击打对方肢体）。约 4:45 插入身穿白衣、手持旗帜的功夫学生队列作为补充画面。
- 04:51–05:19 — 指导（标题“演示与练习”）：“确保动作不是推，而是像弹一下”；不要绷紧身体，释放力量；身体提供“弹劲”。
- 05:22–05:46 — 大幅动作训练法：先刻意夸大动作以掌握力学机制，再“逐渐缩小、再缩小”；太早练反向协调动作，会得到有速度却没力量的击打——“你打到对方，对方还站在那里，这就不行。”
- 05:50–06:25 — 反向协调／收拳：手“像鞭子一样”收回，几乎不离开架势（“我的手就移动这么多”）；肘部和手腕护住中线，“随时都能出手”。
- 06:34–07:17 — 重型反背拳练习：全身旋转；常见错误是“手太早离开”；比喻为“像挥棒球棒……是一个全力投入的动作”，不考虑防守，“基本上无法被挡住”。
- 07:28–08:07 — 总结：训练时交替练三种反背拳，并练习第三种重拳后的恢复；“朋友，像水一样”（与搭档一同练习）。

**编排用视觉细节**
- 架势：右手在前，拳头置于下巴旁；反背拳从戒备架直接发出，不预先摆动——肘部先向前，手腕最后展开。
- 三种动作质感：（1）简单型——沿直线“射出”，像直拳一样由髋部向前驱动，拳头转到拳背击打面；（2）弹击型——在脸前做短促的弧形手腕甩击，躯干几乎不动，髋部反向运动，呈现“鞭响”感；（3）重型——全身大幅转动90°以上，转移重心，像挥出横扫的一棒。
- 距离：出奇地远——一步可从拳击距离之外打到；弹击型适用于很近的距离。
- 节奏：弹击几乎毫无预备地发出，收回比击出更快；只有重型是大幅动作，完全投入后停顿一下再恢复。
- 场景：白天的公园、绿植背景；小圆手靶会发出清脆声响；教练用手势纠正学生手腕动作幅度。
