# 截拳道教程（Jeet Kune Do Tutorial；41:17）

**核心内容：**振藩功夫的踢拳部分：用眼插和假动作衔接距离，侧踢反制（ha pak／jeet que／jik tek），戴手套的“乒乓球”式反制—再反制训练，以及 Jow Sao House 连续动作——从跑手（running hand）转入摔法和臂弯锁。它连接了打击与地面缠斗。

**按时间码排列的技术：**
- 01:41 — 开场。Diana 说“布鲁斯叔叔”创立这门武术是为了**街头实战**，所以要穿运动鞋（街头鞋）训练，不能赤脚；手靶和手套是必需品。
- 02:39 — 左势在前：传统振藩功夫／截拳道训练教右势在前（强侧前置），但“用你偏好的那一侧”；两侧都要练（左右兼练）。
- 03:05 — 入身：衔接距离。眼插（bui jee）要配合整个躯干投入——“要像 Houdini 一样”，让对手相信你真的要伸手戳他的脸。这是诱使对方反应的假动作。
- 04:00 — 入身组合 1：bui jee → o'ou tek（振藩功夫中的圆踢／钩踢）→ 交叉拳—勾拳—交叉拳 → 踢手靶。眼插假动作打开了打交叉拳的线路。
- 06:08 — 入身组合 2（ABD——诱导攻击）：假装低位出拳（chap choy）→ 高位出拳（gua choy）→ 踢击 → 交叉拳—勾拳—交叉拳 → 圆踢。“假动作也要做出完整的一拳，不能只做一半。”
- 07:29 — 入身组合 3：高—低—高组合 → 踢击 → 交叉拳—勾拳—交叉拳 → 踢击；关于搭档的舒适度：持靶者可以用手靶提示，也可以直接用身体接踢（“老师也得学会忍痛”）。
- 09:56 — 侧踢反制。Ha Pak（低位拍击）：像篮球运动员罚球前运一下球——拍击后**立刻**接眼插，“像弹珠台一样反弹”，中间不停顿 → o'ou tek → 组合拳。
- 12:21 — Jeet Que（jeet＝拦截，que＝桥接）：用前臂当减震器；受到强压力时会弹回来，压力弱时几乎不动；随后进入同样的入身组合。
- 14:23 — Jik Tek 反制：对付对方侧踢——jeet que 加向后跳步，并在后撤时**脚尖向上踢入腹股沟**（正面脚尖踢）；“要戴护裆”；如果踢中，对手会像“扎根了一样”，可直接入身；如果没踢中，则使用常规三种入身组合。
- 17:40 — 手套练习（Joe）：不使用手靶的部分。第一半：对方侧踢 → ha pak、bui jee、o'ou tek、交叉拳—勾拳—交叉拳 → 捋手（lop sao）＋挂拳（gua choy，反背拳）→ 勾拳—交叉拳—勾拳 → 前腿圆踢（踢腿或身体——“看到哪里有空档就打哪里”）。
- 20:15 — 第二半：圆踢反制——肩部滚转（用肩胛骨／背部接招，“顺着拳头的方向滚”；低踢也要顺势滚，不然“我会把你轮胎里的气放掉”），回应勾拳—交叉拳—勾拳 → 摇闪并穿身（bob & weave）→ woang pak bui jee（格挡＋眼插）→ 交叉拳—勾拳—交叉拳 → 侧踢。
- 23:44 — 乒乓球训练：双方两半动作衔接成无尽的反制—再反制循环。“重点不是速度，而是节奏和配合”；“速度很容易掩盖错误——慢下来，动作才会干净。”
- 27:38 — 摔法 1：从捋手（lop sao）进入四字锁（figure four，手臂看起来像数字4）：抓住手腕和自己的二头肌，“把它向上撞进我的胸口”，然后坐下 → 腕锁。
- 29:32 — Jow Sao House 连续动作：交叉拳 → jao sao（跑手）绕过格挡；拉对方——如果他往回拉，就从手臂下方低头钻过，耳朵贴着他的身体（否则旋身脱离时会撞上肘击），手掌朝下放在他的髋部 → 把他压向地面 → 手臂横过脸部，跨过去 → 单腿臂弯锁；抬起他的头以防他翻身脱困。
- 33:51 — 侧向转换：由对手**决定**把他摔向哪一侧：如果他没有往回拉，就摔向另一侧，让肩膀顶入他的腋窝。臂弯锁应成45°，不要成90°——角度更紧，像夹皱一样收紧，膝盖缩小间隙，手压在脸上防止逃脱。
- 36:11 — 单腿绊摔：jao sao → 拉拽＋肩撞 → 勾住颈部，向内踏步，做绊摔（勾绊并抬腿扫倒）→ 跨过去 → 臂弯锁，控制头部。
- 38:11 — 连续动作收尾：从侧踢起手，动作相同（ha pak → 立即 jao sao）；如果绊摔失败，就把头钻到手臂下方，跨过去并向后坐入臂弯锁。
- 39:54 — 结尾：“耐心一点，不要硬把动作做出来；慢下来，动作才会干净，然后速度自然会提升。”

**编排用视觉细节：**
- 一直是同一间温暖色调的 Century Vision 健身房：木墙、蓝色窗户、一张带空手道剪影的海报、健身球。Ron 穿红色T恤和综合格斗手套；Diana 穿红上衣和黑色条纹裤；Joe 穿黑色T恤。
- 标题卡：基础入身／Jeet Que／Jik Tek 反制／圆踢反制／Wom Pac Biu Gee／Jow Sao 向左侧摔倒／Jow Sao 双腿扫倒。
- 距离从较远处开始（踢击距离）——这在截拳道教程里不常见：眼插时可以看到滑步加躯干前倾，随后迅速进入黏手和地面缠斗。
- 中速乒乓球式训练像是双方不停交谈般交换击打——适合作为长打戏中势均力敌双方“对话式”交手的模板。
- 地面收尾：搭档沿垂直方向直接倒下（向中线压制），以控制头部的臂弯锁收尾——画面上清晰易读的“定格收尾姿势”。
