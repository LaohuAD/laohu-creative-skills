# 截拳道黏手（JKD Trapping；49:47）

**核心内容：**一整套振藩功夫／截拳道黏手教学DVD：拍手（Pak Sao）和捋手（Lop Sao）作为两种基础“手法”、各自的循环训练、将循环组合成实战对练，以及把所有训练迁移到焦点手靶上的练习。贯穿始终的观点：黏手是一种培养能力的训练（像跳绳），用于训练敏感度和对压力作出反应，而不是背诵固定套路。

**按时间码排列的技术：**
- 01:41 — 开场，Ron Balicki 与 Diana Lee Inosanto。回应批评者：UFC／NHB 里有“大量黏手”——Shamrock、Ruden、Couture；任何“拍一下再打”都属于手部制动攻击（Hand Immobilization Attack）。
- 03:02 — Dan Inosanto 的比喻：训练就像跳绳——它培养一种能力，但在打斗中“你不会真的跳绳”——不要硬把训练方法塞进实际情境。
- 04:02 — 拍手（Pak Sao，pak＝拍，sao＝手）。参考位置：两臂之间搭起接触桥（“除了《龙争虎斗》，没人会这样打”——这是训练用的参考位置）。拍手＋打（Da，da＝任何击打：冲拳（chung choy）、挂拳（gua choy）等）。
- 05:22 — 从有接触和无接触两种状态练拍手；用“随便丢几下”来判断对手是用前手还是后手格挡。这是引诱对方反应。
- 06:23 — 五条拍手线路：（1）越过桥接——越过手臂打向脸；（2）分线入手——从双臂之间进入；（3）低位——打向身体；（4）跑手（jao sao）——绕钩过去，并朝外侧做假动作；（5）挂拳（gua choy）——直线被封住时打反背拳。
- 09:31 — 捋手（Lop Sao，拉手）：“就像两辆车相撞”——她把我拉向击打，动作方向相反。讨论拇指是否参与抓握——“每件事都有代价，适合你的就是适合你的”。
- 11:33 — 关键点：从手臂下方把手楔入并向上走，不要从上面压过去——从上方压会被缠住；章节标题“手从手臂下方楔入并向上”。
- 12:22 — 拍手↔捋手组合：感受压力，再据此选择拍击或拉拽；“要先把这门艺术拆开，才能理解它”。
- 14:44 — 中线理论：自己的中线＝“从胸口伸出的一支铅笔”，母线＝“两人头部之间的一根线”。对手手臂越过你的中线 → 用捋手；留在中线内侧 → 从内侧拍手（loy pak sao／noy——外侧）。
- 16:45 — 捋手循环：膀手（bong sao，放松的“翅膀”）＋冲拳（chung choy）；搭档向下捋手，以前臂对前臂击打（也可用于前臂强化，像李小龙对着桌子练前臂）。17:35 — “把手臂向外旋出去”，不要用肩膀抬起（保护小圆肌）。
- 19:04 — 护手（Woo Sao）——保护手在后方等待：“为什么要用两只手挡一次攻击？”拉拽动作会产生“呼啸的风声”，像鞭子抽击一样。
- 21:44 — 捋手换边：感受对方抓握并抓住那只手（“我偷过来——她又偷回去”），把循环切换到另一侧。
- 23:00 — 在循环中插入冲拳（Chung Choy）：高位线路——搭档拨开、做膀手、再捋手；低位线路（24:16）——像拳击手一样打身体，对手沉肘防守，再向上滚入膀手；黏连原则——不要失去接触。
- 26:16 — 双拍手（Sang Pak）循环：连续拍两下，回应动作是擦颈手刀（sat sao，朝喉咙的反手手刀）；目标包括用拇指抹眼、掌击耳朵／脸部、手击喉咙。“这不是体育比赛——这是街头格斗。”
- 28:23 — 双拍手中的换边：回撤跟踪（跟住／转移手臂并反击）、切换内外侧；两侧都要同等练习“节奏、时机、敏感度”。
- 31:20 — 组合训练：将捋手循环＋双拍手循环组合成实战对练：“把训练变成游戏——这样有趣，也能得到更多次练习。”33:53 — “截拳道练习者会到框架之外寻找解决方案”，“我们是终极窃贼——从所有人那里偷师”。
- 34:46 — 拍手／指插（Bui Jee）循环：拍手＋眼插（bui jee）如楔子般进入；安全说明：手指朝上，“知道这件武器在那里，只是我们现在不用它”。
- 37:00 — 捋手—拍手循环：先做捋手，再接拍手；根据感受到的阻力，选择拍手或捋手。
- 38:41 — 焦点手靶黏手（搭档 Joe，黑色T恤、红色手靶）：把对方格挡手拨到**侧面**，而不是向下拨到自己身上（“把格挡拨到侧面”）；交叉拳 → 他把拳拨开 → 捋手＋反手击打。递进组合：交叉拳—捋手 → 交叉拳—勾拳—交叉拳—捋手 → 交叉拳—勾拳—交叉拳—捋手—勾拳—交叉拳—勾拳。
- 43:06 — 手靶上的 Woang Pak Bui Jee：后手格挡＋眼插；接完勾拳后，手“弹回”并成为一次眼插。递进组合：勾拳—眼插 → 勾拳—交叉拳—勾拳—bui jee → 再加交叉拳—勾拳—交叉拳。
- 46:43 — 将两部分连起来：交叉拳—勾拳—交叉拳／捋手／勾拳—交叉拳—勾拳／woang pak bui jee／交叉拳—勾拳—交叉拳……每回合3分钟：第1分钟慢速，第2分钟加速，第3分钟“全速冲”。
- 48:51 — 结语：“不要硬把动作做出来”，要培养肌肉记忆，保持开放心态。

**编排用视觉细节：**
- 场景：温暖色调的木质健身房，墙上有护垫、蓝色窗户；Ron 身材结实，穿印标志的红色T恤；Diana 穿红上衣和带白条纹的黑裤。章节之间出现标题卡（Pac Sao／Lop Sao／Cycle Drill／Combination Drill／Focus Mitt Trapping）。
- 距离：黏手距离，肘部几乎一直弯曲，前臂持续接触；捋手循环中，双方采用镜像架势，手臂像钟摆一样“滚动”——催眠般稳定的节奏，很适合作为对话场景的背景。
- 训练节奏：缓慢、均匀的循环 → 突然切换／击打 → 回到循环。高速动作像鞭子抽打：捋手会让搭档的头部猛然一甩。
- 女教练击打一名体型更大的男子——动作力学来自身体结构，而非蛮力（可作为男女体型悬殊场景的参考）。
- 手靶部分：持靶者站在架势中，用手靶像手一样“回应”对方——用器材练黏手看起来像打斗，而不是健身。
