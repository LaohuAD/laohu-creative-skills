# 李小龙截拳道——步法（Bruce Lee's Jeet Kune Do – Footwork；20:40）

**核心内容：**完整展示截拳道基础与进阶步法：架势 → 前／后滑步 → 蹬步 → 侧步 → 转步 → 快速换势 → 爆发步 → 钟摆步。拍摄环境：明亮房间、木地板，地上用**白色胶带**标出架势对齐线；频繁特写脚部；学生 Shin 用于演示和纠错；插入李小龙照片和一段打斗片段（约16:30）。

**按时间码排列的技术**
- 00:04–01:50 — 理念：“成功击打和出拳的艺术，就是正确判断距离的艺术”（李小龙）；Tat Wong 的比喻：没有步法的格斗者就像一辆你无法移动的坦克；李小龙会跨过6–7英尺的距离——“别人挡不住他”。截拳道步法很大一部分来自击剑（衔接距离），但手里没有武器——必须同时考虑速度和力量的产生。
- 02:00–02:55 — 沿胶带线演示截拳道架势：前脚脚尖既不朝正前方，也不朝侧面——而是处于中间角度；后脚跟抬起：“它像一个扳机。像手枪一样——它让我们得到所有力量和速度。”后脚掌平贴地面就无法灵活移动。（约110–170秒的画面：沿白线拍脚部特写。）
- 02:57–04:30 — 前／后滑步：后脚留在原地，前脚短促移动；它会缩短一小段距离，“让你多出一点距离，可以打到对手”；后退时做镜像动作，“转移我的重心，然后我就能再次前进”。地上的胶带线帮助自行修正对齐。
- 04:32–06:45 — 向前／向后的蹬步：动作相同，但后腿跟着前腿**移动**（连续动作）——“砰，然后再砰”；常见错误——躯干移动过头，导致失去平衡；重心比例为60/40或50/50——“自己试试看”；距离演示：蹬步明显跨出更大距离（约340–400秒的画面：沿地板长距离滑行）。
- 06:46–09:05 — 纠正学生 Shin 的动作：站姿宽度约等于肩宽再加一点；“这样不行，因为你没法移动……要找到像猫、像老虎一样的移动方式——随时准备砰地出击。”（约420–540秒画面：“演示技术”字样，Dan 从侧面调整 Shin 的站姿。）
- 09:07–11:04 — 侧步：维持相同姿势，向左／右移动；检查动作质量：“我的对线仍然是一条直线……这时你就知道步法还不错”；也可以结合躯干闪避，躲开拳头——动作要“非常、非常流畅”，不能像抽动一样。
- 11:05–13:06 — 转步（约11:05出现“转步”字样）：后退躲避抱摔会让你被摔倒；转步是围绕中心改变角度，可以向右或向左，甚至朝着对手移动（“刚才争取到一些距离”）；搭档演示：对方抓腿时，转步让你离开攻击线，“那样我就可以做自己的动作……这样我就能打击他。”（约700–790秒的画面：搭档弯腰抓腿，Dan 斜向移动，同时保持在出拳距离。）
- 13:07–14:25 — 快速换势：迅速切换架势左右侧；不是直线跨步换脚（“太慢了”），而是沿弧线移动——“动作更像一条曲线”，同时保护中线。以慢动作演示。
- 14:27–15:59 — 爆发步：移动距离最长，把蹬步＋钟摆步＋踢击（通常是侧踢）组合起来；“Bruce 能跨过5、6英尺打到人。我们凡人可能只有3、4英尺”；训练口令：“一、二、三”——分步练习，但不伸腿踢击（约880–960秒的画面：在房间里长距离移动）。
- 16:16–18:45 — 钟摆步（约16:30插入黑白李小龙打斗画面，并出现“钟摆步”字样）：“截拳道标志性的步法”，像钟摆一样——“一只脚替换另一只脚的位置，这就是动量”；这是**隐蔽**步法：“你要隐藏自己的意图”——让对手以为你静止不动；与泰拳不同，截拳道会隐藏踢击；重心保持同一高度——不要上下弹跳或下沉；把后腿藏在前腿后面（“藏到前脚后面”）。
- 18:45–19:35 — 钟摆步＋踢击：拆成2–3段练习：“钟摆步——先只抬膝盖”，再练半程动作，最后做侧踢；组合：向前滑步 → 钟摆步 → 侧踢。
- 19:36–20:40 — 结论：反复观看，在家里贴一条胶带，“多练很多次，直到它像走路一样自然”；结尾“朋友，像水一样”。

**编排用视觉细节**
- 架势：强侧在前，脚尖约呈30–45°，后脚跟始终抬起（“扳机”），膝盖放松；站幅是肩宽再加一点；地上胶带可作为训练场景里的对齐线道具。
- 按距离递进的步法：滑步（短距离）→ 蹬步（中距离）→ 爆发步（最远，普通人3–4英尺，李小龙5–6英尺）——可沿这条梯度逐步升级打斗。
- 针对抱摔的转步：抓腿 → 绕前脚改变角度，主角留在对方侧面并保持能出拳的位置——干净的电影式反抱摔节拍。
- 钟摆步：躯干不动，两脚在下方交替——像踢击的“隐蔽蓄力”；适合看似静止的主角突然踢出侧踢。
- 节奏／移动质感：动作都“非常流畅”，像猫一样；学生常见错误的对照包括：躯干倾斜、站幅太宽／太窄、重心上下弹动。
