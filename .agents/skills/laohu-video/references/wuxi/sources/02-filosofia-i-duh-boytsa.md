# 02 — JKD 格斗心理与策略

**对编舞的补充：**格斗中的心理层面——JKD 高手在银幕上**应该**是什么样：致命交手中的日常平静、毫无戏剧化表演、每个动作都经济。本书提供节奏用语（破节奏、半拍、韵律、“节拍器”）、截击逻辑（截击拳／预先截击）、成对编舞中高手与新手的对比，甚至包括李小龙本人的电影摄影原则：使用远距离固定长镜头，而非剪辑蒙太奇。

## 心理状态与银幕行为

- 本书的关键段落：“实战中，他的心态应当平静……步伐轻盈而稳健，眼睛不凸出，也不以疯狂的怒意盯着敌人。他的行为与平常日常生活中的行为没有任何不同……没有任何事情会泄露他正在进行一场生死格斗。”
- “像幽灵一样迅速移动，像纯真一样平静。匆忙的人会输。”
- “动作时，像水一样；静止时，像镜子一样；回应时，像回声一样。”
- “我就像狂暴、翻涌的波浪中，月亮那静止不动的倒影”——外在混乱中的内在静止。
- 没有“我正在做这件事”：动作自然而然地发生，不带表演。“不是演员，而是戏剧。”意识到自己的“自我”是身体行动最大的障碍。
- 目光：采用周边视野，而不是将视线集中在对手身上——眼睛落在一点，意识却“弥散”到广阔视野中。视觉上，是柔和、不会停留在任何物体上的目光，是眼角“朦胧”的余光；不死盯，也不眨眼（眨眼是对手会诱发的弱点）。
- 站姿中的身体如同“扑克脸”：站姿不向对手透露任何意图，正如扑克玩家的脸不会透露手中的牌。
- “你像一只拱起背、准备跳跃的猫，但与猫不同，你是放松的。”下巴藏在双肩之间，手肘遮住身体两侧，身体收拢成紧凑的球。
- 后脚跟抬起，“像一颗上膛的扳机”。膝盖总是略微弯曲——高手不会被人逮到关节伸直；“优秀的运动员总像急着找裤子穿一样奔跑”。
- 书中明确指出，愤怒、恐惧等情绪会增加反应时间——在这套体系里，愤怒的格斗者客观上更慢、更紧绷。
- 格斗前：保持安静镇定，而非兴奋或摆造型；“紧张不安”被视为内在能量储备，而不是软弱。

## 本书措辞中的原则

- 简洁：“截拳道不绕弯子……它直奔目标。简洁是两点之间最短的距离。截拳道的艺术就在于化繁为简。”
- “最高的发展追求简洁；未充分发展的则追求外在美观。”
- 无形：“截拳道偏好无形，因为它可以呈现任何形式；它没有自己的风格，适用于所有风格……运用所有方式，却不受任何方式束缚。”“无形是最高形式的自我表达。”
- “要保持空无，没有风格或形式，这样对手就无法找到你的‘钥匙’。”
- 空无／无念：“没有思想的地方，只有现实。”“把你的杯子倒空，好让它能被装满。”
- 不经准备地出击：动作“从静止开始，没有可见准备，流畅而毫不犹豫——突然到对手还没察觉就已命中”。击打可从手的任何位置发出，不必先摆出特定站姿或蓄势（像“压缩弹簧”，而非向后拉的手臂）。
- 鞭击原理：击打像一道波浪，从脚趾蹬地传过膝盖、躯干、肩膀，直至最后手腕一甩；手腕动作“延迟”到接触前的最后一刻。“不论距离如何，动作的最后阶段必须最快”——在击打中加速，而不是在出击前加速；击打要“穿过”目标，而不是只到达目标。
- 经济性：所有伟大的格斗者都“很少做无用的动作”；动作持续流动——直线动作与弧线动作结合，中间没有停顿或微停顿；紧张是刹车。
- 截击：截击拳是“在对手发动攻击的同一时刻，精准把握时机打出的一击”，覆盖攻击方向并保护出手者；配合向前跨步／倾身，迎着攻击打出。攻击正在暴露而不是正在闭合的目标部位；最佳时机是对手准备出招、动作进行到一半、正在吸气时。
- 格斗准备公式：“从中立状态瞬间爆发”，并立即回到站姿；“一切都处于持续、平滑的流动之中。自由、速度、变化。”

## 高手与新手

- 高手：“始终行动流畅而优雅。他似乎滑向对手，用最少的力、不易察觉地改变距离”；他的动作有韵律，足以把节奏强加给对手；他控制敌人的反应，带着明确目的行动，而非抱着犹疑的希望。“即使竭尽全力，移动也轻松自如。”
- 新手：“动作紧绷、多余，费力过度”；动作笨拙，无法保持距离，总是迟一步，“总是在行动前先宣布自己的意图”（动作预兆）。他“过于用力”——急着出手、猛推、强迫局面；普遍的紧张会让自己的击打变慢。
- “套路派”（传统格斗者）与之相反：“做出套路化的格挡，听着自己刺耳的喊声，却看不见对手实际在做什么”；“一台典范式的机械机器人”。“二流格斗者盲目遵从师父的示范……反应都是自动的。”
- “‘秘传技法’和令人印象深刻的姿势会让缺乏经验的新手赞叹”——像镀金的纸片而非金币。漂亮姿势 = 软弱者／摆造型者的标志。
- 佯攻高手：“用佯攻把对手缠得晕头转向”，将真假击打结合起来，让两者无法区分，从而“指挥”对手。“当两位速度、力量和技巧相同的格斗者相遇时，佯攻高手会获胜。”
- 掌握技艺的三个阶段（李小龙 1965 年引文）：原始阶段——完全无知；自动阶段——心思被分析动作占据；自发行动——适应对手的技法并暴露其弱点，而不是强加自己的风格。
- “学习前，一拳只是一拳……现在我理解了武术，拳只是一拳，踢也只是一踢。”
- 高手的步法：小步移动，重心绝不失控；重心落在前脚掌上；双脚绝不交叉——不会被击倒。

## 实战

- 实战是“简单明了的”，“不是僵硬固定的东西，而是非常鲜活的东西”——与仪式化套路和各流派的“想象力混乱”相反。
- 不带感伤的残酷：“让对手碰到你的皮肤，你就刺穿他的血肉；让他刺穿你的血肉，你就打断他的骨头；让他打断你的骨头，你就取他的性命。不要顾虑自身安全，把性命摆在他面前。”
- “忘掉胜负，忘掉骄傲与疼痛”；格斗时不回头、不分心，移除所有障碍——情绪、心理和智力上的障碍。
- “当你的性命处于危险中，你还会讨论用什么方法保护自己吗？”——真实格斗中，理想与风格正统都会瓦解。
- 格斗节奏：两个势均力敌的格斗者进入共同节奏后，“较量就会陷入僵局”——获胜者用短暂停顿或突然动作打破节奏；对手就会在调整“节拍器”时遭到击打。脱离节奏的一击会出其不意地命中。半拍：在对手动作进行到一半时出击。
- 选择击打时机要看对手何时暴露：他迈步、蓄势、吸气、注意力分散、失去平衡时——“抓住无助的瞬间”。打空会让他成为容易攻击的目标。“即使技法完美、速度如闪电，若在错误时机发动攻击，也没有帮助。”
- 没有那种停在目标几英寸之外的“非接触式”攻击——那是“扬起灰尘”；真正的击打要瞄准一个正在移动的目标并打穿它。
- 什么都用：拳和脚、肘、膝、头、擒抱、绞技、摔投、固定控制；近身格斗是“爆发式机动”。“我们必须用一切手段保护自己；偏爱一样东西会破坏我们的完整性。”
- 节省力量作为戏剧结构：凭时机取胜而不是凭体量——“轻量级选手挥击快速，打得就像重量级选手一样重”；没有速度的强壮格斗者“像一头徒劳追着斗牛士跑的公牛”。
- 李小龙本人的电影摄影方式（与查克·诺里斯在斗兽场的打斗）：不要剪辑短镜头制造“狂乱的错觉”——“用远距离、固定的长镜头拍摄”，让整场打斗始终清楚可读。
