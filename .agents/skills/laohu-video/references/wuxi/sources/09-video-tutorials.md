# 09 — JKD 动态训练方法
**对编舞的补充：**书中没有的真实**动态**：击打如何实际“弹出”并收回（收回比伸出更快）、击中时重心下沉是什么样、躯干静止时腿部如何在下方切换（钟摆步）、稳定如催眠般循环的黏手训练如何突然打破循环并爆发。还有实际速度与停顿（2 次慢速示范 → 2–3 次“正常速度” → 重置）、搭档被击中后的反应（低头、轮廓被打乱、“扎根”），以及训练场景的完整质感：手靶、木人桩、地板胶带、击掌练习、静力训练绑带。这是动画参考——书籍提供“做什么”，视频展示“如何移动”。

## 1. 动作中的击打力学——视频展示而书中没有的内容

- **前手直拳——“滑步 + 弹击”：**手先出击，身体随后由后腿蹬地带动；脚在击中**之后**才落地（“手先出，脚蹬地，击中后落地”——[OgGWAhpUIjk](video/OgGWAhpUIjk.md)，黄锦铭）。拳头—肩膀—后脚呈绷紧的线，“一条完整的直线”，就像步枪抵在肩上。力量 = 质量 × 速度；“力量从地面向上来，再回到地面。”
- **不转动躯干：**JKD 区别于拳击的主要标志。完全扭转 = “只把半边身体送进拳里” + 暴露下方区域 + 视线受阻（[RTuGiLKA1I8](video/RTuGiLKA1I8.md)）。正确做法：身体“向前推进”，击中时“重心下沉”——可见的沉身，后脚被拖着跟上，肩膀仍几乎正对前方。过度扭转的长拳——“摆拍式动作”。
- **鞭打／抽响／收回：**击打像鞭子：“一旦击中，你会转成弧线，然后它立即弹回来”（[RTuGiLKA1I8](video/RTuGiLKA1I8.md)）；刺拳是“像鞭子一样的伸击”，最后几厘米带着极小的弧线，“抽响目标——然后收回”（[cQ-IOUnSOxw](video/cQ-IOUnSOxw.md)）。收回**总是**比伸出更快——这是动画节拍的关键。动画的动能链：后脚 → 髋 → 肩 → 手（“轰—轰—轰，三个点、四个点”）。连击中，后一击“从第一拳后面击出”——形成频闪般的节奏。
- **拳头竖直**，用下方三根指节，手肘向内、向下；击打前躯干静止得“像岩石”——身体完全不弹跳（与拳击的弹簧感相反）（[cQ-IOUnSOxw](video/cQ-IOUnSOxw.md)、[fOFHFta8aFw](video/fOFHFta8aFw.md)）。
- **“两列火车”／剪刀动作：**拉手——一只手拉，另一只手在同一节拍出拳，动作相反，“像两列火车撞在一起”；拉力不是来自手，而是手肘向肋部拉 + 躯干转动；对手向前、向下“低头”，轮廓被打乱（[ad17nEj_TBg](video/ad17nEj_TBg.md)）。相近的比喻——“撕纸”：双手沿相反方向撕一张纸（[RTuGiLKA1I8](video/RTuGiLKA1I8.md)）。
- **3 种反手拳**（[7M3FWG31ybE](video/7M3FWG31ybE.md)）：(1) 基本型——直线动作，采用前手直拳的力学，拳背朝外，髋部向前，从意想不到的远距离打到对手；(2) 弹甩型——手在脸前甩过，髋部朝**相反方向**转，立即衔接下一击；(3) 重击／终结型——躯干完全转动，“像挥棒球棒”，全力投入，“基本无法格挡”，随后停顿恢复。绝不从背后挥击（“你会把骨头打断”）——在那种位置用锤拳。“不是终结重击——是让人眩晕的快速击打。”
- **不露预兆：**完全不蓄势／后拉，“手先于其他任何部位移动”（[AWHjwZdCeDg](video/AWHjwZdCeDg.md)）；方法——先夸大动作（大幅动作，“预告——我不在乎”），再“不断缩小、缩小”（7M3、RTu）。
- JKD 出拳的力量比传统空手道拳更大；“把整个髋部放进去，再弹甩出拳”（[_naZzjLzVXk](video/_naZzjLzVXk.md)，Nishioka 测试）。

## 2. 动作中的步法

- **摆桩姿势：**强侧朝前，站姿底盘窄而高（肩宽再略宽一些），前脚尖约转 30–45°，膝盖有弹性，后脚跟抬起——“它像扳机，像一把手枪”（[wmFPVRe44q4](video/wmFPVRe44q4.md)）。拳头放松。李小龙的一条笔记：“步法、站姿、协调、对齐”（[OgGWAhpUIjk](video/OgGWAhpUIjk.md)）。
- **踏步并滑 vs 推滑步**（[z1aTbc1Bngs](video/z1aTbc1Bngs.md)、[_naZzjLzVXk](video/_naZzjLzVXk.md)）：踏步并滑——训练中的“两步动作”（前脚踏步 + 后脚拖上）；推滑步——由后腿“跳板”发动的单次格斗冲击：“一个动作——砰。就这样。”呈现为推—弹，是决斗时紧张的脉搏。
- **悬浮／“脚下有轮子”：**躯干沿一个高度滑行，“避免力量向上走，要始终向前发力”——双脚擦过地面，头部不作垂直移动（z1a、wmF）。
- **步幅距离层级**（[wmFPVRe44q4](video/wmFPVRe44q4.md)）：滑步（小间距，30–60 厘米）→ 推步（中等距离）→ 爆发步（最大距离：推步 + 钟摆步 + 侧踢；“李小龙——5–6 英尺，普通人——3–4 英尺”）——可以直接用于打斗升级的阶梯。
- **钟摆步**（[ClfYe9Uly28](video/ClfYe9Uly28.md)、wmF）：“JKD 标志性步法”——双腿在躯干**下方**切换，“像两个球互相撞击”，身体质心稳定；隐蔽步法——“你在隐藏意图”：英雄表面静止，突然侧踢爆发。两拍的“一二”节奏：后撤 = 踢击已蓄势（“我躲过了它——而且踢腿已经在这里蓄好”），无需停顿便反弹出击。
- **侧步／转轴步／快速移位**（wmF）：侧步维持对齐；对付抱腿摔时转轴——绕前腿斜向闪避，英雄仍在侧面并保持出击姿势（电影化反摔节拍）；快速移位——沿弧线切换站姿，而不是交叉迈步。
- **破节奏练习**（[z1aTbc1Bngs](video/z1aTbc1Bngs.md)）：声音／击掌反应——“一！……二—一！二……”从完全静止开始，打破可预测的移动模式；画面意象：起跑线上的跑者、老虎、弓箭手。SAA：斜向移出 45° + 同时出击——“所有动作必须同时发生”（[AWHjwZdCeDg](video/AWHjwZdCeDg.md)）。

## 3. 黏手目录

- **27 门**（[VxmkjF38FeI](video/VxmkjF38FeI.md)，Hajnasr；27 是为了纪念李小龙生日）：门 = 双手接触（touching hands）后形成的“入口”：若击打被挡住，手不收回，而是制住格挡并继续出击。上／中／下／外门切入；中线目标（眼睛、喉咙、太阳神经丛、腹股沟、膝盖）。核心——第 1 门：拍手 + 出拳 + 收回；接着拉手 + 刮拳（gua choy）、内侧膀手、低—高 PIA 佯攻、“漏手”（拳头倒转后从缝隙穿过）、绕手（跑手——小圈绕过肘部）、肘击、拉住头部后头槌、压制后打上勾拳、掌击压脸后膝击，第 27 门收尾——不间断反黏手击打链，“直到对手倒下”。示范节奏：2 次慢速 + 2–3 次“正常速度”——“轻拍—轻拍—爆发—停顿”。“还没看见拳，就已感觉到它。”
- **拍手／拉手机制**（[XpOTci5P7wQ](video/XpOTci5P7wQ.md)——Balicki DVD；[ad17nEj_TBg](video/ad17nEj_TBg.md)、[EFW6GrwDVEU](video/EFW6GrwDVEU.md)）：拍 = 拍击（拍—压住），拉 = 拉扯；按压力选择：对手的手横过你的中线 → 拉；他的手留在内侧 → 拍。拉手——“像车祸：他撞进我，我也击进他”；向上从手臂**下方**楔入；护手（woo sao）——“为什么一次格挡要用两只手？”5 条拍手线路：桥上方／分线切入／低位／绕手／刮拳。躯干转动至关重要——否则双方都仍以 50/50 的角度处在攻击线上。
- **循环练习与黐手滚动**（XpO、EFW、[St8jiC_0NFY](video/St8jiC_0NFY.md)）：前臂如催眠节拍器般滚动（盘手：摊／伏／膀）约每秒一拍 → 任意一拍突然打破节奏——拉手 + 击打——再回到循环。“感觉到什么，就移动”——靠触觉而非视觉反应，“不思考”。循环 → 打破 → 循环模式——是黏手场景最好的节奏模板；高速练习时，拉手真的会猛扯搭档的头（甩鞭效应）。
- **“不要格挡——同一拍内拨挡 + 击打”**（[fOFHFta8aFw](video/fOFHFta8aFw.md)）：JKD——“攻击之术”，“严格说来，根本没有格挡”；格挡是“僵硬的阻停”——应该转移力量。理想状态——一个节拍：“我的格挡其实就是手臂本身。它就是击打”——你的中线直拳本身就用前臂引开对手的攻击；先拨挡再击打（“一二动作”）已经是一种折中。拨挡幅度 10–15 厘米，全程不超出身体轮廓。
- 黏手是一种身体素质练习，“像跳绳”（XpO，Inosanto 的比喻）：格斗时不强迫使用；手部接触参照点——“除了《龙争虎斗》里的人，没人那样打架。”

## 4. 截击与反击

- **截踢——截击式侧踢**（[wJjnmZjwTBM](video/wJjnmZjwTBM.md)）：对付前踢／回旋踢——**不收膝蓄势**：腿直接抬起，脚掌转平，躯干倾斜作反向配重（“移位、倾斜、绷直腿”）；在对方踢击的**前 1/3** 段接触——攻击者像“踩上看不见的台阶”，随即停住。强力版本——踢穿膝盖，对手折倒。向上跳近 10–15 厘米，弥补高度差。立即恢复站姿。
- **截踢逻辑：**“要够到我，你必须向我移动——你的攻击给了我一个截击的机会”（[_naZzjLzVXk](video/_naZzjLzVXk.md)）；切入时低位截击膝盖／胫骨，就像“停止信号”（[Pa2YV2zcfNQ](video/Pa2YV2zcfNQ.md)）。
- **剪腿对付回旋踢**（[M8f5o-mg6ic](video/M8f5o-mg6ic.md)）：违反直觉——切入回旋踢弧线**内侧**（“你的逻辑会告诉你不要这么做”），胫骨楔入支撑线路——踢腿者不是被“击中”，而是失去结构、自己垮倒。电影节拍：反派踢出华丽的回旋踢——英雄向内迈极小一步，反派倒地。
- **Toy Ma 闪踢法**（[g7OInuomm2s](video/g7OInuomm2s.md)）：“后撤马步”——前腿迅速甩到后腿后方，躯干侧对，轮廓在原地收缩——踢击从距腹部 10–15 厘米处掠过；手部反击在攻击者的脚落地**之前**开始（“偷来的一拍”）。
- **侧踢反击**（[9xs25_whwcg](video/9xs25_whwcg.md)，Balicki）：哈拍（低位拍击，“像运球” → 弹出的指刺眼）；截脚（jeet que，前臂作“减震器”：压力强——弹回；压力弱——站稳）；直踢（jik tek，反弹 + 后撤，以脚尖踢腹股沟——“击中——对手原地扎根”）。用肩膀滚动接下回旋踢（“顺着拳的方向滚开”）。
- **切入／搭桥缩短距离**（[Pa2YV2zcfNQ](video/Pa2YV2zcfNQ.md)、9xs、AWH）：切入是低位滑步弓身，而非跳跃：“矛”手先于脚迈出，在 1 个节拍内从踢击距离搭桥切入黏手；用指刺眼（bui jee）开场——“像胡迪尼一样，让他相信你真的伸手去够他的脸”；ABD——“佯攻要完整打出一整拳，不要只打一半”。电影组合的距离推进：踢击距离 → 黏手 → 拳击 → 摔倒／关节锁（[_naZzjLzVXk](video/_naZzjLzVXk.md)——明确说“这个可以用于电影”）；地面收尾：绕手 → 摔倒 → 45° 角扶臂压肘（9xs）。

## 5. JKD 训练是什么样（训练场景参考）

- **手靶／目标：**焦点手靶像“会回应的手”——黏着手靶像格斗，不像健身训练（XpO：格挡动作向**侧面**撞开，交叉拳—勾拳—交叉拳—拉手递进；每轮 3 分钟：慢速 → 加快 → “快快快”）；会发出清脆响声的小圆靶（7M3）；踢靶，持靶者后退——练习者用钟摆步切入追击（Clf）；小型白色速度靶（5OZ）；根据“不……还不行……还不行”计时的豆袋（_na）。
- **木人桩：**拉手力量测试——“如果你能推动木人桩，就能推动一个人”（ad1）。
- **静力绑带、肌腱力量**（[t08AT17B_ks](video/t08AT17B_ks.md)）：李小龙的 5 项练习——将绑带从脚下拉起，分 3 阶段伸臂（可直接作为分镜中的准备姿势）；竖拳俯卧撑，保持后“爆发向上”；双臂伸直举哑铃；用力推固定杠（姿势来自李小龙著名照片）。戏剧结构：静态用力颤抖 10–20 秒 → 爆发。“这是肌腱的力量……不只是肌肉。”
- **击掌／听觉练习**（cQ-、z1a）：从完全静止开始，在击掌声响时出拳／迈步；拍手者在视野之外——“盲反应”场景；破节奏口令。
- **滚动练习**（St8、EFW、XpO）：两人配对滚手——“冥想 → 闪电”；双脚并拢，戏剧性都在手上；最佳角度——严格的侧面，双手剪影清晰可见。
- **师徒调度：**教练绕行，亲手调整双脚／躯干，地板白胶带作为对齐轴线（wmF）；口令“放松。放松。放松”（cQ-）；黄锦铭在酒店地毯上只调整脚的微小角度（OgG）；女教练击打体格更大的男性——力量来自结构，而非蛮力（XpO）；穿运动鞋——“街头上的艺术”（9xs）。
- **场景色盘：**伦敦屋顶 + 贴有李小龙海报的昏暗健身房（5OZ）；2004 年木质 DVD 摄影棚（XpO/9xs）；有全景天际线的阁楼（RTu/Pa2）；顶层公寓（aqn）；围栏后院（ad1/EFW）；塞满泰拳沙袋的健身房——伪纪录风格的研讨会（M8f）；1998 年 VHS 会议室（OgG）；阴阳图案拼接地垫（Vxm）；档案黑白 8 毫米影片——李小龙与 Coburn 在后院（_na）。

## 6. 街头逻辑

- **街斗的 3 个错误**（[aqn6cy3jB0k](video/aqn6cy3jB0k.md)）：(1) “以为这会是一场公平的格斗”——偷袭、藏刀、不讲规则；(2) “让攻击者知道你想打架”——举起拳头 = 冲突升级；JKD 的替代做法：摆出具有欺骗性的中立姿势，张开手掌说“我不想惹麻烦”，重心早已放在后腿——隐形的第一击可以从这里发出；(3) “高估时间与距离”——攻击者只离 1.5–2 步时，一个弓步就能比你的反应更快地合上距离。
- JKD 是自卫，不是运动：“我们想在几秒内结束”（z1a）；“这不是运动——这是街头格斗”：抹眼、掌击耳部、手掐喉咙（XpO）；打斗拖得越久（“一、二、三”），风险越大（fOF）；手杯与搭档提醒标出“不讲规则”的目标：腹股沟、眼睛、喉咙、膝盖。
- 场景对比：在讲究的环境中发生“一个字引来另一个字”的冲突（玻璃、港口全景），“平静 → 爆发”的节奏——1 秒的动作闪光穿插在长时间静止对话中（aqn）。

## 7. 动画师的时机／节奏

- **所有视频的基本节奏公式：**稳定循环／静止 → 突然打破 → 爆发 0.5–1 秒 → 重置／恢复。黏手练习约每秒一拍，黐手滚动每秒 2–3 圈，在不可预料的一拍中爆发（EFW、St8、Vxm）。
- **单次击打中的节奏：**收回比伸出快；在准确的击中帧让重心下沉；每次切入后连续打 3–5 拳，然后恢复站姿（5OZ）；“一、砰”——防守与攻击在一个节拍内完成，不要做“一二”（fOF、AWH）。
- **对练节奏：**每组短促爆发 1–2 秒，中间停下来恢复（5OZ）；乒乓式反击／回击练习——以中等速度连续“交谈式出拳”，可作为势均力敌者之间长篇“对话”场景的范本；“关键不是速度，而是节奏和默契”（9xs）。
- **截击会偷走一拍：**反击在对手完成攻击之前就开始——对方踢击前 1/3 处截踢（wJj）；对方脚落地前手已反击（g7O）；回旋踢弧线还没过半就切入（M8f）。
- **隐藏蓄势：**钟摆步——外表静止，毫无准备动作地出击（wmF）；声音触发后从完全静止开始（cQ-）；破节奏——间隔不可预测（z1a）。
- **训练速度层级：**慢速／干净 → 正常 → 闪电速度（“用速度掩盖错误很容易——放慢速度”，9xs）；重击反手拳是唯一“大幅挥击”的画面，完全发力，随后停顿（7M3）。
- **剪辑对比：**冥想般的长篇独白 vs 1–2 秒的档案爆发镜头（_na）——预告片节奏范本。
