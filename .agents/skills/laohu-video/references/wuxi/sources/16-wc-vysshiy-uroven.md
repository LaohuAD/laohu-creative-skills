# 16 — 咏春高级技法

**对编舞的补充：**
- 第三套、最高级的套路——标指套拳（Biu Jee Tao，“标指套路”），以照片阶段呈现：标指、斜向肘击、转腕动作。
- 完整的木人桩法序列（116 个动作）——包含可直接使用的近战“一个节拍内格挡 + 击打”组合。
- 28 种防守—反击格斗技法及其目标点（脸／喉／躯干／膝盖）——可直接转化为打斗节拍的分镜。
- 新的进阶击打动作：Kup Jarn 肘击、Jut Sau 掌缘劈击、Wun Jeui 掌根击。
- 原则：中线、攻防同时、近距离、动作经济、阴阳（柔克刚）。

## 进阶原则（用于场景物理）

1. **中线：**保护自己的中线、攻击对手的中线；击打沿最短直线进入中线平面。
2. **同时性：**双手同时工作——一只手格挡／控制，另一只手在同一节拍击打。没有“先格挡，再击打”的阶段。
3. **经济性：**防守到攻击之间只用最少动作；不蓄势，不走大幅轨迹。
4. **黏手：**前臂持续接触，感知对手的压力（黐手技巧）；格斗主要用手，较少踢击，踢膝盖和腹股沟。
5. **近距离：**格斗者缩短距离，贴身出手；最贴近时可以用肘。
6. **发力（标指）：**手和手臂全程放松，只在最后几分之一秒绷紧肌肉——打出“穿透式”的鞭击。通过用手指刺穿纸张来训练。
7. **拉向自己：**将抓住的对手手臂拉进自己的击打——“叠加速度”，使冲击力倍增。
8. **阴阳：**以柔和的闪避／躯干转动应对刚猛攻击，沿切线把攻击引入空处；格挡中总包含反击（阴中有阳）。

## 手部击打（粤语名称）

- **日字冲拳（Yat Chi Kuen）**——沿中线打出的竖直直拳；击打面是下方三根指节。
- **侧拳（Side punch）**——沿水平弧线打向太阳穴或下颌下方；少用，视情境而定。
- **Jau Kuen**——由下向前上方打出的直线上升拳（相当于上勾拳），目标为下巴和太阳神经丛；通常是反击中的第二击。
- **Wun Jeui**——掌根击；直击头部（造成脑震荡）或向上击下巴；击打躯干时瞄准肝脏、心脏。
- **标指（Biu Jee）**——用指尖击打（中指、无名指、食指）；手可以水平或垂直，手臂一直放松到最后一刻；目标为眼睛、喉咙、太阳神经丛。只在特殊情境使用。“凤眼拳”变体——伸出中指第二指节的拳头，击打面部要害点。
- **Jut Sau**——掌缘劈击，手肘沿水平弧线伸展；以手掌外侧边缘接触；主要目标是喉咙；将抓住的手臂拉向自己能增强击打。
- **Kup Jarn**——沿下斜弧线向前下方打出的斜向肘击；近身格斗武器，通过躯干旋转和前倾增加力量；目标为喉咙、头部、锁骨；通常是组合中的第二／第三击。
- **Gwai Jarn**——横向肘击（上一阶段学过，用于组合击打头部）。

## 踢击

- **直线踢：**推踢下段躯干；或用脚跟／脚掌水平向前踢；反击时踢膝盖、腹股沟、下腹部。
- **侧踢：**用脚刃，通常用于截停切入；反击时踢膝关节外侧（撕裂韧带，使支撑腿失效）。
- **膝击：**抱缠／抓住脖子时，踢腹股沟和躯干。
- 腿始终攻击下方区域；击中后立即快速落地。

## 防守技法
- **Guzn Sau**——由两个动作组成的双重格挡：一臂做 Gan Sau，另一臂做 Jim Sau；用于应对直线和弧线踢击，攻击高度在中段；通过躯干旋转增强格挡。
- **Fook Sau**——用前臂内侧拨挡，针对上段和中段攻击。
- **Tan Sau**——掌心朝上、由内向外拨挡，手臂沿纵轴旋转；通常同时以手或腿反击。
- **Lap Sau**——用一只手或双手抓住并控制对手手臂；抓住后向自己／向下拉，以增强后续反击。
- **Bong Sau**——“翼手”：用前臂外侧边缘格挡，将攻击向上并向侧面拨开；为反击创造切入机会，常与同时踢击配合。
- **Pak Sau**——用手掌内侧沿水平方向拍挡，朝向对侧肩膀，同时由另一只手反击。
- **Gum Sau**——掌根向下按压的格挡，用于应对中段／下段攻击；也可控制对手的手臂。
- **Fut Sau**——前臂外侧边缘从下方向上格挡，并配合手臂旋转，用于应对直线头部攻击。
- **Gan Sau**——用前臂外侧边缘沿向下弧线砍挡，将来袭肢体从内侧向外拨开。
- **Wu Sau**——置于胸前的备用护手（另一只手的预备姿势）。
- **Huen Sau**——手腕做顺时针／逆时针环形旋转；在接触之间转换并改变攻击线。

## 标指套拳（第三套、最高级）

- 核心：“标指出击”——攻击套路；取胜主要靠攻击（与小念头和寻桥不同）。教授近战战术、手指击打、Kup Jarn 肘击、旋转扫腿（反击时把对手扫倒），以及充分发挥潜能。
- 动作快速而流畅，带有“爆发”力量，但不显露紧张。
- 分阶段动作骨架（图 68–268）：正面站姿（脚尖内扣）→ 从中线向前上／向下／向左／向右做一组标指，配合圈手旋转 → 日字冲拳 → 转身 90°／180°，配合左／右斜向 Kup Jarn 肘击，连续 2–3 次 → 标指 + 护手／耕手／摊手组合 → 转身 45°／90°时交替做双手 Guzn Sau 格挡 → 头部和身体转动 60°时做 Fut Sau → Jut Sau 掌缘劈击 + Wun Jeui 掌根击下巴 → 深度前倾，双臂下垂并向侧面张开（恢复／扎根）→ 最后日字冲拳、Jau Kuen、圈手、握拳收紧、呼气。
- 套路的电影化标记：一组快速原地指刺；以锐利的 90°–180°转向新方向并出肘；以转腕动作“重新上膛”；低位鞠躬／弯身并配合手臂波动。

## 木人桩法（木人桩）

- 木人桩序列共 116 个动作（圆柱高 150–170 厘米，上方两根“手臂”+ 一根“下臂”，一条横杆“腿”）。训练肢体硬度、切入准确度、无伤及搭档风险地连贯完成格挡—击打，并学会令人印象深刻地“穿透”防守。
- 典型模块（全部都是“格挡木人桩手臂 + 同一拍击打躯干”）：
  - 拉手抓住“手臂” + Wun Jeui 掌根击下巴／肋部／浮肋。
  - 踏步放脚到木人桩“腿”旁，同时做摊手 + Wun Jeui；接着 Guzn Sau。
  - 膀手从外侧压住“手臂” + 转接双手 Yan Jeung／Wun Jeui。
  - 拍手拍“手臂” + 日字冲拳击太阳神经丛；左右拍手连续切换方向。
  - 伏手 + Jut Sau 掌缘劈喉／颈。
  - Kuin Sau／Gum Sau——向下拨挡并向上掌击“手臂”。
  - 脚踢木人桩“膝盖”+ 向右／左弧线踏步，将脚放到“腿”后方（绕到支撑腿后面）。
  - 侧踢膝盖，腿不落下——接上位手部连击。
- 编舞模式：格斗者绕木人桩走弧线，每次改变角度就接一组新格挡—击打；双手快速断续地撞击横杆。

## 防守与反击技法（28 个格斗情境）

- 所有技法的逻辑：对手踏步打出直拳／踢击 → 立即化解（拍／膀／摊／Guzn／耕／Fut Sau）→ 拉手抓住手臂并向自己拉 → 连续打出 2–4 次精准击打 → 以肘击／踢击／摔投收尾。
- 目标点（图示地图）：头部——Tai-Yang（太阳穴）、Chen-Zhen、Ren-Zhong（鼻下）、Lian-Quan 和 Tian-Tu（喉咙）、Er-Men／Yi-Feng（耳旁）、Jia-Che（下颌）、Jie-Chi；躯干——Qi-Hai（下腹部）、腹股沟、Ru-Gen、Qi-Men、Ri-Yue（肋部）、Jiu-Wei、Fu-Tu；腿部——Zhong-Du、Liang-Qiu、Du-Bi、Zui-Xiai（膝盖／胫骨）。
- 典型收尾：斜向 Kup Jarn 肘击头部；踢膝把人踢倒；把对手手肘弯折并压在自己肩上（通过疼痛迫使屈服的杠杆锁，有脱臼风险——技法 13）；压着肘部施力，把肩部摔投（技法 8–9）；从后方抓住后颈，拉扯 + 膝击腹股沟（技法 17–22）；圆弧扫腿；用掌推击将对手打倒（技法 25）。
- 对付踢击：离开攻击线 + 双手 Guzn Sau 格挡，接住踢腿，控制住腿 + 用膝／直踢腹股沟，把人摔倒（技法 21、23、24、26、28）。

## 哲学与训练（场景背景）

- 阴阳：用柔和的躯干旋转化解刚猛力量，沿切线将攻击拨入“空处”；柔韧的手臂（阴）从刚硬格挡（阳）下方击出。视觉表现：格斗者几乎不离开原地，一切都由 45°–90°转身和手部动作决定。
- 训练日常：两人练黐手（黏手）、重复套路 2–3 次、练木人桩、用墙靶训练击打力、用标指手指刺穿纸张；高手一天训练两次，每次 6–8 小时。
- 第三年课程；木人桩是分级训练课程的最后阶段（第 1 本——第一阶段，第 2 本——第二阶段，第 3 本——进阶）。

## 场景序列

1. **“标指刺出”：**拍手拨开直拳 → 标指刺向喉咙（Tian-Tu）→ 向前踏步 + 斜向 Kup Jarn 肘击头部 → 对手蜷倒。（技法 7–8）
2. **“叠加速度”：**拉手抓住出拳手臂 → 拉向自己 + 日字冲拳截击下巴 → Jau Kuen 从下方向上击太阳神经丛 → 直踢膝盖。（技法 2–3）
3. **“掌缘劈喉”：**摊手拨开拳头 → Jut Sau 掌缘劈喉（Lian-Quan）→ 从后脑抓住颈部并向下拉 → 膝击腹股沟。（技法 6、17）
4. **“翼手接肘”：**膀手向上、向侧面拨开交叉拳 → 滑入拉手 → Gwai Jarn 横向肘击下颌 → 下劈式 Kup Jarn 收尾。（技法 4、20）
5. **“接腿”：**移出踢击路线 → 双手 Guzn Sau 格挡，抓住胫骨 → 越过支撑腿直踢腹股沟 → 摔倒，从上方收尾。（技法 21、24）
6. **“肘部杠杆锁”：**双手接住出拳手臂（Jut Sau）→ 将手臂痛压着弯到肩上方，转身 180°、背对对手 → 肩摔把人摔倒。（技法 8–9、13）
7. **“攻城槌掌击”：**伏手化解组合拳 → Wun Jeui 掌根向上击下巴（头向后猛甩）→ 第二记 Wun Jeui 击浮肋 → 侧拳击太阳穴（Tai-Yang）。（技法 1、5）
8. **“木人桩断奏”：**训练场景——绕木人桩走弧线，拍手／摊手／膀手连续拍击木“手臂”，伴随共鸣敲击声；Wun Jeui 掌击“躯干”，踢击“膝盖”，最后双掌向上托击。
9. **“独练标指套路”：**把套路表现成格斗冥想——正面站姿，一连串指刺如扇面展开，配合 90°／180°转向，转身时出 Kup Jarn 肘击，圈手转腕，最后深度弯身成波浪，再爆发性地直起身体。
10. **“凤眼拳”：**伏手 + 标指刺眼 → Gum Sau 向下压住对手双臂 → 竖直的“凤眼拳”露出指节，击向脸部要点 → 对手失明倒下。（技法 13）
