# 06 — JKD 应用自卫技法

**重要说明：**俄文版分卷中，“第 4 本书” = 应用型自卫卷。内容是街头防卫情境——突袭、抓握、勒颈、武器、群体格斗，而非对练或五种攻击方式。这是全系列中关于“肮脏”街头编舞的主要一卷。
**对编舞的补充：**
- 可直接用于街头场景的 3–9 阶段照片序列：“刺激 → 反击 → 收尾”。
- 李小龙的标志性逻辑：**不要**格挡，而要抢占主动——在对手蓄势时反击（截击 = 截击拳）。
- 明确描述受袭者的反应：失去平衡、向侧面跌倒、摔倒——可用于物理表现提示词。
- 情境设定：街道、汽车、墙边、倒地、两三个攻击者。
- 心理：看得见的蓄势会成为反击窗口——这是剪辑时机的关键。

## 李小龙在本书中的原则（战术框架）

- 应对突袭的最佳防守是保持警觉：“始终留意周围环境”；不要让攻击者趁你不备。
- “最好的防守是比攻击者稍快一点。”每项技法都要准确、有力、迅速地完成。
- 对付蓄势／抓握——不是格挡，而是立即反击（手指击眼、脚踢膝盖／腹股沟）：对手出击前会“打电话预告”，创造出攻击窗口。
- 低位侧踢膝盖／胫骨——李小龙最喜欢的通用应对方式；在重沙袋上练习（约 35 千克）。
- 绝不背对对手（例外——即时转身并用肘击）。
- 狭窄空间（近身擒抱）内，只有手、肘、膝能发挥作用；腿需要距离。
- 对付武器：棍棒比刀更“会预告”；手枪最危险；最好的技法是避免冲突。

## 反击序列：突袭（第 1 章）

- **街道上的侧面攻击：**李小龙发现墙边有人 → 提前走开，保持距离 → 对手冲刺时：侧踢支撑腿膝盖 → 对手失去平衡，向侧面跌倒 → 用直拳和交叉拳击脸，直到对方倒地。
- **上车时遭到攻击：**李小龙半坐在车里，看见对方为踢击蓄势 → 先发制人：侧踢攻击者膝盖 → 对手被踢倒。
- **从身后追来：**李小龙察觉有人“跟踪” → 对手出拳之前：侧踢／后踢膝盖 → 转身 → 以连续回旋踢踢向下沉中的对手脸部。评注：过早转身会让对手有准备时间；从“盲向”姿势反击能抢到一个节拍。
- **汽车旁攻击（踢腹部）：**从踢击中后撤 → 侧踢胫骨／膝盖 → 用手击打正在倒下的对手脸部。

## 徒手对手：击打（第 2 章）

- **对付摆拳：**从左侧在前的站姿出发，侧踢前侧膝盖 → 抓住衣领 → 用指关节击打脸部。
- **对付直拳（俯视图）：**在对手迈步的同时，用右脚踢腹股沟。李小龙：“先格挡再反击要多用一个节拍；直接反击更有效，但你必须更快。”
- **对付后手交叉拳：**对手“打开防线” → 重心落在左腿 → 在对手拳头到达前用右脚踢胸。
- **对付勾拳 1：**用前臂格挡太阳穴 → 立即指刺眼睛。
- **对付勾拳 2（不格挡）：**躯干顺时针转动 + 转移重心 → 伸出手指刺眼——手臂长度和身体移位使头部离开击打线。
- **对付勾拳 3：**转成侧身，重心移到左腿 → 右脚踢腹部。评注：蓄势会“打电话预告”，提供足够时间；李小龙自己更喜欢以手指刺眼。
- **对付抱腿摔 1：**向后踏步 → 前踢对手低头冲来的脸。
- **对付抱腿摔 2：**向后踏步 → 抓住头发和手臂 → 绊倒对手，转身背朝地面 → 踢击。
- **对付抱腿摔 3：**左脚向后踏步，站稳底盘 → 双手抓住头部 → 右脚向后踏步，向下压头直到对手倒地 → 控制住他。

## 徒手对手：抓握（第 3 章）

- **抓住胸口并蓄势：**向左格挡 → 抓住他的手臂 → 右拳打脸 → 扫腿摔倒 → 跳开，避开他的腿 → 脚跟击打倒地者的脸。
- **双手抓住手臂（1）：**转向对手 → 低位回旋踢膝盖 → 左拳打脸 → 膝击腹股沟。
- **抓住手臂（2）：**不做多余动作——侧踢膝盖。
- **抓手腕（3）：**在他出击之前——左交叉拳打脸。李小龙：简单反击比复杂的脱身技巧更有用。
- **抓住并向内拉：**向前并向右闪身，躲开拳头 → 左手指击眼。
- **从后方抓住手腕／扭臂：**迅速顺时针转身，用肘击脸（“绝不背对对手”规则的例外——动作要快）。
- **从后方半纳尔逊锁：**朝被困手臂的方向（逆时针）转动 → 使对手失衡 → 用体重压住他的手臂 → 向后肘击身体。
- **手臂被扭到身后：**应对方式——后踢腹股沟；若对手侧身站立，先拉开距离。
- **双手抓住胸口（1）：**预先用左手护住腹股沟 → 抬起左手，将对手双臂压在自己身体上 → 右交叉拳打脸。
- **（2）：**准备动作相同 → 右肘击脸。关键：在他出拳之前先困住他的双手。
- **从后方抓住衣领：**小步后退，转动躯干 → 左肘击脸（转动带动击打力量）。
- **肘关节锁（“杠杆”）：**被摔倒之前就行动——顺时针转身 + 向后踢。

## 勒颈与身体擒抱（第 4 章）

李小龙的框架：应对勒颈用最简单的方法；肘、头、踢腹股沟都能起作用。

- **正面勒颈 1：**抓住对手肘部（减轻颈部压力）→ 手指刺眼 → 膝击腹股沟；用右手控制他的右腿，以防膝击。
- **被压在墙上的正面勒颈：**侧步 → 向下击打腹股沟。
- **头部锁定 1：**用空闲的手伸出两根手指刺眼。
- **头部锁定 2：**把头转向外侧 → 向上击打脸部。
- **头部锁定 3：**将躯干转到与对手成一线 → 用空闲的手击打腹股沟。不要拖延——他会把你摔倒。
- **手臂被控制的后方勒颈：**向右转，直到对手失去平衡 → 左肘向后击打肋部。关键——不要让手臂被控制住。
- **从后方熊抱（双臂被压住）：**右脚向前踏步 + 突然下沉（滑脱出来）→ 左手击打腹股沟。整个动作序列只需几分之一秒。
- **从后方擒住身体（双臂自由）：**立即转动躯干，向后肘击脸部。
- **正面抱住身体并把人抬起：**摆动骨盆 → 膝盖向上踢腹股沟。
- **从后方抱住身体并把人抬起：**摆动骨盆 → 双手向下 → 抓住生殖器。从后方被举起来是最危险的姿势；立即行动。
- **正面头部锁定：**被摔倒之前——拳击腹股沟。

## 持械对手（第 5 章）

李小龙的立场：“一个没有武器的人处于极大的危险中；最好避免这种冲突。”对付棍棒时，由时机和距离决定；棍棒和刀会“打电话预告”，手枪不会。

- **棍棒蓄势 1：**退到攻击范围之外 → 对手挥空后，侧踢躯干。
- **棍棒蓄势 2：**蹲到攻击轨迹下方 → 抓住双臂 → 向下拉 → 拳击脸部。
- **棍棒直刺腹部：**格挡 + 极小幅侧向闪避 → 手指刺眼。
- **长棍蓄势：**爆发式切入（跳近）→ 左手格挡手臂 + 右拳击腹部 → 控住手臂，回旋踢 → 对手倒地 → 拳打脚踢肋部（组合收尾）。
- **长棍从上方蓄势：**从棍子下方潜身 → 回旋踢腹股沟。
- **闪避长棍 1：**后退 → 向前爆发 → 回旋踢头部。
- **闪避 2：**后退 → 跳步 → 旋身回旋踢脸。
- **长棍直刺 1：**移出直线 + 双手抓住棍子 → 握住棍子，侧踢胸部。
- **直刺 2：**闪避 + 抓住棍子 → 向下踢手（缴械）。
- **抓住衣服时用刀攻击：**抓住他的左臂 → 右手横扫击脸 → 右腿从后方扫倒他的支撑腿 → 倒地后——脚跟踢躯干。
- **刀刺 1：**用手指向脸部佯攻（迫使对手反应）→ 趁此踢胫骨，同时保持与刀刃距离。
- **刀刺 2：**回旋踢手腕——把刀踢开。
- **刀砍：**从劈砍动作中后撤 → 对手砍空时切入并侧踢胫骨／膝盖，将其踢倒。
- **前方手枪：**向前踏步 + 向侧面转身离开枪口直线 + 抓住靠近肘部的手臂 → 空闲的手夺枪 → 肘关节杠杆 → 击打脸部。
- **后方手枪：**逆时针转身 + 抓住他的手臂（移出枪口直线）→ 左手抓住肘部 → 右手指刺喉咙 → 连续拳击头部。评注：只有近距离才有可能夺枪；不会有第二次机会。

## 群体攻击与地面格斗（第 6 章）

框架：对抗一群人时——看清所有人，双手和双腿同等运用；被两个人控制住就几乎输定了，因此要先爆发行动。

- **正面和后方夹击（A 将对手手臂控制在背后，B 朝脸出拳）：**蹲在 B 的拳下方 → 向右转，解放手臂 → 手腕击打 A 的肋部 → 右手指刺 B 的喉咙 → 高踢 A 的头。（适用于 1 对 2 场景的经典“三连击”。）
- **两人把你压在墙上：**踢 A 的腹股沟 + 左手同时格挡 B 的拳 → 右交叉拳 + 前踢 B 的腹股沟。
- **倒地，两人在两侧：**用手格挡 B 的腿 + 同时撑踢 A 的膝盖（A 倒下）→ 控制 A 的腿，前踢腹股沟。
- **在街上被拦住（第二人靠近）：**抓住 B 的肘部 → 手指刺眼 → 交叉拳击下巴，B 倒地 → 用回旋踢胸部迎击跑来的 A。
- **A 从后方抱住，B 从正面攻击：**左前踢 B 的腹股沟 → 左腿勾住 A 的腿后侧 → 抓住 A 的手臂 + 转动躯干 → 把 A 摔倒在地 → 最后击打脸部。
- **倒地，对手抓住躯干（双臂自由）：**右手抓耳朵 → 左肘击身体。
- **倒地，对手坐在胸口上勒颈：**一只手松开控制 → 另一只手伸出手指刺眼。评注：在地面上，可用招式锐减，速度也变慢——不能从地面姿势防御一群人。
- **倒地，对手控制手臂并用脚跟攻击：**迅速转向对手 → 将他绊倒 → 左拳击侧面。

## 视频生成的编舞结论

- 几乎每个序列都是：（1）威胁／抓握成立 →（2）防守微动作（闪避／蹲下／踏步／截击）→（3）低位反击（膝盖／胫骨／腹股沟）或攻击眼睛／喉咙 →（4）对手失衡 →（5）用手／腿击打正在倒下的对手收尾。3–5 个节拍，银幕时间 2–4 秒。
- 反复使用的反击目标：膝盖、胫骨、腹股沟、眼睛、喉咙、肋部——这套“不讲规则”的目标组合让街头场景有别于比赛。
- 反应：踢膝——腿一软，向侧面倒下；手指刺眼——头猛然抽动，双手捂脸；肘击肋部——身体折起；扫倒支撑腿——仰面摔倒。
- 武器场面的电影化模式：佯攻 → 挥击落空 → 爆发切入；棍棒形成宽阔、易读的弧线，刀则是短促直刺并斜向闪避。
- 在 1 对 2 场景中，防守者总是通过蹲伏／转身逐个“处理”对手，从不静止地站在两人中间。
