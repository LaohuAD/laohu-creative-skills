# 14 — 咏春进阶技法

**对编舞的补充：**
- 第二套拳寻桥套拳（Chum Kiu Tao，“跨过峡谷的桥”）分阶段完整说明——180°／90°／45°转身、双手配合、套路中的踢击。
- 扩展手法词汇：日字冲拳、Wun Jeung、Jau Kuen、Jut Sau、Gwai Jarn + 摊／膀／按／标／耕／拉／拍／枕／伏／护／圈手等防守。
- 13 项黐手练习（以盘手为基础的 Koi Sau）和 9 项拉手练习——可直接用于成对编舞的“接触 → 截击 → 击打”。
- 20 种反击技法（一个节拍内完成防守 + 击打、关节杠杆锁、扭头）以及改变攻击高度的两击／三击组合。
- 易受攻击的中线要害地图（Tan-tu、Jiu-wei、Qi-hai、Ju-xu、Zhong-du 等）——可用于提示词中的击打目标。

---

## 1. 原则（用于场景物理）

1. 不要以力量对抗力量：拨开攻击，用踏步／转身离开攻击线。
2. 中线：保护自己的中线，攻击对手中线上的点。
3. 双手同时动作：一只手格挡，另一只手在同一节拍反击（零停顿）。
4. 整身发力：脚 → 髋 → 下背 → 肩 → 三头肌 → 手（一道伴随身体转动的波浪）。
- 近距离格斗主要用手；踢腿不高过胃部（踢胫骨、膝盖、腹股沟）+ 扫腿／绊腿。

## 2. 步法（第二阶段）

- **踏步并滑（前进／后退）**——快速缩短／拉开距离并切换站姿（左↔右）：重心转移至前腿，后脚跟上，身体转动，双手交换位置。
- **前进之字步**——从侧面以锐角接近攻击线；第一步 = 离开攻击线，第二步 = 切入并反击。有两种变体：切换站姿与不切换站姿。

## 3. 手部击打（粤语术语）

- **日字冲拳（Yat Chi Kuen）**——竖直拳；用小指／无名指／中指的指节根部击打；第二阶段用于击打要害，并有一种变化：伸出手指的第二节，精准击中小目标。
- **Wun Jeung**——掌根击：竖直击打（下巴）或水平击打（躯干／内脏）；也可用来推人。
- **Jau Kuen**——从下向上、向前以 30–45°角打出的直线上升拳（目标为下巴、太阳神经丛、肝脏）。
- **Jut Sau**——掌缘劈击（小指外侧），手肘伸展扫过；目标为喉咙／颈部。
- **Gwai Jarn**——向前横向肘击；力量最大，几乎无法格挡，在贴身距离以躯干转动将身体重量送入击打。
- **指刺（标指类）**——刺向眼睛或 Tan-tu 穴（喉结下方）；速度最快，常用于开启攻击。

## 4. 防守（“手”类格挡）

- **摊手（Tan Sau）**——以前臂内侧拨挡，掌心朝上；手肘在中线上，身体进一步沿移动方向转动。
- **膀手（Bong Sau）**——“翼”：以旋转前臂拨挡，将对手手臂从外向内拨开；躯干转动至关重要。这是整套寻桥套路中的关键动作。
- **按手（Gum Sau）**——用掌根向下按压格挡（对付中段／下段攻击）。
- **标手（Biu Sau）**——以前臂外侧边缘由内向外拨挡（对付打向头部的直线／侧向攻击），也可当作截停式格挡。
- **耕手（Gan Sau）**——以前臂外侧边缘由内向外有力拨挡／截挡（用于中段／下段，包括踢击）。
- **拉手（Lap Sau）**——用手指抓握：制住肢体，向下／朝自己拉，接上摔投和关节锁。
- **拍手（Pak Sau）**——掌击式格挡；**枕手（Jum Sau）**——从上方压住对手前臂；**伏手（Fook Sau）**——控制“桥手”；**护手（Wu Sau）**——中线胸前待命的掌；**圈手（Huen Sau）**——手腕画圈（绕过对手手臂）。

## 5. 踢法

- **直线踢：**用脚跟（脚掌水平向前推进）或脚背（小腿从下方向上甩）踢击；目标：胫骨、膝盖、胃部、腹股沟。动作阶段：切入一步 → 重心落到支撑腿 → 抬膝 → 伸腿 → 呼气。支撑腿略弯，脚掌完全踩地，踢击腿在动作末端绷紧。前腿或后腿都能踢（后腿踢时双手要换位：同侧手收到胸前，对侧手伸出）。
- **侧踢：**支撑脚转动，身体转身，腿向侧面伸出；高位踢（胃部）——用整个脚掌；低位踢（胫骨／膝盖）——用靠近脚跟的脚外缘。用作截踢，打乱对手攻击。
- **直线截踢：**脚尖转向侧面，踢向攻击腿的胫骨／膝盖。
- 训练器材：墙靶、三根柱子摆成三角形（配合转身练习直踢 + 侧踢组合——可直接编成“一对三”场景）。

## 6. 寻桥套拳（动作是什么样）

第二套拳，“跨过峡谷的桥”：先与对手手臂建立接触（“搭桥”）→ 找到未受保护的区域 → 闪电般出击。与小念头不同，它需要**配合步法和转身**完成。标准时长——2–2.5 分钟；每个动作结束时肌肉短暂绷紧。

动作骨架（照片序列，图 89–239）：

1. 开始：摆好站姿，双拳收到胸前，双脚分开进入正面站姿；双臂向下、向前（左臂在右臂上方），握拳收到胸前。
2. 原地动作组：左手日字冲拳 → 张掌朝上 → 圈手（转腕）→ 握拳收回胸前；右手重复。
3. 双手格挡：手指朝前 → 双臂向前上方抬起 → 转为格斗站姿，双手落在胸前（掌心朝下，左手在右手上方）。
4. **双手配合转身 180°：**反复向左／向右转身，不改变手位，接着交替做拍手 + 摊手（右／左），再交替打出 Wun Jeung 掌击。
5. **配合膀手转身：**转身 180° → 一只手臂做膀手 → 弯臂横放胸前 → 双手摊手 → 再转身，用另一只手臂做膀手（反复循环——这是套路的标志性部分）。
6. 向前打日字冲拳 → 向前转身 90° → 肩高位置以掌缘打出截手 → 指刺 → 圈手 → 握拳收回胸前。
7. **套路中的踢击：**拉手朝肩部移动 → 呼气并侧踢 → 向前踏步 → 膀手 → 双摊手 → 踏步并滑 + 膀手（一组“踏步搭桥”动作）→ 上升的 Jau Kuen。
8. 左／右直线踢，落地后双臂做膀手，双摊手，低位膀手，手指朝上做枕手，双手 Wun Jeung。
9. 结束：向左／向右转身 45°并做按手，配合正面转身连打日字冲拳，圈手，双手落下，双脚并拢。

## 7. 第二阶段黐手（Shun Chi Sau / Koi Sau）

基础——盘手（“滚手”）：搭档以前臂接触，摊／膀／伏手位置沿圆圈滚动。练习 = 从滚动动作中爆发出击：

- **第 1 项：**掌击胸口 → 搭档用枕手 → 他打日字冲拳攻击头部 → 你用摊手 → 他用伏手控制 → 通过盘手交换位置 → 枕手 + 立即打日字冲拳攻击胸口。
- **第 2–3 项：**感觉压力过强时——圈手（第 2 项逆时针转腕，第 3 项顺时针转腕）并以掌根击胸。
- **第 4 项：**身体转动 45° + 画圆脱离接触 → 掌压前臂 → 日字冲拳击头 → 另一只手再击一次 + 枕手（同时控制双臂）。
- **第 5–7 项：**膀手时手腕受到压力 → 交叉对手双臂（向下做枕手）→ 击头；掌压肩膀／手臂向下 → 连续击打，对手双臂被“绑住”。
- **第 8–9 项：**枕手压住手臂 → Wun Jeung 掌击头部 → 耕手控制 → 转身 45°打日字冲拳；拍手 → 耕手遮住双臂 → 击打头部。
- **第 10–13 项：**从肘部下方抓住；对方抓手腕时使用标手；抓住 + Jut Sau 劈向脖子 → 枕手下压 → Wun Jeung 掌击下巴。

最终含义：双手“黏”在对手身上；对手压过来，你就滚动化解；对手收回手，你的手就跟过去，打向打开的区域；可以闭眼格斗。高潮动作——Koi Sau：一段自由组合式“较量”，摊→枕→伏→膀→拉→护手流畅衔接，并配合击打（图 313–352）——是长篇黐手场景现成的参考。

## 8. 拉手技法（成对练习）

培养打开中线区域的能力：一只手化解对手，另一只手同时反击。典型循环（练习 1）：日字冲拳击头 → 膀手 + 护手 → 对手用拉手拉住手臂并打横拳 → 拍手 + 抬臂 → 抓住对手手臂 → 日字冲拳击头 → 对手拍手 → 耕手 + 转身 45° → 按手下压 → 击头。其他变化：从中线用按手扫开 → 击打；拉手抓握 + 向下拉 + 击打肝脏／头部；拉手 + 直踢躯干 → 拍手 → 按手控制 → Wun Jeung 掌击下巴。

## 9. 攻击技法（两击和三击组合）

原则：先攻击；两击／三击组合——第一击佯攻／快速出手，依靠第二／第三击；改变高度（头部 → 腹股沟／膝盖更难防守）；击打之间不暂停。

两击组合：I. 踏步 + 指刺眼睛 → 左手日字冲拳击头／喉咙。II. 指刺眼睛（或日字冲拳）→ 左手直拳击太阳神经丛（Jiu-Wei）。III. 踏步 + 指刺眼睛 → Gwai Jarn 肘击头部侧面。IV. 指刺眼睛 → 右手直踢腹股沟／躯干，或侧踢膝盖。V. 日字冲拳击头 → 低位直踢支撑腿膝盖（“对手没察觉”）。VI–VIII. 切入一步 → 踢腹股沟（Qi-Hai）→ 日字冲拳击头／指刺眼睛；踢腹股沟 → 用脚内侧踢膝盖 → 踢胫骨（Ju-Xu）。

三击组合：指刺眼睛 → 日字冲拳击喉 → Jau Kuen 击太阳神经丛／下巴；两次指刺／拳击头部 → 踢腹股沟或膝盖；指刺眼睛 → 拳击太阳神经丛 → 上升拳击下巴；踢腹股沟 → 拳击头部 → 指刺眼睛；踢腹股沟 → 击打头部 → 上升击打太阳神经丛（或以截踢膝盖收尾）。

## 10. 防守与反击（20 种技法）

反击分三个层级：1）先格挡，再击打；2）格挡 + 同时击打（咏春核心）；3）在攻击刚开始时先发制人（高手层级）。

关键情境（沿用书中编号）：

- **第 1 项：**向右侧踏步离开攻击线 + 摊手 → 双手抓住手臂（拉手）→ 朝自己方向拉 + 直踢腹股沟（Qi-Hai）→ 连续日字冲拳打头（Jia-Che、Tai-Yang 穴）。
- **第 2 项：**向左移动 + 拍手 → 抓手腕并转身拉扯 → 掌缘 Jut Sau 劈击喉咙 → 收回手臂 → 日字冲拳击太阳神经丛（Jiu-Wei）。
- **第 3 项：**向左踏步 + 右手摊手 → 同时用左手日字冲拳击头 → 用脚内侧踢膝盖外侧。
- **第 4 项：**向左踏步 + 摊手 → 日字冲拳击肝脏 → 抓住手腕并向右下方拉 → 向下侧踢膝后方——对手仰面摔倒。
- **第 5 项：**枕手 + 抓握 → 拉扯 + 踢膝内侧 → 上升拳击躯干（Qi-Hai）→ 上升击打喉咙／下巴。
- **第 6 项：**标手 → 日字冲拳击太阳神经丛 → Gwai Jarn 肘击头部（Tai-Yang／Er-Men）→ 反向肘击颈部。变体：拉手抓手腕和肩膀（锁住肘部）。
- **第 7 项：**双手抓握 → 拉扯 + 踢肝脏 → 踏步 → Gwai Jarn 击喉 → 压手臂，用肘击 Fu-Tu 穴。
- **第 8 项：**拍手 → 上升拳击肝脏／肋部 → 压住手臂 → Gwai Jarn 肘击头／喉。
- **第 9 项：**摊手 + Wun Jeung 掌击肋部 → 抓手腕并转动 → 用肘施压（Qu-Chi 穴）→ 以杠杆锁关节，让对手脸朝下跌倒。
- **第 10 项：**伏手 → Wun Jeung 掌击肘关节 → 圈手 + 转身 → 将手臂绕住 → 用杠杆锁住肘关节。
- **第 11 项：**膀手 + 向左踏步 → 拉手 + 转动手臂 → 踏入对手双腿之间 → 将他的手臂放到自己肩上 → 猛然向下拉——在肩上施加肘部杠杆。
- **第 12 项：**拍手 → Wun Jeung 掌击鼻根（Ren-Zhong）→ 踏到对方腿后方 → 抓住头部（下巴 + 后脑）→ 扭颈（仅作为“最后手段”——电影化收尾）。
- **第 13 项（对付踢击）：**后撤 → 耕手 → 以脚背反踢腹股沟 → 用脚刃侧踢膝盖。
- **第 14–15 项（对付侧踢）：**向左前方踏步 + 耕手 → 上升踢腹股沟／侧踢支撑膝后；或转身 + 接住腿（弯肘，前臂向上）→ 向下肘击大腿（Zhong-Du）→ 踢支撑膝后。
- **第 16–17 项：**两击序列——交替使用摊／拍／标手 → 伸出标手 → 掌心向下压肩 → 日字冲拳击肋部；标手 → 踢躯干。
- **第 18 项（对付回旋踢）：**朝对手踏步（压入挥击内侧）+ 转身拍手 → 左拍手 + Wun Jeung 掌击太阳神经丛／以指节拳击 Jiu-Wei 穴。
- **第 19 项（对付上升踢）：**切入一步 + 侧向截踢胫骨 → 摊手 + 反击头／喉 → 向左移位，避开右手。
- **第 20 项（对付低踢）：**抬起左腿，用膝盖格挡 → 膀手 → 拉手抓握 + 向下拉 → 日字冲拳击下巴。

## 11. 脆弱部位（目标）

头部：Tan-Yan（太阳穴）、Er-Men（耳旁）、Yi-Feng（下颌后方）、Jia-Che（下颌角）、Chen-Zhen（鼻梁／额头）、Ren-Zhong（鼻下）、Lian-Quan（下巴下方）、Fu-Tu（颈侧）、Tan-tu（喉结下方）。躯干：Jiu-Wei（太阳神经丛）、Qi-Hai（下腹部）、腹股沟。腿部：Zhong-Du（大腿内侧）、Ju-Xu（胫骨）、膝盖（各个方向均可攻击）。手臂：Qu-Chi（肘窝——用于杠杆锁）。

## 场景序列（现成节拍）

1. **“之字切入”：**侧向之字步离开攻击线 → 第二步 + 同一拍内摊手和日字冲拳 → 低位截踢膝盖。
2. **“搭桥后击破”：**前臂接触（搭桥）→ 两轮盘手 → 圈手脱离接触 → Wun Jeung 掌击胸口 → 对手向后飞。
3. **“向下拉扯并收尾”：**对方刺拳 → 膀手 + 护手 → 拉手把手臂向下拉 → 掌缘 Jut Sau 劈喉 → 日字冲拳击太阳神经丛。
4. **“双重变高度”：**指刺眼睛（佯攻）→ 日字冲拳击喉 → 脚跟直踢腹股沟 → 踏步 → Gwai Jarn 肘击太阳穴。
5. **“反踢”：**对方低踢 → 抬膝（胫骨格挡）→ 脚落地 + 膀手格挡出拳 → 拉手拉扯 → 上升 Jau Kuen 击下巴。
6. **“杠杆收尾”：**摊手 + Wun Jeung 掌击肋部 → 抓手腕并转臂 → 肘部施压（Qu-Chi）→ 脸朝下倒地。
7. **“黐手对决”：**长镜头——黏手：摊↔伏↔膀滚动，枕手 + 击打爆发，双方化解后重新切入；最后——按手压住双臂，日字冲拳击头。
8. **“三根柱子”：**训练场景——直踢前方柱子 → 腿不放低，侧踢右侧柱子 → 转移重心 → 左侧踢左侧柱子（仿佛被三面包围）。
9. **“扭颈”（反派的终结技）：**拍手 → Wun Jeung 掌击鼻下 → 踏到腿后方 → 抓住下巴 + 后脑 → 配合身体旋转猛然扭转。
10. **“银幕上的套路”：**英雄独自演练寻桥：缓慢地转身 180°并做膀手，加速，拉手 + 侧踢并猛然呼气——摄影机绕着他转。

**提示词的动作力学：**每次格挡都配合身体转动（不是远离攻击）；格挡与击打在同一画面节拍内；击打短促、不蓄势，从胸口沿中线打出；拳头竖直；踢击在腰部以下，支撑腿弯曲；抓握后把对手朝自己**拉过来**接上击打；最后强调——肌肉短暂绷紧并呼气。
