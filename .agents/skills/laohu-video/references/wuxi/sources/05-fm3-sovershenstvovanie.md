# 05 — JKD 技法精进

**内容：**“手部攻击技法”（分 2 部分）、“腿部攻击”、“防守与反击”、“身体素质与战术”等章节 + 照片插页（照片 1–190；扫描件说明文字几乎无法辨认，动作力学依据正文重建）。

**对编舞的补充：**
- “佯攻 → 空当 → 击打”的逻辑：JKD 高手每次攻击都分两个节拍，先展示一条线路，再攻击另一条线路。
- 完整的反击序列：“对手攻击 → 截击／拨挡 → 反击”，逐项指定手、腿和目标。
- 截击拳是李小龙的标志性动态：对手的攻击打到一半便停下，以指刺或踢膝／胸迎击。
- 距离战术：哪些击打适合编排在远／中／近距离，以及角色如何在出击前“读懂”对手。
- 动作清晰度规则：没有“打电话预告”——适合在银幕上表现闪电般突然的击打。

所有序列的基本站姿：右侧在前的警戒姿势（右手和右腿在前，左侧在后并负责防守）。“相反站姿” = 左撇子对手（左侧在前）。

## 拨挡与防守

- 总原则：格挡／拨挡几乎不会单独发生——它会同时或紧接着转为反击。拨开对手的击打会使他失衡，并为回应打开线路。
- 从右侧前手站姿应对对手面部刺拳的四种回应：
  1. 后手（左手）张开，并比平时略高；刺拳打来时，稍向左闪身，左掌将出击手臂击向下方（击打关节／前臂），接着迅速反击脸部或身体。
  2. 躯干向左闪避 + 右脚向前踏步 + 右拳有力击打脸部／身体。
  3. 躯干向右转，右脚向前踏步，用左拳截击脸部或身体。
  4. 向后踏步——刺拳打空；趁对手收回手臂时反击。
- 抓握／黏手（制住对手）：一只手压住／拨开对手手臂，另一只手击打。向内拉手腕并同时反击；踩住对手伸出的前脚以取消他的踢击和踏步（随后掌击，左手控制其手腕）。
- 任何格挡之后：把对手的手臂拨开，在他伸直／后缩、双脚站定时出击。抓握后继续施压——立刻再击一次，不让对方恢复。
- 防守踢向小腿／胫骨的低踢：不要直线向后退——向侧面移动，以相迎动作格住踢腿，或预先拉开距离。
- 对付双重击打：第一击是欺骗，第二击才是真的；整个连击期间保持格挡。

## 闪避与身体移动

- 向左／右闪身并同时反击——手部反击的基础（向左闪身 → 右拳；向右转身 → 左拳）。
- 对付打向身体的击打（左交叉拳／向下勾拳）：弯下躯干，下潜到击打高度，下巴抵住出拳手臂的肩膀，头部收起——肩膀挡住对手反击下颌。
- 对付反手拳和横向击打，躯干向出击手的反方向倾斜——保持平衡并使头部移出火线。
- 躯干后倾并向后踏步——躲过刺拳后立即侧踢（照片 156–157）：躯干直立或向后倾，双手准备防守。
- 低身潜行、蹲伏的对手更难击中——后退，引诱他发动横扫式切入；闪开前手，再用踢击反击。
- 以前脚掌为轴心（脚跟抬起）转动——身体投入击打的基础力学：髋部转过来，重心向前转移；能加强前手拳、勾拳、反手拳（增加 5–8 厘米触及距离而不损失力量）。

## 佯攻

- JKD 几乎没有“纯粹”的直接攻击：几乎所有击打都以欺骗为先，或作为反击。简单攻击只对付较慢的对手才有效；与自己势均力敌的对手要靠佯攻打开防线。
- 佯攻必须看起来像真正击打：动作幅度大、深入，真的击打则短促锐利（“长—短”）。趁对手**尚未**准备好防守时做佯攻；它必须迫使对手做出某种特定防守动作。
- 对慢或疲惫的对手用单次佯攻；对快速对手用双重佯攻（展示—展示—击打）。
- 经典“展示 → 击打”配对：
  - 手沿圆弧向身体中线移动 → 对手放低手 → 击打越过放低的防守，指刺眼睛（照片 4–6）；
  - 右侧前手作出欺骗性动作 → 对手抬手／打开防守 → 击打打开的线路（照片 7–9）；
  - 连续击打头部，使对手习惯高位防守 → 向前踏步 + 勾拳击身体；
  - 后手在脸前假装蓄势 → 对手双手抬起 → 左交叉拳击腹部（照片 48–50）；
  - 佯装低踢膝盖 → 对手双手下垂 → 高位勾踢脸部（照片 93–95）；
  - 手向上佯攻 → 对手没有反应 → 改变高度：低位侧踢膝盖，再击脸部（照片 90–92）；
  - 抬起后手 → 立刻转身 → 旋踢脸部／腹部（照片 106–113）。
- 佯攻也会缩短距离：第一记佯攻合上一半空隙，击打覆盖后一半。佯攻要短促，不能拖长；始终比对手的反应快一点。
- 三连击中的第一击和最后一击瞄准同一目标：身体—头部—身体（中间一击“卖出”假动作，让人以为高度要变）。
- 眼睛不暴露目标：踢胫骨／膝盖时，李小龙看的是对手的脸，而不是目标——隐藏意图并施加心理压力。
- 不要“打电话预告”：出击前不收手、不动肩、不皱眉——攻击从静止站姿直接开始，不做蓄势（这是 JKD 自己的视觉标志）。

## 反击（序列）

格式：触发条件 → 分步动作（肢体 → 技法 → 目标）。

1. **截击刺眼**（照片 121–125）：对手以任意一只手蓄势 → 右前手（最短线路）→ 指刺直击脸部／眼睛；左掌同时格挡／护住他的出击手臂。
2. **截击拳对付摆拳**（照片 126–128）：对手准备打出宽幅右摆拳 → 闪身／向前倾 → 右直拳击脸，攻击刚开始就被截断。
3. **截击左撇子的蓄势**（照片 129–130）：左撇子把手臂往回拉 → 立即以前手直拳打头。
4. **截踢膝盖**（照片 132–133）：对手开始向前爆发 → 抬起前腿 → 用脚刃低踢膝盖／胫骨 → 对手在进入手臂距离前就被踢倒。
5. **截踢腾空的腿**（照片 134–136）：左撇子抬起后腿准备踢 → 抬起前腿迎击 → 用脚掌在空中截住他的大腿／胫骨。截击不一定要把对手打倒——压制攻击就足够。
6. **侧踢胸／肋部**（照片 145–151）：对手在远距离开始准备／爆发切入 → 滑步 → 前腿有力侧踢胸口或肋部 → 对手被向后／向地面踢出（JKD 最强的击打，“一击足矣”）。
7. **闪避 + 侧踢**（照片 156–157）：对手出刺拳 → 向后踏步并后倾（刺拳打空）→ 立即侧踢躯干。
8. **双勾踢**（照片 160–163）：对手冲上来 → 体重转移，以左腿为轴转身（离开攻击线）→ 勾踢脸部，必要时连踢两次。
9. **格挡 + 勾踢腹股沟**（照片 164–166）：右手佯攻脸部 → 对手用右手还击 → 格挡并把他的手臂拨向一侧 → 勾踢腹股沟（目标较小，几乎无法格挡）。
10. **迎击旋踢**（照片 106–113）：攻击者冲上来 → 以前脚为轴快速转身，背朝对手（目光仍看着目标）→ 后腿甩击脸部或腹部 → 对手飞倒在地。只用于正在冲锋／注意力不集中的对手：转身时，你的背部会朝向交战方向。
11. **从抓握中打出反手拳**（照片 70–72）：对手抓住／压住你的前臂，或刚刚拨开刺拳 → 甩臂：放松的手沿垂直弧线甩出 → 用拳背击打脸部／太阳穴；躯干向相反方向倾斜。
12. **拨挡后的反击组合：**拨开对手的手臂 → 左脚向前迈向对手后腿（缩短退出空间）→ 左拳击脸部／身体。
13. **对付“公牛”的上勾拳**（低头、双臂乱挥）：左手拨开他的右手 → 右上勾拳击下巴；对方打左上勾拳时，右手护脸。右手出拳时重心落在左腿，反之亦然。对付快速、直立的格斗者时上勾拳不起作用。

每个序列背后的原则：反击者几乎不可受伤——对手攻击时门户大开，无法防守。最佳截击时机：对手迈步、向前转移重心、完成一项技法，或失去平衡时。

## 距离与时机

- **远距离：**指刺（最长武器）、低踢膝盖／胫骨（让出拳者保持在攻击范围之外）、滑步侧踢、迎着冲锋使出的旋踢。远距离的对手需要设计复杂的切入方案——这就提供了反击时间。
- **中距离：**勾踢（快速、多变：头部／身体／低位）、侧踢、配合横向移位的反手拳、弧线手击。这是主要交手区域。
- **近距离：**短促鞭击拳（接触之前不要握紧拳头）、向上掌击下巴／鼻子、上勾拳、打身体的反手拳、黏手控制。攻击身体有优势：目标更大，也更近。
- 攻击时机：对手没有准备好时出击——在他准备迈步、变换姿势、转移重心时，或注意力／感知能力被占据时。在他准备好前半拍攻击。
- 破节奏：改变速度会打乱防守——先慢后爆发；攻击前停顿／定住会打破对手的防守节奏。经验丰富的格斗者节奏难以预测；新手跟不上。
- 速度包括：感知（眼睛捕捉时机）、选择决定、启动动作、执行动作、改变方向。肌肉紧绷会偷走速度：直到接触才放松 = 锐利与准确。
- 读取对手（指定为格斗的一个阶段）：准备时观察习惯、站姿、惯用技法、对佯攻的反应。机械式格斗者会重复；有智慧的格斗者会根据对手调整战术。
- 反制战术（相反原则）：对付截击拳专家——用反击；对付佯攻者——用截击拳；对付用手的格斗者——用腿；对付踢腿者——用手；引诱急躁者出击，在最后一刻用截击拳压制。
- 体型：矮个格斗者会冲进近距离（这是他的优势）——让他保持在最远距离并耗尽体力；高个格斗者手臂长但速度慢——保持在他够不到的地方，以爆发性切入接近。对付攻击者，不要直线后退——迎上并拨挡，打乱他的平衡。
- 目光：远距离时看对手的眼睛；近身格斗时看上躯干；永远不看自己的目标。
- 由简到繁：从简单技法开始，只有简单技法失效时才用复杂技法。在复杂准备动作后接一记快速的简单击打尤其有效——因为它出乎意料。
- 以挑衅作为故事节拍：故意暴露身体某个部位（诱饵），等对手往那里攻击，再用预先选好的反击惩罚他。
