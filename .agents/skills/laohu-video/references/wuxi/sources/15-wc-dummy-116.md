# 15 — 咏春木人桩方法

**对编舞的补充：**
- 叶问一系标准的木人桩（木人桩）套路：分八部分，共 116 个动作——咏春／原型 JKD **训练场景**的直接来源（李小龙从叶问处学到的正是这个基础）。

- 风格逻辑：中线、内／外门、“一个有效动作胜过许多花哨动作”、攻防同时、同一拍内用手 + 腿。
- 历史补充：叶问 → 李小龙 → 截拳道的联系（李小龙没有学完木人桩套路，1965 年回来完成——可用于场景／故事）。

## 银幕上的木人桩

- 圆柱形木桩约长 152 厘米、直径约 22 厘米，由硬木制成。
- **三根“手臂”：**两根上臂以一定角度向前突出（像对手伸出的拳头），第三根“中间手臂”位置较低、位于中央。**一条“腿”：**粗壮、弯曲，从下方向外伸出并弯向地面——模拟对手的前腿。
- 传统悬挂方式：木桩由两根穿过桩身的水平杆支撑，水平杆由两根垂直木柱支撑（木框靠墙）。木桩略微**可动**并有弹性——击中时会震颤、摇晃、“弹回”回应。另有一种固定版本——木桩直接埋入地面（“桩”）。
- 木人桩高度 = 对手身体高度：上臂——上段（头／胸）；中间手臂——中段（腹部）；木桩腿——下段（膝盖／胫骨）。
- 叙事功能：木人桩 = 一个“永远不会疲倦或受伤”的搭档；用来强化格斗者的前臂与胫骨，训练中线和角度意识。特写：练硬的前臂滑过木臂，手掌拍击桩身。

## 动作套路（116 个动作 → 12 种典型模式，含阶段）

套路分八部分；几乎所有动作都左右镜像，并围绕木人桩转动身体。典型动作模式：

1. **化解 + 黏手（膀手 → 摊手）。**阶段 1：膀手以前臂从上方接触木人桩的“手臂”。阶段 2：手转成掌心朝上的摊手，手肘压低，接触不断。阶段 3：另一只手掌击打身体（“下位佯攻掌”）。这是贯穿整套套路的基本组合。
2. **拍掌格挡 + 直线击打（拍手）。**手掌猛拍木人桩的“手臂”（内门或外门）——发出响亮、干脆的拍击声——立即接一记直拳／掌击桩身。一组连续右—左—右拍手（动作 21–24）。
3. **上、下同时控制（高低耕手／捆手）。**双手同时搭在木人桩上、下手臂（一个手切高位，一个切低位），身体转侧。这是贯穿全套套路的重复“副歌／标点”——几乎每组动作后都要做，并配合后退步。
4. **圆形手部转换（扣手 + 托手／圈手）。**手腕绕过木人桩的“手臂”画圈，从外门经过内门——双手仿佛包绕木头——随后垂直掌击。
5. **向下压 + 垂直击打（截手 + 垂直掌击）。**一只手猛压木人桩手臂向下（木桩点头），另一只手同时向前打向桩身，使用垂直掌击。
6. **抓颈／抓手。**手从木人桩手臂之间穿过，掌心停在木桩“头部”后方，然后猛拉向自己——木桩在框架上摇晃。用于搭档练习时，这相当于使对手失衡 + 截击。
7. **劈掌（割喉手／铲手）。**从膀手过渡，手掌翻转，以掌缘水平劈向木桩的“喉咙”，或像铲子一样击向“下巴”。
8. **从伏手弹甩出击。**手搭在木人桩手臂上（伏手——“桥手”），随后迅速弹甩拍击木臂——轻快、断续的敲击声，用于黏手训练。
9. **Po-pai——双掌推击。**双掌同时击向桩身（一只手指朝上，另一只朝下）——可以正面或侧面打，同时踏到木人桩“腿”的后方。声音最“有力”：沉闷的双重撞击，木桩在框架内明显后弹。
10. **手 + 侧踢组合。**双手保持接触（摊手 + 佯攻掌），前腿抬起并踢击：侧向推踢“躯干”、斜向下并向侧面的踢击“膝盖”、向前推踢桩身。风格关键：手和腿在**同一拍**运作。
11. **控制腿部（踩脚／沿腿滑动）。**格斗者的脚沿着木人桩弯曲的“腿”向下滑，踩住并控制它——同时双手以低位膀手／按手控制较低的手臂。
12. **交叉踢与摆动踢（套路收尾）。**唯二使用后腿踢击的动作：向前踏步，以交叉推踢“膝盖”，以及旋转摆踢；同时双手抓住并拉动木人桩手臂。套路以双手托手收尾——双掌同时向上推木臂的底面，然后收势。

## 格斗应用（成对动作拆解部分，第 46–105 页）

- 身体地图：中线／中心线、三个高度区域、内门和外门——所有格挡和击打都相对于这些区域说明。
- 每种木人桩套路都对应一种特定攻击：拍手——对付直拳（拨挡 + 直击脸部）；膀手——对付强力直拳（翼手化解、侧步、踢膝盖）；捆手——对付上下两路的双重击打；高低耕手——对付回旋踢；按手——对付从下方踢来的攻击。
- 标志性收尾：抓颈并拉扯 → 对手向前摔倒 → 截击拳打脸；抓住手腕 + 肘部控制 → 摆击前腿膝盖 + 双手拉扯——对手失去平衡并倒地（叶问在警察局制服抢劫者的故事——可直接用于场景，第 110–111 页）。
- 战术格言：“受击时站定；对手后退时压上；手一空出来就击打。”
- 腿部原则：踢击之后，腿不向后收回——只要改变轨迹，就立即踢出下一击；近距离时所有踢击都以前腿完成，远距离侧踢和后腿交叉踢除外。
- 经济性：一个有效动作比很多花哨动作更能保护自己；力量较弱、速度较慢的格斗者可以凭技法获胜——适合“老人对蛮汉”的场景。

## 训练场景：节奏与声音

- **套路节奏：**一侧连续做三到五个动作 → 转身 → 镜像重复组合。脉搏：哒—哒—哒（格挡—转换—击打），耕手停顿作副歌，脚步声——再来一遍。第 1–2 部分较慢（步法），第 6–8 部分更密集（Po-pai、踢击、最后的连招）。
- **声音：**三种质感——手掌干脆地**拍**在木臂上（拍手）；前臂闷闷地**敲**在前臂横杆上（膀／摊／耕手）；手掌／脚掌低沉地**砰**击桩身（Po-pai、踢击）+ 抓“颈”后木桩摇晃时的框架吱呀声和震动。弹甩手一组连续动作如同鼓点填充。
- **动作：**格斗者几乎不离开木人桩——用极小步幅绕桩移动，双手始终接触木头，手肘下沉，背部直立；腿不蓄势地抬起、踢击，然后立即踩到木人桩“腿”的后方。
- **标志性画面：**年长的高手（叶问拍摄于去世前几年——一位穿深色衣服的瘦老人）迅速打完木人桩组合，中间没有任何多余停顿；学生跟着重复但动作不稳；特写——发红的前臂；结尾——双手托手并后退一步，远离已经静止却仍在震动的木人桩。
- 故事钩子：1965 年，李小龙去找叶问，想学完尚未学完的木人桩套路，并请求拍摄——叶问拒绝了；只为部分弟子拍摄这套套路。“师父的秘密影片”——现成的麦高芬。
