# 17 — 咏春动态训练方法

**对编舞的补充：**书中没有的真实**动态**：技法随时间到底怎样移动——分两阶段“啪”地进入站姿，极慢且冥想式的示范与爆发性的 1–2 秒应用之间的反差，以纯粹的压力而非语言纠正学生，Master Wong 的搭档做出夸张的“电影化”反应（向后飞两三步）。还有触觉层面：推动测试身体结构是什么样（身体保持原位／被推开），手部接触后如何“不会抽离”，前臂拍击是什么声音。以及现成的街头小情境：截击拳击手的刺拳、头部锁定、推胸、安静的手 → 截击 → 反击。

---

## 1. 动态中的站姿

**两阶段进入 YJKYM 站姿（[Hi29C5sOJsQ](video-wc/Hi29C5sOJsQ.md)）**——最具电影感的站姿节拍：中立、双脚并拢 → 以脚跟为轴转动，脚尖向外转到“尽可能宽” → 以前脚掌为轴转动，脚跟向外 → 稳住：脚尖向**内**，膝盖弯曲并收拢。看起来像格斗者“啪”地卡入底盘——两声咔哒，身体像雕像一样定住。
- “钳羊”（Kim Yeung Ma）：所有力量向内——膝盖／大腿夹住一只想象中的羊；骨盆收起，呈“坐着”的姿势（仿佛坐在羊上），背部垂直，肩膀下沉。可以坐上好几个小时——小念头就是以这个姿势演练。
- **关键：**这**不是**格斗站姿（“腹股沟敞开、喉咙暴露——不能这样打架”），而像一件“负重背心”：练习者要学会从中**爆发**。场景中：YJKYM 用于训练／冥想镜头；英雄以爆发式踏步／转身进入格斗。
- 格斗站姿（[n-crGQ3NWNs](video-wc/n-crGQ3NWNs.md)）：与肩同宽或稍宽，膝盖略弯、“蓄势待发”——像压紧的弹簧；问手（前手）+ 护手（后手护掌在下巴处）防守，手肘下沉，在胸骨前构成“金字塔”。
- 典型错误——可直接用于编排“没受过训练”的对手：躯干前／后倾，站姿逐渐变成宽阔的空手道马步，重心四处游移；手肘外张 → 一推便把整个身体扫开（[xsXAK3DtbDc](video-wc/xsXAK3DtbDc.md)：Shin 推击，Dan 站根稳固，“新手”被推开）。
- 站姿场景的节奏：长时间静止 + 极小幅转动 → 突然爆发。轮廓对比（[AVPavzLbTVk](video-wc/AVPavzLbTVk.md)）：拳击手——站姿宽、拳套在颧骨旁、躯干先蓄势；咏春练习者——站姿窄、正面、赤手置于中线。

## 2. 动态中的手部动作

Dan Lok 的所有手部动作都遵循一条通用法则：动作从**手肘**发起，不从手开始（“盯着手看的是业余者”）；手肘是距离中线一个拳头位置的固定转轴（固定手肘，[7ic3Y9Jh3VE](video-wc/7ic3Y9Jh3VE.md)）；肩膀放松；每次“格挡”都是沿中线向前发动攻击；格挡 → 击打之间转换，不必重置姿势。

- **护手（Wu Sau，[D5XHHW_ut0I](video-wc/D5XHHW_ut0I.md)）：**前臂竖直放在中线上，张开的手掌斜朝对手脸部，手指紧紧并拢（“手指不要懒散”），拇指收起——手指露出来就会被抓住、折断（适合“受害者”的细小关节锁节拍）。公式：“中线、手肘、推。”转成击打——逐帧切换：手掌握成拳 + 手肘伸展 = 不蓄势的击打。一记护手只需微调就能化解整套直线连击。
- **膀手（Bong Sau，[qyIXOinBHfM](video-wc/qyIXOinBHfM.md) + [n-crGQ3NWNs](video-wc/n-crGQ3NWNs.md)）：**不是“鸡翅膀”式扑动——手肘几乎不动，前臂绕它旋转，手指“摸着一面想象中的墙”，指向喉咙。角度约 45°，手肘不越过中线。“弹簧力量”——持续向前施压，手肘“顶入”对手。最后手段——落败者精细化的受惊反射。躯干转动至关重要。最有电影感的格挡：前臂向外翻滚——搭桥接入拉手／黏手。
- **摊手（Tan Sau，[xsXAK3DtbDc](video-wc/xsXAK3DtbDc.md)）：**掌心向上的“托盘”，拇指收起，前臂约 45°；不是向侧面移动，而是进入**中线**——穿过攻击者手臂楔入拳击线路 + 另一只手同时回应（摊打，tan da）。“这是一种攻击，不是防守。”接触后收尾：像掷硬币般拍击——手像硬币一样弹出，不做蓄势。
- **标手（Biu Sau，[mfj16bcXlNk](video-wc/mfj16bcXlNk.md)）：**矛状手，“全部朝向眼睛和喉咙”；比拳头快几英寸、更长；直线刺出，或沿 S 形曲线绕过格挡——手部动作“像蛇”；连续打出 2–3 次标手并改变角度（上方 → 侧面 → 上方），每次都从上一个拨挡点出发——动作像波浪一样连续，手不收回。“暗杀之术”，是个子小者对付大个子的武器。
- **伏手（Fook Sau，[n-crGQ3NWNs](video-wc/n-crGQ3NWNs.md)）：**手腕弯曲的格挡，是黐手的关键。**拍手：**掌根弹甩拍击，是最佳的第一防守选择（Dan Lok 更喜欢拍手／拉手，而不是膀手 + 拉手——“电影里看着不错，但三步动作对一记拳”）。**枕手：**极小幅斜向下劈，身体转动增加触及距离。**耕／捆手（Gan/Guan Sau，[xI1Uxxke7CY](video-wc/xI1Uxxke7CY.md)）：**由手肘驱动向下落，“落向口袋”，用于对付上勾拳和踢击——“不是接住击打，而是把它压下去”（落下，不是接住）；幅度大的扫动弧线容许时机不准（“实战一片模糊”）。**圈手：**手腕绕过对手手臂画圈 → 立即掌击。
- **动作转换（[nW7sOO82fk8](video-wc/nW7sOO82fk8.md)）：**“拳瞬间变格挡，格挡变拳”，同一肢体不暂停；掌击后抖手——将手臂拉向自己 → 截击（“拉近并迎击”）；膀手 → 双掌推击——对手向后飞。

## 3. 黏着接触与黐手

- **黐手（[nW7sOO82fk8](video-wc/nW7sOO82fk8.md)）**——招牌动作：两名格斗者面对面，前臂黏在一起，手部沿摊—膀—伏的波浪滚动，躯干几乎静止——像用手“交谈”。训练凭本能读取力量方向，用最小动作转移力量。
- **单黏手循环：**搭档 A：摊手 → 低掌击 → 膀手；搭档 B：枕手 → 直拳 → 伏手；伏手搭在摊手上，循环以“有力但放松的力量流动”滚动——可直接套用在训练场景中的循环模式。
- 以压力纠正动作（[qyIXOinBHfM](video-wc/qyIXOinBHfM.md)）：师傅默默按压学生手臂——学生调整角度；“太高了，再低一点”；一有空当就轻轻拍击胸／喉。“他没告诉我——全是触觉感知。”结构错误时身体会在压力下摇晃——节拍标记：“结构垮了 → 躯干塌下。”
- 结构测试（[xsXAK3DtbDc](video-wc/xsXAK3DtbDc.md)、[D5XHHW_ut0I](video-wc/D5XHHW_ut0I.md)）：几厘米的角度调整会立刻改变稳定性；搭档全力出拳——摊手保持不动；“不是力量——是动作力学，我的角度是对的。”
- 黏着接触在格斗中的应用（[AVPavzLbTVk](video-wc/AVPavzLbTVk.md)、[Szs3-z91iKQ](video-wc/Szs3-z91iKQ.md)）：第一次接触后，不要放开对手手臂——压住／拉扯（拉手），向内滑入控制，切入拳套旁边的死角。
- 分层放松（[xsXAK3DtbDc](video-wc/xsXAK3DtbDc.md)）：手指 → 前臂 → 肩膀 → 髋 → 躯干；“像竹子——有弹性，而不紧绷。”

## 4. 踢击与步法

- 所有踢击（[n-crGQ3NWNs](video-wc/n-crGQ3NWNs.md)）——快速、**低位**、走直线、不蓄势，绝不高过躯干：踢腹股沟、膝盖、胫骨；作用是“骚扰”对手并缩短距离，始终配合双手（同一拍内踢 + 拳）。前脚跟踢从地面直线发出，用膝盖弹击；交叉踩踢用脚掌破坏平衡，为收尾做准备；低侧踢——脚跟踩踏。组合：交叉踩踢 → 侧踢躯干；对手前踢 → 格挡 → 利用对方自己的力量扫腿。
- 防踢（[xI1Uxxke7CY](video-wc/xI1Uxxke7CY.md)）：耕手“切”向下、向侧面，躯干保持垂直，距离维持不变；不要硬碰力量——引开它。
- **滑步（Shuffle，[n-crGQ3NWNs](video-wc/n-crGQ3NWNs.md)）：**前脚约 15 厘米，后脚跟上——格斗者以小幅滑步“驱身切入”对手（连环拳 + 前进步 = 对手直线后退，像“缝纫机”）。
- **绕圈步：**后脚沿弧线向前滑，切换站姿——切断后退对手的移动角度。
- **转轴移动（[7ic3Y9Jh3VE](video-wc/7ic3Y9Jh3VE.md)）：**躯干围绕中线轴旋转——防守时顺势滚开击打，进攻时得到新角度并增加触及距离；力量来自腰部／髋部扭转。转轴动作插在组合拳之间，用于变换角度，而不是后退。

## 5. 街头情境

- **截击拳击手的刺拳（[AVPavzLbTVk](video-wc/AVPavzLbTVk.md)）：**戴拳套的对手从远距离打出刺拳／交叉拳——迎上切入动作：平行拨挡（拍／摊手）+ 同时直击脸部（连消带打，一个节拍内完成，不是先格挡再击打）。拳击的长距离缩短成近距离；此时拳套不起作用；切换角度、黏住手腕、爆发连环拳。
- **安静的手 → 截击 → 反击（[Szs3-z91iKQ](video-wc/Szs3-z91iKQ.md)）：**前手在中线“悬停”而不动——不会因佯攻而抽动，只对真正的攻击轨迹作出反应；击打到达时，手短促抬起（拨开 10–15 厘米，不做大幅扫挡）+ 同一拍内在攻击手臂上方反击；接着向右滑步切入，控制颈部／肩部，以短促贴身击打收尾。完全平静 → 爆发——体现破节奏。
- **头部锁定（[K1F-vXRFgyM](video-wc/K1F-vXRFgyM.md)）：**摆脱控制 → 制住对手双臂 → 连环直拳；搭档弯腰对折，从侧面控制头／手臂，从上方收尾。
- **推胸：**用拨挡／转身化解推力，随后反推（双掌击打）将对手推倒。**抓手腕／衣袖：**转腕 + 反击。**“野蛮”僵尸式挥拳：**截击 + 直拳打脸。**从后方熊抱（[nW7sOO82fk8](video-wc/nW7sOO82fk8.md)）：**双手向后推击 → 摔投。
- Wong 风格的中线控制：几乎每种应对都从掌击下巴／脸部开始（头向后仰，躯干向后折），或从朝中线的拨挡开始，然后向前推进打出连环拳；Wong 会在每次出拳之间“挂”在对手手臂上。
- **Master Wong 的“电影化”反应——一种独特呈现风格：**搭档会**夸张地**向后飞出两三步、弯腰对折、仰头；每个技法都像一段街头冲突小场景，而不是练习。需要清楚易读的击打“电影物理效果”时使用；追求写实效果时，使用 Kevin Lee 那种克制的反应。

## 6. 训练场景

- **墙靶（[n-crGQ3NWNs](video-wc/n-crGQ3NWNs.md)）：**用拳和掌击打墙靶——体会“穿透感”，强化指节；慢速并逐步增加力量；这是典型咏春健身房陈设。
- **小念头套路：**从静止的 YJKYM 姿势开始，动作极慢——冥想般地练习单手动作，躯干保持不动（参考画面：白色背景，巨大的书法字）。叶问曾把摊手练习一小时作为冥想（[xsXAK3DtbDc](video-wc/xsXAK3DtbDc.md)）。剪辑模板：“单人套路手势（慢速）→ 与搭档做同一动作（锐利）”——“套路 → 应用”。
- **成对练习：**耕手 → 出拳循环（一只手下压，另一只出击）；用三分之一力量自由流动（“只是顺着动作走”）；单黏手循环；压力测试。手靶训练（[AVPavzLbTVk](video-wc/AVPavzLbTVk.md)）：搭档拿圆形焦点靶——配合前进步打连环直拳、直线连击。
- 年代服装规则：VHS 经典风格——师傅穿黑色功夫服，学生穿白衬衫，摄影机静止，轮廓干净；现代风格——Dan Lok 在有全景窗的阁楼里穿黑色 T 恤，Wong 穿运动服在户外／海滨活动，Lee 在拼接地垫健身房训练。
- 音效设计：手掌拍击前臂发出清脆的拍声——这是咏春的标志性声音；连环拳打出均匀的机枪式爆发。

## 7. 动画师的时机／节奏

- **两种模式必须持续对照：**教学／准备——舒展、如“丝绸”般顺滑、冥想式；应用——不蓄势地爆发 0.3–1 秒。没有中间速度。
- **一个节拍 = 防守 + 击打。**格挡与反击同一拍（连消带打）；对一击做三次动作会显得“不真实、像电影”（Dan Lok 批评膀手 + 拉手的做法）。出拳后收手时会自动形成格挡。
- **破节奏：**静止停顿（双手“安静”，安静手）→ 半秒内做 2–3 个动作 → 再次停住。Master Wong：对话般的停顿 → 爆发 1–2 秒 → 停止。
- **连环拳：**竖直拳交替沿一条管状直线路径“活塞式”击出，手肘下沉，最后手腕一弹，每两三拳配合一个小幅前进步；节奏均匀、没有重音，每秒 4–6 拳。
- **不蓄势：**击打从胸前／接触点开始（一寸拳、掷硬币般的弹掌）；力量来自身体结构和躯干扭转，而非大幅动作。任何大幅蓄势／侧向劈砍式格挡都是“没受过训练”的对手才会做的动作。
- **距离：**一切都在弯曲手臂的长度内决定；前臂几乎始终互相接触；用 15 厘米滑步切近，不要跳跃。
- **结构失效标志：**推一下身体就被移走，躯干在双手后方塌陷，手指张开而被抓住——用结构崩解表现落败，而不是“飞出去”（除非使用 Master Wong 风格）。
