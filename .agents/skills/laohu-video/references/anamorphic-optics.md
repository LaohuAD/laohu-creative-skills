# 变形宽银幕实拍光学专项（Anamorphic）

**触发条件（平时 0 加载）**：仅当本作已明确采用**实拍变形宽银幕电影视觉**，或用户显式要求本镜呈现变形镜头光学特征时读取。常规实拍、动画、绘本、剪纸或仅需普通浅景深/焦段时不加载本文件。正文沿用本轮输出语言，除用户锁定的品牌或资产名外，一律写可见成像结果，不写胶片厂家名。

---

## 1. 按镜头任务选焦段

| 观看任务 | 推荐焦段 | 约略对角视角 | 取用理由 |
|---|---:|---:|---|
| 空间建立与方位交代 | 24mm | 约 84° | 纵深与建筑层次清晰 |
| 带主体物件的环境层 | 35mm | 约 63° | 兼顾虚化与较低边缘拉伸 |
| 紧凑室内、窄巷、车内 | 40mm | 约 57° | 避免 24mm 贴墙过近 |
| 人物中景与对白表演 | 50mm | 约 47° | 比例自然、面部可读 |
| 肖像特写与局部插入 | 85mm | 约 29° | 避免广角拉变形人脸 |

人物肖像需要自然比例时，从 85mm 肖像、50mm 全身或 35mm 群像起步；文字描述视角可写 `对角视角约 84°，变形宽银幕直线投影，镜内视角稳定`。画幅开放时以 `2.39:1` 为构图起点（入口仅提供 `21:9` 时作近似构图，精确裁切归交付设置）。实体机位宜设在空间一侧四分之三斜角望向纵深，写明镜头高度（膝/腰/胸高）并保持单机同侧。

---

## 2. 用物理条件锚定广角强虚化

24/35mm 不会自动产生强虚化；需要明显前景/背景虚化时必须同时落地四项物理条件：

1. **命名唯一焦点物**：精确指出合焦边缘（如最近的桌面边沿或人物睫毛/衣领），避免模型把全画面做清晰。
2. **明确近距离与机位高度**：摄影机距焦点约 1–3 米，写明镜头处于膝、腰或胸高。
3. **大光圈全开**：明确大光圈浅景深状态。
4. **写出融化层次**：交代前景哪一物化作柔和虚影、远处背景哪一层消散为柔焦。

---

## 3. 把变形散景、条状炫光与胶片颗粒写成画面实景

- **纵向椭圆散景**：明确椭圆呈**上下纵向拉长**（非圆形），并指明落在哪一处真实高光上（湿地、水洼、灯泡、窗沿反光）。
- **色温匹配的水平炫光**：条状炫光呈水平拉长，必须源自画面里真实存在的最亮光源；冷/中性强光配蓝色水平炫光，**唯一暖光源（钨丝灯、火焰、烛光）配暖橙色水平炫光**。画面无亮源时不强加炫光。
- **按光线配胶片颗粒（作为视觉质感描述）**：
  - 夜间、室内、黄昏、钨丝灯 → 钨丝灯平衡、500 感光度彩色负片明显颗粒；
  - 日光、阴天、明朗外景 → 日光平衡、250 感光度彩色负片细腻颗粒。

## 4. 常见失效定向修偏

| 画面失效 | 直接改法（用正向画面句落地） |
|---|---|
| 全画面一样清晰 | 点名唯一焦点物 + 距焦点 1–3 米 + 大光圈全开 |
| 散景变圆 | 明确写出纵向拉长的椭圆高光并绑定到具体反光物 |
| 缺炫光或暖灯冒蓝光 | 绑定画面真实亮源，暖光源改写暖橙色水平条状炫光 |
| 边缘鱼眼/桶形畸变 | 明确直线投影（rectilinear），改 35mm 并复核拍摄距离 |
| 人脸边缘拉伸 | 改用 85mm 肖像或 50mm 中景并拉远距离 |
| 画面偏塑料 3D 感 | 补足对应场景的彩色负片颗粒与真实材质受光 |
| 需消除渐变/边缘暗角 | 正向写全画面边缘色调均匀（若入口带独立负向参数槽且启用，负向词限 3–5 词；正文仍守正向描写与用户硬禁分层） |
