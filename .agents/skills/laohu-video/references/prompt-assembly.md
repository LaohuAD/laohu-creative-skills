# 三段编译与初稿优化

由主 Skill 第一步收到初稿时读取，第三步建立素材映射，第十步组织画面内容，第十一步整稿复核时复用。完成当前判断后返回相应步骤，不重新启动全部流程。

## 三段各自解决一个问题

**设定给依据，状态给起点，画面给变化。**

【基础设定】定义当次生成方式、实际参考素材及各自职责、稳定声音设定和必要输出要求。只纳入本段实际调用的资产；标识能追溯到输入文件或当前平台中的真实素材。

【场景状态与氛围画质】建立开拍前已存在的空间、人物与道具状态、继承的前段后果，以及全段风格和成像基线。先以宏观方向定调，再选择能在成片中看见的摄影特征，如光源与主体/背景明暗关系、色彩、空间层次、景别和运动气质。作者、导演或作品锚点只有在相关特征已核实并能转成具体方案时才采用；名称本身不能替代光线、色彩或机位设计。可保留有表现力的宏观情绪或诗性先导，但具体伤势、位置、持物等状态仍明确。第二段不是对第一段资产说明的复述，也不预先写完剧情变化。

【画面内容】沿镜号和持续秒数展开主体、表演、摄影、声音、光色变化及切镜承接。机位路径、动作、情绪和光线如何随时间变化，写进实际发生的镜头；第二段可留下稳定风格与宏观先导，不以全段轨迹替代逐镜过程，也不因此删去诗性表达。局部特写需要强调的特征可再点出；实际参考已经定义的外形无需整段重复。文生视频没有参考固定的主体，描述到足够辨认其身份与关系。

## 资产身份与实际调用

项目资产编号回答“这是哪一项”，文件回答“本次用了哪份素材”，平台标签回答“模型怎样引用”。三者建立对应后才编译，不把资产号冒充模型已识别的标签。同一图片可参考多个属性，写清实际职责；多张图片共同定义一个角色时，区分主身份依据和局部补充。

引用只固定其明确负责的范围：身份图控制外形，不自动固定本镜姿态；场景图固定空间，不消除前镜造成的变化；风格图参考光色与质感，不自动替换剧情主体。已有资产的开放项由本镜设计，固定项按用户决定保留。

必要文件待取得时，块外列素材准备事项，在正文用明确对象名称写方案，并说明该段完成素材绑定后可用。仅改动作且素材不变时复用已确认映射；重新分段、素材顺序改变或输入换图时同步更新基础定义与镜内引用。每段独立完整，不以“同上”作为唯一资产定义。

## 生成段如何接续，参考实际负责什么

同一生成请求中的多镜共享本段的基础设定、事件与前镜上下文；镜头间只需交代会改变或需重新辨认的状态，不把每镜写成一条独立提示词。只有明确拆为多条独立生成请求时，才分别建立自足开场，并按真实提供的参考说明继承职责。

多段生成先判断这条边界是**直接连续、同场重建还是关系重置**，再决定是否使用真实存在的尾部视频、终帧、首帧或声音参考。直接连续时，只有确实取得的参考才写入【基础设定】，并说明它负责继承哪些身份、场景或动作状态；B 的开场仍要说清人物和空间状态以及接下来的第一项新变化。若切点用动作匹配，B 接 A 留下的动作相位，不把已完成的动作重新演一遍。同场重建可用实际终帧固定仍有效的世界状态，但新机位和新构图仍在文字中建立。关系重置时不继承上一段的站位、构图或视线；仍需要身份或风格一致时，只绑定对应真实素材。

没有图像、视频或音频参考时，按独立文生段编写：开场文字自身给出观众需要辨认的主体、注意对象、空间与主要位置、观察方向、光线和初始动作状态；武戏或物件动作按需要补支撑面、双方朝向与距离、持物手及动作相位。只有剧情接续确实需要时，才补前段留下的伤势、破坏、天气、光效、声音或其他状态。不能用“接上段”“保持上一段”替代这些开场事实，也不能伪造参考素材、标签、尾帧或时间码。各段使用什么构图由切法决定，不要求同一构图，也不把同一套状态字段机械填进每段。

## 时长与模型接口分别处理

分别记录成片目标总时长、单次生成上限和本轮实际接口时长设置；前两项决定作品预算与分段，后一项以真实入口可确认的值为准。模型名称本身不构成时长选择。用户只给一个时长时沿用其表达的目标或上限含义，歧义会改变分段时再补问；只给上限也不等于必须填满。接口设置未知时标明待确认，不抹掉“持续约 N 秒”的逐镜计划，也不写成接口可精准调度的承诺。模型与入口另行决定参考标签、模式、声音支持和格式。

用户要求可直接提交的专有格式时，核对该实际入口提供的字段或材料。已确认的入口规则应用于标签、引用和必要参数，保持剧情、时长和三段职责；当前没有某模型专属 Reference 时使用通用创作方法，询问或按授权查证真正影响提交的接口缺项。不把“MiniMax H3”“Seedance”等名称写成固定能力表。新增适配 Reference 须有真实差异与调用条件，不按品牌制造空文件。

本项目三段式是提示词的编辑与使用结构，不声称任意接口都按这三段进行官方解析。平台独立设置的参数放在必要块外说明；用户明确要求正文携带或入口需要时才纳入对应设定。

## 初稿优化保留什么，改变什么

先按当前请求区分三类工作：

| 用户要改的部分 | 执行范围 |
| --- | --- |
| 只整理格式 | 重排到三段、整理引用与编号，不改剧情、台词、镜头内容及情绪方向 |
| 改善导演表达、声画与镜头衔接 | 保留有效事件和关键设计，完善描述粒度、观看理由、表演与声画关系，回相关专业步骤 |
| 明确允许重做分镜或重构视频方案 | 按原表达目标比较并调整镜头结构与时长，保留用户仍锁定的内容 |

没有额外限定的“优化提示词”可完善表达、结构与一致性，不能静默换成另一剧情或另一情绪。既有镜头的目的明确且有效时沿其升级；镜头重复、时长不足或关系不清时指出具体差距，在授权内调整。锁定项冲突只处理受影响部分，不把局部问题升级成整篇重写。

按原句承担的功能编辑：粗述提供动势时保留其方向，细述控制关键接触时保留其因果，抒情先导统领质感时保留其气质。专业化意味着让现有表达更清楚和有力，不等于统一换成平淡、短促的说明文。

## 正式交付的结构

每段编号、源内容范围、计划总时长与必要解释放在代码块外。代码块中用以下固定标题组织；这里是格式合同，不是创作范例：

```text
【基础设定】

【场景状态与氛围画质】

【画面内容】
【镜头01｜持续约N秒｜景别、机位与主运镜】
```

每镜标题必须逐项写出编号、持续时长、景别、机位位置与角度、主运镜；静止机位写“固定”，机位与角度仍需明确。格式如 `【镜头01｜持续约3秒｜中景｜机位：右前侧平视｜主运镜：向左跟拍】`，替换真实内容，不保留空槽。正文用自然导演句写主要观看任务和承重过程，不把内部要素盘点抄成字段表；避免重复描述已经清楚的基线。台词使用明确引号，表演指令在引号外；声音和环境变化按其发生位置并入镜头描述，不另造与画面争夺顺序的主轨。三段之外不增加导演分析的第四区块。

## 合并、压缩与最后复核

先完整兑现剧情与镜头，再删同义复述、空泛修饰与无职责参数。保留身份绑定、时间顺序、关键行动、情绪转折和切镜结果；字符限制实际存在时按入口要求整理，必要时回分段，不靠删除承重因果伪装合规。

逐段核对第一段是谁和参考什么、这些参考真实负责什么，第二段从哪里开始及稳定基线是什么，第三段如何逐镜变化到结束；生成段之间检查 A 尾、B 头、切点载体和新证据，真实剪辑关系按[声音、光色与剪辑承接](audiovisual-and-editing.md#镜头切换先问要留下什么)的术语说明。称呼、标签、台词、镜号、持续时长、每镜标题五项字段与状态在各处一致。反向读稿时检查每个短镜头的主要观看任务是否明确，连续表演是否被无理由拆开；逐镜内部要素是否已盘点但自然落在导演句里；初稿的有效情绪与调度有没有被规范整理写弱，诗性先导有没有由镜头落实，内部解释有没有进模型正文，无参考段首帧是否自足，每段是否能独立复制使用。

## 方法依据与本地适配

三段职责将稳定参考、初始状态和时间变化分开，再沿主流程依次形成。输入映射、格式与优化分支是本能力的使用合同；模型的真实标签、时长与接口要求由实际入口决定。

独立生成与段间参考职责参考老胡AI视觉《跨批次连续性参考模式》及《视频提示词机制与描述粒度》的相应方法。本文件把直接连续、同场重建、关系重置和无参考文生段整理为条件分支：真实素材职责按输入绑定，独立段文字仍建立自足开场，不要求统一构图或机械复述全部状态。
