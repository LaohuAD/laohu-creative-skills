# 三段编译、全模态资产绑定与真成片排障

本文件是 Video 编排中文三段式提示词、全模态参考资产按段零污染绑定、跨段一致性核查、成稿轻扫疤及看片四维减法排障的唯一真源。

**前两段极简锁锚，第三段把全部词元押在一镜一事的高杠杆钢钉上；块外给足人话制片导航，块内只留视频模型直接拍得出的硬画面。**

---

## 一、中文三段式极净编译格式（默认无逐镜死时间轴）

每段独立 P 交付一个可直接复制投喂视频模型的纯净代码块；制作备注、建议生成总时长区间、导演质疑说明、跨段抽帧建议与未绑定项目编号一律留在代码块外：

```text
【基础设定】
画风媒介、影调色温与实时速度/快门质感；本段真实出场或生效的图/音/视参考及单主责绑定（无实参考则整句省去）；全段贯通的统一环境声底与稳定角色声线（本段无对白则不写嗓音）；非画面类硬红线（如禁止字幕、禁止水印、禁止背景音乐）。

【场景与人物初态】
极简 2–3 行锚定开拍空间与唯一主光源；当段出场角色的高对比外观指纹与开拍动作初态（若已绑定清晰角色/场景参考图，大幅压缩外貌与环境复述，防文字与图片冲突）。

【画面内容】
镜头01｜景别与角度｜运镜（可选简短节奏提示，如短促切入 / 稳住久留）
50–90 字高信噪比可执行画面：先钉清机位几何可见面，再写这一镜唯一核心行为（起势微兆 → 核心过程/触觉或物理铁证 → 活态余波/情绪残留）及关键光声点睛。

镜头02｜景别与角度｜运镜（紧接切换 / 硬切反打）
……
```

### 块内表达五条硬纪律
1. **去掉逐镜死时间轴（默认）**：块内不写 `0.0–1.5s`、`1.5–3.2s` 这种小数点坐标，防模型抢拍或僵硬。用自然节奏提示（短促切入、急促爆发、紧接切换、稳住久留）加上画面内真实的持续物理过程（缓缓滴水、呼吸起伏、水雾散淡）控制长短呼吸；**后台轻算的总时长，统一作为“建议生成总时长区间”写在代码块外**。仅用户明确点名可灵自定义多镜头秒数 UI 或 Seedance/Higgsfield 时间轴模板时，才按 [平台适配](platform-seedance.md) 输出逐镜建议秒数。
2. **每镜 50–90 字高杠杆钢钉**：删光稀释注意力的空洞抽象词（极其震撼、杀气腾腾、电影感拉满、充满张力），也不把第二段已定好的完整外貌和场景在每镜反复抄写。每镜只保留真正缩小画面自由度的事实：机位真实可见面、唯一核心行为、物理或触觉铁证、单点生理泄密与关键光声变化。
3. **两类约束分家（防粉红大象）**：只有没有直观正向画面的交付红线（禁字幕、禁水印、禁背景音乐）才在 `【基础设定】` 写 `禁止……`；所有画面物理、完整度、视线、姿态与画风要求（双脚实踏地面、兵器笔直完好、背对镜头只露后脑与肩背）全部写成正面可见事实。
4. **台词引号纯净原则**：镜内双引号只留给角色真正开口念出的逐字原台词本身；重音、气口、语速与听者反应全部写在引号外（如停顿半拍后压低声音轻声说），不再用引号二次摘词点评，防音画同步模型口吃复读。禁配乐戏写打击或脚步声一律直写皮肉、金铁、木石、衣料等物理拟音，避开鼓点、琴弦等乐器比喻。
5. **跨镜顺承收口**：每镜末句自然落在清晰的姿态、道具位置或情绪物理残留上，省去冗余的 `镜尾状态：` 复述栏。

## 二、全模态参考资产绑定与按段零污染规范

1. **三类标识严分**：项目追溯名（如 R1、`@角色名` 仅表项目资产归属）留块外，不冒充已附实图或平台标签；真实媒体只指本轮实际提供或可核实的图/音/视频；平台标签（`@图1`、`@视频1`、`@音频1` 等）仅在真实绑定或按用户约定槽位明确使用时写入，不凭模型名凭空捏造。
2. **按段“出场即引用、未出场清零”铁律**：分段制作时先核对本段真实出场清单——**只有本段画面或声音里真正出现、或实际驱动本段动作/节奏的已有资产，才写入本段 `【基础设定】`；本段未出场的人物、道具、场景或音视频参考一律不引入**，杜绝多模态模型幽灵串脸、强行把未出场人物塞进背景或串味。
3. **三模态单主责分工与文字让位**：
   - **图像参考（人物 / 核心道具 / 首尾帧 / 前段实拍抽帧 / 固定主据点场景）**：
     - 身份与道具图只管稳定外形，不锁死姿态与单场表情；绑定清晰角色图后，正文立刻删去冗长外貌复述，但**多镜或多人同场时在每镜该对象出场处仍保留简短标签复锚（如 `@图1 沈砚`）**，避免后半段脱标换脸或串车；若角色参考图自带的道具在中途脱手、飞失或碎毁，须在绑定句明示该道具随剧情脱离，并在离场后的特写镜显式写清“空手/空口”状态，防参考图权重触发道具回弹长回身上；
     - 承接 `laohu-assets` 四宫格资产图时，在绑定句明示仅取人物头肩五官与全身穿搭（或道具/空间实体构造），**舍弃四宫格分格排版、中性展示底面与棚拍平光，自然融入本场光影与景别**；
     - 跨段承接前段实片高光抽帧时，明示**具体建议抽取前段哪一类镜头（如外景夜景帧或内景光色帧）并仅延续该帧的环境色调、光影质感与空间氛围，切换至本段新机位与新景别**，防把新镜头锁死在旧构图里。
   - **视频参考（复杂动作招式 / 高难运镜轨迹）**：明示参考哪一条视频的招式发力节奏或摄影机运动路径；**一旦绑定动作或运镜视频参考，正文自动清空与之冲突的文字运镜词与手把手招式细描**，把动力学控制权完整交还参考视频。
   - **音频参考（稳定声线 / 既有对白音轨 / 节奏卡点音效）**：明示参考其音色质感、既定对白或打击节奏；同段绑定两条及以上角色音色时，在各自发言镜头就近复锚 `@音频1`/`@音频2` 防中后段串音；正文标清哪一镜或哪一次撞击咬合重拍，已完成对白音轨不重复按待生成台词估时。
4. **块外制片导航（每段必附极简 4 项人话提示）**：
   - ① 裸标号、来源范围与导演质疑/升维简注（2–4 句大白话，无改动则简注视听核心）；
   - ② **建议生成总时长区间**（注明默认上限 15 秒，可随时改 30 秒或更长；若自然时长偏紧，给可删哪一镜压进 10 秒的备选）；
   - ③ 本段已引用出场资产核对 ＋ 跨段衔接建议（常规推荐用前段实片抽帧＋连续声底；仅刻意长镜头提示用动态尾帧生首帧）；
   - ④ **降熵排雷提示**（若某镜含纯文生高危难拍动作、极端构图或多人缠斗，主动建议补 1 张首帧图、挂 1 条动作参考视频或拆成两段短生成）。

## 三、纯格式整理、局部修改与总述一致性

| 请求类型 | 允许操作 | 守住的边界 |
|---|---|---|
| **纯格式整理 / 保真重排** | 迁入极净三段式、理清引用与编号 | 保留原剧情、台词、镜序、秒数与情绪；原稿未指定景别/角度保留原布局或标 `原稿未指定`，跳过导演升维与子模块 |
| **局部修改** | 只修正受影响镜头、相邻连戏与建议时长 | 返回受影响 P 的完整独立三段式代码块，无关 P 原样不动 |
| **缺工作稿或原时长** | 列出精确缺项后停步索取 | 不凭摘要脑补镜头、动作或数值 |

### 总述与镜头工作稿一致性
编写 `【基础设定】`、`【场景与人物初态】` 或块外节奏总述时，必须从**最终定稿的逐镜内容**反向核对，确保前后零打架：
1. **覆盖范围严核**：只有全段真正保持不变的画风、声底、速度或身份才写进全局总述；随剧情中途改变的位置、持物、速度（如局部慢放）或声场，按对应镜号起止写清，不用笼统的“始终、全程”锁死局部例外。
2. **改镜必回核总述**：局部修改任一镜头后，顺手复核全局速度、参考引用清单、出场人物表与建议总时长是否同步一致。

## 四、成稿后 5 秒冷眼轻扫疤（只修真疤，不磨灵气）

写完初稿后，以挑剔剪辑师与视频模型双重眼光快速扫五眼：
1. **因果、换位与连戏关**：后镜爆发的结果前镜是否已埋伏笔？空间时序是否单向推进不倒错？上一镜手握道具、站位与攻防左右位置到下一镜是否零瞬移、换位有交代？跨镜物理情绪残留是否带上了？
2. **几何手性、纵深净空与景别容度关**：过肩或背身镜头是否明写了背对镜头、只露虚焦后脑肩背且零描写背身人脸表情？**正面拍人物时，其左手边物体是否准确落在画右、右手边落在画左（零镜像穿帮）**？面部特写有没有硬塞装不下的远处手部或物件？凡出现多兵器阵列或群像时，是否落实了**主角 Z 轴净空区、物小于口比例（兵器远小于光环内径）与特写切全景必换明显观察角**？
3. **负荷、审美海拔与字数关**：是不是严格一镜一事（且不可分同框爆点未被机械拆散）？镜数是否匹配“单段时长 × 节奏类型”（纯文生无图对白戏避开连续两镜以上无正脸断档；30 秒高频剧场动画/史诗不机械死锁 8 镜内）？未锁定来稿是否真的完成了**机位、前景光学景深、冷暖光影、本能动作与奇观尺度的主动升维**（而非只洗成平淡安全稿）？单镜是否落在 50–90 字高信噪比精华，无死时间戳、规则腔词（如直抄“全脸松弛”）或空洞情绪形容词？
4. **资产与声画关**：`【基础设定】` 里是不是**只引了本段真实出场/生效的资产**？已绑定标签是否在每镜简短复锚且已删冗余外貌？引用电影片名时是否已先写透像素级媒介肌理（不裸报片名赌运气）？有视频参考是否已清冲突运镜词？空镜是否个个说得出明确情绪？全段有没有统一环境声底？
5. **代码块纯净关**：块内零管理标头、零工程前缀、零未绑定符号、零无对白时的嗓音描述、锁定台词一字未改；块外建议时长与制片提示用直白人话。

## 五、看片后四维反向减法排障（带真实成片返修时必查）

真实视频生成偏离预期时，**绝不靠往提示词里继续叠形容词补救**，直接按成片翻车现象定位最早断点做精准减法：

| 真实成片翻车现象 | 最早断点与真实诱因 | 精准减法修法 |
|---|---|---|
| **像廉价短剧 / 浮夸哭嚎过演** | 灵魂/血肉误写了直白情绪标签词，触发全网均值表演 | 删情绪标签，改写**情绪阻力动作 ＋ 面部松弛底盘 ＋ 单点生理泄密** |
| **死鱼眼发呆 / 高潮停顿像静态图** | 静止或停顿镜头缺少活态微动锚点 | 在停顿句补 1 处极轻活态物理微动（胸口起伏、滴水、散烟、眼神轻移） |
| **过肩对峙变成两人都面向镜头** | 只写抽象术语、挂了双人正面图或同镜写了两人表情 | 明确写前景某人完全背对镜头只露虚焦后脑与肩背，**彻底删掉背身者的脸部与表情描写** |
| **动作糊成麻花 / 肢体融化 / 慢飘** | 单镜塞了多招连发、报关节菜名或误用诱发慢放的柔词 | 拆成 **一镜一事短镜**；改写**起势 → 接触质变 → 受击物理反馈**三支点；高难招式改挂动作参考视频或拆段 |
| **切镜节奏僵硬 / 高潮一闪而过** | 块内误写死时间戳，或缺少长短节奏对比与活态停留 | 清掉小数点时间戳，短镜写短促切入、高潮镜写稳住久留配具体耗时物理微动 |
| **后半段换脸 / 幽灵多出路人 / 串味** | 单段字数过载、反复换词重描外貌，或引入了本段未出场的参考图 | 剔除未出场参考资产；有图删外貌复述；无图统一直呼姓名＋高对比短指纹；压减每镜字数 |
| **画面突兀 / 物体瞬移 / 声音断层** | 缺前镜伏笔、手物没交接，或缺少跨镜连续声底 | 补 1 个短信息伏笔镜、写清道具去向，并在基础设定钉死贯穿全段的统一环境底噪 |
| **后景法宝/飞剑膨胀撑破光环、扎穿前景主角或指向跑偏** | 缺少“物小于口”比例与主角 Z 轴净空区，或特写切中全景未换观察角导致尺度惯性残留 | 锁定阵列退至主角身后 2 米以上高空弧形展开、兵器横截面远小于光环内径且锋尖全数高越主角头顶指向远方目标；将特写切全景改为明显异角机位重立人景比例尺 |
| **画面虽通顺但像平淡预演、缺电影大片质感** | 只顾控稳减词却未种入光学景深、冷暖主辅光与像素级媒介肌理，或裸报片名未落可渲染材质 | 补入前景虚焦框景/散景层次、戏剧冷暖主辅光反差与像素级材质笔触，抬升关键镜仰俯角度与人景比例反差 |
| **跨 P 拼接卡顿或画风跳脱** | 段界劈在半截动作上，或两段未共享光色参考 | 把切点移回完整回合/气口处让下段换景别硬切；从前段实片截 1 张高光帧给下段延续环境光色 |
