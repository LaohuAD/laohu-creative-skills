# 三段编译与初稿优化

由主 Skill 第一步收到初稿时读取，第三步建立素材映射，第十步组织画面内容，第十一步整稿复核时复用。本文维护素材/平台职责、三段合同、局部优化与合并的共享方法；仅当多镜/多 P 结果需正式合编或局部改动需要同步完整受影响块时，才按需调用 assembly 方法模块。完成当前判断后返回相应步骤，不重新启动全部流程。

## 三段各自解决一个问题

**设定给依据，状态给起点，画面给变化。**

逐P详细提示词承接用户采用的 P、完整源稿的相关上下文、第一阶段初镜概要和当前可用资产。本 P 的提示词块即使脱离上下文，也须完整交代本段引用职责、开镜与过程状态、必要输入及生成信息。独立完整不等于复述资产：按本 P 需要消费资产关系清单中对应项及依赖；同一资产跨 P 使用时，各块分别写明本段实际调用的职责、依赖和状态，不因此在 Assets 中重复设计同一资产。若本轮实际图片已定义稳定外形，不重抄图像已承载的稳定信息，只补本 P 当前状态与动态；只有设计文本时，项目名和编号只作追溯，应把本 P 实际使用且资料确实给出的辨认信息转成每个独立块内可执行的视觉描述，按需写入【基础设定】、【场景状态与氛围画质】或首次出现镜头；人物外形服装、物件形态、空间方位等只写本段需要的已知信息，不按固定字段补齐，同一 P 内不逐镜重复稳定内容。缺少必要事实时依既有授权在开放项内设计或按原有边界询问，不编造既有资产事实。若没有正式资产或关系清单，依据现有文字继续提示词，不虚构资产 ID、媒体或标签；是否正式转交 Assets 设计依 Video 主 Skill 授权规则。

【基础设定】定义当次生成方式、实际参考素材及各自职责、人物/旁白与稳定声音身份的绑定和必要输出要求。声音素材按本段实际职责区分：稳定声线身份参考、某次具体表演参考、已完成对白音轨、跨镜/跨段声音接续；不得把概念设计、试音、作品音轨或供应商 voice ID 混成同一种素材。项目 `@` 名称/编号只是追溯或本地资产引用，不代表已上传、已被入口读取或是平台标签。实际媒体标识须能追溯到本轮输入或真实入口。只有设计文本时可沿用已知文字锚点并标明没有真实声音参考，不伪称已听取或可调用素材。

【场景状态与氛围画质】建立开拍前已存在的空间、人物与道具状态、继承的前段后果，以及全段风格、成像和场景声场基线。稳定声线身份不在此重选；写场内外声源、房间/距离/遮挡及全段听觉底层等确实成立的基线。先以宏观方向定调，再选择能在成片中看见的摄影特征，如光源与主体/背景明暗关系、色彩、空间层次、景别和运动气质。作者、导演或作品锚点只有在相关特征已核实并能转成具体方案时才采用；名称本身不能替代光线、色彩或机位设计。可保留有表现力的宏观情绪或诗性先导，但具体伤势、位置、持物等状态仍明确。第二段不是对第一段资产说明的复述，也不预先写完剧情变化。

【画面内容】沿镜号和持续秒数展开主体、当句对白表演、摄影、声源/音轨事件、光色变化及切镜承接。每镜继承第一段已绑定的声音身份，不重写整套声线；台词语气、停连、受抑或抢接等表演变化及可听到的环境/动作声按实际时点落在镜头。已完成对白音轨只按已授权的真实素材安排声场和同步，不再作为待生成对白；试音样本不当作剧情声音。机位路径、动作、情绪和光线如何随时间变化，写进实际发生的镜头；第二段可留下稳定风格与宏观先导，不以全段轨迹替代逐镜过程，也不因此删去诗性表达。局部特写需要强调的特征可再点出；实际参考已经定义的外形无需整段重复。文生视频没有参考固定的主体，描述到足够辨认其身份与关系。

## 资产身份与实际调用

项目资产名称或编号回答“这是哪一项”，实际文件/媒体回答“本次用了哪份素材”，平台标签回答“模型怎样调用”；三者不可互相冒充。用户要求以项目已有名称/编号作 `@` 引用时，可照实保留并写明职责；项目级 `@` 不证明本轮已附图/音频，也不自动成为平台可识别标签。只有本轮实际输入或真实入口确认的文件/媒体与平台标签才绑定为当前调用素材；只有设计文本时，名称/编号供追溯，正文仍需把本 P 实际使用且文字明确给出的视觉辨认信息或声音身份锚点编译成对应段落，不以引用代替内容，也不伪造文件、媒体或标签。逐份确认真实素材的职责：身份/外形/服装、场景/道具、风格、明确的构图/姿态参考、实际首帧/尾帧，声线身份参考、特定表演参考、已完成对白音轨或声音接续材料。同一图片或声音素材可承担多个职责，写清范围；多份素材共同定义一个角色时，区分主身份依据和局部补充。

引用只固定其明确负责的范围：身份参考不自动锁定本镜姿态，场景参考不消除前镜造成的变化，风格参考不替换剧情主体；其他明确承担构图/姿态参考的素材及用户已锁定项，按其职责保留约束。若图像实际作为首帧输入，承接其开镜构图、主体位置与朝向、光色和动作相位。以可读图像或已给说明为依据，不从文件名猜画面，不把文字资料说成看过图片。把身份、服装、空间等稳定项与当前镜头持物、伤损、位置等状态分开，前镜结果优先承接，基础资产不重置它们；开放项由本镜设计，固定项按用户决定保留。

声音同样按素材职责而非文件名推断：声线身份参考用于稳定的角色可听锚点；具体表演参考只在它实际承担的表演范围内使用；已完成对白音轨是当前可使用的作品音频，不再次作为待生成对白；接续材料只承接其真实覆盖的声场/状态。只有文字设定时沿已知锚点写本 P 的说话人绑定，并如实注明尚无真实声音参考；不把试听样本当成剧情音轨或其时长当对白时长。

多人物行动用姓名加当镜可见位置或区别线索绑定；换机位后重新确立相对位置。素材与剧情的张力先在开放的摄影变量中处理，不因一次映射额外设确认门槛；只有用户锁定内容或现有授权边界要求选择时才询问。没有真实图像时继续现有文生或实际素材待准备路径，不虚构文件、媒体或平台标签；已知的项目资产名称/编号可以按要求用于 `@` 引用，但不代替真实媒体调用。实际文件/媒体尚未取得时，块外列素材准备事项；正文把已有文字中本 P 实际使用的已知视觉信息编译为描述，并保留名称/编号作追溯，不将待绑定媒体假称为已输入。仅改动作且素材不变时复用已确认映射，重新分段、素材顺序改变或输入换图时同步更新基础定义与镜内引用。每段独立完整，不以“同上”作为唯一资产定义。

## 生成段如何接续，参考实际负责什么

同一生成请求中的多镜共享本段的基础设定、事件与前镜上下文；镜头间只需交代会改变或需重新辨认的状态，不把每镜写成一条独立提示词。只有明确拆为多条独立生成请求时，才分别建立自足开场，并按真实提供的参考说明继承职责。

独立生成段先重建后续动作真正需要的身份、空间、世界方位、身体方向/朝向、屏幕左右、物件形态、持有与接触、持续状态及动作/声音相位；明确区分世界方位、身体方向和画面左右，不能互相代替。转写文字空间资料时保留其参照对象、观察方向和相对方位；视点改变后按新观察方向重新推导屏幕左右，不把原参照下的“左/右”直接搬到相反观看方向。无需坐标或平面图，只具体写明影响行动、接续或观察的空间关系。再判断这条边界属于**直接连续、同场换视点还是时空转换**，决定哪些状态和第一项变化要在本段开场重新成立。直接连续时，只有确实取得的尾部视频、终帧、首帧或声音参考才写入【基础设定】，并说明它负责继承的身份、场景或动作状态；动作匹配接住 A 留下的相位，不重演已完成动作。同场换视点可承接仍有效的世界状态，但需在文字中建立新机位、构图和观察方向；时空转换则清楚重建新场景，不把它写成同一连续空间。若后段动作需要的前提尚未在输入、段首或前段实际形成，回到首次需要建立该条件的位置和相邻段修正，不只换角度或在后段补一句假定其已存在。段界是否需要变更仍按分段方法提供证据与旧/新映射，由用户采用后更新。

没有图像、视频或音频参考时，按独立文生段编写：开场文字自身给出观众需要辨认的主体、注意对象、空间与主要位置、观察方向、光线、必要物件状态及初始动作/声音相位；武戏或物件动作按需要补支撑面、双方朝向与距离、物件形态与接触位置、持物状态及动作相位。只有剧情接续确实需要时，才补前段留下的伤势、破坏、天气、光效、声音或其他状态。不能用“接上段”“保持上一段”替代这些开场事实，也不能伪造参考素材、标签、尾帧或时间码。各段使用什么构图由切法决定，不要求同一构图，也不把同一套状态字段机械填进每段。

## 时长与模型接口分别处理

分别记录成片目标总时长、单次生成上限和本轮实际接口时长设置；前两项决定作品预算与分段，后一项以真实入口可确认的值为准。模型名称本身不构成时长选择。用户只给一个时长时沿用其表达的目标或上限含义，歧义会改变分段时再补问；只给上限也不等于必须填满。接口设置未知时标明待确认，不抹掉“持续约 N 秒”的逐镜计划，也不写成接口可精准调度的承诺。模型与入口另行决定参考标签、模式、声音支持和格式。

用户要求可直接提交的专有格式时，核对该实际入口提供的字段或材料。已确认的入口规则应用于标签、引用和必要参数，保持剧情、时长和三段职责；当前没有某模型专属 Reference 时使用通用创作方法，询问或按授权查证真正影响提交的接口缺项。不把“MiniMax H3”“Seedance”等名称写成固定能力表。新增适配 Reference 须有真实差异与调用条件，不按品牌制造空文件。

本项目三段式是提示词的编辑与使用结构，不声称任意接口都按这三段进行官方解析。平台独立设置的参数放在必要块外说明；用户明确要求正文携带或入口需要时才纳入对应设定。

## 初稿优化保留什么，改变什么

先按当前请求区分三类工作：

| 用户要改的部分 | 执行范围 |
| --- | --- |
| 只整理格式 | 重排到三段、整理引用与编号，不改剧情、台词、镜头内容及情绪方向 |
| 改善导演表达、声画与镜头衔接 | 保留有效事件和关键设计，完善描述粒度、观看理由、表演与声画关系，回相关专业步骤 |
| 明确允许重做分镜或重构视频方案 | 按原表达目标比较并调整镜头结构与时长，保留用户仍锁定的内容 |

没有额外限定的“优化提示词”可完善表达、结构与一致性，不能静默换成另一剧情或另一情绪。既有镜头的目的明确且有效时沿其升级；镜头重复、时长不足或关系不清时指出具体差距，在授权内调整。锁定项冲突只处理受影响部分，不把局部问题升级成整篇重写。

按原句承担的功能编辑：粗述提供动势时保留其方向，细述控制关键接触时保留其因果，抒情先导统领质感时保留其气质。专业化意味着让现有表达更清楚和有力，不等于统一换成平淡、短促的说明文。

## 正式交付的结构

每段编号、源内容范围、计划总时长与必要解释放在代码块外。代码块中用以下固定标题组织；这里是格式合同，不是创作范例：

```text
【基础设定】

【场景状态与氛围画质】

【画面内容】
【镜头01｜持续约N秒｜景别、机位与主运镜】
```

完整可执行导演稿只有在本轮授权补足摄影设计时，才要求每镜标题给出编号、持续时长、景别、机位位置与角度、主运镜的实际选择；静止机位在源稿或已确认设计中成立时写“固定”。纯格式整理或保真重排应保留原摄影决策；若项目标题格式需要字段而源稿未提供相应值，将该项如实标为“原稿未指定”或保留原布局，不擅自补值，也不留含混空槽。完整标题可写作 `【镜头01｜持续约3秒｜中景｜机位：右前侧平视｜主运镜：向左跟拍】`。正文用自然导演句写主要观看任务和承重过程，不把内部要素盘点抄成字段表；避免重复描述已经清楚的基线。台词使用明确引号，表演指令在引号外；声音和环境变化按其发生位置并入镜头描述，不另造与画面争夺顺序的主轨。三段之外不增加导演分析的第四区块。

编译时回看用户锁定项及前步已确认的决定，并将它们写入真正承担该作用的正文位置：全局硬边界放在相应设定区，局部限制落在相关镜头的实际导演句；硬禁止明确写“禁止……”，不能只改述为“没有……”等缺席状态。作者用于解释画面设计的否定说明，转成模型可呈现的正向姿态、行动或状态；实际台词和事实性的否定保留原意，不机械反转。提示词正文直接写目标画面中的主体、动作、机位/视点、时间变化和可观察结果。给用户的解释、素材准备事项及后续安排留在提示词代码块外，块内仍只保留上述三大区块。

## 合并、压缩与最后复核

先完整兑现剧情与镜头，再删同义复述、空泛修饰与无职责参数。保留身份绑定、时间顺序、关键行动、情绪转折和切镜结果；字符限制实际存在时按入口要求整理，必要时回分段，不靠删除承重因果伪装合规。

assembly 模块消费主 Skill 已确认的场面、调度、观看单位、表演/发声、动作/对抗、构图/运动、look、光声、剪辑、连续性结果及用户锁定边界，将它们融成自然导演句；它不重新导演、不改剧情，也不把局部方法回报拼成栏目清单。返回前核对每项边界是否已落在相应设定或镜头正文中。简单格式整理仍由主 Skill 直接完成。只更新局部请求的直接依赖，但凡修改影响某个 P，就返回该 P 完整三段式块，并同步真实 `@`/媒体/标签职责、状态、镜号和时间总和。空间参照保留原始参照对象、观察方向和相对方位，之后才推导当前观察侧的画面左右；不得沿用错误屏幕侧或补造用户未提供的图像/资产事实。

逐段核对第一段是谁和参考什么、这些参考真实负责什么，第二段从哪里开始及稳定基线是什么，第三段如何逐镜变化到结束；生成段之间检查 A 尾、B 头、切点载体和新证据，真实剪辑关系按[声音、光色与剪辑承接](audiovisual-and-editing.md#镜头切换先问要留下什么)的术语说明。反向逐镜核对后续动作所需条件在哪里实际成立、人物能否察觉并行动、当前机位/声源能否交出观众需要的证据、声画机制是否承载所选变化，以及镜尾把什么状态交给下一镜/下一 P；遗漏在真正形成或呈现的位置补齐，矛盾回到最早作出决定的步骤并同步受影响的相邻段与直接消费者，不用块外解释代替正文过程。核对用户锁定边界是否进入正确设定区或实际导演句，作者解释画面设计的否定说明是否已转成可见过程，真实台词与事实否定是否保真。称呼、标签、台词、镜号、持续时长、每镜标题字段与状态在各处一致；完整导演稿按授权填写实际摄影选择，纯格式整理/保真重排不补未指定的摄影值。按最终镜头标题重新求各 P 总时长与全篇 P 合计，块外统一给出数字；区分本次计划时长、自然时长范围和保守上界，沿唯一[逐字预算估时与并行事件核算](segmentation-and-handoff.md#逐字预算估时与并行事件核算)方法复核，任何镜头时长或组织变化后重新计算。再检查每个短镜头的主要观看任务是否明确，连续表演是否被无理由拆开；逐镜内部要素是否已盘点但自然落在导演句里；初稿的有效情绪与调度有没有被规范整理写弱，诗性先导有没有由镜头落实，创作目标是否作为模型方向并由逐镜可见/可听过程承载，内部推导、作者自辩或给用户的过程说明有没有混入模型正文，内部分析是否被误写成成片已呈现的效果，无参考段首帧是否自足，每段是否能独立复制使用。

从最终三段正文反查源稿顺序、空间参照及行动前提；发现问题只回到最早形成该条件的步骤，并同步修复直接消费它的镜头/P。空间方向先依源稿参照对象和观察方向成立，再推导镜头中的左右；不以看似顺畅的画面文字掩盖方位错置、未形成的前提或提前发生的后段动作。简单格式整理只修布局并如实标示缺失字段，禁止借 assembly 改写内容或补做未授权的摄影设计。

## 方法依据与本地适配

三段职责将稳定参考、初始状态和时间变化分开，再沿主流程依次形成。输入映射、格式与优化分支是本能力的使用合同；模型的真实标签、时长与接口要求由实际入口决定。

独立生成与段间参考职责参考老胡AI视觉《跨批次连续性参考模式》及《视频提示词机制与描述粒度》的相应方法。本文件把直接连续、同场重建、关系重置和无参考文生段整理为条件分支：真实素材职责按输入绑定，独立段文字仍建立自足开场，不要求统一构图或机械复述全部状态。Runway 官方《Image-to-Video Prompting Guide》（面向 Gen-4.5）说明其图生视频入口由输入图提供首帧构图、主体、光线与风格，文字侧重描述运动、摄影机和时间推进；这只作为该入口的适配依据，不推广为所有模型的通用接口规则。
