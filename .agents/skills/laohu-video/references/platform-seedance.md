# 平台模板与显式分镜秒数适配

**触发条件（平时 0 加载）**：仅当用户明确点名以下特定平台语法或界面模式时读取——
1. **可灵（Kling 3.0）自定义多镜头分镜 UI**（按镜头槽位填写明确秒数与绑定元素）；
2. **Seedance 2.0 / 2.5 或 Higgsfield 多区块结构化时间轴 / 双图专用模板**；
3. **Google Veo 3 / 3.1 或 OpenAI Sora 2** 明确要求按该平台英文/专有块格式输出。

用户仅顺口提及模型名但未点名专有格式时，一律沿用主入口默认极净中文三段式（无逐镜死时间轴，块外给建议总时长）。具体接口容量、分辨率与画幅以当次真实入口为准。

## 一、跨平台提示词适配速查（均消费同一份导演内核与一镜一事法则）

| 点名平台模式 | 核心格式特征 | 逐镜秒数处理 | 多模态资产与注意要点 |
|---|---|---|---|
| **可灵 Kling 3.0 自定义多镜头 UI** | 全局 Master 锚定画风与元素，分镜按 `镜头1（N秒）` 独立槽位填写（单次通常最多 6 镜） | **按界面要求显式标注每镜整数秒数**（短信息镜 1–2 秒，情绪/高潮镜 3–5 秒，求和等于总长） | 人物/核心道具挂 Elements 元素槽，正文极简去外貌复述；动作戏严守一镜单一主体主动作，硬切极稳。 |
| **Seedance 2.0 / 2.5 全能参考模式** | 默认用中文三段式即可；仅点名时间轴或双图模板时启用下方第二、四节 | 默认不写小数点死时间轴；点名时间轴模板时用整秒粗锚提示推进顺序 | 支持图/音/视混传并用 `@图1 / @视频1 / @音频1` 行内精准绑定；本段未出场资产严禁传入；挂视频动作参考时清空冲突文字运镜词。 |
| **Google Veo 3 / 3.1 专有结构** | 镜头与运镜前置、动作单一清晰、末尾单列 `Audio:` 声画块（明确要求英文时切英文） | 默认自然节奏不写死时间码，靠单镜单一动作与清晰景别稳控 | 极度敏感于词序权重和单镜篇幅，保持 30–60 英文词（50–80 中文字）极高信噪比，台词直接写进对应镜头并配套 `Audio:` 声底。 |
| **OpenAI Sora 2 故事板模式** | 角色与场景锚点文字跨卡 100% 保持原样不变，每卡只改景别、运镜与单一可数动作节拍 | 默认自然节拍描述（如“先停顿片刻再抬头”），或按故事板卡片排布 | 忌讳跨卡换词重描角色外貌；每个镜头只给 1 个主动作 ＋ 1 个主运镜。 |

## 二、Seedance 2.5 / Higgsfield 多区块结构化时间轴模板（点名才用）

以下区块**删去本段用不到的部分，保留其余顺序**；默认中文，明确要求英文时切英文标题（`SCENE CONTEXT`、`ACTIVE REFERENCES`、`LOCATION MAP`、`FIRST FRAME / BLOCKING`、`FORMAT MODE`、`OPTICS`、`CAMERA`、`ACTION`、`PERFORMANCE`、`PHYSICS`、`LIGHTING`、`COLOR GRADE`、`WARDROBE`、`AUDIO`、`STYLE`、`OUTPUT SETTINGS`、`POSITIVE LOCKS`）：

```text
场景情境
[1–2 句写清人物、地点、时间与当前情绪局面]

当前参考
[本段真实出场或生效的实际标签 ＋ 单主责 ＋ 适用时段；未出场资产不列出]

空间图
[核心空间关系、固定主光源与机位基准]

首帧与调度
[开镜站位、朝向、几何可见面、持物与动作初态]

拍摄模式
[连续单镜／顺序多镜／指定时点切镜]

镜头光学
[各镜景别、视角与景深特征]

摄影机
[机位位置、高度、构图压迫、运镜路径与停点]

动作
[按镜头或显式时点写单一核心行为与因果变化，末句自然落交接状态]

表演
[面部松弛底盘、单点生理泄密、刺激与反应停顿]

物理表现
[起势势能 → 接触质变 → 受击物理反馈]

光线
[唯一主光源位置、方向、软硬与明度分离]

色彩与调色
[色调气候与重点材质受光]

服装
[本段确实需控的穿着与当前状态（有清晰图参考时从简）]

声音
[跨镜统一环境声底、对白发声、J/L-cut 或静音抽空与物理拟音]

技术风格
[媒介成像质感与颗粒/快门特征]

输出设置
[已确认时长、画幅与非画面类硬红线：禁止字幕、禁止水印、禁止背景音乐]

正向连续性固定项
[3–5 条简短可观察正向句，锁死全段成立的几何与物理条件]
```

- **时间戳与 `HOLD`（仅本模板需要时启用）**：多镜可用 `0–3秒｜镜头01` 粗锚切分，收尾需明确静止余韵时于最后写一次 `HOLD`（维持机位、环境声底与活态微动至段尾）。
- **离散 FOV 档位参考（仅点名 FOV 模板时选用）**：180° 鱼眼、107° 超广（14–16mm）、84° 广角（20–24mm）、63° 纪实观察（28–35mm）、47° 中性（40–50mm）、29° 人像半身（75–85mm）、18° 肖像特写（100–135mm）、12° 长焦细节（180–200mm）、8° 极窄远跟（300–400mm）。

## 三、人物图与地点/氛围图双图模板（点名双图格式时用）

按实际绑定替换 `@图1` / `@图2`，剥离人物图旧背景旧姿势，只保留本段真正出场的参考：

- **沿用整处地点或前段实片氛围帧**：
```text
@图1 定义人物的身份与已确认外观。@图2 定义场景的空间结构（或延续前段的环境色调、光影质感与氛围）。
人物位于［本场位置与几何可见面］，以［开镜动作初态］起幅。［本场唯一主光源与统一环境声底］。
［按一镜一事顺叙景别、运镜、单一核心行为、单点微表演与自然收束。］
```

- **仅取地点图中单一元素**：
```text
@图1 定义人物的身份与已确认外观。@图2 仅提供［具体元素，如带壁灯的铁门］，保留其自身构造与比例。
该元素位于［新场景位置与画面距离］，周围空间为［本场新环境］，人物按［本场几何可见面、行为与光源］呈现。
［按一镜一事顺叙逐镜内容与自然收束。］
```

## 四、预览工作流边界

若本轮已获准实际调用生成接口且平台支持分档预览，可优先采用低清快出核对动作节奏、景别与几何可见面，确认无穿帮后再以同一素材与提示词定稿高清；仅要求交付文本提示词时，止步于纯净代码块与块外制片导航。
