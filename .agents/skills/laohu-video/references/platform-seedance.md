# Seedance 与 Higgsfield 的本地提示词模板

主 Skill 只在用户明确选择 **Seedance 2.5／Higgsfield 多区块结构化时间轴**或 **Seedance 双图模板**时读取对应部分。只指定模型、入口或投放平台时沿用[通用三段式](prompt-assembly.md#先保三段职责再选择模板)。专用模板仍按用户已采用的 P 和源稿顺序编译，每 P 一条自足的指定格式。模板默认中文，用户明确要求英文时使用英文标题和说明，锁定对白、资产名及实际素材标签沿用原值。

以下区块、度数档位、`HOLD` 和预览流程是本项目已有的编排写法。实际入口的模型、时长、参考数量、声线支持、画幅、分辨率与是否有对应参数，依据当次界面、已获输入或可靠的接口说明。格式选择直接完成文本交付，提交、生成和分辨率切换依本轮的实际权限和设置。

## 按实际素材写标签

保留用户给定并能核实的标签。在 Higgsfield Elements 已保存并实际关联时逐字使用其名称，例如 `@char_hero`。入口若把元素与后来手动加入的图像分别编号，按实际顺序及大小写写 `@Image 1`、`@Image 2` 等。入口若使用小写类型编号，按载入顺序用 `@image1`、`@video1`、`@audio1` 等实际标识。未证实自动附加时核对已选素材，文本里的标签不能代替绑定。仅为用户起草通用模板时保留可填写的槽位，素材尚未提供时用真实已知的描述。

每份参考一行，写明身份、地点、物件、构图、局部修正或单次声音中的主要职责及适用范围。来源重叠时在参考区加“参考优先级”（`REFERENCE PRIORITY`），说明哪一对象、部位和时间窗以哪份为主。状态图只在剧情和时间轴对应的阶段使用。比如已绑定的修正帧仅负责 `21.25–22.00 秒` 的按钮样式或机位。镜头中实际出现的对象才挂其镜内标签。入口已确认声线关联时，在对应角色参考行记录一次真实声线绑定，镜内写当句发声；声线参考、实际台词音轨、表演样本分别说明职责。素材绑定共用 [真实素材规则](prompt-assembly.md#资产身份与实际调用)。

## 结构化时间轴的十六个区块

下面是可填写的中文模板。技术收尾组含“技术风格”和“输出设置”两个子标题，合计十六组、十七个标题行。删去本段用不到的区块，保留其余顺序。情境与参考置顶，随后建立空间和拍摄起点。开场、摄影机与主体行动分别写清，描述性风格靠近其控制对象。已经存在且必须沿用的用户前缀或区块原文逐字保留。

```text
场景情境
[一至两句写清人物、地点、时间及当前事件。]

当前参考
[实际标签＋对象与职责＋必要的可见锚点和适用时间。参考重叠时补参考优先级。]

空间图
[空间层次、机位、人物走位和光源位置。可并写自然主义材料与色彩。]

首帧与调度
[开镜时谁在哪里，朝向、视线、持物与动作相位。]

拍摄模式
[连续单镜／顺序多镜／指定时点切镜／自由补景。指定切点时写只在列出的时点切镜。]

镜头光学
[各镜实际景别、视角及适用的镜头特征；需要固定透视时标出镜内保持的关系。]

摄影机
[机位高度和观察侧、距离、主路径、焦点及到达位置。]

动作
[需要任务型演技时先给任务块，再按时间轴逐镜写事件、主次、切点、可见变化和镜尾状态。]

表演
[依同一人物任务补可察觉的刺激、发声、动作和反应的实际触发点。]

物理表现
[关联事件的重量、惯性、支撑、材质或特效映射。]

光线
[源位、方向、覆盖、实际受光或曝光变化。]

色彩与调色
[明确的调色选择和材料受光关系，自然主义可并入空间图或光线。]

服装
[本段确实需要控制的服装、材料和当下状态。]

声音
[按时点写实际对白、声场、拟音、音乐或声桥。]

技术风格
[本作适用的成像结果、细节密度、笔触或颗粒等。]

输出设置
[本轮已确认或文本中确需写明的时长、画幅、采样或其他要求。用户硬禁止明确写“禁止……”，局部限制附上镜号或时窗。]

正向连续性固定项
[用简短可观察的句子重申实际建立且全段成立的条件，如身份、道具保持和镜尾状态。]
```

英文版依原顺序使用 `SCENE CONTEXT`、`ACTIVE REFERENCES`、`LOCATION MAP`、`FIRST FRAME / BLOCKING`、`FORMAT MODE`、`OPTICS`、`CAMERA`、`ACTION`、`PERFORMANCE`、`PHYSICS`、`LIGHTING`、`COLOR GRADE`、`WARDROBE`、`AUDIO`、`STYLE`、`OUTPUT SETTINGS`、`POSITIVE LOCKS`。固定句重申已经成立且需要保持的条件，通常取最重要的三至六项。实际入口另设的参数在使用时配置。描述画质用可见结果，分辨率只在确认实际设置或确需指定时写入。

## 时间戳、切镜与 HOLD

选择与用户需求相符的时间精度。连续单镜明确一镜到底；顺序多镜可逐条写 `CUT 1`、`CUT 2`；精确同步写 `1.0 秒硬切`（英文 `HARD CUT at 1.0s`）等实际切点；自由补景由用户授权开放镜头组织时采用。切点说明实际交接对象，可用硬切、强切、动作匹配、插入、反打或甩镜；按用户已定的方式使用淡入、淡出或叠化。

需要时间戳版时，将 `起止时间｜镜头号｜景别与观察方式` 写在每阶段开头，并交代该阶段最后留下什么。用真实计划时点绑定表演、道具状态替换与节目节拍，镜号仍用于区分和讨论镜头。相邻时间区间首尾连续，最后以实际计划总长结束。以下是本地 30 秒样式示例，正式稿按用户目标和确认预算重新分配秒数。

```text
0.00–8.00 秒｜镜头01｜固定中景，门边斜侧观察
人物在桌边展开信纸，环形台灯照到信纸折痕；镜尾信纸展开，手仍贴住纸边。
8.00 秒｜硬切至信纸与手部
8.00–18.00 秒｜镜头02｜斜侧特写
人物沿原折痕重新叠起信纸，放进桌上的信封；镜尾信纸全部入袋，人物捏住信封边，刚抬离桌面。
18.00 秒｜动作匹配切镜至桌旁
18.00–29.00 秒｜镜头03｜中景，围绕桌角略移
接上信封刚抬离桌面的相位，人物把信封放进桌边纸盒，手收回；镜尾信封已在盒内，手回到桌面。
29.00–30.00 秒｜镜头03｜HOLD
保持原机位和镜尾状态到 30.00 秒。
```

`HOLD` 指用户选用的收住或保留时段，写镜头、时间与需要维持的画面/声场；可接在末镜同一编号。用户要求整稿以 `HOLD` 栏结束时，将它作为时间轴最后一个阶段只写一次，放在连续性固定项之后。镜尾已经在计划总长成立时按其实际状态收束。切点和末态均为生成前计划，实际结果另据片段复核。

## 离散视角档位

用户明确采用模板的离散 FOV 选项时，用以下已有档位记设计里的视角，镜内有保持要求时写清。焦距列是该模板的近似视觉参照；实际焦距与视角还取决于画幅、轴向、裁切与投影。用户给定的真实器材或视角设置优先。普通三段式按机位、画幅和观看关系写需要的视觉效果。

| FOV 档位 | 模板约略焦距或效果 | 用途 |
|---:|---|---|
| 180° | 鱼眼视觉 | 主观畸变或梦境 |
| 107° | 14–16mm 类超广视角 | 大型室内或建筑建立 |
| 84° | 20–24mm 类广角 | 建立空间、群体调度 |
| 63° | 28–35mm 类观察视角 | 广角环境或纪实观察 |
| 47° | 40–50mm 类中性视角 | 通用建立和中景 |
| 29° | 75–85mm 类人像视角 | 对白半身、分开背景 |
| 18° | 100–135mm 类窄视角 | 肖像特写 |
| 12° | 180–200mm 类长焦视角 | 手部、物件或远处局部 |
| 8° | 300–400mm 类极窄视角 | 远距观察或转播感 |

极端视角的多镜生成若出现视域或身份漂移，返回主 Skill 的可控性方法选择空间锚与镜首/镜尾锁定。变形宽银幕视觉由已确认的摄影方向决定。速度、雾厚或色温在对画面重要且本次确有可用数据时标出，材料受光和演员任务仍按真实媒介落实。

## 人物图与地点图模板

用户明确选择双图格式且已提供两图时，确认第 1 图属于人物，第 2 图是地点或局部元素。知道实际入口支持这两项后再使用可核标签；模板中的“图 1／图 2”可按实际绑定替换。用户要整处地点时，复制并补本段的行动与声画：

```text
图 1 定义人物的身份与已确认的外观。图 2 定义地点的整体空间、通道、地标及相对尺度。
人物位于［本场位置］，以［本次动作相位］开镜。［本场实际光源］说明人物、道具与场景的受光。
［按时间写事件、机位、变化、声音与镜尾状态。］
```

只取图中一项时，写出该元素及它在新构图中的实际关系：

```text
图 1 定义人物的身份与已确认的外观。图 2 仅提供带上方壁灯的出口门，保留门框、门面与壁灯的相对位置。
出口门立在［新场景位置］，门高［相对尺度］，距人物［画面所需距离］。周围环境是［本次采用的墙面、地面或空间］，人物按［本次姿势、动作和灯光］呈现。
［按时间写事件、机位、变化、声音与镜尾状态。］
```

人物照片的背景、姿势、闪光、阴影及地点图的其余部分按已确认的本次画面重新描述。用户明确要求英文版时，整处地点可写 `Use Image 1 for character identity. Use Image 2 only for the place.`；局部可写 `Take only the exit door and its overhead lamp from Image 2. Place them at [location and distance] in [the scene].` 其余文字按所需镜头以英文编译。

## 预览与三段归位

本轮获准实际生成且入口支持时，可沿用原流程用 480p 预览、目视挑选一条，再以该条的已确认素材、画面和时序定稿至 4K。以实际入口和授权决定是原片升分辨率还是重做定稿，随后核对首末状态、动作、切点和画质。仅交提示词时停在可复制正文。

用户要求把专用材料放回三段时，情境、实际参考及必要输出设置进【基础设定】；空间、首帧与稳定声画风格进【场景状态与氛围画质】；时间轴及逐镜光学、摄影、表演、动作、光声、服装和末态进【画面内容】。连续性固定项按实际作用归入已有三段。检查片长与末镜累加、素材职责与出现时窗、用户边界与当前版本语言，再交付所选格式。
