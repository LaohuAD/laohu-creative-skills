# 动作与摄影的描述粒度

由主 Skill 第五步先检查场景如何支持行动，第七步在动作、武戏、运镜、调度与描述粗细需要决定时继续读取。本文保留行动现场、关系证据、动作粒度、打斗/物理反馈和基本景别/机位/运动等共享方法；仅当局部问题需要专业细化时，主 Skill 才分别调用 staging、blocking、physical、combat、coverage、framing 或 camera。模块返回已成立/待形成的行动条件或摄影决定，再由主 Skill 合成逐镜过程，不要求逐镜全读或另交模块报告，也不改变源剧本或已确认资产。

## 把方向交给模型，把决定留在镜头里

**能改变结果的关系写准，能自行完成的过程放开。**

先明确观众要从本镜读出什么，再把表达目标落到源材料里实际会变化的关系：人物与他人、道具、空间或时间如何从起始状态，经触发和行动，变成新的结果。依据剧本与已确认资产，从动作、身体反应、物件或环境反馈、他人反应、声音、构图和前后对照中选足以承重的证据；“选少数”是避免无关堆叠，不是削弱已确认的立场、情绪力度、风格或关键声画目标。只保留当前机位和时长下看得见、听得清的部分，再按“初始关系—变化—反馈—结果”组织摄影与声画，最后从镜尾反查观众能否读出目标。已有材料已给足证据时直接承接，不重复堆料；少写某项会改变人物选择、动作因果、胜负、终态或观看目标时才精确展开，其他过渡仍可开放。

证据随表达目标而变，不套固定字段表。物理属性由阻力、惯性、形变、位移或环境作用等因果体现；心理与关系变化看刺激之后人物怎样选择，以及注意、距离、控制权、彼此反应或等待怎样改变；宏观风格、情绪与隐喻可由空间尺度、排列、光色、声场、节奏和观看时长承载，不自动改成字面特效。宏观方向词可以保留为风格先导，但不能替代目标所必需的可辨过程。例如，要读出速度，可用相对稳定的场景参照、动作启动与越距、摄影机相对路径和视差组织动势；需要看清轨迹时再选局部残影或运动模糊，并让接触仍可辨。视差表示观看位置变化，只有场景确有受力作用时才把环境写成被推动。要读出重量，可选身体承重、提举阻力、重心移交、制动惯性、接触后余势及材料/地面反馈；区分作用力与质量、惯性，并按人物能力表现，强者可以轻提重物，落放、受击物或对手反应也能显出重量，不强迫呻吟或破坏物件。

按下面条件选择粒度：

| 条件 | 写法与执行 |
| --- | --- |
| 表达靠整体运动、节奏和动作风格成立 | 写方向、动作组、力度、阶段与结果，开放中间微动作 |
| 结果依赖谁触发、谁控制、接触何处或道具怎样转移 | 写清必要起点、触发、接触和控制权变化 |
| 情绪变化依赖一个细微可见反应 | 在能辨认该反应的景别中精写相应目光、呼吸或身体动作 |
| 用户锁定招式、运动轨迹或参考表演 | 保留锁定内容，给相应镜头和时间，连接部分仍可开放 |
| 初稿堆了大量手脚方位但主关系不清 | 提取不可替换因果，改写成连贯动作组，删去无职责微指令 |
| 初稿只有“激战、悲伤、电影感” | 补危险或刺激来源、人物选择、关键变化与可辨认结果 |

这不是词数上限。详细描写服务于辨认时就展开，宏观控制已经足够时不为“专业”逐帧编舞。

## 先建立行动现场，再决定怎样观看

先由本场任务、人物目的、源稿和资产检查共同现场怎样支持或阻碍将发生的行动、信息显露：辨认实际要用的入口/出口、通道、支撑与接触面、遮挡、道具可用性及必要光源/环境关系；物件名称或场景图上的位置不自动证明条件已经可用。已成立条件承接，开放实现只在源稿和资产允许的范围内相容选择；必须由此前行动形成的条件回到真正发生处补足。由此建立各镜头共享的空间和基线，再在下节按每镜观看任务确定观察侧与必要证据；镜头层的动作依赖和精度不在此提前铺完。同一场景换机位不重置世界方位；前景、中景、后景只在影响动作阅读、遮挡、空间关系或注意力时交代，不要求每镜填满三层。动作实际改变环境或全画面关系时，写出相关元素如何参与、受到作用或留下反馈；没有实际作用的背景不必逐件描述。

复杂动作或误读会改变剧情时，按需要补出 `起始状态 / 触发 → 发力与运动路径 → 接触和受力 → 人物、武器或环境的可见响应 → 结果与余势 → 终态`。观察面与支撑点能决定谁施力、谁受力或动作是否可见时才明确写出；这是一种按承重关系取用的检查顺序，不是每镜必填的字段表。

### 按观看任务生成镜头

从本镜表达目标与当前实际变化开始，倒查发起者、对象和动作实际参与的身体部位或物体表面，以及形态、位置、朝向、可达性、入口、支撑、施力/控制和信息传递条件。只追踪当前动作及其直接后续实际要用的依赖，按这些依赖而非对象重要性或原文篇幅决定精度：会决定动作能否发生、观众能否辨认或后镜能否延续的条件须明确；与这些决定无关的纹理和细部仍开放。已有条件从场景基线或前镜承接，不重抄；必要条件尚未成立时，回到它首次形成的位置补足，不让后镜临时假定。

再选观众从哪个观察侧、何种视听通道取得证据。涉及接触的动作按需要辨认接近、接触、受力及反馈，选足以读出因果与结果的部分，并核对实际可见面、路径和遮挡；反应须接在同一刺激之后，孤立反应不能代替关键接触或结果。可用源稿和场景已支持的声音、环境反馈或其他通道，不新增伤害、破坏或改变既定结果。最后依这些依赖选择景别、焦点、构图、光源落点、材质响应、声源与时机，用自然导演句写出动作结果/末态及下一镜接续，再从镜尾倒查所需条件、行动和证据是否都已成立。若有切点，说明切入和切出分别处于什么动作、反应或信息相位。

该方法按承重关系取舍，不是每镜字段表。稳定基线可直接继承；但影响本镜观看任务、动作成立或后镜使用的条件，即使已在前文出现，也要核对当前机位下是否仍可观察或确实持续。

### 让跨镜状态延续到观众需要看到的时刻

同一生成请求内的多个镜头共享该段的设定和事件上下文。上一镜末态是下一镜的起态依据；只写有变化或影响后续动作、理解的状态，不把每镜当作独立提示词，也不重复全局基线。按任务跟踪伤势、疲劳、情绪、动作控制、道具持有/破坏、空间与天气等承重状态：写清起始状态、触发或受力事件、当镜末态，以及后续是继续、变化、恢复、遮掩还是有意延后显露。受伤发生与血迹、疼痛反应等可见表现首次出现分别判断；用户指定延迟揭示时，明确此前保留哪些可见反应和首次显露的事件/镜头。角色可凭能力继续行动，也可缓和、隐藏或恢复；不机械要求每镜加重，也不让剧情仍依赖的状态无依据消失。内部检查不强制转成最终状态表。

## 动作与打斗：用攻防关系组织强度

先识别力量差、危险来源、主动权和人物策略。动作组按适用关系组织为蓄势、释放、交换、决定性接触、结果与余势；可短促连续，也可停顿蓄力。写出主角是在压制、被逼退、卸力换位还是夺回主动，让打斗有局势变化。

“快速三轮攻防”可以统领一组交换，但要指明双方关系、速度或力量方向与最后结果。没有剧情依赖时，模型可完成具体格挡和出招；某个接触决定伤势、掉落、救援或反败为胜时，则把该处接触与结果写清。用户的打斗测试支持这种工作取舍，不要求所有题材均采用同一描述密度。

多人动作先建立可读的空间与威胁，决定各镜展示全局、局部交锋还是结果。混战可以强烈和复杂，观看重点仍有组织。连续攻击造成的失衡、伤势、疲劳、破坏与位置变化进入后续镜头；只在这些状态影响观众理解或后续动作时明确其延续、加重、恢复或被遮掩的依据，资产身份不因此自动重置。关键画面可以在蓄势、接触或控场处短促清晰，连接部分允许速度、遮挡、甩镜和运动模糊，维持整体动势；不因留白而削弱已确认的打击力度。

结果强度与物件终态分别控制。道具、兵器或场景需要保持完整时，写明符合其材质的受力反馈和接触后的状态；例如有韧性的棍受击弯曲、回弹，冲击仍由握持者失衡、对方受力或环境回应体现，棍身保持完整。只有剧情确实要它折断时，才写从接触处开始的裂断过程、碎段运动和留下的永久状态，后续镜头沿用该状态。不要用“断裂”来代替打击力度，也不要让未指定的破坏自行发生。

## 景别与机位由证据决定

全景或中远景容下身体路径、阵形与空间；中景呈现重心与交互；近景与特写用于表情、接触或关键细部。按当前镜头必须辨认的内容裁切，不把“愤怒”固定配低机位、“孤独”固定配远景。

先定摄影机相对主体的观察方位、高度和距离，再选景别、俯仰与构图。低机位不自动等于仰拍；倾斜镜头是画面横滚，不是俯仰。景深由前后内容是否需要同时辨认决定；焦距用于取景与视觉设计，透视变化要结合摄影机距离说明，不堆互相矛盾的焦距、景别与位置。

关键动作或细节需要被观众看见时，先确定承担该动作因果或辨认任务的主要证据，再核对实际可见面、遮挡、画面中的相对大小和观众读清所需时间。多个对象同时入画，不表示每个细微表情或接触都清晰可辨；按任务确定主次，并优先利用源稿支持的身体响应、声音或相邻镜头承接。证据仍不足时，先比较剧情允许的观察侧、构图、主体位置和焦点，只有确有新视点或新相位需要时才切镜；持续表演和长镜头可以承载多个变化，不强加特写。若任务只需让观众知道对象在画外发生了什么，可用源稿支持的声响或人物反应；若剧情、场景或已定资产支持监控、镜面等通道，再使用该通道。不要要求镜头穿过遮挡，也不要为补视角另造未支持的画面通道。返回时说明选中的观察位置，以及画面或声音实际交出的证据。

## 运镜有去处，调度有理由

推近适合让某个细节或关系逐步占据观看；拉远可揭示主体所在尺度；横移与跟拍可以与主体行进或遮挡变化共同组织空间；摇镜由当前落点转向新对象；环绕需要连续空间与明确的关系揭示；拉焦把观看从一个距离层次转到另一处。

选一种主导运动，写起始观看、跟随或转向对象、必要方向或速度变化和最后停点。复合运镜在同一连续路径与观看目的下可以成立；不因复杂就拆，不因想“一镜到底”把不可达路径和实际切镜藏在同一编号。摄影机运动、人物走位与环境变化共同构成动态构图，关键处说明谁显露、谁被遮挡、焦点落到哪里。

静止机位可由表演、人物进出与声场改变产生强张力；高速快剪可在每镜中保持明确运动方向。选法服务本镜目的，不把镜头丰富等同于每镜都移动。

## 返回与检查

交回每镜可辨认的开场构图、变化触发、动作组或关键动作、观察位置与主运镜、决定性画面及结束状态。逐镜盘点开场状态、景别机位与可见范围、构图层次、光线、触发至末态、环境声画反馈和切点相位，再按继承关系和适用性取舍正文细节。检查人物、兵器与环境的位置和支撑是否支持所写动作，接触和材质响应是否证明结果，摄影能否看见关键证据，控制粒度是否过细或过粗，动态描述是否与计划时长相容。

接口分工：staging 返回行动所需现场，blocking 返回人物路径/方位，physical 返回关键受力，combat 返回攻防组，coverage 判断需要哪些观看单位，framing 选观察侧/构图，camera 选连续机位轨迹。本 Reference 仍提供它们共同使用的因果与镜头基础方法；局部模块不可互相递归调用。

## 方法依据与本地适配

FSU Film School《Toolkit for Directing Actors》提供目标与行动的演员工作方法；ASC《Where Do You Put the Camera?》与《Camera Movement》分别讨论机位选择、摄影机运动和观看关系。本地将它们适配为“先定人物行动/观众证据，再选观察侧或连续轨迹”的导演提示流程，不把来源方法变成固定机位或表演公式。希区柯克在 MoMA 访谈中的运镜观点作为本地检查目的的参照；不把任何来源的做法推广为所有模型的固定解析规则。

开放动作链与力量关系辨认用于组织武戏，精度按剧情承重关系选择。主事件、结果与连续性保持清楚；可替换的中间招式与过渡动作保持开放。

逐镜开场、动作受力和武戏材质响应还参考老胡AI视觉《视频提示词机制与描述粒度》《文戏武戏与动作组织》及动作设计《专业方法与案例》的相应章节。本文件按观看证据与物件终态作本地适配：只写影响空间辨认、动作因果和结果的部分，不把原方法改成每镜必填的字段表。

“表达目标—关系变化—证据—声画组织—结果反查”是依据本项目用户反馈整合的执行顺序，不声称为任何单一来源的固定公式；物理、心理/关系和风格分支按当前镜头目标选择。
