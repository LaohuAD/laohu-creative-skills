由 Video 主 Skill 在以下信号出现时按需加载：明确要求分段/比较，或新展示过程改变镜头计划时；唯一逐字估时算法继续只读分段与交接 Reference 锚点。输入、触发条件和返回位置见各方法小节。统一接口：接收主 Skill 已确认的用户目标、源稿、真实资产、前置状态和预算；不改变用户锁定边界，不递归调用兄弟模块；返回可直接并入同一导演工作稿的决定、依据、缺口和最早回改点。


## 方法：分段规划

由 Video 主 Skill 在用户要求分段、比较方案，或详细提示词确需新建/修改独立生成范围时加载。只咨询自然时长、已有合适 P 可直接编译、普通剧本创作或改稿时不触发。详细提示词中的调用仅作授权范围内的内部规划，不另交分段报告或等待确认。

先读取 [视频生成用剧本分段与下游交接](../../references/segmentation-and-handoff.md)。该 Reference 是源稿保真、P 边界、唯一逐字估时算法与阶段交接的真源；本模块规定本次执行顺序，不复制第二套估时法。

## 输入与范围

给视频模型新划生成 P 时，先从当前请求和前文取已确认的每段最长时长 U。若两处均缺 U，问“每段最长允许几秒？”后结束本轮，收到值再执行下文。明确允许无上限并委托按自然节拍分时，估自然时长、保留原文，按自然节拍给出边界。

使用用户指向的完整源稿和范围。只提供局部就处理对应范围。沿用既有 P 编号、用户锁定的内容和有效资产事实。逐字切分以实际源稿为依据。

## 执行

1. **全范围读稿。**从头到尾读完授权范围，辨认人物策略/信息变化、关键动作相位、观看信息次序、场次与时空变化。身体动作本身不逐项计作节拍；一段可容纳多个连续节拍，一个节拍也可跨镜。
2. **只追边界相关的观看和行动条件。**从段首、段尾或跨 P 接续所需的证据倒查空间、人物/物件状态、入口、路径、支撑、接触、遮挡和察觉条件。分别标出已经形成、可继承、仍开放或须在更早位置首次形成的条件。只追踪会改变段界、接续或资产需求的关系，不在此完成详细场景调度。
3. **先做初镜与任务预算。**按各段观看任务形成初步镜头目的和必要内容，给每镜“持续约 N 秒”，标注镜尾需要交出的状态。对白、动作、停顿、观众辨认和可并行事件只调用分段 Reference 中的唯一估时算法；先分清实际展示与有证据支持的省略，不把环境声重复加时，也不为填满 U 增加内容。
4. **比较自然边界。**依次比较策略/信息转向、动作可执行相位、语句气口、场次转换与时长上界。选择能保留因果和观看任务、同时给下一 P 留下真实起步点的边界，已有 U 时核它在容量内；不等分、不因镜数或场数机械切分，也不为每个节拍单独开 P。所有场头和跨场来源保持可定位。
5. **从两端复核相位和状态。**逐 P 检查首镜是否拥有本段必要起步信息、尾镜是否完成本段任务并交出后续可用状态。复核动作方向、位置、支撑、接触/控制权、知情、伤损、物件和声音相位；后 P 需要的前提若尚未形成，回到实际首次形成处补齐，不让后段假定存在。相邻 P 可接续但不重演已完成的动作或反应。
6. **最后才切原文。**在段界确定后，从唯一源稿按原顺序切出正文。场头、△、对白、括注、标点和其他有剧情意义的符号逐字保留；完整范围有序且恰好覆盖一次。不得摘要、润色、调序、删词或在相邻 P 重复台词。
7. **返回与消费。**新分段任务交付两份独立完整文本：分段说明列逐 P 来源/任务、初镜概要、逐镜秒数与求和、自然估时/保守上界及接续；逐字剧本按原序恰好一次覆盖。比较任务只比较、不代选；详细提示词中的内部规划把上述边界与初镜交给主 Skill 第四/六步，不另交报告。主 Skill 继续完成提示词。

## 条件分支与停止点

- 已提供并采用 P 时，沿用其编号、范围和顺序；仅当详细制作证明现范围无法满足已确认容量或接续条件时，给出证据及旧/新映射，等待用户采用后才改边界。
- 若保真内容在 U 内没有自然切点，报告具体原文范围、时长/状态冲突和可行取舍；不删剧情、抢读、弱化情绪或伪称达标。故事/台词需改写时返回 Script。
- 用户只要求分段或比较时，在该产物停止；不自动进入资产设计或详细提示词。

## 返回与验收

向主 Skill 返回 P 编号与全来源映射、初镜观看任务、逐镜预算、首尾状态、已形成/待形成条件、段间接续及任何冲突。检查逐字覆盖、顺序与恰好一次；双端动作/信息相位可接续；每镜秒数求和正确，有 U 时核上界是否符合；资产事实不被臆造；一 P 对应一条后续完整提示词。唯一估时依据始终是分段 Reference 的“逐字预算估时与并行事件核算”。


## 方法：逐镜时长回算

由 Video 主 Skill 第六步以及后续镜头设计实际改变展示过程时按需加载。仅整理格式、没有新时间事实且计划仍有效时不触发。输入为实际展示的对白/动作/反应/停留、真实先后与重叠、观看完成点、镜头/P 范围、用户预算与已核实的单次上限。

## 唯一估时调用

1. 只调用主 Reference [视频生成用剧本分段与下游交接](../../references/segmentation-and-handoff.md#逐字预算估时与并行事件核算)中的“逐字预算估时与并行事件核算”算法；不要另造公式、速度表、固定镜长或第二套上界。
2. 分开记录原文/故事实际发生、镜头需要展示、可省略或由证据推知的内容。省略连接不得删改逐字保真原文，也不得让后镜前提凭空成立。
3. 把展示事件放回真实时间线上：按实际先后相加，只对人物可同时完成且观众可同时接收的部分并行；分别判断刺激察觉、台词、反应、行动、声桥、结果辨认和余波的先后。底层持续环境不重复计入，独立事件不因“声音”而免费。
4. 依据本镜观看任务确定观众读清/听清、动作完成或必要余波的完成点，再核每镜及 P/全篇总和、估计范围和保守上界。相邻重复覆盖先判断能否缩合；不能为了凑目标或上限抢读、删去承重反应、提前结果或弱化表达。
5. 新增或改动的展示内容只重算受影响镜头，并同步更新相关 P、全篇总和及上下界；保留不确定性来源和差额，区分内部计划与用户锁定时长、平台容量或真实接口设置。

## 分支与返回

- 同一动作同时占用对白或环境声时间时，依唯一算法判断真实重叠，不按通道数量重复累加。
- 若同一内容既在原文保真文本中保留又在视频中省略，分别标记，不让“展示省略”被误解为删除原句。
- 保守上界与已确认约束冲突时，先交主 Skill 尝试自然重组；不能改变锁定内容、目标或请求数时，返回影响和差额供主 Skill 询问取舍。

返回逐镜/P/全篇核算、实际展示与省略区分、完成点、估值依据/不确定性及与预算差额，交主 Skill 第六步更新镜头计划和最终标题；如已选来源 P 的边界本身需改，交主 Reference 的分段与交接方法，不在本模块改边界。

本模块是唯一算法的调用与回算接口，不复制或改写第二套估时规则；算法本身只维护在上述 Reference 锚点。
