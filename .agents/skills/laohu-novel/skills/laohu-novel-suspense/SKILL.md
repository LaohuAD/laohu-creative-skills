# 悬疑线索与真相揭晓

## 触发边界

仅在用户明确规划调查或解谜过程、布置供读者推理的线索与竞争解释，或设计真相揭晓及其公平回读时读取；自然语言表达同类目标即触发，不依赖术语。

仅贴悬疑/推理标签、偶有秘密/谎言/意外，或心理悬疑、气氛悬疑、不可靠记忆、危险逼近、真相开放，以及续写既有章节或与解谜无关的局部润色，均不触发，由父级直接处理；除非本轮同时重排调查、线索与真相链并让证据推理进入读者经验。

## 同步三线表与来源追踪

先分清既定事实、未知项与可发挥空间；受托构思真相时，新设罪行、规则、隐瞒与因果标为拟案交审，不冒充既定事实。

对每个承重谜题建同步三线表，共用同一事件标记或章节/场景坐标，对齐三方知识的同步、错开与汇合：

| 线别 | 记录内容与作用 |
|---|---|
| 事实线 | 真实时间、行为者、动机/目标、使用条件与结果。作全案底盘，揭晓不得临时补入改写答案的规则 |
| 调查者获知线 | 何时何地借亲见、物证、转述、记录或推论所得，标明已知 / 推定 / 尚未核实 / 误判。确保行动只用当时掌握的材料 |
| 读者呈现线 | 正文何处、经由谁的叙述位置给出什么，当时足以注意并形成何种解释。区分看过与理解，守住叙述承诺 |

关键信息标清来源、可信范围与传递条件；转述写明谁、何时何地告知及对方消息来源，缺依据标未知、不作推理支点。读者早知、晚知或同步依已定聚焦定；叙述者已明说的事实不得假装读者不知。

## 线索五步筛选机制

每项承重线索按序推进：

1. **立正常基线显异常**：落到当场可见可听的具体物、动作、语句、记录或缺席，标清位置、可接触者与显眼度；缺席作线索必先立常态基线。
2. **设竞争解释**：写明调查者判断依据，并列至少一个当下同样说得通、不能凭作者答案排掉的竞争解释；事实确只支持一解时写明排除依据，不硬凑假项。
3. **配可区分的后续证据**：安排后续观察、核对、询问或行动显出的差别，须切实改变解释可信度、策略或读者理解；只重复旧事实者删并。
4. **更新判断**：新证据到位后标明承认、坚持或修正了什么、旧材料的新义与仍未确认处；误判须有知识、利害或可信来源支撑，并标修正点。
5. **结论改变行动**：推论须牵动搜查方向、询问对象、风险、关系或可行选择；既不改行动也不改理解者删并或移位。

## 合法误导与藏牌边界

实质性误导须同时写清正文给出的事实、误读理由，以及负责修正的新材料。

视角知识受限不等于作弊。只有本作叙述承诺要求递送的解谜必需事实被纯为制造惊讶而隐去，或揭晓时才首次补入决定答案的关键规则、能力或物证，才属违反承诺藏牌；须回读者呈现线重排披露或调低公平承诺。

## 揭晓回读五检

揭晓落回具体行动者、行为、条件与后果，并改变人物处境、关系或后续方向，不只作讲解。揭晓前确认事实线完整、结论有已知材料支撑且排他步骤可见，再按正文顺序回读五检：

1. 线索初现时目标读者有机会看见，而非仅存作者笔记；
2. 显著度与周围信息密度相称，不把毫无提示的角落细节事后宣称早已给出；
3. 错误解释有当时可见支撑，未将真实事实改成假事实；
4. 所需证据、规则与能力均在揭晓前建立，或延后符合叙述约定；
5. 承诺回答的问题均获回应，有意留白限于选定范围。
