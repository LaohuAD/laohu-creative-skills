# 连载承诺与跨期接续

## 触发边界

仅在用户明确规划连载、分卷出版、追更节奏或主线分卷兑现与跨卷接续时读取；自然语言表达同类目标（如每卷解决一件事并接出下卷行动理由）同样触发。

仅写长篇、多章、续写已有章纲、单章写作或局部修订、章末留疑或材料提及网文出版均不触发，由父级直接完成；除非本轮同时重排跨卷或跨期规划。

## 三尺度承诺账本

先分清锁定目标、终局事实与暂拟提议（未批拟案标待确认，不冒充正文事实），按真实发布跨度维护三尺度账本：

| 尺度 | 记录内容与流向 |
|---|---|
| 全书 / 系列 | 开篇、母题、核心问题与选择建立的主承诺；完整回答、改释或留白项；终局落定的事实与关系。供每卷对照 |
| 当前卷 / 故事弧 | 入卷状态与待答问题；本卷须解决或推进的承诺；卷末处境与关系变化及由此生出的下卷理由，不另起无关谜面 |
| 章节 / 发布段 | 进入时读者在等什么；本段提供的可核信息、选择或关系变化；跨期仍需记住的事实与利害。交回父级章纲与连续性记录 |

每条承诺须有正文出处，且牵动人物命运、关系或可选行动；不影响选择或理解的未说明细节不升格为承诺。延迟、开放或改释须标明正文依据、预定回应位与理由。

## 卷末实际状态五步倒推

规划卷或发布阶段，先写卷末落定的**实际状态**（问题答到哪步、人物选择与代价、关系/资源/知识/风险或道路变化、全书承诺进度），不只写高潮或反转，再五步倒推：

1. **倒推关键决定**：缺它达不到卷末状态的人物选择，写明保住、放弃或承担了什么。
2. **安排触发事件**：令人物此刻必须抉择的事件或他方行动，写清回应方的目标、已知材料与策略。
3. **补齐事件前提**：此前成立的事实、能力、关系、线索或限制；缺项前置，不靠卷末补设定硬圆。
4. **安排读者接收条件**：放到读者能理解当下行动的位置，标清由谁、何时、经何渠道给出；保留必要未知，不误导行动条件。
5. **从新状态推出下卷目标**：依据卷末变化写出下卷的具体行动与必要性，不另起无关新问题。

成链后按读者接收顺序正向复核：前文条件是否已给、选择是否合当时所知、卷末是否兑现承诺、下阶段理由是否由本卷长出；依赖事后解释处补前置、改链或调未锁定拟案。

## 阶段结账四问与自然唤回

每卷须交与篇幅和承诺相称的阶段结果（局部解决或划新边界），不把答案推后，也不强求每章留钩。结账核对四问：

1. 已答清哪些问题？
2. 仍欠读者哪些答案？
3. 人物、关系与可选行动形成什么新状态？
4. 该状态生出了什么下阶段必需或有价值的行动？

下卷期待只剩新秘密时，追问它如何改写损失、目标、关系或道路；无真实变化不作主线承接。核心答案确需延迟，须说明此刻为何拿不到及等待期何种状态变化令等待值得；缺依据则缩短延迟或阶段释放。

跨期或停更易致遗忘时，把旧事实安排在重新改变眼前理解或选择的位置，标清所补事实、此刻必要性与唤回载体（视角、物事或对白）；严禁脱离当前行动的前情提要摘要，也不以重复讲解代推进。
