# 意识、记忆与联想组织

## 触发边界

仅在用户明确要求一章或一段主要跟随人物当下注意、记忆联想与认识变化展开、以意识运动而非外部事件序列组织文本时读取；自然语言表达同类结构即触发，无需术语。

普通心理描写、常规回忆插叙、情绪波动或材料夹带旧事均不触发，由父级按常规叙述方式处理。

## 意识运动五抓手

以既定叙述者、聚焦、时间与事实为边界（有前文则沿用既有声音与联想习惯），锁定人物此刻真能感知或想到的对象。五项按需选用，非固定配额：

1. **标定当下锚点**：明确注意来源、时空及当前动作或相处对象；感官、物件、对话、问题或环境皆可，不堆感官。
2. **找真实联想接点**：写清锚点为何牵出记忆或念头（声响、用途、称谓、空间、体感或疑问等）；允许跳跃，但留词句或声口信号供读者辨认转入。
3. **只取改变当前经验的记忆材料**：区分亲历、听说、当时推断与后来重构，只留改变此刻感受、关系判断或可选行动的细节，不摊全档；人物可记错、淡化或自辩，正文留合乎叙述位置的迹象，不将记忆版本抬为客观事实。
4. **写出认识受压的可追踪微变**：沿原先理解 → 记忆或当下证据施压 → 解释或抵抗 → 新判断、更清矛盾或拒绝改变 → 对当下注意/关系/行动的影响推进；变化可极细微或只让矛盾显形，不强迫顿悟、成长或外部反转。
5. **清晰落点（返场或有意留在意识里）**：借锚点、动作、对话、时空或现实落差带回当下，显出状态改变或维持；若有意停在记忆、余韵或开放意识中，不强加回场句，但落点须清楚。

若锚点、记忆事实或落点改动锁定的人物关系或结局，停下询问最小取舍。

## 归属与边界快速四问

排纲与落笔前逐项速检（叙述方式与语言沿用父级）：

1. **事实来源**：是叙述者确认、人物亲历/听说/推断，还是当下感受？
2. **声音归属**：评价词、疑问、称谓、口语与语序归人物、叙述者，还是有意交叠？
3. **知识权限**：读者比人物多知或少知什么，差额是有意还是越界？
4. **进出辨认**：转入另一时点或意识层凭何信号看出，返场凭何辨回原层？

## 返回父级

向 [laohu-novel 主文](../../SKILL.md) 返回锚点、联想接点、记忆版本、认识微变、归属边界及返场或意识落点；先交章纲时写明位置、对本章理解或关系的改写及回落状态，获准后由父级成文。不重写父级通用流程，也不为可视化把意识经验削平为纯外部动作。
