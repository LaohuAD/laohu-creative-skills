# 人物选择、观察与声音

完整新作或重新设计主要人物、叙述声音时，以已确认的方向、人物经历、关系和正文为输入。前置设计取会改变写法的人物选择、观察和声口，交给小说章纲与正文。续写或局部修订直接从原文提取有用的基准，按本轮影响读取相关部分。

## 从生活经历推到两难选择

先找这个人正在争取什么、惯常怎样争取、什么原则会使他拒绝看似最省力的办法。这三个问题沿用 Sanderson 的动机、个性与价值观区分。选一项将进入正文的决定，追它在人物生活中的依据：

- **身体与心理习惯**。什么处境使他抢先开口、延迟回应或失去判断？哪种感受他习惯压下去？
- **身份与教养**。他在哪些圈子做事，向谁负责？什么称谓、职业判断和交往礼数是长期练出来的？
- **过往经历**。哪件具体旧事改变了他信谁、怕哪种代价、愿意替谁承担责任？把经历连到当下决策，已有材料足够时沿用原文。

若主要人物的多重在意需要长期互相拉扯，选适合其文化和作品处境的价值维度。例如，用「仁、义、礼、智、信」分别问：他愿意照顾谁、宁愿付代价也要守什么原则、怎样守住分寸与体面、如何判断和应变、凭什么相信或兑现承诺。找出有剧情后果的偏重、缺失和异化，具体写出三者何时发生：哪项坚持过头会伤人，哪件事他一贯做不到，哪条原则在某种压力下变成挡箭牌或执念。五项用来找矛盾，有材料的维度才进入人物设计。其他价值组也可用同一动作处理。

用同一件两难事检验。先写出乍看最划算的做法，再问人物实际上会选哪条路、愿付多大代价、什么触及底线才改口或反悔。把代价写到可见后果，并留一处措辞、动作或沉默供读者辨认。以下是虚构示例：

> 闸站值守员早年替同事挨过处分。他愿为下属担责（义），却少问对方愿不愿让他代做决定（仁有缺处），平时遇上责问总先拿手续挡回去（礼成为挡箭牌）。发现徒弟私自开过闸，他按水情先送人到安全处（智），再想办法补记经过。平时信得过徒弟的口头回报，但日志关系到下一班，谁看过水位就该由谁签名（信）。

人物可以改变，也可以稳定、抗拒改变或只承担对照和喜剧节奏。若本作需要成长，先让旧习惯在具体情境里产生后果，再由后续行动显示修正、反复或失败。Forster 的扁平/圆形区分用于判断人物如何被识别，以及意外举动能否仍令人信服。对次要人物，几项清楚的行为和措辞通常已足够。

## 让景物经过人物的观察

给常驻聚焦者挑一个本作会写到的地点或事件，记录三个会改变成文的选择：

1. **第一眼找什么。** 此刻的任务、欲望或顾忌会使他先注意哪里？
2. **用什么解释和命名。** 他会用哪类常用词、职业经验或旧事类比？什么是他当下的解释，什么是正文可确认的事实？
3. **漏看什么。** 哪项感受或风险会被他当作寻常，等何种刺激出现才进入注意？

同一闸房，值守员先看红线下还有几指水位，把墙上敲响的铁管听成排水不畅。刚接来避险的孩子先看门槛上哪只鞋是干的，把铁管声当作有人要进来。分别读这两处观察，读者应能感到谁知道什么、谁在等什么。实际写景时把详情给到当前注意或本作叙述方式。换焦及信息权限见[谁在讲、谁在观察](narration-and-time.md#先分清讲述者观察位置和读者所知)。

## 建立叙述者的声音

先从已确认正文挑具有代表性的一两处，读出以下选择。新作从同一事件试写一个短段，再按本作承诺定基线：

| 选择 | 在文字上怎样落实 |
|---|---|
| 叙述者的态度 | 同样面对人物出错，声音更在意代价、可笑处还是难说出口的动机？将态度落到称谓、判断与何处沉默。 |
| 语言语域 | 选普通话、行话、口语或书面语的适当边界。看叙述者会怎样称呼一个人、怎样说一件麻烦事。 |
| 距离与移动 | 明确何时贴身写尚未成句的感受，何时拉远交代较长时间或关系。距离变化由[叙述权限](narration-and-time.md#控制叙述距离与切换)约束。 |
| 意象来源 | 从生活、环境和作品关心的事找一组可用质感或物件。在篇幅确实允许反复时，回到[意象处理](prose-realization-and-revision.md#让体感与意象承载余味)决定哪次回返会改变意义。 |
| 句法和停顿 | 试读平静与受压各一段。确定叙述者什么时候铺长句、什么时候截断，重要词在什么位置落下。 |

叙述者的声音、聚焦者眼里的世界与人物当面说的话分别核对。人物的判断可以暂时进入叙述，叙述者也可以有自己的态度。若故意形成反讽或重叠，用前后的措辞和观察位置使读者有据可循。设计完成后，把短段中的实际用词、距离、停顿或取景选择交给正文作基准。

## 用话语样本校准角色声口

给承重人物记下会影响本轮写作的用词边界，例如习惯怎样开口、用什么称谓、怎么提要求、什么时候转去说实务。确定两类越界词句及替代动作：

- **写作者的规则、论证或概括替人物开口时**，让人物按自己正在做的事说清对象或要求。若其职业、教育和关系需要概念表达，凭样本中的真实语境保留。
- **套话或违背本作人物身份、教养、时代与关系的语气出现时**，改回此人对当前听者会用的称呼、动词或句架。口头语、书面语和专业词各按人物能说、肯说及此刻会说的条件取用。

依据实际涉及的日常、办正事、独处内语、情绪受压，写出什么人、场合或压力会让角色换一种说法，什么仍留在各状态里。拟人化 AI 或刻意多面的人物同样要有可辨的切换依据，例如更换受话对象、启用正式协议或掩饰情绪；把切换信号写进正文的上下文。为主要人物摘录或试写 **3–5 句**有处境的对白与内语作为声口标尺，次要人物和无关场合只取本轮需要的一点。

| 闸站值守员的情境 | 基准句及观察 |
|---|---|
| 日常嘱咐徒弟 | “鞋放门边。踩进屋就难干了。”先说能做的事，关心落到实处。 |
| 向下一班交接 | “头一回开闸没复核水尺。你看过水尺再签，开闸那栏留着。”按交接责任说全对象和顺序。 |
| 独处时自问 | “要是那会儿他先问我呢？我会让他开吗？”对自己容许犹疑，仍围绕眼前那一件事。 |
| 被要求替徒弟签字 | “失察写我。谁开的，谁签。”旧习惯仍在，压力使他缩短句子，说清界限。 |

正文写完后，分别抽出一个角色的对白与内语连读，再放回原场景核关系与换声条件。哪句即使换给另一人物也毫无差别，就回查他的目的、听者和措辞依据。需要修的只改漂移处，已有稳定声音用原文校准。实际词句段的密度和朗读验收见[成文复查](prose-realization-and-revision.md#朗读后复查)。
