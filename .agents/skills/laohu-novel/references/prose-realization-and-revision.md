# 词句段成文、深层心理与终审修订

本文件把故事设计、人物底色与叙述安排落实为**顺滑自然、情绪带劲、人物立得住、节奏有呼吸**的小说正文，并承担精准局修与交付前独立扫疤。

## 1. 放飞起草五条正向原理

**动笔起草与成稿修疤严格分两步**：写初稿时脑子只抓下面五条正向原理和 3 个极轻支点（题材骨相与情绪走势、核心母体与主线推进、活人声口与关键记忆点），放手一口气把戏写活；具体表皮瑕疵与物理穿帮统一留到 §5 成稿后独立轻扫疤，绝不边写边背几十条禁令造成雕刻伤气。

1. **现代汉语白话素底与题材质地自适应**：
   - 行文默认顺着现代汉语流水句与自然虚词往前淌，走**八成顺滑舒展的现代白话素底配两成精准点睛**，让读者忘了作者在写作文，直接掉进故事现场。
   - 情绪外放度、语言颗粒与节奏疏密完全服从题材和作品本身的气息：网文、玄幻、都市爽文与强冲突类型大胆保留接地气、生猛鲜活的火气与干脆推进；写实、含蓄日常、心理深潜或意识流动篇章则守住低外放高内压的暗流电压；仅在题材或用户需要古雅、先锋等特异语域时再相应收放。
2. **情绪四步链与真实互动张力**：
   - 真实情绪沿着**刺激戳中在意 → 心里涌出明确火候的主观感受 → 神态语气藏不住 → 逼出要说、要躲或要干的行动冲动**自然展开；按人物身份教养与当前题材自由生长出活人口语表达，不拿干瘪抽象标签总结心情。
   - 戏剧对抗场让双方相反的行动冲动当面撞出火花、每轮交锋改写局面或心态；含蓄日常或静观场则靠未说破的顾忌、停顿与细小偏差维持暗流电压，绝不把人物写成没温度的温吞纸片。
3. **蓄压不泄底，高潮落刀不泼冷水**：
   - 写带核心反转、绝地反杀、关系决裂、真相揭晓或情感破防的重头章段时，后台先钉死最值钱的那一刻，再倒推前段的低水位蓄压与步步逼近——蓄压期忍住不提前泄出情绪底牌，高潮落刀瞬间彻底打透，不停下来解释设定、不竖礼貌防御壳，也不切回理性总结替读者讲道理。
4. **切入快准，环境为场景注入活气而非摆摊**：
   - 开篇顺着人物此刻正在做的事、眼前的麻烦或独特的感知切口直接进场，不先铺一两百字无主摆设或履历说明书。
   - 环境与物件只在真正发挥作用时出场——烘托或反衬当下心境、直接卷入行动与冲突，或用一两笔地域声场与生活毛边把空间立成活生生的现实世界；其余跟人物与场景毫无瓜葛的静物盘点留到扫疤时干脆删掉。
5. **正面画面、贴身视角与直白硬动词**：
   - 平时正面写出人正在做什么、物件此刻什么样，否定留给打破前文正面预期的反差处；第一顺位选现代读者一秒直懂、力度贴切的常见动词，打斗顺着流水句写出招、受击震痛与喘息的松紧节奏。
   - 单主角限知下，连局势掂量、胜负判断和常理对比都装进主角自己的眼睛与心里盘算，绝不跳出人物当场边解说员。

### 景随情动与中文深层心理四招
- **行动互动段**：连贯写出人物注意到什么 → 戳动了什么情绪 → 想要干什么 → 带着这股情绪怎样说、顶回去、躲开或试探 → 结果怎样改写关系或处境。
- **环境融情段**：不为写景而停下叙事，只在情绪翻涌、冲突紧要或需要立住空间氛围处顺笔点出一两处真正贴合人物感知的环境细节。
- **中文深层心理四招（话语与意识无缝切换）**：灵活切换直白心理、直接内心独白与自由间接话语，顺滑带劲：
  1. **称谓与评价词渗入**：不写“她心想”，直接让人物独有的称呼、吐槽和评判滑进第三人称句子（如介绍人说“周先生”，她心里掠过“周老师怎么又站着等？右腿撑得住么？”，开口仍是“周先生，请进”）。
  2. **表里撕裂承重**：嘴上硬扛或假装客气，心里却憋屈、寒心、犯怵或早盘算好反击，让落差自己说话。
  3. **现场刺激直接扳动情绪与念头**：让对方一句话、一个举动或眼前的突发变故立刻点着火气或打断犹豫，告别工整的议论文自言自语。
  4. **有增量的真实思考流**：从眼下线索生出暂时判断，再让新事实或利益顾忌施压，写出试探、动摇、算计或下决心的过程，不替人物提前念结论。

## 2. 对白作为行动：六种攻防模式与迂回潜台词

每轮重要对白先接住对方刚说的对象或眼前动作，明确说话人此刻在**回答、试探、拒绝、安抚、讲条件还是回避**，按双方关系、知情差与压力选称谓和句架，不替读者复述双方早就共知的背景。

### 打破对话单一的六种场景组织模式
感觉对话变平或每场都在硬吵时，按本场关系切换组织打法：
- **均衡冲突**：双方各有清楚筹码与目标，逐轮争夺控制权，每轮回应改写下一轮打法；
- **不对称施压**：一方步步追问逼近，另一方回避、敷衍、转话题或让步，压迫感落在节奏失衡里；
- **间接礼貌冲突**：用闲谈、客套或第三人掩盖敌意与控制，表层话面与深层较劲并行；
- **喜剧错位冲突**：双方各守荒唐自尊或不同盲区互相压低，笑意从认真较劲中升级；
- **自反性交锋**：人物借对白或倾诉与自己的旧承诺、记忆或自我形象较劲；
- **微限克制冲突**：不靠强攻，借极短问答、迟疑与停顿微小累积亲近、孤独或失落。

### 借眼前实事走迂回潜台词（Mamet / Pinter 技法）
当人物把真意说破会付出关系或体面代价时：
1. 选一件两人眼下真要处理的实事（递茶、分旧物、核账单、找钥匙），写出表层事务自身的来回；
2. 挑其中一个小决定承载不敢明说的关系请求，用只答边缘、反问施压、借对方原词改义或突然换题显出张力；
3. 让对方接住、错开或沉默，用一句称呼微变、一个停顿动作把关系结果落到实处。需直说、命令或坦白的时刻仍干脆直说。

- **话语归属与指代清爽**：仅在停顿、视线或动作能显出权力与情绪转向时穿插叙述，不逐句贴机械对话标签；多人同场或行动主体切换时，先以姓名、称谓或现场位置锚定，指代清晰后再用代词，复述他人原话必标清归属。

### 小说高易读排版：引号归位对白，场景与对话清爽分段
面向读者直接阅读的小说正文，排版和标点本身就是阅读体验的一部分，必须让眼睛一眼扫清“谁在说话、场景怎么推进”：
1. **引号极度克制，还引号给真正的人声对白**：双引号原则上只留给**人物直接开口说出的对白**（以及极少数确需逐字照录的纸条、短信或原话）。**拟声词一律直接裸写不加引号**（如咚的一声、啪地拍下、刺啦撕开、咔嚓崩断，不写带引号的拟声字块）；**招式名、称呼绰号、牌匾标语、单个字词与心理转述一律不套引号**（如喊惯了小梁、使出云翻浪、半个停字，除非极少数确有反讽意味且拿掉即变味之处）。页面上见引号即见人声，版面立刻干净通透。
2. **对白独立呼吸，换人与切境必换行**：人物开口说话时，让对白干净独立成段（最多顺带紧贴这一句的极短神态或轻提示动作）；**换另一人说话必另起一段**；从较长场景描写、他人反应切进某人开口，或对白之后转入较长动作展开、前史回忆与大段心理时，**必须回车拆段**，绝不把对白缩埋在一百多字的文字砖中间，也不把两段长对白和中间大段动作夹成三明治。
3. **场景与动作按镜头节拍切短段**：画面重心转移、动作过招或情绪顿挫时自然拆成错落短段，让读者的眼睛像看电影分镜一样轻快往下滑，告别密不透风的段落墙（局部修订仍严格锁死原稿非目标段的原有段落与标点）。

## 3. 核心母体、记忆锚点与人物真实毛边

1. **核心母体按篇幅定尺度**：短篇与重头单章聚焦 **1–2 个**既推剧情又载情绪的核心母体，顺着主角此刻的心境和动作轻巧点出含义翻转，不为了呼应硬停剧情盘点表面磨损，也不让前半场核心物件结尾蒸发；长篇则先钉 1–2 个全书主母体，再允许各卷、各章自然生长阶段承重物件。
2. **黄金记忆锚点（金句 / 名场面）按体量克制落刀**：在独立短篇或重头高潮章的关键转折与主高潮处，按需部署 **1–3 处**过目难忘的台词金句或动作名场面——顺着题材真气靠言外留白、同词回扣改义（把对手前文说过的词原样甩回去反杀）、表里双轨（体面字面下藏一秒意会的里子）、前扬后劈反转、客气冷刀或贴合人物手艺的硬核奇招自然长出（第一遍顺滑零门槛、回味半秒直戳当下情绪痛点）。日常过渡段、安静白描与局部微修绝不硬塞金句抖机灵。
3. **把通透留给读者，把偏执与生活毛边留给人物（防塑料感）**：真实活人在情绪当头时往往要面子、说反话、赌气、自欺或当下没想明白，绝不让人物像受过心理咨询训练一样时刻清醒通透、动辄亲口替作者点破全篇主题，也不草率塞廉价和解。哪怕出场只有几句的配角，也带一点自己的小算盘、行业习惯或小脾气，绝不沦为纯递话工具人。

## 4. 精准局部修订与根因分诊

### 局部修订三条锚定守则
1. **锁区外逐字保真与首末状态**：先通读完整片段及上下文，分清要改的错处与仍成立的资产；用户限定只改指定表达、其余逐字保留时，精确定位待改分句原位替换，区外文字、标点与原稿首末事件状态纹丝不动，改后连读接缝。
2. **核清在场范围与持物物理链**：凡涉及无人、唯一等范围断言，列出此时此地实际在场者复核；对每项关键动作反推谁持有、在哪、能否使用，并在首次需要处交代。
3. **换主体必先锚定**：叙述从甲的动作转到乙的动作、情绪或开口时，在转入的第一个分句立清姓名、称谓或位置，避免多人同场代词回指歧义。

### 三层缺口根因分诊（先修根，再修字）
- 人物突然变招、事件无前因后果 → **故事缺口**，回 [story-design-and-reader-expectation.md](story-design-and-reader-expectation.md)；
- 事能成立，但读者搞不清谁看见、何时知、为何这般顺序 → **叙述缺口**，回 [narration-and-time.md](narration-and-time.md)；
- 事与视角都对，但词句发压缩、缺情绪火花、节奏发慢或人物声口没立住 → **语言缺口**，锁定故事与叙述原地修词句。

## 5. 交付前四道硬检（成稿后独立轻扫疤）

初稿放飞写完后，彻底离开创作提纲，像挑剔读者一口气往下追小说一样默念通读；此处是全部表皮与物理扫疤的唯一收口，只扫真疤不伤活气（局部任务只检受影响处及相邻段）：
1. **语感舒展、版面清爽、篇幅与节奏扫疤**：默念通读——凡因把活人话硬压成单字弱化缩略词、四字播报电报语或拗口雅词而偷偷拧小了情绪音量、读着发紧发闷的句子，一律铺展开改回敞亮顺溜的现代白话（自然贴合含蓄语境的常用汉语词如一声轻响、一句软话照常保留，绝不事后拿风格替真正生硬的句子洗白）；**逐段扫除多余的非对白引号（拟声词、招式、称呼、牌匾等），把缩埋在长段场景或动作里的对白果断拆出独立成段，拉开短段呼吸**；删掉既不推剧情、不衬心境、也不建构空间真实感的死静物摆摊与凑停顿杂音；核对相邻句架与感叹号密度，检验记忆锚点是否自然顺滑；若用户明确给定目标篇幅档（如八百字、两千字左右），核对剪裁不大幅超标失控。
2. **实画面、去套话与死贴视角扫疤**：清掉把身体零件当情绪打卡表的重复微表情与空洞打斗特效（仅保留实打实的痛感、冷暖劳损，或偶发且咬死具体动作的生理失控）；扫一遍“没/不/无”，把缺前文正面铺垫的空心否定改成正面动作或状态；抓出作者跳出当场边解说员、评书对比、外置双人远景镜，以及人物替作者念主题金句、对称排比控诉、作文式强行释然暖尾与剧本掐表词，拉回人物现场与真动作。
3. **物理闭环、道具数字与时代自洽扫疤**：逐项反查——① 锁定秘密、关系红线与不点破对象是否守牢；② 新人或核心物件首次影响选择时辨识清楚，经手道具拿放连贯、特征口径一致、结局不蒸发也不空降（决定胜负的底牌与地形暗桩须前文自然埋过，弱势翻盘守住真实体力与实力压迫感）；③ **回怼或引述前文原话时逐句核对前文确有此话**（绝不把没说过的话栽回前文），并核平版本数、钱物花销、动线顺序（先开门出门再带门）、光线声学遮挡、实体与声音主谓搭配（声音是被听见，实体才承担撞击触碰）、材质工具等生活常识及本作时代与世界观语境（古风、历史与传统架空不漏现代计量单位或违和器物，穿越与跨界设定守住角色认知边界）；④ 单角对白与内语连读不掉声、不无故重姓撞名。
4. **改稿护资产与防钟摆复核**：对照 `docs/runtime.md` §3 与前稿已认可的长处，确认扫疤只修了真漏洞，既未磨平网文与强冲突类型的生猛爽感，也未把含蓄或静观篇章强改出违和火气，原有情绪电压与鲜活气口完好无损。
