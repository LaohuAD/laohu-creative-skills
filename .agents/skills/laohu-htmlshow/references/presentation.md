# 展示美学、交互与验收

由 [laohu-htmlshow 主文](../SKILL.md) 在制作浏览器展示页时按内容形态选读。本文件提供真正拉高页面审美、易读性与操作顺手度的方法和工程底线，不是一成不变的死模板，不要求每页塞满全部控件。

## 1. 视觉气质与排印系统

打开页面第一秒的质感来自色彩克制、留白节奏与字阶清晰，而不是堆积阴影和特效。

### 色彩方案选型（按内容气质挑一套，绝不混搭）

| 内容气质 | 页面纸底 | 内容面 | 主正文墨色 | 次要说明色 | 推荐主强调色（全页限 1 个） | 适用场景 |
|---|---|---|---|---|---|---|
| 暖纸出版 | `#FAF9F6` | `#FFFFFF` | `#24221F` | `#6B665E` | 出版墨绿 `#1E5B4C` 或刊物砖红 `#A63D2F` | 长文章、深度随笔、人文分析、作品集 |
| 理性简报 | `#F6F7F9` | `#FFFFFF` | `#1F2328` | `#59636E` | 深海藏青 `#1F4E79` 或理性蓝 `#2557A7` | 调研报告、技术文档、方案对比、架构说明 |
| 精工工作台 | `#F4F5F7` | `#FFFFFF` | `#18181B` | `#52525B` | 石墨深青 `#0F766E` 或暖琥珀 `#B45309` | 提示词库、命令手册、剧本分镜与制作表 |

- **层级靠细线与留白，不靠厚阴影**：边框使用柔和低对比色（如 `rgba(24, 24, 27, 0.08)` 或 `#E5E3DD`），圆角克制（常用 `6px–12px`）；需要柔和护眼暗色模式时，使用深暖炭底（如 `#161719` / `#1E2024`）配柔和浅灰字（`#E6E5E0`），同样核验前景与背景对比度（普通文字至少 4.5:1，大字至少 3:1）。
- **离线原生字体栈**：
  - 正文无衬线：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif`
  - 文学与刊物标题可选衬线：`"Songti SC", "Noto Serif SC", "Source Han Serif SC", Georgia, serif`
  - 代码、参数与编号等宽：`"SFMono-Regular", ui-monospace, Menlo, Consolas, "Liberation Mono", monospace`
- **排印尺度与留白节奏**：
  - `h1` 用 `clamp(1.65rem, 2.6vw, 2.15rem)`、行高 `1.28–1.35`、`text-wrap: balance`；绝不用全局 `white-space: nowrap` 硬逼单行导致溢出。
  - `h2` 用 `1.3–1.45rem`、上外边距 `2.4em–3em`、下外边距 `0.85em`，可配极细顶线或等宽序号拉开章节起止。
  - 正文 `16px–17px`、行高 `1.78–1.85`、段距 `1.15em–1.35em`；保留原文段落、诗行与代码换行，不把 Markdown 编辑软换行误转成 `<br>`。

## 2. 空间布局与导航体验

### 单栏主文与宽元素混排
- 正文连续阅读时，主文列最大宽度控制在 `680px–760px` 并居中，确保每行落在大脑最省力的 34–42 个汉字区间；不要为了填满宽屏把正文拉到屏幕两边，也不要在右边预留空栏把正文挤在左半边。
- 宽对比表、分镜多列图板与宽图可突破正文栏宽至 `960px–1120px` 或容器内局部横向滚动，不让整页出现横向滚动条。
- 网格与弹性容器一律配置 `minmax(0, 1fr)` 与 `min-width: 0`，图片统一 `max-width: 100%; height: auto; display: block`，长 URL 与超长参数块配置 `overflow-wrap: anywhere` 或局部 `overflow-x: auto`。

### 目录导航（长文与报告必备，短内容按需省略）
- **独立滚动与不挤正文**：宽屏侧栏目录固定在左侧（宽度约 `220px–260px`），内部独立滚动；提供清晰的一键收起按钮，收起后主文自然重新居中，不留下半屏空白。
- **滚动联动与防遮挡**：通过 `IntersectionObserver` 高亮当前阅读章节，同时补充页面触底兜底（滚至底端时准确点亮最后一项）；所有标题设置与顶部栏匹配的 `scroll-margin-top`（如 `76px`），确保点击目录跳转时标题完整露出。若页面同时带有卡片筛选器，点击目录锚点指向被隐藏条目时须自动重置筛选并滚动到位。
- **不重复堆首屏导航**：桌面宽屏已有常驻左侧目录时，首屏正文区不再叠放同名的重复快捷卡片，把第一屏留给标题、导语和实质内容；主题与字号偏好使用带 `try/catch` 的本地存储记忆并支持 `prefers-reduced-motion`。
- **唯一锚点与语义层级**：从真实标题层级生成目录，`h1` 到 `h3` 顺序递进不跳级；若原文存在同名标题，自动追加稳定后缀生成唯一 ID。
- **手机端抽屉**：窄屏下侧栏收进顶部栏的可开合目录抽屉，按钮带 `aria-expanded` 与清晰名称，点击条目跳转后自动收起抽屉，键盘 Esc 可关闭并归还焦点。

## 3. 四大高频场景的高价值交互设计

### A. 沉浸阅读页（长文章、教程、复盘）
- 顶部 2px 极细阅读进度条，不抢正文视觉。
- 文章头部清晰呈现标题、原文导语及必要的阅读信息（如估算字数与章节数，仅依据真实文本计算）；不替文章补写原文没有的摘要或营销金句。
- 代码块右上角提供悬浮或顶条式纯净一键复制按钮，并按原文声明标注语言名称（原文未标明时不瞎猜）。
- 提供清爽的 `@media print` 样式，打印或另存 PDF 时自动隐藏侧栏、进度条与操作按钮，释放全幅正文。

### B. 报告与方案对比页
- 顶部可设核心结论速览区，条目严格忠实于原文已给出的判断、结论或条件，不把猜测变成指标卡片。
- 对比表表头浅底区分、`position: sticky` 吸顶（需配合理背景色防透字）、行悬停微亮；列数较多时容器支持顺滑横向滚动并提示可左右滑动，窄屏下短对照表可转卡片堆叠。
- 维度对齐遵循同一套真实口径，原文缺失的数据留空或标注原文未提供，绝不补打星级或分值。

### C. 提示词与素材工作台
- **顶部工具条**：轻量即时关键词搜索框 + 按原文分组生成的分类筛选标签 + 命中条数统计；可选一键复制当前可见全部原文。
- **展示层与复制层物理分离**：每张卡片上半区展示编号、名称、参数标签或适用说明，下半区是视觉风格鲜明的纯净原文盒，右上角放一键复制按钮。同类文本提示词保持统一字体，终端命令与脚本代码块可用沉稳深色底面与浅色提示词卡拉开材质区分，一眼辨清用途。
- **纯净数据绑定**：将每条纯净原文独立存入对应 `<template>` 或经安全转义的 `<script type="application/json" id="payload-data">`（需将 `</` 转义为 `<\/` 防闭合脚本标签），按钮通过唯一索引直接读取原始字符串复制，确保引号、换行、参数顺序、`{{占位符}}`、负面提示词分毫不差，绝不混入任何界面标签文字。

### D. 剧本、分镜与制作说明页
- 严格锁定场次号、镜头号与顺序，顶部或侧栏按场次快速跳转；若涉及多角色，可按需提供角色台词微高亮筛选（只高亮不隐藏上下文，以免丢失剧情连贯性）。
- 宽屏按真实字段分列对齐（如镜号 | 画面与动作 | 对白 | 声音与备注），长对白与长动作完整展示，不为卡片等高而截断折叠。
- 手机窄屏自动重排为每镜独立区块，字段标签与正文上下呼应，单手滑动即可顺读整场戏。
- 若输入是 `laohu-asrcut` 产出的剪后时间线与审阅包，按需读取 [ASR 审阅页契约](asrcut-review.md)。

## 4. 安全转义与可靠复制实现模式

### 防止源文破坏页面或执行脚本
- 展示给用户看的源文代码或包含 `<script>`、`<iframe>`、`onerror=` 的片段，必须经 HTML 实体转义（`&`、`<`、`>`、`"`）放入 `<code>` / `<pre>`，确保页面渲染出原样可见文字而非执行代码。
- 严禁把用户输入或文稿原文通过未转义的 `innerHTML` 动态写入 DOM；客户端搜索高亮或筛选优先用 `textContent` 与安全的 DOM 节点构建。

### 本地文件 `file://` 与 HTTP 双通的复制流程
```javascript
async function copyPlainText(text, fallbackEl, onStatus) {
  // 1. 优先标准 Clipboard API（HTTPS / localhost）
  if (navigator.clipboard && window.isSecureContext) {
    try {
      await navigator.clipboard.writeText(text);
      onStatus('copied');
      return true;
    } catch (_) {}
  }
  // 2. 降级离屏 textarea（兼容本地 file:// 双击打开）
  try {
    const ta = document.createElement('textarea');
    ta.value = text;
    ta.setAttribute('readonly', '');
    ta.style.cssText = 'position:fixed;left:-9999px;top:0;opacity:0;';
    document.body.appendChild(ta);
    ta.focus();
    ta.select();
    ta.setSelectionRange(0, text.length);
    const ok = document.execCommand('copy');
    document.body.removeChild(ta);
    if (ok) {
      onStatus('copied');
      return true;
    }
  } catch (_) {}
  // 3. 最终兜底：自动选中页面内的纯净原文节点供用户手动 Ctrl/⌘+C
  if (fallbackEl && window.getSelection) {
    const range = document.createRange();
    range.selectNodeContents(fallbackEl);
    const sel = window.getSelection();
    sel.removeAllRanges();
    sel.addRange(range);
  }
  onStatus('manual');
  return false;
}
```
只有在第 1 或第 2 步确认返回成功时，按钮和提示才显示已复制；进入第 3 步时明确提示未能自动写入剪贴板、已为您选中原文请按 Ctrl/⌘+C 复制。

## 5. 交付前核验与问题排查

| 核验项 | 具体怎么查 | 常见暗坑定位 |
|---|---|---|
| 原文保真 | 逐节对照源文标题、段落、参数、表格空缺、特殊符号与代码缩进 | 检查是否漏段、是否把 `<script>` 吞掉、是否误改英文标点或占位符 |
| 视口与回流 | 桌面 1280px、手机 375px 看视觉层级与断行；320px 查整页零横向滚动 | 出现横向溢出时追查未设 `min-width: 0` 的网格子项、固定像素宽容器或未包滚动盒的表格 |
| 导航与可读性 | 点遍目录确认标题不被顶部栏遮挡、收起侧栏正文居中、核对正文对比度 | 忘记设 `scroll-margin-top` 或重复标题撞 ID |
| 复制与交互 | 检查实际写入剪贴板的文本与原文逐字一致；核对搜索筛选清零与复位 | `innerText` 带进按钮文字、`</script>` 提前截断 JSON 数据块、筛选后隐藏了本该保留的原文 |
| 离线独立 | 源码全局排查无未声明的外部 `http(s)://` 字体、CSS、JS CDN 链接 | 删掉外链 CDN，回归本地系统字体与纯原生脚本 |

有浏览器工具时实开页面并在目标视口与交互态下核验；无浏览器环境时执行可执行的代码与结构核验（如检查标签闭合、脚本无语法错误、零外链 CDN、纯净数据与原文一致），并如实告知未在真实浏览器中完成渲染与剪贴板实测。
