# 参考图、材料与场景方法

由[资产主文](../SKILL.md)在需要分配真实参考图职责、把材料样本绑定部位、核对场景视野，或选择照片级空场结构时读取相关节。输入为已定的身份、用途、结构、色材与可读取的资料，返回本项应保留的设计、每张图的作用范围或可见空间关系，编入本项提示词。

阶段顺序和模板用于编制提示词与交接。实际图片、视频制作按 `docs/runtime.md` 的权限与成本边界交给对应能力，素材状态以本轮可核对的真实文件为准。

## 把参考输入编译为有边界的图像指令

### 先明确要用哪类输入、每张图控制什么

确定本项实际需要的是造型/几何参考、人物面貌或身份参考、特定材料样本、服装或地点参考，还是没有图像输入、仅根据文字和已有资产设计。只读取当前任务需要的资源，不因使用某一方法而加载所有同类参考。逐张把输入的真实职责写进提示词：造型图提供姿态、比例、构图或结构；人物图只提供已分配的面貌/身份特征；样本图只提供命名材料或指定部位；地点图只提供用户选定的地点或其中明确指定的元素。

每张图分配一个清楚的设计职责。把几何、面貌、材料和部位一一对应，逐项标出仍应沿用的脸貌、身份、尺度、服装、地点或姿势。一张参考图可提供同一用途下的多项特征。若多图要求冲突，在编译前由用户锁定项和已定用途裁决各图控制范围。需要改变观察点时，在同一世界空间里重新说明固定物、入口和相对位置；不要把全景中的屏幕左右机械翻转成实际空间坐标。只有当前会调用的真实输入存在且可识别时，才在提示词中写它的图号/文件/平台标识；没有则按文字材料继续，或在所选方法必须具备该输入时停在设计阶段。

### 以本项实际布局完成提示词

把已定的身份、用途、结构、色材与必要辨认特征写入原类别的完整独立提示词，再明确真实参考的职责和不能越过的范围。场景参考只继承用户希望保留的地点；人物照片不自动带入其原照片的背景、照明、阴影或姿势。说明参考在新视图中的大小、距离、位置或观察方向时，以实际用途和锁定布局为准。材料映射写出其来源或可辨名称、对应部位、颜色、表面纹理及有依据的使用状态；风格化作品按本作的笔触、形面和细节尺度转译这些材料线索。最终提示词采用用户的语言和项目已有输出结构；专项模板里的参数或比例只在对应分支确实适用时采用。交付的设计或提示词不证明任何图片已经生成、编辑、保存、检查或可用于视频。

### 空间、构造和光线采用同一世界关系

为空场景建立主视图时，先以材料或已定规格中的入口、墙面和主要固定地标建立同一套空间关系基准；仍开放的新设计先定这些要素的相对关系，不强制XYZ。再据此选择相机站位、高度和朝向。机位与朝向定后，从这一观察侧逐项复核要写成可见的墙面、通道、固定物及彼此前后/遮挡关系；镜头背后的设施不能写成远景。出现矛盾时，保留用户锁定的空间关系，改选能呈现目标的可用机位；若单一视点仍不能呈现全部要求，只写该视点真实可见部分，并按原有附图条件判断是否另加视图，不改变默认展示。灯光只来自场景已有或本次获准设计的场内设施，不额外叠加与场景冲突的影棚灯。参考图只取某个元素时，明示保留什么、排除什么，以及该元素在新场景中的尺寸和距离；人物资产参考不要连带采用原照片中的环境和动作。

## 空场景方法分支

当本轮需要一处像实拍的空场，作为可复用地点或供人物与生物后续入场的环境参考时，采用这一结构。风格化空场沿用上文的空间构造与受光核对，按本作媒介组织层次、材料、光源与留白。服从用户已定地点、取景、光线和画内文字范围。

### 房间规则与工作顺序

首次设计而无须复现既定参考时，先定房间几何、识别地标、墙面沿线和光源，再用一条完整提示词直接设计空场。固定几何保持明确。让人手布置留下合理高低差，软包随受力下陷，地面灰尘随动线和日常使用出现。已有选定地点或图像布置时，沿用实际依据，分别说明固定空间和本次观察面。

1. 从现场用途和已有材料确认房间的形状、地标、沿墙构成和场内光源。
2. 按下列七块的次序写一条提示词。照片级空场可从完整文本直接制作；遇到确有跨视角或精度要求的场景再使用已知布局参考。
3. 如已另授权实际制作，可用支持该呈现方式的工具作两张同一构图目标的候选，依实际结果挑选。发现单处问题时，按文末判据只改对应的区块后复核。
4. 地点交给后续镜头时，按实际图像和镜头范围说明沿用整个空间还是指定元素，并给出新视图中的位置与尺度。

### 地点提示词的七个区块

1. **对象与形状。**以“空场景的照片级实拍电影静帧：”开头并命名地点。用直白文字写几何形状：横截面、地板、墙、天花板、隔间/分段数量及尽头的封闭结构。
2. **地标与墙面。**选一个视觉焦点（门、祭坛、窗、机器），逐部分描述；再写沿墙重复出现的内容和材料及使用痕迹，例如接缝、螺栓头、擦伤、地面水膜。
3. **摄影机。**写明摄影机站在哪里、高度、朝向；地标在画面中的位置和大小；其余画面由什么填充。需要时说明轻微倾斜。写“自然比例”。
4. **光线。**只使用地点已有或本次获准设计的场内灯具，不额外叠加与场景冲突的影棚灯。写哪些开启/关闭、画面最亮处、小型强调灯、曝光（“昏暗低调曝光、空气清透”）及地面反光。
5. **镜头。**写镜头特征（例如中等变形宽银幕效果）、焦点位置、虚焦区域、细节向边缘的衰减。写“不要额外添加光斑条纹，不要形成均匀的模糊边框”。
6. **颜色。**写阴影、主要表面、灯光及唯一暖色或亮色强调。
7. **空场。**写“`<地点>`无人占用：没有人、窗后没有人物、没有人的倒影、没有可读文字。单幅连续图像。”

每个区块单独成段。描述画面里实际存在什么，不要堆叠风格词。

### 完整工作示例

以下走廊的对称几何、五个舱段、门板和灯具数量、镜头位置、倾斜角度及色彩均为该例的具体设计，不是新地点的默认规定。

```text
一张空地点的照片级实拍电影静帧：未来研究设施内一条很长的服务走廊。它是一条笔直、对称的隧道，横截面为拉长的八边形：平坦地面，下部墙板向外倾斜上升，中段墙面垂直，上部墙板向内倾斜，接到一条平坦的天花板带。五个相同舱段由深色边缘的肋条分隔，尽头是平坦隔墙，中央关闭着一扇双开门。

双开门是地标：两扇门叶各有上下排列的两块高长八边形灰白色门板，装在深青灰门框中。隔墙门上方亮着一盏小型笼罩灯，发冷白光。两侧长墙完全相同，沿中心线镜像对称：每个舱段的两侧墙上都有一扇宽圆角长方窗，装在深灰色模制窗框内，窗外可见由大块灰砖构成的昏暗房间；窗下有暗黄的管状扶手，窗与窗之间有灰色配电箱，上方倾斜墙板下有黑色线缆。墙板为模制复合材料，带深色接缝、螺栓头和轻微擦痕；地面是密封金属板，上面覆着薄薄一层水膜。

沿隧道方向的四分之三视角：摄影机位于走廊内门的对面端，站在中心线左侧、扶手上方的站立视线高度，略微向右转。关闭的双开门正对摄影机，位于画面左侧三分之一处，门完整可见，高度约占画面四分之一。左墙强烈透视缩短成窄带；右墙占画面右半边，从前景延伸入远处，每个舱段都比前一个更窄。两侧墙的窗、扶手、线缆和灯笼都朝门的方向汇聚。摄影机滚转约五度，形成轻微荷兰式倾斜，使地面线和竖线稍稍倾斜。自然比例。

光线只来自走廊已有或本次获准设计的场内灯具：天花板带每个舱段都有一块嵌入式矩形灯板。离摄影机最近的两个舱段灯板关闭，使近处走廊暗一档。远处灯板开启，各自在潮湿地面形成一片柔和光池；最远端灯板与门上方的灯一起，使门端成为画面最亮处。每条墙上沿肋条脚边的地面各放一盏小琥珀色灯笼。昏暗低调曝光，空气清透，地面上有长而断续的反光。

最终去变形的画面采用中等变形宽银幕镜头特征，场景比例自然。焦点落在双开门和远端舱段；最近的舱段柔和虚焦，近处琥珀色灯笼形成清晰的竖向椭圆散景。细节朝画面边缘和角落适度衰减，只有接近画框边缘时直线轻微弯曲，角落有中等暗角。不要额外添加光斑条纹，不要形成均匀的模糊边框。

颜色：阴影和近处地面接近黑色并略带绿色；门板为冷灰白，远离灯光处偏灰绿；天花板灯光冷白；小型琥珀灯笼是唯一暖色强调。

走廊无人占用，地面中心线从头到尾保持畅通：没有人、窗后没有人物、没有人的倒影、没有可读文字。单幅连续图像。
```

### 场景检查

1. 它看起来是地点的照片还是渲染图？没有东西完全对齐，表面有磨损、灰尘和使用痕迹。
2. 是否有一个清楚地标，且能说清它在画面中的位置？
3. 光线是否来自能看见或能在空间中定位的灯具？
4. 是否为空场：没有人、没有人物、没有可读文字？
5. 人物需要站立或移动的地面是否保持畅通？

### 空间参考交给视频时的图像职责

下游实际可接收人物图和地点静帧时，分别说清两张真实输入的作用范围：

- **使用整个地点：**“图 1 用于人物；从图 2 只取地点。”
- **只使用地点中的一个元素：**“从图 2 只取上方有灯的出口门。把门从图中的其余内容分离出来：不要走廊、墙、地面、天花板灯、窗或扶手。”然后说明该元素在新场景中的大小与距离。
- 说明人物照片中哪些保留、哪些舍弃：“不要使用它原照片中的墙、地面、闪光照明、硬阴影或姿势。”

此段只说明未来可能的图像职责交接，不授权 Assets 运行视频生成，也不包含后续视频草稿分辨率和定稿流程。
