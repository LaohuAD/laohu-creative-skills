# 声音身份交接与完整提示词

本 Reference 维护可复用角色/旁白声音身份的设计方法、交接状态和完整提示词编译。由 Assets 在稳定声音身份已获授权时读取；视觉资产字段与画面布局仍只由[图片提示词交接与固定输出](image-handoff-and-output.md)维护。此处的文字设计不表示已生成、听取、选择或绑定实际音频，也不授权调用外部生成服务。

## 先分清交接对象

开始设计前，核对当前输入究竟是什么，并按可验证状态表述：

- **角色实体：**故事中的人物或旁白身份。可沿用 Assets 已有实体 ID。
- **稳定声音身份：**跨镜头或跨段复用的可听辨认设计；确需管理时使用独立于人物实体的内部标识。
- **视觉资产：**人物外观设计，可以绑定同一实体，但不决定其声音。
- **单句表演：**当前台词中的意图、情绪、力度、耳语、呼吸和语速变化，由 Video 按实际台词与场面处理，不因变化重造声音身份。
- **试听文本：**为听取或生成参考样本而使用的一段文字；仅使用用户授权的材料，或明确获准创作的试音文本。它不是稳定声线提示词，也不是作品对白的改写授权。
- **实际音频文件：**已存在且可访问的声音素材。只有真实提供并可读取时才记录文件、片段或对齐信息。
- **供应商 voice ID：**外部服务中的实际引用标识。只有确认确为该平台的真实值时才记录，不能把内部概念 ID 或项目 `@` 名称冒充平台 ID。

一个人物可绑定视觉资产和稳定声音身份；无肖像的旁白也可独立拥有声音身份。绑定关系只说明它们服务于同一个实体，不把图像参考、文字设定、音色设计和真实音轨混为一件素材。

## 设计顺序

1. **确认用途和可用依据。**明确这是角色对白、旁白还是其他稳定声部；整理用户已定方向、可读文字描述、实际声音参考及尚缺信息。只有文字就按文字设计，不声称听过声音；既有选定声音则保护其辨认锚点，只修改用户授权部分。
2. **把用途转成目标听觉印象。**说明希望听者在什么使用场景中如何辨认这条声音，例如亲近、克制、清亮、粗粝或具有仪式感。目标须服务作品和人物，不把性别、外貌、身材、职业或人格标签当作音色因果。
3. **选择少量有效声学锚点并排主次。**从音色质地、相对音高、共鸣位置、气息、咬字、语言/口音和稳定的发声习惯中，选择确实能塑造辨认的特征；说明哪些是核心、哪些只作辅助。不是全字段清单，不虚构赫兹、声道参数、录音设备或没有依据的口音细节。自然的沙哑、气声等若是身份锚点，不要在“干净录音”要求中抹掉。
4. **仅在有辨识风险时比较同组声音。**确有多个会在同一作品中并列出现、可能混淆的声音时，比较核心锚点并调整差异；单一角色设计不必制作虚构的组内对照表，也不以差异为由背离用户选定方向。
5. **分开身份稳定与当句变化。**提示词定义可复用身份，不锁死每句的情绪或力度。愤怒、安抚、耳语、疲惫、抢接等临场表演留给 Video；只有用户或剧情明确确立持续性嗓音改变时，才写明其形成、持续、变化及恢复范围，并交 Video 在相应 P 中承接。
6. **编译独立、完整的声线提示词。**用自然语言写清角色用途与目标听感、主次声学锚点、语言/习惯和适用的录音呈现。每份提示词独立可用，不用“同前声线”“按角色设定”等缺少上下文的指代；普通细节不需要逐项锁定。提示词不替代试听文本、实际音频文件或外部平台契约。

## 提示词与试音分开

声线提示词回答“稳定身份听起来怎样”；试音文本回答“用哪段文字检查它”。两者分开提供，避免把一段情绪强烈的台词误当成永久音色。若要试听或生成样本，先检查用户是否授权这一操作以及材料是否可用；逐字受保护的对白不重写、不截改成新作品台词。样本文本的语气和内容会影响听到的语速、情绪等表现，因此不能仅凭一次样本把临场表现归为声线身份。

用于形成可比较的声音基准时，通常采用清楚、单一声部、尽量少混入场景混响的呈现，便于辨认核心音色；但不要去掉设计中有意保留的呼吸、沙哑等锚点。具体样本材料、长度、采样参数和合成方式依实际授权与已知工具要求决定，不设通用秒数、语速或供应商字段。

## 交接状态如实报告

交付时分开说明目前处于哪一步，不把较早阶段说成较晚阶段：

- 只有文字概念：交付稳定声音身份设计与完整提示词；若没有真实样本，说明尚无音频参考。
- 已有真实样本但尚未试听：可说明文件已提供/可访问；不能写成已听取或已选择。
- 已执行样本生成：只有确认真实结果后，才记录样本文件及实际可见的生成信息。
- 已试听并选定：仅当确实完成试听和选择，才说明其为当前选定的声音参考。
- 可供下游引用：只有下游实际可访问的文件、内部映射或已核平台标识确实存在时，才说明可引用，并交代真实引用方式。

上述来源和阶段状态面向创作者说明，应放在声线提示词块外；可复用提示词只保留会改变目标听感的稳定身份指令，不把“没有参考音频”“尚未生成、试听或验证”等状态写成声线特征。若已知供应商真实 inputmode、文件引用或参数是其输入契约必需项，则按该接口要求保留为明确的机器输入，不将其误判成可删的交付状态。

概念 ID、实际文件名、平台/供应商 voice ID 和 `@` 项目名职责不同。用户没有给真实文件或平台引用时，不编造它们，也不声称已保证不同段落像素级/波形级一致。若已知具体生成模型的字段契约，才为该模型作局部适配；未知模型时提供可读自然语言提示，不假设供应商功能。

## 来源与本地适配边界

ElevenLabs 官方 Voice Design 文档将声线描述与 Text to preview 文本分开，并指出试音文本会影响预听中的语速、情绪等结果；Qwen3-TTS README 的 Voice Design then Clone 说明了先得到设计参考音频、再建立供新内容复用的 voice clone prompt 的工作路径。本项目仅采用“身份描述、试音材料与可复用引用分开；状态按真实完成步骤报告”这一可迁移方法，不把供应商流程、参数、字段或能力当成通用接口。
