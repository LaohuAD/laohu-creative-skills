# 声音身份交接与完整提示词

本文件是可复用角色或旁白稳定声音身份的设计方法、交接状态与完整提示词编译唯一真源。**仅在用户明确要求固定角色音色、旁白声线或授权本轮声音资产范围时读取**；纯视觉资产任务不加载，也不自动扩出声音设计。视觉字段与布局唯一归 [image-handoff-and-output.md](image-handoff-and-output.md)。

---

## 1. 严守七层声音对象边界

设计、映射与交接时，绝不将以下七类对象互相混淆或替代：

| 层级 | 职责边界 |
|---|---|
| **角色实体** | 故事中的人物或旁白本体，沿用已有实体 ID；同一人物可分别绑定视觉资产与声音身份，旁白可无肖像。 |
| **稳定声音身份** | 跨镜头复用的长期可听辨认设计；确需独立管理时另授内部声音 ID。 |
| **视觉资产** | 外观造型设计，与声音归属同一实体，但外观、性别、体型或职业标签不决定音色。 |
| **单句临场表演** | 具体台词的愤怒、耳语、疲惫、喊话、临时语速与呼吸起伏，归 `laohu-video` 按句落实，不建新声线 ID。 |
| **试音文本** | 用来预听或生成参考样本的一段文字，必须与声线提示词分开列出；受保护的源稿对白逐字原样保留，绝不改写。 |
| **实际音频文件** | 真实存在且可读取的音轨或参考片段，未提供或未读取时不得声称存在或已听取。 |
| **供应商 voice ID** | 外部语音平台确有接口回执的真实引用标识，严禁用内部概念 ID 或项目 `@` 名称冒充。 |

## 2. 声音身份六步设计法

1. **核清用途与真实依据**：区分角色对白、旁白或其他常驻声部；厘清已有锁定音色方向、文字描述与可读音频样本。仅有文字就按文字设计，不假称听过声音；修改已有选定声线时保护原核心锚点。
2. **落定目标听觉印象**：写清在具体使用场景里希望听者凭什么第一听感认出这条声音（如近距离克制讲述时的温厚低沉与利落收口），服务角色用途，不套外貌或性格刻板公式。
3. **挑选少量主辅声学锚点**：从音色质地、相对音高、共鸣位置、气息感、咬字清晰度、语言/口音和稳定发声习惯中，选 2–4 项核心主锚点加少量辅助特征，其余维度开放。**绝不虚构赫兹数值、声道毫米参数、录音棚麦克风型号或无依据的地方口音**；作为身份特征的自然沙哑或轻气声须明确保留，不被干净降噪抹平。
4. **仅在存在混淆风险时作组内对比**：同作多声部并列易混时，拉开核心听觉维度并保持剧情要求的同族相似处；单一角色或独白旁白不硬凑对照表。
5. **剥离长期声线与持续/临场变化**：声线提示词定义可复用常态底色，不锁死单一情绪强度。仅当剧本明确确立持续性嗓音改变（如长期失声、伤后沙哑与恢复节点）时，记录真实生效与结束范围，交 [laohu-assets-voice](../skills/laohu-assets-voice/SKILL.md) 处理继承关系。
6. **编译独立完整声线提示词**：用自然精炼的中文写成单个独立可复制代码块，涵盖声音用途与目标听感、主辅声学锚点、语言习惯及清晰少混响的基准录音呈现，脱离上下文即可使用（不写同前声线、按人物设定）。

## 3. 声线提示词与试音文本严格分块

- **职责分开**：声线提示词只回答这条稳定声音平时听起来什么样；试音文本只回答拿哪句字来测试它。二者在输出中分块呈现，防止把某句激烈情绪台词误判为永久音色。
- **基准呈现清晰度**：为建立可比听觉基准，提示词中可要求人声清晰贴近、单一干净声部、极少环境混响，同时显性保住设计中刻意保留的气声、颗粒感或轻沙哑锚点；不臆造通用采样率或秒数参数。

---

## 4. 交接状态如实分阶（状态留在块外）

声音交付按真实进度如实报告，绝不将前序阶段拔高为后续阶段：

| 当前实际阶段 | 允许报告的状态 | 绝不逾越的边界 |
|---|---|---|
| 仅文字概念设计 | 已交付稳定声音身份设计与完整提示词，尚无真实音频参考 | 不声称已生成、听取或选定音色 |
| 已有音频文件未试听 | 已确认文件提供且可访问 | 不声称已听过音质或已完成辨识度核验 |
| 已授权执行样本生成 | 据真实回执记录产物路径与可见结果 | 不把提示词调用冒充成已通过试听 |
| 已试听并获用户选定 | 记为当前选定声音参考 | 不伪造未提供的平台 voice ID |
| 可供下游正式引用 | 说明真实可访问文件、内部映射或已核平台标识及调用方式 | 不保证跨段波形级绝对一致 |

以上来源说明、实体绑定、使用 P 与尚无真实音频参考等阶段信息**一律放于声线提示词代码块外**，块内只保留真正塑造目标听感的指令（已知工具接口确需的机器输入参数按该契约另传）。

---

## 5. 实听返修快速定位

收到真实试听样本偏差时，**绝不盲目追加抽象形容词**，先定位最早断点做精准精修并锁住已成立的主锚点：
- **落入安全平庸播音腔**：强化唯一高辨识声纹记忆钩子与日常说话呼吸底色，删除笼统好听、标准、有磁性等均值词；
- **情绪飘忽或常态失真**：核查是否把激烈台词或单场情绪塞进了声线提示词，彻底拆离常态音色与试音文本；
- **人声发糊、混响偏重或词义打架**：收紧单一干净近场呈现，消解互相拉扯的修饰项，删冗余留主次。
