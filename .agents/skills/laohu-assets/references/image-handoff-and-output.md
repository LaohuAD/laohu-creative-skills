# 图片提示词交接与固定输出

本文件是视觉资产基础方向字段、按需精控扩展、类别画幅、视图数量与图像质量的唯一真源。由[资产主文](../SKILL.md)在正式留存前读取，随后返回资产设计；明确要求四窗时，内部选择模块也必须回到本文件采用布局与成像保护，不另建平行表。正式视觉资产的创作/修改通常继续编译为完整图像提示词，用户明确只要候选、规格或诊断时才停止在该层。完整提示词指独立可用，不等于每项细节都由文字预先固定；提示词交付不授权实际生成、编辑或保存图片。本文件只定义视觉字段，不承载音频、角色声线、试音文本或供应商 voice ID；稳定声音身份由[声音身份交接与完整提示词](voice-handoff-and-output.md)单独维护。

## 资产画面布局与独立提示词

资产主图默认单格、单一展示视点，不因“角色设定”或“需要复用”自动改成多视图。四宫格/四窗只在用户明确要求时使用；用户明确要求其他多视图或独立视角时照办。若关键身份锚点或功能关系确被主图遮挡且一个必要视图能解决，只增加该视图，不借机套用常规三视图/模型表。四窗是同一项资产的多个视图，不拆成四个资产 ID 或四种持续状态；按具体展示目的安排内容。

- **人物：**单格身份图用 3:4 画布、灰色简洁影棚背景与大面积柔光；微侧身坐在无扶手低靠背椅上完整呈现头脸、全身、双手和鞋。手或坐姿若遮住关键衣型/身材轮廓，就改站姿或其他更有用的姿势，不为保留模板损害识别。明确要求四窗时用 9:16 单画布，上排约三分之一放两个头肩视图（左窗为左侧低机位微仰、右窗为正面），下排约三分之二放全身正面与背面。上排面部清楚；下排若露出脸，保持自然肤色、平滑且不画五官，不模糊身体或服装。各窗统一人物身份、发肤、服装、主光方向、曝光和白平衡；换角度不要求阴影位置像素级一致。可沿用左臂自然下垂、右臂腹前弯曲且掌心向内、右脚略前、身体微前倾的源版站姿；若遮挡衣型、用户另有姿势要求或识别任务冲突，优先调整。
- **道具：**用户明确要求四窗时，从正面、侧面、背面、顶部等视面中选最能说明该实物结构/用途的四个；保持为同一件物品的各角度，不强求物理无缝拼接，也不把人物/服装展示限制套到道具本体。未要求四窗时仍用单视图。
- **场景：**用户明确要求四窗时，可先用入口主视、左侧视、对侧低位和鸟瞰四个视点；按任务调整但所有窗口共享同一世界空间中的门窗、通道和固定物关系，不把屏幕左右固定误当空间坐标。不要默认加入人物/背影，也不要求四个视点拼成物理无缝场景。未要求四窗时仍用一张空间主视图。
- **服装：**默认 16:9 无人物整套平铺。用户明确要求四窗时，在同一 16:9 画布分区展示同一套搭配的整体与有用局部；局部必须来自同套服装，不引入人物、人台或另一套搭配。未要求四窗时仍用单格整套图。

四窗不是四个对象，也不是自动比较多个状态；状态变体仍绑定实际基础资产并按真实范围单独判断。提示词须保持完整独立：每件资产的代码块都写入本项需要的共同风格、主辅/强调色关系、材料、光线、视图布局和质量约束，不用“同前文/同全片”。同作确有共享视觉关系时，逐条提示词带上适用关系和本项自身锚点，不强制新建风格 ID 或台账；小改不重做整套风格。

### 同作色彩方向

正式设计多个需要共享视觉关系的同作资产时，即使用户没有索要色卡，也要把有用的共同色彩方向设计出来并落实到相关资产：先根据已定媒介与目标气质，判断主色承担的整体基调、辅色如何连接对象/空间/材料、强调色是否有明确识别或引导职责；再看明暗对比、相对冷暖及材料的反射/透光与细节尺度，决定哪些关系可共享、哪些要随人物身份、物件用途或场景功能变化。把实际选择写进现有色彩与材质字段及相关提示词，不只写“有统一美感”；不把颜色冷暖固定映射成情绪或善恶。色卡是可按用户要求交付的展示资产，不是共同配色设计的前提；HEX 与面积比例可作为设计值，不能冒充从图像测量所得。实际色卡图缺席时，不声称已取样得到精确颜色。色卡按平面信息图处理：纯白底、不用 3D 立体或投影，带文字的完整交付与实现核验按下文“图片交接与固定输出”执行。人像肤质、金属反光、平面色卡等不同对象的质量要求按各自媒介选择，不共用一套负面词或灯光模板。

### 成像质量控制按对象分支

清晰先由轮廓、形面和材料差异建立，不靠微细节堆积或一套通用负面词。每项提示词先写本对象、本部位实际需要呈现的成像结果，再写针对该处可能失真的限制；形容“精致、干净、清晰”不能代替可见结果。减少无用途随机噪点/重复高频脏纹与避免过度锐化是不同控制：前者针对随机颗粒或重复纹理，后者针对过度锐化造成的轮廓硬化、白边/黑边、光晕、锯齿或不自然微反差；按各自问题表达，不为去噪抹掉结构，也不把正常锐化一概禁止。同一资产处于同一既定光照情境的多个视图，应协调曝光、白平衡与主要光源语境，避免材质或色彩读法漂移；保持相应的世界光源语境，但不要求所有资产使用同一灯光，也不要求各视图的阴影或反光像素完全一致。若视图确实对应已定的剧情时间或状态变化，按该变化处理；不因多视图本身擅改时间或状态。

- **人物：**保留既定肤色与妆造；按写实、插画或 3D 媒介调整纹理强度。需要连续明暗的风格里，让亮部、中间调至暗部自然衔接，避免灰褐脏块、脸部阴影偏色和色阶断层；用柔和补光打开暗部但保留面部体积。控制额头、鼻梁等易亮部位的反射，避免点状油光、死白或蜡塑感；也不靠过度磨皮抹掉有用的自然肤质。眼部高光及嘴唇纹理/光泽按角色与媒介需要保留，不把摄影毛孔强加给所有 3D 角色。头发从发根形成连贯发束与发流，避免浮丝、断裂或发根脱离。
- **动物：**按媒介安排毛发或羽毛的大束关系、生长方向与必要边缘细节；细毛主要用于轮廓和近景，不在全身平均铺成噪点。有岩甲、鳞片等大块结构时，先保住块面和轮廓，细纹从属于主要形体，不用一套锐利微纹同时描绘毛发与硬甲。深色毛发保留暗部层次，不叠随机杂色；抑制噪点时仍保留毛束形体，不把毛面降噪成橡胶质感。
- **道具：**让主轮廓、结构接缝和主要材料可辨。金属反光应有形状且服务体积，不一律磨哑或铺成平面；透明罩保留通透的内外关系与可读边缘，不糊成不透明亮块；晶体以主要断面和棱面建立形体，微小闪点不盖过主面。保留用户或剧情已定的磨损、污迹、裂口等状态，不额外造损伤。
- **服装：**先让剪裁、衣片关系和大褶皱支撑轮廓与穿着状态，面料细纹在当前视距内从属呈现；避免重复高频纹理、摩尔纹和颗粒噪点吞没版型。不把金属饰件、亮面材料或已定纹样一概压成哑光/平涂。
- **场景：**大面积墙面、柜体与地面保持各自色调连续，不出现无依据的斑驳杂色或色阶断层；冷暖光分别落在实际受光区域，不把综合色面混成灰褐。夜景或其他暗调仍保留必要的明暗层次与可辨结构，亮处保留材料和形状而不过曝成死白；接触阴影、反射和投影方向互相成立，避免零碎脏斑或随机纹理冒充使用痕迹。整体可以按作品需要保持暗调、高调、粗粝或非写实，不强加明亮或摄影写实。
- **平面色卡：**沿用上节的纯白底、平涂色块与准确排版要求，不加渐变、3D 体积光或投影；不套用人物肤质、金属反光或场景照明控制。

四窗内若有区域性差异，把“某窗脸部清晰”或“某窗不画五官”等条件明确绑定到对应视图；整体清晰度和通用负面词不得覆盖局部要求。也不要以修正一处局部为由统一美白肤色、禁止 CG、取消金属反射或抹掉用户指定的暗景。

## 先定方向，再判断是否锁定细节

首次探索先明确对象类别、用途和目标感受，再按能否改变设计选择人物/时代适配、宏观轮廓或搭配、色彩关系、材质倾向与展示方式，不逐格全填。方向必须有具体选择，例如“宽松直身、燕麦白配雾蓝、柔软哑光棉料”，不能退成“好看、有质感、随便生成”。服装类型、配饰款式和材质也可作为宏观选择；“雍容华贵”“复杂雕刻纹理”等概括审美词与对象、用途相配时有效，不必逐个拆成工程细节，示例不构成固定词表。用户未描述方向时按上下文主动给出一致选择。

不默认逐项指定领口厘米数、缝线、每个扣件、纹样精确位置或空间XYZ表；这些普通局部交给模型在方向内补足。

只有以下条件之一成立才展开对应精控字段：用户明确要求精细控制；已有被用户接受或选定的资产需复现；剧情识别、物理功能或跨视点复现离不开该细节。只锁影响目标的部分，不把一个关键标记扩成整件物品的工程规格。用户选定图片后，从实际图中提取需保持的身份锚点及细节；图片不可见时不能声称已提取。助手前轮提出但尚未获接受的建议不自动成为锁定资产。

事实、用户约束、已接受资产和本轮设计建议在分析中分清。最终方向连贯呈现，不逐项贴“设计补充”，也不称用户已定下未确认细节。真实人物、地点、产品的未知事实不编造。修改已有选定资产保留原ID与未授权部分；开放探索不伪造历史锁定项。

纹样默认决定有无以及几何、植物等大类形态和与底色的关系，允许局部形状、排布和肌理自然形成。精控条件成立时才写部位、方向、尺度、密度和颜色；没有装饰需求不补花纹。细节特写可放大模型在主图自然形成的结构或材质，但必须对应同件物品，不借此强迫先设计复杂花纹。

首次设计正式资产、且需要作出宏观审美或形式选择时，按对象角色选一项具体方法，再回到本文件形成资产规格：人物的可辨身份、体态和表情/环境关系，读取[内容与观看](../../laohu-image/references/image-content-and-viewing.md)中人物相关方法；服装、道具与场景的用途、整体形态和材料关系，读取[以设计方向组织服装、道具与空间](../../laohu-image/references/light-color-and-style.md#以设计方向组织服装道具与空间)；为阅读而设计的界面、专用图形或关系图，按真实信息任务读取封面的[视觉层级与引导](../../laohu-cover/references/visual-hierarchy.md)、[图形关系与连线](../../laohu-cover/references/relationship-diagrams.md)或[版面与中文排印](../../laohu-cover/references/layout-typography.md)。不得把所有方法机械套给每类资产。

可复用的审美依据须具体到一项可辨视觉作品/页面单元或创作者实践。设计传统/专业规范可以约束技术、阅读和媒介；只有当它本身包含可辨的实际作品单元或创作者具体实践，说明其适用语境，并足以指导本资产的关键审美安排时，才可作为成熟审美参照。一般可读性、层级、色调或标准数字，以及不含上述具体实例的可执行规范，都不能单独替代关键审美取法；只有“好看、高级、完整”、构图主次或色调等宽泛词也不足以作取法。把方法转成当前对象的身份轮廓、功能结构、空间锚点、色材关系或阅读展示决定，并保持普通细节开放。若本地方法仍不能解决会改变资产方向的关键选择，或用户明确要求看真实设计找方向，读取[真实作品研究方法的日常创作取法与方向](../../../../references/exemplar-study.md#日常创作取法与方向)寻找相称的具体作品/实践，再把证据带回资产字段；日常取法不等于正式评分，不读共用 Reference 的正式评估部分。候选盘点、已有身份复现、状态差异编辑和单项修改不触发新的审美研究，也不重置已接受设计。这是读取专业 Reference，不表示执行图片入口或获得生图授权。

## 基础方向字段

候选仅记名称、出现范围、证据和复用状态，不分正式ID。正式资产按下面各类选择真正有作用的方向即可；不相关项省略，不强行填满“无”。同一件资产的主关系能在短段落说清时无需拆成大量字段。

同作多项资产确有共同设计关系时，把适用的关系和每项自己的用途/识别锚点写进现有字段：通常落在“用途与方向”“主要形态与关系”“色彩与材质倾向”“识别与保持项”中的一项或几项，不新增强制风格 ID、全局台账或成组拼图。只选本作实际需要的媒介、时代、地域、材料、形体、色彩或功能关系；不要求每类资产都填同一组维度，也不让展示用的灰棚、平铺或参考光线变成剧情风格。场景/人物/道具/服装仍按各自真实职责写具体关系。

### 人物

人物完整身份不因成片第一视角而缩成手部。规格包括：

- 身份与范围：名称、ID、故事作用、年龄与性别呈现、人物关系。
- 可视性格：一两项有材料依据的体态、目光或行动习惯。
- 身体与面貌：体型比例、脸部轮廓与足以辨认的五官特点、发型发色、肤色肤质及必要识别锚点。保留已选身份，不逐项制造瑕疵。
- 妆造与默认搭配：妆容、发饰/配饰选择；上装、下装或裙装、鞋袜的宏观轮廓、色彩和材质倾向。人物身份完整不意味着衣服局部全部精控。
- 依赖与展示：服装/状态归属；人物图默认灰色简洁影棚柔光、微侧身坐在无扶手低靠背椅上，全身、双脚和面部清楚，双手不遮关键衣物。用户方向优先，坐姿遮挡身份时换合适姿态。

### 道具

- 身份与范围：ID、具体物件类别、用途、持有人/所在地点。
- 宏观外形：整体轮廓、大小感、支持用途的主要组成与连接关系。
- 外观方向：色彩、材质倾向、目标质感和纹样大类或无纹。
- 识别与状态：已有或剧情必要的身份锚点、常态及持续变化依赖。
- 展示：完整本体及关键结构，简洁背景；默认不出现持有人、手部或剧情动作。明确操作示范时才加入必要使用关系。

先保证物件能工作且可辨认。只有用户明确要求精控、复现已选物件，或剧情/功能要求某尺寸、机构、公差或标记位置以便辨认、操作或连续复现时，才给出相应实值；普通杯子只写大小感和可见主要结构，不预设工程图。

### 场景

- 身份与范围：ID、地点类别、时代、用途、室内/室外/半开放。
- 主空间关系：大小感、入口/邻接、主要通道、少数关键固定物相对位置；动作所需路径须成立。
- 观看与氛围：目标感受、宏观构图、主要色彩、材质倾向、主要光源与时间天气。
- 连续性：被选定空间或剧情必需的稳定锚点；临时布置与固定关系分开。
- 展示：空间、固定设施和必要陈设，不自动加剧情人物。只展示当前视点实际可见的内外关系。

有边界或会复用不自动触发 XYZ。只有用户明确要求空间工程，或精确跨视点复现必须依赖固定距离、入口净空、通道宽度或设施落点时，才展开下面的精控扩展；普通场景用入口、通道和固定物的相对位置表达，不补无用坐标。

### 服装

- ID、所属人物、真实穿着范围与用途；人物绑定是文字元数据，不要求图中出现人物。
- 整套搭配：上衣/内搭/外套、下装或完整裙装、鞋袜及实际配饰的宏观轮廓与层次，适合穿着者和时代。
- 视觉方向：目标感受、主辅色彩、材料厚薄/软硬/光泽倾向，纹样有无与大类形态。
- 连续性：已选定或剧情必要的套装识别点、基础状态及独立变化。
- 展示方向：16:9横幅整套平铺及有用的局部放大；只有关键部件需要精控时才写局部精确规格。

**默认服装图：**主区域完整平铺衣物、鞋袜和实际配饰，各层错开，不互相遮挡关键轮廓；辅助区域放大同件衣物有价值的材料、结构或纹样。整体优先，局部不可变成另一款式。画面不出现人物、人体局部或人台。简洁中性底面，光线显出材质。没有花纹也可展示自然形成的领袖口或面料，不为凑特写加装饰。只有用户明确要上身效果、试穿或人物穿搭参考时才使用已有角色展示，标明该用途。明确只要单件时按单件范围。

### 状态与特殊界面

状态写ID、基础ID、真实范围、改变项、保持项与起止/复原条件；未知端点标待核，不扩成全剧。持续衣物变化优先绑定服装，缺独立服装ID时绑定人物并写所指穿着。普通衣褶、表情和瞬间动作不自动变成长效资产。状态展示沿基础类别：服装仍平铺，道具仍本体，场景仍空间。场景视角状态的画面只体现观察位置、观看方向和必要取景变化，并保留已知空间身份锚点；基础ID与范围在提示词块外。参考图编辑按可见内容说明要改与要保持之处；完整提示词合入已知基础关系和本次授权变化，但不强迫复述图中不可见/被遮挡的原貌，也不能把未知处写成已确认结构。

界面写独立职责、所属设备/场景、范围、主要信息区、色彩与交互状态；准确文案逐字保留，依可靠排版合成保证可读性，不押给生图。确需复用时再锁网格、字体字号等，实体设备与屏幕内容分开。

## 精控扩展（仅在触发条件成立时填写）

先说明哪项已接受约束、用户要求或剧情功能使精度必要，然后只展开该部分：

- 人物：选定脸貌、独特非对称特征、实际可见的发肤或妆造锚点；保持身份，不把每个毛孔当锚点。
- 服装/道具：关键部件的结构、比例、纹样所在部位、尺寸/方向/颜色，既有参考图中的对应位置。若真实资料缺失则待核。
- 场景工程：统一单位、稳定原点与XYZ轴、必要固定物定位点/尺寸/朝向/开启区域和通道净空。米制室内可取入口门槛中心为原点，+Y向内、+X向进入者右侧、+Z向上。落地物定位若取地面投影则Z=0；壁挂件/灯具取实际中心高度。门扇写铰点与扫掠区域，核对家具及路线冲突。坐标必须转换成当前视点的前后、左右与遮挡；文字不保证图像严格复现；精确制作时配实际布局参考或三维场景。
- 状态：变化的准确位置、范围、程度及与基础图的对应；不重设未变部分。

## 图片交接与固定输出

将正式资产规格交给 `laohu-image` 的真实图片方法，供本 Skill 把设计编译成可直接使用的完整提示词；用户只要候选、规格或诊断时才在该层停止。编译按资产逐项进行：先从用户要求和本字段真源确定当前资产的视图/版式与所需交付，再把该布局和相应身份、依赖、空间/功能关系写进本项独立提示词；对照本项实际布局、必要字段与请求交付核实无缺后，才处理下一项，最后核对全范围、顺序和所有附属交付。四窗始终是一项资产的多个视图；多个资产各自的四窗不能替换成一张“每项占一窗”的跨资产总览。只有用户另行要求跨资产总览时才增加该总览，且不得因此省略各项已要求的独立提示词/展示。交接方向与用途、ID/范围/依赖、基础身份、用户锁定项及依据、允许开放的局部、类别展示方式和本轮改动；正式规格继续使用既有用途/形态/色材字段，不套用或复制整组资产字段表。

在已授权的逐P资产任务中，完整源稿、已采用的 P、初步镜头概要和既有资产共同提供理解上下文。交付时另列关系清单，字段为正式 ID、类别、实际使用 P、基础依赖及故事顺序中的实际状态位置，并逐P列出该段实际调用项；关系清单整体放入一个独立可复制代码块，标题和必要解释可在块外。然后每项正式资产只交一份完整、独立提示词，不按 P 重复生成同一资产；每项提示词各用一个独立可复制代码块，不将共享资产按 P 复制。共用/单P标注使用范围，不增加资产类别；单P对象只有确需独立设计、辨认或调用时才作为正式资产，瞬时动作仍属于镜头画面内容。若用户只给局部材料，关系清单和提示词也只覆盖该局部。以上交接增补不替代本 Reference 既有的类别设计字段、成像质量控制、画幅/视图布局、局部变化完整返回或图片生成/编辑/保存授权要求。

提示词块外仅列交付所需的标题、ID、真实范围、基础依赖及内部作品名等元信息。块内写下游模型确实能执行的内容：故事内专名或画外目的若没有材料支持的可见指代，不把名称当成视觉信息；改写成已知可见对象、外观和关系，无法落到画面时省略。真正具有视觉指示作用且对当前任务适用的成熟风格参考作品名可以保留，不把“未知专名不传给模型”扩大成全面禁用名称。

块外元信息也承接本次设计的来源与实现状态，例如外观是新提案而非既有设定、色值不是从现图取样、图片尚未生成或验证。模型仍须收到本次要呈现的完整视觉方案及执行细节；获准的画内标题、色名、HEX 和说明文案按色卡固定格式逐字放入提示词块。不要因内容带有“提案”等词就删掉它实际需要生成的指令或可见文案。

用户索要色卡时，默认交付一份带文字的完整色卡制作提示词，放在同一个独立代码块中：写明画幅、纯白平面底、色块布局及目标色值，同时逐字纳入画内标题和每块对应的色名、HEX、用途；有依据的比例或百分比按任务加入，不额外编造。说明标题与注释的位置、阅读顺序、文字对比和与各色块的对应关系；不把必要文案只留在块外，也不默认要求生成无字底图、让用户再拼另一份标签清单。只有用户明确要求无字底图或分步制作时才按其要求拆分。文字准确性与交付完整性分开：制作时须核对字形、色值及文字—色块配对，需要可靠文字层/合成时也保留同一完整制作输入，不以技术路线删掉画内文字或拆散交付；尚未成图时不得声称文字、色值或排版已实现。

修改既有资产只改变授权属性，但默认返回合并已知基础特征、当前变化及保持项的完整提示词；用户明确要求只给差异/补丁时才采用差异提示。附带参考图时，可依据可见内容说明改变/保持，并在完整提示词中写出已知的基础关系与目标变化；不要求臆测或重述不可见/被遮挡的原貌，不把未知处说成确认结构。以上不增加新的必填资产字段或全局台账。把希望目标观众从最终画面辨认的线索和预期观看价值写成设计目标；提示词、规格或制作端理解不等于图片已生成或实现目标。不得把助手未确认建议升级为锁定约束；不能为“更漂亮”改掉已接受身份。图片生成、编辑或保存另需明确授权。

输出按人物→道具→场景→服装→状态→其他排序，空类别省略。基础模板为：

```text
<ID>｜<名称>
适用范围：<实际范围>
归属/基础依赖：<服装写所属人物；状态写基于>
用途与方向：<对象、人物/时代适配、目标感受>
主要形态与关系：<类别所需宏观轮廓/搭配/空间主关系>
色彩与材质倾向：<有依据的具体方向>
识别与保持项：<已接受/剧情必要部分；首次探索不虚构锁定>
展示方式：<对应类别整体与必要局部>
精控扩展：<仅条件成立时写；否则省略>
```

人物另覆盖完整身体、脸貌、发肤与可视性格；服装无需人物脸貌。可用连贯段落承接，不强制逐个空字段。提示词每项置于独立可复制代码块，ID/范围/依赖在块外。完整提示词独立可用但保留普通细节生成空间；编辑默认合并为完整提示词，只有用户明确要差异/补丁时才仅写变化和保持。提示词不表示图片已经生成、编辑、保存或验证；检查成图时按实际可见线索判断它对设计目标的支持程度，没有真实受众反馈时，不把预期感受写成实际受众反应。

交付检查：对象和用途明确、主关系可见；精控有触发依据；未把普通细节开放误写成无方向；已选身份受保护；服装平铺与必要特写来自同件对象；坐标未被当作所有场景的默认作业；未把未接受建议声称为用户锁定；每条提示独立可用且不夹资产ID。
