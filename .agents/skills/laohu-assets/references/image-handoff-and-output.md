# 图片提示词交接与固定输出

本文件是资产基础方向字段、按需精控扩展和类别展示的唯一真源。由[资产主文](../SKILL.md)在正式留存前读取，随后返回资产设计；已获图片提示词授权时再交给图片 Skill。基础方向须足以制作，局部细节允许模型补足；完整提示词指独立可用，不等于每项细节都由文字预先固定。

## 先定方向，再判断是否锁定细节

首次探索先明确对象类别、用途和目标感受，再按能否改变设计选择人物/时代适配、宏观轮廓或搭配、色彩关系、材质倾向与展示方式，不逐格全填。方向必须有具体选择，例如“宽松直身、燕麦白配雾蓝、柔软哑光棉料”，不能退成“好看、有质感、随便生成”。服装类型、配饰款式和材质也可作为宏观选择；“雍容华贵”“复杂雕刻纹理”等概括审美词与对象、用途相配时有效，不必逐个拆成工程细节，示例不构成固定词表。用户未描述方向时按上下文主动给出一致选择。

不默认逐项指定领口厘米数、缝线、每个扣件、纹样精确位置或空间XYZ表；这些普通局部交给模型在方向内补足。

只有以下条件之一成立才展开对应精控字段：用户明确要求精细控制；已有被用户接受或选定的资产需复现；剧情识别、物理功能或跨视点复现离不开该细节。只锁影响目标的部分，不把一个关键标记扩成整件物品的工程规格。用户选定图片后，从实际图中提取需保持的身份锚点及细节；图片不可见时不能声称已提取。助手前轮提出但尚未获接受的建议不自动成为锁定资产。

事实、用户约束、已接受资产和本轮设计建议在分析中分清。最终方向连贯呈现，不逐项贴“设计补充”，也不称用户已定下未确认细节。真实人物、地点、产品的未知事实不编造。修改已有选定资产保留原ID与未授权部分；开放探索不伪造历史锁定项。

纹样默认决定有无以及几何、植物等大类形态和与底色的关系，允许局部形状、排布和肌理自然形成。精控条件成立时才写部位、方向、尺度、密度和颜色；没有装饰需求不补花纹。细节特写可放大模型在主图自然形成的结构或材质，但必须对应同件物品，不借此强迫先设计复杂花纹。

在首次设计服装、道具或场景，需要选择宏观审美与形式方向时，按需读取[以设计方向组织服装、道具与空间](../../laohu-image/references/light-color-and-style.md#以设计方向组织服装道具与空间)，取得对象、用途、材质和整体形式如何共同定向的方法，再回到本文件形成资产规格。这是读取专业Reference，不表示执行图片入口或获得生图授权。

## 基础方向字段

候选仅记名称、出现范围、证据和复用状态，不分正式ID。正式资产按下面各类选择真正有作用的方向即可；不相关项省略，不强行填满“无”。同一件资产的主关系能在短段落说清时无需拆成大量字段。

### 人物

人物完整身份不因成片第一视角而缩成手部。规格包括：

- 身份与范围：名称、ID、故事作用、年龄与性别呈现、人物关系。
- 可视性格：一两项有材料依据的体态、目光或行动习惯。
- 身体与面貌：体型比例、脸部轮廓与足以辨认的五官特点、发型发色、肤色肤质及必要识别锚点。保留已选身份，不逐项制造瑕疵。
- 妆造与默认搭配：妆容、发饰/配饰选择；上装、下装或裙装、鞋袜的宏观轮廓、色彩和材质倾向。人物身份完整不意味着衣服局部全部精控。
- 依赖与展示：服装/状态归属；人物图默认灰色简洁影棚柔光、微侧身坐在无扶手低靠背椅上，全身、双脚和面部清楚，双手不遮关键衣物。用户方向优先，坐姿遮挡身份时换合适姿态。

### 道具

- 身份与范围：ID、具体物件类别、用途、持有人/所在地点。
- 宏观外形：整体轮廓、大小感、支持用途的主要组成与连接关系。
- 外观方向：色彩、材质倾向、目标质感和纹样大类或无纹。
- 识别与状态：已有或剧情必要的身份锚点、常态及持续变化依赖。
- 展示：完整本体及关键结构，简洁背景；默认不出现持有人、手部或剧情动作。明确操作示范时才加入必要使用关系。

先保证物件能工作且可辨认。只有必要时补实际尺寸、机构、公差或标记精确位置；不要为普通杯子预设整张工程图。

### 场景

- 身份与范围：ID、地点类别、时代、用途、室内/室外/半开放。
- 主空间关系：大小感、入口/邻接、主要通道、少数关键固定物相对位置；动作所需路径须成立。
- 观看与氛围：目标感受、宏观构图、主要色彩、材质倾向、主要光源与时间天气。
- 连续性：被选定空间或剧情必需的稳定锚点；临时布置与固定关系分开。
- 展示：空间、固定设施和必要陈设，不自动加剧情人物。只展示当前视点实际可见的内外关系。

有边界或会复用不自动触发XYZ。只有用户明确要求空间工程或精确跨视点复现，且此精度确有必要时，才展开下面的精控扩展。

### 服装

- ID、所属人物、真实穿着范围与用途；人物绑定是文字元数据，不要求图中出现人物。
- 整套搭配：上衣/内搭/外套、下装或完整裙装、鞋袜及实际配饰的宏观轮廓与层次，适合穿着者和时代。
- 视觉方向：目标感受、主辅色彩、材料厚薄/软硬/光泽倾向，纹样有无与大类形态。
- 连续性：已选定或剧情必要的套装识别点、基础状态及独立变化。
- 展示方向：16:9横幅整套平铺及有用的局部放大；只有关键部件需要精控时才写局部精确规格。

**默认服装图：**主区域完整平铺衣物、鞋袜和实际配饰，各层错开，不互相遮挡关键轮廓；辅助区域放大同件衣物有价值的材料、结构或纹样。整体优先，局部不可变成另一款式。画面不出现人物、人体局部或人台。简洁中性底面，光线显出材质。没有花纹也可展示自然形成的领袖口或面料，不为凑特写加装饰。只有用户明确要上身效果、试穿或人物穿搭参考时才使用已有角色展示，标明该用途。明确只要单件时按单件范围。

### 状态与特殊界面

状态写ID、基础ID、真实范围、改变项、保持项与起止/复原条件；未知端点标待核，不扩成全剧。持续衣物变化优先绑定服装，缺独立服装ID时绑定人物并写所指穿着。普通衣褶、表情和瞬间动作不自动变成长效资产。状态图沿基础类别展示：服装仍平铺，道具仍本体，场景仍空间。场景视角状态的差异只写观察位置、观看方向和必要取景变化，并保持基础空间身份锚点；基础ID与范围在提示词块外。参考中不可见的区域不补写为已确认结构。

界面写独立职责、所属设备/场景、范围、主要信息区、色彩与交互状态；准确文案逐字保留，依可靠排版合成保证可读性，不押给生图。确需复用时再锁网格、字体字号等，实体设备与屏幕内容分开。

## 按需精控扩展

先说明哪项已接受约束、用户要求或剧情功能使精度必要，然后只展开该部分：

- 人物：选定脸貌、独特非对称特征、实际可见的发肤或妆造锚点；保持身份，不把每个毛孔当锚点。
- 服装/道具：关键部件的结构、比例、纹样所在部位、尺寸/方向/颜色，既有参考图中的对应位置。若真实资料缺失则待核。
- 场景工程：统一单位、稳定原点与XYZ轴、必要固定物定位点/尺寸/朝向/开启区域和通道净空。米制室内可取入口门槛中心为原点，+Y向内、+X向进入者右侧、+Z向上。落地物定位若取地面投影则Z=0；壁挂件/灯具取实际中心高度。门扇写铰点与扫掠区域，核对家具及路线冲突。坐标必须转换成当前视点的前后、左右与遮挡；文字不保证图像严格复现，精确制作应配实际布局参考或三维场景。
- 状态：变化的准确位置、范围、程度及与基础图的对应；不重设未变部分。

## 图片交接与固定输出

已授权资产与图片组合或明确需要提示词时交给 `laohu-image`：方向与用途、ID/范围/依赖、基础关系、明确锁定项及其依据、允许模型补足的局部、类别展示形式、完整或差异模式。不得把助手未确认建议升级为锁定约束；不能为“更漂亮”改掉已接受身份。

输出按人物→道具→场景→服装→状态→其他排序，空类别省略。基础模板为：

```text
<ID>｜<名称>
适用范围：<实际范围>
归属/基础依赖：<服装写所属人物；状态写基于>
用途与方向：<对象、人物/时代适配、目标感受>
主要形态与关系：<类别所需宏观轮廓/搭配/空间主关系>
色彩与材质倾向：<有依据的具体方向>
识别与保持项：<已接受/剧情必要部分；首次探索不虚构锁定>
展示方式：<对应类别整体与必要局部>
精控扩展：<仅条件成立时写；否则省略>
```

人物另覆盖完整身体、脸貌、发肤与可视性格；服装无需人物脸貌。可用连贯段落承接，不强制逐个空字段。提示词每项独立代码块，ID/范围/依赖在块外。完整提示词独立可用但保留普通细节生成空间；差异提示只写变化和保持，只有用户明确要从零或完整成品时才合入基础方向。提示词不表示图片已经生成、保存或验证。

交付检查：对象和用途明确、主关系可见；精控有触发依据；未把普通细节开放误写成无方向；已选身份受保护；服装平铺与必要特写来自同件对象；坐标未被当作所有场景的默认作业；未把未接受建议声称为用户锁定；每条提示独立可用且不夹资产ID。
