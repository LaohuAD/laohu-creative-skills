# 身份连续性与变体

统筹同作多项资产的共同语言与组内区分、校验 3–5 条稳定视觉指纹、裁定变化是否升格为持续变体，或核对多视角资产防漂移口径时，由 [laohu-assets 主文](../SKILL.md) 读取本文件。单件独立设计且无持续变体或跨对象混淆风险时无需加载。

---

## 1. 理清三层关系：共同语言、组内区分与跨变连续

这三者各司其职，不能互相替代：

1. **同作共同语言（把世界粘在一起）**：先确认哪些对象确属同一作品、时代、地域与媒介语境，再提炼共享的视觉母题、形体概括、色彩气候、材料温度与光影质感，落进各自规格与独立提示词（人物/道具的中性展示底面与展示光是工作棚预设，不属于剧情世界风格）。
2. **组内个体区分（防同框撞脸）**：只对比会同场出现、并列制作或存在真实混淆风险的对象。把差异落到各自岗位与用途支撑的具体轮廓、头身比例、体态重心、功能接口或空间拓扑上，不靠空洞结论词敷衍；**剧本要求一致的制服、同款或刻意伪装照实保留**，不为显得丰富擅自破坏设定。
3. **同一实体跨变连续（换装换镜不换人）**：同一基础 ID 跨越不同场次、服装、视角与状态时，靠跨变化依然成立的物理身份锚点维持辨认，不把同作画风相同误当身份同一。跨 P 共享实体只登记、设计并编译一次；P 只是下游制作分段，不等于单一故事日、单一地点或恒定状态，中途变化按真实来源场次标出节点。

## 2. 视觉指纹承压检验（基础身份留什么）

基础资产只收录**剥离单场剧烈剧情态后仍能跨场景认出同一实体的本质特征**，不把单场临时哭笑、瞬时动作、临时持物或偶发污损焊进恒定身份；**但完整保留角色一辈子养成的习惯重心、眼神底色、劳作痕与穿衣癖好**。

- **选 3–5 条高信息量物理指纹**（简单物件按足以辨认的数量取用，已有接受项优先），写清位置、形状与相对比例：
  - **人物**：脸型骨相与眉眼特征、发形轮廓与发际特征、体型头身比、惯常重心体态及固定胎记/旧疤（全身完整规格字段与板式见 [image-handoff-and-output.md](image-handoff-and-output.md#人物)）。
  - **道具**：核心外形轮廓、主要功能连接与接口、固定铭刻或反映主人脾气的长期修补/改装印记。
  - **场景**：入口位置、主要通道、不可移动的固定设施与相对拓扑（不把临时摆件混为固定空间锚点）。
  - **服装**：绑定穿着者的一整套剪裁轮廓、主辅色块、面料质感与实际鞋袜配饰（服装归属是文字元数据，默认仍无人体平铺展示）。
- **过四关承压测试**：把候选指纹逐条放进**换装、换视角、进暗光、带磨损或持续状态**四种情形里检验。凡一换衣色、换表情或丢下随身小物就消失的特征，立刻移出基础身份指纹，降回对应造型或状态；多视角四宫格中须逐格核验非对称指纹的左右镜像一致性。
- **稳定声音身份的分层提醒**：声音身份与人物视觉外观各自独立绑定到同一角色实体（旁白可无肖像）。怒吼、耳语、疲惫等单句临场表演归 `laohu-video` 按句处理，不建新声线 ID；仅剧情确立持续嗓音变化（如长期失声、受伤恢复）且已获声音授权时，交 [laohu-assets-voice](../skills/laohu-assets-voice/SKILL.md) 与 [voice-handoff-and-output.md](voice-handoff-and-output.md) 处理。

## 3. 变化何时升格为正式持续变体

把观察到的变化对照基础资产拆出 **保持项 / 改变项 / 故事内生效与结束范围**（未知端点标待核，不擅自扩成全剧）。若变化需在后续多个画面持续保持或被下游独立调用，则建为绑定原基础 ID 的独立变体 ID（不重编或覆盖基础资产）；瞬时内容留在当帧画面：

| 观察到的变化 | 默认归属 | 升格为正式变体的条件 |
|---|---|---|
| 人物换新衣服 | 基础人物含默认穿搭，但衣服不是永久身份 | 该套换装需独立复用或专项设计时，建独立服装资产并绑定 `所属人物` |
| 衣物污损、淋湿或撕裂 | 优先绑定对应服装资产的状态；无独立服装 ID 时绑定人物并写明所指衣服 | 污损须在后续多镜持续保持或独立调用 |
| 一次哭笑、回头、抬手 | 单帧表演画面 | 持续身体变化（如包扎伤势、泥污、长期憔悴）跨多镜保持时建人物状态变体 |
| 道具开合、掉落瞬间 | 单帧动作画面 | 持续破损、缺件、变形或需跨镜保持的开启态，建绑定道具的状态变体 |
| 房间临时移椅或单镜光变 | 场景局部摆设或单镜布光 | 持续陈设改造、破坏或跨场持续天气，建绑定场景的状态变体 |
| 既有场景另做新观察机位 | 普通单帧机位归分镜画面 | 用户明确要求或已授权资产确需独立复用的单一新视角，建绑定基础场景的视角状态，只变观察点、方向与取景，锁死原空间锚点与已有物理状态 |

一次性变化若被用户明确要求单独制作，按其范围单次交付并注明仅适本次，不推定长期复用。编译状态变体继承基础资产的板式模式（默认四宫格，原为或明要单图则走单图），默认合并基础指纹、授权变化与仍适用的正向成像控制为**完整独立提示词**（用户明确只要差异补丁才交差异）；参考图不可见区域保持未知不臆造。

## 4. 四宫格与额外多视图的防漂移边界

默认情况下，人物、道具、场景基础资产已通过**一体化无缝四宫格**在一张画布内完成正、侧、背或四全景的跨视角防漂移锁定，且四宫格仍属于**同一项资产的同一状态，不拆成多个 ID**。在此之上，不默认叠加额外的传统三视图、T-pose 绑定表或白底工程排布；仅当用户明确指定其他多视图或特殊局部特写（或用户切换为单张静态图模式且主视点确有不可解的遮挡）时，才按需增补对应视图。具体画幅、默认四宫格规范与单格姿态唯一服从 [image-handoff-and-output.md](image-handoff-and-output.md#资产画面布局与独立提示词)。
