# 身份连续性与变体

当父级第三步归并后仍需判断稳定身份特征、持续变化或多视角规范时读取本文件；若第四步要首次设计同作多项资产，或把新对象与已有资产组对照以确定共同语言和个体区别，也在组级规格定稿前读取。Video 已采用 P 的全篇资产任务使用完整源稿、初镜与逐P候选对应作为上下文，不按每个 P 重做同一实体。产物是适用的共同关系、各项可辨锚点、基础身份、变体差异/范围与视图需求；读完返回父级第四步落实规格，必要时回第三步更新留存裁定。先稳住基础 ID，再判断变化是否值得分支。

## 同作语言、组内差异与身份连续

这三者是不同关系，不能相互代替：作品共同语言连接一组相关资产；组内差异区分不同对象；身份连续性则让同一个对象经过时间、视角、服装或状态变化后仍是同一项。只用本轮范围与可读的用户/剧本/已接受资产依据，不把规则推到未提供的内容。

1. **选共同语言。**先确认哪些对象确实共享作品、时代、地域、媒介/写实程度或功能语境，再从对当前设计有作用的维度中选择共同关系，例如形体、色彩、材料、制作感或用途。不是每一组都要用齐所有维度；灰色影棚、柔光或平铺是资产展示预设，不是剧中世界的风格要求。共同语言写入相关资产现有的用途、形态/关系、色彩/材质字段，不新设强制风格 ID、全局台账或组图。
2. **给各项具体化并作组内对照。**按每项在故事中的身份、职责与用途，把共享关系转成该项自己的具体轮廓、结构、色材、空间锚点或穿着选择；只比较同场使用、并列制作或实际可能混淆的对象。人物需看换装后仍能使用的脸部/身体比例、发形轮廓、体态或动作，不只靠衣色、道具或武器；道具区分具体功能结构、接口和已有标记；场景分别保留入口、通道、固定物与行动路径；服装在共同作品方向内按人物、时代和行动用途变化。最后逐项检查哪些字段造成混淆、哪些差异已有故事依据，并把判断写到字段，不停在“统一”“独特”等结论词。
3. **保持同一项跨变化。**比较的是同一基础 ID 在实际段落、视角和状态前后的稳定锚点，不要把“同作风格相同”当成身份依据。沿用已接受的设计和 ID；人物换装后保留身份线索，物件变化仍绑定同一实物，场景视点变化仍保留空间关系；只把有材料支持且需要后续保持/单独调用的差异记录为变体，并列明故事时序中的实际起止位置。P 是制作范围而非故事日、地点或单一恒定状态；若 P 跨场或中途改变，标出真实出现/变化位置，不将整段贴成同一状态。共用/专用只描述使用范围，不是新资产类别；单P对象若需独立设计、辨认或调用，可正式留存，瞬时动作/变化仍留在镜头内容。
4. **让完整规格和提示词各自可用。**正式规格在已有类别字段内写明本项需要的共同关系和本项自身识别锚点。正式资产通常继续编译为完整、独立可用的提示词；同作共享风格和色彩关系须在每项相关提示词中写明，不靠“同全片/见前项”。逐P统筹时同一资产只设计、列出并编译一次，逐P清单指向它在各段实际使用的位置，不按 P 重建同项。修改仍只改变用户授权项，但默认把已知基础特征、变化与保持项合成该资产完整提示词；只有用户明确只要差异或补丁时才仅写变化。不为了组内差异重设计用户已接受、剧本要求一致或故意相似的制服、同款、伪装等资产；局部编辑保护未授权项。

### 条件性创作实践

- 《Encanto》的创作团队说明，Julieta/Agustín 一支采用冷色/宝石色系、Pepa/Félix 一支采用暖色来帮助观众跟踪家族关系；Mirabel 的手工刺绣保留不完美感，Isabela 的服饰与房间运用哥伦比亚花节相关的花种与形式，角色也通过体态动作形成个体差异。可迁移的动作是先明确本作资产之间真实共享的关系，再把人物职责和选择落到各自轮廓、体态、面貌、服饰或色材等现有字段；不复制其家系冷暖安排、花卉刺绣或文化设计，也不把颜色当成性格/善恶规律。
- 《Raya and the Last Dragon》的 Kumandra 概念设计说明中，Namaari/Fang 的服装承接所属地域的色彩与几何形体语言；Raya 的衣形考虑行动用途，剧情变化影响防护层。可迁移的动作是按本作地域/功能关系组织共同服装语言，再依人物职责、行动及剧情变化选择个体形态与保护层；不把尖锐/方圆与道德性格作固定对应，也不照搬原设计。
- 当项目明确选择带手作感的 3D 形象时，可参考《Luca》创作团队保留绘制感、不过度追求物理写实模拟的实践；它只支持按已选风格控制形面与表面简化，不把该片画风设为默认。需要表现日常使用感时，可参考 RenderMan 的 *Creating a French Bakery* 创作实践，用轮廓、形色和局部变化传达生活痕迹，而不是铺重复的脏纹理；只在对象与目标相称时采用，不把做旧当成统一方向。

## 基础身份留什么

基础资产只收录跨适用范围仍能认出同一人物、物件或空间的线索，不把此刻的动作和状态写进恒定身份。挑选时问：换一个段落或使用场景，这条特征还成立吗？它是否能帮助下游认出同一项？

- **人物：**身份锚点由剧本或用户材料支持；完整展示时还要补齐人物底色的可视行为、身材体态、性别呈现、表情、发型发饰、肤质、妆容和从上衣到鞋袜的完整穿着，字段以[图片提示词交接与固定输出](image-handoff-and-output.md)为准。虚构角色信息不足时据情节、时代和方向补足完整身份，默认穿搭保留宏观方向与局部开放；现实人物不凭空补事实。默认是一张 3:4 单格灰棚柔光身份图，完整呈现全身；用户明确要求四窗时按[中央布局规格](image-handoff-and-output.md#资产画面布局与独立提示词)安排，其他明确视图请求也照办；只有关键身份锚点确被遮挡且必要视图能解决时才补视图，不自动套用常规模型表。
- **道具：**结构、材质、功能细节、独特标记和具体持有人关系；展示时默认完整物体置于灰色简洁影棚柔光中；开合、损坏、污渍等变化另判。
- **场景：**入口、通道、固定结构、相对位置和行动路径；先保持大小感、入口与关键固定物相对关系、材质色彩和光线；只有明确空间工程或精确跨视点复现且必要时才按中央规范展开XYZ、尺寸与净空。默认视点选择能读清空间拓扑的构图，按空间结构和用户方向调整。
- **服装：**剪裁、色块、材料、纹样有无及大类、配饰方向；已选或剧情必要时才锁纹样精确位置；服装资产写成绑定人物的一整套全身搭配并包含鞋袜，始终关联真实穿着时间；局部改衣时保留其余搭配。绑定人物不代表展示人物，服装独立图按中央规格采用整套平铺与必要细节；状态沿用其基础类别的展示形式。

虚构材料缺少外形细节时，在上下文、时代、身份、物理合理性和已确认方向内补齐当前视觉设计必需部分，最终写明方向，普通局部允许生成补足，不逐项标记“设计补充”；真实人物、地点或产品的未知事实写待核，不靠创作补全。待核不要求用户逐项确认；只有身份、空间或核心方向歧义会改变留存/设计结果时再询问。人物、场景、道具的字段模板和提示词交接由中央固定输出文件维护，本文件只处理身份连续性与变体。屏幕设备的实体与屏幕内容分开判断；身份尚未确认时，不能用视觉设计把两个人强行合成一个角色。

### 角色声音身份的绑定与持续

仅当用户明确要求稳定角色音色/旁白声线，或授权本轮声音资产范围时，才判断声音身份与人物实体的绑定；剧本里有对白、当前情绪变化或耳语不自动产生新声音资产。人物实体、视觉资产、稳定声音身份、单句表演和实际音频文件是不同层级：同一人物可分别绑定视觉资产和可复用声音身份，旁白声音身份也可不绑定肖像。沿用已有实体标识；确有复用管理需要时才为声音身份单独标识，实际文件名和供应商 voice ID 不能替代内部资产身份。

跨 P 保持的是经确认的声音身份及其辨认锚点，不是固定某种情绪或每句都同一力度。角色的愤怒、耳语、疲惫、临场语速变化属于表演/发声层，不另造声音 ID；由 Video 按句落实。只有源稿或用户确立了会持续影响发声的剧情状态（如持续失声、嗓音受损、恢复过程）时，才记录其实际形成、延续、改变及适用范围，并交 Assets voice 专项判断继承关系；不把短暂表演状态升级成长期资产变体，也不把视觉状态子级当作声音规则真源。声音身份的可听特征依据用户/可读参考和角色用途设计，不从性别、体型、面貌或人格标签直接推定。

## 变化何时升为变体

将变化对照基础资产，逐项写出“保留项 / 改变项 / 生效范围”。若变化在多个后续画面仍须保持，或生产端会再次独立调用，可建立变体；如果只存在于某个瞬间，则让它留在画面动作、服装细节或场景状态里。

编译正式状态变体时，默认交付合并基础信息的完整提示词；若用户明确只要差异，则遵照中央输出规则的例外。可读取的基础提示词或参考中，仍适用于未变化部分的成像保护也要恢复到本项提示词；只改变状态实际影响的部位、材料表现或视图，其余身份、色材和表面呈现按确认范围保持。把保留目标写成具体的对象/区域及其成像作用，不能用“同基础画质”或“同前项”代替；不可见或无法取得的基础细节仍未知，不补造。

| 观察到的变化 | 默认处理 | 升级条件 |
|---|---|---|
| 人物换一件衣服 | 人物基础图可含默认穿着，但衣服不因此成为永久身份 | 仅当某套换装需要独立复用时，另建服装资产并绑定人物 |
| 衣物污损或沾水 | 绑定对应服装资产的状态；若无独立服装 ID，则绑定人物并明确是哪套衣服 | 该衣着变化须在后续画面继续保持或再次调用 |
| 人物一次哭泣、回头、抬手 | 当前画面的表演内容 | 变化是持续身体状态并影响多个之后画面时，作为人物状态变体 |
| 道具开盖、摔落、沾污 | 该次动作或画面内容 | 破损/开合状态需在后续多次保持时，作为绑定道具的变体 |
| 房间临时调换桌椅或出现天气 | 场景局部内容 | 布置/天气范围需跨画面复用并影响制作时，作为场景变体 |
| 既有场景需要从另一观察位置或方向单独制作视图 | 当前画面的机位选择 | 用户明确要求，或在已授权资产交付中确需独立制作/复用该视图时，作为绑定基础场景的视角状态；只记录观察位置、观看方向和必要取景变化，并保持空间身份锚点 |

同一变化若只出现一次但用户明确要独立制作，仍可按其要求给一个指定变体；说明它只适用本次范围，不推定以后复用。一次性需求先记入当前结果即可，不为了可能性预建库。

## 记录时间范围与依赖

变体有自己的 ID，并指向稳定基础 ID；不改写或重编号基础资产。沿故事时序记录开始、延续和结束范围，必要时复用用户已有的场次/分段号。起点或终点没有材料支持时标待核，不自动扩展到整部作品。服装资产关联穿着者；状态变体可关联人物、道具、场景或具体服装。衣物污损优先绑定对应服装资产；没有独立服装 ID 时绑定人物并明确所指衣服。仅在剧情明确同时需要时记录服装与其他状态的组合，不枚举所有搭配。

OpenUSD 的 `VariantSet` 将一组离散替代组织为下游可切换的选项；这里仅借用“基础对象保持、变化项单独选择”的数据结构类比，不能把软件的替代结构说成故事或角色设计的普遍规律。

## 视图规格只服务于下游

只有人物或物件会在不同角度持续制作、多人需要共用同一设计，且身份锚点可能因角度变化而漂移时，才建议模型表/多视图规格。先确认下游需要正侧面、背面、局部结构或其他哪一种视图，再用重复可见的比例与轮廓锚点核对一致性。既有场景需单独制作另一视图时，不重做完整环境：将观察点移动、观看方向和必要取景作为视角状态绑定基础场景，并保留入口、通道、固定物等空间身份锚点。没有已确认的基础场景时，首次设计仍按完整场景资产处理；基础参考不可见的区域标为未知，必要时补参考并说明复现边界，不写成已确认结构。人物微侧坐姿是灰棚柔光默认展示预设；坐姿遮住身份、体态或服装版型时改用合适姿势，需要时再补视图。模型表不默认三视图、T-pose、白底或固定标签版式。视图规格是资产交给图片 Skill 的需求，具体画面处理仍由 `laohu-image` 决定。

## 来源与本地适配边界

Cheryl Cabrera, *An Essential Introduction to Maya Character Rigging with DVD*, 第 1 章样章第 12–15 页，用模型表和比例参考线说明角色跨视角一致性的生产用途；其中 T-pose 是该书 rig setup 的条件，不是所有资产的通用格式。Toon Boom 访谈 Seth Lanki 谈 Fechin the Wizard 的 turnaround 与手部/嘴部模型表，涉及按生产需要制作多视图。本地适配是按下游身份漂移风险选择视图，不把某种板式设为默认。

OpenUSD 官方 Glossary 的 VariantSet 条目与 Introduction 对可切换变体的说明，只支持将“基础对象+离散替代”作为数据组织类比，不证明这是叙事规律。ScreenSkills 的连续性资料用于按故事时序核对候选变化；具体出处及其适用范围见 [剧本候选与整合](script-candidates-and-integration.md)。

首次探索的方向不等于身份已锁定；只有用户已接受/选定的参考或剧情必要信息才作为复现约束。助手先前未获接受的建议不自动成为保持项。
