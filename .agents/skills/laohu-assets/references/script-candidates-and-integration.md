# 剧本候选与整合

当父级第二步需要跨段核对候选身份、全篇去重或场景复用时读取本文件，产物是带依据的候选对应表与待核项；逐P资产任务以完整源稿、已采用 P、初步镜头概要和既有资产作为输入，再把每个 P 对应到其全部来源场次及资产在 P 内的实际出现/变化位置。声音身份只在用户明确提出固定角色/旁白声线或已授权声音资产范围时加入候选与 P 映射，不因剧本中出现对白自动扩展。只给局部材料时仍限于该范围。读完返回父级第三步，裁定基础资产、变体、一次性内容或未知。本文件不替父级扩大材料范围、添加剧情、生成媒体、重编号或改变 P；候选映射按语义列示，视觉字段/布局与声音提示词分别由各自交接 Reference 维护，不能把视觉坐标/状态字段套到声音对象。

## 从材料范围建立候选

先读用户给出的完整剧本或明确局部范围、已有/已采用分段、初步镜头、资产表与故事时间资料。逐P统筹时用完整源稿理解全篇关系，用采用的 P 与初镜确认各段的实际观看范围；已有故事时间账本或编号能读取时沿用，没有时只在当前分析中记最小对应，不另建持久台账。顺序按故事时间判断，不跟着文件排列、拍摄顺序或复制粘贴顺序走。

- **完整且未分段：**视为全剧范围；只在结果中标“全剧”，不创造段号。
- **已有分段：**沿用原编号，按故事时间核对每段中候选的出现、延续和变化；不重新排序编号。
- **用户指定片段或单段材料：**只检验所给范围内能看到的重复与连续性；未给出的部分记为未知，不推断全剧只有这些资产。
- **既有资产修改：**以资产原文和修改要求为主要输入；不要求剧本才能完成局部修改。

为当前分析使用一张轻量对应表即可：`故事顺序｜原编号｜显示称呼｜候选实体｜出现/变化｜依据与未决项`。它是当前任务的思考工具，不需要落盘成新故事账本。

### 输入含制作段 P 时

P 是下游制作范围，不等同故事中的某一天、地点或资产持续状态。若材料提供用户采用的 P 与来源场次对应，在原有编号和顺序内记录：`P｜该 P 的全部来源场次｜候选资产在 P 内的实际使用位置｜前后变化与剧本证据`。一个 P 可跨多个场次，同一资产也可在 P 中途出现、改变或结束；分别标出剧本支持的位置，不把整段自动视作同一地点、同一天或恒定状态。若手头资料未给足来源场次或变化位置，标明未知，不补造对应。逐P资产清单应让每段能找到当段真正使用的正式资产及其依赖；同一跨P资产只列作一项，不复制重造。

只读取并映射已有或用户采用的 P，不为资产筛选重排源剧本、不改 P 号、不拆并或重切 P；分段由 Video 负责，资产判断沿父级第二步候选盘点和第三步留存裁定返回，不改写剧本原文。

若本轮授权稳定声音身份设计，另建声音角色映射而非把人物实体、视觉外形与声音表现合并为一种对象：先按明确角色/旁白、说话人关系或用户确认，把声音身份绑定到实体；没有肖像的旁白可单独作为声音身份。记录本范围实际使用的 P、声音身份开始/持续/变化位置和依据；只给文本声线设计时标清没有实际音频文件，不虚构平台标签或音频输入。愤怒、耳语、语速变化等当句表现不作为新的声音资产候选，交 Video 按镜头和台词处理。

## 先确认同一性，再归并

对每个候选把材料称呼映射到规范名和现有 ID。显示称呼、生产名、资产 ID 是三层信息：称呼供读剧本，规范名说明唯一对象，ID 供下游持续引用。既有命名和编号优先，只有没有可沿用的命名时才给新 ID。

合并须有身份依据：连续动作、明确代称、稳定独特标记或用户确认都可支持；名称相同、类别相同、职业相同或相邻出现本身不够。若同一称呼存在两种会改变结果的指代，暂不合并，列出缺少的身份信息。

同理，道具按具体实物而非类别归并。两件同款物品若可替换且剧情不区分，可作为一种规格；如果持有人、标记、损坏轨迹或交接关系让它们成为不同实物，就分开保留。不要把“同一种东西”误写成“同一件东西”。

## 按资产职责筛选

先完成候选盘点，再判定正式留存。用户未限定类别时，候选扫描覆盖本范围内有名有行动的人物、直接参与本轮目标的具体物件、地点场景及剧本有据的服装/状态变化；记录它们出现在哪段、目前看到什么复用证据。候选阶段无需先证明重复，未来范围未提供时标待核，不遗漏该对象。第三步再裁定哪些会重复调用、需跨画面识别或其连续性会影响下游，哪些只留在单次画面。用户明确要求设计、修改或保留的单次资产按用户范围处理；单P对象若需独立设计、辨认或调用，也可成为正式资产，但“单P”只是范围，不是新类别。只要求候选判断时，返回候选与证据即可，无需分配正式 ID 或生成提示词。

| 候选类别 | 用来识别是否同一项的证据 | 常见误归并 | 筛选时保留的内容 |
|---|---|---|---|
| 人物 | 已确认姓名/别称、稳定体貌、关系与动作连续性 | 把同职业、同年龄感或同称谓当同一人 | 角色 ID、稳定外形锚点、实际出现范围 |
| 道具 | 独特标记、持有人、连续交接或损坏轨迹 | 把同类不同实物合成一件 | 物件 ID、区别标记、人物/地点依赖 |
| 场景 | 出入口、固定结构、相对位置和行动路径 | 每个场次或镜头各造一个场景；或把同类地点硬并 | 地点 ID、固定空间锚点、真实场次/分段 |
| 服装 | 明确换装、时间跨度、服装功能和持续范围 | 把人物身份与一次穿搭合并；把所有状态都配到所有服装 | 服装 ID、所属人物、实际穿着范围 |
| 状态 | 基础对象、差异内容、故事开始/持续/结束范围 | 把瞬间动作做成永久状态，或把变化覆盖基础身份 | 变体 ID、基础 ID、变化项及适用范围 |
| 稳定声音身份（仅按授权纳入） | 角色/旁白用途、用户确认的绑定、可用的文字或真实声音参考 | 把人物肖像等同声音身份；把当句愤怒/耳语建成新音色，或把文本描述说成已附音频 | 声音身份与实体的对应、实际使用 P、来源类型及真实状态；提示词由声音交接 Reference 编译 |

场次是叙事组织，镜头是取景单位，场景资产是可复用地点；三者可能对应但不等价。相同咖啡馆跨多场次，若入口与固定陈设等空间锚点持续不变，可以共用一个场景；同名地点的布局、入口或用途若实质不同，则先分开待核。窗边的一束临时光或某场桌椅移动通常是场景内容/状态，不必另建地点。

## 第三步作最终留存裁定

候选表不等于资产清单。逐项写出最后去向：

- **基础资产：**身份或空间结构在多处保持，需作为一项稳定对象反复调用。
- **持续变体：**绑定基础资产、在真实范围内持续存在的离散变化；另分 ID 并说明何时生效。
- **一次性画面内容：**只在特定画面成立，之后无身份追踪或复现需要；不因它重要或具体就自动成为长期资产。
- **待核：**是否同一实体、是否持续或用户要不要复用仍无法判断；说明缺少的证据，不把未知纳入资产或武断删除。

当用户只给一个片段时，也可发现该片段内部重复的候选；但输出要限定“当前片段”，不能说它已在全剧被复用。用户明确要单件设计时，按要求建立该项并标明它是本轮指定资产，不暗示全剧复用。

## 来源与本地适配边界

ScreenSkills 的 Script Supervisor 职业简介与 Costume Supervisor Skills 清单（Scripted Film and TV）说明 continuity breakdown 会交叉记录演员、动作、服装、道具、场景与故事日，并随剧本变化更新连续性安排。本文件只将这些连续性信息用于候选盘点；按故事时序归并对象、比较场景空间锚点、裁定资产留存和规定输出字段，属于本项目的本地适配。
