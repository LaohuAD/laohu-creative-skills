# 剧本候选与整合

承接上游故事视听种子或剧本制片附录、对长剧本或片段跨段去重归并、核对场景复用，或执行逐 P 关系映射时，由 [laohu-assets 主文](../SKILL.md) 读取本文件。单件设计或既有资产局部修改不加载本文件。

本文件只产出带材料依据的候选对应表、四去向留存裁定与逐 P 关系清单，不改写原剧本、不重排或重切 P、不越权扩展未授权的声音资产。

---

## 1. 锁定材料范围与故事时间顺序

始终按**故事内发生的时间先后**判断状态演变与实体归并，不按文档粘贴顺序或拍摄顺序推演：

- **完整未分段剧本**：标为全剧范围，沿用原场次定位，不自造段号。
- **已有分段 / 已采用 P 方案**：严格沿用既有编号、顺序与边界，绝不为整理资产重切或改号。
- **单段或局部片段**：仅检验所给范围内可见的实体与复用信号，未覆盖范围标为未知或待核，绝不断言某物全剧只出现一次或必定长期复用。
- **工作草表（内部梳理用，不强行落盘）**：`故事顺序｜原编号｜显示称呼｜候选实体｜出现与变化｜依据与待核`。

### 承接已确认的视听种子与制片附录

- **Story 视听种子**（[laohu-story-handoff](../../laohu-story/skills/laohu-story-handoff/SKILL.md#按实际接收方选取内容)）：提取角色身份与行动、标志物用途与状态节点、地点氛围及叙事匹配的画风方向；先区分已确认事实、工作建议与待下游决定。
- **Script 制片附录**（[laohu-script-world](../../laohu-script/skills/laohu-script-world/SKILL.md#在用户需要时整理独立制作附录)）：直接继承已确认原名、ID、连续性道具、固定空间锚点及动作/特效的起始与末态节点；若有可读源稿，仅回核关键连续性冲突处，资料已足即直接推进。
- **正式设计范围 vs 实际出场严格分列（核心防错）**：获准设计的人物可先完成完整身份规格；但**把某人物挂入某场次或某 P 的实际调用项，必须有当地出场、被目击、可定位行动或用户明确映射的证据**。仅在台词里被提及、只作为某在场物件的持有人或同列于总附录的人物，绝不塞进该 P 的实际调用清单，出现位置不明时单列人物使用待核，当地场景、道具与有据状态照常交接。

### 逐 P 映射规则

P 只是下游视频制作分段，**不等同单一故事日、单一地点或恒定状态**：
- 按既有 P 编号与顺序逐条核清：`P｜全部来源场次｜资产在该 P 内的实际出现位置｜中途状态变化与剧本证据`。
- 同一 P 跨多场、或道具/人物在 P 中途变化（如 P03 的 S-04 完好、S-05 破裂）时，按真实来源场次标明节点，绝不把整段 P 粗暴贴成单一状态；**资产总表与逐 P 明细对切换前后的场次覆盖必须口径一致**（例如在 S-02 中途破损的道具，基础完好态的使用范围精准标至 S-02 破损前）；总表优先用清晰 Markdown 表格排布于可复制关系清单代码块内。材料未给足对应场次则标未知。
- 跨 P 共享的同一实体全篇**只登记一个基础 ID、只设计和编译一次独立提示词**，逐 P 关系清单指向该 ID 即可；只在单 P 出现但确需独立设计辨认的对象可正式留存，注明单 P 范围。
- 获准稳定声音身份时，另列声音身份与角色/旁白的实体绑定、实际使用 P 及素材真实状态；愤怒、耳语、语速起伏等临场表演不进声音资产候选，交 `laohu-video` 按句处理。

## 2. 先确认同一性，再归并扫描

区分三层标识：**显示称呼**（剧本里的叫法）、**规范名**（唯一实体名）与 **资产 ID**（已有命名与编号优先，仅在正式留存且无既有 ID 时按类别前缀与顺序号新建）。

归并必须有身份连续性证据（明确代称、动作衔接、独特标记、持有人交接或用户确认）；**仅名称相同、同职业或同属物件大类不得硬并**，存在两种可能指代时先分开待核。同款物件若可互换且剧情不区分，可作单一类型规格；若各自有独立持有人、独特标记或损坏轨迹，按不同实物分别追踪。

| 候选类别 | 识别同一实体的硬依据 | 常见误归并陷阱 | 扫描记录重点 |
|---|---|---|---|
| 人物 | 姓名与明确别称、关系、稳定体貌与动作衔接 | 把同职业、同年龄感或同称呼当同一人 | 规范名、稳定外形锚点、实证出场范围 |
| 道具 | 独特标记、固定结构、持有人、交接与损坏轨迹 | 把两件同类不同实物合成一件 | 具体实物、区别标记、人物/地点归属 |
| 场景 | 入口、通道、固定结构、相对拓扑与行动路径 | 按场次或镜头拆分同一地点；或硬并格局不同的同名地点 | 固定空间锚点、真实场次与分段 |
| 服装 | 明确换装证据、时间跨度、活动用途与持续穿着 | 把人物永久身份与一次穿搭混为一谈 | 所属人物、整套搭配、实际穿着范围 |
| 状态 | 基础实体、可见物理差异、故事起止与复原节点 | 把瞬时动作升成永久状态，或拿变化覆盖基础 ID | 基础依赖、差异项、故事内生效区间 |
| 稳定声音（仅获授权） | 角色/旁白用途、实体绑定、可读文字或真实音频参考 | 把肖像当声音参考、把单句耳语/怒吼建新音色 | 绑定实体、使用 P、来源类型与真实音频状态 |

场次是叙事切分，镜头是取景单位，场景资产是可复用物理空间——同一地点跨多场只要固定空间拓扑不变即共用同一场景 ID；临时光影或桌椅微调留在画面或场景状态里。

## 3. 四去向最终留存裁定

候选扫描阶段允许宁可先记待核也不漏报；进入第三步正式留存时，逐项作出四选一裁定：

1. **基础资产**：身份或空间结构跨画面稳定保持，需反复调用或由用户明确指定独立设计。
2. **持续变体**：依附明确基础 ID、在具体故事区间内持续存在的物理状态或独立场景视角；另授变体 ID 并标注起止节点。
3. **一次性画面内容**：仅在单帧或单次动作中成立，后续无身份追踪或复现需要（如一次看过的旧报纸、单次哭泣转身），留在镜头画面里不建长期资产。
4. **待核**：同一性、跨段复用或出场位置尚缺证据，明确写出所缺证据，既不武断删除也不擅自升级为全剧正式结论。

只要求候选盘点时，交付候选名称、范围、依据、复用判断与待核项即止，不分配正式 ID 或编写提示词。出处归档见 [SOURCES.md](../SOURCES.md)。
