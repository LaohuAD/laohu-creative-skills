# 资产设计方法

由[资产主文](../SKILL.md)在首次视觉设计或已授权重定、且需要决定对象形态、功能结构、材料或辨认特征时读取。输入为本轮可读的剧本/用户材料、既有资产、已确认方向和修改范围；输出为落入现有类别字段的具体设计选择及需保持/开放的范围，交回主文第四步并由第五步编译。仅盘点候选、沿用已接受资产做状态更新或执行限定局部编辑时，不重新开放无关设计。

本文件把用途变成各类别可执行的形态、结构、材质和识别决定。沿用宿主已确定的题材、媒介、审美范围与已接受方向。衣装、物件和同一使用情境的配套，在这些条件下直接做必要的具体造型及局部呼应，再把规格交回宿主编译。宿主仅在本轮确有独立的核心视觉身份、群像辨识或作品级共用画风决定时另选父级方法。若已选定共用决定，本文件在各项落实它们。

## 从对象用途形成可见决定

### 先判断哪些设计仍开放

沿用用户已接受的身份、造型、所属、同作方向和明确保护项。区分材料确认的事实、用户锁定的决定、上下文可支持的推论及本次仍开放的视觉选择。重定设计只在用户授权的对象和属性内进行；仅改局部或状态时，不顺带改其余设计。

首次设计或开放重定时，从本轮材料里挑出确实会改变当前对象的用途、行动、时代、生活环境、身份关系、既有经历或物理条件。角色职业、贫困、善恶、年龄类别等标签本身不决定脸貌、衣着、污损或身体特征；只有材料中的具体行动和条件能够支持时才把它们转成视觉选择。虚构对象缺少非关键细节时，可在已定方向内补足必要设计；现实人物、地点或产品的未知事实仍待核。

### 把用途、结构、材料与辨认连起来

先确认观者靠哪处形态或关系读出本项用途，再选能让它成立的结构、材料和观察面。把这一处和次要细节分开，再检查当前展示下是否看得见。

- **人物**　把常需要完成的行动落到体块、重心与目光，选择媒介相称的头身比。先用剪影和外部比例辨认，再补换装后仍可辨的脸貌、发形或体态。性格表演可随时点改变。
- **服装**　沿穿着者的活动和时代搭配必要衣层。用主要衣片的重量、垂坠和活动处余量形成轮廓；经常摩擦或受力的部位才随经历出现表面痕迹。穿着者影响设计及归属，图中展示主体依本轮规格决定。
- **道具**　沿使用时的支撑、握持、连接和开合一路检查主要组成。让形态说明用途，从接触和所处环境选具体材质与保存状态；经历能解释修补或磨损时，挑能归到此物的一个位置。
- **场景**　先定入口、通道、固定地标与场内光源，再从拟选视点走一次动线。以近处遮挡、中段使用区域和远处地标组织深度，按用途放置痕迹。需核对可见性或编制照片级空场时，读[空间、构造和光线采用同一世界关系](reference-image-methods.md#空间构造和光线采用同一世界关系)或[空场景方法分支](reference-image-methods.md#空场景方法分支)。
- **材料**　材料描述落到承担辨认、受力、接触、遮蔽或采光的具体部位；用颜色、纹理与使用状态让质感成立。材质数量和纹理尺度随当前任务的观看距离与媒介决定。

### 只比较真正会被混淆的对象

同作组内对照只在对象确会同场使用、并列制作或有材料支持的混淆风险时进行。把具体差别写回原有的用途、形态/关系、色材、识别与保持项字段；人物尤其检查换装后仍可见的稳定线索。差别须符合人物处境、物件用途或已定设计方向；用户锁定、剧情要求的制服、同款、伪装或刻意相似外观照实保留，不为显得丰富而改写。对象的外观仍受已有身份 ID、类别、状态依赖和展示方式约束。

设计依据和内部因果说明用于作出选择，不另建强制字段或方法分析表。把最终可见决定写进本项原有规格，并交给第五步；下游提示词应包含制作该资产真正需要的选择，不能只写“独特、可信、有故事感”。
