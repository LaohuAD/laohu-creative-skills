# 资产方法来源与历史适配台账

本文件记录 `laohu-assets` 的行业参考来源、可迁移边界及写实生物旧平台历史适配注记，**仅在回溯出处或适配指定旧模型时查阅，日常任务不加载**。

## 1. 连续性、资产组织与多视角四宫格实践来源

- **ScreenSkills（Script Supervisor / Costume Supervisor Skills, Scripted Film and TV）**：continuity breakdown 交叉记录演员、动作、服装、道具、场景与故事日并随剧本变动更新。本地适配为按故事时间顺序归并对象、核对场景固定空间锚点、裁定四去向留存及维护逐 P 关系映射。
- **OpenUSD 官方 Glossary（VariantSet）与 Introduction**：以基础对象保持、离散替代可切换组织资产变体。本地仅借作基础资产 ID 与持续状态变体的数据结构类比，不视作叙事规律。
- **老胡一线多视角资产图实践（四宫格直出与单图转四宫格）**：基于人物上排 1/3 高清头肩大头照（微仰左侧 + 正面）、下排 2/3 全身正背且脸部平滑朦胧无五官（防止小尺度人脸污染下游面部一致性参考）的 `9:16` 布局，以及道具 `9:16` 四向结构与场景 `16:9` 四向全景重叠空间一致实践。本地升格为默认多视角资产主模式，同时去除早期模板中硬绑定真人毛孔与反向提示词列表的局限，转为适配全媒介的纯正向表达，并保留单张静态图显式切换与参考图转四宫格路径。
- **Cheryl Cabrera, *An Essential Introduction to Maya Character Rigging with DVD*（第 1 章样章第 12–15 页）** 与 **Toon Boom 访谈 Seth Lanki（*Fechin the Wizard*）**：模型表与比例参考线用于跨视角一致性生产；其中 T-pose 属三维绑定条件，本地不将其设为通用展示默认，仅按实际遮挡与下游需求增补额外局部视图。

## 2. 概念美术、新鲜度与同作色彩材质理论来源

- **Raymond Loewy, MAYA 原则（Most Advanced Yet Acceptable）**：新颖度与可接受度平衡法则。本地运行态内化为八分熟两分偏——守住八成时代与生活常识底盘，仅在 1–2 处关键特征刻意拧偏半寸打破第一直觉套路。
- **Wolfgang Iser, 接受美学召唤空白（Leerstellen）与 Ernest Hemingway 冰山理论**：本地内化为场景与道具的环境叙事留白——不把设定平铺成清点清单，而是在空场与修补痕中留出 1–2 处令观众主动联想背后人生的未说完线索。
- **James Gurney, *Color and Light* 与 Pixar Color Script 实践**：以 60/30/10 色彩主次分配注意力、以黑白灰三阶明度分离（1-2-3 Read）检验主焦点与背景可读性。本地适配为辅助色彩与灰度预检工具，严格服从用户既有色板、单色或暗调要求，不强行拉低对比与饱和度。
- **Disney *Encanto* 与 *Raya and the Last Dragon*（概念设计实践）**：按家族/地域与功能组织色形与衣层，用手工不完美与个体体态动作区分角色关系。本地仅迁移由真实叙事推演共同母题与个体反差的动作，不复制其文化符号，也不将色温或几何固定绑定善恶。
- **Pixar *Luca* 与 RenderMan *Creating a French Bakery***：手作感 3D 保留绘制形面与真实受力磨损而不过度物理写实模拟或满面铺脏纹。本地进一步结合非对称媒介语法，防止跨画风趋同。

## 3. 声音身份与试音分离来源

- **ElevenLabs 官方 Voice Design 文档**：将声线身份描述与 Text to preview 试音文本分离，并指出试音文本本身的语气与内容会影响预听中的语速与情绪表现。
- **Qwen3-TTS README（Voice Design then Clone）**：先形成设计参考音频，再建立供后续复用内容的 voice clone prompt。
- **本地适配边界**：仅采用身份描述、试音材料、实际音频与可复用引用分层管理，以及按真实完成步骤报告状态的方法，不把任何单一厂商的参数、字段或流程固化为通用接口。

## 4. 原创写实生物旧平台历史适配注记

以下记录原写实生物三阶段照片化流程在早期特定平台上的实操搭配，供明确指定沿用同一旧工具的项目回查。新项目以通用模型无关三阶段工艺（见 [laohu-assets-creature](skills/laohu-assets-creature/SKILL.md#写实生物参考制作分支)）为准，按当前实际工具支持的画幅、参考上限、保形与编辑能力执行，不将旧平台名写入通用提示词。

- **历史灰模阶段（2k）**：曾轮换 `seedream_5_5`（默认，优先用于精确解剖、复杂与巨型生物及服装组织）、`recraft_v4_1`（轮廓干净但圆润造型易偏卡通且偶尔误加文字，旧适配需加写实非卡通声明并明确无标题）、`soul_2`（擅长人脸与姿势，遇到多肢、大角易简化，且易输出双主体或转面图，历史开头使用 ZBrush 哑光灰泥雕塑措辞并强调单个形体、单一视图）。
- **历史面貌供体与材样阶段（2k）**：成年人类供体采用 `2:3` 头肩照，使用 `soul_2`（自然成人脸）或 `soul_cinematic`（个性更强，偏漫画感时切回 `soul_2`）；微距材料样本采用 `soul_2` 制作 `1:1` 写实近照，至少一张、优先两张，同会话复用。
- **历史照片化合成阶段（2k）**：使用 `seedream_5_5`，最多接入六张参考，顺序为图 1 灰模、A/C 轨图 2 供体、其后为各部位材料样本。该旧模型自行生成人皮时易出蜡质塑料感，因此强制拆出独立供体；C 轨仅作一次皮肤处理以保护稳定脸貌；出现微缩摆件感时靠真实取景、地面落点、日常物件尺度及实景转化语句修正。
