# 老胡资产创作

**只要各项资产的完整独立图片提示词，由本入口按中央规范编译。**“给出图工具”“图片提示词”在此指交付文字。仅当实际有明确的画面或版面缺口时，按[中央借读条件](references/image-handoff-and-output.md#按具体缺口借读图像或版面方法)读对应小节。纯资产文字任务直接使用资产的成像规范与适用本地方法。

**先看在当前类别内能否定案。**已有题材与审美方向，且本轮只做衣装、具体物件或同一使用情境的配套，直接用已选类别及必要 Reference 完成规格，按中央规范编词。多个配套、分别交付、具体款式自主或另有 Image 组合均沿当前设计范围。只有另有原创核心视觉身份、群像辨识或作品级共用画风的独立决定需要作出时，才选美术统筹。

沿故事时序辨认同一资产，筛出制作需要留下的对象，并用适合作品的美术和声音设计守住身份。**先认同一件，再判断是否值得留下。先定观众需要从它读出什么，再定用哪些特征让人记住。**

## 先确定本轮交付

区分全篇统筹、指定范围筛选、首次单件或成组设计、既有资产修改。视听种子、制片附录、单段剧本或现有资产规格都可作输入。用户只要调用链说明、诊断、候选、方向、规格或差异时，按相应范围交付。正式资产创作和修改默认交完整、独立可复制的对应媒介提示词。单件临时物或一次性画面依用户指定范围处理。

视觉资产与稳定声音身份分别按授权处理。用户明确要固定角色音色、旁白声线或授权本轮声音资产范围时，才进入稳定声音设计。图像、录音、试听、编辑、保存与供应商绑定依本轮实际授权和可用工具执行。提示词阶段交付文字，图片视听的实际实现状态在交接中如实说明。用户明确委托联合图像设计时，`laohu-image` 在已指定的资产及视图内协作。用户另行委托某张画面时，由它承接该图的构图、光色、观看位置及提示词。实际图片生成、编辑或保存由本轮获准且可用的宿主工具执行。镜头、场景声场与单句表演由 [laohu-video](../laohu-video/SKILL.md) 承接。

先沿用用户已定范围、对象称呼、已采用建议和保护项。候选盘点可先从已知材料推进。范围歧义确会改变重复筛选时，先提出有材料支撑的范围，只确认这一项。只有身份、题材、主要用途、资产归属或核心风格仍存在会改变交付的分歧时，才针对分歧给二至三个能看出差异的方案，说明观众会先读到什么及取舍，给出推荐并等待选择。用户已定方向或已委托自主决定时直接做。常规局部形态和纹理在方向内留给生成。

### 所有正式设计都要在成品里兑现用途

- **先确定观看价值。**从作品类型、观众与叙事承诺确定第一眼要认出谁、读到什么或感到怎样的气质。亲切、尊严、生命力、恐惧、奇异和悲剧美都可有明确的作品作用。用户追求向上的力量时，至少让一个可见维度体现这种追求，同时保留剧情需要的破损、贫困、恐怖或悲剧。
- **选能达成目标的具体方法。**人物用形体、体态或可视动作建立辨认，道具用用途与结构，场景用可读的空间关系，服装用有行动依据的整套搭配。稳定声音身份用有主次的可听特征体现真实用途。
- **把方法落实到对象。**形、色、材料、光线和痕迹来自身份、行动、接触位置或环境。年龄、贫困、职业和阵营进入体验与处境的设计。生活困难可以由磨损、受潮或疲态呈现，保留角色的体面、主动选择及其场合要求。
- **把可辨选择交到下游。**让共用画风、独有身份、状态与成像约束都进入各自完整提示词。以实际出图、出声或接收反馈判断是否达成预期。

## 第一步：确定剧本

确定是完整或分段剧本、指定片段、已确认交接、既有资产还是单件起稿。建立本轮覆盖范围、故事时间、已采用编号、可用材料和取舍。材料未覆盖的部分保留为未知。已有可读的故事时间表、资产索引或分镜可沿用。缺少时只在当前分析保留必要对应。完整源稿未分段时标为全剧，沿用原有场次定位，只有用户已采用的编号才能作分段编号。故事时间与文档、拍摄顺序不同时，以故事证据定位状态。

- 收到已确认的 Story 视听种子或 Script 制片附录，优先按[上游交接的接入校验](references/script-candidates-and-integration.md#承接已确认的视听种子与制片附录)核对人、物、地、方向、来源位置及状态节点。区分当前已确认、工作建议和未知。现有经过确认的资料足以支持本次范围时直接使用。可定位且获准读取的原稿或资产版本只核需要的部分。
- 逐 P 任务先确认用户已采用的 P 方案及资产工作授权。有完整源稿时，在全篇故事顺序下理解实体，承接已有 P 到来源场次映射、初步镜头概要及既有资产。材料只到单场、片段或单 P 时按实际已知范围做。提供 P 方案本身只用于定位，分段的编号、顺序及边界沿用既有采用方案。
- 局部修改直接读用户现有规格、可读参考和本次修改指令。将保持项与开放项列清，仅对会改变身份、归属或修改范围的歧义取得必要信息。新设计的虚构对象可按时代、处境与物理关系补足开放内容；既定资产的不可见部分，以及真实人物、地点、产品的未知事实保留待核。

带着范围、用户已有决定与可读材料进入第二步。

## 第二步：根据分析的剧本确定资产

未限定类别时，扫描人物、具体物件、地点以及有材料依据的服装与状态变化。候选记录显示称呼、范围、辨认与连续性证据。可能需要复用但未来范围未知时列待核。用户指定的单次对象也纳入本轮。已有生产名和稳定 ID 随证据承接，新正式编号留到留存裁定后。

- 人物依据称呼、关系、行动、稳定外形辨认。道具依据具体结构、独特标记、持有人、交接及损坏轨迹。同名、同类别、同职业的对象分别保留，证据能证明同一实体时才归并。
- 地点以入口、通路、固定物、相对位置和行动路径核身。既有空间的临时陈设作为布置变化处理，空间身份有实质差别时先分开待核。
- 服装记录明确换装、时间跨度、用途和实际穿着。状态记基础对象、可见差异及出现与改变位置，持续性留下一步判断。设备本体归道具，屏幕内容按是否独立复用判断。确有独立职责、且无法归入现有类别的复用图形或界面可列特殊候选。
- 获准的稳定声音身份按角色或旁白及实际可读的声音依据单独映射。对白、当句耳语和场面机位的变化按各自画面或表演职责处理。

有明确类别任务、指定内部配置时，[在相关判断前读取对应选择型专项](#选择型专项)。跨段辨认、去重、空间复用或逐 P 定位读取 [剧本候选与整合](references/script-candidates-and-integration.md)，核到真实来源场次和资产在其中的事件位置。只要候选就给名称、范围、依据、复用状态与待核项。需要正式留存才将候选交第三步。

## 第三步：整合资产

正式留存前按本轮媒介读取[图片提示词交接与固定输出](references/image-handoff-and-output.md)或[声音身份交接与完整提示词](references/voice-handoff-and-output.md)。字段服务于留存与交接，候选保留轻量。混合任务依各自媒介读取。

逐项裁定基础资产、持续变体、一次性内容或待核。能够跨画面辨认或独立调用、用户明确指定，或会影响后续连续性的对象按其职责留存。每个同一实体只保留一个基础 ID，已有称呼、ID 和编号优先。确需新增正式项且无现有命名时，采用简短的类别前缀与顺序号，后续沿用既有数字。持续变体有基础依赖、实际差异与故事内起止位置。瞬时动作和变化进入具体画面。证据不足的身份或复用关系留待核。既有正式衣服写 `所属人物：<人物 ID>`，变体写 `基于：<具体基础资产 ID>`。

逐 P 任务先整体去重，再交一块可独立复制的关系清单，写正式 ID、类别、实际使用 P、基础依赖和故事内状态位置。每个 P 逐场次列真实使用及事件先后。共享资产只登记、设计和编译一次；某对象只在单 P 出现但需独立设计、辨认或调用时仍可留存。共用及单段描述的是使用范围。变化中途发生或跨段延续时，用真实节点标注，P 继续作为制作定位。

获准的声音身份关系映射文本声线锚点、绑定角色或旁白、实际使用 P，以及存在的真实参考和文件状态。人物实体、视觉资产、稳定声音身份、临场表演、实际录音与供应商 voice ID 分别按其职责保留。旁白可单独有稳定声音身份。人物另一套服装、视图或一场情绪变化沿用原声音身份；剧情确有持续发声变化时，记录范围并交声音专项。

正式清单与锁定、待核项交第四步。用户只要关系映射或留存裁定时，在此交付。

## 第四步：确定资产内容

### 选定造型、媒介与材料

先按本轮意图判断核心美术是否开放。若材料已确定同一人物、物件或空间，本轮只要求整理、忠实提取并将已知特征编成图片提示词，沿用剧本锚点，按中央规范落实画幅、构图和必要的普通细节，只用本主文与本项所需的 Reference。即使对象较多或用户已选择组合 Image，仍按已知特征和本轮范围编译。

复现与修改依本轮可读取的已接受身份和风格。只开放获准修改的维度，有影响的服装、状态和视角变体同步核对依赖。缺少精确复现所需依据时，先交已知规格和可行布局，写明配合实际参考才能复现的部分。

按入口分流后，只沿本轮选中的路径作设计。

- **类别内可以定案。**读取用户选择的类别方法和必要 Reference，在已给题材和审美中确定款式、结构、材料与配套的局部呼应。规格做好后直接进入中央编译。现有审美方向能指导这些选择时，普通造型细节的自主决定就在此完成。
- **确需独立的核心美术决定。**当前交付要从零建立核心视觉身份、协调群像辨识、为跨不同职责的独立资产确定可反复使用的共同画风，或明确委托重定这些关系时，按[父级方法模块](#父级方法模块)选方法，将经决定的媒介质感、造型线面、颜色气候与饱和度、光影对比和材质温度返回类别规格。

本轮若确需处理风格化制作中的比例、姿态、材质呈现或光效，再按其专业触发选择风格化方法。

本轮一般视觉设计依[资产设计方法](references/asset-design-methods.md)或获准的类别专项形成具体的用途、形体、结构、色材与辨认选择。需决定真实参考、材料依据、多图职责或场景制作方法时读取[参考图、材料与场景方法](references/reference-image-methods.md)。把结构接到它承担的用途，把表面接到实际部位和接触条件。只决定会影响身份、功能、穿着、空间或观看的细节。“雍容华贵”“复杂雕刻纹理”等可以定宏观方向，原有普通局部保持开放，精控依[中央规范](references/image-handoff-and-output.md#精控扩展仅在触发条件成立时填写)只处理确有必要的部位。

| 类别 | 默认需要解决的设计问题 |
|---|---|
| 人物 | 依据故事形成有可视行为、体型体态、脸貌、发肤和完整基础造型的身份。全身、双脚和面部按形体与展示需求保持可读，即使成片用第一视角也完成全貌。合适的妆造与饰物按实际有无写，非人形按身体结构完整设计。 |
| 道具 | 确定可独立辨认的具体实物，使本体外形、主要结构、完好状态、尺度、材料和使用关系成立。辨认靠固定结构、标记、持有人及连续证据。 |
| 场景 | 定用途与大小感、入口、通道、固定物之间的空间关系与行动路径，再决定材料、氛围和场内光源。用能读出这些关系的无人场景视图交接。 |
| 服装 | 确定该人物在对应时间和活动中穿的整套搭配及材料，覆盖实际衣物、鞋袜和必要配饰。相邻段落无换装依据时沿用原穿着。穿着归属与展示对象分别按中央规范处理。 |
| 状态或视图 | 在[身份连续性与变体](references/identity-continuity-and-variants.md)核对基础依赖、具体改变、保持项及起止。衣物污损优先绑定对应服装，有必要且无服装 ID 时绑定人物与具体穿着。独立制作的既有场景新视图保持原空间结构，以观察位置与方向记录视角变化。 |
| 特殊资产 | 只给需要独立复用的专用图形、界面或其他有明确职责的对象设定字段与归属。设备实体与屏幕内容各依其用途处理。 |

布局、画幅、类别必述字段、媒体适配与精控只按[图片提示词交接与固定输出](references/image-handoff-and-output.md)执行。完整人物、独立道具本体、无人空间、服装平铺和明确要求的人物上身展示各自遵守适用规范；四窗仅在用户明确要求后使用。只有下游需从不同角度连续制作且额外视点能解决实际辨认/结构问题时，才选必要的模型表或多视图。常规展示直接沿用中央规则。

### 组织同作风格与身份保持项

需要统筹同作跨主体的共用美术、为既有资产组增加新成员、复现多视图或核对换装与状态时，读[身份连续性与变体](references/identity-continuity-and-variants.md)。先按真实作品关系选择共用媒介和材料方向，再只对同场、并列制作或可能混淆的对象比较各自轮廓、结构、色材和空间锚点。已定制服、同款与有意相似按剧情保留。用共同风格维持制作一致，单件仍根据身份与用途作区别。

在现有“识别与保持项”中写各项稳定视觉指纹，重点资产优先选三至五条有辨认作用的特征。对照真实换装、视角、光线和状态变化。若某个锚点只靠临时衣色、持物或表情，改用适用的开放身份线索，或保留已有的稳定锚点。把能跨变化保持的具体线索写进变体所有相关完整提示词，把确实发生的变化单独指向获准改动的部位。已接受且暂不可读的部分留待参考，避免补成新事实。

同作风格通过现有规格字段和提示词传递。60/30/10 用在适合以三种颜色职责安排注意力的画面。明确的现有色板、无彩风格和实际可读性决定怎样使用配色。核对关键焦点即使去色或只看剪影仍能读到对象的职责。色值和面积按设计目标记录；已有图像色值仅在真实可读取并实际取得时以取样结果交接。需要色卡或跨资产总览时依用户请求另行交付，日常以单项规格传递共同关系。

### 本地方法与有针对性的取法

首次设计或重定有开放的身份、材料、空间与展示选择时，依[本地作品方法库检索路径](../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)查资产入口可用且与当前资产选择相称的条目及方法详情。按作用迁移身份、关系或材料组织，归回当前类别的具体字段。已有资产提取、忠实复现、状态变体与明确局部修改沿已有方法和参考处理。

只有本地方法仍无法决定会改变身份、功能或观看的部分，用户明确要求找真实设计参照，或方向需用具体作品辨别时，才按[日常创作取法与方向](../../../references/exemplar-study.md#日常创作取法与方向)寻找可核验实践。每次回答当前具体问题，例如某条线索如何显示人物身份，哪段结构使物件用途可读，哪种入口和固定物关系支持剧情动作。结果落实到本项形态、用法、色材或空间锚点，保持原创与已定方向。找不到可核来源时说明受影响的决定，依其他材料继续能完成的部分。

### 稳定声音身份

本轮获准时读取[声音身份专项](skills/laohu-assets-voice/SKILL.md)与[声音交接](references/voice-handoff-and-output.md)。从角色或旁白的用途及目标听感，选少量有主次的听觉锚点，例如音色、相对音高、气息与共鸣、咬字、语言和习惯。按需要讨论相互容易混淆的声部，保留剧情要求的共同听感。依据可用的资料、角色职责和已确认选择组织长期声线，避免性别、体型、外貌或性格标签的机械推定。固定声线、持续发声变化与当句表演按各自适用范围交接。

本步形成可制作规格、适用风格、构造与保持决定，供第五步编译。只要求规格时交本轮要求的完整类别必述项，到此为止。

## 第五步：编译完整提示词并交接

### 先锁定每条交付的正文

正式设计或修改默认交完整提示词。逐项确定中央布局、类别字段和适用成像保护。声线按[声音交接](references/voice-handoff-and-output.md)编译身份与用途、主辅声学锚点、语言习惯和录音呈现。单句表演或另获授权的试音文本另放，对已定台词保留原文。人物图和声线各有独立代码块。

多视图、已接受资产复现/换视角/版式派生，或采用需要固定模板和短语的方法，在起草前实际读取[编译前固定视图职责与源方法片段](references/image-handoff-and-output.md#编译前固定视图职责与源方法片段)。以逐窗观察面和职责为骨架，再把获准变化写到对应窗口。需要真实参考图、材料样本或多图绑定时，按[参考输入编译方法](references/reference-image-methods.md#把参考输入编译为有边界的图像指令)指明实际每图的对象、部位、职责与保持边界。文字设计版本用已知文字，待提交的图需在交接中写明实际依赖。

逐项把第四步的形态、色材、表现和辨认决定写成模型可执行的画面对象、区域、结构与表现力度。视觉成像用正向可见描述及对应部位的保护，落实该媒介分别对线条、细节、曝光、材质或噪点的控制。只有中央资产成像规则仍无法解决本项可指明的画面或版面问题时，按[中央条件路由](references/image-handoff-and-output.md#按具体缺口借读图像或版面方法)只借读对应专业小节，随后返回本项提示词。既定方法的条件、区块顺序、固定短语和关系照其唯一真源编译，只按明确的适用条件或已获准选择跳过相关条目。最后检查实际正文的对象和关系，避免用“清晰精致”之类概括词代替控制。

每条相关同作视觉提示词独立写出适用的共用美术决定。已选风格锁的条目统一重述媒介笔触、形体线面、色彩气候与饱和度、光影对比和材质温度，再指定该对象自身的部位、识别点、构造、用色与当前状态；不要只写“同全片”“见前项”。针对换装或状态，逐条以实际基础规格核对适用锚点和原有成像保护。涉及图像与声音的保护各按其媒介处理。

### 让单块可直接使用

- 每项正式资产默认一个独立代码块，联合图像设计也按用户点选的资产及交付清单编译。另加上身图、合照、剧情画面或总览只在用户明确指定时交付，持有和配套关系照实写在规格中。明确委托多张独立视图或多阶段参考时，按实际要求分别完整交，保留同一资产 ID 和各项输入职责。明确的四窗是一项资产的多视图，各项四窗独立。
- 画面或听感要实现的获准设计、保持指令、必要共用方向及获准画内文案留在块内。标题、管理 ID、真实范围、归属、依赖、来源与确认/生成/试听/验证状态写在块外。某个方向虽是提议，工具仍需要明确的画面或声音指令。色值是否取样、资产是否已经选定和参考是否真实可用，依事实在块外交代。
- 模型能理解且适用的成熟风格参考名可以保留。只有故事内部含义、缺乏可见所指的专名，改成实际特征、对象和关系，无法转换时省略。服务确需的参数、接口字段（如 `inputmode`）和文件按实际工具契约随机器输入传递，真实供应商 voice ID 只在有接口证据时记录。
- 色卡默认在一个完整代码块内写色块布局、目标色值、画内标题、逐块配对的色名/HEX/用途与排版。用户明确要求无字底图或分步制作时按其要求拆分。文字、色值及排版的效果以实际图像核验，制作输入仍保有用户所需文案，详见[色卡交接](references/image-handoff-and-output.md#图片交接与固定输出)。
- 局部修改只动已授权的属性，默认合并可读取的基础特征、变化、保持项与适用成像控制成一条完整提示词。用户明确只要差异或补丁，或明确限定基于已绑定图只写指定部位的局部变化时，交变化与保持项。可读参考仅证明它实际显示的特征。

逐块读回，设想只复制该块给接收者，核对需执行的可见或可听内容、自身身份、既定展示和适用保护是否完整。随后核对块外对应关系和真实实现状态。全部整理后，视觉依人物、道具、场景、服装、状态、其他排序，空类省略。获准声音身份另列角色/旁白与绑定。实际已获准制作或贯通完整作品的任务依交接进入相关媒介，仍按真实工具结果报告文件和验收。

## 内部方法与专项

配置由本入口定位，以本轮意图和材料重新判断，沿用父级的范围、来源、已定设计和返回契约。只说明调用链时交链路说明。配置之间由父级统合，内部方法读完回本入口对应步骤。

### 父级方法模块

| 方法 | 自动读取的条件 | 返回第四步与第五步 |
|---|---|---|
| [美术统筹](skills/laohu-assets-artdirection/SKILL.md) | 本轮确需建立原创核心视觉身份、统筹群像辨识或让不同职责的资产共用一组美术决定，或获准重定上述方向。已给题材和审美框架的局部款式与配套由相应类别方法解决 | 四项共同美术决定、按需采用的形体与明度组织、各项视觉指纹 |
| [风格化造型与成像](skills/laohu-assets-stylized/SKILL.md) | 正式视觉设计采用动画、卡通、绘本、3D 风格化、国风绘画或奇幻效果，且有实际开放的比例、姿态、材料呈现或成像决定 | 相称的比例、姿态、材质、色光和效果保护 |

正式成组设计按实际设计决定选择方法，二者可并用。候选、纯声音、剧本既有对象的忠实提取与提示词编译、已定条件下的局部修改，直接按各自所需层级和 Reference 完成。纯真人生活写实沿写实展示及成像路径，纯色卡与纯界面沿各自中央规范。

### 选择型专项

在用户明确提出某类的创作、修改、检查，或明确要相应专项时，在具体判断前读取。以所求结果识别，用户说“给她换套衣服”可直接承接。材料里写她穿外衣、道具属于某角色，或整组清单中自然出现这些类别时，通用资产任务由父级直接判断。历史已加载配置只帮助定位文件，本次作用对象和范围仍据当前请求。

| 专项 | 当前授权的工作 | 专项回交 |
|---|---|---|
| [人物](skills/laohu-assets-character/SKILL.md) | 明确设计、修改或检查人物形象 | 身份映射、记忆点、体态和完整身份规格 |
| [道具](skills/laohu-assets-prop/SKILL.md) | 明确设计、修改或检查具体道具 | 持拿/开合关系、可视结构、尺度和使用痕迹 |
| [场景](skills/laohu-assets-scene/SKILL.md) | 明确设计、修改或检查地点空间 | 空间主关系、可见地标、用途痕迹和确需的精控 |
| [服装](skills/laohu-assets-costume/SKILL.md) | 明确设计、修改或检查服装搭配 | 人物绑定、层次、材质行为、活动与局部需求 |
| [状态](skills/laohu-assets-state/SKILL.md) | 明确设计、修改或检查持续物理变化，或为既有地点单独制作另一观察位置或方向的视图 | 基础依赖、变化、保持项和实际起止。普通衣褶和单次机位走原画面路径 |
| [声音身份](skills/laohu-assets-voice/SKILL.md) | 明确设计、修改稳定的角色音色或旁白声线，或本轮明确授权声音资产范围 | 绑定、适用范围、可听锚点与持续声音状态。单句表演走镜头与发声路径 |
| [四窗](skills/laohu-assets-fourgrid/SKILL.md) | 明确要求同一项视觉资产做四宫格或四窗 | 四个窗口各自职责，由父级按中央布局编译 |
| [原创虚构生物](skills/laohu-assets-creature/SKILL.md) | 明确要求设计原创生物、怪物、外星生物或亡灵的虚构形体，或为其制作分阶段的写实视觉参考 | 可辨形态、尺度与表面，按需要交写实阶段参考。按既有资产类别登记 |

多个类别是并列扩展，依当前范围取并集。状态、服装与具体基础对象绑定。例如“人物与场景，另核查周岚的状态”代表两类并列，并只对周岚加状态专项。通用任务附有专项时，只在对应对象上应用。配置文件确实缺失时说明受影响步骤，完成父级有依据的部分。

## 返回值

用一两句说明范围、主要归并与必要的设计取向。候选只列当前名称、范围、依据和复用状态，未来未知标待核。没有可辨候选时说明当前覆盖范围。正式资产依第三步关系和第五步顺序交付，展示、字段与成像由[中央视觉规范](references/image-handoff-and-output.md)维护，声音依[声音交接](references/voice-handoff-and-output.md)维持与各层的真实关系。只应提供规格或差异时，到相应精度停止。现有 ID 优先；下例仅说明新建项的命名与关系格式。

```text
CHR-001｜人物名称
适用范围：全剧 / 用户已有编号
基于：仅变体填写其基础资产 ID
设计说明：……
```

## 交付前检查

- 从原输入重核范围、故事顺序、采用编号、同一实体的 ID、服装归属及变化发生位置。交接的未知项仍保有原范围，待核候选没有变成全剧结论。
- 对照本轮实际对象检查选用了适用两类方法与专项。不同对象保持各自职责，已定形态、画风、复现模板与授权边界贯穿步骤。
- 逐项按中央字段与实际消费场景复核姿态、布局、可见性、关联视角和材料。仅有明确需要时才写细颗粒或工程精控；已定空间坐标按视点转为可见关系。
- 逐块检查有意义的独有身份、同作共同风格、变体保留项和部位级成像保护。正文可复制使用，交接信息对应同一项；结果按实际完成的提示词、媒体、试听或验证事实报告。
