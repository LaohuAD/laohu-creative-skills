# 老胡状态资产

## 适用范围与父级继承

本配置仅在用户明确提出状态资产的创作、修改或检查工作，明确要求执行本配置，或要求为既有场景单独制作另一观察位置/方向的视图时，由父级加载。通用剧本资产整理不因材料涉及状态就加载；读取已有依赖资料不等于执行对应子级。每轮重新核对适用性，历史加载不自动沿用。父级独立具备各类完整方法，仍负责范围、ID、跨类别组合和最终交付。

## 专项判断与可见贡献

对照基础逐项隔离改变项与保持项，明确起止及复原条件。场景的物理变化与视点变化分开记录：用户明确要求既有场景的独立视图时，可建立绑定基础场景的视角状态；它只改变观察位置、观看方向和必要取景，不代表场景本身改造。除这种明确的独立视图需求外，普通单帧机位仍留在画面内容，不自动建档。差异图沿基础类别展示，服装仍平铺、道具仍本体、场景仍空间。

本配置返回专项判断，展示规格以父级[固定资产字段](../../references/image-handoff-and-output.md)为准；不递归加载其他配置，也不因普通依赖扩大任务。

## 确定本次任务

以父级明确的对象、剧本范围、故事时序和既有资产为输入。用户只要求某人物、道具、地点或服装的状态修改时可直接处理，不强索完整剧本；身份或状态生效时间有歧义且会改变输出时再询问。

## 确定状态资产

### 识别与筛选

先问变化是否离开当前一帧仍须被记住。伤势、衣物污损、物件破损或持续天气，若在多个后续画面要保持，可作为变体候选；衣物污损优先绑定对应服装 ID，没有独立服装资产时则绑定人物并指明当前哪套衣服。一次哭笑、拾取、转身、开门或光线瞬变通常留在对应画面。用户明确要求设计单次状态时照其范围交付，不因此推定长期复用。

### 归并复用

每个正式变体依附一个基础人物、道具、场景或服装 ID，拥有独立变体 ID；基础 ID 不因变化而重建。同一持续状态跨多个分段只记录一项及真实适用范围。无法确认是否与既有变化相同，先待核，不重复造变体也不误合并。

### 固定项与变化

按[方向字段](../../references/image-handoff-and-output.md)写基础ID、变体ID、实际范围、改变项与保持项、起止/复原条件；未知端点待核，不扩成全剧。变化程度应足以看懂，只有识别/功能或用户精控需要时才精确到位置尺寸。未被用户选定的助手建议不能当既有锁定资产。

状态沿基础类别展示，服装仍平铺、道具仍本体、场景仍空间。编辑默认只写变化与保持，不重写未变身份和材质；用户明确从零或完整成品时才合入基础方向。普通褶皱、动作或单帧光变不自动生成持续状态。

## 与其他资产的关系

状态可绑定人物、道具、场景或具体服装，但不会自行扩大对象范围；服装状态同时保留服装所绑定的人物。“人物 + 状态”表示检查所选人物的状态；多个类别并用由父级按对象关系扩展，不取空交集，也不默认遍历所有角色。状态子级不递归调用其他子级。

## 返回内容与交付检查

回传本类别对象、ID、范围与归属、主要方向和关系、已接受或剧情必要的保持项、开放局部与必要精控依据，以及类别展示要求。人物仍有完整身体与面貌身份；其他类别不以字段齐全强制细节穷举。只对正式资产设计，候选保持轻量；不越过父级生成未授权提示词，不把设计文本说成已生成图片。
