# 老胡状态资产

仅在用户明确提出状态资产创作、修改、检查、点名本专项，或要求为既有场景单独制作另一观察位置与方向的视图时，由父级加载。不因读取既有基础资料自动递归调用其他专项，也不把单对象状态扩大到全资产组。双模式画幅与最终编译由父级按 [中央视觉规范](../../references/image-handoff-and-output.md) 统一落地。

---

## 1. 划清持续状态、瞬时动作与场景视角状态

- **先过持续性门槛**：变化离开当前单帧后是否仍须在后续多镜保持，或被用户明确指定独立制作？伤势、衣物淋湿污损、物件裂损变形、持续天气跨多镜保持时建独立变体 ID（绑定基础 ID，绝不重编基础资产）；单次哭笑、转身、拿放或瞬时闪光留在具体镜头画面。
- **衣物污损归属**：优先绑定对应服装资产（`基于：<服装 ID>`），无独立服装资产时再绑定人物并写明具体穿着。
- **场景视角状态**：仅在用户明确要求或已授权资产确需独立复用的单一新机位时建立，绑定基础场景 ID，只记录观察位置、观看方向与必要取景变化，**原空间固定拓扑与已有物理状态保持不变**，不重构场景；普通单帧机位仍归镜头画面。
- **精确落到故事起止节点**：写清变化开始、持续与复原位置（未知端点标待核，不擅自扩成全剧）。P 只是制作分段，同 P 内中途发生或结束的变化须标明具体来源场次，不把整段 P 粗暴贴成恒定状态。

---

## 2. 让状态变化合乎物理因果且不淹没视觉指纹

1. **严格隔离改变项与保持项**：逐项对照基础资产——写清变化落在哪个准确部位、范围多大、程度如何，并核对新增破损/污渍与既有修补标记错开方位不撞角，同时明确锁定未受影响的身份指纹、基本形态、其余色材与既有成像保护。
2. **保住核心识别窗口**：蒙灰、淋湿、破损或包扎必须为人物脸部核心特征、眉眼标志物或道具主轮廓留出清晰可读的识别空间，确保观众一眼仍认出是同一实体。
3. **展示形态完全继承基础类别与当前板式模式**：持续状态默认继承基础资产的画幅与板式（原为或明要单张图则继承单图）；多个独立状态各自成图，仅用户要求前后对比时另排对照图；视角状态采用 `16:9` 单视角。

本专项内部拆清变化项与保持项后交回父级；**父级对外默认合并基础指纹、授权变化与适用正向成像控制输出完整独立提示词，且只写此刻真实存在的静置物理事实、彻底剥除旧物对照词**，仅当用户明确要求只交差异或补丁时才输出差异提示（附参考图时仅陈述可见变化，不臆造被遮挡结构）。
