# 老胡服装资产

## 适用范围与父级继承

仅在用户明确提出服装资产的创作、修改、检查或选择本专项时，由父级加载。通用剧本整理沿父级工作，读取人物或既有服装规格可作普通依赖。每轮重新判断。沿父级提供的穿着者、服装、故事时序和修改范围处理；既有服装可以按原规格与新要求直接修改。

## 换装与复用

以穿着者、实际服装部件、剪裁与色块，以及换装证据判断连续性。相邻场次无换装证据时沿用原套装；明确换装、时间跨越或服装功能改变时先列新候选，同一人物的不同实体套装各以独立 ID 记录。已核实的同套装跨段保持 ID 并写真实穿着范围；一次穿搭在需要复用、连续制作或本轮指定设计时独立留存。普通褶皱属画面表现，需要连续记忆的服装变化按具体时间和使用对象交父级判断。把场内穿着关系用于归属与功能适配，按剧本或用户给出的实际关系组合状态。各类专项由父级组合。

## 随穿着者的行动选择衣层与衣片

1. **按作用搭配内、中、外和配饰。**内层贴身、吸汗或便于动作，中层承担保温、固定或主要覆盖，外层形成剪影并回应环境，配饰承担收束、携带、识别等实际职责。只选适合当时、当地和角色需要的层，鞋袜与实际配件纳入整套设计；单件按指定范围处理。服装同作的年代、地域、队伍与材料可一致，按已定制服或伪装保护相似处。
2. **把材料重量写到轮廓。**选一两处能读出的垂坠具体表现。轻薄衣片动作后可晚半拍落下，厚呢下摆以更大的褶线压住轮廓，挺布在肩或袖笼处撑形；配件的重量可以让面料在固定处轻陷。颜色、厚薄、表面光泽和纹样大类落到实际衣片，局部纹样、排布或小工艺依本轮精度开放。
3. **按动作核对活动余量。**从剧情中选最需要释放衣量的动作，如蹲坐、跨步、够高处、奔跑或回身，检查肘、膝、腋下、摆口和绑带。若宽摆会卡在通道或短袖抬臂时会扯皱主要衣片，回改相应的开衩、衣量、连接或长度。把动作条件变成平铺也能读出的一处结构。
4. **让磨损有原因。**别针与斜背带磨到的部位和落雨/扬尘在表面留下不同痕迹。修补落在反复绷紧或曾受损之处，储存与整理习惯可通过折痕或摆放组合呈现。只用经历与材料可支持的痕迹；明确制作、复现或识别依赖时才精控该处。

穿着者归属只用于匹配整套搭配。按[中央服装字段](../../references/image-handoff-and-output.md#服装)确定本轮是平铺还是明确的上身参考。平铺先排出同套部件互不遮挡的关系，有必要局部时指回主图的实际衣片、缝合关系或面料；无纹样时可由衣口、袖口与面料结构承担可见细节。

## 返回父级

交回套装或单件、ID、穿着者、实际使用范围、穿着/换装依据、衣层与形态、动作所需余量、部位材质和色彩、已接受保持项及精控依据。父级按指定展示范围与交付要求编译完整规格或提示词。
