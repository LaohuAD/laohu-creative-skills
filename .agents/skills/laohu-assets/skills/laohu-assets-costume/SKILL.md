# 老胡服装资产

## 适用范围与父级继承

本配置仅在用户明确提出服装资产的创作、修改或检查工作，或明确要求执行本配置时，由父级加载。通用剧本资产整理不因材料涉及服装就加载；读取已有依赖资料不等于执行对应子级。每轮重新核对适用性，历史加载不自动沿用。父级独立具备各类完整方法，仍负责范围、ID、跨类别组合和最终交付。

## 专项判断与可见贡献

先分清穿着者元数据与服装展示对象；逐层列出衣物、鞋袜和实际配饰，再为平铺主图排出不遮挡的部件关系，选取真正影响辨认/制作的局部并指回主图位置。没有纹样时展示必要结构，不为填特写制造装饰。

本配置返回专项判断，展示规格以父级[固定资产字段](../../references/image-handoff-and-output.md)为准；不递归加载其他配置，也不因普通依赖扩大任务。

## 确定本次任务

沿用父级的剧本范围、故事时序和既有服装资产。用户指定人物或服装时只处理该对象；既有服装修改可直接根据原资产与修改指令完成，不要求补交剧本。无用户指定对象时，按父级的全剧或已有分段筛出服装候选。

## 确定服装资产

### 识别与筛选

先确认穿着者，再按换装证据和复用需要判断。相邻场景未出现换装依据时沿用原套装；明确换装、故事时间跨越或服装功能改变时建立新候选。只有多次调用或连续性会影响制作时，才保留为正式服装资产；单幕穿搭默认留在该幕画面，用户明确要求设计/修改时除外。剪裁、色块、材质和标志性配饰用于辨认具体套装，不以职业印象替代材料。

### 归并复用

同一套衣服在不同画面沿用一个服装 ID，并列出真实穿着范围；同一人物的不同套装分开。既有 ID 不变；新增 ID 只在需要正式复用时分配，未确认的换装不提前编号。

### 固定项与变化

正式服装绑定具体人物，以[方向字段](../../references/image-handoff-and-output.md)明确用途、时代/人物适配、目标感受、整套搭配与宏观轮廓、主辅色和材料倾向；上装、下装或裙装、鞋袜与实际配饰均纳入。用户没有详述时按故事主动给方向，不用空泛“美观”搪塞，也不把普通细节缺失变成问卷。

纹样默认决定有无、几何/植物等大类形态，局部形状、排列、领袖结构、缝线等可由模型补足。只在明确精控、已选衣服复现或剧情识别/功能必要时，细化对应部件的位置、尺寸、方向等，不扩大成全套工程规格。

中央展示规范为16:9整套平铺与必要细节放大，无人物/人体/人台；特写可展示主图自然形成的材质或结构，须对应同件衣物，不预先制造复杂花纹。人物绑定仅用于归属与适配，提示词不写其面貌。明确上身效果才人物穿搭。局部修改保护已接受的其余搭配；普通褶皱不生成持续状态也不触发状态子级。

## 与其他资产的关系

沿用已有的人物身份规格记录穿着归属；只有用户也明确要求人物或状态工作时，父级才加载对应配置。组合时以对象与时间关系为准，只记录剧本确立或用户指定的搭配；不枚举所有服装×状态组合。父级可并行组合类别，服装子级不递归调用其他子级。

## 返回内容与交付检查

回传本类别对象、ID、范围与归属、主要方向和关系、已接受或剧情必要的保持项、开放局部与必要精控依据，以及类别展示要求。人物仍有完整身体与面貌身份；其他类别不以字段齐全强制细节穷举。只对正式资产设计，候选保持轻量；不越过父级生成未授权提示词，不把设计文本说成已生成图片。
