# 老胡服装资产

仅在用户明确提出服装资产创作、修改、检查或点名本专项时由父级加载。读取人物资料作搭配适配不触发人物专项；展示边界与最终编译交回父级按 [中央服装字段](../../references/image-handoff-and-output.md#服装) 统一执行。

---

## 1. 换装归并与人物绑定

- 以穿着者、实际衣物部件、剪裁色块与换装证据判断连续性：相邻场次无换装依据时沿用原套装 ID；确有换装、时间跨越或用途切换时按不同实体套装分别授 ID。
- 服装始终在文字元数据里写清 `所属人物：<人物 ID>` 及真实穿着范围，**绑定人物不等于人物入画**。普通动作褶皱属单帧画面；跨镜持续的污损、淋湿或破损按故事起止交父级建服装状态变体。

---

## 2. 随年代形制与穿着者行动组织衣层、重量、余量与痕迹

1. **先过年代与地域形制常识关，再搭齐内、中、外与配饰**：核对每一件单品的剪裁、领襟、裤裙制式与鞋袜是否符合故事时代与地域日常常识，绝不把跨时代的现代单品混进历史或特定年代语境。内层贴身利落，中层保暖或承托主形，外层立轮廓并挡风遮雨，配饰承担收束、携带或身份识别；**默认配齐整套衣物、鞋袜与实际配饰**（用户明确只要单件照办）。同作团队制服或伪装保护既定相似处。
2. **把面料重量垂坠与穿法小习惯写进轮廓**：用一两处可画形态显出衣料物理特性——轻薄衣片轻盈飘动、厚呢下摆以大折线垂压轮廓、硬挺打蜡帆布撑起锋利廓形、重配件令固定处轻微牵拉下坠；在合乎角色日常习惯处留 1 处反映生活史的穿戴习惯或随身露角细节。纹样默认定有无及大类，普通扣件缝线保持开放，仅满足精控条件时锁局部细节。
3. **拿最吃衣量的剧情动作核对活动余量**：代入蹲坐、跨步、抬臂、奔跑或负重检查腋下、肘膝、开衩与绑带，若宽摆或紧袖会妨碍行动，直接反推加开衩、放袖量或调衣长，让平铺结构也能看出合身与实用。
4. **把磨损和修补落到有原因的位置**：区分高频摩擦位（斜挎带肩处、袖口、膝肘、衣袋口）与环境沾染（雨溅下摆、扬尘），修补针脚与折痕呼应人物性格与生活史，不无故做旧。

展示板式遵循 [中央服装规范](../../references/image-handoff-and-output.md#服装)（默认 `16:9` 简洁中性底面整套错开平铺、无人物人体或人台，按需切换 `16:9` 四宫格分区平铺；仅用户明确要求上身效果或试穿图时才由对应角色穿戴呈现并注明用途）。完成后将归属、穿着范围、形制核验结果、衣层轮廓、垂坠色材、活动余量与保持项交回父级。
