# 风格化造型与非对称媒介成像

当正式视觉资产采用动画、卡通、Q 版、赛璐珞、绘本水彩、风格化 3D、定格粘土、国风绘画或奇幻光效，且存在开放的比例、姿态、材料呈现或成像控制决定时，由宿主自动读取。纯现代真人写实摄影、纯色卡、纯 UI 与纯声音沿宿主原有路径处理，不触发本模块。

---

## 1. 校准头身比与习惯静态微姿

先依年龄、媒介与造型张力选定头身比参照，并敢于按角色性格与风格夸张度拉开体块比例（非人形按物种构造与移动方式定比例）：
- **2–3 头身（Q 版萌系）**：突出头部轮廓、大表情结构与大件标志配饰。
- **4–5 头身（卡通动画 / 手作定格微缩）**：兼顾鲜明神情、有张力的手脚体块与特征服装轮廓。
- **6–7.5 头身（强风格 2D 动画 / 国风 / 奇幻）**：保留修长骨感体态、步态重心与大面积衣摆垂坠。

**风格化展示姿态**：用户已定姿势、角色行动条件与辅助器具优先。采用默认四宫格时，下排全身站姿赋予贴合人物日常习惯的静态动作线与重心（破除僵直双臂垂立罚站），同时完整露出头身比、双手、双脚与主衣片轮廓；显式切换单张静态图模式时遵循 [中央人物单格姿态](../../references/image-handoff-and-output.md#人物单格姿态与背景)——简洁中性背景下的正面偏四分之三自然微侧站姿。需坐姿、轮椅、悬停或匍匐时选最清晰展现身体结构的角度。

## 按渲染语系控制成像

**反趋同铁律**：严禁把不同非写实语系洗成同一种低饱和柔和温吞底味，也严禁把写实摄影皮肤毛孔、现场硬闪或胶片颗粒混入非写实风格（仅用户明确要求混合质感时局部启用）。必须把当前选定媒介最极端的视觉旋钮推到位，确保**遮住媒介标签词后仍能一眼脱标盲辨**：

| 选定媒介语系 | 写入提示词的非对称纯正向成像与材质控制 |
|---|---|
| **2D 动画与强风格赛璐珞** | 外轮廓用果断锋利或有手绘顿挫的墨黑线锁稳大剪影，内部结构线高度克制；明暗采用刀切般干脆利落的硬边平涂二分阴影块，暗部敢压深并按需留极细冷暖反光边，小面积几何高光精准切落发梢、衣缘或硬质棱面；大片色面保持干净通透平涂，坚决远离圆钝柔滑的厚涂渐变。 |
| **绘本、水彩与版画** | 强调有方向感的手绘笔触、纸张纤维肌理、颜料局部自然晕散渗色与大块透气纸底留白；靠轮廓虚实、色块溢出与笔触疏密聚拢视线，头脸与主形焦点清晰利落，不硬套三维球体体积光。 |
| **3D 风格化与手作定格粘土** | 饱满拙朴的大体块与有手作张力的局部比例，清晰扎实的地面接触阴影；手作粘土须显出肉眼可辨的软陶指腹按压指纹、刮痕颗粒与微缩粗织毛毡毛刺、实木锻铁微浮雕触感，配微缩实拍焦感与清晰明暗分组，彻底区别于光滑均质的塑料盲盒感；风格化 3D 注重简洁概括块面与清晰漫反射区分。 |
| **国风工笔、水墨与设色** | 工笔重提按顿挫的骨力勾线，辅以绢本底色与矿物颜料层层分染晕染；水墨重干湿浓淡、皴擦飞白与大面积气韵留白；靠线骨疏密与平面设色层次托起主体，绝不强凑西式三维体积光。 |
| **奇幻光效与能力表现** | 发光体严格锚定于明确发光源、肢体边缘或道具外侧，写清扩散半径、色彩浓度及邻近实体的清晰映光；核心人物五官、手部与道具结构在强光影下保持完整锐利轮廓，最亮处绝对服务唯一主视觉焦点。 |

将选定的头身比、习惯微姿与非对称媒介正向成像控制返回宿主第四步落入规格，由第五步编入每条受该媒介影响的独立提示词，确保单块复制即可锁定鲜明独特的世界画风。
