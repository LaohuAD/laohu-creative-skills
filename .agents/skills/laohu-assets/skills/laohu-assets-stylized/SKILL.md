# 设计风格化资产的造型与成像

宿主在本轮正式视觉资产需要决定动画、卡通、绘本、风格化三维、国风绘画或奇幻效果的形体和成像时读取。以用户选定和已接受的媒介为先，从同作美术方向读取需要保持的简化程度、颜色范围和光影。风格尚可自由决定时，选与观看任务相称的一种主要语系并维持其规则。有局部奇幻效果时，保留基础作品的渲染语系，只为该层设计特效表现。纯真人生活写实、纯色卡、纯 UI 和纯声音由宿主已有路径处理。

## 选择比例与可辨姿态

人物先确定年龄、动作和轮廓语言，再选形体比例。有二至三头身的 Q 版适合让头和表情成为大形，有四至五头身的卡通适合兼顾表情、肢体动作和配件，有六至七头身的风格化动画较易保留修长肢体、步态与服装垂坠。把这些区间作为选型参照，按已定比例、角色体形和作品造型实际调整。非人形角色用与身体构造、体量和移动方式相称的比例。

宿主按[图片交接的展示默认](../../references/image-handoff-and-output.md#图片交接与固定输出)确定版式、画幅和单格/多视图。可自由选择姿态时，风格化及靠衣着、披风、尾巴或其他外形辨认的人形身份图，优先用正面偏四分之三的自然微侧站姿。轻度倾斜、放松或挺立的重心来自角色行动习惯，清楚露出轮廓、面部、关键配饰和双脚。已定姿态、角色实际行动能力、辅助器具和展示目的优先。需要坐姿、轮椅姿态、悬停、匍匐或其他姿态时，用合适观察角度保留该角色的身体组织和身份线索。主视图确有遮挡时，再按中央规则选择足以解决遮挡的视图。

## 按渲染语系控制成像

按当前对象从下列选适用的正向控制，写到真实部位或画面层。以具体线条、边缘、阴影、纸面、表面或发光范围告诉模型该怎么画。局部保护按对象和材料指定，维持原媒介有意保留的手作纹理、笔触和颗粒。摄影皮肤毛孔、现场硬闪与胶片颗粒仅在用户明确选定并适配该对象时进入。

| 已选媒介或效果 | 写入提示词的具体成像控制 |
|---|---|
| 2D 动画与赛璐珞 | 外轮廓线管主形和前后遮挡，内部细线表现五官、关节与衣褶。分清亮、暗的平涂块面，将硬边放在转折处，小面积高光只落真正受光的发梢、衣缘或表面。按本作要求用清透或低饱和色块，保住干净的色面分界，暗部仍有读得出的主形。 |
| 绘本、水彩与粉彩 | 选有方向的笔触、纸张纤维或粉质颗粒，让颜料在适当边缘铺开或留白。用轮廓的虚实和不同色层疏密聚焦，脸和关键形体边缘保有识别，纸纹与颜料自然可见，背景留出呼吸。 |
| 3D 风格化与手作粘土 | 用饱满大体块、简化关节、可读的接触阴影和柔和体积光定形。织物、毛发以织面或成束大结构起形，有需要时给适度手作压痕、拉痕或指腹纹。皮肤或半透明材料按本作采用柔和次表面散射，干粘土或布料按其偏哑光的漫反射表现，避免高光让不同材料都显成同一种蜡面。 |
| 国风工笔、水墨与设色 | 已定工笔时，勾线有轻重与顿挫，设色可按需要用石青、赭石、朱砂或绢本暖底分层。已定水墨时，以干湿、浓淡、皴擦和留白建立远近、转折和静处。视觉重心落在故事需要看清的主体，颜色和纹理服从选定的画法。 |
| 奇幻光效与能力表现 | 把发光放在明确的发光源、肢体周缘或道具外侧，定覆盖范围、浓淡和发光对实体的局部反射。实体轮廓、五官、手与道具主要结构继续可读，最亮处只服务当前视觉焦点。主体辨认不足时，先收小光效的亮度或覆盖，再补需要保留的剪影边界。 |

## 返回宿主

第四步把适用比例、姿态建议、可辨轮廓和媒介成像条件写进当前视觉规格。第五步按中央布局把部位、力度、表现和局部限制并入每条受该媒介影响的完整提示词。读回单块，核对能否仅凭它识别媒介、做出可读全身或本体，并保留本作需要的材料与光效。已接受的身份、版式和表现按其适用范围继承。
