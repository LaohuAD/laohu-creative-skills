# 角色声音身份选择

仅当用户明确要求固定角色音色、旁白声线或授权本轮声音资产范围时由父级加载；剧本存在对白、情绪变化或视觉人物任务本身均不触发本专项。完整声线提示词编译、试音文本分离与真实素材分阶状态唯一由 [声音身份交接与完整提示词](../../references/voice-handoff-and-output.md) 维护，本专项专注选声判断并把决定交回父级。

---

## 1. 选声四步（从角色用途到过耳难忘的可听锚点）

1. **分清既有复现还是从零选声**：已有获接受的声音方向或可读真实音频样本时，先锁核心保持锚点，只改获授权维度；仅有文字或音频不可读时据实处理，绝不假称听过。从零设计时以角色/旁白用途、叙事场景与目标听感为起点，**绝不凭外貌、性别、体型、职业或性格标签机械推导音色**。
2. **用一句纯听觉语言立住核心辨认**：落定听者在目标场景中第一耳凭什么记住这条声音，写直接可听的声音状态，避免抽象人格词或偏视觉的通感借喻。
3. **定 2–4 项主辅声学锚点，并专设 1 处高辨识声纹记忆钩子**：从音色质地、相对音高、共鸣位置、气息感、咬字清晰度、语言/口音与稳定发声习惯里挑出真正撑起辨认的主锚点与支撑辅助项，其余开放；**刻意避开安全好听却毫无个性的标准播音朗诵腔，在合乎用途的前提下立住 1 处两秒可辨的声纹脾气**（从声带颗粒肌理、共鸣落点、句尾收口利落度或日常换气节奏中择一做透）。**声线提示词同样全程采用纯正向可听描述，绝不堆砌摒弃、绝不、不做等反向排斥句，也不混用哑光等纯视觉修辞**，不编造赫兹数值、语速字数指标、设备型号或无依据口音。
4. **当场化解互相打架的听觉描述**：优先遵守用户锁定项、角色用途与主锚点。两个开放形容冲突时，把其中一项收束为有明确边界的辅助条件，或直接舍弃干扰项；若冲突发生在两项用户锁定条件之间，交父级给出具体取舍方案而非擅自覆盖。

**按需查库（可选只读）**：仅在开放选声确缺抓手且用户或任务需要具体作品声音参照时，按 [本地资料库分层检索](../../../laohu-benchmark/references/library-retrieval.md) 以 `laohu-assets/voice` 只读检索，并按需参考 [时间与声音分析适配](../../../laohu-benchmark/references/time-and-sound-analysis.md) 声音身份条目后返回选声；无可读音频时仅取文字方向不作音色实证，既有锁定声线复现不查库。

## 2. 组内声部区分与持续变化边界

- **仅在存在混淆风险时做声部对照（含无肖像旁白与主角防撞）**：多条常驻声部会在同作并列出现、或无肖像旁白可能与同片主角声区/年龄层撞车时，主动指出防撞风险并沿相对音高重心、音色干湿明暗、共鸣位置与节奏咬字拉开辨识度（不必每人全维度都拉满）。剧情要求同族、分身或刻意相似声部时保住共同核心，只在允许的辅助维度区分。
- **无实听不宣称已验证**：比较真实音频须用同一试音文本与相近录音条件；尚未实际试听样本时，只交计划拉开的听觉维度与待试听核验点，不宣称已验证可分。
- **剥离临场表演与持续嗓音状态**：单句愤怒、耳语、喘息或抢白交 `laohu-video` 按句处理，不建新声线 ID；仅源稿确立持续嗓音改变（如长期伤嗓、失声与恢复区间）时，记录真实生效与恢复节点交父级承接继承关系。

完成后将选声定位、核心听觉印象、主辅声学锚点与声纹钩子、保留与开放范围、必要组内区分及待试听验证点交回父级统一编译。本专项不执行样本生成、外部试听、文件保存或供应商 ID 绑定。
