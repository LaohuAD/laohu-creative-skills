# 角色声音身份选择

仅当用户明确提出稳定角色音色、旁白声线，或授权本轮声音资产范围时读取本子级；对白、情绪、耳语或视觉人物资产本身都不构成触发。这里负责声线 casting 选择：决定哪个听觉印象最能承载角色用途，哪些特征作为核心/辅助，及同作声部是否需要保持相似或拉开。完整提示词编译与样本/素材状态唯一由父级[声音身份交接与完整提示词](../../references/voice-handoff-and-output.md)维护；本子级把设计决定返回父级，不复制另一套交付流程。

## 从输入到选声

1. **先分已有设计还是新设计。**若已有被用户接受的声音方向或可读真实参考，从锁定锚点与参考本身起步，先标出必须保持与本轮可改的范围；只有文字或不可读取的音频时，只依据实际可见信息，不假称听过。若从零设计，从角色/旁白用途、作品场景、用户选定的听觉方向和可用材料起步；不能从外形、性别、体型、职业或人格标签直接推算声音。
2. **先定听者应记住的核心辨认。**用一句内部判断说明：这条声音在什么场景中，最希望听者靠哪种可听印象认出或理解其角色功能。它应比抽象性格词更接近听觉，例如“话语压低但咬字仍清楚，像在节制地拉近距离”；不是必须采用的固定特征表。
3. **再选主锚点与辅助特征。**从音色质地、相对音高、共鸣、气息、咬字、语言/口音、节奏或稳定发声习惯中挑真正承载核心印象的特征。先定主锚点，再选能加强而不抢走它的辅助特征；其余维度保持开放。不要堆一串互不相干的形容词，也不填无依据的赫兹、语速或声学参数。

当本轮稳定声线决定确实缺少可用方法，且某个具体作品的实际声音处理能帮助决定主锚点、辅助项或同组区分条件时，可按项目根目录的[本地作品方法库检索路径](../../../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)检索，使用 `laohu-assets/voice` 作为接收决定；按需读取 [时间与声音分析适配](../../../laohu-benchmark/references/time-and-sound-analysis.md) 中的声音身份行，并回到本子级的选声流程。优先使用用户指定的参照。没有可读且获准试听的实际音频时，只把文字当作角色用途或目标方向的依据，不把它当作音色证据。检索只读，不自动保存方法或触发音频操作；既有锁定声线的复现不为找范例而检索。

4. **处理互相抵消的描述。**先遵守用户明确锁定项；其次看角色用途与目标听者体验；再保护最能形成辨认的核心锚点。两个开放形容若互相抵消，不并列罗列，而是将其中一个改成有边界的辅助表现（例如“整体温暖，句尾略带冷硬收束”），或舍去与核心冲突的形容。若冲突发生在两项用户锁定且会改变声线身份的要求之间，提出具体取舍，不擅自挑一项覆盖。

## 何时比较组内辨识

只有同一作品中多个稳定声部会并列出现、已有材料显示容易混淆，或用户要求做群组声线配置时，才做声线对照。先找最可能混淆的那组，再只比较有助区分的可听维度：相对音高与重心、音色/气息质地、共鸣位置、咬字与节奏/口音；不要求每人全维度都不同。用同一段已授权试音文本、相近的呈现条件和相同说话任务作为可比基准，判断听者可能首先听到的差别；若素材、文本或呈现不一致，先把差异记为不可比，不从中推断身份。

没有实际音频试听时，只返回“设计上计划拉开的维度”和待试听核实点，不能说已听出辨识度或已验证可分。确有听取授权且真实样本可访问时才描述实际听到的差异；仅有文本时维持待验证。若用户已指定同族声部、伪装、分身或刻意同声，先保留其共同核心；只在剧情和授权允许的范围内用辅助特征、表演或真实声场区分，不为了做评测式对照强行改造稳定身份。

将稳定身份与当句表演分开：愤怒、耳语、疲惫、喊话等交 Video 处理，不另造声线身份。只有用户/剧情明确建立持续嗓音状态时，才给父级提供真实形成、持续、变化或恢复范围；不把它混入基础声线。返回父级的内容限于选声理由、核心听觉辨认、主辅锚点、须保持/可调整之处、必要组内对照与待验证点；父级再按唯一声音 Reference 编译提示词并报告素材状态。

此子级可在本轮授权且真实样本可读取时分析已提供的声音参考；仅作设计判断，不自行生成样本、发起新的外部试听/音频操作、保存或绑定真实音频，也不产生供应商 voice ID。文字声线设计本身不授权样本生成或额外音频操作。父级统一整合同作资产及 P 映射；实际单句台词表演和镜头声场交 Video。
