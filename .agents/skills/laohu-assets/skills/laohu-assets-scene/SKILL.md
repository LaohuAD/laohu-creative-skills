# 老胡场景资产

## 适用范围与父级继承

仅在用户明确提出场景资产的创作、修改、检查或选择本专项时，由父级加载。通用剧本整理沿父级工作，读取既有地点资料可作普通依赖。每轮重新判断。沿父级确定的地点、故事时序、场次和资产工作，改既有场景时保留原 ID 及未获准修改的空间锚点。

## 判定同一空间

对照入口、通道、固定物相对位置和行动路径，确认一处地点跨哪些实际场次或分段。锚点一致的同一空间沿用基础场景 ID；同类型但有另一套格局的地点分别记录。取景或景别变化沿用地点身份。材料不足的归并保留待核，未分段的全剧沿已有来源定位。人物或道具可以在空间内移动，具体临时摆设或持续状态按地点与实际时段另交父级判断。

## 用空间支持动作和环境叙事

1. **先在平面关系中走一遍主要动作。**从入口到中段的实际行动区域，再到关键固定物，确定谁从何处转入、停留与离开。核对通道净空、门扇扫掠和家具边界；用方位、相邻、通行与遮挡关系表达。若用户要求精确复现或行动必需的数值，按[精控扩展](../../references/image-handoff-and-output.md#精控扩展仅在触发条件成立时填写)记录已有依据。把世界空间和本次能看到的画面分别交接。
2. **从一个视点铺出前、中、后景。**用前景边界交代观看位置，中景留给主要使用区域，后景由照得到、看得见的固定地标收束。地板拼缝、屋梁、家具朝向或场内光池可将目光引到地标。机位确定后，沿[空间与视野核对](../../references/reference-image-methods.md#空间构造和光线采用同一世界关系)复查入口、通道、固定物和门窗外实际所见；主视点确实遮住关键关系时才说明另一个必要视点。
3. **让空场上的痕迹交代人和时间。**挑仍留在现场的生活证据，如常走处的地板磨痕、反复修补过的椅面、朝同一桌摆好的两套餐具。再考虑摆放秩序、物件占用空间和亮暗分配能否说明这里的人际关系、使用习惯、阶层处境或时间节点。例如独居长者为等家人空出一张椅子，把台灯转向那侧，洗净的第二套餐具已摆在灯下。用有据的时令物、旧痕与新痕区别长期与刚发生的事；场景依旧展示空间和相应陈设。

同作可继承时代、材料、色光与形体语言，各地点凭自己的空间关系维持识别。照片级空场需要完整提示时，采用[地点提示词七区块](../../references/reference-image-methods.md#地点提示词的七个区块)。可见光线由位置或作品设定中能定位的场内来源决定。

## 返回父级

交回地点、ID、实际使用范围、用途、空间及动线、地标、观察点与可见条件、痕迹归属、锁定关系和必要精控依据。展示与附图条件见[中央场景字段](../../references/image-handoff-and-output.md#场景)和[项目画布](../../references/image-handoff-and-output.md#项目画幅主图与局部图数量)，父级统一编译和交付。
