# 老胡场景资产

仅在用户明确提出场景资产创作、修改、检查或点名本专项时由父级加载。沿用父级范围、场次与既有场景 ID，改既有场景时锁定未授权改动的固定空间锚点；双模式展示与附图规范交回父级按 [中央场景字段](../../references/image-handoff-and-output.md#场景) 与 [项目画布](../../references/image-handoff-and-output.md#项目画幅主图与局部图数量) 执行。

---

## 1. 以固定空间拓扑判定同一地点

- 以**入口位置、主要通道、不可移动的固定设施与相对行动路径**确认空间身份：固定拓扑不变的同一地点跨多场次共用基础场景 ID，景别切换或临时挪动桌椅不另建地点；格局或用途实质不同的同名地点分别记录，证据不足先待核。
- 持续性的空间改造、破坏或跨场天气交父级判场景变体；明确需要独立复用的单一新观察角度交父级记为绑定基础场景的视角状态。

---

## 2. 用动线、三层纵深与冰山留白讲故事

1. **在平面关系中走通一遍真实动线**：从入口走到中段主要活动区再抵达核心固定物，核对门扇扫掠区、通道净空与家具边界，用前后、左右、邻接与遮挡表达空间拓扑；仅满足精确工程或跨视点复现条件时，按 [精控扩展](../../references/image-handoff-and-output.md#精控扩展仅在触发条件成立时填写) 展开米制 XYZ 坐标。
2. **站进房间核对三维机位、纵深与单面标牌方位**：定机位前先验证真实三维投影——镜头背后与门楣头顶的设施不强塞前景；若需透过门窗看见室外天色、街景或远景，须将门窗安排在镜头斜前方或后景视野内，且门扇开启路径不被家具顶死，同时让核心剧情作业区占据足够视觉权重而非缩成远景小点。前景边界锚定观看站位，中景敞开核心使用区，后景落于受光可读的唯一核心地标，借地板拼缝、梁柱或场内光池自然引线。**凡存在单面招牌、门牌或局部壁挂，明确锁定所贴墙面或柱面的唯一朝向**，防止多视角转面时被误复制到相邻立面。
3. **用冰山留白与光温分区让无人空场自己讲故事**：拒绝清点家具式平铺直叙。在守住大片透气空面与清晰动线的前提下，在空场里精准藏入 **1–2 处让观众心里发问的未说完生活破绽或刚刚离席的余温**（落到高频使用磨痕、呼应人物随身物的角落留置、中断中的日常痕迹或冷暖光温分区上），不言自明地交代住着谁与此刻节点。
4. **守住默认无人与真实光源底线**：所有可见光线来自空间内可定位的真实灯具或采光口，默认严格无人（仅当用户明确附人物背影参考并要求融入作尺度锚点时才加背影）；双模式板式与密闭空间物理适配遵循 [中央场景规范](../../references/image-handoff-and-output.md#场景)。

照片级电影实拍空场采用 [地点提示词七区块](../../references/reference-image-methods.md#地点提示词的七个区块)；风格化空场沿用空间拓扑与光影逻辑并承接同作非对称媒介画风。完成后将空间动线、主地标、三维视野与标牌朝向核对结果、冰山生活线索与锁定锚点交回父级。
