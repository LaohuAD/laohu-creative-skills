# 四宫格多视角编排与参考转制

当本轮正式视觉资产采用默认**一体化无缝四宫格多视角资产图**模式，或用户提供单张静态参考图要求转制为四宫格时，由宿主自动读取；纯候选盘点、色卡、纯 UI、声音身份、写实生物三阶段单视图工艺或显式单张静态图任务不触发本模块。四宫格展示的是**同一项资产的同一物理状态**，绝不拆成多个资产 ID，也不把多个不同对象或多种持续状态塞进同一张四宫格。

---

## 执行步骤

1. **核定资产身份与参考边界**：确认资产类别、已定媒介画风、核心视觉指纹、非对称特征位置及是否附带单张参考图。若基于参考图转制四宫格，按 [参考输入编译方法](../../references/reference-image-methods.md#把参考输入编译为有边界的图像指令) 锁定原图已见身份与结构、剥离人物/道具原图单场硬光并规划未见面的合理推演。
2. **承接唯一布局真源**：画幅与分区标准唯一承接 [默认四宫格布局规范](../../references/image-handoff-and-output.md#默认四宫格布局规范)，不另建平行布局表。
3. **按类别落实多视角防漂移与物理弹性**：
   - **人物（三轴分离 + 镜像核对 + 局部无五官与豁免）**：将相机观察面、躯干朝向与头向分开决定——左上格默认低角度微仰左侧头肩特写正拍人物左侧脸，右上格正面平视头肩特写正对镜头（人物左脸特征落于画面右侧）；**若核心非对称指纹集中在右侧脸，左上格自动镜面切为微仰右侧头肩特写并同步校准镜像**。左下格正面全身与右下格背面全身保持完全同一习惯微姿与脚位重心（轮椅、悬浮、卧姿或非人形按真实常态支撑姿态），手臂避开随身配饰防遮挡，非对称发型、袖口、口袋或饰物在正背两格严格左右镜像互证。常规比例露脸人形的下排脸部采用平滑朦胧素面（写实/3D）或平滑素净纯色轮廓面（赛璐珞/木刻/平面插画），严限下排脸部不糊衣身与上排；**遇 2–3 头身 Q 版大头角色、全覆面具/头盔角色或用户明要下排露清五官时自然豁免**。
   - **道具（单一展开态 + 俯视禁转锁 + 微损特写格）**：四格默认分工为正面平视、右侧微低仰、背面平视、高位俯视或关键结构视角；**若道具或状态变体的核心变化极细微（如细缺口、微裂纹、暗扣刻纹），第 4 格优先换为该关键变化部位的近景局部放大特写**。多关节可折叠或机械道具全四格锁死**单一无歧义固定展开形态**，绝不让各格各自猜角度；**右下高位俯视图明确禁止旋转主体朝向**，严格沿用正面视图的左右基准，重叠部位接口与修补痕严格镜像互证。
   - **场景（四全景重叠一致 + 物理结构适配 + 单面标牌方位锁）**：四格均以全景或远景为主，默认正视平视、左视、对称右视低角度微仰与高位俯视鸟瞰（墙体格挡外侧自然沉入暗部）；**面对低矮密闭室内、狭长廊道、车厢或洞穴等带顶空间，第 4 格自然改用高角落斜俯广角或反打回望全景，绝不违背物理硬掀屋顶**。重叠出现的固定建筑、摆设数量、方位、透视距离与唯一主光源/日照方向严格一致，受风倾角合乎物理常识，非重叠区域按同一时代与空间功能合理延伸；**单面招牌或壁挂明确锁定唯一所贴墙面或柱面朝向**，防转视角被误复制到相邻立面。
   - **冲突透明回报**：仅当自然姿态或物理结构与特定窗口要求发生不可调和的冲突时，明确指出冲突窗口及原因，询问是否作最小视面调整。
4. **回交逐格骨架**：将四格观察面、分区比例、左右镜像对应、局部清晰/朦胧边界与防漂移约束交回父级，由父级编入**单块完整独立纯正向提示词**，不新增表单字段。
