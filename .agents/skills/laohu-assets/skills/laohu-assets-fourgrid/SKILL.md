# 四窗视图选择

仅当用户明确要求某一项资产做四宫格/四窗时读取；普通单视图、单项其他视图或多个资产并排不触发。本子级只选择四个视窗各自要解决的识别、功能或空间观察问题，不把四窗拆成四项资产、不把不同对象拼成跨资产总览，也不把多个状态塞进四窗。

1. 确认资产类别、视图目的、同一资产身份锚点及用户已锁定的媒介/风格。
2. 按四个窗口需要显示的证据分配视点与职责，避免重复视图；同一项资产的多个视角仍共享身份、材料和适用的世界光源语境。
3. 读取唯一布局与质量真源[图片提示词交接与固定输出](../../references/image-handoff-and-output.md)，完整遵守其四窗画幅、类别分支、局部清晰要求和成像保护；不复制或重建另一套布局表，不削弱人物、道具、场景或服装的既有条件。
4. 将四窗版式及其局部约束写入该项完整、独立的视觉提示词，返回父级资产整合。人物下排无五官等局部要求只约束源 Reference 指定的对应区域，不扩成全图模糊；具体约束以该 Reference 为准。

本子级不设计声音、不修改资产身份、不生成图片。实际图片操作仍须单独授权。
