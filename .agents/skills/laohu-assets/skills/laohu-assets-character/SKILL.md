# 老胡人物资产

仅在用户明确提出人物资产创作、修改、检查或点名本专项时由父级加载。沿用父级范围、既有角色与修改授权；身份归并、双模式画幅板式与最终编译交回父级按 [中央人物字段](../../references/image-handoff-and-output.md#人物) 统一落地。

---

## 1. 人物归并与层级边界

- 以姓名、明确别称、关系、行动连续性与稳定体貌归并同一实体，沿用既有基础 ID；同一称呼可能指代不同角色时暂分列待核，绝不凭同职业或同年龄段硬并。
- 服装归属绑定穿着者，持续伤势、妆污或伪装按真实起止建状态变体；瞬时哭笑、转身与单场手势留给单镜画面，**但角色常年养成的习惯重心、神色底气与劳作印记保留在基础母图里**。
- **第一视角不截断完整身份**：即便成片全程第一视角只露手，人物母资产依然完整设计头脸、体态、全身与默认穿着。

---

## 2. 将经历、反差与行动变成可辨骨相、微姿与指纹

1. **校准年龄骨相与头身比例**：承接作品媒介，分别定头相对身高比例、肩胯宽窄、四肢长短、手部尺度与脊背姿态。儿童增大头身比与短肢重心，绝不把成人骨架等比缩小；中老年与劳作角色用骨相体态、手部肌理与眼神承载阅历，既不刻板推丑，更不磨成无菌光滑样板脸。
2. **用外壳与里子的真实反差立住活人味**：拒绝拿单一形容词刷满全身。把外在社会身份壳与私密癖好、长期劳作留下的身体印记或执拗的生活习惯拧进同一副身躯，在 80% 素净基底上把记忆点精准押到 1–2 处大特征。
3. **用习惯动作线微姿打破僵直罚站**：挑出角色最常做的一类日常行为，落为脚下重心支点、肩背倾角、不遮主衣片的手部常态落点与自然目光，让静态站姿自带活人脾气，不千篇一律双臂笔直垂立。
4. **筛出换装不丢的 3–5 条指纹并核验左右镜像**：优先从脸型骨相、眉眼结构、发形轮廓、体型头身比、固定疤痕/胎记或惯常重心挑选跨换装与转面依然成立的物理锚点；衣色、临时持物与单场表情移出指纹。**凡存在左/右非对称特征（疤痕、痣、偏分、卷袖、单侧口袋或手腕饰物），逐一核验正视、侧视与背视下的解剖左右与画面左右对应关系，绝不写反**。
5. **同场群像 3 秒黑剪影比对**：仅对会同框或易混淆的角色并排核对身高差、肩臀轮廓、发型外沿与重心；涂成纯黑剪影、去掉同款制服后仍须 3 秒可辨（剧情要求刻意相似或同款制服则保留设定）。

展示板式与局部边界统一遵循 [中央双模式规范](../../references/image-handoff-and-output.md#资产画面布局与独立提示词)（默认 `9:16` 人物四宫格，明要单张图时遵循 [人物单格姿态与背景](../../references/image-handoff-and-output.md#人物单格姿态与背景)）。默认搭配写宏观轮廓与材质触感，普通缝线细节保持开放。完成后将归并依据、反差立意、习惯微姿、镜像核验后的视觉指纹、正向妆饰状态与展示建议交回父级。
