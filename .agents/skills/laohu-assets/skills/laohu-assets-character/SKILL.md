# 老胡人物资产

## 适用范围与父级继承

仅在用户明确提出人物资产的创作、修改、检查或选择本专项时，由父级加载。通用剧本整理沿父级工作，既有角色资料可作普通依赖。每轮重新判断。本模块使用父级给出的材料范围、既有角色与授权项，局部修改可直接从角色资产起步。范围、ID、组合与最终交付由父级处理。

## 人物归并与依赖

以姓名、关系、行动连续性及独特描述确认身份，将显示称呼归到已核实的人物名和同一基础 ID。若一个称呼可能指向不同角色，保留待核并只查会改变归并的依据。职业、年龄段或角色类型相似时仍凭实际身份归并。用户指定局部对象时照该范围，短暂背景群像只在需复用、连续追踪或用户指定时选入正式资产。

服装绑定实际穿着者。跨画面持续的伤势、妆污、伪装按真实时段作为状态候选，转身、哭笑和手势交给相应画面。人物与状态并用时只评估指定人物；多类组合由父级统合。成片第一视角所见的手或身体局部是派生画面，完整人物身份仍保留头脸和全身。

## 将经历和行动变成可辨体态

1. **先校准头身与年龄呈现。**承接父级已定媒介，分别检查头相对总身高、肩与躯干宽窄、四肢长短和体态在全身中是否读得出来。需要放大童年角色时，可放大头相对身高的比例并保留短肢的重心，避免把完整成年比例只等比缩小。成年或年长角色用材料已经给出的体量、姿态或神情来表达年龄。对脸貌、衣着和伤痕的选择以具体行动及经历为据。
2. **为镜头或常态选择重心。**找角色常做的一件事，再定脚下支点、躯干朝向、目光和一处小表情。例如习惯等对方把话说完的人，可以双脚落稳、胸口略前倾，眼神停在对方身上，眉眼只留将要回应的轻微变化。让姿态承担性格，情绪与微表情可随场面改变。
3. **找换装后仍成立的身份。**从脸形、眉眼、发形轮廓、体型比例、可见的固定特征或习惯体态里，选 3–5 条实际依据足够的高辨识视觉锚点。将临时衣色、配件、持物和本次表演另记；发型或外观已获准变化时，以仍稳定的锚点支撑辨认。已有设计优先核对其实际可见特征，未知的锁定处留待原图或规格。
4. **只比较会混淆的角色。**并列比身高、肩胯或头身差、外轮廓和重心。首次设计可用全黑剪影做三秒可辨的设计预检，确认去掉同款制服、亮色和配饰后仍能从形体认出。剧情允许相似、伪装或同款时先保留相似决定，再看已有或获准的微小差别是否足够。

展示需照顾发形、体量、双手及全身衣装的可见性。写实坐姿与动画、奇幻或强服装轮廓的站姿决策依[人物单格姿态与背景](../../references/image-handoff-and-output.md#人物单格姿态与背景)。按需要指出哪一识别线索被遮挡以及可解决的观察面。默认搭配只给宏观剪裁、整套搭配、色彩和材质。

## 返回父级

交回角色与称呼归并依据、ID 与范围、服装和状态依赖、完整身体与面貌方向、可见重心、已接受和剧情必要的保持项、开放局部、必要精控依据与展示建议。父级按[人物字段](../../references/image-handoff-and-output.md#人物)确定妆造和完整规格，并按用户要求编译和交付。
