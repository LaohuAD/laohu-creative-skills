# 统筹视觉资产的共同方向

宿主确认本轮确需建立原创核心视觉身份、解决群像轮廓辨认、给不同职责的独立资产确定共用美术，或获准重定其中的重要关系时读取。接收已确认的题材、观众、人物行动、复用关系、媒介、既有资产和开放范围。已经采用的同作画风与身份先保留，获准重定的部分进入新设计。

题材和审美方向已给定、委托一套穿搭及其配套物件或单一使用情境时，由类别方法协调具体款式、用材与局部呼应。有多条独立提示词或普通款式由作者自定时仍按此范围处理。作品整体的共用画风或核心身份确有开放决定时，再回宿主选择本方法。忠实编译、常规展现、复现和局部编辑沿已知材料处理，候选盘点与纯声音沿各自原流程。

## 把作品意图变成四项共用决定

先说清观众需从这组资产认出谁、读懂怎样的关系或感到怎样的气质。找到剧本里最能支持它的行为、用途、生活条件或材质线索，据此确定下列四项。用可以直接看见、画出或建模的语言写出每项，避免让“高级”“有氛围”等形容词代替选择。

1. **渲染媒介与质感**。定媒介、出图的笔触或表面处理、细节尺度。纸纤维、描线或体积光等应与本作已经确定的呈现相容。
2. **形体简化与线面**。定大体块怎么概括、哪些转折留线、哪些用色面或材质分界，人物、物件和建筑使用相称的简化程度。
3. **色彩气候与饱和度**。定全作色温倾向、饱和度区间和局部可以偏离的范围，按用途安排共同色彩关系。
4. **光影对比与材质温度**。定明暗分组、转折软硬、高光大小或边缘性质，再给木料、皮肤、布面、金属等材料各自可信的反光与温度。

这四项是同作提示词需要继承的美术约定，沿用已有决定并补足获准的开放处。场景内的光线和人物身份图的中性展示光可分别服务各自用途，仍保持共用的渲染、形面和光影处理。不同作品分别提炼，同作各项保留剧情要求的制服、原有配色、材料和身份差异。只涉及一个资产时，把决定落入该资产的规格。

## 用形体和剪影区分同场对象

人物先看年龄、动作习惯、承担重量的身体部位、衣物或配件形成的外轮廓，再决定大体块、次体块与少量小细节。可用圆弧、方形或锐角组织形体，也可让主辅形相反，表现人物公开姿态和私下行动的差别。圆弧适合表达松弛或包裹感，方块能支撑分量，尖角有明确方向。具体性格来自行为和造型关系，按作品选择形体含义。头身比随年龄、媒介和已接受的造型调整。

道具让主要轮廓先显出拿取、安放或开启的用途，再让次级结构说明操作位置，留下少量对身份有用的连接、修补或标记。地点适用时则用结构体量、主要开口和地标形成远处可读的轮廓。均保留主要材质和真实作用支撑的形体。

同场并列、共同复用或有混淆风险的角色，先把代表视图缩到常用观看尺寸，快速比较相对身高、全黑轮廓、负空间和体态重心。人物可以在服装颜色、五官和道具不提供提示时，仍靠稳定形状或姿态被认出。看不清时先改开放的主形、比例或重心，细节只补在确实能起作用的位置。剧情需要同款、相似伪装或故意难辨时保留这些设定。有阵容草图时可用约三秒初读快速筛查，再按实际观看尺寸核验。还没有图时，把对比作为造型预检和出图后的验收点。

## 安排颜色职责与灰度层次

用主色定阅读气候，支撑色分区或承接材质，强调色只提示真正需要注意的脸部、操作点、地标或叙事信号。有三个颜色职责、且分配面积能解决注意力失序时，可用约 **60/30/10** 起排，随后按镜头阅读、画幅、材料和面积调整。严格沿用已有色板、用户指定色、单色或黑白风格时，直接用原约束分配轻重。即使设定了精确色值或面积，其性质仍是设计目标。

将拟定画面映射到黑白灰，检查主阅读点、承托它的对象或区域、背景三个层次。单色、低反差或气氛浓厚时，先保住关键触发点的明暗边界、边缘或材质反差，再保留场景深处微小的受光与暗部信息。若重要区别仅靠色相成立，补一个形体、明度或纹理线索。各资产共用色彩职责，具体用在哪个部位及占多少由对象决定。

## 留下可跨变化辨认的特征

优先从已有设定和开放的造型选择中提炼每项重点资产三至五个高信息量的稳定视觉指纹，写成可见位置、形状或相对关系。人物可选脸部轮廓、特定五官关系、发形、身体比例和惯常重心。道具可选承重结构、材料交界、固定铭刻或使用印记。场景用入口、路径、地标和相对位置。简单资产按足以辨认的特征数量取用。

把识别项逐一放回真的会遇到的远景、换装、转面、低光、磨损与持续状态，判断会暂时不可见、确实变化或可稳定继承的部分。将会动的衣色、污渍或表情移到状态和用途字段中，把在该视图可维持的特征写进本项保持指令。获准改变外形的状态沿其真实范围交接，基础身份和依赖由宿主保留。

## 返回宿主

回到宿主第四步，把共用的四项决定、按需采用的造型与灰度关系、每项有效识别特征落实到资产规格。第五步用可观察的形、色、材质、光与姿态，将四项共同决定和适用辨认点写进每条相关的独立提示词。逐条对读后，应可用同一组具体画面约定制作出属于同一作品、又按身份和功能有区别的资产。
