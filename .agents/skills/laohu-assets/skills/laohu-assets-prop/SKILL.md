# 老胡道具资产

## 适用范围与父级继承

仅在用户明确提出道具资产的创作、修改、检查或选择本专项时，由父级加载。通用剧本整理沿父级工作，既有道具资料可作普通依赖。每轮重新判断。沿用户指定的物件、材料范围或既有 ID 和修改项工作；局部修改可以直接使用现有道具资料。

## 实物归并与依赖

沿同一件实物的标记、持有人和动作连续性对照称呼。一件物品换了持有人时沿用基础 ID；同类物件有不同来源或识别标记时按实际实体分别追踪。确属可互换、无需逐件认出的物件可用类型规格。一次性陈列保留在画面，除非剧情关键、复用或本轮明确设计使它有独立职责。共享制造语境时可统一材料或形面，用具体接口、已有标记和交接证据区分同款。

确认持有人、所在场景和状态依赖。固定设施归场景，服装组成归服装；界面、图形等确有独立复用职责的部分由父级按用途处理。持续影响辨认的开合、破损或污迹按真实范围交父级判变体，瞬间开合归相应画面；组合只处理指定道具。

## 用结构把功能和经历做出来

1. **找尺度参照和接触点。**先列持有者怎样提、握、开、放这件物品，选择手掌、臂长、身体或周围物件作为尺度锚点。把手的大小写回物体的握把、接口和可见结构。旧维修工具箱可采用成人单手提握的宽把，两侧固定在箱体上缘；成图从本体留出的握持空间判断尺度。
2. **沿一次使用核对受力与活动关系。**从手部接触处追到支撑、主要部件、连接和承托点，并看开启部件的可见运动方向与留空。例如工具箱的提把、两侧固定处、箱底承重关系与后侧箱盖铰接能同时说清“如何提”和“如何打开”。奇幻物件同样要让观看者看到装入、闭合、拆接或支撑关系，按世界规则用可辨的连接形态交代原理外观。仅在复现或剧情依靠具体机构时锁相应精度。
3. **让使用史落到地方。**先做基础功能轮廓和主材料，其次把高频接触或存放史落到边角、握把内侧、落地面等位置，最后选一处主人专属印记。旧工具箱可在常拉搭扣处露出温灰底材，在常接触的角上有克制磨损，在箱盖内沿有一片沿用多年的手缝垫。按角色及经历采用已有痕迹，修改时保住已接受的其余形态和材质。

先在本体主视图核对轮廓能否使人猜到用途，再选能看清主要连接的一面。确有遮挡时说明哪个结构、识别标记或另一侧的证据需要局部图；具体画幅、局部框数量与演示例外依[中央道具字段](../../references/image-handoff-and-output.md#道具)和[项目画布](../../references/image-handoff-and-output.md#项目画幅主图与局部图数量)。

## 返回父级

交回具体物件、ID、范围和归属、主要轮廓、尺度与功能关系、各部位材料和使用史、已定识别锚点、开放的局部与必要精控依据。父级按正式留存情况和本轮交付要求整合规格、展示及提示词。
