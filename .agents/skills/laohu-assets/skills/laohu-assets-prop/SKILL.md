# 老胡道具资产

## 适用范围与父级继承

本配置仅在用户明确提出道具资产的创作、修改或检查工作，或明确要求执行本配置时，由父级加载。通用剧本资产整理不因材料涉及道具就加载；读取已有依赖资料不等于执行对应子级。每轮重新核对适用性，历史加载不自动沿用。父级独立具备各类完整方法，仍负责范围、ID、跨类别组合和最终交付。

## 专项判断与可见贡献

沿物件受力、开合或使用关系核对组件如何连接，选能看清接口的视角；把整体轮廓与必要结构局部对应，区分同类实物的身份锚点。道具图默认只有本体，不因持有人信息画手或人物。

本配置返回专项判断，展示规格以父级[固定资产字段](../../references/image-handoff-and-output.md)为准；不递归加载其他配置，也不因普通依赖扩大任务。

## 确定本次任务

按父级提供的剧本/资产范围处理；用户点名某件物品时只判断它。修改已有物件可以不提供剧本，直接以既有 ID 与本轮修改为输入，未说明的特征保持原样。

## 确定道具资产

### 识别与筛选

判断具体物件是否被复用、需连续追踪、或用户明确要求设计。一次性用品或临时陈列默认留在画面描述，不为每个物件建资产；剧情关键、后续必须认出的物件即使只在短范围出现，也可保留。类别相同不代表实体相同：“两把钥匙”只有在身份、标记或连续动作支持时才能归并。

### 归并复用

将材料显示称呼映射到唯一具体物件名及既有/新 ID。刻痕、独特色块、序号、持有人和前后动作可用来区分实物；同一件物品换了持有人仍沿用基础 ID。若有多件可互换且不需逐件识别，可用一个类型规格描述，不把道具类别冒充为同一具体资产。

### 固定项与变化

按[方向字段](../../references/image-handoff-and-output.md)确定用途、宏观轮廓、主要组件与合理连接、大小感、色彩、材质倾向和纹样大类；优先保证能工作、可辨认。普通局部结构和表面细纹可由模型补足，不为每个道具展开尺寸表。仅用户精控、已选实物复现或剧情识别/功能必要时，细化关键标记、机构、比例与位置。

本体完整展示，必要局部对应同一物件；不因持有人资料加入人物或手部，明确使用演示时才加入。屏幕与机身分属不同职责。开合、破损或伤污按持续需要判断，瞬间动作留在画面。

## 与其他资产的关系

记录必要的持有人、所在场景和状态依赖；地点固定结构归场景，服装部件归服装。确有独立复用职责的界面/图形等特殊对象由父级按实际职责归类。与状态组合只作用于指定道具，不自动扩展到所有物件；类别并列由父级统合，子级不递归调用。

## 返回内容与交付检查

回传本类别对象、ID、范围与归属、主要方向和关系、已接受或剧情必要的保持项、开放局部与必要精控依据，以及类别展示要求。人物仍有完整身体与面貌身份；其他类别不以字段齐全强制细节穷举。只对正式资产设计，候选保持轻量；不越过父级生成未授权提示词，不把设计文本说成已生成图片。
