# 原创虚构生物形象与写实参考图

仅当用户明确要求设计原创虚构生物、怪物、外星生物、亡灵或战斗兽形象，或点名本专项时由父级加载。普通人物、拟人卡通角色与通用剧本盘点不触发；下文的写实三阶段工艺进一步要求本轮确需片场实拍照片质感。造型、焦点、材样职责与选定工艺交回父级按 [中央视觉规范](../../references/image-handoff-and-output.md) 登记基础资产并交付完整提示词。

## 原创生物设计分支

### 设计角色

只取解决当前问题的维度；用户仅要外形时，职责与配件保持开放：

1. **角色职责**：以世界内的职业或处境定重心与日常物件（如铁匠、收税人、摆渡人、守夜者或朝圣者）。
2. **供体生物（2–3 种可指认真实物种）**：主供体定头脸（如山魈、鲨鱼、猫头鹰）；次供体定鬃毛、甲壳、角等大轮廓（如鬣狗鬃毛、驼鹿角、穿山甲鳞）；第三供体仅补局部细节（如蝙蝠耳）。写具体物种名，不用泛称。
3. **八选一主混合连接**：① 部位替换（前肢化为螳螂虾螯）；② 栖居天然或器物壳体（沉船铜钟或巨贝）；③ 体表异质生长（蜂巢结构替代发形）；④ 下半身异种；⑤ 完整动物承担人类身份；⑥ 器物化作可见器官；⑦ 蜕皮探出；⑧ 寄生或共生（苔藓与飞蛾栖于毛皮）。写清连接起点、过渡融合面、延展方向与剪影贡献。
4. **经历痕迹**：挑一处有因果的可见印记（旧疤、修补铜片、抵押挂件或风化缺口）落到显眼部位。
5. **静止存在感**：用沉稳有重心的静态姿势显身份（如扶杖而立、矮凳前倾肘抵膝、掌心护小物、微侧回望），同时让脸部与核心连接部位完整可见。
6. **自然色盘**：从真实物种取 1 个主色、1 个辅助色，配**唯一一处明亮强调色**。
7. **生命尺度**：给出真实身高米数，并配一件日常物件（矮凳、杯子、铁桶或塑料椅）作直观尺度锚点。

### 质量规则

- **3 秒全黑剪影**：先以全黑轮廓核对能否瞬间认出物种混合特征与职责，再细化表皮纹理。
- **大中小体量节奏**：1 个主体块、2–3 个次体块、少量小块不对称分布，结合面与重心一眼可读。
- **功能解剖自洽与 70/30 法则**：大角须有厚实颈肩支撑，掘地者须具厚重前肢；保留约七成可信真实解剖结构，将约三成预算集中给选定的奇异连接，让怪异长得像真能活下去的生物。
- **保留尊严**：即便怪异、年老或残破，仍给予沉静眼神、克制举止或珍视物件，不流于廉价丑怪。
- **单一主焦点**：在脸眼或核心标志物里选唯一主焦点，将唯一亮色精准压在该部位。

### 题材提示

| 题材 | 高辨识自然参照方向 | 必给的画面证据 | 重点避开的俗套 |
|---|---|---|---|
| 战斗兽 | 甲虫重甲、鳄龟、象海豹、科莫多巨蜥的轮廓与盾甲 | 靠轮廓、旧铁木革挽具与阵营标记区分冲撞/盾卫/攻城职责；甲面留旧疤与缺口 | 无功能尖刺、模板长角恶魔、崭新无痕盔甲 |
| 外星生物 | 脆蛇尾、管水母、鹦鹉螺、天鹅绒虫、黏菌等非对称构造 | 放射状肢体、群落态或体段代头颈；用人类布条、挂牌或旧装备给尺度与归属 | 大头小灰人模板、廉价发光眼 |
| 亡灵 | 溺水、冻土、沼泽、盐壳、赤陶或菌丝保存状态 | 写实走 A 轨成年原创供体保同一张脸；一句写透皮肤/眼/唇的保存质感，靠平静神色与私物叙事 | 血迹与烂伤口盖满画面 |
| 黑暗史诗奇幻 | 借河马皮、象皮等实材触感重塑兽人、巨魔或精灵 | 独立原创剪影、头饰与职业随身物，真实毛孔与厚重材质过渡 | 橡胶面具感、戏服假尖耳、照搬现成 IP 形象 |

**高端实拍质感三问**：画面能否让人立刻看出它靠什么履行职责、经历过什么、属于哪一方？缺少的大结构在灰模阶段定死，表皮微细节留到照片化阶段。

### 本地调用：确定本项主焦点

从脸眼或具核心职责的既有物件中确定唯一主视觉焦点，把唯一明亮强调色精准落在该具体部位，写入设计、色彩与识别保持项交回父级；优先从已有外形找落点，仅确需支撑职责时才添物件。

## 写实生物参考制作分支

### 阶段顺序及分支

目标是片场拍到的真实活物感，遵循**模型无关的三阶段工艺**：造型设计 → 第一阶段灰色黏土造型图 → 第二阶段人类/动物面貌供体（A/C 轨必做，B 轨按需）→ 准备真实材料微距样本 → 第三阶段多图职责绑定照片化 → 最终照片核验。已有适用参考直接复用，高分辨率出图建议 2k 级；未获实际出图授权时交齐各阶段独立提示词与附件职责清单，不假称已生成。

| 轨道 | 适用对象 | 工艺链路 |
|---|---|---|
| **A. 类人混合** | 含人脸或人皮的半人、异种长者、兽人、精灵、亡灵 | 灰模 → 成年原创人类供体 → 灰模 + 供体 + 材料样本转照片 |
| **B. 纯非人生物** | 无人类皮肤的动物角色、器物生物、外星生物、深海怪 | 灰模 → 灰模 + 材料样本转照片（有动物脸时可补野生动物面部参考） |
| **C. 天然材料服装** | 成年人面貌、身着贝壳/羽毛/虫翼等手工自然材质服装 | 灰模（锁服装组织与姿态） → 成年原创人类供体 → 三类参考合成照片 |

**实材样本底线**：正式保真照片化三轨均**至少接入 1 张真实可读的写实材料样本**（优先 2 张承担不同质感分工，实拍近照与已生成可读样张均可）。仅规划文字或仅有灰模缺实材样本时，须标明先作外观预览与待补材清单，不冒充正式保真照片化。

### 第一阶段：灰色黏土造型图（文字转图像）

先用无色哑光灰模锁死剪影、比例、姿势与混合连接，排除颜色干扰。画幅依构图选定：突出头脸半身用 `16:9` 胸像，全身与服装用 `3:4`，宽体或长形生物用 `4:3`；正式身份图需全身时从本阶段即保持全身。

```text
数字雕塑渲染，一尊未上色的哑光灰色黏土造型。<主体与有重心的姿势>，<脸部；A 轨写“清晰可见的人类脸”>，<混合部位的起点、过渡与轮廓连接>，<确需的两到三件职责物件>。腰部以上胸像，正面朝向镜头，形体填满画面。全体为单一未上色哑光灰色黏土材质，细节集中于连接与主焦点。单个形体、单一视图，黑色背景中完整呈现形体，柔和主光与轮廓光，主体承接自然姿势，画面中无底座、无文字。
```

全身构图将取景句替换为“全身，正面偏四分之三视角，剪影有力，形体填满画面，真实生命尺度比例”。需第二姿势或三视图时以选定灰模作参考并写明“完全相同的生物”。先验剪影可读、脸部无遮、单一灰材与真实连接，再进入下阶段。

### 第二阶段：人类供体（仅 A、C 轨）

独立准备或复用获准使用的成年原创真人面貌（一角色一供体），年龄、体格、神情与胡须匹配灰模，用 `2:3` 头肩近墙直闪格式保证与成片光语境一致：

```text
手机闪光灯照片，头肩肖像，<年龄、族裔、三到四项面部特征、头发或胡须、衣服>，自然面部比例，靠近深炭灰墙站立，镜头正面闪光，墙上有硬阴影，真实皮肤纹理、毛孔、轻微噪点。
```

B 轨需明确动物脸细节时，用“真实的 `<物种>`，按野生动物摄影方式拍摄”准备清晰面部参考，只取指定皮肤、鼻部与皱褶。

### 第三阶段：皮肤处理

以灰模锁几何姿势、供体锁人脸毛孔、各材料样本锁命名部位，按实际工具参考上限依序输入（建议顺序：图 1 灰模、A/C 轨图 2 供体、其后为各材料样本，图号以实际附件为准）。**硬质（甲壳/角/青铜）、柔软（皮肤/毛皮/织物）、湿润半透明（黏膜/眼球/积水）三类纹理各落对应部位形成质感对比**；C 轨确保服装手工实材完整覆盖胸臀，脸貌稳定后不再重复重塑整张脸。

```text
以本阶段附上的灰色黏土造型作为底图，完全保持<姿势、比例、构图和已雕出的结构>，把灰模变成一张<对象>的真实照片。
<仅 A、C 轨：脸部、皮肤和头发采用附上的同一成年原创人物的面貌、皮肤和毛孔>。
<部位>采用附上材料图中的<具体材料>，呈现<颜色、纹理、使用状态>。
<其他部位>呈现真实的<明确物种表面>，<颜色、纹理、湿干或使用状态>。
<服装与具体材料，必要的随身小物及使用痕迹>。<明确部位的一个强调色>是唯一亮色。
<照片呈现区块>。
```

#### 照片呈现区块

切换摄影区块即可改变成片语境，主体、供体与材样保持不变（越奇异的造型越适合朴素近墙直闪建立真实生命尺度）：

- **化妆测试照**（适合干净特效试妆展示）：
```text
实景特效化妆测试照：正面直闪，深灰色无缝背景纸，闪光在纸上投下清晰硬阴影，光线不均。一台真实摄影机，浅景深。表面反光克制，保留肌理与形面，呈现可拍摄的真实活物、实物服装与试妆质感。
```

- **手机快照**（追求最高实拍感默认）：
```text
昏暗房间里的随手手机闪光快照。主体在磨损的水泥地上，靠近深炭灰墙。正面硬闪在墙上留下清晰黑影，光线快速衰减，保留轻微噪点和自然低饱和。按真实生命尺度拍摄。<按实际主体选择可见毛孔、散落毛发、甲壳或皮膜等细节>，以适合现场的少量灰尘与轻微不对称表现真实材质。完整保持参考的姿势与构图。
```

巨型生物可置入昏暗水泥仓库配钢门或普通塑料椅建尺度；类人出现微缩模型感时采用约 35mm 视角、较深景深与从头到脚清晰落地修正。

### 材料样本

为关键表面准备 `1:1` 极近微距实拍或已核样张，一张只对应一个命名部位：

```text
真实<材料>的极近距离微距照片，材料从边到边填满整个画面，<颜色、纹理、使用状态>，直接硬闪，焦点清晰，真实纹理，无文字。
```

选材可沿 **10 类真实质感谱系**自由发散具体物种与年代状态（每类仅列启发例，按世界观自由选取真实自然材料）：
1. **厚皮与两栖肤质**（河马皮、蟾蜍皮、鳄鱼背皮、玻璃蛙、疤痕肌理）
2. **毛发与粗鬃**（斑鬣狗鬃、牦牛长毛、野猪刚毛、打结湿发）
3. **羽翼与薄膜**（渡鸦羽、仓鸮绒羽、蝙蝠翼膜、月蛾鳞翅）
4. **鳞甲与几丁质**（穿山甲鳞、椰子蟹壳、赫克力士甲虫鞘翅、棘蜥棘皮）
5. **骨角与齿喙**（泛黄多孔旧骨、驼鹿角、海象牙、野猪獠牙）
6. **保存组织与遗骸表层**（风干木乃伊皮、沼泽鞣化皮、盐壳、火山灰覆层）
7. **海洋与软体组织**（藤壶贝壳群、玻璃海绵、海蛞蝓、湿滑水母胶质）
8. **植物与真菌附生**（长苔橡树皮、烧焦炭木、灵芝菌丝、枯莲蓬、蜂巢）
9. **风化金石与器物**（绿锈青铜、珊瑚覆黄铜、热变色锻铁、开片瓷、长苔花岗岩）
10. **旧织物与手工饰材**（上蜡沾尘帆布、破麻袍、旧熟皮甲、失光刺绣锦缎、漆面木具）

**虚构材料拼法**：选定 1 种真实自然基底 + 仅叠加 1 项颜色、尺度、生长阶段或附生变化（如带开片青瓷裂纹的几丁质、裂隙积灰的炭化穿山甲鳞），维持实材受光逻辑。

### 问题—修正对应表

| 失真现象 | 根因定位 | 定向修正动作 |
|---|---|---|
| 人脸发蜡或像漫画 | 未用独立真人供体或供体夸张 | 换自然比例、带真实毛孔与微不对称的成年原创供体 |
| 像桌面手办或渲染图 | 柔光棚拍、背景太空或无尺度物 | 切近墙手机直闪区块，补地面落点、35mm 深景深与日常尺度物件 |
| 浑身脏棕难分辨 | 缺明确色盘与焦点控制 | 锁真实物种主辅色 + 单一主焦点亮色 |
| 皮肤像塑料或骨像标本 | 泛称材质且缺年代肌理 | 写清具体物种/年代氧化状态并绑定对应实材微距样本 |
| 像 T 字雕像或动物部位悬空 | 灰模缺重心或接合面未写清 | 灰模定稳重心姿势，明确长出起点、皮肉过渡与替代部位 |
| 出现双人、转面图或误带文字 | 参考被误读为多视图或带字 | 灰模声明单个形体、单一视图、无底座无文字，照片化明确去除残留字样 |
| 脸被角/翼遮挡或仙子像派对服 | 取景冲突或直套现成服装照 | 灰模将角翼后置露出完整脸；C 轨靠灰模控手工衣型覆盖、供体锁脸 |

### 最终照片检查

交付或复核实图时逐项过九关：① 近墙直闪与清晰硬影成立；② A/C 轨人脸自然毛孔且吻合供体，B 轨物种表皮真实；③ 硬/软/湿三类纹理反差清晰；④ 仅一处主焦点亮色且余色自然；⑤ 姿势构图忠实灰模；⑥ 实材受光无多余光效、服装覆盖完整；⑦ 真实生命尺度与地面落点成立；⑧ 一眼读出职责、经历与归属；⑨ 读出至少两种物种线索且照片化接入至少一张真实材样。只交提示词时，块外如实写清待附参考与尚未出图状态。
