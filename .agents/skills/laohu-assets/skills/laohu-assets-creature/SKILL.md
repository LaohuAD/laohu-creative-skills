# 原创虚构生物形象与写实参考图

## 适用范围与父级继承

用户明确要设计原创生物、怪物形象或本专项时，由父级加载。普通人物、拟人卡通角色、局部复现及剧情里只提到怪物的通用盘点，沿父级实际工作范围判断。照片级工艺进一步要求本轮确实需要片场照片感及参考输入。已有风格、身份、构图和正式交付范围优先。

输入包括作品世界、主体在画面承担的职责、用户已定的媒介和能读取的参考图。本专项设计影视、动画或游戏里虚构生物的可见外形。物种借用落实为画面的比例、形态连接和表面，道具用于体量对照或叙事身份。把造型、焦点、材料、对应的实有参考及选定工艺返回父级第四、五步，由父级按[固定资产字段](../../references/image-handoff-and-output.md)处理基础人物或非人形角色的身份、画幅与视图。后续若获准成图，再交有实际参考能力的图像工具执行。

## 原创生物设计分支

### 设计角色

只用能够解决本项设计问题的抓手。用户只要求生物形态时，职责、配件和未开放的身份信息可以留空。

1. **角色职责**　从它在世界里的工作或处境选姿态和可能携带的日常物件，如裁判、媒人、收税人、铁匠或朝圣者。
2. **供体生物**　选两到三种可指认的物种。第一种提供头脸，如山魈、鲨鱼或猫头鹰。第二种提供鬃毛、甲面或角等主要轮廓，如鬣狗鬃毛、驼鹿角、穿山甲鳞片。第三种只提供局部特征，如蝙蝠耳。描述用棘蜥、鲸头鹳等具体形象。
3. **混合连接**　从八种方式选一种主连接。①替换部位，如前肢末端呈螳螂虾螯状。②身体栖居于天然或拟物壳体，如铃体或贝壳。③在身体表面长出另一种结构，如蜂巢外形替代发形。④下半身属于另一物种。⑤完整动物承担人类角色，如狐狸商人。⑥物件成为可见器官。⑦蜕皮，如从自己的旧皮中探出。⑧寄生或共生的外观，如苔藓和飞蛾栖在毛皮中。说明连接起点、过渡处、延展方向和该结构的轮廓作用。
4. **经历**　选一处具体痕迹，如旧疤、留下的纪念物、补丁或一件因债务而保存的抵押物，落到能看见的地方。
5. **存在感**　以静止而有重心的姿势展示身份，例如手肘搭在膝上的矮凳坐姿、双手藏袖而立、手扶立地木杖、回头、蹲着持长烟斗、低头从眉下看镜头、不看镜头地喝茶、手托自己的面具、掌心喂小生物。留出让脸与主要连接可见的角度。
6. **自然色盘**　选来自真实物种的一个主色、一个次色和唯一一个明亮强调色。
7. **尺度**　在设计中给身高米数并配一个日常物件，如矮凳、杯子或旧工具箱，让观看者能估计整体大小。

### 质量规则

- **剪影**　先用全黑轮廓核对三秒内能否辨认主体和主要外形，再推纹理。
- **大中小体量**　一个主体块、两到三个中等块、少量小块；用不对称分布形成节奏，结合面、主焦点和重心都应可读。
- **形态与用途对应**　大角由足够厚实的颈部视觉支撑，岩土挖掘者以厚实前肢表明习性。保留有明确外形和角色用途的部分。
- **70/30 解剖**　保留约七成可读的真实解剖，用约三成集中呈现选定的奇异连接。以形面和动作读法判断，比例是造型方法。
- **尊严**　即便异形或有年代痕迹，也给它平静神色、谨慎举止或珍爱的物件，让角色能被理解。
- **一个焦点**　在脸眼或确有辨认作用的一处物品选主焦点，把唯一亮色落在同一个具体部位。

### 题材提示

| 题材 | 视觉材料 | 画面要给的证据 | 易失效的造型 |
| --- | --- | --- | --- |
| 战斗兽 | 赫克力士甲虫、夹颚蚁、投弹甲虫、鳄龟、蜜獾、象海豹、科莫多巨蜥的轮廓与甲面 | 用身体轮廓、旧铁木革挽具、礼仪或阵营标记区分虚构职责，如冲撞者、盾卫或攻城兽；用外观上的旧疤、划痕和护具缺口表现经历 | 无功能的尖刺、俗套长角恶魔、缺少使用痕迹的崭新甲面 |
| 外星生物 | 脆蛇尾、管水母、乌贼、鹦鹉螺、天鹅绒虫、玻璃海绵、海蜘蛛、黏菌 | 选非人类对称结构，如五条放射肢、群落形态或以体段代替头颈；用缎带、夹克或头盔提供尺度和归属 | 大头类人、小灰人模板和发光眼睛 |
| 亡灵 | 溺水、冻结、沼泽、盐、灰、赤陶、菌丝或根系带来的化妆视觉状态 | 写实采用 A 轨，成年原创供体保持同一脸；一句写清皮肤、眼睛、嘴唇的状态，附相应表面样本，让神色和平静私人物件叙述经历 | 血迹和伤口主导画面 |
| 黑暗史诗奇幻 | 兽人、哥布林、巨魔、矮人或精灵的题材氛围，如兽人面部借河马皮的触感 | 写实采用对应供体脸貌及皮肤样本，用原创剪影、头饰、随身物件和职业关系呈现身份 | 橡胶面具感、戏服尖耳和可辨的现成系列角色 |

**“昂贵电影”三问**　画面能否读出它用什么履行角色职责，已经经历过什么，以及它属于谁？根据用途选一处动作工具、挽具标记、旗帜或制服提供证据。缺少的关键信息在雕塑阶段解决，表面才看得到的小特征留到照片化阶段。

### 本地调用：确定本项主焦点

从脸与眼或确具标志职责的既有物件中选一个主视觉焦点。其余已定锚点作为次要辨认信息保留。把唯一明亮强调色落在主焦点同一个部位，写入本项设计、识别与保持项及色彩字段，交父级编入完整提示词。先从现有外形找落点，只有形态和角色需要时才增加物件。

## 写实生物参考制作分支

### 阶段顺序及分支

目标是片场拍到的真实活物感。遵循造型设计、灰色黏土造型图、人类面貌供体（A、C 轨）、各主要材料样本、参考合成照片、最终检查的顺序。已得到且适用的参考可复用；已有单格展示、用户比例或风格锁定优先。另有制作授权时，沿阶段读取并展示真实结果，以它们作下一阶段参考。检查失败后针对单个区块修订再试，避免直接重复原指令。

| 轨道 | 对象范围 | 参考流程 |
| --- | --- | --- |
| **A. 类人** | 含人脸或人类皮肤的半人类、带动物部位的长者、兽人、精灵 | 灰模 → 成年原创人类供体 → 由灰模、供体和材料样本转照片 |
| **B. 生物** | 无人类皮肤的动物角色、物件生物、蘑菇、鱼或外星生物 | 灰模 → 由灰模和材料样本转照片；有动物脸时可增明确职责的动物脸样本 |
| **C. 天然材料服装** | 具有成年人物面貌、穿贝壳裙、羽毛或翅膀服装的女性与仙子 | 灰模 → 成年原创人类供体 → 由灰模、供体和材样转照片；灰模负责服装组织与姿态 |

三轨照片化均至少接入一张合适、实际可读的写实材样图，优先两张有不同作用的样本。实拍近照与已生成的可读写实材样都可按其实际职责使用。指定还原某件实物的部位时，采用能证明该实物表面的真实来源图。缺关键样本先准备。A、C 轨面貌与人类皮肤来自可辨的供体。越奇异的形态越需要朴素的摄影语境，可选素墙、正面闪光与硬阴影来建立真人尺度。能力不支持参考输入或保形时，仍可交已完成的设计和分阶段提示词，精确照片化留给可接收必要素材的下游。

### 第一阶段：灰色黏土造型图（文字转图像）

先用单色灰模确定形体、比例、姿势、接合和体块。需要探索时，可用擅长复杂形体、轮廓清洁或面部体态的不同方法比选；先按剪影、脸部、局部连接和单视图清晰度选可用构型。脸为主要焦点且允许半身时可用 `16:9` 胸像，全身服装用 `3:4`，横向宽体四足生物用 `4:3`。进入下一阶段前定构图，照片化沿用实际灰模比例；正式身份图需要全貌时从这一阶段就保持全身。

```text
数字雕塑渲染，一尊未上色的哑光灰色黏土造型。<主体与姿势>，<脸部；A 轨写“清晰可见的人类脸”>，<混合部位如何连接>，<本轮确需的两到三件职责物件>。腰部以上胸像，正面朝向镜头，形体填满画面。全体为单一未上色哑光灰色黏土材质，细节集中于连接与主焦点。单个形体、单一视图，黑色背景中完整呈现形体，柔和主光与轮廓光，主体承接自然姿势，画面中无底座、无文字。
```

全身图将取景一段换为“全身，正面偏四分之三视角，剪影有力，形体填满画面，真实生命尺度比例”。小型或长形生物把主体拍大，尽量充满适合轮廓的画面。此阶段只写未上色单一灰材。用户需要第二姿势或三视图时，用实际已选的灰模做身份参考，并写“完全相同的生物”及新姿势，或“同一形体的三个视图并排在一张图上”。

检查选出的灰模是否具备易读剪影、可见脸部、单一灰材以及真实可见的混合连接。若失效，针对几何说明或观察面改写后复查。

### 第二阶段：人类供体（仅 A、C 轨）

供体独立制作或在已有可读并获准使用的成年原创人物图上选取。一个供体对应一个角色。年龄、体格、情绪和胡须应与灰模一致。用 `2:3` 头肩形式，让供体与最终照片具有相容的闪光语境。

```text
手机闪光灯照片，头肩肖像，<年龄、族裔、三到四项面部特征、头发或胡须、衣服>，自然面部比例，靠近深炭灰墙站立，镜头正面闪光，墙上有硬阴影，真实皮肤纹理、毛孔、轻微噪点。
```

人类供体使用成年原创面貌，确保真实照片质感。脸骨比例、鼻、嘴或齿列有变形时，换用正常比例的可辨供体。B 轨若有动物脸，用“真实的 `<物种>`，按野生动物摄影方式拍摄”准备清楚的面部参考，只使用指明的皮肤、鼻部和皱褶。

### 第三阶段：皮肤处理

以灰模为底，保住姿势、比例、构图和几何，按上一步的供体和实际材样转为照片。工具宜支持多参考、保形和局部角色绑定。工艺建议的真实参考顺序为灰模第一，A、C 轨的人类供体第二，其后是材料样本。按当前工具真实输入上限和可用参考决定张数，先满足本轨必需的保形和面貌职责，再为各指定部位选最能说明用材的真实样本。图号以实际文件与顺序为准。

在第三阶段交接中，列清已经可读、符合部位与质感的实际材样图，另记待拟制或待取得的样张。只交设计时照常给完整词，并列清灰模、供体和材样的使用要求。仅有素材计划、或已有灰模但缺合适材样时，可先用灰模与文字做外观预览，标明预览与补材动作。正式保真照片化至少接入一张已实际可用、适合对应部位的写实材样图，再按所选轨道满足保形、面貌和其他必需职责。单次输入不足时，使用确能保住主体关系的分步处理，或留作待实际接口和材料满足后执行。

```text
以本阶段附上的灰色黏土造型作为底图，完全保持<姿势、比例、构图和已雕出的结构>，把灰模变成一张<对象>的真实照片。
<仅 A、C 轨：脸部、皮肤和头发采用附上的同一成年原创人物的面貌、皮肤和毛孔>。
<部位>采用附上材料图中的<具体材料>，呈现<颜色、纹理、使用状态>。
<其他部位>呈现真实的<明确物种表面>，<颜色、纹理、湿干或使用状态>。
<服装与具体材料，必要的随身小物及使用痕迹>。<明确部位的一个强调色>是唯一亮色。
<照片呈现区块>。
```

逐图分配职责。灰模控制几何，供体控制指定脸貌，材料样本各对应一个命名部位。用眉骨、獠牙或胡须等已雕出的特征说明需保留的形体；材料注明来源及同一部位的颜色、纹理和使用状态。灰模未表达的服装甲面、纪念物和小细节可由正文补入。将硬质（几丁质、角、青铜）、柔软（皮肤、毛皮、布料）及湿润或半透明（黏液、膜、眼睛）放在真正承担该质感的部位。混合脸区分人物的眼睛、额头、皮肤与动物部位，说明毛或鳞从相邻皮面自然接合。若灰模原图带座或标题，明确去除并呈现实际站立地面和无字画面。

C 轨保留姿势、构图、服装结构及真实成年人的身体比例。服装做成真人手工制作的自然材料，边缘微有不齐和使用痕迹，完整覆盖胸部与臀部。供体负责脸、皮肤和头发，灰模负责衣装和姿势。已有效完成一次照片化后，保护已稳定的供体面貌，避免反复重塑整张脸。亡灵紧跟供体职责写皮肤、眼睛、嘴唇的具体外观变化，同一供体的结构与身份继续保留。

#### 照片呈现区块

只切换下列摄影区块即可改变照片风格，造型、面貌和材样保持同一组。板式或用户已定语境优先。

**化妆测试照**用于干净展示或特效试妆表。

```text
实景特效化妆测试照：正面直闪，深灰色无缝背景纸，闪光在纸上投下清晰硬阴影，光线不均。一台真实摄影机，浅景深。表面反光克制，保留肌理与形面，呈现可拍摄的真实活物、实物服装与试妆质感。
```

**手机快照**是追求最高照片真实感时的默认方式。沿随手拍摄的现场光线和构图建立日常记录感。

```text
昏暗房间里的随手手机闪光快照。主体在磨损的水泥地上，靠近深炭灰墙。正面硬闪在墙上留下清晰黑影，光线快速衰减，保留轻微噪点和自然低饱和。按真实生命尺度拍摄。<按照实际主体的表面选择可见毛孔、散落毛发、甲壳或皮膜等细节>，以适合现场的少量灰尘与轻微不对称表现真实材质。完整保持参考的姿势与构图。
```

用直接硬光、墙面距离、材质的磨损和污垢建立真实拍摄环境。成图偏向渲染感时，先查是否用了柔和影棚光或纯黑、缺乏实体墙的背景，再改用能承接短距离硬阴影的近墙直闪与普通室内尺度。巨大体型可放在昏暗的水泥仓库，开头给真实尺度高度，并以普通灰塑料椅、钢门或屋顶管道作尺度证据。类人出现桌面微缩感时采用约 35mm 的取景观感、较深景深、从头到脚保有清晰度来给出真实生命尺度。

### 材料样本

为关键材料准备各一张 `1:1` 实材极近特写，可复用同一场制作中已确认的同材样本。用一个样本对应一个名称和部位，先核实纹理与目标外观是否相容。

```text
真实<材料>的极近距离微距照片，材料从边到边填满整个画面，<颜色、纹理、使用状态>，直接硬闪，焦点清晰，真实纹理，无文字。
```

以下为构思和准备材样时的十类候选。照片化阶段只绑定实际素材。

- **皮肤与皮革：**蟾蜍皮、带吸盘的章鱼皮、鳄鱼背皮、鮟鱇鱼皮、犀牛皮、大象皮、河马皮（可用于兽人皮肤）、老人皮肤、山魈脸部皮肤、鲨鱼皮、秃鹫裸露皮肤、科莫多巨蜥皮、鬣蜥皮、变色龙皮、墨鱼皮、海鳝皮、鲶鱼皮、狗鱼皮、独角鲸皮、巨型蝾螈、墨西哥钝口螈、玻璃蛙、箭毒蛙、海星皮、疤痕组织。

### 问题—修正对应表

| 问题 | 检查位置 | 修正 |
| --- | --- | --- |
| 人脸发蜡 | 人脸由照片化工具自行重画 | 用成年原创供体作独立输入，明确其面貌和纹理职责 |
| 形体像摆件 | 柔软布光、背景空间过空或缺少尺度证据 | 改用靠墙照片呈现区块，写真实生命尺度，加入实际比例物件 |
| 全棕或生物之间难区分 | 色盘由工具随机选择 | 以真实物种颜色为主辅色，单独配置一个焦点亮色 |
| 皮肤像塑料 | 泛称材料且缺局部质地证据 | 写具体物种、颜色、纹理、使用状态并绑定材样 |
| 形体像 T 字雕像 | 灰模阶段无姿势设计 | 用贴合角色职责且有重心的姿势固定灰模 |
| 脸被翅膀或角遮挡 | 灰模取景与局部范围冲突 | 标明脸完整可见，翅膀放在身后并选能看到脸的角度 |
| 动物部位似乎悬在身旁 | 工具回到熟悉形状 | 在灰模写明从哪长出、在哪融合、替代哪个部位 |
| 出现双主体或转面图 | 工具将角色参考理解为多视图 | 写“单个形体、单一视图”并复核灰模 |
| 雕塑像卡通摆件 | 工具或描述弱化了真实比例 | 用能保持动物比例与细节的方式重做，强调生命尺度、单一可读形体和真实受力感 |
| 细长生物显得过小 | 画幅或取景留空过多 | 改用相容的 `4:3`，让主体填满画面 |
| 画面出现标题字样 | 灰模带字或工具误加标题 | 灰模声明无文字、无标题，照片化明确去除原画面文字 |
| 骨像洁净教学标本 | 缺少材料年代 | 绑定旧骨样本，描述泛黄、多孔、开裂、附土后的表面 |
| 仙子像派对服装 | 从照片直接套服，缺可读衣装结构 | 采用 C 轨，由灰模保衣装，供体保面貌，材样落实手工实材 |
| 供体近似漫画脸 | 面部参考夸张 | 换成自然成人比例、可辨毛孔和不对称小细节的供体 |
| 服装设计不完整或过于接近已有角色 | 形体描述遗漏覆盖范围或借用他人专属造型 | 补齐实际服饰覆盖，重做原创剪影、头饰、标志物与角色职责 |

### 最终照片检查

1. 照片感是否成立？靠墙位置、正面直闪和墙上硬阴影应清楚。
2. A/C 轨的人脸是否有真实毛孔和自然不对称，且与实际供体一致？B 轨复核动物或非人形的实际表面。实际使用了非人脸参考时，核对已分配的皮肤、鼻部或皱褶。
3. 硬、软、湿三类纹理是否可区分？
4. 是否只有一处明亮强调，其余色彩来自真实物种？
5. 姿势与构图是否沿用已确认灰模？
6. 是否保持实材表面和无额外光效？有服装时，是否实现了已定覆盖？
7. 真实生命尺度、清楚的落地关系和非微距取景是否成立？
8. 它用什么履行角色职责、经历过什么、属于谁，能否从画面读出？
9. 混合生物是否读得出至少两种动物线索？照片化是否实际使用至少一张材料样本？

有真实成图且获准制作时，按失效证据只改相关区块再检查。只交提示词时，逐条核对设计指令与附件依赖，将出图和检查状态写在块外。

### 历史平台适配注记

以下是旧项目中这套照片级流程的工具搭配，供指定同一工具及可用接口的项目回查。新项目先确认实际支持的画幅、参考张数、保形及图像编辑能力。平台名称和版本经验留在适配说明中。

- **历史总设置**　全部阶段采用 2k。旧灰模批次轮换 `seedream_5_5`、`recraft_v4_1`、`soul_2`。前者作精确解剖与服装的默认选择，复杂和巨型生物优先。`recraft_v4_1` 轮廓较干净，圆润或可爱形体易偏卡通，旧适配加 `realistic not cartoon`，若误加标题则灰模写无标题、照片化移除文字。`soul_2` 适合人脸和姿势，遇额外腿、角等形态可能简化；历史开头为 `ZBrush digital sculpture render, unpainted matte grey clay statue of ...`，明确“单个形体、单一视图”以减双人物或转面结果。必要时换 `seedream_5_5` 重做，要求真实动物比例和生命尺度。
- **历史面貌和材样**　`2:3`、2k 的成年供体照采用 `soul_2` 或 `soul_cinematic`，前者用于自然脸，后者用于个性更强的面貌，夸张为漫画脸时改用 `soul_2`。每种材料用 `soul_2` 制作 `1:1`、2k 写实近照样张，至少一张、优先两张，同一制作会话中复用。
- **历史照片化**　`seedream_5_5` 作 2k 照片化，图 1 灰模，A、C 轨图 2 为供体，后续为材料样本，最多六张。该模型曾有自行出人皮产生蜡感的问题，沿用独立供体。历史使用“变成一张真实照片”及排除雕像、黏土、CG、玩具、插画、微缩摆件的工具适配来转变过于像玩具的造型。真实尺度仍由取景、落地关系和日常物件建立。C 轨历史经验为仅作一次皮肤处理以保护脸部质量。
