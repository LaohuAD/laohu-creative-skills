# 把画面决定编入图像模型的输入

宿主需要交付可直接使用的生图提示词时读取对应编译方法。输入为已选媒介和画眼、当前视点与素材、用户锁定项、可变范围，以及已指定且实际核实的工具条件。涉及图生视频首帧时，在画面组织阶段先处理起始状态。仅交首帧的效果说明也采用这项观看设计，有最终提示词时再接入编译。普通效果说明由宿主按参照与画面设计方法完成。

## 先让首句定下媒介与画眼

将已定表现媒介或同作风格中最影响成像的特征，与核心主体、决定性时刻或画眼关系放在首句。需要时同时写首句里的参考职责。接下来安排其他主体位置、遮挡和观看方向，再写能决定可读性的光色、材料、边缘及画幅。简短单主体可直接用一句定下媒介、对象和核心状态，随后补必要的空间与光色。文字排序是本地组织重点的方法，接口字段、显式权重与参数语法依本轮实际所用的入口。

润色时先压缩模糊赞语与同义叠词。若普通正文中的 `masterpiece`、`best quality`、`8K`、`ultra-detailed`、`trending on ArtStation`、`award-winning` 只是泛称，删去或换成对结果有作用的证据，例如釉面窄高光、层叠纸纤维或焦点处清楚的刻线。明确要求的写实摄影是媒介条件，用户锁定的原文、真实尺寸和接口字段遵循各自用途。

## 在镜头中为每个主体固定归属

画面有两个或更多需要区分的主体时，将**本视点的画面区域、当前可见且能区分的特征、稳定的显式主体称呼**在同一个短句里绑定。可选画面左侧、中景、门口内等具体区域。使用已有轮廓、外观或所属物，只有本轮允许设计时才补开放特征。多人制服、同款物件或刻意相似时，保留设定，用位置、姿态、职责或接触关系分别锚定。人群背景可作为整体处理。

写交换、视线或共同操作时，直接用同一个称呼重提动作发起者、接收者与所属物，防止省略主语或把“他”“另一位”误接到最近出现者。区分画面左右与角色自身左右。看不见的特征留在底稿，按其他已知线索区分。影响辨认且确实缺少资料时指出依赖。核对每个称呼、区域、部位与动作只指向目标对象。颜色区分仍弱时，比较各主体的站位、间距和轮廓。

## 分配每张参考图和文字的职责

先从宿主已核的材料得知图名或标签、对应对象、采用维度、保持边界及本轮变更。用户已提供参考图并指定用各图重绘时，以这些图随提示词输入为本轮交付条件。入口尚未指定时，按用户原有图号或文件名用自然语言逐张绑定，提示词说明所需的配图和各自职责。实际入口已经确定时，采用可核实的绑定方式。

| 参考职责 | 编入画面时处理的范围 |
|---|---|
| 底图或编辑源 | 标认所编辑的物件或区域、可见变化和应继承的主体、取景及场景关系。只在真实有掩膜或局部编辑入口时使用其控制字段。 |
| 风格参考 | 给它媒介、表面、颜色或边缘等本轮选中的职责，沿用已确认的参考分工。将新主体、场所与动作交给本图文字。 |
| 角色、道具或身份参考 | 按指定对象采用稳定外形与已认领的识别线索。视角、动作、环境与用户授权的外观变更由当前计划确定。 |
| 构图、姿态、深度或空间参考 | 指明要继承的观察面、轮廓站位、肢体关系、前后遮挡、比例或布局。其余题材和风格沿用户已选方向。 |

**配图编译。** 在正文中用短语说明每张图负责的对象、维度和保持范围，后续句段写文字驱动的新动作、场景、状态、观察位置及必要光色。为了辨认、消除归属歧义或解释新变化才补一两项确有作用的可见锚点。逐句删去配图已经表达、且无需文字再固定的外貌清单、旧画面和背景细节。用户锁定原文及资产固定项照各自契约保留。效果说明需要对照参考时，可以描述支撑本图决定的实际观察，正文按执行所需取用。

**纯文字编译。** 用户明确要求脱离图片独立执行，或已知当前入口无法附图时，将有证据的必要视觉关系转写为文字，交代仍需实际参考的身份或结构范围。有无法确认的部分，交给宿主处理相应依赖。

两张图覆盖相同属性时，按已定主次分别绑定角色、部位或画面区域。同一对象、部位和时点的条件互斥且用途无法裁决时，交宿主只处理此处冲突。需要时按[提示词整合](../../references/prompt-assembly.md#继承同作风格与当前可见的身份)复核同作及资产保持项。

生成后若需要纠正串色、身份或参考偏差，先比对实际图与原提示词的归属、可见范围及参考分工，修最早失效的一项。提示词已有清楚归属仍失效时，记录现场证据，再由宿主评估实际入口是否可用分对象参考、局部编辑或分步合成。

## 为图生视频确定第一帧能接住的动作

确认这张图确实是下一镜的图生视频首帧。读取可用分镜、首个动作或镜头变化、计划方向、此刻角色与道具状态和现有场地。先按视频实际从哪里开始确定位置、朝向、受力支点、眼神、手与物的接触。随后才启动时，用真实的预备状态，例如重心已经换到将蹬地的脚、身体朝向前进方向。若镜头从奔跑中、在空中或静止开始，沿用计划中真实的那一相位。当动作尚在后面发生时，首帧写起始证据，后续轨迹交视频提示词。

根据主体在画面上的运动方向与镜头预定动作留出 Lead Room。横向动作把出发处、运动前方和需要辨认的目标或落点放进取景计划。朝镜头或向纵深走时，用前后尺度、透视线和实际可通过的路线表达空间。例如手推车将从仓门驶向里面的装货位，首帧可让手与把手的接触、前轮与门槛的间距和门内通道同时入画。锁定构图刻意压迫朝向空间时，交宿主核对首动作是否仍可读或依赖镜头移动。

从当前机位检查主体与背景、各肢体及重要道具的轮廓和接触。需要保持一个真实牵手或持物动作时，保留接触点并把参与的手和结构分清。背景可减弱细节，同时让首动依赖的路线、障碍、固定地标和相匹配的光向有足够证据。设计稿写清**画面中的起始状态**与**下游下一步动作**，由宿主分别消费。

有实际首帧文件时，以其中当前可见的位置、朝向、接触、物态和光影为连续性依据，比对原定启动动作。如果现帧与已定起始不同，标出具体冲突，交宿主按本轮授权裁定哪项可变。只有提示词或分镜时，交欲实现的首帧规格，实际文件、裁切和成图连续性仍待查看。不得把预计位置或下一步动作写成已经出现在图里的状态。

## 返回宿主

首帧分支先把起始相位、运动空间、清晰轮廓和保留地标交回[确定画面组织与观看方式](../../SKILL.md#确定画面组织与观看方式)。编译分支把首句重点、逐对象绑定、参考职责和已核接口交回[内容选择与提示词整合](../../SKILL.md#内容选择与提示词整合)，由宿主检查固定项、正文语言、正向表达和交付格式。图生视频交接区分拟定画面目标与实际首帧的已核状态，并带上首个动作依赖。接口取法见[图片方法来源](../../../../../knowledge/图片方法来源.md#提示词与实际接口)。
