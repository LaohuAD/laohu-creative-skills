# 三类高难生图工程防崩坏方法

宿主**仅在命中以下三类工程场景之一时**读取本模块对应小节：画面有 2 个及以上需清晰区分的主体、附带真实参考图需分工控制、或明确设计图生视频（I2V）开头首帧。普通单主体纯文生图直接走 `prompt-assembly.md`，不加载本模块。

## 1. 多主体同框防串色与自然复指

画面出现 2 个及以上需清晰区分的主体时，既要防止发色、服饰、动作与道具互相串换，也要避免机械复读长前缀伤了文气：

- **首句三要素全绑定**：首次引入每个主体时，在同一短句内锁定 **具体屏幕方位 ＋ 互斥且当前可见的显性特征（发型发色、外衣色款或关键持物） ＋ 简短身份称谓**。
- **后句自然复指、严防词面叠撞**：后续描写动作、神态或互动时，用简洁显式称谓直接复指（杜绝他、她、另一位、对方等模糊代词）；**当紧邻短语刚提及该主体的某件服饰或道具时，复指改用纯粹身份称谓**（不把同一服饰词在相邻五字内连写两遍），保持句子自然流畅。
- **同款服饰与遮挡边界**：穿同款制服或外观相近时，改用画面位置、姿态分工与持物区分；提前核查兜帽、帽子或长发等配件是否遮挡用户锁定的发型或侧脸。
- **空间与轮廓防粘连**：交互的双手、手臂与交接物件留出清晰接触点与干净背景间隙，区分画面左右与角色自身左右，确保交接物件独立可辨。

## 2. 多图与图生图参考分工（减法编译）

先核实每张真实参考图的编号或文件名、实际可见内容与本轮授权采用的维度（图不可读时不假装已核查）：

| 参考职责 | 图片负责什么 | 提示词文字负责什么 |
|---|---|---|
| **底图 / 局部编辑源** | 继承未授权改动的主体、场景、取景与光线基线（含拿到真实成图后的局部返修） | 精准写出被改部位的可见新状态与保持边界，不把整段文生图长文案重述一遍引发漂移（仅在工具确有掩膜字段时用参数） |
| **风格参考**（如图 A） | 承接媒介、笔触、色彩气候与边缘气质 | 专注写新主体、新场所、新动作、构图与光影；**删掉参考图里的旧物体与旧场景** |
| **身份 / 角色 / 道具参考**（如图 B） | 承接稳定外貌、体型或造型锚点 | 写清本帧新姿态、视角、表情与环境；**删掉已被参考图承载的冗长外貌清单**与原图背景底色 |
| **构图 / 姿态 / 空间参考** | 承接站位、肢体关系、前后遮挡或布局 | 交代新角色、新题材与新风格 |

- **配图编译（附图提交时）**：开头短语清晰绑定每张图的唯一职责，随后文字全力驱动新场景、新动作、光影与氛围；只在消歧或解释新变化时补 1–2 处关键可见锚点，避免文字与参考图打架。
- **纯文字编译（工具不支持附图或用户要求脱图运行）**：将已观察到的关键风格与身份锚点转译为简洁文字，同时如实说明精确复现仍依赖附上原图。
- **冲突与返修**：两张参考图覆盖同一属性时按主次分角色或分区域绑定；涉及资产规格时按 [继承同作风格与当前可见的身份](../../references/prompt-assembly.md#继承同作风格与当前可见的身份) 复核。

## 3. 图生视频（I2V）开头首帧设计

确认本图用作图生视频首帧时，**在定构图前即进入本节**：

1. **锁定真实起势或预备相位**：按视频第 0 秒真正开始的状态设计姿态——即将发力起动、推拉或跃起时，画**蓄势临界态**（重心已压向发力侧、双臂握稳着力点、目光锁定目标方向），绝不提前画到动作半程或终点；若镜头本就从行进中或静止切入，则严格对齐计划起始相位。
2. **预留运动前方空间（Lead Room）与路径秩序**：主体即将向画面一侧移动时，把主体放在出发侧，前方留足顺畅通道，让**当前起点、中间路径与目标落点**沿清晰透视与引导线同时入画，地平线稳定可接续。
3. **拆清轮廓防起动畸变**：确保即将运动的手臂、双腿或道具与背景地标、彼此身体之间有清晰边缘分离与明暗差，避免肢体交叉粘连或碎杂背景在起动时穿帮；保留锚定空间的固定地标与一致光向。
4. **静帧提示词与下游动作交接严格分离**：
   - **生图提示词代码块内**：只写这一瞬间静态画面里**当下已经存在**的蓄势姿态、受力接触、空间余量、光影与氛围——绝不把随后跑起来、接着推上去等未来动作写进静帧正文；
   - **给视频端的接续交接（放在代码块外）**：完整交代三件事——① 第 0 秒锁定初态（站位、着力点、朝向）；② 适配单镜时长（未指定默认按 5 秒拆 3 拍）的起顿、发力、推进真实物理重量感节拍与稳健运镜建议；③ 延续首帧媒介线条、色阶、光色及人物左右站位不互换的一致性提醒，并标明成图后须以实图握点与位置为准核对微调。

## 返回宿主

- **I2V 首帧分支**：先将蓄势相位、运动余量、清晰轮廓与地标带回 [laohu-image 主文](../../SKILL.md#3-后台极轻三支点定盘与四步推进) 完成画面与效果说明，并在交付时单独附块外视频接续说明。
- **多人与多图参考分支**：将自然复指绑定与参考分工结果交回 [按观看顺序组织](../../references/prompt-assembly.md#按观看顺序组织) 完成正向编译与轻扫疤。出处见 [图片方法来源](../../SOURCES.md#提示词与实际接口)。
