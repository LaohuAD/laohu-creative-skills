# 写实摄影与电影实拍的非对称工艺

宿主在写实摄影、电影感实拍静帧、商业产品、建筑室内或纪实人像需要定情感焦段、快门动态、材质反射焦散或专业人像/戏剧布光时读取本模块。手绘与平面插画不读，混合媒介仅处理写实区。**用真实工业光型与可见光学效果成对锁紧画面，不堆砌无关器材型号或空洞画质词；后台理论名仅作内部推导，绝不写进提示词。**

> **底层判断原理（仅后台推导，绝不泄词）**：以 **Fil Hunter《Light—Science & Magic》反射家族（Family of Angles）与明底暗边/暗底亮边** 解决一切金属、玻璃、水面与镜面布光；以 **何藩硬光几何切面（Chiaroscuro）与《Framed Ink》光影叙事** 控戏剧明暗切割；以 **ARRI 主光/辅光/轮廓/背景四职能** 严控主次分权，绝不让环境次灯冲平主光心脏。

## 1. 情感焦段、景深真实与光学边界

先按 [从机位位置推导透视与取景](../../references/image-content-and-viewing.md#从机位位置推导透视与取景) 锁定物距与三轴朝向：

- **焦段服务情绪与主体比例**：亲密共情、手艺专注或自然人像多用 50–85mm 中长焦贴近主体，压缩杂乱背景并让人物表情与手部稳占核心；压迫悬疑、窄道纵深或宏大环境按需用 24–35mm 贴近前景拉出强烈透视张力，或借前景门框、枝叶形成自然窥视层次。
- **景深与光学严守物理真实**：焦点死锁在眼神、手部触点或核心材质上，前后景按真实光学景深渐进柔化；平视机位绝不误写物体顶面，中全景不硬塞超出分辨力的细微瞳孔描写，焦外远景不写微距水珠或细纹。

## 2. 三类真实快门动态物理

先定可见运动轨迹与清晰归属，再落到画面状态：
- **定格临界瞬间**：选水花飞溅、飘雪过光、衣摆扬起或手指触物同时成立的冻结 0.1 秒，写清被凝固物质的形态与精确落点；
- **固定机位慢门拖影**：相机稳固、主体保持可真实支撑的静止姿态，让周围人流、车流或水流沿真实方向拉出柔和拖影，**确保动态拖影不吞没静止主体的核心轮廓**；
- **追随跟拍**：相机沿移动主体同步平移，令主体清晰而背景拉出水平或斜向运动流线，肢体或车轮末端保留自然动势。

## 3. 按材质反射家族与焦散布光配背景

从相机观察角反推反射角与透射路径内会出现哪些光源或暗面，混合材质逐部位分开控制：

| 材质家族 | 物理布光与背景策略 | 写进提示词的可见光学结果 |
|---|---|---|
| **漫反射**（粗棉织物、旧皮革、陶土、哑光木、沧桑皮肤） | 方向性侧光或低角度掠射硬光扫出表面凹凸，敢压深背光暗面不打平光 | 转面明暗扎实立体，织物纹理、木纹包浆与皮肤细纹显出真实微影 |
| **磨砂与半光泽**（磨砂黑容器、拉丝金属、缎面） | 受控条形光或斜射硬光拉出清晰宽柔亮带配沉稳暗面转折，绝不发灰 | 底色沉稳纯粹，表面呈冷暗大面与克制亮带的利落过渡 |
| **抛光镜面**（镜面金属、眼镜片、潮湿石面、静水面） | 按视线反射角安排可被映出的暖灯、暗卡或天光色块，先定反光形状再控亮度 | 镜面或潮湿表面映出可追溯来源的克制亮带与清晰暗边界，结构转折利落 |
| **透明与半透明**（厚玻璃、液体、冰块、薄纱） | 用**明底暗边或暗底亮边**清晰勾出边缘轮廓，优先借低角度硬光穿透液体与厚壁在台面投出**透射焦散光影** | 玻璃边缘切出锐利亮线或深沉折射边，台面投出清透发光的焦散光纹，小图依然清晰分离 |

## 4. 电影级专业布光与主辅光源严分权

戏剧与情绪实拍中先锁全画**主光主导权**，严控次要实景灯具的亮度——次灯只负责给暗部留一层极克制的环境呼吸与空间轮廓，**绝不抢戏或把整间屋子照成发灰平光**；而商业均光静物与多焦点等权陈列则按反射家族配均匀主光与局部塑形光，不硬造单点戏剧聚光：

- **硬光几何切面（明暗对照法）**：敢让大片环境沉入深暗阴影，借一道斜切窗光、门缝光或建筑投影把画面劈成利落明暗几何块，把视线强行锁进受光刺点；
- **五类精细人像与情绪光型**（配合 [人物表演与观看位置](../../references/image-content-and-viewing.md#人物表演与观看位置) 与 [选择人物肤质与表面明暗](../../references/light-color-and-style.md#选择人物肤质与表面明暗)）：
  - **蝴蝶光**：正上前方主光，鼻下留对称小影，利落端庄；
  - **环形光**：主光略偏侧上，鼻影斜落脸颊留空隙，立体自然生动；
  - **伦勃朗光**：高位侧硬光在暗侧脸颊留出标志性倒三角亮区，最适合雕塑感、沉稳专注与沧桑叙事；
  - **分割光**：正侧硬光将面部近乎一分为二，强烈戏剧冲突与双重性；
  - **聚束暖顶光 / 诡异底光**：低垂罩灯聚束顶光将手艺人或主物件圈进温暖孤岛；由下往上打的弱底光照亮下颌并拉出上扬扭曲阴影，直造悬疑惊悚；
- **三类高记忆点戏剧光**：**窗格门缝或枝叶投影**（跨过主体与墙面形成强几何切割，保住眼神与手部可读）、**体积光束**（交代狭缝来向、尘雾雨雪介质与落点）、**强冷暖混合光**（明确室内外各自受哪束光主导，并在交界与潮湿地面写出自然溢光回弹）。

## 5. 反塑料完美：按题材匹配真实成像肌理

对抗 AI 默认过度光滑的塑料样片，按题材身份匹配对应的真实物理质感，绝不拿同一套旧化胶片模板或冰冷目录感刷遍所有照片：
- **人文纪实、生活叙事与复古电影静帧**：围绕主体与关键接触面落少数真实可触的生活与环境痕迹（微皱织物、受力形变、使用微痕或自然肤理），按年代与情绪按需选用克制的胶片微颗粒与柔和自然的高光滚落，不靠堆满脏乱杂物冒充真实；
- **艺术静物画册与情绪肖像**：守住干净表面与极细微的材质、色温层阶（如相近灰调间区分微妙冷暖色差），靠温润平缓的高光滚落与克制自然的光学细腻感立住画册诗意，不硬加磨损，也不强塞粗重颗粒；
- **全新商业产品、高端广告静物与现代建筑**：靠精准的材质微肌理（磨砂颗粒、拉丝细纹、厚玻璃折射边缘与干净环境反射）及洁净锐利的现代高解析数码成像立住真实感，绝不硬塞旧化磨损或胶片噪点。

单张静帧不写动态镜头呼吸。
