# 风格化与手绘造型的非对称工艺

宿主在插画、绘本、概念艺术、风格化动画、水墨、版画或拼贴需要造型组织、笔触疏密与媒介辨识，或任意创意构想借用单项视觉修辞时读取本模块。本模块不复读主文通用镜距与唯一主光规则，只负责把画面做成**摘掉标签也能一眼认出的高级造型成品**。**严禁混入摄影焦段与光学焦外词；后台理论名仅作内部构思，绝不写进提示词。**

> **底层判断原理（仅后台推导，绝不泄词）**：以 **Arthur Wesley Dow 二值/三值 Notan 明暗块面** 立缩图剪影骨架；以 **James Gurney 色域遮罩（Gamut Masking）与空气透视** 控有限色域与空间退远；以 **赫克特统一中的变化** 平衡秩序与视觉惊喜。

## 1. 二至三阶明度剪影与形块疏密呼吸

- **缩图三秒眯视预检**：构思先将整幅画压成 **2–3 组清晰的明暗大块**（高光焦点区、中灰过渡承托区、沉稳暗部压底区），确保缩到拇指大小依然一眼读出视觉重心、主体姿态与情绪基调，彻底告别通篇灰平。
- **主次笔触与细节疏密分区（单焦点参考约八成概括、二成精收，绝不机械套比例）**：
  - **画眼精细收紧**：把最清晰的干笔叠色、彩铅细线、锐利轮廓或厚涂碎笔集中在眼神、手物触点与核心焦点上；
  - **外围宽笔概括退远**：大面积背景、人潮、远景建筑与天空改用宽笔湿画柔边、平涂大色面或按明暗气质自然退远（亮调留白可融进纸白，暗调与夜景外围融进深色底洗，绝不写融入纸面留白诱发四周发白淡出）。工笔、群像、多焦点并列或满幅纹样则靠群组之间的疏密差与明度差立住主次。

## 2. 有限色域、硬软消失边与空气退远

- **有限色域 + 克制情感呼应**：锁定 1–2 组主导色相与带色倾向的母灰贯穿大片承托区，把最纯或冷暖反差最强的色彩留给焦点与至多 1 处小面积呼应刺点；阴影色温顺着当前主光与环境色自然推导，不落死灰死黑。
- **硬边、软边与消失边分工**：画眼转折、关键轮廓与主物件受力处给 **1–2 处清晰硬边**锁住目光；曲面过渡与次级形用软边；暗部与远处雾气边缘直接融进邻近色面形成消失边，让空间自然呼吸。
- **空气透视替代光学虚化**：用色相向空气雾色靠拢、明暗对比逐层减弱、边线由实转湿来拉开远近纵深，绝不借用相机光圈或镜头焦外表述。

## 3. 五种高杠杆视觉修辞

普通造型不足以制造 0.2 秒记忆点或 3 秒回味时，只选 **1 项**最承重的修辞，其余元素全为其服务：

| 要表达的关系 | 视觉修辞与画面落地 |
|---|---|
| 敬畏、未知、威慑或力量悬殊 | **比例错置**：在同一地面、台阶或通行尺度里把微小人物与越出画框的巨形并置，靠人物迎上、僵立或仰望定情绪方向。 |
| 第一眼可读，细看藏第二层意思 | **负形同构或视觉双关**：让门洞、阴影、倒影或两轮廓间空隙自然显出第二个可辨形态，先读出的主体保持完整识别锚点。 |
| 流逝与停顿并存 | **动静反差**：用宽笔概括的流动人潮、水流或扬起衣角表现行进，用中心停驻的主体与清晰轮廓锚定温暖或紧绷瞬间。 |
| 熟悉对象显出超现实异质感 | **局部材质置换**：保住对象原本轮廓与用途，只在授权部位换成异质材料，以清晰接缝、反光或受力变化交代材质转折。 |
| 人物与空间被同一节奏锁紧 | **图案化光影切割**：用窗格、栏杆、廊柱或枝叶投下跨过主体与墙面的强光影几何切割，同时让核心表情或手势落在清晰可读的光区。 |

## 4. 六类造型媒介的表面脱标工艺

选定媒介后，把该媒介不可替代的纸纹、笔性、边界与着色逻辑直接落到提示词实体表面：

| 媒介 | 可直接写进画面的真实表面工艺 |
|---|---|
| **水彩、叙事绘本** | 细纹或粗纹水彩纸自然颗粒、透明水彩叠染配温润哑光水粉，湿边渗化处理蒸汽雾气与退远外围，干笔或彩铅细线收紧眼神、手势与主物件。 |
| **厚涂、概念绘画** | 笔触顺形体转折与动势走，厚涂亮部与利落碎笔聚在画眼与受光面，承托背景用大块概括色面衔接。 |
| **手绘动画、赛璐珞、风格化 3D** | 带自然笔压的深灰手绘线条与利落二阶赛璐璐明暗划开人物层次，环境配厚润水彩水粉背景；风格化 3D 交代体块转角软硬与手塑或哑光表面。 |
| **木刻、刻线版画** | 黑白大块与大面积留白定结构，排线随形体与动势转向，靠线距疏密表现明暗过渡。 |
| **水墨、工笔** | 水墨靠生宣纸白、枯湿浓淡笔势把形接入空处，借大留白显气象；工笔靠细劲勾线界定轮廓、分染平涂拉出层次，密纹只聚在核心母体上。 |
| **黏土定格、手工拼贴** | 黏土保留圆钝转角、微哑光质感与轻微指塑痕；拼贴用纸层剪裁边、微弱接缝投影与材质反差标识有意并置。 |
