# 用形、色和边缘组织画面

宿主确定了主体关系、观看目标和已锁定的风格，在插画、绘本、概念艺术、风格化动画、水墨、版画或拼贴确需解决造型组织，或作品需要用具体视觉修辞增强表现时读取。输入是画眼与后续观看线索、画幅与显示尺寸、已知的媒介和资产，以及本轮可变的构图与风格范围。常规忠实复现沿用已有关系。写实任务若只遇到单项修辞问题，仅取相应小节。

## 用两到三阶明度检验大形

先用 Notan 起排明暗。把主体和环境归成两到三组明度，画成或想成拇指大小的缩略图。若前后两处主形都需一眼辨认，同时画面要保留大块连续空处，先试三阶。将一阶交给主要承载面，一阶交给关键轮廓或亮区，另一阶给足够大的中间形、物件表面或空间过渡，再分别对照两个主形紧邻的底色。单主形、强剪影或有意共享明度的并置可用两阶。需要一组空间或结构关系而两阶无法区分时，加可辨的中阶。

每组明度都要写到画面中的实际区域或表面，说明它比相邻区域深、浅或接近到什么程度。只有少量微亮和暗纹时，先看是否在缩图里能形成中间层。暗调可从约七成深色母调、两成中灰承托和一成局部亮部起试。高调也可由连贯的浅色承托一小组深色主形。比例随可辨形状和承托关系调整，必要组块及其边界进入最终描述。

在目标观看尺寸做一次约三秒的眯视或失焦预检，先看画眼是否清楚，再看能否沿视线、明暗界线、重复或空处去往下一落点。低反差或有意融入背景时，给关键关系保留一处可辨认的明度交界、断开或转折。若设计有意用色相、图案或多个并列落点来组织观看，灰阶用于定位哪些信息依赖色彩，仍以该情境下的完整画面验证。已有成图才做实际缩图、去色与目标尺寸对照。

## 用大中小形和细节疏密安排观看

- **大形定势。**先合并地形、建筑、光影或主身体块的外轮廓，为前后层、方向和空处留出连续面积。需要力度可使几组长边或尖角指向同一处。需要包裹感可让曲线、圆弧与内凹空间相接。比例和形状仍须能辨认当前主体及已定身份。
- **中形分组。**用肢体、枝干、衣料折面或次级物件把大形组织成可以读懂的几个群组。群组相撞时先改间距、朝向或形块交界。大、中、小约七、二、一可用来起排明显主次的画面，最终按轮廓职责及观看尺度调整。
- **小形点睛。**小碎形、亮点、刻线和密笔触集中在主关系发生的位置。单一画眼可从约八成相对低细节的承托面、两成聚集细节起试。让空处有具体作用，例如平静的水面承接视线，低反差的墙面隔开相似轮廓。刻意繁复的工笔、群像或满幅纹样可在群组间造成疏密、明度或重复节奏差，保留题材所需密度。

画眼与边角若同样繁密，先并掉一处背景碎纹、放宽群组间隙或收低次要细节的反差，再复看主形。提示词标出谁繁、谁简、眼睛下一步有何去处。面积数值只有会帮助实际制作时才传给模型。

## 限定色域并安排边缘与纵深

配色容易由各物件的固有色走散时，借 Gurney 的色域遮罩先在色相环上选一块允许使用的区域，在目标光照下定一到两组主导色相与饱和度范围。用近中性的母色贯穿大面积与过渡区。若需焦点色，让最纯或差异最大的颜色落在能承托画眼的小块上，再把它放回实际邻色检验亮度与面积。材料之间保留足够色差可辨认。用户已给色板、单色方案或高饱和设定时，在原色域内安排主辅和强调。

有纵深且空气参与画面时，从近处开始比较轮廓清晰度、暗部、对比和固有色。随距离让远景的色彩向实际空气或受照雾尘的颜色靠近，通常减弱物体与背景的对比并软化次要边缘。冷雾、暖霞或黄尘可给不同偏色。远层有重要发光体、强逆光或用户要求可辨的地标时，为其留必要的明暗或轮廓证据。

把硬、软、消失三种边缘分配到具体交界。画眼的转折点、动作触点或识别轮廓用一两处硬边。曲面转光、次要形和远处交界可用软边。暗面相接或雾里轮廓在局部并入相近明度或邻色，留下能接续形状的另一段边线。剪纸、图形和硬边版画也可用轮廓粗细、间隙和邻区反差控制层级。检查画眼周围是否还有同样锐利且更抢眼的边，把它移开、并组或降低反差。

## 让视觉修辞改动可见关系

当普通构图无法充分表现已定关系时，选一个最能承重的处理，明确它作用在哪两处以及观者如何发现。其余视觉条件帮助读出这一次变化。

| 当前要表达的关系 | 可采用的处理与可见证据 |
|---|---|
| 敬畏、未知或力量不对称 | **比例错置。**让悬殊尺度同时可比较。用同一地面、人物脚边的台阶或通行尺度提供参照，再让巨形伸向远处或越过画外。人物迎上、停住或回望会改变关系的含义。 |
| 画面先可读，随后发现另一层意思 | **视觉双关或负形同构。**让门洞、影子、倒影或两个轮廓之间的空隙显出第二个可认形状。两层对象须共享本图确实需要的关系，先读出的对象仍留辨认锚点。 |
| 流逝与停顿同时可见 | **动静反差。**在同一时刻让水流、人群或衣摆有一致的方向性线索，再用静止主体的支撑姿态和清楚轮廓形成停顿。叙事单帧可停在事件尚未收束、关系已经从手势或视线显露的一刻。 |
| 熟悉对象突然呈现异质感 | **局部材质置换。**让原对象保住轮廓、结构或使用方式，只按授权在关键部位换成另一种材料。用明确的接缝、反光、色面或受力反应说明哪里发生了变化。 |
| 人物与空间需要被照明连在一起 | **图案化光影切割。**让窗格、枝叶或投影片的光影跨过人物和背景形成同一方向的节奏，留一处动作或表情清楚可读。有光束时写明光从哪来、在怎样可见的尘雾中穿行、亮区在哪里结束。 |

## 把造型落实到媒介的表面

先选该媒介实际能呈现的轮廓、明暗阶数与笔触或材质。媒体混用时给主体、局部与背景各自承担的表现分工，检查相接处的光、形和色是否相容。

| 媒介 | 能写进画面的方法 |
|---|---|
| 水彩、绘本 | 透明洗染和纸白承接大亮面。湿边渗化适合大气与次要形，干画叠色收紧眼睛、手势或物件结构需要辨认的边缘。绘本的疏密和色阶随场面阅读任务变化。 |
| 厚涂、概念绘画 | 笔触方向贴合形体转折或动作方向，厚痕集中在受光面、接触处或画眼。承托面可用较宽的色面和低密度笔触连接。 |
| 赛璐珞式平涂和风格化 3D | 用明确的少数色阶、剪影和成组阴影划开层次，按需配线；需要读出光泽或半透明材质的局部可保留连续过渡。风格化 3D 依作品定大体块、转角软硬、轮廓线和表面细节，姿态和比例来自本作造型。 |
| 木刻或刻线版画 | 黑白块与留白组织整体，排线随表面和动势转向，用线距变化决定明暗与疏密，优先保持刻线的方向和形块。 |
| 水墨、工笔 | 水墨可用纸白、枯湿笔及墨色浓淡把形接入环境。工笔可用细线界定形体，再用分染或平涂分出层次，让最密的线纹集中在需要读的物件与部位。 |
| 黏土定格、国漫 3D、拼贴 | 黏土可保留可塑的圆钝转角、哑光或局部指压痕。国漫 3D 按指定作品方向选择衣料、线面与光影分组。拼贴可用剪裁边、纸层接缝或材料冲突标识有意的并置。 |

## 返回宿主

把当前画眼、第二落点或并列观看关系，以及大形、疏密和纵深决定交回宿主的[确定画面组织与观看方式](../../SKILL.md#确定画面组织与观看方式)。媒介质感、明暗层级、用色职责、边缘落点及所选修辞回到[选择媒介、色域与气质](../../SKILL.md#选择媒介色域与气质)，由宿主按本轮范围编入可见描述。有实际图时分别核对形块可读、焦点周边疏密、边缘和色域职责。取法出处见[图片方法来源](../../../../../knowledge/图片方法来源.md#明度形块色域与媒介)。
