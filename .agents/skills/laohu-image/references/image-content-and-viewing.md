# 内容与观看

由 [laohu-image 主文](../SKILL.md) 在按观看尺寸与情绪定镜距、设计吸睛钩子与 3 秒认知空白、提纯单帧物理证据、理顺 3D 站位与人物表演、处理多焦点共享色场、转译场景坐标或校准机位三轴时按需读取对应小节；完成后将具体画面决定带回主线。

> **底层判断原理（仅后台推导，绝不泄词进提示词）**：以 **Treisman 弹出效应、Von Restorff 孤立效应与罗兰·巴特刺点（Punctum）** 造 0.2 秒预注意锁定；以 **格式塔图底与负形原理** 保住主体轮廓与呼吸留白；以 **卡蒂埃-布列松决定性瞬间** 锁定单帧物理唯一态。

## 1. 按观看尺寸与情绪定镜距，叠合 0.2 秒吸睛与 3 秒回味

- **先按真实观看尺寸核对大块辨识**：手机信息流、播客方封或电商小图必须先保证缩到拇指大小依然一眼分清大块明暗与主轮廓；大幅欣赏、海报印刷或高清静帧再安排供凑近细看的次级层次。
- **镜头距离是决定观者被拉进现场、还是保持观看距离的第一开关**：
  - **温暖治愈、生活烟火与人物共情**：常拉近到贴身亲密的中近景或半身斜拍，让神态、手部接触与主物件成为视线重心，外围环境退作纵深衬托，不为了交代整栋建筑把亲密感推远成冷漠全景；但若题材本身靠开阔空间反衬宁静治愈（如海边、旷野或日光静室），大方保留空间呼吸；
  - **压迫悬疑、孤寂敬畏、尺度悬殊或图生视频运动留白**：按需选用中全景、广角或远景，让空间纵深、巨物尺度或前方通道直接承担压迫与运动余量；
  - **商业产品、轻日常极简与并列研究**：按器物最佳观察比例、舒展留白或等权间距定距，不强行贴脸也不硬拉史诗广角。

距离定稳后，单焦点画面先用统一克制的底调立住秩序，**只押 1 个最强 0.2 秒视觉钩子**打破秩序（绝不堆叠多个钩子互相抵消）；情绪叙事或海报类画面按需叠 1 处 **3 秒回味认知空白**，让观众看完第一眼后主动用脑补完画外故事：

| 层次与钩子原型 | 核心视觉机制（如何让人停住或回味） | 适用边界 |
|---|---|---|
| **0.2 秒 · 光影刀锋 / 主视觉光核** | 大片克制底调里只托起 1 处清晰受光核心、斜切硬光、狭缝光或透射焦散光斑 | 极适夜景、室内外光色对撞、强情绪叙事与雕塑感静物 |
| **0.2 秒 · 孤立异色 / 异质刺点** | 在大片低饱和或统一质地环境里，只放 1 处极小而醒目的异色或反差材质 | 让视线如磁铁吸附，适合人文抓拍、孤寂场景与产品焦点 |
| **0.2 秒 · 非常规视点与尺度休克** | 跳出平庸人眼平视，改用贴地微仰、贴近孩童或坐姿高度平视、门框枝叶前景窥视或巨物压迫 | 视角本身即记忆点，慎用于要求标准平正的产品展示 |
| **0.2 秒 · 打破规律 / 临界 0.1 秒** | 整齐秩序里唯一偏斜或异动的个体，或重力、动作、接触即将触发的悬停瞬间 | 强动态悬念与视频首帧首选 |
| **0.2 秒 · 认知反差并置** | 将气质悬殊却合乎现实逻辑的两物同框（如粗砺沧桑的大手与娇小柔弱的物件） | 极强人情刺点，需合情理不硬造猎奇 |
| **3 秒回味 · 留白召唤与画外指向** | 留下未封死的空间空缺或画外线索（空着的对座、半掩的门缝、人物投向画外的眼神） | 叙事与抒情佳品，让观者用自身记忆填满余韵 |
| **3 秒回味 · 倒影或阴影藏第二真相** | 主体正面看似平静，水面、镜面、玻璃倒影或地面长影里透露出另一重处境、来客或反差 | 悬疑、隐喻海报与深层心理叙事 |
| **3 秒回味 · 冷静表层下的反讽落差** | 用极克制平静的构图与光线呈现强烈的现实落差或时间代价，表层越静、内里越扎心 | 现实主义、冷幽默与纪实讽刺，不套轻甜治愈图 |

## 2. 核心切面提纯、疏密呼吸与单帧物理证据

高信息量绝不是把场景里所有家具道具列成仓库清单，而是只留真正改写观感的可见物理证据：

- **收束主次，踢掉情感零度杂物**：原始需求里的背景故事大多是幕后供能燃料，不必逐条摆满画框。单焦点画面围绕核心主体或关键接触点收束刻画，给外围留出舒展透气的空间呼吸；多焦点并列或满幅纹样则靠等权间距与清晰负形建立秩序。
- **把叙事时间全转译为此刻可见的物理证据**（商业新品、纯形式构成或极简静物无需硬添磨损或剧情）：下游生图模型看不懂背景解说和心理点评，任何时间感都须落在当下肉眼可见的实体上——
  - **已发生的可见落痕**：现场自然留下的使用痕迹、干湿冷暖变化、器物摆放状态或天气落痕；
  - **单帧物理可同时成立的唯一瞬间**：人物身体受力、手部接触、视线落点与环境动态必须在同一瞬间同时成立——绝不把先后两步动作揉进同一帧诱发肢体或物件畸变；
  - **画外空间指向**：靠敞开的门窗亮口、延伸的路径、人物投向画外的眼神或未封死的留白自然引出余韵。

## 3. 3D 顺行几何与专业构图顺势收束

- **先按真实空间与三维逻辑把人摆顺，再顺势归拢构图骨架**：
  - 顺应主体朝向、动作走势与情绪张力安排自然阅读动线（既可从左到右顺行，也可按朝向与留白逆向牵引或有意居中对称）；核对建筑门窗邻接与画框边缘，不让横向构件压死主窗或意外裁切人物额头；动笔前必在脑中走一遍机位与朝向，绝不写出机位与人物站位互相打架、把想看的脸逼成纯背影的几何矛盾。
  - 景别、空间层次与构图术语只用来**顺势锁定已经成立的画面结构**（如门窗自然形成的框中框、路径或墙面拉出的斜向引导线、狭窄通道的对角线张力、三件主物构成的三角分组）。只用真正成立的主骨架，绝不为了凑术语硬塞多余前景块把镜头推远。
- **多焦点与等权陈列**：群像、等权陈列、抽象拼贴与满幅纹样靠相近尺度、精准负形间距与材质光影形成并列或循环观看，不强造单主角或硬编剧情；需要压迫或冲势时主动保留视觉失衡。

### 共享场域中保留各自身份

多件物品或空间需统一成同一整体、同时每件一眼可辨时，用共享大色场或连续底面收拢环境，让每件核心对象保有独立轮廓、局部颜色或细节，并在相邻边缘留出清晰的负形间隙勾出形状。

## 人物表演与观看位置

人物表情、眼神与肢体共同承担情绪时，按 **受力支撑 → 3D 朝向与无遮挡 → 单帧微动作与眼神呼应 → 自然情绪定调** 推进（局部修订若已锁构图与姿势，以它们为基线只调表演层）：

1. **先立真实受力支点**：明确坐、站、俯身、肘抵台面、指搭外沿或迈步转身的身体重心与接触影。
2. **核查 3D 可见性与手部稳态**：确认当前机位能完整看清目标侧脸角度（需要眼神互动时明确四分之三侧脸或斜正面）、眼神交汇与双手分工（避免双臂交叉遮脸，优先让手指持握有清晰实体的柄部、边缘或自然搭放处）；中全景不硬写超出分辨力的细微瞳孔变化，近景与中近景把眼神光、眼尾笑纹或紧绷神态写实。
3. **写活视线呼应与情绪力度**：双人互动优先让目光与微动作隔空呼应；独处人物让目光自然落回手头活计或画外空间，杜绝呆板看镜摆拍，守住目标情绪应有的松弛、专注、欣喜、倔强或惊惧力度。

## 安排空间尺度和动作

- **避开意外切线与悬空**：关键肢体、头顶和物件边缘不与门框、地平线或背景结构意外相切，支撑接触点交代真实受压或接触影。
- **单帧物理可同时成立**：只截取起势、停顿、交接或专注劳作中最有感染力的单一瞬间。

### 把场景固定坐标转成当前镜头关系

收到资产侧的场景布局、固定物清单或空间坐标时，严格继承同一世界空间，**绝不为了凑构图挪动固定门窗或家具**：
- 仅将当前机位视野内实际可见的物件转译为自然近/中/远景与左右、距离、遮挡、尺度参照及可行动路径；
- 墙后或画外设施不写成可见物，不把原始 `(x, y, z)` 坐标表粘进生图提示词；
- 纯文字提示词不能保证毫米级精确坐标，跨镜严格几何复现须依赖平面图、参考图或三维底图。

## 从机位位置推导透视与取景

**观察位置与物距决定透视，焦距或画幅只决定纳入多少。** 强化近大远小先将机位贴近前景再配宽视角，不把短焦本身当透视原因。无真实相机设定的插画直接写观察高度、远近与可见面，不混入镜头焦段。

将**机位高度、光轴俯仰、绕轴横滚**三轴分开控制：
- **高/低机位 ≠ 俯/仰拍**：分别写清机位高低与光轴仰俯，区分斜俯与正上方鸟瞰；
- **横滚倾斜不是俯仰**：横滚令地平线与建筑垂线整体倾斜，专用于强化不安、眩晕、失衡或压迫张力；需要安定感时明写地平线平直与建筑垂线挺直；
- 建筑需垂线平行时采用水平光轴或移轴校正；有意营造威慑或冲势时保留自然透视汇聚。

## 选择焦点与清晰范围

把最锐利的焦点或最细密的笔触锁在最能引发共情的眼神、手部触点或核心母体上；外围人潮、街景与远景按所属媒介自然退远（摄影用光学浅景深渐进柔化，手绘用宽笔概括与湿边晕染退远），焦外远景绝不硬写看不清的微距细节。
