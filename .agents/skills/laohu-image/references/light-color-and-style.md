# 光色与风格

由 [laohu-image 主文](../SKILL.md) 在推导情绪光色方案、配置主辅光与主体分离、拆控人物四层肤质、选单件物件最佳观察面、做邻色比较或初设服装/道具/空间宏观方向时按需读取对应小节；完成后将可见决定带回主线。造型明暗块面与媒介细则归 `laohu-image-aesthetics`，实拍反射焦散与光学细则归 `laohu-image-photography`。

> **底层判断原理（仅后台推导，绝不泄词进提示词）**：以 **Molly Bang 几何情绪原理**（斜角尖锐增张力、水平圆弧显安定、上下位置定主导与压迫）、**Bruce Block 对比与亲和**（空间/线条/影调/色彩/动静对比越大情绪越强，亲和越高越舒缓）、**Pixar 色彩脚本（Color Script）** 与 **Josef Albers 色彩相互作用** 统一推导任何题材的光色与明暗关系——遇到下表之外的情绪（如空灵侘寂、怀旧怅惘、荒诞冷幽默、神圣敬畏），直接按几何倾角、对比亲和刻度与冷暖色温自主反推，不拘泥于固定模板。

## 情绪光色推导与光影分离原则

推导任意情绪与流派的光色方案时，把握两条带适用边界的物理原则：

1. **光影主次分明与物理回弹自洽**：强情绪、夜景或单焦点戏剧画面中，确立清晰的主光主导方向与亮度层级，次要环境灯具刻意退后只留空间呼吸，不另开无关强光源把主体冲平，同时让近处皮肤、器物或潮湿表面承接主光的真实物理回弹；而日光高调、商业平展或多焦点等权陈列则按需采用均匀清晰的主照明，靠局部塑形光、透射或柔和接触影立出层次，绝不为追求戏剧感硬造单一聚光。
2. **主体与紧贴背景清晰分离（不止明度一条路）**：核心主体必须从紧贴其后的墙面、暗部或底面利落分开——最稳妥的是拉开明度反差（暗背景配较亮外层，亮背景配沉稳深色轮廓）；若题材刻意追求同明度低反差美学（如雾景白底白、暗调黑底黑或柔和同色系），改用**清晰轮廓边、受光高光边缘、材质粗细差或冷暖色温微差**实现高级分离，绝不糊粘成一片。

具体色相一律从当前真实环境、材质与邻色关系中长出来，不把任何颜色硬绑为固定情绪象征；下表只给光比、空间亲和与色温关系的推导标尺：

| 典型情绪光谱 | 几何与亲和/对比刻度 | 光型与光比策略 | 色彩关系、阴影倾向与对比方向 |
|---|---|---|---|
| **温暖、治愈、生活烟火** | 舒展柔线与开放空间感；主体内部高亲和，内外空间按需拉开对比 | 柔和方向性主光（如斜射日光、室内主暖光或低角度侧逆光）配自然环境回弹，**阴影通透带环境色倾向，不发死黑** | 色彩取自当前真实器物与环境，可走清亮低反差同调，也可用大片克制冷底衬起局部暖亮区，靠色温呼应而非多色互掐传温情 |
| **空灵、静谧、侘寂与极简** | 平缓水平线、高空间亲和与大片呼吸留白 | 柔和漫射天光或轻掠斜光，靠材质微起伏与柔和接触影立层次，**防硬套强光束或沉重黑影破坏清透** | 克制窄色域或自然原材本色，靠材质粗细、干湿反光与极微弱冷暖差形成素雅质感对比 |
| **蓄势、锐利、破局张力** | 锋利斜线、稳固三角支撑与明确动静或尺度对比 | 高方向性侧顶光或硬朗侧逆光切出利落轮廓，出发区与前方目标区拉开明暗层次 | 大片沉稳底色衬出极小面积高辨识焦点色，用明度与纯度落差集中视觉动能 |
| **冷峻、高级、克制锋利** | 利落直线与干脆几何切割，整体明确偏暗或极致清亮，避开无主见的灰平中间态 | 受控硬光、条形光、明暗对照切割或材质折射光斑塑出锐利明暗边界 | 低饱和克制底调配合精准的材质反差或单点异色呼应，靠边界锐度与表面精度立高级感 |
| **压迫、悬疑、惊悚与不安** | 尖角斜影、逼仄窄框、失衡尺度或克制横滚倾斜（也可用极致空旷反衬孤立不安） | 高反差局部硬光配大面积沉暗未知区（窄缝光、压暗眼窝顶光或诡异底光），或反常规的刺眼无遮蔽强光制造暴露不适 | 色彩服从具体压迫语境——既可用低饱和冷暗底配局部高反差刺点且阴影沉实，也可用惨白高调或单色偏调造不安，绝不套固定恐怖色板 |

- **单束光路严格自洽**：同一束光源只能朝一个物理方向传播并投下一致朝向的阴影；停电、寒夜、雨后等环境前提须落到可见实体实证（熄灭灯具、呼气薄雾、细雪或潮湿水渍）。

## 先定表现媒介再安排细节

先看观者需要读结构、品材料还是跟节奏，再定承载它的媒介，并用具体边缘、明暗阶数、笔触或焦点疏密分区（核心画眼精细收紧、外围概括退远）落实。混合媒介写清主体、局部与背景各自归哪套手法管辖及衔接方式。

## 选择人物肤质与表面明暗

人物皮肤入画且质感会影响观感时，依人物身份、媒介、已选审美与景别确定皮肤目标（健康清透、微带风吹红晕、自然暖褐或饱经风霜的粗糙肌理），**不把假白、过度磨皮、强写实毛孔或性感当默认预设**。拆成四层独立控制：

1. **肤色色阶**：决定整体均匀过渡，还是保留寒风微红、日晒血色、苍白或风霜色变。
2. **形体转面**：靠鼻梁、颧骨、眼窝与下颌的明暗转折立住立体体积，防止脸部被平光拍扁。
3. **表面反射**：按环境和肤质控制额角、鼻尖、颧骨等高光区的面积、强度与边缘软硬（克制自然微光、冷汗微反光或干燥哑光）。
4. **微纹理尺度**：随观看距离与媒介收放——近景手艺人粗糙纹路或户外自然肤理是重要活人锚点，非写实插画或中远景则按媒介收束，绝不给水彩插画硬塞摄影毛孔。

**局部修正与身份标记底线：**
- 反馈皮肤发脏、点状、过油或发平时，定位到对应层只修该层（点状修微纹理连续性，过油修反射层，发平修转面明暗），保住已成立的身份、构图与脸部体积；
- 雀斑、痣、疤痕、泛红仅在身份设定、状态或明确需求时加入，严格绑定具体部位、范围与当前景别可见大小，不蔓延全脸；参考图偶然出现的斑点不随光影迁移；
- 陶瓷、金属、木石等非皮肤材质一律按自身釉层、纹理与反射规律处理，不套人物肤质规则。

## 以物件的表面特征选择观察面

单件器物或材料的识别核心落在轮廓、釉面变化或既有磨痕上时，在允许的观察角度内比较不同朝向如何同时显出主轮廓、受光面与关键痕迹，选出最有辨识力的观察面，再配合相邻背景与尺度参照，保住已有身份边界不擅加新损伤。仅当需要横向比较一组同类物件或系列图时，才将观察位固定为统一比较基准。

## 让光显出需要被看见的部分

明确写出**专业光型 ＋ 入射方向 ＋ 落点与物理回弹**，使光源、受光面、阴影与反光互相解释：

- **常用工业光型**：侧光与**伦勃朗光**塑出立体雕塑感与深沉情绪；**逆光 / 侧逆硬光**切出锋利轮廓、透光发丝、热气或飘雪；**顶光**聚拢温暖中心或压暗眼窝造孤立威严；**底光**由下往上照亮下颌并拉出上扬怪影，专造悬疑诡异；**聚光与狭缝硬光**切出明暗边界锁死视线；**低角度掠射光**沿粗糙木石、织物或旧皮扫出立体触感起伏。
- **软硬与反差独立控制**：阴影软硬看光源表观大小，明暗反差另行控制；仅在暗部关键结构丢失或需回应另一现实光源时加克制环境漫反射，绝不盲目把暗部全打亮成发灰平光。

## 让颜色在彼此关系中工作

- **先分职责再定色相**：明确大面积母调素底、连接主体与场所的过渡邻色，以及承担唯一画眼或孤立刺点的核心色；强调色若无明确落点即省去。
- **邻色与面积比较**：颜色的存在感由邻色明度、色块面积与边界决定。微调主体跳出度时，先固定主体、调整紧贴邻色的明度与纯度，不靠硬添新物件解题。
- **多光源色彩协同**：冷暖混合光须写清各区域分别由哪束光主导，并在门窗交界或潮湿表面写出自然过渡。

## 以设计方向组织服装道具与空间

**先定它为何存在、呈现什么气质，再让形、色、材彼此照应。** 初次探索只锁定最能改写观感的少数方向，常规细节留给模型自然展开，不逐格填表：

| 可控方向 | 何时值得确定 | 保持开放的局部 |
|---|---|---|
| 类别、用途与时代语境 | 防止礼服混常服、祭器混工具，保住现实或架空世界观自洽 | 不影响类别与功能的次要构造 |
| 轮廓、体量与比例 | 修长与宽展、轻巧与厚重、开阔与包裹会直接改写气场时 | 精确厘米数、裁片细节 |
| 材料与表面气质 | 丝绸垂坠、粗棉织纹、旧木包浆、磨砂金属、磨损皮革等支撑质感时 | 逐点划痕、纤维与微纹理排布 |
| 主辅色与背景分离 | 统一套装、确保主体从紧贴背景清晰分离或定整体色温时 | 非必需精确色号与面积百分比 |
| 装饰语言与繁简 | 植物或几何纹样大类、配饰风格、疏密节奏支撑身份时 | 每片花叶、针脚尺寸与珠石数目 |
| 空间功能与行动尺度 | 确保场所能容纳实际活动，入口、通道与视觉中心自洽 | 非剧情必需的坐标与全部陈设清单 |

- 雍容华贵、古朴克制、细密植物纹样这类概括方向词，只要接到明确对象、时代与用途上就是有效方向，无需硬拆成施工细则；仅当同一表面要求打架时才做取舍。
- 服装兼顾穿着与活动，道具兼顾持握与功能，空间兼顾通道与使用；仅在用户精控、复现既有资产或剧情关键辨识时锁定精确纹样部位与尺寸。
