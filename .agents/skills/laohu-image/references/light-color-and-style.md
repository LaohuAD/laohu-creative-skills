# 光色与风格

由 [laohu-image 主文](../SKILL.md) 在媒介、色彩、材料显形或表面取向影响画面时按需读取。沿用已定观看范围、媒介和对象，形成可见的材料、光色及设计方向。肤质、材料和照明回到[让材料在光线中显形](../SKILL.md#让材料在光线中显形)，媒介与颜色决定分别回到[选择媒介、色域与气质](../SKILL.md#选择媒介色域与气质)和[让颜色关系参与观看](../SKILL.md#让颜色关系参与观看)。需要专项的绘画造型或实拍反射、灯位与光型时，由宿主按工作条件选内部方法。

## 先定表现媒介，再安排细节

先确认观者需要读出结构、感受材料还是跟随形状和节奏，再选能承载这一目的的媒介。连续明暗与真实反射适合强调产品形体和地点，少量明确色阶适合清晰剪影和分组，纸白和湿干边缘可形成柔和过渡，刻线与连续空处可组织重复节奏。媒介开放时以这些可见取舍决定，水彩、胶片或其他表现均依当前画面需要。

风格名称可以压缩已选方向。表达含混或混合条件时，落到本图的边缘、纹理、明暗阶数和空间方式。明确主体、局部与背景各用哪种表现，并检查接缝和局部表面。影视感可通过观看位置、光色或材料实现，影调、画幅、逆光与颗粒按任务分别选择。实验画面允许改变现实中的形体或受光，沿同一表达处理相应区域。

## 选择人物肤质与表面明暗

人物皮肤进入画面且其肤色、质感、反射或局部细节会影响人物读感时，先依据身份设定、目标媒介、用户已选审美和当前景别确定表面目标，再设计其可见呈现。方向可以是清透匀净、柔润微光、自然暖调、成熟纹理或明确的局部身份特征；不把白皙、磨皮、毛孔或性感固定为人物图片的默认。

分别控制**肤色色阶、形体转面、表面反射与微纹理**。肤色色阶决定是均匀过渡还是保留局部色变。体积依鼻唇、颧骨和下颌等结构的明暗转折。表面反射由高光面积、强度、边缘和方向体现，柔亮可用面积克制的柔光反射。微纹理按观看距离和素材目标选择，近景仍先保五官和体积，中远景收束到当前尺寸读得到的程度。仿陶瓷、金属、石面等非皮肤部位按本身的釉层、色纹和反射组织。

用户反馈肤色斑驳、点状、过亮或脸部体积变平时，先区分肤色变化、转面阴影、反射高光和微纹理密度各自造成的可见效果，再只调整对应变量与受影响范围：色阶连续性回到肤色层，明暗转面回到形体层，高光面积与强弱回到反射层，纹理疏密回到表面细节层。修订后分别复查表面状态与面部结构，并保持已成立的身份、姿态和画面关系。

仅当身份资料、已确认状态或表达目的需要雀斑、斑点、痣、疤痕、泛红等局部特征时才安排它们，并绑定具体部位、数量或覆盖范围、在当前景别下的可见大小与对比强度。一个局部身份标记保持在其指定区域；大范围肤色与明暗按所选目标继续组织。写实、摄影、高清等媒介词本身不推导出雀斑、毛孔或全脸纹理；用户只认可参考中的光影、姿态或整体氛围时，参考图里偶然出现的皮肤细节不随之迁移。

## 以物件的表面特征选择观察面

物件或材料的识别重点若落在轮廓、受光面、凹痕或擦痕上，先在用户材料或资产明确允许的朝向内比较这些面如何显出本物特征，再选最有辨识力的观察面；接着配合相邻背景和尺度参照，让表面线索既可见又不脱离物件整体。只有需要比较一组对象或一系列图、且固定基准能帮助比较时，才保持观察位置不变。

这项取法来自 Joel Meyerowitz 对《Morandi’s Objects》的拍摄回顾。资产身份、既有痕迹与锁定朝向均按真实材料保持，选择落在允许的观看角度内。

## 让光显出需要被看见的部分

先确定当前视点需要辨认的受光面、转折、投影、反光或透光边缘，再安排主光位置、覆盖范围和近邻背景。粗糙表面可用方向明确的明暗显出起伏。光滑表面先定所反映的环境亮区或颜色。透明表面先定能透出的背景与可辨的边。写实反射和复杂布光细则由宿主按摄影方法的触发条件调用。

| 光线选择 | 具体可见效果与用途 |
|---|---|
| 正面、侧面与逆光 | 正面光保正面细节，侧光拉开转折，逆光给出轮廓、透光边缘或剪影。逆光正面仍需辨认时，用相邻亮度或少量补光保结构。 |
| 顶光、上前方光与底光 | 顶光照到头顶、肩面和物件上面，眼窝和下沿偏暗。上前方也见脸部或前表面，鼻下、下巴和背向处有影。底光先照到下颌、鼻底或物件下表面，影子向上，从实际光源或刻意造型决定。 |
| 聚光与掠射 | 聚光把光区控制在需突出的表面或区域。掠射沿粗糙表面或刻纹扫过，留下能读到起伏的细影。按需要辨认的材质或对象选择。 |

阴影软硬依主体所见光源的相对大小，画面亮度和反差另行调整。辅助光只有在需补暗部、分开轮廓或回应另一现实光源时加。需要威势可比较低机位、稳定重心和能塑出脸的上前方光，需要不安可比较底光造成的上投影和遮挡或倾斜视点。灯位的取舍由人物关系与场所决定。

高调、低调描述全幅的明暗分布和反差。高调可用明亮背景和相近明度组织主体，同时保住轮廓和材料。低调可留出大暗部和局部亮区，并保住所需暗部信息和曝光。匀光陈列可由轮廓、色差、间距或重复节奏形成多个可比较的落点。

## 让颜色在彼此关系中工作

先给主色分配面积，再决定辅助色如何连接空间、强调色要不要转移视线。颜色的视觉分量不能只按色名判断：小块高饱和色可能醒目，大块中明度色也可能压住它。若强调色没有明确要引导的下一处，就不额外加入。

把主体色放回邻色、背景、光照和材料中看。比较时先固定主体，只改一项：换邻色，看轮廓是否跳出；改色块面积，看谁占住画面；挪位置，看视线第一落点是否转移。方法结构示例（非专业作品分析）：同一只暗色水壶放在浅蓝墙面前与深蓝墙面前，边界的分离程度不同；水壶颜色没变，它在画面里的存在感已变。按用户要突出、融入或转移视线来选组合，再用轮廓、光影保住必要辨认。冷暖只能描述相对倾向，不规定唯一情绪；颜色意义来自语境和相互关系。

检查色彩与光线是否协调：日光、室内灯或有色光源可能改变同一表面的观感；设计可保留混合光，但须明确哪些区域受哪束光影响。绘画或图形媒介可以主动调整固有色以服务层次，但要留住物体识别和用户指定的颜色。

## 以设计方向组织服装、道具与空间

**先决定它为何存在、呈现什么气质，再让形、色、材彼此照应。**

初次设计先从题材、使用者、用途与观看目的选择少量会改变整体的方向，不按下表逐格填满。明确对象类型不等于规定全部造型；给出材料家族、轮廓倾向或装饰语言后，普通实现细节仍可开放。

| 可控方向 | 何时值得确定 | 可以开放的实现 |
|---|---|---|
| 对象类型、用途与时代语境 | 防止把礼服画成日常装、把祭器画成工具；现实依据与幻想程度需相容 | 不影响类别与功能的局部构造 |
| 轮廓、体量与比例关系 | 服装修长或宽展、道具轻巧或厚重、空间开阔或包裹会改变整体感受 | 具体尺寸、曲线和裁片，不必量化比例 |
| 材料与表面气质 | 丝绸的垂坠、旧木的温润、金属的冷硬等确实服务方向时选定 | 纤维、划痕、反射与微纹理的逐点形状 |
| 主辅色与明暗关系 | 需要统一套装、区分主体或营造整体氛围时 | 无必要的色号、精确面积百分比 |
| 装饰风格与繁简程度 | 配饰款式、植物或几何纹样、繁复雕刻等支撑身份和气质时 | 每片花叶、雕线走向、珠石数量与排列 |
| 主次、均衡与节奏 | 明确整体重点；让留白、重复、疏密与对比相互配合 | 次要物的逐件摆位和装饰密度数值 |
| 空间功能、尺度感与光氛围 | 场景能容纳需要的活动，入口、主要区域和视觉中心有关系 | 非剧情必需的坐标、每件陈设和全部灯具参数 |

“雍容华贵”“古朴克制”“高端大气”“复杂雕刻纹理”是合法方向词，不因概括就删除，也不强制逐词展开成施工说明。将它们接到明确对象、语境和用途上；词义已足够支持设计时停止补充。只有互相竞争的方向才需要取舍，例如同一表面同时要求完全素净和满布装饰。形容词不能独自保证质量，也不要无差别堆叠赞美词。

审美检查针对关系：轮廓是否易读，比例是否符合角色与用途，材料和时代语言是否协调，装饰是否有主次，空间是否可用，画面是否传达预期气质。这里的人类审美随题材、文化、受众与表达变化；朴素、粗粝或不安也可能是恰当设计，不默认奢华、对称或干净才美。刻意冲突有表达作用时保留，不机械修成和谐。

服装考虑穿着与活动，道具考虑持握和操作，场景考虑行动与空间组织。初次设计可写纹样的大类、疏密或整体表面，精确部位和形状留给确有必要的精控、复现或剧情辨识。锁定衣装保留剪裁、颜色、纹样及配件，取景冲突时先试改姿态、机位、光色或背景。衣物、物件和场地各按资产交接确定展示对象、画幅与对应局部。以本轮实际接受的身份参照进入稳定复现，探索中将新增选择作为提案。
