# 提示词整合

由 [laohu-image 主文](../SKILL.md) 在最终生图提示词编译时读取。定取景、构图等决定前遇到互斥要求，可先取[处理冲突与不确定项](#处理冲突与不确定项)一节，将具体取舍带回原设计步骤。正式编译接收已选媒介、观看关系、当前视点、素材、锁定项及可变范围，返回主文的[内容选择与提示词整合](../SKILL.md#内容选择与提示词整合)。简单单主体只取与本图有关的组织、成像与复查。资产入口按自己的调用契约只取组织或正向成像的小节。

## 先给每项信息定状态

动笔前把信息分为四类，并确认每条信息在最终画面里承担什么职责：

| 状态 | 含义 | 整合动作 |
|---|---|---|
| 用户已定 | 明确指定且必须保留的主体、内容、形式或禁项 | 原意保留；只调整语序，不弱化要求 |
| 用户偏好 | 用户表达倾向但允许实现变化的要求 | 先满足；与硬约束冲突时说明取舍 |
| 开放变量 | 用户尚未决定且委托 AI 设计的部分 | 依据用途、材料与视觉主次补足 |
| 不适用或无关 | 当前画面不存在、不影响观看或无法执行的信息 | 省略；不要为了字段完整而填入 |

材料支持的事实、AI 的设计推断和用户决定不可混为一类。用户给了真实人物、地点或物件时，不以生成提示词为由改动其身份和事实；AI 补充的可见细节只须符合任务范围，不必逐项请用户确认。若两项信息互相竞争，先看哪项是核心关系的支点；用户已定的支点保留，AI 补充的变量服从它。

## 继承同作风格与当前可见的身份

收到资产规格或交接时，依据[图片提示词交接与固定输出](../../laohu-assets/references/image-handoff-and-output.md)确定展示对象、格式、固定内容和基础依赖。完整人物参考按约定展示需辨认的全身与脸，服装平铺按衣装本体展示，道具和场景也各依本项用途。具体叙事帧遵守当前机位，第一视角按当前能看见的手、衣袖、持物或空间线索表达，不因完整人物参考图需展示身份而露出本镜禁止见到的脸或背影。变体和局部编辑仅改本轮明确开放的对象、部位或状态，既定取景冲突时先用可调整的机位、姿态或光线解决。

输入中的资产规格表和模板用于提取对成图有作用的身份、用途、保护项和该条提示词的固定格式。仅在本轮请求同时要求提交资产交接表时，才按该接口整理规格字段。“按已有交接做图”“按资产要求做状态图”沿用相应输入。仅要求完整提示词时，回主文交付一条提示词，块外原样附必要且已提供的真实 ID 或适用范围，缺值省略。

同作确定过画风时，从上游现有规格及相关提示词提取实际采用的四项共同决定，即**渲染媒介与质感、形体简化与线面、色彩气候与饱和度、光影对比与材质温度**。这些关系常体现在“主要形态与关系”“色彩与材质倾向”“识别与保持项”及配套图中。把已定的四项分别落实到当前对象的表面、轮廓、颜色和受光，并保留已定主辅与焦点色的职责。比如棚拍参考中的展示光与剧情场景光可以不同，同时继续承接已选渲染、形面与明暗处理。缺少某项已接受事实时标明依赖，只有明确开放的细节可设计。无需新增 Style Lock 字段或把上游规格标题交给模型执行。

从每项资产现有“识别与保持项”选当前图看得见、在目标尺寸能辨认并确实影响身份的特征。单镜通常可从两到三条高辨认特征起选，按景别和用途增减。只有一条可见就保留那一条。用户锁定、接口规定或职责要求的可见特征较多时逐项保留。锁定纹样沿其原部位、比例、颜色及可见强度承接，远处若细纹不可辨，优先用可见剪裁、色块或结构辨认。遮挡及画外特征仍保留在底稿，已接受但不可读取的原貌也保持未知。准确复现依赖未附的原图或规格时，先交有依据的部分并说明复现所需材料。

场景先继承世界坐标、固定物和结构，再从当前观察点转换成左右、前后、遮挡、距离及尺度参照。视角状态合并已知结构、观察点、方向和必要取景。需要精确复现时以实际平面图、底图或三维布局支撑文本指令。提示词只写当前视角可见的关系和有依据的范围，具体空间推导见[场景固定坐标转成当前镜头关系](image-content-and-viewing.md#把场景固定坐标转成当前镜头关系)。

## 按观看顺序组织

普通生图提示词默认用自然、精炼的中文。用户明确要求英文等其他输出语言时按其指定语言编写。用户锁定原文、指定画内文字或资产固定文字保持准确字形，模型接口保留其真实标签与字段。准确的摄影、美术术语可保留其惯用原名，按画面需要连上可见证据。

首句写出已定的媒介或最承重的风格特征，并用具体主体与动作、状态或位置关系让画眼成立。续写需要辨认的主体、各自空间位置和观看边界，再给光线、颜色、材料与必要画幅。随着任务调整顺序。空间图可让主要观察位置进入首句，肖像可把脸部和姿态的可见关系放在前面，剪纸可先定主形和周围留白。普通细节沿已定方向开放。由宿主在编译时接入多人归属、参考分工和首帧设计的结果，按实际采用的入口附加参数。

专业名词与可见证据各有作用。可以写“伦勃朗光，暗侧脸颊留一块小三角亮区”“顶视，桌面正上方入画，刀叉和杯口分开”。证据和术语冲突时依目标画面校正术语。机位、俯仰和横滚应各自有需要时明确，纯平面可直接写轮廓和构图。提示词中的镜头数字、流派名或画质要求应有明确画面职责。

环境字形按位置、视觉分量或场所作用描述，是否清楚不改变其用途。需让观众准确阅读指定文案或指定字体、字号及排版时，按[能力范围与交付边界](../SKILL.md#能力范围与交付边界)处理。水印遵循用户单独要求，已定资产的色卡等固定文字按实际交接契约承接。

### 普通提示词的正向成像表达

把用户排斥的结果当作目标条件，转为同一对象、部位、范围、数量、身份边界与力度下的正向可见状态。具体目标已由要求或反馈定下时直接编入。只合并对象、范围、作用和强度相同的条件。皮肤色阶、形体明暗、反射和微纹理各自落实。衣物连续纹理、物件边缘、区域或视窗的成像保护仍按原部位、范围和力度表达，压缩或修订也逐项保留。

例如全画面禁字时，把包装、招牌、标签和背景中相关可见表面写成完整空白、纯色或无字图形。普通无字或无需标题的要求只作用于标题等为观者阅读的信息，保留场景所需的环境字形。局部空白只描述指定的表面，其他区域按原有职责处理。按语义识别画面属性，“无袖”描述剪裁，可直接写入普通正文。

普通正文保持正向成像，不附泛化排除清单或额外负面段。遇到用户锁定原文、明确要求独立负面字段，或资产接口指定固定措辞时，保留该句、字段名、顺序和取值中明确锁定的部分。用户给出独立负面字段内容时，按原对象、边界和力度保留其文本及所需语言，在被指定的独立字段交付。用户只指定需要字段、未给出原句时，按其具体排斥内容编写，使用本轮提示词语言。自由组织的资产描述与普通正文同样逐句转换。实际接口须使用其存在的字段或参数语法；若文字交付要求保留独立负面内容而工具没有此能力，可另外给出文本供用户使用，并说明该入口可用的输入范围。

## 处理冲突与不确定项

先查是否同一对象、同一维度和同一时刻的条件互斥，再检查补入的变量有没有破坏根本关系。多数可通过位置、尺度、朝向、局部照明或表现分工解决。两项明确要求确实无法并存且目的不足以裁决时，交宿主说明可见差别并就该项询问取舍。

常见冲突需要落到画面后果：

| 条件组合 | 需要判断什么 |
|---|---|
| 全身与面部特写 | 哪个信息必须可见，是否改为更宽景别或分成系列 |
| 主体正面与身体背向镜头 | 观者需要看清脸还是动作方向 |
| 强逆光与衣料纹理清晰 | 轮廓氛围与表面细节各自的优先级 |
| 密集陈列与大面积空白 | 空白承担主体间隔、观看停顿、表达缺席，还是用户明确要求的后续版式 |
| 写实摄影与平面剪纸质感 | 采用哪种作为整体媒介，另一种是否只用于局部 |

用户有意采用抽象、拼贴或不合常理的并置时，把反常关系写成清楚的画面指令。省略不存在、画外、重复和不影响观看的内容。已知保护项仍逐项校核。

## 整合后返回

逐句检查完整正文，包括整合时新加的分句。把残留排斥句转为准确的正向状态，确认已定风格、每个对象的属性归属及各部位的保护力度仍成立。分开检查用户锁定原文、明确要求的负面字段与资产固定内容是否准确。回读效果目标时核对主体、动作、关系与光色是否服务画眼。

同时交效果说明和提示词时，从同一组已定画面关系写两项。尤其核对两处提到的对象是否都在这个画面里，以及数量、所在位置、动作相位和物理状态是否一致。发现有冲突时，以核心关系和锁定项裁定一个状态，再同步两处。交回前按本轮请求核对交付范围，交所需的成品及适用格式。

新图及既有资产的状态和局部编辑默认返回完整、自然连贯、可直接使用的提示词。以已知基础外观、获准变化和持续有效的保持条件合成一份。按参考图重绘时，完整提示词同时写清需配哪张图、图片负责的变量及文字新增的内容，保持条件经绑定进入模型。用户明确只要差异或补丁时仅交所需变化与保持项。每条提示词独立成块，资产 ID 与适用范围放在块外。成图状态和交付子集依宿主的[返回值](../SKILL.md#返回值)。
