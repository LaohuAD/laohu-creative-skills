# 原则、方法与文档表达

由 [evolution 主文](../SKILL.md) 在写入、改写或迁移运行规则、创作原则、专业来源或示范时读取。它说明怎样保留已选判断并把它接成执行办法；读完返回主文继续实施。核心目标、专业范围与关键取舍仍以上游已确认方案为准。

## 更新规则前按语义对照

局部更新、新建、融合和整体重构，只要会写入或改变运行规则，都先比较本次明确范围内的新旧判断单元；不按相同词语判重复，也不因表达不同误判为不同方法。一段文字含多项判断时，先拆成能独立改变选择、动作或范围的单元再逐项比较，避免整段归并时丢掉独有条件。对照对象/目的、条件与适用范围、动作与判据、优先级与要求力度、例外与停止条件、产物与实际消费者。

| 对照结果 | 写回方式 |
|---|---|
| 同条件下判断与动作相同，只是同义表达 | 择优保留更准确、具体、可执行的主表述为唯一真源；把各自独有条件另行承接，不要求沿用旧句，也不并列重复规则。只有用户明确要求多个版本时才并列呈现，并标明各自用途。 |
| 新内容补足旧规则缺少的有效条件或动作，且能兼容 | 融入现有对应位置，只补缺项并接上消费者。 |
| 条件不同，因而适用动作不同 | 保留清晰的条件分支；不能为追求合并而抹平适用边界。 |
| 同条件下动作、优先级或力度互不相容 | 作为冲突处理，不并列保留。先遵守上位约束和已确认目标，再比较适用证据、具体性、可操作性及该规则是否改变实际选择；不以新旧、权威或篇幅长短取胜。依据仍不足时，只暂停受影响的判断并交回 analysis，其他无依赖工作继续。 |
| 已确认错误、失效或被完整替代 | 可删除，并在轻量映射中记明依据及替代位置；不得把尚有效的独立条件随之删除。 |
| 找不到可承接的对应规则 | 先在现有合适位置补入；新文件只按[文件变更与调用依赖](change-workflow.md)规定的独立职责和真实消费者条件创建。 |

MECE 只检查本次已明确范围内的职责或判断是否重复、是否遗漏；跨职责依赖可以相连，不要求彼此互斥。覆盖检查不能代替上述冲突校验，也不能证明方法正确或质量达标。完成轻量 before/after 对照：每个新增项均有已确认方案、用户选择或可靠依据；每个新增项和仍有效的旧项都有去向，每个重叠或冲突都有处理结果，消费者只读取对应真源。无依据新增或未经允许遗漏仍有效的作用，判 `FAIL`。局部更新只映射受影响单元，不把映射扩成逐句台账。

## 先保留方法怎样作出选择

按上面的语义对照和已确认取舍选定实际采用的方法、原则或原句，再做保真：用户提供的比较材料不等于要求逐句、逐项全收。用户明确指定原句必须原样保留时照字执行；提供范文时，先辨每句话承担的是原则、机制、引导、动作、例外还是交付职责，再将已选功能放入目标中承担同一职责的位置。对选定且准确适用的用户原句，优先写入实际承载判断的主文或 Reference；经核实且适用的专业来源保留其标准名称与核心命题并标明出处，不只放在背景资料里。

已选方法仍有效的条件、机制、顺序、优先级、例外、停止条件、舍弃对象、模板接口和要求力度都须有去处。原句或术语已能指导本地选择时直接使用；只有本地适配仍有歧义或执行缺口，才补足必要说明并区分来源原意与本地适配。可以合并重复内容，但不能机械全抄，也不能把方法缩成只剩核心命题；任何会改变选择的信息若要删改，须有明确取舍依据，不能悄悄降级。信息密度看独有判断及其必要衔接，不以字数相同衡量。

外部原文须准确、可定位并与判断相关；译文与原文分开，自译注明“自译”，转述标“意译”或“概括”，不可把二手说法加引号冒充原话。版权来源只引用完成判断需要的短段；歌曲歌词避免引用。无法核读原文或上下文时，不称为原话，标出待核或使用明确的转述。用户提供的原句按其选择复用，但仍判断本地适用；引文证明来源曾作此判断，不自动证明它适合本地或已产生效果。不要改变原方法的优先级、步骤、条件、舍弃对象或力度，除非有用户已选方案或 analysis 确认作为依据；不为名言感堆无关引文。

## 让运行方法在本地闭合

研究、设计和维护规则时，可以访问外部来源核验原文、上下文、版本和适用范围；这是建设阶段的查证，不是未来执行者的运行步骤。**供任务读取的 Reference 不保留外部 URL/网页链接，也不要求执行者打开网页或点击来源，才能补出理论、判据或方法。**把已选且核实的方法、适用条件、输入、步骤、判断标准、例外及必要的短引或本地用法写进 Reference，使执行者只凭项目内文件即可依方法处理任务。不能只删掉 URL、留下术语或书目。

出处仍可用文字说明作者、书名或文献、版本/年份、章节、页码或机构；准确区分原文、译文、自译、意译/概括和本地适配。核验来源不等于可以整篇复制受版权保护的材料：只保留完成判断所需的短引，方法本身用准确转述或本地执行规则承接。来源暂时无法核实的，不编造出处或原话；收窄相应主张、标明待核，并继续落实已有充分依据的部分。

这条限制的是 Reference 把外链当作方法入口或补缺依赖，不把所有任务改成不得联网。任务本身需要时效事实、新作品核验或用户指定研究时，按本轮目标与授权进行查证；查证由任务触发，应用专业方法所需的判据仍应在本地写清。

## 从目标关系提炼原则

先找出用户要改变的结果、材料之间的决定性关系和优先保留的取舍，再写一句能影响多种选择的原则。原则不是装饰，也不是一串质量赞语：读者应能据它判断该留什么、舍弃什么，及何时换法。补充解释时延续原句方向，不为显示改动而换成平庸近义句。

创作与审美规则采用用户指定的表达总纲。以下原话作为本项目的写作标准完整保留；这是用户选择，不冒称通行学术理论或外部证据：

> 我要的是现代汉语的诗学箴言体。
> 它不是文言文，不靠生僻词，不写成学术说明，也不把规则平铺成禁令。
> 它用熟悉的字词，通过对偶、判断、反差、具体意象和关系压缩，写出一句能够统领多种创作选择的正向原则。
> 它要少说而不空，含蓄而有方向，简洁而有重量。
> 原则句负责定魂，机制说明负责解码，执行规则负责落地，验收规则负责纠偏。
> 不要让解释取代原则，不要让禁令取代审美，不要让细节框架压过文学中心。

用熟悉的现代汉语表达真实关系，选择能使句意变得更准确、更有方向的对偶、判断、反差、具体意象或关系压缩，不要求每句用齐所有手法：

| 表达手法 | 写作动作 | 纠偏条件 |
|---|---|---|
| 对偶 | 并置相互支撑或需要权衡的两项关系，让句法呈现职责或取舍 | 只为整齐而凑出对立、丢失例外时，改回准确关系 |
| 判断 | 明确优先保住什么，让原则决定选择 | 只有赞语而无法改变处理时，补出取舍；有条件的结论在机制中限定 |
| 反差 | 对照熟悉预期与材料中的实际差别，突出决定性的发现 | 新奇来自偷换目标或虚构事实时，退回原材料 |
| 具体意象 | 借熟悉事物的实际关系承载抽象原则 | 无法对应到当前判断与动作时，换意象或直接陈述 |
| 关系压缩 | 将共同关系凝结成一句，合并重复，保留改变判断的区别 | 压缩后指代、因果或条件需要猜测时，补齐自然词组与必要说明 |

若修辞只是为了整齐、新奇或含蓄，却遮住条件、事实或指向，就改回自然准确的说法。

原则可以含蓄，但要能承载明确取舍；丰富联想须有用词、材料或语境支撑，不能靠空泛套用。原则可由不同材料和形式实现，也须排除至少一种偏离目标的做法。检查朗读时的自然搭配、指代和认知承接；不以字数、术语数或句子“像不像金句”衡量信息密度。

## 让原则走到动作和成品

原则给方向，机制说明它为何适用，执行方法把它落到选择，成品验收检查是否偏离。四项职责相互承接，不是每篇 Skill 都要机械出现四个同名栏目：

- **原则定方向：**说清目标关系与取舍，使不同写法仍指向同一结果。
- **机制解含义：**说明材料怎样经由这项关系产生效果，写出适用条件、反例和开放变量；不把所有写法提前说尽。
- **执行给方法：**指出输入、选择、取舍、生成、比较和反馈怎么做；固定必要关系和用户确认边界，给材料、视角、情境、措辞与形式留出条件化空间。
- **验收查偏离：**检查具体产物是否体现原则并保留保护项；没做到就修正对应步骤，不能补一段赞美或解释充作通过。

规则要沿实际处理顺序，让一次普通请求能够走到完整目标产物：执行者看哪些材料、依何条件选择、为什么舍弃近邻做法、怎样制作、中间结果交给哪一步、什么条件会切换或退出。先写可以运行的正常路径，再在它实际改变动作的位置说明分支。未知只在影响选择时补取材料；条件不成立时使用已选替代或说明退出，并推进不依赖部分。

步骤只在有真实输入、决定或下游用途时保留。执行者若仍须自行发明核心取材、筛选或制作方法，就补足已确认的方法或交回专业判断。多个方案都满足硬约束时，根据已选目标说明优先项与代价，不把全部取舍推回执行者。

创作规则参照 [analysis 的四层能力定义](../../laohu-analysis/references/capability-design.md)：专业原理支配选择，作品内部关系承载原理，材料和技法实现关系，目标效果可由接收者感知。写人设时，必须把已选且核实的专业方法分别连到观察变量和裁决动作，再说明保留或淘汰方案的标准；只写“懂审美”“追求高级”不能指导选择。需要扩展专业方法时，沿“目标或问题→少数候选手法→画面可见特征→何时选、怎样组合或何时舍弃”组织内容：术语须能译成位置、形状、边缘、面积、动作、光影或材质等画面证据；主文提供常用选择、触发 Reference 的条件及返回位置，Reference 深化真正复杂的分支，不把能力写成名词词典。只保留会改变选择或避免误用的术语与原理，不用术语数量、通用质量词或单一默认配方代替审美裁决。稳定目标与必要关系，开放受条件影响的材料、形式和技法；不可把某例子的天气、意象、句式或构图改成配方。四层只用于适合的创作成品，不套到路径、数据或无关实现。


### 方向约束与细节自由

维护创作能力时，先区分必须决定的方向与允许模型完成的实现细节。服装、道具、场景及人物穿搭先明确对象用途与目标感受，再按任务选择情境/时代、宏观轮廓或空间关系、色彩、材质倾向和展示方式；不把“完整”写成强制填满纹样、缝线、尺寸、坐标。具体花纹可只定有无或大类形态，细部在方向内开放。类型、款式、材质与概括审美词都可承担方向，不强制把形容词逐一翻译成微观规格；专业控制维度须按该领域的用途与设计基础选择，不能把用户示例固化为穷尽词表或通用审美。

精确展开只由明确精控要求、已确认资产复现或剧情关键识别/功能触发，且只展开必要部分。首次构思、模型探索与选定参考后的连续性维护须有不同约束强度；未确认的Agent建议不自动升级为用户定案。给模型留余地不等于省略方向，也不意味着放松文件接口、授权、事实边界或用户已锁定的特征。

修订字段和模板时同步移除“无论用途都填全”的旧要求，保留方向字段，将精控字段作为条件扩展，并用宽方向请求与明确精控请求分别验证。

## 用结构让文档更好读、更好执行

标题让读者快速找到职责；每段围绕一项判断，先给重点再解释材料和动作。关键原则或决定可加粗以便扫读，不用把所有句子都标亮。表格用于真正需要横向比较的条件、选择或字段，复杂原理用连贯段落说明；确有顺序和依赖时再编号。同级而独立的事项用列表，但列表形状本身不代表顺序、优先级或并行。执行关系要由文字明确。原内容若已用表格、列表或示范准确承载条件与动作的对应关系，重排时保住这层对应，不把它压成失去配对的散文摘要。

面向创作的原则句保持凝练、有方向、有分量，必要的机制说明补全含义而不替代它；普通操作规则仍应短而准确。没有统一字数门槛，也不要求每个标题或段落都产出箴言。文件、授权、事实、路径、字段和停止条件使用确定表述，不借审美留白模糊接口。强度词必须保真：“必须/应当/可以/禁止”及默认、替代、例外不能互换；局部暂停不能扩成全局停止，独立检查不能误写为并行或串行依赖。

诗学箴言体约束 Skill 与 Reference 的规则语言，不自动成为生成作品的语体。先辨作品的用途与读者，再定表达的体裁与形式：按真实情境决定读者需要理解、感受或采取什么行动，再选择相应的语言、组织和版式；产物类型保持开放。

AI 内部的完整性检查不自动成为对用户可见的模板；自然段、列表或表格都按任务选择，没有统一格式默认。最终作品服务人的阅读或使用；若还要交给机器读取，精确保留既定字段、次序、格式和接口，不擅自加解释破坏契约。目标能力已有机器字段、模板或媒介约定时，不顺手改它们；作品内部组织关系与执行者、文件和交接关系也须分别说明，不互相冒充。

迁移时先辨清各段文字承担的身份：AI 执行指令、面向用户的引导或确认、精确输入/输出模板或机器接口、解释性示例、最终作品。用户可见话术标明是必须照用的原句还是可按情境调整的范例；引用块本身不代表外部引文，须说明它是谁对谁说的话或是什么来源。示例默认说明结构或选择，只有已确认方法规定为固定输出时才成为模板。

精确模板和命令放入代码围栏；迁移时保留其围栏、语言标记、字段、顺序、必需/可选项、占位符、可替换部分、前后缀及适用条件。哪些字段必填、何时执行按实际接口说明，不要求每次填入无关字段。嵌套 Markdown 时使用更长的外层围栏，避免内层围栏截断，使内容仍可完整复制。格式承担功能时，不能为排版统一而消除其可复制性、条件映射或接口含义。

## 控制范例和反向检查

正式创作范例只取可核实的专业原作、作者本人资料、专业教材或可靠机构教材。核对作品内容、出处位置、展示的机制与适用边界，并区分逐字引文和改写。正例展示已教的方法如何产生效果；反例指出关系在哪一步失效，两者都不能代替方法说明。来源或上下文不足时标出缺口，不自编片段、署名、读者反馈或验证结果填补。

AI 自拟作品、当前任务的完整试作和隔离评测产物可用于本轮交付或检查，不转成正式专业范例。结构或流程教学可用合成案例，清楚标为结构示例。没有正式范例不妨碍继续写好已确认方法：说明示范缺口，交付方法，并按授权继续局部试作。

以下结构示例只说明局部停止范围和可选强度，不授予任何项目的操作权限：

````markdown
```markdown
1. 备份已确认可恢复后，按清单顺序迁移。
   - 未找到可恢复备份：停止写入并返回目标路径；其他只读检查可继续。
   - 迁移超时：停止后续写入，报告已完成项和失败项。
2. 全部迁移完成后，检查原有读取路径仍可用并交付结果。
   - 可选：记录版本说明；跳过不影响完成。
```
````

压成“检查备份、迁移、处理超时、交付、记录版本”，会把局部停止范围和可选强度变成不确定或必做，不能作为运行规则。
