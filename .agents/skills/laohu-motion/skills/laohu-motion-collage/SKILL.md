# 材料揭示、裁切标注与接续

## 何时采用

当材料的裁切揭示、局部标记/遮罩、并置或跨材料接续实际承担解释、说明、演示或感官体验任务时，使用本方法安排材料如何进入并参与画面。所有材料都要保留其真实身份、来源、许可与语境边界；出现纸张、照片、人物、视频或“拼贴”词语本身都不构成触发，普通全幅人物/场景镜头不必调用。非证据材料不自动标为示意，也不自动承担说明职责；按实际任务判断它是说明、演示、体验素材还是其他画面对象。只有材料确实支撑现实主张时，才额外核对其来源与主张的对应、支持范围及证明力。方法只限于需要这些操作的对象或镜头，不要求全片采用拼贴皮肤。

## 输入与返回

主线传入当前观看任务、材料在本镜承担的职责、材料身份/来源（若已知）、许可与隐私限制、可裁切范围、需呈现的要点、目标尺寸和用户锁定范围。返回选择的揭示/标记/遮罩/并置/接续操作、可见区域与锚点、材料顺序及实际 renderer 映射。需要追踪同一材料的不同裁切、标注或交接时，蓝图以 `entityId` 标明语义材料/证据，以各自的 `instanceId` 标明真实绘制实例；单次出现且无需连续判断的普通素材不新增身份字段。一个材料实体可对应多个绘制实例，不能因它们共用素材文件就假定每处都显示了正确语境。若某材料作为证据，再补来源、语境、出处位置与证据边界；缺少原件时只暂停依赖该原件的主张，可选择明确标示的示意或继续其他镜头。结果回写同一镜头蓝图供全画幅构图与工具链消费。

若主线已选 `templateId`，用本地模板工具的 `show` 和原 schema 核对本镜需要的 image/clip/frame cue、局部遮罩或标记是否真实可用；只传授权的本地素材和源码实际消费的输入。素材/操作不在原接口内时，返回准确缺项与素材边界给主线，不伪造字段或改写上游源码。

若场景改由本地 Canvas `render.mjs` 实现，可查询 `list --type effect --intent mark` 或 `--intent focus`，但只把源局部效果用于有静态矩形边界的真实目标/标注。该 adapter 不绘制、裁切或跟随 image/video 素材；素材显露仍由本镜的实际资源 renderer 承担，圈注只承担局部指示，不能代替证据核验。

若本段选用 Video Shotcraft `ClipCard`，返回的材料必须是可追溯、获准使用的本地 clip；把它何时进入、可见窗口、语义用途、来源/证据身份和实际父层/placement 写回同一蓝图。该组件把已登记 `src` 显示为视频卡片，不因此获得任意裁切、证据认证或独立部件动画能力。它的真实 source props 与 adapter placement 分属两层，按[源接入规则](../../references/video-shotcraft-integration.md)核对；若当前接口不能完成语义需要的裁切/标记/接续，返回主线换用真实素材 renderer 或 Motion 实现，不往 `ClipCard` 传猜测字段。

## 选择与操作

先确定材料是在提供现实证据、解释性示意、操作演示还是感官体验，再选择会让该任务成立的裁切、揭示、标记/遮罩、并置或接续。若为证据，确认材料身份、提供者、支持的主张和必须保留的语境；裁切不能删去改变意义的日期、图注、坐标或限定，标记须指向可核细节并可与原件区分。若为示意/演示/体验材料，按观看目的组织画面，但不要借仿旧、时间戳、新闻边框等视觉符号暗示未核实的出处或证据力度。不同材料只有在对应任务支持同一事件、对比或接续时才连成路径；仅仅先后出现或并列，不自动画成因果关系。

需要读一份材料时，可从整份材料进入局部，再回到来源；多份材料可先并置核对，也可按有依据的时间/论证顺序逐份出现。若新材料的身份或必要细节是后续判断/操作的前提，先在观众依赖它之前露出足以辨认的内容与语境，再交给后续步骤；不要求每份材料都全屏或固定停留。已建立身份的缩略图、已知参照和纯装饰材料不必重复做完整揭示，按它们当下的参照或装饰职责保留即可。裁切方式、镜头移动、标记颜色和纸感按材料语境与观看职责决定，审美化可以有，但不能伪造档案身份、来源或证据力度。没有真实原件时可用中性重绘/抽象图示，并标清“示意”；不能通过仿旧、时间戳或新闻边框制造真实性。

## 映射到工程

Canvas2D motion-core 没有内建图片/视频对象类型。图片材料通过本地工程实际支持的加载方式或具名 custom:<name> renderer 绘制；需要异步资源时通过 runner 已有的 MOTION_READY Promise 等待真实加载完成。已有 rect/path/text/line 可承担遮罩范围、标记、标签和局部动画；事件可驱动已支持属性，裁切揭示可在 custom 内按时间做 clip。若沿对象镜头移动，让材料和标注共享真实坐标锚点；不要假定 scene event 能直接动画图片裁切矩形或 line 端点。源资产使用副本/链接策略须遵循当前工程约束，不得静默覆盖原件。

## 回到主线检查

最终帧和顺播中确认材料操作确实承担本镜职责、标记/遮罩指向正确区域、材料间接续与当前关系一致，且对象、文字和焦点在整幅画面中可辨。若材料作为证据，再核来源可追溯、上下文充足、原件未改写/覆盖、强调没有放大证据强度；小尺寸出处看不清时调整局部呈现或另提供准确说明，不能伪称观众读到了。非证据材料不需要虚构来源背书；未核实/未授权只阻塞依赖该材料的部分，并交回主线选择示意或停用。
