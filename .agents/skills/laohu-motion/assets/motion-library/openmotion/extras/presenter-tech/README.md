# Presenter Tech（Kinetic Tech）

MotionGit / adunext 的科技风口播模板。展开后的工程可阅读可复制，录制口播、字幕和屏幕素材在工作副本中替换。

[观看公开演示](preview.mp4) · [展开的工程目录](project/) · [工程上手说明](project/00-START-HERE.md) · [创作说明](project/CREATION.md) · [归属与许可](NOTICE.md)

工程包含 Python 运行器、渲染脚本、输入格式、字体、品牌素材、原生音效方案与一份纯文字测试例。复制工程目录到工作区后，按工程上手说明在已具备相关工具的环境里运行。专用运行器使用 Node.js、Python、uv、浏览器和 FFmpeg。
