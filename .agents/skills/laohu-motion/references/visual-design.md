# 视觉设计

本 Reference 负责让信息在画面中有清楚位置、层次和运动理由。内容关系与主张判断见 [内容到运动](meaning-to-motion.md)；具体画风专项由二级主文按明确要求读取。方法来源：本地《018_0930录屏讲解后期》口播动画样例的注意接续与样片检查、上游 t1_3b1b 的几何变换/停留/缓动卡，以及 17_ink 的分层笔触与遮挡修订。这里按通用解释任务改写，保留可迁移动作，未继承来源专属数值、节奏配额或频道身份。


## 输入与返回

本 Reference 接收已定观看任务、内容到运动的镜头蓝图、画幅与已选择的画风；如果仍缺少会改变构图的关键信息，先在蓝图标出未知。逐镜返回关键帧、视觉层级、文字位置、运动与停留、声画关系，并写回镜头数据交给工具链。交接后应能从每镜找到对象、起止构图和动作；阅读效果只按实际媒介观察报告，不预称所有观众必然读对。

## 画面组织

**安排注意顺序。** 当主体、文字、线条与背景动作同时争夺注意时，先决定观众应该看见哪个对象或动作，再放入理解它所必需的标签与背景。把主次关系落实到先后出现、位置、对比和运动强弱；目标画幅截图与正常速度片段都应能看出辅助层没有压过主信息，文字和主体也未被裁切。

**把对象关系放进画面。** 依据镜头要表达的是重叠、比较、包含、距离、流动还是作用，选择相应的大小、位置、遮挡、连接和留白。若内容并无空间尺度，就不要用透视或尺寸暗示远近与大小；示意结构也应标为非实测。完成的构图应能对应蓝图中写明的关系，而不只是把概念名词摆在一起。

**让屏幕文字有单一职责。** 字幕保留用户锁定原话，标签负责命名、方向、单位或来源，结论只在确有阅读需要时显示。长解释优先拆镜或交给口播；不要用整句字幕填满空白。按目标尺寸播放后，文字应完整、未被遮挡，并与所指对象同时可见。

**先定阅读路径，再移动画面。** 固定画布、资料桌面、空间穿行、分屏和局部聚焦需要不同的构图逻辑。先用关键帧确定主体、条件和留白，再决定镜头或画布是否移动；运动的起点、经过位置和落点都要留在工程可检查的帧上，必要信息不得在移动中被裁掉。


## 运动与停留

**先按本镜任务选运动方法。** 解释任务中，镜头若表现对象出现、累积、移动、分解、比较、触发或阻塞，就让运动承担这个关系/状态变化并维持可追踪的注意顺序。体验、情绪、氛围或风格任务中，若用户选定的观看目标由材质、形态、重心、速度、重复或变奏承载，连续运动本身可以构成体验，不必每一拍新增事实；把这些变化组织成有方向的进程和可落定的位置，不用无目的微动填时。界面动效把动作接到真实触发、系统状态与反馈。目标可以混合；环境微动只有不抢焦点且确实承担所选职责时才保留。蓝图应指出运动在服务什么；持续动或停住都不是默认答案。

**用 staging 接续注意。** 变化发生前先让对象显现，过程中保持身份、颜色编码或空间锚点稳定，事件落定后再引入下一焦点。这样观众能把前后状态认作同一个对象。检查时间轴时，应能指出显现、变化、落定与焦点交接的先后；不让两个重心同时争抢。

**先定 timing，再设计 spacing。** 先按语义确定关键相位何时出现、哪里需要停留，再用相邻帧位移安排速度变化。真实匀速移动、数据读数或定量变化必须遵守其模型和标尺，不能用弹性或回弹改动端值。逐帧核对后，口播/数据锚点仍对齐，位移趋势符合蓝图。

**普通移动以平稳落点为基线。** 解释性图形通常应顺畅起步并减速到端点；只有角色表演、材料弹性或喜剧效果确有需要时，才加入 anticipatory movement、overshoot 或 squash。任何表演性变化都不能改变测量值、数学关系或对象身份，最终端点仍须落在蓝图指定位置。

**连续形变先建立对应。** 只有同一实体或部件的路径、边、关键点能合理对应时，形变才会解释状态转换。把对应关系和运动方向写进镜头数据后再设计中间态；无法配对时明确切镜、淡出后重建或分步展示，不制造假连续。中间帧应能看出对应部位如何移动。

**锁定随机纹理的身份。** 程序噪声、笔触采样、粒子和生成帧可能逐帧漂移。需要重复渲染稳定时固定随机种子；纹理应附着对象时使用材质或对象坐标，并检查关键中间帧、重复渲染和循环边界。成片不应无故闪烁、滑移，粒子的出现和消失也要有可读理由。

**按观看任务决定何时继续或停住。** 对解释与阅读任务，新标签、关系图、数据或结论刚出现时，保留足够辨认、比较和思考的时间；当下一关系、状态或注意焦点确实要变化时再恢复动作，否则停在清楚的落点。对体验/情绪/氛围/风格任务，如果连续运动本身承担已选的感官职责，可以在没有新事实时继续，但应能指出形态、重心、速度或重复/变奏怎样推进体验，而不是空转。对界面任务，动作以交互结果或系统状态的呈现为边界。静止也可用于阅读、重量、期待或回味。检查落定状态是否有连续可查看的帧、是否被后续元素遮挡，以及下一事件是否等到相应观看任务完成后才开始。

**让镜头运动揭示具体对象。** 推拉摇移应有可指出的目标：揭示、换空间、改变尺度或跟随对象。镜头数据写明起止构图及新增关系；文字需要阅读时保持稳定或避开运动路径。若尺度没有实测依据，就不要让镜头运动暗示真实尺寸。首尾帧应能核对运动目的，且文字不会被裁切带走。

**用转场表达段落关系。** 同一对象或空间的连续变化可匹配运动，对照内容可并置或短停后切换，无关新题则干净切开。选法取决于内容关系，不能让转场模糊段落边界或带入未证事实；单帧检查前后对象仍应可辨。

**按观看任务调速度。** 解释任务中的轻提示、短强调、长路径和真实过程需要不同的时值；慢动作应展开本镜需要看清的关系/状态，或为必要阅读留出时间，不要拖慢无关路径。体验、情绪、氛围或风格任务可以让较慢的连续运动推进已选的材质、形态、重心或变奏，不以新增事实为条件，但须对应明确的感官目标；界面动作则按真实触发与反馈时机安排。快动作按目标帧率检查。没有统一镜头秒数或快动作比例，最终应逐帧确认关键相位、端点和数据准确，且无非预期跳帧。


## 声音与多层信息

口播承担的词语、数字、条件和结论应保持清晰；当配乐或音效压住这些位置时，降低或暂停竞争声。音效只标记真实的动作或交互，配乐支撑节奏，静默可形成有意停留；将声音触发点写入时间轴。最终播放需能定位声画对应时间、听清口播且无音轨断点；无声版本仍要保留关键图形关系。


## 画风与内容语法分开

先依据内容选因果、比较、步骤、空间、数据或情绪等解释语法，再让用户明确选择的画风改变材料、线条、边缘、色彩、纹理、相机和运动。同一种白板、像素或水墨方法可以承载多种内容任务，不能让风格名替代语义决定。拿掉装饰后逻辑仍应成立；加入风格后画面材料和运动语言也应前后一致。
**从参考迁移方法，再为新题材重新构图。** 用户给出具体动画、画面或风格参考时，先依据实际可见画面或实现，读出起态、动作、落态和注意变化；分别辨认风格语言、构图倾向、原作内容母题与叙事/动作。留下当前任务确实需要的身份连续、时序、因果或注意关系，把原作角色/内容、皮肤、专属标记和绝对数值分开。再按本题对象与关系重新安排构图和动作，把采用的关系写回镜头蓝图，并用关键帧与顺播检查是否服务本题。若材质是贯穿性的风格机制，可让它同时作用于主体与背景；静帧要独立成立，动态另核运动与连续性。没有提供参考时，不要求用户补模板或先选画风，直接运用已掌握且适用的方法。确有固定画风需求时，由主文按明确选择调用相应子级，方法与素材来源分开记录。

### 多对象转焦点，或集合状态整体重排

当一镜先建立多个并列对象/信息、随后要突出其中一项，或列表/网格增删后要让观众看出新整体状态时，可按关系选择两种不同的注意组织方法，而不是把某个模板效果固定套用。来源观察中，`motiontemplates/385712` 的 `core/scenes/s01.js` 以多对象空间运动建立场面，强调 cue 触发焦点收拢、背景退让并让文字按层次接续；Google Design Library 的 Photos 删除示例则让整个网格位移，在行移动过程中快速交叉淡化转换中的图像，避免每项各自沿交叉路径补位。前者展示“分散信息转焦点”，后者展示“集合重排”；来源案例说明具体实现存在，不证明哪一种普遍更好。

先判断本题需要哪一种关系：如果观众先要看见整体、再聚焦某个结论或对象，保留各对象的身份、相对位置/方向与必要关系作空间锚点，让选择 cue 到来时焦点对象/相关组向共同落点收拢，外围只在仍可辨认上下文后退或淡出；随后依 cue 逐层显出标签、重点文字或结论。若任务是从有序集合中删除、加入或更换一项，可保持网格/列表的整体顺序与邻接锚点，让布局作为一个整体一致重排，并只对本题中确实发生变化、需要淡入淡出提示的区域选择局部交叉淡化；这是对当前状态转换的本地适配，不是 Google 示例“只淡化被删除项”的复述。两种方法都要安排清晰的起态、动作、落态和停留：起态建立对象及空间关系；动作由真实内容事件/交互 cue 触发；落态保留当前需要读、比或操作的关系，并把下一焦点接到正确位置。

根据本题材料确定运动距离、速度曲线、时长、淡化范围、对象数量、文字层级与停留；不要照搬来源的主题皮肤、蓝金配色、72 个对象、绝对秒数或每镜同一入场动作。若关系需要同时比较，不要过早收拢或淡去比较对象；空间距离、速度或汇聚方向没有语义/尺度依据时，不把它们画成数据差距或因果。删除/替换会抹掉必须保留的身份、顺序、状态或来源时，不用 crossfade 掩盖，改用显式标注或其他经授权方案。验收时比对起态/中态/落态的对象身份、相对顺序与必要空间关系；顺播确认 cue 与焦点交接同步、文字可读、背景退让未删掉理解所需上下文，且动作没有制造数据或因果暗示。把采用的组织方法、保持的锚点、触发/时钟、运动对象与文字顺序、起止状态和停留回写镜头蓝图，供工程实现继续消费。
关键帧、动作预览和最终渲染要分开说明。静帧检查层级、形状、文字和图底；动态检查遮挡、轮廓、节奏、落定和移动端尺寸。结论指出实际看到的是哪一级媒介，并依据目标尺寸截图、关键帧和正常速度播放中可见的裁切、遮挡或闪烁作判断。


## 面向实际媒介

画幅、屏幕、平台、帧率和字幕区按用户或既有工程规格确定；规格未知时采用工具支持的工作默认值并注明可调整范围，不宣称“平台最优”。安全边距、字幕区、裁切和色彩对比在最终尺寸上实测，确认主体与必要文字在实际播放器中仍可见。
同屏新标签、运动对象和数据过多时，先删无关信息，再考虑拆时序、分屏或停顿；不能为减密度而删掉限制条件、来源或逻辑环节。正常速度播放时，每段新增信息应有可追的出现顺序。
涉及现实人物、地区、文化符号或身份时，使用已核实的指代与语境，不把颜色心理、服饰或画风暗示当作人群事实。最终画面不应凭材料未支持的视觉线索推断身份。
