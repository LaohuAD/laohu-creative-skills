# 视觉设计

本 Reference 负责让信息在画面中有清楚位置、层次和运动理由。内容关系与主张判断见 [内容到运动](meaning-to-motion.md)；具体局部动作/材料方法由二级主文按当前镜头承重对象与操作选择读取。方法来源：本地《018_0930录屏讲解后期》口播动画样例的注意接续与样片检查、上游 t1_3b1b 的几何变换/停留/缓动卡，以及 17_ink 的分层笔触与遮挡修订。这里按通用解释任务改写，保留可迁移动作，未继承来源专属数值、节奏配额或频道身份。


## 输入与返回

本 Reference 接收当前观看单元的主要任务、进入前提、完成依据、前后单元交接对象/状态及需延续的身份/比较参照，并接收语义/事实约束、可用素材、画幅与用户锁定的方法/材料范围（如有）；动作图提供对象、关系和时序，不是预先选定的布局或最终视觉稿。与内容判断共同选择表示法和画面构思；若仍缺少会改变构图的关键信息，先标出未知。逐镜返回可预演的关键画面、视觉层级、文字位置、运动与停留、声画关系，并写回同一镜头蓝图交给局部方法和工具链消费。阅读效果只按实际媒介观察报告，不预称所有观众必然读对。

## 整片构思与视觉资源

在具体分镜布局和模板选择前，方案、制作或获授权修改任务按本轮作用范围确定画面办法：全片任务说明哪些材料承载核心内容、什么关系/感官进程推动变化及因此不采用哪些形式；局部任务只处理本范围的承重过程、限制和必要接续，不强制扩成全片构思。仅审查任务检查已有构思与声明范围并报告差距，不要求新写蓝图。构思不能只把组件名、画风名或比喻写成概念；只有未决选择会显著改变关键画面时才比较不同方向，不固定候选数量。

将构思中的视觉职责编译为实际资源，而不是留在蓝图描述里：为背景、主体、表面、正文、辅助信息和强调确定颜色/字重/材质/层次职责；按具体镜头需要合并或扩展角色，不套固定色板或字体组。真实截图、产品、品牌与实拍材料先核来源、授权、版本和用途，再观察其主色、文字/表面关系与裁切条件；无真实材料时才按表达方向建立可绘制方案。最终值写入实际 `scene.styles`、对象绘制参数或被加载的 draw module 常量，字体进入真实 renderer 的资源加载和测量流程。未被消费者读取的 `look`/设计说明字段不算落实。若参考了具体作品的处理，记录可定位的画面、当时语境、可观察机制与迁移决定，不以品牌名代替证据。

**以动画关系组织画面，不以网页页面组织内容。** 先从主题和观看任务确认要追踪的对象、前中后态、空间关系与焦点，再定运动的时间、路径/曲线和交接；随后深化色彩、字体、背景、材质与光影来加强注意和读法。真实字形度量与字框占位、用户锁定的品牌/外观/材料、承担身份/分类/数据意义的色彩编码，以及原生机制中直接承担运动的材料（如纸墨扩散或像素步进）仍须在早期结构设计中考虑；若视觉深化改变空间、阅读或动作逻辑，就回到构图迭代。禁止先用网页页眉、信息栏、卡片槽位、导航/进度条或页脚搭成整片母版，再按页替换标题/卡片来冒充内容推进。该禁令不排除 HTML/CSS/Canvas 作为渲染工具，也不排除真实 UI 演示或作为实际对象/比较单位的几何卡片；是否使用取决于本段真实观看任务。照片、视频、真人、文本与几何都可成为承重画面对象，不要求把它们压成基础形状。

## 按对象职责选择画面载体

为每个承重对象判断观众需要从它看见什么，再选择能真实承担该职责的材料：可计算的形状、边界、数量或精确位置适合代码几何/矢量；需要连续编辑、缩放或复用的标记与字图可用矢量；需要复杂有机形态、特定质感或较完整人物造型时，可用插画或在获准、工具可行且身份/风格可控时生成图；需要保留真实外观、现场、人物或资料语境时，使用用户提供或来源与授权已核实的照片/视频。一个镜头可按对象或图层混用这些材料，不能由题材词直接触发单一工具，也不把“代码可画”当成代码画面更适合的证明。

先评估要表达的细节、身份连续性、是否承担事实/证据职责、可编辑程度、背景移除/裁切需求、屏幕尺寸与后续镜头是否复用；然后写明选用载体、它显示什么、哪些信息不会由它证明，以及实际文件和必要层级交给谁消费。若材料缺失，只有在该镜头允许示意时才以明确的示意形替代；不可把合成/生成图伪装成真实证据。来源、派生、裁切锚点、透明层与运行时加载由 [工具链 Reference](toolchain-render-and-check.md) 记录；需要从照片/视频裁切、遮罩、拼接或保留证据语境时，读取 [证据材料揭示](../skills/laohu-motion-collage/SKILL.md)。

## 先搭一个有焦点的画面世界

视觉设计不是给概念摆图标，也不是把已经列好的语义动作塞进默认版面。先比较前后段在对象身份/状态、观察尺度、证据或比较职责、感官进程上的差异，再决定同一材料内转化重组、新载体交接，或为阅读/比较保持并置；这些是可选的构思方向，不是每拍变化配额。若完整成片制作需要新组织整片或段落画面，或获授权修改确需在授权作用范围内新组织整片或段落画面，先依据所选构思，用实际 renderer 和选定材料绘制少量足以显示关键前态、转场与后态的内部预演，在目标尺寸和正常速度下自审；正常完整制作再按[工具链 Reference](toolchain-render-and-check.md)的对外样片门交付并等待用户明确确认，之后才扩展为全量渲染。检查每个主要构图变化怎样来自内容对象/关系的前后态；持续出现的标题、网格、进度条或容器须承担章节定位、比较参照、读图引导等具体职责，否则应随内容重组或退场。预演数量与时值按仍未确定的画面取舍决定，不设统一帧数/秒数，也不要求每拍换色换版。概念字段、分镜文字或作者自评不能替代实际绘制预演；关键态预演是内部迭代和自审，不需用户批准；它不能替代正常完整制作的对外风格/节奏样片及用户确认。已验证且对本次内容与文字布局均无构图疑问的原生模板，或不改变布局的简单局部操作，不机械追加此内部预演，但这不自动免除待确认方向的对外样片门槛。把观察到的修正带回镜头蓝图。只有当一个具体不确定点会改变选择时，才比较邻近方案；局部方法也要放回全画幅和前后镜头修正。

**把整张画布当成持续重组的场景。** 逐个语义拍点检查标题、对象、背景、尺度、构图、颜色、字体、光影、焦点与运动如何互相作用。标题可以在段落入口短暂建立主题，之后离场、移入对象、缩成锚点，或按理解需要保留；不默认一条顶部标题和一块中央信息栏贯穿全片。当前内容变化时，允许主体从全画面转到细节、关系图转成照片/空间、背景与文字重新配合、对象移位或尺度改变、色彩层级交接。变动多少和哪些层变动，取决于语义、观看任务和画面需要，不规定每拍必须换风格、颜色或构图。若内容关系还在阅读/比较，维持原构图或局部变化可能更清楚；若新信息改变对象、空间、时间或焦点，就让全画面在有理由的范围内重组。每次选择都要在起态、过渡、落态中看得见并写回蓝图。

产品/发布任务先核用户提供且可用的真实 UI、品牌材料、数据和使用场景，再决定画面气质；知识讲解要让实证材料与示意清楚可辨。先挑最难承重镜头，在目标尺寸下检查主体/证据、字组、背景、尺度参照、光影、留白与焦点如何共同构成全幅，再把已验证的约束带入相邻观看单元。剪辑路线按已定观看任务选择：解释/信息任务依对象、空间或色块身份承接，或以有意义的切点/并置组织比较、转折和省略；体验/情绪任务也可沿形式、材质或节奏进程连续展开、切换或变奏。混合路线在连续主干上切到需要展开的细节、证据、结果或体验转折。全片能量、密度与安静段随信息承重或体验进程安排；应延续的是任务所需的对象身份、语义参照或感觉线索，不是同一色板或构图。

- **建立视觉世界。** 依据题材和内容选择抽象舞台、板面、桌面、纸张、屏幕、空间场景或无背景留白。背景要承担语境、深度、情绪或衬托中的具体作用；选浅色、深色、纯色、渐层、网格、纸纹或颗粒都要看主体轮廓、目标尺寸和材料真实性。网格不是默认“科技感”，纯黑也不是默认“高级”。
- **安排视觉重量。** 通过位置、面积、明暗/色彩对比、边缘清晰度、遮挡和运动量决定主焦点。一个镜头可以有多个同时比较的对象，但应让共用基线、目标对象或结论拥有可辨的视线入口；不需要的信息退到背景或暂不出现。焦点变化要能在关键帧上看出发生前、转移中和落定后。
- **让图底、文字与对象共同建立配色。** 根据内容身份、前后景、资料语境、情绪目标、画面材料与阅读职责，决定背景、主体、文字、关系线、数据和强调状态怎样形成色彩关系。色彩可以丰富、对比强或克制，都由这组对象与背景的实际关系决定；不预设统一色板，也不因参考的作品用了某组颜色就照搬。比较对象要有清楚且公平的区分，颜色不能代替单位、尺度、来源或事实标签。相同对象跨拍需要身份连续时保留可辨编码；不同镜头更换背景/主色时重新检查字与图形关系，不要求颜色恒定来制造虚假连续。
- **让光影服务画面关系与审美。** 阴影可区分前后层、托起漂浮物、显示遮挡；高光可指出当前受力面或被选择的部件；柔和渐层可把焦点从背景中分离。光影也可在不误导对象、层级、材质或事实的前提下支持氛围与画面气质，不要求每项形式都增加新事实。若它压过主次、遮挡文字、伪造材料/关系或变成无意的视觉噪声，再删减或调整；不能仅因其装饰性就一概删除。纸、墨、拼贴等材质可以自然覆盖主体与背景，但应留出足够对比保护文字和关系。
- **设计可读的起中落态。** 对动作图中的承重拍，先确定本拍的承重对象及理解它所需的参照；仅当本拍需要比较时，再定义比较单位及其共同参照范围。随后按目标画幅核对承重对象与必要标签在实际呈现尺寸下的可辨边界，安排变化对象及其前后态可读所需的画面空间。变化对象获得阅读空间后，再决定前一对象、标题、容器和其他全幅参照继续、缩小或弱化、退出、合并或重排；比较单位保持稳定，只约束其中对象与基线的关系，不自动冻结整幅。标题或容器留驻时，须在画面序列中确实承担阅读入口、对象身份、比较基准、操作反馈或必要上下文；单写保留理由不算完成。起态让人识别对象和原关系，过程中让关键变化连得上，落态给结果和必要标签留出可读位置。若块面身份、图层遮挡或整体到局部的尺度聚焦实际承重，再由主文选择相应局部方法明确对象/图层锚点与起中落，并把结果交回全幅整合；不因维持局部比较而强加运镜或整幅重排。对比、缩放、揭示、线条生长、结构拆分、相机移动或材料变化都可以成为主要动作；一个镜头也可保持同一构图，让观众观察关系或完成阅读，不要求每拍新增动作、运镜或焦点变化。阅读状态允许停住，运动不需要每层持续。
- **由整体进入局部，再返回关系。** 若解释依赖细节，先建立它属于哪个整体，再移近并指出细部，最后按需要返回整体以看出结果。移动相机时保持参考锚点或给明确过渡；为注意力或图解而推近不需要实测尺寸，但要保持身份锚点并避免标成物理比例；只有画面声称真实尺寸、距离或数值尺度时才需对应依据。

这些规则可在不同范围各自成立：例如背景层使用纸墨材质，数据主体保留扁平色块，选中对象上的局部像素精灵使用硬边采样，标注和箭头仍用平滑矢量。把每个选择落到全片/段落/镜头/图层/对象的范围里。组合前，明确背景、相机、文字布局、对象变换、裁切、透明度与强调层各由哪个已有源、父容器或对象控制，只登记本镜实际涉及的属性。完整来源镜头保留内部控制；局部组件服从其真实父容器、坐标和裁切条件。若两个控制同时作用于同一对象、同一属性和同一时段，先判断能否按任务拆到不同对象、图层或阶段；不能拆时选择一个控制源，不靠加载顺序或叠加强度决定。采用 Video Shotcraft Stage 时，只在该 segment 的 Stage 与 sibling 构成中按[接入规则](video-shotcraft-integration.md)一次建立背景与装饰层；当前 Film `/2` 不提供跨 segment 的持久背景层，需跨段连续时须选择真实可承载它的 renderer，不能假设 Segment Group 会保留 Stage。独立原生镜头不为统一画风而擅自拆掉或复制它的背景。

## 画面组织

**安排注意顺序与画面主次。** 先按语义动作确定观众应该看见的对象、关系或结果，再安排必要标签和上下文的曝光次序。正向选择形状与边缘、字号和字重、颜色角色、光影、留白、空间层级及运动/停留节奏，让它们共同建立清楚、有吸引力的视觉主次；颜色、光影与形状可以承担审美和氛围，不必每项都新增事实。用位置、对比和运动强弱让辅助层支持主信息。目标画幅静帧与正常速度片段都应能看出阅读入口、对象焦点和落点，文字和主体未被裁切。

**把强调效果绑到承重对象、语义触发和空间锚点。** 先确定本拍要读懂的主要对象或关系、引发变化的内容事件，以及继续理解所需的上下文，再共同安排主体、文字、背景与旧信息的强弱变化。为当前内容取得足够的面积、边界清晰度和阅读位置，并让相关高亮、标注或光影跟随实际对象/关系锚点；旧内容按后续用途保留、降为上下文、重组或退出。尺度、位置、色彩、字形力度、局部底板、遮挡、光影和效果按实际冲突与表达目标选择，不作为每次强调的固定组合。需要隔离复杂背景时，只处理会干扰阅读的区域，并检查最终合成中的前景字。入场、强调、阅读、交接或退场按本拍职责取舍、组合或重叠，不预设每段都经过四个阶段；比较或总结需要同时可见的信息可以保留共同重心。波纹、光晕、纹理/粒子或残影既可表达动作关系，也可有意承担审美、节奏、材质或情绪作用；若其形态容易被读成扩散、触达、能量、持续实体或因果，则核对这种暗示是否符合本镜语义与事实依据。装饰性处理也须有强弱和边界，不能掩盖对象关系、制造未支持的物理因果或分裂焦点。效果服务当前焦点而非每次变化的配额；眼动不需连续被移动画面驱赶，声音也只在本镜有可听角色时按共享事件时钟安排。真实执行能力、图层顺序与片尾帧到工具链核验。

**让承重关系成为画面对象和操作。** 从动作图认出参与对象、身份、关系方向、前后态与结果，再选择真正显示关系变化的空间、形状、路径、材料或符号操作；不把句子清单换成通用输入—机器—输出槽位。关系图承重时由主文读取 [关系图构建](../skills/laohu-motion-relations/SKILL.md)，抽象逻辑也可使用符号替换、归属改变或其他合适表达，不规定圆圈、卡片、集合图或固定布局。信息面板、标题和容器只有在实际承担分组、比较、阅读、上下文或操作职责时才保留。全画幅构图决定这些对象如何进入、聚焦、转接和退出；关系类型、端点、方向、对象生命周期及真实绘制方法由适用模块与工具链细化。图形不得声称超过证据的方向、数值、物理尺度或因果强度。

**文字作为整幅构图中的画面对象。** 每段文字是什么、是否锁定、为谁服务以及能否逐批显现，统一由 [字体、字幕与可读性](typography-and-legibility.md) 判定并写入镜头蓝图；视觉设计按其语义、真实目标与共同组外框安排文字和图形、背景及阅读路径。可读性冲突按该 Reference 识别的实际原因处理，再由本 Reference 组织对应的背景、对象、图底关系和全幅层级；不重算字框或另造算法，也不在此另设字数、标点、字号、底板或对比配方。

若字词或字形本身是画面主体，分组、字层轮廓/遮罩、空间变换、曝光停留或退场重组构成本镜主要操作，再由主文读取 [文字主体操作](../skills/laohu-motion-typography/SKILL.md)。该方法只约束文字对象和局部生命周期；普通标题/标签不因使用字体、路径或图层而触发，也不能代替可读性 Reference 的真实字体测量与有效阅读窗检查。

**先定阅读路径，再移动画面。** 固定画布、资料桌面、空间穿行、分屏和局部聚焦需要不同的构图逻辑。先用关键帧确定主体、条件和留白，再决定镜头或画布是否移动；运动的起点、经过位置和落点都要留在工程可检查的帧上，必要信息不得在移动中被裁掉。

**把对象的可见窗口与插值终点分开设计。** 事件到达目标坐标、对象状态或透明度端点，不代表它在到达前或之后仍可见。按镜头任务确定对象何时进入、何时需要持续识别、何时由下一对象接手；用真实 z-order、opacity、clip/mask 或绘制分支实现该窗口。连续观看依赖旧对象时检查其真实可见几何和遮挡关系；其职责完成后，明确将旧对象移除或转换为新的参照/状态，避免只因 renderer 保留旧图层而拖过转场。明确切镜可以切断连续性，不要求每个对象全程驻留。


## 运动与停留

**先按本镜任务选运动方法。** 解释任务中，镜头若表现对象出现、累积、移动、分解、比较、触发或阻塞，就让运动承担这个关系/状态变化并维持可追踪的注意顺序。体验、情绪、氛围或风格任务中，若用户选定的观看目标由材质、形态、重心、速度、重复或变奏承载，连续运动本身可以构成体验，不必每一拍新增事实；把这些变化组织成有方向的进程和可落定的位置，不用无目的微动填时。界面动效把动作接到真实触发、系统状态与反馈。目标可以混合；环境微动只有不抢焦点且确实承担所选职责时才保留。蓝图应指出运动在服务什么；持续动或停住都不是默认答案。

**用 staging 接续注意。** 先写本观看单元的主要任务、进入前提与完成依据，再设计承载它的关键构图。稳定比较框架只在确有比较关系时保留到该比较任务完成；转向内部细节、新对象或新证据时，重新判断观看范围，先为新任务安排可读空间，再决定旧内容作为身份/比较参照保留、缩小或弱化、重组还是退出。先设计交接前后的关键构图，再选入场、移动、遮挡、切换或并置等能承载本次交接的操作。若本拍确需辅助变化，逐层确定辅助形状、速度线、光晕、下划线或第二组文字何时进入、各自的曲线/锚点及其控制属性；主体、辅助层和文字可按职责错时，必要时也可同时动作。将主体完成任务的时点与辅助效果尾部区分：必要内容和对象身份已建立、观众能继续追踪关系时可交接主焦点；辅助层若仍支撑理解且不争焦点，可短暂交叠、继续收束再退去。为比较或职责总结并列多个对象是有效分支。下一对象可先入场或先显露局部，随后接过主焦点；但依赖前一结果的动作必须等该结果实际抵达。决定主体保留、重组为下一状态还是交给下一对象，并保持足以识别连续对象的身份/语义锚点。不要求整幅同时动作，也不强迫一次只有一个对象动作或为辅助效果延长主要任务。

**按事件相位、动作职责与实际帧间距设计节奏。** 逐项标明动作是在引导观众找到对象、展开过程行程、让结果落定，还是留出阅读/比较时间，再据此选时值、曲线、速度、运动范围或静止：引导可以短促，行程遵守真实过程，落定无需默认回弹，阅读段通常静止或只保留不妨碍理解的体验性运动。先确定本段主重音、主揭示或结果落点；以它为中心向前安排入场与必要准备，向后安排稳定、必要的阅读/关系停留、焦点交接和退出。进入阶段可很短，理解需要的落点必须看得清。用户要求利落、快速或有节奏时，把主要变化放在前段迅速建立，再留出足够停留理解；不要把整片所有动作都加速，也不以每拍必须变化代替节奏。区分 `timing`（事件/相位何时发生、停留和交接多久）与 `spacing`（相邻帧如何分配位移及速度感）；速度由位移幅度、持续时值和目标 fps 下真实帧间距共同决定，曲线名称本身不能证明利落或柔和。位置、尺度、透明度、遮罩与模糊是独立通道，可按职责错时、重叠或共用阶段，逐项确认其真实属性与消费位置。真实匀速过程保持匀速；数据读数、比例或定量变化服从实际模型与标尺；提示、聚焦、起步、路径运行和落定依动作选择曲线，不能把同一缓动或持续运动套到所有动作/图层上。anticipation、overshoot 或 squash 可用于适合语气的文字、图形或 UI 强调，但不可改变定量几何、对象身份、关系方向或锁定端点。事件时值与曲线须写入真实被消费的镜头/属性映射；本作蓝图填写本作的时值与节拍，并按用户锁定的总长或节拍安排；不把单个镜头的秒数、BPM 或动作数量写成跨任务通用配方。逐帧核对真实位移、速度、锚点、终态和有效阅读窗。

**局部动作选择交给对应方法。** 同一对象/部件的轮廓对应与连续形变、块面遮挡/聚焦、路径构建、像素步进、笔墨扩散和证据材料揭示分别由主文读取的内部方法给出操作与接口；本 Reference 负责将其放回全画幅，检查当前焦点、前后对象交接和起中落构图，不重复定义绘制算法。方法选择看本镜是否确实需要该动作；仅仅使用 layer 或 path 等基础字段并不构成调用理由。

**锁定随机纹理的身份。** 程序噪声、笔触采样、粒子和生成帧可能逐帧漂移。需要重复渲染稳定时固定随机种子；纹理应附着对象时使用材质或对象坐标，并检查关键中间帧、重复渲染和循环边界。成片不应无故闪烁、滑移，粒子的出现和消失也要有可读理由。

**按观看任务决定何时继续或停住。** 对解释与阅读任务，新标签、关系图、数据或结论刚出现时，保留足够辨认、比较和思考的时间；当下一关系、状态或注意焦点确实要变化时再恢复动作，否则停在清楚的落点。对体验/情绪/氛围/风格任务，如果连续运动本身承担已选的感官职责，可以在没有新事实时继续，但应能指出形态、重心、速度或重复/变奏怎样推进体验，而不是空转。对界面任务，动作以交互结果或系统状态的呈现为边界。静止也可用于阅读、重量、期待或回味。检查落定状态是否有连续可查看的帧、是否被后续元素遮挡，以及下一事件是否等到相应观看任务完成后才开始。

**让镜头运动揭示具体对象。** 推拉摇移应有可指出的目标：揭示、换空间、改变尺度或跟随对象。镜头数据写明起止构图及新增关系；文字需要阅读时保持稳定或避开运动路径。没有实测依据时可为注意力或图解而光学推近/突出局部，但保持对象身份锚点连续且不标成物理比例；只有画面声称真实尺寸、距离或数值尺度时才需要对应测量依据。首尾帧应能核对运动目的，且文字不会被裁切带走。

**用转场表达段落关系。** 同一对象或空间的连续变化可匹配运动，对照内容可并置或短停后切换，无关新题则干净切开。连续性要在前态、过渡中态和后态检查真实对象状态、空间关系、方向、焦点及必要的声桥；同一 ID 或 renderer 不能证明实际画面连续。语义转折可以有意切开，不要求全片强制 morph。选法取决于内容关系，不能让转场模糊段落边界或带入未证事实；单帧检查前后对象仍应可辨。

**按观看任务调速度。** 解释任务中的轻提示、短强调、长路径和真实过程需要不同的时值；慢动作应展开本镜需要看清的关系/状态，或为必要阅读留出时间，不要拖慢无关路径。体验、情绪、氛围或风格任务可以让较慢的连续运动推进已选的材质、形态、重心或变奏，不以新增事实为条件，但须对应明确的感官目标；界面动作则按真实触发与反馈时机安排。快动作按目标帧率检查。没有统一镜头秒数或快动作比例，最终应逐帧确认关键相位、端点和数据准确，且无非预期跳帧。


## 声音与多层信息

声音是另一条按事件与职责组织的时间层，不是自动附加给所有画面的配件。需要安排或检验旁白、音乐、音效、环境声、用户指定原轨或静音时，按 [音乐、音效与静音设计](sound-design.md) 设计职责、授权来源和事件 cue，再在真正输出的音频文件中对齐。音效可标记有意义的动作、触碰或落定，配乐可支持段落节奏，静默也能保留空间；并非每个视觉变化都需要声响。runner 只输出无声画面时，需用明确的作品级音频步骤混音封装，不能仅写一条音频计划就称声音已入片。


## 画风与内容语法分开

先依据内容选因果、比较、步骤、空间、数据或体验表达，再逐对象/图层分配表现方法。主文按承重对象和实际操作读取内部方法模块；题材或名词本身不触发，用户明确锁定的视觉/材料范围则必须保留。模块返回的做法只约束指定的对象、图层或镜头，其余画面继续跨方法协调；一个对象跨方法呈现时，身份、锚点、空间和图层关系仍连续。拿掉无关装饰后，内容关系仍应成立。

**画面固定只限所选作用范围。** 先按观看单元对象的前后态与承重变化判断复用尺度：只需改变局部目标/图层时，优先选能真实作用于该目标的局部 effect；只有完整来源构图或整段机制确实承担本段任务时，才选场景模板。局部 effect 只固定已登记目标、属性和时段，不锁定背景、其他对象或全片画风；场景模板则可保留所选段落中的原生构图、层级、运动、标题/图表位置、颜色和时间安排，只改 `show` 与源码确实开放且本段需要变化的字段。原生布局若适配本段比较、阅读、关系解释或体验职责，可以完整保留；若不适配，就换复用尺度或沿普通 Motion 路径设计，不把模板的固定布局强加给本段或邻段。用户提供外部动画/样片作参考但未匹配本地可调用项时，核查连续画面与实际源码能证明的范围：沿镜头观察标题如何进入/退出，主体及背景如何变化，观察尺度和构图如何重组，字形/字号/文字色、图底色、光影和运动怎样一起配合内容推进；将可迁移的整体关系记入蓝图，不只抽取一组配色。可运行的授权来源命中时按原生接口复用；不能把预览或目录项说成可运行模板，也不能因方法参考而推定资产已获授权。若用户明确限定只复用参考且仍无可运行匹配项，按模板库流程接通许可允许的原源或报告具体缺口，不自动切换原创；普通开放请求无此限制时，没有合适模板就按本段内容决定布局、颜色、字体、材料与节奏，无参考时也可直接创作。

## 跨方法构图与局部动作接合

本 Reference 负责将已选的局部方法放进完整画幅：安排视觉世界、主次、标题/对象生命周期、背景与色彩角色、光影、留白、节奏和观看路径。它不重复内部模块的绘制算法；主文按对象与动作调用 [关系图构建](../skills/laohu-motion-relations/SKILL.md)、[连续形变](../skills/laohu-motion-geometric/SKILL.md)、[块面分层与尺度聚焦](../skills/laohu-motion-flat/SKILL.md)、[路径书写与擦改](../skills/laohu-motion-whiteboard/SKILL.md)、[离散网格与姿态步进](../skills/laohu-motion-pixel/SKILL.md)、[笔墨层与受限扩散](../skills/laohu-motion-shuimo/SKILL.md) 或 [证据材料揭示](../skills/laohu-motion-collage/SKILL.md)。按需采用；同一镜头可在不同对象或图层组合，用户锁定的方法只约束其明确作用范围。读取模块不自动授权扩大材料范围或把局部方法扩成全片皮肤。

局部模块返回本对象/图层的操作、实际约束、锚点和未解冲突，由主线与本 Reference 组合进整幅画面；模块不递归调用同级模块，也不规定固定字体、配色、底板、动势或整片皮肤。每次转向新对象或状态时，主线单独决定上一对象是作为身份/比较参照继续、退让/重组，还是退出；保留不是默认。

catalog 中的局部 effect 与整段模板分开选择：仅按当前操作、具名目标、实际属性和共享 phase 判断能否调用；局部实例只约束它登记的对象/属性/时段，不固定背景或全片画风。候选的精确用途标签、字段和静态目标边界按 [上游模板库](template-library.md) 核对，再由全画幅构图决定它是否帮助观众看到本段重点。

收到模块返回后，先在画幅中确认对象和关系的起态位置、动作中的焦点与空间接续、落态阅读/比较位置，再决定标题、背景和其他对象是否持续、转化、退让或退出。比较任务要让比较对象在所需窗口同时可辨；需要局部聚焦时才移近，且保留能回到整体的空间锚点；集合增删/重排要保持必要身份与顺序。无须每拍改变背景、色彩、动作或镜头；稳定构图只有在画面实际持续承担阅读、比较或关系参照时才保留。具体模块操作见其内部文件，时间、对象、实际绘制映射与预演由 [工具链 Reference](toolchain-render-and-check.md) 检查。

当相机运动时，按当前工程的真实对象空间处理标题/标签：需要持续留在画幅的文字与需跟随对象的标签分别绑定其实际 screen/world 空间或投影方式；在平移、缩放和 seek 后核对锚点。若工程接口没有对应字段，使用已注册的具名自定义绘制或该工具真实支持的等价实现，不虚构 renderer 字段。

**跨方法审美验收。** 对照静帧和正常速度序列，检查形状/边缘、字号与层级、颜色角色、光影、留白及运动/停留是否共同形成有方向的主次和可辨的画面气质。它们可增强氛围，不必都新增事实；多种材质可在同一画面共存，只要对象身份、锚点、阅读路径和视觉主次连贯。把方法范围、保留/退场/重组选择、焦点交接、触发/时钟、文字顺序、起中落状态与停留写回镜头蓝图；关键帧、动作预览和最终渲染分开说明，不以规则调用或字段存在宣称画面质量通过。


## 面向实际媒介

画幅、屏幕、平台、帧率和字幕区按用户或既有工程规格确定；规格未知时采用工具支持的工作默认值并注明可调整范围，不宣称“平台最优”。安全边距、字幕区、裁切和色彩对比在最终尺寸上实测，确认主体与必要文字在实际播放器中仍可见。
同屏新标签、运动对象和数据过多时，先删无关信息，再考虑拆时序、分屏或停顿；不能为减密度而删掉限制条件、来源或逻辑环节。正常速度播放时，每段新增信息应有可追的出现顺序。
涉及现实人物、地区、文化符号或身份时，使用已核实的指代与语境，不把颜色心理、服饰或画风暗示当作人群事实。最终画面不应凭材料未支持的视觉线索推断身份。
