# 视觉设计

画面焦点、跨段比较、空间和运动关系需要进一步裁决时读取本 Reference，将相关判断带回[动画视觉设计](../../laohu-analysis/references/motion-design.md)。旧 Motion、Film 与 Remotion 的实现细节按所用 consumer 查对应章节。它负责让信息在画面中有清楚位置、层次和运动理由。内容关系与主张判断见 [内容到运动](meaning-to-motion.md)；旧工程的局部动作/材料接口按当前 renderer 需要查[旧 Motion 方法兼容档案](legacy/legacy-motion-methods.md)。方法来源：本地《018_0930录屏讲解后期》口播动画样例的注意接续与样片检查、上游 t1_3b1b 的几何变换/停留/缓动卡，以及 17_ink 的分层笔触与遮挡修订。这里按通用解释任务改写，保留可迁移动作，未继承来源专属数值、节奏配额或频道身份。


## 输入与返回

本 Reference 接收当前观看单元的主要任务、进入前提、完成依据、前后单元交接对象/状态及需延续的身份/比较参照，并接收语义/事实约束、可用素材、画幅与用户锁定的方法/材料范围（如有）；动作图提供对象、关系和时序，不是预先选定的布局或最终视觉稿。与内容判断共同选择表示法和画面构思；若仍缺少会改变构图的关键信息，先标出未知。逐镜返回可预演的关键画面、视觉层级、文字位置、运动与停留、声画关系，并写回同一镜头蓝图交给局部方法和工具链消费。阅读效果只按实际媒介观察报告，不预称所有观众必然读对。

## 整片构思与视觉资源

在具体分镜布局、模板选择和工程代码前，方案、制作或获授权修改任务按本轮作用范围确定画面办法：全片/段落任务说明哪些材料承载核心内容、什么关系或感官进程推动变化，以及相关对象、背景语境、文字层级和标题如何持续、改变或退出；只写本片确实涉及的判断。把能指导后续构图与接续的构思记在本片现有蓝图，作为候选和关键态预演的依据，不另建文件或 schema。局部任务只处理本范围的承重过程、限制和必要接续，不强制扩成全片构思。仅审查任务检查已有构思与声明范围并报告差距，不要求新写蓝图。构思不能只把组件名、画风名或比喻写成概念。

将构思中的视觉职责编译为实际资源，而不是留在蓝图描述里：为背景、主体、表面、正文、辅助信息和强调确定颜色/字重/材质/层次职责，并与动作相位、音乐/SFX 声音角色一起协调；按具体镜头需要合并或扩展角色，不套固定色板、字体组或全片布局图。蓝色、深色底、2D/3D、极简或高密度都只是可选表达条件，不作为默认审美门槛。真实截图、产品、品牌与实拍材料先核来源、授权、版本和用途，再观察其主色、文字/表面关系与裁切条件；无真实材料时先判断表达是否确实需要新增素材，再按职责取得或制作内容资产。最终值写入实际 `scene.styles`、对象绘制参数或被加载的 draw module 常量，字体进入真实 renderer 的资源加载和测量流程。未被消费者读取的 `look`/设计说明字段不算落实。若参考了具体作品的处理，记录可定位的画面、当时语境、可观察机制与迁移决定，不以品牌名代替证据。

**以动画关系组织画面，不以网页页面组织内容。** 先从主题和观看任务确认要追踪的对象、前中后态、空间关系与焦点，再定运动的时间、路径/曲线和交接；随后深化色彩、字体、背景、材质与光影来加强注意和读法。真实字形度量与字框占位、用户锁定的品牌/外观/材料、承担身份/分类/数据意义的色彩编码，以及原生机制中直接承担运动的材料（如纸墨扩散或像素步进）仍须在早期结构设计中考虑；若视觉深化改变空间、阅读或动作逻辑，就回到构图迭代。禁止先用网页页眉、信息栏、卡片槽位、导航/进度条或页脚搭成整片母版，再按页替换标题/卡片来冒充内容推进；也不把来自不同原生镜头的画面统一覆盖成暗底、小字侧栏式皮肤。该禁令不排除 HTML/CSS/Canvas 作为渲染工具，也不排除真实 UI 演示或作为实际对象/比较单位的几何卡片；是否使用取决于本段真实观看任务。照片、视频、真人、文本与几何都可成为承重画面对象，不要求把它们压成基础形状。

## 保留原实现怎样形成画面

成熟效果的保真同时涉及计算与表现，不只保留一个函数名。先读其布局/绘制函数和必要共用件，再沿原接口替换本段内容：源用世界坐标和相机时，主体位置不能每帧按当前相机反算到固定屏幕点；只有固定标注才用 screen space。源用设计画幅、单位比例或归一化帧时，保留其 DesignStage/单位和 frame-to-progress 公式，不把数值直接当输出像素或秒。Shotcraft 的 DesignStage 还区分 raster zoom 与 transform scale，字形光栅化条件也属于保真范围。

曲线、标题字形与占位、字距阶梯、主题中的图底角色、表面/阴影/高光、遮罩及速度模糊，在成熟实现中可能共同形成一个动作组。适用时连同实际 provider 与依赖一起调用，不能只取颜色或 easing 数值后用基础图形重造。完整镜头适用时，保留原生构图、颜色角色、字体层级、设计画幅/DesignStage、raster 与 transform scale 关系、材质和结束状态；只替换源接口真正开放的本片内容。未选中且不承担本段作用的来源部分不随整文件搬入；局部更改由本地接线承接，原始许可和来源保留。若任务所需的本片内容字段未开放而完整机制仍适配本观看单元，允许在本片授权工程内增加最小局部 adapter/内容映射，将本片变量交给原实现并保留其布局、曲线、材质、时间与落态；adapter 不另写近似 renderer 或改写成熟机制，也不修改共享库。记录实际 consumer、依赖、许可与属性 owner；确需改变共享机制/接口时另按维护授权更新真实消费者。技术故障先排除；候选不适配或授权/依赖阻断时才暂停受影响部分。用户要求从底层原创视觉机制时才新建绘制方法。

自定义接线须在调用前后恢复 Canvas/图层状态，明确相机、透明度和裁切的唯一 owner；片段结束时检查主体自身的生命周期，不能只退去覆盖层而让旧场景重新露出。比较源基线、内容适配后的起中落与实际最后编码帧，定位差别来自输入变化、必要适配还是实现丢失；不能拿同一 renderer、零碰撞或截图清单替代。

## 按对象职责选择画面载体

**内容关系决定观看需要，工具的强项决定它适合承担的范围。** 抽象文字须转为观众可看见的对象、空间、过程或关系，再以构图、形态、色彩、材质、光影与运动形成具体画面；文字本身也可作为画面主体，装饰、质感和情绪同样参与表达。选材时同时考虑当前观看任务与已确认的审美力度：精确关系、数量或可变形轮廓可由平面图解承担；体积、内部结构、观察侧或空间运动影响理解和感受时，查可接通的 3D/透视镜头；真实外观、操作和现场感可由实拍、录屏、照片或资料画面承担；逐步构建、修改推理可由白板/手写机制承担。按本段需要选取并组合，不要求每段集齐这些形式。

若当前 toolkit 只提供排版、几何图解和缓动，它可以承担适配的局部，却不能因此成为所有镜头的默认表现上限。沿已有 catalog 和精确实现索引检查其他成熟镜头、动作组与素材路径，将能兑现本段体积、材质、密度或视觉力度的实际实现纳入选择；记录选用理由及真实接口后再落定布局。目录收录、方法名或“支持多风格”声明不足以证明候选已能生产；发现本地接线缺口时指出具体缺少的 consumer/素材/依赖，按既有授权继续可独立部分或交维护接通，不悄悄把原目标降成平面图标加文字，也不临时重写底层。

先写清观众必须从每个承重对象看见的形状、边界、数量、材料细节、动作或事实证据，再选择能真实承担该职责的材料：可计算的形状、边界、数量或精确位置适合代码几何/矢量；需要连续编辑、缩放或复用的标记与字图可用矢量；需要复杂有机形态、特定质感或较完整人物造型时，按本轮已授权的素材范围和负责资产入口使用插画、现有素材或生成图；需要保留真实外观、现场、人物或资料语境时，使用用户提供或来源与授权已核实的照片/视频。图标可以标示类别或操作；当观众需要辨认具体材料、结构、表面或现场时，不能以通用图标替代实际授权材料或明确标为示意的具体表现，也不能让生成图冒充证据。图像生成只准备本片内容资产，不授权从摘要重写成熟的绘制、排版、镜头、曲线或材质机制；不额外引入费用、服务或未授权素材。一个镜头可按对象或图层混用这些材料，不能由题材词直接触发单一工具，也不把“代码可画”当成代码画面更适合的证明。

先评估要表达的细节、身份连续性、是否承担事实/证据职责、可编辑程度、背景移除/裁切需求、屏幕尺寸与后续镜头是否复用；然后写明选用载体、它显示什么、证据能支持到什么程度，以及实际文件和必要层级交给谁消费。缺少非证据内容素材时，在 runtime 与素材授权允许的范围内，沿负责入口取得来源已核的实际素材，或制作本片插画/示意资产；保留来源、许可、派生与裁切锚点，再用所选 renderer 的真实输入加载素材并渲染关键态，确认内容确实出现且由预期 consumer 使用。若素材承担证据职责，不能用生成图或重绘件替代缺失原件，也不能让它暗示真实性；必要原件缺失时暂停依赖它的主张。用当前页面或已采用的成熟实现把展示和运动实际绘制出来。成熟镜头、动作组或源函数适合本观看单元时，用其实际接口或最小适配层接入本片内容，保留决定效果的原实现。只有没有适用且获准机制、必要内容又无法安全接入时，才暂停受影响镜头；技术故障先排除。新 Showreel 的来源、派生、裁切锚点、透明层和运行时加载随当前片段交接。需要在旧 renderer 中裁切、遮罩或拼接时，按实际消费接口核对材料和证据语境。[制作接续](production-collaboration.md#时间片段与工作台交接) · [旧工程材料方法](legacy/legacy-motion-methods.md#laohu-motion-collage)

## 让审美方向变成可检索、可消费的选择

新片没有指定画风时，方向仍是开放的：先从内容、目标观众、发布用途、承重对象和现有素材判断本片需要哪些材料、情绪力度、信息密度和镜头语言，再从真实资源目录筛出相关且有实际 consumer 的方向。可以评估明亮轻快、饱和张扬、纸面温暖、漫画夸张、像素跳格、立体纵深、实拍或拼贴等适用方向，不预设深色科技平面图、冷静理性或几何图解为默认胜者，也不要求固定候选数量或固定秒数的风格样片。只有选择确会改变关键画面时才做并置比较；用户锁定的局部风格在仍适用时直接延续，只有新用途、材料或观看任务让它不再合适时才重开。每个实际候选都要说明它如何承担本段任务、有哪些真实 renderer/字段/素材可消费，并保留其原生画面细节。

这些方向先沿模板库的全资源路径寻找：以 `overview` 看类型和状态，用 `browse` 展开本片相关候选，以 `describe` 核对具体记录；style prompt 另用 `styles fulltext --query <ID>` 读原文，再以生产候选的真实 `show` 确认 consumer。`discover` 只是可补充使用的词面检索，命中只表示目录文字相关。可执行的来源函数按其真实输入与 consumer 保留原绘制机制；风格提示只作参考，必须由有真实暴露字段的登记组件、动作组、镜头或素材路径消费。读完整提示词后若现有 consumer 没有承载它的字段，不得根据摘要临时重画一个新 Canvas/SVG/native/media/Three 画面，也不得把提示词说成镜头已落地；改选适合的已接通候选、在授权范围内建立对原 consumer 的最小字段映射，或明确说明未接通。没有预览图的完整提示仍可用于审美判断，但预览/提示都不等于真实 runtime consumer，也不保证它适合本片主题。

当这次工作会打开新的审美方向时，先运行 `styles fulltext --library --page-characters 12000 --json` 并逐页读完全部原文；把每页的 `nextCursor` 传给下一次调用，直到末页 `complete: true` 且没有缺项。新方向在 production-plan 的 `styleLibraryReview`/`decisionInputs` 留覆盖回执；实际选用的机制要有原文位置、适用理由和它在具体镜头/真实 consumer 中的落点。回执核对的是原文是否覆盖，不是模型是否读懂；审美判断仍需依据当前观众任务和作品条件作出。锁定方向内的小修、用户直接锁定及局部技术 probe 仍走与实际范围相符的路径。

资源总览和候选核对后，凡本段需要现有材料承载，都实际检查素材文件的内容、覆盖状态、权利和与本镜动作/身份/材质的适配；不以“工程里有文件”判定已有合适素材，也不只在模板/effect 零命中时才走素材路线。素材缺失或不适用时，先判断该任务是否确实需要图像/实拍，再沿负责来源与素材能力取得许可明确的成品，或在授权和运行条件允许、且原件/成品不适合时生成本片内容资产；证据原件缺失仍不能由生成或重绘替代。取得素材后，再通过 `list`/`show` 核对适用的真实 renderer 字段、输入条件和固定能力，并把实际文件接入并渲染。视频卡只播放已有且获准的视频并静音；照片蒙太奇只让已有 PNG 静图按组件机制移动；证据拼贴只组织已有照片/文档/截图/视频帧；wipe 序列只作为已有场景之间的转场输入。任何一条都不把素材改造成风格提示的形态，也不凭词面匹配宣称已经有水彩液体、蒸汽或其他缺失画面。没有合适素材或 consumer 时调整画面表达并继续独立部分，不能因本地素材为空或不匹配就默认只用几何图形。

完成素材路径核对后，把结果写为三种实际状态：已取得且权利明确、可进入该真实 consumer 的素材；已有素材但需换一种确实能承载它的画面表达；素材、授权或生产 consumer 仍缺失。第一类继续预览/渲染；第二类更新本镜的材料—关系—动作方案后再查其入口；第三类只标明该镜缺什么并继续不依赖它的段落。不能通过回退到抽象风格名、把文件存在说成适用，或自写成熟绘制机制来伪装缺口已经解决。

## 跨镜头统一靠内容锚点，不靠固定皮肤

全片有可辨认的视觉连续性，不等于每镜使用同一种背景、材质、布局或动画语法。为需要持续追踪的对象与关系保留身份、锚点、主次、色彩角色、关键字形或空间方向；让章节标题、语义对象、证据材料和观察尺度按本段任务进入、离开或重新组织。下一镜若换成真实素材、卡通角色、像素状态、手绘过程或三维空间，用可理解的对象运动、构图接力、形态相似或有意的切点/声桥完成接续；保留必要身份线索即可，不强迫新材料套上旧材质。

色彩和样式以段落/镜头职责为单位决定：可以在同一主色世界里改背景明度、局部强调或材料，也可以在章节/视角确实变化时换成新的色调和表现方法。改变前后需检查对象能否识别、文字对比是否足够、关系是否连续以及转场是否讲得通。没有语义变化时不为追求视觉变化而更换整套皮肤；用户也没有给全片每两秒换样式的规则。运动速度、镜头切点和声画重音照应时间线与语义，不把静止消除或固定换肤频率当成吸引力标准。连续段落保持角色一致、镜头语言相连、重点显隐有次序，比背景/滤镜持续变化更能让观众追踪主线。

## 先搭一个有焦点的画面世界

视觉设计不是给概念摆图标，也不是把已经列好的语义动作塞进默认版面。先比较前后段在对象身份/状态、观察尺度、证据或比较职责、感官进程上的差异，再决定同一材料内转化重组、新载体交接，或为阅读/比较保持并置；这些是可选的构思方向，不是每拍变化配额。若完整成片制作需要新组织整片或段落画面，或获授权修改确需在授权作用范围内新组织画面，先依据蓝图中的构思和真实候选，用实际 renderer、原生机制及本片实际内容变量绘制关键态预演。按未决画面取舍确定预演范围，覆盖承重单元的起、中、落、主要画面推进、必读文字的完整阅读状态及重要交接；在目标尺寸和正常速度自审候选固定机制是否承担内容、本片变量是否进入真实 consumer、画面结果是否兑现构思。若原生布局或文字字段不匹配，回到候选选择或真实接口适配，不以缩小文字或塞入侧栏兜底。发现对象身份、焦点、阅读或接续偏差时，把修正带回同一蓝图后再做对外样片；新 Showreel 在工作台展示实际方向帧和动态小样，按阶段取得方向确认，再展开全片。[方向探索与全片制作](production-collaboration.md#方向探索与全片制作)持续出现的标题、网格、进度条或容器须承担章节定位、比较参照、读图引导等具体职责，否则应随内容重组或退场。预演数量与时值按仍未确定的画面取舍决定，不设统一帧数/秒数，也不要求每拍换色换版。概念字段、分镜文字或作者自评不能替代实际绘制预演；关键态预演是内部迭代和自审，不需用户批准；它不能替代正常完整制作的对外风格/节奏样片及用户确认。已验证且对本次内容与文字布局均无构图疑问的原生模板，或不改变布局的简单局部操作，不机械追加此内部预演，但这不自动免除待确认方向的对外样片门槛。只有当一个具体不确定点会改变选择时，才比较邻近方案；局部方法也要放回全画幅和前后镜头修正。

**把整张画布当成随观看任务调度的场景。** 逐个语义拍点检查标题、对象、背景、尺度、构图、颜色、字体、光影、焦点与运动如何互相作用。标题可以在段落入口建立主题，之后离场、移入对象、缩成锚点，或按理解需要保留；不默认一条顶部标题和一块中央信息栏贯穿全片。当前内容变化时，允许主体从全画面转到细节、关系图转成照片/空间、背景与文字重新配合、对象移位或尺度改变、色彩层级交接。变动多少和哪些层变动，取决于语义、观看任务和画面需要，不规定每拍必须换风格、颜色或构图。若内容关系还在阅读/比较，维持原构图或局部变化可能更清楚；若新信息改变对象、空间、时间或焦点，就让全画面在有理由的范围内重组。每次选择都要在起态、过渡、落态中看得见并写回蓝图。

章节导航按“总览—章节揭示—内容展开—必要回返”承担不同职责。总览只在观众需要建立全篇关系时出现；进入某章时让该章主题接管主视觉，可以用大字标题、对象聚焦、穿入或其他与内容相合的入场方式，不固定一种章节卡，也不固定停留秒数。总览完成定位后，若本章讲解无需持续比对其他章节或追踪跨章关系，就退出主要画面，不常驻左侧、顶部或底部占位；仅在关系比较、步骤追踪或回到整体确实仍是观看任务时，保留必要的最小参照。章节收束时可用对象归位、空间拉远、关系重组或明确转场回返总览，再由下一章接管。地图出现、聚焦、退出、回返应对应现有稿件/ASR 时间线的真实语义锚点；新增停顿、旁白位移或章节前置只能沿用 `laohu-asrcut` 已确认时间轴或用户授权，不由 Motion 私自改声画时长。

产品/发布任务先核用户提供且可用的真实 UI、品牌材料、数据和使用场景，再决定画面气质；知识讲解要让实证材料与示意清楚可辨。先挑最难承重镜头，在目标尺寸下检查主体/证据、字组、背景、尺度参照、光影、留白与焦点如何共同构成全幅，再把已验证的约束带入相邻观看单元。剪辑路线按已定观看任务选择：解释/信息任务依对象、空间或色块身份承接，或以有意义的切点/并置组织比较、转折和省略；体验/情绪任务也可沿形式、材质或节奏进程连续展开、切换或变奏。混合路线在连续主干上切到需要展开的细节、证据、结果或体验转折。连续范围由内容与镜头关系决定：同一语义段仍需追踪对象/关系，且背景语境、颜色角色和文字层级仍有助于辨认与阅读时，优先保留这些线索；新章节、新证据材料、观察范围或体验目标变化时，可重组相应范围的背景、色调、材料和文字组织。无需随内容变化的层可继续承担参照，也无需随某层变化而整幅重置。跨章节或材料改变外观时，在蓝图中确定画面怎样接续；是否由声音承接由主线判断，声音细节随当前声音链核对事件相位、素材落点和配乐衔接。全片能量、密度与安静段随信息承重或体验进程安排。[原生 Showreel 声音](showreel-sound.md)

- **建立视觉世界。** 依据题材和内容选择抽象舞台、板面、桌面、纸张、屏幕、空间场景或无背景留白。背景要承担语境、深度、情绪或衬托中的具体作用；选浅色、深色、纯色、渐层、网格、纸纹或颗粒都要看主体轮廓、目标尺寸和材料真实性。网格不是默认“科技感”，纯黑也不是默认“高级”。
- **安排观察尺度与视觉重量。** 先按观看任务决定看整体、局部、细节还是并置，再通过位置、面积、明暗/色彩对比、边缘清晰度、遮挡和运动量决定主焦点与辅助层级。一个镜头可以有多个同时比较的对象，但应让共用基线、目标对象或结论拥有可辨的视线入口；不需要的信息退到背景或暂不出现。焦点变化要能在关键帧上看出发生前、转移中和落定后，并给必读内容留出有效阅读窗。
- **让图底、文字与对象共同建立配色。** 根据内容身份、前后景、资料语境、情绪目标、画面材料与阅读职责，决定背景、主体、文字、关系线、数据和强调状态怎样形成色彩关系。色彩可以丰富、对比强或克制，都由这组对象与背景的实际关系决定；只借鉴方法时可按本片重新选择，不预设统一色板。若选用适合本段的完整成熟镜头或耦合动作组，则保留承担表现作用的原生色彩角色与对比关系，不为显得不同而换色；只在真实开放字段和授权范围内调整。比较对象要有清楚且公平的区分，颜色不能代替单位、尺度、来源或事实标签。相同对象跨拍需要身份连续时保留可辨编码；不同镜头更换背景/主色时重新检查字与图形关系，不要求颜色恒定来制造虚假连续。
- **把视觉重量和颜色关系做成可检查的预演。** 输入是本拍第一要读的对象、比较单位、文字、实际背景和目标播放尺寸；先在关键态拉开主次的面积、位置、明暗、边缘与留白，再用黑白/眯眼快速检查主焦点是否先被看见。这个检查只暴露明暗层级，不决定画面该用什么色或证明审美通过；恢复原色后，还要在真实背景上检查同一色块、字色和关系线是否互相抢夺、融掉或误读。若主焦点跑偏，调整承重对象的大小/位置/对比或弱化竞争层，再复查起态、过渡和落态及正常速度短片；颜色相邻关系要在实际组合里试，不凭单独色值或固定色板下结论。
- **让光影服务画面关系与审美。** 阴影可区分前后层、托起漂浮物、显示遮挡；高光可指出当前受力面或被选择的部件；柔和渐层可把焦点从背景中分离。光影也可在不误导对象、层级、材质或事实的前提下支持氛围与画面气质，不要求每项形式都增加新事实。若它压过主次、遮挡文字、伪造材料/关系或变成无意的视觉噪声，再删减或调整；不能仅因其装饰性就一概删除。纸、墨、拼贴等材质可以自然覆盖主体与背景，但应留出足够对比保护文字和关系。
- **设计可读的起中落态。** 对动作图中的承重拍，先确定本拍的承重对象及理解它所需的参照；仅当本拍需要比较时，再定义比较单位及其共同参照范围。随后按目标画幅核对承重对象与必要标签在实际呈现尺寸下的可辨边界，安排变化对象及其前后态可读所需的画面空间。变化对象获得阅读空间后，再决定前一对象、标题、容器和其他全幅参照继续、缩小或弱化、退出、合并或重排；比较单位保持稳定，只约束其中对象与基线的关系，不自动冻结整幅。标题或容器留驻时，须在画面序列中确实承担阅读入口、对象身份、比较基准、操作反馈或必要上下文；单写保留理由不算完成。起态让人识别对象和原关系，过程中让关键变化连得上，落态给结果和必要标签留出可读位置。若块面身份、图层遮挡或整体到局部的尺度聚焦实际承重，再由主文选择相应局部方法明确对象/图层锚点与起中落，并把结果交回全幅整合；不因维持局部比较而强加运镜或整幅重排。对比、缩放、揭示、线条生长、结构拆分、相机移动或材料变化都可以成为主要动作；一个镜头也可保持同一构图，让观众观察关系或完成阅读，不要求每拍新增动作、运镜或焦点变化。阅读状态允许停住，运动不需要每层持续。
- **由整体进入局部，再返回关系。** 若解释依赖细节，先建立它属于哪个整体，再移近并指出细部，最后按需要返回整体以看出结果。移动相机时保持参考锚点或给明确过渡；为注意力或图解而推近不需要实测尺寸，但要保持身份锚点并避免标成物理比例；只有画面声称真实尺寸、距离或数值尺度时才需对应依据。

这些规则可在不同范围各自成立：例如背景层使用纸墨材质，数据主体保留扁平色块，选中对象上的局部像素精灵使用硬边采样，标注和箭头仍用平滑矢量；可按对象、相机、材质、文字、转场和声音各自职责组合多个来源，不设最多一个外来风格的限制。把每个选择落到全片/段落/镜头/图层/对象的范围里，保留来源形成画面的具体细节，而不只抽取抽象机制。组合前，明确背景、相机、文字布局、对象变换、裁切、透明度与强调层各由哪个已有源、父容器或对象控制，只登记本镜实际涉及的属性。完整来源镜头保留内部控制；局部组件服从其真实父容器、坐标和裁切条件。若两个控制同时作用于同一对象、同一属性和同一时段，先判断能否按任务拆到不同对象、图层或阶段；不能拆时选择一个控制源，不靠加载顺序或叠加强度决定。既有 Video Shotcraft 工程使用 Stage 时，只在该 segment 的 Stage 与 sibling 构成中按[接入规则](legacy/video-shotcraft-integration.md)一次建立背景与装饰层；当前 Film `/2` 不提供跨 segment 的持久背景层，需跨段连续时须选择真实可承载它的 renderer，不能假设 Segment Group 会保留 Stage。独立原生镜头不为统一画风而擅自拆掉或复制它的背景。

## 画面组织

**逐个时间阶段确定观众正在做的主要观看任务。** 一个阶段选定一个当前任务，可以是比较一组对象、追踪关系或路径、看懂过程、读一段文字、观察表情/情绪，或感受整个氛围；它不等于画面里只能有一个物体或只准一个对象运动。写清该任务的目标/参照及阶段进入时的状态，再标明哪些对象或文字提供支持、哪些只作背景语境、哪些应等待、退让或退出，以及观众何时已读清、看懂或感受到足以交接。阶段转换时重新作出选择，不把全片锁成单一焦点。

检查同一阶段里会争夺视线或听觉的具体变化：字幕/文字开始、闪光、颜色突变、主体运动、人脸或表情、相机运动，以及音乐或音效的瞬态。根据实际同时发生的时机与承重关系，安排错开、空间位置、面积、明暗/对比、遮挡、清晰度、背景处理和声音让位；不要求压暗整幅、冻结所有背景或改成极简。鲜明、丰富、强势的效果可以保留，也可以成为主要观看任务的一部分，条件是观众仍能看清任务对象、读完必要文字并接住前后关系。以真实关键画面和正常速度播放判断竞争是否发生，不用固定显著度分数、动作配额或通用秒数。

**安排注意顺序与画面主次。** 先按语义动作确定观众应该看见的对象、关系或结果，再安排必要标签和上下文的曝光次序。正向选择形状与边缘、字号和字重、颜色角色、光影、留白、空间层级及运动/停留节奏，让它们共同建立清楚、有吸引力的视觉主次；颜色、光影与形状可以承担审美和氛围，不必每项都新增事实。用位置、对比和运动强弱让辅助层支持主信息。目标画幅静帧与正常速度片段都应能看出阅读入口、对象焦点和落点；必读文字、数据、关系端点和承重证据细节须在有效阅读窗内完整可见。有意出血可以裁去背景、装饰或不承重部分，但蓝图要标明出血边界及仍须完整辨认的关键轮廓/细节；意外裁掉必读内容不能当成风格处理。

**把强调效果绑到承重对象、语义触发和空间锚点。** 先确定本拍要读懂的主要对象或关系、引发变化的内容事件，以及继续理解所需的上下文，再共同安排主体、文字、背景与旧信息的强弱变化。为当前内容取得足够的面积、边界清晰度和阅读位置，并让相关高亮、标注或光影跟随实际对象/关系锚点；旧内容按后续用途保留、降为上下文、重组或退出。尺度、位置、色彩、字形力度、局部底板、遮挡、光影和效果按实际冲突与表达目标选择，不作为每次强调的固定组合。需要隔离复杂背景时，只处理会干扰阅读的区域，并检查最终合成中的前景字。入场、强调、阅读、交接或退场按本拍职责取舍、组合或重叠，不预设每段都经过四个阶段；比较或总结需要同时可见的信息可以保留共同重心。波纹、光晕、纹理/粒子或残影既可表达动作关系，也可有意承担审美、节奏、材质或情绪作用；若其形态容易被读成扩散、触达、能量、持续实体或因果，则核对这种暗示是否符合本镜语义与事实依据。装饰性处理也须有强弱和边界，不能掩盖对象关系、制造未支持的物理因果或分裂焦点。效果服务当前焦点而非每次变化的配额；眼动不需连续被移动画面驱赶，声音也只在本镜有可听角色时按共享事件时钟安排。真实执行能力、图层顺序与片尾帧到工具链核验。

**让承重关系成为画面对象和操作。** 从动作图认出参与对象、身份、关系方向、前后态与结果，再选择真正显示关系变化的空间、形状、路径、材料或符号操作；不把句子清单换成通用输入—机器—输出槽位。关系图承重且继续旧 renderer 时，按实际接口读取[关系图方法兼容锚点](legacy/legacy-motion-methods.md#laohu-motion-relations)；抽象逻辑也可使用符号替换、归属改变或其他合适表达，不规定圆圈、卡片、集合图或固定布局。信息面板、标题和容器只有在实际承担分组、比较、阅读、上下文或操作职责时才保留。全画幅构图决定这些对象如何进入、聚焦、转接和退出；关系类型、端点、方向、对象生命周期及真实绘制方法由适用模块与工具链细化。图形不得声称超过证据的方向、数值、物理尺度或因果强度。

**文字作为整幅构图中的画面对象。** 每段文字是什么、是否锁定、为谁服务以及能否逐批显现，统一由 [字体、字幕与可读性](typography-and-legibility.md) 判定并写入镜头蓝图；视觉设计按其语义、真实目标与共同组外框安排文字和图形、背景及阅读路径。可读性冲突按该 Reference 识别的实际原因处理，再由本 Reference 组织对应的背景、对象、图底关系和全幅层级；不重算字框或另造算法，也不在此另设字数、标点、字号、底板或对比配方。

若字词或字形本身是画面主体，分组、字层轮廓/遮罩、空间变换、曝光停留或退场重组构成本镜主要操作；既有旧 renderer 的文字主体接口见[文字方法兼容锚点](legacy/legacy-motion-methods.md#laohu-motion-typography)。该方法只约束文字对象和局部生命周期；普通标题/标签不因使用字体、路径或图层而触发，也不能代替可读性 Reference 的真实字体测量与有效阅读窗检查。

**先定阅读路径，再移动画面。** 固定画布、资料桌面、空间穿行、分屏和局部聚焦需要不同的构图逻辑。先用关键帧确定主体、条件和留白，再决定镜头或画布是否移动；运动的起点、经过位置和落点都要留在工程可检查的帧上，必要信息不得在移动中被裁掉。

**把对象的可见窗口与插值终点分开设计。** 事件到达目标坐标、对象状态或透明度端点，不代表它在到达前或之后仍可见。按镜头任务确定对象何时进入、何时需要持续识别、何时由下一对象接手；用真实 z-order、opacity、clip/mask 或绘制分支实现该窗口。连续观看依赖旧对象时检查其真实可见几何和遮挡关系；其职责完成后，明确将旧对象移除或转换为新的参照/状态，避免只因 renderer 保留旧图层而拖过转场。明确切镜可以切断连续性，不要求每个对象全程驻留。


## 运动与停留

**先按本镜任务选运动方法。** 解释任务中，镜头若表现对象出现、累积、移动、分解、比较、触发或阻塞，就让运动承担这个关系/状态变化并维持可追踪的注意顺序。体验、情绪、氛围或风格任务中，若用户选定的观看目标由材质、形态、重心、速度、重复或变奏承载，连续运动本身可以构成体验，不必每一拍新增事实；把这些变化组织成有方向的进程和可落定的位置，不用无目的微动填时。界面动效把动作接到真实触发、系统状态与反馈。目标可以混合；环境微动只有不抢焦点且确实承担所选职责时才保留。蓝图应指出运动在服务什么；持续动或停住都不是默认答案。

**用 staging 接续注意。** 先写本观看单元的主要任务、进入前提与完成依据，再设计承载它的关键构图。稳定比较框架只在确有比较关系时保留到该比较任务完成；转向内部细节、新对象或新证据时，重新判断观看范围，先为新任务安排可读空间，再决定旧内容作为身份/比较参照保留、缩小或弱化、重组还是退出。先设计交接前后的关键构图，再选入场、移动、遮挡、切换或并置等能承载本次交接的操作。若本拍确需辅助变化，逐层确定辅助形状、速度线、光晕、下划线或第二组文字何时进入、各自的曲线/锚点及其控制属性；主体、辅助层和文字可按职责错时，必要时也可同时动作。将主体完成任务的时点与辅助效果尾部区分：必要内容和对象身份已建立、观众能继续追踪关系时可交接主焦点；辅助层若仍支撑理解且不争焦点，可短暂交叠、继续收束再退去。为比较或职责总结并列多个对象是有效分支。下一对象可先入场或先显露局部，随后接过主焦点；但依赖前一结果的动作必须等该结果实际抵达。决定主体保留、重组为下一状态还是交给下一对象，并保持足以识别连续对象的身份/语义锚点。不要求整幅同时动作，也不强迫一次只有一个对象动作或为辅助效果延长主要任务。

排一个具体动作时，以承重对象、动作任务和实际声源事件为输入：先让 staging 说明观众要看哪里，给主要动作留出空间；再把准备、触发/接触、结果和必要的稳定阅读段落标到真实帧。只有不同部件确实有不同受力或职责时，才用 overlap / follow-through 表现延迟与余动；只有强调能帮助读者看清状态或表达语气时才夸张位移、形变或落点。夸张不能改写数值关系、对象身份或事实强度。检查动作前一帧、触发/接触帧、结果帧和一段正常速度播放，确认主焦点、运动余量、结果依赖和阅读时段清楚；有合适且获准的声音命中时，再核实际 SFX cue 是否落在同一成片事件的实际相位。

**按事件相位、动作职责与实际帧间距设计节奏。** 逐项标明动作是在引导观众找到对象、展开过程行程、让结果落定，还是留出阅读/比较时间，再据此选时值、曲线、速度、运动范围或静止：引导可以短促，行程遵守真实过程，落定无需默认回弹，阅读段通常静止或只保留不妨碍理解的体验性运动。先确定本段主重音、主揭示或结果落点；以它为中心向前安排入场与必要准备，向后安排稳定、必要的阅读/关系停留、焦点交接和退出。进入阶段可很短，理解需要的落点必须看得清。用户要求利落、快速或有节奏时，把主要变化放在前段迅速建立，再留出足够停留理解；不要把整片所有动作都加速，也不以每拍必须变化代替节奏。区分 `timing`（事件/相位何时发生、停留和交接多久）与 `spacing`（相邻帧如何分配位移及速度感）；速度由位移幅度、持续时值和目标 fps 下真实帧间距共同决定，曲线名称本身不能证明利落或柔和。位置、尺度、透明度、遮罩与模糊是独立通道，可按职责错时、重叠或共用阶段，逐项确认其真实属性与消费位置。真实匀速过程保持匀速；数据读数、比例或定量变化服从实际模型与标尺；提示、聚焦、起步、路径运行和落定依动作选择曲线，不能把同一缓动或持续运动套到所有动作/图层上。anticipation、overshoot 或 squash 可用于适合语气的文字、图形或 UI 强调，但不可改变定量几何、对象身份、关系方向或锁定端点。事件时值与曲线须写入真实被消费的镜头/属性映射；本作蓝图填写本作的时值与节拍，并按用户锁定的总长或节拍安排；不把单个镜头的秒数、BPM 或动作数量写成跨任务通用配方。逐帧核对真实位移、速度、锚点、终态和有效阅读窗。

本拍若呈现真实接触或受力，按材料与动作目标安排可读的准备、接触/受力、结果和余动；anticipation、形变、overshoot 或 settle 只在角色/物体机制和语气支持时使用，示意动画不能因此声称未有依据的真实物理。输入是一个明确的动作/声音事件时，把视觉触点与共享事件锚放在同一成片时钟上。声源适合本片且用途获准时，再安排声音命中。检查接触前一帧、接触帧、结果落定帧，再检查目标尺寸下的实际短片/样片，确认焦点、受力对象、文字阅读窗与音效起点没有互相遮断。关键字段要能从蓝图追到真实绘制属性、音频事件和最终消费者；不以曲线名字、事件标签或波形存在代替画面/声音审听。

**既有工程的局部动作按真实 consumer 查兼容锚点。** 同一对象/部件的轮廓对应与连续形变、块面遮挡/聚焦、路径构建、像素步进、笔墨扩散和证据材料揭示，只有旧工程的真实接口仍消费这些方法时，才按其动作需求读取[旧 Motion 方法兼容档案](legacy/legacy-motion-methods.md)的对应锚点并核 catalog/source。新 Showreel 通过[动作语言与实现](motion-language.md#从片段决定选择动作和实现)查成熟工艺和当前绘制方法。将所选动作放回全画幅，检查焦点、前后对象交接和起中落构图。方法选择看本镜是否确实需要该动作；仅仅使用 layer 或 path 等基础字段并不构成调用理由。

**锁定随机纹理的身份。** 程序噪声、笔触采样、粒子和生成帧可能逐帧漂移。需要重复渲染稳定时固定随机种子；纹理应附着对象时使用材质或对象坐标，并检查关键中间帧、重复渲染和循环边界。成片不应无故闪烁、滑移，粒子的出现和消失也要有可读理由。

**按观看任务决定何时继续或停住。** 对解释与阅读任务，新标签、关系图、数据或结论刚出现时，保留足够辨认、比较和思考的时间；当下一关系、状态或注意焦点确实要变化时再恢复动作，否则停在清楚的落点。对体验/情绪/氛围/风格任务，如果连续运动本身承担已选的感官职责，可以在没有新事实时继续，但应能指出形态、重心、速度或重复/变奏怎样推进体验，而不是空转。对界面任务，动作以交互结果或系统状态的呈现为边界。静止也可用于阅读、重量、期待或回味。检查落定状态是否有连续可查看的帧、是否被后续元素遮挡，以及下一事件是否等到相应观看任务完成后才开始。

**让镜头运动揭示具体对象。** 推拉摇移应有可指出的目标：揭示、换空间、改变尺度或跟随对象。镜头数据写明起止构图及新增关系；文字需要阅读时保持稳定或避开运动路径。没有实测依据时可为注意力或图解而光学推近/突出局部，但保持对象身份锚点连续且不标成物理比例；只有画面声称真实尺寸、距离或数值尺度时才需要对应测量依据。首尾帧应能核对运动目的，且文字不会被裁切带走。

**用转场表达段落关系。** 同一对象或空间的连续变化可匹配运动，对照内容可并置或短停后切换，无关新题则干净切开。连续性要在前态、过渡中态和后态检查真实对象状态、空间关系、方向、焦点及必要的声桥；同一 ID 或 renderer 不能证明实际画面连续。语义转折可以有意切开，不要求全片强制 morph。选法取决于内容关系，不能让转场模糊段落边界或带入未证事实；单帧检查前后对象仍应可辨。

**按观看任务调速度。** 解释任务中的轻提示、短强调、长路径和真实过程需要不同的时值；慢动作应展开本镜需要看清的关系/状态，或为必要阅读留出时间，不要拖慢无关路径。体验、情绪、氛围或风格任务可以让较慢的连续运动推进已选的材质、形态、重心或变奏，不以新增事实为条件，但须对应明确的感官目标；界面动作则按真实触发与反馈时机安排。快动作按目标帧率检查。没有统一镜头秒数或快动作比例，最终应逐帧确认关键相位、端点和数据准确，且无非预期跳帧。


## 声音与多层信息

声音是另一条按事件与职责组织的时间层，不是自动附加给所有画面的配件。需要安排或检验旁白、音乐、音效、环境声、用户指定原轨或静音时，按本片的声音消费者确定职责、授权来源和共享事件，再在真正输出的音频文件中对齐。原生 Showreel 走当前项目的声音交接；既有 Remotion 或 Film 工程沿原混音合同执行。[Showreel 声音](showreel-sound.md) · [既有工程声音合同](legacy/sound-design.md)音效可标记有意义的动作、触碰或落定，配乐可支持段落节奏，静默也能保留空间；并非每个视觉变化都需要声响。runner 只输出无声画面时，需用明确的作品级音频步骤混音封装，不能仅写一条音频计划就称声音已入片。


## 画风与内容语法分开

先依据内容选因果、比较、步骤、空间、数据或体验表达，再逐对象/图层分配表现方法。按承重对象和实际操作检索相应工艺，沿用用户明确锁定的视觉与材料范围。兼容档案的做法只约束旧 consumer 仍消费的指定对象、图层或镜头；新 Showreel 则由 Analysis brief 与原版 Showreel References 指导本片代码设计。一个对象跨表现方式呈现时，身份、锚点、空间和图层关系仍连续。拿掉无关装饰后，内容关系仍应成立。

**画面固定只限所选作用范围。** 先从观看单元和承重材料明确要表达的对象、关系、生命周期及全幅任务，再把适用的完整镜头、成熟动作组和局部 effect 当作并列候选，检查各自原生构图、对象关系、动作顺序、曲线、结束状态、开放字段与素材条件。选择完整镜头时，保留其适配本段的原生构图、层级、运动、标题/图表位置、颜色角色、字体和时间安排，只改源码实际开放且本段需要变化的字段；选择动作组时，保留其中相互依赖的布局、顺序、曲线与收束；选择局部 effect 时，只固定它登记的目标、属性和时段，不锁定背景、其他对象或全片画风。视觉设计与真实候选相互校正后再落定全幅构图；不因“局部粒度较小”就优先局部 effect，也不把自制 layout 设为找候选的前提。原生构图若适配本段比较、阅读、关系解释或体验职责，可以完整保留；若不适配，按模板库先换成熟候选/复用尺度并检查精确 source index，能接入则按原函数局部适配；仍无适用原件时暂停依赖部分，不把固定机制强加给邻段。用户提供外部动画/样片作参考但未匹配本地可调用项时，核查连续画面与实际源码能证明的范围：沿镜头观察标题如何进入/退出，主体及背景如何变化，观察尺度和构图如何重组，字形/字号/文字色、图底色、光影和运动怎样一起配合内容推进；将可迁移的整体关系记入蓝图，不只抽取一组配色。可运行的授权来源命中时按原生接口复用；不能把预览或目录项说成可运行模板，也不能因方法参考而推定资产已获授权。普通开放请求无可调用匹配项时，查精确原实现索引并换适配候选；成熟机制适合但缺本片内容字段时，优先通过最小本地 adapter 暴露本片变量并保留原生机制。技术故障先排除；只有没有适用且获准机制、必要内容无法安全接入时才暂停受影响部分。用户明确要求从底层原创视觉实现时才新建绘制机制，不因全新内容、未指定画风或参考材料缺口重造已有机制。

## 跨方法构图与局部动作接合

把局部方法放进完整画幅，核对背景、光影、留白、节奏、色彩和排版怎样组织标题、对象与观看路径。新 Showreel 按 Analysis Brief 选择原版或已核的本片做法。既有 Motion、Film 与 Remotion 项目在原 consumer 确实接用该方法时，查对应锚点、源码和实际条件，具体作用范围落到本片对象或镜头。[动作选择与实现](motion-language.md#从片段决定选择动作和实现) · [旧方法兼容档案](legacy/legacy-motion-methods.md)

局部模块返回本对象/图层的操作、实际约束、锚点和未解冲突，由主线与本 Reference 组合进整幅画面；模块不递归调用同级模块，也不规定固定字体、配色、底板、动势或整片皮肤。每次转向新对象或状态时，主线单独决定上一对象是作为身份/比较参照继续、退让/重组，还是退出；保留不是默认。

局部效果、成熟动作组和完整镜头并列比较，分别核对当前用途、对象、可见生命周期、复用尺度、变体、固定机制、实际属性、时钟与运行状态。局部实例只约束它登记的对象/属性/时段，不固定背景或全片画风；动作组或完整镜头适配时，保留它们承载观看任务的原生机制。在全画幅核对真实候选是否帮助观众看到本段重点。新制作的资源正文与消费者由统一入口查阅；既有项目需要已登记模板的字段时查旧 catalog 合同。[设计输入与资源查阅](showreel-runtime.md#设计输入与资源查阅) · [既有模板复用](legacy/template-library.md)

把所选动作放到画幅中，先确认对象和关系的起态位置、动作中的焦点与空间接续、落态阅读/比较位置，再决定标题、背景和其他对象是否持续、转化、退让或退出。比较任务要让比较对象在所需窗口同时可辨；需要局部聚焦时才移近，且保留能回到整体的空间锚点；集合增删/重排要保持必要身份与顺序。无须每拍改变背景、色彩、动作或镜头；稳定构图只有在画面实际持续承担阅读、比较或关系参照时才保留。新 Showreel 将对象、时间和绘制落到本片实际页面，再用工作台同一事件上的帧和可播放结果复查。既有 renderer 按它的实际实现检查。[本片动作接线](motion-language.md#从设计到确定性实现) · [方向帧与实渲](showreel-runtime.md#方向帧与同一状态的工程实渲) · [旧 renderer 检查](legacy/toolchain-render-and-check.md)

当相机运动时，按当前工程的真实对象空间处理标题/标签：需要持续留在画幅的文字与需跟随对象的标签分别绑定其实际 screen/world 空间或投影方式；在平移、缩放和 seek 后核对锚点。若工程接口没有对应字段，使用已注册的具名自定义绘制或该工具真实支持的等价实现，不虚构 renderer 字段。

**跨方法审美验收。** 对照静帧和正常速度序列，检查形状/边缘、字号与层级、颜色角色、光影、留白及运动/停留是否共同形成有方向的主次和可辨的画面气质。它们可增强氛围，不必都新增事实；多种材质可在同一画面共存，只要对象身份、锚点、阅读路径和视觉主次连贯。把方法范围、保留/退场/重组选择、焦点交接、触发/时钟、文字顺序、起中落状态与停留写回镜头蓝图；关键帧、动作预览和最终渲染分开说明，不以规则调用或字段存在宣称画面质量通过。


## 面向实际媒介

画幅、屏幕、平台、帧率和字幕区按用户或既有工程规格确定；规格未知时采用工具支持的工作默认值并注明可调整范围，不宣称“平台最优”。安全边距、字幕区、裁切和色彩对比在最终尺寸上实测，确认主体与必要文字在实际播放器中仍可见。
同屏新标签、运动对象和数据过多时，先删无关信息，再考虑拆时序、分屏或停顿；不能为减密度而删掉限制条件、来源或逻辑环节。正常速度播放时，每段新增信息应有可追的出现顺序。
涉及现实人物、地区、文化符号或身份时，使用已核实的指代与语境，不把颜色心理、服饰或画风暗示当作人群事实。最终画面不应凭材料未支持的视觉线索推断身份。

<a id="remotion-camera-and-parallax"></a>
## 本地 Remotion 相机、视差与空间

`templates/runtime/laohu-remotion/components/camera` 使用秒和像素坐标。`CameraRig` 接受 `camera(t)` 的 `center:[x,y]`、`zoom>0`、弧度旋转/tilt；world children 只受主相机变换，`screen` 层用于字幕/HUD，不能把相机再套到已变换 children。`cameraPath` 对位置、角度与 tilt 使用共享切线 Hermite，对 zoom 先取 log 再插值；`stop:true` 是该 key 到下一个 key 的停驻条件，Hermite 仍可能过冲，角度跨 ±π 前需 unwrap。`ParallaxLayer` 自己处理 depth，避免与同一相机重复变换；它是近似 2.5D，不计算真实深度遮挡。`RackFocus` 是基于归一化深度差的 CSS blur/轻缩放，不模拟镜头光学；`shake` 的 frequency 是 Hz 且起止包络为零，`dollyZoomFov` 的距离单位须一致。CSS perspective 有 tilt 时，不能把 2D 锚点反解冒充完整 3D 投影。

<a id="remotion-procedural-backgrounds"></a>
## 本地程序背景与阅读区

`components/backgrounds` 的 `BackgroundCanvas` 接收显式秒、宽高、draw 函数与 `dpr`，每次同步重绘，不启动私有 `requestAnimationFrame`；资源/字体加载仍须在上层等待。`FlowField` 默认 100 条线 × 35 步、步长 6px、12s 周期；`ParticleAtmosphere` 默认 240 粒子，可选 drift/orbit/gather，gather 需每粒目标坐标及起点/时长；`DotGrid` 默认间距 42px、事件振幅 6px；`NoiseGradient` 默认 cell 24px、3 octave、20s 周期；`LightSweep` 取显式 0…1 progress。`Grain` 用固定 seed 与绘制拍更换颗粒，不是连续纹理。`ReadingZoneMask` 是亮度/alpha attenuation 函数，接收屏幕像素矩形与 padding/feather/floor；它不会自动让世界粒子绕开文字，也不是 3D 体积光或 GPU 后期。需要世界空间阅读区时先做坐标变换，再调用屏幕背景。

<a id="remotion-character-rigs"></a>
## 本地 SVG 角色与步态

`components/character` 的 `Rig2D` 只承接 SVG drawing 节点，部件 offset/pivot 是相对父级的像素；重复 ID、缺父级或父级循环都会报错。`poseTimeline` 的 key 用秒，hold/linear/ease 定义该 key 到下一个 key 的插值；blink 的 seed 固定后可重现。`lookAt` 假设 eye/target 在同一局部坐标，不做世界投影。`WalkCycle` 的 speed 是 px/s，ground/lift/legLength 是 px，period 是秒，且会按腿长做可达性检查；身体位移与脚点不能分开调速。`pendulum` 的长度/重力/阻尼分别是 m、m/s²、1/s，角度是 rad。`throwSnap` 是闭式位置示意，不模拟接触冲量或布料。像素风可在该组件外做整数网格量化，手绘变形保持实际接触点。

<a id="remotion-specimen-scenes"></a>
## 本地标本册与 Three 组件

`components/three/specimen` 保留 `SpecimenCanvas`/`StudioEnv`、`VolumeScene`、`ParticleField`、`CubeStage`、`BounceGraph`、`GlyphAnatomy`、`StrokeDraw` 与 `specimens` 的局部实现。Specimen 的参考坐标为 1920×1080；BounceGraph 的 contacts 必须递增，其波形是接触示意，不是真实音频波形。CubeStage 让同一 draw 输出到面/子块；检查镜像、裁切与扭转窗口，避免旋转重叠。VolumeScene 使用 24×24 实例体素，`wave` 以帧为单位，`drop/sink/field/flat/rise/wire/dark` 为 0…1，`detail` 与 `amp` 控制细分和噪声，camera 参数包含角度、距离、高度与目标；改帧率时显式换算 wave。ParticleField 默认 60000 个 GPU 点，支持 sphere/galaxy/text/image/line 等阶段；图片取 alpha>140 的像素并按步长 2 采样，空点/加载失败会报错，资源会经 Remotion 等待并在取消时释放。它的噪声场不保证不可压缩流体。只在目标运行时安装 Three、Fiber、`@remotion/three` 所需依赖；Canvas/2D 分支应按需导入，不因 specimen barrel 引入 3D。主题 luma 是 sRGB 加权近似，不是线性化 WCAG；实际 WebGL、材质、裁切和字体加载仍要按目标浏览器独立渲染检查。
