# 导演构思、四维 4×4 判断架构、双阶升维与可执行三段式 Brief

好动画从不是靠在表皮堆叠暗黑发光玻璃或炫酷字形拼出来的，而是严格从**灵魂 → 筋骨 → 血肉 → 表皮**逐层降维，让每一维都闭合**目标 / 判断 / 行动 / 结果**：先让观众收获“豁然开朗又如沐春风”的公共审美心情，再用空间运动演透稿件逻辑，再发明有物理重量直觉的核心母体，最后用恰当有度、引而不抢的字体与清透光影完成交付。

本参考是 `laohu-motion` 四维导演构思、理论裁决、引擎选型、双阶升维及 `brief.md` 契约的**自足唯一真源**（纯方案与定稿阶段看本文件即可闭合全部字段，无需另翻上游 `brief-template.md` 或 `.mjs` 源码）。

## 1. 动画 4×4 顶层构造体系（从高维往低维降，缺一维必失公共审美）

**最高禁令：严禁跳过灵魂、筋骨与血肉，直接在表皮（字体/配色/卡片样式/光晕）上打转！** 凡涉及世界观风格、逻辑表达、构图转场、材质隐喻、字重排布或引擎选型，一律沿以下四维自上而下推演：

### 1.1 第一维 · 灵魂（Soul）：定清最终心情、反刻板皮肤与世界观路线
- **目标**：穿透表层题材词（“AI / 金融 / 效率 / 历史”），经五层需求穿透（钉子 → 洞 → 画 → 屋子 → 心情）锁定观众看完后唯一该留下的**底层公共心情**（如豁然开朗的清明通透、温暖从容、犀利清醒或厚重震撼），确立最配得上这种心情的美学世界观。
- **判断（Reber-Schwarz-Winkielman 加工流畅度与 Aha! 美学 × Russell 情绪二维环 × Loewenstein 信息缺口理论 × 风格路线三态裁决）**：
  1. **情绪科学推导（绝不靠模型瞎猜）**：逐句用 **Russell 情绪坐标（唤醒度 Arousal × 效价 Valence）**与 **Loewenstein 信息缺口理论**推导观众此刻的真实心理状态并映射为画面动作——**好奇/悬念**靠“先露一半反常线索或未完成动作、藏住另一半，0.8 秒后掀开”；**期待/探索欲**靠镜头持续向前推入或逐层剥离；**顿悟爽感（Aha!）**靠分散概念咔嗒拼合归位并给出超越口播的真增量；**震撼/敬畏**靠先沉浸极轻极小日常、再瞬间打破尺度的物理反差。
  2. **反关键词条件反射**：绝不因出现“AI / 算力”就默认套熏黑霓虹玻璃大屏，也不因讲“方法”就默认套白板 PPT。先问：**说话人此刻是在吓唬炫酷，还是在拨开迷雾帮普通人看透真相？** 绝大多数面向大众的深度认知、商业与趋势讲解，底色天然需要**清透、明亮、从容、有空气呼吸感的公共美感**（如极净暖白浅灰建筑摄影棚、温润编辑纸感或克制去油腻哑光影棚），而非压迫感拉满的重金属科幻壳。
  3. **单一风格 vs 受控融合 vs 受控跨风格怎么选？**
     - **单一纯风格**：整篇情绪连贯、系统拆解同一体系（如 Apple 工业设计片 / 建筑实体模型），用单一极精纯的物理世界把高级感推到顶点；
     - **受控融合风格（Vox / NYT / Ordinary Folk 路线）**：稿子同时包含现实证据、抽象机制与观点表达时，**守住统一的底盘材质、色调温度与留白呼吸**，局部自然融合真实照片、产品界面、精绘矢量图解与克制手绘标点——融的是信息媒介，绝不拼贴互打的皮肤模板；
     - **受控跨风格/空间跳切**：仅当稿子本身存在剧烈的**“表层日常错觉 vs 底层真实重量”**认知劈裂时，才在反转瞬间做表里明暗或空间剖面跃迁，且必须由同一物理载体或地坪剖面无缝贯通，绝不无故换皮肤割裂。
- **行动**：写分镜前先落《灵魂定盘卡》：① 唯一要制造的认知顿悟与最终心情；② 选定的世界观路线与氛围依据；③ **本片明确要主动避开的低级刻板皮肤**。
- **结果验真**：关掉全部文字和声音，只看 1 秒底图光影氛围——观众心里升起的情绪温度是否和稿子想给他的心情 100% 同频？只要让人感到压抑、装酷、油腻或廉价，灵魂层直接判 FAIL。

### 1.2 第二维 · 筋骨（Skeleton）：把稿件逻辑翻译成空间运动结构 × 视觉强度波形 × 视线接力
- **目标**：让稿子背后抽象的**逻辑关系**（垂直托举、主脉分叉、因果连锁、表里掀开、状态演化）变成不用靠嘴硬讲、眼睛一看就懂的空间与时间运动，并全程稳稳牵住注意力。
- **判断（Tversky 一致性 × Paivio/Mayer 图文互补信息增量 × Zeigarnik 钩子与 Juice 物理爽感 × Bruce Block × Murch × Berlyne）**：
  1. **关系原型同构（Tversky）**：先剥出每段话真正的逻辑关系原型——“自底向上托举”必须呈现垂直物理承重，“一股浪潮的四个切口”必须由一根连续流动主脉串起差异化落脚点（绝不切成四张孤立同模卡片！），“轻盈表层背后是庞大底座”必须演成真实掀开或向下剖面潜入；
  2. **图文互补信息增量（Paivio 双编码 × Mayer 互补原则，根治“留白变单调空洞、像念 PPT”）**：口播是线性的，画面是二维并行的！**严禁画面信息量 ≤ 口播文字本身**（嘴里说 4 个词、画面也只摆这 4 个词加无现实含义的抽象小积木）。在不胡编事实的前提下，紧扣全篇语境在画面上**主动多展开半层高价值结构增量**——如把泛指机会精准连回核心地图对应层位并点破具体落脚点、补清隐含的机制拆解或对照维度，让留白真正服务于高密度干货，而不是因为没内容才留空！
  3. **开场 1.5 秒视觉钩子 × 物理微爽感（Zeigarnik 未完成势能 × Kinetic Juice / 视觉 ASMR）**：为什么顶级动画哪怕静音都能让人一直看下去？① **开场 0–1.5 秒必须制造“正在发生、即将落定”的蔡格尼克未完成物理势能**（如实体利落剖开弹层、零件凌空依次磁吸落槽），绝不在第 0 秒静静摆拍一座死模型；② **全程注入触觉联觉微手感（Juice）**——不同材质重量对应不同落地回弹阻尼、按钮按压微缩回弹、轨线推进像滚珠精准咔嗒卡位；③ **每 1.5–2.5 秒制造一次「微期待 → 微兑现」多巴胺闭合循环**；
  4. **视觉强度波形、视线追踪与新鲜感（Bruce Block × Murch Eye Trace × Berlyne）**：空间、景别、光影与速度同频演奏“亲和蓄力 → 推进 → 对比反转”波形；每拍只留 1 个主焦点，转场借上一镜眼球落点变形、延伸、推近或剖面穿越；相邻场构图持续翻新；
  5. **分场与观看完成点（McKee × 观看完成点）**：按认知/情绪转向划大场，按观看完成点定小拍长短（看懂即演进推入下拍，杜绝连续 3 秒以上呆板站桩；口播严守 `ASRcut` 实测词锚）；多要素冲突严守 **Murch 优先序（情绪 > 故事/理解 > 节奏 > 视线落点 > 二维平面 > 三维连续）**。
- **行动**：碰任何颜色、字体、特效前，先画**“剥皮逻辑白盒”**——每场只写清：逻辑原型是什么？镜头景别和主焦点怎么从上场落点接进来？在哪一秒完成“咔嗒”顿悟？
- **结果验真**：做**无字静音白盒检验**——遮掉文字与声音、只看极简几何块在动，陌生人能否一眼看清“谁托着谁、流量往哪去、哪里掀开了底牌”？

### 1.3 第三维 · 血肉（Flesh）：概念隐喻物理母体 × 真实过程戏剧 × 代码引擎强项
- **目标**：把第二维的抽象逻辑骨架，注入**全人类一眼自带物理直觉、经得起放大品味的核心实体母体与真实互动现场**，彻底告别空壳卡片、简笔画、塑料 3D 方块与廉价科技贴纸。
- **判断（Lakoff & Johnson 概念隐喻 × 造梦五维筛材 × 真实过程戏剧化）**：
  1. **概念隐喻物理映射**：追问——*如果稿子里的抽象层级或力量有真实物理重量、密度、温度与透光度，它们该是什么？*（如越底层越厚重密实温热——石材/古铜/精钢/地基；越表层越轻盈洁净通透——雾面亚克力/薄纸/纯净光面），用材质的自然物理语言不着一字讲透因果；
  2. **五维正向精筛**：视觉母体须跨时代耐看、单独定格像博物馆展品或顶级大刊视觉专题、人人无需解释即懂、正在发生真实状态演变、且落在本代码引擎最无敌的质感区；
  3. **真实实测素材 vs 真媒体嵌入代码交互壳（四类媒介规范，绝不拿代码假画冒充真图/实测）**：
     - **实证 / 评测 / 作品演示型**（稿子明确讲述“某次真实提示词测试的返回、真实生成图/歌词/音频/视频作品或软件操作”）：**必须放真实产物**（真去实测或使用用户提供的真实图片/音频/视频/录屏；缺素材时必须向用户索要或标明缺口，严禁用代码画假图、编假歌词冒充实测）；
     - **泛指日常示例型**（如顺口举例“AI 生成一张图、写一段话/做首歌/出段视频”）：**同样优先把真正生图/音视频工具产出的高审美真实媒体嵌进代码做的极净交互壳里**，让代码专攻“界面包装、点击微回弹、显影/跳转运镜与波形联动”，绝不强迫 Canvas 2D 硬画矢量插画冒充生图效果；
     - **四类媒介交互语法**：文字 = 打字机输入 → 点击运行 → 真实流式逐字浮现；图片 = 点击生成 → 模糊/扫描显影 → 真实高清图片弹出微推；视频 = 点击运行 → 视口放大跳转播真实动态视频；音频/音乐 = 点击生成 → 真实动态频谱波形随真实声音同步呼吸。
- **行动**：全片钉死 **1 个贯穿核心的物理视觉母体**（及 1–2 个从它身上自然长出的演化形态），落清材质重量、触感纹理、真实信息密度与下方 6 引擎最优组合。
- **结果验真**：抽掉全部文字把核心主体单独定格——它像一件**Apple 工业设计模型 / 国际设计大刊专题作品**，还是像“批量 AI 科技展会模板素材”？

### 1.4 第四维 · 表皮（Skin）：字体「引而不抢」之度 × 光影通透去油腻 × 光学质感 6 要素
- **目标**：让第一眼观感**通透、干净、克制、耐看**；让文字、色彩与光影恰如其分地接住注意力，然后优雅退隐把舞台还给内容，**绝不过犹不及（炫技抢戏），也绝不什么都没有（细弱模糊）**。
- **判断**：
  1. **字体与排版的「引而不抢、恰当有度」铁律（Robert Bringhurst × Brumberger × Saul Bass）**：
     - **核心之度**：字体的意义不是“炫酷特别”，而是**尊崇内容、恰如其分地吸引并释放注意力**！严防两极失度——**① 防过犹不及**：不滥用夸张狂草、重金属发光字强凹“有情绪”去抢画面与逻辑的风头；**② 防细弱失踪**：辅助词与标签必须具备清晰饱满的视觉分量与高对比，坚决杜绝细如蛛丝、灰暗发虚的低字重小字；
     - **分情境精准选角（绝不写死固定字体）**：按题材气质 × 说话人情绪 × 文字角色实测本地 62 款字库选角（优雅现代雕版宋体、饱满人文黑体、温润中粗楷体、真实 UI 字体或确有宣言张力时的克制笔锋字，详见 [typography-and-legibility.md](typography-and-legibility.md)）；
     - **破除左上角 PPT 母版（文字即演员）**：文字按镜头角色自由进入画幅核心、紧随焦点节点、融入真实输入框或纵深穿插，同时保持高度优雅的秩序与大片留白呼吸；动态入场不计停留，完整显现后严守物理阅读窗（中文 `字数 ÷ 4.5 + 1.5s`，英文 `字母数 ÷ 15 + 1.5s`）。
  2. **色彩与光影的「通透去油腻」法则（Dieter Rams “少却更好” × 感官洁净度）**：
     - 洗掉廉价霓虹发光线、过曝眩光与浑浊脏渐变！无论极净浅灰白摄影棚、温润编辑纸感还是极简哑光深灰影棚，均严守**去色验明度阶差清晰**＋**同屏唯一克制焦点色**＋**清透纯色文字**＋**大片敢留白呼吸**；
  3. **通用电影级代码物理光影质感 6 要素（适用于浅调/纸感/暗调一切世界观）**：
     - ① **空间透视与景深退让**（焦点锐利，背景柔和退让，拒绝 0° 死贴屏幕的纸片框）；
     - ② **唯一方向自然主光与细腻受光切边**（柔和侧光、1px 精准受光棱边与克制表面质感回弹，彻底消灭无光死平面）；
     - ③ **双层真实阴影**（紧贴底面的短距深接触影 + 宽距柔和环境散射影，让实体真正落在空间里）；
     - ④ **表面微材质与真实信息密度**（哑光石膏/拉丝金属/温润纸齿/雾面亚克力微纹＋真实信息层级，零 85% 空箱、零无意义圆点、零灰条骨架屏）；
     - ⑤ **大胆取景尺度与呼吸留白**（在全景秩序、近景剖面与贴脸特写间果断拉尺度反差，绝不永远两米外居中平视）；
     - ⑥ **高频利落转变与音画合流（Chion Synchresis）**（靠景别切换、形变、匹配接力与剖面穿越推进，声音赋予实体物理重量并守住人声清晰主权）。
- **行动**：在前三维全部立稳后，在表皮层专做**减法精雕**——校准每级字重清晰度、洗去多余光晕与装饰杂线、检验去色明度层次、严守底部双语字幕安全区。
- **结果验真**：拿给不懂设计的普通观众看——脱口而出的是**“好清透、好高级、一眼就明白了”**，而非“这特效/这字好花哨”或“黑漆漆有点累眼”。

### 1.5 镜头情绪、运动物理与剪辑执行细则（Mercado/Katz × Bordwell × Murch × Chion）
- **大场（Scene）按“认知或情绪价值转向”划分**：入场前态 A 经演化抵达后态 B 为一大场，**绝不按固定秒表硬切**；大场体量过大易致单次注意力稀释时，按自然子命题拆为首尾相接的子场（`s03a` → `s03b`）。
- **小拍（Beat）以“观看完成点”定长短并杜绝呆板站桩**：
  - 只要画面继续停留仍在积累等待、压迫、连续物理演进或情绪余韵 → 保留长拍甚至刻意静默 `HOLD`；
  - 一旦观众已看懂本拍变化 → 立刻通过**景别切换、内容形变、构图重组或剖面穿越**推入下一视觉增量，**零容忍连站数秒只有微弱漂浮的空拍**；靠长呼吸蓄压、段落递减加速、爆发前抽空憋气与短促重击拉出起伏（口播严守 `ASRcut` 实测词锚，音乐片守 BPM 拍格）。
- **六条电影情绪律**：
  1. **景别与心理距离（Mercado / Katz × Hall）**：主动在远/全景（尺度秩序）、中景（结构对照）、近景/极近特写（强迫聚焦、压迫感、放大质感细节）间制造跳切反差，拒绝全片死守平视中景；
  2. **运镜方向与情绪动势**：先问固定机位是否已足够笃定，需要动时选缓推、急推、拉远揭示、Z 轴纵深穿越、微倾失衡（±8° 内）、短促受震或分层视差，明写起止构图与停点，全元素共走同一虚拟相机矩阵；
  3. **速度五变量与物理弹性**：分别定① 物理性格（`snap` / `spring` / `glide` / 12fps 拍二步进配顺滑相机）；② 预备、过冲、错峰与挤压拉伸；③ 顺势连贯 vs 逆向阻断撞击；④ 快速运动 180° 快门模糊（`--subframes 4` 或定向拖影）；⑤ 完整可读停留窗；
  4. **唯一方向主光与材质受光**：每场锚定唯一主导光源方向与光质，统一接触影、边缘高光回弹与自然空气层，保证主体与背景明度分离；
  5. **双端零重演与七种内容转变/剪辑载体（Murch 六法则）**：前拍收在未完动势、母形或声尾，后拍直接承接并立刻给新认知证据；按需选**形状变形（Morph）/ 图形匹配（Match Cut）/ 穿孔穿越（Zoom-through）/ 建筑剖面下潜 / 景深交接 / 动作匹配 / 硬切反差 / J-L 声画桥**，禁用默认淡入淡出。冲突严守 **Murch 优先序（情绪 > 故事/理解 > 节奏 > 视线落点 > 二维平面 > 三维连续）**；
  6. **音画合流与静音抽空（Chion Synchresis）**：声音赋予图形物理重量与材质真感；转场揭开帧用 `revealOn` 倒推起点精准踩拍，高潮前敢抽空声画憋气再同帧炸开；口播片永远守住人声清晰主权。

### 1.6 代码强项判断与全栈渲染引擎选型矩阵（做质感最无敌的，避开塑料低模雷区）
**先判题材需要什么视觉质感，再选代码能把该质感打到天花板的引擎**——绝不为了“听起来高大上”盲上裸模 Three.js，也不一刀切全塞 Canvas 2D：

| 渲染引擎 / 工具层 | 代码绝对封神的主场（何时质感最无敌？） | 明确翻车禁区（何时少用或严禁硬用？） | 质感必达工艺门槛 |
|---|---|---|---|
| **DOM / CSS 3D + SVG** | **实体建筑/光学空间界面与高保真产品界面**（Apple/Linear/Dieter Rams 风格倾斜透视实体层、细腻微材质、1px 受光切边、真实代码/终端/UI 流转）、**克制高级的中文动态排版与编辑图解**、**高精矢量工程剖面与连续 SVG 路径描边/形变** | 成千上万粒子、复杂实时体积光、需要自由 360° 环绕观察的真三维实体 | **必过物理光影 6 要素**：严禁扁平纸片 `div` 贴正面、严禁 85% 空白配装饰圆点、严禁灰条骨架屏；须配双层影、受光高光边、真实信息密度与景深层次 |
| **Canvas 2D** | 精密几何与拓扑形变、数学曲线、流动主脉轨迹、规整数据图谱、建筑剖面透视与材质微粒、合成遮罩（`multiply` / `destination-in`）与**程序化精密工程剖面纹理** | **严禁手画写实人物、手部、动物、厚重插画（简笔画重灾区）**；大面积高开销实时模糊 | 善用离屏纹理、多层柔和自然光与微噪点防色带；可作内容层送入 WebGL2 叠加光学后期 |
| **WebGL2 片元着色器（GLSL）** | 液态/流体光场、折射玻璃与材质微粒、噪声大气场、SDF 丝滑形变、CRT/半调、**克制局部景深与自然光散射** | 直接从零手写中文排印与复杂 UI | **高级质感的放大器**：把 DOM/Canvas/SVG 画清的内容或独立背景光场经着色器赋予真实光学呼吸 |
| **Three.js（真 3D）** | **仅在真需要多角度三维空间穿行、大型实例化建筑/阵列、真实折射玻璃/金属 PBR 物体或 3D 挤出巨字时启用** | **严禁无外部 `.glb` 高精资产时，用裸 `BoxGeometry` / `CylinderGeometry` 硬捏复杂写实场景、建筑或五块雷同圆角砖叠罗汉（2005 塑料玩具重灾区）**；严禁纯平面/轻透视卡片硬套 Three.js | **启用即锁死 4 项 PBR 硬门槛**：① `PMREMGenerator` / `RoomEnvironment` 真实环境反射贴图（防金属发黑发死）；② 程序化高精 `CanvasTexture` 表面微纹理（电路/栅格/拉丝/粗糙度/自发光）；③ 非均匀真实工业轮廓（镂空、台阶、内壁厚度、异形错落）；④ 光学后期（微 Bloom/景深/层次光）。四项做不到位，立刻改用 CSS 3D + SVG + GLSL！ |
| **p5.js + p5.brush** | 明确需要水彩、彩铅、蜡笔纸齿的有机手绘题材（`floor(t * 12)` 拍二步进笔触配顺滑相机） | 常规科技/商业/长篇快节奏讲解片 | 启用前先测单帧毫秒数，实例模式 `noLoop()` 由 `render(t)` 驱动 |
| **真实影像 ＋ FFmpeg 后期** | 真人实拍 A-roll、真实软件录屏、用户真实照片/头像/Logo、高精摄影素材叠代码运镜与排版；全局 `--grain 4–8` 胶片颗粒、`--subframes 4` 180° 运动模糊、`--dpr 2` 超采样 | 无原件时伪造假日志、假报告或假界面冒充现实证据 | 胶片颗粒交 FFmpeg，不在页面逐帧画噪点；实拍/视频严守确定性帧定位 |

### 1.7 原生闭环与资源缺失破局原则
- **彻底去除跨媒介生图代画方向帧**：默认全链路在原生代码媒介内闭合（用本地 OpenMotion 参考原图做视觉音叉，直接由选定代码引擎实渲 1920×1080 真实代码 PNG 定妆帧给用户亲眼拍板）。
- **本地资源库不匹配或资源缺失时**：① 绝不为凑资源 ID 强套不合拍风格/动效/配乐；② 直接回到上述四维 4×4 架构与代码主场引擎做纯粹原创或拆件重组（受管工程如实登记 `resource-mode: original-only` 或仅绑定确有增益的字体/算法）；③ 缺失真实照片、品牌原件或一手数据原件时，诚实标清缺口或改用明标「机制示意」的抽象视觉载体，绝不伪造现实证据。

## 2. 四步升维策划流（分场独立推演，打通 Brief → 执行交接）

### 第 1 步 · 灵魂定盘、筋骨白盒与分场地图（先立高维，再下血肉）
接过输入或 [pre-analysis.md](pre-analysis.md) 拆骨底盘后，先在极轻上下文里定三件事：
1. **极薄《灵魂定盘卡》**：由 1.1 推导出唯一最终心情（Aha! 顿悟与感官温度）、美学世界观路线（单风格 / 受控融合 / 带桥跨风格）与**明确主动排除的刻板皮肤**；
2. **极薄《筋骨白盒分场地图》**：按 **McKee 认知/情绪价值转向** 与真实 `ASRcut` 时钟划出全部独立场次，每场只写清逻辑关系原型（垂直承重 / 主脉分叉 / 表里剖面 / 状态演化）、视觉强度水位与首尾视线接力方向；
3. **核心血肉物理母体与全片共享总纲卡**：由 1.3–1.4 锁定贯穿全片的 1 个物理隐喻母体（重量/材质/透光度梯度）、字体「引而不抢」字重基准、主光色与声音情绪弧——确保分场并发后拼起来仍是完整一部作品。

### 第 2 步 · 逐场双阶升维（先盲起保原生上限 → 再自由查库双输入否定升维）
**每次只在轻量聚焦上下文里攻克 1 个场次**（只带入 `全片共享总纲卡` + `本场真实口播词锚/意图` + `上一场尾态交接卡`）：
1. **2A · 裸脑盲起极薄白描初稿（不看任何参考库）**：放开原生创意，按观看完成点、光学质感 6 要素与镜头转变语法快速写出极薄白描构想（拆清每 1.5–3 秒的视觉推进、景别切换、内容转变、起落交接）——**不堆文艺散文形容词**。
2. **2B · 自由查库 × 双输入否定升维（不限次数，服从本场成败）**：把 2A 白描当待升维粗糙输入，按本场真实瓶颈自由查阅本地五大库（纯方案用 `resource-overview` / `resource-search` / `resource-fulltext` / `audio-map`，受管工程用 `input-map` / `input-candidate`），**并必须用 `read_file` 亲眼查看候选参考图（OpenMotion 6 帧实拍图 / 风格预览图）**，从中扒出具体的光学质感、构图胆量、镜头切入或运动算法：

| 本地参考库 | 解决什么真实瓶颈 | 正确借法（扒光学与构图骨头，绝不只是抄名字） | 警惕退化与缺失兜底 |
|---|---|---|---|
| **风格库（75 套）+ Atlas** | 表面材质发平、光影层次薄、滑向默认皮肤 | 亲眼看样张，记下它的**受光方向、明度层级、无框标注工艺与微纹理**，并对照「最俗版本」翻掉平庸套路 | 绝不拼贴多套打架风格；不合拍时回 6 要素原创 |
| **OpenMotion（按本机目录取材）** | 卡片扁平、构图保守、镜头站桩发呆 | 亲眼看 **6 帧参考原图与阶段时序**，精确拆出“卡片怎么斜切进景深、怎么扫光、怎么切全屏反色”，并把**原图路径写入本场 Brief**供执行 Agent 读图对标 | 看完即换成本片总纲色盘与真实内容，零抄主题 |
| **Motion Prompt（240 套 MIT 源码）** | 具体动效曲线、形变、数据流数学实现难 | 读 L2/L3 源码抽纯函数数学路径与缓动节奏，融入本片舞台重写 | 绝不把原始小方框 `contain` 硬贴成贴纸 |
| **字体库（62 款）** | 中文字体性格平庸、缺字或版权隐患 | 带本片真实完整原句实测检索，用字重与字族性格强化口气 | 缺特种字源按授权引入合规字源，等宽字不绑汉字 |
| **音频库（137 条 CC0）** | 画面缺物理重量、转场绵软或情绪平淡 | 成品优先、短片慎碎切；拟音只落受力/转场/反转帧（详 [showreel-sound.md](showreel-sound.md)） | 缺对味时由具备实听能力的执行者原创混搭实听迭代 |

带着参考原图视角**敢于直接否定 2A 初稿**中站桩、扁平或选错引擎的设计，选定本场最出彩的代码渲染引擎栈，落成下方第 4 节的**本场可执行三段式指令书**，并抽出本场「尾态交接把手」喂给下一场。

### 第 3 步 · 独立高维总审与场间拼缝（清空过程包袱）
全部场次三段式出齐后，剥离过程草稿，站在**总导演＋剪辑师**视角通审「全片共享总纲卡 ＋ 全部场的独立三段式指令」，连查五关并原地修订定稿：
1. **交接可执行度（防“Brief 与执行两张皮”）**：检查每场是否已把空泛形容词替换成**可编码的光学质感工艺单、真实信息密度定义、镜头切换/内容转变机制与参考原图真实路径**；
2. **场间关键帧咬合**：核对每处「上场尾态交接把手 → 下场首帧承接态」是否在图形、透视、色块、运动方向或 J/L 声画桥上双端零重演严丝合缝；
3. **镜头密度与节奏呼吸**：消灭任何连续 3 秒以上无景别变化、无内容形态演进的发呆站桩拍；核对爆点前后蓄压与反差落差；
4. **代码强项与退化红线**：核对每场引擎选型是否落在代码质感最强项，一票否决裸堆塑料 `BoxGeometry`、空壳扁平白卡、灰条骨架屏与 Canvas 简笔画；
5. **可读性与口径零自打脸**：核对屏显字停留窗、底部字幕安全区零碰撞、真人隐身与口型、无原件事实标示意、无词锚预估时刻带 `~` 与 `[待词锚校准]`。

## 3. A-roll 与 B-roll 四档调度与高风险内容保真

### A/B-roll 四档调度（Murch 优先序：情绪 > 故事 > 节奏 > 视线）
| 档位 | 适用时机 | 画面组织 | 进出衔接 |
|---|---|---|---|
| **1. A-roll 主导**（真人全屏/微推） | 情绪直击、吐槽反差、亲历讲述、金句与建立信任 | 舞台还给活人，重音处轻微慢推或空侧极轻短钉字 | 顺人声气口与视线呼吸 |
| **2. 画中画 / 局部叠加** | 真人边讲边指认结构、对照指标、关键数字或证据 | 预留真人重心与干净图形区，随词锚长出并收束；不遮脸不压字幕 | 随话音轻入轻退，背景连贯 |
| **3. B-roll 全屏接管** | 底层原理、多步因果、数据冲击或签名爆点 | 代码动画全屏演透，过遮字检验，明起态 → 过程 → 落态与读窗 | J-cut 提前声带画入；L-cut 留尾音交回 |
| **4. 真实录屏聚焦** | 产品演示、软件实操、代码输出与真实反馈 | 以真录屏作舞台，虚拟相机推近真实触发与结果区（周边压暗、隐私用随动纯黑实心条） | 以真实操作变化为切点；仿绘必标示意 |

长口播不长时间死盯固定机位，也不无故狂切；真人贯穿型混剪口播片默认避免真人中段连续隐身过久。

### 高风险内容保真速查（Tversky 一致性与可理解性原则，纯情绪/无数据片不硬套）
| 类型 | 必须演清 | 翻车红线 |
|---|---|---|
| **因果机制** | 触发条件 → 可追踪中间过程 → 后态变化 | 相关/先后不画因果箭头；无来源步骤不伪造 |
| **同口径比较** | 共用零基线或同输入参照保持可见，分离高亮差异 | 异单位/异口径不强拉同轴；不以面积速度夸大 |
| **数据数值** | 自带对象、单位、分母/时段与基线；柱图从 0 起 | 截断纵轴必标明；示意曲线必标非按比例 |
| **步骤流程** | 区分因果、时序与并列目录；每步看见前态交后态 | 纯并列目录不硬画成因果流水线 |
| **组合机制** | 具体输入 → 各自可辨贡献 → 合成更新目标后态 | 不画空框而目标不动；无实测权重标教学示意 |
| **反馈循环** | 结果与目标差距 → 连回同一被更新对象 → 下轮真变 | 不画空转搬运死循环 |
| **类比比喻** | 只动画化成立属性，失效处及时退出 | 不把类比无关装饰延伸成错误科学结论 |
| **档案证据** | 真截图/照片/文档标来源与语境 | 缺原件不以生成图或高仿拼贴冒充，必标示意 |

## 4. 双轨交付版式、可执行单场三段式格式与 `brief.md` 工程契约

### 给人类审阅 vs 给下游执行的双轨呈现
- **上半段·给人看的导演提案（自然 Markdown 3 秒扫读）**：核心判断前置，按「全片视觉世界与光学质感定位 → 分场地图与镜头节奏弧 → 选定参考坐标与换血思路 → **需你拍板的关键决定**」清晰呈现，100% 直白导演人话，绝不混入 XML 机器字段、内部枚举或文字墙；
- **下半段·给工程执行的 `brief.md`（独立完整代码块）**：在聊天中用单个独立 Markdown 代码块包裹完整 `brief.md` 供一键复制（写盘剥离外层围栏）。

### 受管工程 `brief.md` 八块契约（极简工程壳 ＋ 可直接落像素的三段式分镜核）
新项目维护项目根唯一 `brief.md`，闭合八 XML 块（`<role>`、`<inputs>`、`<confirmations>`、`<direction>`、`<structure>`、`<build>`、`<gotchas>`、`<start>`），**正文严禁残留 `……` 或 `待填` 字样**。把繁杂字幕和词锚交给后台 `caption-source` / `timeline.json` 自动消费，绝不往 `brief.md` 手抄逐条 `cue:` 字幕表：

- **`<role>`**：核心导演定位、目标观众与不可妥协的质感/事实边界。
- **`<inputs>`**：主题、唯一记忆点、真实素材/原稿/锁定项、规格（默认 `1920x1080` 16:9；实拍/录屏先 `ffprobe` 锁帧率）、工作台与声部状态；有口播字幕时声明唯一 `caption-source:`（格式见 [typography-and-legibility.md](typography-and-legibility.md#原生双语讲解字幕)）。
- **`<confirmations>`**：独立记方向定妆确认与最终预览/导出确认的真实用户原话与范围。
- **`<direction>`**：写入精炼的**全片共享总纲卡**（视觉基因、光学质感 6 要素底座、色彩极性逻辑与去色明度分离、唯一光源原则、字体声口基准、默认运动脾气、全栈渲染引擎主线、声音情绪弧与退化红线），并成行登记受管脚本所需字段：
  - `direction-name: <简洁中文方向名>`
  - `styleframe-source: code`
  - `resource-mode: 2`（自由借库升维时绑确有增益的已读 L2 资源；锁单一主风格写 `1` + `primary-style` + `resource-selection-quote: 原话`；锁外部对标写 `3` + Benchmark 本地来源与 SHA-256 + `benchmark-selection-quote: 原话`；原创或资源缺失写 `original-only` + 说明依据或原话）
  - `resource-use: <stable-id> — <具体借用的光学工艺/构图尺度/运动算法，作用于本片何处，翻掉了什么俗套>`（纯原创可省）
  - `motion-probe: required; reason: <具体待验连续过程>`（探索期 `--phase explore` 工程脚本硬校验 3–6s 且覆盖至少一个 `explore-moment`）或 `not-required; reason: <理由>`
