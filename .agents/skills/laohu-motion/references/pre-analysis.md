# 动画前置内容拆解清单（配合 `laohu-analysis` 第一棒）

接到完整新片、口播稿、ASRcut 时间轴、长录屏、真人 A-roll 混剪、多源资料或整体重设视听方向时，由 `laohu-motion` 调用 [laohu-analysis](../../laohu-analysis/SKILL.md) 配合本清单完成第一棒拆骨。局部小修、已有方向续做或极简 4–8 秒单概念循环小动效跳过本清单。

**唯一职责**：把原始输入拆成干净、扎实、无逻辑硬伤的内容与视听底盘交回 `laohu-motion`。**本阶段不打开风格库、不选字体、不抄 XML 表格、不写像素坐标**——把审美想象与双阶查库升维留给下一棒，防止过早被模板锚定。

---

## 1. 先核材料身份、真实时间与硬边界

1. **辨清输入形态与权限**：标明手头有哪些真实素材（文稿、原录音、ASRcut 编译结果、SRT、真人出镜 A-roll、实操录屏、图片/PDF、品牌规范），划清哪些文字、数字、原音或顺序被用户逐字锁定、哪些可删减提炼、哪些仍是开放创作。
2. **只吃真实时间精度**：
   - 若项目已有与当前音源匹配的 ASRcut 输出（`animation-handoff.json` / 编译时间轴 / edit plan / SRT），直接读取真实成片 `targetRange`、句子边界、`narrativeBeats` 中的 `emotion`、`energy`、`pacingNote` 以及作者词锚 `visualCueCandidates`，切勿只看摘要忽略词级字段；
   - 仅有句段 SRT 时保持句段精度；只有文稿无录音时按语义与阅读需要给暂定预算并标明待对齐；无口播短片直接按视觉与情绪节奏组织，不造空旁白。
3. **拆开三类决定不混为一谈**：原稿删留改写是内容决定，镜头怎么演与停留多久是导演决定，实际剪音或插入无声展示时段是时间线修改（涉及剪音须回 `laohu-asrcut` 授权执行，不为了画面方便擅自剪坏原声）。

## 2. 定立意海拔、判需求三态与挖逻辑暗坑（拉开与裸模型差距的关键）

1. **穿透表层需求、分清三态与可换血外壳**：先确认用户要求落入哪一态——若用户已给出同向且清晰的视觉或结构方向，完整承接；若表达模糊，主动补齐专业海拔；若字面要求夹带明显违背视听规律的表皮做法（如把整篇文字逐句铺满大字卡片、要求每词加特效图标或硬塞满屏框线粒子），**分清真实事实/逐字锁定底线与可换血视觉外壳**，穿透挖出用户真正想要的情绪或表达目的，标出换血替代建议交第二棒与用户拍板，绝不顺着平庸前提把错路写实。
2. **钉死立意海拔与唯一记忆点**：剥掉废话和铺垫，判断这支片子该站到哪一档——是只做信息传达，还是能挖出直击观众切身处境的底层机制或反常识真相（讲解与概念片力求一镜见机制／见情绪，不滑回流水账或平铺名词图解）。钉死观众看完唯一要带走的那一个认知改变或真实感受。
3. **锁定 1–2 处核心张力翻转点**：找出全片最让人屏住呼吸、认知反转、情绪破防或真相豁然开朗的 1–2 个关键节点（以及前 1.5 秒必须立住的视觉悬念），明确交给下一棒的爆点脑优先独立锻造，避免全片按平缓讲解节奏一路顺写变平（纯平实实操或静谧体验片按自身节奏标出核心观察点，不硬造戏剧反转）。
4. **抓出高风险事实与逻辑陷阱**：扫描原稿里所有承重数字、比例、因果判断、比较口径、时间线、产品实况与类比比喻：
   - 相关或先后绝不默认画成因果；
   - 比较必须核对同单位、同口径与零点基线；
   - 缺失证据原件或未核实数据立刻标成待核或改走明确标注的机制示意；若台词提到日志、报告或档案但手头并无真实文件原件，明确界定画面只做机制示意绝不冒充真件；条件允许时主动核查其背后一手研究方向与指标口径（如是否把继续率记反成放弃率、是否混用不同口径分母，仍诚实标出未读原文边界），绝不让下游画面把猜想画成铁证；
   - 若为修补硬伤而建议局部补录 2–3 秒纯画外音干声，同步核查该时段是否安排真人露脸——露脸段必须给出藏嘴画面分支（切满脱敏录屏或图形板）并叮嘱同环境底噪（Room Tone）接缝防换声；
   - 类比只划出真正成立的对应属性和失效边界。
5. **查必要解释缺口（Mayer 认知负荷与双通道冗余原则）**：站在目标观众（未指定时默认聪明但不懂行话的普通人）视角，找出只听原话会卡壳的地方——缺的是具体实例、尺度参照、前后状态对比，还是从输入到结果的中间环节？标出画面真正该补上的那一环，去掉纯复读口播的废画面。

## 3. 划分内容单元、情绪曲线与 A-roll / B-roll 分工

1. **按认知或情绪价值转向划场（McKee）**：不按句号、字幕条或固定秒数机械切镜；观众完成一次“前态 → 后态”实质理解或情绪转移即归为一完整场次，单个大场体量过大可能引发注意力稀释时再按内部子命题拆为连续承接的子场。
2. **标出全片情绪与能量起伏**：顺着原稿语气（或 ASRcut 的 `emotion` / `energy`）勾出张力—释放弧线——哪里前 1–2 秒钩住注意，哪里蓄压铺垫需要收低水位，哪里密集讲解需要克制稳推，哪里必须留白停顿让信息沉下去，哪里是认知反转或情绪爆发的最高潮。
3. **按默奇剪辑优先级排定 A-roll 与 B-roll 职责（有真人出镜或实操录屏时必做）**：以情绪共鸣 > 内容推进 > 节奏呼吸 > 视线落点为裁决序：
   - 情绪直击、吐槽反差或强信任感段落 → 保留真人 A-roll 主导，不轻易切走或用重卡片盖死；
   - 真人边讲边指认结构或关键数字 → 画中画 / 分屏 / 轻叠加人画共生；
   - 肉眼看不见的底层原理、多步对比、数据冲击或高潮视觉奇观 → 交给代码 B-roll 全屏演透；
   - 真实软件操作与系统反馈 → 保留真录屏作舞台，标出推近聚焦的真实触发点与结果（同时注意长片中段避免让真人连续隐身超过半程）。

## 4. 交付给 `laohu-motion` 的极薄白描底盘（6 项直接接手）

分析完成即交回 `laohu-motion` 接管全场，产出紧凑的 6 项白描底盘（聊方案直接融入导演提案思路，建工程则沉淀入 `brief.md` 对应块）。**严守白描交接防反向污染**：只写清真实事实、核心冲突、情绪节点与观察任务，绝不堆砌空洞的文艺气氛形容词污染下一棒的视觉构思与编码：

1. **核心任务、立意海拔与唯一记忆点**：受众、用途、片长/画幅规格、目标海拔与观众必须带走的一句话或一个感受；
2. **锁定项与风险提示**：不可改动的原稿/数据/素材、已核与待核事实清单（含可能口径溯源）、类比或口径边界；
3. **真实时间底盘**：当前时间依据（无口播 / 语义预算 / 句段 SRT / ASRcut 真实时间与词锚版本）；
4. **有序内容单元与张力曲线**：每个单元的起止范围、观众前态 → 新增理解或情绪 → 落态、能量强弱、停顿留白与 1–2 处核心翻转爆点位置；
5. **A-roll / B-roll 与声部职责初稿**：实拍/录屏与动画的进退切点，旁白、音乐情绪走向、功能音效与刻意沉默的分工；
6. **核心视觉命题与真实素材缺口**：提炼本片最难演、最决定高级感的画面难题（例如抽象机制怎样转译为代码最擅长的视觉载体而不滑向简笔画），同时明标哪些真实原件/图片/数据缺失须按机制示意处理，交由 `laohu-motion` 在逐场盲起与自由查库双阶升维中攻克。
