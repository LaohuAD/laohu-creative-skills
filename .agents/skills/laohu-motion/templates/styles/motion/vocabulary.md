# 动作与时间语言

这份短参考把 Motion Prompt 的术语接到本项目的时间线。术语帮助说准“发生什么”，不代替镜头里谁在动、动作怎样改变信息、何时停住或怎样离场。

## 描述一个动作

为每个动作说清五件事：

1. **对象**：具体是标题、图表、图层、镜头还是一组元素。
2. **前后状态**：动作开始前观众看见什么，结束后发生了什么。
3. **路径与阶段**：从哪里到哪里，是否分段、交错、过冲、变形或沿镜头轴移动。
4. **时间性格**：何时起步、快慢如何变化、是否停留、怎样退出；秒数属于该元素的局部时间。
5. **内容关系**：动作揭示、比较、解释或推进了什么，怎样交到下一镜。

只写“Stagger + Morph + Zoom”没有对象、状态和时机；把这些关系写出来，后续执行者才能判断术语是否真对应画面。

## 术语用于什么

- **入场**说明元素怎样进入可见区域。指定方向、遮罩边界、起始尺度或是否有回弹；不是所有入场都要弹跳。
- **交错**说明一组元素如何按次序错开。要指出顺序、间隔和被引导的观看关系；仅仅把多元素分时出现称为交错，不会自动形成阅读顺序。
- **描绘/生成**说明线条、数值、形状或文字逐步显露的路径。要保留源代码定义的绘制方向、阶段和停止位置。
- **缓动、过冲、弹簧**描述速度曲线和回弹特征。它们不是通用替代品；原实现若包含分段、回弹或反向行程，不能压成单一 ease-out。
- **变形、重排、液态融合**描述对象结构或轮廓的改变。要指出起点与终点是否在语义上成立、哪些边缘/锚点需要保留。
- **镜头运动**改变观众相对主体的位置、尺度或视线。说明镜头移动与主体动作的关系，避免把镜头词当作元素位移动作。
- **视差/景深**依赖分层及层间不同速度或深度。没有可用的前中后层时，不把单张图整体平移称作真实视差。
- **转场**连接两个明确状态。指定何时遮挡、揭示或交接；两个全屏效果不能只因各自可运行就叠在一起。

## 局部时间、循环与停留

每个 Motion Prompt element 都接收该元素的**局部秒数**，并是时间的纯函数：同一输入时间应得到同一帧。`draw(ctx, w, h, t)` 不读取墙钟、不累加上一帧状态；视频逐帧、重复和乱序取帧都按传入的 `t` 重算。

运行适配器默认按该 pack 声明的周期循环。单次使用时可选 `once`；停留时用 `hold` 并明确源周期中的停留时刻；需要保留源退场时，用 `hold-exit` 同时指定停留源时刻、影片时间线上开始退场的时刻和源代码退场开始时刻。三者是不同时间轴上的值，不能因为句子长短而一起拉伸。

当作品时长短于源动作必需阶段，先读取 L2 条目和 L3 源码，再决定局部适配。保留原路径、阶段和曲线；改变后用连续小样检查起点、衔接、停留与终点。

## 画幅和代码边界

源示例主要按横向卡片画幅绘制。适配器在目标区域中等比 `contain`，会留边，但不压扁或拉宽字形、圆形和轨迹。若本片需要满屏构图，应重新设计内部排版或裁切，不应把比例变换交给非等比缩放。

每个 pack 的 kit 和 24 个 element 在同一模块闭包里，避免诸如 `C`、`CELLS`、离屏画布等名字互相覆盖。绘制前后使用 context `save/restore`；离屏层在每次绘制中按源实现重置。源码中的背景、字体、颜色、示例文字和图像处理都是该条目的实际行为，替换前逐项检查。

有源代码只表示该动作可被调用，不表示它已匹配本片的素材、字号、构图、透明度或叙事目的。视觉和连续性仍需检查真实输出。
