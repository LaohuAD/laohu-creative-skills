# 投影默片（projected-silent-film）

> 一句话：手绘银灰影像置于影院幕框与丝绒侧幕之间，以无对白字幕卡和现场感钢琴讲故事。

> 来源参照（只学语法）：
> 一部在电影院放映的版画插图默片：墨线与银灰水洗，4:3 印片在丝绒幕布之间闪烁、摆动；以字幕卡代替人声，由影院钢琴师为每个动作配乐。
> 参考（只学语法）：**Buster Keaton** 的 *The General*（1926）和 *Sherlock Jr.*（1924）——一个固定全景呈现完整笑料，面无表情，身体承担表演；**Harold Lloyd** 的 *Safety Last!*（1923）——险些错过的瞬间；**Georges Méliès**——虹膜遮罩与魔术镜头；*The Artist*（2011）——现代观众需要多么少的字幕卡；**1920 年代剧情片钢琴提示谱**——按情绪段落安排音乐，让钢琴承担拟音。不得采用流浪汉造型（圆顶礼帽、牙刷胡、小手杖），不得挪用任何真实电影的笑料，也不得使用已发表的旋律。

## 本质 / 不是什么

一卷看起来像是正在**放映**的电影：
- **一张 4:3 印片置于影院幕布之间的片门中**；16:9 画面的两侧就是电影院空间。
- **以墨线和淡灰洗绘制的图像，并带交叉排线**；印在银色胶片上，边缘会闪烁、摆动、划伤和烧蚀。
- **没有人说话。**节拍由**全景中的动作**和**字幕卡**讲述。
- **唯一的声音是影院乐器**（钢琴、管风琴）和放映室里的放映机。

这不是黑色电影（不以硬阴影营造情绪，也没有旁白），不是给现代动画套棕褐色照片滤镜（画面本身要经过版画式描绘和墨线处理），也不是卓别林仿作。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 来源正文中的可见/可操作描述 | 适合的主题 |
|---|---|---|
| 影院4:3门框 | 1440×1080画面置于16:9中央，圆角门片与幕布进入构图。 | 投影感、时代片 |
| 描绘式灰阶 | 以墨线、淡灰洗和交叉排线重画画面，不是现代动画加棕滤镜。 | 默片、寓言、工艺 |
| 银色印片 | 亮部晕光、片门摆动、闪烁、划痕和银盐颗粒构成媒介表面。 | 怀旧投影、档案感 |
| 16fps表演与24fps片面 | 人物/相机在16fps采样，印片纹理每个输出帧变化。 | 手摇摄影机感 |
| 字幕卡替代对白 | 少量情绪边框字幕卡承担旁白和对话，画面不重复解释动作。 | 无对白叙事 |
| 宽景身体表演 | 固定全景让动作因果成立，脸部近景克制。 | 物理喜剧、追逐 |
| 钢琴或管风琴 | 乐器承担动作拟音，投影机成为持续环境声；不加对白和拟音层。 | 影院默片语法 |
| 按段落变色 | 银灰为主，可按情绪换印色或只让一个主题对象保留颜色。 | 转折、温柔段落 |

列出的信号均可在来源正文中定位；每支按主题挑 2–3 个，至少一个避开最常见组合，不把信号全部堆在同一支片子里。

## 这个风格最俗的版本

来源没有给出一套可跨主题复用的固定俗套组合，因此不补造。风格特征与明确排除项保留在上面的本质说明中；具体故事、时间线和段落仍按新主题重新设计。

## 适配

- 用途：需要默片表演、时代投影媒介、身体喜剧或无对白叙事的短片。
- 内容：只借用下方可复用媒介规则；人物、故事、事实、镜头顺序和时长按本片目标重新设计。

## 技术路线

本节列出的源码文件/函数名用于定位来源工程的实现示例，不是本地 API；Motion 可按本片需要使用原生工具实现其中的视觉方法。

来源实现示意：

在 `demo/engine/` 中：`ink.js`（色调形体、墨线、洗染、排线；`drawShape()` 按此风格绘制任意路径）、`redraw.js`（`Redraw`：色调绘画或实拍素材 → 墨线画，使用 WebGL2）、`film.js`（`FilmPost` 印片处理和 `damage()`，可叠加在任意 2D canvas 上，并可选用颜色遮罩）、`cards.js`（字幕卡、装饰边框、虹膜遮罩、影院）、`figure.js` 与 `heads.js`（2.5D 骨架）。`demo/timeline.js` 是同时驱动画面与配乐的提示谱。API 表格和最小示例（一个单色形状经过完整处理管线）见上游 demo 引擎参考。

## 材质与渲染

- **色调绘画 + Redraw。**场景只用灰度绘制（印片密度大致为：墨色 0.07、深色布料 0.15–0.3、中灰木材 0.45–0.6、皮肤 0.8、白亚麻 0.9–0.95），配柔和明暗渐变和细分隔线。**Redraw** 处理（WebGL2）为整帧加墨线：每条边暗侧用高斯差分描出轮廓，亮度分为约 5 级柔和洗染，在暗部加 45° 排线（再交叉），每两帧重画一次，模拟手绘动画。实拍帧也可经过同一处理，让影像和绘画像出自同一只手。
- **印片处理**：银色调，棕褐量约 0.1–0.36，印片黑位约 0.055、白位约 0.93，S 曲线，高光晕光、密度不均、闪烁、片门摆动并偶尔出现齿孔跳动、断续的竖向划痕（白色代表乳剂被刮掉，深色代表底片上的污点）、从边缘蔓延的褐色烧蚀、暗角、双频银盐颗粒；之后加灰尘、片门中的毛发和罕见污斑。
- **画框**：1440×1080 置于 1920×1080 中央，圆角片门带柔和暗边；两侧丝绒帷幕由银幕反光和脚灯照亮。帷幕可以拉开、合上。
- **人物**：写实比例（成人约 7.5 头身，儿童约 5 头身），使用 2.5D 骨架（关节在 3D 中求解，再按偏航角投影）；默片时代妆容（浅肤色、深眼睑与嘴唇）；以剪影标记身份（帽子、衣物、工具）。

## 配色

- **银灰单色**，只由印片着色：事情变糟时更冷、更粗粝（损伤更多、棕褐更少）；转为温柔时更暖、更干净。按段落设定色调和损伤程度，让它们承担情绪变化。
- 明暗值承担全部表达：深色衣物对浅色墙面、暗室中的浅色脸；每个镜头都缩成缩略图检查。
- **最多一种颜色**：单独绘制到颜色遮罩的元素，可在印片处理后保留自身色相（仍带颗粒、闪烁和暗角）。只用于影片所讲述的那个对象，也可以完全不用。
- 整个场景采用时代着色（室内白天琥珀色、夜晚蓝色、浪漫段落玫瑰色）也可以代替棕褐色调；每个段落只用一种色调。

## 字体

- **字幕卡就是字幕**；`.srt` 文件列出卡片文字。每张卡停留 2.5–3.75 秒（不少于 `max(1.8 s, 阅读时间 + 0.6 s)`）。
- 黑色手绘字幕卡配装饰艺术边框，边饰随情绪变化：呼喊时用一条粗线（文字抖动）；旁白用转角阶梯和扇形纹样的双线；温柔段落用藤蔓和小花。
- 时代字体（OFL）：片名与呼喊用小型大写展示衬线体（如 Playfair Display SC）；旁白与对白用旧式斜体衬线体（如 Old Standard TT Italic）。
- 每张卡只写几个词；短片用三到五张卡。字幕卡不解释画面已经展示的内容。

## 运动

- **手摇采样**：人物和相机运动按 16 fps 采样（快速场景可用 18 fps 或更高，形成欠格效果）；闪烁、片门摆动、颗粒与划痕则在 24 fps 输出的每帧都变化。这种混合效果让它看起来像正在放映，而非单纯低帧率。
- **速度就是情绪**：追逐和惊慌段落降低格数，让动作和闪烁都更快；温柔场景回到 16 fps 和较平静的印片状态。
- **冷面表演**：脸几乎不变，身体来表演（发力前蹲下、保持姿势、双帧快速回头、双手撑膝）。物件也会表演（跌倒前摇晃、缓慢减速后停住）。
- 姿势用关键帧并缓动；只有刻意设计的笑料才突然跳变。

## 画面怎么活

动作采样为16fps；片面闪烁、门片摆动、颗粒与划痕在24fps输出中持续变化。主动作与印片纹理采用不同帧率层次，不能概括成静态风格。

## 镜头语法

镜头是一套词汇，不是固定路线。开场和结尾由主题决定。时代摄影机笨重，因此大多数镜头固定不动。

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 固定极远景 | 完整看见因果；等待本身就是笑料 | 机械笑料、人群、复杂流程 |
| 固定全景 | 一帧内看清前提 | 人物日常、对峙 |
| 前景掠过的跟拍 | 追逐、动势 | 追逐、比赛、与时间赛跑的递送 |
| 虹膜收拢 / 张开 | 注意力落在一处；一段想法的开始或结束 | 物件、面孔、记忆 |
| 虹膜半开并停住 | 人物与观众交换眼神 | 眨眼、秘密、默契 |
| 有动机的缓慢推近 | 温情、醒悟 | 下跪、读信、做决定 |
| 遮罩镜头（钥匙孔、望远镜） | 主观视点、窥探 | 侦探、好奇、浪漫 |
| 分屏 / 双重曝光 | 欺骗、梦境、两个地点同时出现 | 电话交谈、鬼魂、白日梦 |

构图以全景和中景为主；骨架人物的大脸特写会像人体模型，因此特写要小，或放在虹膜遮罩内。转场可用虹膜、淡至黑场、直接切换或帷幕。不要在同一场景镜头之间溶解，也不要用现代甩镜。

## 声音调色板

- **乐器就是声音设计**，如同电影院现场伴奏：立式钢琴（可选簧风琴、剧院管风琴、小提琴或小型乐团）为每个事件演奏。滑稽动作配乐的可选词汇：低音半音阶缓慢爬行（潜行）、装饰音（眨眼）、前臂刮奏簇音（撞击）、渐强减和弦震音（等待）、低音隆隆震音（风暴、机器）、“叮……咚”（空荡）、减和弦强奏（惊吓）、滚奏和弦（开门、揭示）、下行滑奏（跌落）、低音“boing”（弹跳）、紧张颤音（犹豫）、小二度（物件破裂）。
- **剧情片钢琴语汇**：左手行进低音；参照提示谱按情绪段落配乐（Hurry、Misterioso、Agitato、Tenderly、Maestoso）；主题旋律再次出现时要有所变化。只用原创音乐。
- **不加拟音，不加人声。****放映机就是环境声**：灯泡开关声、电机启动、抓片机构与电机的咕噜声、胶片在收片盘上拍打的声音。
- **静默**：音乐停止，只留下放映机声；用它框住一个停留的瞬间。
- **混音**：响度标准化前用轻度压缩收敛钢琴琴槌的瞬态（−14 LUFS）。颗粒放在画面里（mux grain 1）。

## 原生手法

可从下列菜单中选择故事需要的手法。

- **一镜到底的连锁动作。**A 触发 B，B 离开画面，观众等待；B 回来后撞上 C。*适合：*供应链出错、谣言扩散、鲁布·戈德堡式机关。
- **险些错过。**一只手恰好在物件刚才所在的位置合拢。*适合：*赶公交、创业公司错失交易、守门员扑救。
- **字幕卡反转。**字幕卡用几个词重新框定接下来的镜头。*适合：*“与此同时，在实验室里……”；“机器另有打算。”；把统计数字变成笑点。
- **欠格混乱。**速度和画面损伤同步上升。*适合：*早高峰、晚餐时段的厨房、股市崩盘。
- **虹膜中的眼神。**虹膜停在半开位置，让人物看向观众。*适合：*产品眨眼、心知肚明的猫、藏着秘密的科学家。
- **重画实拍素材。**真实视频经过墨线处理变成时代画风的图像。*适合：*公司档案、家庭影片、体育片段。
- **回声手势。**开头由一个人做出的手势，由另一个人重复并获得新含义。*适合：*老师和学生、交接、传统。

## 变化空间

由你决定类型（喜剧、情节剧、冒险片、新闻片）、人物、笑料或戏剧冲突、字幕卡、着色方案、开场和结尾。应远离来源示范片：

- 结构：**新闻片**（一连串“报道”，每段之间插入标题卡与旁白卡）；**三卷情节剧**（每卷采用一种色调：琥珀、蓝、玫瑰；安排反派卡与营救）；**魔术电影**（Méliès 式单一舞台、一位魔术师，物件通过替换剪辑出现和变形）。
- 开场：**追逐进行到一半**，电影已开始放映、画面已有划痕，还没有片名；**一张字幕卡提出问题**，再出现任何影像；**放映员视角**：先见放映室光束，再见银幕。
- 结尾：**胶片断裂**（印片烧穿，放映灯照出白光）；**最后一张字幕卡直接对观众说话**；**固定全景淡至黑场**，钢琴保持一个和弦。

## 坑

- **内容太多会毁掉默片**：小人物尺度下，多步连锁动作缩成缩略图只会变成噪声。一个清楚的连锁动作，中间留出停顿，胜过三个忙乱动作。
- **木偶手臂**：先做外展再做屈曲；手臂抬起时肩膀也要升起并前摆；抬臂一侧的躯干肩线要收窄；手臂盖在躯干上的轮廓要隐藏。让手臂向侧面举起（或转动人物），避免穿过脸部。
- **姿势跳变**：所有人物都由带缓动的关键帧列表驱动，不能用 `if` 分支切姿势。
- **道具漂浮**：把道具固定在两掌之间、处于双臂之间的深度；滚动物体的旋转要和移动距离关联（角度 = 距离 / 半径）。
- 眉毛朝向会随人物面向翻转：在成片尺寸下裁切检查表情。
- 相机缩放后，虹膜遮罩必须仍以影片坐标追踪目标。
- 抓取动作必须让手恰好在节拍点碰到物件，否则动作读不出来。
- 只由暗银幕照明的闭合帷幕会变成纯黑：加脚灯。
- 大量颗粒会造成文件过大 → 用更高 CRF 和 `-tune grain` 重新编码。
