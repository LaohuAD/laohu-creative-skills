# 丝印旅行海报（silkscreen-travel-poster）

> 一句话：不透明丝网印墨一层层揭示地点海报；套印与纸张本身也作为画面的一部分。
> 参照（只学语法）：本来源未列具体参照作品。

## 本质 / 不是什么

这是镜头前正在**印制海报**。每种颜色都是一次独立刮印形成的不透明墨层；后印的墨会完全覆盖先前墨层。没有半调点、荧光墨或线描：形状边缘就是一种平涂墨色的终点。**禁止渐变：** 天空和雾气必须用**阶梯色带**表现（先铺平涂色，再用逐渐变稀的条纹过渡到下一种颜色）。

它之所以看起来像丝网印刷，而不是平面矢量图：

- **套印：** 1080p 下，每一层错开 1–3 px；镂空形状会留下新月形的裸纸边。
- **叠印边：** 每种墨色下方约偏移 2 u 的淡淡正片叠底影子；墨色彼此搭接处会留下一道较深的细边。
- **墨层厚度：** 左上方有浅亮边，右下方有深色边，只用于填色；新印墨有湿润光泽，并在一秒内消退。
- **纸张：** 带纤维的奶油色纸张；纸色斑驳和针孔只在墨色上可见。

它不是 Risograph（半调颗粒、半透明荧光叠印），不是浮世绘（主版线描加ぼかし渐层），不是木刻（雕刻线条），也不是低多边形（3D 切面）。这种风格使用不透明、无线描、平面分层和阶梯色带。

## 材质与渲染

- **每种墨色使用一张 `Path2D`，**按当前变换的单位进行填色；镂空部分是路径里的孔洞。任何形状都可以印刷。
- **刮印显现：** 用参差的刮板前缘作裁切路径（拖印尾迹约 30 u）；刀片、墨珠和一小截手柄跟随前缘移动。
- **墨珠：** 圆管状墨珠带一侧高光、底部暗面、滚动高光和黏稠的丝状墨迹；分色供墨会让一个墨珠同时带多种颜色。
- **网框：** 带网布、感光胶层和胶带的铰接框；投影是环形（奇偶填充），绝不画成完整矩形。
- **形状：** 用参差受光切面画山脊，用一笔勾出层层下垂的松树，用平涂水面与亮条表现水。所有边缘都要硬朗。
- **海报模板**（1000×1500 u）：包含纸边、画面区，以及底部深色的**信息带**，用于放置名称、编号、分隔线和统计数据行；栏宽随内容调整。
- **纹理预算：** 细纸纹图块、约 55% 正片叠底的斑驳、约 75% 可见度的针孔，以及编码时加入的浅颗粒。纹理再多就会像 risograph。

## 配色

- **每张海报一套不超过 6 种墨色的配色，**按角色分配：浅天空、深天空 / 色带、远景、中景、近景（最深色，同时用于信息带）以及**一种鲜亮强调色**（太阳、路线、高光、关键数字）。可选一种受光面专色。
- **颜色明度从远到近分级变深；**深度由明度表达，绝不靠模糊。
- **强调色很少使用：**只留给太阳或光源、唯一一条路线或产品、最重要的数字。
- **纸张本身也是一种颜色：**未印的纸面是整张纸上最亮的部分（可表现水、雪或光束）。
- **系列海报 = 同一模板，每张换一套配色**（一天中的不同时段、季节、配色款、不同街区）。用新配色重印同一套几何图形，本身就在传递意思。
- 文字墨色按其下方墨色的对比度选择（遵循 WCAG），不能用固定配色；夜景配色不能吞掉标题。
- 配色示例（天空色 1 → 近景色，强调色）：黎明 `#F6CD98 #EE9A73 #9A7FA8 #3E7079 #1E3B3F #FBE6B4`；港口正午 `#E8F0F2 #7FB3C8 #D9C7A3 #2F6E8E #173247 #E8553D`；冬季 `#EEF1F4 #B8C9D9 #8B9BB0 #4A5D78 #1F2A3C #F2B134`。

## 字体

- 名称和数值使用**窄体展示字体**（如 Big Shoulders Display、League Gothic），自动适配宽度；字距拉开的标签使用几何无衬线字体（如 Outfit 600）。
- 标题印在**天空区域**并拉开字距；信息带最后印出。
- **海报文字就是字幕。** 不需要旁白；若有人声，字幕采用印在纸上的条带（一次刮印形成的色带），绝不使用悬浮字幕。
- **阅读规则：** 每段文字最后一个条目落定之后，仍保持至少 chars/12 + 1 s（最少 1.5 s）；有人声时，保持时间不少于 max(1.8 s, 语音时长 + 0.6 s)。根据文字内容计算，再向上取整到节拍。
- 墙上海报镜头中，标签在 1080p 下至少 18 px，数值至少 30 px；信息带特写要完整留在画框内，两侧至少留 5% 边距。

## 运动

- **每次刮印都保持线性、匀速**（刮板不做缓入缓出）。同一层的强调色墨比主墨晚半个节拍开始。
- **信息项**按节拍细分从左向右印出。任何地方都不做淡入。
- **网框抬起：** 网框绕铰链向上抬（竖向压缩 + 逐渐扩大的阴影），约 0.4 s。
- **重新换色：** 宽刮板约 0.35 s 内斜向掠过整张纸；刮板两侧的几何图形完全相同，只改变墨色。画面中只露出刀片、墨珠和一小截手柄。
- **松散分层：** 多平面运动时，各层按景深产生视差，层间留纸缝并带厚度阴影，随后在一次重音上**瞬间套准**。

## 画面怎么活

- 印完后的纸面和墨层保持稳定；刮板、网框、墨珠只在一次套印动作中移动。
- 多层画面只有在设计了层间位移时才产生视差，随后按来源在一个拍点套准；来源没有规定持续的待机微循环。

运动与循环描述来自来源文字 / 实现说明；本地尚未独立逐帧复现或核验，不作为本地渲染验证。

## 镜头语法

镜头词汇，不是固定路线。开场和结尾由主题决定。

| 镜头变化 | 表达作用 | 可用于 |
|---|---|---|
| 跟随刮板移动，轻微滚转，画面中能看到网框边缘 | 印制动作本身、色彩抵达 | 开场钩子、分色供墨形成的天空 |
| 锁定俯拍整张纸 | 层层堆叠成为完整图像 | 看海报逐步建成、做比较 |
| 网框抬起时快速拉远 | 揭示已经印好的完整层 | 场景完成、标题 |
| 推近并倾斜至信息带 | 阅读信息 | 事实、日期、价格 |
| 镜头沿画面空间穿过前景剪影（树、路灯、帆） | 进入下一张海报 | 海报与海报之间的转场 |
| 升降镜头穿行于松散的多层平面（多平面视差） | 深度、在印刷图像内旅行 | 路线、攀升、街道 |
| 沿一排印张缓慢横移 | 一组作品、不同款式或系列 | 系列海报墙、不同配色款 |
| 推进网布，直至能看到网眼 | 手艺、媒介的颗粒 | 拉近观众与工艺细节的片刻、局部细节 |
| 对数变焦后拉远至墙面或窗户 | 海报存在于现实世界中 | 最终定版画面（保持 ≥ 3 s） |

纸面特写需保留纸边；刮板经过特写时要倾斜并藏起手柄，避免手柄把画面切成两块。图层之间通过刮板改变；海报之间通过前景剪影或桌面移动切换。不用溶解，也不用裸硬切。

## 声音调色板

- **原声、手演乐器：** 扫弦吉他、滑棒吉他、口琴、立式贝斯、卡宏鼓或刷子、班卓琴、小提琴、手风琴、簧风琴、乌克丽丽。根据地点选择乐器家族：民谣、冲浪、Bossa Nova 或铜管乐队都适用。
- **一次刮印配一个击点：** 每层墨色落下时对齐一个音乐事件（扫弦、击打或和弦变化）；通过细分节拍加速，不改变速度。套印瞬间是一个强重拍。
- **按材质设计拟音：** 网框上的刮板声（带通噪声并带约 220–280 Hz 的网布颗粒；越快越亮）、湿墨挤压声、网框扣合和铰链吱响、纸张盖章声、虚线路线的滴答声、纸张嘶声、木与金属夹具声、晾架夹子声。
- **从印刷画面内部传出的环境声：** 完成的场景可以“醒来”（海浪、街道、人群），声音以 J-cut 提前进入、以 L-cut 延后退出。桌子下方保留房间底噪。
- **静音是一种工具：** 关键事实出现前，音乐退出一个节拍；剩下一个环境声，之后的第一个声音是明确动作（夹具声、长音上滑）。
- 拟音出现时音乐压低几 dB。响度 −14 LUFS。

## 原生手法

每种手法都服务于信息顺序。以下是菜单，按影片需要选用。

- **一种墨色，一个节拍。** 等信息读到时再印出。*适合内容：* 博物馆开放时间、渡轮时刻表、品鉴记录。
- **分色供墨。** 一次刮印使用多种墨色，给画面填满色彩。*适合内容：* 节庆夜空、日落海滩酒吧、一组彩色款式。
- **重新换色。** 同一张海报换一套配色 = 时间流逝、季节变化或产品变体。*适合内容：* 夏季和冬季的营业时间、三种夹克配色款、市场昼夜变化。
- **套印错位 → 瞬间套准。** 松散图层在一次击点上夹紧归位，随后出现关键信息。*适合内容：* 比赛日期、上市价格、开售时间。
- **纸张作为颜色。** 未印纸张是画面中最亮的元素。*适合内容：* 滑雪坡、灯塔光束、屋顶新雪。
- **路线作为印刷层。** 用强调色分段盖印一条虚线。*适合内容：* 公交线路、马拉松路线、配送路径。
- **系列海报墙。** 最终收尾画面把每张海报一起挂出来。*适合内容：* 一个城市的四个街区、乐队巡演日期、产品系列。

## 变化空间

由你决定主体、场景及其空间层次、在配色逻辑内的墨色、海报张数、相机路径、开场、结尾、乐器家族和片长。案例用于说明**信息先后与停留时长的语法**；应根据用户事实设计自己的时间线。

| 用例 | 信息顺序（印刷顺序） | 每层停留时间 | 片长 |
|---|---|---|---|
| **步道 / 景点指南** | 地点 → 每个项目依次：场景 → 名称 → 难度 → 距离 → 时间 → 页脚 | 标题约 3 s；名称至少 chars/12 + 1 s；统计行最后一项落下后至少 2.2–3 s | 30–40 s，3 项 |
| **活动 / 节庆海报** | 场景刮印 → 主标题 → 日期 → 地点 → 行动号召 | 主标题 2.5 s，日期 + 地点 3 s，结尾 3 s | 15–20 s |
| **目的地系列** | 同一模板、每个地点换一套配色：名称 → 一个事实 → 系列海报墙 | 每张海报 2.5 s + 海报墙 4 s | 20–30 s |
| **产品发布** | 围绕平面产品剪影印刷图层 → 名称 → 三种配色款（重新换色）→ 价格 / 日期 | 每种配色款 1.8 s | 12–18 s |
| **季节 / 营业时间通知** | 每个季节重印同一张海报 → 季节 + 营业时间 | 每次更换 2 s | 10–15 s |

每支新片都从主题重新设计，不照搬来源示范片：

- 结构：**一张海报，多次印制**（四个夜晚各重印一次，信息带里的演出阵容不断变化）；**沿街行走**（多平面镜头沿街道横移，经过的每家商店招牌逐一印出）；**套印错误故事**（套印位置逐渐偏移，直到最后一次刮印准确落在日期上）。
- 开场：**空网框**（光线穿过空白网面，显露正在曝光的模板）；**强调色先出现**（裸纸上只有一个亮色产品）；**夜里的成品海报墙**，随后回到桌面。
- 结尾：**晾晒架**（一排夹起的印张轻轻摆动）；**正在使用的海报**（贴在公交站亭上，开始下雨）；**最后刮印是纸白**（刮板墨尽，留下白色剪影）。

替换 `content.json` 并重新构建，是检查引擎能否重新排布内容的技术测试，不是制作成片的方法。

## 坑

- **描边边缘效果会在合并路径内部画出线条** → 只做填色（先填色，再在裁切区域内向内偏移填充）。
- **完整矩形的网框阴影会弄脏印刷效果** → 阴影应为环形。
- **水边的冷色阴影切面会看起来像水** → 阴影使用近景墨色。
- **参差墨珠会看起来像纸边** → 墨珠要保持圆形。
- **只有视差会像“山在移动”** → 图层松散时保留纸缝和厚度；在一个声音击点上归零套准。
- **剪影擦除留下深色空白** → 以切换位置为中心，让完整遮挡约持续 1 帧。
- **超宽横幅在 16:9 中会变成细条** → 采用约 4:1 的比例。
- **桌上随机的彩色点会像纸屑** → 设计真实工作台（木板、木纹、低饱和污渍、胶带）。
- **按诚实阅读时间显示太多信息会超时** → 在同一次刮印中并排印出次要信息，或让次要信息在最后的海报墙上阅读。
