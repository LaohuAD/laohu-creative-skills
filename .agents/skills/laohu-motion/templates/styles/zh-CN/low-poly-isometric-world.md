# 低多边形等距小世界（low-poly-isometric-world）

> 一句话：正交等距镜头观察浮空低多边形世界，六边地块按节奏升起，光照与发声共同记录生长。

> 来源参照（只学语法）：
> 通过正交等距镜头观察一个微缩切面世界：所有物件都是几何块，所有新出现的物件都带弹跳和音符落下。
> 参考（只学语法）：*Townscaper*（搭建本身就是表演；每块物件都带弹性地弹入并发出声音；零件会自行长出细节）；*Monument Valley*（等距几何、柔和粉彩、渐变天空、平静节奏和大量留白）。不得复制它们的网格、建筑、角色、UI 或字体，也不得在画面中点名。

## 本质 / 不是什么

一个由**平面着色低多边形几何体**（六边形柱状地块、带棱柱屋顶的盒状建筑、圆锥和二十面体树木）构成的微缩世界，漂浮在分面海面或虚空中，由**正交相机**以等距角度观察。没有透视，也没有地平线：远处融入**屏幕空间天空渐变**，让世界像悬浮在一片颜色中的模型。**用光而非纹理表现时间**：太阳移动时每个几何面都会变色；黑暗中只有自发光块保留颜色。

这不是体素游戏（没有立方体套立方体，也没有像素纹理），不是现实地点的移轴摄影（没有透视和照片细节），也不是平滑着色的 3D 卡通（没有圆滑法线或次表面散射）。

## 适配

- 用途：岛屿、城镇、生态或系统生长的三维小世界；需要真实立体分层与时间光照，不是二维架构信息图。
- 内容：只借用下方可复用媒介规则；人物、故事、事实、镜头顺序和时长按本片目标重新设计。

## 材质与渲染

- **几何体**（世界单位 = 一个六边形地块的外接圆半径）：使用尖顶六边形柱（`CylinderGeometry(r, r, h, 6)`），轴向坐标转换为世界坐标 `x = √3(q + r/2)`、`z = 1.5 r`。地形高度编码材质（沙地低、草地、丘陵、岩石最高）。顶部单独盖一层薄顶板，侧面用更深颜色；**侧柱顶部要低于顶盖**，否则会产生 Z-fighting。地块之间留小缝，让 AO 表现接缝。
- **道具**使用基本几何体组合：盒子、棱柱、低分段圆柱和圆锥、细分等级为 0 的二十面体、收腰盒体。自发光部件（窗、灯）为每个物件单独设材质，使它们可以分别发光。
- **材质**：`MeshStandardMaterial({ flatShading: true, roughness ≈ .9 })`，**不使用纹理**。每块地砖的明度轻微随机变化几个百分点，避免地面像电子表格。
- **水面**（如有）：用密集的非索引平面，在着色器中叠加正弦波使其变形；采用平面着色，让每个三角面独立闪光（粗糙度不能太低，否则面片会闪成白色）；缩远景时在下方加粗糙平面；每帧重绘显示陆地范围的**浅滩贴图**，将深水到浅水颜色混合，并加一圈淡淡的泡沫边；每块地砖的水线加一圈细窄透明环表现浪边。
- **无地平线的天空**：后期处理中线性化正交深度，并把远处像素混入竖向屏幕渐变；将雾效起止距离设为视锥高度 × 仰角余切的比例，使无论怎样缩放，地平线色带都留在画面上方三分之一。星点（哈希网格、闪烁）只在浓雾区域出现。
- **后期**：MSAA + 深度 → **GTAO**（必需：它能画出地块缝和屋檐下方的暗部）→ 天空／雾合成 → 很轻的边缘移轴 → 辉光（夜间更强）→ 粉彩调色 → Neutral 色调映射。超采样 2×。
- **光束**（探照灯、投影机、手电筒）：朝向相机的带状面，亮度按高斯分布、光束根部最亮并向远处衰减；再复制一条更宽、更淡的光晕。用独立着色器照亮光束下方的表面。

## 配色

- **粉彩、低对比、少量色相**：一个地面色系（沙地／草地／泥土或对应色系），一种中性色岩石，以及少量墙面和屋顶颜色，在建筑间重复使用。
- **一天中的光色由一组关键帧控制**（天顶、地平线、深水、浅水、太阳色、强度、高度角、方位角）并插值。白天清透偏冷；黄昏让地平线变暖；夜间所有颜色向蓝紫方向去饱和。
- **夜间只有暖色自发光物是亮点**（窗、灯、光束）。关键镜头中的太阳要从相机侧边照来（低太阳位于主体背后，会让分面水面产生眩光）；水面不接收阴影。
- 不画轮廓线，不用黑色；暗部只由阴影和 AO 形成。

世界配色示例：淡蓝白日天空下的沙地、草地和珊瑚色屋顶；淡紫天空下的雪地砖、松绿色和红色小屋；杏色黄昏下的陶土高原、鼠尾草灌木和绿松石水池。

## 字体

- 使用几何感 OFL 无衬线字体：字幕用圆润字体（如 Quicksand 600），标题用字距较宽的几何大写字体（如 Josefin Sans）。
- **字幕**不加字幕框；暖白色文字加柔和深蓝投影，居中置于画面下方；旁边配一枚平面着色地块图标，其顶面颜色随一天时段变化。停留时间不少于 `max(1.8 s, 台词时长 + 0.6 s)`，不得与下一行字幕或标题重叠。
- **标题表现得像地块**：字母逐个从水线下升起，过冲后落定。
- 世界上叠一张文字卡时，卡片周围要留出空隙，让世界仍然可见。

## 运动

- 以 24 fps 每帧连续运动。魅力来自**到达曲线**，不是逐格跳动。
- **从下方升起**：用短促三次缓动向上，再产生阻尼正弦过冲；突破水面时出现涟漪和水花。物件落定的时刻就是事件时间。
- **下落并堆叠**（楼层、屋顶、圆环）：快速加速下落，接着阻尼弹跳；着地时做保持体积的挤压与拉伸。
- **弹出**（树木、灯具、细节）：缩放 `1 − e^(−k s)·cos(ω s)`，过冲约 25%。
- **生命迹象**：风车旋转、烟雾喷出、鸟盘旋、船随水面同一波函数起伏（在 CPU 上计算）。
- **把生长安排在音乐网格上**：每个最小格至多放一块，以便每个事件都有自己的音符；通过增加密度（半拍 → 四分之一拍 → 八分之一拍）加速，不改变速度。
- 镜头投影不可变化（不能改透视，也不能改视场角）。

## 画面怎么活

水面波纹、风车、烟、鸟、船与星光按来源持续或错相运动；日夜光色按关键帧改变。生成件依音乐格安排，不默认为静止背景。

## 镜头语法

使用 `THREE.OrthographicCamera`。**视锥高度就是缩放量**（特写用几个单位，整个世界约十几个单位，展示尺度时用数百单位）；相机至少离场景 3 × 视锥高度，否则画面底部会看见海面以下。镜头是一套词汇，不是固定路线。开场和结尾由主题决定。

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 水平环绕（方位角扫动） | 从各个角度观察对象 | 搭建、检视、组装产品 |
| 纯正交缩放（改变视锥） | 不改变透视的尺度变化 | 结合上下文的细节、渺小感、世界中的世界 |
| 改变仰角 | 低角度（约20–25°）扩大天空区域；高角度（约50°）读起来像地图 | 夜空与星星、扫过整个世界、俯视平面图 |
| 固定3/4全景 | 世界自行运转 | 灯光亮起、延时、等待 |
| 对某次物件到达的紧特写 | 弹跳和水花 | 关键部件、里程碑、笑料 |
| 侧面跟随移动物体 | 穿越画面而行，方向不是朝着镜头 | 递送、离开、路线 |
| 沿一排地砖横移 | 列表、序列 | 流程步骤、时间线 |
| 相机固定，延时扫过太阳 | 光是时间机器 | 一天、一个季节、历史 |

按节拍在全景和近景之间切换：全景显示整体如何生长，近景卖出弹跳动作。转场可用节拍上的硬切、时段变化或穿过天空的缩放；不用溶解，也不用透视甩镜。

## 声音调色板

- **配乐可以由事件驱动**：生长事件带有音符，配乐在事件发生的准确时刻合成每一个音符，因此画面写出旋律。适合几何面的打击乐器：木琴、卡林巴、木块、铃、颤音琴、钢片琴、钢鼓；下方铺柔和铺底音、轻柔固定音型、轻沙锤或软底鼓。五声音阶或调式素材能让任意音符顺序保持和谐。**不使用钢琴或弦乐。**
- **一个音符可以成为动机**：世界独有的一种声音（铃、钟声、号角）以变化后的形式反复出现。
- **拟音跟随材料**，都可合成：地块升起时的气泡扫声 + 水花声和水滴声（物件越大，音高越低）；楼层的木头敲击声加较轻的回弹声；屋顶陶瓷碰击声；空心木板敲击声；沉重石块闷响；玻璃叮声；任何物件启动时配低沉冲击声与电流嗡鸣。
- **底声**：低通处理的棕噪水声并带起伏、向下滑动的 FM 鸟鸣、木头吱呀声、夜间蟋蟀或风声。
- **静默**：把声音降至低频嗡鸣和底声；重大节拍前让音乐总线短暂数字静音。也可以不完全停下音乐，而将固定音型削减为一个声部；或让世界自身事件在一段时间内承担节奏。
- **人声**：清晰、温和、台词少而短；避免使用容易和主题混淆的词（例如影片讲烘焙时，`flour` 听起来像 `flower`）。
- **混音**：人声压缩并明显高于音乐，音乐在人声下自动降低，−14 LUFS；**颗粒 0**（平面色块会因颗粒而闪烁）。

## 原生手法

可从下列菜单中选择故事需要的手法。

- **搭建就是作曲。**每个落下的零件播放一个音符；之后的扫镜可以按空间顺序重播音符，形成完整旋律。*适合：*楼层组成天际线并成为音符、团队搭建产品、花园中的花组成和弦。
- **程序化生长。**地砖升起、楼层堆叠、树木弹出。*适合：*创业公司的第一年、恢复中的珊瑚礁、规划中的街区。
- **纯缩放表现尺度。**一个物件填满画面，之后整个世界变成一个小点（也可以反向）。*适合：*数百万人中的一个用户、大洲上的村庄、网络中的数据中心。
- **环绕拍摄。**持续绕着正在制作的事物旋转。*适合：*组装机器、博物馆展品、房屋翻新。
- **光是时钟。**阴影扫动，几何面重新着色。*适合：*一天的商店营业、一年的农场变化、医院的轮班。
- **暗处的自发光积木。**灯一盏盏亮起，光束像时针般扫过。*适合：*网络上线、夜幕降临时的城镇、志愿者加入一项事业。

## 变化空间

由你决定世界（岛屿、城镇、果园、工厂地面、行星）、生长或变化的事物、符合色彩逻辑的调色、开场、结尾、相机路径和节奏。应远离来源示范片：

- 结构：**侵蚀**（完成的世界逐件失去部分，每个移除动作都成为下落音符，直到只剩最重要的部分）；**两个世界**隔空并列，互相交换零件，直到连接；**同一个世界中的四季**，用配色关键帧讲述一年变化。
- 开场：**建造到一半**（繁忙的半成品世界，许多零件已经在下落）；**从上方看起**（俯视地图，再倾斜进入等距视角）；**先展示完整世界**，再推近故事发生的那一块地砖。
- 结尾：**最后一块落下的近景**，不再拉远；**世界被收好**（零件飞起并堆入盒子）；**日光出现**（黎明照亮世界，音乐在第一块受光的几何面上解决）。

## 坑

- 共用后期代码中的 `perspectiveDepthToViewZ` 不适用于正交相机 → 改用 `orthographicDepthToViewZ`。
- GTAO 会把精灵和透明物体渲染成实心四边形 → 在 AO 通道期间隐藏它们；不透明度为 0 时设置 `visible = false`。
- 侧柱与顶盖共享同一平面 → 产生 Z-fighting → 把侧柱下沉。
- 双面加法圆锥像两条白线 → 改用朝向相机的高斯带状面 + 光晕。
- 相机离视锥太近，画框底部会看见海面以下 → 距离至少为 3 × 视锥高度。
- 两个物件落在同一音乐格会让旋律混乱 → 每格只放一件。
- `half` 是 GLSL 保留字。
