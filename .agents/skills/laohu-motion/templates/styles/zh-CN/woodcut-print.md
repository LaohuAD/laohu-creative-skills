# 木刻版画（woodcut-print）

> 一句话：以刻线方向、被刻去的留白和克制的印刷色层，将体积与情绪表现为木版画。
> 参照（只学语法）：仅借用视觉语法。Frans Masereel 的《Passionate Journey》（1919）与 Lynd Ward 的《Gods' Man》（1929）是由一系列独立版画组成的无字木刻小说；Käthe Kollwitz 的木刻以刻刀方向承载情绪；Gustave Doré 的雕版作品以线距与线向塑造光线和体积。不得复制他们的版画、人物、边框或标题。

## 本质 / 不是什么

每个镜头都是**一张印出来的版画**：黑墨落在有纹理的纸上，四周保留纸边。遵循真实凸版印刷的三条规则：

1. **黑色是木板，白色是被刀刻去的部分。** 光线是“刻”出来的：亮部由大量宽刻线组成，暗部则是未动过的木板。
2. **画面通过刻制显现。** 不做淡入；刻线沿着形体逐笔生长，先出现粗凿痕，再出现细线。
3. **木版上的图像是镜像。** 抽出纸张之前，字是反的；抽纸动作本身就是这种风格的转场。

它不是铜版雕刻（不在白底上做随压力变粗的雕版线，也不从白色底色叠加交叉排线），不是平涂色块的油毡版画海报，也不是把黑白照片用阈值滤镜硬切成两色（刻线必须顺着形体走）。

## 材质与渲染

- **印刷画框：** 印刷图像位于纸边之内；较宽的下边留给说明文字。图像边缘就是版边：墨迹参差，不是干净的矩形。
- **刻刀类别**（在 1080p、相机缩放 1× 时的刻痕宽度）：

| 工具 | 宽度 | 用途 |
|---|---:|---|
| 刻刀 `k` | 1.2–2 | 轮廓；在黑色主体与黑色背景之间刻出白色分界线 |
| V 形刻刀 `v` | 2–8 | 排线、头发、胡须、细小亮部 |
| U 形刻刀 `u` | 10–22 | 光芒、天空扫线、第一轮粗刻 |
| 点刻 `stab` | r 3–8 | 雪花、火星、泥土碎屑、木屑 |

- **排线（木刻中的 Doré 语法）：** 线的**方向跟随形体**（圆物以弧线包绕，坡面顺坡，火与光向外放射，布料沿褶皱走）。**线宽跟随明暗：** 亮部用几乎连成白块的宽刻线，中间调用细线，暗部不刻。远处密而细，近处疏而粗。每条线都是一条独立刻痕（30–160 px，起刀钝、收刀渐尖、边缘带缺口），绝不是机器绘制的连续线。
- **人物：** 黑色剪影 + 白色刀刻光晕 + 只在受光边缘用掠射光排线（光线 z ≈ 0.2，使平面区域仍保持黑色）。**皮肤刻白，五官留黑**（无字小说的规则）。
- **手部与物件特写：** 构造小型高度场（胶囊状、团块、木板、褶痕），打光后送入 `woodcutFilter`（第 10 节），使刻线像雕刻师刻等高线一样顺着等光照线条走。
- **印刷：** 白色代表刻除部分的遮罩通过 WebGL2 合成器处理：边缘带刻刀毛刺、墨色不均 ±6%、木纹条痕、未吃墨的斑点、带少许固定套印错位的斑驳色版。木板模式表现为有木纹光泽的上墨木板，刻槽露出浅色木头。

## 配色

- 两种明度承担全部画面：近黑墨色与温暖的纹理纸白。原木色只出现在展示木板本身的镜头中。
- **最多一种颜色版，**只印在已刻出的白色区域，让颜色从刻口中亮起，绝不压在黑墨上。颜色版压在黑墨上几乎看不见，因此要规划在刻出的白处。
- 颜色只留给最重要的一件事（火焰、熔融金属、心脏、信号灯）。它可以在高潮时扩散，之后缩成一个小高光；不能作为装饰。
- 颜色版示例：表现热量的烧铜橙、表现水或夜晚的冷普鲁士蓝、表现伤口或印章的深牛血红。按主题选择。

## 字体

- **字幕是纸边上的凸版印字，**位于版画下方，像木刻小说里的版画题注，不覆盖图像。使用老式凸版字体（IM Fell English，OFL），约 40–44 px，墨色，与图像经过同一印刷着色器。墨迹在 0.1 s 内显现，不滑入，随后用 0.15 s 淡出。保持至少 max(1.8 s, 语音时长 + 0.6 s)。
- **标题是刻出来的，不是打出来的：** 在木板上刻出（IM Fell English SC）；若木板在抽出印纸前出现，字要镜像。
- 结尾文字应像一张新印的字：放在纸边上做凸版印字，或刻在黑色面板上。

## 运动

- 人物按双帧动画（12 fps）；相机、粒子、火和光按一帧一格动画（24 fps）。排线固定在身体局部坐标中，随肢体移动而不沸动。
- 每个关键动作都包含**预备 / 动作 / 跟随**：往回蓄势几帧 → 两帧打击 → 落定并伴短暂抖动。
- **刻线显现：** 每条刻线都有自己的起始时间和速度（0.08–0.35 s）。显现关键方式：`light`（先亮部，从粗到细）、`radial`（从一点向外：光芒、倾注）、`down`（向下），或使用任意函数。
- **硬切 = 新的一次印刷：** 两帧套印错位（先偏几像素，再归位）。
- **纸张转场**（唯一的转场语法）：墨辊滚过（湿亮高光扫过）→ 纸张铺下 → 马莲螺旋摩擦，使图像渗印出来 → 纸张绕圆筒朝镜头剥起，先沉重后迅速，纸背露出镜像透印。
- 绝不移动的东西：纸边。

## 画面怎么活

- 只有火与液体按来源每两帧重新刻制，形成有意的版画沸动；人物按双帧动作，排线固定在身体局部坐标。
- 纸张边距保持不动；其它动作随刻线揭示、纸张压印和揭纸转场发生，不叠加无因纹理循环。

## 镜头语法

镜头在纸面上移动；纸边保持固定。焦点是刀尖或最亮的刻线。

| 镜头变化 | 表达作用 | 可用于 |
|---|---|---|
| 跟随刀尖移动 | 刻制本身就是故事 | 第一笔、地图上的路线、签名 |
| 随刻线扩散而持续拉远 | 一条线变成一个世界；尺度变化 | 一条街变成一座城市、家族树、一段声音或新闻覆盖的范围 |
| 锁定版画 | 像在阅读无字小说的一页；留出阅读时间 | 决定、肖像、事后余波 |
| 缓慢微距推近雕刻特写 | 耐心、触感、劳动 | 工作中的手、工具、正在读的一封信 |
| 快速变焦并停住 | 震惊；那个打破原有认识的细节 | 裂缝、错误数字、转过来的脸 |
| 门、窗或拱门形成画中框 | 距离、排斥、等待 | 外面的群众、病房、边境 |
| 跟着节拍硬切，每次都是新的一版印痕 | 累积、一系列印刷品 | 供品、日子流逝、姓名清单 |
| 从细节升降到全貌 | 后果 | 洪水漫向村庄、灯光照到人脸 |
| 通过揭纸在两张版画间换焦 | 一个状态印在另一个状态上 | 前后变化、兑现承诺、代际传承 |

开场和结尾由主题决定。构图可用刻出的白色区域中的黑块，或未刻黑木上的白色主体；不能用灰上灰，文字只放在纸边。转场用硬切（新印痕）或剥纸，不用溶解。

## 声音调色板

- **乐器：** 低音弦乐（低音提琴、大提琴；断奏、拨奏）、木与皮革（长鼓、木鱼、框鼓）、大鼓、定音鼓、一面锣、合成敲击金属（模态音色：3–5 个非谐泛音加锤击瞬态）；用锯琴或手摇风琴持续音增添民间色彩。
- **选项：** 故事中的物件出现之前，先不让观众听到它的音色；用节拍率调制而非突然跳速；在长混响尾音中改变调式；锁定版画下铺一条持续音。
- **拟音跟随材质，且都可合成：** 刀刻入木（瞬态 + 带通的纤维撕裂声，并与刻刀速度同步）、木屑、墨辊粘连声、纸张气流、马莲摩擦、湿润的揭纸声；金属按尺寸区分（大件偏低，小件偏高而纯）；有共鸣的物件可用模态模型加回声表现距离。
- **静音是一种工具：** 可用近乎无声、只留微弱环境声，也可在最响亮的时刻前使用真正的数字静音；静音后的第一个声音要经过选择。
- 用 J-cut / L-cut 让声音跨越版画与揭纸转场延续。
- **混音：** 人声下方的音乐降低约 8 dB，关键拟音下方略微降低；**拟音也要在人声下方压低。** 瞬态声硬声像移离中心。响度 −14 LUFS。
- **人声：** 台词少、语调低而平，像有人把字幕念出来；剩下内容由版画讲述。

## 原生手法

以下是方法菜单，按故事需要选用。

- **光即刻痕：** 从一点向外刻出放射线。*适合内容：* 电网重新通电、科学发现、修复灯塔。
- **刻制即时间：** 在画面中耐心地一刀一刀刻出来。*适合内容：* 一年的训练、建筑物拔地而起、工艺学徒期。
- **镜像木版 → 正向印张：** 反写的字在纸张揭起后变为正字。*适合内容：* 投票结果、洗清某人的名字、纠正误会。
- **点刻纹理：** 白点可以停在空中，也可以重新印回去，直到黑色恢复干净。*适合内容：* 城市上空星光熄灭、雨停、地图上的疾病范围消退。
- **唯一颜色版扩散再收回：** *适合内容：* 献血、日出照亮丰收、停电时唯一亮着的窗户。
- **把雕塑或画面转成顺形刻线：** *适合内容：* 根据照片刻出真人肖像、机器零件、重新刻制的档案图像。
- **无字小说式编排：** 一组独立版画，少字或无字；画与画之间可以静默。*适合内容：* 迁徙、罢工、分成七幅版画的一生。

## 变化空间

由你决定故事、人物（或不出现人物）、版画数量、开场、结尾、相机路径、节奏，以及唯一一种专色用来表现什么。每支新片都根据主题重新设计，不照搬来源示范片：

- 结构：**祈祷书**（七幅锁定的版画，每小时一幅，每幅内部不移动）；**同一木版反复重刻**（每个场景都刻得更深，图像随之改变）；**两块版依次印刷**（两个地点交替留下印痕，最后落在同一张纸上）。
- 开场：**墙上的成品印张**（随后回到木版内部，看它如何被刻出来）；**白纸**（上墨木板压下后，整幅图像一次出现）；**木纹**随着第一道刻痕变成水面或田野。
- 结尾：**洗净木版**（墨被洗掉，只留下浅色的刻痕木头）；**一摞印张**（同一块版连续印出很多张纸并越堆越高）；**未刻的一角**（停留在刀从未触及的黑木上）。

## 坑

- **在白色区域画白色记号**会看不见 → 点刻需放在深色主体后方。
- **每个表面都排线**会看起来像皮毛或雨 → 使用掠射光，只在受光边缘刻 3–6 条线。
- **黑脸配白色刻痕时缩小会认不清** → 皮肤刻白、五官留黑，并在白色部分周围留一道黑色轮廓线。
- **手绘特写道具像连指手套或一团团块** → 使用高度场再交给 `woodcutFilter`。
- **短排线段再叠上明暗摇摆，会变成之字形箭头** → 刻线加长（为线间距的 14–50 倍），使用一条宽高光带、一条窄轮廓光和更强的光晕。
- **把蒸汽或烟画在主体前面，会像火焰** → 将其画在后面，只让几缕烟雾逸出。
- **不同镜头共用懒加载缓存的刻线**会让帧依赖渲染工作进程 → 每个缓存都要能在首次使用时自行构建。
- **细排线 + 墨噪点 + 纸纹会撑大文件** → 用较高 CRF 并加 `-tune grain`；检查 1:1 裁切画面。平坦区域里的 `woodcutFilter` 出现 NaN → 在 `sqrt` 前做范围钳制。
