# 水彩田野手记（watercolor-field-journal）

> 一句话：暖纸上的透明水彩逐笔显形，手写标注把观察对象和测量信息留在同一页。

> 来源参照（只学语法）：
> 像手绘田野手记页面自己绘出来：温暖棉纸上的透明笔触带有干笔飞白；手写注记写在所绘对象旁边；不使用矢量线条绘制。
> 参照（只学语法）：自然观察手记和植物图谱水彩（样本 + 注记）；横向长手卷全景（一片连续绘出的世界）；教科书中的“样带”图（沿空间读出渐变）。借用其语法，不借用具体作品、角色或版式。

## 本质 / 不是什么

- **一张温暖、有纤维的纸**垫在所有内容下面；纸张同时也是橡皮擦（纸色雾洗掉画面）。
- **一切都由独立笔触组成：** 半透明、宽度可变的带状笔触，加上几条断成虚线的细**鬃毛痕迹**（飞白）。笔触相交时叠加变深，像透明颜料。没有矢量轮廓线；唯一类似“线条”的东西，是沿形体边缘画下的深色笔触。
- **对象通过绘制逐笔显现，**先结构、后细节（树干 → 树枝 → 树叶；轮廓水洗 → 阴影 → 强调色）。
- **注释层**像画家会亲手写下的一样：用钢笔引线连接标签、少量测量数值和克制的标题。
- 整体语气平静、好奇、精确。数据是真实的；配色可以承载数据。

它不是水墨（有颜色，不只墨色；不用书法式的挥笔），不是厚涂油画（没有厚颜料和画刀），不是儿童绘本（没有蜡笔或可爱轮廓线），也不是在矢量插画上叠一层水彩纹理。每一处都要同时有水彩笔触和纸面质感。

## 适配

- 用途：自然观察、旅行与过程记录；仅在主题适合手绘观察、留白和缓慢显色时使用。

## 材质与渲染

- **纸张：** 预先生成的图像（温暖底色、三个八度的平滑噪声 ±3.5%、数千条短而弯曲的纤维、细颗粒、浅暗角），每帧最先绘制。
- **笔触**（`engine.js` 的 `mk` / `drawS`）：带状笔触宽度跟随轮廓类型（`brush`、`leaf`、`even`、`tip`、`trunk`），并叠加约 ±22% 的数值噪声粗糙度；先用较薄的水洗色填充（有鬃毛纹时主体不透明度约 0.55–0.6），再画 3–9 条不透明度为 30–85% 的鬃毛纹，每条采用随机虚线图案并在随机位置提前结束，形成飞白。一条笔触可以绘制到任意长度比例（就像移动中的笔尖）。
- **水洗：** 同一多边形以三分之一的不透明度绘制三遍，每次顶点轻微抖动，因此重复处边缘会加深（形成积水的水彩边缘）。
- **通过图层表现深度：** 用多个视差图层承载水洗色块与绘制对象；越远越小、越浅、饱和度越低；图层之间有纸色雾带。
- 将完成的对象缓存为 sprite；只对正在绘制或变形的对象逐笔重画。
- **所有画面都严格由 `t` 决定；** 在 `render(t)` 内创建的任何笔触都使用固定种子生成。

## 配色

- **纸白就是亮部。** 绝不涂纯白；光亮部分就是没有上色的纸面。
- **透明叠层：** 越暗就叠更多层，不是在上面直接加深色颜料。每个场景保留 3–5 种色相，另加墨色。
- **墨色**（温暖的近黑或浅棕）只用于线条、文字、边缘和茎秆。
- **颜色可以承载数据或情绪：** 根据位置或时间混合天空、地面和背景颜色，让调色板随主体变化。量化成 4–6 个色带的地图坡度像颜料，连续平滑的坡度则像软件生成。
- **一种强调色**（朱红、雨蓝）只留给一个反复出现的元素：印章、标记或关键物件。
- 配色示例：从干燥到湿润——红赭色 → 鼠尾草绿 → 稻草黄 → 蓝灰 → 深绿；黎明港口——天空 `#f3e2c8`、水面 `#9fb4c4`、船身 `#5f7486`、浮标强调色 `#c8442a`；菜园——土壤亮部 `#e8e0c0`、叶片 `#8ea860`、阴影 `#4e6e3c`、南瓜强调色 `#d9632e`。

## 字体

- 标题和字幕使用优雅衬线体（如 Cormorant Garamond），注记使用手写字体（如 Caveat），测量标签使用小号等宽字体（如字距较宽的 IBM Plex Mono）；中文使用 Noto Serif SC（仅子集化实际使用的字符）。
- 手写注记先在纸色光晕上绘制两遍，再像书写一样从左向右显现；钢笔引线生长至所标本体。
- **字幕**落在纸面上，不放入方框：底部居中，约 36 px 斜体衬线（最多 2 行、行宽均衡），第二语言行放在下方、字号约为三分之二，墨色叠在纸色光晕上、不透明度约 78%。保持至少 max(1.8 s, 语音时长 + 0.6 s)。
- TTS 文本里把数字拼写成词，屏幕上则写阿拉伯数字。

## 运动

- **绘制显现是主要运动：** 对象的进度取决于它在画面中的位置或指定 cue；列表中的各笔触分配进度区间，因此先显现结构。
- **轻摆**只发生在对象绘制完成后：小幅水平倾斜（`sin(1.15t+φ) + .4 sin(2.7t+2φ)`），树约为 0.006，草约为 0.01–0.03。
- **笔刷边缘擦除：** 用波浪状垂直裁切层揭示整个场景；线条依笔触进度生长；标签通过由左向右的裁切显现。
- **雾**用于擦除：纸色图层带波浪状上升边缘。
- 动物和事件可以按音乐节拍网格分配动作阶段，使落点踩在节拍上。
- 使用平滑缓动（`ss`、`eio`、`eo`、`ei`）；慢速流动的笔触适合 60 fps；画面不要抖动。

## 画面怎么活

笔触显色、树草轻摆和纸色雾擦除按来源规定的进度发生；固定种子让静态笔触可复现。来源没有规定额外的通用背景微循环；主绘制动作与镜头仍按来源方法及本片任务设计。

## 镜头语法

镜头词汇，不是固定路线。画面是一张连续绘制的纸，少用切镜。开场和结尾由主题决定。

| 镜头变化 | 表达作用 | 可用于 |
|---|---|---|
| 沿连续世界长距离横向移动 | 渐变、旅程、因果 | 样带、路线、时间线 |
| 沿单个对象垂直倾摇 | 尺度、测量 | 高树、建筑、深度 |
| 锁定纸面，让内容逐笔绘出 | 研究、专注 | 样本图版、食谱、图解 |
| 缓慢推近细节 | 观察者靠近查看 | 种子、昆虫、手写注记 |
| 拉远至地图或图解 | 重新看到全貌 | 事情发生的地点、系统全貌 |
| 纸色雾洗至空白纸面 | 章节结束、时间流逝 | 季节、遗忘、新地点 |
| 翻页 / 新纸页滑入 | 手记的新条目 | 新的一天、新物种、新案例 |
| 锁定画面中时间发生变化 | 生长、衰败、历史 | 季节循环、前后对照、深时间 |

构图保留宽阔纸边；每个画面只突出一个主体和它的注记，标签不覆盖主体。转场可以是笔刷边缘擦除、雾洗、翻页或连续相机运动；不做视频硬切，也不在无关画面间溶解。

## 声音调色板

- **音乐：** 原声、柔和，可用毡音钢琴、指弹吉他、木管、轻弦乐、钟琴、卡林巴和柔软的铺底音。可剪辑获许可的曲目，并对齐节拍跳切；随后画面可采用其节拍网格。
- **来自场景材质的拟音：** 每次逐笔绘制时配纸刷摩擦声（带通噪声、轻微颤音、从一侧平移到另一侧）；注记配铅笔刮纸声；印章配轻轻的闷响；另有翻页声和题材相关的自然环境与生物声（鸟、风、雨滴、水声、昆虫、火焰噼啪声）。
- **静音：** 像笔刷抬起一样，音乐退出，只留纸张和房间底噪；用来框出一个绘制瞬间。
- **混音性格：** 人声在前（RMS 比音乐高几 dB），人声下方的音乐用平滑包络压低约 4 dB，加入短而柔和的混响，最终响度 −14 LUFS。Kokoro 人声峰值偏高（峰均约 17 dB）：在响度匹配前先做限制。
- **人声：** 温暖、不赶时间的纪录片口吻，每个意思用一句话。

## 原生手法

以下是方法菜单，按故事需要选用。

- **逐笔绘制作为揭示。** 新对象出现时，笔触一笔笔把它画出来。*适合内容：* 建筑施工阶段、一道菜的食材、人体器官。
- **集中显现。** 整组对象在不超过 1 s 内一同绘出，作为高潮。*适合内容：* 节庆人群、盛开的花田、亮灯的城市。
- **配色作为数据。** 按测量值混合天空、地面与背景。*适合内容：* 河流污染变化、海拔温度、城市噪声分布。
- **样本 + 注记。** 一个核心物件配手写标签和引线。*适合内容：* 工具套件、葡萄酒产区的葡萄、自行车零件。
- **雾洗擦除。** 世界逐渐水洗退回纸面。*适合内容：* 遗忘、梦境结束、场址拆除。
- **时间地图。** 地图上的填色跨越年份持续改变。*适合内容：* 语言扩散、海岸侵蚀、铁路网络扩展。
- **水彩变形。** 对象渐变为烧焦、潮湿或老化的 sprite，再重新生长。*适合内容：* 野火与恢复、洪水、修复工程。

## 变化空间

由你决定地点、主体、颜色如何承担作用（一直存在、暂时收起或逐渐抵达）、是否使用旁白、音乐家族、相机路径、开场、结尾和片长。设计要远离演示片：

- 结构：**一年手记**（每月锁定一页，逐页覆盖上一页）；**一个对象的解剖**（同一件样本拆成带标签的部件，每个部件都用绘制特写呈现）；**食谱或流程**（在同一张高纸页上自上而下画出步骤，并向下倾摇）。
- 开场：先展示**一幅已完成的画**，接着倒放绘制到第一笔，再正向播放；**湿颜料特写**逐渐扩散，再拉远揭示它变成什么；**空白纸上的手写问题**由画面作答。
- 结尾：**纸页没有画完**，笔刷停在半道；**一个细节特写**停留，其他画面都褪回纸面；**纸页风干后归档**，放入一摞其他页面中。

## 坑

- **画布外的水洗色带太短**会把高形状压平，并在倾斜时露出接缝 → 色带尺寸应明显超出画框。
- **半透明水洗色块刚好止于画布边缘**会在其他图层下露出硬接缝 → 将色块延伸到画外，并用渐变过渡回纸面。
- **经典脚本共用全局作用域：** 在异步初始化中，声明前读取 `const` 会让 `READY` 一直为 false、所有截图超时 → 在初始化内部构建所有内容，并查看 `[pageerror]` 行。
- **笔触构建器会消耗全局随机数生成器：** `render(t)` 内创建的任何笔触必须用 `withSeed` 包裹，否则并行工作进程会得到不同结果。
- **每帧绘制数千条笔触太慢** → 使用 sprite 缓存。
- **音乐剪辑发生变化时，按节拍锁定的动画也必须重新推导。**
- 新增中文字幕字符后，如果没有重新构建字体子集，会回退到另一种字体。
