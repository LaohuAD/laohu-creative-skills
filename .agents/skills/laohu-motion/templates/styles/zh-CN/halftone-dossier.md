# 复古半调案卷（halftone-dossier）

> 一句话：以半调印刷与纸质案卷的视觉装置，把调查组织成一串清晰、可触的证物展示。
> 参照（只学语法）：本风格仅借用视觉语法，不复制作品。Ben-Day 波点流行艺术印刷（Roy Lichtenstein 时代漫画）用于理解以点的密度塑造明暗；risograph / 胶印叠印小志用于理解多层叠印与套印错位；警方头像照身高尺与案件档案夹用于理解画面框架；日本综艺节目 telop 字幕用于理解关键词高亮字幕条。

## 本质 / 不是什么

- **整部影片都像纸张。** 使用温暖的奶油色纸面，带低频斑驳、细颗粒、暗角和折痕；暗场也印在纸上，不能发光。
- **明暗绝不用渐变：** 以半调网点呈现，点的大小随密度场变化。两三层网点使用不同网角叠印（正片叠底），形成“印出来”的质感。
- **官僚档案装置：** 案件编号、档案标签、编号证物、身高尺、姓名牌、印章。严肃的框架负责定调，题材可以严肃也可以琐碎。
- **醒目但易读：** 每张 2–4 秒的卡片只讲一个意思：一个大标题、一处视觉笑点或证物、一行字幕。

它不是 Risograph（全片不做粗糙的双墨色 risograph 颗粒和小志拼贴），不是瑞士动效（不在白底上做由网格支配的动态排印），也不是平面游戏节目风（不使用糖果色布景和节奏游戏式回合）。每一帧都必须看得见网点、纸张和印章。

## 材质与渲染

- **纸张层**（画布上一次构建并正片叠底覆盖全画面）：放大的随机纹理图块形成斑驳，逐像素噪点略偏暖，另有径向暗角和浅浅的中央折痕。
- **颗粒层**（逐帧绘制）：数百个纸色小点和较少的墨色小点，每两帧重新播种一次；这是印刷品上的灰尘，不是胶片颗粒。
- **半调网点：** 将圆点按旋转网格绘制成一条路径；间距 20–26 px；各层网角不同；半径 = 密度 × 间距 × k，k 为 0.6–0.72（约 0.7 时圆点会合并成实墨）。密度场包括径向场（光晕、绽放、角落亮起）、边缘场（圆点在画框边缘变密）和线性坡度（“上方来光”）。第二层使用正片叠底，使墨色叠印。
- **半调填充的数字与图形：** 先铺平涂色，再叠印较深的半调网点，并将网点裁切到字形内部；巨大的数字可以溢出画框。
- **线条沸动：** 湍流位移幅度较小（约 5 px），约每秒重新播种 10 次，并用细墨颗粒遮罩轻微侵蚀每块填色。只用于角色和手绘道具，**绝不能**用于文字、半调点、HUD 或字幕。
- **角色：** 造型敦实，使用粗重墨线轮廓（约 7 px）、平涂色块、较浅的腹部或脸部区域，以及有光泽的眼睛（墨色椭圆加两个高光）；眼睛可以眯起、眨眼或闭成开心的弧线。所有身体姿势共用一个头部骨架。
- **印章：** 双线圆角矩形与粗体文字经过粗糙墨粒和位移滤镜处理，让边缘参差、墨色斑驳；不透明度约 93%，倾斜 ±10°。
- **道具：** 星芒、对话气泡、纸屑、径向光线、便签、文件夹、时钟等，全部采用平涂填色加墨线轮廓。

## 配色

- **纸色底、一种深色墨、四五种平涂专色。** 深色墨（海军蓝、黑褐或深绿）承担所有轮廓、正文和字幕条，也是淡出颜色。
- 一种墨色用作**套印阴影**（错位偏移、字幕阴影）；一种用作关键词和数字的**强调色**；一种暖红专用于印章和警报。
- 只用平涂墨色。不用渐变，也不用透明度坡度；色调由圆点大小和叠印形成。
- **夜景或“秘密”场景：** 改为深墨色底，并加同色系较浅的网点层，整体仍与纸张正片叠底。
- 角色可以有一两种局部专属色（毛色、衣服），这些颜色不出现在其他物件上。
- 配色示例：奶油色 / 海军蓝 / 钴蓝 / 亮粉 / 黄色 / 红色；马尼拉纸色 / 棕黑 / 青绿 / 芥末黄 / 朱红；米白 / 森林绿 / 番茄红 / 天蓝 / 赭色。

## 字体

- **大标题：** 使用极粗衬线字体（例如中文 Noto Serif SC 900；拉丁字母用极粗 slab 字体），字号 100–230 px，靠左贴近页边；加一层**套印错位阴影**（用套印墨色偏移 +8/+8 px，并做正片叠底）。
- **展示字 / 数字：** 使用厚实圆润的展示字体（例如 Bagel Fat One）书写姓名、大数字和时间。
- **感叹词：** 使用俏皮手写字体（例如 ZCOOL KuaiLe），纸色填充、粗墨线描边并加错位阴影。
- **数据 / HUD：** 使用粗体等宽字体（例如 JetBrains Mono 800）显示案件编号、日期、刻度尺和文件名。
- **字幕和印章：** 使用极粗无衬线字体。
- **卡片就是字幕。** 每个节拍配一个大标题和一条**字幕条**：深墨色圆角胶囊，带套印墨色偏移阴影，使用纸色文字，关键词以强调色呈现。大标题出现之后再弹出字幕条，并保持至少 max(1.8 s, 语音时长 + 0.6 s)。有旁白时，字幕条承载所说的台词。
- **HUD：** 左上角放案件编号和章节标签，右上角放状态（REC 点、日期）；暗场时反转颜色。
- 拉丁文字比中文占时长 2–3 倍：大标题更小，印章只用 1–2 个词（GUILTY、CLOSED），逐字错开的时间更紧。

## 运动

- 变换动画为 30 fps；角色的线条沸动约为 10 fps，让画面有呼吸感、位置仍平滑。
- **所有内容都带过冲入场**（回弹缓动，0.3–0.45 s）：从画框下方升起或从 0 缩放出现。不使用淡入。
- 大标题逐字弹出：每个字形下落 30–100 px 并挤压落下，错开 0.05–0.08 s（小字为 0.02 s）。
- **印章猛击：** 约 0.09 s 内由约 2.6× 缩至 1×（缓入），然后轻微阻尼回弹；相机抖动、闪白和印章声同一帧发生。
- **挤压落地**须保持体积（使用 `scale(1/sq, sq)` 和阻尼余弦函数）。
- **圆点擦除转场：** 粗网格圆点扩大至完全遮满画面，再缩回（约 0.44 s），并沿对角线错开；场景在被遮住时切换。每次切换可单独选择擦除颜色。硬切是强烈撞击时的对比手法。

## 画面怎么活

- 有角色时，可按来源安排呼吸、尾巴或头发轻摆、眨眼；没有角色也成立。REC 点或时钟冒号可作明确的录制状态提示。
- 点密度随情绪或证据状态改变，不做固定频率的装饰性脉动；来源未规定其它待机循环。

## 镜头语法

在平整正视的纸面上使用 2D 相机组。以下是镜头词汇，不是固定路线。开场和结尾由主题决定。

| 镜头变化 | 表达作用 | 可用于 |
|---|---|---|
| 正面锁定，伴随轻微节拍脉冲（约 0.6%） | 让整页像一张有律动的海报 | 标题、清单、指控 |
| 缓慢推近（1 → 1.05–1.08） | 审视、紧张感上升 | 人物档案、判决前的总结 |
| 二次函数衰减的抖动（5–26 px） | 撞击感 | 盖章、撞击、落地 |
| 闪白帧（白色叠层 ≤ 0.95 → 0；强烈撞击时最高限制为 0.5） | 被拍摄、揭示 | 头像照、判决、发现证据 |
| 沿着钉满证物的板子横摇 | 建立证物之间的联系 | 时间线、嫌疑人、事件链 |
| 快速变焦推进到半调细节，直到圆点变得巨大 | “仔细看” | 指纹、签名、数字 |
| 翻页 / 文件夹滑入 | 下一个档案、下一章 | 第二个案件、闪回 |
| 拉远以露出整张桌面 | 文件只是众多文件中的一个 | 规模、“每天都在发生” |

构图像印刷页面：大标题在左上，主体在右侧中部，字幕条在底部中间，HUD 放在角落。转场使用圆点擦除或硬切，不用溶解。

## 声音调色板

- **合成器流行印刷感工具组：** 合成器底鼓、军鼓、拍手、踩镲；方波感的八分音符贝斯；三角波铺底；类似木琴的拨奏音（基频加约 4 倍频泛音）承担旋律；潜行时用拨奏弦乐与弹指声，温柔时用八音盒铃声。
- **拟音跟随印刷动作与笑点：** 盖章 = 音高下坠的低音撞击加咔哒声（强击加爆裂声），相机快门、纸张滑动和文件夹翻动、打字机或键盘点击、擦除转场的呼啸、每个字形弹出声、角色的“啵”和弹跳声、易碎物的玻璃或陶瓷声、合成动物或生物声音（共振峰扫动）。
- **印章前的静音：** 在判决前抽掉音乐，让印章独自落下。其他选项包括：揭示前的军鼓滚奏加上升滑音；秘密场景只保留贝斯和弹指声；尾声加一段铃声琶音；悲伤证物下铺一条持续的合成器垫音。
- **人声**可有可无；卡片本身可以承载整支片子。若使用旁白，采用干燥、冷面报告式的声音，不要气喘吁吁。
- **混音：** 撞击处音效要压过音乐；母线使用软削波，响度 −14 LUFS，真峰值 ≤ −1 dB。

## 原生手法

以下是方法菜单，按故事需要选用。

- **指控框架：** 将主题转为“X 案”，并列出相关数量。*适合内容：* 受审的认知偏差、城市交通问题、停不下来的植物。
- **编号证物：** 每个节拍在主体后方放一个巨大的半调数字。*适合内容：* 停电的五个原因、合同的三条条款、召回流程的各阶段。
- **印章：** 用一次有实体重量的猛击宣告判决。*适合内容：* 补助申请上盖“批准”、政策上盖“已过期”、传闻核查上盖“已验证”。
- **头像照：** 正面主体、身高尺、姓名牌和闪光灯。*适合内容：* 新物种、产品拆解、软件缺陷报告里的“嫌疑对象”。
- **证据板：** 将证物钉起来、用线连接，再摇动证据板。*适合内容：* 供应链、家族树、抢劫案时间线。
- **圆点密度 = 情绪：** 圆点可膨胀成光环、挤向边缘以制造紧张，或径向绽放以表达喜悦。*适合内容：* 打破纪录、期限逼近、重逢。
- **涂黑：** 黑条印在文字上，再逐条揭开。*适合内容：* 泄露的备忘录、惊喜派对计划、剧透。

## 变化空间

由你决定档案讲什么、包含哪些数量或证物、是否出现角色、在既定配色逻辑内选哪些墨色、整体语气是闹剧还是严肃、如何开场和结尾以及片长（证物越多，片子越长；每个证物都要留出阅读时间）。

每支新片都根据主题重新设计，不照搬来源示范片：

- 结构：**逐页解密的报告**（一页页揭去涂黑，直到真相显露）；**失踪者档案**（从最后一次现身倒推）；**保险索赔案**（每件证物都与索赔者的陈述相矛盾）。
- 开场：**证物袋**（深墨色底上放一件物品，档案围绕它组装起来）；**巨大网点指纹**（拉远时解析成一张脸）；**电话**（纸面上只有字幕条，随后档案落下）。
- 结尾：**档案放进抽屉**，抽屉里有一模一样的档案；**最后一页被涂黑**，答案仍被遮住；**印章没盖中**，落在桌上，主体从画框里走开。

## 坑

- **字体尚未加载就开始排版** → 逐字定位仍按后备字体计算，字形会互相挤压。根据整页原稿与最终文字预加载每个字体系列；运行时文字只能用文件中出现过的字符。设置 `font-display: block`。
- **在线条或网点上使用沸动**会让它们变成一团糊 → 滤镜只加在角色和道具上。
- **`clip-path` 的 id 是全局的** → 每个被裁切的大数字都需要唯一 id。
- **按时间窗出现的场景**中，元素在入场点之前不可见时，必须明确设为 `t < t0` 时 opacity 为 0。
- **圆点擦除没有完全遮住画面**会在切镜处露出硬切 → 最大半径必须覆盖网格单元的对角线。
- **100% 白色闪光**看起来像掉帧 → 限制在约 0.5。
- **网点太小**（1080p 下间距 < 约 14 px）在编码后会产生摩尔纹。
- **墨色过多**会失去印刷感 → 最多五种专色，纸色不计在内。
