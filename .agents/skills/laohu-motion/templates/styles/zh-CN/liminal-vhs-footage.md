# 空室录像带怪谈（liminal-vhs-footage）

> 一句话：连续手持家用摄像机穿过空旷熟悉空间，焦距、曝光、OSD 与磁带损伤承担叙事。

> 来源参照（只学语法）：
> 从空旷、无尽、荧光灯照明的空间中找回的摄像机磁带。规则取代怪物。
> 类型参照（只学语法）：“the Backrooms”网络民俗与新怪谈／规则恐怖；1990年代家用摄像机录像。影片中**不得**出现“Backrooms”一词、wiki“Level”编号、社群实体名称，也不得出现任何现存组织或标志。画面中的所有内容（规则、表格、公司声音、任何存在）都必须原创。
>
> 适合短片；时长随行走过程而定。如果没有新异常发生，恐惧感会逐渐消散。

## 本质 / 不是什么

- **一段第一人称家用摄像机录像**（1990年代 VHS、4:3），手持、连续。
- **一个空无一人、熟悉却不对劲并不断重复的室内空间**：办公室、酒店楼层、学校、商场、停车层、医院病区。荧光灯嗡鸣，没有人。
- **恐惧来自空荡、重复、官僚式规则，以及摄像机自身机械结构在错误时刻失灵。**没有东西追赶任何人。要让人后颈发凉，不要突然吓人一跳。
- **媒介本身是叙事者**：焦点、曝光、磁带损伤与屏幕显示共同推进情节。

这不是恐怖电影（没有怪物特写、血腥、突发惊吓或配乐惊吓音效），不是 ASCII／CRT 终端作品（故障来自磁带和镜头，不是荧光粉和扫描线），也不是废墟（空间干净是风格的一部分）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 来源正文中的可见/可操作描述 | 适合的主题 |
|---|---|---|
| 连续4:3手持POV | 一镜到底，只在开机、磁带撕裂或停止录制处出现断点。 | 走廊、室内探索 |
| 重复的熟悉空间 | 办公室、酒店、学校等重复出现，空间干净、无人且不合常理。 | 空无、规则恐怖 |
| 局部光与雾联动 | 雾色取决于邻近灯光，熄灯区会形成光中的空洞。 | 灯光异常、远处轮廓 |
| 磁带摄像机失真 | 抖动、色度拖尾、自动增益和磁头切换带随录像而变化。 | 录像带、失真 |
| OSD独立于磁带噪声 | 录制点、时间、电量等摄像机字层不被视频噪声污染。 | 时间线、证据 |
| 自动对焦寻找 | 焦点从模糊过冲到锁定，再滑开，成为看见/看不见的叙事。 | 远处不确定物 |
| 单一饱和信号色 | 环境主色病态低饱和，只有一个报警/提示色饱和并发光。 | 警示、规则变化 |

列出的信号均可在来源正文中定位；每支按主题挑 2–3 个，至少一个避开最常见组合，不把信号全部堆在同一支片子里。

## 这个风格最俗的版本

来源没有给出一套可跨主题复用的固定俗套组合，因此不补造。风格特征与明确排除项保留在上面的本质说明中；具体故事、时间线和段落仍按新主题重新设计。

## 适配

- 用途：以空无、重复规则和拍摄媒介异常制造克制不安的短篇；不适合需要动作追逐或配乐惊吓的恐怖片。
- 内容：只借用下方可复用媒介规则；人物、故事、事实、镜头顺序和时长按本片目标重新设计。

## 材质与渲染

- **画框**：4:3 画面置于 1920×1080 中，两侧加黑边。3D 场景以低分辨率渲染（例如 720×540），再由 VHS 处理放大；低分辨率可以隐藏 CG 的干净感。
- **空间**：沿网格布置轴对齐隔墙，并随机留出缺口和短墙段；加入柱子、规则排列嵌入式灯板的方格吊顶。用手工设计路线穿过程序生成的空间，让每个门洞后都显得更加空旷。
- **照明 = 数千个灯光源，不投阴影**：在浮点纹理中保存每块灯板的颜色和强度；每个片元累加附近灯板的贡献（发光方向余弦 × Lambert / (d² + ε)），再加一项反弹光。没有遮挡，因此照明是平的。每盏灯有少量暖／冷／绿偏差；少数灯坏掉，少数灯闪烁，比例均为百分之几。环境光遮蔽用于加深接缝。
- **雾跟随局部光照**：雾色 ×（局部光照 / 平均光照）。灯坏掉的地方雾会变暗，因此那里的剪影读起来像**光线中的空洞**。背景 = 雾 × ~0.15，使走廊逐渐融进黑暗，而不会变成明亮墙面。
- **克制的破旧痕迹**：部分墙脚有潮痕，天花板下有褪色带，少量接缝剥落、几块发黄或缺失的顶板、灯罩内有死虫。各项比例控制在个位数。
- **印刷品**：办公激光打印在泛黄纸上，标题用窄体无衬线字，含表格编号和修订版号、编号规则，以及“管理处”的礼貌结尾。纸张钉起或贴起。
- **VHS 摄像机处理**（不是 CRT）：细小线抖（低频摆动 ≤ 0.25 px）、磁头切换带、按需出现跟踪撕裂、画面有桶形畸变和暗角但 **OSD 不受影响**、亮度模糊与边缘振铃、色度向右拖尾、轻微光晕拖影、白平衡漂移、暗部自动增益噪声、信号掉失、黑位抬高、柔和削波。噪声按磁带速率变化（30 fps）。没有扫描线，也没有 RGB 遮罩。
- **OSD**：手制位图字体带黑色描边，包含 REC 指示点、电池、时间和日期。摄像机标题生成器使用相同字体，但字号更大。

## 配色

- **一种主导的病态色调**，来自地点材质（芥末色墙纸、机构绿、医院蓝、米色贴面板），并搭配更深的装饰线和同色系斑驳地面；天花板与灯板接近暖白。
- **恰好一种饱和色**：一个信号色，例如红色警报灯、绿色紧急出口标志、琥珀警示灯。只有它产生辉光（把其自发光亮度推到超过辉光阈值）。
- 白平衡会漂移；画面永远不会被调成干净稳定的颜色。
- 示例材质色：墙纸 `#d5bd66`、饰边 `#4d3d26`、地毯 `#8c763c`；泳池瓷砖 `#9fc7c0`、填缝 `#e6ece6`、池水 `#5e8f96`；学校走廊 `#b9c49a`、储物柜 `#6f7f66`、油毡地板 `#a89a7d`。

## 字体

- **闭路字幕（CEA-608 风格）**：等宽字体（例如 IBM Plex Mono 600），约 42 px；每行白字置于实心黑框，最多 32 个字符，位于 4:3 画面内、OSD 上方居中。不受磁带噪声影响（电视机会解码它们）。停留时间不少于 `max(1.8 s, 台词时长 + 0.6 s)`。
- **说话者标记**：公告用 `[PA]`，操作者台词用斜体；SDH 声音描述放在方括号中（`[LIGHTS FLICKER]` 灯光闪烁、`[TAPE NOISE]` 磁带噪声、`[SILENCE]` 静默）。
- **告示上的规则不加字幕**：它们就是画面内容。以 1080p 播放时应能读清，无遮挡至少 3–4 秒。拍特写时**降低相机，使镜头与纸页平行**；对垂直纸张向下俯拍会把文字拉斜，像假斜体。
- **片名**使用摄像机标题生成器字样，覆盖在第一个镜头上。

## 运动

- **一镜到底的手持拍摄。**只有磁带发生断点时才切镜：开机卷入画面、跟踪撕裂、REC 停止。
- **手持感** = 行走步态（头部上下几厘米、摆动、小幅滚转）+ 呼吸（约 0.27 Hz）+ 几种频率的颤动噪声，其振幅随**恐惧曲线**变化。屏住呼吸时，**全部运动冻结**。
- **低头时**只看见鞋尖与地面，绝不出现腿。
- **自动对焦** = 带过冲的焦距动画：模糊 → 锁定 → 滑开 → 再锁定。模糊来自向近处拉焦。变焦会缩窄视场角并开大光圈。
- **灯光闪烁**表现为短暂熄灭（约 0.1 秒）；自动曝光经过滞后（约 0.45 秒）才补偿，增益噪声随之涌动。
- 物件会自行缓慢移动（门移动超过 1 秒且带缓动），不会突然跳动。

## 画面怎么活

手持画面跟随步态、呼吸和恐惧曲线；灯具短暂熄灭并由自动曝光滞后补偿，对焦持续寻找。静止屏息时冻结整套手持运动，这是来源明确的动作状态而不是全片静态原则。

## 镜头语法

镜头是一套词汇，不是固定路线。开场和结尾由主题决定。

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| POV 沿走廊行走 | 日常、无尽感 | 建立空间、时间流逝 |
| 从细节缓慢摇向空间 | 尺度；空间仍在延伸 | 揭示、初见 |
| 低头瞥向脚边 | 服从、回避 | 遵守规则、不愿看见 |
| 蹲下并停留在印刷文字上 | 阅读、官僚制度 | 规则、矛盾 |
| 变焦并向远处反复对焦 | 看见／看不见 | 某种存在、怀疑 |
| 磁带撕裂后保持相同构图，只改变 OSD | 时间被抽走 | 跳时、失去 |
| 转过拐角后停住不动 | 门槛 | 出口、选择 |
| 无声地缓慢推近 | 被某物吸引 | 一扇门、一个标志 |
| 拍摄时向后退 | 撤离、恐惧 | 离开房间、违反规则 |
| 把相机放在表面，固定拍摄并继续录 | 被遗弃 | 操作者消失、漫长等待 |
| 因声音猛转镜头，然后什么都没有 | 期待落空 | 没有来源的声响 |

构图时让文字清楚且无遮挡；任何异常存在都要小、远，并处于灯光失效区域。转场只能来自磁带事件。

## 声音调色板

- **不加配乐。**只保留磁带实际录下的声音。音乐仅存在于故事空间内（背景音乐、隔墙传来的收音机声、失真的 PA 铃声），并经过滤波和混响；也可以随磁带颤音而减速。
- **荧光灯底噪**：120 Hz（或 100 Hz）及其谐波、经过带通的嗡鸣成分、微弱镇流器啸声、坏灯管的爆音；与画面使用同一灯光曲线门控；小房间里声音更近。
- **PA 声音**：平静、公司式的天花板扬声器广播（约 300–3500 Hz 带通、扬声器纸盆共振、饱和、房间混响），保持足够干燥以便听清。广播前有一段原创短提示音；跳时之后，提示音和人声可以一起走音变平。
- **操作者**：少量短而轻的台词，带近讲低频和呼吸声；呼吸速度随恐惧变化，安排一次屏息和一次长呼气。
- **拟音按材料设计**：地毯脚步（低闷击声 + 湿润挤压声）或硬地板吱响、衣料摩擦、摄像机咔哒声和马达声、变焦伺服声、自动对焦咔嗒声、灯闪时镇流器轻敲、铰链黏滑声、头顶拖拽声、自动售货机声、管道声。
- **静默**：数字零电平持续一秒或更久（包含尾音），并标注 `[SILENCE]`（静默），是最有力的工具。最多只做轻微惊吓：声音回来时，所有灯同时重新点亮。
- **嗡鸣底音**选项：缓慢上升并带拍频正弦波的低频棕噪；房间底噪本身逐渐变调；或者什么也不加。
- **混音**：床底声和世界内音乐比人声低约 8 dB。−14 LUFS；不额外添加颗粒（噪声已经在画面里）。

## 原生手法

可从下列菜单中选择故事需要的手法。

- **自动对焦／自动曝光寻找。**只有对焦正确时，某物才会显现。*适合：*酒店楼层里失踪的宠物、空体育场中的人影、医院走廊尽头的形状。
- **磁带跟踪损伤。**撕裂是宇宙造成的剪辑；之后构图相同，但时钟跳了、电池耗尽、一盏灯熄灭。*适合：*夜间值班记录、商场里失去的一周末、两盘录像之间逐渐老去的房子。
- **OSD 就是情节。**REC、电池、日期和时间码都是证据。*适合：*不在场证明、倒计时、带日期的检查记录。
- **画面中的规则文字。**告示和 PA 广播从普通内容逐渐变得不对劲，互相矛盾，最后开始对观众说话。*适合：*泳池安全规则、学校消防演习、闭馆后的博物馆。
- **空无与重复。**同一告示出现在不同地点；同一房间只有一个细节改变；走廊通向雾里。*适合：*搬家检查、凌晨四点的机场、裁员后的办公室。
- **几乎像人的东西。**远处剪影有 15–40% 的比例错误（小头、长脖子、窄而高的肩膀、长手臂），以有机曲线画在广告牌上并缓慢移动。*适合：*并非普通模特的人偶、夜班保安、延迟的倒影。

## 变化空间

由你决定地点与材质、拍摄流程或缘由、规则、路线、是否出现某种存在、信号色、开场、结尾和片长。

应远离来源示范片：

- 结构：**两盘录像带**（同一路线拍两次、相隔一年；第二盘发现了变化）；**房产介绍**（操作者愉快地逐间介绍房间，房子却不断增加新房间）；**逐项朗读清单**，每读一项便在画面中的夹板上打勾，直到出现清单上没有的一项。
- 开场：**从一句话中途开始**（操作者已经在说话，磁带仍在卷入）；**测试图**和带日期的场记牌出现在拿起相机之前；**镜头盖仍盖着**，先只有声音，之后才揭开。
- 结尾：**电池耗尽**（图标闪烁，画面冻结在空电池上）；**把相机放下**，让它继续拍摄空房间；**磁带循环**回第一镜，但现在能看见操作者的鞋子。

## 坑

- **场景全亮会读成医院走廊** → 隔墙之间留缺口，让远处落入暗部。
- **灯光穿墙泄漏**（没有遮挡）→ 某个暗区约 ±5 m 范围内的所有灯都必须熄灭，并让其后方空间变暗。
- **走廊尽头背景变成明亮矩形** → 背景 = 雾 × ~0.15。
- **均匀的雾把剪影提亮成灰色** → 让雾跟随局部光照变化。
- **线抖让文字歪斜；向下俯拍让文字变斜体** → 抖动 ≤ 0.25 px，并降低相机。
- **用基本几何搭的人物像玩具，腿像管子** → 用有机剪影，只展示鞋尖。
- **纯红自发光太低，不会产生辉光**（亮度太低）→ 把亮度推得高得多。
- **按滤波前峰值对滤波信号归一化会让总线爆音** → 按处理后的信号归一化。
- **PA 混响过重会毁掉可懂度** → 用 ASR 检查处理后的台词和完整混音。
- **广告牌在 AO 中留下深色矩形** → 在 AO 阶段排除它们。
- **压缩已经完成的时间线** → 在原始时间上设置关键帧，再通过一个统一时间扭曲函数映射；其他硬编码时间也必须一并处理。
