# 产品界面重绘演示（非实机录屏，product-ui-redraw-walkthrough）

> 一句话：真实产品界面和功能状态被重绘成可控的演示画面，低分辨率角色沿界面行动；这是模拟演示，不是实机录屏。

> 来源参照（只学语法）：
> 一段看起来像真实屏幕录制的产品演示，低分辨率吉祥物生活在高分辨率界面中，并演出软件正在执行的操作。
> 参照（只学语法）：
> - **Screen Studio 风格的产品录屏：** 自动放大光标、平滑光标移动、点击时推近、窗口浮在桌面壁纸上。
> - **Apple “Guided Tour” 视频：** 真实界面、平静旁白、每句话介绍一个功能。
> - **Duolingo 与 Headspace 的吉祥物动画：** 挤压与拉伸、预备动作、在 UI 内表演的角色。
> - **The Browser Company（Arc）发布影片：** 俏皮语气与快速剪辑。
>
> 不复制它们的角色、UI、音乐或影片素材。
>
> 这是一个软件功能演示，通常 45–75 s。用户提供产品和功能；由你决定故事、镜头、动作编排、声音和音乐。

## 本质 / 不是什么

影片看起来像**真实产品的屏幕录制，**但它不是录屏。每个窗口、菜单、代码差异行和按钮都用 **2D（HTML/CSS/SVG）重绘，**因此相机可以移动到任意位置，每个像素都可控，文字无论放大多少都保持清晰。

一个由**大方块像素构成的吉祥物**生活在这个高分辨率世界中。两种分辨率的冲突——硬边低分辨率精灵与经过抗锯齿的 UI——就是它的视觉风格。

吉祥物让软件的行动能力变得可见：软件读取时，它沿着正在读取的行奔跑；软件规划时，它握着一支像素铅笔；软件测试时，它踩下按钮。

**两个角色，绝不出现手：** **光标**代表用户操作；**吉祥物**代表软件行为。这是以重绘方式模拟产品，不是真实屏幕录制、截图，也不能证明真实用户执行过画面中所示步骤。若交付物必须记录实际产品操作，应使用真实录屏。

它不是暗色科技主题演讲（没有黑色舞台，也不捏造抽象 UI：画面展示真实产品），不是像素风格游戏（世界是高分辨率矢量 UI，只有吉祥物和它的道具是像素），也不是实机录屏（没有任何截图）。

## 材质与渲染

- **真实 UI，全部重绘：** 每个标签、模式名和快捷键都与真实产品一致；不放截图，不用 lorem ipsum。演示内容（代码、数据、测试输出）必须连贯，且被演示的应用真的会改变状态。
- **像素网格是硬约束：** 吉祥物、道具（铅笔、“!”、闪光、爱心、灰尘）和拖尾共同使用一个方形像素网格，边缘清晰。随着相机缩放；位置吸附到半像素，使运动有阶梯感。
- **重力 = UI 元素的上边缘：** 吉祥物只站在真实元素（输入框、菜单、列表行、代码行、按钮、状态栏、标题字母）的顶边。位置**每帧通过测量实时 DOM**获取，绝不手动摆坐标。
- **壁纸上的窗口：** 应用窗口浮在桌面上并带柔和投影；放大时不能看到显示器之外。
- 只有为注意力服务时才表现**深度：** 用机架式对焦模糊不相关面板，或加暗角聚光；绝不模糊观众需要阅读的文字。
- **运动模糊**根据相机速度推导，只在甩镜时加到**未变换的包装层**上；慢速镜头保持清晰。

## 配色

- 产品自身的界面颜色优先：严格跟随真实的亮色和暗色主题。
- 吉祥物使用产品/品牌既有角色色，或使用一种 UI 中没有的饱和色，使其在任何画面中都易被看到。
- 叠层（章节胶囊、按键 HUD、字幕）使用中性磨砂玻璃；最多一种强调色，且从产品配色中选择。
- 主题切换可以成为故事事件：整个影片可随主题切换改变状态。

## 字体

- UI 文字依照产品本身的字体（或使用 Inter、JetBrains Mono、适合编辑类 UI 的衬线体等免授权限制的相似字体）。
- **只允许信息层：** 章节胶囊（01–04）、KeyCastr 式按键提示 HUD、磨砂玻璃字幕胶囊、可选的“▶▶ 4×”延时标签。不能再往屏幕上叠加其它东西。
- 字幕放在底部胶囊中，不能盖住正在讲解的元素，也不能被吉祥物挡住；保持至少 max(1.8 s, 语音时长 + 0.6 s)。
- 若有片名，必须是场景中的文字：作为 UI 的一部分出现（空状态标题、窗口标题或通知）。

## 运动

- 30 fps；UI 每帧一格动画；吉祥物位置吸附到像素网格。
- **吉祥物表演：** 起跳前蹲下预备，起跳时拉伸，空中收腿，落地时挤压并带阻尼回弹和扬尘。待机时跟着配乐节拍微微挤压呼吸并不规则眨眼。走路通过左右腿交替，并按方向翻转精灵。
- **眼睛承载表演**（中性 / 左 / 右 / 上 / 下 / 睁大 / 开心 / 闭眼 / 眨眼）：视线看向当前重点。手臂姿势：下垂 / 举起（欢呼）/ 挥手。
- **光标：** 使用平滑、弹簧缓动的路径，点击时轻推一下，绝不瞬移。
- **因果关系：** 每个吉祥物动作都触发真实 UI 状态变化；每个用户动作都要表现为光标移动、点击或 HUD 上的按键操作。
- UI 按真实产品的方式动效化（自身菜单、弹出层、代码差异揭示）；不能捏造产品没有的装饰效果。

## 画面怎么活

像素角色在等待时小幅呼吸并不规则眨眼；光标沿平滑弹簧路径移动，界面只在真实产品状态变化时响应。镜头和 UI 仍按来源连续工作流设计。

## 镜头语法

像录屏软件一样让镜头在屏幕内部连续移动，缩放不得小于 1，仅在章节转场处切镜。开场和结尾由主题决定。

| 镜头变化 | 表达作用 | 可用于 |
|---|---|---|
| 推近光标或文字插入光标 | “事情发生在这里” | 输入提示词、选择菜单项、更改设置 |
| 静止时缓慢漂移 | 我们听讲时应用仍有生命 | 一行旁白、等待结果 |
| 带模糊的甩镜在面板间移动 | 这里的原因、那里的结果 | 发送消息 → 结果出现；代码 → 预览 |
| 推近 + 暗角冻结 | 唯一需要记住的承诺 | 安全保证、价格、撤销功能 |
| 面板之间机架式换焦 | 注意力转移，其它东西不动 | 阅读文件；日志滚动而聊天等待 |
| 拉远到整个窗口 | 把完整流程放进视野 | 总结、并行任务、前后对照 |
| 沿列表跟随吉祥物 | 软件逐项处理工作 | 扫描结果、检查清单、迁移 |
| 重新取景成分割窗口 | 同时看到两个事物 | 并行会话、比较两个版本 |

正在讨论的对象和它的字幕不得重叠；吉祥物不得挡住需要阅读的文字。转场使用章节胶囊擦除、像素擦除或主题切换圆形揭示；不用溶解或截图。

## 声音调色板

- **音乐中有两种分辨率：** 高保真层（钢琴、原声或电贝斯、刷奏或紧凑鼓组、钟琴、真实采样）代表世界；芯片音乐的方波或脉冲音色代表吉祥物。两者可以交替、对奏或融合。
- 可选：暗色主题时对乐队做低通，做成“夜晚”版本；章节交界用通鼓滚奏和镲片；抽掉鼓声建立紧张感；吉祥物落在台词词语上时配音符；分屏时让声像左右分离；冻结画面下铺单一长音垫底。
- **拟音：** 键盘（厚重敲击 + 点击，带有人手的时序抖动）、触控板点击、面板滑动、弹出层弹出、通知铃、CI 提示音、截图快门声。吉祥物步伐、跳跃和落地使用 8-bit 音效。
- **静音：** 关键承诺出现前短暂退到房间底噪，让它更有分量。
- **人声：** 语气平静，每句话介绍一个功能；用 whisper 核对产品名称。音效不能盖住词语起音。人声下方让音乐避让；−14 LUFS。

## 原生手法

以下是方法菜单，按演示需要选用。

- **匹配剪辑诞生。** 吉祥物从已经存在于 UI 的元素中诞生（标志的方块字、图标、载入旋转圈），再爬出来并留下轮廓。*适合内容：* 聊天气泡变成向导、图标变成助手、载入动画变成帮手。
- **场景内片名。** 名称作为真实 UI 元素出现；吉祥物在重拍上落在其上。*适合内容：* 空状态、新项目对话框、欢迎邮件。
- **移动的地面。** 吉祥物乘上插入光标、弹出层、已发送消息或进度条。*适合内容：* 消息飞进聊天串、上传进度条、拖放。
- **带标签的延时。** 长时间工作以 N× 倍速播放，同时有闪动标签和机架式换焦。*适合内容：* 索引资料库、导入数据、构建项目。
- **聚光冻结。** 推近并用暗角强调承载承诺的单个徽章。*适合内容：* “已保存”、“已加密”、“……之前不收费”。
- **影片随主题切换改变状态。** 切换按钮的效果离开预览，接管整部影片，并在之后恢复。*适合内容：* 深色模式、语言切换、离线模式。
- **细胞分裂。** 新会话或窗口把屏幕分开，吉祥物也伴随像素爆发分身。*适合内容：* 并行任务、多个账号、团队成员。
- **光标和吉祥物都是角色。** 光标抚摸、戳或拖动吉祥物，吉祥物作出反应。*适合内容：* 同意建议、撤销操作、新手引导中的趣味。
- **逐词跳跃卡拉 OK 点。** 吉祥物随着口播，从一个词跳到下一个词。*适合内容：* 口号、快捷键清单、步骤名称。

## 变化空间

由你决定功能与顺序、吉祥物（产品现有角色或原创像素人物）、故事、开场、结尾、相机路径、章节和音乐。与演示片保持足够差异：

- 结构：**寻错**（吉祥物沿日志、代码和修复追逐一个错误，作为单章）；**一个用户的一天**（从早到晚都在一个应用中，主题与音乐随时间改变）；**竞赛**（两个窗口并排，旧方法对新方法，吉祥物在右侧获胜）。
- 开场：**任务进行到一半**（文档只写了一半，吉祥物已在推动光标选区）；**一则通知**（系统提示弹出，吉祥物就在其中）；**空状态**（空白应用里文字光标闪烁，吉祥物从菜单栏落下）。
- 结尾：窗口变暗，**吉祥物在已完成的项目上睡着**；**应用关闭**，吉祥物留在程序坞上；**真正的分享**（结果已发送，吉祥物搭乘它一起离开画面）。

## 坑

- **捏造功能或改名模式** → 对照产品文档核实每个按钮、模式和快捷键；文档中没有的内容不应出现在影片中。
- **吉祥物漂浮或离开元素** → 每帧测量 DOM，只站在元素顶边。
- **吉祥物挡住文字或落在字幕下面** → 为它预留没有文字的通道。
- **对必须阅读的文字套用模糊滤镜伪造深度，或拉远到显示屏之外** → 只对当前不阅读的面板机架式换焦；缩放 ≥ 1。
- **画面里出现手、胳膊或手指** → 用户由光标代表。
- **对已经变换过的图层加运动模糊，会把像素精灵拖糊** → 模糊未变换的包装层，并且只在甩镜时使用。
- **按键或弹出层的落点盖住产品名称** → 将拟音移开词语起音，并用 whisper 复查最终混音。
- **TTS 把产品名称念错** → 尝试不同声线和拼写，再用 whisper 核实。
