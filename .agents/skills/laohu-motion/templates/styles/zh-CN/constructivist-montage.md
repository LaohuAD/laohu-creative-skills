# 构成主义蒙太奇（constructivist-montage）
> 本页为中文译文视图；来源定位见文末「来源与证据」。

> 一句话：用摄影碎片、斜向色带、醒目的字体和有节奏的切镜，通过并置形成论证。
> 参照（只学语法）：语法参照：1920 年代苏联蒙太奇电影（分屏、计数和机器节奏构成的城市交响曲；A + B 产生一个概念的“智性”蒙太奇），构成主义海报与摄影拼贴（红 / 黑 / 纸张、陡斜线、几何色块中的照片剪影、把字体当作结构）。不得复制它们的镜头、版式、口号或字样，也不得在影片中点名。

## 本质 / 不是什么

1. **重剪证据。** 每幅画面都是真实且与实际主题有关的材料（档案胶片、照片、文件）。影片的论证来自如何剪切和布置它们，而不是靠插画。
2. **整张画面像同一张印刷品。** 所有素材统一转换成双色印刷效果（暖色油墨 → 纸张）；红色是唯一彩色，并作为印刷元素叠加在表面。
3. **节拍负责剪辑。** 切镜、砸入、擦除和计数都踩在 120 BPM 网格（或配乐速度）上；每到一个段落，就通过将镜头时长减半来加速。
4. **字体就是结构。** 文字和数字像梁柱：沿 −18° 色带排布、组成实心色块或垂直堆叠。绝不让字幕漂浮在画面上。
5. **集体高于个人。** 画面强调人群、手、机器和大量小人物；单张脸永远不是主角。

不做 **Data Storytelling（数据叙事）** 或发布会演示：没有居中标题加项目符号、幻灯片转场或页眉条；数据以有标注的文件、计数器和测量条的形式进入构图。不做 **Swiss Motion Graphics（瑞士动态平面）**：采用不对称和斜线，不留白网格，也不用细线装饰。不做 **Art Deco（装饰艺术）** 或 **60s Spy Titles（60 年代间谍片标题）**：没有金色、细线或爵士乐。也不是博物馆幻灯片：档案素材绝不放进中性画框里原样展示，而要经过裁切、窗口化、堆叠和计数。

## 技术路线

本节列出的源码文件/函数名用于定位来源工程的实现示例，不是本地 API；Motion 可按本片需要使用原生工具实现其中的视觉方法。

- `index.html`：一个无状态的 Canvas 2D 页面 `render(t)`；场景函数绘制完整画面。擦除时先绘制旧场景，再裁切并绘制新场景，最后绘制色带。`txt()` 绘制旋转文字框并登记供 `readcheck.mjs` 检查；`reg()` 登记逐块绘制的组合；`slam()`、`flash()`、`flicker()`、`shake()`、`slant()`（平行四边形窗口）、`cover()`（按焦点填充窗口）、`clipImg()`（正放 / 倒放 / 往返 / 速度）。
- `tools/prep.py`：执行印刷调色、提取 24 fps JPEG 序列片段（每段素材一组百分位）、处理静帧、文件页面和轮廓抠像、人物剪影。`tools/fonts.py`：获取 OFL 字体，并按实际使用字符为 Noto Sans SC 生成子集。`tools/cues.mjs`：从页面自带表格生成字幕段，并逐条测量为单行。`audio/mix.py`：配乐、拟音、旁白、环境声和母带处理。
- 检查工具：`readcheck.mjs`、逐行 `asr_check.py`、最终混音的 `tools/final_asr.py`、`tools/rhythm_report.py`（检查平铺窗口、切点和重音对齐起音情况）、`mux.sh` 响度检查。



## 材质与渲染

- **只用四类元素**：**色带**（红色或油墨色，沿轴线布置）、**窗口**（承载胶片或照片的矩形 / 平行四边形）、**剪影**（从照片中剪出、带纸白边的人物）、**文字块**。除此之外，整幅画面叠一层纸纤维纹理。
- **印刷调色**（胶片、照片、文件共用一个处理函数）：亮度 → 百分位拉伸（胶片按每段素材设一对百分位，避免亮度抽动；0.7 / 99.5；照片 0.8 / 99.4）→ S 曲线 `x + s·(x−0.5)·(1−|2x−1|)·2`，s = 0.32（文件为 0.18，保留纸张原色）→ 映射到油墨 → 纸张：`rgb = INK + (PAPER − INK)·g`。档案胶片在窗口内保留逐帧 ±2.5% 闪烁（`hash(frame)`）；照片和文件不闪烁。
- **剪影**：使用人物分割模型（u2net_human_seg 经 onnxruntime）→ 阈值 0.5 → 中值滤波 → 最大连通分量 → 将遮罩向外膨胀，形成 7 px 纸白边。纸边属于这种媒介本身的视觉特征，也能遮住模型边缘误差。合照很少能干净地分割：应把整张照片留在窗口中使用。
- **文件**：使用全分辨率扫描件，绝不重新排字。用红色高亮条以 `multiply` 叠在原句上；用手绘红椭圆圈出标题；在地图上画红圈。文件上的图表、地图等绘图可以从纸面抠出后重复使用，按纸张亮度进行抠像（`alpha = (205 − luminance) / 90`）。
- **分辨率上限**：屏幕上的档案胶片不超过其来源像素的 2.5×，现代影像不超过 1.5×，照片尽可能保证每个屏幕像素对应至少 1 个来源像素。调色前用 `hqdn3d → lanczos → light unsharp` 预处理片段；颗粒只在母版混合时添加。一段 720 线胶片转制素材可以放满 1,700 px 宽的窗口，但不能铺满 1080p 全画幅：应放进窗口、分割条带或虹膜画框，而不是拉伸它。
- **纸纤维**：在整幅画面上乘入一张固定随机种子的噪声画布，α 0.5；胶片颗粒 4 由 `mux.sh` 添加。

## 运动

- **网格**：画面与配乐使用同一速度（120 BPM：一拍 0.5 s，一小节 2 s）。每次切镜、砸入、擦除和计数都落在整拍、半拍或十六分音符上。页面将这些时间导出为 `window.EV`；混音读取同一列表。
- **镜头长度**：影像镜头为 0.5–2 s；每镜只表达一个想法。某段可通过镜头长度减半来加速：0.5 → 0.25 → 0.125 s（不得短于 3 帧）。停留只用于阅读：文字块、定格或比较。
- **切镜规则**：相邻镜头至少在一个维度上形成冲突：方向（从左 / 从右砸入）、明暗值（纸张 / 油墨底色）或几何形状（斜色带 / 竖直窗口）。绝不连续放两张纸面文件。
- **媒介内部的转场**（每个切点挑一种，不做淡化）：
  - *红色擦除*：260 px 宽的红色条带以 72° 角（垂直于轴线）在 0.25 s 内扫过画面，下一场景从后方显露；落在强拍上。
  - *虹膜*：在地图或照片上画红色标记圆圈，让它变成光圈并打开，显露影像。
  - *砸入*：下一个元素沿轴线从画外进入，历时 0.08–0.2 s，缓出后急停，并让画面震动（振幅 3–18 px，`exp(−14·Δt)`）。
  - *闪切*：在切镜或定格处，让窗口上闪过一帧纸白画面，不透明度为 50–80%。
  - *强拍硬切*：在明暗值相反的底色之间切换。
  - *跳入*：定格内部切到同一画面的 1.2× 裁切，标注也同步缩放。
- **两处静默**：一处由乐队停下，只剩真实录音；另一处是真正的半小节静默（油墨色画面、一个红点），放在最重的重音之前。

## 画面怎么活

- 停留超过一秒的镜头，按来源让窗口中的档案片继续播放、让有事实依据的计数器推进、缓慢推镜，或保留画中画内层运动；不需要每项同时出现。
- 比较停顿、一个静音拍和片尾卡是来源明确允许静止的例外。

## 声音调色板

- **配乐**：原创的机器固定音型（八分音符、小调，例如 D–D–F–D–A–D–E–F），由断奏大提琴 + 短音巴松管演奏；大号 / 长号在重拍短促演奏，小军鼓敲十六分音符，木琴为计数发声（每个亮起的格子或建成的楼层上升一个音），圆号 / 小号短促重击并演奏一小段铜管动机，段落切换前定音鼓滚奏，最重的重音配大鼓（gran cassa）+ 锣。采样音源使用 CC0 库（VSCO 2 CE、VCSL）。不用钢琴加弦乐的铺底。
- **原声与配乐交替**：某一段由乐队停下，改用真实录音（铆钉枪、机器、人群）单独承接切镜；每段录音都裁到对应镜头长度。提前一拍进入（J-cut）。
- **每个印刷动作都配拟音**：砸入 = 低沉闷击 + 钢铁碰撞；盖章 = 闷击 + 咔哒；擦除和虹膜 = 呼声；标记笔 = 滤过的摩擦噪声；纸张 = 带通处理的沙沙声；楼层和网格格子 = 有音高的金属碰击。
- **分层**：环境声（真实地点 / 街道录音，比旁白低约 20 dB，静默段撤掉）；拟音在说话时压低 35%；音乐在说话时压低 70%（比旁白低约 10 dB）；旁白按 RMS 压缩并校平。混音至 −14 LUFS；在 `mux.sh` 之前把峰值限制到 −1.8 dBFS，并在采样点 0 加 25 ms 淡入（AAC 编码会让首个采样点的重音超峰）。
- **旁白**（影片包含旁白时）：短句陈述，采用新闻片节奏；每种画面格式上最多讲一个句子；TTS 中把数字拼写成文字，字幕中仍用数字。

## 原生手法

1. **给文件做标记，不要只引用它**：扫描页中的真实句子加一条红线；随后把数字单独变成红色块。
2. **让文件变成图表**：将印在页面上的图形抠出、转向，按比例立在一条地面基线上。
3. **A + B → 一个想法**：两类图像越来越快地交替（机器 / 双手；标题 / 标题遗漏的人群），直到卡片或数字说出并置产生的含义。
4. **数出众人**：计数器随切镜推进，网格逐格填满，塔楼逐层建起。
5. **由人物搭起结构**：将剪下的人物堆叠成他们建造的东西（摄影拼贴）。
6. **静默，然后让最重的重音落在结果上。**

## 变化空间

每部影片由 Agent 决定：结构、所用档案和文件、采用哪些格式（不必一部片用完所有格式）、轴线角度（−15° 至 −30°）、红色的具体色相、速度（100–140 BPM）、是否使用旁白（只用字幕卡也成立），以及标志性建造画面（塔楼、桥梁跨度、人群拼出一个词、地图逐渐填满）。

- **三种结构：** 日历机器（一个计数器贯穿影片，在里程碑处停下）；文件提出问题、影像回答问题（中途转折）；一个物体走过完整流程，随后展示整体规模。
- 适合的主题：建筑与工程史、工业周年纪念、大型集会、劳动与集体努力、基础设施开放，以及任何有档案胶片和文件支撑的“许多人、同一机器节奏”故事。


## 坑

- **放大后的档案胶片**铺满 1080p 全画幅时会糊成一团：应放进窗口、拆成分割条带，并将推近限制在 2.5× 上限内。
- **逐帧调色会抽动**：每段素材只用一组百分位。
- **色带上的字跑出画框**：按色带中心线（基点 + 法线）放置，不要凭目测。
- **红上加红**：红色底上的红色答案块会消失；改用油墨色。
- **把脸当英雄**：普通且可识别的工人以群像、工作状态和快速切镜呈现；不慢放，也不把某个人拍成特写主角。
- **计数器容易被当作事实**：只给最终值和带日期的锚点加标签；计数器旁的字幕必须在每一帧都与显示数字一致（字幕显示期间，计数应停在该字幕对应的数字）。
- **数字缺少单位**：所有计数器都要在相同版式中带上单位（小时 / 层 / 人 MEN）。
- **窗口上的油墨字**：文字超出照片边缘后会落入深色胶片而消失；给文字加纸色标签，或让它避开窗口。
- **结论挡住被比较的内容**：等内容停留结束后，把结论放在没有项目的位置。
- **文件太多**：每个文件镜头只标记一个句子；一页上有三处高亮就像幻灯片。
- **加速段里的短标签**会因为预设时长而读不完：1/8 拍切镜期间不放文字；结果放进之后停留的色块。
- **采样点 0 的重音会在 AAC 编码中超峰**：对最初 25 ms 做淡入。
