# 电视新闻包装（broadcast-news-package）
> 本页为中文译文视图；来源定位见文末「来源与证据」。

> 一句话：电视新闻包装用一致的播出图形系统组织标题、事实、地图和新闻影像。
> 参照（只学语法）：语法参照：晚间电视新闻标题菜单、财经频道市场图形、欧洲新闻频道的解释地图、科技新闻桌的规格卡。不得复制任何广播机构的标志、布景、字体、颜色、音乐或识别片头，也不得在影片中点名。

## 本质 / 不是什么

1. **整片一致使用一套包装系统。** 每个图形都由同一组少量组件构成：品牌牌（平行四边形）、强调色标签、纸色新闻条、顶边带强调色的油墨卡、等宽日期、印章。观众会先读懂系统，再读具体文字。
2. **按新闻简报的顺序组织。** 片头音画点题 → 新闻目录（简短列出各条新闻）→ 单条新闻 → 单条新闻 → …… → 回到目录并逐项打勾 → 节目收尾。每条新闻都先在新闻条标签上标明类别，并在第一张图形上标日期。
3. **每屏只讲一条事实。** 满版图形只陈述一件事：一个价格、一道门槛、两只股票、一个地点、两封信、一段引文或一个结论。
4. **新闻条承载标题。** 从第一条新闻到回顾页始终保留同一条下三分之一信息条；文字用垂直翻转更换。上方画面留给图形使用。
5. **画面干净。** 不放滚动新闻条，也不把字幕烧录进画面；字幕以独立 `.srt` 提供。每帧只包含图形、新闻条、角标和来源行。

不做 **Caption News（字幕新闻）**（那是字幕优先的社交视频，以醒目的砸入式大字幕领画面，没有新闻目录和新闻条；这里的字体小而有秩序，图形领画面）。不做 **Data Storytelling（数据叙事）**（每拍一张图表，绝不做仪表盘；图表只是新闻简报中的插段）。不是发布会演示：没有居中标题加项目符号，也不翻页。不是演播室节目：没有虚拟布景、主播或飞越镜头——包装由叠在油墨底上的平面图形构成。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 来源正文中的可见/可操作描述 | 适配主题 |
|---|---|---|
| 120 BPM 网格 | 强拍 0 落在片头音画点题结束处（1.5 s）。每次切镜和擦除都落在整拍或半拍上。 | 新闻快讯、周报与事实摘要。 |
| 镜头长度 | 片头 1.5 s；新闻目录 4–5 s；新闻镜头 3–7 s；地图长镜头 6–12 s，作为新闻简报的呼吸段；比较画面至少停留到每个项目都完整上屏 2.5 s。 | 新闻快讯、周报与事实摘要。 |
| 每 0.5–1 s 安排一次包装动作 | 镜头内部可翻转、计数、盖章、打勾、更换新闻条、点亮地图或推进线条。画面静止不得超过 1 s；每个切点后 0.5 s 内要有有力动作。 | 新闻快讯、周报与事实摘要。 |
| 每条新闻都标日期 | 周报中的新闻发生在不同日期；日期放在目录行、眉题、读数或文件上。 | 新闻快讯、周报与事实摘要。 |
| 单条新闻内部的顺序 | 是什么（名称或数字）→ 规模多大（线条、柱形、价格板）→ 影响谁或是谁说的（柱形、文件、引文）→ 盖上结论印章。 | 新闻快讯、周报与事实摘要。 |
| 包装层被留在原地 | 如果新闻条、来源行或标签只在最上层绘制一次，擦除会让旧标题下方的画面先换成新图，而新闻条要晚 0.3–0.5 s 才跟上。应在每幅画面内部、擦除蒙版范围内分别绘制它们。 | 新闻快讯、周报与事实摘要。 |
| 留下的空版面 | 移除字幕或滚动新闻条后，若不把内容下移，新闻条上方会留下一道空带。 | 新闻快讯、周报与事实摘要。 |
| 被蒙版裁切的文字提前露头 | 若推近标题的移动距离不够越过蒙版，裁切后的文字顶边会在移动前露出来；应让它完全从下方进入，进度为 0 时不要绘制。 | 新闻快讯、周报与事实摘要。 |

列出的是来源正文中的可复用媒介信号；不是固定元素清单。每支按主题选择 2–3 个，其中至少一个避开最常见组合。

## 这个风格最俗的版本

- 来源正文未给出一套固定的俗套画面、配色、配器或开场结尾组合，因此不补造。相邻风格边界与明确排除项保留在「本质 / 不是什么」。
- 每支片子按主题从来源信号中挑 2–3 项，并在简报的风格栏说明保留或改动了什么；故事、数据、构图与时间线重新设计。

## 适配

- 用途：新闻快讯、周报与事实摘要。
- 内容：以当前项目真实素材和用户目标决定是否适配；只借用下方通用媒介规则。

### 新闻事实、素材与署名

画面事实和旁白优先回到机构公告、公司原始页面、交易数据或正式演讲；若信息仅来自媒体报道，明确归因，避免把报道推论写成已确认事实。真实影像、文件截图、数据图与重绘示意分别标明身份；示意图不得冒充实拍、真实产品或现场操作。素材来源、许可、事实依据和片尾署名依项目现有流程处理。

### 来源包装组件规格（源文完整记录）

下列模块来自 L8 的一套包装方案，说明同一品牌板、新闻条、来源行和组件间承接方式。节目题材、具体图表和事件型组件按本片内容重新选择，不作为固定新闻脚本。

| 部分 | 规格 | 规则 |
|---|---|---|
| 片头音画点题 | 0–1.5 s | 两道强调色斜线（0.04、0.10 s）→ 品牌牌带超调砸入，伴随撞击圆环和画面震动（0.16–0.42）→ 字母逐个落下 → 字标和日期从中心打开 → 闪光 → 品牌牌飞到右上角，并在竖向色带擦入首镜时**变成角标**。0.4 s 内响起重音。 |
| 品牌牌 | 520×180 平行四边形，强调色渐变，左侧有油墨色和金色条，名称用窄体 800 | 同一块牌同时承担片头、角标、新闻台正面和片尾卡。 |
| 新闻目录 | 左侧：日期块（大数字、月份、周次）；右侧：三行，每行 1024×140，数字块使用强调色 | 每行在节拍上垂直翻入（回弹缓动），并带闪光；节目收尾时同一目录再次出现，每行逐项打勾。 |
| 下三分之一新闻条 | 见 §2 | 第一条新闻出现时进入；更换新闻时翻转（新文字从下方上翻，旧文字向上翻出，0.32 s；类别变化时标签闪白）；回顾页开始时滑出。另有**人物**版本（标签“人物（PROFILE）”），用于标明发言者。 |
| 翻页数字板 | 数字片为 220×130，上下半片分别裁切 | 同一块板同时展示旧值和新值，便于一眼看出变化；右侧标出 ×2 / +x %。 |
| 门槛图表 | 从峰值画线，门槛用金色虚线表示 | 线头每步前进一个交易日；最后一步以强调色越过门槛，伴随震动和圆环；之后读数面板滑入；坐标轴只显示数据能支持的内容。 |
| 柱形 | 亏损时从零线向下延伸，数值滚动更新 | 加一条共用门槛参考线和标记。 |
| 解释地图 | 使用同一投影，作为一个长镜头 | 按成员距城市的远近依次点亮；显示城市标签、带引线的机构标签和印章；摄影机先推近，再平移腾出空间。 |
| 文件 | 380×490 纸张，油墨色页眉 | 文件从城市圆点沿弧线飞出（0.5 s，缩放 0.08 → 1，旋转逐渐停下）；旁白说到关键词时逐项打勾。 |
| 引文卡 | 油墨色底，叠加包装中的光带；先落下一个大型强调色引号，文字逐行上推（间隔 0.18 s），再出现中文大意、金色细线、姓名、场合和日期 | 保留机构原话及其原始语言；引号内绝不改写；旁白读到关键词时扫出下划线。 |
| 规格卡 | 眉题（来源 · 日期）、从蒙版后推入的产品名称、类别印章、同一比例尺上的整体和局部柱形（数值滚动）、百分比标记、背景信息芯片；右侧另放硬件或地点组，逐格填满，并用括号连到总量 | 所有柱形共用一个比例尺，确保比例真实；每个数字都来自来源页面。 |
| 印章 | 强调色填充或油墨色底，双层强调色边框，倾斜 −6° 至 −10° | 在 0.16 s 内从 1.9× 落下并超调，同时扩展椭圆；每条新闻最多一个。 |
| 转场 | 新闻或节目板块之间用竖向色带擦除（强调色 84 px + 油墨色 5 px + 金色 14 px 边缘，0.3 s）；单条新闻内部使用硬切 + 定音鼓；转入片尾卡时使用斜擦 | 不使用其他转场：没有叠化、3D 翻转、翻页或飞越镜头。**包装层随画面移动**：擦除时两侧都分别绘制自己的新闻条文字、标签、来源行和角落标签（旧状态跟旧画面，新状态跟新画面），让色带擦过标题；硬切时它们在同一帧更换。新闻条文字不翻转，也不重叠。新画面的入场动画在色带下开始，因此它首次露出时就已经有内容。 |


### 来源画面层与调色方法（源文完整记录）

以下图像来源标记、画面处理和素材放大边界均来自 L8 源文；具体资源须另行核对授权与用途。

- 没有实拍影像时，画面层使用代码绘制的数据图形，最多再加入少数**示意图版面**（生成图或图库图）；只要它们还在画面上，就持续标注“示意（ILLUSTRATION）”。它们用于营造气氛（例如产品或数据对比背后的情境背景），绝不冒充事件、地点或人物本身。
- 每个版面使用同一套调色：灰度 → 自动设黑白点（百分位 0.5 / 99.6）→ γ 1.05 → 35% S 曲线 → 黑位 8、白位 232 → 双调 `#0E1013` → `#ECE7D8`（`tools/prep.py: grade()`）；另加左侧深色油墨渐变承托文字、50–55% 暗角，以及在六张纹理间循环的 7% 叠加颗粒。图形和包装本身不加颗粒。
- 若有真实影像，也使用同一套调色路径；现代影像放大不超过 1.5×，档案素材去块后不超过 2.5×；裁掉电视台标志。

## 配色

| 角色 | 色值 | 用途 |
|---|---|---|
| 油墨色 | `#121417` | 背景、版块、新闻条尾块 |
| 第二、第三油墨色 | `#1B1E23` / `#22262C` | 卡片、地图陆地区域 |
| 强调色（柠檬黄） | `#F2CF1D`（浅色 `#F8DE4A`，深色 `#D8B30C`） | 品牌牌、标签、色带擦除、柱形、印章、越过门槛的线 |
| 金色 | `#D4B064` | 门槛、日期、来源行、光片、标记 |
| 纸色 | `#F4F1E8` | 新闻条、文件、图表线 |
| 警报色 | `#FE6B3D` | 只用于“突发”（BREAKING）和“直播”（LIVE）。每周汇总不用这两类标记，因此不显示此色。 |

更换品牌时保留结构：一种强调色 + 一种近似金色的次色 + 纸色 + 油墨色，并预留一种警报色。强调色上用油墨色文字；纸色上用深橄榄色 `#6E5A1E` 排英文次要行，因为金色在纸上对比太弱。

## 字体

- 中文：Noto Sans SC 900（标题、新闻条）/ 700（标签）。
- 拉丁字母：Barlow Condensed 800（数字、名称、品牌牌），600（次要行、引文），600 斜体（片尾卡英文标题）。
- 等宽字体：日期、来源、坐标轴标签使用 IBM Plex Mono 500，全大写，字距 1–4 px。
- 所有字体均为 OFL，使用 `tools/fonts.sh` 从 Google Fonts 获取并生成子集（字符列表读取 `main.js`；文字改变后删除 `fonts/*.woff2`）。本风格不使用手写字体。
- 每个标签都用中英双语，各占一行（中文在前，英文较小）；绝不换行。

## 运动

- **120 BPM 网格**：第 0 拍落在片头音画点题结束处（1.5 s）。每次切镜和擦除都落在整拍或半拍。
- **镜头长度**：片头 1.5 s；新闻目录 4–5 s；新闻镜头 3–7 s；地图长镜头 6–12 s，作为新闻简报的呼吸段；比较画面至少停留到每个项目都完整上屏 2.5 s。
- **每 0.5–1 s 安排一次包装动作**：镜头内部可翻转、计数、盖章、打勾、更换新闻条、点亮地图或推进线条。画面静止不得超过 1 s；每个切点后 0.5 s 内要有有力动作。
- **每条新闻都标日期**：周报中的新闻发生在不同日期；日期放在目录行、眉题、读数或文件上。
- **单条新闻内部的顺序**：是什么（名称或数字）→ 规模多大（线条、柱形、价格板）→ 影响谁或是谁说的（柱形、文件、引文）→ 盖上结论印章。

## 画面怎么活

- 来源以每 0.5–1 秒一次的包装动作组织镜头，长地图镜头和比较画面则留作可读的呼吸段。
- 日期、标签和计数只在各自信息更新时翻换；没有连续新闻爬字或待机动画设定，不额外加入。

运动与循环描述来自来源文字 / 实现说明；本地尚未独立逐帧复现或核验，不作为本地渲染验证。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 地图长镜头内推近并平移，为新标签和机构名称腾出空间 | 让地域关系在同一镜头中展开 | 城市、机构与地区影响关系 |
| 文件从地图城市点沿弧线飞入版面，落地后勾选 | 把文件来源和发出地点连成视觉因果 | 公告、报告、公开信 |
| 产品或方案卡片从遮罩后推入，再以比例尺说明整体与局部 | 先识别对象，再看组成和指标 | 产品发布、方案比较 |
| 竖向色带擦换节目板块；新闻条随画面一起换状态 | 明确切换段落并避免旧标题压在新画面上 | 周报、栏目、多个新闻条目 |

来源明确要求整片保持平面图形包装；不以 3D 飞行镜头或虚拟演播室代替板块运动。

| 板块情绪 | 市场：小提琴降低八度并加入颤音，四拍踩鼓形成心跳感；政策：只用拨奏和圆号。 | |
| 标志性重音 | 片头全乐队齐奏；新闻目录每行落下时敲钟琴；硬切和新闻变更时用定音鼓；最大变化前留一拍静默，再响起全片最重的重音；结论印章后留持续音；最后一条新闻升至大调；片尾卡配全乐队齐奏。 | |
| 拟音 | 擦除配呼声；翻页数字板配翻片声；印章配闷击 + 咔哒；市场图表下铺交易室滴答声；每个亮起的国家配地图点击声；城市配声呐脉冲；文件配纸张和打字机声；打勾时配点击声 + 钟琴。 | |
| 环境底音 | 科技品牌牌下铺服务器机房嗡声，地图下铺柔和空气声。 | 音量很低。 |

母带响度 −14 LUFS，真峰值 −1.2 dB（`core/render/mux.sh`）。采样库：VSCO 2 CE 和 VCSL（CC0）；拟音用合成方式制作（`core/audio/sfx.py`）。

## 原生手法

1. **片头牌变成角标**——品牌牌砸入，再飞向角落，并在整段新闻简报中留在那里；开场和节目身份是同一个图形。
2. **新闻条标签就是类别**——新故事开始时，新闻条标签通过白闪更换类别（模型、市场、监管……）；新闻之间不另放单条新闻卡。
3. **新闻目录逐项打勾**——用同一张目录开启并结束节目；结尾时为每一行打勾。
4. **规格卡**——用比例呈现新品发布：整体和局部共用一个比例尺，再标明驱动它的配置，并用括号连到总量。
5. **新闻条始终保留**——从第一条新闻到回顾页都使用同一组新闻条；文字翻转更换，但新闻条本身不会在节目中途退出。
6. **翻页数字板呈现前后变化**——同一块板显示旧值和新值，每片数字都从旧值翻到新值。
7. **越过门槛**——折线每一步推进一个时期，逐渐靠近虚线门槛；最后一步前音乐停一拍，越线时响起最重的重音。
8. **眉题标日期**——每个图形的眉题都用等宽大写字标明来源和日期，避免周报把不同新闻的日期混在一起。
9. **文件从城市发出**——地图长镜头中，文件从发件城市飞向收件对象；通过同一个世界坐标 → 屏幕坐标函数，让标签和文件在推近、平移过程中保持贴合。
10. **引文卡 + 结论印章**——用文字呈现官员原话，并标明姓名、场合和日期；旁白说到关键词时为它加下划线，最后盖一个印章。


## 变化空间

每部影片决定：频道名称、品牌牌和强调色；新闻条数（可做一条主新闻加长篇包装、三四条等量新闻、或五条新闻汇总）；每条新闻需要哪些满版图形；地图长镜头放在哪里；主播使用什么声音。

- **三种结构：** 新闻目录 → 各条新闻 → 返回目录并逐项打勾（汇总）；一条主新闻配记者双窗和简短的“今日其他新闻”网格；新闻条目倒数（选举之夜、体育成绩）。
- **三种开场：** 片头音画点题 → 新闻目录；先冷开场展示最大图形，再播放片头；片头直接进入第一条新闻，新闻目录只留作回顾。
- **三种结尾：** 新闻目录逐项打勾 → 片尾卡；“下周预告”提示卡；最后一个印章定格并转成片尾卡。

## 坑

- **包装层留在原地。** 如果新闻条、来源行或标签只在最上层绘制一次，擦除会先换成新画面，旧标题下方已是新内容，而新闻条要晚 0.3–0.5 s 才跟上。应在擦除蒙版内部、每幅画面分别绘制它们。
- **版面留下空带。** 移除字幕或滚动新闻条后，若不把内容下移，新闻条上方会留下一道空带。
- **蒙版裁切的文字提前露头。** 若推近标题的移动距离不够越过蒙版，文字顶边会在移动前露出；应让它完全从下方进入，进度为 0 时不要绘制。
- **措辞强于来源。** “要求提供信息”不等于“展开调查”或“处罚”；只有来源明确支持时才写“未罚款、未立案”或“有史以来首次”。同时检查机构自身页面，因为它可能与报道矛盾（“首次提出要求”可能几个月前就已发生）。
- **门槛取决于参照点。** “熊市”是相对*哪一个*高点下跌 −20%？在坐标轴上标出参照点；换一个高点，结论可能就不成立。
- **只归因于报道的内容要注明报道来源。** 若官方来源没有点名相关公司，图形和旁白都要标为“据……报道”。
- **不要把示意图伪装成数据。** 收盘价的滚动计数器可能闪出从未存在的价格；改用蒙版推入静态收盘价。坐标轴只标数据能够支持的内容。
- **新闻条下方的来源行。** 右对齐，等宽字体 13 px，不超过 36 个字符。
- **印章盖在关键词上。** 印章重音可能盖过旁白中的“罚款”；移除印章的铜管声，并对敲击声做低通处理。
- **金色放在纸上**对比度太低：改用油墨色或深橄榄色。
- **生成的品牌牌**可能带有多余角标：用 `prep.py` 裁掉。
- **目录预览文字较短。** 新闻目录各行是新闻内容的预览；`readcheck` 会在开场时标为过短，但这些文字会在回顾页和新闻条再次出现，所以可以接受这条提示，或不把它们纳入 `TEXTS`。
- **合成语音中的姓名。** 在 TTS 文本中按正确读音拼写品牌名、型号和缩写（可用音近拼写、把数字写成单词，或去掉缩写中的点），新闻条和字幕仍保留真实拼写；若语音转文字把罕见姓名听错，将预期转录写入该行的 `asr` 字段，不要改写台词。
