# 60 秒间谍片头（spy-title-sequence）

> 一句话：以不透明平涂墨色、剪纸剪影、图形字体和铜管重音作为剪辑点，构成悬疑片头序列。
> 参照（只学语法）：只借用视觉语法。Saul Bass 为《North by Northwest》《Anatomy of a Murder》《Vertigo》设计的片头（不透明平涂、抽象到剪影、字体作为结构）；Kuntzel + Deygas 于 2002 年为《Catch Me If You Can》做的致敬片头（在图形布景中展开剪纸追逐，以横向跟拍呈现）。不使用枪管开场，不使用踮脚潜行的卡通黑豹，也不复制任何真实片头中的标志、字形、人物或镜头。

## 本质 / 不是什么

- **纸面上的不透明平涂墨色：** 四种颜色，不用渐变。
- **每个形状都有手工剪出的边缘；** 分层之间留出剪切间隙和浅浅的纸影。
- **抽象到剪影：** 人物侧面出场，所有表演都通过轮廓和时机完成。
- **字体构成画面的骨架：** 演职员字幕同时成为建筑、道具和交通工具。
- **音乐切开画面：** 铜管重音就是剪辑点。
- 片头序列本身就是一个故事：一个目标、几个地点、一次揭示。

它不是平面矢量动效（边缘是剪出来的，纸张有实体感），不是半调印刷（没有网点），不是瑞士网格（使用对角线、活泼字体和俏皮感），也不是用小玩意和枪管构成的间谍恶搞片。

## 这个风格最俗的版本

- 来源正文未给出一套固定的俗套画面、配色、配器或开场结尾组合，因此不补造。相邻风格边界与明确排除项保留在“本质 / 不是什么”。
- 每支片子按主题从来源信号中挑 2–3 项，并在 brief 的 style 栏说明保留或改动了什么；故事、数据、构图与时间线重新设计。

## 技术路线

本节列出的源码文件/函数名用于定位来源工程的实现示例，不是本地 API；Motion 可按本片需要使用原生工具实现其中的视觉方法。

来源实现示意：`paper.js`（四种墨色、缓存的剪刀边缘、剪切间隙、纸影、纹理、带关节切口的剪影层）、`glyph.js`（League Gothic → opentype.js 轮廓 → 重新剪切字母）、`chars.js`（剪影骨架、姿势、跑步/走路循环）、`title.js`（自定义剪纸标题字形、对角切分）、`story.js`（速度网格、单一时间来源）、`film.js`（时间线、表演、相机、字幕、声音事件）。`?sheet=1` 渲染角色转面设定表，`?frame=<scene>` 渲染风格帧。

## 材质与渲染

- **剪刀剪出的边缘：** 每个多边形约每隔 9–10 px 重新取样，沿边缘法线施加低频噪声（幅度约 1.2–2.2 px，大形状偏移更大），偶尔加一道 1–2 px 的缺口。**在纸片自己的局部空间中只剪一次并缓存边缘，**使移动的剪纸保留同一轮廓，像真正的剪纸动画（若在屏幕空间重算，边缘会爬动）。
- **纸张分层：** 独立纸片之间留约 2.4 px 的底色剪切间隙，并投下小块纸影（偏移几 px、模糊约 5、alpha 约 0.3）。整个人物外轮廓也保留间隙，使黑色人物即使在黑色字形前仍可辨认。
- **纸张纹理：** 顶层叠加一张覆盖整帧的纹理（斑驳 + 浅纸纤维）；深色墨上加稀疏的“缺墨”斑点；浅浅的刮印条纹；最终封装时加入约 6 的胶片颗粒。
- **剪影人物：** 高挑、风格化的成年人（约七头身），身份由帽子、外套剪裁、鞋子和**一种强调色**区分；强调色同时也是运动指示（奔跑时向后飘的领带或围巾）。人物内部的纸片**合并为一个整体轮廓，**只在肩、肘、髋和膝处留细小关节缝。手部用尖锐楔形表示；除特写中的眼缝外不画脸。
- **追逐目标物**衬在黑色底板（墨色关键线）上，使它在任何底色前都清楚；它是画面里最亮的对象。
- **字体：** 演职员字幕使用 OFL 窄体展示字（如 League Gothic）；抽取字形轮廓（opentype.js）后逐字**重新剪切**（边缘噪声、旋转 ±0.8°、基线抖动 ±1.5 px）。标题采用自定义几何剪纸字形（直线和弧线混合、粗细不均、基线错落），绝不使用任何真实片名的字形。

## 配色

- **四种墨色：** 墨黑、纸奶油色、一种亮色、一种暖色辅助色。只用这些墨色的深色“影纸”变体表现空间深度。
- 每个场景只用**一种主导底色，**随地点变化；人物和文字使用其余墨色。
- 亮色留给主角身上的一种强调，以及危险信号；辅助色标出追逐目标物。
- 背景道具用比底色更暗的版本，绝不用黑色，否则看起来会像字母。
- 配色示例：黑 `#1b1714` / 奶油色 `#efe4c9` / 红 `#d23a22` / 芥末黄 `#e2a52a`；墨色 `#161a22` / 骨白 `#ece6d6` / 蓝绿 `#1f8a8a` / 橙 `#f07a28`；黑 / 浅粉 `#f3d6cc` / 钴蓝 `#2a46b8` / 柠檬黄 `#f0d23a`。

## 字体

- 演职员字幕放在**布景之中，**不放在字幕条：每个地点用一行字幕，并在某个时刻完整可读。只能写虚构职务，不写真实人物姓名。
- **字幕：** 放在左下方窄纸条上（末端剪纸状、略微倾斜），前面加片中一个小字形作项目符号，使用几何 OFL 无衬线字体（如 League Spartan 600，约 44 px）。暗场使用浅色纸条，亮场使用深色纸条；约 0.18 s 内从左侧滑入。保持至少 max(1.8 s, 语音时长 + 0.6 s)。
- 每条演职员字幕要有足够的停留时间，能与字幕同时读完。

## 运动

- **木偶按双帧动画**（12 fps）：人物、手、落下的字母、车辆的姿势与位置。**相机、字幕滑入和网格增长按一帧一格动画**（24 fps）：相机以阶梯方式抖动。
- 演职员字幕沿网格线滑入，并在节拍上**骤停**（短暂缓出）；字母落下时带纸片拍打声。
- **停格时间：** 遇到重音时整幅画面冻结（包括背景滚动），总共静音几个节拍，然后恢复。
- 碎裂转场：把场景切成与剪切线平行的条带，再让它们沿对角线交替滑出。

## 画面怎么活

- 有人物或车辆时，可按来源的约 8 张跑步循环、每拍一步的走路循环推进；身体前倾、外套和强调物随步态回摆。是否使用循环由内容决定，不要求每个镜头都出现。
- 字幕与网格只在建立、滑入或扩展时运动；停格段按来源完全冻结并静音。

## 镜头语法

镜头词汇，不是固定路线。图形扁平、明确、果断。开场和结尾由主题决定。

| 镜头变化 | 表达作用 | 可用于 |
|---|---|---|
| 先用广角展示整行演职员字幕，再推近 | 先阅读、再行动 | 由字体建构的地点 |
| 沿同一个屏幕方向横向跟拍 | 追逐、动势 | 追车、竞赛、递送 |
| 在铜管重音上硬切 | 冲击、新地点 | 蒙太奇、揭示、笑点 |
| 图形匹配剪辑（切前后形状相同、位置相同） | 呼应、加速 | 车轮 → 硬币 → 瞳孔 → 月亮 |
| 平底色上锁定一个单一形状 | 悬疑、图标 | 冷开场、线索、标志 |
| 巨大圆形前的剪影 | 主角时刻 | 接住、胜利、对峙 |
| 对角线切分后形成网格 | 碎裂、同时出现多处画面 | 分屏、阴谋、团队 |
| 沿文字列向下垂直摇镜 | 下坠、清单 | 建筑、名单、倒计时 |
| 推进一个字母，直到字形填满画面 | 字母变成地点 | 门、隧道、窗户 |

构图使用强烈对角线（约 30°）、大片平涂底色，并让人物相对于字体显得较小。匹配剪辑前后应保持圆心和直径一致。不要溶解转场。

## 声音调色板

- **1960 年代间谍大乐队：** 八度叠奏的断奏小号和长号并加撞击声（重音）；低音弦上带弹簧混响的冲浪吉他颤音、行进低音提琴、刷奏或鼓棒、邦戈鼓和沙锤、颤音琴、长笛、管风琴重音、大键琴。使用小调、半音旋律线和附点节奏。只创作原创动机：避免最著名间谍主题里那段著名的半音爬行旋律，以及它以小调—大调九和弦结束的做法。
- **重音 = 剪辑点：** 铜管断奏约提前 8 ms 放置，让采样峰值落在画面帧上。
- **可选技法：** 追逐加速时逐渐缩短切镜间隔；停格静音；大和弦推出片名后接一个短促收尾音；安静场景只留一件独奏乐器。
- **拟音跟随材质：** 纸张（剪切的“唰”声、滑动声、字母落下的纸片拍打声、百叶翻动、撕裂声），金属（钥匙、链条、锁、咔哒声），磁带（卡嗒、嘶声）。环境声只略作暗示：平移声像的喷气机掠过、按节拍响起的火车车轮、逐渐慢下来的轮盘滴答、风、电话铃、楼梯脚步。
- **静音：** 使用真正的零电平，混响尾音也要归零；也可以留下单独一次磁带卡嗒声或嘶声。
- **混音：** 人声下方的音乐压低约 7 dB；峰值较高的混音在响度标准化前先留出几 dB 进入限制器，再达到 −14 LUFS。
- **人声：** 像通过磁带链路传来的简报（带通约 220–5200 Hz、轻微饱和、缓慢抖晃，声音下方嘶声渐强）；台词只用几句、每句很短。

## 原生手法

以下是方法菜单，按故事需要选用。

- **字体就是布景。** 每个地点是一行演职员字幕，也是它的建筑结构（字母像柱子、词语像车厢、一个字母像一把锁）。*适合内容：* 把会议议程变成一座城市、把菜单变成一家餐厅、把队员姓名变成一座体育场。
- **演职员字幕就是节奏。** 字幕落在节拍上，重音就是剪辑点。*适合内容：* 产品特点、节日演出阵容、奖项提名者。
- **图形匹配剪辑。** 让形状彼此押韵，并随着紧张上升缩短间隔。*适合内容：* 硬币 → 行星 → 时钟；齿轮 → 车轮 → 太阳。
- **对角网格。** 对角线切分后变成网格，碎片再沿着网格飞回去组装成一个新形状。*适合内容：* 解开谜题、团队成形、组装标志。
- **剪影木偶。** 侧面剪纸人物，表演全靠轮廓和时机。*适合内容：* 劫案、赶截止日期的信使、侦探。
- **停格笑点。** 在重音处冻结、静音，再恢复。*适合内容：* 擦肩而过、二次确认、价格揭示。
- **追逐目标就是片名。** 所有人追逐的对象成为最后拼出的内容。*适合内容：* 产品发布、书名、生日姓名。

## 变化空间

由你决定追逐什么、由谁追逐、把哪些地点（用演职员字幕构成）作为场景、使用哪些墨色、如何开场与结尾。每支新片都从主题重新设计，不照搬来源示范片：

- 结构：**没有追逐，改成倒计时**（十行演职员字幕、十个地点，每个地点里的文字拼出一个炸弹时钟数字）；**倒叙劫案**（物件逐个地点返回它原本所在的位置）；**两名特工，同一画框**（对角线分屏，两边各用一种底色，最后相遇）。
- 开场：**满版片名**，随后碎裂进入序列（把揭示移到开头）；**电话铃响**，画面只有一个剪纸房间；**主角已经开始下坠**，穿过一整列字体。
- 结尾：**片名始终没有拼齐**，缺少一块，主角带着它离开；**缓慢拉远**，发现所有地点原来都在一整页巨大的演职员字幕上；**停格**在最后一个重音上并保持。

## 坑

- **人物内部的每块纸片都带缝隙，会像人体模型图** → 先在画外图层合并纸片，再用 `destination-out` 只切关节缝，并为整个人物描边。
- **调用 `clear()` 后变换矩阵被重置，悄悄破坏相机运动。**
- **人物被字母完全遮住，会像“没人在那里”** → 让帽子、鼻子和强调色露出来。僵硬的飘带像舌头 → 使用带移动正弦波的多节丝带。
- **演职员字幕始终只能看到一部分，会让人不舒服** → 一定要用广角完整展示整行字幕。
- **黑色背景道具会被看成字母** → 用更深一档的底色。
- **物件与底色墨色相同会消失** → 加黑色底板。
- **圆形道具放进单词里会遮住旁边字母** → 排字时为它留出空隙。
- **如果切前后圆心移动，匹配剪辑会失败。**
- **平涂墨色 + 颗粒在较低 CRF 下会造成巨大文件** → 较高 CRF 视觉效果相同。
