# 积木玩具逐格动画（brick-toy-stop-motion）

> 一句话：刚性塑料积木在真实桌面上以逐格姿态搭建、倒塌和重组，微距景深保留玩具尺度。

> 来源参照（只学语法）：
> 像微距摄影一样在真实桌面上拍摄的积木玩具定格片：用相互咬合的塑料积木组成世界，顶部有圆形凸点，每次只移动一个姿势。
> 参考（只学语法）：桌面上的积木定格短片，以及“积木电影”逐格移动角色、同时让相机平滑移动的方法；微距玩具摄影（光泽塑料上的柔光箱、浅景深、真实物件构成地貌）。不得复制其角色、布景或音乐，也不得使用任何品牌名称。

## 本质 / 不是什么

一个由**真实表面**（木桌、餐桌、窗台）承托的积木世界，用**微距镜头**拍摄，并以**定格动画**制作。它的魅力来自玩具世界与真实房间之间的反差。

一眼能认出的特征：带干净矩形高光的亮面 ABS 塑料；每个顶面都有凸点；接缝被接触阴影压暗；真实物件在后方虚化；角色以保持数帧的姿势逐格表演。

**绝不**使用 LEGO 名称、标志或小人仔轮廓（商标）。角色必须**由积木拼成**（例如用 1×1 砖做腿柱、2×2 砖做躯干、圆砖做手臂、圆形 2×2 砖做头盔）。凸点上不能有文字。

这不是低多边形等距岛屿（没有平面着色切面，也不是漂浮的微缩景观），不是黏土或毛毡定格动画（不发生变形，积木是刚性的），也不是干净的玩具产品渲染（这个世界被人玩过、拿过、撞倒过）。

## 材质与渲染

- **塑料**：ABS 材质带强清漆（约 0.85，清漆粗糙度约 0.07）；粗糙度贴图表现淡淡指纹和划痕（底值约 0.17，划痕最高约 0.65）；增加倒角，让边缘接住高光。
- **几何体**：圆角盒体（倒角约为凸点节距的 0.045），凸点带细边。一个单位 = 1 个凸点节距（8 mm）；砖高 1.2，薄板高 0.4。大底板采用**哑光**处理（清漆低于砖块），否则会把柔光箱反射成一片有颜色的亮斑。
- **布景**：用真实材质表面的真实平面和真实尺度道具（1 m = 125 个凸点）。家用品成为地貌。使用**中性日光影棚 HDRI**照明，绝不用钨丝灯室内光（白砖会变橙）。
- **灯光**：玩具摄影布光。一盏来自上方一侧、投下阴影的暖白主光（逐镜头调整阴影视锥，保持阴影清晰）；另加两到三盏**矩形面光源（RectAreaLight）**柔光箱（前方主光、后方冷色轮廓光，大型布景上方再加一盏），让亮面塑料出现干净的矩形高光；环境光保持较低（约 0.45）以增加反差。在主体物体后方主光投影落处增加柔和的接触阴影团块。
- **环境光遮蔽必不可少**：使用 GTAO（半径为几个凸点大小）压暗叠放积木之间、凸点底部和接触点的缝隙。没有 AO，积木会像贴上去一样。
- **超采样 2×**（以 3840×2160 渲染，再交付 1080p）：否则凸点边缘和倒角高光会闪烁。
- **镜头**：物理景深（DOF；CoC ∝ |1/focus − 1/z|）。按镜头尺度调整光圈：特写最大，中景较小，远景最小（景深过浅会把中距离主体也模糊掉）。焦点始终落在角色头部或正在放置的积木上。
- **特效也要由积木构成**：火、烟、水、光、天气、天体均用薄板、圆砖和透明零件拼成，并逐格抖动或重搭。不能用粒子系统或柔和渐变代替。

## 配色

- **玩具色盘**：从几种饱和的积木原色，加上白、黑、灰、棕褐中选择。每个拼搭物有一种主色，最多再加一到两种装饰色；人物和主要物件使用最饱和的颜色。
- **真实世界保持自然、低饱和**：木材、纸张、陶瓷和日光色彩克制。饱和色属于玩具，因此玩具会从房间环境中跳出来。
- **白色必须看起来仍是白色**：色调稍微偏冷，避免房间反射光把白砖变成奶油色；反差柔和，饱和度提高约 10%。
- 透明零件（橙、黄、透明、蓝）留给特效：火、光、水、玻璃。
- 示例色盘（经典积木原色）：红 `#c91a09`、蓝 `#0055bf`、黄 `#f2cd37`、绿 `#237841`、白 `#f2f2ee`、黑 `#1b2a34`。其他可用粉彩和棕褐色；灰色搭配一种强调色。

## 字体

- 片名和字幕使用圆润、友善的 OFL 字体（如 `core/fonts` 中的 Fredoka）。
- 字幕落在**玩具元素上**：画面下方放深色圆角条，旁边配小积木图标；也可以放在印刷砖块上，或做成布景中的标志。深底白字，最多两行。第二类说话者（收音机、设备、旁白）使用另一种图标颜色或标签。停留时间不少于 `max(1.8 s, 台词时长 + 0.6 s)`。
- 片名以 12 fps 的逐格方式弹入，像一块积木刚刚放上；副标题使用一种积木颜色。

## 运动

- **角色和积木以 12 fps 步进**（每两帧一张）；**相机、焦点、火焰和飞行载具以 24 fps 连续运动**。相机若也逐格跳动，读起来会像抖动，而不是魅力。
- 积木**沿弧线飞入并卡合**，带极小的过冲（几分之一凸点距离 → 0，约 4 帧内完成）。每次卡合都配一声咔哒。
- 角色用幅度大、容易读懂的姿势保持数帧：骄傲时双臂举成 V，惊恐时双臂张开，悲伤时低头，开心时跳跃。走路循环让腿摆动约 ±0.55 rad 并轻微起伏。手臂和腿绕关节转动，不发生弯折。
- 倒塌和跌落使用**真实刚体物理**：先绕底边倾倒，再让各个刚体独立受重力运动（比真实值更低的重力在这个尺度下读起来更好）、弹跳（恢复系数约 0.3）、摩擦并最终平放。提前预模拟，使每次渲染结果一致。
- 允许细小瑕疵。积木绝不拉伸、挤压或变形。

## 画面怎么活

角色与物件按12fps逐格改变姿态，镜头、对焦、火焰与飞行物按24fps连续移动；积木火、水、烟和天气也按来源由积木部件搭成。

## 镜头语法

镜头是一套词汇，不是固定路线。开场和结尾由主题决定。

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 对单块砖或凸点的极近微距，后方真实房间虚化 | 玩具尺度就是整个世界 | 开场、重要细节、单个零件 |
| 小人仔视线高度的低角度 | 让微小角色显得英勇 | 野心、自豪、面对强大事物 |
| 俯看整个桌面的高位全景 | 揭开尺度：原来一直是个玩具 | 总结、反讽、搭建完成 |
| 低机位、宽画幅、孤独构图，让角色缩在角落 | 渺小、失败 | 挫折、等待、失落 |
| 正面特写，手和积木清晰 | 亲密、抉择 | 选择、修理、赠礼 |
| 撞击时手持震动 | 身体冲击感 | 倒塌、到达、碰撞 |
| 沿移动物体跟拍，让目的地留在前方 | 朝目标前进的动势 | 旅程、比赛、发射 |
| 俯拍平面图 | 秩序、布局、地图 | 计划、零件分类、俯瞰城市 |
| 从真实物件拉焦到积木（或反向） | 同一画面中的两个尺度 | “大世界、小小创造者”；对照 |
| 绕完成的搭建物环拍 | 自豪、检视 | 产品、纪念物、结果 |

构图时不要让前景杂物挡住画框边缘（零件堆很容易挡镜头）；每镜检查头顶留白；每个真实道具都要对照所有相机检查，因为只在一个镜头轴线上的道具，可能会偷偷出现在另一个镜头的背景中。按节拍或小节切镜；积木卡合也可作为切点。不用泛化溶解；转场可以让手放下一块砖遮住镜头、沿桌面甩镜，或从一个场景拉远进入下一个。

## 声音调色板

- **乐器**：小型、原声、俏皮（钟琴、玩具钢琴、拨奏、尤克里里、口哨、拍手、口风琴）；表现尺度时可加铜管或管弦乐渐强；悬念可用心跳鼓。音乐可用授权素材或原创，按画面剪辑（按小节切换、按小节对齐跳转、连接处保持调性相似），不要直接循环铺底。
- **拟音**（可合成）：故障前的塑料吱响、细小塑料脚步声、大量咔哒声构成的撞击、积木卡合声（短促瞬态 + 约 2.9 kHz 与 4.6 kHz 的共振）、木面上的咔哒声、搅动零件堆的沙沙声、抛掷时的呼啸声、发现时的“叮”声、积木在纸上滑动声、由滤波噪声构成的马达声和引擎声。
- **静默也是工具**：失败或意外发生时让音乐突然停止，只留房间底噪和一个小小的真实声音（钟表滴答、冰箱嗡鸣、远处鸟叫）。大场面前也可以让音乐退出，只留下脉冲或倒数声。
- **人声**：温暖的讲述者，台词少而短，留出呼吸空间；第二类声音经过设备滤波（约 380–2800 Hz 带通 + 轻微软饱和），可以配提示音。用 whisper 核验每句台词。
- 混音：人声压缩，音乐在人声下方约 40% 音量；目标响度 −14 LUFS。

## 原生手法

可从下列菜单中选择故事需要的手法。

- **拼搭就是情节。**积木沿弧线飞来并卡合，搭建本身推动故事。*适合：*公司组装第一件产品、街区一条街一条街建起来、食谱逐样加入食材。
- **不造成伤害的拆解。**物件散开后，零件变成新事物；失败留下可再利用的零件。*适合：*失败计划后的转型、回收利用、团队重新组合成更好的样子。
- **真实桌面上的玩具。**真实物件在玩具尺度下变成地貌。*适合：*把笔记本键盘变成城市网格、把室内盆栽变成丛林、把咖啡洒出变成洪水。
- **手作定格动画。**12 fps 姿势、细小瑕疵，连火和水都由积木构成。*适合：*天气预报、用积木火焰讲解厨房、用积木演示火山科学。
- **重拼成另一件东西。**同一批零件在画面上重新排列，变成不同物体。*适合：*职业转换、改造前后、重新拼写一个词。
- **揭示尺度。**拉远直到整个世界变成桌面上的玩具。*适合：*仍然很小的宏大目标、年度回顾、孩子的想象。

## 变化空间

由你决定结构、人物（也可以没有人物）、桌面和道具、开场、结尾、相机路径、节奏、符合色彩逻辑的配色和音乐。应远离来源示范片：

- 结构：**物件目录**（每拍搭建一个物件，都回答同一个问题，最后排成一列）；**两位搭建者**各站桌子一端，让两人的作品朝彼此生长；**逐件拆解**一件完成品，解释内部构造。
- 开场：**一只手把一盒积木倒在桌上**，零件堆落定后变成第一个造型；**先出现真实物件**（杯子、手机），再拉焦到它底部的小世界；**俯拍空底板**，让它像地图一样逐渐填满。
- 结尾：**留下一个多余零件**并以特写呈现，让它引出的疑问保持未解；**房间灯光熄灭**，只剩一扇亮着的积木窗；**一只真实的手伸进来**，把角色拿起。

## 坑

- 钨丝灯 HDRI → 白色变橙。改用中性影棚 HDRI，并略微冷调。
- 大片平面底板的清漆会把柔光箱反射成一片有颜色的亮斑。让底板保持哑光。
- 首次渲染显得平、略有锯齿：光照均匀、无 AO、单采样、相机逐格。修正：柔光箱 + 低环境光、GTAO、2× 超采样、冷调、相机每帧运动。
- 光圈过大，会让中距离主体失焦。按镜头景别调整光圈。
- 快速升起或移动的物体在空白墙前会变成一个点。跟拍它，并让目的地留在画面中。
- 用球体切面制作弯曲透明件，会让零件在圆柱内消失。改用开口圆柱片。
- 后续镜头的相机轴线上出现真实道具，导致它进入背景。逐镜对照所有道具与相机。
- 把随机抖动用于材质或颜色索引可能得到负值 → 材质未定义并导致崩溃。将索引限制在有效范围内。
