# 节拍象形图形目录片（pictogram-motion-catalogue）

> 一句话：圆头几何人、分行移位的方格图案和双语大字组成卡片目录，动作与切点锁在同一拍格。

> 来源参照（只学语法）：
> 一部按节拍锁定的闪卡影片，仅由三种元素构成：圆、半圆和微小图案单元组成的**方格“核心图案”**，其中各行彼此错位滑动；由圆端条形肢体与圆盘头部组成的**几何象形人物**；以及从遮罩中向上滑出的**粗体双语文字**。每个切点都落在鼓点上。
> 参照（只学语法）：Otl Aicher 1972 年慕尼黑奥运象形图（几何化运动员）；综合运动会的“赛事视觉识别”系统（一套模块化图案 + 一组颜色应用到所有物料）；瑞士体育转播图形（等宽元文字、刻度条进度）。只学习视觉语法；绝不复制真实赛事的象形图、徽记、口号、图案设计或颜色名称，也不在影片中点名这些赛事。

## 本质 / 不是什么

这是一部**目录片**：一次显示一个项目（产品、菜品、步骤、物种……），快速呈现并踩准节拍。每张卡片 = **一个象形人物做一个动作 + 一个大标题 + 一行第二语言文字 + 一条等宽索引“07 / N”**。卡片按章节分组；每章使用一种色相，并以一张满版图案章节卡开场。

一眼看上去符合这种风格的画面应有：

1. **方格图案：** 圆盘和半圆跨方格单元排列，约一半单元放置小图案；整行被切开并横向移位。这是推动背景与转场的标志性元素。
2. **象形人物：** 平面、无面孔，由圆端条形与圆盘头构成；远侧肢体混入背景色。道具由圆盘、圆环、胶囊形和线条构成。
3. **字体就是建筑：** 900 字重无衬线标题放得很大，下面有粗体第二语言文字，角落以小号等宽元文字模拟转播 HUD。
4. **锁定节拍：** 每个镜头都从节拍开始，每个关键动作都落在节拍上。

整体气质是高级转播视觉识别系统；使用平涂色彩、浅颗粒，并仅用一道柔和扫光作为渐变。

它不是等距信息图（没有纵深或 3D），不是瑞士动效图形（人物和图案与字体同样重要），不是卡通（人物没有表情或五官），也不是数据影片（数字是标签，不是图表）。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 来源正文中的可见/可操作描述 | 适合的主题 |
|---|---|---|
| 方格图案 | 圆、半圆与小图案落在正方格中，整行按格宽横移。 | 章节卡、目录背景 |
| 五阶单色纹样 | 同一色相的五个明度承担背景、纹样和前后层。 | 分类、主题章节 |
| 圆头条形人物 | 人物由圆头和圆端条形肢体组成，表情保持中性。 | 动作目录、流程、运动 |
| 分栏舞台 | 文字栏与人物舞台分开，人物不能压住标题。 | 双语卡片 |
| 双语标题层级 | 大标题、第二语言和角落等宽元信息各自有固定层次。 | 目录、产品分类 |
| 章节色 | 一章使用一种色相，章节开卡的图案对比提高。 | 类目、步骤 |
| 动作落拍 | 镜头起点和人物关键动作都落在整数拍。 | 动作演示、节奏目录 |
| 动作卡片长度梯度 | 普通卡一小节，相关子项可按半小节加速，不能靠随意改速度。 | 清单加速、过程展示 |

列出的信号均可在来源正文中定位；每支按主题挑 2–3 个，至少一个避开最常见组合，不把信号全部堆在同一支片子里。

## 这个风格最俗的版本

来源没有给出一套可跨主题复用的固定俗套组合，因此不补造。风格特征与明确排除项保留在上面的本质说明中；具体故事、时间线和段落仍按新主题重新设计。

## 适配

- 用途：需要快速展示一组物品、步骤、地点或类别，并由章节颜色帮助归类的目录片。
- 内容：只借用下方可复用媒介规则；人物、故事、事实、镜头顺序和时长按本片目标重新设计。

## 技术路线

本节列出的源码文件/函数名用于定位来源工程的实现示例，不是本地 API；Motion 可按本片需要使用原生工具实现其中的视觉方法。

来源实现示意：

在 `demo/` 中：`engine.js`（`G.pattern`、`G.motif`、`G.joints` / `G.drawFigure`、`G.keyPose`、`G.maskText`、缓动函数）、`poses/base.js`（姿势契约、props `G.P`）、`edl.js`（以拍为单位的剪辑表）、`scenes.js`（版式、转场、HUD、运动模糊）、`lab.mjs`（姿势转面设定表）、`music/music.py`（带起音报告、与画面锁定的配乐）。API 表、姿势约定及最简示例见上游演示引擎参考。

## 材质与渲染

- **平面 Canvas2D，**干净绘制；颗粒只在封装时添加。使用一个方格网（单格约为画面高度的 1/6）统一支配色带、转场与墙面。
- **图案模型：** 先铺中深色；在方格节点随机放置半径为单格宽的圆盘，颜色随机，也可画圆盘套小圆盘；接着选取部分单元，从通用几何图案库中随机抽一个图案（四分之一圆、鱼鳞状波纹、圆点与三角形鳞片、同心弧、太阳轮、棋盘格、新月……），按 90° 的倍数旋转；绝不使用吉祥物、地标或标志。图案画布要比屏幕宽，使任意一行都能横移一个单元。
- **人物模型：** 以身高为单位，原点位于髋部；依次绘制远侧肢体（约 40% 混入背景色）、躯干、近侧肢体、头部。第二个人物位于后方，并进一步混入约 60% 的背景色。
- **舞台：** 人物站在一个邻近色相的大型**太阳圆盘**上，圆盘上扫过一束浅光。
- **人物环境**（水、渔网、坡道）放在人物专用缓冲区内，并在进入文字栏前用遮罩归零。

## 配色

- **五种色相 + 一种深中性色，**每个色相再分成**五阶明度**（最暗到最亮，中间档作为基底）。一章使用一种色相；多色章节可以每张卡轮换一组。
- 文字下方的图案使用**低对比度；**章节卡使用**完整对比度**。
- 浅色相使用深色文字和深色人物，其圆盘用更浅一档；深色相使用奶油色文字。深中性色上的圆盘需用更浅色，否则会消失；强调色选一种暖色。
- 所有色相共用一种奶油色和一种墨色。不要描边；除扫光外不加高光。
- 根据主题选择色组。配色示例：温暖节庆（红、紫、森林绿、金、赭）；海岸（海军蓝、青绿、珊瑚、沙色、天蓝）；厨房（番茄红、罗勒绿、藏红花、茄子紫、面粉奶油色）。为颜色起自创名称；不要借用赛事颜色名称。

## 字体

- 标题使用 900 字重无衬线字体（如 Inter Tight），1080p 下字号 150–330 px，字距紧凑并自动适配。第二语言使用粗体字体，放在标题下方。元信息使用等宽字体（如 DM Mono），约 22 px、字距较宽；标签做成等宽小胶囊。
- 每张卡都有 **HUD：** 角落放等宽文字，并加入含 N 个刻度的**进度条**（当前项较高，已完成项变暗，剩余项浅显）；N 根据项目列表生成。
- **双语规则：** 一种语言始终作为大标题；第二语言由版本开关选择，不能手动编辑单张卡片。
- 卡片文字本身**就是文字层**。使用旁白时，字幕以等宽文字放在本章节色相的实色条带上，位于画面底部，绝不压住标题；保持至少 max(1.8 s, 语音时长 + 0.6 s)。必须阅读的卡片（如规格或数字）至少停留 1.6 s。
- 根据剪辑表生成标题卡 `.srt` 字幕文件。

## 运动

- **时间方格：** 为影片选定一个速度；每个镜头在节拍上开始，姿势中的每个关键动作（放开、接触、落地）都落在整数拍上。
- **节奏阶梯：** 普通卡片持续一个小节；相关子项目可以变成半长度的连续快闪。第二层速度通过节拍细分获得，不改变速度。
- 缓动：入场用指数缓出；鞭甩和擦除用指数进出缓动；最多使用一次 back 缓动。
- **文字通过遮罩向上滑入：** 先出现标题，约 0.08 s 后出现第二行，再出现标签；元信息逐字打出但不显示光标。短卡片压缩所有时序。
- **人物组装：** 人物以水平色带的形式从左右交替滑入并套准。
- **背景呼吸：** 各行朝交替方向漂移；章节卡在节拍上跳动四分之一格。
- **转场**对齐网格：滑动行、落下的列、推进、从单元角落长出的四分之一圆、从最后一个人物开始的光圈、翻转瓷砖。轮换使用；每种持续剪辑点前后几帧。
- **只在物体运动时添加运动模糊：** 在转场和鞭甩窗口内做子帧平均；静止帧只渲染一次。

## 画面怎么活

背景行按来源交替漂移，章节卡可在拍点跳动四分之一格；人物动作与字幕显现继续承担主节奏。这里的纹样运动是来源明确规则，不将其改写为以静为主。

## 镜头语法

大多数镜头使用锁定的平面画面；能量来自分行移位、转场和人物动作。相机移动时，沿网格移动。开场和结尾由主题决定。

| 镜头变化 | 表达作用 | 可用于 |
|---|---|---|
| 锁定平面画面 | 清晰、卡片如海报 | 任一项目、必须读清的规格 |
| 横向跟拍，每拍做一次横向鞭甩 | 保持一个连续系列、增强动势 | 一列车站、生产线、路线 |
| 沿一行缓慢漂移 | 平静、浏览 | 画廊、菜单、较慢章节 |
| 按网格行垂直滚动 | 排名、深度、下行 | 十佳榜单、建筑各楼层、海洋深处 |
| 推近一个图案单元，直到它变成下一画面 | 放大进入局部 | 菜里的食材、地图中的城市 |
| 拉远至由项目拼成的整面墙 | 同时看到整体 | 总结、“全部项目”、比较 |
| 所有瓷砖向一点收拢 | 多个变成一个 | 合并、共同目标、数量归零 |
| 沿网格线分屏 | 并列看见两个项目 | 对比、前后变化、两个版本 |

文字与人物各占独立区域（一个文字栏、一座舞台），绝不重叠；横向人物姿势会把舞台向外移动。HUD 固定在角落。允许的转场仅限第 5 节列出的网格转场；不用溶解、3D 相机运动、手持抖动或景深虚化。

## 声音调色板

- **单靠文字和音乐也能撑起影片；**人声可选，语气平静，每章最多一句。
- **打击乐是骨架：** 根据主题选择一组鼓乐（框鼓、太鼓、行进小军鼓、钢鼓、身体打击乐、电子鼓组），再加鼓边点击、拍手、沙锤和镲声。
- 上层加入色彩乐器：Karplus–Strong 拨弦（可模拟琵琶、筝或竖琴音色并做音高弯曲）、木琴类（马林巴、钟琴）、失谐锯齿波和弦重音、合成器贝斯、铺底音、上升音和持续音。
- **各章节配专属强调声：** 每个镜头起点按章节选择一种声音（泼水、啵声、金属撞击、裂响、呼啸、滋滋声）；拟音表现章节对应的材质。
- **由数据锁定画面：** 配乐读取剪辑表中的镜头时间并将强调声放在那里；逐个检查所有起音与画面误差不超过 ±15 ms。
- **静音是一种工具：** 大撞击前半个节拍让鼓和低音静音；或者整小节只保留滴答声进行倒数。
- 混音：总线胶合压缩与限制器，−14 LUFS，≤ −1 dBTP。

## 原生手法

以下是方法菜单，按影片需要选用。

- **一张卡片 = 一个项目。** 数量就是钩子（“全部 N 项”）。*适合内容：* 工坊里的每种工具、地铁线路的每一站、一种地方菜系中的所有菜品。
- **一章 = 一种颜色。** 不同类别转化为不同色相，让观众随时知道自己身处何处。*适合内容：* 管弦乐团的乐器组、食物类别、公司部门。
- **每个项目只用一个动词。** 一节拍内能看懂的一种身体动作，或一种道具动作（齿轮转动、杯子倒水）。*适合内容：* 瑜伽姿势、厨房技巧、建筑工地上的工作。
- **节奏阶梯。** 某个子类别用两倍速度呈现。*适合内容：* 四种刀工、手部骨骼、工作日例行事项。
- **沿轨道长镜头。** 各站点相隔一个屏幕，每次切镜时相机鞭甩。*适合内容：* 食谱步骤、马拉松检查点、火箭发射阶段。
- **数字砰地出现。** 大数字滚动一小节后停在目标值。*适合内容：* 回收吨数、俱乐部成员人数、公司经营年数。
- **图标墙。** 所有象形图标再次组成网格，并统一成一种颜色。*适合内容：* 年度总结、习惯的周期表、团队名单。

## 变化空间

由你决定项目、分组、动作动词、配色、章节顺序、是否使用长镜头、节奏阶梯、开场、结尾、音乐和人声。与演示片保持足够差异：

- 结构：**倒计时**（项目从 N 排到 1，相机沿行向下滚，清单越短速度越快）；**象形图一日**（同一个人物，每小时一张卡，色板由黎明变到夜色）；**组装**（每张卡都往角落里逐渐长大的象形机器加入一个部件）。
- 开场：**单个图案单元**填满画面，然后分裂成网格；**动作进行到一半时开场**，第一个象形人物已经在奔跑，文字随后砰地出现；**空白网格**，先在节拍上画出细网格线，再出现颜色。
- 结尾：**最后一张卡长时间停留**，图案行逐条停止；**人物走出画面**，最后一个象形图标退场，HUD 刻度逐个消失；**反向组装**，网格拆成几行后向画框外滑去，只留下奶油色。

## 坑

- 人物周围的环境元素扩散到文字栏 → 将人物层渲染到独立缓冲区，再用渐变遮罩淡出文字栏前的内容。
- 浅色相上奶油色文字对比不足 → 浅色相使用深色文字和深色人物；圆盘使用更浅一档。
- 深中性色上太阳圆盘消失 → 圆盘使用更浅一档。
- 图案画布很大且每张卡都各用随机种子 → 使用有容量上限的 LRU 缓存；并行渲染器使用无界缓存会耗尽内存。
- 横向姿势（游泳、躺下、爬行）挡住标题 → 把舞台向外移动并收窄文字栏。
- 过于贴近真实赛事视觉识别 → 根据网格纹样自创配色、标记和口号。
