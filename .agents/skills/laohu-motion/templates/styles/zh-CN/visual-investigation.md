# 视觉调查（visual-investigation）
> 本页为中文译文视图；来源定位见文末「来源与证据」。

> 一句话：围绕一个发现，将影像、文件、照片和证词组织成可追溯的证据。
> 参照（只学语法）：语法参照：报纸的视觉调查视频、法证建筑重建、广播媒体的事实核验团队。不得复制它们、引用其名称或使用其品牌标识。

## 本质 / 不是什么

1. **多方来源在同一时刻汇合。** 每一段最终都要让至少两个独立来源（画格、照片、证词、报告原文、声音）指向同一地点或同一秒。切点就是同步点。
2. **画面里有一只可读的时钟。** 时间通过属于版式本身的大号读数呈现：每张电报卡的时间戳、数据图表上带时间读数的播放头、关键几秒上方的 `T+xx.x` 秒表，或冻结在“32 s”的读数。随着故事推进，时间刻度在段落切点处改变（小时 → 分钟 → 秒 → 天）。每个镜头底下铺一条固定时间带是**可选做法，而且通常不合适**：它占用画面底部、增加一层小标签，故事离开计时场景后又会空在那里。
3. **每种版式只讲一个发现。** 每一段只说一件事；标题属于版式内部，不是页面页眉。
4. **把不确定性画出来，不要为它道歉。** 使用 `≈`、*推断*、*示意*、虚线框。已知与未知分成两列。某个来源还没有覆盖到某段时，就先不显示（它稍后才在自己的列中亮起）；绝不放空的“没有影像”方框，因为那看起来像渲染出错。
5. **克制。** 面对真实灾难和真实人物：不慢放灾难，不用音乐指挥观众该有什么感受；火焰只出现在证据画格里；伤亡人数用点和数字计数。

不做 **Satellite Briefing（卫星地图简报）**（没有轨道影像，也不从太空推近）。不做 **Archive Light Table（档案灯箱）**（没有玻璃上的纸张、放大镜或手：文件以平面的证据画格呈现）。不做 **Halftone Dossier（复古半调案卷）**（没有印刷纹理、印章或拼贴）。不做新闻片包装（没有频道标识、滚动字幕带或主播声）。也不是发布会演示：没有居中标题幻灯片，也没有翻页。

## 这个风格最俗的版本

- 来源正文未给出一套固定的俗套画面、配色、配器或开场结尾组合，因此不补造。相邻风格边界与明确排除项保留在「本质 / 不是什么」。
- 每支片子按主题从来源信号中挑 2–3 项，并在简报的风格栏说明保留或改动了什么；故事、数据、构图与时间线重新设计。

## 适配

- 用途：多来源调查、事件时间线与证据解释。
- 内容：以当前项目真实素材和用户目标决定是否适配；只借用下方通用媒介规则。

### 素材、事实与推断标注

用可查证的照片、文件、录音、地图、实测数据或现场影像组成证据层；画面来源标签说明材料类型和具体出处，完整署名进入片尾或项目记录。画面数字和旁白主张回到一手/官方材料或原始测量；把直接观察、资料原文、计算结果和推断分开。地点、时间或机位无法确认时标成约略、推断或未知，不让标注动画替代证据。

## 技术路线

本节列出的源码文件/函数名用于定位来源工程的实现示例，不是本地 API；Motion 可按本片需要使用原生工具实现其中的视觉方法。

- 单页 Canvas 2D（`index.html`）；`window.render(t)` 可确定性重现画面；`window.TEXTS(t)` 供 `readcheck.mjs` 检查（仅检查关键文字，计数器除外）；`window.SUBCHECK()` 检查字幕是否单行。所有时间都在 `film.json` 中（段落、旁白起始时间、原声片段、字幕），页面、混音（`audio/mix.py`）和字幕工具（`tools/cues.py`）共用该文件。
- 页面中的可复用部件：`plate()`（调色 + 颗粒 + 闪白）、`ring()`（圆圈 + 引线标签）、`cover()`（填满版块且不拉伸，并返回来源 → 屏幕坐标映射供圆圈使用）、`badge()`、`wave()`（带播放线的波形）、`playhead()`（与混音共用的事件时钟关键帧）、`planPanel()`、`schematic()`（带分区 / 抖动效果的 16 格侧视图）、`push()`。
- 预处理：`tools/prep.sh`（ffmpeg + pdftoppm + PIL）、`tools/wave.py`（波形峰值）、`tools/fonts.py`（OFL 字体子集）。检查工具：`tools/subcheck.mjs`、`tools/final_asr.py`（逐行检查成片语音）。



## 材质与渲染

- **至少三类来源**：动态影像（新闻片、CCTV、手机视频、发射现场摄像机）、文件（证词、备忘录、电报 / 电传、报告页面）和照片。若有相关素材，再加入声音（原始解说、无线电、录音）、数据（天气、遥测、计数）和地图。
- **文件**：扫描页以条带或整页展示，绝不重画；只高亮决定性的一行（红色，`multiply`，α ≈ 0.6，由左向右擦入）。若文字只有转录稿（报告、电传内容），则用代码重新排字，并标明“转录”。
- **档案影像处理**（1950 年以前的胶片，最大约 2.5×）：去隔行（`bwdif=0`）→ 裁边 → 去块（`hqdn3d=2:2:3:3`）→ lanczos 放大 → 轻度 unsharp（`5:5:0.5`）→ 灰度；所有素材使用同一层颗粒。现代影像不超过 1.5×。绝不使用上过色或“修复过”的拷贝。
- **统一调色**（Canvas 的 `ctx.filter`）：影像和照片使用 `grayscale(1) contrast(1.22) brightness(0.94)`；纸张使用 `grayscale(1) contrast(1.05) brightness(0.86)`（将白页压成浅灰）；地图转灰度、反相并设 `brightness(.62)`，让它们呈现为深色线稿。
- **统一颗粒**：六张 256² 高斯纹理逐帧旋转，使用 `overlay` 混合；影像 / 照片 α 0.22，纸张 α 0.10。颗粒只加在来源素材上，不加在文字或线条上（`mux.sh … 0`）。
- **绘制的证据**（平面图、侧视示意图、图表、点阵）在版块底色上用细线绘制；未经测量的内容须标明*示意*。
- 去掉频道标识、水印和来源自带的标题卡；绝不生成图像来冒充历史影像。

## 字体

- 中文标题和调查发现：Noto Sans SC 700（30–124 px）。标签、时间码和刻度使用 IBM Plex Mono 400/600。引文原文使用 Source Serif 4 Italic；其下的译文使用 Noto Serif SC 500 和次要色（仅在字幕没有表达该译文时加入）。所有字体均为 OFL，只嵌入屏幕上实际使用的字符。
- **每帧少放文字。** 每帧只保留当前节拍需要的信息：主要读数或标题、被高亮的原文，以及每件证据的一条简短来源标签。除非当前节拍就在讨论它，否则不放眉题标签、每个中文标签下的英文复本、档案编号、日期或“估算／示意／不按比例”等脚注，也不重复字幕当前正在说的话。
- **来源标签**：6×12 芯片 + 等宽字体的 `类型 · 来源`，约不超过 12 个字符（`照片 · Pasquarella`、`FBI 电传 · 1937-05-08`），放在画格正上方。完整署名放在片尾卡，不放在版块里。
- **下三分之一信息条**：红条 + 地名（36 px 粗体）+ 一行等宽字体的地点代码。
- **字幕**（双语影片）：位于画面底部（中文基线 y ≈ 984，英文 y ≈ 1022）；中文 34 px 粗体叠在英文 23 px 上，居中并加 10 px 黑影；**每种语言各一行**，以页面实际 1,500 px 宽度测量；长句拆成两条字幕段。原声也要配字幕，并标记 `【原声】` / `[1937 newsreel]`。
- **阅读时间**：每条关键文字完整静止显示 中日韩字符数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 s（用 `readcheck.mjs` 检查）；结论和比较画格至少停留 2.5 s，且每个项目都要完整出现在画面内。计数器（时间码读数、秒表）和刻度标签不受此规则限制。

## 运动

- 30 fps。图形以**切入**方式出现（透明度变化 ≤ 0.1 s），配 3–4 帧白闪，仿佛从证物柜里取出；没有飞入、弹跳或缩放弹出。
- 只有**绘制**的内容逐步显现：圆圈在 0.5 s 内顺时针画出（缓出三次方曲线），引线和连接线用 0.4–0.8 s，平面图逐笔绘出，高亮扫入，电报使用打字机逐字出现。
- 单个画格内部允许缓慢推近（地图 ≤ 1.9×，照片 ≤ 1.06×）；“摄影机”本身不移动。版式只在切点处改变。
- 时间刻度变化（分钟 → 秒 → 天）发生在段落切点，并通过读数形式变化承载（钟表 → `T+` 秒表 → 日期），不靠一条时间带缩放。
- 至少每秒发生一次变化；只有结论画格可以停留。

## 画面怎么活

- 计时段内，事件时钟 / 秒表在关键帧间缓动、运行时匀速推进（每格代表一秒）；波形播放线只跟随对应的声音位置。计时结束后读数停在证据值。
- 圆圈、引线、高亮和打字逐项出现后停止；档案静帧不额外漂移。来源没有规定独立的背景微循环。

## 镜头语法

- 画面规格 1920×1080，边距 60 px；内容放在 y 60–900，字幕置于其下（y ≈ 950–1030）。版式使用完整高度；不为时间线预留条带。某一段没有字幕时，让内容垂直居中。
- 版块使用硬边矩形和 1 px 边框；影像版块保留来源画幅比例。
- 常见版式：左侧**地图 → 平面图**，右侧配参考照片和影像版块；**一条大陈述 + 一段引文 + 一张宽幅示意图**；**五来源证据板**（上方三个证据画格，下方声音和报告，右侧示意图，红线汇聚）；**三栏同步网格**（报告 / 照片 / 视频置于同一秒表下，各来源开始时对应栏目亮起）；**文件条带 + 双栏结论**；**主张卡 + 事实核查卡 + 点阵**；**证据地图**（平面图、断轴迷你时间线、示意图、带连接线的缩略图）。
- 避免居中版式、页面页眉和幻灯片式翻页。转场使用 0.5 s 网格上的硬切、白闪和倒放；不用叠化。

## 声音调色板

1. **底音**：低音提琴和大提琴持续演奏低音 D；滤过的室内底噪比旁白低约 30 dB。
2. **时钟声**：分钟刻度段每 0.5 s 一次钟摆滴答，等待的分钟里更响；计时事件中每个**事件秒**响一次（每 5 秒加重音），形成可听见的秒表。
3. **和声**：慢速段落下方铺安静的八分音符拨奏固定音型（Dm – B♭ – Gm – A）；用小二度簇状颤音营造紧张；结论栏使用缓慢持续和弦；证据地图配能解决张力的 D 小调 add9 和弦与颤音琴。
4. **拟音**（操作动作）：文件配纸张声，照片配快门声，电报配摩斯“滴答”和按键声，电传配连续敲字声，倒放配扫掠声，平面图配铅笔刮擦声，撞击瞬间配一次深沉闷击——随后接近静默。
5. **原始声音**（档案解说、无线电、录音）：限制在 180 Hz–5.5 kHz，并加入稀疏爆裂声；画面中显示带红色播放线的波形，并逐词点亮；音乐在其下方压低 −12 dB。原始声音和配乐轮流出现，绝不同时都很响。
6. **旁白**：平静、平直（来源方案中的旁白为 Kokoro `am_michael`）；音乐在旁白下方约压低 −9 dB；响度 −14 LUFS，真峰值 ≤ −1.2 dB。

## 原生手法

- **定格、圈出、放大。** 用白闪冻结画面；顺时针画出 2.5 px 红圈；画到 60% 时出现引线和粗体标签；旁边打开 ×2 放大镜，裁自同一来源像素（屏幕像素不得多于来源 1 像素）。*适用：*CCTV 中的车牌、焊缝裂纹。
- **硬同步点。** 选择每个来源都能识别的同一瞬间（撞击、闪光、公共时钟、枪声峰值），并据此对齐各来源。较晚开始的来源就较晚出现；如果时间差有意义，用旁白或字幕说明。*适用：*哪部手机先开始拍摄；发射摄像机何时失去飞行器画面。
- **三栏同步网格。** 文件 / 照片 / 视频并排放在一个大秒表下；每栏在其来源开始时切入（伴随白闪），于是时钟运行时网格从左向右逐渐填满；在同步点冻结画面，并用红色虚线横贯各画面。*适用：*两部行车记录仪和一份警方日志。
- **读数切换刻度。** 每次段落切点都改变时间读数形式——卡片时间戳和图表播放头表示分钟，`T+` 秒表表示秒，日期表示天——以配合故事收窄或展开。*可选：*只有整部影片始终围绕同一只时钟时，才在底部放按来源类型分轨的时间带；不加标签，并在时钟停下时撤掉。*适用：*从一周缩到一分钟的市场崩盘。
- **倒放冷开场。** 从关键冻结画面开始，把其他来源砸入网格，扫过同步线，再倒放（影像反播并加扫描线）回到事件起点。*适用：*任何事件重建。
- **电报跟着时钟落下。** 用排字呈现无线电报 / 消息，在各自时间戳处落入，并配摩斯声和按键声；用红色虚线引线把卡片连到数据图表时间轴上的对应位置。*适用：*聊天记录、空中交通管制呼叫、电子邮件。
- **带播放头的数据图表。** 在画面下方放风速、速度或温度图表，包含时间轴、只用一个词标记的事件色带（风暴、停电）、消息标记点，以及承载时钟的红色播放头。*适用：*停电前电网负荷变化。
- **地图 → 平面图。** 真实测绘地图推近现场，再切到测量平面图，标出主体位置、方位、距离环、摄影机位置和推断视野锥；地图保留为定位小窗。*适用：*每位目击者站在哪里。
- **证据 → 模型连接线。** 每个来源里的圆圈都用红色虚线连到同一张示意图的同一区域；✓ 标记彼此相隔 0.12 s 落下，并配轻微木槌音。*适用：*火灾从哪间屋子开始。
- **当时的主张与记录对照。** 先播放时代主张的原声，再切到事实核查卡；把主张里的错误词划掉。*适用：*新闻稿与已提交的数字对照。
- **已知 / 未解决。** 分成两栏，以勾选框和虚线框区分；每项完整停留至少 2.5 s；整张板共用一条来源标签。*适用：*任何调查的结论。
- **用点表示人物。** 每人一个点；死者逐个变为红色空心圆环；另配一个大号总数。*适用：*任何事件中的乘客、工人或受害者。
- **证据地图。** 平面图、断轴迷你时间线、示意图和每个来源的缩略图同时出现，所有连接线汇聚其上；作为海报帧。*适用：*任何调查的结尾。

## 变化空间

每部影片由 Agent 决定：事件、来源、同步点、时钟经过的时间尺度、版式、开场和结尾。

- **三种结构：** 从关键冻结画格冷开场，再倒放并重建事件；围绕“它从哪里开始？”这一问题，逐个来源给出答案；或用严格时钟（T−10 min → T+1 h），让发现按实际发生时间依次落下。
- **三种同步点：** 撞击或闪光画格；多段录音中都能听见的声音峰值；公共时钟或广播报时信号。
- **三种结尾：** 证据地图；停留在画面上的已知 / 未解决板；回到开场画格并补全标注。
- **其他题材：** 交通碰撞（行车记录仪、CCTV、警方报告）；抗议活动（手机视频、照片、陈述）；体育比赛中的争议判罚（多个机位、规则手册）；发射失败（跟踪摄像机、遥测、事故报告）。

## 坑

- **把推断冒充事实。** 摄影机位置、照片时间和时间偏移须在屏幕及 Motion 既有项目事实 / 来源记录中标为 `≈ / 推断 / 无法定位`（必要时保留原标签 `inferred / unlocated`）。
- **把早期报告当成事实。** 首夜备忘录和当时的新闻片经常与最终报告不一致；可把它们作为画面，或作为待核查主张，绝不能据此提供数字。
- **伪造多机位事件。** 只有一段获许可的胶片时，不要借用来源不清的片段；改用胶片 + 照片 + 文件 + 声音交叉核对。整体结构仍然成立。
- **“连续”镜头里的接缝。** 曝光跳变或胶片拼接会打断计时；时间长度采用官方记录，并注明对齐误差。
- **时区和钟表。** 旧报告可能使用标准时间，而当地当时采用夏令时；选定一种时间并在屏幕首次读数时说明一次（如 `18:25:00 EST`）。
- **一次塞太多内容。** 每种版式只呈现一个发现；一块证据板最多五个来源；字幕绝不逐字重复标题。
- **屏幕文字过多。** 只留当前节拍所需内容（主要读数或标题、高亮的原文、每个来源一条简短标签）。眉题、每个标签的英文复本、档案编号、脚注，以及字幕已经表达的翻译都会让画面变成噪声。
- **为缺失素材留空白占位框。** 灰色的“没有影像”或“等待照片”方框看起来像渲染错误。用真实材料填入该位置、改变版式，或等来源实际开始时再让它出现。
- **底部预留条带**（时间线、字幕轨）在没有内容时会留下空带。内容区延伸至 y ≈ 900；字幕区（y ≈ 950–1030）不放其他内容。
- **把灾难当成奇观。** 不慢放火焰或撞击，不满屏火焰，不在死亡画面上加音效。
