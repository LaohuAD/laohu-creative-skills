# 让下游从已形成的构想继续

当前文件为父级方法。若宿主先打开这里而本轮尚未由父级确认所求产物、材料边界和调用范围，先返回[laohu-story 主入口](../../SKILL.md)完成运行接入、意图、授权和方法选择。父级选中本方法后，再按它交付的状态与范围处理并返回父级。

接收总体构想及实际进度、目标媒介及接收方、用户目的与体验、已有文件及位置、锁定项、开放项和材料证据。沿已建立的骨架、人物和核心材料编译方向简报。题材或媒介若只用于讨论，可在当前构思尺度完成，依宿主判断启用。

## 先核实下游能从哪里继续

- 先看每处主线需要什么前提，已经有的具体行动或感知材料是什么，离开该段时改变了什么，后段消费了什么。提纲已有台词、段落名或效果词，须核实是否实际写出了承重内容和依赖。若主题、重大转折、结局或某段为何承重仍缺，先回宿主处理影响范围。
- 在当前授权内能补时，给一项具体的工作提议，写明依赖的前段条件、这一段的可表现内容和它为什么支撑后段。限制导致无法定案时，给出所缺条件、其具体影响和有依据的补法，标出该处待选或暂缓定稿。已有可传部分先交接；不要让下游猜主题、主要行动、关键方法或结局。用户留白的部分应写出有意保留的问题、下游可用的边界及不靠解答也能继续制作的依据。
- 用户要求转交或进入制作时，宿主按运行约定核实实际入口及本轮授权。文字简报和正式调用按各自授权执行。能力不可调用或缺少必要生产输入时，仍可交可用简报，指出缺哪一项；创作建议不得冒充已确认制作决策。

## 按实际接收方选取内容

共同材料包括作品目的、收看的关系或体验、固定事实和必须保住的立场、已采用的方法/具体处理、出处与现有路径、开放空间与后续待核证据。只传会改变下游判断的信息。每个承重单元给可表现动作或形态、作用及前后承接；视需要说明接收者进入、离开时的认识与感受。确认项和工作推荐的身份随内容传递。

| 接收方 | 交接锚点 | 由接收方处理 |
|---|---|---|
| [laohu-script](../../../laohu-script/SKILL.md) | 目标体量或时长区间、开场和结构顺序、阶段的意图与实际行动、转折所据、人物欲望及关系、观众与人物的知情先后、伏笔与对应回收。可附一两句关键声口提议和可见可听的高光方向。 | 分场、场戏与完整对白、剧本正文和后续制作。 |
| [laohu-novel](../../../laohu-novel/SKILL.md) | 保住现有章节梗概、事件顺序与连续性，注明各段要让读者看到的人物经验。需体现视角时注明推荐观察位置、聚焦与读者会先知什么，列清已定关系、身世与材料事实等保护项。 | 完整章节、叙述声音与精确时序、小说成文和修订，承接已成形的全书方向。 |
| [laohu-lyrics](../../../laohu-lyrics/SKILL.md) | 抒情主体、倾诉对象、场合、具体动作物件和情感为什么会转。按实际曲词形式给段落的情感作用、何处集中表达、核心句意或可变义的重复。主歌、副歌、桥段等只在该形式需要时给方向。 | 完整歌词、押韵、声口、格律和演唱适配。 |
| [laohu-arrangement](../../../laohu-arrangement/SKILL.md) | 目标听感、进入到收束的推进、关键情绪/动作处如何张弛、时长倾向；若词已定，带上真实词稿、重要句意和表演需要。纯音乐沿声音材料和感知变化交接。 | 曲式、旋律、和声、编配、音色、音频与实际试听。 |
| [laohu-writing](../../../laohu-writing/SKILL.md) | 核心命题、态度边界、事实材料和证据缺口、读者认知起点、由哪几步得到新理解、拟收束或行动。 | 完整文章或口播、标题定稿与发布编辑。 |
| [laohu-assets](../../../laohu-assets/SKILL.md)、[laohu-image](../../../laohu-image/SKILL.md)、[laohu-cover](../../../laohu-cover/SKILL.md)、[laohu-video](../../../laohu-video/SKILL.md) | 仅对实际接收方给必要的方向。角色记身份/关系、可辨动作或形态、用户已定能力和情境；标志物件记功能、出现前后状态、必要持有/空间关系；场景记地点、关键空间用途、可见/可听行为及氛围；视觉方向记与叙事或感知对应的明暗、动静、气质或画风，区分用户已定与工作建议。资产可标重复使用、状态变化与来源位置；图像/封面优先关键视觉关系和被识别的对象；Video 保住行动、顺序、位置、信息显露和声画分工。 | 角色、服装、道具、场景的正式资产设计与提示词，正式画面、视频分镜和运镜、制作分段及实际生成。没有设定依据的微观规格由对应专业制作补足。 |

没有选定具体制作入口时，提案可以仅保留对后续确有影响的方向级信息。诗词、独立标题及其他作品按当前工程中实际可用的专业能力承接其对应构想，已有素材与表达要求照常递交。正式制作、保存及外部发布沿运行约定接续本轮授权。

## 返回宿主

交付按实际接收方清晰可读的简报，至少能指出锁定内容、可直接采用的工作决定、未定且会影响实现的事项、下游可自行解决的尺度、真实未验证项。面向多个接收方时共用一份主线，再分别传少量制作相关信息。宿主把它接回完整构想或诊断交付；给了交接资料后按用户请求决定是停止在简报还是调用制作入口。
