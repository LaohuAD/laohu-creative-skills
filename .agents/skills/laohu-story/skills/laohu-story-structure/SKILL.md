# 叙事结构与因果推进

当前文件为父级方法。若宿主先打开这里而本轮尚未由父级确认所求产物、材料边界和调用范围，先返回[laohu-story 主入口](../../SKILL.md)完成运行接入、意图、授权和方法选择。父级选中本方法后，再按它交付的状态与范围处理并返回父级。

接收宿主已恢复的目标、人物最在意之事、当前所知、既定事件与规则、目标体验和可补范围，按已有顺序、篇幅与媒介约束选用方法。这里负责故事主线及跨集依赖，局部事件只在需要处理单回与跨集承接时进入本模块的相应部分。

## 按故事如何推进选择主结构

先找能带动前后变化的关系，再选一种主结构。用户已选的组织原则优先，先检查它在哪些事件上实际起作用。以人物选择推动全篇的因果故事，读取共享[五项宏观功能](../../../laohu-script/references/narrative-and-structure.md#完整因果故事的五项宏观功能)，按初态如何失衡、旧路如何逐渐受限、此时必须选什么、选择怎样改变局面、后来留下什么来回查拟选结构。五项功能可以相叠、合并或缩放。

| 主导材料和体验 | 落地动作 | 适配检查 |
|---|---|---|
| 救援、追求明确目标、闯关或限时竞争由行动改变局面 | 默认采用 Syd Field 的三幕及两处转折，用五项宏观功能检查因果。建立人物常态与失衡事件。第一转折落实为主角的选择或压力造成的义务，从此按开场的办法生活就无法达成眼前目标。中段让阶段成果改变计划，并让旧策略逐步耗尽。第二转折落到可追溯的损失、发现或受阻，逼出必须承担的选择。末段写选择怎样变成解决行动及其余波。 | 第一转折与激励事件可同场发生，但要分别能看见扰动和真正走向新路线的原因。第二转折改掉的是可行解法，光提高危险口号或临时撤回角色能力不成立。 |
| 短寓言或奇遇的要害是离开常态、带着所得及代价回来 | 用 Dan Harmon 八环。建立人物与缺口，跨过门槛，适应陌生规则，获得或一时以为得到了所求，付出代价，带着实际所得或缺失返回；回到可比的处境时，以具体做法显示这段经历带来的变化或暴露的固守。 | 返回可以是回到同一关系、动作或问题，无须走回原地点。人物若仍旧固守，须看得出他此前未见的代价或重新作出的选择；由材料决定是否适用此圆环。 |
| 人物惯用解法为何失灵、怎样认识到自己造成的后果，是主要关心的结果 | 借 John Truby 的七项人物与情节关系，区分已有弱点和实际需要、试图获得的明确目标、以自己的计划或规则阻断人物达成目标的对手、人物计划、决定性较量、对自己的重新认识及新的常态。由结尾的具体行为回推何种碰壁使认识成立。 | 让同一性格既给人物解决问题的办法，也使他付出具体代价；认识须从行为或关系结果显现，未要求教训时无需解释成道德总结。 |
| 多位人物各有主线，必须看到彼此改变对方的路 | 用群像交织。为各人确定独立目标、资源和压力，找共同接触面。安排一次交会，使甲的策略实际改变乙能做的事，再让乙的回应回到甲的后续选择。穿插按意义、因果、揭示时机和观看节奏裁决。 | 盖住一条线，另一条线的选择或理解应有可指出的损失。人物能互补，也能错开，各自主线的代价或所得需要在交会后留下。 |
| 主要满足来自看习惯、时间、关系或状态，而非对抗制胜 | 沿日常基线、同一物件/行为的重复与偏离、处境如何显露、余波或有意维持组织。把观众从前后可比动作中能读出的差异落成可见可听的材料。 | 如果故事仍由人物行动带来的实际后果推进，按上面的五功能回查低强度的失衡、选择与余波，强度服从用户的观察目标；有意平静的状态组织采用本行自己的依赖。 |
| 串联单集或规划后续 | 按[单回结算与跨集承接](#单回结算与跨集承接)处理。每一集内部再按该集实际任务选轻量组织方式。 | 系列名、角色数量或用户提到“下一集”以外的素材本身不打开跨集写作。 |
| 已锁定非线性、碎片或其他组织原则 | 按原选择找每个单元的承重关系。分别注明世界中何时发生和观众此刻能理解什么；让并置、重访或局部行动实际改变认识、注意或感受。 | 如果补足条件就可成立，保留书写顺序；缺口确需改变已锁定组织时带回宿主核对。 |

## 正推人物行动，倒推高潮成立的条件

1. 先从拟议的高潮或结局倒推。决定性结果需要什么资源、规则、能力、选择、关系或知情条件？把其中影响结局的因素在前段自然用过一次。篇幅允许且容易忘记或依赖复杂时，中段再轻触或变奏一次，兼有当场用途。极短篇可让同一次建立同时完成提醒。开放结尾可保留答案，但要知道哪个问题得到回应、留下的问题由哪一件事托住。
2. 再沿人物能知道的事正推。以当时的目标、性格、可选办法与真实代价来决定行动，对手或环境的回应来自其原先的目标、规则、时间、信息或资源。两端接不上时修补能动的前提或路径，保持已有角色实力与世界规则。可以让另一项义务、限时或彼此的应对堵住原有优势。
3. 主线有持续对抗、若干次尝试而中段散开时，借 Gulino 的序列思路给每组事件一个能局部结算的目标。适合以数个阶段推进的中段可先试两至四个承重单元，再按体量调整。其余组织方式依自身的变化和接触次序划分单位。每一单元写清尝试、局部回应和结果。相邻承重单元用“因此”检验前果是否成为下一条件，用“但是”检验既有规则或对方回应是否改掉眼前路。实际提案顺口即可。并置、呼吸和感知段落可有自己的作用。
4. 只对承担改变策略、期待、知情、局势或关系的关键单元，读取共享[构造有效落差](../../../laohu-script/references/narrative-and-structure.md#构造有效落差人物预期世界回应下一策略)和[相称尺度的回查](../../../laohu-script/references/narrative-and-structure.md#幕序列场beat-的拆分和回查)。写出人物凭已知行动并预期什么、合乎对方或环境规则的回应、人物如何重释/换策或承担新代价，以及全篇或本序列因此改变什么。承诺兑现、等待或有意维持只需相应条件；不要求每拍逆转。
5. 对中段和高潮做一次删减检验。暂去一个单元，查看选择、信息、后果、人物关系或必要体验是否改变。承担节奏、对照和预期回收的单元可留，只有地名、怪物和难度标签换了的单元改成真的前后依赖，或合并。确有问题待解时，用前文已知条件完成决定性的解决行动并留下一处可见后果。观察故事可用重复、微差或余波回应开场。

## 单回结算与跨集承接

明确要求系列、连续多集或让本回状态进入下一回时，仅读取 [系列开发的可验证发动机](../../../laohu-script/skills/laohu-script-series/SKILL.md#2-把引擎写成可验证的因果句)和[结算账本](../../../laohu-script/skills/laohu-script-series/SKILL.md#季弧与结算账本)的相关方法片段。借局部方法，本次仍是故事构思。

1. 写出谁反复面临什么问题、哪类关系能让每回带来相似而有变化的体验。用户仍在探索系列时，按每条候选方向先从已有材料推演可各自成立的触发、行动及本回结果。比较同方向各点，只有更换参与者、地点或物件时，再找真正改变走向的行动、条件或结算。把共享机制和各点简述一并交回宿主，供细写前完成覆盖与浏览检查。未选的事件互不继承。
2. 只续一个独立单回时，在该事件内写清解决或留下什么。用户点选或明确要续写的连续事件，先辨认接手的是实际发生、已选事实还是工作提议。让人物在新事件中使用前一结果改变过的能力、资源、承诺、关系、知情或可行路径，不把提议冒充已发生事件。实际前果要参与人物选择及结果，开头提一句旧事仍缺承接。
3. 留给后续的是这一回确实产生的具体可用状态，说明后来可以由谁使用以及它允许或改变什么。保留系列结局和身世等原有开放范围。本模块停止在当前所需单回、跨集承接或连载构想，不据此写完整季纲、Pilot、series bible、剧本或产能配额。

## 回到宿主

返回选型及其对应体验、全篇或本轮单元的承重条件与结果、相邻变化、铺垫回收和相对容量。标出已定顺序、工作补设及未决承重条件。宿主把骨架交给需要的体验方法补实事件，再经全篇组织走查。开放系列探索返回每个方向下的独立事件概要，交宿主按[对话呈现与阶段记录](../../SKILL.md#对话呈现与阶段记录)先排入实际交付稿。概要里的变化和本回结果供用户独立选点，支撑细节再接到相应点下。只要单回或明确接续时，返回这一回的具体行动、结果及实际指定的继承状态，宿主沿原限定完成。
