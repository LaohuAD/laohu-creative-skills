# 叙事结构与因果推进

当前文件为父级方法。若未由父级确认任务范围与材料边界，先返回[laohu-story 主入口](../../SKILL.md)。接收目标体验、人物最在意之事、既定事件与规则、体量及可补范围，搭出从开端到收束不散架、前后咬死的因果骨架，交回宿主配体验引擎与完整组织。

## 一、按故事驱动力选主结构

用户已锁定的组织原则优先；未锁定时，按材料真正推动变化的方式选一种主结构（可按需轻度组合），不要求用户先说出结构术语：

| 故事靠什么往前推 | 首选结构与落地重点 | 常见失效红线 |
|---|---|---|
| 救援、闯关、追明确目标、限时竞争，由行动改写局面 | **三幕两转折 + 五项宏观功能**：建常态与失衡（激励事件）→ 第一转折让旧生活办法彻底失效、进入新路线 → 中段分 2–4 个可局部结算的阶段（进展纠葛），每次成果改变计划、旧策略逐步耗尽 → 第二转折带来可追溯损失或发现，逼出两难抉择（危机）→ 选择变成决定性行动并改写局面（高潮）→ 回应开场问题的余波（结局） | 第二转折只靠喊口号升级危险，或临时把强者写蠢；把五个功能名词直接当标题抄进正文 |
| 短寓言、奇遇或跨界穿越，要害是离开常态再带所得与代价回来 | **八环回环（Harmon Story Circle）**：常态 → 缺口/想要 → 越界进陌生规则 → 试探适应 → 拿到或以为拿到所求 → 付出真代价 → 回到可比处境或关系 → 以具体行动显出变化或固守 | 返回后什么都没变，或强行把固守改写成鸡汤成长 |
| 核心看点是人物惯用办法为何失灵、怎样直面自己造成的后果 | **人物因果弧（Truby 七步）**：内在弱点与真实需要 → 明确外在欲望 → 以自身合理计划阻断主角的对手 → 主角计划与碰壁 → 决定性较量 → 由行动结果显出的重新认识 → 新常态 | 让人物突然开口发表道德感悟，而不是用具体行为和后果证实认识 |
| 多位人物各有主线，精彩在彼此撞出连锁变化 | **群像交织**：各自立独立目标、资源与压力，找共同接触面，安排交会让甲的策略真实改变乙的选择，乙的回应再反咬甲的下一步 | 盖住其中一条线，另外几条线毫无损失；仅靠轮流切场拼盘 |
| 满足来自看习惯、时间、关系微移或日常状态，不靠对抗制胜 | **日常观察流**：建立日常基线 → 同一物件、动作或地点的重复与微偏 → 处境借具体细节显露 → 留白余波或有意维持（仍可按低强度失衡与选择核对推进，绝不硬拉高冲突） | 强行加反派、秘密或大反转破坏安静气质 |
| 串联多集、规划系列持续机制或承接前次结果 | 转入下方[单回结算与跨集承接](#三单回结算与跨集承接)，单集内部仍按本集驱动选轻骨架 | 仅因故事有固定店铺或多人就硬扩季纲或剧本圣经 |
| 已锁定非线性、碎片或倒叙 | 保留原顺序，同时分开记录真实发生时钟与观众知情时钟，确保每次并置或回访都改变理解或感受 | 靠遮蔽基本前提冒充悬念 |

## 二、两阶段定爆点，再两端咬死因果

搭好骨架后，必须先立高潮再两端对推，彻底掐灭中段流水账、高潮写软与结尾机械降神：

1. **强高潮与铺垫区两阶段解耦（安静观察流豁免）**：凡高潮成败决定全篇上限的因果故事，绝不从头顺写一锅煮——**先用爆点脑独立铸硬核心高潮或反转瞬间**（接住前文蓄压完成高对比效价释放，人物当场做出不可逆选择或真实破防，绝不在高潮处竖起防御盾、继续解释世界设定或切回理性结案说教）；锁定爆点后，再彻底切回克制铺垫脑倒推引入、蓄压与节奏伏笔。
2. **从高潮与结局倒推**：决定性破局需要哪件道具、规则、能力、秘密、关系或认知条件？把真正影响结局的要素提前在前段自然用过一次（且当场有合理用途）；篇幅较长时中段再变奏轻触一次。开放结尾须明确定出核心问题回答到哪、留白靠哪件事托住。
3. **沿人物所知正推**：每个阶段写清人物凭当时掌握的信息与能力试了什么、对手或环境按自身原本的目标与规则怎样回应。两端接不上时调整未锁定的前提或路径，绝不靠临时降智、削弱强者或空降新规则救场。
4. **相邻单元过因果/转折检验**：把中段连续阶段两两摆在一起读——下一段必须是上一段结果的直接延续（因此）或被既有规则与对方回应硬生生撞偏（但是）。如果相邻两段之间只能用然后接上，立刻把上一段的成果、损失或代价改写为下一段的门槛。
5. **关键转折过局部落差检验**：只对承担改变策略、关系或局势的关键节点，核实行动者预期 → 独立世界回应 → 人物被迫换策与代价 → 改变上级故事问题；承诺兑现、等待或仪式段落不必硬造逆转。
6. **中段删减检验**：暂抽中段任一承重单元，看后续选择、信息、关系或必要体验是否真的受损；只是换地图或换名字重复同一种受阻的，合并或重做。

## 三、单回结算与跨集承接（仅系列任务触发）

1. **系列发动机一句话**：写清在什么固定世界或日常条件里、哪类持续矛盾会迫使人物反复介入、每回带给观众什么可重复又各有变化的观看乐趣。仍在开放选点时，按方向给出彼此独立的故事点简述（每点自成触发、行动、回应与本回结果，不靠只换顾客或物件凑数），交宿主先排总览与概要再细写；未选故事点互不继承。
2. **连续单回消费前果**：用户点选或续写连续事件时，先辨清接手的是已发生事实还是工作提议；新事件里的行动与抉择必须真正用上前次留下的具体能力、资源、承诺、关系、知情或路径变化，绝不只在开头提一句旧事。
3. **本回结算账本**：写清本回解决了什么、给后续留下哪项具体可用状态（谁能用、改了什么门槛），同时保住用户未定的主线身世与大结局开放空间。本模块止步于单回或跨集故事构想，不越权写季纲、试播集全本或制作圣经。

## 返回宿主

交回所选主结构、各承重阶段的前提/行动/回应/结果、关键铺垫与回收位置、相对体量估计及待决承重项。完整叙事回宿主接[体验引擎](../laohu-story-engines/SKILL.md)与[完整作品组织](../../references/whole-work-conception.md)；系列探索回宿主按好扫读版式呈现。
