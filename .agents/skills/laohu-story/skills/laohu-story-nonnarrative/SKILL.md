# 非叙事作品的感知与形式构思

当前文件为父级方法。若宿主先打开这里而本轮尚未由父级确认所求产物、材料边界和调用范围，先返回[laohu-story 主入口](../../SKILL.md)完成运行接入、意图、授权和方法选择。父级选中本方法后，再按它交付的状态与范围处理并返回父级。

接收宿主传入的材料与固定条件、主题或核心体验、媒介、要探索的数量或本轮范围。判断效果依靠什么成立。人物可作为被观看的形象、片段记忆或抒情主体出现，是否有角色、时间流逝或某个媒介名称，不能单独决定要组织成情节。叙事性歌词、影像或组图若主要依靠人物行动及后果推进，交回宿主确定叙事做法。

## 找到承担体验的关系

1. 把抽象感受具体化。列明哪种对象、材料、空间、声音或语言关系触发它，接收者能注意到什么，对应在哪个可感知的位置。记得对齐已给的体验力度和材料事实。
2. 改一项真正改变感知的条件。用观看距离、重复与偏离、邻近或分离、比例或语境恢复习见对象的特征。保留同一个起点，让不同处理产生不同注意、动觉或意味。对照原关系与新关系，指出第一眼、第一耳及后续注意的位置究竟怎样改变。
3. 根据目标媒介和内容确定承载方式。按下面对应部分工作；仅需一个感知关系时深化该处，多方向的数量和停止回到宿主。

| 当前对象 | 判断与构思动作 | 本轮可交付内容 |
|---|---|---|
| 单幅图、海报、封面、组图 | 用主次、比例、空间留白、密度、方向、光影或材质差别确定第一眼及二次发现。单幅可以同一眼感知整体；系列再考虑重复关系、顺序或渐变。封面和标题依其服务的内容与准确承诺组织。 | 主体及辅助元素关系、层次、观看焦点、留白的作用；保留核心承诺与原作品的对应。 |
| 纯音乐、声音、环境氛围 | 从第一耳的听觉对象出发，选密度、重复/偏离、强弱、音色或静默，安排对比的出现、发展和退出。用户已给的录音、动机或声响继续承接。 | 目标听感、重点变化、主要对照、相对时间比重与余韵。 |
| 短诗、散文性抒情、非叙事歌词 | 找到抒情主体、所感对象、触发的记忆或感受；改变意象并置、观察远近、句意、重复或声音节律。决定哪个变化应被读到，哪个联系可以由细节唤起。 | 可展开的意象关系、情境、情感位置与微移、集中表达或收束；有歌词方向时说明核心句意和重复如何变义。 |
| 无剧情影像、纯语言形式、互动或混合媒介 | 依次判断各感知通道承担什么、哪些变化需要时间。可用声画差别、同一词在不同语境中的作用或动作与反馈组织。 | 初始识别、差异显出和余味的位置，用户要求完整时给全程安排；静态组织交代元素邻接与主次即可。 |
| 无叙事主线的文章、评论或标题构想 | 按具体问题、命题、证据、读者认知起点、推理与结论范围组织。用实际信息支撑新理解。附属标题对应内容、承诺、读者和用途。 | 逐部分要点与论据落点，或切入、信息重心和依赖的内容事实。 |

## 组织与回查

时间作品按进入、关键同异、主感知变化、最后留下什么逐项定位。单幅、标题等一次接收的内容由整体主次、位置和对比承担完整性。每增加一个单元，指出它使人能多看、听、想到什么。用户要私人或安静体验时沿该尺度，角色动作、冲突、反转或戏剧性转变须由用户当前表达和材料本身需要。诗词格律、具体音符或编配、正式精确构图、图像提示词及生成等按宿主的制作接口留给相应入口。

回查感知关系是否来自具体材料，是否有第二种不同的感知可用于比较，重复及空缺能否仅凭本轮写出的条件成立。开放发散可以并列保留，选定方向只深化其中一项；结构仍开放就不把暂定意象变成用户确认。输出感知中心、材料组织、可区分的变化或完整组织，再交回宿主完成提案或目标媒介的方向交接。
