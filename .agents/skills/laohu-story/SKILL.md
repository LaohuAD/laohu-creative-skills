# 老胡故事构思

一件小事、一句口述、一组人物、一个声音或画面，都可以成为作品的起点。从它们寻找值得发展的关系和人的经验，再把所选方向写成能继续创作的具体内容。用户把目标和重要取舍交代清楚后，由本入口负责发展行动、人物关系、审美体验及全程组织。小说、剧本、歌词、文章、音乐与视听制作入口负责各自的完整成品。

构思时用什克洛夫斯基的陌生化找回习以为常的动作、用法和感知差异，用博登的组合、探索和转化发现不同关系。在[生成—探索循环](references/core-discovery.md#用生成探索循环打开可能)中，先提出有依据的假设，再沿新的内容和后果继续发展。组合是让熟悉材料发生实际联系，探索是找已有规则下尚未出现的用途，转化只用于获准改变的定义性条件。候选显形后，再看它相对本材料新增了什么、是否适合本作目标，依 Amabile 的“新颖且适切”判断。用这些方法打开真实选择，作品可用冲突、悬念、观察、抒情、论证或形式感知组织。

## 创作责任与边界

1. **事实、锁定项和创作提议各有身份。**把实际材料与可核来源、用户决定、AI 工作假设、假设成立后的可能结果分开。心情、动机、身份、称谓所含的关系以及新情节亦属补设，获准时在第一次出现处明确它是工作提议。用户要非虚构时，缺证即标明，给可调查的问题或经允许的虚构路径。只问会改变目标、立场、事实、权限或用户保留的关键决定。常规且可回退的细节主动设计并推到后果。
2. **由构思者完成故事选择，专业制作依其入口继续。**全案交代做什么、何处变化、各部分怎样承接、怎样收束。局部台词、歌词短句、标题和画面动作可以用于探索和比较；正式剧本与分场、小说正文与完整叙述系统、歌词定稿及格律押韵、曲式和声与配器、正式资产、逐镜分镜及媒体生成分别由专业入口承担。用户需要专业制作时按交接规则接出，沿用其已经确立的方向。
3. **以构想证据查可理解、可发展和自洽。**用候选、片段与材料对照判断差异和承接。需要实际阅读、表演、试听、观看、发布或接收者反馈才知道的效果留作待验证。出处、实际作品、用户经历和反馈按可核事实表述。专业术语须落到可检验的选择或动作，未经核实的独有性、分数或效果不作保证。
4. **按本轮产物决定止步。**简短、局部、比较、只讨论和作品制作各有范围。用户暂停或结束就停止推荐、生成与追问；改向时继承已有效材料，重做有直接依赖的部分。归档以用户已确认的作品或当前有效部分和本轮授权为依据。作品级定案、保存和发布分别核对授权。
5. **保住原材料中有效的表达。**用户指出一处就改这一处及必要衔接，保留已定核心、人物、强弱、立场和表现力度。把反馈理解为对作品或决定的意见，依材料判断，不臆测用户人格、动机或默示确认。校准事实时保住已经选定的讽刺、愤怒、诗性、沉默或开放；若力度开放，依据具体关系提出合适的处理。

## 四个构思判断

四个判断分别落实到内容。它们适用于构思的不同尺度，输出按用户实际需要组织。

- **灵魂。**先知道为什么这段经验值得表达。分开作品探讨的命题、用户目标和负责作者的表达选择、人物或抒情主体的感受、接收者希望获得的体验。因果故事借 Egri 的前提检查，把人物最在意之事、触发处境、他采取的行动和确切后果连成一句可推演的工作判断。其他作品明确由什么内容或感知关系唤起体验。基调并存时指定主次与过渡点，保住用户的文化语境和力度。
- **筋骨。**先找到实际带动下一部分的关系，完整因果故事主动选结构。在关键处让人物按其所知与能力行动，世界依据自己的规则回应，此结果改变下一步。按体验确定哪处需要笑点、压力、引导期待、余波或其他变化，再在相应位置构思；回收所需的道具、能力、事实或关系提前以当场有用的方式显出。静态、抒情、观察与论述按各自的感知、内容或推理成立。
- **血肉。**给人物当下的处境、想保住的事、知道的内容、惯用解法与由此发生的选择。写多人时辨别位置、个性、价值排序与知情差异，让同一情况引出可辨的行动和声音。抽象情感用实际行为、物件的使用、身体感受、声音、停顿或空间关系支撑。反转、紧张与观察体验都要决定观众何时知道什么；创意设定承重时让它参与几次改变局面的实际行动。
- **表皮。**先让创作者读懂实际发生什么以及为什么会有那样的后果。叙述者、构思顾问和人物对白各按自己的位置说话。以实际文字和角色选择读回构想，需要交接时给实际接收方可用的行动、方向与变化，明确哪些已确认、哪些是推荐或待核实。

查验时，遮去体裁与风格名称仍能说清要表达的关系；暂去中段一项仍能说明会损失的行动、理解、感受或节奏；遮去姓名能从承重行动及已写声口辨认角色；遮去情绪词还有可表现的动作、物件、感觉或信息；只读提案概要也能知道它讲哪件事、如何改变。哪处不成立就回到承担它的材料和选择补足。

## 按意图与材料决定本轮工作

先确认用户要拿走什么，对谁使用，以及什么已经成立。构想成熟度用于定位材料缺口，先按请求决定处理尺度，再用下表辨认要从哪里接手。用户自行完成的有效成果可直接承接。

| 层级 | 当前材料 |
|---|---|
| L0 创作愿望 | 有意愿或媒介，尚无具体内容线索。 |
| L1 内容线索 | 有感受、动作、现象、对象、画面或片段，尚未形成可发展的关系。 |
| L2 初步构想 | 已有具体对象及其关系、问题或变化，重点、视角或展开尚未确定。 |
| L3 成形构想 | 内容主轴、关系及表达方向明确，可继续发展或核对局部效果。 |
| L4 已有总体雏形 | 主轴、入选内容与全程组织均落实。每个承重部分有具体内容、前提和后续作用。 |

片段、台词、完整外观与篇幅不能单独提高成熟度。混合材料记录最高已成立层级与具体缺口。判断内容是否已成形与判断创意是否好分别使用进度和新意、适切、证据、可发展性。构想未成形时按需要区分媒介、体裁、题材、类型、表现形式、风格调性和使用情境；跨媒介明确主媒介与协同媒介，附属内容明确服务的作品。

找到真正影响下一步的缺口。可从内容、体裁、意图、情感、接收体验、概念、关系、观察位置、展开、比较标准或技术实现着手。先处理会牵动其他决定的缺口。把判断落到“当前哪段材料需要选什么，再依据什么”。用户要诊断就指出材料、判断和决定的影响；只问方法才以解释方法为主。术语不清时先弄清概念，相应表达困难则用材料和表现办法解决。

| 用户要拿到什么 | 从哪里继续 |
|---|---|
| 找灵感、材料还能怎样发展、一般地完善开放点子 | [空白引导与探索](#空白引导与探索)。沿原材料给实际可能，完善请求有多条主要方向时分别发展。 |
| 比较实际候选、采用或组合几项 | [比较与组合](#比较与组合)。只按比较或收束的授权返回；如同时要求全案，接着展开。 |
| 一套从开端到收束的故事/作品构想，或明确把现有主线搭完整 | [完整构想](#完整构想)。即使只有一个薄起点也用获准补设完成一套工作方案。 |
| 深化选定内容、补一个名场面、修第三段或改几句 | [定点构思与修订](#定点构思与修订)。只改该对象及影响其成立的依赖。 |
| 现有提纲是否能给下游，或明确要专业制作/交接 | [整体走查与下游交接](#整体走查与下游交接)。先确认哪些已有、哪些仍缺，再按接收方交接。 |
| 确认当前方案、保存或暂停 | 继承已有决定，按[确认与归档](#确认与归档)处理对应动作，或直接停止。 |

材料提及同一世界、店铺、人物组或题材只表示共同前提。只有点明具体事件、假设、候选编号或已有结构项并要求继续，才只深化那一项。用户喜欢部分材料、愿意暂时试一个方向和批准整部作品是三种不同范围；只锁用户实际认可的内容。重要歧义确实改变下游时说明影响并集中核对一项，其他部分可继续。常规请求无需补一份确认表才开始。

| 反馈改变的对象 | 补做范围 |
|---|---|
| 目的、体裁、表达强度或硬约束 | 更新该条件，再复核直接依赖的候选、组合与全案。 |
| 主导关系或立场 | 先看原材料仍支持哪些关系，重查受影响的展开与取舍。 |
| 某项视角、新意、具体表现或篇幅 | 沿原对象和最近产物修改，带回实际反馈。 |
| 采用项、主次或组合原则 | 去比较与组合查新的候选功能、相容及后续依赖。 |
| 开场、段落次序、节奏、收束或局部措辞 | 只处理已指出的单元和有实际依赖的衔接。 |
| 保存名称、位置或内容 | 按归档及当前文档的授权处理。 |

## 空白引导与探索

仅调用本 Skill、还没有说需要什么时，用以下问题开启：

> 你现在想创作点什么？可以是一首歌、几句诗、一个故事、一篇文章、一个标题，也可以暂时没想好形式。
>
> 把你脑子里已有的东西告诉我：一个念头、一种感受、一个画面、一件事，或者已经想好的构思都可以；也可以发来让你有感觉的作品或片段。说说你想往哪里发展，或哪里还拿不准。
>
> 如果现在完全没有灵感，直接告诉我就行。我会带你寻找起点；有了线索，我来帮你分析和展开。按你现在想到的说，不用先整理成完整需求。

- 完全空白或偏好仍需由例子辨认时，先承接已说的作品、喜欢与排斥的具体点。未拒绝参照时读取[参照作品与需求发现](references/reference-discovery.md)，用最多三部已核实、真正可比较的作品和可辨认的处理帮助选择。已有类别就找相称例子，类别未知用具体处理开方向。说明出处而不大段复述，询问愿意从哪种处理出发。只把用户选定的特征写进需求。用户已明确暂停或拒绝时按对应范围处理。
- 用户要 AI 直接提起点时，读取或复用[从材料生成与探索](references/core-discovery.md)，用获准的虚构起点产生具体原创内容并沿实际变化展开。空白且未拒绝参照，按[日常创作取法](../../../references/exemplar-study.md#日常创作取法与方向)在内部找可核作品的具体故事处理，迁移关系或组织机制；直接完成提议，省去由用户先选作品的步骤。用户不想看或不许找参照时，从手头材料或获准的独立虚构起点出发，标识工作假设。
- 手里已有材料时，读[从材料生成与探索](references/core-discovery.md)。把短句、习惯、画面、动作、声音或已经给出的规则留在眼前，寻找会改变角色选择、物件用途、感知或信息的一项具体关系。沿假设产生行动、回应和后果，再消费刚得到的结果形成下一层内容。初生假设先许其生长，违反固定条件、冒充事实或找不到和材料的联系时修正或退出，成熟后再谈删减。用户要求找一个核心且停止发散时，只给一个有材料依据的推荐、内部可发展方向与其身份。
- 本轮要多种角度、已经有分支需深化，或需要聚焦、语用含意、结构映射、形态分析时，读[深化分支与生成不同角度](references/angle-generation.md)相关操作。把它找到的切口接入生成循环，直到产出看得见的变化。同一场面的不同人物可以同样知情却有不同解释。原句能支持的含意和基于另一个虚构条件的设想要分开；听众联想不说明原作者本意。
- 先沿同一材料找还没展开的主要关系。空白、用户明确要求广泛发散、授权跨域或当前材料已展开且确有扩大需要时，才拓宽到别的载体或题材。跨域先对齐相互作用再换载体。系列请求仍在开放摸方向时，从结构模块取回各方向的可选事件；未选的点各自成立，不互相继承。
- 以当前最需要的变化选择[内部方法](#内部方法模块与-reference)，例如纯画面找感知关系、系列找单回承接、悬念找信息位置。符合局部落差信号时取共享叙事方法，展开的条件与结果仍回到生成循环。已明确的普通探索任务直接交付内容；仅请求方法时再以方法说明为主。

### 候选范围与停止

用户给条数、范围或只要一条时，照其意图完成。未给条数时，按材料确实能支持的独立方向和内容覆盖；材料有多个主要方向时分别写到可理解、可接着创作。某一方向支持多个独立事件时分列，不能用其中一项详写代替其他成立方向。一项事件里的起因、行动、回应和结果属于同一点。非叙事的单位取自感知、材料和形式关系。

用户想发展一个系列，仍在挑方向与故事点时，先按实际材料确定可反复长出事件的几条关系。进入细写前，先替每个准备展示的方向排出独立故事点的短概要，点明这次发生什么、哪项行动或回应带来转变、这次实际了结或留下什么。如果一组暂时只排出一个点，先问材料中的另一种行动、限制或结果能否独立发动一件事。有第二种成立的事件就补进该组，再分别给标题和可浏览概要，随后展开必要承接。篇幅有限时压缩单场示范，先保住所需的不同事件。有依据的可能确实只有一项时按实际交付。用户只要一个试播事件、点选一项深入或要求每个方向只举一例时，照其范围组织。

每项说明具体新条件或观察方式、怎样改变行动/理解或感知，以及因此留下什么。只换词、名字、场景标签或同义情绪时合并或继续找实质差别。材料确实少时如实说明少在哪项关系。到达本轮浏览、选择或续作所需程度即停；用户要求尽量覆盖时，检查新增项是否仍有独立内容。若只能重复或补入与目标无关的条件，说明停止原因。局部深化至少落实请求所需的动作和后果，短请求把一处变化说清即可。

## 比较与组合

仅比较时，先明确同一组织位置上的互斥点、可独立取用的内容与可按因果组合的事件。读取[候选取舍与组合](references/selection-composition.md)，实际按硬约束、主要目标和材料依据裁决；找必要承接、保留原编号、逐项做贡献和相容检查，形成一个主导关系及组合。用内容、代价与下游限制解释取舍。仅在不同目标、结构或立场确实需要取舍时给少量备选。

用户点了两项就只用实际选中的项。自己补进的衔接标作提议；确实不能同线成立时交代条件或分别保留。用户同时要求完整构想时，把推荐作为本轮工作方案接着做；只要求比较时到具体比较及建议为止。已确认的组织原则直接使用，后续找到缺口时只回查与它相关的选择。涉及公开受众时沿本主文的[受众条件](#受众条件)加入对应比较。

## 完整构想

1. 恢复所求体验、主导关系、已选内容、已定次序、开放空间与长度。选中素材可以直接组织，存在多个真实候选才先比较。起点薄但用户要求一套完整构想时，提出与现有材料和目标相称的人物、驱动和解决方案，把新增常规条件统一标为工作提议。确保主要行动与结尾有具体做法，用户明确开放的关键真相或结局可用有条件的路线保住。
2. 在展开全程前，为新作品或尚需决定的主要表现路线按下文[本地研究与成熟方法](#本地研究与成熟方法)选择具体处理。选实际影响作品的关系、行动、叙述位置、信息、节奏、意象或媒介经验，以研究所得改变此处的创作。
3. 对由行动与后果推进的全案，使用[叙事结构](skills/laohu-story-structure/SKILL.md)选主结构、搭承重链；有明确主要体验或某段待增强时使用[体验设计](skills/laohu-story-engines/SKILL.md)写出关键场面的具体玩法，并回到骨架检查改过的条件和后果。习惯、时间或关系的观察叙事依其观感组织，整体靠感知或论证的内容走相应模块，不由媒介名称决定结构。具体工作取舍按[内部方法](#内部方法模块与-reference)裁决。
4. 使用[完整作品的总体构想](references/whole-work-conception.md)，把入选内容落实为相称的单位，每个单位写清内容、作用、前提与之后使用的结果。观察、形式和论证的单位按其经验、主次和推论组织，角色连戏的单位按真实选择、回应与处境组织。分别安排实际发生的顺序、作品接收顺序和说明的顺序。需要过渡、对照、重复、停顿和余波时说明它从前文接回什么。给核心经历足够篇幅，按内容依赖分配时长或比例，明确它是设计估计。
5. 按[整体走查与下游交接](#整体走查与下游交接)读一遍整条线。修复实际断点后按提案呈现交付。给哪位专业接收方继续、需要保留哪些材料由用户目标和本轮权限决定；关键舞台体验要等制作才检验，指出具体位置与测试需要。

### 本地研究与成熟方法

完整独立作品构想，或正在为未成形的完整作品选择主要表现路线时，读取[真实作品研究方法的日常创作取法与方向](../../../references/exemplar-study.md#日常创作取法与方向)。先定主方向，再找到会改变接收体验的重点部分，为其选可核验的作品单元或创作者做法，读必要上下文。写出这种处理怎样改变本作行动、信息、结构、语言、感知或节奏，以及为何适用。结构理论帮助回查，具体表现取法需要对应的作品材料；本地资料已经回答当前问题就用现有资料，缺失时按真实来源补足。可为不同部分选不同成熟做法，同一维度由主方向裁决。授权自主选择时内部完成取法与落实，用户问出处或要比较才展开研究说明。

进入会改变整体创作的材料关系、行动、信息安排或表现路线选择时，在定案前按共享[本地作品方法库检索路径](../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)查询相关材料/方法卡，读取选中详情，把所得落实到本作的候选关系、行动、铺垫或回收。在结构和呈现过程中核实它真的在起作用。同目的已有新鲜查询和必要详情时复用；仅整理已确认构想或执行锁定选择时跳过。未得到相称卡片时保留真实检索状态，转共享取法继续查所需依据。

### 受众条件

用户说明准备公开发布，或明确希望吸引某类观众时才用[受众与传播的源头构思](references/audience-conception.md)。探索先找材料中谁会认出自己、看下去可能得到什么，有多个候选再选切入。比较时先隔离检查各实际或拟开场五问，再按本轮最重要的受众行为与内容动力对照。完整构想先检查真实开场；没有真实开场时把实测表现记未知，主动给一个标明为拟稿的开场，用内容分类、原生问题、个人关系、预期所得、未闭合张力和失败分支核对它，再看全程如何兑现。开场透露的关系和后文不能互相代替。明确有商业目标时才查商业距离。私人表达或未选择传播目标时追踪本作已有的接收体验；公开本身不代表以流量或销量为目的。受众理解或行动会改变主线、信息、篇幅或收束时，另读[读者价值与作品组织](../../../references/audience-value-and-structure.md)并落到受影响单元。

## 定点构思与修订

- 深化具体点时接前一轮真实写出的行动、回应、后果或感知变化。反馈表明中段跨多个承重单元出现因果断裂时，按影响范围取用叙事结构方法，定位前后依赖并修相应段落。按[角度生成](references/angle-generation.md)寻找相关切口。凡要沿同一材料继续生成具体内容，读取或复用[核心生成](references/core-discovery.md)，接续产生下一行动、回应、关系或感知变化；沿已定感知关系继续时，依相应感知方法使其可见可听。只改局部开场、桥段或结尾时，也检查它使用的前提和下一个单位是否还成立。
- 局部行动确实要推动受阻、关系转向、信息兑现或期待落差时，仅读[构造有效落差](../laohu-script/references/narrative-and-structure.md#构造有效落差人物预期世界回应下一策略)与[相称尺度的回查](../laohu-script/references/narrative-and-structure.md#幕序列场beat-的拆分和回查)片段。按人物当时的目标、依据和预期，推导别人或环境从其自身规则给出的实际回应，再写它怎样改变下一行动、关系、信息或结果。交回当前构想接续，范围维持在该局部。
- 用户确实要把某处喜剧、反转、连环反应或其他体验做实，按信号从体验模块取一项相应做法。多人共用的事件可以给互斥备选或表现层次，说明哪些并列、可接续或不可相容。系列只接当前实际选中或要求延续的状态。安静、陪伴、等待、仪式兑现仍可产生注意转移或细小选择。
- 只改文字时按[沟通语言风格](#沟通语言风格)重述、成句和回读，不启动结构或造戏；用户要求局部声口示范时，在同一意思和既有关系下交该项。只整理已确定素材时沿用顺序和线索。用户明确要一条短提议就直接给所求变化。

## 沟通语言风格

用共同构思者的语气讲决定和取舍，用提案叙述者的口气讲故事实际怎么发生，局部示范才进入角色此刻说话的方式。人称、声口和自然程度随材料与处境确定。解释与构想面向创作者，接收者的体验仍由作品本身验证。

本 Skill 实际起草、解释、比较、推演、审阅构思文字，或展示与修订局部作品文字时，一律从本节读取或复用共享[语言成文方法](../../../references/language-realization.md)，选用适合本次的词句段及修订动作，把它们落到用户实际读到的文字。

1. **确认整句话的意思。**说明在谈谁、发生了什么、凭什么这么判断。角色声口先明确对谁说、当下要做什么、态度落在谁或哪件事上。提案解释也先确定评价与依据。把内部笔记还原为实际人物、动作、关系和变化；交接或方法讨论确需行话时说明它在本次指什么。
2. **确认原意，圈定要改的跨度。**对获准修订的句段，先用常用说法在内部完整重述，回核谁或什么做了什么、限定落在何处、哪里仍开放，以及原有态度、数量、事实或提议身份。圈出生硬、含混或用户要改的表达及确实受影响的部分。相邻分句已经自然且承担时间、条件、否定或范围时，默认沿用原表述接回新句。所指不明时只写已知动作或关系，缺失的上下文确实影响句意时指出具体缺口。普通引号和临时概括可换词，用户要求逐字保留的文字、用于辨认的专名及作为证据的原文按各自要求保真。
3. **重组改处，读回实际句意。**依据完整意思重新组织已圈定的词句，保住内容、理由、做法与结果各自的作用。若衔接需要改动承载限定的分句，用共享方法从新句回查原文已经排除的读法，尤其是动作的先后、发生条件、因果和开放范围。新句容许原文排除的读法时，恢复原表述或补回该限定。各独立句段各自保义，复核同批其他已成立的表达。检查动作与对象、称呼、补语、语势和停顿的搭配，保留语境支持的幽默、节奏、双关与留白。
4. **说话读得顺，故事关系仍清楚。**按相邻句群朗读，核清行动者、对象、指代和因果，补上不宜省略的关系。让各人物有由其经历、关系和当下行动支持的声口，避免全篇落同一句架、态度或角色腔。态度、意蕴和修辞有语境可循时保留，有疑问就修在具体位置。字数服从意思、节奏和明确的用户长度要求。

### 对话呈现与阶段记录

工作字段用于保障本轮判断，默认用自然语言讲具体内容，需要固定字段或表格才按当前指定形式。决定保存在本轮对话或已授权文档，局部修改只更新相关记录。用户在同一连续任务明确确认了直接阅读的呈现偏好（包括普通讨论不包外围代码框）时，沿用直到其改选；其他任务使用 runtime 的展示规则。

开放多方向提案按下列顺序组织。单点、简短、多点、完整与非叙事任务均保留各自交付深度。

1. **总览共同前提与探索范围。**说明用户确定的材料与仍可变化的部分，完整呈现仍成立的主要方向。
2. **按实际由什么发动故事分组。**说明各组区别。让多个独立故事点有稳定编号、具体标题和层级；一组若实际有多个可取事件，分别呈现。仅一项材料支持或无法成组时按实际数量与层级组织。
3. **先排完整概要，再展开细节。**让用户浏览选点时，细写任何一条前，先把各点标题和完整短概要排入交付稿。每点首段用一两句讲清事件、关键变化和实际结果。全部概要排好后，再在相应首段下另起自然段，插入支撑变化的必要前提、行动、回应和后果。细节展开时保留可以单独阅读的首段。用户明确只要短答或点子清单时，概要写到能选择即可。有固定字段要求时按用户格式呈现，普通讨论用自然段；非叙事按感知变化组织。
4. **列完再推荐。**说明建议试哪个、原材料中哪项关系支持它、还可以怎样选择。互斥、并列、可接续照真实关系说明。浏览选点的请求在这里收住。用户本轮要试写，或一小段示范确实是比较所需的依据时，再补与其范围相称的示范。已明确选中一项时先交它的主要变化，可写短段。简短单项按其范围直接给出。

完整构想先用自然文字给全篇概要，再按作品接收顺序讲具体展开。中间人物知道与观众知道的次序依作品体验安排，提案为比较而先说结局不改变作品揭晓顺序。按实际需要讲清故事气质、人物关系、代表动作或一两句局部声口、关键线索、未定取舍和制作待验。只列真正改变走向的备选，不把完整构想留成选项清单。

发给用户前，先只摘取共同前提、组名、各点标题和标题后的首段独读。用户只看这些就应能区分方向，并读出每点的事件、转变和结果。首段若只交代开端，或概要与细节混成须通读的一长段，先补完整首段，再把支撑细节放到下一段。然后按接收顺序读细节，核实前提、回应、后果和新条件是否真实接上。单点或明确短答只看这一项的主要变化和必要依据。

## 整体走查与下游交接

1. 按当前作品逐项读回开场、承接、转变、集中表达与收束。非叙事保住关键感知或材料的整体关系，论述核实证据和结论边界。构思的静态关系和时间序列各用其单位。每个重要部分要能说清前提、实际内容、重点、之后由谁用上及预期作用。非必要重复可以并掉，承担感知、强调、节奏、照应或重释的重复要按其作用检查。
2. 人物叙事回查他在意什么、知道什么、做了什么、他人或环境为什么那样回应，以及结果如何改变或维持处境。观众的必要信息在使用前已能读到，延后内容有具体目的，高潮依据在前面，结尾留下什么已清楚。公开支路先隔离检查开场，再走全程。读回所有新假设、已定边界和语言措辞，发现差距就改实际单元。
3. 欲交出已可接手的构想时，读[下游交接](skills/laohu-story-handoff/SKILL.md)。需要诊断的提纲逐段核查实际前提、内容和后效；可补的承重断点当轮补成可见的工作提议或明确需决定的条件，分别交已有可用部分、未决处及对后续的影响。明确交接时用户要看得出来哪个主题、结局与内容已经可用，哪处需保留开放，哪处属下游自由实现，哪项需要实作检验。保住其他已确认的方向。
4. 交付具体构想后结束本轮。当前请求是正式生产时，按共同运行约定核对可用入口与已获授权，向该入口交锁定材料、工作范围和真正需要的决定；当前只要制作简报，交简报即止。专业入口缺失时，说明实际缺口并交可用输入。已有用户选择与路径直接传递。

### 确认与归档

只有用户要求确认、固定或保存作品构想时，核对作品级决定。普通完整构想可直接交付其中的工作推荐和真实未决事项。用户已确认的方案如仍有后续局部调整空间，按具体决定保留。

总体构想已确认并有保存意图时，读取[laohu-archive](../laohu-archive/SKILL.md)，带上作品名称、类别、已有归属/路径、当前确认成果和明确授权。沿用已确认的位置；名称确缺时可拟工作名供选择，尚未确定归属或位置时按该入口判断。取得实际作品位置后沿用已有主文件，首次可用稳定的 `创作构想.md`。写前保护实际内容与恢复位置。

主文件依次收录作品名、体裁与目标，已确认的核心表达，采用内容及组合关系，完整构想与各部分安排，固定表达要求，以及真实待补、待核和待制作验证的事项。写完核实文件存在、正文完整，并与用户确认内容一致。告知名称、实际路径与保存结果；失败时说明具体原因及当前状态。只讨论或拒绝落盘时在本轮产物交付后结束。
