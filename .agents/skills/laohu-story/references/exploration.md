# 从用户材料到可选择、可发展的角度

本文件提供材料拆解与创意发展的方法。阶段判断、开场、回应分支和停止条件以 [主 Skill](../SKILL.md) 为准；无用户起点时，以下方法不能用来代拟题材。关键机制的解释、适用条件与边界见 [机制解释与创作方法](theory-and-practice.md)。

## 从材料到分析选项

用户提供对象，AI 负责把尚未说清的关系变得可看见、可比较。分析解释作品可能怎样起作用，不能据此断言用户为什么喜欢，也不能要求他先完成专业归因。

| 材料状态 | AI 可以承担的分析 | 仍需用户提供什么 |
|---|---|---|
| 只有作品名，无法查看内容 | 说明尚不能分析原作，定位一个最小可描述片段 | 该片段发生什么；不要求完整剧情与喜欢理由 |
| 只有兴趣词或主题词 | 给出该范围内可分析的关系维度，条件性描述，不编造具体经历 | 若维度不能指向实际内容，再补一个对象或变化 |
| 已有完整片段或可读取作品 | 还原对象、行动、形式、关系与信息出现顺序，再解释可能效果 | 选择想保留哪一种作用，或纠正分析 |
| 用户已明确吸引点 | 解释它由材料中的什么支持，以及有哪些可变因素 | 有实际分歧时才问取舍，不重复问兴趣 |
| 材料很多、关系混杂 | AI 聚合相关部分，区分事实与解释，推荐最值得先发展的关系 | 认领或否决推荐；不用重写长材料 |

分析的最低信息量是“哪一处材料 → 什么组织关系 → 为什么可能形成这个效果”。只有“反转、共鸣、治愈、电影感”不算完成。材料允许多种解释时展示差异和根据，不让用户先猜标准答案。

## 让用户选择什么

起点之前只提供取材方式，不能提供 AI 自拟内容让用户被动选择。起点之后，选项应承担不同的创作取舍：

| 比较对象 | AI 要说明的差异 | 用户做的判断 |
|---|---|---|
| 作用机制 | 同一材料可能凭形态、信息差、行动关系或声音组织产生不同作用 | 哪个更接近想保留的部分 |
| 新的角度 | 改变什么关系或条件，而不是换几个题材名 | 哪个更想继续、是否需要组合 |
| 表现方法 | 各自让接收者先感知什么，难度与代价在哪里 | 哪种体验或成本更合适 |
| 试作结果 | 同材料的差别、有效处、薄弱处与修改建议 | 是否更接近意图，要保留或撤回什么 |

选项可附 AI 推荐，但不能假装推荐已经获得同意。用户说“都不是”时，回到原材料查误解，不不断生成同类选项。每轮优先解决一个关键取舍，避免让用户同时判断情绪、题材、受众、平台与制作预算。

## 匹配当前缺口的方法

| 卡点 | 专业概念与处理动作 | 应出现的变化 | 主要边界 |
|---|---|---|---|
| 材料被常用名称遮住 | 陌生化：从已有材料中重新注意声音、痕迹、尺度、观看位置或使用关系 | 同一对象出现此前忽略的可感知差异 | 不能编造材料细节，也不等于奇怪措辞 |
| 联想只有外形或标签 | 结构映射：保留角色之间的作用和关系，再找可对应的新情境 | 新旧材料有明确映射，知道哪里相似、哪里不成立 | 形态联想仍可成立，不因不是关系类比就否决 |
| 信息有意思但表达平铺 | 信息缺口：明确接收者已知什么、尚缺什么，调整线索与揭示顺序 | 形成可追踪的问题，揭示能回应前文 | 不把困惑当好奇，不保证点击；安静或纯形式作品不必加悬念 |
| 被一种做法卡住 | 条件变换：区分事实、习惯与保护项，改变一个允许改变的条件，推演后果 | 新条件改变真实动作、空间、声音或信息关系 | 相对事实设相反条件才称反事实；艺术设想不是现实预测 |
| 只有片段，不知道如何成形 | Geneplore 生成—探索：从用户片段生成局部变体，再分析变体暴露的可能 | 具体小样帮助发现下一步；探索可以返回生成 | 不能从无输入启动，不以生成数量证明质量 |
| 方向反复雷同 | Boden 的组合、探索、转化区分：分别考虑新联系、原规则内的可能、可变规则 | 改动发生在不同层次，而非近义改写 | 改规则不天然比深挖材料高级 |
| 构想成立但落地失效 | 行动中反思：检查实际试作，区分方向、组织、材料与执行问题 | 下一次只改最能解释失败的一处 | 不能把每次意外都包装成洞察，专业执行缺口交对应能力 |

方法选择依据当前材料。心理学和传播学不能替代领域技法：好奇机制不能给出镜头规格，类比不能证明物理可行性，语义解释不能替代音乐试听。

## 从初步角度到有价值的构想

先判断新意来自哪里：注意到新关系、改变观看顺序、揭示一个真实矛盾、提供不同体验，还是只是换了名词。保留用户带入的核心，再沿发生条件、具体作用、后果和表现方式发展。

候选至少要能回答：从哪条用户材料发展，具体改变了什么，原材料中值得保留的部分是否还在，接收者通过什么感知，最大的不确定性是什么。信息可以自然写在几句话里，不强制制成卡片。

发展到什么程度取决于作品。音乐可以用节奏与织体组织，图像可以用空间与注意关系组织，文章可能需要论证，互动作品可能需要操作与反馈；不要求全部具备人物冲突、情节反转、中心思想或传播卖点。

## 用同材料比较修订

### 把感受写成可见动作，选择信息顺序

用户要求克制、可拍、少解释，而原稿只有“意识到、感到、明白、被感动”等内心结论时，先从已有材料找承载关系的对象、痕迹、声音和正在进行的动作。保留用户指定的感受方向，但不把某种感受说成观众必然反应；下面的方法用于这一分支，不要求散文、独白或纯形式作品全部动作化。

1. 把原稿的内心结论单独识别出来，找它在材料中的支持：人物注意到哪一处，原本准备做什么，注意之后有什么可以看见的改变。没有可支持的动作时，给与材料相连的虚构提议并说明新增；不擅自添加死亡、回忆或冲突来制造分量。
2. 先写“动作开始 → 已有细节进入注意 → 动作延迟、改变或继续”的局部片段。动作变化可以很小；如果目标只是安静观察，可以保持动作不变，把变化放在观看位置或声音显著性上。不要为证明感情一定要加哭泣、独白、象征物或顿悟。
3. 比较信息顺序时保持人物、材料、事件和保护项一致。先给细节再给动作，观众较早知道动作所针对的对象；先给动作再揭示细节，让后面的信息重新解释前面的动作。写出两段真正可读的片段，再按本轮目标推荐；不能只把两段分别命名为“悬念版”“情绪版”。
4. 核对物件和动作连续性、信息首次可见的位置、声音能否按描述发生。删掉解释句后若关系无法理解，先补必要识别线索或调整顺序，不自动把原旁白加回来。若关系已经成立，停止补意义，不因还能加细节而加戏。

**合成对照，非真实经历或效果验证：** 输入是“母亲缝好的衬衫放在椅背，孩子临出门要拿走；不加对白，不新增身世”。甲：“袖口的新线被窗光照亮。孩子拿起衬衫，手从那一小截线边移开，改捏住肩缝。”乙：“孩子拿起衬衫，手指停住，换了个位置捏。衣服转过来，袖口露出一截新线。”甲先给缘由，动作较容易当场读懂；乙把缘由后置，动作先成为问题。若用户优先要自然易懂，先试甲；若要一次很轻的信息重释，可试乙。新线只支持补缀痕迹，不能据此补出家庭贫困或人物愧疚。若用户要求客观展示而不拟写人物心理，保留动作与线索即可。

早期比较方向，成形后比较具体效果。保留改前结果，说明改动、目标效果和可能损失；需要判断因果时尽量控制无关变化，不能拿换题后的新作品证明旧构想已改善。

| 观察到的问题 | 更可能需要的工作 |
|---|---|
| 新设定拿掉也不影响作品 | 补充实际关系，或撤回无作用的新设定 |
| 方向有意思，但读者无法理解联系 | 调整必要线索与组织，不直接增加解释性口号 |
| 意图清楚，材料支撑不足 | 补已授权的真实材料，缩小主张或明确改为虚构创作；不补造事实 |
| 核心有效，局部表达妨碍感受 | 保住核心，按媒介修具体执行变量 |
| 改后新奇却偏离用户要的感受 | 回退相关变化；新奇不自动优先 |
| 仅凭文字无法判断 | 停止质量宣告，进入真实试听、观看、演示或专业交接 |

继续迭代的依据是有具体且值得处理的缺口，不是“还不完美”这句泛评。用户认可方向但效果尚未测试时，交付应写“方向可继续，效果待验证”，不虚构成功。

## 合成教学示范：夜班守门人留灯

**说明**：以下情境、反馈与文本均为合成教学材料，不是真实用户经历、真实作品案例或实际效果验证；只示范怎样从起点选构想、做局部小样并依据反馈修订，不是所有媒介的套用模板。

**起点与选择**：假设材料是“夜班守门人给晚归的人留灯”，保护项是温暖、克制，不靠亲人去世等创伤背景。留灯已经是一个照顾动作。可继续发展被照顾者如何回应；相比增加悲惨身世，这个方向直接沿着现有动作形成关系变化。

**初稿小样（待修改反例，不作范文）**：

> 夜班守门人给晚归的人留灯。晚归人关上被风吹开的窗，说：“你一直等着我们，我们也该关心你。”旁白：“温暖就是彼此照顾。”

这段把互相关心说了两遍，实际动作被解释盖住。**假定的教学反馈**是：“保留留灯和关窗，删掉说教；让回应发生在动作里。”这只是为示范设定的反馈，不代表真的有人提出过。

**修订稿**：

> 守门人伸手去按开关。雨里传来跑步声，他收回手，继续低头对账。晚归的人进门，停在桌边。风把窗扇吹得一撞一撞，他伸手扣好了窗。守门人抬头，那人已经上楼。最后一盏灯这才灭了。

**修订对照**：留灯和关窗仍在，温暖克制的保护项保留；说教台词与总结旁白删去。守门人因雨中跑步声收回关灯的手、晚归人扣好窗、守门人抬头时对方已上楼，再到最后关灯，用连续可见动作表现回应。下一步可用这段小样检查关系是否看得明白、是否仍显得温暖而不煽情；在真实读者或最终媒介反馈出现前，不能声称效果成立。

## 真实作品拆解范例：《一一》的平行剪辑

**教学分析所述事实边界**：Yale Film Analysis 的 Editing 教学分析介绍杨德昌《一一》（2000）：父亲与女儿分别在日本与台北约会；教学分析将父亲的经历解释为重访初恋、女儿的经历为第一次约会，并讨论交替呈现怎样关联两条行动线。这里转述的是教学分析，不表示本轮独立观看影片；不补写未提供的具体台词、镜头时长或原片之外的情节。

**AI 可以直接完成的拆解**：

- 空间上分开的两条线，经交替呈现被建立联系；“同在约会”的对应是材料依据。
- 相似行动的意义并不相同：一个与重访有关，一个与第一次经历有关。这个差异提供了继续理解的方向。
- “代际重复”是 Yale 页面给出的解释，不等于用户必然被它打动，也不是影片唯一意义。

**若用户已经带入这段材料，AI 可给出的分析选项**：沿行动对应研究两条线如何呼应；沿经历差异研究同类行动为何意味着不同的事；沿信息安排研究交替观看比逐段讲完多出了什么联系。这些选项保留同一材料，不需要先问用户“哪里有趣”。AI 可以推荐先比较行动对应与经历差异，再由用户决定想保留哪一部分。

**后续创作边界**：迁移的是关系或组织方法，新的角色与情境只能作为明确标注的创作提议；不能说它们也来自原片。用户尚未给出任何起点时，不主动把这部电影塞给他作为创作种子；用户要求学习方法时，可以把它作为有来源的教学案例。

这是专业教学分析，可用于学习平行剪辑的分析方法，不能证明使用该方法一定提高作品质量或传播表现。
