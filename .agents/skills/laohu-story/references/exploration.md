# 从用户材料到可选择、可发展的角度

本文件提供材料拆解与创意发展的方法。阶段判断、开场、回应分支和停止条件以 [主 Skill](../SKILL.md) 为准；无用户起点时，以下方法不能用来代拟题材。关键机制的解释、适用条件与边界见 [机制解释与创作方法](theory-and-practice.md)。

## 从材料到分析选项

用户提供对象，AI 负责把尚未说清的关系变得可看见、可比较。分析解释作品可能怎样起作用，不能据此断言用户为什么喜欢，也不能要求他先完成专业归因。

| 材料状态 | AI 可以承担的分析 | 仍需用户提供什么 |
|---|---|---|
| 只有作品名，无法查看内容 | 说明尚不能分析原作，定位一个最小可描述片段 | 该片段发生什么；不要求完整剧情与喜欢理由 |
| 只有兴趣词或主题词 | 给出该范围内可分析的关系维度，条件性描述，不编造具体经历 | 若维度不能指向实际内容，再补一个对象或变化 |
| 已有完整片段或可读取作品 | 还原对象、行动、形式、关系与信息出现顺序，再解释可能效果 | 选择想保留哪一种作用，或纠正分析 |
| 用户已明确吸引点 | 解释它由材料中的什么支持，以及有哪些可变因素 | 有实际分歧时才问取舍，不重复问兴趣 |
| 材料很多、关系混杂 | AI 聚合相关部分，区分事实与解释，推荐最值得先发展的关系 | 认领或否决推荐；不用重写长材料 |

分析的最低信息量是“哪一处材料 → 什么组织关系 → 为什么可能形成这个效果”。只有“反转、共鸣、治愈、电影感”不算完成。材料允许多种解释时展示差异和根据，不让用户先猜标准答案。

## 让用户选择什么

起点之前只提供取材方式，不能提供 AI 自拟内容让用户被动选择。起点之后，选项应承担不同的创作取舍：

| 比较对象 | AI 要说明的差异 | 用户做的判断 |
|---|---|---|
| 作用机制 | 同一材料可能凭形态、信息差、行动关系或声音组织产生不同作用 | 哪个更接近想保留的部分 |
| 新的角度 | 改变什么关系或条件，而不是换几个题材名 | 哪个更想继续、是否需要组合 |
| 表现方法 | 各自让接收者先感知什么，难度与代价在哪里 | 哪种体验或成本更合适 |
| 试作结果 | 同材料的差别、有效处、薄弱处与修改建议 | 是否更接近意图，要保留或撤回什么 |

选项可附 AI 推荐，但不能假装推荐已经获得同意。用户说“都不是”时，回到原材料查误解，不不断生成同类选项。每轮优先解决一个关键取舍，避免让用户同时判断情绪、题材、受众、平台与制作预算。

## 匹配当前缺口的方法

| 卡点 | 专业概念与处理动作 | 应出现的变化 | 主要边界 |
|---|---|---|---|
| 材料被常用名称遮住 | 陌生化：从已有材料中重新注意声音、痕迹、尺度、观看位置或使用关系 | 同一对象出现此前忽略的可感知差异 | 不能编造材料细节，也不等于奇怪措辞 |
| 联想只有外形或标签 | 结构映射：保留角色之间的作用和关系，再找可对应的新情境 | 新旧材料有明确映射，知道哪里相似、哪里不成立 | 形态联想仍可成立，不因不是关系类比就否决 |
| 信息有意思但表达平铺 | 信息缺口：明确接收者已知什么、尚缺什么，调整线索与揭示顺序 | 形成可追踪的问题，揭示能回应前文 | 不把困惑当好奇，不保证点击；安静或纯形式作品不必加悬念 |
| 被一种做法卡住 | 条件变换：区分事实、习惯与保护项，改变一个允许改变的条件，推演后果 | 新条件改变真实动作、空间、声音或信息关系 | 相对事实设相反条件才称反事实；艺术设想不是现实预测 |
| 只有片段，不知道如何成形 | Geneplore 生成—探索：从用户片段生成局部变体，再分析变体暴露的可能 | 具体小样帮助发现下一步；探索可以返回生成 | 不能从无输入启动，不以生成数量证明质量 |
| 方向反复雷同 | Boden 的组合、探索、转化区分：分别考虑新联系、原规则内的可能、可变规则 | 改动发生在不同层次，而非近义改写 | 改规则不天然比深挖材料高级 |
| 构想成立但落地失效 | 行动中反思：检查实际试作，区分方向、组织、材料与执行问题 | 下一次只改最能解释失败的一处 | 不能把每次意外都包装成洞察，专业执行缺口交对应能力 |

方法选择依据当前材料。心理学和传播学不能替代领域技法：好奇机制不能给出镜头规格，类比不能证明物理可行性，语义解释不能替代音乐试听。

## 从材料选择事件发展或观察组织方式

本节用于从已有起点形成可继续制作的局部构想，接续主 Skill 第 3、4 步；它不是固定问卷。已有信息直接沿用，不要求用户重复分析。先从材料中找出值得保留的具体关系、体验或形式，再把内容区分为：

- **已给事实**：用户提供、可查看来源或已核实的内容；非虚构任务不得把猜测的动机、经历或结果写成事实。
- **保护项**：用户明确要求保留的目标、关系、语气或限制。
- **可变项**：不违背事实和保护项、可以由创作者调整的条件、顺序、媒介实现或虚构设想。
- **未知**：材料尚未说明且会改变方向的内容。只有它确实影响选择时才问一个关键问题；不影响时可以缩小设想并继续。

拆材料时看对象、动作、状态、空间、时间和信息如何相互作用；需要固定一项选择时，同时看它牵动哪些关系、哪些其他选择仍可变化。变换须有目的，不能把无关元素拼在一起冒充发展。虚构创作可以提出新人物、事件或条件，但要使新增条件支撑后续动作；把它标为创作提议，不回写成用户给定事实。

### 任务需要事件发展时

从当前局面和人物眼下要做的小事开始；人物意图可由材料支持，也可以作为明确标注的创作假设，不要求先编完整人物背景。随后按下列关系推演一个或几个局部后果：

1. 选一个可变条件或行动，说明它相对起点改变了什么；条件可以来自用户材料，也可以是为虚构作品提出的新增设想。
2. 按作品既定的现实程度和内部规则检查世界条件、物件功能和行动连续性：这个人此刻为什么会这样做，行动需要哪些物理、信息或关系前提，材料是否支持这些前提？一个主题联想不能直接推出人物需要、设备状态或故事结果；缺少中间条件时补出明确、合乎设定的虚构条件，或换一条发展路径。若用户要梦境、荒诞或刻意断裂的组织，不用写实因果否决它；检查断裂是否遵循该作品的约定，并承担目标作用。
3. 写出行动如何改变状态、信息或关系，以及这个改变让谁可能作出什么回应或让后续何以继续。偶然事件可以成为起因；只有当本次目标要求因果连续发展时，后续行动才须有可理解的条件联系，不能把互不相干的巧合冒充连贯因果。
4. 检查“为何此时发生、前提是否成立、改变是否可感知、还能往哪里发展”。有一处完整而有效的局部就可以停，不补造冲突、高潮、反派、顿悟或结局来证明它像故事。

### 任务更适合观察、并置或形式组织时

不造事件来抬高材料。选择已有细节的并置、重复中的差别、观看或聆听的先后、主次关系与逐步累积，试着安排一个局部顺序。检查每个部分怎样改变对其他部分的注意、理解或感受；若某个细节主要承担节奏、强调、回声或重释，即使它不增加新事实也可能有用。允许作品保持安静、静态、开放或只呈现一个完整局部，不强迫解谜、主题升华、人物成长或收束。

### 比较候选并作推荐

候选要在作用上有差别，而不只是换名称、标签或装饰。按本轮目标选用以下比较视角；它们服务执行者判断，不是每次都要逐项询问用户或整理成清单：

1. 它保留了材料或用户保护项中的什么，又改变了什么关系、行动、信息或观看顺序？
2. 关键动作、物件功能和结果是否由给定条件或明确的虚构前提支撑？有没有偷换事实、强加动机或让前提悬空？
3. 接收者能从什么具体局部感知差异？重复或少量元素是否承担节奏、强调、对照或重释作用？
4. 去掉或替换起点里的关键材料后，作品作用是否几乎不变？若是，检查它是否仍是泛化套壳；如果通用性本身就是用户目标，不因此否决，只说明它与这份材料的联系较弱。
5. 候选能否按用户想要的媒介与范围继续，依赖什么新增资料或制作成本？

先剔除违反事实/保护项、依赖不成立前提或明显牵强的方案；刻意断裂的作品则按其自定规则和目标作用判断，不以写实连贯作唯一门槛。对其余候选按用户目标、材料联系、内部自洽（或有意断裂的作用）、可感知差异和可发展空间给出推荐，并说明代价与尚未确定处。新增设定若不改变理解、行动、节奏、强调、关系或目标感受，通常删去或替换；承担其中任一作用的重复或细节不为“避免重复”而机械删除。候选数量、复杂度和篇幅都不单独证明质量，用户想要极简时，一个局部也可以完整。

方向确定后，试一段与媒介相称、足以感知关键差别的局部；文字、声音、图像与互动作品可用不同方式承载，不把媒介操作硬译成故事。把试作交付在前，之后简短说明推荐依据和下一项取舍；内部分类与术语不必每次展示。

## 用同材料比较修订

### 按原稿与反馈修订

收到用户提供的原稿和明确反馈时，沿用本轮已确认的目标与保护项，以实际原稿和反馈为依据：

1. 找出反馈指向的具体位置，以及该处与目标之间的差距。
2. 保留仍有效的关系和表达，只修改与这个差距有关的动作、措辞、信息顺序或媒介变量；不引入无关背景来替代修订。
3. 将修订稿与原稿对照，说明实际保留和改变了什么、希望观察什么、哪些效果仍待真实媒介或接收者验证。

没有用户原稿或反馈时，不编造一份“用户初稿”、虚构反馈或伪造修订对照。用户明确要求原创试作时，照常进行创作；方法教学需要示范时，使用有出处、经过核实的专业作品或方法，并区分来源所述与本文件的分析。

### 把感受写成可见动作，选择信息顺序

用户要求克制、可拍、少解释，而原稿只有“意识到、感到、明白、被感动”等内心结论时，先从已有材料找承载关系的对象、痕迹、声音和正在进行的动作。保留用户指定的感受方向，但不把某种感受说成观众必然反应；下面的方法用于这一分支，不要求散文、独白或纯形式作品全部动作化。

1. 把原稿的内心结论单独识别出来，找它在材料中的支持：人物注意到哪一处，原本准备做什么，注意之后有什么可以看见的改变。没有可支持的动作时，给与材料相连的虚构提议并说明新增；不擅自添加死亡、回忆或冲突来制造分量。
2. 先写“动作开始 → 已有细节进入注意 → 动作延迟、改变或继续”的局部片段。动作变化可以很小；如果目标只是安静观察，可以保持动作不变，把变化放在观看位置或声音显著性上。不要为证明感情一定要加哭泣、独白、象征物或顿悟。
3. 比较信息顺序时保持人物、材料、事件和保护项一致。先给细节再给动作，观众较早知道动作所针对的对象；先给动作再揭示细节，让后面的信息重新解释前面的动作。写出两段真正可读的片段，再按本轮目标推荐；不能只把两段分别命名为“悬念版”“情绪版”。
4. 核对物件和动作连续性、信息首次可见的位置、声音能否按描述发生。删掉解释句后若关系无法理解，先补必要识别线索或调整顺序，不自动把原旁白加回来。若关系已经成立，停止补意义，不因还能加细节而加戏。

早期比较方向，成形后比较具体效果。保留改前结果，说明改动、目标效果和可能损失；需要判断因果时尽量控制无关变化，不能拿换题后的新作品证明旧构想已改善。

| 观察到的问题 | 更可能需要的工作 |
|---|---|
| 新设定拿掉也不影响作品 | 补充实际关系，或撤回无作用的新设定 |
| 方向有意思，但读者无法理解联系 | 调整必要线索与组织，不直接增加解释性口号 |
| 意图清楚，材料支撑不足 | 补已授权的真实材料，缩小主张或明确改为虚构创作；不补造事实 |
| 核心有效，局部表达妨碍感受 | 保住核心，按媒介修具体执行变量 |
| 改后新奇却偏离用户要的感受 | 回退相关变化；新奇不自动优先 |
| 仅凭文字无法判断 | 停止质量宣告，进入真实试听、观看、演示或专业交接 |

继续迭代的依据是有具体且值得处理的缺口，不是“还不完美”这句泛评。用户认可方向但效果尚未测试时，交付应写“方向可继续，效果待验证”，不虚构成功。

## 专业教学分析案例：《一一》的平行剪辑

**来源与定位**：[Yale Film Analysis, Part 4: Editing](https://filmanalysis.yale.edu/editing/)，小节“Crosscutting, aka Parallel Editing”。页面先把这种剪辑方式说明为交替呈现发生在不同地点、通常同时进行的两条或多条行动线，再以《一一》说明。

**来源所述（按页面转述）**：父亲与女儿大致在同一时间分别于日本和台北赴约，并经历相似动作；父亲重遇初恋后重演第一次约会，女儿则在经历自己的第一次约会。Yale 页面把这种交替解释为“历史在一代代重复”。本案例依据该教学页面的描述；这段转述不代替对原片的实际观看，也不补写页面未述的具体镜头、时长、对白或额外情节。

**可迁移的分析方法（本文件的概括，不是页面逐字原话）**：先找出交替呈现的行动线及其空间、时间关系；再比较两线共享的动作和各自不同的处境；最后说明交替组织增加了什么联系，以及这种联系仍有哪些解释空间。用户带入相关材料时，可沿行动对应、经历差异或交替顺序发展分析，不要求用户先说出自己为什么喜欢。

这项方法适用于分析材料确实支持的平行行动线，以及探索交替呈现能建立何种联系；不适用于把一切相似动作都解释成代际重复，也不能证明某种剪辑会让所有观众产生相同反应。新的角色与情境仍须明确标为创作提议，不能说成来自原片。
