# 候选取舍与组合

由[主 Skill](../SKILL.md#快车道-3比较候选取舍与组合)在比较多个候选、筛选方向或组合要素时按需读取，完成后将主导方向、入选要素、组合原则与取舍理由交回主文。

## 一、先分层，绝不把不同物种塞进同一排行榜

1. **分清三种关系**：
   - **同位置互斥整案**：互相竞争同一套故事主线，只能择一作主导，其余作备选；
   - **独立可并列故事点**：可分别拍成不同篇目或系列单集，互不吞并；
   - **可按因果连接的局部材料**：如一条线索、一件道具、一个视角切口，拆出来放入主导方案检验是否增光。
   同一事件内部的起因、行动与结果是一个点，不拆成多个竞争候选。
2. **保留原编号**：用户点了哪几项就只按实际选中项处理；补入的衔接条件明示为新建议，确无法共存时直说原因与成立条件，绝不硬拼。

## 二、五步裁决与防拼盘组合

1. **硬约束一票否决**：先过用户锁定的事实、调性、题材禁区与媒介限制。撞破红线且未修复的直接淘汰或标明需重定前提；只有感人、高级、有潜力这类空赞语、没有具体动作和内容的候选，直接退回补实，不混入比较。
2. **按实际贡献与反俗套新意选主导**：比较各合格候选对核心目标的真实承载力。当用户追求出彩与独特性时，拿每个候选对照同材料最容易顺手写出的俗套版本，指出它究竟改掉了哪段关系、规则或选择，换来了什么不可替代的画面与乐趣（不按设定堆得多寡或术语新奇度计分）。只有各方面确实打平时，才按与原素材衔接更紧、补设更轻裁决。
3. **找缺口再补要素（不为救候选找借口）**：从主导方向自身找缺了什么前提、反差层、人物声音、节奏或收束，再把局部材料放进缺口检验。多条材料填同一缺口就择一或合并。
4. **成对查相容**：沿身份、时间、世界规则、知情权限与立场核对入选要素。互相否定的必须改或弃；有意保留的对立或并置，须写出支撑二者共存的具体条件。
5. **亚里士多德删除检验**：把刚补进来的要素暂时抽掉，看故事的行动选择、人物声口、理解层次、节奏或回响是否真有可见损失。没损失就删，有功能的重复（强调、变奏、照应）则保留。必要缺口补齐即停，不做无止境加料。

## 三、交付清晰结论

只要求比较时，多候选先用极简 Markdown 对照表或推荐优先级排序（列清方向、核心优势、代价与适用目标）把首推结论加粗亮在最前，让用户 3 秒扫清拍板，再补直白取舍理由，绝不逐项抄写内部打分表或堆成议论文字墙。同步要求完整构想时，直接把胜出组合带回主文进入完整构想。
