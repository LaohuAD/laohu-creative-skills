# 参照作品与高阶对标

由[主 Skill](../SKILL.md#快车道-1空白进入或借作品找感觉)在以下两种情境按需读取：① 用户完全没有内容线索、表达口味尚模糊，或明确想借真实作品找启发；② 原始素材偏琐碎日常易做土做散、或切入陌生流派拿不准质感，需要后台借顶级同类真品做一次四维校准。用户已有清晰方向或直接授权纯原创展开时，不加载本文件。

## 一、用具体处理差异代替空泛追问

1. **用户已提作品**：先接住用户对这部作品的描述和在意的具体点，不假装读过未核对的细部；确需深入拆解本地方法库或真实作品细节时，按需转读[laohu-benchmark](../../laohu-benchmark/SKILL.md)。
2. **后台高阶四维对标校准（素材偏碎或陌生流派）**：不靠真空硬猜，迅速在脑中调出 1–2 部经受过时间或一线口碑验证的顶级同类真品，拆清四点——它站在什么立意海拔与活人声口、怎么切入媒介横截面与推进变体、怎样提纯唯一核心母体、靠哪些细节守住克制与锋芒。拆透机制后立刻合上对标，100% 换成本作自己的原创血肉，学规律绝不抄外壳与原句。
3. **用户记不起作品或完全空白**：别丢回你喜欢什么类型这类空问题。默认给出 **最多 3 部** 身份可核、彼此在核心处理上有明显差异的真实作品（体裁已定就选同类不同写法，体裁未定就选三条截然不同的创作路线）。资料不足以核实具体处理时宁缺毋滥，减至 1–2 部并说明局限，不靠名气凑数。
4. **每项参照写清四点**：作品与作者 → 一处具体可观察的故事或表达处理（如同一动作跨代并置、一直不解释直到最后靠一次小动作重释前文）→ 它相对另外两项的差异 → 提醒哪些题材元素不自动继承。**把赞美词全删掉后，若看不出它和另外两项有什么区别，立刻重写。**

## 二、从用户反馈精准抽需求

呈现完对照后，直接问用户更想靠近哪种处理、排斥哪一点，或有没有因此冒出自己的新念头，并按反馈精确更新边界：

| 用户反馈 | 处理动作 |
|---|---|
| 指明喜欢某项具体处理（如自嘲、不解释） | 只锁定该表达特征，不自动继承原作题材、人物或结局 |
| 只报作品编号 | 简明确认用户看中的是它的表达机制还是题材内容，防错锁 |
| 各喜欢不同作品的一点 | 分别记录；若两项存在张力，坦诚标出待取舍，不假定天然兼容 |
| 全部排斥 | 有理由则避开被排斥项换新轴；无理由则换另一条差异轴试一次，仍无感即保持开放 |
| 暂停或都不想要 | 立即停止推荐与追问 |

用户选中某种表达机制后，立即把它迁移为全新原创的人物、环境、行动与后果，绝不把原作人物、情节或独特意象换名照搬。
