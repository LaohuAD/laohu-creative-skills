# 参照作品与需求发现

由 [主 Skill](../SKILL.md) 阶段一在用户缺少内容线索、需要参照作品辨认偏好时读取。输入已有类别、喜欢或排斥的内容、用户提供的作品及本轮目标；输出经用户选择的需求，返回阶段一填写确认单。用户已有需求时直接承接；本文件不设新的阶段门槛。

## 先确定需要比较的差别

1. 用户记得作品：提取其名称、描述、在意之处，先分析已有内容。仅有回忆描述时以该描述为输入，不声称看过原作。
2. 用户记不起作品：先接住已说出的创作类别或稳定偏好。类别未定时给少量类别及其表达用途，等待选择；不先替用户指定主题。
3. 类别已定但内容空白：选同类作品作比较。优先改变题材、情感立场或组织方式中的一个主轴，让用户看清选项区别。其余差异作辅助说明，不把每部作品都描述成“感人、经典、有深度”。
4. 用户已经确认只想探索某个宽泛类别、明确要求直接提议：记录这项探索授权，返回阶段一确认需求，不强迫其先选经典作品。

## 检索、核实与停止

优先读取作者或创作者发布的原作、出版社或唱片公司资料、馆藏与专业教学材料。先核对作品名称、作者、所分析内容及所在段落、章节、场景或页面，再写解释。检索是由本轮的事实缺口触发的动作：具体作品、章节、场景或版本会改变当前比较，而用户提供的材料不足以支撑判断时，按任务需要查阅原作或可靠资料；现有材料已足以支持当前比较时，直接据此工作并说明范围，不为“有参照”额外扩查。Reference 不保留外部链接，不等于禁止本轮按需联网核实。

- 搜索摘要只用于定位；具体作品分析以实际读取的原文或可信教学描述为依据。
- 来源只有简介：只分析简介已经提供的内容。没有试听或观看，就不裁定演唱细节、镜头细节或实际声画效果。
- 同名、翻译、改编或演出版本影响分析：标明当前版本。无法区分则换用已核实作品。
- 原作暂不可得：使用已有可靠描述并限定分析范围；没有任何可信内容则撤换该参照，不补造名作细节。
- 已获得满足主文数量要求、差异明确且可核实的参照，即停止扩查。来源证明内容，不证明用户喜欢，也不证明它适合本次创作。

## 把作品变成可选择的参照

每项依次写出：**作品与创作者 → 具体内容 → 表达安排 → 本次可借鉴的区别 → 来源**。

“具体内容”须包含分析依赖的对象、关系或变化；“表达安排”须定位它通过什么选择呈现这些内容。删除赞美词后仍看不出与其他作品的区别，该项退回重写。两项只换作者、名气或题材标签而没有表达差异，替换其中一项。

解释停在方向层：讲清它聚焦什么、怎样组织内容、留下什么问题；逐句修辞、配器和剪辑技术交专业制作。每个选项的说明长度保持接近，禁止靠篇幅或赞美力度诱导选择。

给用户的选择问题指向刚展示的差别：更想保留哪种情感、关系或表达方式；允许都不喜欢、混合其中的已指明要素或直接补充自己的方向。

## 从反馈提取需求

| 用户反馈 | 裁决与动作 |
|---|---|
| 指明喜欢某项具体特征 | 将该特征写为本轮偏好，保留其原话依据 |
| 只选作品编号 | 先概括该选项呈现的主差异；若可能混淆题材与表达方式，只核对这一个差别 |
| 喜欢作品但不想创作同类内容 | 只提取其指定的表达特征，题材不继承 |
| 多部作品各喜欢一部分 | 分别记录所选特征；互相冲突的要求列为待选择，不假定全部兼容 |
| 全部排斥且给出原因 | 下一组改变被排斥的特征，保留已接受条件 |
| 全部排斥、无原因 | 改用另一条主差异轴，不重复盘问记忆；仍无选择时保持需求未定 |
| 暂停、不想继续 | 停止提问与推荐 |

返回结果：已定创作类别、用户选择的特征及原话、明确排斥项、开放项、下一步所需帮助。用户选择只代表此次需求，不推断其人格、经历或永久审美。

## 专业案例：把教学描述转成选择依据

Yale Film Analysis 的“Part 4: Editing”中“Crosscutting, aka Parallel Editing”小节以《一一》为例：父亲和女儿大致同时在日本与台北约会，经历相似动作；父亲重遇旧日恋人，重新经历初次约会，女儿则是第一次约会。页面把两条线的平行剪辑解读为暗示代际历史重复。这里依据的是该教学页的文字描述与解读，不表示本文件已核看影片。

据此给参照时，介绍“不同代际的相似经历被并置”这一表达安排，供用户判断是否喜欢这种联系；不要只写“温暖、深刻、很有共鸣”。用户接受并置方法，不等于接受恋爱题材或代际主题。上述内容属于教学页对影片的描述；方法迁移是本文件的分析。不得添加该页未提供的对白、镜头或人物动机。

本文件的参照选择与反馈步骤是本 Skill 的需求引导规则，不冒称某位理论家的标准程序。
