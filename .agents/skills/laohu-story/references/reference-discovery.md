# 参照作品与需求发现

由[主 Skill](../SKILL.md)阶段一在用户没有内容起点、表达偏好仍模糊，或希望从真实作品获得创作启发时读取。输入可以是已有类别、用户喜欢/排斥的作品、用户给出的线索，或“我不知道”的空白；输出是作者能针对具体作品处理作出反应的候选路线，随后返回阶段一记录确认项。跨领域作品来源核验和上下文细读按根目录[参照作品研究方法](../../../../references/exemplar-study.md)执行；本文件保留故事构想任务里的比较轴、对话方式和反馈提取。用户已有需求时直接承接，不为研究名作另设门槛。

## 先确定需要比较的差别

1. 用户记得作品：提取其名称、描述、在意之处，先分析其提供的内容。仅有回忆描述时以该描述为输入，不声称读过原作；如果分析需要具体原文，才按共同方法查阅。
2. 用户记不起作品或完全没有内容线索：不让其先回答“你喜欢什么类型”这类无依据的宽泛问题。若创作形式已经确定，提供二至三件在该形式中处理方式不同的可核实作品；形式也未定时，挑二至三种不相同的真实创作路线作为入口，说明作品是什么、它实际怎样组织内容/视角/行动、哪一项具体处理可能提供启发。数量最多三项，必要时可以更少；每项差异须来自可读到的材料，不用类型形容词或名气填空。
3. 用户已定类别/形式但内容空白：选同类作品，优先只改变题材、情感立场或组织方式中的一个主轴，让作者看清其差别。其他差异作辅助说明，不把每部作品都描述成“感人、经典、有深度”。
4. 用户明确要求直接提议或已授权 AI 定案：记录这项授权，按共同方法研究一至数个真实作品作为创意起点，之后把所学机制转成当前材料没有的新构想；直接交付原创新构想和它的依据，不先停在“选一部名作”这一步。用户明确拒绝参照/外部检索时尊重该限制，转用已给材料或清楚标作假设的创意起点。

## 检索、核实与停止

按根目录共同方法确认原作身份、版本、证据边界和细读范围。针对故事构想，当前作品处理至少要能说明一个可观察的故事事实或内容关系，才能作为偏好入口；只见海报、简介或未读到的成片内容时，不补对白、场面细节或人物心理。Reference 中保留的《一一》教学页例子仅说明其页面提供的并置关系，不表示本 Skill 实际看过影片。

- 不以榜单、获奖、热度、知名度或大众偏好直接推断质量和用户偏好；其证据范围按共同方法区分。
- 若原文或足够详细的可信描述不可得，就停止对具体机制的判断，换用能读到的作品或只呈现有限资料，不能把未知细节补成结论。
- 来源证据证明作品身份、传播或评价，不证明用户喜欢，也不证明该机制适合当前构想。

## 把作品变成可选择的参照

每项依次呈现：**作品与创作者 → 实际可观察的故事/表达处理 → 本次可能用到的差异 → 不能据此推断的主题/偏好 → 来源范围**。

“具体内容”须包含分析依赖的对象、关系或变化；“表达安排”须定位它通过什么选择呈现这些内容。删除赞美词后仍看不出与其他作品的区别，该项退回重写。两项只换作者、名气或题材标签而没有表达差异，替换其中一项。

说明要让作者读完能回应具体东西，例如“我喜欢这个人物在关系变化前一直不解释，只用一次动作让观众重新理解前事”，而不止说“这部片很有深度”。候选路线说明长度接近；不能靠作品名气、篇幅或赞美诱导选择。若作者只要故事方向，逐句写法留给下游专业 Skill；该用户选择的是表达机制，不自动继承原作题材、角色或结局。

给用户的选择问题指向刚展示的差别：更想保留哪种情感、关系或表达方式；允许都不喜欢、混合其中的已指明要素或直接补充自己的方向。

## 从反馈提取需求

| 用户反馈 | 裁决与动作 |
|---|---|
| 指明喜欢某项具体特征 | 将该特征写为本轮偏好，保留其原话依据 |
| 只选作品编号 | 先概括该选项呈现的主差异；若可能混淆题材与表达方式，只核对这一个差别 |
| 喜欢作品但不想创作同类内容 | 只提取其指定的表达特征，题材不继承 |
| 多部作品各喜欢一部分 | 分别记录所选特征；互相冲突的要求列为待选择，不假定全部兼容 |
| 全部排斥且给出原因 | 下一组改变被排斥的特征，保留已接受条件 |
| 全部排斥、无原因 | 改用另一条主差异轴，不重复盘问记忆；仍无选择时保持需求未定 |
| 暂停、不想继续 | 停止提问与推荐 |

返回结果：本次创作类别/媒介、用户选择的具体处理及原话、明确排斥项、仍开放的作品元素、下一步所需帮助。作者选择的是当次表达决定，不推断其人格、经历或永久审美；应转成新作品的原创人物、关系、行动和后果，不复制原作的独特内容。

## 专业案例：把教学描述转成选择依据

Yale Film Analysis 的“Part 4: Editing”中“Crosscutting, aka Parallel Editing”小节以《一一》为例：父亲和女儿大致同时在日本与台北约会，经历相似动作；父亲重遇旧日恋人，重新经历初次约会，女儿则是第一次约会。页面把两条线的平行剪辑解读为暗示代际历史重复。这里依据的是该教学页的文字描述与解读，不表示本文件已核看影片。

据此给参照时，介绍“不同代际的相似经历被并置”这一表达安排，供用户判断是否喜欢这种联系；不要只写“温暖、深刻、很有共鸣”。用户接受并置方法，不等于接受恋爱题材或代际主题。上述内容属于教学页对影片的描述；方法迁移是本文件的分析。不得添加该页未提供的对白、镜头或人物动机。

本文件的参照选择与反馈步骤是本 Skill 的需求引导规则，不冒称某位理论家的标准程序。
