# 完整作品组织

由[主 Skill](../SKILL.md#快车道-4把点子撑成完整作品构想)在将选定方向与骨架落实成完整全篇构想时按需读取，完成后将覆盖全篇的承重单元、信息顺序、衔接与走查结果交回主文呈现。本文件只管完整构想的组织落实，不重做候选海选，也不越权代写正式剧本、小说全文或分镜。

## 一、把骨架落进具体承重单元

承接宿主选定的叙事结构（来自[叙事结构](../skills/laohu-story-structure/SKILL.md)）与体验玩法（来自[体验引擎](../skills/laohu-story-engines/SKILL.md)），非叙事则承接[非叙事构思](../skills/laohu-story-nonnarrative/SKILL.md)，论述类按问题、证据、推理、反例与结论推进。按实际作品尺度（单场、短片、单集或长篇全案）切分承重单元：

- **冰山提纯，不把原素材当打卡清单**：原始经历或背景材料很多时候是冰山底下给情绪供能的燃料，不必逐条演完；宁可钉死 1–2 个承载命运的核心母体物件或关系动作反复变奏，绝不塞满零度杂物拖垮节奏。
- **每个单元必须有活肉**：写清具体发生什么、人物此刻在意什么、知道与不知道什么、因此怎么选择或行动，以及世界或他人如何回应。只有制造共鸣、拉高张力这类空效果词的单元立刻补实。
- **同一结果允许不同人物有不同读法**：不把所有人物反应压平为单一信息差或工具人功能，也不在作品未要求人物成长时强加升华或和解。
- **写明相邻承接**：标出上一单元留下了什么新条件、困境、物件状态或情绪余波，下一单元实际接住了哪一条。接不上就重排、合并或补前提，不用过渡自然糊弄。
- **一眼扫清的导演案头版式（严禁长段文字墙）**：各阶段按清晰标题与短自然段推进，每段只把最关键的局势转折、道具状态变化或伏笔落点克制加粗点亮，既保持生动画面感，又让创作者 3 秒扫清全篇承重骨架（不写成密不透风的连续长段，也不在每段下贴机械的本段新增变化自证标签）。

## 二、管住两条时间线：发生顺序 vs 揭晓顺序

1. **时序、时距与频率**：有叙述时间的作品，分开把握事件真实发生的先后与观众实际看到的先后；哪些关键场面放慢展开、哪些平淡过渡果断压缩省略；同一动作或物件重复出现时，每次必须因为新处境改变作用或意味，否则合并。
2. **铺垫、回扣与开放结尾**：
   - 每个重大转折、反转或高潮破局，核实前置条件已在前面以当场有用的自然方式露过面；
   - 开放结尾必须写清核心问题回应到哪一步、故意留给观众回味的问题由哪件事托住，绝不拿没想好结局冒充留白。
3. **浏览顺序不改揭晓顺序**：提案开头为了方便用户快速判断，可以先交底全篇走向与结局，但正文展开严格按作品自身让观众逐步知情的顺序排布，不把提案概要误当成观众一开头就知道的内容。

## 三、反向提纲逐段走查（吸收增量与体验检验）

交稿前按观众真实接收顺序做一次极简反向提纲核查，对每个主要段落只问三件事：**进这段前观众已知什么？这段真正新增了什么新关系、新后果、新认知或新感受（或承担了什么有意的停顿、对照与回返）？后文哪一处实际用上了它？**

重点揪出六种病灶并当场修掉：
1. **承诺落空或迟迟不兑现**：开头吊起来的趣味或问题在中段消失了；
2. **中段空转**：连续两段在换场景重复同一种受阻或同一种情绪，没有推进变量；
3. **人物突然失忆、降智或物理/算术穿帮**：人物做出违背既定能力与知情范围的行为，或为了破局硬掰温差、混合比例、器械动作、精确凑整的机械对账——有瑕疵立刻修顺物理逻辑或改为合情理的估算抹平，不靠金手指滑过去；
4. **高潮泄气或防御性结案**：核心高潮或情绪破防瞬间被前段克制惯性拖软，或在高潮处忍不住继续解释设定原理、让人物开口讲道理总结升华，瞬间泼冷情感电压；立刻删掉理性解释，让可见动作、代价或沉默留白独自完成释放；
5. **体验信号与预期混为一谈**：区分作品里实际写出的动作/物件/节奏信号、创作者预期的感受和尚未验证的真实观众反应，绝不把自我预期说成观众必哭必笑；
6. **把核心主线甩锅给下游**：主题、关键转折、主要结局或中段承重内容还空着，却写着交由编剧或制作方发挥——能补的当轮补成清晰提议，缺关键决定的标为待定。

规模与时长比例按内容依赖给出设计估计，同时按目标体量预判最容易超标塞车的段落（如高密度算账或说明戏建议靠视觉图标减词）以及可省资产预算的场景取舍，注明实际节奏、声画或表演效果留待制作阶段验证。需要交给下游专业入口时，回宿主启用[下游交接](../skills/laohu-story-handoff/SKILL.md)。
