# 完整作品的总体构想

由[主 Skill 的完整构想](../SKILL.md#完整构想)在展开总体构想前读取。输入用户已定目标与边界、已选内容、已完成的功能分工和组合原则，以及宿主选定的结构或感知组织。没有组合记录时，从当前材料和用户请求建立工作方案。返回覆盖整体的内容安排、衔接、关键位置、收束和专业待验证项。不得重新把所有候选排一次名，也不代写正式作品。

## 承接已定组合，落实全程组织

候选取舍决定采用什么及其基本关系。本文件把这些决定落实到各部分的内容、位置和承接。已有顺序直接继承并补齐内容；顺序尚未确定时按依赖安排。发现用户已确认的组合原则本身冲突，带具体受影响单元返回宿主检查取舍；若只是本轮工作推荐不成立，说明依据后修订，不因局部衔接困难推翻所有已定内容。

## 按本作目标选择叙事尺度

总体构想承接已实际生成的核心前提、人物关系、事件/场景、策略变化与后果，再按用户本轮要解决的尺度组织：可以只交一个关系、一场事件或一个节拍，也可以展开单集、全篇或系列中的跨集状态。不得因为故事任务使用“完整能力”就把用户只要的局部扩成全篇。灵魂、筋骨、血肉、表皮四维和目标/判断/行动/结果四层是检查作品决定的不同关注方向，不是故事时序或层级；不得把它们对应成幕、序列、场、节拍，也不得据此增设故事单元。叙事完整构想承接宿主用[叙事结构](../skills/laohu-story-structure/SKILL.md)选定的组织单位与因果骨架。非叙事构想承接[感知组织](../skills/laohu-story-nonnarrative/SKILL.md)选定的材料关系。论述按证据和结论推进。

如果本轮只修局部，宿主先按[定点构思与修订](../SKILL.md#定点构思与修订)形成有效动作或承接，再只使用本文件中受影响的整体依赖的检查，返回当前范围。

## 选择组织方式

| 入选内容之间的关系 | 组织动作 | 不通过条件 |
|---|---|---|
| 前一行动改变后一处境 | 按前提、行动、后果组织；倒叙时另列信息显露次序 | 后果没有前提，人物知道尚未取得的信息 |
| 同一对象引出不同感受或认识 | 按触发内容与态度变化推进，保留转变依据 | 只有情感标签升级，没有引发变化的内容 |
| 新信息改变旧理解 | 先安排旧判断依据，再安排新增信息与回看位置 | 靠隐去理解必需的信息制造误解，揭晓与前文无关 |
| 多组内容通过差异相互解释 | 明确比较轴，按对应位置并置 | 只有轮流出现，没有共享关系或决定性差异 |
| 内容围绕命题提供证据 | 按问题、证据、推理、反例与结论组织 | 结论超过证据，论点靠重复代替支持 |
| 重复材料在不同语境中改变作用 | 写明首次建立、再次出现的变化和最终回响 | 重复只增篇幅，未承担已选定的组织功能 |
| 静态视觉、纯声音或互动概念 | 以主次、感知变化或行动反馈关系组织整体 | 被迫补出与目标无关的人物剧情或高潮 |

以已确认或推荐的主导原则为准选一项统领，辅助关系只补其未覆盖的功能。只有更换原则会改变用户已确认的方向时，才返回核对；若只是修正本轮工作推荐，说明理由后更新。

## 从单元到全貌

1. **列内容单元。**逐项继承来源编号和采用要素，为每项写出实际内容、主要作用及固定前提。只有“制造共鸣”“加强冲突”等效果词的单元退回补内容。
   人物叙事不能只把人列为结构功能的执行者。沿用[深化分支与生成不同角度](angle-generation.md)关于观察位置、知情范围和行动后果的既有检查，并服从本作已选的成熟专业方法：先问人物此刻在意什么、已知与未知什么，据此确定他注意、误解或选择什么；再安排具体事件里的阻碍与后果，说明它改变或维持了人物的态度、关系或处境，并将其落实为下游可表现的动作、细节和信息次序。同一结果在不同人物那里产生的不同理解要留在相应单元和回应中，不把它们压平为泛泛的信息差或单一功能。作品未要求人物变化时，不强加变化；新设想标明为构思，不冒充来源材料。
2. **列依赖。**时间型作品记录各单元进入时已知什么、增加什么、后续使用什么；静态作品记录主次、邻接、对比与观看关系；互动作品记录选择条件与反馈。依赖不成立先补条件，不用“过渡自然”遮蔽断裂。
3. **安排整体。**把必要理解条件放在其被使用之前，悬念只延迟答案，保留理解当前处境所需的信息。用户选择非线性或碎片形式时，仍标明各片段依何种内容关系共同成立。
4. **落实关键位置。**开场给出进入对象，集中表达承接前文，结尾回应核心；是否设置转折与高潮由实际内容决定。静态作品用主次关系与整体对照承担完整性，不机械套首尾段落。
5. **连接相邻部分。**写出上一单元留下的条件、问题或材料，以及下一单元接住的内容。无法写出具体对应则重排、合并或补内容；具体转场文字、镜头与声音工程交专业制作。
6. **分配规模。**沿用户对作品篇幅、时长和用途的要求，安排成品中哪些内容重点展开、哪些简要交代；这与本轮构思需要解释到什么程度是两项不同判断。短篇作品的承重事件、选择与后果仍可在构思说明中讲清，不因成品短就跳过关键过程；也不因解释过程需要展开而把总体构想扩成正式作品。用户明确要求简短时保持简洁。相对比例只作为概念估计；禁止声称已经验证演唱时长、阅读节奏或传播效果。
7. **全程走查。**按接收顺序读内容概述，逐项核对前提、转变、照应和固定核心；在会影响理解或体验的位置，说明接收者此时已知什么、刚得知什么、暂时不知道什么，以及离开该部分时理解或感受有何变化。保留未揭示信息须有表达目的，不能遮住理解眼前处境的必要条件。人物叙事还要回读其具体处境、注意和选择，确认象征物件或回扣改变/显出人物经历，而不是代替人物经历。专业制作仍需自行决定主题、主要内容、关键方法或主要结局时，构想未完成；只剩措辞与技术实现时，交主文确认。

若已有系列、单回或跨集承接的判定，按宿主返回的结算结果和实际跨集依赖安排位置。候选之间若仍未选定，不把各自的局部结果串成已经发生的连续行动。

## 区分时间的三个问题

事件发生顺序与呈现顺序分别记录。时序决定先后，时距决定展开、压缩或省略，频率决定一次发生与多次叙述之间的关系。只有作品包含叙述时间时使用这组工具；声音重复或视觉重复不能不加区分地称为叙述频率。

Gérard Genette《Narrative Discourse: An Essay in Method》（Jane E. Lewin 英译，Cornell University Press，1980）第 1—3 章分别讨论“Order”“Duration”“Frequency”。本文件用这三项检查构想中的信息安排，不把它们当成必须倒叙、必须反转的指令。

## 铺垫、兑现与开放结尾

亚里士多德《诗学》第 VII—XI 节（S. H. Butcher 英译）讨论整体行动及其变化。本文件据此在叙事构想中核对关键变化由哪些先前条件引出；跨体裁使用时检查的是内容依赖，不强制采用戏剧情节。

对每个关键转变记录前置内容、触发项和转变后的关系；缺少其中一项则补齐或取消该转变。开放结尾记录故意保留的问题与已完成的表达，禁止把缺失结局冒充留白。重复与变奏在本流程中是“相同材料因上下文改变作用”的组织方法，不代替音乐动机和曲式设计。

## 按体裁控制交付深度

| 体裁 | 本阶段写到哪里 | 留给专业制作 |
|---|---|---|
| 故事或小说总体构想 | 人物处境、核心关系、主要行动、前提与结局的完整梗概及章节承接 | 小说章节正文、叙述声音与完整成稿修订由 laohu-novel 承接 |
| 歌词、诗词 | 内容序列、情境与情感发展、集中表达和收束方向 | 逐字文本、意象措辞、格律、押韵、演唱适配 |
| 文章 | 问题、逐部分要点、证据位置、推理与结论范围 | 正文写作、修辞与发布编辑 |
| 影像 | 内容段落、关键行动或画面概念、信息顺序与声画分工 | 逐镜分镜、摄影剪辑技术、生成制作 |
| 音乐 | 目标听感、整体情绪或感知变化、对比与结束感 | 旋律、曲式、和声、配器与音频生成 |
| 图像 | 表达对象、主次元素和关键视觉关系 | 精确构图、光影材质、制作提示词与生成 |
| 标题 | 内容承诺、切入方向、信息重点及与正文的对应 | 定稿措辞 |

遇到未列体裁，先确定接收者接触的内容与整体组织方式，再划分构想决定和制作决定；不把陌生形式自动改成故事。

制作交接只划定何时由专业入口完成正式成稿或媒介制作，不免除本阶段当前提案文字的责任。总体构想、概要、衔接说明和局部台词示范都是本轮交付的一部分，仍须按主文“沟通语言风格”的共同规则写清字面对象与关系、保留语境支持的余意，并读回句群；不能把含混或不自然的提案留给下游入口再修。

## 专业案例：并置如何形成整体关系

使用 [参照作品与需求发现](reference-discovery.md) 中已给出处的《一一》教学案例，读取该案例后回到本节：两条行动线的相关性来自相似动作与不同代际处境。构想层必须写出比较的对应内容和差异；若只有“交叉剪辑”四个字，组织方案不通过。迁移到用户材料时核对其自身是否确有对应关系；没有关系就换组织方式，不凭空宣称代际重复。这里检验概念结构，不制作镜头，也不复原作者未公开的创作过程。

## 返回结果

返回宿主按[提案呈现规则](../SKILL.md#对话呈现与阶段记录)交付。每个单元关联已选或推荐的内容、概述、位置、承接与固定要求。接收者在作品中何时知道什么，仍按作品方法安排，不随提案为了浏览而先列概要改变。当内容会改变下游制作时，补上传递作品目的与取舍、已选成熟方法、具体表现设计、接收者进入/离开状态和信息显露/保留。只交接实际影响接手的信息，不强制固定表格；仍需下游决定的主题、主要内容、关键方法或主要结局退回补齐或标为未决，不以“制作方会处理”冒充构想完成。明确区分用户决定和 AI 工作推荐，并列新增补充、待核事实及专业制作待验证项。本轮需要下游继续使用时交回宿主调用[下游交接](../skills/laohu-story-handoff/SKILL.md)，依真实接收方编译简报。要确认、保存或停止时均回到宿主所定范围。

上述制作边界针对完整定稿与系统设计；为说明构想而提供的局部台词、歌词短句、标题和动作示范仍可使用。总体构想的提案浏览顺序服从主文唯一呈现规则；单元按作品实际接收顺序组织，二者不混淆。分析字段及表格也按该主规使用。
