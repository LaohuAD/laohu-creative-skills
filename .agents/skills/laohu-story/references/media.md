# 让灵感进入不同媒介

准备局部试作或比较表现方式时读取对应部分。先问“接收者实际会看到、听到、读到或操作什么”，再选择方法；不能把换几个领域名当成跨媒介适配。

下面是起点，不是穷尽目录。当前领域 Skill 的专业规则优先决定正式制作规格；这里负责探索方向，不能替代专业验证。

局部试作尽量落到接收者能读、听、看、演或操作的内容与变化；参数、风格词和制作计划可以说明选择，不能单独充当试作结果。只有概念建议时，说明它尚未经过实际媒介验证。

## 歌词、诗歌与音乐

**歌词与诗歌**准备局部试作时，不急着填满主歌副歌；可以只试一句、一个呼吸长度或两种重音。按以下次序推进：

1. 要发展表达内容时，从用户片段辨认说话者、说话对象、两者关系、此刻动作和情绪方向；同时留意已经吸引用户的字音或意象，以及表达怎样随时间变化。纯声音、语言游戏与抽象意象也可成立，不强迫交代人物故事；任务若只处理韵脚或声音，不要求补出说话对象、动作或情绪。
2. 发展表达内容时，从已有片段中挑选能承载表达的具体动作或感官细节。有画面却写不动时，可把“描述看见什么”换成“说话者此刻做什么、说不出什么”；这是可选变换，不替用户设定悲伤、创伤或遗憾。
3. 需要续写表达内容时，检查下一句承担什么作用。若本段需要推进而句子只用近义表达重复同一种感受，就让它增加事件、关系或态度变化；重复、回环、副歌或音韵复现若承担节奏、强调、结构或语义重释作用，可以保留，不要求句句引入新事件。可保留直接说出的情绪，不把每句都改成意象。
4. 读出小样，检查语序是否自然、重音与呼吸是否顺畅；当前任务使用押韵时，再检查韵脚是否扭曲意思。按中文实际读音判断，不把英语押韵或音韵结论直接套用到中文。

方向已定而只缺韵脚、曲式或语言修订时，交专业入口，不重做灵感探索。

**音乐与编曲**可以从音色、节奏、音高走向、织体、密度、重复和变化进入。只挑与当前感受相关的变量，例如保留短节奏，比较结尾延长与突然停住。不先逼用户给音乐写中心思想；纯音乐与环境声不需要歌词或剧情。

有音频时才依据实际试听谈声音效果；只有文字时，只能提出试听方案或暂定音乐方向。用户不会乐理时用可哼、可敲、可比较的动作承接，不把理论术语当门槛。真实生成与专业制作仍交对应能力和工具。

## 故事、剧本与短剧

用户被关系或事件吸引时，可试一个人物动作、一次回应或一个选择的后果，检查它是否改变局面。悬念、信息差和冲突能推动某些叙事，但观察性片段、日常喜剧、气氛作品也可采用其他组织方式。

局部试作时，先从现有材料中选择可发展的事件或观察顺序，按[探索方法](exploration.md)的“从材料选择事件发展或观察组织方式”推进。

只有设定标签时，先问或示范“这个条件会怎样改变一件具体小事”，不要立即扩写世界观百科。只有人物背景却没有可试内容时，找一个当下处境；不为制造戏剧性擅自增加死亡、背叛或创伤。

短剧的试作可以是一小段可表演的动作与对白。用实际可见、可演的信息检验关系，不以旁白解释完整证明戏成立；正式场次、分镜和完整剧本交专业负责人。

## 文章、解释与公共表达

从观察、疑问、判断、经历或某个读者真实困难进入。需要明确“我想弄清什么”时，先保留问题，不急着给正确答案；需要表达观点时，试一个具体场面、一个解释或一个有事实支持的判断。

比较角度时保持材料一致，观察从亲历、问题解释或反思等位置进入会改变什么。论证型文章需要证据；叙事、抒情和个人分享不强求统一论点或营销痛点。不得把虚构启发材料写成真实案例。

灵感方向已清楚，进入面向谁谈什么、系列如何安排时核验选题能力；需要完整成稿、改写、标题或事实检查时交各自负责人。仅因没有标题，不必重启全部探索。

## 封面、图片与视觉资产

先区分“需要承诺什么内容”与“需要让人感受什么”。服务已有作品的封面继承该作品的内容和保护项；独立图像可以从形状、空间、色彩、材质、尺度与观看距离发展，不必先编背后故事。

准备局部视觉试作时，按以下次序推进：

1. 先说明接收者应从现有材料中看见哪种关系，以及第一注意点落在哪里。如需增加人物、象征或剧情，让它与现有材料相连并明确标作创作提议，不说成材料事实或用户意图；不强加用户明确排除的内容。
2. 从位置、尺度、对比、遮挡、疏密、重心、重复或留白中，选实际可控且能共同服务该关系的变量，不把整份清单逐项填满。需要比较时控制无关变化，检查调整是否改变观看重点或关系辨认。
3. 把风格词落成可画的对象、空间关系和主次，以及明暗、尺度或材质层次。“安静”不等于让信息不可辨；风格词的数量也不代表完成度。
4. 去掉旁白或解释后，检查目标关系与第一注意点是否仍能从画面读出。只有草案时，把这当成待检验的问题并称为概念建议；不能保证观者仅凭图像知道材料未提供的背景。

封面文字和作品名分别处理；文字未定不等于视觉方向无从探索。角色或场景资产的灵感还要考虑后续是否需要持续识别和复用，不能只追单张图的新奇。

能看见实际图像时再谈可辨性与视觉效果；只有草案时称为概念建议。正式构图、光影、提示词和生成交专业入口，不伪造已生成或已验证的画面。

## 视频、动态画面与多媒介作品

视频多了时间：先找什么发生变化、观众何时看见或听见、变化之前与之后有什么差别。可试一个动作过程、一段声音与画面的关系，或改变一次信息出现的时机；不把静态图片描述后面加“推进镜头”当成完整动态构思。

运镜不是必选项。静止机位也能靠人物、光线、物体或声音的变化形成体验；只有移动会改变观看关系时才提出相应概念。正式镜头规格、视频生成提示词与连续性验证由专业能力负责。

同一作品包含歌词、音乐、封面和视频时，先保留共同感受、材料或表达目的，再让各媒介各自承担适合的部分。无需每种媒介逐字复述同一内容；检查它们是否相互矛盾、泄露本应延后的信息，或掩盖了原本值得保留的东西。

## 遇到未列出的作品形式

不要先把新形式归成文章或故事。沿用这五个判断：

1. 接收者通过什么感知或参与，体验是否随时间或操作改变？
2. 现有材料中，哪个部分让用户在意或能服务任务？
3. 哪个可变因素最可能改变这种体验，哪些限制不可改变？
4. 用什么最小尝试能感知差别，当前工具是否做得到？
5. 什么证据足以决定继续，什么仍需用户选择或专业验证？

例如互动作品可以先试一个操作与一次反馈，不必先写完整剧情；纯纹理作品可以比较密度或触感联想，不必制造人物冲突。无法判断专业成立条件时说明缺口，完成可做的概念探索，不以“通用”名义保证所有媒介的成品效果。
