# 受众与传播的源头构思

由[主 Skill](../SKILL.md)在确认公开传播情境后，按需于阶段二至五读取。它服务公开发布或用户明确希望吸引观众的构思，不把私人表达默认转成流量任务。输入可以是原始材料、暂定分支、用户选中的方向、候选或总体构想；按当前动作只读所需部分，输出受众关系、观看所得、传播切入、目标比较或全程兑现检查，再返回主文对应阶段。它不代替陌生化、Boden 的组合—探索—转化、Amabile 的新颖且适切，也不改写用户明确的事实、立场、目标或制作边界。

## 先确定这条支路何时适用

阶段一依据用户说明的用途判断：准备公开发布，或用户明确希望作品吸引某类观众时，进入本 Reference。用户为自己、亲友或私人体验创作，没有提出传播目标时，不默认做流量优化；仍按主文分析他希望接收者理解或感受什么。用途尚不明确，且该区别会改变当前核心或候选时，只询问公开/私人这一项；不影响本轮决定时沿用已有用途，不替用户补一个传播目标。

公开发布与追求某项传播反应也不是同一件事。公开作品可以服务表达、审美、娱乐或记录，并不自动以扩大受众为首要目标。只有用户给出要优先改变的结果时，才据此比较候选；不明确时评估内容与受众关系的适配，不把播放、评论、收藏或商业转化设成默认目标。

本文件处理的是**内容构思的可能条件**。没有真实作品、真实开场、发布数据或观众反馈时，不把可能感兴趣的人写成人群统计，不推断播放量，也不声称实际留存、共鸣或传播已经发生。可用“对正在经历……的人，这个关系可能有意义，因为……”说明成立条件；人数、比例和真实反应仍未知。

## 阶段二：从材料找到具体的人与观看所得

先沿主文[从材料生成与探索](core-discovery.md)找到可辨认的材料关系或暂定分支。传播分析可在核心形成前或后介入：**谁能从这段具体关系中认出自己，继续看可能获得什么。**它补充接收者条件，不替代原材料，也不要求先确定唯一主题。

从已有材料寻找主要关系类型。可同时存在几种，但只保留有材料支撑且会改变构思的关系：

- **当前处境：**某些人此刻正在经历相似的情境或任务。
- **利益后果：**内容会影响他们在钱、机会、风险、关系或身份上的处境。
- **尚未命名的经验：**作品把某种熟悉但难以说清的感受、习惯或矛盾具体呈现出来。
- **身份与立场：**材料触及某群体怎样看待自己、他人或共同经历。
- **好奇与窥探：**人们因少见的人物、过程、经历、结果或幕后信息想继续了解。
- **社交用途：**内容能帮助观众表达立场、解释自己、参与谈话或递给某个具体的人。

关系类型说明“为什么有关”，范围说明“哪些人可能共享这层关系”。按材料将范围描述为专业小众、单一群体、跨群体或广泛共同处境；这只是构思层面的范围判断，不是观众规模统计。随后分开记录以下四项，避免把“人多”误作“关系强”：

1. **范围：**共享这段关系的人可能来自哪里、需要什么条件；不凭年龄、职业或身份标签扩写用户材料没有支持的人群。
2. **发生频率：**这类处境是反复遇到、只在某个生活阶段遇到，还是偶尔遇到。
3. **关系强度：**它只是轻度兴趣，能改变理解、表达、选择或情绪，还是触及当前任务、利益、风险、身份或长期困扰。
4. **关系显露：**观众能否从构思准备展示的开头或首个内容单元认出这种关系；专业对象如何接到日常生活，相关性是否拖到很后面才出现，人群称呼是在帮助识别还是只留下空泛标签。

范围、频率、强度和显露互相独立。一个只在少数人身上发生的处境可以很重要；广泛共享的经验也可能只带来轻度兴趣。没有材料支撑时，把某项留为未知，不因公开传播而猜测受众。

再确认继续观看的主要所得（DBS 方法称**观看回报**）。以下是可组合的工作分类，不是每条作品必须提供的清单：

- **解释：**得到一个简单、可复述的原因或理解方式。
- **判断：**得到区分情形、评价或作选择的依据。
- **行动：**知道一个可尝试的步骤、问题、工具或下一件事。
- **情绪：**感到爽快、安慰、愤怒、希望、惊奇、释放或其他有材料支持的变化。
- **身份：**确认自己或所在群体的经验、立场与归属。
- **表达：**得到一句能转述的话、一个可用的称呼或参与谈话的材料。
- **娱乐与审美：**获得故事、表演、画面、声音、节奏或语言带来的体验。

先从内容实际能给出的东西确定主所得，可能有次要所得时再补充。审美与娱乐本身可以是主要价值；不强行添实用技巧、反转、煽情或说教。候选关系需指出来自哪项材料、谁在什么条件下可能认出它、所得如何由内容承载。为了探索而增加的受众处境或虚构关系标为提议，并可沿它继续推演；只有它触犯用户明确的事实、目标、立场或硬约束时，才退出该支路或请用户决定。不以吸引观众为由改写用户经历或表达方向。

阶段二返回主文前，形成足以指导当前生成或探索的判断：可识别的关系与材料依据、可能认出的处境、主要观看所得及未知条件。无需把七种所得或六类关系逐一填表；当前创作没有传播目标时不读取本节。

## 阶段三：从同一材料生成不同的受众切入

保留用户明确的事实、目标、立场与硬约束；如果已有用户选中的方向，沿用其当前边界。公开传播候选可以改变“谁先认出这段材料、因何继续、能得到什么”，但这些变化必须进入具体内容，不能只换标题、称呼或强调语气。新增受众处境写作提议并继续推演，不能把提议说成已知人群事实。每条有效候选交代：

- **具体内容：**同一材料在此方向里呈现什么关系、情境、行动或理解变化；
- **受众切入：**哪类人因哪种关系可能认出自己，关系是材料已有还是明确新增的设定；
- **观看所得：**本方向实际准备提供的主要解释、判断、行动、情绪、身份、表达或审美体验；
- **拟开场：**给出与该方向具体内容相符的一种候选第一句、画面、声音或开场安排，并明确标作“拟开场”。

开场可以在候选构想阶段提出，不要求先完成正文。拟开场只是需要后续检查的创作方案，不能写成已有成稿、真实发布数据或已经验证的观众反应。首句之外，图文可包含封面和标题，视频可包含开场画面与声音；构思时说明最先被接触的内容，不把未提供的视觉或声音材料当成事实。

发散覆盖材料实际支持的不同受众关系，不设通用条数，也不凑齐所有类型。相同材料可从处境、利益后果、未命名经验、身份立场、好奇或社交用途切入，也可让审美或娱乐成为主所得；每次变化须让内容或观看所得确有差别。只改包装而材料、关系、受众切入及所得都不变，按主文合并。候选若违反用户明确的事实、目标、立场或硬约束，退出该分支；若只是扩大了假设，标出条件后继续探索，不擅自要求用户逐项确认。

## 阶段四：按用户优先目标比较候选与代价

先执行主文的硬约束筛查、候选层级区分、贡献和相容检查。传播判断为比较补充条件，不取代故事构思的材料价值、用户偏好与整体表达。用户明确了公开表达的首要目标时，按该目标比较候选；没有明确目标时，不推断“更多流量最好”，也不把不同结果合成一个总分。

在比较候选的停留或后续互动动力之前，先对每个候选开场执行“阶段五”中的五问和失败分支。区分已提供的真实开场、明确标记的拟开场与缺失开场；构思材料没有拟开场时，依据现有内容提出并标记一个候选开场，再检查它。没有真实开场时，实际表现始终未知。开场未显出相关关系或合理所得时，先修改候选开场；后文预计能带来的好处不能替它补出停留理由，也不能据此预测持续观看、评论、收藏、转发或关注。

接触行为要分别判断其动力和阻力，依据候选中实际安排的内容：

| 观众行为 | 可能的动力与需要检查的阻力 |
|---|---|
| **停留** | 第一眼看到的反常判断、直接利益或风险、少见结果、身份关系、情绪、明确承诺等是否与观众有关；冲突措辞本身不足以证明相关。 |
| **持续观看** | 未回答的问题是否值得继续、后文是否逐步增加案例/层次/结果或感知变化、各部分是否推进同一关系；重复判断、回报迟迟不来、突然换题、连续抽象或离主线很远的例子会增加阻力。 |
| **评论** | 是否有容易辨认且可参与的立场、身份或经历；是否有值得补充、反驳或回答的问题；参与门槛是否过高。 |
| **收藏** | 内容是否值得将来重看或再次使用，例如步骤、判断依据、案例，或值得回味的表达与审美；不把收藏只等同于工具资料。 |
| **转发** | 是否能帮助某个具体的人、替观众表达立场、连接群体谈话，或带去值得分享的谈资、惊奇、情绪与审美体验。 |
| **关注** | 当前构思是否显出作者可辨认且能持续提供的视角、经历、能力、判断或审美供给；一条内容的即时回报不自动构成长期关注理由。 |

这是六个不同问题，不是一套总分。某方向能引人评论，不等于它有更好的持续观看、收藏、转发或关注理由；不相关的行为不必分析。没有平台、成品和反馈时，只描述由内容安排支持的可能动力及成立条件，不使用“大多数会”“强流量”等人群比例口吻。

**受众范围与关系强度分开比较。**宽范围、浅关系与窄范围、强关系是不同取舍，不按受众标签数量判优。频率帮助判断处境是否反复进入目标人群生活，显露程度帮助判断他们是否能及时识别。比较时点出候选的实际材料和差异，不使用抽象的“受众更广”代替证据。

表达选择可能带来相反影响，应把增益、代价和必须保留的内容一起说明。强断言可能让立场更显眼、容易引发评论，也可能排斥被归因的人或不接受绝对说法的人；片面归因可能减少理解步骤、提高确定感，也可能抹掉复杂经验；身份对立可能加强群体表达，也会拒斥被攻击者；普遍情境可能扩大关系范围，也会削弱特定群体识别；复杂解释或实用步骤可能增加判断、收藏或行动所得，却提高理解和观看成本。它们只是检查方向，必须回到候选材料作具体判断。简化解释不能虚构事实、因果或人物动机；保留 Story 的事实边界、确认立场和表达力度。

只有用户说明了产品、服务或商业目标时，才增加商业承接检查。先按候选内容可能形成的关系区分泛兴趣者、强共鸣者、同行或评论参与者、潜在客户、已有客户与围观冲突的人；这些是内容来源的可能构成，不是实际流量数据。再看构思中能让人感知作者哪些能力：为问题命名、简化复杂经验、提供一手经历/资源/案例、呈现清楚立场与稳定风格、持续提供方法/判断/情绪体验，或展示可见成果、身份与社会证明。说明哪项具体内容让目标人群看见这种能力，它怎样可能支持后续关注、咨询或合作，以及从当前关系到产品任务还缺什么连接。只有内容直接触及产品解决的任务或目标客户时商业距离才较近；展示相关能力但仍需连接到具体需求时属中间；主要吸引来自娱乐、争议或泛身份且与承接无关时较远；目标信息缺少则未知。每一项须落回候选材料，不能臆造产品、目标客户或承接路径，也不以商业距离压掉已确认的创作目标或擅自插入销售动作。没有明确商业目标时跳过此分支。

推荐时说明为什么它最符合用户当前优先目标、比近邻候选保住了什么，以及可能缩窄或排斥什么；其余有效方向可作为不同目标下的备选。关系强度、传播动力、审美价值与商业距离均不能替代用户选择。

## 阶段五：先隔离检查开场，再沿接触顺序核对全程

总体构想可以先把有价值的内容安排好。验收时必须先把后文放在一边，只检查观众最先接触的开场，再重新打开全程构想检查承诺有没有兑现。**后文的好内容不能反证开场有效，也不能用它预测观众已经能看到的回报。**

### 只读开场的五个问题

以目标媒介里实际先到达观众的内容为准：图文包含封面、标题和首段；短视频包含封面、标题、第一句话及最初画面和声音；长视频看封面、标题和开场承诺；纯文本看最先可见部分。只按本轮真实提供的材料判断，不从正文擅自抽一句，冒充原有开场。

1. **内容分类：**观众从这段开场会以为接下来呈现哪类内容——概念解释、个人故事、实用做法、利益判断、情绪表达、故事/表演/审美体验，或其他具体方向？
2. **原生问题：**相关的人是否本来就在想、经历或留意这件事？说清是哪些人在什么处境下会这样想；没有依据时不猜有多少人。
3. **个人关系：**开场是否显出观众熟悉的处境、后果、情绪、身份或好奇对象？相关性是否需要等到很后面才成立？
4. **预期所得：**继续下去，观众可以合理期待得到什么？这个期待具体且与候选实际内容相符吗？
5. **未闭合张力：**是否留下观众有理由继续追的疑问、未完成行动或待见结果？若材料没有悬而未决的关系，不强行造悬念；审美、表演和情绪也可以直接构成继续理由。

如果用户提供了真实开场，按它当前呈现的内容检查；如果没有，状态记为**真实开场未知**，不作真实停留诊断。构思任务仍应依据当前内容主动写出明确标记的“拟开场”，再用同一组问题检查它的构思潜力。拟开场可被改写，但不能因为它通过内部检查就说实际观众会继续。

### 按失败位置修开场与全程

- **开场误导内容：**若它让目标观众以为内容只讲低需求的术语、内部事务或作者兴趣，而后文真正处理的是另一段具体处境，优先重写开场，显露已有材料中的关系。不能靠后文补课来证明它会停人。
- **关系或所得不可见：**若开场看不出它和谁有关、继续后能得到什么，先寻找同一核心材料中更清楚的入口。用户目标依赖这层关系时可以调整内容呈现；不得编造冲突、因果或效果，也不得偷换核心。
- **只有特定群体能进入：**指出需要什么经历、知识或身份条件才会认出关系；若其关系很强，保留垂直方向的价值，只有在用户优先目标要求扩大范围时才比较替代入口。
- **开场成立、后文未兑现：**保持开场单独判断，再对照它承诺的内容与实际构想。承诺没有对应内容时补入、改准承诺或调整顺序，不能用漂亮开场掩盖内容缺口。
- **全程缺少增量：**从开场之后逐段核对新增了什么信息、后果、经验、情绪变化、关系重释、观点依据或审美变化。连续重复同一判断、回报等待过久、突然换议题、抽象层层堆叠或例子离开主线时，修复对应部分。抒情、喜剧、静态视觉、纯声音等作品可以靠节奏、感知或形式变化推进，不必补成冲突—反转—升华结构。

然后再沿观众接触顺序走查：每段是否接住前项、是否增加新的内容或体验、是否朝主要所得推进、结尾是否回应已经建立的关系。完成的只是构思判断时，交付拟开场和内容安排，标明仍需真实作品、媒介呈现或接收者反馈验证的效果；不报概率、播放量或已经发生的受众反应。
