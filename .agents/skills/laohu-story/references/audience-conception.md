# 受众与传播源头构思

由[主 Skill](../SKILL.md#快车道-4把点子撑成完整作品构想)在用户说明准备公开发布，或明确希望吸引某类观众时按需读取，完成后将受众切入、开场检查或传播取舍交回主文。**私人表达或未提传播目标时不加载本文件，绝不强行做流量优化。** 公开发布本身也不自动等于追逐流量或变现；只有用户给出优先传播目标时才按该目标排序。

本文件分析的是内容构思的成立条件，绝不编造人群规模、播放量或传播概率，也不把构思潜力说成已验证的观众反馈。

## 一、找到具体的人与观看回报

在已有材料基础上追问两件事：**谁会从这段具体关系里第一时间认出自己？继续看下去能拿走什么？**

- **6 类常见关系切口**（只挑有材料支撑且改变构思的项）：正在经历的当前处境、钱/机会/风险等切身利益后果、熟悉却一直没人说透的未命名经验、群体身份与立场、少见幕后或反常结果的好奇心、能递给朋友或帮自己表态的社交用途。
- **范围与强度必须分开看**：把受众范围（专业小众 / 单一群体 / 跨群体 / 广泛处境）、出现频率、关系强度（轻兴趣 / 改认知 / 碰切身痛点）与关系显露速度（开头能否立刻认出）分别判断，绝不把人多误当成关系强。
- **7 类观看回报**：解释（一个好复述的新说法）、判断（帮人选边或辨真假）、行动（可照做的办法）、情绪（爽快、荒诞、安慰、释放等）、身份确认、社交谈资、娱乐与审美体验。娱乐与审美本身就能当主回报，不强行塞干货或说教。

多方向发散时，同一材料若要做出不同受众切入，必须让**具体呈现的内容和观看回报真正拉开差异**，并为每条配一个明确标作拟开场的入口（图文含标题/封面/首段，视频含首句与开场画面声音），不能只换标题词或人群标签。

## 二、先隔离检查开场，再沿接触顺序核对全程

检验公开作品或比较候选时，**先把后文盖住，只看观众最先接触的开场**（用户给了真实开场就查原件，没给就把真实开场状态记为未知，同时主动拟一个标明为拟开场的方案来检，绝不从正文偷抽一句冒充原开场）。后文写得再好，也救不了第一眼划走的开场。

### 只读开场的五问
1. **内容分类**：观众第一眼会以为这是什么内容（故事、笑剧、实操、观点、情绪共鸣还是审美体验）？
2. **原生问题**：相关的人原本就在意、经历或好奇这件事吗？具体是谁在什么处境下会留意？
3. **个人关系**：第一眼就能看出和自己有关，还是得忍到后半段才明白？
4. **预期所得**：观众看完开场，会合理期待接下来拿走什么？这期待和后文实际内容对得上吗？
5. **未闭合张力**：有没有留下让人想继续看下去的疑问、未完行动、反差趣味或直接审美吸引？（安静审美类不硬造悬念。）

### 常见失分位置与直接修法
- **开场误导或关系隐身**：把后文真正有趣、切身的关系或反差直接搬到开场露出来，绝不夸大到后文兑现不了（例如把个人一次走错路夸成所有人都会怎样，必须先收窄口径或补足依据）。
- **开场成立但后文没兑现 / 全程没增量**：用反向提纲顺着接触顺序查每段新增了什么信息、后果、反差或体验，砍掉原地打转的重复判断、跑题举例和迟迟不给回报的拖沓；有功能的留白、节奏与回返照常保留。

## 三、传播记忆点（认知空白 × 六原型 × 三秒质检）

情绪真挚与结构工整守住下限，真正触发截图转发与口碑记忆的社交货币，来自未完全封死的认知空白与精确双轨张力。按题材真气在全篇集中部署 **2–3 处黄金锚位**（主高光 1 处 ＋ 铺垫或转折 1–2 处，绝不句句抖机灵）：

1. **表里双轨**：用清白体面的日常面皮，包裹放进语境便一秒意会的私密经验或人性里子；
2. **熟语微拧 / 同词异义**：借大众闭眼能背的熟语或高频词微拧半寸，或让同词两义正面相撞；
3. **语意反转 / 前扬后劈**：前半句顺理性或温和轨道建预期，后半句急刹劈翻亮出相反真相；
4. **反讽冷刀 / 降格留白**：用极客气克制的口吻刺穿最残酷的落差与代价，表层平静、底色见血；
5. **陌生化跨界撞击**：把抽象情绪撞进冷峻具体的物理、空间或异质动作里，打破麻木；
6. **人性公理 / 空槽召唤**：用极简短句定格共通真相，或搭出通用生活空槽召唤观众代入自己。

每处锚位必过三秒质检：第一遍顺滑零门槛、回味半秒第二层含义击中、100% 服务核心情绪而非硬凑冷梗。

## 四、按用户优先目标比较行为动力与商业距离

六个观众行为各自依赖不同内容动力，**绝不合成单一总分**，只分析与用户目标相关的项：

| 行为 | 看内容里有没有这些硬支撑 | 常见阻力 |
|---|---|---|
| **停留** | 首眼反常判断、鲜明反差、切身利害、少见结果或精准情绪 | 泛泛铺垫、术语堆砌、空口号冲突 |
| **持续观看** | 悬而未决的问题、层层递进的反差/案例/后果、主线统一 | 重复同一意思、回报拖太久、中途换题 |
| **评论** | 好参与的立场、共同经历、留有讨论空间的真实争议或疑问 | 说得太满没插话口、门槛过高 |
| **收藏** | 值得以后再翻的步骤、判断依据、金句或耐品审美 | 看完即忘、无回看价值 |
| **转发** | 能帮具体某个人、替人表态、好玩的谈资或强烈审美惊艳 | 过于私密自嗨、拿不出手递给别人 |
| **关注** | 显出创作者稳定独特、能持续复产的视角、手艺或风格 | 一次性奇闻，看不出下期还能给什么 |

同时摊开表达取舍的双刃剑（例如强断言易引评论但也排斥反方，普遍处境扩大范围但也稀释精准共鸣）。**仅当用户明确说明产品、服务或商业目标时**，再补查商业距离（内容直击产品所解任务为近、展示相关能力需搭桥为中、纯娱乐泛争议为远），且只依据用户提供的真实经历与能力，绝不编造创作者背书或擅自硬插卖货动作。
