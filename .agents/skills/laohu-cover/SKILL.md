# 老胡封面与传播视觉设计

**一眼入心，三秒见骨；向内极致提纯，向外直击焦点。**

## 视觉底座：综合强情绪、感官洁净与品类骨相

观者在前 50 毫秒就会绕过理性分析，凭身体与感官本能判断画面的洁净度、情绪温度与生命力（50ms 第一印象、Norman 本能—行为—反思三层情感设计、加工流畅性与统一中求变化、Brumberger 字体人格声口、具身运动共情与 Bar & Neta 弧度愉悦神经美学），再决定是否停下来读字、信服内容并记住核心信息。动笔前先守住四条跨品类通用判断：

1. **视觉奇观与综合强情绪（告别安全情景剧，热烈的有冲击、平静的有定力）：**
   - 情绪感染力从来不只靠喧闹嘶吼，而是镜头语言、光影奇观、主角状态与定制字形四位一体共振出的磁场——炽热痛快让人瞬间上头，沉静笃定让人半秒屏息安静下来，**两者都是高浓度强情绪**；
   - 先立住一眼令人惊叹或屏息的戏剧反差、空间神圣尺度或高电压真实瞬间，彻底淘汰温吞礼貌的商业图库坐姿摆拍，同时既拒绝拼贴打卡与廉价躁喊，也严防浮夸假拔高或粗糙塑料质感拖垮作品。
2. **感官洁净、95 分底图含金量与趋近型生命力：**
   - 把足够笔墨留给底图本身的电影摄影与美术含金量（镜头焦段、真实光学空气感、戏剧明暗切割与可触摸材质），确保遮掉全部文字后画面本体依然极具感染力；第一眼通透清爽、绝不浑浊脏乱，同时也打破灰白壁纸、机打字幕条与笨重 3D 挤出浮雕的死气；
   - 主角与核心视觉对象始终保有美感、酷感、松弛爽感或沉静定力等**趋近型生命力**（哪怕讲痛点或深情，也是美而动人、有尊严的，绝不扭曲丑化）；高张力题材保住锐气，绝不磨成温吞小清新。
3. **单一视觉母体、80/20 呼吸素底与打破死板隔离盒：**
   - 原始长文、提纲或复杂材料是底层的燃料，绝非必须逐项塞进画框的道具清单；宁可舍弃七八件情感零度的杂物，也要钉死极少数（往往唯一一个）托得住主题的核心视觉承担者，用约八成退隐底盘托起约两成高度集中的视觉核心，全图始终只有 **1 个绝对视觉老大**、至多 3 个清晰视觉锚点；
   - **彻底打破上字下人、左字右人的死板盒子惯性**：文字不是躲在黑框角落里的贴纸——强情绪封面与海报大胆让压场巨字横跨大片宽幅，并借前景人物发丝、肩线或道具自然压在大字边缘前方造出三层影院纵深（同时保住关键笔画 100% 清晰）；纯平面建筑、极简海报与信息图则靠严谨留白、尺度悬殊与定制骨相立住博物馆级秩序。
4. **先分清四类成品截然不同的审美骨相，绝不串味：**
   - **自媒体封面**：半秒停指的综合情绪磁场、洁净好光影、趋近型主角或反差焦点、带活人呼吸律动的表现性展示字；
   - **信息图**：编辑部秩序美学、以白代框的呼吸留白、透明清晰的阅读字与零造假真实拓扑；
   - **作品海报**：极值留白容器、单一强切片的凝视余韵、字图共生且挪位即破功；
   - **UI 与阶段关键帧**：器物精密感、清晰表面明度阶梯、克制点睛与工程可落地的功能字。

## 1. 先核实际工件边界与跨入口分工

- **实际成图必须有当轮真实工件。** 遇到直接做一张海报、给我出图等成品请求，先查当前会话有无可用图像制作工具。有授权和工具时实际制作并以原生可访问工件交付；无工具或尚无结果时，把交付定为**设计稿或制作稿**，回复首句直接说明当前为设计稿、实际图片待制作，随后交可直接使用的完整提示词或精排规格。具体判定见[实际工件状态](#实际工件状态)。
- **跨入口分工：**
  - 纯画面艺术、摄影、插画或无字封面 → [laohu-image](../laohu-image/SKILL.md)。
  - 只拟或改写标题文案、或只要交给视觉同事的标题单 → [laohu-title](../laohu-title/SKILL.md) 的[封面四字段](../laohu-title/skills/laohu-title-entry/SKILL.md#5-交付封面主标题与字图分工)；真正进入视觉设计或审图再走本入口。
  - 跨图复用的角色、道具、场景或服装身份资产 → [laohu-assets](../laohu-assets/SKILL.md)。
  - 文章篇内讲解图 → 承接 `laohu-writing` 传入的原文锚点、邻文语境、读者任务、事实条件与文字权限，沿正文栏而非封面画幅设计；实质事实或读法缺口交回 `laohu-writing`。
  - 动画局部构件委托 → 接收 `laohu-motion` 同一镜头的知识图/关系图/文字板委托，交付事实或示意身份、逐字文本、目标画幅、底图或叠加层、透明与 alpha 目标、可动部件拆分、前后遮挡与裁切边界；整幅动画方向帧走关键帧专项并按 [Motion 方向帧交接](../laohu-motion/references/production-collaboration.md#方向帧的两种来源与回交)办理。

## 2. 需求穿透、三态裁决与方向闸门

- **先分清硬锁定项与表层视觉想法，按三态灵活裁决：** 逐字锁定文案、真实事实数据、品牌红线与合规禁项一律视为不可触碰的硬锁定项；面对其余视觉表述，先穿透字面挖出真实观看处境与不变的核心情绪，再区别对待：
  1. **同向且有明确独到方向**：用户给出了清晰且符合视觉规律的风格或构图指定（如黑白胶片、冷静极简、瑞士网格或特定材质）→ **完全尊重并顺着这条路做到极致**，不拿默认偏好强行覆盖；
  2. **表达模糊宽泛**：用户只给了高级一点、有科技感、帮我做张封面等粗略愿望 → 守住基本方向，直接按顶级传播视觉标准补齐情绪定位、洁净光影与清晰主次，不敷衍交平庸套壳；
  3. **表层视觉想法明显伤可读性或破坏美感**：例如要求在封面背景塞满多项功能图标与杂物、强加花哨多色艺术字或把画面填满毫无呼吸 → 守住背后的不变诉求（如显得专业有料或热闹醒目）与全部硬锁定项，**坦诚直说原做法在缩图下互相抵消的后果，不顺着做烂图**，直接给出换血后的高水准主方案供拍板。
- **用户问最少要给什么时直接给精简清单：** 封面给标题或主题（需图像佐证时附正文要点）；信息图给材料或读者要看懂的问题；海报给发布对象或主题及目标观者（有真实行动才补时间、地点、报名方式）；阶段/UI 关键帧给作品目的、目标状态与已有草图或截图。平台、比例、品牌资产、参考与禁项按需补充，复用前情不重复追问。
- **关键缺口与 2 选 1 方向闸门：** 缺口会实质改变主结构时，默认只问最关键的 1 项（确有两个独立主缺口才问第 2 项）。材料支持两个视觉路线显著不同、且用户未拍板时，给 2 个画面差异鲜明的候选方向（写清情绪气场、第一眼落点、代价与推荐），等选定再出终稿。方向已定、用户授权自定或只剩常规细节时，直接设计交稿；纯讨论、比较、审图诊断或只要单项产物时严守所求范围。

### 同一画面任务的后续请求

沿上下文和最新授权承接后续指令，如再做一套继续同作品视觉探索、可以添加接前文唯一明确的添加方案；已有功能实现、代码修复或直接前端开发仅在需要整幅视觉设计或交接时才进入关键帧：

1. **预览方向：** 用有实质差别的画面构想、独立提示词或宿主实图呈现差异，相容亮点可跨候选合并，严分设计稿与实图。
2. **选定后只交接：** 直接按[制作参考与交接](references/production-reference-handoff.md)移交已核准实图与取用说明，不重新选方向或重写已核准帧提示词；混合组逐帧分流，只设计仍缺的帧；非相邻帧仅在状态关联与图像职责有据时取用。
3. **已授权直接制作：** 免预览只省去向用户呈递候选，内部制作与核验仍按交接办理；无可靠同向基准时宿主先取代表帧并核验；共用方向明确且只需局部素材时直接按实际作品状态接入并检查。宿主缺生图工具且用户明确要实图时，关键帧可按交接文档中的模型小屋兜底规范现场核实。

## 4. 四步统一创作主线（极轻定盘放飞 → 成稿轻扫疤）

局部修改只走受影响步骤，冻结其余已定决定并复查直接依赖，绝不顺手推翻已成立的版面或气质。

### 第一步：锁任务、定海拔情绪、立事实与文字权限

1. **定观看处境与默认工作画布：** 明确谁在何处、多大尺寸下看这张图，先核实用户指定比例或平台裁切；未指定时按项目工作画布起排，工具仅支持有限比例时改用实支持参数、取回实图后再核像素：
   - 信息流封面、独立知识卡、海报：**4:5**（1080 × 1350 px）
   - 公众号文章头图横幅：**2.35:1**（1200 × 510 px，兼顾转发正中 1:1 方形安全核）
   - 横向对照、架构全景、宽屏演示或 B 站横封：**16:9**（1536 × 864 px）
   - 全屏短视频或竖屏故事版：**9:16**（1080 × 1920 px）
   - 公众号正文篇内图：沿文章正文栏宽度与局部关系定相对比例，不套封面画布。
2. **定第一眼情绪浓度与同级分量：** 先明确观者扫过前 50 毫秒应升起的具体情绪（无论是炽热破局还是让人一下子安静下来的沉静笃定），以及当前内容最契合的画面分量——让厚重与轻盈、克制与锋芒严格配得上题材本味，拒绝千篇一律跨题材复刻同一套暗色或浅色模板。
3. **守死文字权限与事实边界：**
   - **文字权限：** 逐项区分**明确逐字锁定文案**、**未锁定草稿或主题叙述**、获准压缩润色文案、可拟说明与禁现文字；保护专名、数字、单位、标点、来源与限定语。凡用户已定稿或明确保留的封面主副标题（含技术与知识图标题）默认逐字保留，绝不因看起来长就擅改词面，靠清晰层级与语义断行救可读；若用户仅丢来一段未锁定的超长草稿句或随口主题叙述，明显超出封面缩图舒适容量时，可在保住原意的前提下先按更紧凑的封面字面（或按需调 `laohu-title` 接收[封面四字段](../laohu-title/skills/laohu-title-entry/SKILL.md#5-交付封面主标题与字图分工)）出主方案，并在块外保留原句供一句切回。图内节点名、关系词、图例和行动字段不送去当标题改写，8 字预算也只约束共用封面主标题。
   - **事实与证据：** 逐项核对数值、单位、比较对象、时间范围与出处。输入冲突并列记录并只问改变结论那项；精度或出处缺失时挂起依赖边和数值，其余有据结构继续；无数据时只在获准下做可辨认的概念示意，绝不冒充实拍、测量或真实界面；时间先后绝不画成因果，预测不进实证图，无真实行动任务的海报绝不编造日期、价格、按钮或二维码。

### 第二步：极轻三支点定盘，再交专项放飞构思

动笔前绝不背负几十条事前微操清单，只用极轻三支点定盘，随后进入选定三级专项大胆放飞画面构想：
1. **定唯一核心视觉母体与洁净情绪气候**：从原始材料抽魂蒸馏出 1 个最托得住主题的可见承担者，并确定与之共振的通透色域、光向与材质触感（色光与字形一律从当前题材自身长出来，绝不跨题材套用固定配方）。
2. **定图文空间关系与文字声口方向**：明确品类归属下的阅读字或展示字路线、主副标题清晰层级（主标第一层、锁定副标第二层不压成蚂蚁脚注）以及图文互补关系——遮掉全部文字后，画面本体仍须立得住情绪、悬念或结构价值。
3. **拿不准时用高阶真品四维校准**：遇到陌生流派或原始材料偏琐碎易做土做散时，先借同类顶级真品（或用户给定参考、或按需只读检索[本地资料库](../laohu-benchmark/references/library-retrieval.md)）拆透其情绪分量、空间骨架、核心母体与材质工艺，随后立刻合上对标、彻底长出本作自己的血肉，学机制绝不抄外壳。

### 第三步：按实际瓶颈精准加载专项参考（平时不盲拉）

日常轻文字 AI 封面与海报优先靠主文 + 对应 L3 专项 + `prompt-compilation.md` 完成，保持轻量与创意锐气；仅在命中下表具体瓶颈时按需读取对应参考，读完回主线整合。

| 复杂关系图拓扑、视觉隐喻容器校验、跨区连线路由、分支汇合或节点尺寸规划 | [图形关系与连线](references/relationship-diagrams.md) | 仅信息图/关系图/篇内图遇复杂拓扑或隐喻校验时读。 |
| 从歌词、剧本、照片提炼作品锚点，或设计海报当代平面构成与字图穿插 | [从作品材料生成艺术构图](references/artwork-composition.md) | 仅作品发布海报或艺术化重构主视觉时读。 |
| 用户提供可访问参考图或截图，需判断职责、多阶段拆图或跨图抽变量 | [参考图迁移](references/reference-transfer.md) | 无参考图或截图时零加载。 |
| 关键帧交付两段式制作说明、已有帧直接交接、混合组、宿主出图或模型小屋兜底 | [制作参考与交接](references/production-reference-handoff.md) | 仅关键帧交接、混合组或宿主实图落地时读；单要探索提示词时零加载。 |
| 将最终方案编译为中文 AI 正向生图正文（路线 A）或可编辑精排规格（路线 B） | [生图提示词与精排制作规格](references/prompt-compilation.md) | 输出最终提示词、贴字表或精排规格时按对应路线读取。 |

学术理论与案例出处统一归档在 [SOURCES.md](SOURCES.md)（日常零加载）。

### 第四步：双轨编译与陌生观者自检

1. **按接收媒介选编译路线：** AI 生图默认走[路线 A](references/prompt-compilation.md#路线-a编成能直接粘贴的成像正文)，用精炼自然的导演语言定死灵魂、骨架、锁定文案与色光气质，把具体微排布与造型呼吸放手交由生图模型发挥；遇密字、多组精确数据或严格字体时按文字密度红绿灯给出无字素净底图＋精确贴字表或建议精排/矢量路径；明确要求 Figma、设计系统、品牌精确参数或前端/动画工程规格走[路线 B](references/prompt-compilation.md#路线-b交给设计或工程执行的精排规格)。
2. **内密外透双隔离：** 块外用懂行的美术总监人话讲清情绪定位、第一眼钩子、图文关系、裁切与工件状态，绝不甩理论术语或框架黑话；生图代码块内保持 100% 纯净，绝不混入内部权限标签、规则词、色板编号、试排计算或免责语。
3. **成稿后遮住说明做五项轻扫疤盲检：**
   - **脱标品类与情绪分量：** 遮掉文字解释，第一眼能不能立刻认出这是封面、信息图、海报还是 UI 而无串味？画面分量与内容立意是否严丝合缝，光影是否清透干净，主角与字形是否带着活人生命力与呼吸律动，既无浮夸装大也无杂乱粗俗或冷淡死板？
   - **遮字与 80/20 呼吸：** 遮掉文字画面能否独立立住？底盘是否足够干净克制、焦点是否高度收束？
   - **内容与证据零越界：** 锁定文字、数字、单位、来源、成立条件、非因果边界与海报行动字段逐条吻合，无私加虚构。
   - **视觉与版位可执行：** 主副标题层级、语义断行、字族协调、平台安全区与密字贴字分流全部自洽。
   - **交付与工件诚实：** 说明与提示词指向同一张图，交付范围精确匹配所求，工件状态严守下表。

## 返回值

常规完整设计默认交付**简明美术指导说明**（用途与情绪气质、第一眼审美与图文咬合逻辑、关键安全区与当前工件状态）＋ **独立可复制的代码块**（生图提示词、无字底图与贴字表，或精排规格；多图、多比例、多方案各自独立成块）。用户明确只要提示词、只要规格、只要比较或局部差异时只交所需，不附冗余说明。交回 `laohu-writing` 的篇内图另附原文锚点、图内局部关系与必要图注；阶段关键帧按所求交逐帧提示词、制作说明或宿主实图。

## 实际工件状态

适用于普通封面、信息图、海报、关键帧，以及 `laohu-image` / `laohu-motion` 转来的成品请求：

| 本轮实际观察到什么 | 诚实交付与回报口径 |
| --- | --- |
| 只有构想、设计稿、提示词、贴字表或精排规格 | 直接交付可用文字。用户明确索要成图或页面时，首句明说当前为设计稿、实际图片待制作，再交可直接转用的提示词或规格。 |
| 有调用准备、旧参考或工具失败 | 按授权继续或给可用替代设计，严格区分旧参考与本轮新工件，具体说明缺口在工具、参数还是权限。 |
| 当轮获授权宿主返回可访问的图片、渲染文件或页面 | 原生呈现工件或给出真实定位；实际读取文件或回执后再报告尺寸与结果，并区分生成成功与内容验收。 |
| 已实看当前真实工件 | 只报告实际核对过的文字、构图、色彩、裁切、清晰度或交互状态；未核的终端与平台保留待检，绝不用提示词、临时画布或附件名冒充已出图或缩图已通过。 |

## 审图诊断与实图四维反查

无论用户发来已有封面、草图或候选图求诊断改稿，还是刚拿到生图工具返回的真实成图发现偏差，都**先实看当前真实像素**（仅有文字设计稿时只做纸面方案评审，绝不假称缩图已通过），绝不给零散的客套润色意见，也绝不靠往提示词里狂堆形容词硬改。按以下四个断层从上到下锁定**最早失效的 1–2 个根因**：

1. **画风与情绪定位断层：** 整体塑料廉价、色调灰脏闷堵、风格跑偏或题材串味 → 先改开篇媒介材质基因与光色气候，不在细枝末节打补丁；
2. **构图骨架与主次断层：** 多焦点互掐、缩图糊成一团、裁切安全区出界或字图两张皮 → 先砍多余元素、扩大干净素底静区、拉开主次面积差与视线路径；
3. **物理细节与字形/字量断层：** 主角假笑扭曲、光影发平、景别偏远、字形单薄像后期字幕或僵硬如机械斜切，或密字小图笔画粘连错乱 → 把空洞抽象词替换为具体景别、光向色温、自然微动作与有机呼吸字骨，密字精确数据直接切文字密度红绿灯改无字素净底图＋精确贴字；
4. **提示词编码与参考图污染断层：** 模型漏读核心主体、顺手乱加杂字水印，或把旧参考图的灰脏底色与旧文字串了进来 → 调整语序把核心主体与锁定文案提前、收紧正向洁净收束，或把污染源旧图移出视觉参考通道。

查明最早断点后，**冻结其余已经成立的画面资产**，只改受影响处及直接依赖，给出直白可执行的最小改法或差异化修改提示词；若仅要求正式质量比较或人类标尺评估，按 [评估与验证协议](../../../docs/governance/evaluation-protocol.md) 执行。
