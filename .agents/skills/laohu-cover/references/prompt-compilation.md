# 生图提示词与精排制作规格

由[主文第四步](../SKILL.md#第四步双轨编译与陌生观者自检)读取，依据**谁来执行以及目标媒介真能落实什么**，把视觉方案编译成可直接粘贴的中文生图正文（路线 A），或可交接给设计师与工程师的精确规格（路线 B）。前置审美与信息决策不全时先修设计，绝不把未决矛盾塞进最终文本。

## 双轨路线选择

| 路线 | 采用条件 | 本轮交付 |
| --- | --- | --- |
| **A · AI 生图、视觉探索与图像编辑** | 默认路线：自媒体封面、海报、轻文字信息图、关键帧方向预览。 | 纯净自然中文可见画面描述；每张图、每比例或每帧独立成块。用户指定其他语言照办，锁定文案保持原语言。 |
| **B · 可编辑精排、矢量与工程规格** | 用户明确要求 Figma 等可编辑排版、品牌设计系统精确字族/色值/坐标、确认密字与精确图表走矢量分层，或交付前端/动画工程规格。 | 仅展开接收方真能消费的精确坐标系、字体与真字重、RGB 色值、图层与组件规范；用户锁定值照录。 |

用户给出作品方向与短文案仍走 A；若目标仍是生图却锁定了个别精确色值，照录锁定值并标明生图复核，不将整份升成 B。复杂文字提出分层建议后，仍沿用户当前已选路线交付，确认后才切换。关键帧可按需同时交付 A 成像正文与独立工程交接；已核准实图帧绝不重写提示词，具体逐帧契约见[制作参考与交接](production-reference-handoff.md)。

## 路线 A：编成能直接粘贴的成像正文

**核心编译铁律：灵魂与筋骨由我们定方向，表皮微操放手交由前沿生图模型自由发挥；一切抽象情绪与审美判断，必须无损转译为模型直接能画出来的物理画面语言。** 现代生图模型具备极强的构图规划与字体审美，把提示词写成像素坐标表会捆死灵气，而把高级感、含金量、氛围感拉满、有张力这类抽象评价词照搬进提示词，模型同样听不懂、只会滑回塑料合成风。

- **自然导演简报（不设机械死字数牢笼）：** 按 **3–5 个自然呼吸段**精炼聚焦地口述画面——只说透真实媒介基因、景别机位与核心主体动作、逐字锁定文案与契合情绪的书体表现、真实光向材质与纯净边界，绝不写方括号模板标签、不重复铺陈同一底面、不做像素坐标或逐行断行微操；只在真正影响构图的物理安全核与避让关系处给空间方向，把具体字形微调与留白呼吸交给生图模型自然生长。信息图底图与 UI 关键帧按空间复杂程度自然展开分区与避让效果。
- **参考图自然指代切割：** **提示词正文中不要硬编码 `.png` 等本地参考文件名**（把附件挂载与禁用边界收拢在块外的出图输入卡中），保证纯文字无图工具也能直接粘贴；实际携带参考图出图时，正文用清晰自然语言切清**严格沿用参考图中的哪项可见特征**（如人物面部特征与发型、某件特定器物轮廓）与**本张图明确改变哪些要素**（姿态、光向、场景或文案），防止多图串脸、串背景或把旧图里的文字带进新图。

以下四拍用于检查每段正向中文画面描述是否抓在杠杆上（不照抄拍名，不涉及项自然省略，媒介、色光与字形一律从当前题材自身生长）：

1. **画幅、电影/美术级媒介基因与戏剧光色气候：** 开篇一句话前置定死比例、真实镜头与媒介基因（如 35mm 电影胶片实拍近景、28mm 广角电影动态抓拍、纯正平视建筑移轴摄影、哑光纸媒编辑插画、精密暗房界面渲染等，锁死顶级摄影/美术含金量防塑料图库风），交代清透高对比的整体色域基调；需要纵横建筑线条笔直或正视文字不畸变时锁纯正平视/90° 俯拍，避免微仰与笔直轴线冲突。
2. **戏剧视觉奇观、景别机位与趋近型高电压瞬间：** 把充分笔墨还给底图本身——用模型可直接渲染的**具体景别（极具临场感的近景特写/动态中近景/宏大空间纵深）、机位角度、前景/中景/背景层次与光学氛围（如光束微尘、静水倒影、落日逆光轮廓光、高反差明暗切割）**写清核心主体与退隐背景；写清人物极富感染力的真实瞬间神态、动作、眼神落点与利落穿搭，写清物件的无标志极简材质外观（避免模型顺手画出真实科技品牌 Logo）与平台安全区可见空间。知识图按真实拓扑写明逐区形态与干净留白区。
3. **锁定原文、定制字标骨相与破盒子空间穿插（按品类严格分轨）：**
   - 用清晰引号标出逐字原文，并**明确写出准确的语义分行切分**（如第一行与第二行各自包含哪些字，避免写模糊的两到三层导致模型拆断词组）；文字坚持**高亮度清透纯色**弹出屏幕，绝不使用浑浊脏渐变，也绝不叠加笨重 3D 塑料挤出浮雕或易脏化边缘的强立体石雕厚影；
   - **自媒体信息流封面**主动打破上下/左右死板隔离盒：
     - **情绪与电影感封面**大胆让核心大字撑满画幅大半宽幅，按构图启用**三层前后穿插**（背景光影 → 横跨宽幅的高亮度大字 → 前景人物发丝、肩线或道具轻盈压在文字底边/侧边前方，同时保证每个汉字的关键笔画 100% 清晰完整可辨）；字形写出定制主视觉字标骨相（如毛笔笔刷劲势、厚实楷体或带干刷飞白挥洒感的行草展示字标，自然弧度、波浪起伏与分明粗细顿挫，且清晰易认绝不糊笔）；若搭配 1–2 处轻量互动装饰（手绘微图标、极简贴纸、灵光短芒或干刷划重点），写清它与人物视线/手势或文字转角的具体交互位置与融入画面的手绘纯色质感；
     - **极简建筑、沉静人文或理性封面**采用博物馆海报级的纯平面印刷质感（零多余投影与浮雕），用高反差定制现代雕版宋体或精炼几何展示体配合悬殊大小节奏立住静气，并让文字与斜向光束保持清晰错位互不冲切；
   - **信息图、UI 与静谧作品海报**保持各自透明清晰阅读字、精密功能字或诗意骨力书体边界，绝不把信息流展示字风或装饰贴纸串味带入；所有品类均把像素坐标微操放手交由生图模型自然发挥。
4. **真实光影材质与纯净正向收束：** 写出具体光源方向、色温、软硬光质（如 2900K 暖钨丝锥形光、6500K 冷白北向天光、落日黄金逆光轮廓）与可触摸的真实肌理（如胶片微颗粒、模板清水混凝土气孔、自然皮肤纹理、哑光织物），确保遮掉全部文字底图依然值 95 分。用一句正向画面语言收束纯净边界（画面通透纯净，除上述锁定文案外无其他多余文字、边框或水印），不堆叠长串负面禁令清单。

**块内纯净防火墙（交稿前必回读）：** 凡不改变画面成像的内部管理词、权重术语、理论名、流程状态与试排说明（如文字权限、锁定、获准编辑、第一文字层级、举证职责、非实证概念表达、360px 试排、内部编号、待实测待核验），以及下游模型无法渲染的抽象评价词与心理点评（如高级感满满、氛围感拉满、情绪价值十足、极具含金量），一律清出代码块——前者放回块外给人类看的美术说明，后者全部改写为可见物理细节。用户明确要画在图上的字原样保留。只要提示词时省略整份块外说明；需提示工具限制或尚未出图时，用一句自然人话写在代码块外。

### 文字密度红绿灯：复杂中文、多数据与精确图表的稳妥分流

做科普或解释类信息图时，**先压出最终上图短稿再写提示词**：删掉两处同义重复与能移到图外的解释话，示意界面只画识别轮廓、不填多余假条目，删掉一项文字连同槽位一起删掉。逐项保真的数表与锁定原文完整保留。判灯不只看总字数，更看**最小字块占画幅的比例与繁密笔画汉字在小图区的粘连风险**——即便总字数不多，只要落在偏小区块且含繁密笔画或精确多组数字/单位对应，同样走黄/红灯。

- **绿灯（轻文字直出）：** 短主标题 + 副标题，或仅约 3–6 个极简短标签且无复杂小数，可直接用 A 路线中文生图并提醒成图逐字核对。
- **黄/红灯（密字、多组精确数据、严格字族）：** 逐字零误差优先于一次出图便利！主动告知直出风险并提供两条稳妥落地路：
  1. **无字素净留白底图提示词 ＋ 逐行精确贴字表（AI 辅助最稳路线）：** 底图代码块只画高级视觉隐喻、材质光色、整体版面呼吸与干净平整的托字留白区；**凡需后期精准贴字、画真比例数据条或对齐坐标的区域，一律保持素净无字留白，绝不让 AI 预画零刻度基准线、标尺底纹、成排引出线或刚性空白小胶囊框**（避免 AI 条件反射往框线里填乱码字，也杜绝后期叠条对不准位）。紧接着另给一块精确贴字表，逐行写明**序号、所属区块/锚点、逐字原文（含单位与同测前提）、建议断行、相对字级层级（标题/副题/组标题/数据主值/短注释）与对齐方向**。给出坐标与对称锚点时必须验算中点与像素边距零错位；若已定画布且用户要精确贴字，附字号起点、精确条宽与纵坐标并用最长行验宽；合成后逐列复核中文、数字、小数点、单位与裁切。
  2. **人工精排或矢量/网页路线：** 用户确认采用后切路线 B 输出精确规格，或按需衔接 [laohu-htmlshow](../../laohu-htmlshow/SKILL.md) 交付确切文字、拓扑与显示要求（代码排字仍须实查中文字体回退、换行与导出）。若用户仍坚持试 AI 直出，沿其要求输出并明示错字错数复核点。

## 路线 B：交给设计或工程执行的精排规格

只展开当前接收方真正需要的字段，明确区分用户锁定值、设计目标值与待实排核验项。所有坐标采用统一原点与单位（归一比例标明基准，像素标明所属画布或视口）；跨比例逐版重算，不拿旧坐标套新画布。

| 规格字段 | 可直接执行的内容 |
| --- | --- |
| 画幅、用途与观看条件 | 目标画布或视口尺寸、显示情境、主要任务及安全裁切来源。 |
| 情绪气质与美学基线 | 本图情感定调、80/20 秩序与视觉焦点比例、光色材质及参考取用边界（无参考省略）。 |
| 逐字文案与权限绑定 | 主副标题、短标签、关系词、数值、单位、来源与图注，逐项绑定区块或组件并标清锁定边界。 |
| 图文分工与信息拓扑 | 第一落点与视线路径、视觉隐喻映射、逐区对象/状态/边与成立条件、图例语义及宏观到局部归属。 |
| 网格、坐标与容量预算 | 各区与组件的 `x/y/w/h` 或网格约束、文字安全宽、组距、系列共用锚点与页码开关、长文与节点容量核算。 |
| 排印规格 | 完整 family 名、真实字重或受支持变量轴、显示/源图字号、行距、字距、精确语义断行与缺字回退（取值见[版面与中文排印](layout-typography.md)）。 |
| 角色色、材质与强调 | 精确颜色名称与目标 RGB、邻接底色与面积占比、图表一致编码、具体强调参数（不以内部编号代替实际数值，取值见[视觉情绪、层级与强调](visual-hierarchy.md)）。 |
| 裁切、图层与工程交接 | 安全核与遮挡禁区、底图/文字/图表/可动部件分层、透明与 alpha 目标、多状态共用与差分组件；关键帧另按[逐帧制作说明](production-reference-handoff.md#逐帧制作说明的唯一格式)执行。 |

系列多页、多比例与互斥候选各自完整独立；单项局部修改沿用其余已定值并只复核直接依赖。未实排或未实看时，参数按目标回报，状态口径遵循[实际工件状态](../SKILL.md#实际工件状态)。
