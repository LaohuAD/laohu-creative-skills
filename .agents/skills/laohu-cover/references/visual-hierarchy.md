# 视觉层级与引导

层级让重要内容先到眼前；每个视觉信号都要把观看送向一个有意义的下一处。

## 何时读取

当主文第三、五至八步要定第一落点、后续路径、文字/图像职责，或需处理焦点竞争、复杂背景、色彩与视觉信号时，带入用途、显示条件、材料锚点、锁定文字和证据边界。本 Reference 返回层级、颜色角色、强调动作和复核视口。字号和字体细规格读[版面与中文排印](layout-typography.md)，事实关系与量值/类别编码读[图形关系与连线](relationship-diagrams.md)。

## 先选第一落点

信息流封面用材料中的进展、动作、差异、体验或结果确定观看理由，再排“第一落点 → 支撑关系 → 后续阅读”。完整主标题为第一文字层级，锁定副标题清楚居第二层，可按原文语义将受众与观看所得分组。视觉注意可以先落在图像、人物、对象、动作、标题或它们的关系上，随后应抵达完整标题的承诺。第一落点如何配合传播用途见[自媒体专项](../skills/laohu-cover-social/SKILL.md)。

| 由什么承接观看任务 | 第一落点与后续 |
|---|---|
| 标题给出主题、具体动作、问题、判断或结果 | 突出完整标题，后接对象、证据或图形解释，避免只重复受众/目录。 |
| 重点结论或观点需要展开 | 标题承接结论，后续给关系、解释、证据和成立条件。 |
| 对象、作品或结果是理解标题所必需 | 可从图像开始，以邻近、轮廓、动作、视线或标注进入标题。 |
| 人物身份、表情或动作承担内容 | 用可辨身份与动作作入口或支撑，文字接住人物和主题的关系。 |
| 知识图要比较、查找或追踪步骤 | 标题引入命题；多个同等入口按共同尺度、分组或顺序组织，保留关系、条件和可读正文。 |
| 发布、代表或行动类海报 | 先使主题、作品或对象可辨，后接该用途必要信息；实际需行动时才组织行动字段。 |

缩小后入口、材料关系或读序不清，从面积、位置、明暗、邻接、清晰度和方向定位问题，只改直接冲突。

## 选择强调通道

**可读性与视觉张力各自检查。** 文字主次不清先核字级、区域容量和真字重；短标题已可读但缺张力时，再查字形轮廓、轴线、硬影、疏密、前后关系或背景竞争。仅一处重点时可用色、字重、底形或位置。文字遇繁忙背景，优先移到稳定处或增底板，需要时试描边/柔影。平行角色用一致信号，文字强调色与数据角色分别选择。实际强度从面积、对比、近景、轴线、距离和动作中可见，多个信号可以分工。

| 任务与文字气质 | 可组合的真实字体起点 | 失去可读性时 |
|---|---|---|
| 知识/传播题材的短封面，需要清楚有分量 | Noto Sans SC wght 900 或 Source Han Sans SC Heavy；副标题可同族 500–700，另用字级、底形或位置分层。 | 字腔粘连改 Noto Sans SC 700 或 Source Han Sans SC Bold，并扩大文字区。 |
| 密集说明、数据、条件或来源 | Noto Sans SC wght 700 标题/400 正文，或 Source Han Sans SC Bold/Heavy 标题/Regular 正文。 | 说明受装饰、描边或字重所累时试 400/500 阅读档并加容量。 |
| 故事、艺术或出版的短标题 | Source Han Serif SC Medium/SemiBold，说明可配 Source Han Sans SC Regular。 | 小尺寸衬线断裂或字腔粘连时试 Source Han Sans SC Bold/Medium。 |
| 短标题需要手写温度 | LXGW WenKai Regular/Bold 仅用于短标题，正文、节点和注释用 Noto Sans SC 或 Source Han Sans SC。 | 专名难辨时查覆盖，再换清楚的阅读字族。 |

IBM Carbon 的 productive 和 expressive 字体角色启发按阅读与展示职责拆选。具体字重、断行与排印见[版面与中文排印](layout-typography.md)。

## 本地角色色板起点（CP01–CP12）

先定入口及后续阅读，再保锁定色、证据和数据编码。BG、P、S、E、G 按职责拆选，也可跨组或采用本作独立值。CP01–CP08 采用 IBM Carbon 色阶原值，角色配对由本地设计；CP09–CP12 是本地试配，不代表来源取样。

### 按入口和邻接关系选择颜色

相邻颜色差影响注意，同色可表同组，文字与底面的亮度差帮助识字。先辨所需职责，再选关系。

| 条件 | 色彩关系与落地选择 |
|---|---|
| 整体需要统一，层级已经能由字级、位置或空间承担 | 可用同色系；焦点用明度或彩度拉开。同组同义角色沿用同色，不为区分而虚构类别。 |
| 信息需要安静清楚，且只有一个重点需要被指出 | 可用中性底加单一强调色；强调色只指出该重点，不借给类别图例。 |
| 需要低冲突、连贯的编辑或主题表现 | 可用邻近色；层级再由明度、位置或字重承担，并在实际邻接中判断是否清楚。 |
| 冷暖对照符合目标，而且需要拉开入口与承托面或相邻组 | 并置实际候选色，明确哪处偏冷、哪处偏暖，并对照它们各自邻接的颜色；冷暖不固定代表前景/背景或强弱。 |
| 两组需要快速区分，且没有既有类别编码 | 可试互补或分裂互补关系，先给主色和对照色明确职责与面积，再检查它们与各自邻色是否都清楚；有既有编码时保留原映射，不用装饰对照色替代。 |
| 短标题需要强表现，且材料适合更鲜明的入口 | 可试较远色相差（包括近互补），并用稳定的明暗字底或轮廓把标题与底色分开；正文不使用明度相近的彩色字相互振荡。 |
| 数值或等级有真实顺序 | 可选顺序色关系表现由低到高或由前到后的次序；不要用于无序类别。 |
| 数据有明确且有意义的中点，两端表示相对中点的不同方向 | 可选发散色关系，把中点与两端的职责标清；没有实际中点含义时不造发散关系。 |
| 内容是无序的真实类别 | 可选分类色，但同一类别保持一致映射，并用标签、形状或图例辅助识别；不固定颜色数、具体色值，也不让装饰色制造类别。 |

收到“颜色偏淡/不明显”反馈，先辨当前证据：可可靠取色则记实值及来源；只能看图则判断可见邻接；只有提示词时改角色、邻接或面积目标，仍可完成能做的提示词修订。只有诊断依赖成图时才补取样张。按字底、角色区分和注意入口分别处理：文字难读改字色、底色或位置；角色彼此难辨才调色相、彩度、亮度或色面，保留真实同色组；颜色清楚而入口未成立则改布局或强调职责。不设普遍色差阈值。

**复核与导出。** WCAG 2.2 成功准则 1.4.3 的参考值为普通文字 4.5:1、标准定义的大号文字 3:1，按最终呈现字号与字重而非源图像素判断。CP 保守按 4.5:1 查看，不借大字例外放宽。按 sRGB 相对亮度公式、以未舍入值对阈值；下表顺序 P/S/E，文字放在组底用 G 栏。CP12 电光青 E 仅作图形，和 BG/G 的平底比为 10.76:1 / 8.51:1。照片、渐变、透明叠加按实际合成像素重算；小字、细笔画和抗锯齿还须在缩略尺寸实看。字底比值不能替代类别辨识、注意或审美检查。

## 强调动作目录（E01–E16）

按阻碍拆选 E 动作，可从不同 FP 或 CP 组合。F 为目标显示尺寸下相关文字角色的字号。表中数值是本地试排点；交给成像模型时写可观察的位置、字形和方向，精确的已锁定值或可设置数值走[编译路线](prompt-compilation.md)。

| ID / 触发条件 | 动作与可试规格 | 提示词操作关键词 | 不适用或停止条件 |
|---|---|---|---|
| E01 层级不清、但角色容量足够 | 按当前用途调整一个角色的字号；短封面主标题沿用排印基线步长，信息流副标题按版面排印的主标题相对试排范围，知识图副标题/主结论按各自正文或结论角色调整。 | 写明角色、字号变化和保持不变的其他决定；缩到目标宽度复看第一与第二落点。 | 锁定文案容不下时先调区域或拆图；不压行距和字腔换层级。 |
| E02 字号调整不合适，但字体有真实相邻字重 | 正文从所选阅读家族真实可用的 Regular 起；标题按当前已核实/实际加载 family 的真实档位逐档试。FP/LD 是可拆选起点，不是封闭白名单；目标字族或样式未实装核验时记录期望 family/档位并标待落实，不伪造可用档。 | 写明 family、角色、原样式→目标样式；汉字不伪造粗体/斜体。 | 所选 family 没有该档或运行环境尚未核实，就换实际可用 family/档位，或调整字号/位置；不能合成档冒充字体事实，也不能将目标设定写成已加载。 |

| E05 文字必须反白并处于暗底 | 将已有文字设为浅色，仅铺在稳定暗底；在最终暗底和组底分别核对 P/S/E 的对比。 | 写明浅色 RGB、具体暗底 RGB 和文字角色；标注纯平或合成后状态。 | 文字跨越照片明暗变化而对比不稳定时，改位置或加 E06 底板；不能只写“反白”。 |
| E06 复杂背景上文字必须留在原区域 | 加不透明或明确给出不透明度的衬底。起试水平内边距 0.30F、垂直 0.18F；每次改 0.05F。 | 指定底板 RGB、透明度、上下左右 padding 与文字组；成图后测真实像素。 | 半透明结果须重新计算；底板若遮住证据或造成错误分组，改文字位置。 |
| E07 短标题要形成有轮廓分量的展示字，或短字在目标底色上确实难分 | **表达分支：**展示字可从 0.04F 描边起试，每次加 0.02F，先比较至 0.10F；用描边与字面共同构成标题轮廓。**阅读补救分支：**从 0.02F 起、每次加 0.01F，先试至 0.05F，优先确认能否改位置/底板。两支均在目标尺寸检查中文笔画和字腔。 | 表达：指定标题字面、内/外描边、对照颜色与描边范围，作为展示字轮廓；补救：指定具体背景、描边宽度与分离作用。 | 正文小字、复杂笔画、字腔闭塞、轮廓变成独立焦点时停止；表达目标与字形不合则换字族/形状机制，不把加粗描边当通用强表现。 |
| E08 文字要形成可见层次/动势，或底图确有分离问题 | **表达分支：**短标题可试硬影，位移从 0.08F 起、每次 0.04F，比较至 0.16F；模糊从 0–0.03F，不透明度试 70–100%，明确投影方向与颜色，让影子成为字形造型的一部分。**阅读补救分支：**轻分离从偏移 0.04F、模糊 0.10F、黑色 20% 不透明度起试；之后模糊每次加 0.05F、不透明度每次加 5%，优先尝试移字或底板。 | 表达：明确硬影方向、offset/blur/opacity/RGB，写出它与标题字形/底形的关系；补救：说明分离对象、实际底色和轻影规格。 | 硬影方向与图像动作打架、产生第二个字形/阅读顺序、脏边或堵字腔时减弱/换机制；补救影形成重影或缩图不可读时去掉并改位置/底板。不得把一种分支套给所有封面。 |
| E09 有效信息被邻近元素争抢，空间可重排 | 把当前重点放入较干净区域并扩大局部隔离；同组、跨组空隙直接使用版面排印的现存组距及其步长。 | 指定对象起点/终点与保留区；每轮只移动一组。 | 不增设无内容空白栏，不把文字位置变成未支持的顺序或因果暗示。 |
| E10 标题和证据图的面积竞争不合适 | 在可测版面中固定一方，另一方文字盒或图像主体盒面积按画布面积每次改 5 个百分点作 A/B；记录实际比例。 | 写明“保持 A 不变，B 面积 +/−5 个百分点”、锚点和裁切保护。 | 这只是本地比较方法，不存在通用图文面积比例；若画面不能稳定量盒，标记估计值，不写成标准。 |
| E11 需要沿用现有文字而不新增标记 | 在既有关键词下方加一条线；线宽 0.03F、离字 0.12F 起，线宽每次 0.01F、间距每次 0.04F。 | 指定原有词组、线宽/F、间距/F、颜色 RGB；文字和标点不变。 | 不能让线看起来像删除线、链接或图表坐标；小字下划线合并时移除。 |
| E12 一个现存区域需要被看作独立组 | 用括框/角括线包住整个既有文字或图形组；线宽 0.025F、内容净距 0.20F，每次调整 0.05F。 | 指定包围对象、是否闭合、线宽/F、四边净距/F；不写额外标签。 | 材料没有组关系或框线会暗示节点/数据关系时不用；不要与 E06 底板重复包围。 |
| E13 需要圈出已有内容以便定位 | 手绘圈/椭圆描边起试 0.025F，距对象 0.15F，每次改 0.05F；只圈现存对象。 | 指定闭合形状、颜色、线宽/F、间距/F 和目标对象。 | 不能新增圈号、感叹号或解释语；可能误读为数据圈选、勾选状态或错误更正时不用。 |
| E14 原材料已有序号且它本身需醒目 | 把已有序号放入徽章，徽章直径/高度先试 1.3F，每次改 0.1F；数字本身逐字保持。 | 指定“使用源文已有序号”、徽章尺寸/F、颜色 RGB 与附着对象。 | 不虚构 01、排名、步骤或优先级；非序列含义却会被读成顺序时不用徽章。 |
| E15 多个项目确实等价，需要建立稳定重复线索 | 对同层级项目重复同一颜色/字重/形状/尺寸信号；同类的间距和标记完全一致。 | 指定被重复的一个既有信号和项目集合，其他组保持不同。 | 单一项目不重复；不能把不等价对象包进同一组，也不能重复多个强调色形成噪声。 |
| E16 需要把视线导向标题/结论/说明，或表达材料已确认的对象关系 | **导视分支：**leader 线、无关系含义的指向箭头、人物视线/手势可指向明确文字重点；让线条/样式与事实关系边清楚区分。**关系分支：**因果、顺序、组成等箭头只按[图形关系与连线](relationship-diagrams.md)及材料证据绘制。 | 导视：写明起点、目标文字、线宽/F、终点留白和“阅读导向/非事实关系”；关系箭头：写明关系词并引用对应材料。 | 导视不得穿过节点或被误读为因果/步骤；关系箭头不能只为造动势而添加；视线目标含糊或两类线撞在一起时改用位置、留白或形状分组。 |

**兼容检查。** E04/E05 文字角色不能混同类别编码；E06 底板和 E12 框常解决同一分组问题；E07/E08 区分展示和阅读分离；E11–E14 保留原字、数字和标点。授权设计范围内可选圈、框、星芒或导视形态；有用户禁项则沿用。图形本身也可能被读成新顺序、事实或类别，须有明确目标/语义。新增文字、数字和事实仍由相应权限决定。

**返还字段。** 当前问题、已选 E 动作、作用对象、职责和方向、所需的实际幅度和互斥检查。记目标显示宽度、缩略、平底/合成背景和原文/图例复核。无精控需求时省精确 family、F 比例、RGB、坐标；手工检验语放在效果说明或制作说明。

## 让学习图的信号帮读者定位

Mayer 的多媒体学习原则在解释图中用于删去无关素材（连贯）、明确提示结构/顺序（信号提示）、把说明贴近对应图形（空间邻近）。导视只在标题、图例或近邻标签仍不足以理解时补；区分阅读线和事实边。

先按[关系拓扑](relationship-diagrams.md)建主关系、分支或包含，按“标题 → 主关系 → 区内要点/条件 → 解释”安排位置、对齐、留白和标签。可先在弱样式草图中验证读法，再恢复有职责的边缘与色面。相同语义角色共用字重、基线、线宽和图标笔画；嵌套框的内外圆角、边距和间隔协调。符号保持清楚轮廓与负形，线宽与邻近文字相称。必须编码时给文字或图例，装饰与气质色可独立，避免暗示无依据的类别、顺序、数量或因果。图标可辅助识别，不能独自代替关系；框可服务包含、模块或字底，不把静图做成假的界面。概念示意保持解释身份和实际已知边界。

## 让人物、引导线与光色指向内容

只把明确瞄向对象的眼神、手势或线条记录为“可见起点 → 标题、证据、结果或行动入口”。直视观者可建立接触，朝向画外可表现动作或悬念。留下终点空间，避免线条穿字、遮证据、指装饰或误成事实边；优先试位置、朝向与留白，仍不足再加线或光。光影突出先要辨认的动作、形状或证据，保住文字分离。无关纹理、道具或光效减细节/对比/面积；背景是真实证据时保留并重排文字。插画、象征或解释性示意依事实边界成像。

**方法出处。** Kelley Gordon（Nielsen Norman Group，2020）用于视觉层级、尺度、对比与平衡；IBM Carbon Design System *Typography* 用于阅读与展示角色；Mayer，《The Cambridge Handbook of Multimedia Learning》第 2 版（2014）第 12 章用于教学图的取舍、信号与邻近。实际传播效果需相应媒介证据。
