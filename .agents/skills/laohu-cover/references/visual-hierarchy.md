# 视觉情绪、层级与强调

**美感先引目光，秩序再定主次；每一个视觉信号都该把情绪和视线送往同一个焦点。**

当主文需要裁决焦点竞争、把标题动词转为具体画面关系、设计精细情绪色彩与对比度、拆开未定视觉变量、执行单维度局部修改的依赖复核，或落实精排强调动作时读取。常规清晰轻文字 AI 封面不强读；字体与容量细则归[版面与中文排印](layout-typography.md)，复杂拓扑与连线归[图形关系与连线](relationship-diagrams.md)，理论与案例出处归[SOURCES.md](../SOURCES.md)。

## 先选第一落点

人眼在前 50 毫秒先用直觉感受画面情绪与主焦点，再顺着清晰路径进入阅读。信息流封面先锁定材料里的具体反差或证据瞬间，再安排第一落点 → 支撑关系 → 后续阅读；完整主标题恒为第一文字层级、锁定副标题清晰居第二层，但第一视觉注意可以先落在人物动作、戏剧性物件、强光色切面或字图整体关系上，随后顺畅汇入完整标题。

| 观看任务 | 第一落点与后续视线路径 |
| --- | --- |
| 标题直指核心痛点、判断或反转 | 突出带情绪性格的完整主标题，后接支撑证据、反差物件或结构解释。 |
| 实物、对比结果或作品本身最抓眼 | 由强轮廓主视觉或对比画面先截停目光，借位置邻近、光向、视线或轮廓咬合引入完整标题。 |
| 人物表情、手势或动作承担情绪 | 人物可辨姿态与明确动作指向直连标题或证据，文字立刻接住人物与主题的因果/态度关系。 |
| 信息图比较、查找或追踪逻辑 | 标题与极具辨识度的主隐喻骨架先抓眼，同级入口用一致尺度与清晰形态分开，条件贴近所指。 |
| 作品、品牌或活动海报 | 先以独特气韵和字图共生立住主题识别，再露真实必要信息；仅真实行动任务才引向行动入口。 |

缩略后入口发散或主次模糊时，按**面积占比 → 位置重心 → 明暗反差 → 边缘清晰度 → 视线方向**五项定位，只修直接冲突，不盲目全图加粗加亮。

## 标题动词与七种图文空间接合

把标题里的核心动作变成看得见的画面关系，避免呆板直译和画外硬解释：

| 标题动词或表达需求 | 正向可见画面动作 | 失配时切换 |
| --- | --- | --- |
| **分析 / 解析 / 拆解** | 掀开表层、拉开展开层片、切开剖面、分离已有组件，让原本藏在里面的结构或线索一眼可见。 | 只剩支离破碎看不清原物时，换整体加局部放大揭示；组合成新物归下行。 |
| **生成 / 创作 / 转化** | 同屏给输入与产出的鲜明状态差或流变轨迹，让人一眼看清怎么变、变出了什么。 | 材料只讲旧物剖析时切回拆解；结果未知时用清晰概念示意。 |
| **学习 / 理解 / 避坑** | 关键物件与近邻精简标注、对照错与对或清楚观察视角并置，一眼知道下一步看哪。 | 不编造未证实的学习成效数字；真意是拆解或转化时按对应动作画。 |
| **视觉隐喻 / 情绪强化** | 取与标题共享可见物理属性的日常物件直白演活关系，搭配光影和字形冲劲放大情绪。 | 离开画外解释就猜不出含义时，换成更直接的真实对象或降作氛围背景。 |

**七种图文空间接合方式（按任务与情绪选用，不强求每张都叠字）：**
1. **并置对照**：标题与主图/证据分占相邻区、共享对齐边，互不遮挡，适合强对比与严谨核验。
2. **上下分带**：先读题带再看主图（或反之），节奏利落，适合信息图与多平台裁切兼容。
3. **稳定区叠字**：照片或材质有大块干净暗区或亮区时直接压字，写清字盒与主体避让边界。
4. **轮廓咬合 / 避让**：文字贴着主体外轮廓起伏排列或留在外侧留白呼吸区，保持极佳一体感。
5. **字图前后穿插**：主体局部越过字块居前，大字落中层咬动势，保住关键笔画一眼可辨。
6. **纯文字主角**：标题自带极强张力时，靠字形骨相、词眼大小差、色面与纸墨质感撑起整幅。
7. **场景实物文字**：招牌、纸页批注、屏幕界面等按真实透视、材质和受光生长，与版面标题严格分层。

## 情绪色彩四维调配与高对比参考色板

颜色传达情绪的核心顺序是：**先用明度定轻重氛围，再用饱和度定唤醒烈度，接着用面积比例定呼吸秩序（约八成克制底盘托两成情绪焦点），最后用冷暖关系与自然生态联觉选高级耐看色**（如暖棉纸、松烟墨、青石蓝、陶土橙、琥珀金、哑光炭灰），坚决避开刺眼廉价荧光撞色与浑浊脏色。

| 目标情绪与结构需求 | 色彩关系落法 | 护栏 |
| --- | --- | --- |
| **清透愉悦 / 舒展阅读** | 高明度暖白或清浅中性底 + 墨黑/深炭主字 + 一处鲜亮清透点睛色（如陶土红、信号红、松绿或明澄蓝）。 | 唯一点睛色留给最核心词眼或焦点，绝不挪去凑装饰。 |
| **锋利破局 / 强唤醒冲击** | 强冷暖撞色或深沉暗底配高纯度亮色主角（明黄、炽橙、信号红或冷白），辅以清晰明暗切面。 | 正文小字绝不用明度相近的高彩字互撞造成视觉振荡。 |
| **精密专注 / 电影沉稳** | 低明度哑光深炭或深海军蓝沉底 + 细腻冷白/象牙白文字 + 极克制单色高光点题（金、青或珊瑚）。 | 深底忌一片死黑，靠微阶表面明度与局部光感撑出高级层次。 |
| **低冲突叙事 / 编辑格调** | 邻近色或同色系明度阶梯铺开柔和气氛，靠字级、留白、光影和材质拉出第一落点。 | 同义同组共用一色，不为丰富凭空制造假分类。 |
| **数据与多阶段信息编码** | 有序量值用**顺序色**，有真实中点两端分化用**发散色**，无序真类别用**一眼彼此分清的分类色**。 | 分类色必须兼顾彼此可辨（不止字底合格），并配文字、形状或图例共同识别。 |

**对比度核验口径：** 精排与可编辑路线遵循 WCAG 2.2（普通文字 4.5:1、大字 3:1；保守按 4.5:1 核平底 sRGB 相对亮度）；照片、渐变与透明叠加须按最终合成像素复核，未实测标待检。字底对比合格不等于审美高级，更不替代类别互辨。

| 情绪气质与用途 | 背景 BG | 主字 P | 次字 S | 强调 E | 分组底 G | 平底保守对比参考（P/E 对 BG） |
| --- | --- | --- | --- | --- | --- | --- |

## 独立拆选变量与单维度修改的依赖复查

字体、网格、颜色、主视觉与强调通道彼此独立，**绝不绑定成固定套装**。只有未定项会显著改变气质时，才给 2 个差异鲜明的方向供选；用户明确授权或已锁定其余项时直接执行。

**局部单项修改冻结纪律：** 当用户只改一个维度（如把文字换色改成下划线、只改配色偏淡反馈、或只换字族），严格冻结其余全部已定决定，**只复查直接依赖**：
- 换色或收色淡反馈 → 分辨文字难读（调字底对比）、类别难分（调色相/彩度差）还是入口不显（调面积与布局）；只有提示词时直接改目标色与面积，不假称已测像素；
- 换字族 → 只复查字符覆盖、行宽、断行与容量；
- 改网格或标题轴 → 只复查读序、图文避让与裁切安全核；
- 改强调或连线 → 只复查遮挡、图例冲突与关系语义。

## 视觉强调工具箱（按具体阻碍拆选，仅路线 B 精排或成图局部修疤展开参数）

先分清**造张力**与**救可读**：主次不清先调字级与真实字重；已清晰但缺锋芒再调轮廓、轴线、硬影、光影或前后层。常规 AI 生图路线只写自然可见的气质与对比方向，绝不把下表像素比例当成事前微操塞进生图提示词；仅在路线 B 精排或成图单项精确修订时按下方起点给参数（`F` 为目标显示字号，未实排均标设计目标）：

| 触发阻碍 | 精准动作与精排起点 | 停止与防误读边界 |
| --- | --- | --- |
| **层级或字重拉不开** | 扩大单角色字级差，或切换该字族**真实存在的相邻字重档**（不合成假粗/假斜）；短 Latin 标题仅在支持变量 `wdth` 轴时微窄。 | 绝不靠压扁汉字、压缩行距换层级；缺字重改换字族或位置。 |
| **唯一词眼需点亮 / 暗底反白** | 对锁定词眼赋独立强调色 E（平底核 4.5:1），其余守主/次字色；暗底统一换浅色字并在实际暗区核对比。 | 标题强调色不与图表分类色混用；跨明暗杂图时不硬压裸白字。 |
| **繁忙背景保文字清晰** | 优先移到干净负空间；必须留原位时加不透明/半透明衬底（精排起点：左右 `0.30F`、上下 `0.18F` 内边距），合成后再核对比。 | 衬底不得遮住关键证据或制造假分组，不与外括框重复套用。 |
| **短标题造展示分量（描边 / 硬影）** | 展示描边起点 `0.04F–0.10F`（阅读补救 `0.02F–0.05F`）；展示硬影偏移 `0.08F–0.16F`、极低模糊 `0–0.03F`、70–100% 不透明，与主体动势同向（柔影补救偏移 `0.04F`、模糊 `0.10F`、黑 20%）。 | 正文小字禁用描边与硬影；字腔闭塞、脏边或与图像方向打架时立刻撤回换位。 |
| **沿用原文定向标记（下划线 / 括框 / 圈选 / 序号徽章）** | **下划线**：线宽 `0.03F`、离字 `0.12F` 标既有词眼；**括框**：线宽 `0.025F`、净距 `0.20F` 围真实整组；**手绘圈**：`0.025F` 圈现存焦点；**序号徽章**：直径 `1.3F` 仅包原文已有序号。 | 严禁篡改原字或虚构序号；下划线防误读为删除线或链接，括框防误读为数据节点，圈选防误读为报错。 |
| **空间隔离与面积重配** | 删无用装饰、扩大焦点周围呼吸留白，或固定一方将另一方盒面积按 ±5% 步长比对重配。 | 不造无内容空栏，不把纯粹挪位暗示成新因果。 |
| **平行同级统一与导视/关系分离** | 等价并列项重复单一一致信号（字重/色/形）；**导视线与人物目光/手势**明确起点→目标文字重点，外观与事实关系箭头彻底区分。 | 导视线绝不穿字、不遮证据、不被误读为因果或流程；易混淆时改用位置、留白或共边对齐。 |

多媒体学习图的额外护栏：删去无关装饰、明示阅读骨架、把解释贴近所指对象；先在弱样式草图里确认关系顺畅，再叠加有温度的色面、光影与微材质。
