# 视觉层级与引导

层级让重要内容先到眼前；每个视觉信号都要把观看送向一个有意义的下一处。

## 何时读取

当主文第三、五、六、七、八步需要决定文字入口与图像/人物的关系、展示字表现、多个焦点竞争、复杂背景或多个编码互相干扰时读取。输入是观看任务、受众、锁定文字、证据强度、画幅与显示条件。返回整体视觉方向、标题/核心文字入口、支持它的下一层信息、字体角色、所用强调通道、人物/导视目标、背景与媒介职责和整幅复核条件；不接管版面几何与排印数值。

字号、字重、艺术字与阅读字的具体排印起点唯一见 [版面与中文排印](layout-typography.md)；图形颜色若已承担数量或分类编码，则连线与数据视觉规格见 [图形关系与连线](relationship-diagrams.md)。本 Reference 不重复两处的数值表。

## 先选第一落点

有标题或核心文字时，让它作为鲜明的视觉入口和语义锚点；图像、人物和符号可以吸引视线，但要把视线接回标题、结论或其他文字重点。先根据实际材料判断它后面应接什么：

| 当前承诺由什么成立 | 第一落点选择 | 下一层负责什么 |
|---|---|---|
| 标题本身给出主题、问题、判断或结果 | 让完整标题清楚突出 | 对象、证据或图形解释标题里的词义/承诺。 |
| 用户给了重点结论或观点 | 标题后接住该结论 | 说明文字、关系图或证据继续展开，不另起割裂中心。 |
| 对象、作品或结果是理解标题所必需 | 标题仍是语义锚点；对象可承担注意吸引 | 用邻近、轮廓、动作、视线或标注把对象与标题文字连起来。 |
| 人物身份、表情、动作承担主题/情绪/关系 | 人物关键识别或动作可辅助形成焦点 | 标题或其他文字说明人物与内容的关系；不强求人像成为第一入口。 |
| 目标成品是信息流自媒体封面，且有锁定副标题 | 完整主标题为第一落点；副标题以受众、利益或观看所得成为清楚的第二落点 | 可把原句按语义分组为受众标记和价值说明；之后图像再承接主题、证据或情绪。不要默认把副标题缩成底边单行。题材是知识不改变封面用途。 |
| 目标成品是知识讲解图 | 标题引入重点命题，再展开关系、解释与成立条件 | 准确性和正文可读性优先；不要机械套用封面式标语或促点层级。 |
| 内容是步骤、并列比较或多项同等重要信息 | 标题后按任务安排多个同级入口 | 用一致分组、共同尺度或顺序线索维持阅读，正文仍可读。 |

信息流封面即使讲知识，也按封面任务组织；题材不决定媒介。选定标题/核心文字入口后，减少会把图像与文字割裂或引向无关中心的元素。封面可让尺度、明暗、字形、颜色、斜轴、近景、姿态或背景形状等多个信号共同加强标题；知识图可用局部色块、分组、导视线或人物/符号将注意带到标题后的结论与解释。各项可以有不同职责，不要求每次都使用，也不要求每个元素反复指向标题。若缩小后标题、结论或图像关系变得不清，先检查面积、明暗、位置、相邻关系、清晰度和方向，再改实际冲突项。

## 选择强调通道

常规排查可先从字号、字重或位置开始，再看是否需要颜色、衬底、轮廓、线条方向或局部光影；这是查找有效信号的次序，不是封面使用通道的数量上限。封面需要更强表现时，可让不同通道围绕同一中心分工，但每项要指向具体对象、说明阅读/情绪/分离职责、选定力度和空间值，并在目标尺寸复核。用户已锁定色彩、图表使用类别颜色、或文字压在复杂背景时，先保护语义与可读性；知识图/图表还须服从数据、关系和图例，不用效果改变其意义。

| 条件 | 处理 |
|---|---|
| 文字层级不清 | 先调整字号和区域容量；再以真实可用的字重档强化主次。 |
| 只有一项关键词需要提示 | 以少量颜色、字重、底形或位置突出，并保证其语义稳定。 |
| 图表颜色已表达类别或数值 | 标题强调色避开同一编码；类别信息同时配合文字、形状或线型。 |
| 文字落在明暗变化或繁忙图像上，且目标是阅读分离 | 将文字移到较干净区域，或加清楚衬底；描边/柔影作为可选分离手段并复核实际背景。 |
| 短标题需要更强的字形主视觉 | 选与标题语气相合的展示字形、轮廓或硬影；让文字形状参与主题表达，同时保住笔画字腔。 |
| 多个部分确实同等重要 | 使用一致的字级和视觉线索，不硬造唯一焦点。 |

封面表现力度按画面中可见差异的幅度衡量，不按效果或通道数量：轻时用温和的字级、位置或局部对比差建立入口；中等时让尺度差、色块面积、元素距离、方向偏转或动作幅度中的一两项在缩略尺寸清楚可辨；强时可明显扩大这些差异，例如大幅尺度反差、较大的局部对比面积、贴近观者的透视、鲜明斜轴或明显动作。具体幅度可从对应排印/版面或 E 参数起点作内部试排，数量只描述实现方式。这是本地检查分档，不是平台标准；提示词说明足以辨认的实际动作和视觉目标。仅当用户精控、品牌/系列锁定或制作媒介能执行时，才输出 family、RGB、F 比例、坐标等精确数值；普通创意生成不因内部试算而被绑定到这些参数。

**可读性对比和视觉张力分开检查。**字底明暗只回答文字能不能辨认；对比值达标也不会自动产生有力字形或清楚层级。标题已经可读却显得平时，回看字块轴线、字形轮廓、大小与疏密节奏、硬影/描边的形状职责、图字的接触或前后关系，以及背景主体是否争焦。按需要调整这些可见关系，不把盲目加深字色或抬高对比值当作张力的替代方案。完整文字、笔画和字腔始终受保护。

| 任务与文字气质 | 可组合的真实字体起点 | 失去可读性时 |
|---|---|---|
| 知识/传播题材的信息流短封面，要清楚且有分量 | 主标题可试 Noto Sans SC wght 900 或 Source Han Sans SC Heavy；副标题可同族选 500–700，另用字号、底形或位置做第二层。 | 复杂字腔在缩略图粘连就改 Noto Sans SC 700 或 Source Han Sans SC Bold，并扩大文字区；不可把副标题压成脚注。 |
| 知识讲解图含密集说明、数据、条件或来源 | Noto Sans SC wght 700 作标题、400 作正文；也可用 Source Han Sans SC Bold/Heavy 作短标题，Regular 作正文。 | 装饰字形、重描边或过密字重影响节点辨认时回到 400/500 阅读档并增加区域。 |
| 故事、艺术或出版感的短标题 | Source Han Serif SC Medium/SemiBold；说明文字可配 Source Han Sans SC Regular。 | 小尺寸下衬线断裂或字腔粘连时换 Source Han Sans SC Bold/Medium。 |
| 需要手写温度，且标题短、目标尺寸仍易辨 | LXGW WenKai Regular 或 Bold 只承担短标题；正文、节点和注释用 Noto Sans SC 或 Source Han Sans SC 阅读档。 | 复杂专名或小尺寸难辨时检查逐字覆盖，直接切回清楚的阅读字族。 |

这些是从已核实字体目录取出的选择起点，不是封闭类别；可按题材语气、受众、字数、实际字形与缩略可读性拆开组合，不让某个主题自动绑定某个字体。IBM Carbon 用 productive 与 expressive 两类字体角色区分任务型阅读与编辑、营销表达；这里按中文字形和封面职责转成选择条件。具体字号、字重、显示检查和中文断行按 [版面与中文排印](layout-typography.md) 执行，不在这里另设基线。

## 本地角色色板起点（CP01–CP12）

CP 编号只提供可拆选的角色色值，不替你决定整张图该采用什么色彩关系。先从标题、结论、主关系或证据里确定第一注意入口，以及读者接下来要看的支撑信息；再结合用户锁定颜色、品牌、图像证据和数据编码，判断颜色要统一整体、区分相邻角色，还是承担真实类别；最后只按本图实际使用的背景、文字、分组、强调或其他职责选择相应 RGB，不要求把 BG/P/S/E/G 全部填满。精确色值是否写入制作规格/提示词，按用户精控、品牌/系列锁定或制作媒介能落实色值判断；其他创意生成可保留具体配色开放，并按需用色值作内部预检。相同角色可保持同色，气质色面也可以不新增命题；没有现成类别编码，并不等于必须使用中性浅底。

### 按入口和邻接关系选择颜色

先保护用户锁定的品牌色、图像证据及已有数据/类别编码，再按阅读任务选颜色关系。局部颜色与邻接差异会影响注意竞争；同色可作为同组线索；文字与实际底色的明度反差主要帮助读字。这三种作用不能互相替代，也不证明点击效果。下面是本地适配的条件，不是固定调色板；可继续使用其他有材料依据的关系，色数、面积和底色都不预设：

| 条件 | 色彩关系与落地选择 |
|---|---|
| 整体需要统一，层级已经能由字级、位置或空间承担 | 可用同色系；焦点用明度或彩度拉开。同组同义角色沿用同色，不为区分而虚构类别。 |
| 信息需要安静清楚，且只有一个重点需要被指出 | 可用中性底加单一强调色；强调色只指出该重点，不借给类别图例。 |
| 需要低冲突、连贯的编辑或主题表现 | 可用邻近色；层级再由明度、位置或字重承担，并在实际邻接中判断是否清楚。 |
| 冷暖对照符合目标，而且需要拉开入口与承托面或相邻组 | 并置实际候选色，明确哪处偏冷、哪处偏暖，并对照它们各自邻接的颜色；冷暖不固定代表前景/背景或强弱。 |
| 两组需要快速区分，且没有既有类别编码 | 可试互补或分裂互补关系，先给主色和对照色明确职责与面积，再检查它们与各自邻色是否都清楚；有既有编码时保留原映射，不用装饰对照色替代。 |
| 短标题需要强表现，且材料适合更鲜明的入口 | 可试较远色相差（包括近互补），并用稳定的明暗字底或轮廓把标题与底色分开；正文不使用明度相近的彩色字相互振荡。 |
| 数值或等级有真实顺序 | 可选顺序色关系表现由低到高或由前到后的次序；不要用于无序类别。 |
| 数据有明确且有意义的中点，两端表示相对中点的不同方向 | 可选发散色关系，把中点与两端的职责标清；没有实际中点含义时不造发散关系。 |
| 内容是无序的真实类别 | 可选分类色，但同一类别保持一致映射，并用标签、形状或图例辅助识别；不固定颜色数、具体色值，也不让装饰色制造类别。 |

当反馈是“颜色偏淡、不明显或难区分”，先列出现有实际 RGB 和角色，判断问题属于哪一类，再只改相关维度：文字对实际底色读不清，就按最终邻接底色复核并改字色/底色或文字面；需要区分的类别/层级色彼此混在一起，就保留应同色的语义组、调整有必要区分的角色色相/彩度/明度并给出具体候选 RGB，优先重选颜色，再看是否仍需调整色面或布局；若颜色清楚但视线没落到预定入口，回看所选关系是否贴近第一落点并支持后续阅读。复核时分别问：第一落点是否落在预定标题/结论/主关系；文字与各自实际底色是否能读清；需要区分的颜色角色能否在目标尺寸下分辨。普通文字的 4.5:1 是保守的字底参考，只用于内部对比核查，不能证明类别色彼此可辨、全图有焦点或审美通过；最终合成的照片/渐变/透明叠加按实际像素检查。相近色仍可服务同组或整体气质，不设普遍色差阈值，也不全局禁用相似色。

## 让学习图的信号帮读者定位

Richard E. Mayer 的多媒体学习原则用于教学/解释性图，而不能外推成封面点击率公式：

- **连贯（coherence）：**去掉与当前解释无关的文字、图像、符号和装饰，减少读者需要筛选的东西。
- **信号提示（signaling）：**用有限、明确的视觉提示标出结论、结构、顺序或当前关系，让读者知道重要信息在哪里。
- **空间邻近（spatial contiguity）：**把说明文字靠近它解释的图形，避免读者在相隔区域间来回寻找。

知识图中的结构/导视信号先说明它提示哪项关系或阅读位置；若标题、图例或关系标签已清楚承担同一作用，不再叠加箭头、光效或色块重复提示。仅承担气质、节奏或用户明确指定封面表现力度的形态、色面和光效无需新增命题，但不能被读成未支持的类别、顺序、量值或关系；封面表现仍按主文已定方向与力度裁决。若导视能让人更快找到标题重点，可明确目标并标为阅读线索，与关系箭头区分。

知识图先由关系与拓扑决定整体空间，再安排视觉层级。根据[图形关系与连线](relationship-diagrams.md)确认主关系、真实分支/包含/交集后，以位置、对齐、邻近、连线和留白建立“总标题 → 主关系骨架 → 区内重点/条件 → 解释文字”的读法；不要让色块和卡片边界把应相连的关系截断。位置先说明主次与归属；再按需决定是否用形态、边缘或色面面积区分主关系、真实类别/状态、条件/重点与解释，不要求每种角色都使用不同形状或颜色。总体底色或形状可建立气质，不必每块都添一个命题；但颜色或形状一旦会被读成类别、顺序、等级、数量或因果，就须有材料依据和清楚定义。同组检查项若只是并列字段，不要为了区分而分别着不同类别色。

颜色可以鲜明、多色或暗底，形状可以圆角、直边或局部框；没有固定的灰白底加单一强调、四色胶囊或全去框配方。主关系可用显著轴线/色面，分类或状态只在关系真实存在时用稳定编码，解释文字可用较轻的底或直接靠近对应图形；框只在真实包含、明确模块或必要可读底面有用时保留。制作前可先用弱样式草图检查：暂时拿掉表面色面/装饰后，位置、标签和连线是否仍能说明主骨架及区内条件。若不能，先修空间或关系表达；这只是诊断草图，不要求最终图保持无样式。定稿再按整幅气质恢复有职责的色面、边缘和形态，并在缩略尺寸检查主次与密度。

相同语义角色的字体字重、基线、连线宽度与图标笔画应互相协调；采用嵌套框或圆角形时，检查内外圆角、边距和间距是否形成连贯的一组。符号可借用“轮廓简洁、负形清楚、线宽与文字角色匹配”的方法，但不必采用 SF Symbols，也不要求加载或安装系统符号/字体，更不把静态知识图伪装成可交互 UI。图式可以是承担解释任务的概念示意、对象组成或空间位置图、局部标注及状态/操作对照，不限于流程节点。图标可帮助辨认对象，但不能单独替代对象间关系；没有实证素材时将解释性画面标为概念示意，不伪装成截图、测量或真实证据。

## 让人物、引导线与光色指向内容

人物视线、直视和手势可以分别承担阅读引导、与观者建立接触、或表达情绪、动作、分享及角色关系。人物确实朝向标题/对象时，才把目光记为导视；手指指向标题时，记作手势引导；直视观者可建立正面接触，但不能据此声称眼神把人带到标题。只有方向线索实际把观者带向某项内容时，才记录为“可见起点 → 标题、证据、结果或行动入口”。引导终点附近留出目标信息，沿线避免穿过正文或落到无关角落。人物看向画外可服务悬念、动作或情绪，不必伪称标题引导。画面没有合适的人物或方向线索时，不为完成构图规则而添加。

引导线应从观者能识别的起点通向有意义的终点；它不能穿过关键字、掩盖证据、误指向界面装饰或让无关对象看成一组。先通过位置、朝向和留白建立方向；必要时再用线条或局部明暗提示。光影只加强应先被辨认的形状、动作或证据，同时给标题保留足够区分度。

真实截图、照片、数据或产品承担证据职责时，必须保留它们确实支持的内容；插画和象征物可解释或表达情绪，但不能画成未提供的实证。背景的纹理、道具和光效若与观看任务无关，先减细节、对比或面积；若背景本身是必要证据，保留它并重新安置文字和层级。

**方法出处：**Kelley Gordon, Nielsen Norman Group, “5 Principles of Visual Design in UX” (2020)，用于启发视觉层级、尺度、对比和平衡的版面判断，不证明信息流封面点击效果；IBM Carbon Design System, *Typography*, productive 与 expressive type sets；Richard E. Mayer, *The Cambridge Handbook of Multimedia Learning*, 2nd ed., Cambridge University Press, 2014，第12章，coherence、signaling 与 spatial contiguity 原则。Mayer 的原则在这里用于学习图的材料取舍和图文邻近，不支持关于封面点击或转化效果的断言；其余首要入口与引导动作是结合本地封面职责作出的执行适配。
