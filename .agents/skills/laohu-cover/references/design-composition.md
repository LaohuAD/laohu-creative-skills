# 设计元素的独立选择与组合

从观看任务和材料选画面角色，再将各角色需要的字形、色面、空间和视觉信号组合起来。可以分别取自不同参考。

## 何时读取与返回

当第三步拆分参考，或第六至八步要协调版式、字形、角色色、图文和强调变量时，带入用途、观者在意处及材料依据、锁定文字、画幅/显示条件、品牌/图例、参考职责及权限。只改简单变量且无组合影响时沿用主文；若要把作品内容转换成场景、局部重构、符号、抽象节奏或文字造型，另外读[艺术构图](artwork-composition.md)；同一任务同时有两个问题时一起处理。

回交本轮改变的选择及保持项。主文第三步接整体方向，第五步接各角色职责，第六步接区域与读序，第七步接字体角色，第八步接材料与色彩，第九步按制作路线编译并核查兼容。

## 选择顺序：任务、角色、候选、兼容、落值

1. 先写观者要识别、理解、比较、判断、感受、记住或采取什么行动。封面用材料差异选入口，知识图用结论和真实关系，海报按真实用途组织必要信息和行动项。锁定文案、事实、品牌、图例和禁项优先。
2. 先定整体字图主视觉，再拆变量和选候选。分开决定网格/标题轴、中文展示与阅读字、Latin 展示与阅读字/数字、背景及各颜色角色、图像职责、图形语义和强调通道。FP、LD、CP、E 彼此独立。
3. 保护准确文字、材料和读法。检查画幅与字符容量、实际字体与字重、图例、字与邻色对比、遮挡和裁切。有冲突先换有冲突的单项，需取舍时沿父级权限处理。
4. 把选择写成可观察的字图、颜色、空间和方向目标。精确目标、已实现值与编译路线按[实际参数接口](#完整提示词中的实际参数接口)处理。

## 拆开未定的视觉选择

带入本轮已有文案、品牌、禁项、个人偏好、参考职责和自主授权。只有仍未定且会显著改变主视觉或标题气质时，才就最重要的一两项给少量候选，指出焦点、视线路径、依据和代价。可跨项混选，只有容量、图像职责、对比或阅读路径等直接冲突才联动。用户保留取舍时暂停依赖该决定的定稿；已有授权或方向明确时直接选，不询问像素/字距、字体文件或无关项目。

| 未定维度 | 可拉开的候选差异 | 选择时说明的焦点与代价 |
|---|---|---|
| 主视觉主体与媒介 | 按材料选纯字图、物件/证据、人物、插画或抽象形式，沿用无人物、克制等限定。 | 说明物件能否直指主题，纯文字能否讲清，人物身份、表情、手势或目光如何承担阅读或表达。 |
| 展示字气质 | 按作用拆选轮廓、倾轴、疏密、尺度、描边/硬影、边缘材质或字图前后关系。高张力候选呈现至少一种实质组合，如厚轮廓配斜轴或硬影。 | 看语气、视线和副标题容量。用真实样式，保字腔与完整文案，避免假斜切和压扁汉字。 |
| 背景与文字颜色 | 高张力候选须呈现鲜明字底关系，如深/饱和底亮字、亮底深描边，按色面和邻接定具体值。若本轮确认用户常用白、黄、红，把它们当候选，主字和局部强调分别分配。 | 先核字底阅读对比。字已读清却平淡，改轮廓、尺度、轴线或前后关系。未锁定时保留候选色的独立选择。 |
| 构图动势与强调 | 稳定水平轴、斜向阅读、近景/前后层、人物动作或一两项有职责的轮廓/阴影/方向信号。 | 说明读者先看标题还是对象、接着去哪里；指出动作、角度或阴影与标题的联系，以及它们是否遮字、形成新焦点或和背景争夺视觉重量。 |

品牌、主题或字体覆盖有约束时调整通道并说明影响。个人偏好仅沿用本轮适用部分。

## 信息层级：先决定观者第一眼需要得到什么

封面先接材料锚点、主副文案和观看情境；依[第一落点](visual-hierarchy.md#先选第一落点)分别排视觉注意和文字次序。知识图用重点结论、关系和条件展开；平行比较或查阅所需的同级入口使用一致尺度和信号。

把选中的信号写成“对象—职责—可见力度—空间—复核”。用尺度/面积、对比、距离、方向、透视或动作落实实际力度；需要加强就扩大有效幅度或换承担者，多个围绕同一入口的通道可以互补。出现焦点竞争时先删无用装饰、改位置或再分版；颜色已用于图例时保留语义，用[强调通道](visual-hierarchy.md#选择强调通道)处理剩余问题。

## 标题与图像共同表达：先建立能看见的语义关系

把材料里的在意关系变成可见对象、动作、差异或结果。明确标题和图像分别做什么，检查完整画面能读清主题和限定。图像可提供语境；若标题也被作为独立字段，再按该用途检验。主动作定下后，在授权内开放具体形状、道具、姿态和视觉修辞。证据不足的字段、界面功能、结果和量值按父级边界处理。

| 触发条件 | 图文如何共同表现 | 关键词和切换条件 |
|---|---|---|
| 动作、对象或变化本身提供进入理由 | 确定谁在做什么、实际显示什么；让字块轻重、疏密、方向或位置回应动作，完整文案和读序保持可辨。 | 字块节奏、对象动作、清楚分工。只在说明里能看见联系就换对象、动作或纯文字；读字困难先调动势和字组。 |
| 标题指向具体对象、动作或结果 | 选择可识别的对象、可见动作或局部字形，让观者能指出它对应的词或承诺。 | 对象与标题词义、明确动作。泛泛的科技、速度、增长符号无法说明对象时，换有材料依据的对象或纯文字。 |
| 标题是“分析 / 解析 / 拆解” | 用打开层片、显露整体与局部、分离已有部分等动作，揭示已有对象的真实组成、层次、关系或观察线索。无正文时可写非实证的揭示姿态，界面、功能、参数与结论仍须有依据；画面身份文字按父级决定。 | 揭示既有结构、观察要点、层叠。只见破碎或对象寓意不清就换动作/字形；组合材料产生新对象属于下一行。 |
| 标题是“生成 / 创作 / 转化” | 有材料支持产出关系时，给输入和产出不同位置或状态，显示材料如何组合或变化。 | 输入与输出的可见区别、组合/转化。若材料只揭示旧结构，切回解析；输入/结果未知时用抽象示意。 |
| 标题是“学习 / 理解” | 将关键对象和邻近说明、关系线索、讲解/观察姿态或阅读路径组织起来，让人知道下一处看什么。 | 对象与说明邻近、注意路径；未给证据的掌握程度和成绩不加入。若题意实际是拆解或生成，按相应谓词设计。 |
| 需要比喻或修辞 | 找能直接看到的共享属性，让标题与来源对象联结，保留其事实身份。 | 可解码隐喻、共享属性。仅靠画外解释时改近邻线索、减弱、撤掉或换更直接的对象。 |
| 明确要求强冲击/情绪 | 用主文与[情绪和可见表现](#自媒体封面情绪性质与可见表现)锁定情绪和力度。细排前和参照或同任务轻/强构思比较，从标题尺度/密度、前后层、动作/透视/方向、颜色面积中挑能拉开差别的维度。 | 写谁承担情绪、与轻表现差在哪里。小静物配细线、暖纸白留白与一点红字若整体仍克制，就重选承担者或扩大幅度；预期差异不冒充版位实测。 |
| 知识图同时需要导视和事实边 | 导视只带向明确的文字目标；事实边写关系词、起终点和材料依据。 | 区分导视/关系箭头。仍会误读时用位置、视线、共同区域或其他分组。 |
| 交付整幅画面前 | 看入口如何接到完整承诺或解释；检查字形、主体、底形、边缘/材质、色面面积及视觉重量是否相容。 | 图像关系需靠说明才懂，先换职责；形态各自漂亮却割裂，先换主形、位置或材料再细排。 |

## 整体审美选择：根据内容挑字形、色彩、形状与空间

整体主视觉和字图关系选好后，按下表找能落实实际语义的审美选择。精确字形、字级、RGB 各从所属 Reference 取。形状、色彩和情绪联想依本作材料与受众判断。

| 条件 | 正向选择与操作 | 提示词关键词 | 失配时切换 |
|---|---|---|---|
| 短标题要有明确性格，当前字形只有“加粗”却未形成主视觉 | 观察锁定汉字的粗细、转折、笔端、宽窄与字腔；语义清楚、偏直接时先比对已核实 FP 的无衬线展示角色，编辑/文化语气再比较衬线角色，书写动作或亲近感才试手写角色。把实际 family/样式与字形结构一起检查，不能仅凭“科技/高级”命名。 | 中文展示 family + 真实字重；笔画结构/转折/宽窄；标题语义与字形一致 | 锁定汉字缩小时字腔粘连、笔画太细或与主题语气相悖，就换 FP 角色、改断行/字号；不拉伸汉字，不伪造档位。 |
| 标题已清楚但行块平、重点词不显，或副信息挤成同一层 | 先按完整语义断行，再让关键词的字号、字重或字形差形成节奏；副标题/解释使用阅读角色，不因“强”而一起放大。让断行和词组形状构成标题造型，而非牺牲读法的随机切块。 | 语义断行；关键词级差；主副信息不同字形角色；保留完整文字 | 断行拆开条件/否定/词组，或长副文压成微字时扩大文字区、改横竖轴或拆图；精确字号/行距回排印 Reference。 |
| 配色气质未定或画面闷/散 | 依任务在中性、鲜明、深暗或多彩间选。气质色面可只形成统一与节奏，色数、面积和饱和度随本作决定。 | 气质目标、统一或区分的职责 | 依据[视觉层级](visual-hierarchy.md)分别修注意、类别暗示、邻接阅读问题。 |
| 标题与主体/底形需要共享一种造型语言 | 根据主题和参考选择几何直边/锐角、圆弧/软边、书写笔势/不规则切边或明确材质；比较字体轮廓与主图外形/容器边缘，协调同类边缘，不让每项都换一种表面语言。圆弧可传亲近，直边可传技术与明确，笔势可传行动或手作。 | 主体轮廓呼应字形；共享边缘/圆角规则；材质一致；局部笔势 | 造型联想和标题内容无关、字体和容器互相吞边或材质争抢时减少表面种类，改用清楚的边界/留白。 |
| 文字需与主体形成一体感但完整度不能损失 | 先选一种有意义的接合方式：标题与图像共边适合共享版面轴；轮廓咬合适合文字贴着对象外形走；邻接并置适合先读标题再看说明；局部层叠只用于不损关键笔画/证据的短语；视线/手势只在有真实人物动作时指向明确文字焦点。 | 共边；轮廓咬合；文字与主体邻接；局部层叠；视线/手势至目标文字 | 读序混乱、局部遮字、眼手指向空处时换分带、纯文字或明确留白；不要求每张都叠字/斜字。 |
| 需要逼近感、能量或层次 | 用近景透视/紧裁切拉近，前景越框建前后层，硬影立轮廓，背景动势线强化方向。多项可组合，如近景越框与标题硬影，各有职责。 | 受控裁切、前后关系、硬影方向、导视目标 | 核方向、字形、留白和识别。越框遮挡、错误关系或争焦时弱化冲突层或改平面色块。装饰线保留导视身份。 |
| 人物是情绪/动作载体，且用户希望画面有相应情绪 | 先定情绪性质，再写能被看见的部位和动作：兴趣/发现可用注意到对象的眼神与微前倾；兴奋分享可用张开的嘴、外展手势或身体朝向分享对象；笃定掌握可用稳定目光、落稳姿势与正在操作/展示的手；痛点反应可用皱眉、压紧嘴角、收肩/回避动作。姿态强弱按主题和用户力度调，人物不是必需。 | 眉/眼/嘴状态；头肩/躯干方向；手与对象接触；视线目标；人物与标题区关系 | 仅写“开心/惊讶”或表达夸张却不合语义时，删人物/降具体表情并改用物件或字形；不能凭表情补材料没有的事实。 |
| 单项都合理，但整幅像拼贴或重量偏向辅助物 | 对照主标题字形外轮廓、人物/物件形状、底形边缘、色块面积和主要视觉重量；让一两种轮廓/材质贯穿主视觉，先调主形、位置和面积。 | 同一主视觉语言；色面节奏；标题重量优先；图文协同审稿 | 只靠增加贴纸、纹理或强调信号补整体不合时，退回材料和主次选择，替换不服务标题的主体/形状。 |

## 自媒体封面：情绪性质与可见表现

信息流的新设计或重定方向按[自媒体专项](../skills/laohu-cover-social/SKILL.md)确定材料理由、情绪/态度、突出程度及保护项。高强度与专业、克制、安静或无人物要求同时出现时，优先用可兼容的字形、尺度、结构、颜色面积或有依据的主物件达成，再按可见力度核查。实际冲突交父级裁决。

| 内容条件与观看理由 | 可试的可见表现方向 | 失配时的回调 |
|---|---|---|
| 读者需要发现、好奇或理解反常处 | 让遮挡后的对象/结果有清楚显露关系；可用局部近景、侧向视线或单一斜轴引向已说明的对象。 | 线形或遮挡若盖住完整标题、把关系说成因果或做成另一焦点，改为并置、稳定文字区或纯字形层级。 |
| 材料支持兴奋、活跃或行动感 | 用进行中的动作、斜轴、近景透视、人物/物件朝向或强局部明暗协同。 | 信号太弱时扩大面积或动作幅度。多个落点时统一指向、删重复，保持力度；标题冲突先重排。 |
| 内容需要轻松、释然或亲近 | 可试稳定轴线、较开放组距、较近的人物/物件关系、自然表情或相互作用；舒适配色由角色面积和邻色关系决定，不默认去饱和。 | 空白令文字断组或主体显得疏远时收紧关联区域；暖色若与品牌/参考冲突就保留已定角色色，改用位置、字重或距离。 |
| 内容需要笃定、专业或有把握 | 可试落稳的基线/中轴、明确物件握持或操作、清楚目光/朝向和坚实的形态轮廓。 | 统一轴线显得呆板或对象身份不清时，改为有秩序的偏置或用图文并置说明对象，不用黑底粗体作为必选外观。 |
| 内容需要悬念或未揭晓感 | 可试偏置构图、视线暂不落在标题、部分可见对象或由前后景产生的深度，但完整文案仍须可读。 | 省略部分被误解成标题内容缺失、证据或人物身份被遮断时，撤掉遮挡，转用标题外的留白/明暗或局部对比。 |
| 内容确有紧迫性、限时或风险条件 | 可试缩短视觉路径、提高必要文字与底面的局部对比、让关键动作/时间条件靠近入口。 | 材料未证明紧迫/风险时不要用警示视觉放大暗示；加入紧迫表现导致限定文字消失时先扩大文字区域或拆分。 |

人物可先吸引注意，直视可建立接触。照片写眉眼嘴、头肩、目光、手与对象、景别和透视，插画写轮廓、姿态和动作。保护必要题名、眼口、动作对象或身份。主表演写到可见，未锁定的次要细节保留开放。对照目标尺寸核幅度，实际太轻就扩大有效差异或换承担者。

Astudillo、Muñoz 与 Maldonado（2018）的自然图像自由观看研究分别观察情绪价性与唤醒；Wilms 与 Oberfeld（2018）的受控色块实验涉及色相、饱和度、亮度及其交互。按本作选择表现，传播表现依实图与实际观察。

## 网格与标题轴：用内容长度和图文职责决定位置

带入文字长度、图像职责、读序、画幅和裁切，按表选骨架。区域可组合，不绑定标题轴、字族或颜色；边界 m 和沟槽 g 取[排印规格](layout-typography.md)。

| 条件 | 网格选择与具体操作 | 提示词关键词 | 冲突时切换 |
|---|---|---|---|
| 连续说明、单一结论或文字先行 | 单栏；让标题、说明、来源共用一条主要对齐线，按语义分组。可用宽度 Wc = W − 2m；不需内容的区域不预留空栏。 | 单栏网格；共享左对齐线；标题与解释分组 | 文字长到难读时分段或拆图；若存在真实对照维度才切双栏。 |
| 两类或多类对象需逐项比较，且有共同字段 | 双栏比较；先确定共同内容宽 Wc = W − 2m，再算每栏 c = (Wc − g) / 2；相同行/字段对齐。 | 双栏共同网格；匹配行与基线；同指标并排 | 字段多或栏内文字溢出时改为纵向比较表/模块卡；没有共同维度时用独立分组。 |
| 多个独立信息组需要用同一结构重复呈现（两组也可） | 模块卡片；依据同一信息结构重复卡片宽度、内边界与间隔；卡片只圈同一语义组。 | 重复模块；一致卡片宽度；共同区域 | 组间关系会被卡片切断时改连续流程或关联网；不能只为整齐切卡。 |
| 标题短、表现方向稳定且左右内容权重相当 | 居中轴；标题盒中心与主图/面板的中心线重合，其他信息另行对齐。 | 居中标题轴；主图同轴；独立落款 | 文案变长、阅读信息多或有明确阅读起点时切左对齐轴。 |
| 材料明确表示循环或互相回返，节点数量可追踪 | 径向循环；按真实循环顺序沿环排节点，闭环方向连线只表达已确认的循环关系并标关系词。 | radial cycle layout；环上节点；闭合方向箭头与关系词 | 非循环、有分支或节点过密时换线性流程、分支图或分面；分类型径向布局改用无闭环的分组/树，不得为图形平衡造循环。 |
| 短标题或主体确有方向/运动意象，且不破坏读词 | 斜轴；只让短标题或图形主线沿同一斜向，正文与标签仍按正常阅读方向排。 | 单一斜向标题轴；图形引向真实目标；正文保持正向 | 长文、数据图或多条斜向彼此交叉时回到水平轴/网格。 |
| 图像确为主证据/情绪场景，且存在稳定可读区域 | 全幅叠字；文字盒落在经观察的干净/暗区，写清文字和主体各自的位置，保护证据与裁切边界。 | 全幅图像；文字叠于稳定区域；主体与文字避让 | 明暗变化、细节复杂或文字不能移动时切上下/左右分带，或加不透明文字底板并复核。 |

精排需要 x/W、y/H、w/W、h/H 及实际容量；第六步回交网格、锚点、读序和位置。

## 标题分行与展示轴

先按完整语义断行。展示轴控制位置，字体、颜色和主图仍独立。家族、真字重和字距由[排印](layout-typography.md)提供。

| 条件 | 标题操作 | 提示词关键词 | 冲突时切换 |
|---|---|---|---|
| 锁定文案含主词、条件、否定或对照关系 | 语义分行；断在语义边界，保持限定词和中心词相连；锁定文字逐字不变。 | 语义分行；短语成组；保持限定词贴近对象 | 文字盒过窄时扩区/换轴/拆图，不拆开否定、量词和限定。 |
| 需要先看见标题而不是副信息 | 先用字级说明主次；若目标表现需要，可让颜色、衬底、轮廓或方向围绕同一标题入口协同，各自承担不同职责并写出具体参数。 | 主标题一级；副信息次级；尺度先分主次；同焦点通道协同、职责分开 | 空间不足时调整位置、行数或画幅，不压缩文字或行距；重复信号或产生第二入口时减项。 |
| 中文展示字与正文需要不同气质/笔画密度 | 字族反差；单独选择中文展示 family 和中文阅读 family；混排 Latin 再单选 Latin family。 | CJK display family 与 CJK reading family 分离；脚本分别指定 | 标题行宽或字腔不兼容时替换一个角色；不因此换整套配色。 |
| 短 Latin 标题需节省横向空间 | 窄体 Latin；可从 Oswald 真实 family 与实际 wght 档试起；配套汉字另选 CJK family，不拉伸字形。 | condensed Latin display; explicit family and weight; keep CJK width unchanged | 字重/字符密度不清或窄体影响辨认时改常规比例 family、换行或加宽标题盒。 |
| 短 Latin 全大写标题需要更疏朗、居中或编辑式节奏 | 宽字距 Latin；只调用排印 Reference 的短全大写展示字 tracking 分支；指定真实 family、样式和角色。 | tracked Latin uppercase display; keep CJK and reading text at zero added tracking | 标题变长、行宽不足、词组被字距拆开时降低 tracking 或回到自然字距；不把数值施加给汉字。 |
| 用户要求竖排、旋转或样本方向会改变读法 | 改变展示标题方向，但正文、数字与图例保持目标语言习惯的阅读方向；明确哪些文本旋转，勿整图旋转代替排版。 | vertical title block / rotated display word only; body remains upright | 方向使扫读变慢、数字/混排难辨或裁切不适配时回到水平轴。 |

## 字体角色：把中文、Latin 和数字分开选

中文短标题用展示角色；正文、节点、条件、注释用中文阅读角色。单独给 Latin 短标题和副信息选字，数字和代码看是否需等宽；可跨用 [FP01–FP08 和 LD01–LD03](layout-typography.md)。精排时记录家族、真实字重/轴、字符/地区字形、标点和字宽；未核实加载只称设计目标，缺汉字只换相关角色。opsz 是光学尺寸，工具单位与映射明确才手调，默认由渲染器处理。换字体导致宽度或密度变化时重新核断行、容量、字腔和目标显示，其他项仅随直接冲突修。

## 色彩气质与具体选择的分工

按观看任务决定气质和大色块职责（统一、对比、分组或形成节奏）。颜色邻接、角色 RGB、字底取样、类别和焦点复查统一见[视觉层级](visual-hierarchy.md)。

## 图像与文字：分配证据、情绪和阅读职责

带入标题、文字权限、图像真实内容和背景复杂度，选字图的相对空间。涉及主体加局部、重复、交错或作品锚点转换时，按[艺术构图](artwork-composition.md)记录每片来源、变换和实际职责。遮挡检查优先保护证据及识别特征。

| 条件 | 画面中可观察的关系与操作 | 提示词关键词 | 冲突时切换 |
|---|---|---|---|
| 标题与证据对象需要同屏核验，二者都需清楚 | 并置；标题和图像分占相邻区域，共用一个对齐边或留出明确间隔；不让图像盖住要看的证据。 | side-by-side image and text; separate evidence and title zones; shared alignment | 横向空间不够时改上下分带或缩小非必要图像区。 |
| 有明确先读标题、再看证据/解释的顺序 | 上下分带；标题带与图像/图表带边界清楚，按阅读路径排列。 | stacked title rail and image panel; ordered reading bands | 标题下方内容会被裁切、或两带都很拥挤时改单栏或拆卡。 |
| 照片/插画有稳定空区，短标题需与图像融合 | 叠字；观察文字将落的区域，明确文字盒、图像主体与不遮挡区；只有局部邻色持续稳定且对比充分才直接压字。 | text overlay in stable negative space; protect subject and evidence | 明暗复杂或长文跨多个背景时移到独立文字区或加底板，合成后复核。 |
| 主体轮廓是关键线索，文字只需占据周围空间 | 轮廓避让；把文字盒放在主体外轮廓之外并保留间隔，不让字碰到脸、物件边缘或关键证据。 | preserve silhouette clearance; text outside subject contour | 画面不足以同时容纳主体和文字时改分带/缩小次要素材，不靠遮挡补救。 |
| 单一主题图形承担解释/象征，标题需要稳定阅读区 | 主题图形与独立题带；图形和标题分区，题带不压线描/机制节点；图形不冒充数据证据。 | one thematic graphic; separate title band; keep diagram detail clear | 图形无证据职责或占满文字容量时改纯文字、列表或简单图解。 |
| 标题本身足以建立主题，图像不增加有效信息 | 纯文字；靠字级、分行、网格、颜色角色或一处强调形成主次，不补人物和装饰图形。 | type-only cover; clear title hierarchy; no decorative subject | 若读者无法理解标题所指对象或需证据支持，再加最小必要的图像/图形。 |
| 文字本身是场景内真实对象，如招牌、屏幕、包装标签 | 场景嵌入；文字依照透视、材质、遮挡与现场光线；与版面叠加标题分层处理。 | in-scene lettering follows plane and occlusion; overlay title remains separate | 文字必须精确或复杂时改可编辑文字层；不承诺模型逐字排准。 |

第五步分职责，第六步落区，第九步写出实际位置、前后和避让。需要精排时给文字盒、图像盒锚点/坐标及保护区。

## 图形语义：形状、容器、线和颜色不能替材料发明关系

依[图形关系与连线](relationship-diagrams.md)从已确认命题选拓扑、空间、边及图例。标签说明类别和边的含义，直线、正交线或曲线处理路由。导视须有明确目标，易与事实边混淆时改位置、视线或色块分组。

### 知识图的整体空间与形态

真实中心可向分支展开，主流程沿主轴，交织关系的局部子图靠近对应位置。位置、邻近、对齐、轴线、留白和尺度先组织区块，容器只在有实际分组、边界或文字承托需求时使用。单纯气质色面可保留；会被读作类别、包含、数量、等级或因果时给出材料依据和清楚定义。类别另配形状或文字线索。

## 强调动作：依据阻碍组合有职责的通道

按当前问题读取[强调动作 E01–E16](visual-hierarchy.md#强调动作目录e01e16)，对每个动作写清对象、角色、方向和可见目标，再核遮挡、互斥、重复提示、锁定文字与图例。描边或阴影须区分展示轮廓与阅读补救，分别核笔画字腔。图形强调不会自动获得增写文字、数字或事实的权限。

## 兼容检查与单项替换

按下表复核组合，冲突只改直接依赖，说明影响。换字体回查容量和笔画，换颜色回查底色及图例，换标题轴回查读序与裁切，换箭头回查关系。

| 依赖 | 检查 | 冲突时只改动直接相关项 |
|---|---|---|
| 字体 × 文案 × 网格 | 字形覆盖、脚本、真实字重/轴、行宽、断行与区域容量 | 缺字换相应脚本的字族；溢出调整区域/行数或拆图，保留未冲突颜色和图像职责。 |
| 层级 × 强调 × 信息语义 | 单一承诺是否有清楚第一入口；若多个通道围绕同一入口，职责是否互补；多个同级入口是否真的可比；标记会不会新增含义 | 封面只撤掉重复/冲突通道，保留有效协同；图表按关系语义与图例回调；不改标题、数字或图例含义。 |
| 颜色 × 背景 × 图例 | 对比按真实邻接背景复算，颜色是否已承担数据类别/顺序 | 替换单个文字/强调角色并补形状或标签线索；重算实际底色比值。 |
| 图像 × 文字 × 裁切 | 文字覆盖证据、照片明暗、人物/主体关键部分及目标平台遮挡 | 移动文字或图像、调整范围或加底板；保留字体/色彩方向直到发生直接冲突。 |
| 图形 × 关系证据 | 容器、矩阵、箭头、循环和线型是否对应已确认关系 | 回到关系图改形状或连线；不以美化为由改变命题。 |

## 从研究样本借单项手法

八张 Pin 只支持表中可见局部。未公开字体、字重、尺寸、配色值和传播结果保持待核。只借单项处理，保有当前题名、品牌与图例，原始链接在项目知识来源台账。

| 样本 | 像素所支持的单项观察 | 可复制的技术关键词 | 适用条件与切换 |
|---|---|---|---|
| P01 | 浅色底；左对齐英文标题分行，末行换深蓝；大型斜面从左下引向右侧门形和小人物；小型大写信息靠上和边角。 | 左对齐短标题轴；末行单色强调；单一斜向引导至有意义目标 | 短主题且图像确实补充方向意象；长文或多色标签时改单栏/独立图文区。 |
| P02 | 竖版红底；黑字问题标题置于白色对话泡；半透明大引号作背景符号，小泡承载补充文字；下方分出单项百分比指标、小型柱形、免责声明和行动区，另有标记与二维码。 | 单一问题容器；一项指标独立分区；免责声明/行动信息置底 | 一个有依据的问题带出一项已核验指标；无来源数字时删除指标区，不照搬数据、标记或二维码。 |
| P03 | 黑色竖底；白色中文主标题与较小英文副题在上；中央青绿色三节点环路以连续箭头连接并配双语标签；底部有短引语。 | 上方标题带；闭环节点路径；短解释独立下带 | 材料真实构成循环且阶段数可追踪；单向/分支关系改流程或分支图。 |
| P04 | 黄色齿孔/票券外框内有白色纸感矩形；点状线分开两段有序内容；各段先有粗体双语步骤名，再有短英文和较小双语说明，并配对象图标。 | 单一外框；有序模块；内部点状分隔线 | 仅用于确有短步骤；并列观点或长解释改比较网格/普通分组。 |

| P06 | 奶油色外围留白，中间绿色矩形面板；短英文全大写细衬线分三行居中并拉宽字距；面板下沿有极小人物与长椅；面板外下方放小型斜体副信息。 | 居中 Latin 展示轴；短全大写宽字距；中央色面板；外围留白 | 短而安静的 Latin 标题；中文另选字族；宽字距数值用 layout 唯一分支，不认作原作参数。 |

## 完整提示词中的实际参数接口

第九步按[双轨提示词编译](prompt-compilation.md)把本轮决定写给实际接收方。回传场景、画幅、锁定原文/事实、层级与视线路径、网格、字体角色、邻接色、图像职责、关系结构、情绪的可见表现及强调动作。普通生图给相对大小、方向、颜色面积和真实可见结果；精确坐标、字族/真实字重、RGB、F 比例按用户明确需求、品牌锁定及确认的制作方式展开。已有锁定参数仍须保留。FP、LD、CP、E 和 Pin 编号只供查找。

排印参数归[版面与中文排印](layout-typography.md)，颜色及 F 比例归[视觉层级与引导](visual-hierarchy.md)，节点、边和尺寸归[图形关系与连线](relationship-diagrams.md)。说明实际加载、覆盖、渲染、取样或缩略检查状态时区分目标、内部试算与实测。

## 方法来源范围

Paula Scher 为 Public Theater 设计的视觉项目（Pentagram，1995/2008），可借“题材动作值得看见时，让文字块疏密、位置和方向响应动作”。原题名和读序优先，按中文需要重做造型。MoMA 的 1995 年作品记录另可学习用间距、字重、字色组织高密度信息。依据项目说明和作品记录取局部关系，不推断原字族、数值、点击或复制其标识与木活字系统。

Childers 与 Jass（2002）用于理解字形的语义线索；McQuarrie 与 Mick（1999）、Forceville（1994/1996）用于检验图文隐喻能否解码；Pieters 与 Wedel（2004）的印刷广告眼动研究启发比较图像面积与注意；Reber 等人的加工流畅性研究启发图底分离、字腔及缩略检查。各项按其条件作本地适配，完整书目和核查范围查项目知识来源台账。
