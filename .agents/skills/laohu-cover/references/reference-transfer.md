# 参考图迁移

**参考图只提供可见证据；先认清它替本轮干什么，再拆取真正有用的变量，绝不整张照搬。**

当收到可访问参考图或界面截图，需判断截图职责、区分单图内多个阶段、复现人物或跨参考组合视觉变量时读取；无参考图时零加载。

## 先辨认截图在当前任务中的职责

沿用[主文的阶段判断](../SKILL.md#同一画面任务的后续请求)，进入关键帧或参考迁移前，逐图定清职责与可变边界：

| 截图 / 参考角色 | 必须保留 | 允许调整 |
| --- | --- | --- |
| **当前页面的美化目标** | 主结构、熟悉的操作触点、交互方式（如下拉菜单仍是下拉菜单）、当前状态（如展开态仍保持展开）及已确认触发结果。 | 视觉气质、表面层级、光色材质、间距、弹层局部定位与遮挡修复。 |
| **明确允许重排的起点** | 同一用户目的、真实功能、主要操作关系、锁定文案与状态。 | 整体版面布局、分区与视觉系统。 |
| **仅供取风格的参考图** | 仅提取能解决当前审美或情绪问题的可见视觉原理（明暗比例、材质光感、圆角与字形气质）。 | 绝不导入参考图的文案、对象、功能、品牌标记或原布局（除非另有指定）。 |
| **已核准可直接使用的成品帧** | 完整原图、真实身份与本帧职责，直接交[制作参考与交接](production-reference-handoff.md)。 | **不重新选方向，不重写该帧提示词。** |
| **派生画面的基底** | 用户明确确认可延续的可见内容与关系。 | 新状态与变化须由方案或口述支撑，不凭截图自行发明功能。 |

可见外观与真实功能分开取证：当前状态原生截图可核文字、控件与骨架；隐藏交互、转场与业务规则以已确认方案、口述或实际运行为准。旧主题截图可作结构依据，旧外观只保留本轮选中部分。

## 像素实看与单图多阶段辨识

1. **打开实际像素再描述：** 只记录像素可见的文字、主体、相对尺度、色彩、光影与边缘关系；模糊难辨的字、身份或隐藏意图标为未知。图片打不开或未提供像素时如实说明，仅暂停依赖它的决定，绝不拿文件名或口述冒充像素证据。
2. **拆清一张图里的多个阶段：** 遇到上下拼接、前后对比板、带原图缩略的过程展示时，先凭边框、留白、重复元素辨认哪块是原始素材、哪块是过程对比、哪块是最终成品。整张附件的外框比例不自动等于目标画幅；过程演示的上下分带、外框、日期与批注绝不自动迁入新成品（确属成图内部的撕纸、画中画或叠层才迁移其画内关系）。区域身份不清且会改变构图时，只问哪一块是成品目标。

## 按变量跨图拆取与整体重组复核

不为一张图好看就把人物、标题、Logo、背景与布局打包照搬，按具体职责拆取：
- **复现同一人物：** 只锁定目标画幅可见的清晰身份特征；姿态、表情、服装、道具、背景与光线分别决定，不随身份硬绑。
- **只借姿态或表现：** 只迁移像素可见且指定的表情部位、姿态、手物接触、视线方向、景别或用光关系，不复制原人物身份或无关造型。
- **借版式 / 字形 / 色彩 / 风格：** 转成适配当前锁定文案与画幅的相对比例、字形骨相、明暗色面和材质原理；未经授权不带走原图文字、商标、账号或水印。
- **多图分区混选（如 A 的菜单质感 + B 的内容布局）：** 逐图指定唯一职责与负责区域，以当前真实功能状态为准，用统一间距、表面层级与色温协调交界；相同变量冲突按主任务与锁定项裁决，真会改变核心读法才问取舍。

**变量拆取后必回整幅复核：** 把抽来的字块、主体、色面、光影与留白放回同一画布，检查情绪是否同频、文字与主体有没有被色块撕裂成两张图、视线与动作是否指对方向、缩略尺寸下主副标题与核心锚点是否依然清楚。局部只改一项时冻结其余决定，只查直接依赖。

每张实读参考形成精炼 5 项内部记录（不写泛泛参考风格）：**可见事实｜本轮职责｜取用与改编变量｜禁止带入项｜冲突与保留依赖**。
