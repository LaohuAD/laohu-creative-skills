# 参考图迁移

参考图只提供可见证据；先辨明它替当前任务做什么，再决定带走哪些变量。

## 何时读取

当主文第二、三步收到可访问的参考图，且用户要对标、复现身份或迁移其形式时读取。输入包括图像、每张图的职责说明、观看任务、锁定文字及复用权限。完成后返回第二步的可复用文字/身份/素材范围、第三步的视觉方向、第五步的图文职责、第六步的区域安排、第七步的文字角色或第八步的材料决定；只交接受参考影响的字段。

## 先确认看到了什么

打开实际像素后再描述图像。记录可辨认的文字、主体、位置、相对大小、关系、颜色和边缘特征；比例、字号和位置只能据像素估计，读不清的文字、人物身份、品牌或隐藏意图一律标为未知。图像打不开或细节不足时，说明哪些部分无法观察，只继续不依赖它的决定，不用文件名或用户的概述伪装成像素证据。

## 按职责拆取参考

先为每张图指定它在当前任务中的单一或少数职责，再判断保留哪些变量。不要因为一张图整体好看，就把其主题、标题、人物、服装、Logo、色板、背景和布局一并照搬。

| 观察条件 | 选择与处理 |
|---|---|
| 要复现同一人物 | 只锁定目标画幅里实际可见、足以识别身份的锚点；姿态、表情、服装、道具、背景、光线分别判断，不随身份自动复制。 |
| 只借姿态或表现 | 只迁移像素可见且用户指定的动作、眉眼嘴表情、头肩/躯干姿态、手与对象接触、视线方向、景别/透视或光线关系；记录它与标题/对象的可见位置关系，不推断隐藏情绪、意图或人物身份，也不复制其他造型。 |
| 参考含标题或文字 | 仅转录可辨文字；先判文字承担标题、说明、标签还是数据角色，再决定借用断行、层级或字形表现。不得把原文案带进新图，除非用户要求复用。 |
| 借用版式 | 估量文字区、主体区、空处和阅读顺序的相对关系；依据当前锁定文案、画幅和显示尺寸重新分配，不追求像素级复刻。 |
| 借用风格或媒介 | 记录可见的字形特征、边缘、色彩关系、材质和光影，映射到当前信息职责；不把风格标签当成具体证据。 |
| 多张参考 | 逐张指定职责。相同变量互相冲突时，按当前任务目标、用户明确偏好和锁定内容裁决；无法判断且会改变核心读法时，只询问这项取舍。 |

## 跨参考按变量组合

多张图或一个样本集不必按整张图绑定。用户可指定 A 借版面、B 借字体外观、C 借色彩关系；也可只借一项边框、图文位置、字形或强调动作。对每项分别记录来源、像素所支持的事实、当前职责、本图目标值和不复用的内容；不得因为取了 A 的网格就自动复制 A 的字体、背景、标题、人物或品牌标记。Pinterest 样本只支持设计组合 Reference 中列出的单项可见手法，未知的原作字体、字重、精确 RGB、字号及设计意图仍记为未知。

若当前任务有多项已定值，用户后来只改其中一项，就冻结其余决定，只重查直接依赖：换字族需复算字符覆盖、行宽与容量；换色需重算真实邻接对比并检查图例编码；改网格/标题轴需重排区域、阅读路径与裁切；改图像区域需确认文字是否遮住证据；改箭头或线型需回到关系语义。依赖检查若未发现冲突，不把局部改动扩成整套重新选择。完成观察后按[设计元素的独立选择与组合](design-composition.md)裁决组合，再把受影响字段返回主文，不替主文更改锁定文字和证据。

## 生成可交接映射

每张参考按下列字段形成短记录，不能只写“参考其风格”：

| 字段 | 记录要求 |
|---|---|
| 观察事实 | 只写像素可见内容和可复核的相对位置、尺度；涉及人物表现时记录可见表情部位、姿势、手与对象关系、视线方向、景别/透视及人物和文字/对象关系，不把推测出的情绪或意图写成事实。 |
| 当前职责 | 说明它帮助提出、说明、证明、分组、引导或营造何种观看条件。 |
| 可迁移变量 | 写明可调整的具体变量，不用“高级”“科技”等无法落地的标签。 |
| 处理决定 | 对每个变量标为保留、改编、省略或冲突待决。 |
| 本图目标值 | 写成当前任务可执行的文字、区域、相对尺度、字形或色彩关系。 |
| 冲突与限制 | 说明与锁定文案、身份、证据、画幅或其他参考的冲突，以及据此采取的处理。 |
| 保持项与依赖 | 写明本次抽取后仍保持不变的其他已定维度，以及必须重新检查的直接依赖；无依赖变化就注明保留。 |

标题参考要记录其语义角色、行数/断行、文字区位置与相对尺度、字形和字重、颜色/衬底、背景繁简及图文关系；只转移当前任务需要的项。看不清的值不填猜测；它不阻止其他字段继续完成。未经授权不复制商标、标题、账号标识或身份资产。参考中的形式若会改变主文已确认的承诺或证据读法，保留内容事实，改编外观；无法兼容时暂停该变量并交由主文取得必要决定。

## 来源与方法边界

本方法沿用 `laohu-cover` 主文关于按像素描述、区分人物身份与表现方式、记录观察事实和迁移决定的规则；这里提供字段与判定步骤，不额外声称有固定的参考复刻理论或像素容差。
