# 参考图迁移

参考图只提供可见证据；先辨明它替当前任务做什么，再决定带走哪些变量。

## 何时读取

当主文第二、三步收到可访问参考图，且用户要对标、复现身份或迁移形式，或关键帧需要判断截图职责与取法时读取。输入包括实际图像、每张图的职责、当前观看任务、主文已选材料入口（若为信息流封面）、锁定文案及复用权限。先区分“本材料为什么值得观者进入”与“参考图如何呈现其内容”。完成后把取用决定返回关键帧委托，或返回主文相应步骤的文案、身份、方向、区域、文字及材料选择，写明保留的任务、依据和适配方式。

## 先辨认截图在当前任务中的职责

沿用[主文的阶段判断](../SKILL.md#同一画面任务的后续请求)。进入关键帧路径后，逐图确定截图职责和可变范围。

| 截图角色 | 可调整范围 |
|---|---|
| 当前页面的美化目标 | 保留主结构、熟悉的操作触点、已知功能、操作方式、当前状态及已确认的触发和结果。为改善遮挡或可读性，可调整间距、弹层的局部定位与外观。展开态仍呈现为展开态，操作方式与数量的变化遵从获准的改动范围。 |
| 明确允许重排的起点 | 可调整整体布局，但仍须实现同一用户目的、功能和主要操作关系，并保留锁定文字与状态。 |
| 仅供取风格的参考图 | 只提取能解决当前视觉问题的可见原理，不导入其文案、对象、功能、品牌或布局，除非用户另有指定。 |
| 已核准并可直接使用的成品帧 | 保留真实图像身份和本帧职责，交给[制作参考与交接](production-reference-handoff.md)直接交接；不因有参考图而重写该帧提示词。 |
| 派生画面的基底 | 只保留用户已确认可延续的可见内容/关系；新状态与变化需由方案或用户说明支持，不从截图自行发明。 |

把可见内容与实际功能分开取证。当前对应状态的原生截图可核对文字、项目、控件归属和界面骨架。隐藏操作、状态转场和业务规则用已确认方案、用户说明或实际运行核对。生成草稿或来源不明的截图只按可见内容使用。若旧主题的截图仍能提供当前结构，按结构采用，旧主题外观仅沿用本轮指定的部分。截图无法读取或信息不足时，把缺项留为未知，只暂停依赖它的决定。

## 先确认看到了什么

打开实际像素后再描述图像。记录可辨认的文字、主体、位置、相对大小、关系、颜色和边缘特征；比例、字号和位置只能据像素估计，读不清的文字、人物身份、品牌或隐藏意图一律标为未知。图像打不开或细节不足时，说明哪些部分无法观察，只继续不依赖它的决定，不用文件名或用户的概述伪装成像素证据。

### 先分清一张附件里有哪些图像阶段

遇到上下拼接、前后对照、撕边嵌图、缩略图/页面截图或同一对象的多张局部时，先查看可见边框、留白、裁切、重复内容和层叠关系，给每个区域判断其当前身份：原始素材、过程/对照面板、参考设计、设计中的嵌入局部，或用户要交付的完整成图。图像附件的整体外框和宽高比不自动等于目标海报的画布，也不能因区域相邻就把它们认作同一幅构图。

用户明确说明“上方是原图、下方是设计效果”等时，沿用该说明；它只决定区域职责，不代表原始照片和成品海报要一起复制到目标图里。用户只把整张附件作为审美参考、但区域身份会改变构图时，依据像素分界和用户说明判断；仍无法确认时，把有影响的区域标为未知，只询问“哪一块是成品目标/哪一块只是原始素材”。

对照板或过程板可用于比较其不同阶段的具体改动，但不可把演示用的上下分带、边框、撕口、日期或注释自动迁入新海报。相反，若边界显然是最终成图内部的撕纸、窗口或嵌套照片，则按其画内职责迁移对应边界与关系。任何分隔、重叠或局部放大都先记为可见构成事实；只有材料与文字共同支持时，才解释为对照、时间、因果、揭示或叙事。

## 按职责拆取参考

先为每张图指定它在当前任务中的单一或少数职责，再判断保留哪些变量。不要因为一张图整体好看，就把其主题、标题、人物、服装、Logo、色板、背景和布局一并照搬。

| 观察条件 | 选择与处理 |
|---|---|
| 要复现同一人物 | 只锁定目标画幅里实际可见、足以识别身份的锚点；姿态、表情、服装、道具、背景、光线分别判断，不随身份自动复制。 |
| 只借姿态或表现 | 只迁移像素可见且用户指定的动作、眉眼嘴表情、头肩/躯干姿态、手与对象接触、视线方向、景别/透视或光线关系；记录它与标题/对象的可见位置关系，不推断隐藏情绪、意图或人物身份，也不复制其他造型。 |
| 参考含标题或文字 | 仅转录可辨文字；先判文字承担标题、说明、标签还是数据角色，再决定借用断行、层级或字形表现。不得把原文案带进新图，除非用户要求复用。 |
| 借用版式 | 估量文字区、主体区、空处和阅读顺序的相对关系；依据当前锁定文案、画幅和显示尺寸重新分配，不追求像素级复刻。 |
| 借用风格或媒介 | 记录可见的字形特征、边缘、色彩关系、材质和光影，映射到当前信息职责；不把风格标签当成具体证据。 |
| 多张参考 | 逐张指定职责。相同变量互相冲突时，按当前任务目标、用户明确偏好和锁定内容裁决；无法判断且会改变核心读法时，只询问这项取舍。 |

## 跨参考按变量组合

多张图或一个样本集不必按整张图绑定。用户可指定 A 借版面、B 借字体外观、C 借色彩关系；也可只借一项边框、图文位置、字形或强调动作。对每项分别记录来源、像素所支持的事实、当前职责、本图目标值和不复用的内容；不得因为取了 A 的网格就自动复制 A 的字体、背景、标题、人物或品牌标记。Pinterest 样本只支持设计组合 Reference 中列出的单项可见手法，未知的原作字体、字重、精确 RGB、字号及设计意图仍记为未知。

用户指定用 A 的菜单和 B 的内容区时，分别写出各区采纳的视觉做法以及由当前作品提供的真实功能和内容。用同一画面的间距、字级或状态信号协调交界。若参考与目标状态不一致，以目标对应的内容依据为准，参考仅提供指定的视觉做法。

若当前任务有多项已定值，用户后来只改其中一项，就冻结其余决定，只重查直接依赖：换字族需复算字符覆盖、行宽与容量；换色需重算真实邻接对比并检查图例编码；改网格/标题轴需重排区域、阅读路径与裁切；改图像区域需确认文字是否遮住证据；改箭头或线型需回到关系语义。依赖检查若未发现冲突，不把局部改动扩成整套重新选择。完成观察后按[设计元素的独立选择与组合](design-composition.md)裁决组合，再把受影响字段返回主文，不替主文更改锁定文字和证据。

## 把变量放回整幅关系中复核

变量分别提取后，还要重新检查它们组合起来的主视觉，而不是把各项“都能用”当作整体成立。把完整文字块、人物/主题物件、背景与色面、空间距离和遮挡放回同一张版面，逐对看它们的面积与视觉重量、边缘和材质、前后层、相互间距、标题/副标题可读性、主体动作和标题方向是否协同。特别检查文字块—人物/物件—色面—距离组合：颜色可能把文字与主体分成两张图，人物动作可能指向不相干区域，字块和对象也可能因距离过远失去语义连接；若有这些情况，先调整整体位置、比例、邻接或主次，再微调独立字族/颜色值。缩略尺寸下复核完整标题、材料锚点和必要信息是否仍能被看到。将整体重组后的实际区域、职责、读序和裁切保护返回主文第三/五/六步，并供第八步与第九步消费；仅有提示词时说明这是目标关系，不能据此声称成图通过。

## 生成可交接映射

每张参考按下列字段形成短记录，不能只写“参考其风格”：

| 字段 | 记录要求 |
|---|---|
| 观察事实 | 只写像素可见内容和可复核的相对位置、尺度；涉及人物表现时记录可见表情部位、姿势、手与对象关系、视线方向、景别/透视及人物和文字/对象关系，不把推测出的情绪或意图写成事实。 |
| 当前职责 | 说明它帮助提出、说明、证明、分组、引导或营造何种观看条件。 |
| 可迁移变量 | 写明可调整的具体变量，不用“高级”“科技”等无法落地的标签。 |
| 处理决定 | 对每个变量标为保留、改编、省略或冲突待决。 |
| 本图目标值 | 写成当前任务可执行的文字、区域、相对尺度、字形或色彩关系。 |
| 冲突与限制 | 说明与锁定文案、身份、证据、画幅或其他参考的冲突，以及据此采取的处理。 |
| 保持项与依赖 | 写明本次抽取后仍保持不变的其他已定维度，以及必须重新检查的直接依赖；无依赖变化就注明保留。 |

标题参考要记录其语义角色、行数/断行、文字区位置与相对尺度、字形和字重、颜色/衬底、背景繁简及图文关系；只转移当前任务需要的项。看不清的值不填猜测；它不阻止其他字段继续完成。未经授权不复制商标、标题、账号标识或身份资产。参考中的形式若会改变主文已确认的承诺或证据读法，保留内容事实，改编外观；无法兼容时暂停该变量并交由主文取得必要决定。

## 来源与方法边界

本方法沿用 `laohu-cover` 主文关于按像素描述、区分人物身份与表现方式、记录观察事实和迁移决定的规则；这里提供字段与判定步骤，不额外声称有固定的参考复刻理论或像素容差。
