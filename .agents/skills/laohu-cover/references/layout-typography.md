# 版面与中文排印

**先用真实文案反算呼吸空间，再落字号与网格；字排得舒展透亮，情绪和信息才能一起到达。**

常规单张轻文字 AI 封面不加载本文件。仅在遇到**多区块容量核算、长中文说明排印、多张系列视觉统一、跨比例重排、平台详细遮挡校验，或 Figma/品牌精确字体与坐标规格**时读取；节点/连线尺寸归[图形关系与连线](relationship-diagrams.md)，情绪色彩与强调归[视觉情绪、层级与强调](visual-hierarchy.md)，字体仓库一手来源归[SOURCES.md](../SOURCES.md)。

文章篇内讲解图以正文栏为宿主而非封面画布，按关系与密度定相对比例；正文栏宽未知时只交相对布局与放大阅读要求并标待验，不编像素。

## 先安排区域，再分配字级

以下分区起点仅用于**路线 B 精排规格、多区块信息图或严格容量反算**（AI 创意封面与海报遵循整体字图共生构图，绝不按此表硬切成上下盒子）。分配可伸缩配图前，先核算全部锁定文字（含副标题、条件、来源与真实行动区）所需高度，扣除外边距与组距再分剩余空间，不留空壳占位。默认工作外边距先试左右 `5%W`、上下 `5%H`（再让位给真实平台安全区）。

| 任务骨架 | 相对起始分区（`x, y, w, h`，按锁定文案重算） | 调整原则 |
| --- | --- | --- |
| **单一承诺封面** | 标题区 `(0.05W, 0.06H, 0.90W, 按实际行高)`；主图/证据区紧随其下占余高 | 第一落点在图时可上下对调或左右并置；纯字构图不留空图区。 |
| **知识卡 / 信息图** | 题名结论 `(0.05W, 0.05H, 0.90W, 按行高)`；关系主体占中段核心区；来源/条件落底带 | 节点增多优先扩主体区、改构图或拆图，绝不靠把标签缩成微字硬保大题栏。 |
| **真实行动海报** | 题名/主题居主视觉位；时间、地点、资格按容量独立成组；真实行动入口落清晰收尾位 | 缺关键行动条件只问缺口、绝不占位编造；无行动任务的海报省去行动带。 |

- **信息流主副标题并存：** 主标题守第一文字层级，锁定副标题清晰居第二层（本地试排起点先取主标题字号的 `0.45×`，比较范围 `0.40–0.55×`），可按原语义拆成受众呼应与收获两组、一字不改；缩略读不清优先增容、挪图或换行，绝不缩成底边脚注。
- **常见版面网格选型：** 连续说明用单栏共享左对齐轴；同指标对照用双栏等基线匹配行；结构一致的多组信息用统一模块卡（跨组有强流转关系时不强切卡片）；短而稳的对称主体可用居中轴；确为真实闭环才用径向循环；短标题确需强动势可用单一斜轴（正文与标签仍保持正向水平读法）。
- **文字组距起点（以所属组显示字号 `F` 为基准）：** 同组相邻行块额外间距先试 `0.5F`，跨独立组先试 `1.5F`（仅用于文字组，不替代行距或图形节点间距）。

## 发布版位的裁切与遮挡试排

优先核实本轮目标平台实时规范或用户模板；缺失时按下表作本地压力试排，并在块外标明待实机预览核验：

| 显示情境 | 本地安全核与避让动作 | 实际验收点 |
| --- | --- | --- |
| **微信公众号头图 2.35:1（兼转发 1:1）** | 取画布正中 1:1 方框（宽等于画布高、约占全宽 `42.6%`），把完整主副标题字块与可独立识别的核心主视觉收进中央方框并留内边距；左右两侧自然延展背景与氛围。 | 同看 2.35:1 横幅与 1:1 方形裁切；若入口提供独立方封或裁切偏移，按实重排。 |
| **横版视频 16:9（B 站 / YouTube 等）** | 避开右下角时长角标遮挡区（不写死平台像素，按相对角区移出关键字、眼部与证据）；兼顾 B 站 4:3 列表卡片时同步把核心压在居中安全域。 | 以实际列表缩略图与播放页角标双检。 |
| **竖版短视频 9:16** | 避开底部约 `20%`（标题文案栏）及右侧互动按钮列与交叠角区，背景自然延伸进覆盖区。 | 覆上目标端真实文案长度与按钮状态检查，列表缩略与个人页裁切分别复核。 |

多版位兼容先查保留区交集；若挤进交集会压坏标题或主体清晰度，分版位独立构图重排。

## 容量反算、跨比例重排与系列统一

**高分辨率只保锐度，阅读容量由最终显示宽度决定。** 源图与显示换算式：`F显示 = F源 × W显示 / W源`，反算 `F源 = F显示 × W源 / W显示`（目标显示宽未知时可暂以 `360px` 作压力观察窗，仅作内部试排而非平台标准）。

1. **单张多区块容量核算：** 扣除内边距、图标与配图后得文字盒可用宽 `L`、高 `h`；全角零字距粗估单行字数 `N ≈ floor(L / F)`（混排按实修正）；所需总高 = 各段实际行数 × 行距 + 段距 + 标题/节点/连线/条件标签及全部组距。**完整锁定文案未给齐前，不假定容量够用或强凑终稿；已知溢出先重组、换区、删获准次要说明或拆图，绝不静默删锁字或缩字到糊涂。**
2. **跨比例重排：** 换比例必须逐区重算版面、断行与图像占位（绝不直接把旧比例坐标硬塞进新画布），同时完整保留原命题、锁字权限、角色色与字体角色。
3. **系列视觉统一（固定角色，变化图式）：** 多张连续知识卡先把**跨页共用规格**钉死并展开到每张独立输出——统一同角色字族/字重/字号层级、色板与符号语义、标题对齐线、外边距与页码规则；仅让每页具体图式随内容切换。需要页码时统一开启并固定锚点（无指定时可从右上安全边界内侧右对齐起试，同标题隔至少 `0.5F`、弱于主标题层级），明确封面是否计入；单张图不加无意义页码。

## 本地排印参数起点（仅作可复现试排基准，非行业硬标准）

| 项目 | 试排起点与常用范围 | 调整与红线 |
| --- | --- | --- |
| 普通短封面主标题 | `F源 = 0.10 W源`（参考 `0.08–0.12 W源`） | 强展示大字不以 `0.12 W源` 为上限，先定语义分行与字块宽 `L`，按 `F ≈ L / (N × g)` 反算并保完整字盒。 |
| 信息流副标题 | 主标题的 `0.45×`（参考 `0.40–0.55×`） | 保持清晰第二层；绝不压成脚注。 |
| 知识卡正文与标题层级 | 正文最终显示 `16px` 起排；副标题 `1.25×`、主结论 `1.5×` | 正文读不清先扩区、换字形或拆图；中文单栏先试 `14–24` 全角字/行（起点约 20 字）。 |
| 行距与段距 | 标题行距 `1.15×`（`1.05–1.25×`）；正文行距 `1.5×`（`1.4–1.7×`）；段间额外距 `0.75em` | 过紧致笔画粘连即放开，不为塞字压缩行距。 |
| 字距（tracking） | **中文与所有阅读正文恒保持 `0em`**；仅短 Latin 全大写展示标题可试 `0.04–0.16em`（起点 `0.08em`） | 绝不拉宽汉字或负字距硬塞，绝不把西文宽字距套给中文。 |

## 已核实常用中英字族速查（精排按角色拆选）

中文展示、中文阅读、Latin 展示、Latin 阅读与等宽数字**各自独立选字**，不互相捆绑，也不以风格词替代真实字族。以下仅标明字体项目公开的覆盖与真实字重/轴，**不代表本机已装或生图引擎必能精确复现**；精排交付写明完整菜单名（如 `Source Han Sans SC` 与旧静态 `CN` 菜单名勿混写），缺字指定覆盖完整的中文无衬线回退，**严禁伪造合成粗体、假斜体或不存在的变量轴**；光学尺寸轴 `opsz` 默认交渲染器自动处理，绝不把像素字号当轴值填入。

| 角色与气质 | 推荐核实字族 | 真实覆盖与可用字重 / 轴 | 适用边界 |
| --- | --- | --- | --- |
| **中文无衬线（通用 / 高密阅读 / 强展示）** | `Source Han Sans SC` / `Noto Sans SC` / `IBM Plex Sans SC` | Source Han Sans 静态含 ExtraLight–Heavy；Noto Sans SC 变量 `wght 100–900`（正文 400–500、标题 700–900）；IBM Plex Sans SC 含 Thin–Bold | 通用封面、信息图与 UI 首选；高张力短标题可探 Heavy/900 并查小图字腔不粘连。 |
| **中文衬线（编辑感 / 书卷 / 文化标题）** | `Source Han Serif SC` / `Noto Serif SC` | Source Han Serif 含 ExtraLight–Heavy；Noto Serif SC 变量 `wght 200–900`（标题 400/600/700） | 适合出版、故事与情绪短标题；密集长正文或极小标签优先配无衬线阅读字。 |
| **中文手写温度（仅短展示标题）** | `LXGW WenKai`（霞鹜文楷） | 公开 Light / Regular / Bold 三档 | 仅用于短标题（Regular/Bold），须逐字核复杂专名覆盖；正文一律配中文无衬线。 |
| **西文无衬线与等宽数据** | `Inter` / `IBM Plex Sans` / `IBM Plex Mono` | Inter 变量 `wght 100–900`；IBM Plex Sans 静态 Thin–Bold（仅特定变量包带 `wdth 75–100`）；Mono 仅用于短代码、ID 与等宽数据 | 纯 Latin/数字，不含汉字；绝不把 Mono 扩成长段落，不把 Latin 设成中文回退。 |
| **西文特色展示（仅短 Latin 标题）** | 窄体 `Oswald`（`wght 200–700`，无 `wdth`）；高反差衬线 `Bodoni Moda`（`wght 400–900`, `opsz 6–96`）；编辑衬线 `Source Serif 4`（`wght 200–900`, `opsz 8–60`） | 均仅含西文字集，不含汉字 | 仅限短 Latin 展示字；相邻中文独立配中文字族，绝不横向压缩汉字凑窄体。 |

## 中文语义断行与标点禁则

1. **按语义组断行，连读回查不造歧义：** 保持主语、否定词、限定语、数字与单位相连，锁定文案只换行不改字。分完行连起来整句重读，确认没有因为换行让动作错配主体或让单行截出错误断言。
2. **中文禁则（CLREQ）：** 句号、逗号、顿号、分号、冒号、感叹号、问号及右括号/右引号等**避头标点不放行首**；左括号/左引号等**避尾标点不放行尾**；破折号与省略号保持连写不断开。

精排路线如用户明确要求精确字体规格，在[路线 B](prompt-compilation.md#路线-b交给设计或工程执行的精排规格)中完整写出中文标题字、中文阅读字、Latin/数字字、逐字覆盖与回退、字级/行距/组距与不合成限制，未在真实渲染器加载前诚实标为设计目标。
