# 从作品材料生成艺术构图

**作品的气韵长在它自己的物件、处境与节奏里；挖出那颗真核，再让字和画面长成一体。**

当成品需要把歌词、剧本、剧情、建筑/物件照片或既有素材转化成整幅有辨识度与情绪感染力的艺术主视觉（尤其是作品发布海报，或以作品本体为主视觉的封面）时读取；按既定模板换字或单图已自足时无需读取。排印细数值归[版面与中文排印](layout-typography.md)，多焦点与精细色板归[视觉情绪、层级与强调](visual-hierarchy.md)，经典海报案例出处归[SOURCES.md](../SOURCES.md)。

## 1. 四类作品材料的真核提取与防脑补边界

先分清材料里真实存在什么、作者最想传达什么情绪、观者光看画面能不能直接读出，以及哪些属于设计阐释（获授权阐释绝不冒充原作事实）：

| 作品材料 | 优先挖出的情感与视觉锚点 | 严禁擅自脑补 |
| --- | --- | --- |
| **歌词 / 歌曲介绍** | 反复出现的具象意象、人物称谓与关系、具体动作、情绪转折、段落疏密与已说明的演唱气质。 | 仅凭歌词虚构节拍、乐器、调式、录音棚现场或歌手真实经历；无音乐材料时标待定。 |
| **剧本 / 故事 / 短片** | 人物当下处境与未完成动作、关键道具、空间阻隔、两人张力与最能代表作品余韵的一瞬（不复述全剧情）。 | 未给的时代因果、隐藏结局或直接剧透反转；不把安静关系强画成激烈动作。 |
| **建筑 / 物件 / 作品照片** | 强识别主轮廓、视点透视、局部结构线、光色与材质表面、画面原有留白空处。 | 仅凭色调臆断年代、地点、材料名或作者隐喻。 |
| **既有设计稿 / 过程图** | 原素材与设计分区边界、被放大或重复的局部、字图关系。 | 把上下对照板误认成一张海报，或把纯装饰撕边直接当时间因果。 |

把选定锚点按冰山原则凝成唯一核心母体：**真实材料切片 ＋ 它承载的情绪与共通处境 ＋ 画面唯一可见承担者**。舍弃情感零度的无关道具清单；若落不到具体可见承担者，说明构思还停在抽象口号，必须重找真核。

## 2. 先定整幅构成方式（单一有力，远胜拼贴杂烩）

在拉文字框之前，先决定观者第一眼遇到哪一种整幅形态——经典平面实践的启发在于**让主形轮廓、空间节奏与题名成为同一个有机整体**（如用锯齿剪影轮廓牵引片名走势，或用疏密几何节奏转译音乐强弱停顿），绝不套现成名作模板或堆砌廉价题材贴纸（音符、胶片、宫灯）：

| 整体构成 | 适用信号与画面动作 | 边界与切换 |
| --- | --- | --- |
| **完整场景** | 单一空间与光线已自带强烈情绪和辨识度。定好观察距离、前后景光影与留白呼吸区，让题名顺势落进场景的方向或空处。 | 不为显得有设计感强行切碎画面；缺干净托字区时调景别或留出独立题带。 |
| **主体与局部重构** | 主体负责立身份、放大局部负责演情绪细节或材质张力。用尺度反差、裁切边、叠压或共同色线把碎片锁成一个节奏。 | 每个局部须有明确情绪或叙事职责，删掉像独立贴纸的无用碎图。 |
| **符号凝练** | 一件真实道具、剪影轮廓或空间接触已能浓缩全作之魂。提纯最具辨识度的外形与材质，借位置、重心与字图咬合放大余韵。 | 符号必须可追溯到材料或标作设计阐释，绝不用泛题材通用图标凑数。 |
| **抽象节奏** | 作品的重复、停顿、疏密、聚散或强弱对比比具象人物更能击中情绪。将可指认的节奏转译为形状尺度、间隔密度、方向与留白。 | 视觉转译绝不伪装成真实波形、声谱或乐谱测量图。 |
| **文字成为造型** | 作品名本身词形有力或意象浓烈。锁定逐字原文，靠字块轮廓、大小错落、笔势、负形或纸墨材质直接撑起整幅主角。 | 造型表现只作用于展示标题，保住关键笔画与自然读序；必要署名与信息保持易读。 |

### 当代平面海报构成方法

定好整体构成后，用下列五种现代平面语法把**题名与主视觉牢牢锁死**，选能让作品情绪与身份最出彩的一种：

| 构成语法 | 适用气质与画面动作 | 失配时调整 |
| --- | --- | --- |
| **字图穿插与破框** | 主体有强轮廓或冲击动势（如机甲、动作、燃系作品）：主体局部越框居前、大字落中层咬合动势轴、背景退后拉出纵深，写清精确遮挡交叠点。 | 必须露出标题关键笔画与主体核心识别；缩略读不全题名就挪交叠点或改为共边咬合，破框不侵裁切安全区。 |
| **瑞士理性网格** | 秩序、建筑、科技、当代展览或冷静理性主题：以共享列线、基线与横竖呼吸留白定位题名、主形与精炼信息，靠少数格线上的剧烈尺度疏密反差造高级张力。 | 若等分切坏主体动势，合并栏位或跨栏突破并守住主对齐锚线。 |
| **东方留白与竖排韵律** | 民谣、抒情、东方意境或含蓄留白题材：以大片有呼吸的空处与景物走向（水际、光带、屋檐、器物势）自然引向竖排题名与精巧落款。 | 长标题、多数字或西文混排阻碍竖读时，说明信息改横排，只让简短展示题名竖置；纸墨与色面随材料定，不硬套古风旧套。 |
| **杂志编辑式构图** | 兼顾质感主图、大气题名与若干真实发行字段（期号、日期、署名）：主图利落裁切，标题呼应画面视线或边界，必要信息沿共享基线收拢成干净编辑层。 | 只放真实必要字段；信息割散主图时先收拢成独立底栏或侧栏，缩略先保题名与情绪主形。 |
| **负形同构与视觉双关** | 作品自带两重互相说明的核心意象且能共用边界：让主形的外轮廓或内部留白自然显出第二重可辨形象，一眼顿悟。 | 若需画外解释才看得出来，立刻简化轮廓、加大图底反差或退回单一强符号。 |

**字图换位试金石与黑白小样自检：** 动作、光向或留白主导画面且题名位置未锁定时，试把题名字块移到画布另一块同样可读的空处——若两处能随便互换，说明字图还没长在一起！必须改用主形动势轴延续、轮廓贴合、前后穿插或留白导引把字锁死。收尾前默想黑白轮廓小样，核查共边、呼吸空处、前后层与缩略一眼辨识，删掉最像多余贴纸的元素；系列作品则沿用固定识别骨架，只在开放区呈现本期独特情绪与主形变化。
