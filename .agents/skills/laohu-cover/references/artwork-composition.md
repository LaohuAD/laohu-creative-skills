# 从作品材料生成艺术构图

本 Reference 负责把一件作品或一组已有视觉材料，转成当前成品用途所需的整体艺术构图。它处理“作品内容怎样成为画面”这一层：决定选哪处材料、用完整场景/局部重构/符号/抽象形式/文字造型中的何种构成，以及各部分如何共同承担作品表达。它不选择主要用途、不重写作品、不规定统一风格，也不接管字体库、精确版式数值、角色 RGB 或图片生成；是否读取由实际构成问题决定，读取后只处理材料到整体构图的转换，不改变父级已确定的主要用途。

## 触发、输入与返回

当构图问题是从作品、歌词、剧情、照片、建筑/物件或既有图像中选取并转换材料，才能形成整幅主视觉时读取；不论父级已选择作品发布海报，还是以作品本身为主视觉的信息流封面，都按这一局部构成需求调用。用户明确要做拼贴、撕纸重构、符号凝练、抽象视觉、文字参与造型等，属于直接触发信号；即使用户没说这些术语，只要成品需要从作品材料构造主视觉，也可按此方法执行。

以下情况沿父级通用方法或既定决定继续，不为读取而读取：用户只要按既定版式换标题/日期或做一项局部修正；视觉构成和素材职责都已锁定，只需忠实落地；用户仅讨论成品类别而没有要创作；现有单幅图像、作品标题或确定标志已足以承载目标，且没有新的材料转换问题。简单不等于不完整，方法调用也不以增加复杂度为目标。

调用时沿用父级确定的用途、传播任务、受众、画幅/媒介、完整锁定文案、事实边界、品牌与身份资产、参考图职责、版权/复用许可、系列规则和作者表达。还需读取当前作品中可核的意象、人物处境、动作、关系、空间、重复结构、材质线索及用户明确的强调点。信息不足时区分“设计仍可开放”与“会改变作品含义的事实未知”；前者可在授权范围内作有限阐释，后者只暂停依赖它的构成决定。

返回父级一份可执行的构成决定：

- 本次选用的作品锚点、它在材料中的依据，以及事实/作者强调/设计阐释的边界；
- 整体构成方法、为何适合该锚点、表达重心及主要观看关系；
- 每张图、局部、符号、色面或文字的职责、变换方式、相互位置和保留项；
- 锁定文字与图像/字块的关系、需保护的身份特征、读序、字形和裁切条件；
- 可直接交给后续排版与提示词的相对结构，以及提示词/设计稿/成图各自仍待验证的部分。

父级把材料锚点和作品表达理由带回第三步；把素材职责、重复/省略和解释边界带回第五步；把画面区域、比例、交叠、层级及读序带回第六步；把文字轮廓、断行与读序保护带回第七步；把色彩、边界、质地和空间层次带回第八步；第九步将已选结构翻译为制作路线与完整提示词。若实际问题另涉及字体选择、网格、颜色关系或焦点竞争，再读各自 Reference；不让本文件重复建立那些参数表。

## 从材料中找可见锚点

先分开四件事：

1. **材料里已经存在什么。** 记录能在歌词、剧情、照片、物件或作品资料中明确找到的人物、对象、动作、空间、关系、重复词句、形状、表面与状态变化。照片里可见的轮廓/颜色/视点属于图像证据；文字里写出的处境和关系属于作品内容；二者不能互相冒充。
2. **作者本次要突出什么。** 依据用户锁定的标题、介绍、直接说明或已确认作品意图，分辨这张发布画面需要让观者感到/认识的主旨。不能因为一个物件很容易画，就自动把它认定为作品核心；也不能让广告式“卖点”覆盖作品的实际表达。
3. **观者能从画面读出什么。** 对每个候选锚点说明它如何让观者认出作品、理解人物/对象关系、感到一种处境/节奏，或进入标题。若解释要依赖画外的设计说明才成立，换一种更可见的关系，或把它明确降为气氛材料。
4. **哪些属于新增阐释。** 新增的象征、空间、碎片、纹理或联想可以作为设计选择，但不写成原作情节、作者事实、真实场景或证据。用户授权自定不等于授权虚构作品事实。

按材料类型调整读取方法：

| 材料 | 优先找什么 | 不从材料中擅自推断什么 |
|---|---|---|
| 歌词/歌曲介绍 | 反复出现的意象、称谓、关系、动作、情绪转折、段落间变化，以及用户说明的声音/演唱身份 | 只凭歌词补造节拍、速度、乐器、调式、录音现场或歌手经历；没有音乐材料时把这些标成待定 |
| 剧本/故事/短片 | 人物当下处境、选择或未完成动作、两人/人与物的关系、关键道具、空间阻隔、转折点；发布海报通常选一个可代表作品的瞬间，不复述全剧情 | 未提供的身份、时代因果、结局含义，或把悬念/反转直接揭开；默认选冲突动作而忽略安静的关系变化 |
| 建筑/物件/作品照片 | 主轮廓、视点、可辨局部、比例关系、结构线、光色/表面、画面中真实存在的空处 | 仅凭色调推断建筑时代/象征含义、材料名称、作者意图或地点；除非用户/可靠资料已确认 |
| 已完成的图像/设计稿 | 原始内容、设计分区、被重复/放大/覆盖的局部、标题与图像关系、可见的材料边界 | 把并排展示的原图和设计稿自动视为同一张海报；把撕边、叠放等形式直接解释成时间、因果或对比 |

把选定材料压成内部短句：“材料锚点 + 它承载的关系/处境/节奏 + 画面中可见的承担者”。例如不止写“怀旧”，而要落到由哪种材料中的何种关系或形态产生怀旧读法。若无法指出依据，则它目前只是抽象方向，不是作品特有的主视觉理由。

## 从具体作品取法，不从作品复制模板

以下案例说明怎样把可见做法转成当前任务可执行的决定；它们不是海报模板，也不构成质量保证。来源页、图像位置、所见证据与本地适用边界记录在 `knowledge/封面设计来源.md`。

- **Saul Bass，《The Man with the Golden Arm》电影海报（1955）。** 可见做法是把一条锯齿状手臂压成强烈黑色轮廓，并让它与不规则黑色形块、奶油色空处和片名安排形成同一主视觉；片名的空间关系随主形转折，而不是另找一个无关插图。可迁移动作是：当作品中确有可辨的身体/物件轮廓承担核心处境时，把轮廓提炼成主形，让文字绕行、贴合或借其负形安放。适用边界是当前材料须有能被识别且与主题相关的形态；不复刻其手臂图形、版面、标题字或黑色主形、奶油色负空间、蓝/青/紫色块的整幅配色关系，也不因题材是电影就默认采用剪影。
- **Josef Müller-Brockmann，Tonhalle Zürich「beethoven」音乐海报（1955）。** 可见做法是以不同粗细和间隔的分段圆弧形成由疏到密的视觉运动，而不画出具象乐手；Shizuko Yoshikawa and Josef Müller-Brockmann Foundation 对该作的说明将几何形体与音乐的活力/运动相连。可迁移动作是：当歌曲/作品材料已给出可说明的重复、强弱、停顿、方向或累积变化时，把该模式转为形状间隔、尺度、密度和方向，再与文字建立空间关系。边界是抽象形式只能作为视觉转译；不能假称它是实际节拍/音高图，也不把圆弧或同一色彩直接泛化成所有音乐海报的公式。

新任务须重新找到本作的材料依据和视觉关系；案例不替用户决定主题，不要求模仿名家，也不因为某个手法“经典”就让它挤掉作品自己的意象。

## 先决定整幅怎样成立

在安排文字框和装饰之前，先决定观者看见的是一个完整场景、一个被放大的局部/碎片关系、一个凝练符号、一种由材料转译出的抽象节奏，还是由文字本身形成的主要画面。选择依赖锚点的可见性、作品身份要保留什么、标题文字量和画幅空间；不要求列固定数量的方案，也不要求每项任务做候选实验。只有仍存在会改变作品读法的不同结构选择时，才向用户展示有实质差异的方向；用户已授权创作者判断时直接选定并说明依据。

| 构成方法 | 适用信号与具体操作 | 保护与切换条件 |
|---|---|---|
| **完整场景** | 单一处境/空间已能同时承载作品识别与情绪关系，或源图的轮廓、透视、光线和空处本身有足够表现力。选一个有效观察距离和角度，安排主体关系、前后景、空处及标题进入的位置；必要文字借场景的方向或留白参与，而非必然盖在正中。 | 保留让场景可识别的主体和关键关系，不为了装点而碎片化。标题若没有可读区域，调整景别、画面边界或独立文字区；关键剧情事实不因氛围需要而补造。 |
| **主体与局部重构** | 作品主体与细节承担不同内容职责，或不同尺度并置能让主题被看见。先选一个保留身份的主体形态，再选有明确作用的细节；分别决定裁切边、尺度、朝向、间隔/叠压、共同轮廓或色彩联系，让局部与整体形成可读关系。 | 每个片段需承担识别、叙事线索、节奏、材质或视线作用。重复同一图像只有在尺度对照、节奏、强调或身份复现确有作用时保留；无作用的复制、堆图和装饰裁片删减。局部不能破坏关键身份锚点或暗示材料未支持的联系。 |
| **符号凝练** | 某个真实物件、轮廓、动作或空间关系能浓缩作品的核心关系。保留它最具辨识度的形状/状态/接触关系，减少非必要细节，再通过位置、重心、遮挡或与文字的接触表达本次含义。 | 符号必须能追溯至作品材料或明确标作设计阐释。无法说明它与标题/作品锚点共用何种属性时，换成直接的对象或结构。不要仅凭“音乐、电影、古风”等类型词套用音符、胶片、宫灯等通用图标。 |
| **抽象节奏** | 作品的重复、停顿、疏密、强弱、方向、对称/偏移等结构比具体对象更能代表其形式或情绪。把材料中实际可指认的模式映射到形状、大小、间隔、密度、方向、留白或边界节奏，并注明这是视觉转译。 | 只有材料明确提供节拍、波形、音高或数值时才按其数据身份准确绘制；从歌词/情绪推导的图形不伪装成声谱、波形、乐谱或测量结果。观者若无法辨认这是作品表达而非数据证据，移除数据外观或增加明确的概念表达语境。 |
| **文字成为造型** | 标题/作品名本身具有独特词形、动作或关系，或图像难以比文字更准确地承载主题。先锁定逐字文本、顺序与角色，再用字块外轮廓、比例、断行、错位、方向、字重、局部笔触或负形组织画面；让字与物件轮廓、空间边界或色面产生可解释的关系。 | 保留字形识别、语义读序和必要文字层级；手绘/变形只作用于允许表现的展示文字，不改变文字内容或把关键字做到无法辨认。说明文字和必要署名不能为造型让出其阅读职责。 |

几种方法可以组合，但组合需各有职责，例如主体负责认出作品、局部负责展开关系、文字负责命名；不要把所有形式手段一起使用。纯文字、单图或单符号已经足够时，复杂处理会降低主题清晰度，应停在更简单的构成。

### 当代平面海报构成方法

选好场景、局部、符号、节奏或文字造型后，再决定怎样安排字图。以下五种方法沿用上文的作品取法：从可见关系选择动作，从本作材料决定形态。只采用能让主题、身份或节奏更清楚的做法。

| 做法 | 适用条件与构图动作 | 失配时调整 |
|---|---|---|
| 字图穿插与破框 | 主体有强轮廓或明确动作，标题也承担动势时，让字块贴动势，让主体轮廓局部越出色面或内框。以主体居前、部分字块位于中层、底色退后表现深度，写清前后关系与交叠点。 | 保留主标题关键笔画、主体识别锚点和必要信息。缩略时读不全标题，就移动交叠点、让完整字块与主体共边，或只让主体越框。外框动作不能侵入实际裁切保护区。 |
| 瑞士理性网格 | 材料的秩序、分组或节奏适合用清晰信息层级表达时，用共用列线、基线和横竖留白定位题名、主视觉与必要信息。让主形在少数格线上形成明确的尺度或疏密变化。 | 对齐应让读者找到名称、主体和说明。若等分切断作品动作或构件关系，合并相关格子、局部跨栏，保住网格锚点。 |
| 东方留白与竖排韵律 | 材料有适合延伸的空处、笔势、缓急或有意义的空间距离时，按画面方向安排竖排题名、短落款及可停留的留白。例如用水际、山势或器物轮廓引向题名。 | 用实际中文读序、标点与混排检查竖排。若长标题、数字或拉丁文阻碍辨认，说明区改横排，或只让可读的展示短语竖置。材料决定用什么意象、纸墨和色面。 |
| 杂志编辑式构图 | 需要兼顾有内容的主图、可辨题名和若干发行字段时，先定清晰裁图和主图边界，让标题响应图像中的位置或方向，几条必要信息沿共享基线分组。 | 用真正需要显示的数字、期号、作者或日期填编辑层。若信息把主体割散，先移走可省字段或独立成栏；缩略先保题名与主题，细看仍能找到必读信息。 |
| 负形同构与视觉双关 | 两个与作品相关的意象可共享边界而且能互相说明时，以一个主形的空处或轮廓显出另一形，例如让特定物件的轮廓和作品中另一可识别对象共边。 | 检查观者能先认主形，再读出次形及其和标题的关系。若需解释才认得，简化轮廓、加强留白或回单一符号；保留必要身份与事实边界。 |

动作、受力或节奏统领整幅且题名位置未锁定时，做一次换位检查。把题名字块移到画面另一块同样可读的空区，比较它是否会失去与主形的联系。若两处可以任意互换，回看能否用动作轴延续到字块、让字块靠着受力处的外轮廓，或借前后层/共边承接主体动势。采用哪种由本作决定。落位不能盖住动作接点、识别线索或关键字形。题名独立成区时也可通过轴线、留白方向或清楚的相对位置建立联系。

完成后可用黑白轮廓小样看共边、空处与前后层，再用实际版位检查题名和必要字段。成像正文或制作规格要写明参与接合的具体形体、题名字块和两者可见关系。把构成依据、保护区及回退交回父级。

## 将构成写成画面关系

确定方法后，先写整幅的骨架，再细化材料：

1. **定主要形态和空间关系。** 说明画面首先形成的整体轮廓/色面/方向，以及主体和标题是相邻、嵌入、穿插、遮挡、围绕、呼应还是远离。若有多个部分，说明它们在阅读/情绪上的先后、并列或层叠；只说明可见关系，不把位置自动说成比较或时间顺序。
2. **逐项规定素材变换。** 对照片、人物、物件、建筑局部、背景、纹理、插画或图形，说明取用哪一部分、保留哪项识别、裁切/放大/缩小/重复/旋转/重排/遮挡/显露怎样服务所选表达，以及它在整体中占什么位置。可把颜色、形状、边缘或空间联系作为跨片段统一线索，但它们不必新增事实含义。
3. **安排准确文字成为构图的一部分。** 写明完整标题、必要副题/署名及锁定状态；说明文字是独立信息区、场景内文字，还是参与整体轮廓的字块。描述断行目标、主副层级、读序、字图交叠位置及不可遮断的字形/文字区域。标题可以与画面共同成为第一视觉关系，但不因此取消清楚的文字层级。
4. **确定边界、色面和材质的作用。** 说明留白让观者停在哪里或帮助字图分开；分割/撕边/折页/描边/阴影/纸墨/织物/金属等边界或质感承担的是内容切换、叙事断裂、节奏、材质感还是纯审美触感。颜色选择从作品可见材料、系列要求和本轮表达出发；不把某色固定解释成某种情绪。纹理或“手作感”无需制造新事实，但须有审美/节奏/材质职责，不能仅为填空堆效果。
5. **检查整体是否仍能被读懂。** 缩到发布缩略尺寸，先看作品身份/主题锚点和标题是否可辨，再看叙事关系或设计节奏是否能读；放大检查字形、材质边界、局部与主体的关系、署名和必要信息。删除最像独立贴纸、却没有明确贡献的部分。若细节漂亮但整体关系散，回到构图骨架重排，不先堆更多纹理或描边。

一次撕边、叠片、重复主体、超大字或异色标题只是形式信号；只有与本作材料锚点发生可解释的可见关系，它才成为本作的构成。艺术构图允许使用分区和并置；它们不会自动表示比较、因果、包含或时间。

## 作品身份与系列延续

作品特有不意味着每张都要发明新模板。已有系列的共同字体角色、固定标记、边距、编号和色彩关系优先沿用；只在开放区域内呈现本期作品的差异，例如本期材料改变的轮廓、符号、色面、图像细节或文字组合。判断该差异是否能指向本期来源，同时核对它没有拆掉稳定系列识别。单张作品可按内容决定是否形成新结构；不要把一次独特处理误升为全系列规则。

有多张参考图时，先按[参考图迁移](reference-transfer.md)区分原始作品材料、设计案例、局部细节和最终目标，逐项标清可复用权限。参考图的整体构成可启发方法，不能以“参考风格”跳过对当前作品锚点的选择；用户明确要求复刻布局时则保持所定版式与身份，只迁移允许变化的细节。
