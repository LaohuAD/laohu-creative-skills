# 图形关系与连线

**一根线要能还原成一句真话，一个容器要让复杂关系一眼顿悟。**

当主文或[信息图专项](../skills/laohu-cover-infographic/SKILL.md)需要处理长材料覆盖规划、复杂拓扑与视觉隐喻容器校验、跨区连线路由或节点尺寸规划时读取。排印容量与字体归[版面与中文排印](layout-typography.md)，色彩情绪与对比归[视觉情绪、层级与强调](visual-hierarchy.md)，出处归[SOURCES.md](../SOURCES.md)。

## 长材料覆盖、单张全景与系列拆页

先按读者要解决的问题归组（而非按原稿自然段机械照搬），保住回答问题必需的核心命题、成立条件与关键检验，删去重复铺垫，并在内部核对原命题 → 图内文字/关系 → 所在区块或页的覆盖去向：

- **锁定单张全景：** 选一条统领主骨架（如主轴、冰山上下层、分层树、对比矩阵或关联网），各主区回答一个子问题、条件紧贴节点；**宏观阶段与局部区块必须能一眼看清归属**（通过空间对齐、色带对应或带标签分支，需区分的阶段色彼此清晰可辨），且局部区内仍须用真实静态图式画出内部步骤、组成或状态变化，绝不把整图退化成顶部一条箭头＋几段密字。溢出现实容量时优先合并重复、压获准说明、改画幅或向用户提出范围取舍，不私自拆多张。
- **锁定多张系列卡：** 按可独立回答的子问题拆页，每页保住必要成立条件（不把决定对错的条件藏在另一页造成单页误导），跨页保持统一视觉角色而图式随关系变化。
- **数量未定：** 比较读者需要全局同屏查阅（宜单张）还是循序分步消化（宜系列），结合真实文案容量给出推荐张数与取舍。
- **篇内讲解图：** 直接承接 `laohu-writing` 的锚点、邻文与局部任务，只呈现该处最值得直观看清的局部关系，限制条件留在图内或紧邻图注；材料不足以支持关系时标缺口交回，不替正文编造证据。

## 先按任务与关系选图

先明确读者要做的认知动作，再选最贴合的图形。**无序并列或独立事实用清单、并置或网格即可，不必强画边和箭头；证据缺失的边只留已知陈述并标待核，绝不补画假因果或假循环。**

| 真实关系与读者任务 | 优先图形形式 | 必须守住的事实边界 |
| --- | --- | --- |
| **并列列举** | 清单或同级并置模块 | 标明并列依据，不凭相似外观硬造分类或步骤。 |
| **分类、层级、整体与部分** | 树形、嵌套包含或分层框架 | 分类须有明确统一依据；容器边界不自动暗示先后、因果或重要度。 |
| **物体组成或空间位置** | 剖面/对象示意图配引出标注 | 标注线精准指向确认部位、保留真实方位；无实拍时采用明确概念示意画法。 |
| **先后顺序、条件分支或循环** | 流程图、分支图或时间轴 | 写清分支条件；只有材料给出真实时间比例时才按距离编码时长；确认闭环才画循环。 |
| **同一对象操作前后状态变化** | 前态 → 操作 → 后态并列示意 | 保持对象身份可对应，标出触发条件；诊断分支不误画成循环反馈。 |
| **多概念语义关联** | 概念图或关系网 | 每条关键边旁标短关系词，能还原成材料支持的自然语言命题。 |
| **同组对象共同属性对照** | 矩阵或对齐比较表 | 行列共同维度必须已知，绝不为凑整齐把无关项塞进同行或同列。 |
| **精准数量比较 / 趋势 / 分布 / 相关** | 条形/点图（比较）、折线（连续时间）、直方/点分布（分布）、散点（双变量相关） | 精确量值优先用共同位置或长度编码，保留单位、基线、时间范围与样本前提；相关散点绝不暗示因果；缺测间隔不画等距。 |

## 按真实关系选择视觉隐喻容器

选定真实拓扑后，若材料自带贴切的物理或结构对应，用视觉隐喻容器能让复杂逻辑在第一眼就产生强烈的直观顿悟与审美记忆点。**先遮掉装饰确认底层拓扑与命题完全准确，再检查轮廓与面积绝不会让读者多读出一层假比例、假步骤或假因果：**

| 视觉隐喻容器 | 适用真实关系与映射动作 | 防误读边界与回退 |
| --- | --- | --- |
| **冰山模型** | 外部可见表象与底下支撑机制的鲜明对应：一条清晰分界线隔开水上可见表现与水下底层能力/原因，上下部位可精准对应。 | 冰山大小不代表数量占比；若材料仅并列两类现象而无支撑关系，改并列对照。 |
| **漏斗 / 管道** | 对象经历明确的筛选缩减（漏斗）或传输分流（管道）：依次标清输入、筛选条件、阶段与去向。 | 宽度仅在基数与单位都有据时编码数量；无真实流转关系改分组。 |
| **天平 / 杠杆** | 两端存在明确的权衡取舍、平衡或以小博大作用：标明共用比较维度、两侧对象与支点条件。 | 倾斜角度和砝码大小易被读成量差；无量化或受力依据时改水平等权并置。 |
| **同心圆 / 洋葱层** | 真实由内而外的包含、包裹或核心到外围分层：每圈写清层名与真实成员归属。 | 圆圈面积不代表占比，相邻圈不自动表示先后进程；无包含关系改树或网络。 |
| **解剖 / 透视标注图** | 内部构造、前后遮挡或部件方位决定理解：用切面、展开层或局部放大配清晰引出标注。 | 缺实物图时保持克制概念示意质感，绝不伪造实拍、测量尺寸或未证实部件。 |

## 拓扑决定整体空间与连线路由

空间骨架随拓扑自然生长，**绝不为看起来整齐把完全不同的关系强切成等大圆角白卡**：
- **交集共享成员**才用交叠区或 Venn 图（交叠面积不代表占比；仅节点相连无共同成员时用关系网）；
- **一分多 / 多汇一**用清晰分叉与汇合点，把且、或、条件紧贴分叉处；
- **多路径共享阶段**才用对齐泳道，无关清单绝不加泳道暗示先后；
- **多交叉网络**优先重排节点序与分组减少交叉，交叉仍遮挡读法时以一条真实主关系作主轴、把局部子图贴在对应节点旁并标跨区连线。

## 几何关键词与边线语义

先定关系命题与本图图例，再选线型与路由；**线条外观只帮助追踪，绝不脱离图例自行发明通用含义**：

| 关系与布局条件 | 线型 / 路由做法与关键词 | 语义边界 |
| --- | --- | --- |
| **明确起点到终点** | 单向箭头 + 边旁短关系词 | 箭头仅示方向，不自动等于因果或时间先后。 |
| **双向成立 / 对称无向** | 双向同义用双向箭头，异义拆两条单向边各写关系词；对称或并列用无箭头连线标关系 | 绝不因习惯给所有线加箭头；导视阅读线与事实关系边视觉彻底区分。 |
| **网格清晰、需沿区块绕行** | 正交折线（`orthogonal connectors`, `grid-aligned routing`, `labeled edge`），少弯折不穿字 | 直角折线不暗示层级或因果。 |
| **直线/折线拥挤或相切** | 清晰弧线（`curved connectors`, `separated endpoints`, `edge label clearance`） | 曲率不表强弱或反馈；仅真实循环才首尾闭环。 |
| **局部真实包含 / 同组** | 共同容器框（`group container`, `nested containment`, `shared region`），组名贴边界 | 装饰留白框不是包含容器；卡片内点状分隔线不继承关系边语义。 |
| **同字段多对象对照** | 带明确行列标题的矩阵（`labeled matrix rows and columns`, `aligned comparison cells`） | 缺共同维度不硬造矩阵。 |
| **已证实的带条件关系边** | 同图默认同义用实线；条件边可选本地虚线起点（线段长 `3L`、空隙 `2L`，`L` 为线宽，关键词 `medium-dash conditional edge`, `explicit condition label`），边旁写清具体条件并在图例定义 | 虚线仅作本图本地定义，假设或待核关系须明标状态，绝不伪装成已证实。 |

## 图形尺寸精排试排起点（以最终显示主节点标签字号 `F` 为基准）

仅在多区块容量核算或路线 B 精排时使用，成图后按实际显示尺寸复核；细线断裂或箭头并成黑点时先简化关系、扩画布或拆图，不靠加粗线条挤占文字：
- **节点文字内边距**：四边各 `0.5F`；**同组节点间距**：`1.5F`；**跨组节点间距**：`2.5F`；
- **连线宽**：`max(1px, 0.1F)`；**箭头长 × 宽**：`0.6F × 0.45F`；**连线标签净空**：上下至少 `0.5F`。
