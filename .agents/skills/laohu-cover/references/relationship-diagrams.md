# 图形关系与连线

一条线要能读成一句有依据的话；路线只帮助追踪，不替材料补出关系。

## 何时读取

当主文第二步需要从长材料确定知识覆盖，第四步需要组织单张全景、系列或具体关系图，或第六步需要解决节点、连线、图例与交叉时读取。输入是内容清单、命题与条件、观看任务、单张/系列要求、数据及单位、目标显示尺寸。返回第二步的覆盖去向、第四步的全图与逐区图式草案（对象/状态、关系词/条件、局部标注和图文职责），再将说明分工交第五步、位置与连线规格交第六步。

## 从材料确定讲解覆盖与成图数量

**先保住要讲清的判断，再决定用几张、画几块。**主文第二步的内容清单是本节输入，按读者问题而非原稿段落归组。必要点包括回答主问题的结论、使结论成立的关系/条件，以及学会操作所需的选择和检验；背景、近义重复和无关展示不自动列为必要点。用“原命题→本图文字/关系→所在区块或页”的简短映射核覆盖，图式选择后再回查，不把清单整张贴给读者。

| 输入与阅读任务 | 组织决定与产物 | 容量或语义冲突时 |
|---|---|---|
| 用户明确一张全景图 | 选材料支持的统领结构，如流程、分类树、比较矩阵或概念网络；每个主区回答一个子问题，条件和例子靠近对应节点。先扫到总关系，再读局部解释。 | 保留必要点与跨区关系，合并重复，压缩获准说明；仍放不下就提出放大阅读、改变画幅或减少范围的具体取舍，不自行改为多张。 |
| 用户明确多张讲解卡 | 按可独立回答的子问题拆页；每页包含结论及理解它所需的关系/条件。案例可连续展开，但标明承接且不把关键条件留在另一页让本页误导。封面只承担进入系列的理由。 | 试排后决定页数；某页拥挤才拆，若相邻页反复讲同一关系且没有新判断就合并。封面是否计数须统一。 |
| 数量未定，要求完整讲清 | 先判断读者需要全局查阅还是连续学习，再用真实文案与目标显示条件比较单张/系列。给推荐数量、每张问题与取舍。 | 缺少会改变选择的观看条件时只问该项；用户授权自定则注明工作条件，不能用任意字数阈值决定页数。 |

单张不是系列缩略拼贴，系列也不是把一张图切成等份。统领关系不等于所有边同义：主流程、分类、反馈和条件支路分别标注。只有关系本身要求时才采用四列、闭环或树，不能先选整齐版式再凑节点。单张与系列的视觉角色和容量分别交[版面与中文排印](layout-typography.md)落实，不在本节再设字号表。

区块式知识图要把全图阅读骨架与区内关系分开处理：第四步直接消费主文第二步已经按拟放区块标记的内容关系，不另建重复清单。全图主流程或阶段条只说明整体导航，不能代替主要区块内影响理解的步骤、条件、反馈、组成或空间关系。选图时不把图形缩成顶部箭头和节点连线；按材料选用已有图式与标注分支，让对象、局部位置、状态变化或操作关系在画面上可见。短关系词和条件标签贴近对应图形；解释文字补定义、证据、案例状态或限制，不独自承担已经确认的区内关系。没有实证素材时，解释性插图明确标为概念示意。

## 把知识点转成可检查的讲解

**换图式可以，换命题不可以。**每个分类先写“按什么分”，每个步骤先写“做什么及为何进入下一步”，每个判断保留触发条件和检查依据；再把它们转换成节点、说明与边。压缩删的是重复表达，不是限制条件或区别依据。

- 分类图：标题或组名明确分类依据，成员在同一维度上成立；用途、受众、阶段和组成不能因名称方便互换。类别数量由材料决定，不把某次案例的四项、六项固化为通用模板。
- 方法图：操作性内容给出材料支持的“什么情况→采取什么动作→怎样检查”；缺条件、动作或结果时保留缺口，新增建议明确为建议，不冒充原案例已验证的方法。
- 案例图：保留具体场景、采用的办法、观察到的结果或不足。图面若称“案例/测试”，至少呈现足以理解该次判断的输入和实际观察；只有泛化步骤时改为方法示意。无需复刻所有摄影细节，只有它改变本页结论或举证时才重点展开。
- 跨区关系：一条边写明起点、终点与关系词。重复学习的返回边表示迭代；“问题不清才诊断”等条件支路连接实际处理位置，不能因为都能画弯箭头而合并。导视箭头只安排阅读，不承担上述知识关系。

逐个主要区块检查：只看静态图式、节点和短关系词/条件标签，能否复述材料支持的关系；再读相邻解释，确认它补充定义、证据、案例状态或限制，且没有与图式冲突。若必须读完长段落才知道已确认的关系，或图形暗示材料未支持的关系，就修正命题或图式。真实无序并列和独立事实可留作清单或网格；关系证据缺失时保留已知内容并标待核，不画未知边。

## 先按任务与关系选图

先问读者需要列举、归类、看组成、追步骤、理解概念关系、比较对象，还是判断数量变化；再选能够直接承载该任务的图形。真实无序并列或独立事实可以用清单、网格或表格，不必加边；关系证据缺失时保留已知陈述并标待核，不画未知边。凡材料已确认、且会影响读者理解的关系，都由合适的静态图式可见地承载，配套说明只补定义、证据、案例状态或限制。

| 关系与任务 | 优先形式 | 保留条件 |
|---|---|---|
| 并列列举 | 列表或同组节点 | 先给出并列依据，不凭相似外观造分类。 |
| 分类、层级、整体与部分 | 树、包含结构、分层框或标注图 | 只有材料支持父子、组成或真实成员分组时才使用层级与嵌套；容器边界不自动表示顺序、因果或证据强弱。 |
| 对象的组成或空间位置影响理解 | 对象示意图配局部标注，或按材料安排对象的相对位置 | 标注线须明确指向材料确认的部位；用相对位置表达空间关系时，保留真实方位和对象边界。没有实物图或实证素材时标为“概念示意”，不伪装成实拍、测量或证据。 |
| 已确认的顺序、条件分支或循环 | 流程图或时间线 | 写出分支条件；只有真实时间比例才按比例排时间间隔。 |
| 同一对象在操作前后的状态变化 | 前态→操作→后态的并列示意或流程 | 保持对象身份可对应，标出材料确认的操作和触发条件；只有材料支持反馈或返回时才画回路，不把诊断条件改画成反馈。 |
| 多个概念间的语义关系 | 概念图或关系网络 | 节点间加关系词；跨不同分区的关键联系可作为 cross-link 单独检查。 |
| 同一组对象的属性对照 | 矩阵或比较表 | 行列共同属性和维度必须已知并明确标注；避免空间位置让无关对象看成一组，不能为填版硬造行列。 |
| 类别间量值比较 | 条形图或点图 | 类别使用共同位置/长度尺度，保留单位、基线和量值范围。 |
| 连续时间上的变化 | 折线图 | 横向位置按实际时间坐标；缺测间隔或不等时距不得画成等间隔。 |
| 离散时间事件 | 时间线 | 事件顺序明确；仅在距离代表实际时间时按比例放置。 |
| 数值分布 | 直方图或点分布图 | 说明分箱或点的样本含义，保留必要的样本量、单位和范围。 |
| 两个数值变量的对应 | 散点图 | 位置按两轴各自尺度；相关图不暗示因果。 |
| 少数对象的多项离散属性 | 矩阵或比较表 | 行列维度定义一致，便于横向比对。 |

概念图按 Joseph D. Novak 与 Alberto J. Cañas 的方法，以焦点问题限定范围，用概念节点和连接词组成命题；交叉链接可以表达不同分区间成立的联系。每条关键线都要能还原成材料支持的命题。Tamara Munzner 的任务抽象、标记与视觉通道、网络与树形章节支持先辨认查找、比较、排序或分布任务，再选编码；以上表格将常见数量任务映射到可读图形。精确量值优先用共享位置或长度，色相主要区分类别。面积、线宽、颜色明度只有在变量有定义时才代表量值。

## 由拓扑选择整体空间

前表决定关系适合什么图式；再看这些关系怎样相连，确定整幅画面的主骨架和局部图的位置。空间安排跟随已确认的拓扑，不为齐整把关系切成同款卡片，也不另造一套关系词典。

| 已确认的拓扑 | 整体空间候选 | 选择条件与边界 |
|---|---|---|
| 真实包含、组成或分类层级 | 树枝或嵌套区域 | 只有材料确认父子、整体/部分或真实成员归属时才用；层级需要强调归属时可嵌套，层级较深或分支多时用树。视觉分区框不自动表示真实包含。 |
| 多组共享成员或特征 | 交叠区或 Venn 图 | 交集只放确实同时属于这些组的成员/特征；交叠区域不代表数量或占比，不能用面积编码大小。若只是节点相连而没有共同成员关系，改用关系网络或标注，不画交集。 |
| 一个对象明确分成多个去向，或多个输入明确汇到同一结果 | 可见分叉或汇合点 | 将条件、结果贴近分支/汇合处；`且`、`或`、先后顺序和回返去向只按材料标注，证据未说明时不推定汇合逻辑。 |
| 多条路径确实经过共同阶段 | 对齐泳道或共同阶段列 | 只有共同阶段对读者比较有用时采用；不能为排得整齐给无关清单加泳道或让同列位置暗示未确认的先后/对应。 |
| 多类关系相连或节点交叉较多 | 网络全图，或主轴加邻近局部子图 | 网络能清楚呈现全局关系时保留整体；若交叉遮住局部读法，以一条真实主关系作轴，把相关子图放在对应阶段/对象旁，保留必要且有标签的跨区连接。 |
| 对象需要按共同属性直接比较 | 共用坐标、基线或矩阵 | 只在共同维度与尺度已知时使用；同一位置表示同一维度，不能为追求对齐把不相干对象排成比较关系。 |

混合拓扑先确定观者需要一眼掌握的主关系，再把条件、组成或证据局部贴近它；主轴只承担实际的整体关系，不能吸收材料没有说明的交集、分支逻辑或反馈。若主轴/阶段和多个局部区块并存，须用邻近、对齐或带标签的分支说明每个区块实际展开哪个阶段或对象；一个阶段可展开多个区块，不强造一一对应，也不只靠颜色或上下位置猜归属。图式与空间安排定后，再按后文选择线型与路由；有标签的局部图、注释或证据可以有不同面积和形态，不必每一项都变成节点框。

## 再决定方向、样式与路由

| 条件 | 选择 | 修正或例外 |
|---|---|---|
| 关系有明确起点与终点 | 单向箭头，旁边写明关系词 | 箭头只显示该关系的方向；它本身不表示因果或先后。 |
| 关系确实在两个方向都成立 | 双向箭头，或两条分别标注的单向边 | 若两个方向的含义不同，分开绘制和命名。 |
| 关系对称、并列或无明确方向 | 无箭头连接，并标出关系类型 | 不因视觉习惯给所有边加箭头。 |
| 各条线表达同一种已确认关系 | 实线作为本图默认连线 | 默认仅对这张图有效，不宣称实线跨图代表某个证据等级。 |
| 材料明确写出条件边，且当前图尚未定义其线型 | 可把线段长 3L、间隔 2L 作为本图虚线的本地试排起点；在图例和边旁写出具体条件。 | 3L/2L 是可选几何起点，不是跨图固定语义；同图的其他线型须各有图例定义。不能为了视觉完整而补造未知关系。 |
| 节点少、路径短、没有遮挡 | 直线优先 | 线段不得穿过文字或造成节点归属不明。 |
| 流程、层级或技术关系需要逐段追踪 | 先试正交折线 | 保持弯折有序并贴合布局网格；若折角增加交叉，改路由。 |
| 直线或折线拥挤，弧线更容易辨认 | 试曲线 | 曲线也要避免相切、相压和标签碰撞；不是装饰弧线。 |

先调整节点顺序、分组和层级，再绕开交叉；将关系词贴近对应的边，把解释文字靠近所解释的节点。交叉不可避免且会改变读法时，拆成子图或分层呈现，不依赖读者猜测线条在交点处是否相连。图例只解释读者不能直接判断的线型、颜色、形状和尺度。

IBM Design Language 技术图规范将连线含义交由具体图示定义，要求以图例说明线型、颜色和形状；默认建议沿网格作正交路由，也允许直线或曲线按可读性切换。Graphviz 将线型、箭头方向和路由分别设为绘图属性。这些资料说明可用哪些画法及需明确本地图例，并不规定虚线或双向箭头的统一语义。

## 几何关键词与边线语义

提示词先写关系语义，再写几何关键词。以下画法不改变边所表达的命题；几何只帮助追踪。关系状态由材料和本图图例定义，不从线形推断通用语义。

| 触发条件 | 可观察操作与提示词关键词 | 语义边界 |
|---|---|---|
| 网格清楚、边线需沿区块边缘绕行 | 正交折线；相邻边保持水平/垂直，少弯折，避免穿字与交叉。关键词：orthogonal connectors、grid-aligned routing、labeled edge。 | 直角路径不表示层级、时序或因果；仍需关系词和箭头方向。 |
| 直线/折线让路径交叉或相切，弧线更好区分 | 曲线连接；为每条边保留清楚起点、终点和关系标签。关键词：curved connectors、separated endpoints、edge label clearance。 | 曲率不代表强弱、反馈或时间；仅当材料支持循环时才首尾构成环。 |
| 材料明确说明局部隶属、组成或同组 | 容器/包含框；只包围一组真实成员，标题或组名贴近边界。关键词：group container、nested containment、shared region。 | 边界不暗示步骤、排名、因果或量值；单纯留白/装饰框不是关系图容器。 |
| 需要用两个共同字段比较对象，字段和值可核对 | 矩阵；行列各写明一个真实属性，单元格只放对应对象/值。关键词：labeled matrix rows and columns、aligned comparison cells。 | 若共同字段未知，沿材料已知陈述继续，不补造行列，不用矩阵代替缺失关系证据。 |
| 材料写明边只在某个条件下成立，且当前图尚无条件边编码 | 可选本地虚线起点：每段线长 3L、空隙 2L，L 为当前连线宽；边旁写条件，图例说明本图语义。关键词：medium-dash conditional edge、explicit condition label。 | 本地 3L/2L 只是参数候选，不是跨图标准。其他真实关系状态可选本图所需线型，但每种线型须有单一且明确的图例含义；材料标记为假设/待核时要明确标出状态，不可伪装成已证实。 |

图形关系和本图图例是线型语义的真源。隔断卡片内容的点状分隔线不是连线，不继承关系图线型含义。虚线、点线、颜色或其他边形状都不能自行补造关系；材料没有关系证据时保留已知陈述，不画未知边。

## 图形尺寸的本地试排值

以下值是便于开稿与逐项调整的本地启发式，不是 Novak、Munzner、IBM、Graphviz 或行业标准。`F` 指目标最终显示尺寸下的主节点标签字号，`1F` 即该字号对应的显示尺度；所有值按最终显示图像核验，不用源画布放大状态代替。

| 项目 | 起点 | 每次调整 | 何时修正 |
|---|---:|---:|---|
| 节点文字内边距 | 四边各 `0.5F` | `0.25F` | 多行标签拥挤时先增内边距或扩大节点；不删锁定文字。 |
| 同组节点外框间距 | `1.5F` | `0.5F` | 连线标签与节点挤压时加大；空间不足先简化或分图。 |
| 不同节点组间距 | `2.5F` | `0.5F` | 组边界仍不清时增距或加共同区域提示；不要只加颜色。 |
| 连线宽 | `max(1px, 0.1F)` | `0.05F` | 目标尺寸下过弱才加粗；若线条压过节点文字，先减线宽或降低非主关系对比。 |
| 箭头头部长 × 宽 | `0.6F × 0.45F` | 每边 `0.1F` | 箭头难辨时增大或放大图；箭头比关系标签醒目时减小。 |
| 连线标签净空 | 标签上下至少 `0.5F` | `0.25F` | 若标签贴线、贴节点或与其他边相叠，先改路线，再增加净空。 |

若缩到真实显示尺寸后细线断裂、箭头并成黑点或标签不可读，先减少无关关系、放大画布区域或拆图；不要让加粗连线取代关系词或证据限定。目标尺寸未知时，按[版面与中文排印](layout-typography.md)的观察条件复核；不把临时观察尺寸当作平台规格或最低可读标准。
