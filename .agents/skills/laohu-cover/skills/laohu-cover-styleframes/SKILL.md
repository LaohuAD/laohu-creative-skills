# 阶段视觉关键帧选择专项

本子级沿用[父级判定的任务阶段](../../SKILL.md#同一画面任务的后续请求)，承接需要新设或调整完整页面、场景视觉方向的部分。关键帧是可独立观看的完整静态画面，可对应动画某一刻、应用完整视口或页面状态。口述、方案、脚本、分镜、页面结构、交互流程、线框、草图和已有图均可作输入。仅有材料名称、题材词或图片数量不决定调用。本配置是选择型专项，由父级选择和整合。

沿用父级已确认的项目根、工作项目、任务目标、材料、观者、授权、锁定内容、资产、媒介条件和保护项。父级负责整体用途、事实、总体方法、成品整合与验收；本子级负责选帧、共同视觉基线及各新设计帧的具体变量。

## 识别画面状态并确定覆盖

从作品目标和本轮范围找出观者实际会看到、且会改变设计或实现的状态。记录所属作品单元、观者任务、同一时刻可见的对象/文字/布局/动作及已知承接关系。视口、页面、事件或时点按实际材料定位。

把视觉延伸到另一页或另一段时，先用目标位置的截图、实际运行、已确认方案或用户口述核对该处的内容和状态。入口的操作按其实际发生位置记录，去向与到达后的状态须有对应依据。缺少目标位置的依据时，先交可复用的视觉做法及适用范围，待目标状态可定位再补帧和对应检查。

可复用的相同状态共用画面，其余按实质差异决定帧数。每帧只表现同一时刻或稳定状态下同时可见的内容。动画或交互的连续变化影响观看时，说明前后要接得上的对象、位置或方向，以及真正要看见的变化。首尾无法说明关键变化时才补中态，并把需要在播放或实际操作中观察的变化交给制作方。

关键帧接入动画讲解时，先从导演的观看单元选样。确认观众能从该状态认出哪个物件、哪处接触或哪两项变化，从而读懂这一刻的关系。需要推进、分离或局部揭示的物件在画面里保持可辨的轮廓和层次，题字、引线给实际看到的对象留足位置。按[制作说明](../../references/production-reference-handoff.md#逐帧制作说明的唯一格式)交回可取用的视觉属性和需要独立制作的对象，供工程在同一状态对照。

## 截图意图与设计委托

有可访问截图或需要辨认参考职责时，按[参考图迁移](../../references/reference-transfer.md#先辨认截图在当前任务中的职责)核对画面来源、对应状态和可变范围。优先以实际状态相符的原生截图或已确认方案作内容依据，美化沿用已确认的结构、操作方式与状态。另做新方向时，旧主题图可用于核对结构，外观只带入本轮选中的部分。多图混选按区域或视觉变量标明取法，再合看交界处的阅读和操作。

给每个需设计的画面一份简明的内部委托。写明观者为什么到这里、当前状态、已知功能与主要操作、已确认的触发和结果，以及观者应看到的效果。区分锁定内容、设计建议和开放实现。隐藏交互、未显示的状态和数据按证据范围写。缺少关键材料时只暂停受影响的决定。用该委托组织提示词与制作说明。

## 混合组按帧处理

按[制作参考与交接](../../references/production-reference-handoff.md#已有帧与待设计帧分支)逐帧盘点。保留可用的已定实图及其职责，用获准的共同外观基准设计组内仍缺的画面。新帧仍需写清独有任务和变化。

## 界面视觉基线与状态

只有当前关键帧是完整界面、视口或实际交互状态时使用。沿用已有组件或已确认视觉系统，从真实页面任务、可见字段和已知操作确定以下做法，再纳入共同基线与逐帧委托。

1. **用设计变量固定表面和节奏。** 定义背景底面 Canvas、主要内容面 Surface（如 Panel）、浮起层 Elevated Layer（如 Popover）的底色与分隔方式，明确边框、圆角家族、文字层级和间距。没有现行网格时，可用 8pt 间距节奏组织布局与组距，细部与紧凑控件按内容调节。相同职责跨帧沿用，共用角色优先于逐帧定一套色值。
2. **让主要操作的权重清楚。** 每个有明确首要动作的视口或任务状态只给一个 Primary CTA 最高权重；次级操作使用描边、浅底或文字形式，仍保可辨识和可操作。页面只是阅读或任务没有首要动作时，保留真实的操作关系。工具组、危险动作等另依实际任务分组，不能靠放大次级装饰夺走首要操作。
3. **用真实状态差分区分交互。** 对已知的默认、悬停、键盘焦点、选中、展开、空态和校验错误分别说明哪里变化，组合边框、位置、图标或文字与状态色，保留焦点和错误的非颜色线索。弹层需让当前操作对象与核心上下文仍可辨，例如调整锚点、方向、浮层高度，或按已有组件规格切到另一呈现。缺少触发或状态证据时只保留设计建议、待核项和适用范围。
4. **给动态内容留空间。** 从当前内容选择长标题换行、缺图替代、空列表、超长列表或密集数据等代表边界，预定换行、重排或滚动归属及默认占位。记录实际会改变布局的状态，遵循选帧规则决定是否另画。
5. **按可实现的可读性验收。** 以实际字底、目标视口和组件布局核表面顺序、标题、控制区和弹层遮挡。低对比透明层、破坏响应式的异形装饰、压过数据/控制的发光用可读底色、可伸缩结构与明确层级修正。单帧可以交付观感与接口预期；响应式、键盘焦点和交互由实际制作与操作检查。

回交用到的组件/视觉变量、首要动作、已知状态差、长短内容边界及展开避让条件。只有主屏图时把仍需实现和检查的状态写入制作说明，不用想象的控件替代已有事实。

## 共同基线、单帧变化与绑定条件

需要以整帧探索新方向时，优先选一个与实际功能或演出状态可靠对应、能同时呈现主要任务与设计问题的画面。可直接采用满足目的的已有画面。代表帧按表达与使用价值选定，沿用其原有时间或流程位置。

从本作材料、用户认可的画面或适用设计方法中选取具体做法，和真实用途、当前状态及要看到的效果一起写进视觉委托。说明做法会怎样改变画面，例如把取来的线条或字形节奏同时用在主画面和需要快速辨认的入口。只定支撑方向的关系与限制，给生成媒介选择局部构图、字形、材质或装饰的空间。已有足够依据时沿用。把适用的做法变成共同基线，交给相关画面或组件延续，逐处标明哪些视觉变化属于当前状态。

宿主取得代表帧后，按真实状态和选定设计效果检查，定位并修正超出事实或带入旧风格的部位，再将可采用的变量用于相关状态。只写提示词时，以代表帧的设计委托建立预期基线。直接制作只需局部素材时，交付该素材的可见目标和在完整作品中的用法。

将每帧绑定到可执行条件：完整画布或视口、作品阶段/页面/交互状态、触发事件和本帧实际可见内容。比例或尺寸未知且不影响结构时可给可缩放目标并标为待核；不虚构平台规格、像素、时间码、界面元素、功能或数据。

Motion 委托的动画方向帧沿用本片 Brief 的画幅与所取时点。按[方向帧委托](../../../laohu-motion/references/production-collaboration.md#方向帧的两种来源与回交)核对同刻文字、原生字幕阅读区和需在工程实现的字层，把图上可采用的变化交回本片相应段落。

## 提示词、说明与回交

依[制作参考与交接](../../references/production-reference-handoff.md)按帧交付。已核准且有实图的帧交原图与取用说明。待设计帧若要交宿主出图，每帧都提供独立可复制的成像正文和该帧的制作说明，包含真实附件标识及用途、目标状态、共用外观和保护项。若宿主工具用途和接口字段已核实，标明正文、图像输入与画幅各落在哪个实际字段。缺失的附件、工具或参数标待核，已具备的交付照常完成。

“只准备或说明怎样交宿主出图”“暂不调用”限定执行范围，待设计帧照样要有可直接提交的输入。核交接稿时单独取出每帧，看宿主能否按正文与附件生成本帧，无需将状态表或设计说明再改写成提示词。用户只要提示词或明确只要制作说明而未委托准备出图输入时，交所选项。需要直接制作时按父级授权交给宿主执行。

组装首轮成像正文时，用自然语言说明用户或观者在什么情境下做什么、要看到什么。写明已确认的操作触点、状态、原文和素材。对布局、位置和造型做替换检验，能用多种做法兑现且未被锁定的要求，写成可核对的效果。比如要解决菜单遮挡，先要求菜单打开时原素材仍完整可见，横排或缩放仅在有依据时指定。需要比较方向时，各候选使用独立的成像正文。

成像正文使用拟随提示词提交的附件身份、用途与保留范围；给制作方的实现位置和核对动作放入制作说明。文字工具的附件处理及实图状态按交接 Reference 记录，由获授权的宿主实际出图。

回交父级采用的帧、共同基线、各帧的已知状态与独有设计、参考职责和待核项。父级接入整体方向和本轮实际交付，宿主按交接要求核验所得实图或实现结果。
