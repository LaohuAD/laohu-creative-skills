# 阶段与 UI 视觉关键帧专项

**既让使用者第一眼心生好感与信任，又让工程师照着真能落到代码里。** 本专项承接[父级判定的任务阶段](../../SKILL.md#同一画面任务的后续请求)，处理需要新设或调整完整静态画面方向的部分——涵盖应用/网页完整视口与交互状态、动画关键时刻视觉方向帧，以及同一作品的主题迭代与截图美化。沿用父级底座、材料、授权、锁定内容与保护项，不调用兄弟专项。仅把多张网站截图当普通封面参考、或直接要前端开发交接而不需要视觉关键帧时不进入本项。

## 识别画面状态与器物情绪气质

基于**美感可用性效应**（同等底层功能下，器物感与视觉秩序出众的界面被感知为更可靠、更易用），界面与关键帧的美学必须与真实使用场景同级共振——既拒绝冰冷灰白工单式的平淡死气，也严防给普通生产力工具硬糊炫光霓虹、低对比毛玻璃的浮夸表皮拔高：

1. **辨认真正改变设计或实现的代表状态。** 从口述、分镜、线框、方案或截图中找出观者实际看到的独立画面，记录所属单元、观者任务、同刻可见的对象/文字/控件及承接关系。相同可复用状态合并；每帧只展示同一时刻稳定可见的内容；连续动画或交互变化在首尾不足以说明关键变化时才补中态，并注明需在真实运行中核验的变化。延伸到另一页面或状态时，必须先依据该处截图、方案或口述核实内容，缺依据先交可复用视觉基线、待状态明确再补帧。
2. **先按产品脾气定器物表面性格（绝不套通用后台模板）。** 动手细化控件前，先从真实使用情境出发统一整套画面的表面明度、分割线精密度、圆角锐钝、字体声口与留白节奏——例如暗房创作工具追求低眩光专注与精密刻度、编辑阅读工具追求清透纸面与呼吸秩序、流程效率工具追求高图底分离与可靠托付感，让视觉气质直接服务操作专注度。
3. **动画方向帧特殊衔接：** 接入动画讲解或 `laohu-motion` 委托时，沿用本片画幅与时点，按[方向帧委托](../../../laohu-motion/references/production-collaboration.md#方向帧的两种来源与回交)确认观众在该刻靠哪个物件、接触点或变化读懂关系，给可动或推近物件保住轮廓厚度，给原生字幕与工程字层留足干净区域。

## 截图意图与设计委托

收到可访问截图或参考图时，先按[参考图迁移](../../references/reference-transfer.md#先辨认截图在当前任务中的职责)分清每张图是当前美化目标、允许重排起点、纯风格参考、已核准成品帧还是派生基底：
- **美化当前页**必须保留已确认的主结构、操作方式（如下拉菜单仍是下拉菜单）、当前状态（如展开态仍保持展开）及触发结果，只升级美学质感、层级、间距与遮挡修复；
- **非相邻风格参考**只提取可迁移的视觉原理（表面层次、光色比例、字形与留白气质），绝不把参考图的旧文案、旧功能或旧布局塞进当前状态；
- **多图分区取用**写清各自负责区域与交界协调。

为每一张待设计帧建立简明内部委托（观者来意、当前准确状态、锁定原文与控件、视觉情绪与共同基线、本帧独有变化、待核项），混合组按[已有帧与待设计帧分支](../../references/production-reference-handoff.md#已有帧与待设计帧分支)逐帧分流——已核准实图只直接交接，绝不重写提示词。

## UI 界面可落地设计系统五硬杆（仅完整界面/视口状态启用）

在立住器物气质的同时，守住五条工程真能实现、经得起实操检验的硬标准：

1. **三层表面层级、起步量化基线与桌面合理栏宽：**
   - **三层表面与可起步量化变量：** 用统一设计变量定义底层画布 Canvas、主内容面板 Surface（工作区/侧栏）与浮起层 Elevated Layer（下拉菜单/弹层）的三层明度阶梯（相邻表面保持肉眼可辨阶差、下沉槽底深于承托面板）、微亮细边或轻投影分隔、统一圆角家族与 8pt 间距节奏。面向工程交接时，按[制作参考与交接](../../references/production-reference-handoff.md#逐帧制作说明的唯一格式)给齐可立即搭建变量的起步建议值（守住正文 WCAG AA ≥ 4.5:1、交互边框与图标 ≥ 3:1，深色报错色留对比余量，含真实字体栈数字字重与关键控件高度）；未开图实看像素时醒目标注待开图取样校准，绝不冒充已观测像素。
   - **桌面固定/夹逼栏宽与跨轨一致：** 桌面侧边或右侧工具栏须设固定宽或带上限的夹逼宽（如 260–300 px），且生图提示词里的栏宽视觉比例须与工程规范保持一致，绝不给无上限百分比导致大屏把窄菜单拉宽吞噬主画布。
   - **克制点睛面积：** 深色或暗房界面的点睛高光面积保持极克制（仅落游标、唯一主操作或当前激活标记，不把大面积高光写进提示词）。
2. **唯一主操作权重（Primary CTA）：** 每个有明确首要动作的视口只给 1 个主按钮最高视觉权重（高对比实色或明确点睛色），次级操作退为描边、浅底或文字按钮；纯阅读或无单一主操作页按真实操作关系分层，不让装饰抢走主操作。
3. **真实七态差分与弹层避让：** 涉及已知交互时，明确默认、悬停、键盘焦点、选中、展开、空态/禁用与校验错误的视觉变化，组合边框、位置、图标或文字与状态色（焦点与错误绝不只靠颜色单线表达；单行选中态用底色 + 文字 + 单侧勾选或单侧竖条即利落克制，避免多重信号堆砌）。展开的菜单或浮层必须清晰浮于上层并**绝不遮挡当前核心工作区或预览主内容**（优先调锚点、展开方向、独立栏留空或限高内滚解决）。
4. **动态内容容错边界：** 针对当前真实业务预判长文件名/长标题换行或截断、空列表、缺图占位与密集数据行高，留足自然伸缩与滚动归属；会改变整体结构的边界态才另立关键帧，其余记入制作说明。
5. **拒绝不可落地的假精美特效：** 坚决舍弃低对比透明毛玻璃糊字、破坏响应式的异形斜切面板、压过波形或数据的炫光渐变，用精准的明度阶梯、克制边缘高光、扎实字底对比与清晰秩序做出真正高级又可实现的界面。

## 提示词、说明与回交

- **只探索视觉方向提示词时（零加载交接手册）：** 每帧直接交付 1 条独立可复制的正向中文成像正文——自然描写场景视口、情绪气候、表面层级与材质光感、精确可见原文与控件状态、参考附件分工及可验证的效果要求（例如菜单展开时完整避开中央预览区，未锁定具体位置则先写清可检验的避让效果，避免替设计锁死唯一摆法）。不附制作说明与工程清单。
- **需交付工程制作说明、混合组交接、宿主按字段出图或模型小屋兜底时：** 读取[制作参考与交接](../../references/production-reference-handoff.md)，按[逐帧制作说明](../../references/production-reference-handoff.md#逐帧制作说明的唯一格式)与逐帧独立输入格式交付——保证宿主拿到单帧正文与附件标识就能直接调用，无需再把说明表改写成提示词；若本轮限定只准备交接暂不调用，同样交齐可直接提交的逐帧输入。
- **回交与诚实边界：** 向父级回交选定帧清单、共同情绪与视觉变量基线、各帧独有状态、参考职责与待核项。单帧静图交付观感与结构目标；真实响应式行为、键盘焦点与交互流畅度留待工程实现后核验，不虚构未观察的像素、接口参数或已成图状态。
