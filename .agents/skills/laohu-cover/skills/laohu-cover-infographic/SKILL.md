# 信息图与篇内讲解图专项

**逻辑零造假，画面有温度；以白代框，一眼顿悟。** 本专项负责让读者看懂、比较、查找或判断信息关系的独立知识图与文章篇内讲解图。材料里偶然出现流程、数据或箭头不触发，封面借图形辅佐标题也不转本项。沿用父级底座、事实边界、锁字、品牌资产与授权，不调用兄弟专项。

## 1. 先定读者任务、真实命题与拓扑零造假

信息图的专业杠杆来自三项实证规律：**Bateman 视觉润色助记效应**（紧扣主题的具象视觉隐喻不拖慢理解，反大幅拉高长期记忆留存）、**Mayer 多媒体学习三原则**（连贯去杂、信号显骨、空间邻近）以及 **Munzner 可视化编码通道阶梯**（精准量值交给共同位置与长度，绝不靠面积或色相胡乱暗示比例）。

1. **定义读者要完成的动作。** 写清读者看图后要回答什么问题（如分清表层与底层、按同尺度比较两套方案、追踪带条件的分支、定位局部部件）。文章篇内图直接沿用 `laohu-writing` 的原文锚点、邻文语境、正文栏约束与局部任务，不重复全文背景。
2. **先写自然语言命题，守死关系边界。** 把核心内容先压成准确短句，严格区分**因果与先后、相关与导致、分类与组成、已证实与待核**；保留单位、时间范围、同测前提、分类依据、例外和来源。输入缺失或未证实因果（如记录只确认 A 发生在 B 之前、尚未证实 A 导致 B）时，绝不顺手画因果箭头，标清边界或以时间轴/并列注记诚实呈现。
3. **按真实拓扑选主结构，严防机械等大方块与玄虚假隐喻。** 复杂分支、多区块全景、交叉网络或视觉隐喻映射读取[图形关系与连线](../../references/relationship-diagrams.md)。只有当材料存在真实物理或结构对应时，才选用贴合的视觉隐喻容器（如[冰山、漏斗/管道、天平/杠杆、同心圆/洋葱层、解剖/透视标注](../../references/relationship-diagrams.md#按真实关系选择视觉隐喻容器)），并核查轮廓与面积绝不偷偷多暗示一层因果或比例——**绝不把复杂结构拍扁成一排等大方块，也绝不给普通三点清单硬套宏大玄虚隐喻假拔高**。宏观阶段与局部区块并存时，用空间对齐、色带归属或带标签分支清楚标明每个局部属于哪一宏观阶段，需要区分的阶段色与类别色彼此一眼可辨。

## 2. 编辑部秩序美学、以白代框与一眼顿悟点

好看且有呼吸感的信息图本身就能拉高专注度与收藏欲。动手定版前，按当前题材气质独立建立整幅视觉秩序，绝不套用千篇一律的灰白软件截图或固定纸色模板：

- **色域、材质与阅读字随题材自然生长：** 依据内容脾气自主定调（人文社科可走温润纸媒编辑感，工程原理可走精密干净的技术图解感，生活科普可走清透利落的插画剖面感），选用透明清晰、扫读无阻的阅读字与清晰数字层级，告别廉价色块拼盘。
- **以白代框 × 80/20 呼吸留白 × 唯一视觉顿悟点：** 优先用充裕组距、清晰对齐轴和形态差异自然分开各层信息，而不是把所有文字都关进一模一样的圆角白卡；全图留出 1 处最直观的主视觉顿悟锚点（如悬殊的同尺度对比、一眼看透的剖面结构或清晰分层骨架），让读者三秒先抓住骨头、细看再读血肉。
- **跨区语义颜色隔离与零伪层级：** 客观对照的双方（如方案甲与方案乙）必须用两支彼此平等、均不带褒贬或警示暗示的对比色，**绝不与事故异常或警示提示共用同一色系，也不让其中一方借用正面底座色造成潜意识偏袒**；并列支撑的多个底层机制须水平均衡呈现，绝不画成由浅入深或上下分阶造成虚假等级误读。
- **审美严格服务理解：** 气质色面与微纹理用来建立愉悦感和节奏，绝不冒充额外分类或数值；凡用于编码类别、阶段或状态的色彩，必须配文字标签、形状或图例共同辨认。无实证图时明确定位为概念示意画法，不伪装成真实产品截图或实测照片。

## 3. 最终上图短稿先行法 + 文字密度红绿灯分流

避免信息图变成字海鬼画符的关键，是在写任何提示词之前先动刀减字、再按字量选最稳的落地路线：

1. **压缩认知负荷，先产出最终上图短稿。** 单张快速扫读图先以**主层 3–5 组块、可编辑短标签 6–10 字以内、短解释 18–25 字以内**为压力测试基准，兼顾手机竖屏未放大时的首眼扫读减负。逐条核对准备上图的字：凡删掉后仍能准确读懂该组命题的内容，一律移出到图外说明或正文；重复出现的同一对象只标一次；示意界面只画识别所需轮廓，不填多余假用户名与示例卡片；删掉一项文字同时删掉它占用的槽位。锁定文案、单位、同测条件、关键边界与来源不得误删。
2. **按文字与数据密度红绿灯分流（具体底图避坑与贴字表编法统一执行[双轨编译](../../references/prompt-compilation.md)）：**
   - **绿灯（AI 直出）**：仅含清晰主标题 + 少量短标签（约 3–6 个核心短词），无小字密排或复杂多列小数，可直接走路线 A 输出纯净中文生图正文并提醒成图逐字核对中文与连线方向。
   - **黄/红灯（密字、小图繁密笔画、多组精确数据、对比表或严格字体）**：逐字准确优先于一次直出便利，先明示直出错字错数风险再按用户路线分流——AI 辅助主推无字素净留白底图＋逐行精确贴字表（若用户坚持一体直出则保留必留短稿并标核验点）；确认人工精排、Figma 或代码矢量路线则切路线 B 或按需对接 [laohu-htmlshow](../../../laohu-htmlshow/SKILL.md)。

## 4. 回交与验收自检

遇精确多区块容量反算、系列跨页一致或严格字体规格时按需加读[版面与中文排印](../../references/layout-typography.md)；遇多焦点配色冲突按需加读[视觉情绪、层级与强调](../../references/visual-hierarchy.md)。交付前核对 4 点：
1. 读者任务明确，每条连线和隐喻容器都能还原回材料支持的真实命题，未证实因果绝不画因果箭头，且无假拔高玄虚隐喻；
2. 整张图是否做到了以白代框、情绪色调贴合题材、三秒扫见主骨架且无偏袒配色或伪等级；
3. 上图文字已做减法，锁定词、单位、同测前提与边界完整保留，密字/精确数据已走稳妥分流；
4. 篇内图已附原文锚点、局部关系与图注；无真实成图时不宣称清晰度与可读性已通过。
