# 海报专项

**一幅海报就是一件作品的脸与魂；留白托余韵，字图长成一体，绝不无中生有。** 本专项服务五类主要任务：作品或产品发布、活动与行动招募、品牌形象与主题表达。完成歌曲、影片、剧作、画册等以其名称、意象和情绪亮相时走本专项，即使在社交平台发布也不改；若核心工作是信息流文章/教程引流走社交封面，解释复杂信息关系走信息图。沿用父级底座、锁字、品牌资产、事实边界与授权，不调用兄弟专项。

## 1. 判清任务与必要字段（无真实行动绝不编 CTA）

1. **辨认观者看完要记住或做什么。** 是记住一部作品的名字与情绪余韵、建立品牌气质印象、单纯公告一场活动，还是完成报名、购票、预约或到场？出现作品或商品绝不自动变成售卖广告。
2. **逐项清点字段，严禁补造行动信息。** 分清主标题/作品名、主题语、品牌/作者署名、时间地点、资格价格与行动入口，标明必显、可选与未知。只有任务确含报名、购票、到场等真实行动时，才收齐对应条件与入口；缺阻断行动的关键字段只问该项，**无行动任务时干净留白，绝不为了显得完整强加二维码、扫码按钮、敬请期待或假日期**。

## 2. 极值留白容器 × 真实作品切片 × 召唤空白

海报区别于信息流封面的独特基因，在于用**格式塔图底反转与负形闭合**以及 **Arnheim / Molly Bang 物象物理重力情绪语法**（重心、倾角、尖钝与疏密直接制造心理重力），把整幅画变成一个经得起长久凝视的留白容器：

- **从作品真料提纯最见真魂的具体切片（反题材贴纸化）：** 从歌词、剧情、物件、空间、人物处境或品牌内核里，淘出唯一一处朴素却最能照见全作共通真相的具体切片作为核心母体——绝不凭题材词机械堆砌廉价符号（写歌就画音符、拍电影就画胶片、古风就堆宫灯祥云），也不为了显得宏大给克制作品强加浮夸特效。
- **用极值负空间与召唤空白放大余韵：** 全图严格收束在极少数（至多 3 个、最好只有 1 个主切片与题名对峙）安静而有重力的视觉锚点，用疏可跑马的大片呼吸负空间托起画面，把未说完的故事、停顿或双层意会留给观者自己补完。材料较少且获授权时可作有限审美阐释，绝不伪造原作剧情或事实。涉及歌词、剧本、照片的深度材料转化与具体艺术手法时，按需读取[从作品材料生成艺术构图](../../references/artwork-composition.md)。

## 3. 字图共生骨相：字图换位试金石与当代构成

- **字图换位试金石（动笔必查）：** 构思好主视觉与题名位置后，试着把片名、歌名或主标题挪到画布另一块同样空旷可读的地方——如果随便挪来挪去画面都差不多成立，说明字和图还是两张皮！必须重做构图，让字通过**主形动势轴延续、物体轮廓咬合、前后层遮挡穿插、网格共边或景物留白导引**牢牢锁死在整幅画面的唯一最佳位置。
- **按作品气质选定当代平面构成语法：** 依据作品脾气五选一——强动势/强轮廓选**字图穿插与破框**，诗意含蓄选**东方留白与竖排韵律**，秩序/建筑/展览选**瑞士理性网格**，兼顾主图与真实发行信息选**杂志编辑式构图**，自带双层互证意象选**负形同构与视觉双关**（具体落地动作与失配调整详见[当代平面海报构成方法](../../references/artwork-composition.md#当代平面海报构成方法)）。
- **标题声口与材质合一：** 让题名的字形骨相、笔触纹理、冷暖明暗从作品自身材质与情绪里自然长出，必要发行信息或行动条件放在清晰次级层级，既不抢戏又能一眼找到。面向手机信息流缩略图展示时，中文字体慎用极细笔画，优先选用骨力清楚的衬线或无衬线字重并守住副落款字号比例，防止小图断笔发虚。

## 4. 回交与交付自检

需要精确多焦点配色或强调调控时按需读[视觉情绪、层级与强调](../../references/visual-hierarchy.md)，严格排印或系列规范读[版面与中文排印](../../references/layout-typography.md)，最终输出交[生图编译](../../references/prompt-compilation.md)。交付前核对 4 点：
1. 是否立住了作品独有的真实切片与凝视余韵，彻底避开廉价题材贴纸与浮夸假拔高；
2. 题名与主形是否通过字图换位检验真正咬合，且缩略尺寸下题名关键笔画与主体轮廓依然清晰；
3. 锁定名称、署名与真实字段是否一字不差，无行动任务时确实没有强塞按钮、日期或二维码；
4. 无生图工具时首句坦诚标明海报设计稿并交可直接复制的正向提示词，绝不虚构已成图或已验证分辨率。
