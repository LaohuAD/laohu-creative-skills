# 自媒体发布封面的选择型专项

本子级只负责把信息流内容入口要承接的理由转成情绪/态度、突出程度、视觉入口与字图协作。由父级按最终成品用途选择读取；用户不必说出本子级名称。若任务是为一篇/段关于工具、工作流、教程、观点或选题的内容设计封面，目的是让观者决定是否继续阅读/观看，走本子级；材料讲的是歌曲、影片或故事，不会因此改变为作品海报。若要发布/代表一首完成歌曲、一部影片、剧作或其他艺术作品本身，并让主视觉承载作品身份、主题或情绪，则由父级读取海报配置，即使最终发布在信息流。仅提到封面、平台、人物或画风不触发；若最终图像主要用于讲解/查阅关系或确实承担海报任务，继续走父级对应路径。每个成品只认一个主要用途，能兼容的次要作用由父级整合，本子级不调用兄弟配置。

沿用父级已经解析的 `{PROJECT_ROOT}`、工作项目、用户授权、材料、锁定文字、品牌/身份资产、保护项与既有任务状态；不能从本子级目录重新推导项目根。父级仍负责信息核验、排版几何、精确参数、完整提示词、交付说明与最终检查。本子级仅回传会改变这些工作的封面选择。

## 输入、固定项与开放项

从父级带入标题/副标题及逐字权限、正文或口述材料、目标受众、发布位置/显示尺寸、用户已定的情绪与风格、品牌/系列资产、人物身份要求、画幅/裁切和禁项。父级转入 Title 的封面四字段时，用完整字面与首要强调词定文字锚点，保住不可拆词组，将建议断行拿到目标尺寸试排。用字图互补建议检查下方母题和实际材料证据，由本专项确定画面承担什么，并回交父级做成像或排版。锁定文字、事实、身份、品牌色、裁切保护以及用户明确指定的专业、克制、安静、无人物等方向属于固定项。若当前只是局部改稿，延用仍有效的情绪、视觉入口和表现选择；只处理改动及其直接依赖，不重启整套选择。

材料足以支持的表达理由、注意入口、突出程度、字形、色面、构图、人物/物件/图形职责及其相对关系属于待选项。没有正文时可依据标题与已知上下文作有限的设计判断，标成推断，不补事实；没有目标平台数据时按父级当前工作画布检查设计目标，不推断点击效果。

## 封面操作链

1. **确认观看处境。** 写明观者在什么信息流/发布位置、以什么显示尺寸接收这张封面，以及本图要让其识别、理解、感受或继续阅读什么。区分已核实的平台条件、用户给定画幅与父级暂用的工作画布。
2. **从材料找进入理由。** 对照标题承诺和材料，找出目标观者此刻可能在意的一项具体进展、差异、动作、关系、结果、经验或体验；记录原文/事实依据以及它如何区别于泛主题。如果只有标题，限定推断范围。保留证据边界，不把视觉隐喻伪装成事实。
3. **主动定表达轴。** 结合材料、作者表达态度、受众处境、用户已定表达和显示尺寸，选本图的情绪/态度及相称的突出程度。新设计不等用户额外说“醒目”或“冲击”；突出程度没有预设等级，既可清楚、安静、克制，也可强烈，必须有材料或用户选择依据，并能在画面上感知。不得用“普通题材”之类分类默认退回温和，也不得把所有封面推成高唤醒。若用户同时提出强表现与专业/安静表达，先找能兼容的表现渠道；只有具体要求确实无法兼容时才请父级澄清。
4. **选注意承担者，保留文字锚点。** 决定视觉注意由标题、人物、主题物件/证据、动作、图形或字图共同关系中的哪项开始；可先从图像开始，也可由文字开始。完整主标题是语义与文字锚点，保持第一文字层级；锁定副标题保持清楚的第二文字层级。第一视觉注意不等于第一文字层级。人物不是默认选择；无人物、性别/身份、姿态、裁切及品牌限制按父级保护项执行。
5. **把理由落实为整体字图关系。** 先按下表选一个有材料依据的主母题，让它改变主体、字块、色面、动作或空间距离。题材动作/节奏本身值得进入主视觉时，可借 Public Theater 的字块与动作分工方法，让字块疏密、方向或位置呼应动作，保全文案与读序。做法见[设计元素的独立选择与组合](../../references/design-composition.md#方法来源范围)。颜色或强调裁决读[视觉层级与引导](../../references/visual-hierarchy.md)，几何与字号归[版面与中文排印](../../references/layout-typography.md)。
6. **从滑屏速度到实际版位复核。** 按下文三拍先检查注意、价值与开放问题，再做拇指眯眼测试和[发布版位的裁切与遮挡试排](../../references/layout-typography.md#发布版位的裁切与遮挡试排)。若缩略时情绪与力度不见了，调整主体、字块或它们的相对面积和位置。最终完整标题、副标题、身份和证据均按目标版位验收。

### 五种视觉母题

| 材料中最值得看见的理由 | 选型与操作 | 不成立时调整 |
|---|---|---|
| **强反差对照**。两种结果、状态或路径可在同一条件下比较。 | 用同轴、同尺度或同一物件的两态把差别摆在同一眼里，将如“3 小时／5 分钟”的已核数字贴近对应状态。 | 条件、对象或单位不相当时标清差异并改为各自陈列。涉及决定结论的限定须可读。 |
| **好奇缺口与聚焦揭示**。材料里确有一个值得展开的局部、原因或转折。 | 先给可辨的对象和已知线索，再用局部放大、光区、轮廓或部分遮挡把注意指向原文会解答的问题。 | 读者连对象、现状或价值都认不出时，移开遮挡或加近邻线索。保留完整标题与事实限定。 |
| **结果前置实证**。已有可展示的成品、测试、真实界面或可核结果。 | 把结果放在第一落点，让原图、数字或状态与副标题/说明相邻，正文接着解释怎样做到或在什么条件下成立。 | 材料没有实证时，转成有依据的对照、概念表达或字形主视觉，避免生成假截图、假数字或夸张保证。 |
| **一眼能解码的视觉隐喻**。材料关系和熟悉物件共享一种可见属性。 | 让物件的轮廓、接触、阻隔或动作对应标题里的关系，图与短语相邻提供解码线索。 | 若图只能靠画外说明读懂，换一处更直接的材料对象或把该物件降为氛围。 |
| **极简大字宣言**。完整标题本身有明确判断、对象和态度，画外信息很少。 | 让整句的字形、面积和断行撑起主视觉，差异集中在需先读的短语，保住副标题第二文字层级。 | 字号再大仍说不清具体价值时，改换能承载它的物件/证据或在授权范围内修文字。 |

这些母题是选型工具，可按职责组合。专业、安静或无人物方向可用稳定的轴线、可辨物件、明确字形或真实的尺寸差承担强度；不固定人物、颜色、表情或笔刷。

### 0.5 秒滑屏预览与拇指眯眼测试

按 **Hook → Clarity → Curiosity Gap** 检查一眼中能否先捉到明确形状、动作或字块，再迅速读懂题材价值或冲突，以及是否还有一项正文确实回应的开放问题。对照型可留“差异怎么做到”，结果型可留“在什么条件下能做到”。三拍是项目短时预览的读法，0.5 秒是模拟扫过的时长，实际理解和传播仍依版位、受众和成图验证。

有图时先按该信息流真实显示宽度查看，再做一次约原稿 1/6 宽的压力预览（只是临时缩比）。像刷手机一样短看，眯眼看能否辨认主色块、入口与 3–6 个核心大字，睁眼再核完整主副文案与必要细节。入口散就重配色块、面积和距离，价值模糊就换字图关系，开放问题靠误导才成立就换材料线索。只有提示词时写清预期效果和待验动作，实际可读或传播结论由成图支持。

## 回交父级

返回：观看位置、尺寸及遮挡情境；材料进入理由及依据；情绪/态度、突出程度及主母题；视觉注意如何经过价值线索抵达完整标题及可展开的问题；主副文字层级；字块、人物/对象、色面和距离；裁切保护、锁定项、禁项、未知事实和预览状态。

父级将材料理由与表达方向带回第三步确定整体视觉方向；将标题/图像角色带入第五步分配图文职责；将注意路径、空间距离与裁切保护带入第六步；将完整文案和副标题容量带入第七步；将实际视觉材料、色彩和人物/对象选择带入第八步；在第九步把这些决定写进可复制提示词并按封面用途检查。只涉及一项局部修改时，父级保留其他有效决定并重查直接依赖，不因本子级已加载就强制重走全链。

## 验收

- 标题文字准确、主副文字层级清楚，身份、事实、画幅、裁切及用户禁项完整保留。
- 情绪/态度与突出程度来自材料、用户已定表达和真实观看条件，且由字形、色面、构图或图像表演承担。
- 第一视觉注意可以从图像、物件、动作、文字或它们的共同关系开始；不把“主标题第一文字层级”误作“必须先看标题”。
- 有效封面无需固定颜色、人脸、惊讶表情、笔刷或效果数量；专业、克制、安静、无人物等选择仍能得到可辨的表达。
- 若成图尚未生成/读取/实看，只报告设计目标和待验点，不宣称缩略可读、感染力或点击效果已通过。
