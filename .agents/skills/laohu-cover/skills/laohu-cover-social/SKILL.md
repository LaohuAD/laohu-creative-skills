# 自媒体信息流封面专项

**半秒停指，绕过理智，先让身体与感官动心。** 本专项服务于让信息流观者决定要不要点进这一篇或这一段内容：工具、教程、工作流、解说、复盘或观点一律走本项，哪怕题材是音乐或电影。若任务是发布或代表一首完成歌曲、一部影片或独立作品本身，由父级转走海报专项，发在社媒也不改；主要任务是讲解复杂关系则走信息图专项。沿用父级底座、材料、锁字、品牌资产、禁项与授权，不调用兄弟专项。

## 1. 绕过理智的四个感官底层开关（综合强情绪共振）

信息流封面的强情绪绝不只是激动大喊——**让浮躁的观者在半秒内一下子安静下来、屏住呼吸的沉静、笃定与深邃，同样是极高浓度的强情绪**。真正决定点击欲的，是画面、光影、主角状态与字形四位一体同时打开四个感官开关（依据**眼动显著性竞争**、**视线与手势线索效应**、**图文互补加工**、**具身运动共情**与 **Bar & Neta 神经美学弧度偏爱**）：

1. **感官洁净度与好光影（第一眼舒服，绝不脏乱反胃）：** 画面通透、色调干净和谐、光源方向清晰、文字坚持清透纯色而非浑浊脏渐变，视网膜第一眼感到清爽高级，绝不触发生理排斥。
2. **趋近型生命力与向往感（造梦之魂）：** 主角或核心对象自带美感、酷感、松弛爽感或沉静定力，让人潜意识里想凑近看、想成为或拥有这种状态；哪怕讲痛点、困境或深情，呈现依然美而动人、有尊严，绝不扭曲丑化或低俗扮丑。
3. **活人的有机律动（有呼吸、有起伏、拒铁皮冲压）：** 人类看字时大脑运动皮层会无意识模拟写出这几个字的手势、力道与呼吸（具身运动共情），而尖锐生硬的机械直线折角会无意识点亮杏仁核防备感（Bar & Neta）。因此画面动势与展示字形绝不做冰冷的电脑机打字幕，也绝不做全员同角度硬掰歪的铁皮冲压斜切，而要透出活人的起伏节奏、粗细顿挫与呼吸空隙。
4. **半秒就懂、留半寸悬念（低负担 × 心里发痒）：** 焦点极致干净，一眼扫清主次零费脑，同时借图文互补藏住半寸让人忍不住点进来看答案的反差或方法钩子。

## 2. 两阶段解耦构思（先炸 20% 视觉奇观与主核，再做 80% 退隐清场）

为避免一锅煮造成克制铺垫把主核磨软、或局部躁气把全图搞脏，构思分两步物理拆开：

1. **第一步 · 独立锁死 20% 停指奇观与主核：**
   - 先抛开边角与安全区杂念，从材料里揪出目标观者此刻最痛、最反常识或最具戏剧张力的单一高电压瞬间或空间奇观（拒绝温和图库坐姿摆拍；只有标题时基于字面语义做有限推断并标边界，绝不编造稿外事实与假截图）。
   - 钉死**唯一视觉老大**与**压场级核心词眼**，并配至多 1 处未完全封死的**视觉认知空白钩子**（下表六选一），确保遮掉全部文字后，底图本身凭电影级镜头语言、光影反差或动态抓拍依然足以让人停指惊叹。
2. **第二步 · 破死盒子清场，用 80% 呼吸素底与三层纵深托核：**
   - 立刻切回冷静克制的美术总监状态：拉近景别、清空杂乱背景与无关道具，收进从当前题材自身长出来的通透情绪色域（绝不跨题材复刻同一套暗色或综艺配色）。
   - **主动打破上字下人、左字右人的死板隔离盒**：当画面情绪与主体结构适合时，大胆让压场核心大字横跨画幅 **75–90% 宽幅**，借前景人物头顶发丝、肩线或核心道具自然轻微压在大字边缘前方，形成**背景光影 → 巨型压幅大字 → 前景主体**的三层真实空气纵深（同时保证每个汉字的关键笔画 100% 清晰完整）；纯平面冷静构图则借建筑/几何留白与清晰光影轴线形成高张力对峙，用目光、手势或单一光束把观众眼球自然送进核心标题。

### 单一视觉认知空白钩子（按题材真气至多选 1 处）

| 视觉钩子原型 | 画面如何制造半秒悬念或顿悟 | 适用边界 |
| --- | --- | --- |
| **熟物微拧半寸** | 拿人人都认得的日常物件或工作场景，只改动半寸关键反常细节，零门槛又能立刻勾起为什么会这样。 | 改动必须紧扣正文真正拆解的核心原因，不搞无关猎奇。 |
| **同框极端反差** | 同一条件下的繁与简、旧与新、单人与大片气场在画框内直面对撞，一眼看见悬殊落差。 | 对比前提不对等时标清边界，绝不伪造未证实数据。 |
| **未完成动作与视线悬置** | 定格在动作即将出手、答案正要掀开或情绪将要落下的前一毫秒，人物眼神或手势把观者直接拉进现场。 | 动势须指向标题或关键证据，不做无意义空摆。 |
| **冷峻留白召唤** | 越重磅的代价、转折或情绪，越用大面积克制留白配极小精准证据切片，把冲击留给观者脑内补完。 | 缩略尺寸下唯一证据切片仍须清晰可辨。 |
| **跨界材质撞击** | 把抽象方法或老话题撞进意想不到的真实物理材质与光影场域，瞬间打破信息流审美麻木。 | 材质情绪须与题材分量同级，防浮夸假拔高。 |
| **局部负形或视觉双关** | 单一轮廓或场景切片自然藏进第二层意会关联，第一眼顺滑看懂、回味半秒咔嗒击中。 | 离了画外解释就猜不出时立刻退回直白表达。 |

## 3. 人物硬路、有机展示字与克制字色

1. **用人物必走两条趋近型硬路（无人物题材绝不硬塞）：**
   - **路子 A · 人物气质即作品含金量实证**：审美、音乐、影像、创作与个人 IP 题材，人物自身的辨识度、微表情、体面穿搭与通透现场氛围本身就足以兑现题材向往感；
   - **路子 B · 人物成为标题的活体互动演员**：干货、效率、拆解、冲突题材，让人物以真实抓拍般的生动表情、手势、动作与道具直接演活标题内容，并主动把观众目光牵引向主标题，彻底拒绝空洞礼貌的广告标准摆拍微笑，也绝不扭曲扮丑。用户提供参考人像时严格保真气质与特征。
2. **定制主视觉字标骨相 × 高亮度清透纯色（兼得压场突出与殿堂高级，告别平淡字库与笨重 3D 浮雕）：**
   - **压场级大尺度与定制字标骨相**：依据 Arnheim 视觉重力与 Brumberger 字体人格声口，彻底跳出挑普通系统字库或缩在角落的保守心态。主标题敢拉出极具统治力的视觉跨度与悬殊大小落差，副标题稳守清晰第二层级；同时**绝对拒用笨重 3D 塑料挤出浮雕与脏重外投影**，改靠极高亮度清透纯色、锐利轮廓与定制字形骨相直接弹出屏幕。
   - **活人呼吸起伏 × 随题材自然显形（拒呆板机打，也拒等角硬斜切）**：7–10 字主标题按准确语义切分成清晰 **2 层或 3 层节奏块面**（绝不留模糊断行让模型拆坏词组），把核心词眼推到一眼压场的绝对视觉高峰：
     - **炽热、爽快、电影情绪或强反差题材**：大胆采用带**毛笔笔刷劲势、厚实楷体骨力或干刷飞白挥洒感**的定制手写展示字标，释放自然弧度、波浪起伏、分明粗细顿挫与顺势舒展收笔，同时严守**每一个字 100% 清晰易认、缩图不糊**；
     - **平静、深邃、极简建筑或人文理性题材**：同样保持压场存在感与呼吸悬殊节奏，采用**高反差定制现代雕版宋体或精炼建筑几何展示体**（绝非普通系统黑体或细弱易断的细宋），以绝对锐利平整的博物馆纯平面印刷质感（零多余浮雕与阴影）传出让人半秒心静的定力；若用户明确指定硬朗几何轴线则顺应其秩序，绝不硬贴手写飞白。
   - **清透纯色克制 × 轻量互动微点缀边界**：文字坚持清透高亮度纯色，拒绝浑浊脏渐变，整组文字以 **1–2 个和谐主色**打底，高纯度强调色集中落在核心词眼或重点标记上（个人默认方向按已读取的偏好执行）；若题材与风格适合加入**轻量手绘微图标、贴纸或情绪小符号**，全图严控在 **1–2 处**，必须真正与人物动作/眼神或标题转角发生趣味视觉交互，色调材质融进底图，绝不堆满屏或贴廉价厚白边网图表情包。收到 `laohu-title` 封面四字段时保住完整字面、核心词眼与不可拆词组。
3. **无人物或静谧专业题材的四根真张力杠杆：** 当用户要求专业、安静、无人物或禁强暖色时，绝不退回隐身极简壁纸，改用**极端尺度反差、通透高反差明暗切割配单一克制点色、非对称紧裁切与清晰秩序轴线、触手可及的真实物件材质**，同样拉出让人半秒定住的高级情绪磁场。

### 五种视觉母题

按材料最值钱的进入理由选主母题（可按职责组合），色光与形态随当次题材自然生长：

| 材料最值得看见的理由 | 构图与审美动作 | 失配时调整 |
| --- | --- | --- |
| **强反差对照** | 同一条件下的两态、繁简或新旧同框直撞，已核对比数字贴近对应状态，用冷暖、明暗或疏密拉开第一眼爽感。 | 条件或单位不对等时标清边界改各自陈列；决定结论的限定词须可读。 |
| **好奇缺口与聚焦揭示** | 先让对象可辨，再用一道侧光、掀开一角、局部放大或精准景深把视线钉在原文要拆解的异常细节上。 | 观者连对象本身都认不出时减弱遮挡并补近邻线索，保完整标题与事实限定。 |
| **结果前置实证** | 直接把真实成品、界面状态或已核成果放进第一落点，用干净质感托出高级感，邻近短副题点出背后反差。 | 材料无真实结果时转对照、隐喻或大字宣言，严禁编造假截图、假成绩或夸大保证。 |
| **一眼能解码的视觉隐喻** | 找一件与主题共享可见物理属性的日常物件直白演活关系，借光影材质造出记忆点。 | 离了画外解释就看不懂时，立刻换更直白的对象或降作氛围。 |
| **极简大字宣言** | 完整标题本身极具态度与金句锋芒时，直接靠有机字形骨相、词眼尺度落差与底面肌理撑满主角，用大面积留白拉出张力。 | 光靠大字讲不清具体价值时，补入一件高辨识核心物件或授权内调整文案。 |

## 4. 成稿后三秒眼检、1/6 眯眼压测与平台安全核

常规单张 AI 封面直接在此完成成稿扫疤，无需盲拉重排印手册（仅遇多比例精排、长文多区块或严格字体参数时再按需读[版面与中文排印](../../references/layout-typography.md)）：

- **三秒感官质检与 1/6 缩图眯眼：** 把构想缩到约 1/6 宽模拟 0.5 秒滑屏——① 第一眼画面是否清透干净、光影舒服，主角或核心物件是否让人产生想凑近看的趋近感；② 主标题与画面是否透出活人的呼吸律动与对味情绪磁场（无论炽热还是沉静，绝非死板字幕或铁皮硬斜切），同时半秒后有咔嗒一下的反差或好奇余韵；③ 1 秒内能否读懂主副标题核心承诺，且 100% 忠于真实内容不搞虚惊标题党。缩略发散就减元素、扩素底面积或加大明暗对比。
- **三大中文平台真实裁切与遮挡保护（未核实具体客户端时作工作条件并在块外提醒待验）：**
  - **公众号横幅 2.35:1（兼转发 1:1）**：把完整主副标题字块与核心可辨主视觉稳稳收进正中 1:1 方形安全核内（宽等于画布高、约占全宽 42.6%）并留呼吸边距，左右两侧自然延展环境与留白。
  - **横版视频 16:9（B 站 / YouTube 等）**：右下角预留时长角标遮挡区，核心字、主体眼部与关键实证细节一律移出；兼顾 4:3 列表裁切时同步保住中心安全域。
  - **竖版短视频 9:16**：底部约 20%（标题文案区）与右侧互动按钮列作遮挡禁区，只延展背景，不落关键文字与焦点。

## 5. 回交与交付自检

向父级或[生图编译](../../references/prompt-compilation.md)交回：观看版位与安全核条件、材料进入理由、情绪浓度与通透色光气候、核心视觉母体与单一视觉钩子、人物或无人物张力路线、有机展示字声口与主副层级、统一材质及图文咬合方式、锁定项与禁项。核对 4 点后交付：
1. 四个感官开关是否同时成立（通透洁净光影、趋近型生命力不丑化、活人呼吸律动拒铁皮僵硬、半秒懂加半寸悬念），画面气质是否从本题材自身长出；
2. 锁定主副标题是否一字不改、纯色克制、主次分明且在安全核内一眼读清；
3. 遮字检验是否过关，画面是否演出了真实反差或证据，没有编造稿外事实与假截图；
4. 尚未出图时只报告设计预期与待验点，不宣称缩图或点击效果已通过。
