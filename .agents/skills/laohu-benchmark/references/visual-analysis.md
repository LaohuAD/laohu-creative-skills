# 视觉分析适配

按需由 [SKILL.md](../SKILL.md) 挂载，把图像、版面、封面、关系图、视觉资产与连续转静态的判断接到视觉下游。动效与视频样片细读交 [animation-analysis.md](animation-analysis.md)，本文件只承接静态构图、形态与观看路径；仅有文字构想时只分析设计意图，不冒充已见成图。

## 四个反偷懒观察抓手

1. **双重识别形态拆解**：同一可见形态支持两种读法（同时或先后识别）时，分别指出两种读法依赖的实际轮廓、朝向、遮挡、材质/色彩线索，以及是否依赖特定观看距离/角度/尺寸；把外观形态与制作方式分开——**来源未说明是单体塑形还是多部件拼组时，制作方式保持开放变量**，具体实现方案另标为新增建议。
2. **追踪真实观看路径与编码语义**：按目标尺寸看第一眼落点、邻接跳转、争焦与分组依据（居中不等于视觉中心，同色不等于同组）。拆信息图/关系图时，核对节点与线条/面积/颜色的编码是否准确对应因果、时间或类别，防止装饰线被误读为流程箭头。
3. **连续动作转静态成品（封面 / 单图换轨）**：**绝不把一整段连续过程硬塞进一张图。**
   - **选帧与小图分离度**：挑单帧可承载的决断瞬间，必核手机信息流缩略图下的**主体轮廓分离度与背景明暗差**（避免关键小物件与手势叠成黑团糊掉），同步避开视频界面控件遮挡与公众号 2.35:1 居中裁 1:1 裁切飞边；
   - **图文错位分工**：严格区分画面可见证据、**封面短字（4–8 字补被静图吞掉的前情、堵死静图歧义误读）**与**外置发布长标题**，三者各担一责绝不互当复读机，也不把文案解释说成画面已画出来；
   - **诚实算清三笔损失与盲看验收**：明说单帧注定保不住的先后/声音/视线往返，同时评估两笔隐性账——**静态化对“真实突发感”的折损（精修或 AI 感易像摆拍）**与**提前露底剧透换点击值不值得**；无实际成图时只给设计判断，并落到“缩到真实手机小图 + 陌生人 1 秒盲看”的硬核验收点。
4. **资产身份 vs 连续状态 vs 临时变体**：拆解角色/道具/场景时，区分跨镜不变的身份基线、随剧情演变的连续状态与仅属本镜的临时变化；视觉资料绝不用于推断角色声线身份。
