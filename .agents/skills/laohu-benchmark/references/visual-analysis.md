# 视觉分析适配

本文件把实际图像、版面、封面、镜头、动作和动画关系接到下游的视觉/制作决定。读图时先确认用户要观者看见什么、目标尺寸/介质是什么、原作被观察的是成品还是提示词/草图。只有构思说明时可分析作者明写的视觉意图，不把它当成已经实现的画面。

## 观察依赖双重识别的形态

当同一可见形态允许两种不同读法时，把两种识别分别拆开；它们可以同时成立，也可以在观看过程中先后被识别。说明实际可见的轮廓、朝向、部分遮挡、颜色/材质线索和彼此位置是什么；第一种读法由哪些形态线索成立，第二种读法又靠哪条新增或重新解释的线索出现。再说明它们是否需要移动视点或改变观看距离才成立。若当前任务需要判断两种读法分别支持什么用途、动作预期或文化意味，就把这些解释连回具体形态、命名和场景条件，说明它们怎样支持或偏离读者可能带入的熟悉理解；没有来源或语境依据时保留为条件推论，不泛化成所有观者都会如此理解。不要只写“像某物”“有反差”或“有双关”，也不把预想的观众反应说成已测效果。

识别效果依赖真实观看条件。记录实际可核对的尺寸、观看距离/角度、裁切、遮挡、光线、分辨率或页面位置中哪些会改变辨认；没有对应成品时把它们写成待实现条件或假设，不假装已经从图像看见。只有提示词、构思说明或口述点子时，可以分析设计者打算怎样安排形态与识别次序，但不说画面已经出现、辨认已经成功或动作已发生。

把文字明确给出的形态特征与尚未说明的实现方式分开。若来源没有说明一种形态是由一个连续塑形的单体构成，还是由多个部件拼组而成，就把实现方式保留为开放变量；具体选择其中一种来解释可读性或制作条件时，标为新增建议。只有文字而没有图像时，不把设想写成已实现的轮廓或部件边界；有图像时只报告可见的形态关系，除非另有证据，也不据此断言实际制作方式。

## 先看对象如何互相组织

对照原作可见画面、目标观看尺寸和其前后帧/页面，记录对象身份、位置、大小、遮挡、方向、视线、明暗、色块、边缘、纹理、文字面积与阅读顺序。说明哪个视觉关系是证据、哪个是推论：主体在中央不自动等于视觉中心；颜色相近不自动说明对象属于同组；“氛围高级”没有描述实际画面关系。

优先追踪观者的可见路径：第一眼可能落在哪里、沿什么邻接/方向进入下一信息、谁与谁形成比较、停留或动作后观者得到什么新证据。若强调元素并列或争焦，分别说明它们如何竞争；若同色、同形、共同方向或空间分组将元素连接起来，说明连接的是实物类别、阅读层级还是装饰关系。仅当观看路径比较能改变当前判断时，才对比缩略图、实物尺寸、移动端或全屏效果；没有相应成品就保留为设计假设。

拆解动作/镜头时不仅记姿态，还要记动作起点、空间路径、接触对象、结果状态、连续帧相位及观众能否还原因果。静态关键帧不能证明整段动作；首尾帧不能证明中间材质运动或时间感。焦点、构图或人物位置的变化应连到剧情/信息目的，而不是只贴“动态”“冲击”“电影感”标签。

封面与知识图不是同一任务，配色和字号不能脱离现有编码、标题承诺与观看尺寸泛化。图像生成与成品创作分开：工具支持哪些参数需要看本次入口；模型提示词无法保证指定色值或像素，只有读到成图才可以报告像素层面结果。资产视觉一致性也不是要求每张图外观完全相同，而是识别哪些身份条件需稳定、哪些状态需按剧本变化。

## 关系图、动作与视觉证据

关系图先识别节点代表的是真实对象、概念、时间、因果还是类别，再检查线条/邻接/颜色/面积是否让观者读到同一关系。装饰线若会被误认为流程箭头或因果连线，要改变它的语义强度或明确图例。结构更清楚不等于论据成立，图像好看也不证明事实准确。

对连续视觉过程选择足够上下文：起始状态如何建立，哪一动作造成变化，是否有中间相位必须让观者看见，结果状态怎样承接，空间或物件是否跨镜保持。重复出现的构图或动作要比较它是否带来新视点/信息/情绪/记忆关系；若重复承担回声，不误判为浪费，若仅复播同一信息，不称为进展。区分主体速度、相机运动、镜头切换、画面显示时长和声音进入；它们可以分别变化，不能一概叫“节奏快”。

创建原子时以可定位的画面/帧范围、画面层级、实际动作相位和周边视觉条件为单元。解释“具体哪些对象怎样排列或变动、观者因此能先后看到什么、在哪个目标尺寸成立、设备/材质/生成条件是什么”。如果要迁移到视频，应写视频消费者的观看决定；若迁移到 motion，应另写它的状态/时间和模块返回 binding；不要用一个“视觉”标签覆盖两种产物。

### 从连续过程转为静态成品

当目标是封面、单张图片或其他静态视觉时，不因来源包含连续动作就要求把整段动作压进一张图。先从来源确定要保留的具体关系、成立条件和足以让观者读懂它的视觉证据，再选择静态成品能承载的状态或关系。明确观者第一眼应落在哪里，接着能从哪些对象位置、方向、表情、形态或文字关系读出依据。图像与文字可以共同建立目标关系；分别说明画面实际提供的可见依据和文字补足的信息，不能把文字说明说成画面已经展示了它未提供的证据。

若来源效果依赖先后、持续、打断、视线回返或状态变化，指出静态画面无法原样承接的时间信息，并判断能否由图文组合或另一种画面关系重建目标；不能重建的部分如实记录为损失。不得把一帧描述成已经展示完整过程，也不把设计者预想的首读路径说成真实观者效果。按实际目标尺寸和观看条件复核首个落点及关系证据；没有目标成品时只交设计判断，不称画面已成立。
