# 动画样片与动态风格分析

当用户认可或要求拆解动画/视频样片的动效、视觉风格、转场、声画关系或源码实现时，由 [SKILL.md](../SKILL.md) 按需挂载；按观察需要辅读 [visual-analysis.md](visual-analysis.md) 或 [time-and-sound-analysis.md](time-and-sound-analysis.md)。本文件负责真实媒介细读、证据分级与向 Motion / Analysis 交接，不替代正式生产写入。

## 1. 媒介证据硬边界（不凭截图脑补，不凭 MP4 猜源码）

- **用户只说喜欢整片时直接推进**：先按可达范围正常速度完整观看，定位实际突出的视觉信号、反复出现的设计选择与具体动作再展开，不反问用户“你想看风格还是局部”。
- **正常速度 + 关键帧 + 连续帧 + 音轨四层核对**：记录实际版本、画幅、时长、帧率与时间基准（取不到标未知，不肉眼估时）。正常速度判观看节奏，关键帧记状态与构图，连续帧判速度曲线、形变、遮挡与中间相位；涉及声音时沿同一时间基准核对实际音轨（无音轨不臆造音效）。
- **静态截图只证静态**：几张截图只能分析构图、材质、排印与层级，**绝不据此补出运动方向、形变路径、时长、缓动或音画同步**。
- **MP4 外观绝不证明作者源码或工具栈**：编码视频只证明可见画面与声音，不能证明作者用了 AE、Three.js、特定 shader 或弹簧参数。源码未知时仍可拆透可见动作，并基于 Motion 成熟本地方法给出**明确标注为“本地实现建议”**的复现路线，绝不把本地重建冒称为原作者实现；只有实际读到源码、版本、依赖与许可才能定性为“源实现”。

## 2. 按真正可迁移的单元定交接（不拿单效果充整片风格）

跨多段核对重复规律与例外，按证据覆盖范围分五类交接：

| 单元类型 | 核对与去重硬规矩 | 交接去向 |
|---|---|---|
| **稳定视觉风格** | 须在多段反复出现统一视觉语法；单帧或单个局部效果**绝不硬填风格卡**。对比已有风格时按**材质成图因果链、对象连接与运动结构、光路/空间、排印与声音**深比，不以“蜡笔/剪纸”大类名称判已覆盖；真覆盖就复用，有独立因果链再按原版模板结构提变体（仅用实测信号，不凑数） | 核对 [laohu-motion](../../laohu-motion/SKILL.md) 本地风格索引与模板（只读对比），新增由授权 Evolution 写回 |
| **局部动作 / 转场配方** | 把耦合生效的前态、起势、关键中间相位、遮罩/镜头、落定、声响、可替换项与验收帧保成完整配方，不拆碎 | 对照 Motion 本地 `recipes`，已有则复用 |
| **成熟源码 / 工程实现** | 必读完整源码、许可、依赖与调用接口（不以 MP4 或文件名代替），核验不覆写已有受保护原版资源 | 交授权 Evolution 迁入 Motion 本地资源并接通消费者 |
| **声画关系** | 基于实听音轨标记动作/转场时点、声源职责与授权状态 | 交 Motion 本地声音方法（音轨授权另核） |
| **整片节奏 / 结构参照** | 提炼段落递进、变奏与信息节奏作为设计参照，不变成逐镜模板 | 交 [laohu-analysis](../../laohu-analysis/SKILL.md) 编入本项目唯一 `brief.md`（本报告不充当第二份 brief） |

## 3. 研究私库与正式生产资源严格分离

- **研究收录（私库）**：遵循 `SKILL.md` 与 [atom-recording-and-reuse.md](atom-recording-and-reuse.md)，主记录入 `laohu-motion/benchmark/`，帧段与声画依据写入既有 `analysis` 可扩展字段，保持 7 字段 `consumer_bindings[]` 与稳定 `ATM-ID` 复用（同时服务 `laohu-motion` 与 `laohu-analysis/motion` 时追加 binding，不复制原子）。
- **正式生产转入（Motion 本地库）**：私有 `benchmark/` **绝不能作为生产运行时缺文件时再去翻的方法库**。需要升级为可调用/可编辑本地动效模板时，须在 Motion 正式目录完整登记身份、来源版本、输入、可替换项、必须保留条件、本地可读素材、实现与验证状态，并由授权 Evolution 写入接通；**声明“可编辑”或“可导出”前，必须实际改换内容、复演并从同一时码核对导出结果**，仅写说明文档不等于可调用资源。
