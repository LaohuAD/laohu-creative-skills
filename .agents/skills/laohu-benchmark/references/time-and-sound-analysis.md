# 时间与声音分析适配

本文件用于有实际音频、乐谱、动作时序、剪辑片段、字幕时钟或动态画面证据的决定。阅读纸面文本只能分析预期的节奏组织；没有相应声音或时间数据时，不把速度、停顿、重音、混音、可唱性、切点或观看效果说成已发生事实。理解一个形状、词句或声源可能需要怎样的先后线索，是对识别条件的分析；它不等于媒体里实际播放/停留了多久。只有读取到对应媒体或可信时间数据时才报告实测秒数、帧数或时间码，不能从口述、草图、字幕文字或剧情描述补出数值。

## 先分开时间、节拍和声音层

定位原作的时间范围和读取条件，确认听到/看到的是哪个版本、速度、声道、现场或剪辑状态。对能改变判断的事件分别记实际发生顺序、作品呈现顺序、接收者看见/听见线索及辨认所需条件，以及媒体实际占用的时长；并行与先后不能混算。把“观者需要看到哪些线索才可能认出对象”与“这段镜头/声音实际持续多久”分开；前者是关于可读性的机制判断，后者必须有可计量媒介证据。再区分主体实际速度、展开/压缩的展示时长、剪辑切换、声音/信息进入时机和留白停留。某一维的改变不自动代表整体节奏变快/慢。

至少观察：声音由谁/什么发出、源内/画外/配乐/环境属于什么层；音量、频带、音色、音高、密度、节奏、动态、重复和混响如何变化；哪些声部/声响彼此让位或遮挡；哪些镜头或动作和声音同步/错位；每一处变化在前后段落中的实际职责。由前后关系解释“听众此时先注意什么或等什么”，别只给音色贴“暖、厚、燃”的形容词。

## 编曲：从实际声音分工解释段落关系

分析编曲时先找某一段需要哪种听觉变化，不由歌名、流派标签或乐器名代替声音证据。比较同一动机在回来时的音高/节奏/配器/和声/空间差异，明确固定的是可辨关系还是某一音色；判断段落对比由音区、密度、节奏、动态、音色还是空间中的哪些真实维度承担。鼓、低音和和声节奏若共同支持或抵消律动，写明它们如何共享拍轴；声部有冲突时检查音域、奏法、可演奏性、频谱与对旋律的遮挡。能量变化不等于只推响度，减法或减配也可以把信息焦点交给歌词/主旋律。

使用原作动机或乐段作为方法候选时，既要读到其之前建立什么、变化处发生什么、之后怎样回归，也要听到真实音源；单张频谱图或风格说明不能证明情绪效果。将可迁移关系编译为当前歌曲的一个声部/段落决定，再由编曲负责按词曲交接流程试配与回填。

## 口语、剪辑和停顿：保护时间证据

录音中一次停顿可能承接呼吸、句法、情绪、强调、现场系统声或听众处理信息。无声能量低、ASR 行间空白、标点或转录断句不能证明可剪。需要精剪时须听源音频，按源范围和时间精度记清被保留、删除或未决；切掉静音不得吞掉辅音起音、爆破、齿擦音或尾辅音。无可靠词时码时只能作句段级范围判断。

如果讲话和画面共同制作，另区分录音已有的停顿、剪辑形成的接缝和没有源声音的 presentation 时段。画面需要观众读完一张图、看见结果或等待动作落定时，观看预算来自该视觉任务；只新增已保留可用原声停顿之外的净不足部分。ASR 时间线中 presentation 的插入会改变后续目标时钟，不能由 motion/HTML 消费者自行移动词锚或重算连续光标。

剪辑的来源保真是硬条件：raw transcript 保持不变；候选说法不是核听确认；有转录只可支持它实际覆盖的范围，不表示整段声音已完整。编辑性 display text 不等于实录原话。

## 输出绑定必须指向实际介质

原子具体到音频/乐谱/时间片、段落位置、镜号、源范围或帧相位；细读列明原作中能实际听/看的事实、有限推论、适用条件、制作依赖及未知效果。若当前下游是编曲，binding 写到声部/曲式/词曲交接；若是 ASR，写到有时间精度的 source range、coverage 与问题；若是视频或动画，写到镜头观看任务、时钟、声画关系或状态变化。不同输出需要的证据精度不同，不用一个“大概节奏”原子横跨全部任务。

实际试听、视看、采样/帧读取或用户给的可信时间数据缺失时，可以提出观察假设和需核验项，但不提供虚假数值、精确时间码或 PASS 结论。使用记录只记录当前成品/使用者怎样处理了候选及结果，不证明原子机制普遍正确。
