# 时间与声音分析适配

按需由 [SKILL.md](../SKILL.md) 挂载，处理编曲、稳定声线身份、ASR 口播剪辑、视频时序与声画关系。动画样片细读配合 [animation-analysis.md](animation-analysis.md)。

## 四条硬核观察与保真抓手

1. **可读性推演 ≠ 实测时长（无媒体绝不估数值）**：先确认可读版本、时间基准与音轨覆盖范围。“观者辨认需要什么线索”是结构判断，“实际播了多少秒/多少帧”必须有可读媒体或可信时间数据支撑——**绝不从口述、草图、字幕行数或剧情描述编造秒数、帧号、速度、停顿或混音听感**。
2. **多维拆解“节奏”，拒用空形容词**：把主体运动速度、展示停留时长、镜头切换、声音进出时机与留白分别拆开；观察声音来源（源内/画外/配乐/环境）、音区、密度、动态与频谱让位——能量抬升不必靠堆响度，减配留白同样能把焦点交给人声/主旋律。不用“燃、暖、厚、节奏快”代替声部与时序关系。
3. **稳定声线身份（`laohu-assets/voice`）边界**：仅在真实参考音频已提供、可读且获授权时将其作听觉证据（纯文字只代表角色用途与方向，不证明实际音色或辨识度）。从音色质地、相对音高、共鸣、气息、咬字、口音与稳定语速习惯中选 1 个主锚点 + 少量辅锚点，**把稳定身份与单句表演情绪严格分开**；仅当同作多角色确有混淆风险或用户要求群组配置时，用同文本、相近条件与相同任务做横向对比，条件不同即记不可比。
4. **口语停顿与时间轴保真（`laohu-asrcut`）**：低能量空白或标点断句不等于可剪——停顿可能承担呼吸、强调、句法转折或听众消化。精剪须听核原音频，切静音绝不吞掉起音辅音、爆破音或尾音；无可靠词级时码只作句段级判断。区分原声停顿、剪口与无原声的 `presentation` 时段（插入 `presentation` 会改变后续时钟，下游不得擅自偏移词锚）；`raw transcript` 保持原真不篡改。
