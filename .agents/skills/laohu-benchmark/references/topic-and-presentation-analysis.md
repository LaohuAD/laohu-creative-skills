# 选题与呈现分析适配

本文件把作品中“谁会关心、什么内容值得进入、材料作何承诺、怎样在页面/标题/排版中呈现”的可见关系，接到选题、标题、文章与 HTML/公众号决定。它不把主题相同当作可比理由，也不从流量、点击、热搜或名气倒推内容质量。

## 先把读者关切连到真实材料

分析某一作品的选题或入口时，至少区分：作品谈什么；作者/作品想让读者理解、选择、体验或继续追看的是什么；目标读者在何种处境会在意；实际内容在哪里兑现这项承诺。人群标签、熟悉术语、较大受众范围和强烈措辞本身都不能证明关切成立。

观察原作实际呈现的路线：

1. **入口与材料锚点。**标明可定位的题目、标题、开场、案例、人物/行为/差异/问题，以及它们在正文中的真实位置。入口可以是局部细节或作品识别，不必概括全文；但不能把正文没有提供的身份、结论、收益或结果写入承诺。
2. **读者和情境。**从原作材料、作者明确陈述、实际受众资料或有边界的公共经验，识别读者可能认出的场景/任务/选择。把事实与推测分开；不能只写“所有人都关心”“大家都以为”。
3. **内容所得。**说明读者若继续看，会得到什么解释、判断、做法、事件进展、幽默、情绪或审美体验。不同内容类型用不同标准；体验型作品不必伪装成教程，知识型内容也不能只靠标题有力。
4. **承诺兑现。**沿正文/章节/媒体路径标出材料在哪一处支撑标题入口、范围、结论或故事问题；校准承诺强度与实际覆盖。一个局部细节可以引读，但不能把未出现的因果或广泛结论强加给它。
5. **比较真实替代入口。**对比原作与备选标题/角度的材料锚点、读者理由、涵盖范围和兑现位置；只因更新鲜、短、强烈、覆盖更大或更像教程，不构成胜出理由。

不要把“提前说出结果”本身判成标题错误，也不默认剧透一定伤害体验。看作品实际承诺的是悬疑、结果进展、知识结论、情绪体验还是审美进入，再检查标题透露了什么、读者仍要看正文获得什么、哪些信息在后文兑现。只有目标体验确实依赖某项信息暂时未知，且材料建立了这种期待时，才把提前揭示记作代价；有些作品可以先交代结论，再靠过程、理由或表现吸引读者继续。

若作品没有发行/受众/平台表现数据，只讨论内容和编辑判断；不能宣称哪种入口获得了更多点击、推荐或传播。若有数据，记录平台、日期、样本范围、曝光/进入/停留/互动等各自口径。流量只能支持该口径的表现，不自动证明语言机制或可复制因果。

标题读者入口、文章选题和公众号页面虽相关，却不是一项决定。标题的传播理由须由选题/正文材料支撑；正文的阅读结构由写作 Skill 负责；HTML/GZH 的视觉/HTML 合规由呈现 Skill 负责。把三者混成“更吸引人”会使责任和复核对象都不清楚。

## 用 P—E—Q 避免假反转

只有目标候选真的采用反转时才调用：P 是文本或材料显示的起点；E 是目标读者能形成某个预期的依据；Q 是作品/材料展示的差异，以及它如何违背 E。E 可来自用户提供、稿件已经呈现或明确限定的公共经验；若无法指出它来自哪里，就不称为“大家原来都以为”。P 可以是真事实，Q 改变的可能是从 P 推出的预期，不一定否认 P。递进、并列、补充和观点变化不因为用了“却、反而、原来”就成为反转。

这项检查是标题 Skill 已定义的专业方法，在 benchmark 中只用于分析原作/候选是否真的具备该关系。若下游仅要普通说明标题、目录、作品名或篇内导航，不强加反转、利益句、问句或悬念。

## 从作品入口迁移到本题

保存时把标题/选题入口连回材料位置和正文兑现。把事件或其他源形式用于标题时，按入口职责决定透露、概括或暂缓哪些信息；标题可以直接概括一件短事件，也可以突出其中一个由材料支持的关系或问题。判断时核对读者进入前能知道什么、标题实际承诺什么、继续阅读的理由是什么，以及正文具体在哪里兑现；事件摘要本身不自动说明标题有入口价值。语义矛盾须落在同一对象、判断或期待关系上，不能只把两个相反词并排就称为冲突；标题可以揭示结果，也可以留下结果，按作品要交付的体验和读者随后还能得到的内容决定，不固定要求悬念或反转。迁移时再写明当前读者在什么具体情境遇到什么事实/问题，为什么可辨认，内容将给出什么、哪里支撑、用户要求的读者范围是否真的覆盖。若拟作圈外入口，解释专业内容如何从生活/工作场景进入专业材料，并说明事实和范围如何保持准确；只把专业术语换成大白话并不代表新读者能接上。

如果原作入口依赖真实作者身份、时效、地域、素材独占、用户评论、明确发布场景、私有经历或实际反馈，记入不可迁移条件。只借用关系结构；不把它当成用户本人经验，也不复制受众承诺、品牌声誉或未经本项目验证的点击成效。

## 归档前的最小记录

一张原子检索卡能告诉下游这次可比较的不是同题材而是哪种“入口—读者处境—材料兑现”关系；完整记录需附标题/正文定位、实际可读上下文、作者陈述与数据来源（如有）、读者关系推论的依据与限制、候选之间的真正差异、当前消费者和正文回查点。没有作品/受众反馈时效果状态保持未知。
