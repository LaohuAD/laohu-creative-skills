# 选题与呈现分析适配

按需由 [SKILL.md](../SKILL.md) 挂载，把作品的读者处境、标题入口、承诺兑现与页面呈现接到选题、标题、公众号文章、HTML 排版及元治理证据输入。绝不以流量、点击、热搜或大范围人群标签代替材料因果。

## 四个反偷懒观察抓手

1. **三点咬合核查（读者处境 — 入口锚点 — 正文兑现）**：拆清楚作品谈什么、读者在什么真实工作/生活处境会在意、正文具体在哪一处兑现标题承诺。体验型、观察型作品不必硬套教程标尺；知识型内容也不能只靠标题猛而正文发空。有平台数据时标清平台、窗口与指标口径，不反推唯一语言因果。
2. **别把“剧透”一刀切判错**：是否该藏结果，取决于作品核心体验是“悬疑揭晓”还是“看过程/理由/锋利观察”。只有目标体验明确依赖信息悬置时，提前说破才算代价；很多好稿先抛结论，再靠硬核拆解和过程留人。
3. **P–E–Q 核验防“假反转”**：仅当标题或入口确实采用反转时启用——核对 **P（材料起点）**、**E（读者已有预期的真实来源，如前文或明确公共常识，绝不空口说“大家都以为”）**、**Q（落同一对象的实质偏离）**。普通递进、并列或补充不因加了“却、反而、原来”就成反转；普通说明标题或篇内导航绝不硬加反转或悬念。
4. **剥离不可迁移的独占红利 + 圈外真实入口**：原作若靠作者独特身份、热点时效、独家经历或品牌背书成立，明确记为不可迁移前提，只抽关系结构。做专业内容圈外入口时，检查是否真从圈外人的真实痛点/场景搭桥，而非只把术语换成大白话。
