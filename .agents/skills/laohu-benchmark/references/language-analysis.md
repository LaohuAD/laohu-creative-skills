# 语言分析适配

按需由 [SKILL.md](../SKILL.md) 挂载，把选词、句法、称呼揭示、声口、意象与非语言转词句接到写作、口播、歌词、词曲交接与标题句面。不把分析做成修辞贴标，也不代替下游成稿。

## 四个反偷懒观察抓手

1. **放回使用位置做“替换 / 删句实测”**：先看谁对谁说、承接前文什么动作、后文怎么回收。动手测试：换一个近义动词，人物姿态、亲疏或责任变不变？删掉某句或压成事件摘要，具体丢了哪种语气、时间感或关系？若毫无具体损失，那是评论者贴的虚优点。直接准确的普通话一样能完成表达，绝不为“诗性”强加意象。
2. **称呼与命名的揭示次序**：当效果靠名称/称呼带动时，分步记清①先看到/听到的词、②当时已有的具体线索、③何时获得新解释。命名本身不等于揭秘，信息晚出也不自动等于反转，必须有可辨的前项期待与后续偏移。
3. **意象/声音贯穿核验**：不因名词反复出现就称“贯穿”——追踪它每次出现与谁并置、意义如何位移、何处暂隐与回返。涉及经典词作意象关系对照时，可核对 [laohu-lyrics 歌词对标方法](../../laohu-lyrics/references/benchmark-method.md) 的原文上下文，绝不搬运现代长段歌词或复制连续韵脚。
4. **非语言材料转歌词 / 文章 / 口播（换轨硬规矩）**：把画面或事件迁进文字时，**绝不按来源动作逐行切句**，也不强求每个物件变意象。先抽可迁移关系，再重建说话者/歌者身份、向谁说、在做什么言语动作、段落如何推进与回返；画面先后或视觉误读无法由文字原样承接时，明说损失与补足材料。无实际旋律或录音时，绝不推断真实重拍、可唱性或演唱听感。
