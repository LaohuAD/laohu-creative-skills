# 语言分析适配

本文件把作品中的选词、句法、声口、句群与旋律/口语证据，接到写作、口播、歌词、编曲和关键句的专业决定。它不把文学分析简化成修辞命名，也不代替消费者的成句、押韵、论证、编曲或改稿流程。

## 从使用位置开始，而非抽取金句

先确认这句话或句群在原作中的真实位置：谁对谁说、在什么关系里、它承接前文哪个意思/动作、后文怎样继续使用它。若要判断全曲、整篇或情绪推进，就读到足以看见首次建立、变化、暂隐、回返和收束的段落；如果只读一句，就只对这句的可见语义和句法作有限判断。

观察原文中的具体动作，而不是先选修辞名：

1. 逐词核对具体名词、动词和搭配由谁使用、对象是谁、有什么感知/动作指向；若把动词换成近义词，人物态度、动作力度、亲疏或责任是否变化？
2. 追踪语序怎样安排已知与新信息、重点与补充、判断与保留；代词、称谓、问句、否定、范围词和指示语是否让焦点或对象收窄/转移？
3. 比较相邻句及前后段的句法、并置、对照、省略、回环、韵位、停顿和声音重复。描述它实际改变的关系，不把出现重复等同“强调”，也不把有意空缺等同“留白”。
4. 回读上下文，检验删除某句或压缩成事件摘要后，接收者会失去哪种关系、语气、时间感、人物姿态、理解次序或段落功能。若没有具体损失，可能只是评论者贴上的优点。
5. 对比同作品相似位置和近邻替代表达：差异必须能在用词、句法、声音或段落作用中指出，并能解释为何与当前任务有关。

若效果依赖某个称呼、命名或揭示次序，分别标出“先看到/听到的名称”“当时已经可辨的具体线索”和“何时得到进一步解释”。逐步说明读者此刻能把名称连到什么对象或关系；若认知改变，指出是名称让对象更具体、前文线索使名称可被重读，还是解释补上了新的材料。命名本身不等于揭秘，信息晚出现也不自动等于反转；只有材料给出可辨的前项期待、后续差异和必要上下文时才作此判断。替换称呼或调换揭示顺序仅在可能改变意思、视角或接收顺序时比较，不为凑对照另造一种效果。

专业分析不要求作品处处比喻、含蓄、反转或押韵。直接表达可由前文建立的事实与关系承托；普通叙述可通过词语的准确选择完成任务。当前材料真实、具体、易懂不代表语言有缺口，不能为了“诗性”自动加意象。

## 将非语言材料转为歌词或语言段落

来源是画面、动作、事件或其他非语言材料时，先保留它真正能取用的关系及成立条件，再决定当前文字由谁说、向谁说、此处在完成什么言语动作。随后把关系重新组织成歌者或叙述者的表达、段落承担的变化，以及后文是否需要回返或改写前面的词句；不按来源事件逐个切行，也不要求把每个物件都变成歌词意象。若来源的先后、视觉误读或动作结果无法由词句自然承接，就说明这部分不能原样迁入，并判断目标段落还需什么材料或上下文。

目标是歌词时，以歌者的身份与关系、歌词段落在整曲中的作用、语言重心和必要的回返来组织采用说明；有实际旋律、录音或曲式信息时再检查句长、重音和可唱条件。没有对应音乐材料时，不推断实际旋律重音、节奏、可唱性或演唱效果；歌词段落在整曲中的文字作用仍可按已有歌词文本判断。目标是文章、口播或其他语言成品时，按该消费者的实际接收次序重建对象、信息和表达动作，不因来源有完整情节就把报告或正文写成分镜逐行转述。读完回到目标消费者的语言方法，由其负责人完成词句、段落和整篇复核。

## 特别检查：把意象、声音或隐喻落到句群关系

若本作依赖某个意象或声音线索，不因为标题/名词反复出现就称其“贯穿”。沿前后单元追踪它每次何时出现、与谁/什么动作并置、感知和意义是否改变、何处暂隐与回返；辅助材料怎样进入相同关系，彼此是否有可见共同点。压缩为主题概述后，写出丢失的实际体验或句法路径。只有这些位置成立后，才提炼能迁移的动作。

项目现有歌词方法记录了《牡丹亭》中“敬孤灯”这一搭配的段落关系细读：宴席共同声场逐步收束为独唱，举酒的礼节形式仍在而应答者缺席。它可作为已存方法来源的核对入口，但本文件不重印歌词或替其他歌曲设定同类意象。要用时读取 [歌词对标作品筛选与转化](../../laohu-lyrics/references/benchmark-method.md)，核对该词作本身的完整上下文、来源和适用条件，再决定当前作品是否确有可迁移的“关系变化中仍保留某个动作/声音”结构。

歌词中个别鲜明短句只能支持局部词义、语序或说话关系观察；整曲结构必须看多个段落，押韵与声口判断要尊重语言传统和旋律，若没有真实音频就不宣称听感结果。为了避免误用，迁移卡片记动作和关系，不保存现代歌词长段、不近义改写原作或复制连续韵脚。

## 写入消费者的可用记录

建立 atom 时把位置定位到段落、句群、曲式段或声音时间点，附够理解它的上下文。完整分析分别写明原文可见事实、作者自述（如有）、机制推论和效果证据/未知；记录固定关系、可变词项/节奏、适用语域、文化含义和不适用范围。

绑定到某个消费者时，说明这一源处理会在哪一步改变什么：选词、主语与责任、句子顺序、问句范围、口播信息切分、歌词句群/重音，或标题承诺。只写“可用于加强情绪/更有画面感”无法执行。返还的检查须看本作实际正文、歌词、试唱/音频或所在版位，不以方法说明代替成品。
