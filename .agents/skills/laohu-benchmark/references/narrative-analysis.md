# 叙事分析适配

本文件把作品细读接到故事、剧本、小说及含叙事结构的内容分析与创作决定。它只说明 benchmark 如何观察和交接，不代替这些 Skill 的创作步骤。本轮要解释材料中的事件、人物、信息、因果或回收关系，或为具体/未来采用决定选择材料时，均可加载；若只是改句子、标题或单个镜头，优先读对应适配。

## 先确定下游要解决什么

开始时先辨明本轮要解释的材料关系，或要支持的具体/未来采用决定。仅解释素材本身时，定位相关事件/信息关系所在单元及必要上下文，不要求先有当前项目；若服务当前作品，说明具体决定及实际作品位置；若暂无当前作品，说明未来可能遇到的决定、触发条件和适用边界，不虚构作品、场次或段落位置。只说“拆情节”“研究节奏”仍不能指导选择。

把接收者限定为本作实际读者或观众，不把“观众喜欢反转”“读者需要爽点”当作未证实的普遍前提。作品可以追求平静观察、幽默、留白、形式、抒情或开放状态；是否需要冲突、谜面、人物变化和闭环，要由原作证据、用户目标及目标 Skill 的方法共同决定。

## 读取单位与观察动作

不要把一句梗概当作剧情证据。先划出一个完整的行动/信息单元，再扩大到其前后必要材料，直到能解释它的前提、触发、后果和读者何时获得信息。

关于材料中的动作主体和时间先后，叙事适配使用主文“定位来源与证据范围”的句群还原与回查方法。这里把已确认的主体和事件关系接到人物行动、场面次序及读者/观众获知信息的次序；姓名、动机或知情背景仍可未知，但不能因此抹掉材料已给出的动作归属或时序。写场景梗概或原子候选后回看对应原句，核对重要关系有没有被调序；另提出的换人或调序作为建议单独标明，材料未定的顺序保持开放，不强排成节拍线。

1. **复原事件、呈现与知情顺序。**按材料分别列出事件发生顺序、讲述/镜头/文本呈现顺序、角色知道或误以为什么、观众/读者何时得到可辨认线索并能理解它。角色掌握信息的时间与接收者看见信息的时间分开记录；只在源材料支持时判断倒叙、延迟、预示或交叉，没有可靠顺序证据时标待核。
2. **读取人物所处的现实位置。**标出人物当时在意什么、已知/未知什么、可采取哪些行动、谁或什么限制了选择。再观察人物实际看见、误解、隐瞒、尝试、改变策略或坚持了什么；人物的关系、处境、态度或可用道路是否真的变化。若材料中有表态或评价，连同触发它的线索、评价者、所指对象与评价面向一起看，再对照人物当时的处境和关系，判断这句话或动作在当前语境中意味着什么，哪些条件支持或偏离通常读法，以及当事人或对方实际怎样回应、选择。对象、意味、刺激或回应没有材料依据时就保留为未知，不用人物标签、情节功能或象征物补齐。
3. **把身体反应、解释和选择分开。**先记可见或可听的身体反应，再说明人物如何理解眼前线索，最后记录他实际选择了什么。身体动作可以支持某种情绪推论，却不能单独证明人物的解释、动机或后续决定；推论要指出依赖的线索和仍可能成立的其他解释。若接收者只见到人物的反应，还未得到原因或判断依据，也要保留这层信息差。
4. **追踪行动而非套结构名。**将有证据的行动还原为触发条件、目标、阻碍、策略/选择、结果及他人回应。不是每场都要填齐或制造高潮；若原作是静态观察或情绪停留，就记录其注意、认识、关系或体验如何被维持、转移或重新看见。
5. **读取单元怎样接续。**对前后单元逐个说明：前一处留下的行动后果、尚未回答的问题、人物已持有的信息或可见材料是什么；后一处怎样接收、改变或回避它。只有回返或近邻比较能改变这次判断时才展开，指出每次出现的实质差异，避免把重复误记成无功能复述。
6. **识别读者承诺及公平边界。**区分缺少信息产生的好奇、结果未定产生的张力、违反预期产生的惊讶，以及后文对先前承诺的回应。检查延迟是否仍保留理解眼前处境所需条件，揭晓是否能从先前材料重读；若没有问题、损失或待兑现体验，不强行给作品加“钩子”。

对一件作品的整体弧线主张，应读到该弧线建立、变化与收束的位置；对一个局部行动，只读足以证明它怎样进入邻接关系的范围。不同版本、剪辑或译本可能改变时间、行动、语义和悬置判断，逐一记明。

## 转成各类消费者的专业决定

| 消费者/当前职责 | 观察什么 | 对照/比较动作 | 返回产物与接手步骤 |
|---|---|---|---|
| `laohu-story`：选材、取舍组合、组织整体构想 | 入选材料实际表达的经历、人物处境、内容作用和固定前提；单元依赖顺序、回收与结尾承诺 | 逐项比较完整候选与本轮目标、已有主导关系及其他候选；检查抽掉某项后具体损失什么，补入后是否仍与用户锁定项相容 | 返回材料位置、实际贡献、承担的功能/关系、相邻依赖、待核事实和开放变量；交给故事 Skill 的选择组合或总体构想，不代写正式作品 |
| `laohu-script`：剧本结构、场景开发与节拍 | 主行动、角色目标、对抗/阻碍、行动选择、空间/物件状态、结果与对手回应；一场如何改变下一场条件 | 对照同一单元的动作前后、角色之间行动能力、线索与人物判断的证据链；比较幕/序列/场/beat 的实际职责，不把理论结构名当原因 | 返回可落到场次、节拍和场间承接的关系，以及动作结果、知识权限、场面或格式中仍需创作者决定的部分；由剧本 Skill 接入其结构/场面方法 |
| `laohu-novel`：小说材料、读者期待、叙述与正文 | 人物目标与有根据的选择；谁讲、谁感知、读者知道什么；事件顺序、展开/概述/省略、期待和回收 | 比较事件时序与呈现次序、角色/叙述者/读者所知、相邻段落的注意焦点；追问问题的答案怎样改变人物处境，而不只补“谜底” | 返回可用于材料推演、章间承诺、聚焦/时序或段落呈现的具体决定；由小说 Skill 在当前步骤重建正文，不模仿原作表面声音 |
| `laohu-writing`：含真实经历或案例的叙事写作 | 事实顺序、讲述者视角、证据来源、人物行为、解释何时出现以及故事如何交给文章判断 | 对照原材料与文章的主线、观点/体验和证据所需条件，检查叙事是否遮掉必要事实或用故事结果暗示超出证据的因果 | 返回可核事实的位置、读者进入点、叙述单元作用及需要保留的来源边界；交还写作结构与材料核验，不把人物化叙事强加给解释型文章 |
| `laohu-video`：把已定文本分成可观看事件 | 行动因果、观众必须看见的证据、人物/物件状态与切后新增信息；事件表演和镜头职责分开 | 比较保留/省略后的因果能否由观众还原，镜头前后是否真有新证据或回应；镜头切换与剧情 beat 不互相代替 | 返回需观众看见的事件范围、前后状态和承重线索；交给视频 Skill 决定镜头、时长与声画执行，不提前伪造时间码 |

故事/剧本/小说的整体层与局部层不能互相替代：单个漂亮行动无法证明整条弧线；宏观结构图也不能证明场景里人物已经做出选择。下游正在作哪个尺度的决定，就把材料读到哪个尺度，必要时明确说尚缺父级作品证据。

叙事交接时，明确这是人物的身体反应、人物自己的解释、读者/观众可见的信息，还是人物实际作出的选择；它们不是同一字段，也不要求每场都出现四者。只有源材料呈现了行动后果时，才把它记作来源已有的因果事件；若提出可能的发展或后果，另标为新增建议，并说明这是待采用的推演，不是原作事实。若材料只支持一个短暂感受或观察，不把推演混进来源叙述或冒称戏剧反转。

## 写成可复核的原子和采用说明

原子卡的标题需指向一个可区分的关系，例如信息何时从“能听见内容”收束为“能理解说话者”，或后果怎样成为下一场的行动条件；概要写明其来自何处、适用于哪个决定。完整记录至少保留具体位置、该处前后上下文、可见行动/信息次序、机制推论、适用条件、固定关系、开放变量和限制。不要只记“信息差”“反转”“钩子”“三幕结构”等词。

给 `consumer_bindings[]` 写清对应消费者的具体决定、阶段、必须重新读的上下文、转换到当前作品的方法、返回到哪个创作步骤及一条真实复核标准。一个叙事关系可以被剧本和小说共用，但各自的行动、叙述、交付和复核不同，应各写 binding，不复制 atom。若来源只有短梗概、单幕片段或未核版本，atom 保持候选/局部观察，不升级成全作规律。
