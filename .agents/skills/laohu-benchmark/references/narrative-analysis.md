# 叙事分析适配

按需由 [SKILL.md](../SKILL.md) 挂载，把事件、人物选择、知情次序与单元回收接到故事、剧本、小说、叙事写作与视频事件决定。不代替下游 Skill 写正文或分镜。

## 四个反偷懒观察抓手

1. **四条线彻底拆开（别把梗概当证据）**：对最小完整行动单元及其必要上下文，分别记清①事件实际发生顺序、②文本/镜头呈现顺序、③角色当时知道或误以为什么、④读者/观众何时拿到可辨线索。只有源材料支持时才判倒叙、延迟或预示，未定序保持开放，不强排节拍线。
2. **身体反应 ≠ 人物解释 ≠ 实际选择**：先记可见/可听反应，再分出人物如何理解线索，最后看其实际策略与行动后果。身体反应不能单独证明动机或决定；只有材料真写出后果才记作来源因果，另推的可能发展标为新增建议。
3. **拆“行动与条件变化”，绝不套结构名词**：追踪一场/一段里前一处留下的后果、债务或信息，后一处怎样接收、改变或回避。作品完全可以是静态观察、幽默或留白——**绝不默认观众都要爽点/三幕冲突**；只有前项建立明确期待、后项在同一关系上动摇它时才算反转。
4. **守住读者承诺的公平边界**：分清缺信息的好奇、结果未定的张力与违背预期的惊讶；检查揭晓能否从前文线索重读，以及局部漂亮行动能否撑起全作弧线（整体弧线须读到建立—变化—收束，缺父作品证据就收窄结论）。
