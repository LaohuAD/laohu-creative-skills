# Dance-pop：强记忆歌唱 Hook、四踩身体支点与期待释放接力

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **歌唱 Hook 占绝对前台 ＋ 舞池脉冲托住身体**：无相反参考时采用 4/4（常见 116–128 BPM，缺省起稿可用 120 BPM）：四踩 kick 稳住地板、clap/snare 落第 2、4 拍、bass 在 kick 间隙切分弹出推进感；但与纯 Club 舞曲不同，**所有律动与合成器必须让位于副歌第一句立刻亮出的可跟唱歌唱 hook**（用户锁定 breakbeat 或现场乐队律动时继承其真实拍轴）。
2. **蓄压—抽空—释放的段落接力（按真实职务决定段数，不为套公式硬塞）**：
   - **Verse**：收薄中高频合成器密度，清晰交代主唱叙事与基础脉冲；
   - **Pre-Chorus（仅确有期待抬升职务时保留）**：靠 hi-hat 加密、和声加快、滤镜渐亮或上行铺垫把张力拧紧，并在进入副歌前半拍到一拍**果断抽空低频与底鼓**吊起胃口；
   - **Chorus**：四踩与饱满低频同帧回归，把主唱记忆 hook 狠狠托上强拍与最宽声场；
   - **Post-Chorus / Drop（仅当器乐采样或短人声延伸钩子承担独立舞池参与职务时保留）**：可与歌唱 hook 形成分段接力，末轮副歌再将两者叠合推向全曲峰值；无独立职务则果断省去，绝不为凑小节硬填。
3. **清晰声部避让**：高频合成器、切分吉他与开合踩镲错开拍位与声像，绝不在副歌与主唱钩子争抢 1–4 kHz 辅音清晰区。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：清亮有弹性的现代流行低频瞬态、极高清晰度的贴耳主唱前景（副歌可配宽声像叠唱或干脆和声支撑）、利落干脆的声场收放反差，不沦为同质化合成器糊墙。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 明确四踩与 2/4 clap 脉冲、bass 切分、歌唱 hook 的首次亮相与回返、预副歌抽空蓄势及恢复爆发点（无 Pre/Post 则直接跳过不写占位）。MIDI 按 4/4 每小节 4 QN：kick `+0/+1/+2/+3`、clap `+1/+3`，bass 避让底鼓瞬态切分，hat 主歌八分、抬升段加密十六分。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否立刻能感受到既有让人跟着踩拍的鲜明舞池推进、又牢牢把洗脑歌唱 hook 托在聚光灯正中央的清脆张力？

将舞池拍轴、核心歌唱/器乐 hook 接力分工、预备抽空与释放点、段落取舍与人声空间回传主文蓝图。
