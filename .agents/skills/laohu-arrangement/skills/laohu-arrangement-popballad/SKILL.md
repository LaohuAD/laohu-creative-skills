# Pop-ballad：钢琴呼吸托唱、真实递进与克制回落

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **钢琴 × 主唱的亲密骨架**：无锁定时以 4/4、约 66–80 BPM（缺省起稿可用 72 BPM）立住可跟随的稳定呼吸拍感（有锁定 rubato 时标清速度弹性与共同恢复拍点，绝不写任意漂移）。先让钢琴与主唱自身独立成立：**左手在和声换位处稳给低音根基与线条，右手用近距可唱的分解或柱式托底；一旦碰到主唱关键词与持续长音，右手果断减密让出 1–4 kHz 空间，等句尾再给一声轻盈短回应**。
2. **克制蓄势 × 副歌协同打开（严防穿交响大龙袍，也防拘谨打不开）**：主歌保持近场干爽与窄音区呼吸，让听众像坐在歌者对面；预副歌（确有蓄压需要时）借和声悬置、低音持续或半拍抽空把情绪拧紧；进副歌时按情感真实体量锁定 **1 到 2 个主导推进轴**协同发力（如钢琴张开八度宽 voicing ＋ 暖厚贝司与轻鼓确立脉冲 ＋ 远景克制弦乐长线托宽声场），**绝不把私密倾诉强行堆成史诗交响大合唱，也不靠全体硬推响度充当高潮**。
3. **桥段与高潮回落的真实分量**：高潮可以是音区抬升、织体绽放，也可以是抽空至一架钢琴配撕裂弱声的极度静谧；桥段承担对照、换气、停留或视角微转即可，不要求新增剧情因果或强制转调；高潮过后安排真实落点或素颜尾奏回收，让余韵留进听众心里。
4. **反套路选材**：抒情绝不等同于 3/4 拍、机械四和弦循环或每句强终止；若加层后主唱发挤，立刻移开钢琴右手音区或删去多余铺底，再谈混音。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：有真实木质琴槌与踏板空气感的近场立式/三角钢琴（低潮段可微暗柔和，高潮段打开亮度与宽深）、清晰可辨唇齿气息的主唱干近前景、远景柔和缓起的暖弦乐托底。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 重点交代钢琴左手低音锚与右手在主唱长音处减密留白、主歌近场克制与副歌选定推进轴及回落动作。编排 MIDI/谱面时，分列 Vocal / Piano-LH / Piano-RH / Bass / Strings 轨，左手仅在和声目标起音，右手随主唱长音让位并在句尾回应，弦乐长音写实起止与段落动态曲线，不靠整轨拉满力度模拟高潮。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否立刻能感受到钢琴随着主唱呼吸一收一放的亲密对话、副歌打开而不抢词的克制张力，以及高潮落定后余味绵长的真实回落？
