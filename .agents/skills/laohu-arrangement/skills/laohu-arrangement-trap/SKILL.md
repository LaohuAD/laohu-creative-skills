# Trap：倍拍骨架、半拍重击、808 音高线与节制滚奏

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **4/4 倍拍轴上的半拍骨架**：无速度与拍号锁定时，采用 **4/4、140 BPM（以四分音符计）** 作为项目倍拍工作起点，**snare / clap 稳落每小节第 3 拍**，由此形成强烈的 **70 BPM 半拍身体感**（绝不把项目 tempo 改成 70 后混淆网格）；用户已锁定其他拍轴或直拍时沿用其拍轴。
2. **基础八分帽 ＋ 句法节点节制 roll**：基础 hi-hat 先以稳定八分音符立住推进感；十六分或三连音 roll **绝不是每小节乱铺的风格配额**——仅在主唱句尾或转段前存在至少一拍真实空隙且需引回下一强拍时加入，默认每 8 小节至多一次、长度不超过 1 拍并精准落回强拍；无空隙则省略。
3. **808 音高、尾长与底鼓分离治理**：808 不是无音高轰鸣，须紧扣和弦根音或低音线条标定准确音高。需重击时在主 kick 位短促同击，需延展低频能量时拉长同音至下一和声或鼓点前切断；其余位置错开起音或缩短尾长防低频互吞。滑音须写清起点、目标音高与到达拍位，并核实音源支持 portamento/slide（不支持时改离散经过音，不画空饼）；超低频默认保持清晰单声道中心。
4. **稀疏前景与中频大留白**：Trap 风格本身不绑定黑暗情绪或固定音色；靠 1 个高辨识核心旋律/音色核配合空旷中频托起说唱或旋律说唱，段落推进靠 hi-hat 细分切换、808 进退、音区与低频重量拉出大反差。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：干脆尖锐的高频瞬态与紧实可控的超低频形成冷峻或炽热的极端动态反差，保住高张力打击力度，绝不因过度圆润把冲击力磨平。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 交代倍拍半拍口袋、第 3 拍 snare 重心、808 延音或目标滑音性格及句缝节制 roll。编排 MIDI/谱面时，每个 808 音符注明实际音高与起止门长，roll 逐音写出细分与力度渐强（三连音标清拍轴），808 滑音单列 pitch-bend 曲线、目标音源弯音范围与回中拍位，且不与同通道持续音共享弯音。
