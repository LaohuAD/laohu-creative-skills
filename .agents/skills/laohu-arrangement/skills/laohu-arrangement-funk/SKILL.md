# Funk：十六分咬合、贝司领跑、幽灵军鼓与干脆切音

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **十六分精密网格与 Bass Riff 领跑**：无锁定时以 4/4、约 96–110 BPM（缺省起稿可用 100 BPM）建立十六分细分网格，以一条 1–2 小节极具记忆度的 **bass riff**（结合强拍支点、十六分切分、干脆休止与强弱重音）作为整支乐队的律动引擎，每小节务必留出让重音弹起来的呼吸空隙。
2. **鼓组 × Bass 精密错位（绝非只靠十六分踩镲冒充 Funk）**：snare 稳砸第 2、4 拍主重音，其间穿插极低力度的 **ghost notes** 粘合十六分动势；kick 只强化 bass riff 的关键支点并补空位，绝不拍拍全盘复制 bass。校验整组 pocket：若 bass 只傻弹根音、吉他扫长和弦，单铺十六分踩镲仍不是真 Funk。
3. **干脆短促的中高频切分回应**：清音电吉他闷音刮弦（chicken scratch）或 clavinet 择一主责，以极短时值切分填入 bass 留白，与低音形成错落对话；铜管短重击（horn stabs）只留给乐句尾或转段点睛，不从头铺满。
4. **Vamp 和声与克制变奏**：和声完全可在 1–2 个和弦的 vamp 上稳健循环（不强求 V–I 终止），七/九/sus/布鲁斯色彩音按旋律需要点缀；段落发展靠 riff 句尾小变奏、鼓组开合、铜管回答或短独奏接管，绝不靠推翻核心 pocket 换段落。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：干脆紧绷、瞬态清晰、零多余混响泥淖的录音室乐队咬合感，保住贝司指弹/拨奏弹性、军鼓脆击与切音闷弦的颗粒动感。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 明确十六分网格、2/4 backbeat + 稀疏 ghost notes、bass-led 切分 pocket、短促闷音吉他/clav 回应与 vamp 骨架，人声短句重音与 bass 错位咬合且避开三方同时密集十六分撞车。MIDI 按 0.25 QN 十六分网格写实 bass riff 起音与休止、snare `+1/+3` 主击与低力度 ghost、吉他/clav 短门长（如 0.25 QN 起步）而不移动拍位。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否一听就能感受到鼓、bass riff 与短切吉他/clav 像精密齿轮般在十六分网格上互相让位又紧紧咬合的弹跳口袋？

将 bass riff 识别核、kick/snare/ghost 互锁坐标、短切和弦分工、铜管/句尾回应及段落变奏回传主文蓝图。
