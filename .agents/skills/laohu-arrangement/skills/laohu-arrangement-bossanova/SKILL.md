# Bossa Nova：直八分二拍宏拍、落拍单音低音与拍间切分漂浮

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **二拍组织 × 四拍直八分计数（严禁自动加 Swing 或摇滚后拍）**：继承宿主拍号；4/4 时明确数 **`1&2&3&4&`**、以第 1、3 拍组成两个二分宏拍（缺省起稿可用 96 BPM 四分音符计）；2/4 时数 `1&2&`（两小节 2/4 等价一小节 4/4，换 2/4 须重写小节数绝不混淆拍速）。**八分细分必须保持绝对 straight 直分，绝不自动做成三连音摇摆，也不用重摇滚 2/4 拍 snare 或强四踩舞曲 kick**。
2. **极简落拍单音 Bass 支点**：4/4 默认第 1 拍弹当前和弦根音、第 3 拍弹五度（若第 3 拍前换和弦改弹新根音）；2/4 每小节第 1 拍弹根音、第 2 拍相容时弹五度。禁止乱写连续 walking bass；仅在连续同根音且旋律有至少一拍空隙时加单个三音连接，或换和弦前主唱 `4&` 留白时将新根音提前到 `4&`。
3. **上声部拍间短切分与乐器互斥**：尼龙吉他（拇指稳落低音、手指轻拨拍间和弦）或键盘（左手低音、右手短 voicing）把切分和弦放在拍间 `&` 位（与 bass 至少拉开一个八度）；若吉他与钢琴同奏，遵循《Corcovado》分工——吉他扛基础律动，钢琴只补缺位拍与短句，绝不双重复制完整伴奏型。轻打击（shaker、鼓刷、轻侧击 rim）仅点染细微脉冲，区别于高密度狂欢 Samba。
4. **弱拍漂浮旋律与克制色彩**：主旋律自由在弱拍起句、跨小节线延留并留白呼吸；和声延伸音（优先 9 音）仅在旋律长音自然相容时点缀，不为了显爵士强叠繁复延伸音。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：贴耳清澈、微带指尖拨弦空气感的尼龙吉他或轻触键电钢，低动态大留白，人声亲近自然（不自动刻板假定低沉气声）。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 必须写清四拍直八分计数与二拍宏拍感、落拍单音 bass、拍间短和弦切分与极轻打击，绝不写 swing。MIDI 坐标按原拍号：4/4 bass 落 `bar_qn+0`（根）与 `+2`（五/新根），上声部短和弦默认起音 `+0.5`（1&）与 `+2.5`（3&）（gate 默认 0.5 QN，与辅音/低音碰撞时先删冲突音，必要时缩至 0.25 QN）；仅当人声句末落 2/4 拍且后续八分完全留白时，才按需加 `+1.5` 或 `+3.5` 切分。
