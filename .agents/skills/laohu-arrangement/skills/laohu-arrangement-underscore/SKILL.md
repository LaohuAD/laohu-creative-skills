# Screen Underscore：潜台词叙事职务、对白净空与沉默重量

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **每个 Cue 必须有明确叙事职务（绝不为填满空白铺电梯乐）**：动手前先钉死这段音乐对观众认知起什么作用——制造潜台词预感、托住情绪暗流、缝合剪辑连续感、定格空间气候，还是推动一次心理转折。能靠安静放大压迫感或真实感的时刻，**沉默本身就是最强声部**。
2. **五类画面/叙事场景的进退裁决**：
   - **新场景或悬念未揭**：切镜前短暂预入持续音或低密脉冲建预感；需靠环境声/首句制造惊愕时则延后至事件发生后再进；
   - **关键台词与角色抉择**：果断降旋律起音密度并彻底清空对白相近频段（1–4 kHz），留极稀低/高持续床层或在承重词前干脆退出，句尾再留一声余响，绝不靠大混响试图藏起拥挤声部；
   - **发现、反转与心理突变**：把和声、音区或织体转折落在观众接收信息后的**确认点**，不机械抢在每一个肢体动作上砸重击；
   - **动作与快剪**：锚定长呼吸句或整体低频脉冲带过密集剪辑，仅在导演指定或核心剧情重击处落精确 hit point；
   - **离开或接下场**：明确收束、跨景尾音延留或提前抽空让位，无缝衔接下场时保调式或单音连续。
3. **无画面与锁画同步严格分界**：
   - **有锁定画面/镜头表**：严格按素材版本、fps、精确时码与关键对白/SFX 列表换算 `cue-in` / `cue-out` 与转折点；版本变动即重核；
   - **暂无画面与时码**：按用户给出的剧情事件顺序编排**未同步叙事草案**（如以相对时间窗建立 → 呈示关系 → 关键节点变单维 → 对白前留白抽空 → 余韵收尾；绝不编造假时码或自创未给情节；若需均匀量化网格可标明探索工作网格且未同步）。
4. **对白下克制人声红线**：场景配乐默认器乐或声音纹理前景；仅在确需人声时使用避开对白频段的极简无词长音或对白缝隙极短碎片，绝不把对白下的 underscore 偷换成长段歌词主唱。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：极宽的动态余量与精准的频谱避让——近景极微弱的材质张力与远景克制和声气候配合，为对白人声和物理拟音让出绝对舞台。
- **AI 生成与符号/MIDI 专属注意**：器乐草案在 `Motif / Front Identity` 与 `Instrumental Form` 写清单一核心材料（动机、低频脉冲、和声场或刻意静默）、叙事入出与对白让位节点。编排 MIDI/谱面时，自由速度保持绝对时间点或 tempo map 而不强造等距小节，无画面事件用相对拍位并明标未同步；核查长释放音源在 Note Off 后的真实尾音以免拖进下句台词；时码、fps 与音效信息作伴随 cue 表，不伪造成 ABC 音符。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉说明，这段编排是否读起来就自带镜头呼吸感——该退让台词时彻底干净、该屏息处敢留真安静、转折精准踩在观众心头确认那一瞬？
