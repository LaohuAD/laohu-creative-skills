# Techno：铁律脉冲、一节稀疏核与单轴催眠演化

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **铁律四踩与极简 1 小节核心循环**：无速度锁定时采用 4/4、124 BPM 起稿，四分音符 kick 稳如机械心跳；选一个高度凝练的短声音事件（低音脉冲、金属短击、稀疏合成音型或噪声纹理）作为循环识别核——**默认锁死 1 小节循环**，仅当不可分割的起音—回应动机跨越小节线时才扩至 2 小节。
2. **与 House 的本质分野——重单轴连续演化而非和弦问答**：Techno 不靠反拍和弦对话或传统主歌副歌取胜，而是靠重复中的微距运动制造催眠张力。**每个大段落（如每 4/8/16 小节）只移动一个主要变化轴**：音色/滤波（cutoff、共振、谐波饱和）、起音密度（加减单层细分）、音区或空间反馈（延迟与混响景深），并安排收窄退回的呼吸段，绝不默认强加 EDM 式大 Drop。
3. **极少音高材料与清晰低频**：常以单音中心、持续 drone 或极少和弦变化维持紧张度，不强套 V–I 终止；sub/bass 用音长、错拍或滤波与 kick 清晰分家，高频只选一层主细分，绝不同时铺满多种镲片与噪声。
4. **主题与人声服从催眠秩序**：器乐保持单一明确前台事件；确有人声时选克制短语或获授权的稀疏重复切片，嵌在固定循环槽位并留出足够空间，绝不因 Techno 标签擅自加人声。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：冷峻、精确、空间纵深极强的工业或暗房质感，保住低频压迫感、金属瞬态锋芒与连续滤波张力，绝不磨成柔和背景电子乐。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 重点写清固定四踩、1 小节稀疏核心事件（跨线才 2 小节）及逐段单一变量演化方向（纯器乐写入 `Motif / Front Identity` 与 `Instrumental Form`）。编排 MIDI/谱面时，kick 落每小节 `+0,+1,+2,+3` QN，核心辅助事件定在清晰槽位（如 `+3.5`），保持 note onset 稳定而把滤波/空间轨迹交由目标 DAW 明确控制映射，不把自动化伪装成音符。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否立刻感受到铁律般的稳定四踩、1 小节稀疏催眠核与缓慢有力的单轴音色/密度演化，且毫无流行副歌或暖调 House 和弦串味？

将固定拍点、1/2 小节循环核、各段单轴演化轨迹、主题留白与无缝循环或收尾边界回传主文蓝图。
