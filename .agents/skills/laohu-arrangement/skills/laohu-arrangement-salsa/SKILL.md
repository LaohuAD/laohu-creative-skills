# Salsa：两小节 2–3 Son Clave、Cut-Time 真实速度、跨线预奏 Tumbao 与同向 Montuno

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **不可随意翻向的两小节 2–3 Son Clave 与 Cut-Time 真实速度（严防半速事故）**：
   - 现代标准 Salsa 采用**两小节 = 1 组 Clave 周期（8 个四分音符）的 `4/4` Cut-Time（`2/2` 律动感）记谱**：**第 1 小节（2-side）两击落 `2`、`3` 拍；第 2 小节（3-side）三击落 `1`、`2&`、`4` 拍**。
   - **速度铁律**：Son-based Salsa 的真实舞蹈速度按**二分音符宏拍计为 `𝅗𝅥 = 90–100 BPM`**（1 组两小节 Clave 耗时约 2.4–2.7 秒），因此在 `4/4` 记谱、ABC `Q:1/4=` 与 DAW/MIDI 四分音符 Tempo Map 中，四分音符速度必须设为 **`♩ = 180–200 BPM`**（无指定时默认 **`♩ = 184` 或 `192 BPM`，并明注 Cut-Time 宏拍 `𝅗𝅥 = 92` 或 `96 BPM`**）。**绝不可在两小节 Clave 记谱里把 `Q:1/4=` 或 MIDI 速度写成 `96 BPM`**——那会让实际播放慢成 48 BPM 半速！
   - 全曲保持同一周期朝向，仅当用户明确指定 3–2 或来源曲确有翻转时才整周期换向，绝不逐小节乱翻。
2. **第 4 拍跨小节线预奏根音的 Bass Tumbao（最核心识别核）**：
   - 标准 son bass 绝不在第 1 拍重砸起音——**在前一小节第 4 拍提前奏响下一小节目标和弦的根音，并持续跨过小节线、完整占住下一小节第 1 拍**（`onset_qn = cycle_start_qn + 3`，`offset_qn = cycle_start_qn + 5`），随后留空并在下一小节 **`2&`（`+5.5`）** 奏出五度、三度或半音引导音（如 Dm→E7 用 `F→E`、E7→Am 用 `G#→A`）回应；低音优先落在扎实饱满的四弦贝斯音域（如 `E1–A2`），避免全程悬在高音弦显得单薄；第一小节起手空出重击第 1 拍或仅极轻引导。
3. **同向双手八度 Piano Montuno 与严守编制的分层打击乐**：
   - 钢琴 montuno/guajeo 贯穿两小节 2–3 周期，在中高音区以双手八度切分填补 clave 空隙、保共同音顺滑换位，且**偶数小节第 4 拍与 bass 同步提前切入下一和弦**；核对 bass 5 音与钢琴色彩音防刺耳小九度撞车（如 `Am` 下 bass 落 `E2` 时，钢琴上声部配 `[C G]` 或 `[C F#]`，避开 `[C F]`）。
   - conga、bongo、timbales、cowbell（campana）、maracas 各自只扛单一层次——若用户限定**只配一层关键打击乐**（如 Conga Tumbao），严守编制绝不擅自加进 timbales 或牛铃；大型合奏也须到 montuno/mambo 高潮段才逐步加层，绝不从前奏一窝蜂全开。
4. **Cuerpo 正文 → Montuno 问答结构**：人声曲遵循正文（cuerpo）交代主旋律 → 短 break 切入高能 montuno → 领唱短句（pregón/guía）与固定合唱（coro）交替呼应，铜管齐奏精准落句尾回应不盖词头；器乐循环可纯以和声与律动推进，不强套古典 V–I 终止。

## 二、声音质感与符号/MIDI 编译专属避坑

- **物理听感方向**：热烈清脆、层次分明的拉丁合奏现场感——干脆木质 clave 与有清晰强弱反差的 conga 拍击（Slap/Open 与 Heel/Tip 鬼音拉开鲜明力度差）、清亮中高频双手八度钢琴切分、温暖饱满跨线低音。
- **AI 生成注意**：Style Prompt 写清真实 Cut-Time 速度感、两小节 2–3（或指定 3–2）Son clave 周期、同向双手钢琴 montuno、第 4 拍跨线预奏且次小节 `2&` 回应的 bass tumbao、克制打击分层及人声问答（无词或非西语锁定词严禁擅塞西语群唱词）。
- **符号谱与 MIDI 硬规则**：
  - **跨小节线延音**：ABC 2.1 / MusicXML 4.0 编译 tumbao 与钢琴跨线音时，**必须拆为小节线前后同音高并用同音连线（tie，和弦用括号内逐音连线）连接**；MIDI 中写成单条连续 Note On → Note Off，绝不截断重触发；
  - **GM1 康加鼓与 Ch 10 防错**：GM1 兼容层中，Conga 轻掌鬼音（Heel / Tip）必须映射到闷音 **`62`（Mute Hi Conga）** 靠力度拉开层次，**绝不可错绑到 `64`（Open Low Conga，专留给低音 Tumba Open）**；共享 GM 通道 10（底层 9）的多条打击乐轨**绝不可在 `tick 0` 发送互相冲突的 `CC7`/`CC10`**（通道控制器会互相覆写），独立摆位须注明在 DAW 挂独立音源分通道处理。

## 三、脱标盲辨与返回主文
