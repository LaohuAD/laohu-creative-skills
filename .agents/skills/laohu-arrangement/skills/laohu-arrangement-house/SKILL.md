# House：四踩地板、反拍弹跳、切分低音与层进舞池

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **地板 ＋ 反拍高频的经典舞池三角**：无更窄分支锁定时，采用 4/4（常见 120–128 BPM，缺省起稿可用 124 BPM）：**kick 每拍稳踩（1/2/3/4 拍）**，clap/snare 锚定第 2、4 拍 backbeat，闭合 hi-hat 或 shaker 在反拍八分音符（`&` 位）维持上扬弹跳感；开放 hi-hat 留到乐句尾或段落交界提神。
2. **与 Techno 的本质分野——切分 bass 与反拍短和弦互动**：四踩底鼓本身不能区分 House 与 Techno。House 的灵魂在于低频与和声的温暖摇曳：写短促弹跳的 bass cell 穿插在 kick 间隙形成切分呼应（绝不拍拍机械复制 kick）；键盘、电钢或吉他以短促反拍和弦（stabs）落在拍间，内声部保共同音小步滑行，扩展色彩（七/九/sus）仅在旋律与气质支撑时加入。
3. **单一可记前景钩子**：选人声短循环（chant/sample）或清晰旋律主唱、抑或单一合成器/和弦钩子担纲前台，与 bass 空隙互补；主唱入句与重音词处减薄同频段和弦起音。
4. **靠叠层与抽空组织长舞池呼吸**：先确保 kick、bass 与核心钩子三者独立成立，再按乐段逐层增减高频细节、和弦长度、滤波明暗或空间尾音；绝不为强造流行副歌而强塞硬套的 EDM 巨型 riser/drop。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：饱满而有弹性的低频瞬态、温暖有律动呼吸的中频和弦短触键、明亮上扬的反拍高频，整体兼具舞池推动力与温暖人性摆动。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 明确四踩地板、2/4 clap、反拍八分高频、kick 间隙切分 bass 与短反拍和弦的角色互动（人声按主唱叙事或短循环 hook 择一，纯器乐写核心钩子音色）。MIDI 起点按 4/4 每小节 4 QN：kick 落 `+0,+1,+2,+3`，clap 落 `+1,+3`，反拍高频落 `+0.5,+1.5,+2.5,+3.5`；bass 与短和弦只挑选定拍间位且短和弦 gate 可从 0.25 QN 起步，保持低频互锁留白。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否能一听就和冷峻极简的 Techno 及重度 build-drop 的商业舞曲区分开——立刻感受到四踩之上的反拍弹跳、kick 间隙切分低音与温暖短和弦对话？

将舞池拍轴、kick/bass 互锁、反拍和弦 voicing、核心钩子及段落叠层抽空轨迹回传主文蓝图。
