# 中国风：单线主力传神、调式风骨保真与现代脉冲有机咬合

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **地域曲种优先，无来源诚实标现代融合**：若用户指定具体地域、曲种、曲牌或乐器流派，严格沿其真实音级中心、落音与演奏语汇构建；未提供具体传统来源时，将方案明确标为**五声性现代流行融合编配**，绝不冒称某地正宗传统，也不强套固定五声或现代四和弦套路（缺省现代人声融合起稿常见 4/4、约 76–92 BPM，如 84 BPM）。
2. **严拒民乐大杂烩——聚焦 1 件主力传统乐器担纲核心声音母体**：除非用户明确要求民乐合奏，否则**一次只立一件主力传统乐器承担前景主题角色**，围绕它做跨段发散——**前奏素颜孤声呈示主题核 → 主歌退居完整乐句后的句缝短回应（绝不在主唱词头与重音处并行抢戏）→ 器乐间奏完整发展呈示 → 末副歌用音区上移、尾音复述或克制对位长线拉出高潮**。绝不同时把古筝滚奏、笛子独奏、二胡长线和戏曲锣鼓一锅乱炖！
   - 需连贯歌唱长线与滑音叹息 → 选**二胡**等弓弦单旋律（标注连弓、换把与句尾滑音）；
   - 需清脆颗粒动机、短促句缝应答或紧绷张力 → 选**琵琶**或**古筝**（单音拨弦、轮指/摇指化点成线、扫弦或分解）；
   - 需带真实气息分句的空灵点染 → 选**竹笛 / 箫**（留足换气休止，装饰落句首句尾）。
3. **调式中心优先于西方导音和声**：传统旋律或五声调式与现代流行和弦三音打架时，**绝不硬用强导音 V–I 强行拗直传统句尾**——优先改用**省略三音（open 5th）、挂留和弦（sus2/sus4）、共同音或持续低音踏板**，守住东方留白与调式风骨。
4. **现代节奏组与传统线条错位呼吸**：电声底鼓、低音或流行鼓组稳住现代身体脉冲与低频地基，传统乐器保持自带呼吸感的线条与句缝对话（绝不让民乐呆板跟着每个 kick 敲齐奏，也不默认乱加锣鼓）。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：保住真实手工乐器的物理肌理（指尖拨过尼龙/钢弦的清晰颗粒、琴码共鸣、马尾擦弦的细微松香感、竹管气息风声），与紧实干净的现代低频及宽广留白空间形成古今冷暖对照，绝不堆廉价塑料民乐合奏音色。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 明确单件主力传统乐器的具体奏法与位置分工（前奏呈示、主歌句缝短答、间奏主题）、现代节奏与低频的清晰承托及温暖通透的中频人声净空（不用 Hz 数字），绝不罗列三四件传统乐器一起抢戏。写具体琵琶动机时核准标准定弦 **`A2–D3–E3–A3`**（空弦 D 为 **D3** 而非 D4），给出明确节奏拍点，并确保动机音列真正体现所宣称的五声骨相（如 D 羽 `D–F–G–A–C`），不让西洋小调半音下行（如 `F–E–D`）喧宾夺主。
- **传统奏法 MIDI / 谱面专属规范**：单旋律弓弦/吹管不写多音和弦；拨弦不可靠把单个拨音拉成不可能的长音——目标音源无原生琵琶长轮/古筝摇指映射时，在 1 QN 窗内用 8 个间隔 `1/8 QN` 的同音独立 note（强弱交替）作为**重复音代理**并明确标示代理（GM 原声吉他不冒称真实琵琶）；弓弦滑音单独写 pitch-bend 曲线、明标弯音范围并在句尾回中，不与同通道其他持音共享弯音。MusicXML 读谱可用 `unmeasured tremolo`，播放版将 `divisions` 设为每 QN 至少 8 并逐音写实。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否立刻能听出单件传统乐器极具呼吸与笔触的东方韵味、保住调式风骨而不土气的和声留白，以及与现代低频脉冲严丝合缝的对话，毫无塑料民乐大杂烩味？

将地域/现代融合定性、主力传统乐器选角与奏法、主题母体首现/句缝回应/间奏布局、调式与和声兼容策略及现代节奏协作回传主文蓝图。
