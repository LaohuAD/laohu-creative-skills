# Hard Rock：强辨识吉他 Riff 统领、全队齐咬重击与高张力保锋

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **吉他 Riff 是整首歌的绝对骨架**：先将核心 riff 写实为可演奏的清晰音程、节奏、闷音/延音、重音与休止边界（无锁定时常见 4/4 直八分驱动，缺省起稿可用约 105–120 BPM，如 112 BPM），全曲围绕主 riff 的陈述、截取、换重音与回归组织；只在该转情绪时才引入副 riff。
2. **贝司加倍低音核 ＋ 底鼓咬合主起音**：贝司默认紧贴并加倍 riff 的低音根音/核心节奏赋予厚重下潜（riff 低频极密时改稳重根音长音防糊）；底鼓精准咬合 riff 的关键重音起音形成拳拳到肉的集体冲击（不必每个吉他音都双击），军鼓牢守强劲 2/4 拍骨脊。**Riff 休止处必须显式决策**：全队齐停制造窒息张力，还是鼓组维持脉冲托住推进。
3. **早核人声与 Riff 轮替交接**：尽早把主唱句法节奏与 riff 放进同一草图（呼应 Metallica 预制作经验），让鼓手与吉他清楚何处收力给主唱让出中频、何处空拍由 riff 强势接管回应；双吉他明确齐奏、八度、和声或主副交替分工，绝不只为显响盲目叠双份同轨。
4. **高张力保锋红线**：硬摇滚的灵魂在于过载/失真吉他的中频攻击力、饱满鼓击瞬态与现场乐队扑面而来的压迫感——**清晰分层绝不等于把锋芒磨圆**，主歌收紧能量是为了让副歌与主 riff 砸下来时更猛更有劲。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：紧实有颗粒冲击力的过载音箱吉他、沉厚贴合低频的拨片/指弹贝司、大动态实感军鼓与真实乐队房间感，吉他低频、贝司基频与底鼓瞬态各占其位。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 写清吉他 riff 节奏/音程身份、贝司低音加倍、底鼓齐咬起音、riff 休止处齐停或续拍的选择、双吉他分工及与主唱的句缝交接（纯器乐以 riff 回归替代人声位置）。编排 MIDI/谱面时，power chord 五度按实际同时音符写出（不用和弦名替代），闷音/重音/断奏写入 articulation 或真实音箱奏法映射（GM program 不代表失真吉他音色）。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否立刻能听出一条让人跟着甩头的核心吉他 riff 统领贝司低音加倍与底鼓重击、休止收放凌厉且主唱中频充满锋芒？

将 riff 身份特征、低音/底鼓同位与错位、休止处理、主唱交接、双吉他分工与演奏把位边界回传主文蓝图。
