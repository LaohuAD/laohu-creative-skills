本子级仅在用户明确委托 screen-theme、影视/游戏主题曲、角色主题或片头/片尾主题编曲时由 [主 Skill](../../SKILL.md) 加载；只做场内剧情配乐归 `underscore`。暂无完整片头画面时先创作独立可听的完整主题方案，只暂停依赖具体镜头时码的剪辑对齐。

# Screen Theme：作品身份核、可变形基因与标题落点

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **先钉死主题指向与高辨识核心基因（绝不拿史诗电影感充当主题）**：先将作品命题、世界观或角色关系转译为一个**哪怕剥离宏大配器也三秒能认出的核心识别核**——可以是极具个性的短音程轮廓、标志性节奏脉冲（如 Nicholas Britell 为《Andor》立住的 pulse motif）、独特和声进行，或鲜明音色组合。大管弦与合唱不是必选项，稀疏极简的独特音色往往比宏大罐头更具传奇辨识度。
2. **为长周期演化预埋 1–2 条可变形叙事轴**：一套顶级影视主题必须经得起从开场、危机、崩塌到终局的反复变形仍一眼认出：
   - **保留轴**：核心节奏型、关键音程轮廓或特征音色至少锁死一项；
   - **变化轴（每次动 1–2 轴）**：调式/和声明暗（揭示人物与命运转向）、音区与编制跨度（亲密独白 ↔ 宏阔全景）、碎片截取与节奏重心（适配短片头/预告或角色压迫感）。两名角色共享主题时必须写清共享体现的关系，区分则至少改一项强识别要素而非仅换乐器。
3. **适配不同时长载体与标题落点**：
   - **独立完整版**（缺省器乐起稿可参考约 60–90 秒结构：核呈示 → 发展 A → 对比变轴 B → 核心归来升华 → 余韵收尾；有词主题歌按完整歌曲结构让 hook 同时承载词与曲）；
   - **短片头/标题序列**：按目标秒数压缩前奏直亮识别核，把核心高潮与休止收束精准对齐片名弹出帧；有锁定画面时核准版本、fps 与片名时码，无画面只控完整音乐时长与收尾，绝不编造帧点。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：高记忆度的标志性前景音色材质与清晰的声场纵深反差，确保主题核在首次素颜出场、高潮全景重现与片尾残片回响三种尺度下都立得住。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 写实主题指向、核心识别核的具体节奏/音程/音色特征、首次呈示位置、回归时改变的单一或双叙事轴及目标时长收尾（纯器乐写入 `Motif / Front Identity` 与 `Instrumental Form`，绝不附空人声栏）。编排 MIDI/谱面时，将每次主题变形的具体移调音程、截短或时值变化写入对应 `section_id`，锁画同步的标题 cue 点单列绝对时间/tempo map 映射。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉剧名与说明，光听或看这份主题核——它是不是自带不可替代的世界观气象，并且能清楚看出未来怎么变暗、变壮、剪短成片头或融进场内配乐？

将主题所指、核心识别核、呈示与回归变形路线、主唱/器乐分工、目标时长与同步需求回传主文蓝图。
