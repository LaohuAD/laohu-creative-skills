# Reggae：第 1 拍留空、第 3 拍落锚、歌唱低音与反拍 Skank

## 一、非对称核心骨相（相对通用底座的风格偏移）

1. **One Drop 核心重力场（无更细分支默认）**：4/4（常见 70–85 BPM，缺省起稿可用 76 BPM）下，**第 1 拍低频刻意留空**，将底鼓与鼓边/军鼓（rim/snare）主重击连同 bass 锚点一起**落在第 3 拍**，制造极具呼吸感的空—落—回弹身体律动。若用户明确指定 **Rockers** 或 **Steppers**（或参考曲鼓型不同），切换对应鼓型并**必须同步重排 bass 落点**，绝不孤立多加底鼓破坏整体 pocket。
2. **旋律化呼吸 Bass（半前景叙事声部）**：低音绝不是机械拍拍跟根音的铺底，而是带着大段休止、长短音对比与经过音连接的可歌唱旋律线条，紧扣歌词力度承担情绪支撑；绝不用持续 sub 铺满全部拍位。
3. **干脆拍间反拍 Skank**：吉他或风琴/键盘择一主责，在拍间反拍（`&` 位）弹出极短干净的和弦切音（skank），音区避开 bass 与人声；可选风琴/键盘 bubble 在另一音区做极轻内部细分填充，绝不抢主 skank。
4. **节制留白与 Dub 空间回送**：主歌极简留出大片空气感，副歌靠和声伴唱、第二短回应或开放高频微抬能量；dub 式 delay throw 或滤波回声只投放在真实句尾空拍，确保回声尾音绝不遮挡下一主唱词头或第 3 拍低音落点。

## 二、声音质感与风格专属编译要点

- **物理听感方向**：温暖厚实而松弛通透的低频、脆短带木质/弹簧混响质感的反拍吉他切音、宽广克制的空间留白，不把唱法刻板绑定为特定口音或强制拟声口号。
- **AI 生成与符号/MIDI 专属注意**：Style Prompt 写清 One Drop（或指定的 Rockers/Steppers）鼓与低音第 3 拍重心及第 1 拍低频留空、反拍短 skank 与句尾 dub 延迟留白；toast 仅在明确要求时启用。MIDI 按 4/4 每小节 4 QN：One Drop 主击与 bass 核心锚定 `bar_qn+2`（第 3 拍），skank 落在选定的 `+0.5/+1.5/+2.5/+3.5`（短门长约 0.20 QN 起步），bass 跨线延音用 tie、句尾留白写实休止。

## 三、脱标盲辨与返回主文

**脱标自检**：遮掉风格名，是否第一拍就感受到低频悬空、第 3 拍鼓与旋律化 bass 一起稳稳落锚、吉他干脆切在拍间的纯正雷鬼呼吸感？

将 One Drop 或指定变体鼓型、bass 呼吸线条、skank 拍位/音长、人声空位、段落密度与 dub 回送位置回传主文蓝图。
