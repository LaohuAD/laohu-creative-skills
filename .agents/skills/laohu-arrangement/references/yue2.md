# YuE2 外部 ABC 编译

由 [主文](../SKILL.md) 在用户明确指定 YuE2 外部 ABC 三输入接口（或给出对应可核实 schema）时按需读取。本文件负责把已定或获准修订的音乐决定编译为可分别复制的 `Style Prompt`、原文 `Lyrics` 与 bounded native `ABC`；不替代常规嵌入式人声包、一般 ABC 2.1 / MusicXML / MIDI 交付，也不指导本地模型推理或调用音频转谱。

---

## 一、三输入分工与硬边界

严格按 `Style Prompt` → 原文 `Lyrics` → bounded native `ABC` 交付，三者必须忠实对应**同一份声音蓝图**：

1. **`Style Prompt`**（默认英语）：用自然可听的声音指令交代作品身份、风格、速度拍号、歌者音色与唱法、配器与制作空间、整曲能量弧，以及必要的段落差异与关键完整乐句动作（用少数原语种承重词锚点定位）。**禁止把拍内精确起止写成伪硬命令**——精确音高、起音、时值与休止归 ABC，Style Prompt 只负责 ABC 无法承载的配器、音色、空间与演唱表演方向，且绝不与受保护 ABC 矛盾。
2. **`Lyrics`**：仅放经 [词曲交接与回填](composition.md#词曲交接与回填) 核对后的本轮演唱稿原文（歌名元数据置外），**严禁嵌入 `[Section ｜ ...]` / `[(...)]` 控制标签、严禁添加 ABC `w:` 行、严禁翻译、严禁按一字一音强拆或改写歌词**。
3. **`ABC`**：从共同音乐事件底稿投影出**两条单音声部**——主唱主旋律进 `Vocal`，一条有实际旋律职责的器乐主题或独奏进 `Ins`（`Ins` 不是多音和弦堆叠，也不把鼓件写成假旋律字母）；鼓、贝司、完整和弦排列与空间制作由蓝图和 Style Prompt 承担。

---

## 二、来源状态与 `full` / `melody` 模式选择

先核来源状态（**用户锁定**原样保事件、**作者暂定**获准改进先回谱曲、**忠实转换**照可信谱源投影不润色，任何投影均不覆盖原件；需要精确翻唱但缺少可靠全曲谱源时先获取谱源，不凭记忆编造也不调 SheetSage2 自动转谱），再按保留需求定模式（**不把翻唱一刀切判成 `melody`**）：

| 本轮需保留内容 | 模式 | 编译硬要求 |
|---|---|---|
| 主唱/器乐旋律 ＋ 本轮明确要保留的和声进行 | `full` | 两条单音旋律按保护范围保留；需进入符号谱的和弦用白名单引号和弦名标在 `Vocal` 行实际起点（本地 profile 不强制至少含一个和弦，但声称保留锁定和声时须确认已编码）。 |
| 主唱/器乐旋律，伴奏和声留给模型自由发挥 | `melody` | **音乐行绝不可含任何和弦符号**；完整保留两条旋律的音高、起音、时值、休止、小节网格与段落边界（删和弦绝不动音符或静默删去 `Ins`）。 |

## 三、Bounded Native 双声部 ABC 规范

本项目的本地校验器执行比通用 ABC 2.1 更窄的 bounded profile，确保事件可确定解析：

```abc
X:1
T:
M:4/4
L:1/32
Q:1/4=96
V: Vocal clef=treble name="Vocal Melody" snm="Vocal"
V: Ins clef=treble name="Ins Melody" snm="Inst."
K:C
```

1. **固定头部与交替分组**：
   - `T:` 留空；声部固定为 `Vocal` 与 `Ins`，不得换名或加第三声部；
   - 正文每组按 `V: Vocal` → 谱面行 → `V: Ins` → 谱面行交替，每行含 1–4 个完整小节；仅在进入新段落或需要结构边界时写 `% verse`、`% chorus` 等注释；
   - 两声部小节数、拍号/调号变化时点、拍格与总时长必须完全同步（变拍开新双声部组同步 `M:`，变调可在新组同步 `K:` 或小节内同位置用 `[K:...]`）。
2. **字段与合法记号白名单**：
   - `M:` 显式分数拍号（分子正整数、分母 ≤1024 的 2 的幂）；`Q:` 固定 `Q:1/4=<正整数 BPM>`；`L:` 固定 `1/<2 的幂>`（分母 ≤1024，调整 `L:` 须同比缩放全部音长）；
   - `K:` 仅支持 15 个大调（`Cb, Gb, Db, Ab, Eb, Bb, F, C, G, D, A, E, B, F#, C#`）与 15 个小调（`Abm` 至 `A#m`）；
   - 单音/休止时长乘数仅允许 `{1, 2, 3, 4, 6, 8, 12, 16, 24, 32, 48}`，更长时值用相邻同音 tie `-` 或相邻休止拆分，不可近似；
   - 音高大写 `C–B` 为 C4–B4、小写 `c–b` 为 C5–B5，逗号降八度、撇号升八度（落 MIDI 0–127）；升降记号 `^ / _ / = / ^^ / __` 在同小节按字母跨八度延续，过小节线或变调重置；tie 仅连同音高、不可连休止、谱尾不可留未闭合 tie；全小节休止 `Z` 至 `Z4` 不得跨和声或调号变化事件。
3. **引号和弦白名单（仅放 `Vocal` 音乐行和弦起点，休止拍亦可标）**：
   - 根音与可选 `/斜线低音` 为 `A–G` 加可选 `b / # / bb / ##`；
   - 质量后缀仅允许：`""`（大三）、`m`、`dim`、`aug`、`7`、`maj7`、`m7`、`dim7`、`m7b5`、`sus4`、`sus2`、`6`、`m6`、`7sus4`、`m(maj7)`；
   - 持音中换和弦须在换位处拆分并以同音 tie 连接。若用户锁定的复杂和弦（如 `maj9`、`13`、`alt`）超出白名单，绝不静默降级或假称 Style Prompt 可精确保留——暂停该符号交付，说明表达损失并请用户选择通用谱/MIDI 或授权有损简化。
4. **受限语法拒收边界**：本 bounded profile 不接收 `w:` 歌词、自定义 voice/directive、同轨多音堆叠 `[...]`、装饰音、slur、tuplet、反复记号、附点简写（broken rhythm）与双小节线。仅当可精确展开为等价单音事件且不失真时才展开；若三连音或复调属锁定信息且无法无损落格，明确报告损失并请用户改用通用 ABC 2.1 / MusicXML / MIDI 或授权有损投影，绝不静默删记号。

## 四、ComfyUI 接线、名义时长核对与本地校验命令

1. **ComfyUI `YuE2GenerateMusic` 节点核对**（仅适用于已核验公开 ComfyUI 节点/模板，不外推为其他云平台 API）：
   - 确认外部非空 ABC 字符串直接接入节点的 `abc` 输入，以及 `mode` 准确设为 `full` 或 `melody`；若模板中的 `ABC_planning` 辅助开关关闭后送出空字符串，节点会自动把模式降为 `off`（内部 `cot` 参数不是云端用户字段）；
   - 核算 ABC 纸面名义时长：**总四分音符数 ÷ BPM × 60**（例如 68 个 4/4 小节在 96 BPM 约 170 秒），确认 `max_duration` 至少覆盖目标长度（但该参数仅是上限，长输入仍可能受模型上下文截断，不保证完整生成）。
2. **本地离线校验命令**：
   ```sh
   # 检查 bounded profile、模式、时长上限与独立 Lyrics 逐字保真
   python3 "{SKILL_DIR}/scripts/check_yue2_abc.py" inspect <ABC文件> \
     [--mode full|melody] [--max-duration <秒>] \
     [--lyrics <本轮演唱稿> --package-lyrics <投喂Lyrics文件>] [--output <JSON>]

   # 核对锁定投影前后两声部旋律事件完全不变
   python3 "{SKILL_DIR}/scripts/check_yue2_abc.py" compare <投影前ABC> <投影后ABC> \
     [--voices Vocal|Ins|both] [--allow-tempo-change] [--output <JSON>]

   # 另存去和弦 melody 版（不覆盖源文件，保留双声部旋律）
   python3 "{SKILL_DIR}/scripts/check_yue2_abc.py" strip-chords <源ABC> <目标ABC>
   ```
3. **证据边界**：脚本通过只证明本地 bounded profile 语法、事件网格、模式与歌词比对成立，不证明云端接通、审美和声、音频完整性或模型真实遵从；拿到实际生成音频并实听后，才报告声音结果与偏差归因（区分空接线 / 模式 / 时长上限 / 谱面投影 / 模型生成偏差）。
