# 旋律、曲式与和声

由 [主文](../SKILL.md) 在需要谱曲、发展动机、处理词乐对齐、设计或修订和声，以及发生跨入口词曲交接或回填时按需读取。输入为创作目标、锁定材料、可确认的旋律/和弦/节拍与歌手条件；听不清或未提供的事实标为未知，不靠猜测补齐。读后将音乐决定与待试唱项回传主文蓝图。

---

## 一、三类音乐来源状态与创作起手

动手前先辨清材料身份，将原件保留与音乐是否锁定严格分开：

| 来源状态 | 处理边界 |
|---|---|
| **用户锁定** | 按锁定范围原样保护音高、时值、歌词或段落；技术修正绝不暗中改写核心旋律与表达。 |
| **作者暂定** | 保留原文件，仅在本轮获准改进时返回谱曲步骤修订音符或结构；文件存在不等于已定稿。 |
| **忠实转换** | 以可信谱源或指定录音为准，只做精确投影与格式转换，不顺手润色或添音；导唱音准不稳时标明不确定小节。 |

只有歌词且授权新作旋律时，交付实际候选音高与拍内时值（或清晰可还原的谱稿），不以情绪形容词充当作曲；若任务是交由 AI 模型探索，明确锁定关键节奏、轮廓、重音落点与回返关系，具体音符标为开放变量。

## 词曲交接与回填

当歌词进入谱曲、演唱生成，或谱曲发现歌词容量、重音、气口与旋律冲突时，统一按本协议交接（`laohu-lyrics` 同步复用本节）：

1. **三层材料身份（不要求硬拆三份文件）**：
   - **原始词稿**：改动前用于核对差异的对照源；
   - **本轮演唱稿**：经授权核对、实际用于本轮谱曲与生成包基线的歌词版本；
   - **词曲对应关系**：记录音乐 `sections` 与完整语义演唱乐句的对应，仅在会改变下游编配或编译时加标可选 `phrase_id`、`lyric_anchor`，不强制逐字造表。
2. **继承与隔离**：完整继承上游已确立的歌者立场、对象、声口、核心意象与段落职务，明确区分锁定文本与开放音乐结构；歌名元数据、纯唱词与交接说明各自独立（遇旧包前置 `Song Title:` 仅在确认其为标题元数据行时分离到块外，不按词面删正文）。歌词段落标签不自动等同完整曲式，视觉换行不等于乐句或小节；允许一乐句跨多行或多小节、多音承接一字、段间回返复用及无词器乐段。
3. **冲突授权分支**：
   - 歌词锁定、旋律开放 → 优先调旋律音高、节奏、时值、气口或伴奏留白，不改词；
   - 旋律锁定、已有明确改词授权 → 将具体小节/拍位、音节容量、重拍/高音冲突与必保关键词交作词侧出最小候选；
   - 两侧均开放且在既有授权内 → 守住原表达意图做最小协同回填，不对已获授权的同一范围反复追问。
4. **回填差异核对**：回填后必须对照原始词稿逐项复核——改标签核正文、调序核对应词段、回返核复用文本、改词核增删替换；保留原稿，确立已核对的本轮演唱稿为唯一基线，再同步更新所有受影响蓝图与输出，绝不借更新基线追认越权改词。

## 三、有词作品的词乐对齐：先听活人说话，再落音符

依据 **Pat Pattison 的 Prosody（词意与音乐要素协同）** 与 **Dennis DeSantis 的 Scansion（词韵轻重对齐）**：

1. **先朗读辨语言动作**：按自然语速出声读出完整语义乐句，辨明此刻是在低声试探、克制陈述、追问、对抗、执念复沓还是释然收束；标出句法边界、核心承重词、否定词、可延展元音与真实换气点（不把视觉换行当自动换气）。
2. **顺应或有意反衬**：将自然词组轻重与停连对照节拍强弱、音高轮廓、长短音与休止——顺应让情绪直接落地，有意反衬须说清反差带来的额外心理含义，且实际唱出仍清晰可懂。
3. **中文声调与防倒字专核**：普通话字调、自然语句重音与旋律音高分开判断——不要求旋律机械死贴每个字的调值，但对重拍、长音、高音与快唱处的**核心承重词**必须排查倒字歧义（例如阴平/阳平滑入低谷或上声硬顶最高音导致词义错听）。歌手真实音域未知时，先落可移调的中声区草案，不虚构极限高音；未经真实试唱的纸面旋律一律标为待试唱。

## 四、动机发展、曲式推进与句法边界

1. **一核贯穿与单维变形（Arnold Schoenberg 动机保留核法）**：
   - 先从全曲抽出唯一或极少数值得听众记住的核心材料（一段主唱钩子、短音程/节奏动机、riff 或核心音色运动），标清**必保识别核**与首现/回返位置；
   - 需发展时一次先动单一维度并核认辨度：**原样重复**（稳住记忆锚点，变化交给伴奏或段落位置）、**移调 / 调性模进**（换音区或在新和弦上承担新功能）、**增值 / 减值**（拉长宽阔或压缩紧迫，重核拍内重音）、**片段化**（抽识别核短片做延续、呼应或过门）、**扩展**（保留核头、延伸后段至新落点）；
   - 探索多候选时可借 **DeSantis 逐代单变量变体（Mutation Over Generations）**：基于上一版每次只改一个有效音乐变量比较职务，不限代数，也不强迫稳定循环型作品强行变形。
2. **乐句呼吸与古典句法边界（William E. Caplin 形式功能论）**：
   - 先按完整演唱乐句与呼吸落点决定小节数，不把 4/8 小节当死配额；长短不对称乐句、二句问答或连绵长句皆可成立。
   - **古典功能型主题**可借 Caplin 的 **Sentence**（基本乐思 + 重复 → 片段化/加速延续 → 终止）与 **Period**（前句弱收悬置 → 后句回返并强收闭合）校验结构推进；但绝不把古典 2+2+4 强套进流行循环、说唱或电子舞曲。
3. **乐段衔接职责**：
   - 有预副歌时，写清它靠何种张力（和声悬置、音区爬坡、密度拧紧或停顿抽空）把听众推向副歌，以及副歌是痛快兑现、转折换色还是安静落定；
   - 有桥段时，它承担视角切换、情绪停留、换气反差或蓄力转向任一真实职务即可，让末副歌回返带出新分量，不强要求剧情大反转，也绝不把桥段变成每首歌的必填项。

## 五、和声语法：先辨语境，再定稳定与张力

选和声先听低音线条、旋律结构音（强拍、长音、动机重音与句尾落点）和段落职务，**绝不把古典 V–I 强套一切风格**：

| 和声语境 | 核心法则与操作要点 |
|---|---|
| **功能调性** | 以主（稳）、下属（离）、属（推）服务段落到达；明确需要闭合才用强 V–I 正格终止，未说完用半终止（停在 V）、转向用欺骗终止、温柔收束可用变格终止。 |
| **调式中心 / 东方五声 / 静态循环** | 守住中心音、持续低音（踏板）或少数特色色彩和弦，靠旋律、律动、配器与音色驱动进程；和弦三音与调式特征音打架时，优先试省三音、挂留或持续低音，绝不硬造导音 V–I 冲淡风骨。 |
| **非功能 vamp / 律动循环** | 1–2 个和弦或单低音循环即可立住全曲，和声稳定反而放大律动与人声张力，不为显复杂乱加换和弦密度。 |

**声部进行与色彩边界**：
- 先定低音根音/转位目标（让低音自带歌唱线条），再安置上声部——内声部优先保共同音、小步级进连接；经过音、邻音、挂留音等非和弦音查清准备与解决，爵士延伸音与有意摩擦不按古典禁忌一概抹平。
- 借用和弦、副属和弦或转调必须服务于具体的情绪转折或高亮强调，写清进入枢纽与回返确认点（只停留一拍立刻回原中心称局部染色，不夸成完整转调）。若和弦越复杂主旋律或中心感越糊，果断减慢和声节奏、回到清晰根基。
