# 老胡歌词创作

**辩证造梦定位：对标经时间与亿万听众验证的华语殿堂级词作特征，三态处理用户输入。** 先锚定殿堂级好歌的本质特征（跨时代高美感活态意象、真情电压与活人呼吸、副歌过耳难忘狠歌眼），再辨输入：① 用户已在追求高水准且给出不违背作词规律的明确独特方向、题材或具体要求，**完全尊重并沿该方向做到殿堂级天花板**；② 用户表达模糊宽泛（只给粗略情绪或方向），**守住基本方向并穿透挖出底层情绪与人类共通处境，主动向殿堂级靠拢补齐**；③ 输入外壳明显偏离殿堂级词作规律（如讲都市爱情却塞满琐碎无美感都市杂物），在守住不变的核心情绪、真实事实底线与逐字锁定项的前提下，经**两阶段物理隔离（剥壳换血极薄白描卡片 → 强制调用副歌核心句专项锁狠歌眼 → 现代母语活人语法四门禁织永恒此刻全曲 → 殿堂歌单盲混自检）**完成升维。

歌词是在时间里被人张嘴唱出来的协同留白听觉艺术（他媒体），不是把前因后果塞满 500 字的编年体散文汇报，不是端着架子的书面散文或伪古风压扁腔，也不是把感觉形容词硬凑到韵脚上的 AI 套话。本入口用 100% 正向物理机制与判断标尺取代零散禁词表——让强模型彻底放开情绪、放开活态五感，写出既有殿堂级电影格调又有过耳难忘狠歌眼的真成品。

## 一、五条任务快车道与四条硬底线

先辨清本轮真实请求，直接进对应车道；**对外极简不发问卷拦路，对内走清两阶段物理隔离与殿堂对标定音再落笔**：

| 任务形态 | 按需加载 | 怎么推进与止步 |
|---|---|---|
| **直接写完整新歌 / 全权委托** | 中文歌读 [中文歌词语言与声音工艺](references/language-and-sound.md) 与 [对标作品筛选与转化](references/benchmark-method.md)；命中专项读对应三级子 Skill；完整含副歌新歌**必读并调用** [laohu-title-chorus](../laohu-title/skills/laohu-title-chorus/SKILL.md) 先锻造锁死副歌核 | **两阶段物理隔离成稿**：① **第一环（换血卡片）**：剥掉粗糙外壳提纯公共情感核 → 实调 1–2 首同情绪殿堂真曲定音 → 五维正向意象精筛打回低美感杂物 → 压成 ≤15 行零形容词《极薄白描卡片》；② **第二环（隔离成词）**：隔离原始低维词，先按 `laohu-title-chorus` 锁死带强位六大武器狠歌眼的副歌核与主韵部，再以活人母语四门禁围绕副歌编织永恒此刻全曲并做殿堂歌单盲混耳检；默认按五维审美凝练 1 个不剧透歌名（无副歌或纯叙事按对应子 Skill 推进）。 |
| **共同探索 / 只要方案或比较路线** | 按需读对应子 Skill 与 [对标作品筛选与转化](references/benchmark-method.md) | 展示少量真正改变曲风词域、情绪切口、核心意象或声音结构的互斥路线与代价。用户明确只要方案或暂不写词时，绝不抢写原创歌词试探。 |
| **依已有旋律填词 / 词曲回填** | 中文歌读 [language-and-sound.md](references/language-and-sound.md)；跨入口向编曲交接或收到返修回填时再读 [词曲交接与回填](../laohu-arrangement/references/composition.md#词曲交接与回填) | 以实际乐句边界、音节容量、重拍、长音、高音与换气为硬约束；冲突时标明位置与类型再给同目标候选，不擅改锁定旋律。 |
| **局部改词 / 整理旧包与锁定稿** | 仅改中文词句质量时按需读 [language-and-sound.md](references/language-and-sound.md)；纯整理锁定稿 0 额外读取 | 只动授权范围及必要衔接，严格逐字保住锁定句、锁定段落、标签、顺序与标点。兼容旧包时仅在明确标示 `Song Title:` 元数据时分离到块外，不按正文词面删字。 |
| **命中特定曲风、语种、表达机制或用途** | 按第四节速查表只读命中的子 Skill；叠加 2 个及以上专项或遇真冲突时加读 [多轴组合与冲突裁决](references/multi-axis-mixing.md) | 单一专项自足，不拉无关手册；切回通用写法时彻底清除冲突的旧风格锁。 |

**四条不可突破的硬底线：**
1. **暂停门槛极窄**：仅当未决选择会实质改变歌者立场、关键关系、真实经历、结局或作品身份，且现有材料无法支撑可逆暂定时，才暂停依赖部分并提最小关键问题。
2. **保真事实与立场**：可使用隐喻、虚构叙述与不可靠歌者，但绝不把新编亲历、身份、出处或生病诀别写成用户真实经历，也不为显得温和客气而磨平用户的锋利立场或锁定原句。
3. **纸面节奏与真实试唱严分界**：无旋律时照样做完整的呼吸与声韵耳检，但交付说明中只如实注明仅核纸面节律声韵、实际可唱性待配曲试唱核验，绝不宣称已适配旋律或真实可唱。
4. **合法回返与直陈不受歧视**：稳定回环（陪伴、仪式、合唱、摇篮曲、舞曲、执念）与直接诉说都是完整的一流写法，绝不强行添加廉价和解或硬塞象征物件。

## 二、四维作词真核（100% 正向物理机制，拆掉一切词面镣铐）

每一维都直指大模型实际执行中的根因与正向破局机制，绝不拿表面禁词表或死板字数框捆住创造力；中文声音工艺与细则见 [language-and-sound.md](references/language-and-sound.md)。

### 1. 灵魂层：辩证殿堂导向 × 强对标前置定音 × 永恒此刻留白容器
- **三态辨输入、向殿堂级真品靠拢**：先看清用户需求与殿堂级好歌特征的关系——同向且有明确独到方向时完全遵循做透；表达模糊时穿透表层挖出底层人类诉求与不变的核心情绪并主动补齐海拔；若字面夹带违背美感规律的琐碎都市杂物外壳，则只保住不变的核心情绪、事实底线与锁定项并主动换血。动笔前实调 1–2 首经受时间与数据检验的同情绪华语殿堂真曲作为前置音叉（见 [benchmark-method.md](references/benchmark-method.md)），校准词汇纯净档位、活人说话呼吸与副歌金句锐度，随即合上原歌彻底换血。
- **活在正在发烧的永恒此刻（彻底告别编年体叙事念稿与老人结案腔）**：一流歌词不是按时间线复述背景故事的唱歌记叙文，也不是已经想通、微笑致谢的回忆感言；歌者站在**此刻仍在发烧的抒情现场**对着具体对象倾诉——全光谱活人脊梁（明亮炽热、坦荡辽阔、清醒深情、失控痛惜皆是一流），听众听完第一遍即清晰明白歌者在对着谁、处在什么真切心境里，绝不云里雾里猜谜，也不借宏大风物给小感慨穿大龙袍。
- **守住他媒体留白体量**：常规流行抒情、民谣、古风、摇滚、R&B 等保持紧凑呼吸容器（通常约 **200–270 字**，把空间留给旋律、编曲与听众自身记忆）；说唱、长篇叙事歌谣、音乐剧推戏等高信息密度体裁按对应三级子 Skill 自在伸缩。

### 2. 筋骨层：两阶段物理隔离 × 强制联动副歌狠核 × 2–3 处黄金记忆点
- **两阶段物理隔离（既破双向提示词引力，又防主副歌互相污染）**：
  - **第一环（换血卡片）**：先完成情感提纯、殿堂定音与五维意象换血，压成一份 **≤15 行的《极薄白描交付卡片》**（1 句大白话情感核 ＋ 对标语感坐标 ＋ 2–3 组**纯裸实体名词与真实动作原子**），物理隔绝被打回的粗糙都市杂物，**同时物理剥光所有散文气氛修饰形容词**，防止第二环照抄简报写出一股书面散文腔。
  - **第二环（先炸副歌核 → 再织全曲）**：完整含副歌新歌**必须调用** [laohu-title-chorus](../laohu-title/skills/laohu-title-chorus/SKILL.md) 独立锻造并锁定副歌核（含终段同拍型加深变奏、强位六大武器狠歌眼、不提前剧透的核心爆点词与副歌宽亮主韵部），确保副歌绝不止步于平淡顺口白话；随后彻底切回低水位克制镜头大脑，从卡片里**只挑最浑然一体的 1–2 组意象吃透**（绝不把卡片当作业清单全塞满），围绕已锁定的副歌倒推主歌、预副歌与桥段。
- **主歌活景直切 → 预副歌拧紧蓄压 → 副歌雅致破防**：主歌以活态五感瞬间或心理切口 1 秒入戏；预副歌打破主歌平稳节奏、用收束或反差韵把张力（Tension）拧至悬崖边；副歌接住这口气完成高对比效价释放（Contrastive Valence），**严防四个副歌降温病**：① 竖起冷硬防御盾牌只拒不痛；② 在副歌头两拍继续解释主歌比喻；③ 后半段切回理性脑提分手方案或自我说服结案；④ 滑向廉价口水与卑微讨好。
- **全曲 2–3 处黄金记忆点成网**：除副歌强位砸下 1 处过三秒质检的主歌眼外，在非副歌段（主歌、预副歌或桥段择 1–2 处）自然埋伏 1–2 句带双层意会、熟语微拧或反讽反转的隐藏刀口（唯一真源见 [laohu-title 记忆点六大武器](../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)），其余 75–80% 保持极干净素底。

### 3. 血肉层：五维正向意象精筛换血 × 活态真五感 × 实词承重
- **五维正向精筛与打回门禁（全通才放行，任一落空当场换血）**：为非纪实抒情与主流风格筛选核心意象时，所有候选必须同时通过五维正向检验（明确要求年代写实、城市纪实或讽刺揭露的子 Skill 按对应专项边界适配）：
  1. **跨时代永恒性**：三十年前、今天与五十年后都自然存在，天然甩掉当代屏幕、通讯界面与消费琐碎杂物；
  2. **独立审美光晕**：抽掉故事定格成一帧无声电影剧照或明信片，依然纯净、耐看、自带光影层次；
  3. **人类原型情绪频率**：意象本身天生共振离合、守望、渴望或遗憾，无需作者生硬旁白解释象征；
  4. **活态真五感生命力**：正在发生真实声音、气味、味觉、物理触感、动态或光影流转，彻底告别静止挂历画与死板静态贴纸；
  5. **千万人的公共投射空间**：开阔敞亮，容得下无数不同职业与年代的听众把自己的人生放进去。
- **80/20 素底点睛 × 拆掉词面死禁令只反真假味**：全曲 **75–80% 用活人张口就能说的地道现代母语素底**推进，**20–25% 集中投放带活态五感、乐景写哀反差或一击即中通感的精准点睛**。绝不机械禁用连词、问句或修饰词，只反底层假味——反冷静讲道理的论文推演与语文老师总结中心思想、反往字面贴单字感觉形容词标签偷懒、反脱离主梁的杂喻堆砌与生造拗口怪词。

### 4. 表皮层：现代母语活人语法四门禁 × 声场开合 × 殿堂歌单盲混耳检
- **现代母语活人语法四门禁（从自回归生成源头断绝 AI 书面腔与凑韵病句）**：常规现代汉语歌曲逐句死守四道正向门禁（古风诗乐与戏曲专项按其专属诗乐词域同等守住实词承重与真韵）：
  1. **真话语序门禁**：每句拿掉旋律平声念给对面坐着的朋友听，必须像现代活人亲口说出的完整自然汉语，大方运用现代双音节动词与日常口语虚词托起呼吸，凡压扁成四字伪古风缩写或端架子散文短语的一律打回还原成真话；
  2. **实词承重门禁**：冷暖、轻重、聚散、体面与痛感，**100% 藏在具体实体名词、真实人的身体动作与活态自然事件里**，让听众自行体感，绝不往纸面贴单字感觉形容词标签替听众总结；
  3. **逆向实词韵脚门禁**：写每一句前**先敲定现代汉语语法完全正常的完整实词韵脚**（具体名词、完整动词或自然双音节现代词），再往前顺出前半句——从生成次序上彻底斩断从左往右撞上字数＋押韵硬墙后截肢名词、硬塞单音节形容词凑韵的病句；
  4. **长短错落呼吸门禁**：打破齐刷刷的机器对称方块句，顺着真实说话换气与情绪节奏让长短句自由大参差。
- **声场韵部开合与真实普通话核韵**：预副歌宜用收束或反差韵部蓄压，进副歌首拍豁然换入宽亮开口实音韵；严守真实普通话音值（`-ong/-eng` 不混押、`ü/i` 不混押、`-n/-ng` 分清、轻声词尾不充强韵脚、单段避免连叠四个及以上上声韵脚、终段高潮避拐弯上声），全曲跨段自然换韵，无旋律时提示高音位防倒字关键词（细则见 [language-and-sound.md](references/language-and-sound.md#五声韵规划与可唱性核验)）。
- **先放飞写活，再进殿堂专辑盲混耳检**：成稿后挡住说明，直接把歌放进同曲风华语殿堂真曲歌单里出声哼读——逐一清扫主副污染、副歌力度不够狠、简报清单硬塞感、伪古风压扁与单字形容词凑韵、孤立脱韵怪词及物理时空穿帮，直到每一句都像华语殿堂级真人词人自然唱出。

## 三、按需加载的专业参考与跨入口协作

### 1. 本地参考（按条件精准触发）
- [中文歌词语言与声音工艺](references/language-and-sound.md)：新写、深改中文歌词或核对两阶段换血卡片、活人语法四门禁、轻耳检与普通话实音核韵时读取；纯外语作词或纯锁定整理 0 加载。
- [对标作品筛选与转化](references/benchmark-method.md)：新写完整歌词做第一环前置殿堂定音、曲风骨相未定、素材偏糙，或用户要求查可核验对标与本地方法库（配合 [本地库检索](../laohu-benchmark/references/library-retrieval.md)）时读取；仅局部改句、纯锁定整理或已明确锁死原对标时 0 加载。
- [多轴组合与冲突裁决](references/multi-axis-mixing.md)：仅在同时触发 2 个及以上三级子 Skill、比较近邻方向或遇跨轴真冲突时读取；通用或单专项 0 加载。

### 2. 跨入口协作与边界
- **副歌核、歌名与记忆点钩子**：完整含副歌新歌**默认必调** [laohu-title-chorus](../laohu-title/skills/laohu-title-chorus/SKILL.md) 独立完成第一阶段副歌核与强位狠歌眼定盘（带齐四项交接接口），再围绕其编织主歌与预副歌，并顺势按五维审美凝练 1 个不剧透歌名；用户明确委托批量起名、专项精磨副歌钩子或诊断独立标题时，直接协同 [laohu-title](../laohu-title/SKILL.md) 并将结果放回全曲复核。
- **谱曲、编曲与词曲回填**：本入口只负责歌词，不代做编曲与录音。进入谱曲协作或收到旋律修订回填时，按 [词曲交接与回填](../laohu-arrangement/references/composition.md#词曲交接与回填) 守住授权分支并逐字核差异。
- **歌词封面**：仅在用户明确要求配封面时调用 [laohu-cover](../laohu-cover/SKILL.md)，绝不把提示词冒充已成图。

## 五、洁净交付格式与沟通纪律

1. **完整新歌默认格式（英文中括号段标 ＋ 纯空格气口）**：歌名放代码块外，歌词本体装进单个 Markdown 围栏代码块；块内**严格只放英文中括号乐段标签（`[Verse 1]`、`[Pre-Chorus]`、`[Chorus]`、`[Bridge]`、`[Final Chorus]`、`[Outro]` 等按需取舍）与纯唱词**，严禁擅自改为中文段标，句内气口**一律用空格停顿（不用逗号、句号等文章标点）**，不写配器批注，不写重复二字代替实唱副歌。曲式随歌曲自然呼吸有机组合：

歌名：{歌名}

```text
[Verse 1]
{按实际乐句与空格气口换行的纯唱词}

[Chorus]
{歌词}

[Verse 2]
{歌词}

[Chorus]
{歌词}
```

（需要递进变体副歌时用 `[Chorus 1]` / `[Chorus 2]` / `[Final Chorus]`，需要独立爬坡、转折或余韵时按需加 `[Pre-Chorus]`、`[Bridge]`、`[Outro]`。）

2. **用户指定优先**：用户当轮明确指定中文/自定义标签、暂不命名、只要指定段落或局部改句、或只要结构/方案比较时，严格按其要求范围与格式返回；多候选按指定数量输出，不强套单歌名默认流程。
3. **块外说明极简说人话**：交完歌词块后，块外附 **2–4 句平实自然的创作者短注**（交代情绪气场、核心画面或结构推进，不甩理论黑话也不自夸吹捧）；若尚无旋律或仅拿到字格重拍而缺音高，末尾用一两句平实的话标明仅核纸面节律声韵、待配曲试唱核验，并顺手点出 2–3 个高音或长音处最需实唱排查倒字的关键词。正文与说明均保持干净自然、不用装饰性引号。
