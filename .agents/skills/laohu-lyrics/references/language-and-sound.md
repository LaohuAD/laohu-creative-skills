# 中文歌词语言与声音工艺

本手册在创作、深改或诊断中文歌词时按需读取，落实 [laohu-lyrics 主文](../SKILL.md) 的四维真核。核心原则：**第一环极薄白描卡片物理换血破双向引力、第二环强制先调副歌核专项锁狠歌眼、全曲死守现代母语活人语法四门禁与 80/20 素底点睛、用韵部开合与进棚真韵底盘通过殿堂歌单盲混耳检。**

---

## 一、两阶段物理隔离、三段接力与记忆点布局（筋骨实操）

### 1. 两阶段物理隔离创作法（既断提示词引力，又防主副歌双向污染）
写完整含副歌新歌时，绝不把粗糙原始输入直接带进作词大脑，也绝不在同一次顺写里一边维持主歌克制、一边强行拉副歌爆发，严格按两环物理隔开：

1. **第一环（换血卡片：剥壳提纯 → 殿堂定音 → 五维精筛 → ≤15 行极薄白描卡片）**：
   - 先用 1–2 句最直白的现代大白话提纯跨年代**公共情感核**，实调 1–2 首同情绪华语殿堂真曲定音（见 [benchmark-method.md](benchmark-method.md)）；
   - 将原始输入里的低维都市道具、俗套杂物或静态挂历词按**五维正向门禁**当场打回换血，在后台压成一份 **≤15 行的《极薄白描交付卡片》**：只留大白话情感核 ＋ 对标活人语感坐标 ＋ 2–3 组**纯裸实体名词与真实自然／身体动作原子**；
   - **双向防污染铁律**：卡片内**绝不出现被打回的粗糙原始词，也物理剥光所有散文气氛修饰形容词**，只当备选弹药库——下游只挑最浑然一体的 1–2 组意象吃透，绝不逐条硬塞清单。
2. **第二环（隔离成词：强制调用副歌专项先炸狠核 → 活人语法织永恒此刻全曲）**：
   - **步 2A（高潮爆破大脑）**：**必按** [laohu-title-chorus](../../laohu-title/skills/laohu-title-chorus/SKILL.md) 独立锻造并锁死 2–4 句副歌核（含终段同拍型加深变奏），确保同时汇合**情绪决堤呼告 ＋ 清晰对象称谓 ＋ 强位六大武器狠歌眼 ＋ 逆向宽亮实词韵脚**，同步锁定两项下游接口——**不提前剧透的核心爆点词**、**副歌宽亮主韵部**。
   - **步 2B（克制镜头大脑）**：锁死副歌核一字不软化，彻底切回低水位克制镜头大脑，围绕副歌倒推编织主歌一、预副歌、主歌二与桥段。

### 2. 主歌活景直切 → 预副歌拧紧 → 副歌雅致破防（三段接力与排雷）
- **主歌三种纯抒情永恒此刻切入法（反编年体流水账，反静态风景播报）**：
  - **活态五感瞬间 1 秒直切**：跳过前因后果与年份倒叙，直接落进正在发生的声音、风动、气温变化、气味、光影流动或微距身体动作里；
  - **心理症状直接连击**：零事件汇报，直接抛出人人都经历过的真实心理与生理发作瞬间；
  - **乐景写哀 / 高饱和切片跳剪**：以明媚盛大的当下自然光景反衬心底未熄的遗憾，或把最滚烫的记忆切片直接并置。
- **预副歌（Pre-Chorus）拧紧蓄压**：用紧促断句、昔今冷暖反差或悬而未决的呼告把压力（Tension）拧到临界点，并**避开副歌大开口主韵部**（优先收束韵或反差韵），两段预副歌递进不照抄。
- **副歌（Chorus）接住压力完成雅致破防（严防四大降温病）**：
  1. 严禁竖起冷硬防御盾牌只拒不痛（把预副歌刚攥紧的气泄光）；
  2. 严禁在副歌头两拍继续解释主歌比喻（把比喻留给主歌，副歌轻装直抒胸臆）；
  3. 严禁后半段切回理性脑提分手方案或自我说服结案；
  4. 严禁止步于平淡顺口白话（漏掉强位六大武器狠歌眼）或滑向廉价口水与卑微讨好。
  选法上按题材真气组合**极力靠近 ↔ 偏偏阻断**、**祝福与心碎正面碰撞**、**先推至极热再摔落的坠落反差**、**同构排比叠爆**、**今昔镜像翻转**或**带悔意的执念假设**。

### 3. 全曲 2–3 处黄金记忆点分布（六大武器见 `laohu-title` 唯一真源）
单纯把话说顺、说满只会听完即忘；按 [记忆点六大武器与三秒质检](../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源) 在全曲布局 **2–3 处彼此呼应的记忆锚点**：
- **副歌 1 处主歌眼**：情绪高潮与双层余味（表里双轨、熟语微拧、同词异义、前扬后劈、冷刀反讽、跨界撞击或空槽公理）二合一，听一遍就能脱口跟唱；
- **非副歌段 1–2 处隐藏意会刀口**：在预副歌、主歌二或桥段克制推进中突然亮出一句表面清白体面、里层意会炸裂或语境翻转的金句，全曲 75–80% 保持素净留白，绝不句句抖机灵。

### 4. 整栋房咬合、时空严密与体量呼吸
- 全曲围绕同一根清澈情感主梁与同一流动时空盖成一栋连贯的房，绝不两行换一套毫不相干的杂喻；原样复唱副歌不剧透后文，镜头空间与物理常识真实连贯，尾声有机取舍不强行做作文闭环。
- 常规中文抒情、民谣、古风、摇滚等保持约 **200–270 字**的呼吸留白容器，把空间让给旋律、编曲与听众自身记忆（说唱、长篇叙事歌谣与舞台推戏不受此限）。

## 二、五维正向选象、活态五感与真假味判断（血肉实操）

### 1. 五维正向精筛与活态真五感（彻底清零低维杂物与静态贴纸）
- **五维全通选象关**：为常规流行抒情与诗意曲风建构意象时，候选须同时通过**① 跨时代永恒性、② 独立审美光晕、③ 人类原型情绪频率、④ 活态真五感生命力、⑤ 千万人的公共投射空间**，任一不达标当场打回换血（纪实民谣、现实讽刺或明确锁定的年代题材按对应子 Skill 边界保留必要时代锚点）。
- **让五感活在实体动作里**：视觉之外，积极调动**真实声响、气味、味觉、皮肤触感、身体细微动作与光影动态**——绝不把风景写成静止挂历画，也绝不造无生命假触感或脱离物理常识的空词。
- **75–80% 地道母语素底 × 20–25% 精准点睛**：每个动宾搭配都须是活人汉语里自然顺嘴的表达，坚决清扫零度生活账本、流水线网感套路道具、生造拗口怪动词与脱离主梁的杂喻乱拟人。

### 2. 拆掉词面死禁令：真假味道对照表
判断一句词好不好，永远看它背后的**情绪真味与生成机制**，绝不靠死板禁词表打地鼠：

| 曾被误杀的手法/词类 | 真正该砍的假味 | 大胆放开用的真味 |
|---|---|---|
| **`如果 / 假如 / 倘若`** | 冷静权衡利弊、像写论文或辩论的理性推演腔 | 带着悔意、执念或心碎冲动的滚烫假设与祈愿 |
| **`原来 / 才明白 / 才发现`** | 画面演完后画蛇添足、当语文老师替听众总结中心思想 | 作为全曲情绪与认知最高峰的撕裂式顿悟或残酷翻转 |
| **直面 `你 / 我` 发问对峙** | 琐碎算旧账、毫无美感的泼妇吵架腔 | 爱到痛处或激动处的当面质问、拉扯与赤裸呼告 |
| **修饰与感官词** | 往字面贴单字感觉标签词替听众总结、自回归句尾截肢名词塞单字形容词凑韵、连刷空洞体感谓语 | 靠具体实体名词、真实人的动作与自然事件自带体感，必要时在刀口用极高浓度反差或精准通感点睛 |
| **拟人与超常规动词** | 脱离主梁、批量让抽象名词像人一样干活的炫技堆砌 | 紧扣主情、一击即中的 1–2 处鲜活动作或通感 |

## 三、现代母语活人语法四门禁、声场开合与殿堂盲混耳检（表皮实操）

1. **现代母语活人语法四门禁（逐句把关，零 AI 散文与伪古风压缩腔）**：
   - **真话语序**：去掉旋律平声念给对面朋友听，必须像现代活人亲口说出的完整自然汉语，善用现代双音节动词与日常口语虚词托起说话火候，绝不把完整话压扁成伪古风四字缩写或端架子书面短语；
   - **实词承重**：冷暖、轻重、聚散、体面与痛感全部藏进具体实景名词、真实人的身体动作与平实事实里，绝不拿单字或抽象感觉形容词往字面上贴标签；
   - **逆向实词韵脚**：写每一句前先敲定现代汉语语法完全站得住脚的完整实词韵脚（具体名词、完整动词或双音节现代词），再往前自然顺出前半句，从源头杜绝从左往右写到行尾撞墙截肢名词塞单字形容词的畸形句法；
   - **长短错落呼吸**：打破齐刷刷的 `6+6 / 7+7 / 5+5` 机器方阵，顺着真实演唱换气让长短句自由大参差，并留意避免单段连撞三句同构句式顺拐。
2. **情绪放开唱与韵部开合张力**：喜则滚烫敞亮，痛则锋利清醒，豪则坦荡舒展，守住**向内审美干净耐品、向外零防御直击人心**的双向之雅；预副歌与副歌优先拉出**窄/收束韵 → 宽大开口实音韵**的听觉绽放。
3. **英文中括号段标与纯空格气口**：歌词正文默认一律使用 `[Verse 1]`、`[Pre-Chorus]`、`[Chorus]`、`[Bridge]`、`[Final Chorus]`、`[Outro]` 英文中括号段标，句内用单个空格作歌唱换气停顿，不用逗号句号等文章标点。
4. **放飞成稿 → 殿堂专辑盲混轻耳检**：
   - 成稿后挡住说明，直接把歌放进同曲风华语殿堂经典歌单里出声唱读四关：① **查高潮与主副隔离**——副歌是不是明显高过预副歌，首尾强位有没有 1 记过三秒质检的狠歌眼，有没有防御盾牌、比喻说明、理性结案或主歌口水污染？② **查活人语法与实词承重**——有没有一句像在翻译简报、像四字伪古风缩写、或拿单字感觉形容词贴标签凑韵？③ **查五维意象与体量**——有没有漏进粗糙都市杂物、静态挂历套话、编年体回忆念稿或意象硬塞清单感？④ **查声韵与物理**——做孤立脱韵拷问、扫净混韵/轻声韵/高潮上声拐弯与镜头空间穿帮。

## 五、声韵规划与可唱性核验

本节全部作为**成稿后的轻度耳检与逆向落韵工具**（仅在依已有旋律或固定字格填词时前置作硬约束）：

1. **逆向实词落韵、韵部自由、孤立脱韵拷问与真实普通话核韵**：
   - **逆向先定完整实词韵脚**：构句时先锁定意思顺畅、现代汉语语法完全正常的完整实词韵脚再往前顺句；韵部完全自由，绝不机械扎堆死压单一韵部，`ou / ai / ei / e / o / i / a / ao / an / ang / ong` 皆可出神品，唯以贴合气质、实音清晰为先。高音长音位避轻声词尾、弱方位词尾、高音易拐弯的上声，以及爆破高音位的偏扁 `ian`（`[iɛn]` 适低吟而不冒充最宽爆破韵）。
   - **孤立脱韵拷问（零凑韵病句铁律）**：把每一处押韵词句抽离韵脚单独出声念——**如果它脱离押韵就显得别扭、词类截肢、非自然汉语、语域违和或物理失真，立刻整句打回换词甚至换整段韵部，绝不为凑纸面合韵牺牲一句真话！**
   - **严格按普通话实际音值核韵**：`-ong` 与 `-eng` 绝不混押（如 `东/钟` 不可混 `风/灯`）；圆唇 `ü`（如 `去/雨/居`）与展唇 `i`（如 `避/底/里`）绝不混押；`z/c/s` 后 `[ɿ]`、`zh/ch/sh/r` 后 `[ʅ]`、`j/q/x` 后 `[i]` 互不通押；轻声词尾（如 `事情/地方/客气/麻烦` 的轻声尾）绝不充强韵脚；同一乐段避免连续堆叠四个及以上上声韵脚（易致音高倒字与唱感憋闷）；严韵分清 `-n` 与 `-ng`（绝不让 `-ing` 撞 `-en`）。四句单元呼应韵式预期，全曲跨段自然换韵，轻叹处允许留白不押。
2. **同段零重字与咬字排雷**：
   - 除刻意复沓叠句外，同一乐段韵脚换用不同汉字且避同音撞车；短句排查平翘舌连撞或连挤四五个扁口高元音 `i/ü`；语气词 `啊/呀/吧/呢` 仅承担真实呼告或摇曳唱腔时保留。
3. **已有旋律、固定字格与显著位防倒字**：
   - 依曲填词时每个停顿槽放母语自然完整词组，绝不跨停顿拆词或硬砍虚词；冲突优先调词序或换词，不擅改锁定旋律。
   - 重拍、长音、高音与快唱处关键词预查倒字歧义；无旋律时在块外短注如实注明仅核纸面节律声韵，并顺手标出拿到音高后需实唱排查的 2–3 个关键词。
4. **词曲交接与回填**：交给作曲编曲时将纯净唱词与极简说明分开；收到旋律返修回填时按 [词曲交接与回填](../../laohu-arrangement/references/composition.md#词曲交接与回填) 守住授权边界并连读完整句群复核。
