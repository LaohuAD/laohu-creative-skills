# Blues：用复现拉满等待，用变句翻转处境

## 1. 按选定形式排句，不把 AAB 变成唯一律法
- **采用 AAB 传统时**（参考《Good Morning Blues》的复现蓄力与第三行推进）：
  - **A1**：直接亮出谁撞上了什么具体处境，动作与对象清清楚楚；
  - **A2**：原样复现拉满执念与等待张力，或只换一个改变责任与处境的关键词；
  - **B**：必须给出因果、反击、反讽、后果或更扎心的物证，彻底改写前两行的听法，绝不只是把 A 换同义词说一遍。
- **采用现代 Blues / Soul-blues / Blues-rock 时**：保留所需曲式，重点借用回句加压、留白回应（call-and-response）与接地气的直白声口；十二小节行长只在已有伴奏或明确指定时匹配。

## 2. 先定 B 行翻转核、留白与蓝调记忆点侧重
- **以 B 行为核心爆点倒推蓄压**：AAB 结构里，B 行天然就是先定盘的核心翻转爆点；A1 立具体处境，A2 靠原样复现、重音移位或替换唯一关键词拉满等待张力，B 行一刀翻转处境。
- **Blues 专属记忆点侧重**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，优先主打 **A2 原词微拧 ＋ B 行冷幽默反讽、现实反转与一针见血的市井双关**；把最狠的实词与韵脚压在语义重拍上，给乐句尾端留足器乐或伴唱回应的空隙。

## 3. 回主文与自检
核验每一组 AAB 的 B 行是否真改变了前两行的意思；若非 AAB，核验蓝调回句与回应机制是否真正落在歌词句群里。
