# 抒情咏唱：让注意力、词句与内在时间互相牵引

## 1. 四种注意力运动，按需组合
先定贯穿全曲的抒情焦点与内在时间，再为各段选择动作，绝不强求每段新增事件或结尾必然释怀：
- **凝视**：反复看向同一物件或画面，靠远近距离、细微状态变化或原样停留写深心境。
- **回忆**：由当下某个细小声音、触感或词句唤起旧时，自由切回此刻，不写成按年份排队的回忆录。
- **直陈与咏叹**：用承认、呼告、追问、拒绝或未决叹息直抵情绪核心，句尾延宕与回声本身即可撑起重量。
- **矛盾意识**：把两种无法互相抵消的感受正面并置，靠转折词、句长落差与复沓演出真实拉扯。

## 2. 一物深写、内在留白与咏唱记忆点侧重
- **先锁核心咏叹母题，再展开活态五感与极高留白的内在时间**：纯诗性独白不强套流行抒情的高音副歌公式，但仍须先定死贯穿全曲的核心凝视母题或矛盾咏叹回句，意象同样过五维精筛并靠真实声、光、触、动与现代活人实词承重（零静止挂历词与单字感觉形容词硬凑韵），再决定是一物深写还是多象共照（参考 Joni Mitchell《Both Sides, Now》以云、爱与生命三个对象共照同一次认知运动，句架呼应而回句语境加深），绝不靠歌词外宣布象征。
- **抒情咏唱专属记忆点侧重（全曲 2–3 处）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，优先主打 **陌生化通感意象撞击 ＋ 矛盾意识并置 ＋ 复沓回环中的意义微移**，保持极简呼吸感，拒绝喧哗玩梗。

## 3. 回主文与自检
裸读正文检查：听众能否顺着歌者的目光与呼吸进入这股心绪？多对象之间有没有真实的感情或声音牵连？重复句有没有在回返中撑住情意，而不是空洞复读心理结论？
