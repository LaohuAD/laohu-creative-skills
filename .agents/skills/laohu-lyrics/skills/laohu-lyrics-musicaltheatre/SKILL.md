# 音乐剧歌曲：让角色在舞台当下用唱词改写关系

## 1. 先锁定舞台现场与五大唱段分支
开写前先钉死：这场戏在台上的具体职责、谁在场、唱前与唱后戏势怎么接。按职责选定主分支，绝不把所有舞台唱段都硬拧成行动谈判：
- **行动歌（说服 / 交易 / 对抗）**：明确角色此刻想让谁做什么、阻力在哪；每节换一套策略、筹码或谈判句法（称谓、祈使、条件、反问、让步），对手的反应或沉默推动下一段换招，唱毕须在决定、关系、信息或代价上发生真实位移。
- **人物显影 / 自我揭示**：通过面具与真心的裂缝、习惯、矛盾欲望或联想让观众看穿人物内心（参考 Sondheim《Company》中《Being Alive》从泛指代价清单 someone to... you 翻转为第一人称主动请求 somebody... me，靠人称与动词改写完成认领）。
- **群体场景 / 仪式**：锁定现场共同规矩与各方利害，给不同声部配不同称谓、名词与句长，用领唱、叠答与错位发言让舞台权力分布听得见。
- **快嘴（Patter）**：仅在角色靠语速、规程或卖弄知识压制对方/掩饰心虚时选用；清单按尺度递进，末项暴露致命缺口，音节密度须保证演员在台上吐字清晰。
- **回归唱段（Reprise）**：仅在人物、对象或处境生变时重现旧歌——只精准改动主语、动词、时态或关键判词，让观众听见旧词里的新命运。

## 2. 潜台词与舞台声口
词句永远属于此时此刻站在台上的这个角色，不让角色替作者宣读全剧主题总结；压住不能直说的真实意图时，用称呼、回避、借题发挥与停顿在正文中留足可推断线索。

## 3. 回主文与自检
把唱词放回舞台当下念一遍：是活生生的人物在演戏，还是场外旁白在交代梗概？每段策略或声部站位是否清晰可排演？
