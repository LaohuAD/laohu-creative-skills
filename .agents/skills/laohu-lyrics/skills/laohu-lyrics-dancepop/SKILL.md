# Dance-pop：把重复分配给人声、听众与 drop

## 先确认 hook 承载者

听用户参考曲或既定结构，判断 hook 主要由哪一方承担：

- **人声 hook**：核心命题/标题短句贯穿副歌；重复可增强集体跟唱或逐次改变对象，但每次变化必须有语义任务。
- **Drop / 器乐 hook**：副歌前写清身体期待、邀请或悬置；drop 可少词、无词或只留回应音节，别用解释歌词填满本应由节奏承接的区域。
- **人声 + drop 叠合**：首轮先让两种 hook 分开辨认，末轮才合并或加层；歌词重复与制作重复是两个不同变量，先听参考曲确认谁在承担高潮。
- 参考曲没有明确 drop，或它与副歌合并时，直接按其旋律分段；不把“dance-pop”强制排成 Build—Drop 模板。

## 写作步骤与纸面卡

把副歌/舞段画成“进入句 → 期待句 → drop/回应 → 回归句”，逐格填写：本格需新增的信息、可重复短语、歌者/听众谁发声、编曲留白在哪里。人声短钩子通常优先保留动词、称呼或一条完整判断；若删除背景后只剩“嗨、燃、跳”，补回歌者与对象的关系动作，不靠流行词增添参与感。

Osborn 对 David Guetta 与 Anne-Marie《Don't Leave Me Alone》的曲式分析区分了带人声标题 hook 的 riser-chorus 与随后以采样/节奏为中心的 drop；末段把人声钩子与 drop 材料叠合。可迁移的是首轮分工、末轮合并的组织方案，不是规定每首 Dance-pop 都要同样的段数或 drop 次数。

## 回父级

交付 hook 承载者、段落卡、重复在哪次产生变化，以及给 beat/听众留出的空位。验收：听者能区分 chorus、riser 和 drop 的文字职责；若同一句复现，说明它是参与、期待还是叠层；正文没有侵占器乐本该承担的空间。无音轨只能声明文字分工假设。
