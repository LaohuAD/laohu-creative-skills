# Dance-pop：把重复分配给人声、听众与 drop
## 完整 Dance-pop 歌词的段落起点
整曲组织取决于实际舞曲段落、听者参与方式和可用旋律/制作条件，不沿用固定歌词行位。明确记忆点由人声 hook、节奏/音色 drop、两者交替或其他声音关系承载；回句是否变化取决于本作表达，不为舞池参与强塞统一副歌或 post 句。指定 drop、旋律或短视频窗口优先；只有声音位置确需无新歌词的器乐延伸时再交由编曲处理。

## 先确认 hook 承载者

听用户参考曲或既定结构，判断 hook 主要由哪一方承担：

- **人声 hook**：核心命题/标题短句贯穿副歌；重复可增强集体跟唱或逐次改变对象，但每次变化必须有语义任务。
- **Drop / 器乐 hook**：副歌前写清身体期待、邀请或悬置；drop 可少词、无词或只留回应音节，别用解释歌词填满本应由节奏承接的区域。
- **人声 + drop 叠合**：首轮先让两种 hook 分开辨认，末轮才合并或加层；歌词重复与制作重复是两个不同变量，先听参考曲确认谁在承担高潮。
- 参考曲没有明确 drop，或它与副歌合并时，直接按其旋律分段；不把“dance-pop”强制排成 Build—Drop 模板。

## 写作步骤与纸面卡

先按实际曲式与 hook 承载方式判断是否需要段落卡。只有作品确有相应的人声进入、期待、drop/回应或回归关系时，才记录这些位置各自承担的信息、声音、参与和留白；若副歌连续承载、没有独立 drop，或记忆点由其他声音关系形成，就按实际结构说明 hook 如何出现、重复、变化或留白，不逐格套四段链。人声短钩子优先保留动词、称呼或一条完整判断；若删除背景后只剩“嗨、燃、跳”，补回歌者与对象的关系动作，不靠流行词增添参与感。

Osborn 对 David Guetta 与 Anne-Marie《Don't Leave Me Alone》的曲式分析区分了带人声标题 hook 的 riser-chorus 与随后以采样/节奏为中心的 drop；末段把人声钩子与 drop 材料叠合。可迁移的是首轮分工、末轮合并的组织方案，不是规定每首 Dance-pop 都要同样的段数或 drop 次数。

## 回父级

交付 hook 承载者、实际曲式中相关段落的关系、重复或变化，以及给 beat/听众留出的空位。存在 chorus、riser 或 drop 时，说明各自的文字职责及其衔接；某段不存在或与另一段合并时，按实际关系描述，不另造段落。若同一句复现，说明它承担参与、期待、叠层或其他实际作用；正文没有侵占器乐本该承担的空间。无音轨只能声明文字分工假设。
