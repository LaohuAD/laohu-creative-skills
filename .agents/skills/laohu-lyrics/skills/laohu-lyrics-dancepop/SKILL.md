# Dance-pop：把记忆点分配给人声、身体律动与 drop 留白

## 1. 先定 hook 承载分工，不硬套 Build—Drop
- **人声 hook 主导**：用极短、带清晰动词或称呼的完整短句贯穿副歌，方便跟唱与身体共振；重复本身就是集体参与动力，不必每遍硬换词，只有改对象或升级邀请时才变句。
- **Drop / 器乐 hook 主导**：前段（主歌与升势段）把期待、邀请或情绪悬置铺满，到了 drop 果断少词、无词或只留节奏型短呼应，绝不用解释性长句侵占节奏空间。
- **人声与 drop 先分后合**：首轮先让人声标题 hook 与器乐 drop 各自立稳辨识度，末轮再叠合爆发（参考 David Guetta & Anne-Marie《Don't Leave Me Alone》在 riser-chorus 与 drop 先分工、末轮合流的组织法）。

## 2. 两阶段锁极简 Hook、记忆点侧重与拒绝空口号
- **先锁 3–7 字洗脑 Hook 与 drop 留白，再倒推升势段**：先独立锻造并锁死极短、开口响亮、带清晰关系动作的人声标题 Hook 并划清 drop 留白区，再围绕它写主歌与升势段（Build-up）把期待和邀请拧到顶峰，轰然落进 Hook/Drop；全曲比抒情歌更精简，绝不用密集长句塞满节拍。
- **舞曲专属记忆点侧重（1–2 处超强循环锚）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，舞曲优先主打 **熟语微拧的短促音律回环 ＋ 带具体称呼与身体邀请的良性越界短钩**——删掉节拍后仍立得住说话者与对象之间的真实动作或态度，彻底拿掉泛泛喊嗨空口号。

## 3. 回主文与自检
写清各段哪里归人声唱满、哪里留给 beat 与听众接唱；无真实音轨时只作文字分工与拍感假设，不把器乐 drop 强写成满词副歌。
