# 日语歌词：按实际读音数 mora，保住文节边界与语体

## 1. 先定语体，不套动漫或七五调模板
先锁当代口语、凝练书面/诗性、角色语或指定歌谣/演歌传统，保持助词省略、终结语气与人称稳定，不把七五调、俳句或动漫主题曲句法套给所有日语歌。

## 2. 按真实发音计 mora，保护文节不断裂
- **实音数 mora（不数汉字）**：将关键短语化为假名读音计数——撥音 `ん`、促音 `っ` 与长音各占 1 mora，拗音组合（如 `きゃ`）的小假名并入前一 mora。
- **按文节自然断行**：先切出词干与助词、活用词尾相连的自然文节，绝不为了押韵把助词孤立在行尾或拆碎活用结构。
- **灵活协商容量（非一 mora 一音符）**：有旋律时把自然文节试放进乐句，容量不合时按表达需要调词、调整短语，或有意用 `字余り`（制造赶话或说话式推进）与 `字足らず`（给关键词留出延音与呼吸留白），但绝不截断促音、长音或搅乱词界。

## 3. 音高重音、句尾语气与复沓
- 按目标词汇音高重音与句末语调判断旋律冲突是否真引起误听，不照搬汉语逐字声调规则；不把句尾上扬机械等同疑问。
- 日语不强求每行押韵；更常用稳定的动词/助词句架回返，只换承载新记忆或季节的名词短语推动语境变化（参考永六輔《上を向いて歩こう》用抬头走的固定动作回返串联变化场景，且 `歩こう` 含长音须按读音核容量）。

## 4. 回主文与自检
内部核清假名读音、mora 分布、文节边界与促音/长音位置（默认不把读音表塞进歌词正文，用户要时才另附）；无旋律时标明仅核纸面短语与 mora 容量，待配曲实唱核验。
