本子级由[歌词创作主 Skill](../../SKILL.md)在方向确定后加载。用户明确要求双语歌词、跨语种 hook、按人物/场景切换语言或分析 code-switching 时触发；一个借词、外语歌名、非歌词文字翻译、双语字幕或背景中出现两种语言不触发。用户要求两种语言创作/改写并实际在歌词中切换时触发；若只要整首歌词的逐行对照译本，按翻译任务处理。先读[歌词风格与语言配置](../../references/style-and-language.md#双语切换语言是戏剧动作不是翻译动作)，由父级同时加载本作涉及的具体语种配置；本子级只管语言切换如何改变表达，不代替英语、日语、韩语或粤语子级校验单门语言。

# 先定语言关系，而不是先分配比例

开始写词前填写这四项：

1. **主语言/语法底盘**：哪门语言负责主要句法、信息推进和听众入口？如果不同段落各有主语言，分别标明，不能假装全歌只有一个底盘。
2. **谁切换、对谁切换**：切换是歌者换了身份/亲疏，引用他人声音，转向另一群听众，还是场景变了？
3. **切换落点与功能**：在词内、短语边界、句尾、段落或 hook 切换；它具体增加了何种关系、语气、身份、声音、押韵或参与效果？
4. **听众理解条件**：关键信息是否能被目标听众跟上？若有意让某一群听众暂时听不懂，这种排除必须是用户选择的表达立场。

默认每个句子/段落有可辨的主语言，另一语言只在明确功能处进入；用户要求均衡双语、整段交替或两种语言并列时照其选择设计，不设固定 70/30 或“副语言只能点缀”的规则。区分真正语码切换与已融入主语言的常用借词，也区分“两个语言段落并置”与“同一句内切换”：两者都可成立，但组织方式和听众预期不同。

# 先各自写对，再决定在哪儿接合

先用各语言分别写出完整、自然的意思和句法，再安排切换。切换处可以承接称呼、代词、谓词语气、引用、身份词、韵脚或 hook 声音，但后半句不能只是前半句的逐词翻译。若句内混用，先确定哪门语言提供矩阵语法，再检查插入成分是否符合两边真实说话者的习惯；不要把一种语言的词序、冠词、助词或动词词尾硬套到另一门语言。

韵脚和节拍按实际发音判断，而非看拼写相似。英语重音、日语 mora、韩语终结语尾/连读、粤语韵尾等分别按对应语种方法复核；跨语种押韵只在目标歌者真实读音中成立时保留。视觉上押韵、听起来却断裂的词，不算有效接口。

每次切换至少要改变一项可听见的关系或声音任务。常见的可选机制：

- **身份/归属**：某语言指向家庭、地域、社群或私下身份；进入与退出都应有声口依据。
- **对象/亲疏**：称呼、代词或语尾从公开说话变成私下对话，改变人与人的距离。
- **引用/立场**：另一语言承载他人原话、流行套语或歌者对该套语的反讽，清楚标出声音归属。
- **韵脚/声音**：切换带来该语言独有的重音、元音、韵尾或节奏，并在句意中站得住。
- **共同参与/分众**：副歌让特定听众能跟唱；需要其他听众理解的核心事实仍在可进入的位置。

一段只有“听起来国际化”而说不清切换功能时，删掉或把它改成明确的声口动作。若用户要的是两种语言的对应版本，则保留翻译任务，不把平行译文改造成语码转换。

# 已发表语料怎样改变判断：Texas conjunto 的英语/西语切换

Loureiro-Rodríguez 与 Moyna 对歌手 Nick Villarreal 的 178 首 Texas conjunto 作品研究发现，语料里既有以西班牙语为矩阵语言的切换，也有少量更均衡的交替；《Así es la vida》在西语韵脚处出现受英语发音影响的韵声，《La Happy Hour》则把英语短语和双关/押韵接进西语主句。可迁移的方法是先确定哪种语言承担句法底盘，再问另一种语言在韵脚、幽默、地方身份或引语上做了什么；切换有时改变的是发音和韵脚，不一定改变主句语言。

该研究只分析特定歌手、地区和 conjunto 语料，样本比例不能外推成全球双语歌统计，也不证明双语歌词应以西语为主。它是检查切换功能的真实个案，不是模板。

# 冲突修复、验收与回父级

- 若单一短语的两种语言要求冲突，先保住用户锁定的意义、关系和声口，再调整切换点、句法或韵脚；不能用“混搭风格”掩盖任何一边的语法错误。
- 若目标听众未必懂副语言，决定关键命题是否需由主语言提供入口；信息不对称可以保留，但必须与作品立场一致。
- 若切换只是翻译重复，重写成身份/对象/声音上的新动作，或按用户要求改回双语对应版本。

回交风格卡：每段的主语言/矩阵语法；次语言进入点及功能；语言比例的实际分工（不只写百分比）；听众入口；跨语种韵脚/节拍如何按发音验证；需要各语种母语读者或真实试唱核验的词句。验收看语言切换是否真的改变声口、关系、节奏或听众参与，而不是正文里外语单词的数量。
