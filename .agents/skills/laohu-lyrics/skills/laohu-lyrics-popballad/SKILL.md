# Pop ballad：让情绪由关系证据决定走向

## 选择递进还是守候

- **认识递进**：材料包含新事实、误解消除、承认或选择变化。主歌一立现场，主歌二增加不能回避的证据；副歌只说由这些事实推出的欲望/判断。桥段可改变责任或决定，但不把“情绪更强”冒充新认识。
- **守候 / 悼念 / 承诺**：材料重心是持续而非转折。保持核心副歌句，主歌改变记忆时点、物件、距离或守候成本；不为了显得完整硬写“放下”或“释怀”。
- **Power ballad**：用户明确选择大幅宣泄，且旋律/编曲允许长音与能量累积时才把高点安排在后段；纸面文字只能安排语势、重复和句长，不能证明音区或编曲高潮。

写每段前用三项固定情绪账：这段新增什么可感证据；歌者对关系的动词/判断是否变化；副歌回归后新听法是什么。选择稳定路线时，把“未变化本身”写成具体承担，而非反复声明同一情绪。

## 句法与案例

主歌优先使用关系动作、时间/地点和可观察细节；副歌用最直接的一句命题承载愿望、承认、拒绝或代价。允许抽象情绪词作核心，但前文必须交出它指向的对象。回句可原样回归或因语境变义，不强制末副歌改词。

V4 对王菲《红豆》（林夕作词）的对标拆解记录：主歌把尚未抵达的亲近写成愿望，副歌让歌者知道聚散不可免，却仍选择留恋；它靠两种判断并存而非逐段加重形容词。迁移时先决定歌者面对的是新证据还是稳定矛盾，再将其写成“行动/关系证据 → 命题”，不可套用原作句架和具体意象。

## 回父级

交付递进/守候分支、情绪中心句、主歌证据和副歌回归听法。验收：抽象词有明确关系对象；每段要么改变认识、要么具体承担稳定状态；高点由材料的代价而不是程度词堆高。无旋律不声称音域和可唱性通过。
