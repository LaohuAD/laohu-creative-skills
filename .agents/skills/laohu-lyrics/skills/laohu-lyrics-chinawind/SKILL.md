# 中国风：用移步换景的东方现代通感照亮当代情感

## 1. 当代情感脉搏为底，通体纯澈、移步换景
- **统一纯澈的当代东方词域**：当代中国风的核心是**现代人的思念、孤寂与自然白话句法**，彻底化进东方风物、工艺与节候意境（如《青花瓷》《东风破》全曲不写一件电子产品、也不刻意给当代通讯穿古装戏服，现代听众依然一秒入心）。
- **两头排雷**：① 绝不把古代交通/古偶词（如车马、驿道）与当代通讯/城市语境混焊在一首歌里，也绝不把题干里的泛大抽象词复读三五遍当拐杖；② **绝不把全曲锁死在一间十平米屋子里对着同一两件器物原地拍十张照片**，必须像《青花瓷》一样以轴心器物向外移步换景，打开工坊、节候、巷陌、江岸、光影等多层东方画面。

## 2. 灵魂造血：两阶段锁副歌通感核、记忆点侧重与物理真实
中国风与普通古装流行歌的生死分界，在于**先独立锁死带超常规东方通感活动词的副歌核心画卷，再倒推移步换景的主歌**（如门环惹铜绿、月色被打捞起晕开结局、岁月在墙上剥落看见小时候）：
- **中国风专属记忆点侧重（全曲 2–3 处）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，中国风优先主打 **东方器物/工艺与当代情思的表里双轨双关（如天青色等烟雨双关宿命等爱）＋ 超常规陌生化活动词撞击 ＋ 时空跨度留白**——副歌必落 1 处过耳难忘的东方通感奇句，主歌移步换景间再埋 1–2 处意会双关，绝不堆叠古风名词凑数。
- **器物工艺、活态五感与实词真韵**：用釉色、窑火、纹理、声响、气味与流转对应等待与距离，**严守昼夜、地理与主语物理常识**（绝不为造唯美硬写违背光影规律或主语自相矛盾的穿帮画面），抽掉器物句意须受损才留；借节候与空间改写人的等待与沉默，现代白话句法里同样坚持实词承重与逆向实词落韵，远离单字感觉形容词贴标签，不搬原典成句，也不在桥段拉成散文长句。
- **副歌体量与韵律洄游**：可省略独立预副歌，但副歌须有 **4–6 行灵动长短切分的饱满体量**（绝不只写四行等长拉锯散文句），全曲保持紧凑留白与舒展稳定的韵部洄游，严防句尾声调仄堵砸断流动，多遍副歌有真语境推进或一两字精准翻转。
