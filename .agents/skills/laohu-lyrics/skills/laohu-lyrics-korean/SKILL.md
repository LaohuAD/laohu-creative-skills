本子级由[歌词创作主 Skill](../../SKILL.md)在方向确定后加载。创作主体要求韩语、为韩语旋律填词/改词，或检查韩语词句的语尾、连读和韵律时触发；只提到 K-pop、韩国歌手/影视、歌曲中有一句韩语或非歌词文字翻译时不触发。用户要求把已有歌词译写成可演唱韩语时，按韩语作词/改词触发。先读[歌词风格与语言配置](../../references/style-and-language.md#韩语从真实韩语短语出发按演唱读音核对收音)，并沿用已确认的歌者关系、情绪与用途。

# 先定谁对谁说，以及句子要完成的动作

先用 Hangul 写完整韩语意思，再决定说话者与听者的亲疏、年龄/身份差、公开或私密场合，以及这一句是陈述、反问、请求、命令、承认还是挽留。由关系选择终结语尾、助词、敬语和词汇层级；同一段中的语尾不是装饰，它会改变说话者姿态。默认维持同一关系层级；如果语尾突然从客气转亲密或从陈述转请求，必须由关系/情绪的变化解释。

不以中文或英语逐词替换韩语。逐句核主语/宾语可否省略、助词是否承担对比、谓词语尾是否说清时态与态度。韩语可以省略可恢复的主语或对象；如果去掉助词后听者会误认动作主体、受事或对比对象，就保留它，不能为节拍省掉句法骨架。

# 按完整短语检查边界，再校对 받침 的实际读音

Yu 对韩语流行歌词的研究以 AP（重音短语）与 IP（语调短语）边界，以及音高/时长听辨为研究对象；在本作中把这些当作听辨单位，不当作固定乐句公式。先按韩国语者自然说话切出短语，再决定歌词换行、停顿和换气；标点不能替代真实的语法边界。

拼写里的 받침 不能只按单字查表后直接填旋律。把完整短语连起来读，检查词尾跨到下一音节时发生的连音、鼻音化、流音化、紧音化或中和；尤其标出长音、高音、切分入口和两词交界的风险。真实读音以标准发音资料和目标歌者/母语读者核验。**有 받침 不等于不能上高音或拉长**：若咬字难辨，先改短语、辅音组合或音符时值；旋律未定时只登记风险，不宣布已经难唱。

# 句法压缩与韵脚必须保住韩语关系

副歌可由自然谓词短语、请求或问句回返，不为“短 hook”删掉改变关系/态度的语尾。韩语词尾和助词承载的信息远多于字面长度；压缩后要重新核对谁在做什么、句子是在求问还是断定、说话者与听者的关系是否改变。韩英混写、方言或俚语按用户指定声口处理，不能靠罗马字拼写或英语借词堆出所谓当代感。

韵脚按 Hangul 实际读音检查，兼顾词尾辅音、元音和短语语法；视觉上相似的韩文字形不等于可唱同韵。重复句可以保留同一终结语尾，再只替换事实/对象来积累意义；若每一行都换语尾，先确认这是角色姿态变化，不是为了押韵任意换句型。

# 已发行作品怎样改变判断：BTS《봄날 / Spring Day》

这首歌开段用短句反复表达想念，并把“说出口”本身写成思念加深的原因；随后用照片、时间和相见困难提供关系证据。预副歌把雪与等待组织成问题，副歌再转向等待季节变化、询问何时能见面和请求对方停留。可迁移的不是“春天意象”或固定 K-pop 曲式，而是三种韩语句法任务的分配：陈述/自我复述建立钩子，疑问句把等待变成未决，祈使/请求语尾把关系动作推到前景。写本作时分别选择这些动作需要的谓词与终结形式；不能把同一语尾填满所有段落。

该歌是一个已发行作品的文本观察，不证明所有韩语流行歌都按此推进。Vocal line、Rap line 或体裁标签也不自动决定敬语、亲疏或某种结尾。

# 改稿验收与回父级

- **有旋律**：按完整韩语短语标 AP/IP 边界、重点语尾与呼吸，再连读/试唱实际词组；长音和强拍上的辅音风险以目标发音验证。
- **无旋律**：报告纸面短语节奏与待试唱位置，不把标准发音核验冒充为旋律适配。
- **指定方言、年代/角色语或正式场合**：只按用户确定的范围核查；不把单个 K-pop 案例升格成韩语全体规则。

回交风格卡：目标韩语声口及关系层级；各段的谓词动作/终结形式；重要助词与 AP/IP 断句；받침 连读/音变风险；韵脚方案及实际发音待核点。验收看韩国语者能否按常速理解句子、听出关系和语气，文本是否仍自然；不以“挂了韩语标签”或“收音不多”代替检查。
