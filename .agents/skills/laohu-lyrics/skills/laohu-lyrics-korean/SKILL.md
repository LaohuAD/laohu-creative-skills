# 韩语歌词：用敬语终结语尾演活关系，按语流核对收音

## 1. 直接用自然 Hangul 构思，终结语尾兑现关系动作
- 先定歌者与听者的亲疏、年龄/身份差与公开或私密场合，直接用 Hangul 写出自然句法，绝不从中文或英语逐词直译。
- 敬语、半语与谓词终结语尾直接决定句子是在陈述、追问、请求、承认还是挽留（参考 BTS《봄날 / Spring Day》以短陈述立钩、预副歌转疑问、副歌切请求语尾逐段换挡）。连续段落默认维持同一礼貌层级，突变必须对应真实关系转折；压缩短句时绝不删掉改变关系态度的助词与语尾。

## 2. 按自然短语断行，按整句语流核对 `받침`（收音）
- 按韩语母语者的自然语流切分重音短语（AP）与语调短语（IP）来决定换行与换气。
- **核音变不看单字拼写**：遇到收音 `받침` 时，连读整组短语检查跨音节连音、鼻音化、流音化、紧音化与中和后的实际读唱音；尤其留意高音、长音与两词交界的清晰度。**有收音不等于禁唱或不能拉长**，只在确实咬糊难辨时调词序或换词。
- 韵脚按实际语流读音对齐，不看韩文字形相像；重复句可保持同一终结语尾、只换事实与对象做累积。

## 3. 回主文与自检
常速连读核查：韩语母语者能否立刻听出关系层级、动作态度与自然连音？无旋律时标明纸面短语节律与高风险辅音位置，待配曲和真实演唱核验。
