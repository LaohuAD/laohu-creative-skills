# 喜剧歌：先卡准期待与反转的拍点，再让押韵跟着跑

## 1. 先锁笑点对象与五类主机制（按段聚焦，绝不乱堆）
笑点指向行为选择、逻辑错位或荒谬局面，绝不拿弱势身份当靶子。每段选定一项主机制，走通**铺预期 → 延迟/误导 → 重音落包袱**：
- **误认错位**：听众比角色多知道一条关键信息，每次回返补新证据或新尴尬，别过早揭破。
- **升级清单**：同类项按尺寸、荒唐度或后果层层拔高，最后一项突然翻盘改写整张清单（参考 Gilbert & Sullivan《Major-General's Song》熟练炫耀百科博学，末项却自曝唯独不懂现代打仗）。
- **一本正经**：用极其庄重、专业或仪式的口吻处理鸡毛蒜皮小事，靠语域尺度差制造反差，角色自己必须全程认真。
- **夸口自曝**：角色拼命往脸上贴金，举的例子和细节却自己拆穿短板。
- **反高潮延迟**：先搭起极高预期，停顿半拍后砸在一个极小、极现实的落地结果上。

## 2. 包袱压重拍、记忆点节奏留白与绝不解释
- 喜剧笑点底层遵循良性越界（Benign Violation）与预期违背顿悟（协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源) 的语意反转与熟语微拧）：把最要命的动词或实词钉在断行落点与重拍上；若押韵把包袱拖长或藏进句中，立刻重排句架，绝不画蛇添足解释笑点。
- 全曲聚焦 2–3 个层层升级的大包袱并留足快慢呼吸反差——一路快嘴狂念或每句都用热梗插科打诨，只会抹掉制造笑声的时间差。

## 3. 回主文与自检
大声念一遍：每个包袱第一遍听能不能立刻跟上？笑点前有没有多余形容词剧透？角色声口是不是从头稳到尾？
