本子级由[歌词创作主 Skill](../../SKILL.md)在创作方向已确认后加载。歌词主体要求英文表达、英文填词/改词，或用户明确要求检查英语重音与自然度时触发；英语标题、借词、角色偶尔说英语、非歌词文字翻译或双语切换本身不触发。用户要求把已有歌词译写成可演唱英文时，按英文作词/改词触发。只处理英语词句的语音、句法和旋律接口，不替用户决定全曲立场或曲式。先读[歌词风格与语言配置](../../references/style-and-language.md#英语让语义重音在音乐节拍里说得像英语)，再把判据用于当前句子。

# 先锁目标声口，再标自然重音

先确认目标口音与说话者：美式/英式或其他地域变体、正式/口语、年龄与关系声口。用户没指定时，依据人物和材料选一个一致的当代标准声口；不为押韵混拼口音，不靠拼写拼出并不存在的俚语。遇到重音或发音有地区差异的词，先核实际读音，不把一种口音误判为唯一正确英语。

逐行先按歌者会说的话朗读，再分两层标记：

- **词重音**：多音节词自身的主重音和次重音。它们不能随意挪；落进旋律弱位造成误听时，先换词或改短语，不要求演唱者把词念错。
- **句子焦点**：本句要强调的新信息、否定、对比、称呼或转折。焦点随语境改变，单音节词也可能承受强重音；功能词不能一律禁上强拍，但无表达理由时不让冠词、介词或助动词抢走实词的语义位置。

Palmer 与 Kelly 对英语韵律和歌曲节拍的四项研究，支持检查复合词/句核重音与音乐节拍的相合倾向；这提供的是审查轴，不是“每个重读音节必须落强拍”的机械公式。刻意错位可以用于切分、反驳或突出焦点，前提是句意仍按目标声口清楚可辨。

# 由旋律条件决定如何安排句子

有旋律时，先标乐句边界、强弱拍、长音、弱起和换气，再把自然英语短语放进去。英语行长不按总音节数与中文逐字对齐：先听每行的语义重音和短语重心是否能进入这条旋律，非重读音节再用弱拍、弱起或较短音符承接。只有同一旋律反复承载多段时，才逐行比较重音拍与句法重心；不强套 common meter，也不为了数拍改坏信息顺序。

没有旋律时，先用朗读确定短语重心、重音间距和自然停顿，写成纸面 prosody 假设。可标哪些词适合长音或强拍，但不能声称已经适配具体节拍、通过试唱或可由特定歌者自然演唱。

# 句法、行断与韵脚按同一口气检查

先让完整主谓关系、时态、否定、代词指向和搭配成立，再选句长与韵位。押韵不能逼出古旧的 `thee/o'er`、不合目标声口的缩约、错误时态或诗歌倒装；缩约只有在该人物真的会这么说时才用。词尾落在行末不等于句子结束：跨行 enjambment 可用于延迟信息，但每次断行都要检查听者会不会暂时误认修饰对象、时态或句子焦点。

内韵、尾韵、头韵和重复音型都是选项，不按每行都押或每段同韵处理。若韵脚要求把重点词移到不自然句位，先改韵链、句序或韵位；韵式不能替句子提供本来没有的意义。

# 已发表作品怎样改变判断：The Beatles《Hey Jude》

在《Hey Jude》中，开头以称呼直接对一个人说话，随后连续采用劝告/行动句式；歌名反复回到称呼位置，使 hook 保持“对某人说话”的关系。长尾声则从词义推进转向重复音节的共同参与。这个例子说明，英文 hook 不只有押韵名词或整齐短句一种形态：称呼、动词句法、反复位置和非词汇声响可以分担不同工作。它是对该曲文本与录音结构的观察，不规定英文歌都写成劝告歌，也不授权复制其句子或旋律。

# 分支选择与改稿验收

- **依现成旋律填词**：旋律强位和歌词句核冲突时，先在保留命题的前提下换词/换短语；只有用户允许改旋律时才提出旋律侧替代方案。
- **先词后曲**：给每行留下可供作曲的重音骨架和自然口气；不把音步表或 common meter 当成所有英文歌的底模。
- **角色口吻或时代语体**：先锁角色实际词汇和句法，再决定缩约、俚语、倒装；不以古典拼写伪造年代感。

交回父级的风格卡应写明：目标口音/语域；本段的句子焦点与词重音风险；旋律已知条件或纸面节奏假设；韵脚采用方式和句法代价；需要母语读者或实际歌者核验的地方。验收看正文而不是报告：朗读时句法自然，焦点词听得出，行断不误导，押韵没有迫使错误语序；有旋律时按实际乐句复核，无旋律时明确待验证。
