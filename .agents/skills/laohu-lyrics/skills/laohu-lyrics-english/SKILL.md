# 英语歌词：先锁自然口语重音，再对准节拍与断行

## 1. 锁定目标口音与两层自然重音
先定美式、英式或其他目标口音及人物语域，全曲发音统一，绝不为凑韵混拼口音或硬写古旧 `thee / o'er` 与假俚语。逐行按真人说话朗读并核清两层重音：
- **词重音（Word Stress）**：多音节词自身的固有主次重音绝不强行挪位；落在弱拍导致念歪时，优先换词或改短语。
- **句子焦点（Sentence Focus）**：承载新信息、否定、对比或称呼的语义核；单音节实词乃至强调态功能词皆可承重，但无表达理由时不让冠词、介词或助动词抢占强拍与长音。

## 2. 旋律对齐、跨行断句与韵律
- **有旋律时**：按真实乐句边界、强弱拍、弱起（pickup）、长音与换气放进自然英语短语，弱读音节自然交给弱拍或短时值，绝不按中文字数硬算总音节。刻意切分可以突出焦点，前提是句意仍清晰可辨。
- **跨行（Enjambment）与韵脚**：断行可用于延迟信息或制造悬念，但必须核实听众在行尾不会误判修饰对象、时态或否定范围。尾韵、内韵、头韵按目标口音实际读音规划，不为整齐韵式写生硬倒装。
- **多形态 Hook**：英文钩子未必靠工整押韵短句，称呼、祈使劝说、稳定歌名回句与尾段无词音节齐唱各有其效（参考 The Beatles《Hey Jude》由呼名劝说递进到共同咏唱）。

## 3. 回主文与自检
自然口语念一遍：语法、搭配、缩约与口音是否像母语真人开口？句子焦点落没落在可听重位？无旋律时只报纸面重音与节奏骨架，待配曲核实唱。
