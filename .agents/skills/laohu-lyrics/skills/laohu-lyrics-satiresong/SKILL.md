# 讽刺歌：让漂亮说辞直接撞上它遮住的真实代价

## 1. 先钉死四项批判骨架
动笔前先锚定：**具体批判对象（行为/制度/机制，不偷换成无关身份攻击）→ 它挂在嘴边的漂亮口号或自我形象 → 与之迎面相撞的真实后果与吃亏的人 → 歌者的明确站位**。

## 2. 四种核心讽刺手段（可按段分工）
- **反语**：字面一本正经地夸赞、感谢或服从，紧挨着把荒唐后果甩在下一句，让落差自己抽耳光；字面语气必须稳住，绝不半途泄气解释。
- **仿拟**：复刻权威公告、企业话术、广告或典礼的句法节奏，用它自己的腔调把空心逻辑照透（参考 Tom Lehrer《The Vatican Rag》把庄严仪式写成轻快舞曲节拍下的操作说明书，靠形式与内容对撞成讽刺）。
- **夸张**：顺着目标的真实逻辑推到荒诞极致，但基底仍让听众一眼认出源自现实，不拿假事实冒充证据。
- **荒谬规程**：老老实实照着对方定下的奇葩规矩执行到底，直到把谁受益、谁倒霉彻底暴露出来。

## 3. 先锁带刺副歌判词、并置撞击与讽刺记忆点侧重
- **两阶段定盘**：先独立锻造并锁死一句最带刺、最好哼的副歌中心反判词（可原句稳砸，也可随新证据层层加辣），再倒推将冠冕堂皇的抽象套话和受影响者的具体狼狈动作紧挨着并置在主歌相邻两行，不用说教，反差本身就是最狠证词。
- **讽刺歌专属记忆点侧重（全曲 2–3 处）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，优先主打 **反讽冷刀（极客气语气扎最深伤口）＋ 熟语/官方话术仿拟微拧 ＋ 语意反转**，确保过三秒质检且立场零和稀泥。

## 4. 回主文与自检
拿掉插科打诨词后，听众能不能一眼指出你在戳穿谁的哪套说辞、谁付出了代价？结尾是不是守住了用户的原始锋芒而没有偷偷和稀泥？
