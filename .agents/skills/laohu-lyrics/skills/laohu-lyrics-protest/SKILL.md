# 抗议歌：把伤害指回责任方，把拒绝与诉求钉在重拍

## 1. 先锁四项责任骨架与唯一主行动
写前锚定：**责任对象与权力关系 → 具体伤害行动与代价 → 歌者与受影响者的站位 → 明确拒绝或可执行诉求**。事实指控须有材料依据，绝不把行为责任偷换成身份羞辱。从四种主言语行动中选一项统领全曲：
- **见证**：按亲历或可见证据写清看到了什么、留下了什么后果、为何不能沉默；虚构见证须在角色世界内自洽。
- **控诉**：明确谁做了什么、谁承受后果，把权力者的公开说辞与普通人的真实损失紧挨并置，不用空泛他们敷衍。
- **拒绝**：用第一人称边界句直截了当拒绝不再接受的行为或交易，把最硬的一句砸进副歌强拍，稳定复唱即成力量。
- **动员**：写清具体诉求与共同可执行的第一步（参考 Florence Reece《Which Side Are You On?》每节逐层叠加冲突证据，副歌稳定用同一追问逼出听众站位），绝不用空洞的改变世界顶替真实诉求。

## 2. 段落推进与现场可唱性
主歌交出行动、证据或代价，预副歌把矛盾推到判断边缘，副歌执行主言语行动。面向集体齐唱时副歌压短句法、强化主语和动词重音；个人叙事抗议则保住具体现场细节，不硬改成标语。

## 3. 回主文与自检
裸读全曲检查：听众能否清晰指出反对什么、谁在维持伤害、具体诉求是什么？副歌重拍有没有真正打出所选主行动？
