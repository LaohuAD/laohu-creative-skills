# 粤语歌词：先立活的粤语词法与助词，再核真粤韵与声调

## 1. 先锁地域声口与雅俗语域
先定香港、广州或其他指定口音及说话关系：当代港式流行未另指定时，默认香港都市自然口语或流畅的三及第层次（吵架、吐槽、日常对话用纯口语短句；庄重咏叹、年代抒情才提高书面词比例），同一段落保持语域连贯，绝不上一句地道粤口语、下一句突兀跳回普通话书面腔。用完整粤语短语定主语、核心谓语、补语与态度，主语仅在上下文可恢复时省略。

## 2. 否定词、时体词与句末助词各司其职
- **四个否定词严禁混用**：
  - **唔**：否定当前谓语立场、意愿、能力或判断（`唔想`、`唔會`、`唔係`）。
  - **冇**：表示缺少、不存在，或在参照时段内没有发生过。
  - **未**：明确带着到现在还没发生、但仍留有余地的时间预期。
  - **咪**：放在动作前表制止或劝阻；注意 `係咪` 是正反问构式，切勿与普通否定混淆。
- **四个时体标记按事件边界选**：已完成有界事件用 **咗**，正在进行用 **緊**，状态持续用 **住**，曾有经验用 **過**。
- **句末助词承担真实对话动作，绝不当凑韵垫字**：邀请对方跟进或呼应多试 **呀 (`aa3`)**，回应问题、下判断或表态多试 **嘅 (`ge3`)**，兼有判断与提醒/感叹语气试 **㗎 (`gaa3`)**，其余按目标口音真实语气取舍；读来多余即删。

## 3. 按真实粤语读音核韵，分别管好入声尾与鼻尾
- 严格按目标口音的粤拼韵腹和韵尾核韵，绝不看字形或普通话拼音判同韵；区分严韵与近韵，不把近韵伪报为严韵。
- **入声塞音尾 `-p / -t / -k`**：收尾短促闭塞，适合利落断句、吐槽咬字或节奏顿点；若要放在长音拖腔上导致词义发散听不清，改移短时值/休止前，或换同韵开口尾字（不设入声禁用表）。
- **鼻韵尾 `-m / -n / -ng`**：三组唇/舌尖/舌根鼻尾分别核清，严韵段落不混押。

## 4. 声调排雷、两阶段粤语副歌核与港乐记忆点侧重
粤语九声六调与旋律是协商关系而非逐字死锁（参考 Edwin K. C. Li 的 speech-melody complex 视角），但听众必须听得出否定词、称谓、核心动词与关键名词：
- **两阶段与港乐记忆点侧重（全曲 2–3 处）**：写含副歌的 Cantopop 时，先独立锻造兼顾大开口真粤韵与清晰词义的副歌核心歌眼，再切回克制都市镜头编织主歌与预副歌；协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，善用粤语天然擅长的 **表里双轨/物情双关、三及第反讽冷刀、熟语微拧与一字降格**，保持紧凑留白，拒绝逐字硬译普通话金句。
- **有真实旋律或音频时**：按粤拼标出重拍、长音与高音处关键词，不看词听辨是否被旋律带歪成另一个常用词（倒字）；出现非刻意误听时，依次换同语域同韵词 → 调词序切分 → 调重音时值 → 授权内微调旋律。只有刻意做讽刺双关（如农夫《学海无涯》）或哭腔表演时才保留双解，且须在邻句留足语义锚点。
- **无旋律时**：照常把粤语母语语法、助词、真粤韵、入声/鼻尾位置与朗读顺畅度做到位，交付说明中用一句话注明声调与旋律协音待配曲试唱核验即可。

## 5. 回主文与自检
