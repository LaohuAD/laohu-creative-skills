# 儿童歌：按年龄校准认知负荷，让孩子真正听进去、唱起来

## 1. 按年龄与用途选分支，不把所有儿歌写成课堂操
- **学龄前共同动作**：用孩子摸得到、看得见的名物与单一动作，每句只给一个可模仿动作并留一拍供回应或接唱，多用短并列与拟声。
- **小学低年级游戏 / 探索**：按发现—猜测—结果的两三步小链条设计轮流、数数、问答或选择，每轮只加一个新概念，回句作为孩子稳稳接上的固定入口（参考 Raffi《Baby Beluga》用鲜明主角回句串起每节可想象、可模仿的新动作）。
- **想象 / 抒情 / 陪伴**：靠具体形象、好听的语气与稳定复沓让孩子在聆听与跟唱里感到被陪伴，绝不强加动作指令或问答任务。
- **小学高年级故事 / 观点**：允许适度复句、比喻与角色误会，让儿童角色自己做判断，绝不硬塞成人道德结论。
- **知识歌曲**：一次只锚定一条必须准确的知识点并嵌进故事或动作，术语在首次出现处就地演明；**事实与押韵冲突时立刻改韵，绝不为押韵篡改知识**。

## 2. 留住清晰参与入口
互动类歌曲给孩子留出明确的接唱词、拟声点或动作空拍；年龄未给且不影响大方向时先作可逆假设继续写，不把年龄问卷变成停笔门槛。

## 3. 回主文与自检
站在目标年龄孩子耳朵前念一遍：词句清不清楚、好不好跟唱、有没有藏着成人说教味？知识事实全部准确无误？无真实儿童试唱反馈时如实区分纸面判断与实际反应。
