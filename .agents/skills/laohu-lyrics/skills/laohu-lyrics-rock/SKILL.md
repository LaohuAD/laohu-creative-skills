# Rock：用站直的脊梁、强拍承重与大格局呼吸让态度震耳

## 1. 按材料选分支，立意一路穿透到底绝不后半段泄气
- **朋克 / 硬核对抗**：仅在材料有明确对手、规则或边界冲突时选用。短句一刀一个动作（指控、拒绝、要求），主歌给可见事实，副歌重复裁决；只有明确群体身份才用我们。
- **另类 / 独立清醒**：材料含反讽、清醒审视、现实拉扯或重新掌握生活时，用冷硬具体的现世切面与**直面真相的骨气**切入——既敢照见荒诞与软弱，更敢亮出挺直的腰杆、干脆的拒绝或清醒的选择（如《平凡之路》《山丘》），**从第一句到终副歌一路把这股脊梁贯通到底**，严禁中途泄气滑回过时选秀鸡血口号、粗鄙骂街或缩手缩脚的自怨自艾。
- **辽阔自由 / Arena 呼告**：材料指向奔赴、远行、自由、热望或大合唱时，用紧实短促的主歌蓄起推力，在副歌豁然打开辽阔坦荡的格局与短促铿锵的回句，堂堂正正唱出滚烫的生命力与呼吸反差。

## 2. 剥壳换血、先锁狠副歌宣言与强拍实词真韵
- **剥掉狭隘琐碎外壳，用硬朗大格局实景承重**：面对粗糙职场或生活压迫输入，先抽透核心脊梁与处境冲突，以带物理质感、开阔空间或荒野公路等五维高美感实景换血（绝不把全歌困在琐碎办公杂物清单里），同时严守现代活人实词语法——靠硬核名词、利落动词与当面真话砸强拍，零虚飘感觉形容词与书面散文腔。
- **先按 [laohu-title-chorus](../../../laohu-title/skills/laohu-title-chorus/SKILL.md) 锁重锤副歌宣言，再铺冷硬主歌压迫**：写含副歌的摇滚词时，先独立定死副歌 2–4 句精悍锋利、留足 riff 撞击空隙的态度宣言或呼告核（靠态度强硬与狠歌眼而非粗鄙嘶吼或空洞鸡血），再倒推低水位冷硬现实切面的主歌与加速逼近的预副歌，严防一开头就喊满 100 分贝把情绪曲线唱平。
- **摇滚专属记忆点侧重（全曲 2–3 处）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，摇滚不搞绵软暧昧双关，优先主打 **反讽冷刀（用最冷的语气揭最荒诞的代价）＋ 熟语微拧砸强拍 ＋ 硬核人性公理短句 ＋ 高空反转**——副歌砸下 1 处掷地有声的宣判级歌眼，主歌或桥段埋 1–2 句冷峻扎心的现实短刀，全曲精悍留白、不写绵长抒情散文。
- **强拍承重词与逆向实词真韵**：全曲守住唯一清澈的情感主梁与连贯画面（不堆杂喻、不泛滥拟人），先逆向定死强拍与句尾的硬朗完整实词韵脚再顺出前半句，把态度重词、动作词与转折词撞在强拍或清晰实音重音上。严守普通话实音真韵与物性（`-ong/-eng`、`ü/i`、`-n/-ng` 绝不混押，轻声不充强韵脚，不为凑韵造反常物理动作或词类截肢）；尾声可选，无伴奏时如实标明仅核纸面节律与强拍承重词候选。

## 3. 回主文与自检
歌者脊梁是否完全贴合题材真实心气、一路贯通到底且一听秒懂？把每一处押韵短语单拎出来念，是否 100% 自然顺畅、真韵不混、强拍炸耳？无真实伴奏时不宣称已卡死 riff 拍点。
