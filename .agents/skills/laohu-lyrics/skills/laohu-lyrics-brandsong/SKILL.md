# 品牌歌：把一条有据可核的主张写进真实关系

## 1. 先定三大分支与唯一记忆锚
先锁定**唯一核心信息、真实发声者、目标听众、播放场景与可核验事实**，绝不把五六个卖点挤进一首歌：
- **短促识别 jingle**：按真实投放窗口，把品牌名或声音锚点精准放在重拍或句尾，围绕一项经核验的产品动作回返。
- **品牌形象歌**：把品牌承诺放进用户真实可见的日常关系场景，在主张自然兑现处带出品牌（参考 Coca-Cola 1971 Hilltop 广告歌先立普遍共享愿望、再由品牌作为陪伴物自然收口），不拿无品牌的纯流行歌冒充广告识别版。
- **企业 / 团队歌**：用真实劳动动词和同伴称呼写基层日常协作，不拿管理层标语假扮员工心声。

## 2. 事实红线与品牌词落拍
- 凡涉及功效、排名、资质、对比优势、保证或用户证言，**必须有用户提供的真实依据与授权**，严禁编造；愿景与态度标明为立场，绝不伪装成已证实结果。缺少关键事实时先完成不依赖它的骨架或留清待核位。
- 商标与品牌名按实际读音拆音节，自然嵌入主谓通顺的句子和重音位，绝不生硬连喊品牌名硬凑押韵。

## 3. 回主文与自检
逐句核查：事实断言都能回到用户依据吗？品牌词唱起来自然不生硬吗？听众听完一遍能不能记住那唯一一条核心信息？不拿文字完成度冒充投放或销量效果。
