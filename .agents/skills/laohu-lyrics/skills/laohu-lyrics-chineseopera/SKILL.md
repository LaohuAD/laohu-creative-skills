# 戏曲唱词：先锁剧种、行当、板式与场面职责

## 1. 先分清路径，绝不跨剧种乱套
- **已指定剧种、曲牌或谱本**：以指定谱本的句格、正字、衬字位置、韵位、板眼和气口为最高约束。
- **只说戏曲唱词且无谱本**：先确认剧种；需直接出纸面可试听草稿时，可采用注明边界的京剧上下句草稿路径，绝不冒称既有传统曲牌或可直接登台；昆曲须明确曲牌版本，地方戏绝不套用京剧或昆曲句格。
- **行当与念白分清**：先锁生、旦、净、丑及人物当下处境，京白、韵白与唱词分别标注，不拿念白直接当唱词。

## 2. 两大核心体系实操法
- **京剧板腔体（西皮 / 二黄）**：
  - 按唱段职责（行动质问、抒怀、写景、仪式、对唱攻守）选句格：单动作或直判断常用七字句（草稿节奏槽 `2+2+3`），需在同句铺开因果、阻碍与态度常用十字句（`3+3+4`）。慢板留语气与拖腔空间，流水与快板重一拍一动作或一轮攻守交锋（参考《四郎探母·坐宫》快板对唱：每轮反制真正改变下一轮，背景交给念白或前唱）。
  - **韵辙与吐字**：纸面草稿通常按十三辙选定一辙、成对句尾归同辙，并核对行当读音与上口字；把否定词、称谓与主动作词稳放板眼听得清的位置，衬字放非承重处。
- **昆曲曲牌体**：
  - 严格按所选谱本（如《集成曲谱》中《牡丹亭·游园》从散板、一板三眼到快板的联套衔接）先列每句正字、衬字、韵位与板眼空槽，再按场面次序回填语义重心与衬字，不先写满现代短诗再硬剪。
- **拖腔与语气词边界**：不设跨剧种的句尾禁语气词规矩——实义词常稳语义落点，但具体曲牌、板式或唱腔确需语气词、呼告词或衬腔时，依谱例与唱段需要处理。

## 3. 回主文与自检
标明剧种、行当、声腔/板式或曲牌依据、韵辙与唱段职责；按程砚秋字字听清、出字收声、角色声口与情感一致原则逐句朗读检查。未按具体谱本合腔试唱的草词，如实标注仅作纸面句格草稿。
