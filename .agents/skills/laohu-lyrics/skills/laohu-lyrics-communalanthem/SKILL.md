# 群体颂歌：让共同经历立稳我们，让每个人一口气接得上

## 1. 先界定我们是谁与三类共同体边界
开写前先明确作品里的我们指谁、为何聚在此处、共享什么经历或任务，以及现实/虚构边界：
- **现实机构或社群委约**：只把确认过的共同经历放进齐唱重句，未经确认的个人证言或单方立场留在领唱或我，不替成员强行代言。
- **虚构 / 艺术共同体**：按设定通过一项正在共同完成的行动或羁绊立住我们，保留成员间可辨的个性与分工。
- **仪式 / 纪念 / 行进**：按时间位置分配段落任务（参考《Lift Every Voice and Sing》由召唤发声—历史受苦与站立见证—面向未来的祈愿承诺逐节推进），情绪可庄严、悲悼、温柔或欢庆，不靠喊口号凑宏大。

## 2. 声部分工与首次即跟唱设计
用清晰的声部结构安排**领唱、回应、轮唱或齐唱**：领唱交出具体名字、时间、经历或提问；齐唱回句缩短语法负担、用具体动词和敞亮重音让第一次听的人也能一口气接唱。

## 3. 回主文与自检
检视全稿：我们是谁、共同经历了什么、哪句归领唱、哪句归齐唱一眼清楚吗？领唱和齐唱有没有互抢任务？缺少真实群体试唱反馈时不宣称群体认领已验证。
