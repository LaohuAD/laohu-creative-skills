# Rap：按表达任务组织 flow、韵链与节奏压力

## 1. 先选推进分支，不预设固定 bar 数
- **Battle / diss**：明确对手与争议靶点，按靶点—证据或反驳—裁决 punch 组织；每个 punch 必须回扣靶点，绝不拿密韵冒充论据。
- **叙事 Rap**：按行动、发现与后果切分句群，转折即换组，不死锁每 2–4 bar 换意。
- **观点 / conscious**：先立可被反驳的清楚判断，再配现场动作或事实证言，不靠吼叫替代材料。
- **旋律 Rap / 歌唱型 hook**：先试副歌句的元音延展、句长与复唱感，再用主歌控制信息疏密。
- **声音 / 氛围主导**：允许口腔音组、发声质感、停顿与原样回声承担全段组织，不强迫每 bar 必带独立论证命题。

## 2. 体量豁免、Hook/Punch 记忆点侧重与可拍读 bar
1. **体量豁免与两阶段分工**：说唱明确**豁免 200–270 字抒情字数上限**——说唱靠空拍、切分与韵距疏密造呼吸，绝不拿短抒情容器压扁 bar 密度。凡带歌唱或洗脑 Hook 的说唱，仍先独立锁死极简抓耳的 Hook 核，再以高密度主歌 bar 与之拉出信息量反差；纯 Verse 则把关键 Punchline 节点当作情绪爆点前置锚定。
2. **说唱专属记忆点侧重（每段 2–3 处硬核 Punchline）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，说唱优先主打 **谐音双关与一语双关（Wordplay）＋ 熟语拆解微拧 ＋ 跨界喻体撞击 ＋ 延迟反转 Punch**——全部卡在 bar 尾强拍或空拍落点，须过三秒质检（自然口语零晦涩、半秒回味炸场），严禁为凑多音节押韵强造不通顺废词或硬塞网络烂梗。
3. **先抓承重词、临时拍感与三变量韵链**：圈出决定听感的承重词按自然一口气分句群；有真实 beat 严格沿用，无 beat 选临时拍感标清强拍承重、弱起、反拍与跨 bar 衔接（不把 4/4 或 90 BPM 设成全局默认）。用**落点**（行尾或 bar 内）、**周期**（相邻韵距）与**密度规律**（参考 Kendrick Lamar《A.D.H.D.》短程由疏转密再放松的张力弧）控制节奏压迫；押韵若逼出倒装或虚词凑数，优先移韵位或换韵族。

## 3. 回主文与自检
自然口语读一遍再按节拍拍读一遍：首听能否抓准本段核心或声音推进？反拍处前后是否有稳拍对照？承重词是否清清楚楚落进可听见的位置？无 beat 时只注明纸面 flow 编排，待进真实伴奏再核实唱适配。
