# 影视角色歌：把歌词限制在角色能感知和承担的范围

## 类型边界与固定关系

用户明确要求影视插曲、角色歌、片中演唱，或要歌词表现某个影视角色的具体处境与内心时启用。材料提到电影、角色名或画面，不触发；若歌面向观众概括全片母题，改用影视主题歌。

开写前固定四栏：**此刻是谁发声、对谁、角色知道什么、画面已经说了什么**。再确认歌词结束时角色的认知、态度或行动是否改变。角色可撒谎、误认、隐瞒；歌词可有潜台词，但不能突然借作者口吻预告角色不知道的结局。画面可提供信息，歌词须补足画面没有说尽的欲望、关系或矛盾。

## 按声音是否属于场景选分支

- **戏内歌曲（diegetic）**：角色和场景中的人都能听见。必须给出角色为何此刻唱、用什么音源/场合、旁人会怎样回应；句法靠近人物能公开说出的语汇，唱词若是表演，说明其台词身份。
- **角色内心/非戏内插曲**：只有观众听见。允许比日常对白更凝练，但词汇、比喻、盲点、记忆仍属于该角色；角色尚未承认的内容可以由意象泄露，不可直接宣布全片答案。
- **与镜头对位**：画面展示行动时，歌词写行动者的选择、代价或对象；画面停留在脸/物时，歌词可推进未说出的关系；故意反讽画面时，让字面赞颂与已知事实形成单一清楚的落差，不在下一句解释笑点。

剪辑点按镜头实际发生的动作分配：标出进歌前、每次镜头转折、出歌后的状态；歌词行与画面动作重叠时问“去掉这行，观众是否已从镜头完全得到同一信息？”若是，换成角色为何这样做、对谁做或不愿承认什么。主歌可用完整句承接场景，副歌压住角色此刻的自我判断；仅在镜头促成新认知时才改回句。

## 案例拆解：Disney《Frozen》中的 Elsa 与“Let It Go”场景

Disney 官方场景说明把歌置于 Elsa 的秘密能力暴露、她逃离 Arendelle 的情境，并标出冰宫建造等画面行动。文本先借雪夜与隔绝建立她的内外环境，再用一串自我规训句呈现她努力维持的“好女孩”面具；重复的释放命令不是写给另一角色的对话，而是她说服自己的言语行动。随后歌词从“藏住能力”转成“承认并使用能力”，银幕同时把这一句法转向外化为冰宫、服装和空间变化。结尾完成的是当下的自我定位和物理离开，不等于姐妹关系或王国后果已解决。新作应把可见行动留给镜头，把“她为何此刻改口、改给谁看、承担什么代价”交给歌词；不得将此场景泛化为所有角色歌都要唱成自我解放。

## 与父级流程的分工及验收

父级负责七步创作；本配置只强化第三、四步的信息权限和视听分工。验收表逐行注明角色/观众/画面各自知道什么；至少一句歌词提供镜头未提供的内心信息；剪辑前后不出现无来源的全知判断。无法区分戏内演唱与角色内心声时，先确定声源再写。案例来源和本地适配见[表达机制与戏剧用途](../../references/expression-and-purpose.md)。
