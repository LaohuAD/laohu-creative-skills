# 影视角色歌：死守角色知识边界，与镜头形成声画对位

## 1. 先锁死四条银幕边界
开写前明确：**此刻谁发声 → 对谁唱 → 角色当下知道什么（严禁剧透或跳成全知旁白）→ 镜头画面已经交代了什么**。角色可以隐瞒、自欺或误判，但绝不能说出自己尚未得知的后续结局。

## 2. 区分声源与镜头对位
- **戏内实唱（Diegetic）**：片中其他人物也能听见。须合乎当下场合、音源与公开说话分寸，兼顾在场者的反应。
- **角色内心声（Non-diegetic）**：只有观众听见。可比日常台词更凝练，但词汇、比喻与盲点仍须完全属于该角色。
- **绝不复述画面**：如果删掉某行歌词，观众单看镜头已经完全知道同一件事，就立刻把那行改写成镜头拍不出来的东西——角色为何此刻改口、藏着什么代价、不愿承认什么（参考《Frozen》中《Let It Go》把建冰宫与变装交给画面，歌词专注呈现从自我规训转向自我认领的言语动作）。若只写单场插入剪辑，按进歌前、镜头转折与出歌后三节点组织，不硬补完整流行曲式。

## 3. 回主文与自检
逐行对照镜头与角色认知：有没有越界剧透？有没有跟画面说重复废话？戏内实唱和内心声的说话分寸有没有串位？
