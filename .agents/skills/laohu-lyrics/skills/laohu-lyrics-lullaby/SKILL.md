# 摇篮曲：用低刺激、可预期的呼吸回返陪伴安顿

## 1. 三类陪伴场景，各自守住分寸
- **照护者陪婴幼儿**：抓一两个熟悉的陪伴动作（轻拍、守在床边、轻呼小名）贯穿，回句严格原词原序，让听者稳稳预期下一句。
- **为害怕或想念的人守夜**：先安静接住对方的真实不安，再用同一陪伴动作回应，避免轻率否认害怕或替现实许下无法兑现的安全保证。
- **成年人睡前自我安抚 / 失眠陪伴**：允许成熟细腻的内省意象，仍保持单一夜间时段与极低信息切换率，不把必须睡着写成压力任务。

## 2. 低认知负荷与舒展声韵
- **低事件密度**：一段最多只展开一处温柔细节，不连换人物、场景或突发悬念，不强加高潮桥段或越唱越响（参考 1939 年 Bernice Haynes 拍哄录音的稳定哼唱留白与呼吸循环；仅在角色轻巧哄逗时才借鉴《Hush Little Baby》的物件替换链）。
- **舒展长元音与平稳换气**：多用平行句、舒缓开口韵与自然呼吸句尾，重复本身就是让人安心的节拍，绝不为了新鲜感打碎回返预期。

## 3. 回主文与自检
放慢语速轻声读一遍：有没有突然跳出的刺激意象、任务指令或高亢转折？安慰承诺是否在歌者真实能力范围内？实唱安抚效果以真实使用为准。
