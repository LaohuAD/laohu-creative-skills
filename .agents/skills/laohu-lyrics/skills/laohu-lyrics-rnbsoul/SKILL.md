# R&B/Soul：让口语短语在 pocket 与留白里协商关系

## 1. 四大分流，绝不揉成平均丝滑风
用户点名或参考曲特征明确时直入对应分支；仅有宽泛标签且直接交稿时，暂按 Contemporary R&B 组织并注明假设：
- **传统 Soul / Gospel-rooted Soul**：领唱完整提出主张、请求或见证，伴唱承担稳定回声、集体确认或补充反证三选一（参考 Aretha Franklin《Respect》将抽象诉求化为可执行请求，拼字 Hook 方便参与、姐妹声部稳定确认并给器乐退场留白）。稳定回声允许原词原拍反复，以坚持与群体在场取胜。
- **Contemporary R&B**：近距单主唱与清晰 verse-hook 对比。主歌一个意群推进一件关系动作，Hook 压成可复唱的请求或判断，伴唱在主唱交代完对象与动词后再轻回或补尾音。
- **Neo-soul**：稳定循环 groove 与拍后声口（laid-back）。句长不对称、允许一短一长，每句只抓一个主承重词后置落入 pocket，把转音或即兴留在句义闭合后的空拍，靠循环本身累积律动。
- **Alternative R&B**：仅在点名或参考确有稀疏、断裂、非线性听感时选用。可用残句与截断造距离感，但每段保留至少一个说话者、对象、物件或动作锚点。

## 2. 两阶段 Hook 分工、记忆点侧重与拍位留白
1. **先锁近距 Hook 核与伴唱应答，再织主歌推拉**：写含副歌的 R&B/Soul 时，先独立锁定极近距、元音可舒展延音的 Hook 核心短句与伴唱应答位置，再切回低声近距的主歌铺垫关系试探与细节推拉；字词绝不挤满拍格，把丝滑和呼吸留给 pocket。
2. **R&B/Soul 专属记忆点侧重（全曲 2–3 处）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，R&B/Soul 天然最吃 **成年人私密表里双轨（边界、分寸、亲密试探的清白面皮 × 私密里子）＋ 休止空拍后的短促语意反转 ＋ 称呼与微距动作的留白暗示**，忌生硬说教与粗鄙喊叫。
3. **保完整意群再切分与延音落位**：否定词—动词、动词—对象、条件—结果尽量留在同一可听意群内，绝不把否定词切到弱拍后面导致听反；每意群锁定一个主承重词落元音核（正拍宣告、laid-back 后置、急迫才弱起）；长音或候选转音优先落在韵腹清楚、口腔舒展的音节上，末端再收鼻尾或辅音。
4. **给每一处空隙定职责**：休止分别服务呼吸、等待、重词余韵、伴唱回声或乐器接话；伴唱优先在主唱句义闭合后进入，避免遮住新信息。无旋律时仅标候选拍位与延音字，不臆定具体转音音符。

## 3. 回主文与自检
拍读检查：第一遍能听清对象、动作与条件；第二遍能听出弱起、后置与留白的呼吸分工；字词绝不挤满拍格。
