# 叙事民谣：用可复述的行动链承载歌谣声音

## 类型边界与支配关系

本配置指以事件讲述为承重机制的传统 ballad 或现代叙事民谣，不是所有木吉他歌曲，也不是流行语境里的慢情歌。乡村、旅行、旧物或慢速旋律不构成触发。用户指定英语/苏格兰 Child ballad、某地区口传传统或具体歌谣谱系时，先按该谱系选文本与声腔；只说“叙事民谣”而未指定历史传统时，默认现代叙事民谣，不假造传统韵律或方言。

固定听者必须复原的行动因果：人物想要什么—哪一行动/消息改变局面—产生什么可见后果。开写先列事件候选，删掉只作背景、不会改变行动/关系/代价的节点；但不删导致结局无法理解的消息。每节增加一个动作、消息、选择或后果；可以省略解释，不能省略理解因果所需的行动。

## 选定叙述者、披露次序和诗节句架

### 现代叙事民谣：以段落节点控制揭示

按材料选定一支，不混成平均口吻：**直线見證**從起因推到結果，適合事件本身有推力；**結果先行**先交後果，再回到原因，適合哀悼或已知命運；**旁觀講述**只報見到/聽到的動作，心理由行為推斷；**人物自述**只講角色當時知道或願意承認的內容。每段草擬「場景錨點／新行動／新資訊或代價／段尾聲音落點」四格；跨時空時以人名、稱謂、地點、時間詞或重複物件標清切換。只有新節點改變方向時才轉段，不按字數平均分配。

自由诗节按实际旋律安排，但保留一项稳定的口传抓手：短句末尾重复、核心问句、叠句或相同节拍。每次回句先选“固定记忆/宿命”或“信息递增”分支：固定句让事件语境改变听法；递增句每次只加一个事实或责任。不能强迫所有副歌逐次升级。

### 英苏传统 Child ballad：一段一事，叙事靠韵脚和直引推进

用户指定此传统且未指定异本时，可明示采用 Francis James Child 编号文本 84A 的叙述分支作结构参照：四行歌谣节为主，第二、四行用尾韵/近韵收束，第一、三行交代新动作或场景；保留长短行的口头弹性，不硬凑现代工整音节数。每节只推进一个节点：时地/关系→召唤→抵达与识别→直接对话揭露旧怨→人物离场/死亡→公共消息→后果回声。对话转折用人物原声和称谓承担，不插入作者心理解释。连续叠句只放在歌曲已有的呼告、钟声/死讯、告别等结构铰链；要递增时改一个信息焦点，不改整段成现代副歌。若用户指定其他传统或异本，先读该异本，再按其诗节、节拍和叠句特征重做此句架，不能将 84A 格律冒充普遍歌谣律。

## 案例拆解：Child 84A《Bonny Barbara Allan》与口传版本

Child 第二卷 84A（据《Tea-Table Miscellany》文本）按季节和关系开篇，随后用使者召唤、病榻对话、迟到的旧怨、告别、钟声死讯和回到母亲处的结尾逐节披露故事。它先让听者知道人和危急处境，再由病榻对话补出女主人公的旧怨，故拒绝不是作者旁白的性格评语；钟声把私人的死亡变成外部可听消息，最后的平行命运完成后果。文本主要用四行段落、二/四行声韵回扣、直接引语及局部词组复返。迁移方法：每段用第一/三行推进动作，第二/四行收紧关系或声韵；关键旧因在改变当前判断时才披露。

美国国会图书馆 Todd–Sonkin 1940 田野笔记还记录 Lois Judd 与 Rosetta Spainhard 同一采录场合演唱不同旋律版本：Judd 约二十年前在肯塔基听到较早版本，后来在印第安纳从广播听到且更偏爱另一旋律，Spainhard 又转入一版。录音史证明同一歌谣的旋律与措辞可变；不是证明文本内容完全相同。因此创作时固定的是可追踪的因果节点和被选的口传分支，不是假装存在唯一“原汁原味”版本。不要照搬其死亡爱情故事、称谓、方言和旋律。

## 与父级方法的分工及验收

父级负责材料研究、整曲结构、初稿与交付；本配置把段落职责转成“此段新增哪个事件节点、由谁以何种距离讲”。验收时陌生听者可复述谁行动、消息如何改变局面、结尾为何发生；每段都有信息增量或明确承担稳定复沓；时空与说话人没有断链。若听者只记主题不知经过，补动作/因果；若像剧情梗概，删背景并让人物在场行动。出处见[表达机制与戏剧用途](../../references/expression-and-purpose.md)。
