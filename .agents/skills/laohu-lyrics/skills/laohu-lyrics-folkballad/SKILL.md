# 叙事民谣：用事件因果、披露视点与口传声口讲活一个故事

## 1. 先钉死可复述的因果链与披露视点
先把核心因果理清——人物怀着什么欲望、做了什么选择、收到什么消息、招来什么后果——再决定讲故事的站位（可在关键处切换）：
- **直线见证**：随事件从起因走到后果；
- **结果先行**：先亮命运终局，再倒回缘由；
- **旁观讲述**：只讲叙述者亲眼所见所闻；
- **人物自述**：严守角色当时知道、记得或肯承认的边界。

善用姓名、称谓、地名、时间词、复现物件与直接引语定位时空；**纪实选象边界**：叙事民谣允许保留承载真实年代质地与人物命运的具象地标或核心物件（不必硬抽离成泛自然风光），但只精选 1–2 个能随岁月变重的母体反复照应，绝不罗列零碎生活杂物账本；全篇严守活人口传白描、实词承重与逆向实词落韵，在关键后果前后允许停留、回望或复沓，把故事写成活生生可唱的歌，绝不写成干瘪剧情梗概或文艺散文腔。

## 2. 先锁宿命回句核、民谣记忆点侧重与传统变体
- **叙事民谣的两阶段变体**：民谣不靠高音嘶吼副歌制造高潮，而是**先独立锻造并锁死承载全曲命运重量的核心回句（Refrain / 宿命歌眼）**，再倒推铺设质朴克制的事件链。回句二选一：**固定宿命句**（字面不变，靠每节新事件反复改写其分量）或**信息递增句**（每次只添一个更重的新事实或责任）。诗节随事件、披露或情绪停留自由切分，保留口传抓手与呼吸留白，绝不强套流行抒情的高音预副歌公式。
- **民谣专属记忆点侧重（全曲 2–3 处）**：协同 [laohu-title 记忆点六大武器](../../../laohu-title/SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)，民谣优先主打 **极简空槽召唤（搭出生活容器让听众代入半生）＋ 轻描淡写写剧痛的反讽冷刀 ＋ 复现回句的语境反转（同一句话听三遍分量截然不同）**，保持 85% 质朴白描素底，拒绝华丽炫技与廉价网歌塑料道具。
- **指定英苏传统 Child ballad 时**：可参照 Child 84A《Bonny Barbara Allan》的四行歌谣节（二四行押韵收束，一三行推动作；直接对白揭旧怨，钟声等外部声音传死讯，叠句留在告别与结局铰链，保留口头长短句弹性），具体仍以用户指定异本为准。

## 3. 回主文与自检
听完一遍，陌生听众能否复述清人物做了什么、发生了什么、落到什么后果？同时整首读来是不是活的口传歌唱，而不是散文摘要？
