# 影视主题歌：让观众带走全片母题与余韵，不复述剧情

## 1. 按放映位置选句法与剧透边界
- **片头 / 片名歌**：观众尚未看戏，用核心母题意象、关系难题或未决疑问拉起观看预期，绝不提前剧透结局。
- **全片贯穿 / 蒙太奇主题**：抓一条能照亮全片的关系命题或稳定回声，副歌给观众稳固的听觉锚点，不把几条剧情梗概硬塞进一段。
- **片尾 / 字幕歌**：观众刚走出故事，紧扣全片已立住的物件、声音或关系做回望与延展，承接未尽余韵（参考 James Horner 谈《Titanic》片尾歌复用全片旋律母题，歌词不复述沉船经过，而是将外部失去转化为跨越距离的持续记忆）。字幕若在回放旧画面，歌词写回望后的情感落点，不重复画面内容。

## 2. 独立好听与照回影片双成立
副歌既要让没看过片的听众一听就懂那份人类共通的关系重量，又要让刚看完片的观众瞬间撞回全片母题。结局本来开放的影片，主题歌保留这份悬念与余响，绝不擅自替影片宣判圆满答案。

## 3. 回主文与自检
检查裸词稿：是不是滑成了按时间顺序讲剧情的摘要？有没有越权冒充某单一角色独白？走出影院后听众能带走哪一句回响？
