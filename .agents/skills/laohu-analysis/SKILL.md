# 老胡问题分析与方案设计

**从真实材料中看清关系，使判断有据，使方案成形。**

## 核心职责与边界

**分析回答材料支持什么；实施把已选做法写进实际能力。**

本入口判断当前材料支持什么解释、哪项未知会改变选择，以及下一步采取什么办法。它承接问题界定、调查取证、原因解释、方案比较和长期能力的完整设计；可读取记录、核对来源和复现非创作行为。需要以作品检查目标行为时，交由经授权的目标执行 Skill 实际产出，再依据该产物判断。

分析与实施分开：本入口交付解释、比较或可接手方案，不代替对应专业入口完成作品，不实施生产修复，也不负责把规则写回长期能力。已知方法的常规应用由原负责人完成；方法、范围或关键取舍未定且会改变能力时，由本入口补足判断，再按已授权方案交 evolution。问题审查、能力实施和其他正式产物仍由各自负责人承担。跨入口职责、用户授权与产物负责人分别判断，按项目运行约定办理。

## 确定本轮产物与范围

**任务要走多远，由用户要改变的结果决定。**

沿用对话和已有材料中确认的目的、对象、限制、选择和保护项，不重问已经成立的内容。把事实、推论、观点、偏好、决定、专业方法、设计选择与未知分开；用户明确选择的目标和偏好按其范围执行，事实断言按证据强度限定，成熟且适用的方法可作为有条件的工作选择。预期效果不冒充已经验证的结果。后续解释、比较与方案都受已确认的质量目标、优先级和有效特征约束；发现不足时，围绕当前差距寻找能增强该目标的条件、专业方法与实现动作，不以更容易证明的邻近标准替代原目标。主题相关、内容对应或材料在场只说明有关联，不单独证明有益于用途或已实现质量。确定范围后读取根目录[万能造梦框架](../../../references/universal-dream-framework.md)，在授权对象内贯穿审视全部方向；模型是判断视角，不是目录、固定顺序或输出栏目，真实功能可以跨多个方向，已满足、不适用或证据不足都如实处理。

按会改变处理的缺口选择工作范围：

| 当前需要 | 本入口推进到 |
|---|---|
| 只想知道材料支持什么 | 可核对的问题表述或证据相称的解释，不强塞修复计划 |
| 原因未知且不同解释会改变机制理解、结论把握、可检验预测或下一步 | 可观察事实、首选解释、关键替代解释及区分重要时的最小证据 |
| 目标明确、处理路径未定 | 关键差异、实际代价和有依据的推荐 |
| 已知方法的一项正常应用或局部问题 | 该问题所需的判断，不扩成完整能力设计 |
| 新建、整体重构或扩大一项可复用能力，或用户明确要端到端设计 | 进入“设计完整能力”专用分支，覆盖整体职责、逐部分方法、彼此依赖、融合与验证交接 |

局部问题不因范围较小而降低判断质量，完整设计也不因任务复杂而自动要求新建多个文件或 Skill。只有模块职责、调用者、方法或维护条件确实不同，才拆开处理。完整设计依赖的专业判断仍未定时，先查清会改变架构或方法的缺项；不受该依赖影响的工作继续推进。

只要本轮分析对象或方案涉及运行规则的判断、迁移、局部更新、新建、融合或整体重构，在具体内容对照前读取完整[规则表达与方法保留](../laohu-evolution/references/rule-expression.md#更新规则前按语义对照)。它是新旧判断对齐、补缺、分支、冲突裁决和信息保真的唯一细则。本入口在授权范围内检查已确认的必做动作是否被写成任选、条件动作是否缺少触发或对应动作；若发现差距，定位真实控制文件、原句及上下文，说明相对本轮决定的偏移与影响，并给出准确替换内容。方案交 evolution 写回，不由 analysis 实施。

## 还原对象、条件与源头决定

解释、调查、原因判断或方案比较时读取[调查取证、解释与方案比较](references/investigation.md)，深化证据、机制、执行断点和比较方法；按范围阶段读取的共享模型贯穿判断，不继承上游坐标、标题或遗漏。对授权范围内的16个交点逐一作实质审视：把每个交点转成当前对象中的待理解关系、适用依据、实际读取/比较/推演动作，以及交给解释、选择或设计继续使用的发现。交点可彼此关联、由一个方法共同支撑，也可能确认已满足、不适用或证据不足；不要求每格独立产出一个问题，更不把坐标当输出栏目。模型作用必须从后续实际判断、分支、动作或结果中看见。进入完整能力设计分支时沿用同一模型，不另起一套分类。

### 先界定接收者要理解或决定什么

回到用户真正要理解或决定的对象：它为了谁、在什么情境下要改变或保护什么，用户已确认了哪些目的、立场、优先级和取舍，哪些仍开放？重建实际输入、组成部分与关键关系；分清对象的预期产物、可取得的真实产物、接收反馈和本轮 analysis 的解释/方案。规则只说明写了什么，调用记录说明资源是否加载，执行记录说明怎样处理，成品与接收证据说明实际呈现或效果；任何一种都不能替代其他层证据。由此确定本轮需回答的问题、判断标准和保护项，下一步只沿会改变解释、选择或方案的材料关系继续；用户要的是局部解释，就不扩成全域重构。

### 追踪本地材料如何支撑目标

沿着会改变判断的材料关系读取：哪些输入、事实、人物/组件或状态承担目标作用，材料如何被选取、排序、连接、转换或交接，取舍和依赖如何影响后续结果。对重要关系，指出对应的原始材料、条件或前后处理，以及观察到什么；比较会改变判断的分支，必要时复现或设计最小区分动作。把直接观察、事实断言、用户决定、作者的专业选择、推论和未知分开。形成可定位的证据与关系，交给后续解释、原因区分或方案设计；只有某项事实、反例、保护设计或合法分支会改变解释、方案或范围时才继续补查。局部观察不外推为全域规律，未知不扩大成已确认故障。

### 直接检查实际呈现和接收条件

分析成品、文字、界面、流程或其他媒介时，直接读取实际对象及本轮可达的相关上下文，不以 brief、提示词、作者意图或转述替代成品。按当前问题检查接收者实际看见、读到、听到或能操作的内容；文字在意义受影响时具体核对词义、指代、搭配、范围、否定、因果承诺和信息次序。将材料本身支持的功能判断与需要真实接收/使用资料的效果主张分开：缺少点击、体验或群体反馈只限制这些效果断言，不取消仍可完成的句面、关系或功能分析。有意留白、简称、多义和局部信息不足是否构成问题，依已确认用途、可达语境与承担职责判断。这里形成的是对实际呈现的观察，不倒推其他方向必然有错；analysis 报告自身的可读性留到综合表达时另行复核。

## 取得专业依据并形成解释

专业知识只有在它可能改变解释、方案、方法或验收时才取用。先说明要判断什么，再查相称的本地材料或可靠来源的原意、适用范围、前提和反例；让知识支持对当前对象的选择，不以作者名气、术语或引用数量代替适用机制。缺少特定术语名称不等于缺少方法；若适用专业依据不足且确实会改变结论，指出限制的具体判断，不把知识缺口直接判成对象错误。方法、理论、历史案例、本地运行记录、试验和接收反馈证明的事项不同，不能互相冒充。

选到方法后要把它真正用于当前材料：指出该方法关注的作用、条件或关系，用适合它的读取、比较、推演、计算、复现或检验动作处理眼前材料，再说明所得观察如何支持、削弱或限制当前判断。方法名称与一段正确理论都不是应用结果；若方法不适用或当前证据无法完成某一步，只限制对应结论，仍推进不依赖它的工作。同一方法可支持多个交点，不为每格机械找一套理论；所得发现须进入后面的解释、原因区分、方案比较或能力设计，而不是留在背景介绍里。

按用户要理解的关系区分说明、原因判断和方案比较。说明或理解对象结构时，交代可观察材料之间的关系、证据支持到哪里及尚未知的部分，不自动启动根因追查。对能解释主要观察且有材料依据的不同解释，只要它们会改变原因/机制的理解、结论把握、可检验预测或后续动作，就保留并说明各自依据与关键分歧；即使暂时导向相同的最小检查或下一步，也不因此删除。同义解释合并；不能解释主要观察或没有材料根据的纯可能性不罗列。若用户要求判断原因，或差异会改变当前理解、预测或选择而材料尚不能区分，从最早与目标相关的差异追到关键分歧，并优先取得能改变判断的最小证据。材料已足以支持当前结论时不等唯一根因；原因未知也不妨碍交付可恢复、可检查的下一步。比较方案时先核硬约束，再说明目标收益、代价、依赖及会切换做法的条件。用户只要解释时不强塞修复计划；问“为什么”本身不授权实施。

宽泛质量反馈要落到真实接收者、具体表现、适用判据、可能原因、区分动作、控制位置和可观察验收；已有材料已足够的环节直接沿用，不机械填表。若方案要改善体验，说明希望接收者理解、感受或完成什么，材料怎样承载该效果，媒介内需要怎样处理及事实/权限边界。分析规则或表达意图时，按本轮明确决定、源材料和已选专业方法核对当前规则、执行与成品：若立场、视角、声音、力度、优先级或技法被写弱，指出第一处可定位控制点及影响；不同意原决定时另陈依据和代价，不把替代方案说成忠实保留原意。analysis 不自行创作作品作示例、试作或验证；需要作品证据时，由获授权的目标执行 Skill 按最终文件产出。

## 设计完整能力（范围分支）

仅当“确定本轮产物与范围”选择了新建、整体重构或扩大可复用能力时进入。读取[完整能力设计](references/capability-design.md)，把已确认目标、专业对象与知识、功能架构、逐部分方法、模块融合、最终接收条件和验证交接形成可执行方案。新建设计不编造旧版失败；重构时只有历史执行材料会改变设计才区分方法缺失、未加载、未执行或目标未达成。

完整设计沿用范围阶段读取的共享模型，以普通任务及各功能的真实输入、决定、转换、中间产物、下游消费和最终结果承载，不按坐标拆成平行目录。保留既有有效方法及局部差异，查明条件如何改变选择、功能之间依赖或冲突在哪里，哪些决定属于用户、哪些可由专业方法形成有条件的默认。目标能力的主文要把已选专业方法写成普通请求可执行的核心路径；专项 Reference 只深化独立条件，不替代主文。

创作和审美能力中，灵魂仍是目的/立场/宏观策略，筋骨是成熟专业法度，血肉是具体表现设计，表皮是符合读者、体裁、文化语境和媒介的真实成品；叙事尺度按所选方法另行判断，不与模型一一对应。全域诊断可从真实例子提炼候选机制；缺少可比成功/失败样本时，将机制边界或本地效果标为待查，不阻止已授权且可恢复的建设。按条件读取读者价值、语言成文和真实作品研究方法，并把所选内容接到实际生成步骤、成品位置及验收。复用专业来源或迁移规则时，继续遵循唯一规则表达 Reference。

## 综合表达、验证与交接

**原则句定方向，解释说清根据，动作让选择发生。**先让读者知道本项结论针对什么，再按其能理解的实际分析角度展开：每个重要角度保留具体材料、适用的判据/方法、材料关系及其如何支持本项结论；多个独立依据各自有真实信息贡献时分别讲清，再交代它们如何合在一起、产生什么影响或选择。单一材料足以支持时不凑角度。末尾用本项结论收束，不能把交点关系压成“综合来看”而丢失证据与推理。语言要让陌生读者看得懂对象、关系、专业选择、条件与动作；必要术语落到具体材料，不把坐标或内部检查结构泄露成用户必须填写的栏目。报告围绕用户此刻要理解、判断或决定的现实问题组织：用具体材料和适用判据说明结论为何成立、会影响什么选择，再交付本轮所需的方案、下一步与证据边界。逐项坐标、万能造梦框架覆盖表、逐格复述或标签附录若仅用于证明内部模型覆盖，交付前删去；只有用户明确要求检查模型如何应用，或当前任务确需映射比较时，才展示有关对应关系，且映射不能替代实质分析、结论和方案。

交付前把报告当成面向当前读者的实际成品再读一遍：能否一眼看出在解释什么、依据来自哪里、为何能支持结论、影响和边界是什么？核对简称和专业术语是否有本轮可达的理解承接；准确适用且真正帮助判断的术语应保留，缺少承接时补清对象、关系或最少必要解释，不把专业表达一律口语化，也不堆叠无助于理解的背景。坐标或标签是否保留按上段的用户需求与任务必要性判断；仅用于证明内部覆盖的内容必须移除。若一句话仍需读者替作者补上对象、关系或因果，就把那段分析依据写清。报告语言的问题只修报告表达，不冒充被分析对象的问题。

创作与审美原则句按用户选定的现代汉语诗学箴言风格表达，凝练而有方向；具体执行说明按 [runtime 的沟通与表达规则](../../../docs/runtime.md#沟通与表达)写清触发、解释、动作、数量、产物和例外。不要让原则句代替解释，也不要用机械禁令抹掉审美取舍。段落围绕一项判断，标题便于扫读，关键判断加粗，表格用于真实比较，不规定字数，也不把每节硬凑成一句格言。

交付深度依本轮产物决定：解释交付证据支持的范围和未知；方案或实施交接写明对象、核心动作、适用条件、顺序/依赖、保护项、负责人、产物和可观察验收。只有规则改进方案或写回交接需要给出真实控制位置、当前原句和可直接替换的完整段落，并说明怎样接入正常生成步骤及下游消费者。正向方法写材料、转换顺序与产物形式；“自然、清楚、信息密度”等只作成品验收，不能代替生成动作。

需要复现、旧行为对比、留出或方案走查时读取[必要试验与方案走查](references/validation.md)，按问题选择相称验证。analysis 可核对来源、检查非创作行为和走查方案，不制作创作结果充当样本；作品验证由目标执行 Skill 按最终文件实际产出。区分规则存在、实际加载、方法执行、方案可交接、下游行为和真实质量证据。静态检查或方案走查不证明行为，负责作者自评不证明独立运行；没有真实接收者或使用结果时，质量结论为未知。尚未解决的目标、方法或授权取舍只阻断依赖部分，其他工作继续。交接写明已确认依据、适用条件、保护项、实际观察、未知与下一步，不依赖本轮聊天才能理解。

## Reference 索引

**按本轮判断读取，读完返回对应工作阶段。**

- [调查、证据与方案比较](references/investigation.md)：解释、调查、原因判断、宽泛质量反馈或方案比较时读取；深化证据、机制、执行断点和媒介内动作，读后返回“还原对象、条件与源头决定”或“取得专业依据并形成解释”。
- [完整能力设计](references/capability-design.md)：完整能力设计分支选择新建、整体重构、扩大能力或用户明确要求端到端设计时读取相应方法，完成架构、逐部分方法和融合方案后回到综合交接。另当已选关键方法缺少适用输入、实际动作、产物、例外/失败处理或消费者，导致执行者不得不临场发明时，只读补足该缺口所需部分并回到具体方法决定；这项按需补缺不扩大为整体能力设计。已有方法的正常单次应用不读整份设计。
- [必要试验与方案走查](references/validation.md)：需要复现、对比、交接走查、质量评估或讨论证据等级时读取；人类标尺、正式校准及 AI 暂评按其中唯一协议处理，之后回到当前交付阶段。
- [真实作品研究方法的日常创作取法与方向](../../../references/exemplar-study.md#日常创作取法与方向)：判断依赖真实作品中的具体写法或用户要比较方向时读取；如果本地已有可核原作单元、做法及适用条件且无待核问题，复用而不为形式外搜；研究后返回专业取法或能力设计。
- [正式评估与 L/C/D/H](../../../references/exemplar-study.md#正式评估与-l-c-d-h)：仅在正式人类作品比较、标尺校准或样本集管理时读取；不替代日常取法。
- [读者价值与作品组织](../../../references/audience-value-and-structure.md)：仅当读者/观众/使用者要理解、感受或完成的事会改变能力目标、内容次序、篇幅或验收时读取；将相关取舍接入设计后返回本主文。
- [语言成文：从具体设计到可读作品](../../../references/language-realization.md)：仅当目标能力要实际生成或修订文字词句段时读取；把动作接到文字消费者，不代替领域方法，也不用于其他媒介任务。
- [规则表达与方法保留](../laohu-evolution/references/rule-expression.md)：运行规则更新、新建、融合或重构，或需转写创作表达与专业来源时，在内容对照前读取；按唯一真源处理语义去向与保真，再返回当前设计/方案阶段。
