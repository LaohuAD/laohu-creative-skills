# 老胡问题分析与方案设计

## 核心职责与边界

查明材料支持什么解释、哪个断点和未知会改变选择、可采取什么办法。可核读记录与来源、复现非创作行为、比较方案和完整设计。已知方法的常规执行归原负责人；未定且会改变行为的目标、方法或取舍在本入口形成判断。规则的定因、定法和规格按[三技能职责](../../../references/triad-handoff.md#1-三技能单一职责与交接红线)接到已获授权的 evolution 写回；生产修复、完整作品和后续成品归各自负责人。

承接已有材料或诊断时，按[以解决问题推进审查与分析](../../../docs/runtime.md#以解决问题推进审查与分析)还原其真实困难和有据发现，把校正用于深化原因和改法。按分析或解释需求交付，避免逐条反驳或用已有规则回避方法缺口。

## 确定本轮产物与范围

沿用已有目的、版本、限制、用户选择和保护项。分清事实、推论、观点、偏好、已选决定、专业方法、设计选择和未知；按证据限定事实，成熟适用的方法可作为有条件的选择。以已确认的质量目标、顺序和有效特征判断，预期效果和主题相关不能替代真实功能与质量。

读取[万能造梦框架](../../../references/universal-dream-framework.md)，按[分级深耕](../../../references/triad-handoff.md#3-万能造梦框架的跨入口接力与分级深耕)承担本入口的判断。接上游问题包先快核覆盖、证据和明显盲区，再深查问题及直接因果交点。把结果用于解释、分支、方案或设计。

| 当前需要 | 本入口推进到 |
|---|---|
| 只想知道材料支持什么 | 可核对的问题表述或证据相称的解释。 |
| 原因未定，解释差别会改变机制理解、结论把握、预测或下一步 | 实际观察、首选解释、关键替代解释及必要的最小区分证据。 |
| 目标明确、处理路径未定 | 关键差异、实际代价、依赖和有据推荐。 |
| 已知方法的一项正常应用或局部问题 | 给该项所需判断，沿真实直接依赖检查。 |
| 分析运行规则的更新、迁移或融合 | 判断最早控制点，给决策级变更规格、保护项与验收。 |
| 新建、整体重构或扩大可复用能力，或明确要端到端设计 | 进入[完整能力设计](#设计完整能力范围分支)，覆盖职责、方法、依赖、融合和验证。 |

## 还原对象、条件与源头决定

### 先界定接收者要理解或决定什么

核目标接收者、真实输入和重要关系，以及已定的立场、取舍、优先级与开放条件。分清预期产物、实际产物、用户反馈与本轮解释/方案。按实际证据记规则文字、加载、执行、成品和真实接收效果；每层支持其所见结论。复盘多轮时并看各阶段当时有效的要求、产物、具体改动、反馈和认可范围。旧加载/执行日志缺失就保留未知，不能以当前规则或最近一次改动推定历史过程及单一根因。

### 追踪本地材料如何支撑目标

1. 从可定位输入、状态、组成和结果追踪选择、舍弃、顺序、组合、转换和消费。标记重要条件、真实处理和观察；只有会改变解释、方案或范围的反例、未知或依赖才继续补查。
2. 判断“关键材料未提供”前核已读材料中的路径、链接、字段或记录选择器，沿权限内指针读取能改变判断的最小原件。输出截断补读，哈希只证身份。确实不可定位、无权或不可读时才限制相应结论。
3. 直接读取可见、可听、可操作的对象及其可达上下文。文字据所需核词义、指代、搭配、范围、否定、因果承诺和次序。是否有意留白、允许简称或多义，按用途、语境与职责判断。真实阅读、体验、点击或使用按相称接收资料判断；材料内关系仍可独立分析。

### 对照源头意图与真实规则

涉及规则判断、迁移、局部更新、新建、融合或重构时，先读[语义对照](../laohu-evolution/references/rule-expression.md#更新规则前按语义对照)与[表达意图第一关](references/investigation.md#核对表达意图是否在规则链中走样)。核实已选动作的触发、优先级、例外及力度，按实际材料定位立场、视角、声口、技法或有效动作的首处偏移。与原决定有分歧时另陈依据及代价。把真实位置、偏移作用和保护项带入变更规格。

## 取得专业依据并形成解释

先写清哪项判断需专业知识，再按其影响取相称本地材料或可靠来源的原意、范围、前提、反例，把方法落实为读取、比较、推演、计算、复现或其他检验动作。方法名、来源名气和数量不证明适用；知识缺口只限制受影响判断。选中或迁移来源时查实际片段、版本、顺序/依赖、前提、例外、参数接口和许可，记录采用/适配/有据替换/本地推导、控制位置和消费者；冲突按条件分开或明确裁决。

| 待判断的差别 | 读取并带回的结果 |
|---|---|
| 宽泛反馈、需要读出机制或在媒介内找到真正动作 | [会改变处理的判断](references/investigation.md#先找到会改变处理的判断)。把表现落到材料位置、收受者、判据、可能原因、区分动作、控制点和验收，已证项直接沿用。 |
| 证据性质不清，或多个解释会改变理解、把握、预测或动作 | [证据](references/investigation.md#让证据回答具体问题)及[区分解释](references/investigation.md#形成并区分解释)按需读。支持主要观察且有实据的不同解释即使暂指同一个下一步也保留，先拿最小区分证据；同义合并，无据纯可能性不列。已能交付有据、可恢复的下一步时不等唯一根因。 |
| 要区分方法缺失、首轮执行和后续指导的影响 | 读[八类执行断点](references/investigation.md#区分方法缺失与执行断点)。将首轮、当时规则/加载及指导修订并读，分清提醒旧动作、补出方法、适用条件和历史证据不足。 |
| 比较路径，或提出跨入口、共享规则及重要能力的修改 | 读[路径比较](references/investigation.md#比较路径并选定下一步)。先过硬约束，再比较收益、阅读、素材、实施、验证和返工的条件/代价；未知成本如实标记。规则改动按其中的生态扫描、负载和规格步骤交付。 |

需要复现、核旧行为、留出或走查时按[验证协议](references/validation.md)读取本轮小节；需要真实作品的独立行为由获授权的目标 Skill 按最终文件实际产出。把比较、调查及复现得到的观察与未知交回本节或交付，方案选择须说明哪些条件改变时要换法。

## 设计完整能力（范围分支）

只对范围表中的完整能力要求读[完整能力设计](references/capability-design.md)。按普通任务用专业方法安排实际输入、决定、转换、中间产物、下游消费和结果；各部分的条件、失败分支和接口围绕真实职责组合。主文须能指挥普通请求，专项 Reference 深化独立工作。创作原则、技法、具体表现、实际作品与不同叙事尺度按所选方法区分。方向覆盖按框架实查，交付按实际职责组织。

已有方法缺适用输入、动作、产物、例外/失败处理或消费者时，只读补缺所需部分，不必升级为整建。完整改造依赖的关键选择仍未知时只暂停受影响部分。保留有效旧方法和局部差异；用户已选升级目标、可靠方法或可证缺口支持推进时，不以反复失败作为前提。缺可比材料只限制边界和效果结论。

## 综合表达、验证与交接

1. **说明已证关系。**报告先交代对象、结论与现实影响，再说明每项实际材料、适用方法、关键条件和连接理由。多项独立依据分别写明再结合影响；单项足够不凑角度。只在用户明确需要或映射有真实比较作用时展示框架关系。
2. **回核成文及可交付对照。**写说明、比较、方案、诊断和交接时，按[成句](../../../references/language-realization.md#成句把表达动作写出来)和[成段](../../../references/language-realization.md#成段让句子共同完成一项工作)核报告的完整意思、目的、态度、次序与材料。专业词需要时落到眼前关系或补最小解释，报告文字问题不冒充对象问题。依据适用判据确认已读材料的具体差距后，按[报告内局部对照](references/investigation.md#把已确认差距落实为报告内的局部改后对照)默认在报告给同材料实际改后，须回查语义和首个下游。
3. **把方案接到负责人。**写明对象、动作、条件、顺序与依赖、保护项、负责人、产物和可观察验收。涉及规则改动按[决策级变更规格](references/investigation.md#交付规则的决策级变更规格)给实际控制位置和新逻辑，按 [AUDIT-ID](../../../references/triad-handoff.md#2-统一追溯主线audit-id-交接契约)交已授权实施；仅用户指定精确补丁或不经 evolution 的独立实施者时附完整原句级替换。规则规定的动作须比成品质量词更具体，诗学原则句与执行语体按[规则表达](../laohu-evolution/references/rule-expression.md#从目标关系提炼原则)处理。
4. **注明验证条件。**按[验证协议](references/validation.md#先说清要证明什么)交付证据范围和未知。静检、走查、自评、独立执行和真实接收各证其所及。核心方法、目标或授权未决时只暂停依赖部分；交接可独立阅读，不需上游聊天补关键事实。
