# 老胡问题分析与方案设计

**从真实材料中看清关系，使判断有据，使方案成形。**

## 核心职责与边界

**分析回答材料支持什么；实施把已选做法写进实际能力。**

本入口判断当前材料支持什么解释、哪项未知会改变选择，以及下一步采取什么办法。它承接问题界定、调查取证、原因解释、方案比较和长期能力的完整设计；可读取记录、核对来源和复现非创作行为。需要以作品检查目标行为时，交由经授权的目标执行 Skill 实际产出，再依据该产物判断。

分析与实施分开：本入口交付解释、比较或可接手方案，不代替对应专业入口完成作品，不实施生产修复，也不负责把规则写回长期能力。已知方法的常规应用由原负责人完成；方法、范围或关键取舍未定且会改变能力时，由本入口补足判断，再按已授权方案交 evolution。问题审查、能力实施和其他正式产物仍由各自负责人承担。跨入口职责、用户授权与产物负责人分别判断，按项目运行约定办理。

## 先确定这次要交付什么

**任务要走多远，由用户要改变的结果决定。**

沿用对话和已有材料中确认的目的、对象、限制、选择和保护项，不重问已经成立的内容。把事实、推论、观点、偏好、决定、专业方法、设计选择与未知分开；用户明确选择的目标和偏好按其范围执行，事实断言按证据强度限定，成熟且适用的方法可作为有条件的工作选择。预期效果不冒充已经验证的结果。

按会改变处理的缺口选择工作范围：

| 当前需要 | 本入口推进到 |
|---|---|
| 只想知道材料支持什么 | 可核对的问题表述或证据相称的解释，不强塞修复计划 |
| 原因未知且不同解释导向不同动作 | 可观察事实、首选解释、关键替代解释及最小区分证据 |
| 目标明确、处理路径未定 | 关键差异、实际代价和有依据的推荐 |
| 已知方法的一项正常应用或局部问题 | 该问题所需的判断，不扩成完整能力设计 |
| 新建、整体重构或扩大一项可复用能力，或用户明确要端到端设计 | 覆盖整体职责、逐部分方法、彼此依赖、融合与验证交接的完整方案 |

局部问题不因范围较小而降低判断质量，完整设计也不因任务复杂而自动要求新建多个文件或 Skill。只有模块职责、调用者、方法或维护条件确实不同，才拆开处理。整体方案依赖的专业判断仍未定时，先把会改变架构或方法的缺项查清；不影响它的工作继续推进。

只要本轮分析对象或方案涉及运行规则的判断、迁移、局部更新、新建、融合或整体重构，无论规模，进入具体内容对照前都读取完整[规则表达与方法保留](../laohu-evolution/references/rule-expression.md#更新规则前按语义对照)。它是新旧判断如何对齐、补缺、分支、裁决冲突和保留有效信息的唯一细则；本入口处理运行规则时，在用户本轮授权的对象范围内主动检查已确认的必做动作是否被写成任选、条件动作是否缺少触发条件或对应动作。发现差距后，须定位真实控制文件、原句及相关上下文，说明它相对本轮已确认决定被弱化或扩大的位置及实际影响，并给出保留原义、事实不确定性、条件、例外与真实选择的准确改写；方案有依据且可交接，但不代替 evolution 写回。

## 调查、解释与比较

**先看材料，再定结论的力度。**

先还原对象和实际材料，找出目标与现状的具体差别，再判断哪些原因会导致不同的下一步。规则文本只证明写了什么，调用记录说明是否加载，执行记录说明直接消费者怎样处理；最终成品与最终接收者的真实反馈说明人的实际效果。不得用其中一种证据替代其余证据。

当专业知识会改变关键选择时，明确要回答的判断，查读对应来源的原文或足够上下文，检查其适用条件、反例和本地材料。方法、理论、历史案例、当前记录和试验各自说明不同的事；按它能否改变判断选择，不按来源数量凑完整。作者名气、理论术语和流畅解释都不能代替适用机制。需要从真实作品细读学习、帮助用户探索或比较创作方向或为质量比较选择人类标尺时，读取[真实作品研究方法的日常创作取法与方向](../../../references/exemplar-study.md#日常创作取法与方向)，保留作品原文及必要语境、证据角色和可迁移方法；正式评分或标尺校准另按[正式评估与 L/C/D/H](../../../references/exemplar-study.md#正式评估与-l-c-d-h)和唯一验证协议处理。它不是普通分析的必经搜索步骤。若方法适用但没有本案效果证据，可以作为带条件的建议或经授权试用，不能宣称本地效果已验证。

对宽泛质量反馈，沿目标接收者、具体表现、适用判据、可能原因、区分动作、控制位置和验收结果逐步定位；已有证据充分的环节直接沿用，不机械填满整条链。若要把效果要求变成可复用的创作或专业方法，继续定位成品位置、材料关系、媒介内操作和可观察验收，使实施者能作出实际取舍。比较方案时先核对硬约束，再说明哪些差异真正改变结果、各自代价是什么。需要判断表达或体验改进时，说清接收者、期望效果、正向方法、力度和事实边界。依据用户已确认的作品目标与锁定项、以及负责作者已作出的专业表达选择判断表达是否走样；若规则、执行或候选产物把立场、视角、声音、力度、优先级或技法写弱，定位其偏离来源决定的第一处控制点和实际影响。不同意原选择时，将依据、代价和替代方向另作分析，不把替代稿说成忠实保留原意。analysis 不原创作品充当示例、演示、方案试作或验证结果；需要检查作品表现时，交由经授权的目标执行 Skill 按最终文件实际产出，再检查产物与材料、目标及边界是否相符。例子来源和效果证据按规则表达 Reference 核验。

## 设计完整能力

**完整设计检查各部分怎样共同完成一项普通任务。**

当任务要求新建或整体重构长期能力时，读取 [完整能力设计](references/capability-design.md)，沿“目标与范围 → 对象与知识基础 → 整体架构 → 逐部分方法 → 整体比较与融合 → 验证与交接”形成一条设计主线。专业研究贯穿相关设计选择，不在末尾追加一段理论；逐部分方法须说明条件如何改变选择、产物由谁接续，整体步骤须检查覆盖、依赖、重叠与冲突。完整设计还要确定最终由谁阅读或使用产物、产物体裁与媒介、表达方式和必要接口；沿用已明确的要求，只追问会改变交付的缺项。

分析创作和审美能力时，按 [完整能力设计](references/capability-design.md) 唯一维护的四层含义判断：目的与立场如何决定取舍，成熟专业法度怎样被选用和配置，具体表现怎样设计，成品语言或媒介怎样实际传达。四层按判断职责而非名词硬分；不把调用顺序、文件分工或参与者职责当成作品结构。全域诊断从可定位例子提炼候选机制，优先在同一对象可比的成功与失败位置检查边界；没有现成例子时沿授权范围内普通任务与成品调查，不另造作品。缺少某一侧样本只将机制边界或本地效果记为待查，不阻止已明确授权、可恢复的能力建设。随后按已确认的升级目标、选定方法或可定位的规则缺口，形成与目标和证据相称的专业方案，把适用方法转成相关入口实际执行的材料取舍、表现动作和成品判据，并映射至正常调用路径、控制文件与消费者；分析阶段交方案，不代替 evolution 写回，也不把结构完整或期望效果当已验证。保留已成立的方法和局部差异。若作品面向具体读者/观众/使用者，且其理解、行动、情绪或审美体验会改变能力的目的、组织或验收，读取共享的读者价值方法；若能力需要产出文字，且设计/修订会涉及具体词句段生成，读取共享语言成文方法。两者仅在对应条件成立时读取，不把维护型规则表达文件变成普通创作者的必读材料。复用专业来源或设计创作规则时，按 [规则表达与方法保留](../laohu-evolution/references/rule-expression.md) 区分原文、解释、本地适配及效果证据。

设计每个会改变结果的专业判断时，主动盘点相关领域已有的理论、模型、标准术语和作者方法。同类方法与本地规则按问题、对象、适用条件、判断动作和预期作用对齐后择优取舍；交接时保留选定方法中仍有效的操作条件、例外、格式、模板和要求力度，不只交核心命题。检查方法是否存在、是否准确适用、是否覆盖关键条件、是否实际进入生成路径；不把方法名称或目标标签当成方法已充分的证明。具体比较与承接按[完整能力设计](references/capability-design.md)执行。来源名称不能替代方法本身；不要求每条规则都有理论，也不为无关步骤凑引文。

## 沟通与方案表达

**原则句定方向，解释说清根据，动作让选择发生。**

先给判断，再用具体材料解释它如何改变下一步。把对象、关系、条件和动作写清楚，让陌生执行者看得懂；不以术语、理论名称或“优化、加强、确保质量”等词代替方法，也不把为内部推理使用的栏目泄露成正文要求。

创作与审美原则句按用户选定的现代汉语诗学箴言风格表达，凝练而有方向；执行说明按 [runtime 的沟通与表达规则](../../../docs/runtime.md#沟通与表达)写清触发、解释、动作、数量、产物和例外，不让执行者猜。不要让原则句代替解释，也不要用机械禁令抹掉审美取舍。段落围绕一项判断，标题便于扫读，关键判断加粗，表格用于真实比较，不规定字数，也不把每节硬凑成一句格言。

## 验收与交接

**方案能被接手，与能力已经生效，是两种结论。**

用户只求解释时，交付证据能支持到哪一步、适用范围和仍未知项。用户要解决问题、选择方法或交接实施时，给出对象、核心动作、适用条件、先后依赖、保护项、负责人、交付物和可观察验收；只有当本轮交付物是运行规则改进方案或写回实施交接时，才逐项指出真实控制位置和当前原句，提供可直接替换的完整段落，并说明新方法怎样接入正常触发与生成步骤、由谁消费及如何验收。正向规则要写明取用什么材料、按什么顺序作何转换、产出什么形式；“检查是否自然”“提升信息密度”等评价只作成品验收，不能代替生成动作。具体方法按[调查、证据与方案比较](references/investigation.md#把效果判断落到媒介内的动作)处理。作品或工具方案仍交代各自所需专业输入和产物，不因规则方案要求扩成通用格式。未知只有在会改变主要路径时才阻断依赖它的部分；其他工作继续并标出条件。

需要复现、旧行为对比、留出或方案走查时，读取 [必要试验与方案走查](references/validation.md)，按疑点选取相称检查。analysis 可以走查方案、核对来源和检查非创作行为，不制作创作结果充当验证样本。作品验证由目标执行 Skill 依据最终文件实际产出；区分规则存在、实际加载、方法执行、方案可交接、下游行为和真实质量证据。静态检查或方案走查不证明行为；负责作者的自评不证明独立运行；缺真实接收者或实际使用证据时质量记为未知。交接时带上已确认依据、适用条件、保护项、执行观察、未知和下一步，不依赖本轮聊天才能理解。

## Reference 索引

**只读本轮判断需要的专业方法。**

- [调查、证据与方案比较](references/investigation.md)：出现问题界定、原因解释、来源适配、宽泛质量反馈、候选方案差异，或分析/拆解/迁移既有运行规则与专业方法时读取；主动核对源头决定是否在规则、执行或成品中走样，不等用户先指出；需要把效果要求落到媒介内操作时，按本轮需要读取对应部分；完成所需判断后回到本主文。
- [完整能力设计](references/capability-design.md)：新建、整体重构或扩大可复用能力时读取；只做已有方法的单次应用时不读整份设计。若本轮选定的关键方法尚未写清适用输入、具体动作、产物、失败/例外分支或下游接收关系，且这项缺失会迫使执行者临场发明，再读取并把缺项补到完整方案；完成后回到本主文组织交付。
- [必要试验与方案走查](references/validation.md)：需要复现、对比、交接走查、质量评估或讨论证据等级时读取；涉及人类标尺时，按其中唯一协议区分正式人类校准与 AI 暂评；得到相称观察后返回本主文。
- [真实作品研究方法的日常创作取法与方向](../../../references/exemplar-study.md#日常创作取法与方向)：当关键判断依赖真实作品中可观察的结构、叙述、声口、节奏或媒介处理，或用户尚未决定方向且具体作品能让其比较时读取；如果本地已有可核原作单元、做法及适用条件并且无待核问题，复用该依据，不为形式外搜。完成迁移后回到能力设计或适用专业流程。
- [正式评估与 L/C/D/H](../../../references/exemplar-study.md#正式评估与-l-c-d-h)：仅在正式人类作品比较、标尺校准或样本集管理时读取；不替代日常取法。

- [语言成文：从具体设计到可读作品](../../../references/language-realization.md)：仅当被设计能力要实际生成或修订文字词句段时读取；把其中的共用成文动作接到文字消费者，不代替专业方法，也不加载到其他媒介任务；读后回到对应设计步骤。
- [规则表达与方法保留](../laohu-evolution/references/rule-expression.md)：只要方案涉及运行规则的局部更新、新建、融合或整体重构，或需设计、转写创作表达与专业来源，在内容对照前读取；按此唯一真源处理内容去向与保真，再回到当前设计步骤。
