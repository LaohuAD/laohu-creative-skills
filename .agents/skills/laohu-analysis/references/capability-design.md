# 第一性原理能力设计

由 [laohu-analysis 主文](../SKILL.md) 在新建、整体重构或重大扩域可复用能力（Skill / 工作流）时读取，完成后回主文交付设计；局部补缺只读对应小节，不升级为整建。

设计一项能力只有一个终极标准：**在不束缚前沿强模型原生能力的前提下，靠高杠杆专业方法和清晰契约，稳定产出超越纯原生模型（A）的真实成品。**

## 第一步：借万能造梦框架定本质标尺（灵魂 × 表皮）

读取[万能造梦框架](../../../../docs/governance/universal-dream-framework.md)，沿 4×4 十六交点对目标能力做一次全向 X 光透视，锚定三件事（16 交点是设计者的思考坐标，交付时按领域自然工作语言组织，不强搬 16 个死标题）：

1. **它服务谁、对标什么殿堂级特征、如何三态裁决输入？** 用典型普通口语定义真实入口、最终接收者与明确退出边界；凡创作与规划类能力，先立清**本领域经时间与数据验证的殿堂级核心特征**，并定清三态输入裁决——尊重并做透用户同向独到的好方向、对模糊愿望主动按殿堂级补齐、对偏离殿堂级本质的粗糙字面输入抽出不变核心情绪与事实底线换血带回正道。
2. **辨清四类工作形态，立对专属标尺（绝不拿同一把尺子绑死全部能力）**：
   - **直出作品类**（文章、小说、剧本、歌词、标题等，文本即终稿）：核心在殿堂海拔、独特切口、情感电压、活人母语呼吸与脱标风格辨识——最怕事前填字数独、满屏禁令与冷硬架构词。
   - **提示词中继生成类**（生图、视觉资产、封面出图、AI 视频、AI 音乐/声线等，文本是跨模型媒介）：核心在把终端殿堂视听要素按灵魂定调 → 筋骨构成/时序 → 血肉可渲染物理细节 → 表皮模型友好编码无损转译，**严禁拿提示词文采冒充成品，必须以真实渲染物验真并沿四维反查断点**。
   - **上游规划简报与诊断判断类**（前置 `brief`、选题、故事构思、找茬、深度分析、拆解）：核心在为最终殿堂级成品锁死方向与骨架、直击最早杠杆断点、坦诚给立场与代价，且交接给下游的简报保持纯净白描防反向污染——最怕走形式填表与四平八稳官僚腔。
   - **确定性工程类**（归档、脚本工具、格式编译、发版更新）：核心在零歧义接口、安全授权闸门、幂等可恢复与自动化测试——必须严守确定契约。
3. **优先级、表皮呈现三分轨与不可突破的保护项**：区分不可违反的硬约束（安全、授权、写实事实底线、合法逐字锁定项、机器接口）与开放给模型发挥的创作空间，冲突时明确优先级；并按 `docs/runtime.md` §4 明确该能力的**表皮呈现三分轨**——中间态给人类拍板用清晰标题层级/分条/对比表/推荐排序与重点加粗让人 3 秒扫清，下游交接守洁净定式，最终作品本体严守媒介原生格式与用户明确的固定输出格式硬契约、绝不掺过程废话。

## 第二步：对照纯原生 A 除限减负 + 瞄准原生短板升维增优（筋骨 × 血肉核心取舍）

光靠删减瘦身还不够，把规则写厚更会让 B 输给 A。逐项筛查所有既有规则与拟新增方法，完成**除限**与**升维**两刀：

| 区域 | 判据 | 设计处理 |
|---|---|---|
| **原生强项区（坚决除限减负）** | 删掉或放宽后，当今前沿强模型纯裸跑（A）就能做得同样好甚至更自然、更有灵气（例如基础逻辑常识、常规写作结构、微观选词/句长硬限制、老模型防呆补丁、过度防御否定墙） | **果断删或松绑！** 删前先辨明每条旧规则原本防的是哪类真坑——确属旧模型防呆才删，若是领域真实暗坑且强模型仍易失手，应提纯升级而非盲目误删。 |
| **原生短板与升维区（精准增优）** | ① 纯原生 A 在这件事上真正容易偷懒、讨好、套路化、编造写实证据、遗漏硬伤或达不到专业品味的真实短板；② 原文档里虽本身没错但抓手不够有力的弱规则；③ 原文档压根没想到、补上即显著拉高成品价值的新维度 | **重点打磨与替换！** 写入更高杠杆的判断维度、反直觉自检抓手、稀缺品味锚点或领域核心机制（落到真实材料怎么选、怎么比、怎么改，不留更有质感、更专业这类空词）。 |
| **硬契约区（零歧义守门）** | 权限与落盘边界、脚本 CLI 参数、JSON Schema、跨入口交接格式、**用户或领域明确约定的固定输出格式契约**、路径与仓库校验规范 | **确定写死！** 写明唯一真源、触发条件、失败处理与停止点。 |

- **冷热知识硬分界（核心判断原理宁精勿滥留本层，出处细分归 `SOURCES.md`）**：凡真正改变日常裁决、支撑跨题材迁移的核心原理全部显式留在本层运行态（能用锋利本土实战机制说透时不硬凑学者人名表，绝不把原理抽空锁进平时 0 加载的 `SOURCES.md`，也不因人为卡条数把跨体裁通用原理错塞进单一子技能）；外部出处、版本核验、文献细分与实战示范脱敏溯源统一归 `SOURCES.md`。
- **对抗均值权重与双向提示词引力（殿堂定音 + 物理换血 + 活人语法）**：涉及审美上限或面对琐碎粗糙输入时，优先设计**殿堂真品先行定音**（借 1–2 部真品校准海拔与呼吸后立刻合上对标换成本作血肉）、**正向五维筛材与物理换血**，以及**极薄白描无形容词交接卡片**（既隔绝粗糙原始词的正向引力，也隔绝散文详案简报的反向污染）；文字短句与强位收口（标题、封面、歌词、金句）优先采用**真话语序、实词承重与逆向先定实词落点**，防自回归句尾截肢与伪古风压扁。
- **破第一反应套路与保护锋芒**：设计创意传播类能力时，显式保护合法心理钩子、隐喻、高张力锋芒与教学故事演绎（抵双向之雅，既去粗鄙也破防御性文雅），仅对冒充写实证据的编造设红线；把省出的篇幅押在打破强模型第一反应均值套路的贴地自检上——按工作形态落为挑剔真受众的直觉发问（直出类查切口不可替代、现实因果自洽、去饰验骨与终局余韵；中继类查四维物理可渲染与零冲突；规划类查直击核心取舍与防走形式），并指导将用户锁定硬设定无痕融入成品。
- **严守语体同构与两阶段解耦**：创作类 Skill 正文必须写得像顶级真人主编/导演当面点拨，绝不把定盘、压测、闭环、偏移、标尺等冷硬系统架构词搬进下游创作规则；高潮定生死的品类优先走**爆点与铺垫两阶段解耦**，协同留白媒介守 **80/20 素底点睛**，绝不堆装饰引号、生猛怪比喻或高频示范锚词。
- **对外极简不砍后台轻支点，放飞与修疤物理分离**：砍掉发给用户的冗长问卷与动笔前几十条填字数独（非物理硬上限不设死数字牢笼；核心母体集中绝不写死成只准 1 个物件的新配额），保留后台 2–3 个定魂定骨轻支点先放飞成活稿，将声律、排版、细节核查全部后移为成稿后轻度扫疤，严防雕刻伤气。
- **方向约束与细节自由（视觉与创作资产通用）**：先定用途、感受与宏观方向，不把完整写成无论用途都填满纹样/缝线/尺寸/坐标；微观精控仅由明确精控要求、已定资产复现或剧情关键识别触发，且未确认的 Agent 探索建议不自动升级为用户定案。

## 第三步：设计四层非对称架构与上下文预算

1. **四层非对称分工、热路径极简与按需挂载（减负不压扁核心骨架）**：
   - **严格单一真源、各守一层绝不复读**：二级 `SKILL.md` 主文负责跨体裁通用海拔底盘、核心原理标尺与路由；`references/` 只放按需触发的高杠杆深工艺与扫疤细则；个人口味拆进随时让位当轮要求的 `knowledge/` 偏好文件。
   - **三级子技能聚焦专属机制**：内部子 Skill `skills/<child-name>/SKILL.md`（区分选择型专项与父级方法模块，遵循[项目检查与版本维护](../../../../docs/maintenance.md#skill-命名层级与部署结构)）直接承接二级底座，不复述通用原理、护栏与自检，而是聚焦**本专项独有机制（理论标签宁精勿滥）、行当现实逻辑、高潮递进校验与专属风格锋芒**（以摘掉流派标签能否第一眼盲辨作验收）。
   - **严防过度压缩伤及下游实战力**：减负砍的是废话、微操与学术词表，**绝不把双目标/双受众冲突时必须明确主次或拆题、不做两头落空折中的硬裁决，或按不同起点交付的可直接接手结构压扁成一段笼统长句**；每条高杠杆手法标明媒介体量与题材适用边界，防止被单一热门体裁染味。
   - 严禁将垂直业务特例或仓库维护条文塞进日常必读热路径。
2. **上下文与认知复杂度预算**：
   - 固定 1 条典型请求与 1 条近邻切换请求，核算改前与新架构的**去重必读文件数、总字节、超 300 字多条件文字墙数量与跨文件跳数**；
   - 保证同一判断只有唯一真源，严禁用把文字墙搬到另一个同样必读的文件来制造减负假象。
3. **代表性走查与决策级交接**：
   - 用真实普通口语请求走一遍全链：加载前 `description` 判断 → 主文核心决策 → 按需挂载 → 产物形成 → 下游消费 → 退出，再改变 1 个关键条件核对分支切换是否灵光；
   - 按 [investigation.md](investigation.md#5-交付规则的决策级变更规格) 形成清晰交接规格交给 `laohu-evolution` 落盘，并标明方案走查不代替最终文件的独立运行与盲测验证。
