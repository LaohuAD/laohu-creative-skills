# 写作前的内容设计

承接 Writing 通过 [Analysis 主入口](../SKILL.md) 委托的前置设计或局部分析。调用方带读者/听众、媒介、目的、材料与原稿、授权范围、作者已确认的立场、声口和锁定项，以及仍有效的研究与设计。若作者说过、认可或拒绝过有参考价值的句子，保留原句和位置，注明它的确立作用或实际问题，供成文时判断。

完整委托先把中心认识、事实与证据关系、承重材料和主要结构做到可成文。局部委托从失效或待定的判断起步，已有可靠设计直接复用。能独立起草的单元可继续，缺论据的判断按证据范围收窄或暂停。Writing 依据当前授权成文并终审。

## 先确认本篇要交付的认识

先落实文章主要回答什么，给谁新的理解、体验或操作结果。核读者熟悉的对象、使用情境、真正要懂的关系和可能卡住的前提。保留原稿或作者输入里已经成立的观点、态度、亲历、说法和声口。区分作者已确立的认识与尚开放的组织选择，也区分材料事实、外部判断、编辑推论与未知。

技术、行业和商业材料先定承诺范围。解释行业结构时，把构成、上下游或机制讲清。只有作品明确承诺行业参与或商业路径时，才查谁有具体需求、现用办法和代价、付费条件、所需能力和资源、实际门槛、交付与收益怎样形成。行业增长或岗位存在本身不足以支持个人收入路径。面向行业外读者时，另核目标读者所需的能力前提、材料支持的现实选择和还要查什么。材料不足时删缩相关承诺。

## 调查会改变判断的事实

把可能改变中心主张、读者选择或关键机制的未知整理成可核的问题。依事实的重要程度和时效选相称来源并按授权调查。优先检查对象、条件、过程、需求和实际结果。来源已能支持判断时直接使用。每项承重事实要能追到实际出处、适用时间、对象和条件；来源结论、预测、亲历和价值判断用各自证据边界。

来源冲突时，先核时间、定义、被研究对象、方法和使用条件。条件不同就区分适用范围，同条件互斥再补查可区分它们的证据；未解时收窄依赖它的主张。调查停止在能定下主张范围、承重证据或必要限制，缺证部分明确交回。用户授权范围之外的核查不强行开展。

## 把材料接成可追踪的判断

对承重判断交出主张、根据以及事实中的什么特征支持或限制它。可用图尔敏方法核对，在条件变化、推论跨度大或有关键反例时补适用条件、支撑或异议。作者有立场时保留材料足以承载的观察与取舍。编辑推论另标身份。确认各单元真的因材料而形成因果、证据与主张、比较、过程依赖、时间变化、并列或回返。时间先后和同一话题只提供组织线索，须另有材料支撑因果和递进。

## 选择材料和讲述办法

挑选能完成当前读者任务的材料和呈现关系。解释对象变化时可跟随过程，判断组成或上下游时按角色交接，比较则核对对象、任务、尺度和条件。故事采用真实处境、选择和后果，经授权的假设清楚标明；修辞中的反差依材料或设定形成可辨预期。类比应对应真实关系并回到解释对象。

把可用原话及位置留给 Writing，注明那句话承载的态度、变化或认识。相近判断归并到主展开位置，后续用新的证据、条件、应用或可辨节奏继续推进。内容选择可给多种成立的讲述办法，文章章节、口播听觉组织、用词和气口由 Writing 按实际媒介决定。这里选好足够成文的材料与关系，Writing 接回后再落实体裁。

### 前置检查视觉和实操素材

找一遍成稿中可能要求读者辨认、比较、追踪或核对的地方。记下精确锚点、读者需要知道什么、素材当前状态和可用于此处的关系。优先指出会改变理解、操作或承诺的缺口。

- 真实操作态需要知道当前版本、页面状态、字段或成功反馈时，标已有截图、需授权实采或当前只能发采图单。
- 层次、分支、跨角色关系和复杂流程若需同时比较或追踪，标可用于图解的有据命题及关系条件。
- 同尺比较、字段和命令写明需可复制的原值；可复用表格或代码块时交原件位置。
- 体验依赖真实人物、场景或证据时，标出素材身份、能证成的范围及缺项。

记在内容设计包里；无需画图也无需启动与当前授权无关的制作。Writing 根据实际读者任务决定图文载体、制作权限和是否出实图。

## 交给 Writing 足以成文的设计

交给 Analysis 主入口核对后，在同一任务上下文返回 Writing。依据真实复杂度交轻量内容设计包；已有资料可在交接中引用。只有用户或实际协作明确需要文件时才按项目约定保存。

| 设计项 | Writing 接收的判断 |
| --- | --- |
| 读者、媒介与本篇承诺 | 希望谁看清什么，正文实现到哪一步及哪些延伸暂不涉及。 |
| 中心判断、事实及证据界限 | 可发表的主张、关键事实出处、材料为何支撑或限制它、已知条件和未决问题。 |
| 主要单元及讲述办法 | 各承重单元展示、解释、论证、呈现选择或交付动作的具体作用。列实际材料、顺序依赖、开头兑现位置和自然落点。 |
| 视觉与实操截图资产建议 | 准确锚点、读者动作、关键信息、已有或仍缺的可核资产、需要验证的版本/状态。没有必要图文时直接留空。 |
| 保护项和开放空间 | 锁定标题、主张、作者原话及声音证据。标出待决定问题、可完善的组织和可自由选择的成句。 |

普通背景或短过渡由相邻单元解释即可。若设计只列内容名词，补出材料怎样让接收者看清过程、关系、条件或选择。关键事实、作者判断和内容设计充分后交还 Writing，写成实际段落。新出现的词序、段落轻重、普通衔接由 Writing 处理。

## 接收成稿反馈并局部更新

通过 Analysis 主入口接收实际文字位置、原决定、证据、受影响范围，以及前后已经成立的原句或锁定词。局部补桥时，沿用两端已经确认的称谓、身份、动作、所评价或接收的对象和适用范围。材料没有确定指称时保留原有称谓，另一个例子须有独立证据才能用于确认指称。

查材料支持怎样的承接，交回插入或改动的位置、可用根据及两端的保留基线。材料只足以支撑相关理由时说明限度；缺少推导根据时把结论保留在证据能支持的范围，让作者愿望仍作为愿望表达。

若 Title 的开放探索带来可能改变主张、论证或全文组织的认识，接收 Writing 核过的实质修改范围、新旧主张和直接依赖。一项新表达是否足以改变主张，由原材料、推导和授权共同决定。

回到最早需要改变的事实、证据、推导或组织条件，明确原判断为何推进、收窄或保留。核直接依赖的段落、开头承诺及结尾结论，已有成稿中经核仍成立的关系和保护项继续用。Analysis 达成局部判断后返回可执行的修改位置与材料。Writing 负责实际改稿、关键句嵌回并终审。仅声口、搭配、顺序或气口问题直接交还 Writing。
