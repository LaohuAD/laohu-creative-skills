# 剧本前置设计

由 [Analysis 主入口](../SKILL.md)承接 Script 的完整新作、复杂口述成稿、整体重写或核心因果、人物重塑委托。复用用户的灵感、原稿、已确认构想、选定方法与停点，把会决定成片的体验、事件因果和人物选择设计到能写，交回 [Script](../../laohu-script/SKILL.md) 分场和成稿。用户只指定一项设计时按该项执行。续用已确认的 Story 构想或设计时，只补影响当前写作的时间线、人物决定或声口等缺项。

先分清用户锁定的情节、关系、原句、媒介与风格，和授权作者决定的空白。记录哪些旧场、交锋、反转、知情时点与情绪力度已有作用。作者用这些材料推演可以落到成片的安排。专业取舍明确且可恢复时，当轮决定并交回；只有用户保留的关键方向仍有实质冲突时，按[运行约定](../../../../docs/runtime.md#关键决定不靠猜测)处理受影响部分。

## 把口述恢复成能发生的时间线

1. 从口述、旧稿或既定结局挑出会改变结果的事件。将前置准备、早已发生的变化、已存在但未被人物知道的线索，与本集现场实际发生的行动分开。对每个承重变化写清何时已有条件、何时有人能行动、何时产生后果、谁在何时能知道。口述用一句话跨过的等待、往返、确认、递送或积累，按作品规则和场景实际耗时复核；并行事件说明各自依赖。
2. 从终局选择、必须付出的代价、关系变化和结算倒推所需铺垫，再按时间正推人物如何从一个处境走到下一个。逐一检查行动之前的条件和证据是否已经在位，现场能做完哪一步，当场变化够不够支持下一决定。超出现场时间窗时，把准备或手续移回合理时点，让现场承担真正需要在场发生的触发、结果或揭示。保住已锁定事件；涉及关键现实事实时按[承重事实核查](#查会改变写法的承重事实)补证。
3. 先定故事中事件真实发生的顺序，再定观众按什么顺序看见。把作者知道、人物已证实或暂以为、观众已经看见的材料各落到事件和时点。叙述可以留谜、倒叙、按关系并行或打破时间顺序；需取结构方法时依[故事形态](../../laohu-script/references/narrative-and-structure.md#结构形态如何适配故事)和[叙述视角与知识](../../laohu-script/references/narrative-and-structure.md#叙述视角知识与信息路径)选用，遵守用户已定形态。

### 核两方为什么都要走到这里

从各自位置复走一次主角和主要阻力方的决定。各自掌握什么、能调动什么、想守住什么，以及当时能选哪些实际办法？分别代入一个合理的替代行动，查清人物为什么仍会选择眼前这一步。如果已有信息和资源就能达成目标，明确这次到场或交换到底还要改变哪件事。若相对方另有可行选择，找出为何此时会拒绝、等待或改口，以及观众能在哪看出这个条件。必要时修正最早出错的知情时点、目标或限制，并顺推到后果。

例如口述把清空老屋、联系搬运和在新家布置都挤在交钥匙前五分钟。将整理、约车和打包安排在交房日前，把最后五分钟留给父女处置旧柜和交钥匙。女儿早已量过，新家放不下柜子。她赶回老屋是为了接上仍守在柜前的父亲，打电话催他已经催过三次。父亲有力气起身，却舍不得柜侧那三道给孙女刻的身高。他看见女儿带来一条空木尺，请他亲手把三道记号挪过去，才接过笔并交出钥匙。两人此刻各有能做的选择，现场改变的是他们一同离开的条件。

## 找到能拍到的情感支点

从最终观众要体会的关系、代价或变化出发，确认本集或全片提出了什么问题，会给出哪种兑现。完整设计选 2–3 个可拍的生活细节承接“冷淡”“亲情深”“依恋”等印象，例如留下什么物件、向谁保留什么习惯、面对哪件共同经历会下意识做什么。选能体现两个人怎样相处，又能在后来改变行动或含义的细节。以共同生活中的真实行为支撑感情，测试本事或处理线索的动作仅在它本身也写出了关系时承担这一作用。

用关键事件画本集或全片的情绪走势。选定观众的起始期待、关系或情境的温差、足以改看前事的揭示、人物付出代价时的情绪峰值，以及结尾兑现或引出的具体问题。按片长、体裁和用户选定的强度安排升落。每一个关键转折写出观众之前相信什么、片中将给他看到或听到什么、由此在等什么。保留已经好用的误会、停顿、接招和反击，给 Script 留出写足对手之间来回变化的空间。成片的具体分场、声音和动作由 Script 落实。

## 建立人物底色与声口

只为影响行动、阻力、知情、关系或结局的人物确定内核。沿用 Lajos Egri 在《The Art of Dramatic Writing》“Character”部分的生理、社会和心理三维观察。取能改变剧情的身体条件、社会处境和内在信念，追看哪段过去在这些条件中留下了会改变当下反应的痕迹。人物的教育、阶层和身份通过实际经历、关系和选择见效。

把依据接到可见选择。遭遇什么刺激，他会先看见或误解什么？对谁有何欲望、戒心或亏欠？他会拿什么换结果，什么即使能换也拒绝？言语、沉默与身体动作怎样把这个判断递给当前听者和观众？为主要角色至少核一处常态和一处受压后的选择，两者须来自同一底色。

当作品需要用价值取舍区分人物，尤其在中文语境或性格反差强的作品中，可用「仁·义·礼·智·信」五维。用户明确采用时沿用。逐维问它指向谁、遇压力时表现如何、会让他选哪一步。重点找过载、缺损和异化，观察一次决定中哪一维压住了另一维，然后落实到关系、行动及用词。未在本作发生作用的维度只记所需边界。

| 价值维度 | 在当场取舍里找什么 |
|---|---|
| 仁 | 谁会得到他的体谅和照看，谁被排除。一遇到难处就包办，可能让他听不进被照看者的意愿。 |
| 义 | 他给哪件事、哪段关系留一条原则，肯承担什么代价。只守一句旧承诺的人可能和眼前的亲人激烈冲突。 |
| 礼 | 他怎样给彼此留位置，会用什么称呼、让步或拒绝。礼貌成为防御时，称呼越郑重，话反而越难接近。 |
| 智 | 他凭什么分辨真假、估计别人下一步。处处先算代价的人也可能错读体谅、过早掐断求助。 |
| 信 | 他凭什么信任、把事托给谁或守谁的约。信任破裂后，明确哪些说法已经说服不了他，以及什么证据、行动或承担会动摇旧判断。 |

为实际会改戏的偏重写一项发生条件和一个后果。例如早市摊主总要亲自核对分量，又很敬重曾教他认秤的街坊。客人当众指责街坊少给了东西，转头问能否从他的摊子买。他先把备用秤递给街坊核对，肯为此多等一会儿，哪怕客人转身去别处。明确他先和谁说、当众说到哪一步，以及他愿意付出的代价。这样的人物设定能接到下一场的行动与对白。

### 按处境校准人物声音

1. 取教育、职业、关系和已定语体中真正改变说话方式的条件。给每个承重角色划两条用词界限。一条处理把当场谈话写成公文的抽象术语、论文句法和规则词。另一条处理与身份、对象或当前行动脱节的市井话、网文吐槽和耍贫。两边都要核具体处境。行内术语、地域话或礼制称谓在人物会这样说且言语有当场用途时照用。
2. 按实际处境列出角色何时改变说话的对象、目的、信息量、句式或呼吸，以及变了仍能辨认他的习惯或价值。拟人 AI 先确定和对象的关系、能力范围、当场能知道什么。日常从对方眼下处境出发回应、陪伴或梳理情感。危急或办正事时把可信事实、时间余量和下一项要做的事说清。绝境触到所珍惜的人或承诺时，惯常镇定可以断裂，能力与知情边界继续可辨。未在剧情中发生的处境留在内部标尺。
3. 从零建立或整体重定主要角色的声音时，为涉及的每位角色写 **3–5 句基准声口**。覆盖实际会出现的日常对话、指令或正事、内心推演和关系或情绪被触动之处。每句附具体对象、当时发生了什么及这句话想改变什么。把句子放回关系读一遍，确认换角色或换听者会失真，且同一角色跨情境仍听得出来。只有角色确实在当前情境承担该判断，才考虑把一句写入正文。已有声音的局部润色沿原稿有效台词校准，仅缺一个处境时只补该处境的例句。

## 查会改变写法的承重事实

只核会改变行动能否发生、何时发生、人物能查明什么或观众能否理解结果的制度、职业、技术、地点或时间条件。先从用户材料和已确认的设定取依据，查现实时按 [Analysis 的调查方法](investigation.md#让证据回答具体问题)保留来源位置、适用条件和仍未知部分。虚构世界把当场触发、限制、可见反馈和例外核到前后相容。遇到重要事实不足时，给 Script 可用的范围及相应处置，例如选择已可确认的场所或让具体原因继续未明。只有会改变用户已锁方向的冲突才需要其决定。职业写实、调查细节和篇幅等后续要求仍由 Script 按已选的开发尺度接续。

## 把能写的决定交回 Script

默认在当前任务上下文把**《剧本前置设计包》**交回 Script。用本作材料和可定位的节点写出以下承重决定。

- **作品承诺与保护项。** 本集或全片边界、观看对象、情感与关系方向、已选结构与方法、已锁素材、有效交锋和结局兑现点；对应 Script 的概念与结构接续。
- **因果、时间线与知情。** 前置条件、现场触发与结果、各方的机会和动机、终局如何承接；让 Script 据此定序列、场次顺序、必要铺垫及跨场连续性。用户在口述或资料中补正或限定了会影响行动的条件时，按实际定下的意思接到对应的场次、动作、提问或答复。标明人物与观众在此处第一次知道什么，以及哪些限制或例外留到后面才知道。
- **情感锚点与转折。** 在何处建立对人物或关系的期待，什么可拍细节承担前后的变化，观众何时获得足以更新直觉的新视听信息；让 Script 编排分场、情绪转折和声画分工。
- **角色决定与声口。** 哪个底色在什么压力下决定哪一步，知情与行为边界、价值冲突、按处境切换的方式、用词界限和基准例句；让 Script 带到人物、对话、表演和单角连读验收。
- **[视觉媒介与画风基线](../../laohu-script/references/script-format-and-delivery.md#按风格写可见过程)。** 一句交本作媒介、画风与需沿用的基调或揭示条件，具体演出随场面调节。
- **现实依据与取舍。** 交清可用来源与事实边界、作者拟定的方案和依据、仍待决定且会改变哪几个段落的事项，以及 Script 可自行决定的实现空间。

交回前核对 Script 能据此知道关键决定如何落实到场和人物行动。用户已要完整剧本时，Script 接着完成分场、正文与自审，再按请求交付；若用户要求先看设计或只要大纲，沿用其停点。默认随任务在对话上下文传递；明确要求保存时由负责人按项目的保存约定处理。

## 遇到设计断点时局部回修

成稿推演发现必需证据到得太晚、行动时长冲突、核心动机断开或关键选择与已锁人物底色相抵时，由 Script 带着场次、原设计、触发矛盾的具体动作或信息、保护项和受影响的直接依赖交回 Analysis 主入口。只重读对应小节，修正最早失效的前提。把更新的条件、它怎样传到受影响场次以及仍须成立的承接交 Script 定点复写。气口、潜台词、场内调度、节奏和动作块的可拍表达由 Script 直接修订。已有情节、场次、人物决定与声口继续按确认范围使用。
