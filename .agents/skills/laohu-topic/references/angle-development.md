# 角度扫描与逐步扩展

本文件供主 Skill 第4、5步在选题角度未定时使用。它把原有内容一步步发展成可比较的整条主题命题；所有候选仍要通过[材料与兑现判断](materials-and-production.md)。普通简单任务不为流程完整度读取深挖部分。

## 默认：从原有内容逐步扩展

### 先定基线

在拆细节前，先写出完整内容许诺。方法、经验合集或步骤系列的完整方法/合集本身通常就是一条主题；某个具体技巧可作为它的证据或注意点，不因醒目而自动拆成新方向。只有该部分有完整独立内容时才单列。

已有标题、强判断或能独立成立的开场句时，按原文保留为第一比较基线。记录它承诺什么、谁可能关心、正文哪一处兑现，以及历史表现来自用户回忆、可核数据还是尚未发布。原句不因新角度更完整或更抽象而自动降级；若新角度更适合，说明它新增了什么人群、问题、解释或材料依据。

从原稿已有的大主题中寻找能够连接的共同处境；可检查工作、健康、家庭、关系、时间、自我价值等常见领域，但只有材料确实涉及的领域才进入候选。不得把某个常见母题当作选题的预设终点。

### 找具体亮点与可信支撑

逐类扫过原稿或记录中的：

- **数据：**确切数值、前后变化、比例或频次。记录单位、时间和来源；无口径时只保留用户原有表达并标明未核，不能补精确数。
- **成果：**做成了什么、形成了什么结果、经过什么可比较过程。单次结果按个案表达，不推成人人可复现。
- **权威或经验：**可核身份、专业来源、一手观察和实际经历。说明它凭什么支持当前判断，不把“头衔在场”当因果证明。
- **反差：**实际表现与已有预期之间的差异。先指出预期从何而来及事实差在哪里；无真实预期或反差时不用反常包装。
- **容易被作者忽略的细节：**看似寻常但能解释判断、行为或结果的原话、步骤、条件或场景。找到它对理解的具体作用，避免只因新奇就保留。

如方法、经验或建议内容存在明显的可信度缺口，最多向用户问一到两个最可能有事实答案、并能改变判断的问题。先从材料检索，再问；问题要指向真实年限、产量、结果、身份或一手观察等可回答信息。用户不补充时不阻断已可成立的候选；未有的数字、经历和截图只列作待补依据，不造占位的实际成品承诺。

没有明显亮点且作者确有提到自己处在不利条件时，可以反向追问“在这种条件下，哪项事实解释了事情仍然发生/做成”；只把回答中可验证的具体因素用作支撑。没有此类条件或事实时跳过，不制造逆境故事。

### 逐词检查限定与受众

按限定词逐个做小实验，一次只改一处，并保留每次变化的具体内容：删除限定、换成受众在实际生活里的说法、改为材料支持的另一读者/需求，或连到稿中已出现的共同问题。每次都问：原有对象和问题还准确吗？新读者为什么会在意？少了哪个成立条件？完整材料增加了什么解释责任？

换受众不只是替换标签。先写出原受众在什么处境下关心，再说明新受众何以拥有相同后果、角色或选择；受众名称扩大而材料没有对应处境时，不成立。受众范围与关切程度分别评估。

只有业务必需、删去后就无法准确交付的限定词才必须保留；说明它保护什么事实或服务条件。其他限定也不必一概删去：如果去掉会改变核心理解、适用条件或用户选定对象，就保留。对每次有实质区别的扩大，跟原始基线及上一步比较；换同义词不算一层新方向。

### 沿材料连接共同问题

从材料中的具体事实开始，检查它是否呈现重复处境、可说明的机制或带条件的共同问题。扩展时可以逐步改变：

- **解释层次：**具体事件 → 有材料支持的重复模式 → 可解释模式的机制 → 适用条件明确的共同问题；
- **关联人群：**直接参与者 → 相同角色或处境的人 → 有同一后果或选择的其他群体；
- **时间范围：**单次事件 → 重复发生的处境 → 材料能证明的持续结果；
- **读者问题：**现象本身 → 其后果 → 读者真实面临的选择标准或价值冲突。

每次上移都写清增加的受众或关切，并保留能回到原材料的具体入口。单一案例只能形成个体观察或待验证问题；不能直接推为普遍规律、时代趋势或长期因果。能找到“共同问题”这几个字还不够，必须说明稿中哪项事实、行为或关系让问题成立。

## 条件性扫描：补找不同解释

### 什么时候用

用户明确要求多找角度/深挖；材料较复杂，初步逐步扩展仍有多种可能；或快速判断找不到合格方向时，才启用扫描。只改既定方向、用户锁定选题、或已有一条充分可交付路线时跳过。每轮只找会改变整条内容主题、人群或解释的问题，不把某个文字包装当新选题。

### 先过四类真实争点

只有材料涉及实际冲突、公开回应、争议或可评价行为时，才检查：争的是否是事实（发生了什么/原因是否成立）、定义（该把事情理解成什么）、价值（是否合理/重要/可责）或行动（谁该回应/如何选择）。对每个真实争点记录两种确实存在的判断、它们会导致什么现实差异、当前材料的支撑与缺口。双方没有不同判断、缺乏实际后果或没有相关材料时，标为不适用，不为了讨论度造对立。

### 再选抽象路径

按任务选择少量相关路径，不将下列变化强行套到每个主题：

| 路径 | 观察动作 | 停止条件 |
| --- | --- | --- |
| 结构与问题定义 | 检查个人事件是否还与组织规则、机会条件或资源安排有关；尝试用另一种问题定义观察它是否会改变读者判断。 | 个案没有群体资料时，只提出可调查的问题；重命名而不改变解释或选择时不算新角度。 |
| 争点与选择 | 找出真实的两种判断、读者正在面对的选择或材料推翻的旧判断。 | 不虚构反对者、行动期限或普遍预设；事实未明时保持待核。 |
| 受众与需要 | 检查原领域外的人是否遇到材料中同一具体处境；他们能借内容理解、判断、尝试或讨论什么。 | “能联想到自己”不等于实际关注；内容没有对应体验或用途时不扩大。 |

### 深挖的十二个检查视角

十二个角度是用于补漏的检查项，不是每次都写十二份结果。按相近的判断动作分三组依次检查，同一受众与命题下的重复发现合并；每组最多保留真正不同且有材料路径的方向。把它们分组是为减少重复推导，避免同一个事实被多种理论名称包装成多个选题。无新增路径就停止该组。

| 组 | 视角 | 具体检查 | 必守条件 |
| --- | --- | --- | --- |
| 结构与抽象 | 社会学想象力 | 个人困境是否还与机会结构、组织规则或资源获得有关，并能提出具体可查的问题。 | 单个故事或共同情绪不能证明结构性问题；缺群体资料时保留为问题假设。 |
| 结构与抽象 | 抽象阶梯 | 从具体事实到重复模式、解释机制和有条件的共同问题，逐层写出新读者承担什么后果。 | 单个案例不证明普遍规律；抽象后只剩人生道理就退回。 |
| 结构与抽象 | 框架理论 | 同一组事实是否可按问题定义、原因解释、评价或处理方向重新理解，并改变实际判断。 | 新框架不证明新原因；只有换说法、没有判断差异时停止。 |
| 结构与抽象 | 沉默的螺旋 | 只有出现意见气候、孤立担忧或表达代价线索时，检查谁可能因此保持沉默。 | “没人说”不等于“不敢说”；无材料线索时不采用。 |
| 争点与判断 | 争点理论 | 分析事实、定义、价值或行动上竞争的判断及不同答案的现实后果。 | 不编造争议；事实未明时留作问题。 |
| 争点与判断 | 修辞情境 | 找到当下真的面对具体选择、且表达可能改变其判断的人，并核查真实限制与时机。 | 没有期限或行动窗口就不制造紧迫感。 |
| 争点与判断 | 认知失调 | 检查材料是否呈现一个人既有判断、行动或自我认识与真实经验之间可定位的矛盾，并判断它是否构成值得解释的内容问题。 | 不替读者诊断心理，不虚构“大家都以为”；普通新知识或标题的新奇感本身不算认知失调。 |
| 受众与需要 | 自我参照效应 | 找原领域外的人能联系到自己的真实场景、损失、机会或选择。 | 泛称“大家都焦虑”不算受众连接；能关联也不证明会点击。 |
| 受众与需要 | 社会认同与自我分类 | 检查材料是否触及真实群体的规范、身份、尊严或利益，以及读者是否会把自己归入相关角色。 | 不靠刻板印象制造“我们/他们”；素材可能没有身份角度。 |
| 受众与需要 | 使用与满足 | 问读者实际能用内容理解什么、判断什么、尝试什么或与谁讨论。 | 好奇、认同不自动等于实用价值；内容需要能交付相应用途。 |
| 受众与需要 | JTBD 进展 | 在确有任务的情境里，查找行动主体想推进什么进展，以及当前做法在哪一步受阻。 | 推测不冒充当事人原话；只有真实购买场景才分析购买进展。 |
| 受众与需要 | 情绪评价理论 | 分开看目标的重要程度、责任归属、确定性与可控性，探索有条件的情绪或行动难题。 | 不据此诊断真实心理，也不声称某内容能消除情绪。 |

深挖只在内部形成路径；逐条说明它从哪段材料出发、经过什么关系连接到新读者的什么处境，哪些是事实、推论或待验证假设，什么事实会推翻它，以及当前状态可直接使用、需改稿、补证、补拍还是另做。材料价值和制作能力按[材料与兑现判断](materials-and-production.md)审核。没有新路径时如实结束，不为了覆盖所有视角填空。

本表中的检查动作改编自 dontbesilent 内容方法中的 DBS 角度开发材料，并转写为造梦项目可执行的选题观察项。名称用于帮助选择观察动作，不代表理论效果已由本项目证实；实际选题命题仍须由当前材料支撑。

## 扫描后的停点

只有改了目标读者、内容承诺、核心事实或制作范围，才重查受影响的角度；用户选择或明确授权后，停止发散并回到主 Skill 的候选比较。把推荐、仍需作者选择的分歧、必要材料和兑现范围交还主文。角度研究不写入标题、封面或正文成品。
