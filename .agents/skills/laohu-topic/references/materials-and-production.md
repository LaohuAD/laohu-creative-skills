# 材料基线与兑现边界

由 [laohu-topic 主文](../SKILL.md) 在用户交来已有草稿、长录制/视频转录、零散一手材料或既有发布数据时按需读取。职责是锚定现有材料真正撑得住的承诺上限，防止选题虚标翻车；只记录改变取舍的关键信息，不要求用户填表，也不代写正文或标题。

## 1. 先立原稿完整基线，再挖高辨识支撑

1. **先保留完整内容许诺作第一对比基线**：通读可读稿件或允许使用的录制区段，写清受众看完整体真正能得到什么（一套方法、一个判断、一段过程或一种体验）。已有标题、核心强句或高辨识度事实时，原样记作基线参与比较——新方向必须说明它新增了什么受众进入理由或更准的切口，不能仅因更抽象或更稳妥就淘汰原基线；除非原句失真或正文无法兑现，才指出硬伤并收窄。
2. **局部亮点不自动替代整篇主题**：快速扫描材料中的五类高辨识支撑——确切数据或前后对比（记口径与时间，缺口径不补数）、可核成果与过程、可信专业身份或一手亲历、真实预期反差、作者习以为常却能解释根因的具体细节。单个猛料通常用来做入口钩子或核心论据；只有该局部自身能独立讲透成篇时，才拆成独立选题。
3. **克制补问可信度缺口**：当经验或建议类内容存在明显信任缺口（如凭什么相信这个判断）时，最多只问 1–2 个作者最可能真实答出且会改变支撑力的事实（如实操年限、样本量、可核结果）。未答时照常完成其余判断，把依赖该事实的候选标为待补，绝不代填。

## 2. 五类创作与制作状态的兑现边界

先分清用户当前所处的创作阶段和允许改动的上限，再据此筛选候选。**下表为内部判断坐标，面向用户交付时须按当前实际媒介（文章、视频、音频、故事或歌词）翻译成自然人话，绝不生搬跨体裁错位词。**

| 当前状态 | 可直接成立的承诺上限 | 越界或待补内容的处置 |
|---|---|---|
| **想法或零散材料，尚未成稿** | 不要求先写正文；以已知事实、自述与具体起点形成可比较方向，清楚标出未来成稿必须补出的关键论证、案例、细节或过程 | 未发生的实测与未查证的资料标为待补条件，不提前写成已有证据 |
| **已有草稿，还可修改** | 标清每个方向对应的原稿段落，说明需保留、前移、压缩或补足之处 | 仅在补足材料或局部改写后才成立的方向，明确写清改动条件；不越界直接重写全文 |
| **已有录制或成片素材，允许补充** | 先列单靠现有素材即可完整交付的方向，再将更强但需补充实测、画面或口述的方向另行标出 | 说清新增内容承担哪项承诺、依赖什么真实事实；未补内容不按已有处理 |
| **已有录制，不可补充** | 严守现有原话、画面、字幕与实测数据上限，绝不把未录制的操作演示、未完成的复测或缺失数据写进承诺；实现蓝图严格限定在剪辑重组、保留原声与花字字幕包装，绝不写成重录口播 | 更有潜力但缺支撑的更大命题，彻底剥离出本期方案并归入后续另做一条的建议，不留含糊后门；若涉及在职内部复盘、企业实验数据或未脱敏品牌，须主动提醒核查保密与公开授权前提 |
| **较长录制中截选单条** | 按目标长度，从可访问转录、章节或时间码中挑选连贯、可独立讲清的完整区段 | 绝不把互不相连的碎段硬拼出原材料没有的论证，也不用区段外的材料抬高本条承诺；无可靠时间码时不编造精确切点 |

## 3. 既有发布数据的分层校准（仅在用户提供数据时启用）

仅当用户提供了过往发布表现且会影响本次选题取舍时启用，不扩成整套账号诊断：

- 按实际平台、时间窗口与统计口径，分层核对**曝光触达（是否被看到） → 入口点击或停留（切口是否让目标人认出关系） → 完播或中段互动（后文是否接住承诺） → 关注与后续需求（是否触发持续信任）**。
- 缺哪一层数据就只把该层标为未知；低曝光或缺数据不自动判为选题失败，单次点击或收藏也不等同于长期关注或商业转化。将真正改变本次取舍的观察带回主文。
