# 材料与兑现判断

供主 Skill 第1步的赛道人群探索，以及第2、6步按材料形态读取。用途是把任务比较或选题陈述落实到真实材料、作者原意与当前可完成的作品范围，不代写标题或作品正文。只记录会改变选题选择的内容，不要求用户填写完整简报。

## 从赛道和画像发现人群任务与需求

当用户只给出赛道、领域或教学定位并询问适合讲什么时，这本身就是可工作的起点；不要求先有成稿、用户访谈或个人故事。先沿作者明确的专业定位界定探索边界，再辨认该领域中实际参与任务、承担决策或受到结果影响的人及其情境。不要预设固定的人群清单，也不要先列工具功能或技巧教程、再给它们贴受众标签。

形成候选或推荐前，先完成足以改变方向的“人群—情境—任务”比较，不从第一个容易描述的场景直接跳到题目。差异可以是同一角色在不同情境中承担不同任务，也可以是不同角色共享一个任务；只保留会改变读者结果、内容范围或推荐顺序的分支，不规定人群数量，也不枚举画像组合。

对每条可能改变选择的关键任务，核对什么情境触发它、当事人想推进什么、现在怎样处理或替代、具体在哪一步受阻及其原因/代价、不解决会有什么后果、怎样才算成功，以及时间、设备、预算、权限、技能等资源限制。不能停在“想做 X”“想学 Y”或一组任务标签；要辨清当前做法为何不能达到所求结果、哪些条件会让方法或内容选择不同。只深入会改变主题、读者所得或兑现范围的关键项，不要求每个群体填写所有字段。按题目选择功能性需要，并在材料确有线索时考虑情绪或社会关系上的需要；不把三类需要做成固定表格，也不把每种内容强行解释为购买或采用产品的任务。

年龄、职业、熟练度、人生阶段等画像信息只作为可能影响任务的条件，不直接等于需求结论。只有它们会改变任务发生的情境、期望结果、现行做法、资源条件、风险或成功标准时，才据此区分选题；若条件并未改变需要完成的事，就不为画像差异另拆方向。同一年龄或职业的人可能承担不同任务，不同身份的人也可能因相同任务、阻碍或结果要求而有关联。只保留会改变内容选择的真实差异，不机械排列画像组合或设置各群体配额。

若用户只给领域/定位，尚未说明希望完成的具体任务或结果，也没有受众资料，可从该领域的实际工作与生活场景提出少量待验证的人群/任务假设，继续比较可能改变方向的任务路径；不要把第一个听起来合理的假设直接升级成首选主题。将假设与用户自述、现成观察或材料明确分开，不称为已调查的需求、普遍心理或市场事实。事实不足时可以条件式比较：“若关键障碍是 A，内容要解决……；若主要限制是 B，读者所得和内容范围会不同”；只在一项缺失信息会改变选择时追问该项，其余未知先标明并继续不依赖它的判断。官方工具文档可以证明某功能、步骤或限制存在，不能单独证明某类人有需要或在意。

若用户已给出明确的任务目标或所求结果，但未提供当事人的当前做法、实际障碍/原因或受众研究，不能因现况未知而只列候选、把比较全部推迟到补充资料之后。先从已知目标倒推内容要兑现时读者必须完成的条件、需要作出的专业决定，以及可以观察或核对的对象/结果；说明这是根据任务逻辑作出的内容设计推论，不是对实际受众行为或根因的事实判断。围绕会实质改变选题、内容范围或推荐的关键未知，按需要展开可能的条件分支，分别说明讲解范围、所需材料和读者可取得的进展会怎样变化；不穷尽所有未知或填满字段，也不设固定分支数。再把拟共用的方法放回各项任务及其条件分支逐一核对，判断哪些情况下能够共同承接，哪些情况应分讲、收窄或留待验证。将比较结果交回主 Skill 第1步继续共同入口检验，并在第6步按各自任务条件和作者当前可提供的材料核对兑现。其他未影响选择的未知照实标明后继续判断；不推断现况、习惯、原因、频率或普遍性，不要求填满所有字段或默认合讲，也不把尚未制作的内容说成已有证据。

将人群发现整理成作者能实际比较的任务路径，而不只交付标签或研究摘要：把会改变选择的人群与情境、当前做法、关键阻碍及后果、所求进展、资源限制和证据状态连起来，交回主 Skill 第1步供共同入口检验和命题使用；形成的候选再进入第6步核对兑现。这里采用 OpenStax《Principles of Marketing》第 5.1 节的人群细分思路、Christensen Institute 的 Jobs to Be Done Theory，以及英国政府 GDS Service Manual 的用户需求指导，并将其适配到内容选题：分类帮助找到差异，任务情境帮助理解人想取得的进展，需求研究帮助避免把解决方案误当问题。它们是发现与组织问题的方法，不是受众规模、内容热度或传播效果的证据。

## 材料记录

先归拢下列项目中当前可获得的信息：

- **完整内容许诺：**读者看完整条内容能获得的方法、并列清单、判断、事件过程、体验或其他成果。
- **作者原意与目标：**作者想解释、展示、反驳、记录或让人体验什么；哪些立场、事实、范围已锁定。业务目标只在用户明确提出时记录。
- **原有入口基准：**现成标题、能够独立成立的强判断、开场句或用户认可的既有方向；原样记录其来源、所作承诺、可能关切、正文支撑及历史数据口径（如果有）。新方向需说明它新增了什么对读者有用的理由或更适合哪个范围；更完整、更抽象或更稳妥本身不构成胜出理由。若原句失真或无法兑现，具体指出原因并缩窄其承诺。
- **注意力材料：**最具辨识力的事件、数字、经历、行为、结果、原话、反差或作者容易忽略的具体细节；注明原文或录制位置。
- **读者关系：**谁在什么实际处境下要完成什么任务、目前怎么做、为何受阻、会有什么后果、期望得到什么并受什么限制；将人群范围与任务/关切分开记录，不把画像标签、用户指定的目标群体或作者猜测当作已验证需求。
- **内容增量：**读者继续看能获得什么解释、证据、做法、判断、故事发展、幽默、情绪共鸣或审美体验；按作品类型判断，不把所有内容改造成教程。
- **证据状态：**分别记录用户自述、可定位的实际观察/材料、从它们推出的工作假设，以及未知或待核实信息。作者自述按其身份表达保留，不升级成独立核实的外部事实；待验证的人群/任务假设可以用于探索，但不能写成已观察到的需求。
- **制作范围：**当前是想法、未成稿、可修改稿、已录且能补充、已录且不能重录、长录制待选范围，或其他已明确的状态。

省略不适用项目。已有材料不足但不影响独立部分时，继续处理该部分；只问会改变候选成败或用户取舍的一项信息。

## 内容价值验收

在推荐前让原有入口基准和每个新方向逐一过关。没有通过的方向可以说明为什么不采用，但不能和可直接交付的方向混在一起。

用户明确要让专业内容触及圈外读者，或只提供赛道并要求探索谁可能关心时，候选还须同时指出相关读者实际可能遇到的任务/处境或能辨认的现象，以及本内容如何用专业材料回应它；术语陌生、身份相似或理论上人数更多都不等于读者有关或已有关注证据。这里判断选题所具备的进入理由和兑现潜力，不代替发布后的表现诊断。

若用户提供了发布表现，且这些记录可能改变候选比较，按实际平台、时期和统计口径分别核对可得的曝光/触达、进入或继续观看、关注及后续需要信号，用来区分内容是否被看到、入口是否让相应读者认出与自己的关系、后文是否接住被吸引的人。缺少哪一层就只把该层标为未知；低曝光或缺数据不自动判为选题失败。将真正可能改变取舍的具体记录与差别带回主 Skill 第6步。这里只校准本题，不扩成整套账号诊断；不假定转化比例或受众保持不变，也不把点击或收藏当作关注。

1. **读者进入：**具体人群在什么处境下会被材料中的哪项事实、人物、行为、冲突或体验吸引。宽泛的“相关”不够；扩大专业内容时，说明圈外读者熟悉什么、它与专业对象/机制的真实关系，以及何处能进入专业内容。
2. **读者所得：**继续看会得到什么解释、方法、判断、事件进展、情绪、笑点或审美体验。赛道探索的候选须说明读者从当前做法或卡点能推进到什么结果，以及内容相对现行方法增加什么具体判断、解释、做法或证据；“流程完整”“适合教学”或“容易展示”本身不是读者所得。按材料所能提供的价值评估，不要求所有内容都改变读者认知；若用户明确关心持续关注或账号价值，可再核对这条内容是否呈现作者能够持续提供的同类价值，不推断真实关注行为。
3. **独有材料：**保留负责兑现的具体机制、经历、结果或细节。解释内容若只是复述常识，要指出新增的原因、条件或判断；故事、幽默和审美则看过程与体验，不用知识增量标准淘汰。
4. **完整范围能否支撑：**指出正文中哪一部分提供该价值。扩大后的受众名称若没有对应内容，缩回具体范围；若可通过最小改稿、补事实或补拍兑现，标清所需动作和成本。局部内容只在其范围独立成立时成为单独选题。
5. **证据与表达尺度：**核查核心事实、因果、限定和用户承诺。核心举证不足或错误期待会影响理解时，核验、标待补或最小收窄；不因次要例外、经验判断或口语概括不够精确而自动削弱。
6. **读者范围与关切：**单独判断可能覆盖的范围和相关人群的关切程度。专业小众可以高度关切，跨群体也可能只是弱相关。若目标是扩大专业内容的覆盖面，只有能说明新读者的具体处境、进入理由和内容所得，且有材料兑现路径的候选才算有效扩大；不以“更多人”“大众都能看懂”代替关系。现实关注程度只有在用户提供或允许查看具体评论、提问、咨询、数据、检索记录时才能称为观察结果；没有真实标题/开头或表现数据，不推断实际点击、停留和关注；理论上有关不等于实际关注，更不是流量预测。

以上项目用于判断候选是否成立、能兑现什么，以及它们各自给读者什么；通过候选的统一比较与推荐顺序按主 Skill 第6步。需要补充的材料要标清具体内容及其对兑现范围的影响。

## 制作状态分支

制作状态与选题发现是两条判断线：先确定用户允许改变什么，再发现候选；候选产生后再按状态筛选。用户已锁定方向或只要求检查该方向时，保留方向，不重新扫描。

### 只有想法或零散材料，尚未成稿

先判断用户给出的起点类型。若已有赛道、领域或教学定位，即使没有具体问题、观察、经历、记录或成稿，也转入本 Reference 的“从赛道和画像发现人群任务与需求”，直接探索并标明假设；不再要求用户先补一个个人经历。只有连领域定位、真实问题、观察、经历、资料或明确想回答的问题都没有时，才问一个最能让工作继续的起点；不给长问卷，也不凭空补受众需求或“爆款”方向。用户明确邀请虚构创意或开放式脑暴时，可以提供清楚标为假设的创作前提；它们不是已发生的经验、受众需求或已验证的选题。

已有真实起点时，不要求先写成文章。先把已知事实、经历、记录和作者主张，与仍待解释、判断、解决或呈现的问题分开。依用户本轮目标选择一个具体问题及相关读者处境；只展开与材料和目标相符的内容方式：解释型问题要明确原因、条件或事实关系；方法型问题要明确读者的受阻任务及可取得的进展；故事或体验型问题要明确材料能呈现的过程变化。无需把所有内容类型都套一遍。

据此写出可比较的完整候选命题，说明它讲什么、谁在什么处境下会关心、内容能带来什么理解、判断、行动或体验。再标出现有材料的出处及其用途、决定候选能否成立的关键缺口，以及可从现有记录、作者真实经历或本轮允许核验的来源中补充什么。未知答案继续作为问题或带条件的候选，不预写成结论或证据。回到主 Skill 第6步审核和比较，不要求先完成正文。

若用户给出多份未成稿材料或允许范围，先按用户指定范围选取可用材料，再沿上述步骤形成候选；每项需要新内容才能成立的方向，写明必须补入哪类真实材料以及它会怎样改变承诺。方向确定后标出目标读者、核心命题和已有材料位置；没有的事实或经历保持待补，不把计划中的内容说成已有。

### 已有稿件、还可修改

通读当前稿件并划定完整许诺及能承载它的段落。选题比较后指出各方向对应的正文位置、需保留/前移/压缩/补足的材料，以及最小事实缺口；方向只靠改稿才能成立时标清修改条件。按用户所求交付选题建议，不直接重写整稿。

### 已录制且可以补拍

先列只使用现有录制可成立的选题，再把更强但需补事实、镜头或口述的方向另行标为“需补拍/补证”。说明新增内容承担什么承诺、依赖什么事实；未提供的补拍事实只列为待补，不写成已录素材。

### 已录制、不能补拍

当前候选只采用现有原话、画面及字幕能支撑的范围。更广的共同问题如果缺解释、案例或关键事实，留作未来内容，不进入当前成片方向。不得以新写引语、虚构结果或扩张因果补足。

### 较长录制中选一条

先确认这次要制作的一条内容的范围或目标时长，再从可访问转录、章节或时间码中选一个连贯、可独立讲清的区段；用户已给出具体区段时沿用。不能把互不相连的片段拼成原材料没有的连续论证。以原有时间码或段落标出证据位置；没有可靠时间码时不编精确切点。依该段内容确定整条选题，不用其他段落的内容抬高它的承诺。

## 状态回传

每个保留的方向须明确属于以下哪类：现有材料可直接成立；经过有限改稿后可成立；还需一项可核的事实/经历；需要补拍或重新制作；只适合另做一条。写清差异来自哪个事实、正文范围或制作条件。用户未确认的方向保持“候选”，作者明确选择或委托后才称“选定”。
