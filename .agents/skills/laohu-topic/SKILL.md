# 选题的目标

选题是一句可复用的完整内容命题：说明整条内容讲什么、哪些人在什么处境下会关心、材料能带他们理解判断或体验什么，以及现有稿件或制作状态能否兑现。它把读者的具体关切、作者手头的真实内容和可交付范围连在一起，使后续创作有清楚的内容依据。

本 Skill 负责确定和比较整条内容的主题命题、受众处境、材料依据、交付范围与制作条件。封面上的视觉表达、发布标题和正文写作各有自己的成品目标；本入口交付的选题简报可以供用户之后选择的工作继续使用。

用户已经锁定选题时，保留方向，只检查它与当前材料、作者目标、受众关切和制作状态是否相符。只问一项会改变当前判断的缺失材料；可成立的部分继续完成。用户明确授权代选时，由你比较并给出推荐；若多个方向会带来不同的受众或内容承诺且用户尚未授权替其决定，简明呈现实质选项并询问选择。

候选只基于本轮可访问的原稿、记录、用户自述或本轮授权核验的来源。明确区分已确认事实、作者经验或主张、基于材料的推断、待验证信息；不编造经历、数据、身份、普遍心理、受众规模、因果或传播效果。作者的口语概括、观点和修辞力度，只有在影响核心理解或造成无法兑现的期待时才作最小调整。

# 选题判断

## 1. 确认这次要决定的范围

先辨认用户从哪种起点进入：只给赛道、领域或教学定位并询问适合讲什么时，走赛道人群探索；给出问题、观察、经历、资料或稿件时，从已有材料提炼；已经锁定读者或选题、只需核对能否兑现时，走快速检查。用户明确要求比较人群任务或共同入口且尚未锁定唯一命题时，也进入相应探索分支；不同起点可以并用，但用户锁定的范围优先，不因此重开选题。沿用作者明确的专业定位和本轮给出的读者、目标、平台、事实、方向与限制；赛道探索只在作者能负责的领域边界内进行。

只给赛道/教学定位而尚未锁定唯一命题，或明确要求比较不同人群的任务/共同入口时，按“需求比较 → 共同入口检验 → 命题与取舍”完成并呈现本轮探索。先从作者的专业边界内辨认会改变选题的人群、情境和任务：不同身份可能有同一任务，同一身份也可能处在不同任务中；对影响方向的关键任务，比较当事人现在怎么做、关键卡点及其原因或代价、不解决的后果、希望取得的结果或成功标准，以及会改变做法的资源限制。用自然段或少量有重点的小节，把这些差异写成作者能核对和选择的需求比较；不设人数、表格或字段配额。证据不足时将合理解释标为工作假设，指出什么未知会改变判断，不把画像标签、常见教程或第一个顺手的任务当成需求结论。

从这份比较中找可能共享的问题、机制或受阻环节，具体检验同一条内容能否解释或演示它，并分别说明相关人群能推进到什么结果；如果一条内容接不住某类人的目标、成功标准或必要步骤，就指出差异并分开，不因身份不同自动拆分，也不为了扩大范围勉强合并。只有完成这个检验后，才形成候选命题。作者应能从答复里看到需求比较、共同入口判断、候选和推荐之间的依据关系，而不是只在开头看到结论、把前两项留作隐藏分析。

只给赛道而没有成稿、访谈或个人经历也可开始；按[材料与兑现判断](references/materials-and-production.md)的需求发现方法和[角度扫描与深挖](references/angle-development.md)中“从多类人群的任务中检验共同入口”完成比较与检验。

已锁定方向、只要求核对兑现或只处理某一段时，直接从该范围开始。一个局部细节或强句可以成为整条内容方向，前提是现有内容能独立承担它；它不能仅凭足够醒目，就替换一篇完整方法、清单、判断、故事或体验原本提供的整体内容。

用户明确希望让专业内容被圈外读者理解和关心时，沿专业对象、机制或材料事实寻找圈外人实际遇到的处境、后果、选择或可识别经验；这不等于把内容改成人人都关心的泛题，也不覆盖用户锁定的专业读者或目标。

## 2. 依材料状态形成原有许诺或待发展命题

仅赛道/定位起步已在第1步完成需求比较与共同入口检验后，直接进入第6步；第2至5步承接用户实际提供的问题、观察、经历、资料或稿件。赛道请求同时附带材料时，仍先完成需求比较，再用相关材料核对作者贡献和兑现范围。

先按当前制作状态确定可读材料范围：要重构已有稿件的整条选题时，通读当前稿件；已有录制时，只看本轮允许剪辑或交付的部分。已有完整内容的，用普通话写下读者看完能得到什么：一套方法、一份并列清单、一个判断、一段事件过程、一种体验，或其他材料真实提供的结果。若内容由多条步骤、技巧或案例共同组成，先保留整体许诺；单条技巧或最醒目的局部通常是支撑整体的证据、注意点或可独立剪出的内容，不自动替代整条主题。

有具体问题、观察、经历、资料、念头或零散材料但尚无成稿时，不要求先完成正文；读取用户已给的起点及相关记录，按[材料与兑现判断](references/materials-and-production.md)的未成稿取材分支，区分已知信息、作者自述、材料推论与待回答的问题。开放脑暴或虚构创意沿用该 Reference 的对应分支，并清楚区分假设与真实材料。

已有标题、核心判断、开场强句、具体事件或最有辨识度的事实时，原样记录为比较基准，并注明它承诺什么、可能面向谁、现有正文或录制能否兑现。无稿件时不虚构一个原有标题或已成稿的内容许诺；以用户给出的起点、明确目标或现有资料作为基准。若用户提供既往发布表现，记录平台、时间、来源与口径；它只说明该句在当时条件下的表现，不证明观点正确，也不保证新版本复现。原有标题即使可能不是最佳选题，也先让它与新方向一同接受比较；只有事实失真、偏离内容或无法兑现时才指出具体问题。

对材料提炼路径，此步形成够用的材料记录：作者本意与目标、已有内容的完整许诺或待发展命题、原有入口基准（若有）、注意力材料及出处、适用读者处境、内容价值、事实状态、争点（若真实存在）及制作范围。无稿时把已知支撑与待补信息分开，不将未回答的问题写成结论。完整字段及取材动作见[材料与兑现判断](references/materials-and-production.md)。

## 3. 从内容里找值得讲的具体材料

先找可以让这份内容区别于同类内容的细节，再判断它支撑的是整条主题还是局部切口。按材料情况检查五类亮点：数据或明确结果；成果、战绩或可比较的前后变化；可核实的专业身份、权威来源或一手经验；真实反差或与预期不同的行为；作者认为寻常、但能解释事情为何如此的具体细节。只把实际存在的材料写成事实。单个数字、知名身份或猎奇细节只能说明可能先引起注意；还要找到正文后续能提供的解释、方法、判断、故事进展、情绪、幽默或审美体验。

方法、经验或建议内容如果会引出“凭什么相信这个判断”的问题，而现有材料没有回答时，可问最多一到两个最可能由作者真实回答、并会改变选题支撑力的问题，例如相关经历的年限、实际做过的数量或可核结果。只问与这份内容直接相关的事实，不泛化为采访表。用户未答时继续分析，但把依赖该信息的候选标为待补，不填数字或身份。若材料没有显眼亮点，可在确有现实依据时反向检查：作者遇到什么不利条件，为什么事情仍然发生或做成；没有真实答案就不把“逆境”写成故事。

## 4. 逐个检查限制词与读者说法

把原标题和主命题中的限定词、行业词、术语及受众名称逐一列出，并分别检查：

- 删除这个词后，原来的人群与问题是否仍准确，新读者是否能进入？
- 能否换成读者在相同处境下会使用的日常说法，同时不改掉真实对象或任务？
- 这个限定是否是交付必需的条件？删除它会不会让承诺变成不准确或无法履行？
- 是否能把问题接到材料已经谈到的共同后果或更广处境？是否真的会改变谁关心、关心什么或能得到什么？

当用户希望专业内容触及圈外读者时，不能只删术语或换成日常词。保留必要的专业对象与限定，从材料中的事实、机制或流程出发，连接到圈外读者熟悉且确有依据的处境、后果、选择或体验，再说明本内容能为他们解释、判断或解决什么。专业内容仍须在候选中兑现；只扩大受众标签、泛称痛点或另造冲突都不构成有效入口。概念不能省略时，可以用日常语言说明它在材料中起什么作用，同时保留需要准确表达的专业名称。

受众标签多不等于内容更准；但为了扩大范围删掉必要行业、资格、时间或适用条件，同样会误导。只有删除后原意仍成立、或替换后仍有材料支持时才改。对每种有意义的扩大，每次只改变一个限定、读者或问题，再与原始基准及上一种变化比较；纯换措辞不算新方向。每次变化都记录新进入的人群或新发生的关切，以及内容多承担了哪项说明责任。

## 5. 逐步比较主题范围

从原始许诺和现有入口出发，逐级检查是否能从具体事件连接到可重复的处境、材料支持的共同问题，再到有成立条件的解释或判断。人群可以从直接参与者扩展到有相同角色的人，再扩到因同一机制受影响的人；时间也可以从单次事件延伸到反复情况或长期结果；价值判断可以从现象转向后果、选择标准或真实冲突。只沿材料已经出现的事件、行为、结果、事实关系或作者主张扩展；单个案例不能直接证明普遍规律、时代趋势、长期因果或所有人共同心理。

从已有稿件或材料提炼时，“更大的共同问题”必须在原材料中找得到落点：说明哪项事实、经历、行为或关系支撑它，以及读者看完整条内容能多理解、判断或体验什么。仅从赛道探索且尚无原稿时，以已记录的人群任务、情境、现行做法、阻碍和结果要求作为候选依据；区分用户自述、实际观察、工作假设与未知，并标出未来内容需补充什么才可兑现，不把假设写成现成材料。无论哪条路径，若只剩“成长、焦虑、赚钱、关系”等宽泛词，就回到具体任务或材料；若大范围命题需要删除关键条件、依赖未知动机或无法由现有材料兑现，降回上一层，或标为待补材料后的未来方向。

围绕一件真实事件有不同解释时，先区分事实、定义、价值和行动问题，确认材料或用户实际提供的讨论中确有不同判断，且每种判断会造成可说明的现实差异。只有一方存在、没有真实争议或内容本身只是教程、经历、方法时，不制造对立来抬高话题。

材料路径需要扩展角度、当前快速判断没有可用方向或用户明确要求深挖时，才按原条件读取[角度扫描与深挖](references/angle-development.md)的逐步扩展方法；十二视角只在该 Reference 的触发条件成立时使用。材料路径需要把专业内容连接到圈外读者时，读取其中“把专业内容接到圈外读者能辨认的处境”一节。赛道起步的共同入口检验已由第1步按该 Reference 的专节完成，不在本步重复；不论起点如何，候选最终都回到第6步核对读者价值、作者贡献与制作范围。
本轮进入具体选题、角度或读者入口的实质选择时，若当前项目资料库已确认存在，按项目共用[本地作品方法库检索路径](../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)查询相关材料/方法卡、读取选中详情，再回到具体选题并按真实材料和制作范围判断能否兑现；用户已锁定选题且本轮只做资料核验、忠实整理或执行时不触发，同目的已有新鲜查询和必要详情时直接复用。不能用原作的读者规模、反馈或热度替代当前受众证据。

## 6. 审核候选并按本轮目标比较

每个候选写成一句完整选题陈述：点明讨论对象、核心问题或判断、相关读者处境，以及内容能提供的理解、决定、行动或体验。把读者类别（可能覆盖谁）与具体任务和关切（他们在何种情境下想推进什么、目前受何阻碍、希望得到什么）分开判断；材料没有真实人口统计或受众数据时，不推算人数、市场规模或广泛关注。年龄、职业、熟练度或阶段只在材料显示它改变任务、结果标准、资源条件或解决方式时，才作为选题区分依据；不得把画像本身写成需求结论。

逐项让候选通过[材料与兑现判断](references/materials-and-production.md)中的内容价值与制作状态审核：读者为何进入并继续、整条内容的独特增量是什么、已有正文/录制的哪一处承担承诺；无稿时则说明已记录的任务或材料能支持什么，未来内容还要补出哪类解释、事实、行动或过程。尚未成文的内容是未来工作，不当作现成证据。只对会改变核心理解、造成错误期待或使方向无法交付的缺口核验或收窄；商业目标仅在用户提出时纳入。

对所有候选（不论从材料提炼还是从赛道起步），先以事实、作者原意、专业边界及明确的制作限制作为成立门槛；不满足者剔除，或写清补齐什么条件后才成立。对通过者，按用户本轮明示目标比较目标读者的实际所得与内容增量；若多个方向同样达成目标，再以作者明示目的、材料独特性、具体读者关切、制作成本与偏题成本说明次级取舍。用户未明确本轮目标时，依据材料独特性、读者关切、内容增量、作者目的、制作成本与偏题成本作有依据的定性推荐。成本用于判断能否兑现及代价，不替代内容目的；不把理论覆盖人数、题目完整度或“适合教学”当作读者价值，也不合成虚构分数。

赛道起步候选沿第1步已展示的需求比较与共同入口判断进入审核：核对命题相对其中各类读者当前做法带来的具体进展、内容增加的解释/判断/做法/证据或体验，以及作者确能提供的内容与仍缺的部分；并检查同一内容是否能兑现共同入口中说明的各自所得，不能承接的差异应分开或收窄。这一核验补充赛道候选的读者进展、内容增量与承接范围，随后仍按上一段对所有候选适用的门槛和排序依据取舍。

当本轮目标是拓宽专业内容的圈外读者，在通过成立门槛的候选中，优先比较新读者在什么具体处境下会关心、专业内容能给出什么所得，以及材料如何兑现它；不以理论上可能覆盖的人数或制作方便替代内容价值。只有用户明确把持续关注或账号价值列入目标时，才进一步说明本条内容是否呈现作者可持续提供的同类专业价值；这仍不是实际关注行为的证据。

## 7. 推荐、请作者选择或补一项材料

用户已经定方向时，交付该方向的兑现检查和最小修改建议，不再重开完整比较。只有一个候选通过时，说明为什么它最适合当前材料；没有合格方向时，指出目前的内容上限并只问一项最有机会改变判断的真实材料。

多个通过审核的方向若会改变整篇讲什么、服务谁或承诺什么，而用户没有授权代选，最终简报最多呈现四个实质不同的方向；有效方向不足四个就少给，不为凑数拆分同一命题。这个上限只约束精选方向，不限制前面的需求发现。若原有完整许诺或原稿方向通过兑现检查，将它放在第一项作为基线；其余方向说明改了什么、谁在什么处境下会关心、各自能得到什么、依据或待补内容及兑现条件。赛道起步的简报沿用第1步的可见顺序，只保留改变选题和推荐的关键比较，不重述所有探索细节。用户可用自己的话提出、合并或否定方向；收到反馈后只重做受影响的比较。用户授权代选时，按第6步依据推荐并交代主要取舍。

交付的“选题简报”只包含本轮有用信息：选定或待选的完整主题陈述、目标读者及其具体关切、读者看完能得到的内容、材料依据及原稿/录制中的位置、事实或待补信息、制作条件与范围、推荐原因或尚待作者决定的分歧。需要下一步时，用户可以把这份简报交给其选择的标题、封面或写作任务；当前不预写那些成品。

## 8. 交付可继续使用的选题简报

完成时，选题简报能让作者和后续创作清楚看到：整条内容讲什么、服务哪类读者及其何种关切、读者看完会得到什么、已有材料中哪些事实或经历支撑承诺、原稿/录制的位置（若有），或未成稿时未来内容必须承担什么、哪些信息仍待补，以及当前制作状态允许做到哪一步。局部选题请求则按用户指定范围交付。

交付前核对推荐是否回应用户目标、候选是否有实质不同的读者所得或内容承诺、缺口是否改变候选成立或取舍。若比较理由未能支撑推荐，回到第6步；若仅一项输入会改变判断，只问该项或标为待补，并继续完成不依赖它的部分。锁定方向只核对该方向；后续成品由用户另行选择。

若方向是为圈外读者打开专业内容，选题陈述要让不懂术语的人从可识别的处境看出为何在意，并知道后文会用什么专业材料回答；不能靠删掉关键对象或适用条件换取易懂。未提供真实标题、开头或受众反馈时，只交代内容入口与材料路径，不推断实际点击、停留或关注。
