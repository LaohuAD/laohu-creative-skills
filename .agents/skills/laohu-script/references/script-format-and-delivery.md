# 剧本格式与交付：让演员、资产与视频直接接得住

起草影视正文 `△`、写表演括注与声源标记、选交付层级或整理可复制模板时读取本文件。用户或项目已定体例与既有编号永远优先；P 分段双文本与估时细节由 [Video 分段与下游交接](../../laohu-video/references/segmentation-and-handoff.md) 维护。

## 1. 交付层级与默认 Markdown 容器

只交用户本轮请求的层级，不把开发附件强塞给正文任务：

| 层级 | 内容边界 |
|---|---|
| 故事概念 / 三幕故事纲 | 清晰短段或分条交代核心前提、行动因果与结局（先亮看点再分层展开，严禁大段文字墙）；不含场头、对白、`△` 或节拍。 |
| 转折序列纲 / 扩纲 | 按幕写大事件因果、策略阻力与承接；工业二幕扩纲才锁定一三幕只扩二幕。 |
| 分场纲 | 按真实连续时空列场头、人物、目标、经过、场末状态与预算；节拍仅内部构思或明确要求时外显。 |
| 剧本正文 | 仅含作品标题、场次与正文；人物表、简介、研究与制片附录按需另附块外。 |

- **默认 Markdown 层级**：完整影视正文以 `# 作品/集标题` 起头（独立短片不虚构集号；局部正文不编造全篇 H1），正式场次用 `## S01 内/外·地点·时段` 或 `## E01-S01 内/外·地点·时段`（以真实连续时空为场界，地点或时段改变另起场头，同场切视点或换话题不拆场）。新增场沿用既有编号规则，绝不静默删改旧号。
- **正文纯文本洁净底线**：剧本正文代码块内，除 `#` 剧名与 `##` 场头外，画面描述与台词一律保持纯粹剧本纯文本——**严禁使用 Markdown 行内反引号（`` ` ``）框时间、单号、屏幕文字或普通中文词句，严禁用加粗或斜体修饰台词与 `△`，普通名词克制装饰引号**（屏幕、招牌与纸面文字自然融进 `△`，需区隔时用书名号或必要引号）。
- **正文直出、开发扫读与改稿分轨**：按 `docs/runtime.md` §4 执行——完整连续正文整体放入单个 Markdown 代码块（围栏标 `markdown`）；明确只要正文时，直接交干净代码块，块外零前言、零自夸与自检表。交付开发大纲、审稿诊断或多方案比较时，分析与拍板项留在块外，先亮一句话结论，用分层标题、重点加粗与对照表（含推荐排序与代价）让决策者一眼扫清，绝不堆紧凑文字墙；成套可复用大纲本体或审稿修订后的完整正文另进独立干净代码块，块外只用简明分条或“原问题 → 改法”对照交代核心改动与待决项，不把批注混进正文。
- **不自动分 P 或编 M**：普通剧本默认不分 P、不自动加逐镜编号 `M`（仅用户明确要逐镜稿或已有工程编号时保留）。舞台剧、广播剧或文学剧本按该媒介体例，不强套 `△`。

## 2. `△` 画面描述写什么

普通影视剧本的每段画面描述以 `△` 起始。**`△` 描述的是摄影机拍得出、话筒录得见的完整视听画面，而非只写人物动作**——它涵盖空间环境、自然光声、物件状态、人物站位与静默留白，以及画面里面包含的动作与反应。

### 有尾必有头，有头可留白（视听衔接与蒙太奇铁律）
- **严防有尾无头**：凡后文画面、动作或台词实际消费到的物件、状态、环境设施或特效结果（如吃剩下半块饭团、滚到脚边的帽子、掀翻火盆、法阵长剑齐射），前文必须在合理位置立出可见来处、初态或自然过渡。
- **保护有头留白与画面趣味**：绝不搞道具全生命周期打卡流水账——后文不再追问去向的常规过渡、杂物拼装成新载具或快切蒙太奇直接留白，把改造后的成品外观写生动即可；画面成立且有趣的生活动作（如手里攥着半块饭团同时双臂托物）直接保留，不搞教条物理抬杠。

### 把六类拍不出来的小说句转成纯视听

| 发现画面描述落入 | 正向转译为可拍声画 |
|---|---|
| **念头起止**（如收回探问的念头、思路收拢） | 写目光移向哪、手在哪一步停住、隔了半拍又改做什么。 |
| **作者代述意图**（如拿最核心的问题试底线） | 删去意图声明，直接写走近、扣住物件、抬眼神态与紧接而来的台词。 |
| **抽象局势总结**（如仇清了、大局已定） | 交出证实变化的物件、屏幕画面、环境声停顿或身体松懈反应。 |
| **纯内心抒情**（如心口大半年的沉闷松开了） | 先落到站位、呼吸、手部力度与物件互动；主观感受必须听见时交 `VO`。 |
| **负向未发生动作或作者吐槽**（如连引信都没看一眼、没念招式） | 改成此刻真在发生的动作或干脆删去；有声画实据的缺席（等待落空、声音骤停）写具体停顿与反应。 |
| **感觉/抽象形容词贴标签**（如露出复杂愧疚的苦笑、空气弥漫沉重微妙的压抑） | 删掉摄影机拍不出的情绪评价与散文修饰词，把冷暖压迫全藏进具体实体物件、光线声响、眼神落点与手部微停顿里。 |

### 按风格写可见过程
动笔前先锚定本作视觉媒介与画风，并在同作内随场面基调自然流动，不死锁单一写实克制：
- **写实真人 / 生活剧情**：靠站位距离、呼吸、日常小动作、视线停顿与现场环境声给潜台词留空间；
- **动漫 / 卡通 / 萌系喜剧**：主动释放鲜明夸张表情、弹性形变、治愈微动态与强反差动画演出——例如角色自带气场的亮相与战队集结摆 Pose、极度装酷定格后一秒破功的喜剧骤停，让画面动作自己演活人设与笑点；
- **奇幻 / 科幻 / 特效奇观**：写出下游视频团队可直接分镜的可见演变过程（触发起势 → 能量/形变凝聚 → 爆发与结果反馈），不直接干瘪跳到结果。

### 按观察重心分段与物理站位清晰
- 同一观察主体连贯完成的画面流与共框回应留在一个 `△`（不按句号或动词机械切碎）。当画面需要**正反打换主体反应、视线对接转念、特写强调关键证据、并行动作各自落点或喜剧骤停**时，主动另起 `△`，让下游 `laohu-video` 一眼读出切镜呼吸（正文绝不写机位焦段参数）。
- **不写机位参数 ≠ 省掉物理站位与动线**：自然写清人物在门边还是桌旁、朝向谁、手里拿着什么、场内主导自然光与环境声，既让演员立刻知道怎么站怎么演，也让下游 `laohu-assets` 与 `laohu-video` 空间零穿帮。

### 首次出场视觉锚点
主要角色、核心奇观道具与固定主场景第一次看清时，随画面自然落 **1–2 笔最具辨识度的视觉特征**（如体型年龄感、发型/标志物、衣着大类主色、空间核心陈设与光温），让读者与 `laohu-assets` 立刻立住形象而不停下来念简历。首次定锚后复现从简，只在外观发生持续变化（淋湿、破损、凌乱）时补记；剪影或隐藏身份按原揭示时点落笔；精确三视图、纹样细部与出图提示词留给 `laohu-assets`。

<a id="台词行与表演括注"></a>
## 3. 台词行与表演括注

**括注只点表演要害，绝不复述台词字面，也不逐行填满。** 表演括注写在人物名后、冒号前，仅用于情绪在此刻突变、嘴上说与心里想相反、强压情绪露出破绽，或停顿重音与伴随小动作会改写整句听感的节点；普通应答直接写 `人物名：台词`。

- **写法基准（Judith Weston 可演原则）**：先连读前后回合定清此刻对人行动，挑一个演员真能演或听得出的短小中文变化——声音如嗓音发紧、话音哽住、重音压在某字，身体如目光移开、笑意骤收、手上停顿；对象与触发时点写清，不堆砌形容词清单，不把独立大动作塞进括号（大动作归 `△`）。
- **无实体角色与录音**：无实体 AI 或纯声源只写听得出的声音变化；系统播报只在异常变化承重时加注；录音表演不随现场听者反应改变。声源与表演同括时以分号隔开，如 `陈默（OS；声音放轻）：……`。

<a id="声音文字与主观时空的标法"></a>
## 4. 声音、文字与主观时空的标法

- **声源三分（全篇统一真源）**：通用影视默认采用无点简标 `OS` / `VO`——同场画外、场内人物听得见的真人对白标 `OS`（入画即取消）；场内人物听不到的内心声音与旁白标 `VO`；电话、录音、广播、车载 AI 等设备传声按实际来源标注（如 `小周（电话声）`），首次接入或切换时标明，连续回合沿用。纯中式古风、国漫或用户偏好中文标注时，也可改用`（画外）`/`（内心）`，确保全篇统一即可；用户或项目既有体例永远优先。
- **屏幕文字**：放进标明载体的 `△` 画面中，写清剧情内谁能看见，不写成对白；可见权限与已锁能力边界前后一致。
- **主观时空成对闭合**：回忆用“回忆开始 / 回忆结束（回到现在）”，梦境与幻想同理成对闭合；退出时立刻重建现实时间、地点与身体状态，回忆跨场仍保留真实场头。

<a id="可复制模板"></a>
## 5. 可复制模板

**普通影视剧本正文模板**（完整交付时整体进单个 `markdown` 代码块，块内除 `#`/`##` 外严禁反引号、加粗、斜体等非原生富文本修饰；局部摘录只留已知层级）：

```markdown
# {作品/集标题}

## {S01 或 E01-S01} 内/外·{固定地点}·{时段}
△ {从观察重心写完整可拍画面：空间环境、光声、初见立形、站位与画面内动作}

{人物名}：{普通台词}
{人物名}（{仅情绪突变或反差处写的短小可演提示}）：{台词}

△ {换主体反应、特写强调或视线对接时另起段落}

{人物名}（OS）：{同场画外、场内听得见的对白}
{人物名}（VO）：{场内听不到的内心声音或旁白}
{人物/设备名}（{电话声/车载语音等实际声源}）：{设备传声}
{人物名}（{声源}；{确需强调的可听表演提示}）：{台词}
```

**开发阶段简明交付骨架**（仅按本轮所求层级选用，不提前下钻细节；多方向取舍放块外用对照表标清推荐优先级与代价）：
- **概念**：用清晰短段或分条交代类型背景、承重人物、行动、阻力、失败代价、结局方向与独特看点，另标锁定项与真正待决项（明确要 logline 时附 1–2 句）。
- **三幕故事纲**：第一幕建置 / 第二幕对抗 / 第三幕结局（写到实际结局）+ 待决项。
- **结构纲 / 扩纲**：采用结构 + 分幕转折点与序列（每段写清前因、目标、阻力、结果与下步承接；工业二幕扩纲另列各幕字数与占比）。
- **分场纲**：分场号、内外/固定地点/时段、在场人物、目标、经过阻力、场末状态与下场承接、播放预算（工业配场另列比例与偏差）。
- **独立制作附录**（仅用户需要给资产/视频制作交接时另附正文外）：按 [laohu-script-world](../skills/laohu-script-world/SKILL.md#在用户需要时整理独立制作附录) 提取四类锚点，**单开独立洁净代码块**附于正文块外，剥离寒暄与创作点评。
