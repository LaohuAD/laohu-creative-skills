# 剧本格式与交付：让接收者知道读到哪一层

当用户要求确定剧本版式、集场镜号、输出一份可交付稿、向他人介绍项目，或审稿时需要核对 `△` 画面单位、台词前括注、动作/道具连续性或成稿时长时读取。先识别接收者与用途，再选必要组件；读完回到主 Skill 当前步骤。若用户已经指定体例，沿用该体例并保护既有编号，不把个人默认写成行业硬标准。

## 先定交付层级

先判断用户要故事雏形、分场大纲、局部正文还是一份可独立阅读的完整剧本，不把高一层的交付包压给低一层任务。

| 交付对象 | 默认交付内容 | 何时省略或换层级 |
|---|---|---|
| 故事雏形或提案 | 标题、核心概念、一句话故事、短梗概、类型/观看方向、主要未决选择 | 用户只要一个灵感版本或一句话时，不展开人物表与分场 |
| 普通完整影视剧本 | 标题、预估时长、一句话故事、理解剧情/关系所需背景、人物表（姓名、性别、性格或声口、关系）、正文与场次 | 用户只要局部片段或明确说只给正文时，不附完整前置信息包；背景无额外解释需要时不凑内容 |
| 系列开发包 | 系列引擎、人物关系、季弧、分集梗概或 pilot 正文 | 用户只做单集场景，不附完整季规划 |
| 分场大纲 | 场次次序、人物行动、该场变化与场间承接 | 用户只确认结构时，不写对白或拍摄规格 |
| 明确要求逐镜编号的稿件 | 按用户/项目确认的编号规则，在每个指定画面单位附镜号 | 未要求镜号或没有已确认工程格式时，不自行加 `M` |

完整剧本的人物表只列理解人物与关系所需的识别信息，不等同内部人物卡或完整人物档案。性格/声口栏用读者能直接理解的自然短句，说明角色通常如何观察、说话或行动；内部分析标签要编译成有材料依据的行为习惯，不原样贴进表格。新写作品的人物简介承接本轮已建立的人物卡、创作设定与正文；可按故事目的主动设计身份、生活前史和行为习惯，并保持与正文一致。既有稿改写依原稿和已确认的人物卡/设定，不擅增未经用户选择的背景，也不为事后解释怪句而改卡；用户授权改写的空白按创作决定处理。涉及真实事实的断言以现有资料为限，尚未确定的虚构设定标为暂拟。背景只解释读者理解故事行动和人物关系所必需的条件；事实未定时标为待定，不把猜测写成事实。用户给出的片长是目标时长，应与当前稿的预估时长分开；预估必须依据当前剧本文字、动作和停顿核算，不能把目标时长直接填成估计结果或声称已经达标。预估只依据交付稿本身，不引用运行日志、验证记录或缓存路径；这些过程材料另存验证记录，不进入作品正文或时长注。一句话故事说明主人公/核心人物正在做什么、面对什么关键阻力或关系变化，不以宣传句替代故事事实。

创作过程、内部审稿和未采纳备选方案默认不进入作品正文；用户要求创作说明或开发报告时另列。

### 稿件体例的优先级

按以下次序确定正文的视觉单位、排版和编号：

1. 用户本轮明确指定的体例优先；若本轮未指定，沿用该项目/该稿已经确认的体例、`△` 定义和编号。改写既有稿时保留其可追溯编号，不静默删号或改义。
2. 用户和项目都未确认时，普通影视剧本采用本项目的画面描述体例：`△` 表示一个清楚的画面/分镜单位，默认不加 `M`。`△` 以观察主体、空间关系或信息重心为界；同一观察重心下连续发生的动作可以留在一个 `△`，不按每个动词机械切开。
3. 用户明确要求文学/连续动作块、舞台剧或音频稿时，按其媒介与体例写；若项目已有明确的动作块定义则继续沿用。`M` 只在用户明确要求逐镜编号或已有确认的工程格式要求时使用。单独要求镜头/画面描述，不自动等于要求 `M` 编号。
4. 故事雏形、提案和结构/分场大纲保持各自文本层级，不套用剧本正文的 `△` 或镜号。

`△` 是文本里的可见画面单位，不规定机位、焦段、设备、运镜或真实拍摄切法。同一观察重心里可以写连贯表演；当观察对象、空间关系或观众需要辨认的画面证据改变时，才另起 `△`。画面已经给出限制、关系或结果的可见证据时，不用场外作者说明替观众复述其含义；但人物可以用有关系目的的对白、动作、括注或声音侧面呈现同一事实，或让它产生新的理解。证据不够时先通读整场，查看对白、动作、表演、声源、空间和前后文分别承担什么，再选择最自然且符合人物立场的渠道补足，不默认只能补画面。例如“试雨→身后撑伞→伞下只遮住部分身体”依次呈现试探、回应和空间限制，可按三个画面重心各写一个 `△`；人物随后仍可借这段距离调侃、遮掩或确认关系，不必用作者说明替观众总结。旧稿已有 `M` 或项目已选用的其他编号时兼容并保留，不把旧约定改写成全局默认。`P` 只在用户明确要求按视频生成时长切分剧本时进入分段方案；它是视频内容段，不是 `△`、`M` 或场号。

### 层级先分清：集、场、动作与画面

- **集 / 幕 / 段落**组织长篇作品的阶段和观看节奏。幕数、页数、分钟数随媒介、平台、制作方与用户规范确定；没有指定时只用一致、可读的组织方式，不虚称通用标准。
- **场（scene）**围绕一个连续的主要行动或观察重心展开。地点或时间切换常会新起场，但是否拆场仍看行动、知情和戏剧目的是否真正改变。一场戏可有多个 `△`，也可以包含同一空间中的连续表演。
- **`△`** 默认是一个清楚的可见画面/分镜单位；同一观察主体与空间/信息重心下的连续动作可以放在同一 `△`。如果用户/项目已经确认它表示连续可表演动作块，则按已选定义。整稿保持同一含义。
- **动作节拍不等于画面切点。** 不为每个动作动词或每句对白新起 `△`；只有观察重心、重要空间关系或需要观众看见的证据发生变化时才分开。镜号和摄影机参数仍由用户/项目指定的制作层级决定。

文字要让读者知道此刻看见什么、人物处于什么关系和关键状态怎样变化，同时保留同一观察重心内的动作连续性。

### 基础排版合同

按项目规范确定场号、内外景、地点、时段、人物、动作、声音和台词的顺序。没有既定样式时使用稳定、可定位的结构：

> - `S01`　内/外·地点·时段（剧集可用 `E01-S01`）
> - 出场人物：只在有助定位场内关系时列出
> - `△` 可见画面、连续动作、空间关系或必要声音
> - 人物名（需要时给可表演的语气、表情或短动作）：台词

场头给能帮助制作或理解的时空信息。人物第一次出现若身份或关系对理解剧情重要，可在场面中简明标明；不把每次出场写成人物小传。场次编号在改稿时保持稳定，插入场次用项目接受的后缀/新号规则，不因排版重排让下游定位失效。

### 动作块写什么

动作描述由“谁在何处做什么—看见/听见什么—造成什么结果”构成。动笔前在脑中走通人物如何发起动作、动作如何发生及其结果，再用准确自然的动词和对象承载人物的具体体验；分别复核动作是否能成立、中文表达是否准确。只有当关键动作或连续性需要时，才具体写到手部、物件位置、接触方式、方向或作用力；普通动作保留足以让读者想象、让演员实现的过程。只有会影响观众理解、人物选择、连续性或下游执行的对象才写入；一个动作已经清楚时不再用场外作者说明复述。心理状态可用合适体裁的叙述保留，也可用可见行为表现，不强迫文学剧本变成纯客观摄影报告。

人物位置、朝向、视线、持物、出入口、动作方向和场尾状态在后续场面需要继承时写明。人物或物件的位置/状态发生变化时，交代其已成立的触发、接触或作用力，再写移动结果和对方反应；若变化会影响观众理解或后续连续性，不能只让新结果无因出现，也不能为填空捏造未建立的原因。

对白通常写成“人物名（可表演的语气、表情或短动作）：台词”；括注放在台词前，包含会改变观众对当前意图或关系的判断、演员实际能完成的提示。**关键回合**指会改变人物处理关系或作出选择方式的承重台词，包括试探、遮掩、露馅、承认、拒绝、邀请或态度转向。关键转向由台词完成时，在该句人物名后写明角色当下意图及可演的身体/声线提示；逐一把各人物的策略变化对照到具体台词行及其括注，不能以同步动作、前一 `△` 或全场整体可演替代。没有承重转向的普通台词不必重复标注；不以抽象情绪词代替具体可演提示，也不为每句台词填标签。若用户要求逐句备注，按其明确交付要求执行。

### 声音、文字与主观时空的标法

用读者能直接看懂的中文标明特殊声源；只有既有项目格式要求时才附 `O.S.`、`V.O.` 等缩写。台词前说明谁在说、声音属于什么空间/媒介、画面当前呈现什么；声源持续或停止的位置影响理解时标出起止，不为每句对白增加声音标签。

- **同场画外声**：人物仍在当前场景与时间中、但不在画面里时，写“人物名（画外）：台词”；不要把画外声和画外时空旁白混为一类。
- **内心独白、旁白与跨时空声音**：分别写“人物名（内心独白）”“旁白”或明确的来源（如某时刻留下的录音/回忆声）。标明它与当前画面的时间关系以及谁能听见。项目已采用 `V.O.` 时沿用并在首次出现处解释具体含义。
- **电话、广播、电视、扩音器或录音**：标清说话者/声源和“电话声”“广播声”等形式，同时写出观众此刻看到的画面、故事内哪些人物听得到、声音何时接入或停止；不要让读者猜画面是在说话者处还是接听者处。
- **同期声、音效、配乐与沉默**：需要区分时写清来源、谁能听见、遮蔽关系和停止点；沉默只在改变等待、知情或关系时标出，不为格式要求每场写“静默”。
- **屏幕文字/字幕**：明确文字出现在哪个载体、谁能看见、是否为台词字幕或剧情内文字。手机信息、标牌、字幕、片头/片尾文字不写成角色说出的对白；文字内容影响剧情时准确照录。
- **声音转场**：说明声音从何处进入、跨过什么画面或时空、何时落到实际声源/停止；只在此关系会影响理解时标出。

### 回忆与梦境要成对闭合

使用回忆或梦境时，为进入、持续范围和退出提供同一套清楚标记。每场或每段都能被读者认出发生在何时何地；结束时重新建立现在时空：

- 回忆入口标作“回忆开始”并带必要的过去时间/地点；结束标作“回到现在”，重建当前时间、地点、人物身体状态、动作与关键物件状态。
- 梦境入口标作“梦境开始”；退出标作“梦境结束/醒来/回到现实”，并交代醒来时的现实地点、身体反应与当下行动。梦中事件不会自动成为现实事实；只有梦境改变了人物醒后的感受或选择，才把这一影响写入现实场。
- 若回忆/梦境跨越多场，所有范围内的场头持续标示其时空；最后一场必须成对结束，不把读者留在未经标明的时间线上。
- 作者有意让现实与梦境暂时难辨时，可以延迟揭示，但要在后文给出可追溯的判断线索，并确保每一段实际行动仍符合其真实时空。

摄影机移动、焦段、镜头长度、灯光器材或剪辑时长属于进一步制作指令。只有用户要分镜方案、导演阐述或制作规格时再细化；镜头脚本里也只写当前创作交付确实需要的参数。

### 场、集、画面与分段编号

用户未提供编号格式时，按作品层级采用可读且可定位的编号：

- 独立长片/短片以 `S01` 标记第一场，后续为 `S02` 等；短片不额外加 `E`。剧集按已确认的集号与场号写作 `E01-S01`。已有格式不同则沿用项目现有规则，不批量转换。
- 如项目需要区分同一连续场内的子段，可依其已确认格式用 `S01A`/`E01-S01A`；若时空或主要行动已经改变，应另起场号，不用字母掩盖真正的新场。
- 新写稿默认 `△` 标画面单位，不附 `M`。只有用户明确要求逐镜编号，或已有确认工程格式要求时，才在场号后按该格式标 `M01` 等；沿用已有 `M` 时保护原号，不静默重排。
- `P` 只用于用户明确要求按视频生成时长切分的内容段方案，和 `S`、`E`、`M` 分属不同编号空间。没有该请求时不在剧本正文添加 `P`。

编号服务阅读、修订和交接，不决定每场时长。改稿时尽量稳定既有号；新增场按字母后缀插入或按项目指定方式处理，并检查相关交叉引用。

### 可复制模板

普通完整影视剧本可先给必要的前置信息，再按同一 `△` 语义组织正文：

    标题：
    预估时长：
    一句话故事：
    背景（仅填写理解剧情/关系所需内容）：
    人物表
    |姓名|性别|性格/声口|关系|
    |---|---|---|---|

    S01  内/外·地点·时段
    出场人物：（确有定位需要时填写）
    △ [一个清楚的画面/观察重心；同一重心内可写连续动作]
    人物名（需提示时写可表演的语气、表情或短动作）：台词
    △ [观察对象、空间关系或重要画面证据发生变化时另起]

局部正文或用户明确只要正文时，只交指定场次/片段，不加完整前置信息包。若用户/项目明确要求逐镜编号，在对应 `△` 处按已确认格式补 `M`；用户未要求编号时不加。舞台、音频或其他媒介按其明确体例替换场头与声音字段。

## 完整剧本的前置信息与可选附件

普通完整影视剧本默认在正文前提供这五项：

1. **标题**：沿用用户/项目已有名称；没有时可给清楚标为暂定的工作标题。
2. **预估时长**：按当前剧本文字、动作与停顿核算并标明为预估；用户给出的时长另作目标记录，不能直接当作当前稿的估计或达标证据。按需读取[逐字预算估时与并行事件核算](segmentation-and-handoff.md#逐字预算估时与并行事件核算)，只估时不触发 P 分段。
3. **一句话故事**：用一句话交代核心人物/群体的行动及主要阻力或关系变化，让读者知道故事承诺。
4. **必要背景**：只解释理解故事行动和人物关系所需的事实、时代条件或规则；没有额外背景时可省略该项，不用补作者阐释。
5. **人物表**：普通完整影视剧本须以 Markdown 表格呈现，列依次为姓名、性别、性格/声口、关系；每位人物的信息须落在对应列。写到帮助辨认和读戏为止，不复制内部人物卡，不用人物简介替代正文中的行动证据。

用户明确说“只给正文”、只要求局部片段/一场/几句对白时，交付范围不变，也不强塞上述完整剧本前置信息；若用户只要正文，正文前不加体例说明、制作资料或内部人物卡。用户已提供这些材料时直接整理，不为填表而重复或捏造。

短梗概/完整梗概、风格与叙述说明、分集梗概/后续规划、待定选择仅在用户所需接收任务能从中受益时附加。故事雏形、提案、系列开发文件和分场大纲仍按各自层级组合内容，不套用完整剧本前置信息。创作说明不是作者为作品辩护，也不能规定观众只能怎样理解。

## 产物、验收与返回

按本轮体例和编号规则输出用户要求的正文、梗概或结构层级；只有存在歧义时才补充说明媒介、交付层级或 `△` 含义。完整交付完成后，从标题、一句话故事、背景、人物表到正文顺读一遍，检查内容准确、中文自然、指代清楚、人物资料与正文一致；人物表的性格/声口应是读者可以直接理解的短句，而非内部分析标签。验收还检查：普通完整剧本含默认五项前置信息，且实际有人物表 Markdown 表格，姓名、性别、性格/声口、关系各列存在且对应；关键回合都逐项对应到台词行和人物名后括注；局部/只要正文没有被扩成整包；`△` 观察重心清楚且同一观察重心的连续动作没有机械拆开；新稿未无故增加 `M` 或 `P`；既有编号稳定；场头、声音来源和时空闭合足以让接收者理解；镜头参数与附件没有越出用户要求。

故事层级不清返回主 Skill 的故事开发/整体结构步骤；动作块与台词需展开返回 [场次展开](scene-development.md) 或 [对白与视听](dialogue-and-audiovisual.md)；剧本排版导致审稿或连续性错误，返回 [全稿审读与修订](review-and-revision.md)。完成后回主 Skill 交付。
