# 剧本格式与交付：让接收者知道读到哪一层

选择交付层级、版式或附件时读相应章节。起草和审查影视正文时读[动作块写什么](#动作块写什么)，把结果写回当场正文。沿用用户指定体例和既有编号。P 分段双文本与模板由 Video 维护。

## 先定交付层级

只交用户当前要判断或使用的层级，不把完整开发包压给局部正文任务。

| 交付 | 内容边界 |
|---|---|
| 故事概念（步骤1） | 用自然段说明类型/背景、承重人物、行动、阻力、失败代价、结局方向和独特看点；不展开逐幕事件。用户称“一句话故事概念”仍交故事概念，不自动另附 logline。 |
| 三幕故事纲（步骤2） | 分第一、二、三幕写清大事件因果并到实际结局；不含对白、动作细节、环境、场头或节拍。只标真正影响方向的拟案/待定项。 |
| 转折/序列结构纲（步骤5） | 按幕列转折点与序列，写明前因、目标、阻力、结果和承接；不提前拆场或列行动节拍。 |
| 扩纲（步骤6） | 普通扩纲补承重行动与前后因果。采用工业二幕扩纲或用户明确只扩第二幕时，保持第一、三幕原定内容，只扩第二幕并核算字数与占比。 |
| 分场纲（步骤8） | 按实际连续时空写场头、人物目标、行动与场末变化；只在内部需要或用户明确要求时细拆节拍。 |
| 普通剧本正文（步骤10） | 只交获批范围的连续正文和场次；附件另行要求时另列。 |
| 系列开发包 | 只在用户要求系列/分集规划时提供系列引擎、关系、季弧或分集纲 |
| 逐镜稿 | 只有用户明确要求或项目工程格式已确认才编 M |

按[本轮交付与停点](../SKILL.md#先确认本轮交付与停点)选择模板。未指定正文或更深阶段的普通新作默认先交概念和三幕纲，委托完整开发到审纲时按步骤1–9交当前纲稿。本轮明确交正文时在内部完成必要准备后接步骤10。人物、研究、地点与预算只在当前阶段或接收方实际需要时单独交付。

### 各层纲稿给用户看什么

概念交代故事规模和可感卖点，三幕故事纲交代大事件因果和结局，结构纲组织转折与序列。扩纲按所选步骤6分支补足承重情节，普通扩纲可修补尚未锁定且后段依赖的伏笔和因果。分场纲才按连续时空拆场。分别标记事实、作者拟案和确会影响当前结构的未知。线索承诺、证据路径或受限规则实际承重或用户要求时，说明来源、人物推论和回答位置。纲稿供创作者判断结构，观众通过正文接收信息。

### 稿件体例的优先级

1. 用户本轮指定体例优先，其次沿用该稿/项目已确认体例和编号。
2. 未指定时，普通影视正文用本项目的 △ 画面描述体例；△ 不等于镜头参数或镜号。
3. 用户选择舞台、音频、连续动作块等其他体裁时按该体裁，不把影视格式强加过去。
4. 旧稿已有镜号、场号或其他编号时保留可追溯含义，不静默删号、改义或批量重排。

### 普通任务的起稿预算与纲稿单位

各阶段开发字数预算、分档和停止点以[主 Skill 执行步骤](../SKILL.md#执行步骤)为准。未定片长且只要概念或三幕粗纲时，仍用500/1000字起稿基准。结构纲未定片长时沿用步骤5的默认档。采用[工业开发口径](../SKILL.md#按交付选择开发尺度)，且片长会改变二幕扩纲定额、总场数或配场比例时，按对应步骤确认片长。保留所选定额及配场核验，按步骤9确认本轮交审或接正文。

已明确总片长时，分场用观众实际接收、连续时空和单集/短片播放预算核对场界与总时长。轻体量与局部请求按[步骤8的时长条件](../SKILL.md#先决定时长怎样约束本次分场)处理：需精确对齐而缺总时长时，先确认这一项；只要观察当前场或前后行动时，沿已有材料推进并说明适用的规划预算。开发字数、场数和实际播放时间分开统计。分场预算与正文估时共用[逐字预算估时与并行事件核算](../../laohu-video/references/segmentation-and-handoff.md#逐字预算估时与并行事件核算)，纯纲标为规划预算，独立 P 分段由 Video 承接。

### 层级先分清：集、场、动作与画面

工业开发沿主文十步接续。按当前范围交结构纲、二幕扩纲、地点名册或分场纲。不同起点按[主文分流](../SKILL.md#先确认本轮交付与停点)补齐所求层级的实际依赖。概念、三幕纲和结构纲止于各自的行动尺度，场和关键节拍留给分场及后续层级。

正文内部按幕或序列、连续时空场次、相邻行动与回应节拍组织。三幕是本项目普通故事默认，用户或项目已定其他结构时照用。普通影视场次以连续时空为边界，地点或时段真实改变时另起场头，场内主要行动或观察重心改变继续沿用本场。回忆/幻想中仍保留适用场头。连续行动中的内外切换可用清楚的内/外场头承接。一个场可含多个画面段和回应节拍，按实际观察和行动连接组织。P 用于用户明确要求的视频时长分段；分段方案和完整映射见 [Video 分段与下游交接](../../laohu-video/references/segmentation-and-handoff.md)。

### 剧本正文的默认 Markdown 层级

完整正文按集/作品 H1、场按 H2；标题沿用用户/项目名称与场头。独立短片不虚构集号；局部正文只输出已知层级，不编造全篇 H1、集名或场名。H3 可用于正文确有必要的小标题，不能拿来冒充机器段界。

普通剧本默认不分 P。用户明确要求按视频生成范围切分或比较方案时，由 Video 产出分段设计说明和逐字保真分段剧本；本 Skill 只在收到已确定 P 后按这里的有效正文格式编排。人读方案的 H3 标题可用“第一段（P01）”标示段号，但只是阅读层级，不是机器分隔符，也不能代替 `---`。用户要求整理为普通剧本 Markdown 时，沿用已确认段界：同场真实 P 边界转为单独一行 `---`，跨场保留每个原场头且不加分隔线；不重复正文。来源/估时/上界/制作交接短注、资产事实和作者说明都在剧本正文之外。完整剧本无用户可用标题时才使用中性正文标题。

### 基础排版合同

场头按项目已定格式写场号、内外景/地点/时段及必要出场人物；角色名、括注和台词的顺序保持全篇一致。出场表仅在有助定位或用户/接收模板要求时附。附件与正文分开，不为“完整”自动附人物表、简介、背景、提案或制作资料。

### 动作块写什么

普通影视剧本的 `△` 写可见、可演或可听的事实。**有尾必有头，有头可留白。** 后文实际用到的物件、人物状态、设施或特效结果，须在前面给出可见来处、初态或自然过渡。观众能接上时，让蒙太奇略去过程和无关去向。改造物用一两笔写出生动成品。手里还攥着小物而用双臂托举，画面成立就保留。高潮按该场承诺给当事人可感的反应。

| 发现动作块在写 | 落到声画的做法 |
|---|---|
| 念头的起止 | 写目光转向哪里、手在哪一步停下、到了什么时点又接着做事。 |
| 作者代述人物意图 | 写人物实际靠近或避开的对象、先递出或扣住的物件，再接开口或对方回应。 |
| 抽象局势或结果 | 交出能证实变化的物件、屏幕、环境声或他人行动，并保留可辨的反馈。 |
| 纯内心感受 | 先从站位、动作力度、呼吸、停顿及物件互动显出变化。主观感受本身须让观众听见时，由符合体裁的 `V.O.` 承担。 |
| 未发生的动作或编剧评述 | 写眼下真正发生的动作，或删去冗余。等待落空、画外声突然中止等有声画证据的缺席，可写出等待对象、可感停顿或现场结果。 |

给视线和身体反应具体的触发对象和时点。用动作、距离和气息辨认不同处境。诗性比喻可落到可感的光、声、物或行动。主观声音见[让观众听见人物怎样想](dialogue-and-audiovisual.md#voice-over-reasoning)。

#### 按风格写可见过程

沿本作媒介与画风，随场面和当下情绪调节力度。同场也可从喜剧或奇观转入安静的反应。动画可用鲜明表情、弹性形变或骤停。奇观承重时写清可见的触发、演变和效果。写实戏用站位、呼吸、日常动作和现场声给潜台词留空间。

#### 按观察重心分段

同一观看重心下的连贯动作、共框回应和连续相位留在一个 `△`。求援使对方转念时，让求援段落在递物或视线，另起段从对方最早可见的反应写起，再接其行动。并行动作各有落点、关键证据需要看清或动态骤停时，也按观看重心分段，以视线、动作、物件或声音相接。正文给观看重点和衔接，镜头与分 P 由 Video 承接，M 按已定体例。

#### 首次出场视觉锚点

主要人物、核心道具和固定主场景首次看清时，随动作落一两笔。用能带到后场的轮廓、衣着、惯有动作、标志物或空间印象立住辨识度。若换场只认得职业或一时的神态，回初见补一处已定或可在本轮决定的可见特征。已有可辨形象就收笔。剪影、遮挡或秘密身份按原时点揭示，复现只带必要的变化。精确造型交 Assets，普通过场和局部改词沿任务范围。

### 台词行与表演括注

**括注点出表演的要害，不重复台词的表面。**表演括注写在人物名后、冒号前，只在需要着重突出本句情绪或表演转向时出现；普通应答及上下文已经清楚表达的状态不加，不把每段填满作为格式目标。声源标记另按下节执行，不因没有表演括注而省略必要的 `O.S.`、`V.O.` 或设备来源。用户指定其他体例或只准逐字保留源文时，遵守其范围。

落笔先连读触发动作、前一句、本句和对方回应，明确人物此刻要影响谁、争取什么，以及他愿意显露或正在掩饰什么情绪。这些是作者内部的表演依据，不原样填进括号。随后确定本句需要着重表现的区别：情绪在此刻突变；嘴上所说与实际态度相反；人物正在压住情绪却露出破绽；或一句话的停顿、重音、伴随小动作决定观众怎样感到这一刻。属于这些强调处，再从已建立的人物与现场条件中选一个最能承担该区别的表演信号。

将信号写成自然、短小的中文：用动作动词写说话如何起、停、抢、忍或失控；涉及目光和小动作时写清实际对象；变化发生在某个词或答复之后时写出时点。声音表现可选重音落点、话被哽住、没说下去等实际差别；身体表现可选目光回避、笑容中断或手上动作停住等当场可见变化。这些是选择维度，不是每句必配的动作词表。只写会改变这句情绪理解的部分，不把语气、表情、肢体和目的拼成清单，也不以堆叠形容词换取细腻。简短情绪词在前后场面已把含义和转向建立清楚时可以成立；不把“低声”“冷冷地”等词列成禁词，更不靠补更长的身体描写自动提高质量。

声源与表演在同一括号并列时用分号分开。只有声音可被接收时，选择听得出的情绪信号，无实体AI不凭空做身体动作。内心声音只有需要突出其情绪或思路转向时加表演提示；系统提示沿用既定播报方式，不逐行附“平直、匀速”，只有异常变化对情节有作用时才强调。录音的表演属于录音中的说话人，不能随现场听者的反应改变。

括注只容纳与说出本句紧密相连的提示；独立发生、涉及多人交互、改变空间或物件状态、需要看清过程的动作放进 `△`。不为增加画面感发明无关姿势，不重复抄写相邻动作，不让括注提前泄露尚未触发的反应或隐藏事实。交稿时将括注连同前后回合读回：只有删去会丢失需要强调的情绪差别或造成关键误读的提示才保留；只是重复台词已有的怒、急、轻，或给已发生的应答再写一遍“应了一声”的提示删除。需要强调却仍只写笼统评价时，回到该句的表演依据，改成能演出或听出的区别，不继续加同义形容词。

本地取法：Judith Weston《Directing Actors》及其本人总结用动词、事实、意象、身体生活和事件帮助演员进入过程，不把所求情绪结果直接当作表演办法；此处把它用于先定情境与对人行动，再选必要信号。John August、Craig Mazin《Scriptnotes》第533期区分影响读法的括注与需独立展开的动作；本项目不把其英文篇幅经验改成中文字数上限。《Big Fish》最终拍摄稿第194场以“voice cracking”标明儿子在父亲去世后打电话时开口哽住，周边动作承担完整的悲伤过程；这个局部选择用于说明情绪在说话中怎样显露，不是每句都写哽咽或每场都添动作的模板。

### 声音、文字与主观时空的标法

依次核声源类型、剧中谁听得见、真人是否入画。同一时空、场内听得到的画外真人对白在人物名后标 `O.S.`，可再加空间说明，入画后取消。场内听不到的内心声音与旁白标 `V.O.`。电话、录音、广播等传声及非人角色按实际设备或声源标注，沿用各自标记。首次接入或换声源时交代，连续回合沿用，表演提示另按上节。

跨场由画外入画且需写听者前后位置或反应时，先读[场次衔接](scene-development.md#场与场之间说明连接依据)和[画面与声音各自提供证据](dialogue-and-audiovisual.md#画面与声音各自提供证据)，再落实两端声源与听者反应。只问标点或代号时直接用上段标法。

屏幕文字放在标明载体的 `△` 画面描述中，并注明剧情内谁能看见，不写成角色对白；若可见范围影响情节，后续画面、摄像头、转述或记录须按已建立的接收权限处理，不能无意改变谁能看见。用户明确锁定的能力/权限限制须连同作用范围保留；当前屏幕处在视野外、未同步或某次未接通，只说明本次读取条件，不能替代“该通道不能取得”的限制。角色据此行动时，让其依据适用的既定规则或实际检查及反馈；未核实的通道留作未知，不把作者设定逐项写成人物已检测的事实。用户本轮指定或该项目已有明确声源体例时按其约定处理；其他情况下采用以上项目默认，不混用标记。

### 回忆与梦境要成对闭合

回忆写“回忆开始”与“回忆结束（回到现在）”；梦境写“梦境开始”与“梦境结束（醒来/回到现实）”；幻想写“幻想开始”与“幻想结束（回到现实）”。退出时重建现实时间/地点、身体状态和当下行动。跨场持续时各场头保持时空标示；主观时空不自动变成现实事实。

### 场、集、画面与分段编号

沿用项目编号；无既定编号时，长片/短片场号用 S01 起，剧集按 E01-S01 等格式。新增场按既有规则插入，不为排版重排旧号。无明确要求不加 M 或 P；P 与集/场号、镜号分属不同编号空间。P 的来源映射、跨场延续、资产事实接口和每 P 一条提示词规则均见[分段与下游交接](../../laohu-video/references/segmentation-and-handoff.md#p-标识来源映射与阶段交接)。

### 可复制模板

以下占位模板与主 Skill 十步一一对应。按用户本轮所需层级只复制对应模板；早期故事纲和结构纲不含场头、对白、△、环境细节或节拍编号；只有分场纲或用户明确要求关键行动节拍时才下钻。花括号内容由实际稿件替换，不是固定故事示例。

**步骤1｜故事概念**
```text

# {作品名}
故事概念：{用自然段写类型与背景、承重人物、行动、阻力、失败代价、结局方向和独特看点}
已定材料：{只列会影响当前概念判断的锁定项}
作者拟案 / 待确认项：{只列真正会改变故事方向的内容}
{仅当用户明确要求1–2句logline/提案时另加：Logline：主角+目标+主要阻力+赌注}
```

**步骤2｜三幕故事纲**

```text
# {作品名}
第一幕｜建置：{从人物初始处境写到主线由何事件/决定启动}
第二幕｜对抗：{人物行动、阻力回应、策略变化与代价递进}
第三幕｜结局：{危机选择、高潮行动、实际结果及必要余波；写到故事实际结局}
作者拟案 / 待确认项：{只列仍会改变方向的选择}
{线索、权限、信息差及钩子兑现表仅在这些内容实际承重或用户明确要求时附}
```

**步骤3｜实际调研项**

只有实际核读并能定位的来源才填写为研究结果。已有的一手资料足以回答时先据此核查；缺少相称证据时检索并阅读可靠来源。未取得资料的项目写成未知及其创作影响，不以模型记忆、搜索标题或待查问题代替结论。

```text

可定位来源：{机构/作者；资料或作品标题；发表/更新日期；URL、页码、章节/场次或其他可复核位置}
查明结论与仍未知：{……}

```

{按该片长/方法增删，转折点与序列分别编号}

第三幕｜{同一结构}
字数预算（工业扩纲）：{起稿预分配；交付回填实稿 I幕a、II幕b、III幕c；E为步骤6扩纲总目标；I+III合计a+c及其占E的比例；确认锁定I、III；II幕当前b、扩纲目标E−a−c}

**步骤6｜第二幕扩纲**

此模板用于工业二幕扩纲或明确只扩第二幕的请求。普通扩纲以承重情节与因果为单位，沿用已确认的幕序和必要篇幅。

扩纲模板只承载故事层级的大事件与因果。写清每段事件的前因、人物选择、阻力、结果和后续改变；不写对白、具体表演动作、场头或逐场环境/场景描写。第二幕前段、中点改向、后段是结构段落，不是场景编号。

```text
# {作品名}
目标总字数：{……}
第一幕：{沿用步骤5，不扩写}｜{字数，占比}
第二幕前段：{新增的事件及其改变}｜{字数}
第二幕中点改向：{承重事件、前因与新策略}｜{字数}
第二幕后段：{新增阻力、代价及终局条件}｜{字数}
第三幕：{沿用步骤5，不扩写}｜{字数，占比}
总计：{各幕字数与占比核算}
```

**步骤8｜分场纲**

采用工业配场或用户明确要求第二幕比例时，填写片长、场数、各幕比例、硬约束可行范围、两项比例和分配/偏差。轻体量按确认的播放预算安排实际连续时空，沿用下方场次字段，省去工业比例行。片长待定时按[本轮时长条件](../SKILL.md#先决定时长怎样约束本次分场)处理，规划值按其实际依据标识。

分场先用[场面卡](scene-development.md#用场面卡写清过程)把观众前后的认识和感受、听到或看到的依据、承重互动及反应时间安排好。交普通分场纲时，将结果并入事情经过、结束局面和播放预算。用户需要场面卡或细拆时再交相应细化层级。

```text
# {作品名}
确认片长：{T}｜总场数：{N}｜各幕场数与比例：{……}
硬约束可行范围/参数关系：{N1+N2+N3=N、各幕至少一场、N1>N3；用范围/参数关系概括，不列全部排列}

第一幕｜{幕目标与结果}
序列{编号}｜{序列目标/结果}
场{编号}｜{内/外·固定地点·时段}
在场人物：{……}
各自目标：{……}
事情经过与阻力：{……}
结束局面及与下一场的因果关系：{……}
播放预算：{……}

```

**步骤10｜剧本正文**：沿用下方正文模板。完整工业开发或用户明确选择四批写作时，内部按第一幕、第二幕前段（含中点）、第二幕后段、第三幕制作并分别自审。轻体量按场次顺序连续写作，在需要保留关键动作、对白和声画衔接处检查。最终交付为连续正文，批次和大纲标签留在作者内部。

**普通剧本正文**：完整稿有标题容器；局部摘录不虚构。每个动作/画面描述段都以△起始；普通台词直接写“人物名：台词”，情绪需要强调的台词才加表演括注，具体选择按[台词行与表演括注](#台词行与表演括注)。声源按实际接收关系标明，不因缺少情绪强调而删去。回忆、幻想的出入成对。人物卡、研究、步骤说明不进入作品正文。完整剧本交付时，按[运行约定的可复制交付规则](../../../../docs/runtime.md#聊天中的可复制交付与媒介呈现)将连续正文整体放入一个代码块；作品/集/场标题属于正文，审稿结果、用途说明和必要附注置于块外，不拆散正文或混入作者说明。

```text
# {作品/集标题}
## {第一场：S01 或 E01-S01} 内/外·{地点}·{时段}
出场人物：{确有定位需要时填写}
△ {从空间/观察位置写可见刺激、行动、回应及余波}
{人物名}：{普通台词}
{人物名}（{只在此句情绪需要强调时填写的具体表演提示}）：{需要强调的台词}
△ {观察对象或可辨信息变化后另起}
{人物名}（O.S.）：{同场画框外真人对白；场内人物听得见}
{人物名}（V.O.）：{叠在画面上的内心声音/旁白；场内人物听不见}
{人物/非人角色名}（{电话声/录音声/车载语音等实际来源}）：{剧中人物听得见的设备传声}
{人物名}（{必要声源标记}；{确有情绪强调时的可听表演提示}）：{声源与表演需同时标明的台词}
```

## 按接收任务另交简介或制作附件

用户明确要求提案、读稿或制作资料时，按接收者要作的决定另列必要字段；事实未定标为待定，附件不混入作品正文。用户给定时长是目标；现稿估时按[逐字预算与并行事件核算](../../laohu-video/references/segmentation-and-handoff.md#逐字预算估时与并行事件核算)另行计算并标为预估。

用户要求用已定稿的剧本准备资产与视频制作资料时，按父级的[动画与世界规则交接方法](../skills/laohu-script-world/SKILL.md)取场次事实与状态节点，依本节单独交付所需附件。Assets 决定资产归属、复用与持续状态，Video 承接估时、分段和镜头设计。短片与动画剧本沿用本文件的连续时空、场头和 `△` 规范；实际采用的开发轨道由父级决定。

## 产物、验收与返回

按指定体裁、范围、编号及模板交付；局部稿不扩成完整资料包。交付前核对正文/附件分离、场头与编号稳定、动作画面段 △ 完整、声音及时空出入可读。动作因果与连续性详见[场次展开](scene-development.md)，全稿审阅返回[全稿审读与修订](review-and-revision.md)。
