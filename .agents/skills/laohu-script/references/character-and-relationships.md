# 人物与关系：目标、价值和声音

当故事人物还像功能标签、行动动机不清、关系变化不可信、对手只有阻碍作用，或所有人物说话像同一作者时读取。返回人物行动模型、关系动力、冲突来源、变化范围和可在场次中体现的声音差异。

## 人物不等于人物小传

人物建模只收集会改变当下行动、关系、选择或台词的信息。身份、身体、阶层、历史、欲望、需求、价值观、习惯、品味、偏见、恐惧与矛盾可提供不同证据；不为填写档案而追加与剧情无关的传记。

Lajos Egri 的三维人物观（《The Art of Dramatic Writing》“Character”部分）提醒创作者兼顾生理、社会和心理条件：身体限制、处境资源、教育关系与内在信念会共同改变行动。三维是观察人物的入口，不是必须写满的清单，也不应将群体身份推成固定性格。

John Truby 在《The Anatomy of Story》中把弱点/需求、欲望、对手、计划、战斗、自我揭露和新平衡组织成相互牵引的故事构件。若本稿要设计一条完整主角弧，读取 [叙事与结构](narrative-and-structure.md) 中的 Truby 七项关系图，逐步检查外在目标怎样受人物弱点和对手影响、计划怎样经冲突失效、结果怎样改变人物理解与结局状态；人物变化可以成为故事核心，也可不是作品的主要驱动力。

## 角色行动：相信什么，打算怎样，实际做什么

对每个关键人物分别记录：

| 维度 | 检查问题 |
|---|---|
| 当前目标 | 此时想得到、避免、保护、证明或改变什么？ |
| 价值排序 | 两件重要的事冲突时，哪一个更优先？这个次序从哪里可见？ |
| 解释方式 | 人物注意什么证据，忽视什么，以何种偏见或经历解读它？ |
| 策略 | 如何获得目标：直接说、试探、讨好、隐瞒、拖延、控制、拒绝、表演、退出等？ |
| 边界 | 什么事即便有利也不肯做？什么条件会使其跨过界线？ |
| 代价 | 行动会伤到哪段关系、信念、自尊、利益或安全？ |
| 矛盾 | 公开宣称与私下欲望、品味与阶级位置、亲近与控制、忠诚与怨恨等张力如何具体化？ |
| 可见证据 | 观众从什么动作、选择、停顿、称呼或回避看见上述判断？ |

Stanislavski 的“Units and Objectives”与“Super-Objective”可作为表演排练的行动语言：《An Actor Prepares》讨论每个片段中的目标、行动与回应如何彼此牵引。书中写道：“Every action meets with a reaction which in turn intensifies the first.”（自译：每个行动都会遇到回应，而回应又加剧第一个行动。）在剧本层把抽象情绪翻成可表演的意图和对方可感回应；不能把演员训练法升格成剧情必须连续升级的定律。

角色因果核对：他当时知道什么？相信什么？有哪些可行办法？为什么选择此策略？若某行为只在编剧知道隐藏真相时才显得聪明，须补人物可获得的证据或调整选择。误判可成立，需让误判有来由并产生后果。

### 内部人物卡：让同一个人进入后续场次

新故事或新剧本开始时，先为关键人物建立一份供编剧内部复用的人物卡；已有稿件则从人物已写出的行动、对白和关系中提取，不用新编传记覆盖文本；局部修改只更新直接受影响的人物。卡片是生成与连续性检查的中间材料，不自动作为独立人物资料交付，也不自动转成视觉资产。

卡片只记录会改变选择或表演的维度：

| 维度 | 记录什么 |
|---|---|
| 身份与处境 | 身份、当前资源、限制、所处关系和他当下能做的事 |
| 欲望与需要 | 眼前想取得/阻止什么；较长期缺少或回避什么，两者如何拉扯 |
| 价值次序与盲点 | 重要事项冲突时先保什么；缺陷、偏见、误读及其代价 |
| 禁区与成本 | 不愿做什么、越界条件是什么；选择会损失哪段关系、利益、自尊或安全 |
| 压力下的惯用行动 | 受到何种压力时会怎样解释、先用什么策略；策略失效后会升级、退缩还是换法 |
| 关系权力 | 对不同对象能要求什么、依赖什么、怕失去什么；谁控制信息、时间、空间、资源或离开的资格 |
| 声口 | 句法和句长、熟悉词汇、称呼、语域、口头习惯、回避词句，以及不同关系下的停顿、抢话和改口方式 |
| 稳定与可变 | 可识别的性格底色、情境触发的状态变化，以及本故事已证明的变化证据 |

从故事文本能确认的内容标为已建立；推断只作暂拟，缺少文本证据的前史留作未知。短片可以保持性格底色，也可以在因果充分时出现转折；长篇也不能靠篇幅替人物漂移开脱。仁、义、礼、智、信只在用户选择这一价值镜头或它确实帮助本稿作取舍时使用，不作为所有人物必填的性格标签。

易卜生《玩偶之家》第三幕中，海尔茂收到信后先把注意力放在自己的名誉；危险解除后，他随即想恢复原来的夫妻生活。娜拉没有因为威胁消失而回到旧位置，而是在谈话中判断双方关系并作出离开的选择。此例的可用机制是：两人对同一事件的价值排序不同，关系危机显出既有立场，人物再以有代价的行动兑现自己的判断；它不规定所有故事都要让人物离开或完成成长。

## 人物关系是一张持续变化的利益网

写关系时不止标明亲属、同事、恋人、师徒或敌对。还要辨认每一方在关系里求取、提供、隐藏、占有、交换或拒绝什么；他们是否共享历史、误解、义务、秘密、亏欠、信任、身份或权力。关注同一关系的双方如何用不同标准理解它。

对重要场次问：

1. 谁向谁提出什么要求？
2. 对方为什么接受、拒绝、延迟、误解或改变要求？
3. 谁能决定资源、时间、空间、称呼或信息？
4. 行动后关系的距离、责任、信任或控制权具体变了吗？
5. 没变化是否正是本场要呈现的僵持、习惯或被压住的情绪？

冲突不必表现为争吵。互相爱护但对未来判断不同、利益一致而方法相斥、表面和气而控制权不对等都可构成关系动力。亲密、冷漠、依赖、怨怼或尊重须通过具体行为出现。

## 对手和群像各有自己的故事

对手不以“坏”作为完整动机。为他写出自身要保护或争取的利益、现实理由、掌握的信息、限制与行动策略；这不要求作品替他辩护。双方目标相撞时，观众能看懂他为何采取此举，也能看清作者如何判断其行为。

群像不必把每个人安排成主角或平均分配台词。给每人一个影响共同局势的立场、利益或注意焦点。人物相遇时目标可相交、错开、互不理解或共同改变；若删掉一人毫无关系损失，可以缩写或删去，但并列与静观作品也可能刻意保留多视点，而非都合成主线。

## 人物弧不是成长打卡

弧线可能是相信某种做法，经事件逐渐改变；也可能是坚持原立场、为它付出代价，暴露其局限，失败、倒退、分裂，或拒绝被外界改造。若采用 Truby 的完整人物弧方法，按上文链接的七项因果图核对；McKee 的压力与选择可用于确认人物深层品格是否显形。人物结局按作者的故事方向决定。

判断弧是否成立，看变化的触发、人物反应、选择成本和最终状态是否在具体事件中可追溯；作者说明“他成长了”不能替代剧情证据。固定性格可以通过环境、关系或观众理解变化形成戏剧弧，即使人物本人没有改观。

## 人物声音：从所见所想写到所说

Anton Chekhov 在致 A. S. Suvorin 的信（1888 年 5 月 30 日）批评戏剧人物缺少各自声音：“all its characters speak one and the same language”（自译：所有人物说的都是同一种语言）。逐角验证说话内容及表达方式是否属于此人。声音不靠口头禅或错别字区分，而由以下组合形成：

- **注意力**：他会先看见钱、礼貌、伤口、权力、笑点还是别人的需求？
- **解释习惯**：他把事件理解为侮辱、机会、危险、义务、玩笑或交易？
- **词汇与知识**：惯用哪些具体名词、比喻、专门词、俗语、禁忌词？
- **句法与节奏**：长句绕行、短句裁决、重复、停顿、抢话、半途改口或精确列点？
- **策略与关系**：讨价还价、掩饰、试探、命令、安慰、切断、取悦、表演或保持沉默？
- **情绪尺度**：克制、暴烈、干笑、恳求、轻蔑或突然温柔；力度随刺激和对象改变。
- **品味与偏见**：什么让他觉得俗、丑、重要、可笑或不容侵犯？

为主要人物拟一份内部声音谱系：常关注什么、避开什么、怎样组织句子、在压力下怎么变、哪种词句属于他。草稿出来后盲读对白，去掉姓名检查是否仍能辨出部分人物；目标不是人人都有绝对独特腔调，而是关键人物不被统一成作者声音。必要时相同角色可随身份、听者、风险与情绪切换。

## 返回产物与限制

把人物模型作为内部中间结果交回对应整体结构或场次：明确关键人物各自目标与选择逻辑、关系变化渠道、反对者动机、弧线类型及声音锚点。只有用户要求人物卡或设定资料时，才将其单独作为交付；只列会影响当前创作的维度，未决定的分支标明即可。已有成稿时以文本证据为准，不凭空补传记；发现动机断点时返回剧本开发者补因果，不用精致小传掩盖问题。
