# 人物与关系：用选择、权力和声音立住活人

当角色像替作者传话的纸片人、对手只负责当拦路木桩、关系吵半天原地打转，或全场人物说同一种话时读取本文件。

## 1. 行动驱动的内部人物卡（唯一真源）

人物建模绝不写与剧情无关的百科简历，只锁真正会改写当下选择、关系博弈与台词声口的条件。从 [剧本前置设计](pre-design.md) 接用三维底色、五维价值张力（偏重/缺失/异化）与声口基准句，或从既有正文提取实际行为基准，为承重角色整理内部人物卡：

| 行动维度 | 写戏前必须钉死的判断 |
|---|---|
| **处境与筹码** | 身份、手里可调动的资源/权限、现实软肋与当下够得着的办法 |
| **外在欲望 × 内在需要** | 眼前急着拿下或保住什么；心底回避或匮乏什么；两者怎样互相撕扯 |
| **价值排序与盲点** | 两件大事相撞时先保哪一样（仁义礼智信哪一维过载、哪一维枯竭或异化成面具）；什么偏见最易让他错读局势 |
| **底线与代价** | 哪怕最划算也拒不碰的禁区；跨线要失去哪段关系、自尊、安全或筹码 |
| **压力应对链** | 常态用什么策略（直说/试探/讨好/拖延/控制/离场），一旦失效会升级、退缩还是换招 |
| **关系权力** | 对不同对象能要求什么、怕失去什么；谁握着信息、空间、时间、资源或离开的资格 |
| **声口标尺** | 接用前置设计的用词双禁红线、跨情境切频条件与 3–5 句基准声口（拟人 AI 等非人角色同时锚定其独立职责、感知边界与切频触发） |

- **Stanislavski 行动循环**：每个动作都会撞上对方的回应，而回应又迫使第一个动作加剧或改向——把抽象情绪翻成此刻想让对方做什么的可演意图。
- **人物因果硬校验**：他当时知道什么、相信什么、有哪些可行退路、为何选这一招？绝不允许角色凭作者才知道的秘密显得聪明；允许误判，但误判要有当时证据与后果。
- **名字听辨测试**：把同场主要人物的姓名、姓氏与称呼放在一起朗读，读音相近易听混的立刻改清，并在全稿与下游资产中保持唯一一致；次要过场角色用清晰身份称呼即可。

## 2. 重要交锋后的状态继承

凡重要交锋、交易、拒绝、失败、援助或揭示改变了局面，立即更新受影响人物的四项状态并带进下一场（普通寒暄不记账）：
1. **知情与判断更新**：每人新确认、暂信或仍未知什么，从对方刚才的招数里摸清了什么意图或底线；
2. **筹码与空间增减**：得到或失去了哪些资源、权限、时间、退路或盟友；
3. **关系控制权位移**：信任、亏欠、依附或主导权向哪边倾斜；
4. **下一步合理动向**：换策略、加压、撤退、改目标还是暂忍不动。下次相遇绝不允许信息无故归零；若人物仍固守旧招，必须让观众看见其误读、退路已断或性格执念。

## 3. 人物关系网与 Egri 四种冲突形态诊断

写关系不只贴亲属、恋人、上下级标签，而要写清**双方各自在关系里求取、提供、隐瞒、交换或控制什么**，以及谁定规矩、谁能先离场。冲突不必大喊大叫——互相爱护却判断相反、表面客气而控制权悬殊，照样张力十足。

当一场戏绕圈打转、人物突然发疯或爆发缺力度时，用 Lajos Egri 四种冲突形态定点急救：

| 冲突形态 | 症状辨认 | 精准修法 |
|---|---|---|
| **静止型** | 双方你来我往聊了半天，信念、筹码与决定纹丝不动。 | 若并非刻意写压抑僵持，找出最早泄气处，补进一条改写局势的新事实、新利益或真实威胁，绝不靠堆更多话救场。 |
| **跳跃型** | 人物突然暴怒、翻脸或反水，与前文性格和当场信息脱节。 | 从突变处倒追：他刚看见/听见什么、触动哪条利益或旧伤？补实中间过渡台阶（如从失望→烦扰→恼怒→威胁，不一步登天）。 |
| **递进型** | 每轮反击都实打实拿走对方一个办法、改写关系位置或抬高代价，步步逼近危机。 | 按触发 → 甲出手 → 乙按自身逻辑反制 → 谁得谁失逐轮推进，反击要更有分量而非只拔高嗓门。 |
| **冲突预示** | 尚未正面交火，但双方互斥的目标、期限或必然相遇已让观众悬心。 | 钉牢预示所靠的具体承诺或条件及后续兑现处，安心延后爆发，不急着提前加吵架戏。 |

## 4. 对手双轴、群像与人物弧

- **对手绝不靠坏字解释**：给对手写足自身要守护的利益、现实道理、筹码与局限，让观众看懂他为何这么干，同时清楚作品如何审视他的选择。
- **价值对手 × 行动阻力双轴**：检查主要对抗是否同时具备两股张力（可由一人兼任，也可分属不同人或制度）：
  - **价值/规则对手**：持一套自洽却与主角相悖的生存原则，在关键选择处逼主角直面代价与自我拷问；
  - **行动/资源阻力**：掌握主角当下所需权限、通道、时间或资源并实际阻断。
  只有挡路人易成纯打关，只有哲理对谈缺现实压力；让两轴在具体行动中相撞，戏才立得住。
- **群像不平均分台词**：每人带着独立注意焦点与利益切入同一事件，相遇时互相改变局势或照出盲点；删掉某人若无关系损失，果断合并或精简。
- **人物弧靠选择和代价证明**：成长、坚守付出代价、倒退、分裂或拒绝被改造都是有效人物弧（需完整蜕变弧时配合 [Truby 七项因果](narrative-and-structure.md#2-按症状调用经典结构大师武器库)）。区分同底色随对象换策略、暂时状态波动与真正改底色——真改底色必须有可见的经历、压力、选择、代价与后续行为证据，绝不靠旁白宣布他终于懂了。

## 5. 人物声音七维（Chekhov 声音法则）

契诃夫批评劣质剧本里所有人物说同一种话。真正让人遮住人名也能听出是谁的声音，不靠生硬口头禅，而靠七处自然分化：
1. **注意力偏向**：进门先看钱、体面、伤口、权力排序还是别人需求？
2. **解释习惯**：习惯把沉默或意外解读成侮辱、商机、危险、义务还是玩笑？
3. **词汇与知识域**：日常顺口带出的具体名词、行话、比喻与禁忌词；
4. **句法与呼吸**：长句绕行、短句裁决、抢话、停顿、半途改口还是条理分明？
5. **关系策略**：命令、试探、自嘲、讨好、推责、照料、切断还是冷处理？
6. **情绪尺度**：受压时更精准、更刻薄、更沉默还是突然露软？
7. **品味与偏见**：什么让他觉得俗、丢人、可笑或绝不容冒犯？

同一个人面对亲人、对手与上位者，在称呼、直说程度、句长与停顿上随风险切频，但底层观察习惯和价值排序一脉相承。交稿前按 [review-and-revision.md](review-and-revision.md#3-遮名围读与逐角抽读) 抽读验声。
