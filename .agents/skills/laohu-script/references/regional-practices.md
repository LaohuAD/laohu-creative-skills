# 具名地域实践：按作者方法选路，不推定国别风格

当用户想理解几种写法的差异，用本页的问题和作品证据直接回答。遇到创作委托时，由父级按用户已选择的地域实践、作者或作品方法启用表中专项。国别、语言、地点、人物国籍及作品偶然提到的名字都作为材料处理。

## 路由与保真规则

先说明各做法从何种材料开始、优先解决什么、会如何影响同一段稿。未给作品时按作者处理方法比较。给了同一场戏时，说出哪些条件使某一路更贴合，以及采用它后观众会先得到什么。只比较的任务到此即可交付。用户随后选择实际写作时，再进入所选方法。

用户选了某地区但未指定讲者时，根据现有材料和创作瓶颈定主路，承接已确认的事实、主题、结尾、类型、声音、情绪力度和原句。只有分支会改变作品方向且材料无法判断时才问。作者说法、教材转述、具体作品证据和本地推演分别归属。

## 组合与冲突裁决

- 吴胜郁与崔石焕可分别处理情绪证据和类型承诺。如果两人会给同一结尾不同的体验任务，说明选择将怎样改变尾声。
- 内田用已有终点或目标决定开工，三木让素材显出故事轴，大宫先定委托主题。看比较材料里哪些前提已经成立，哪些仍需通过写作发现。
- 福田从试写台词发现喜剧情境，奥比坦在场面结构成立后写正式对白。要在同一项目结合，前者提供探索材料，最终对白接到已定场面行动。
- 古泽以观众信息顺序安排事件，横浜先处理难以抹平的经验连接。比较时问当前材料更需要排序还是要保住两端差异。跨地域也可分别由崔石焕解决全片类型承诺、由奥比坦解决具体场面信息，但应在实际委托中明确这种分工。

## 来源及材料边界

日本路线据泊贵洋编的访谈和旧工作单，韩法路线据刘大鹏编《故事创作大师班（国际卷）》相应讲者。原书版本与工作单来源见[日本专项](../skills/laohu-script-japanese/SKILL.md#来源及材料边界)和[韩法专项](../skills/laohu-script-koreanfrench/SKILL.md#来源及材料边界)。可用美国或其他地区作品比较叙事机制，类型拍序见[类型速览](genre-anatomy.md#十二类模型速览)（第1–27行）。当前制作、发行与产业要求按本轮实据判断。
