# 具名地域实践：按作者创作起点选路

本页汇总日、韩、法具名编剧的起手式与选路对比。仅比较差异时直接用本页回答；明确选用某地域实践、作者或作品方法创作时，由父级进入对应专项。国别与地点本身只作故事材料；用户只选大区未指明作者时，按当前创作缺口定主路。

<a id="japanese-practices"></a>
## 日本编剧实践

完整操作、工作单与成稿验收见 [日本编剧实践专项](../skills/laohu-script-japanese/SKILL.md)。

| 作者 | 一句话选路 | 适用缺口 |
|---|---|---|
| **古泽良太** | 先列观众必知行动与信息，再排事件次序与多线切换（《怪胎刑警》） | 事件已有，信息次序混乱 |
| **内田贤治** | 锁终点或目标决定，借人物日记与时间线反验前因 | 复杂时间轴或反转缺依据 |
| **筧昌也** | 以如果加而且压合异质设定，令第二设定改写代价（《美女罐头》） | 单一概念偏平，缺限时引擎 |
| **三木聪** | 排序小物、声音与生活片段，从重复偏离长出故事轴（《速成沼泽》） | 仅有零散片段，未现主线 |
| **园子温** | 让非写不可的经验、人物或强画面熟成，再反推事件与重心 | 情绪画面极强，套框易失真 |
| **横浜聪子** | 变形亲历并保两端不均衡，靠搭桥改写两端含义（《奇迹爱情物语》） | 两端异质经验硬融合易失魂 |
| **高桥泉** | 从日常品性认人，让终场指针台词与画面由行动挣得（《清晨之汤》） | 人物模糊，金句或结尾悬浮 |
| **福田雄一** | 让声口、演员特质与逗捧错位发动喜剧，借已知事实让观众捧哏 | 喜剧缺活气，沦为段子拼贴 |
| **大宫艾丽** | 先锁委托需求、主题与调性，再配置执行意图的人物组合 | 命题委托清晰，需高效配人 |
| **行定勋** | 把制作与场地限制转为人物关系材料，让剧本成全组坐标 | 预算场地受限，需化约束为戏 |
| **荒井晴彦** | 提炼对原作的个人发现，拆散重组为新媒介关系（《W的悲剧》） | 改编逐章压缩，缺新焦点 |

<a id="korean-and-french-practices"></a>
## 韩国与法国具名实践

完整机制、案例与成稿验收见 [韩法编剧实践专项](../skills/laohu-script-koreanfrench/SKILL.md)。

| 创作者 | 一句话选路 | 适用缺口 |
|---|---|---|
| **吴胜郁（韩）** | 先看见生活行为与空间位移，让处境、资源与情绪长成故事（《无赖汉》） | 情节套路化，缺生活肌理与空间压迫 |
| **崔石焕（韩）** | 以类型契约统领全局，让欲望、危机与代价逼出人物质变并验尾声反转 | 商业类型清晰，危机无质变或尾声失焦 |
| **弗雷德里克·奥比坦（法）** | 行动、结构、视点与知情次序排在对白之前，借读稿贯通制作（《巴黎，我爱你》） | 对白先行致场面发虚，或短片集缺情绪主线 |

## 四条同轴冲突裁决

1. **情绪空间 vs 类型危机（吴胜郁 vs 崔石焕）**：尾声体验冲突时，先定首要观众承诺，辅路只在局部供料（类型拍序见 [类型速览](genre-anatomy.md#十二类模型速览)）。
2. **起点方向（内田 vs 三木 vs 大宫）**：终点成立选内田倒推，仅有片段选三木排序，主题委托锁定选大宫配人；按最稳固前提定唯一开工序。
3. **对白先后（福田 vs 奥比坦）**：合用时先用福田法试写台词探声口与喜感，落稿按奥比坦法锁进场面行动与知情次序。
4. **排序 vs 保异质（古泽 vs 横浜）**：瓶颈在信息顺序用古泽，魅力在两端反差用横浜搭桥；跨地域如崔石焕定主干、奥比坦控单场，须先明分工。
