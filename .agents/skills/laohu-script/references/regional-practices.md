# 具名地域实践：按作者方法选路，不推定国别风格

本 Reference 由父级编剧 Skill 在用户明确要求日本 / 韩国 / 法国实践或点名相关作者、作品方法时读取。读后回父级当前任务步骤，不另起完整创作流程。

## 路由与保真规则

- 国别、语言、人物国籍、发生地点和题材本身不触发地域方法；用户用普通说法表达方法选择也算明确意图，例如“按日本编剧那种路子”“韩剧那种写法”“法国编剧的做法”。不要求先报作者名或专业术语；只说故事在韩国/日本/法国发生、人物来自当地，或明确说“韩国背景但别用韩剧写法”，不触发对应专项。只比较方法时说明差异，不预先把某一种加到作品中。
- 用户点名作者时直接走该作者分支。用户只说某地区、不知道作者名时，根据现有材料和创作瓶颈选一条有据主路并说明，不反复问作者姓名；只有分支会改变用户已锁定的主题、结尾或作品方向而无法由材料判断时才问。
- 先承接用户已确认的事实、主题、结尾、类型、声音、情绪力度和原句。父级通用方法可检查因果、人物选择、媒介和交付，但不能用通用默认覆盖已选作者方法的创作起点、优先次序和成稿表现。
- 一个主路必须承担本轮主决定。副路只有在它处理另一变量且不会静默改写主路时才接续；写清主路、副路分别决定什么。相同变量上互相排斥的方法不可熔成“都可尝试”。
- 作品、方法说明、教材转述和本地操作化分开：真实作品能证明它呈现了什么；作者方法只按材料明确归属；机制解释若是整理者推导，应标成分析或转写。举例不是普遍效果证据。

来源与引用约定见文末。这里引用中文旧教材记录时，不把二手转述冒充作者未核原话，不把地域案例写成国民性。

## 日本编剧实践

这组材料出自多位创作者的不同章节；“结构优先 / 人物片段优先”只能作导航，不能作完成后的统一公式。作者的创作起点和优先次序一旦选定，要一直作用到实际大纲、场次或剧本。日本背景本身不触发。

### 路由信号：按作品当前缺口选一个主路

| 信号 | 主路 |
|---|---|
| 已有题材 / 中心行动，缺整体呈现顺序或多线组织 | 古泽良太：行动框架、事件先后和节奏跳跃 |
| 已有结尾 / 目标决定，或多人物时间因果不稳 | 内田贤治：目的地先行、人物日记和日程验证 |
| 两个单独不够的念头等待合成 | 筧昌也：“如果 X，而且 Y”的 premise |
| 只有小素材和观察，没有稳定故事轴 | 三木聪：素材并置、关系浮现、主题后生 |
| 强烈人物、亲历材料或首尾场景先有力量 | 园子温：人物与作者材料先熟成，后搭结构 |
| 两条真实 / 虚构片段难以自然连接 | 横浜聪子：保留不均衡并处理经验到虚构的桥梁 |
| 人物像职业 / 身份说明，或终场只剩抽象抒情 | 高桥泉：写品性、行动和指针性台词 / 画面 |
| 明确要求台词驱动喜剧、演员声口或逗 / 捧关系 | 福田雄一：人物关系和台词先生成喜剧情境 |
| 有明确委托 / 主题 / 调性待实现 | 大宫艾丽：brief 和主题先定，再配置人物 |
| 空间、预算、物件、制作条件或导演合作决定写法 | 行定勋：将限制变成关系，把剧本当协作坐标 |
| 明确是改编且要求日本实践 | 荒井晴彦：先确定个人视点，再重组原作 |

材料同时支持多条时，优先用户已确认的作者 / 方向；未点作者且不同起点同样成立，比较各自要锁定什么，选与用户目标更贴近的一条，直接说明后写。不要把作者姓名当成风格装饰。

### 古泽良太：事件次序和结构中的变化

**固定选择：** 结构从人物关系和主要矛盾开始，按“必须先让观众知道什么”排信息，而不是先套三幕比例。古泽谈起承转合时强调“承”要足够精彩、有多次变化，转与合从前面的行动逼出。一个场面无变化、没有新的目标 / 信息 / 情绪跳跃，就删掉或加入能改变其意义的新想法。

**写作动作：** 有交错故事时先画全部主线的行动顺序，再决定何处切换；上一场与下一场可以形成鲜明反差，甚至让后句否定前句，以制造速度和观众期待变化。跳过两三级过程可省掉无用说明，但不能省掉观众理解关键结果所需的证据。以电视剧开发为任务时，可先在一页整理整季必须提前呈现的事件、伏笔和发挥位置；“广告前约十分钟、列七件事”是特定电视制作经验，按本剧媒介与材料决定是否使用，不转为任何剧本的时间指标。

**案例：**《怪胎刑警》第一集框架先列黑木的梦 / 内心状态、被迫回警署、女新人鹤登场、掌握案件的朋友丢失小提琴、嫌疑人改名等必需信息，再把若干交错场面排在一起。这个工作单显示的是“先定观众必须经历的顺序”，不是所有剧集都采用同一案情或框架长度。《外事警察》的新人女警作为误入陌生组织的局外人，让观众借她认识组织；这是具体的观众入口选择。

**工作方法来源：**旧材料还记载古泽摹写《七武士》剧本、把电视剧倒写成剧本来学组织；这种训练观察结构，不要求新作仿写作品。制片人称某稿“内容过于通俗易懂”后，创作者也可能有意挑战变形表达；是否采用取决于用户目标，不把难懂本身当品质。

### 内田贤治：结尾先行，人物选择和时间线反向验证

**固定选择：** 若有明确结局方向，先写终点状态，或主人公真正决定目标的瞬间，再逆推必要前置事件。情节点不是任意幕节点，而是人物决定开始采取目标行动的时刻。内田以《E.T.》藏起 E.T.、《虎胆龙威》拿起机关枪说明行动目标；以四段框架组织材料，但仍要问好作品为何形成该结构。

**写作动作：** 给人物写可解释选择的履历；需要时从主人公视点写剧情覆盖的几天日记，用“当时如何理解”检验反应和伏笔。多人物同日故事画出逐人的出行时间，检查交通、等待和物理时间是否成立。倒叙 / 省略要分清观众与人物分别知道什么。关键时刻“手机没电”这类坏偶然要往前找因果；若此前由事故造成手机失踪，后来的沉默才有前置证据。时间轴可作为低成本影片的故事工具，但变序仍须看得懂。

**课堂例证：**内田课堂用《E.T.》藏起 E.T.、《虎胆龙威》拿起机关枪讲“决定采取目标行动”；再用《洛奇》（三流拳击手获得冠军挑战机会，并与对手打成平局）和《放课后》（男子帮助初恋）练一两句概括。这些都是课堂借来分析的作品；前三部是美国影片，均非内田原创或执导，《放课后》也不是内田作品。《人生补时》《美女罐头》则是筧昌也的 premise 案例，不属于内田创作。

若用户没选结局而不同结局会改写故事承诺，保留真实选择；不为了“结尾先行”伪造结局。

### 筧昌也：“如果 + 而且”让两种材料相互改变

**固定选择：** “如果”提出可能，“而且”把第二个、最好彼此相距很远的材料变成第一项必须承受的条件。两项只是在时间上相继发生，就不是有效结合；第二项必须改写人物可以做什么、承担什么或如何理解第一项。

**写作动作：** 先写两个启发点及其矛盾关系；用一句话说明它们为何非得发生在同一故事里；再反推什么身份、职业和行为倾向会让人物可信地进入并留在这个处境中。接着列出几步选择与后果，证明 premise 能生成持续故事。只作点缀的材料删除，不强合用户已明确要分开的内容。

**案例：**《美女罐头》把“美女”和“罐头”结合，普通青年偷走罐头并与沙纪相处；保质期带来限时关系，结尾再发现雄太自己也有期限，随后回补前置暗示。《人生补时》把车祸临终和足球伤停补时直播相加。《恋爱部屋》把房间互换与“新生活里出现的是前房主恋人”相加，再加入搬家摔跤队和家具条件；短裤、手机挂件、杯子、入场券存根等小物成为两条生活线索。旧教材还以《水男孩》的“男性 + 花样游泳”说明相距甚远的材料可成为构想起点。它们说明组合要造成新行动和人物后果，而不是靠奇观词语。

### 三木聪：素材排序、脱力趣味和后生主题

**固定选择：** 输入由小观察、怪念头、生活物件和散点场面驱动时，先让素材相遇，不先要求主题句和完整传统大纲。可以记笔记、倒出素材后分类，也可以凭记忆保存笑料；三木、横浜、筧谈过笔记，福田则更相信记忆是笑料的游戏，不把记笔记设为人人必做。

**写作动作：** 记录或列出材料后，看哪些物件 / 关系 / 声音重复、哪些重复发生了变化；试着按时间、因果、人物、空间或反复变奏并置。每个片段都要产生可说明的相邻关系，但不必过早把它们压成幕结构。主题可以在写到大半时从人物共同等待的事中浮现；主题一旦浮现，就删掉重复说明和无助行动的台词。主人公未成长、目标不清或故事“什么也没发生”并非自动失败，只在日常变化、观察乐趣和观看关系本身有意义时成立。情况说明尽早结束；空转需要扇动期待、对照或情绪，不能只因看似没用就保留。

**案例：**《速成沼泽》旧工作单从 41 条素材反复排列：十日元硬币、古董店、欠债、古怪老爷爷、仓库里的泥土、巧克力牛奶等，渐渐长成“沼泽 / 诅咒 / 解除封印”故事。工作表也保留从 Tree 软件草案到后续剧本的变化，不能把草案素材当成完成稿。开场约两分半、108 个镜头的巧克力牛奶独白把日常材料放进荒诞语气，体现情况说明尽快结束但保留脱力趣味；后续版本添加高空作业车上的演讲和“把水龙头拧开”，显示写作会把作者难为情的部分放进角色声音。《乌龟意外之速游》沿用《原野奇侠》“陌生人到来又离开、生活回归常态”的故事骨架，写成“什么也没发生”的电影；《在池中》也不要求三个角色全都被治愈。这些案例说明不强制主人公成长 / 疗愈，但平淡和重复仍需有观察关系。旧教材另记“写到约七八集后才发现大家都在等待、留萌在等待鲱鱼”的主题浮现故事，但没有指出具体作品和唯一作者归属；只保留其“创作者后来认出共同关系”的例证，不擅自补作品名或归给单一作者。

**喜剧分支：** “脱力”可以噱头先行、以微小疏漏牵出更大麻烦，例如“只下不上的楼梯”或重要物件被细节更换；先查这个偏差如何推进人物处境。十分钟事件、固定形式和笑点数量是对应作者 / 电视格式的材料，不是日本剧本的国别规则。

### 园子温：人物和个人材料先熟成

**固定选择：** 人物还不够鲜明时，不以漂亮行文或结构表假装主角已经成形；有力量的次要角色可以改变原定主角位置。创作者确有强烈个人经验、难以启齿材料或两个能撑住全篇的具体场景时，可以先从其情绪和选择工作，再搭能容纳它们的结构。

**写作动作：** 从作者真正注意到的经验、动作或关系中选素材，把它转为虚构人物自己的处境，不直接复写私人事实。必要时先把结尾或两幅关键画面定下来，再倒推人物和事件；有意让作品挑衅、极端或延长时长，须是本轮已选择的表达方向，不将作者的强烈判断变成读者 / 创作者必须遵守的普遍标准。

**案例：**旧访谈记载《爱的曝光》最先出现海边劝妹妹与精神病院妹妹前来救人两个场景，之后从这些锚点倒推前半；同一材料也记载园子温把自身加入宗教团体、逃离据点的经历转为创作材料。它们支持“先抓住能推动作者继续写的场景 / 经验，再找到剧情关系”，不证明其他创作者都要用相同的极端题材。

### 横浜聪子：亲历须变形，不均衡材料须搭桥

**固定选择：** 亲历只是突破口；不能把“真实发生过”当作电影已经成立。作者可保留不均衡、难以用标准剧作理论衔接的感受，但必须辨明作品要保留什么体验、连接处为何存在、删掉或移动会损失什么。

**写作动作：** 把两个 / 多个故事种子先各自写清，找出共同动作、对立和空白，再试不同连接方式；明确哪些是事实、角色记忆、观察和创作推演。选定的连接要把两端改变，不能只补交通性桥段。对白可保留真假不定和多重理解，重视声音回响和具体发生的事；不以“伤心”解释已经由动作给出的情绪。

**案例：**《奇迹爱情物语》有两条不同起点：阳人沐浴农药、死亡又重生、最后被熊吃掉；幼儿园教师町子与阳人相爱、共同生活并带孩子进森林。旧材料明确说把两条线组合、补出之间的内容很辛苦。保留这一创作难题比把它简化成“先人物后结构”更有用。

### 高桥泉：人物是“人品”，台词 / 画面要由前文挣得

**固定选择：** 不从职业标签推一套标准人物行为；从具体物件、动作、羞耻、热情和关系细节认出人物。需要演员参与时，有限的角色设定和即兴可观察现场反应，但正式对白仍由编剧负责。选择一句台词或一个画面作指针，前文要扩出能支撑它的行动，不能只留下金句。

**案例：**“研究者的房间里放两本《哆啦 A 梦》”比“摆满文献”更像一个具体人。旧材料还记载《清晨之汤》两个终场版本：最初以樱花和骑车上班的对话离别；完成稿以“别人”作最后一句，嚼咸菜声回荡后暗场。教材的解释是后者让“承认对方为他人”成为离别动作。版本比较说明结尾不只是换辞藻，而是人物关系和动作 / 声音含义变了。

### 福田雄一：台词、演员角色和观众捧哏构成喜剧发动机

**固定选择：** 在作者明确选择喜剧和台词驱动时，先确定人物 / 演员会带来的声音、弱点与互动位置，再写台词并由角色关系生成故事。观众可以担当捧哏；条件是场面上的事实足够清楚，观众能发现人物偏差。不要机械做成“逗一句、捧一句”的交替节奏。

**写作动作：** 试分配谁夸大、谁误解、谁装镇定、谁插话；角色可以在创作中换位置。设计能重复的固定形式，然后给每次重复新的行动麻烦。笑点来自人物想摆脱困境时造成的处境和节奏，不只是机灵句子。观察真实新闻和他人荒唐行为，避免现实感只来自创作者看过的戏；改写他人行为时仍尊重事实和人物差异。

**案例：**《33分侦探》从案件、侦探宣告“让我用足 33 分钟”、先抓到的嫌疑人、失序推理到位置移动镜头形成固定骨架；某一版由大田原作捧哏、里佳子天然呆，制片人指出位置似乎反了，后续改为大田原深信侦探而承担“大逗哏”，助手插话纠正。此反馈改变了观众的观看位置，也改变笑料机制。

### 大宫艾丽：brief、主题和调性先定，再配置人物

**固定选择：** 已有委托或作品命题时，不等待它在写作中偶然浮现。先问清委托，再由作者给出明确主题、色调和声音；随后像布置花坛 / 火锅食材般安排不同人物和对照，台词从内心长谈中找到素材后改成角色的当下语言。

**案例：**《木下部长和我》将效率主义公司中的“撞钟部长”与不同部员、精英对手组成职场关系攻防；企画书先写故事梗概、人物口头禅 / 座右铭、前两集与十二集标题、目的和看点。“休业是面向开业的准备”等主题先确定，再由懒散外表和意外行动体现。工作人员说难做时，工作提问从“做不到”改成“怎样做能成功”；这不是代理同意任何预算或制作承诺。

### 行定勋：用约束生成独特场面，剧本成为共同创作坐标

**固定选择：** 场地、预算、道具、广告 / 委托条件可成为原创起点；不能只写一条展示要求，再另加脱离情节的说明场面。剧本可以让演员和工作人员有参与空间，也必须有牢固的故事中轴，使制作知道什么可以改、什么是讨论所围绕的对象。

**写作动作：** 将限制改写成人物必须做的事或关系变化；对“重复日常”先做一个能比较的基线，再以他人或小选择造成偏离，观众应能辨出丰富度从何而来。可把不确定处留给剧组讨论；对已确认的目标、结尾、人物事实和不可替换场面写清保护范围。创作者合作中听取有用意见，但不能用“剧本为议论而存在”否定作者已锁定的决定。

**案例：**《奢侈的骨》关于三人、隐秘目光和搅拌机里金鱼的散文诗式情节构想，起点是朋友新婚后在家中搅拌机养金鱼的生活观察；这件物事被放入人物秘密后成为关系张力。行定还以广告、服装、歌词或手机影像任务作为限制生成原创的例子。这些只证明限制能提供材料，不要求所有委托都用广告置入。

### 荒井晴彦：找到对原作的个人发现，再重组适合媒介的故事

**固定选择：** 改编时先识别原作中哪部分真正打动创作者，以及编剧从什么视点发现新作品。改编不是把喜爱的原著逐项搬运；可删减或重建人物情节，但新的行动与主题须相连。准备时间可分给取材、梗概和全稿复查，不能凭“忠于原著”跳过视点选择。

**案例：**《W的悲剧》原有雪山密室题材被认为难以改写；编剧保留题目，把戏中戏、替罪羊与龙套追梦重组为新核心，并访问剧团培训班女孩。这里用来说明改编要有作者发现和具体人物行动；不声称访问记录或后续制作细节已由本 Reference 独立核查。

### 日本方法的共同误区检查

- 标题 / 一句话梗概可用来检验观众能否明白作品是什么事；讲给几位读者后询问他们具体在哪里失去兴趣，所得只是本次反馈，不证明普遍受众效果。
- 小素材可用日记、笔记、人物涂鸦或从记忆回想；按作者路径选择，不要求“每天一条”。亲身经历、新闻、访问和取材都要辨明观察与推演。
- 不必默认主角必须成长、有目标或完成疗愈；若选三木聪路线，日常和不变也可成为观看经验，但仍须有关系、趣味或观众期待的具体支点。
- 题目、梗概、人物日记、企画书与剧本承担不同工作；只有用户当前需要企画 / 销售介绍时才做三人听讲、类比作品、前两集与全季标题等材料。
- 十分钟事件、每卷七件事、三人组、四框架、否定式对白、台词数、物件数量、幕比例等都是具体作者 / 体裁工作经验。除非已选方法或媒介让它成为当前固定约束，不变成地域风格清单。
- 旧材料中“主题在七八集后才浮现、留萌等待鲱鱼”没有明确作品和单一作者对应；引用时按来源合并转述，不补作者或作品。主题后置只属于明确选择该路线的作品；大宫艾丽等作者的主题先定路径不被它覆盖。

## 韩国与法国具名实践

旧材料来自同一本国际编剧大师班，但三位讲者路径各自不同。韩国只在吴胜郁和崔石焕之间按瓶颈选择；法国段落按奥比坦自己的结构 / 对白 / 协作方法工作。该材料不支持“韩国都重类型”或“法国都重作者电影”的国别推断。

### 吴胜郁：先看见生活，再让空间和情绪长成故事

**适用条件：** 用户点名吴胜郁，或明说想用日常行为、人物空间、首尾画面形成情绪；普通悲伤、病痛、社会现实题材不够触发。

**先后次序：**

1. 先找真实生活里人物会做什么、如何处理物件、怎样与别人相处。情绪落到可表演动作上，不能先写一串“温柔、忧伤、无奈”形容词。
2. 需要研究时，到场观察土壤、树木、居民、空间和关系；把现成事实、观察和推演分开。旧讲授材料有卧底和伪装身份取材的做法，保留其要求具体经验的创作目的，但本地执行只能用公开资料、公开场景或经许可的访问；不把教材中的欺骗行为变成执行授权。
3. 先定第一幕与最后一幕的可见状态，再设计让二者成为不同状态的中间行动。可先列很多可能场次而只写部分、留出空白，再与美术 / 导演观察地点、开发新场景；这是讲者的试探工作法，不是所有稿件一律留一半场次。
4. 以空间组织整部戏。移动地点若没有改变人物可用资源、行动选择、距离或关系位置，就没有兑现空间骨架的功能。
5. 按情绪起伏组织幕和段落，不均分场数。留意约 90 分钟片在 60 分钟、120 分钟片在 70 分钟左右出现的“过渡疲劳”观察：看观众期待是否消失，先用人物情绪冲突和下一次承诺过渡，不硬加不合适的情节。
6. 再以强烈转场画面、动作声响和观看位置连接场面；读稿找真正没用 / 没存在价值的戏。喜欢的场面被要求删除时，先查它承担的意象和作用，再找方法把它放进剧情必需位置，不能只说“这是我最喜欢的一场”。
7. 与导演、制片合作时守住自己要表达的情绪和人物行动，说明具体损失并争取保留；合作权力和本轮授权仍按真实制作条件判断。

**作品证据与操作：**《八月照相馆》面对患者形象时，访谈材料里的煮拉面、骑车散步、与妹妹吃西瓜打闹和独自落泪，让人物不止是持续悲伤的绝症患者；场面用洗钢笔、写录像机说明书落实生活质感。《无赖汉》以女主三次搬家表现其处境越来越差，房间空间随关系与资源改变；远看像拥抱、近看是持刀刺人的结尾让观众重新理解画面。《双生警贼》先有江原道雪地里垂死男子和跪者的首尾画面再补中间结构。规则是行为和空间证明情绪，首尾画面须由中间行动挣得。

**署名边界：**同一章还引述李沧东的步行采风，以及把亲历整理成第三人称“讲真话的说谎者”的说法；这些按材料归于李沧东，不并入吴胜郁个人方法。读者可从外部视点写难以启齿经验，但应称作作者的虚构处理，不冒充真实证言。

### 崔石焕：类型契约统领故事，危机与欲望须造成质变

**适用条件：** 用户点名崔石焕，或所选韩国路线要解决类型承诺、危机只加数量、欲望不增长、人物代价不足和结尾不成立。纯现实 / 情绪题材不自动套类型模板。

**先后次序与固定承诺：**

1. 先写类型对买票观众的主要承诺，以及此故事必须满足的核心体验。喜剧在悲伤收束里也要交还喜剧感，推理故事不能忘掉推理主轴；类型混合要分别充分兑现并维持统一调性。
2. 课堂记录把允许创新描述为约 5–10% 的小幅偏移；这是崔石焕这一路的严格讲法，不是所有作品或韩国类型的通用比例。选定这一路即以主类型承诺作硬约束；需超出时应明确说明具体会改掉哪项承诺，不能称作无代价微调。
3. 提前定结尾、高潮解决方式和高潮之后人物的心理落点，避免“可以去北京也可以去天津”的悬置。主旨优先让动作 / 画面体现，不让人物复述摘要。
4. 逐段同时检查外部危机、人物欲望、持续恐惧点、应对策略和选择代价。两线须互相加压，不能各自平行增高。
5. 每次转折问它是否改变人物能做什么、必须舍弃什么、对世界的理解或对手关系。损失金额、军队人数、敌人规模变大但策略 / 处境没变，只是量变。
6. 主角即使只过一晚，也要有可见的性格 / 选择质变；他不必十全十美，配角也必须像自己人生中的主角。主人公获得越多而承担越少，通常越不值得期待；标出他愿意拿什么冒险。
7. 每稿都必须执行第二次反转的搜索与比较：在第一次解决方案之后提出候选，核对它是否由前事支持、造成质变并兑现类型承诺，再决定要否补入必要铺垫。旧课堂记录原话强调“只有一个反转不够，竭尽所能挤出想象力让结尾变成两个反转”，同时警告不能为反转而反转；因此，两次反转是强烈的收束目标，第二次搜索 / 比较 / 因果准备是必做动作，不能据此强制每篇完成稿都出现两个转折。若没有成立的候选，不硬造；说明比较结果和未达讲者期待的具体损失。
8. 喜剧 / 类型需要信息时，让争吵或行动承载解释；不要让次日喝咖啡的对白复述前情。

**作品证据与操作：**“外婆讲老虎和糕点”的课堂拆解先介绍环境、让突发事件改变质地：糕点成祭品后，母亲也将成为第二个祭品；它不同于“大军之后又有更多大军”这种单纯数量上升。童话解围时先天降一根绳子，再掉下一根绳子形成第二次转折，并用 bittersweet 情绪调整结尾。这个例子说明如何让两次变化带有前因，不意味着每部作品都机械交付两个转折。选定此路时必须做第二次转折的搜索、比较和前置因果准备；不能跳过，也不能把未成立的候选硬塞进成稿。《港囧》案例记载原始癌症父亲圆梦设定在中国遭遇质疑后改得更喜剧化；它提醒制作反馈会改变类型承诺，修改前须写出得失，不把它解释成崔石焕唯一认可方案。

### 弗雷德里克·奥比坦：行动、结构、视点在对白之前，编剧贯穿制作

**适用条件：** 用户点名奥比坦 / 法国编剧实践，或稿件对白先行造成场景行动空洞、视点与隐情不清、集合段落难以接续，或已明确需要编剧参与生产交接。法国地点、法语台词或艺术电影题材不够触发。

**初稿至定稿：**

1. 先完成事件初稿，再组织结构，最后写对白。不要从“内景 / 时间 / 地点”直接进入一段解释性谈话。
2. 每场先写为何要它、人物目标、进入条件、行动、阻力、策略变化和离场状态；问“为什么这样处理”和“这一场怎样推进”。喜剧以角色通过情景摆脱困难、节奏和身体行动制造，不用机智语言替代事件。
3. 分清观众、主人公、其他关键人物知道什么；让隐瞒、误会和信息差有来源、有时间，不靠作者任意扣住人物已经知道的事实。先分别从创作者、观众和主人公视点读剧本。
4. 最后组织对白、潜台词、沉默、停顿与可说性。信息表面之外要能打开另一层意图。原课堂以“12 句，不要 13 句”表达对白经济；只有当下采用对白压缩练习时才以此作限额，不是每场统一硬指标。
5. 戏剧改编不要拍成舞台录像；删减 / 新增人物和情节以电影的三维空间和行动为依据。情绪特别饱满的段落后安排必要呼吸，不用等长平均处理。
6. 结尾让风格和全片一致，维持人物尊严。人物道德失败的后果可以严厉，不能靠镜头羞辱他来伪造判断。
7. 读稿后继续检查结构和声音。朗读是过滤稿件的过程；未组织真实围读时，不把单人朗读写成观众 / 演员反馈。

**编导合作与读稿：**若生产任务明确包含协作，编剧参与写作、筹备、拍摄、后期，提前想出现场会问的关键问题，保留对白之外的场面意图和修改依据。意大利式围读的做法是先逐场列步骤，团队 2–3 天高声读完整文本（连场景、附注和时间说明），录音师按场记录，开拍前回听；它用于让全片结构和声音可被共同听见。编剧可以晚一点让制片人 / 演员读稿，减少第一印象锁死，但正式生产安排以用户合同和导演需要为准。需要长时间共同创作时可找合写者或与导演一起写，不把陌生朋友的泛泛赞扬冒充专业评审。

**作品证据与操作：**《偷情桥》旧结尾以妻子跳桥、丈夫救起和焰火解决关系；作者认为它像另一部好莱坞电影，改为两人各走一边，让离别温和、有人格尊严，并和全片风格一致。《巴黎，我爱你》由 20 位导演各完成一个限时片段，初版过长、衔接不足、巴黎和主题不清。奥比坦与剪辑师提炼情绪主线（好奇 / 幽默 → 死亡 / 漂泊 / 孤独 → 升华 / 解决），再经 82 次排序，不以外加故事逻辑强行统一。采用这种集锦结构时，情绪线就是主骨架；每次移动仍复核观众理解和事实时间。《特使》让记者在巴黎藏身并制造仿佛身处伊拉克的喧闹，再用伪造人质录像升级情景；来源也记录其观看残酷视频后思考伦理边界。案例只说明喜剧情境可以很极端，不替制作授权现实取材或鲁莽呈现残酷事实。

**定制与合作案例：**《激情联盟》是接受国际足联委托的作品，创作受制片方审看。旧材料记录创作者用镜头符号和前后场景的误解 / 澄清保护表达。引用时说明它是该项目如何处理限制的个案，不把规避审查写成一般指导，也不以该案例取代当前真实法律 / 制作要求。

## 组合与冲突裁决

- 吴胜郁与崔石焕只有在不同轴上才能明确并行：崔石焕定全片类型承诺、危机和代价；吴胜郁负责把相应情绪落实为生活动作、空间和首尾画面。若克制的悲剧尾声会破坏喜剧承诺，必须显式重定或由用户选择。
- 奥比坦可负责场面、知情差、对白顺序和生产读稿；只有用户确实选择相应的韩国作者方法时，才叠加类型或空间轴。不要将法国方法解释成韩国方法的执行阶段。
- 日本方法内部也需避免同轴冲突：内田 / 崔石焕 / 吴胜郁可要求先定结尾，三木可选择等故事轴和主题浮现；大宫要求 brief 主题先定。按用户既有决定和材料选一条，不写成两边都可。
- 福田的正式喜剧台词可以先试写来发现角色，奥比坦的定稿步骤把对白放到场景结构后。要并用，须明确福田台词仅作探索素材、奥比坦结构确定后重写定稿；不能让两种顺序在同一环节互相否定。
- 父级一般因果检查不能替三木预先指定主题；一般主题检查不能抹掉大宫已定 brief；“动作更明确”不能把横浜的多义声音台词改成情绪解释；一般反转数量也不能覆盖崔石焕所选教学路径或用户已有结尾。用户已经锁定的事实和决定优先。
