# 全稿审读与修订：追最早断点，过四道实操体检

审查大纲或完整剧本、定位漏洞、局部精修或定稿交付前读取本文件。局部任务只审指定范围与直接受影响的前后场，绝不因几句台词重做整部戏。

## 1. 先读懂原稿的魂，再按张力与价值分层优化

审稿标尺不是套用一套普通正确的通用模板，而是先读透眼前这部作品已经成立的**观看体验、风格气质、人物底色、情绪张力与锁定项**。接手已有剧本做诊断或优化时，先完成三项正向定盘再动笔：

1. **辨认人物的独特底色与语言指纹**：逐个看清角色鲜明的性格与说话方式——哪怕表面显得机械、啰嗦、高傲、天真或偏执，先判断它是不是角色刻意的魅力、喜剧反差或隐含原型特征；看准以后顺着他的骨头打磨得更像自己，让每个角色更有辨识度。若原稿明显带着未明说的背景或原型设定，或改动会触及核心前提与结构取舍，先用一两句直白的话向作者确认，对齐后再动刀。
2. **护住牵动全片的剧情张力与预期落差**：无论写实悬疑、生活剧情还是卡通喜剧，凡靠观众当下的未知、误判、绝境感或角色自带缺陷在后文引爆反转与笑点的信息差，都是戏最值钱的机关——任何润色与补全都要顺着这份情绪张力服务，严禁为追求表面平整而提前泄底。
3. **由上而下直击最早断点，再按价值分层动手**：诊断先看戏核前提与情绪方向是否跑偏（前提本身站桩或狗血时直接点破并给换血方案，绝不只在表皮改词），再看结构因果与张力，再看戏核载体与场次，最后落到台词与 `△`。原稿剧情与台词本就立得住时，优先通过画面表演、节奏停顿与画风张力把戏味放出来；台词只在掉声、翻译腔拗口或挤塞气口处精修；确需追溯因果或调整结构时，沿单向因果链追到最早根因：

> **观众看到的结果 ← 人物作出的选择 ← 人物当时的解释与策略 ← 触发他的现场证据 ← 前文是否真正建立该证据与关系**

- **源头补条件、不磨角色锋芒**：角色突变若源于前文缺少铺垫或现场触发，优先在源头补实条件（因果、硬时间线或核心动机断掉时，按 [pre-design.md](pre-design.md) 局部回修）；让角色保持原本的偏见、锋芒、犹豫或独特声口，完整短片与单集在本作内实质兑现核心回报。
- **反事实价值检验**：检验一场戏或一轮升级是否真正改变后续选择、情绪走势或观众体验；刻意安排的观察、等待、仪式、人设铺陈与余波按其观看任务完整保留。

## 2. 静音画面测试（Silent Film Test）与画面描述四检

<a id="silent-film-test"></a>
对画面与空间承重的场次，暂时遮住全部对白、旁白与括注，只顺读 `△`：
1. 能不能一眼看清环境空间、人物站位与动线、谁的行动改变了局势，以及场末留下的新状态？如果核心转折只能靠台词解释，回 [scene-development.md](scene-development.md) 补实站位、物件互动与可演画面。
2. 逐段对照 [画面描述写什么](script-format-and-delivery.md#画面描述写什么) 过**画面描述四检**：
   - **初见立形与空间站位**：主要角色、核心道具与固定主场景初见有没有 1–2 笔辨识锚点？人物相对位置、进出动线与场内自然光声是否清楚？
   - **有尾必有头 + 清六类不可拍句**：后文用到的物件、状态、设施或特效在前文是否立了头？念头、意图、抽象局势、纯抒情、负向词与**感觉/抽象形容词贴标签**是否已转清？
   - **画风贴合**：动漫/奇观场是否放出应有弹性与演变过程，写实场是否守住克制与潜台词空间？
   - **观察重心拆段**：正反打反应、特写强调与视线转念是否自然拆出切镜气口？

## 3. 遮名围读与逐角抽读

<a id="blind-table-read"></a>
### 遮名围读三检（Blind Table Read）
人物说话趋同、回合拗口或场尾拖沓时，遮住角色名、声源与表演括注，大声连读相邻回合：
1. **气口、活人语序与重音**：拿掉标点念出来是不是像真人开口（清掉翻译腔与四字书面压扁词）？自然换气与重音是不是正好落在角色最想护住或刺出的实词上？
2. **声音与节奏差**：光听台词能不能分清谁更在意什么、谁控着局面、各自句法快慢如何不同？
3. **场尾 Button 落点**：恢复画面与声源后连读最后一个转折到下场开场，砍掉戏已演完后的复述补话，给足关键反应的留白时间。

### 逐角抽读与声画四复核（整稿与重写交付必做）
1. **逐角连读保真声口**：把主角与核心配角的全部对白与 `VO` 按场序分别抽成一列从头连读，确认每个角色自始至终保持自己鲜明的性格底色与语言指纹。只把违背当前身份与意图的突然掉声拉回角色本身；若机械播报感、暖心废话、清冷毒舌或直率天真本就是人物刻意立住的鲜明特征，放手让这份特色更传神。
2. <a id="voice-over-final-read"></a>**无声顿悟优先与 `VO` 去前提合读**：凡眼神切换、物件照面或日历/单据对照已让观众自己寒毛倒竖的瞬间，**坚决整句砍掉 `VO`**，把空白留给画面与声音；确需保留的 `VO`，逐句试着去掉已被相邻画面和对白演过的前提，从人物真正转念处连读到下一动作（详见 [VO 三分法](dialogue-and-audiovisual.md#voice-over-reasoning)）。
3. **表演括注与声源核查**：括注保持短小可演，把独立大动作归回 `△`；核准画外、内心、设备传声与回忆/梦境成对闭合，确保视听所见与人物知情边界一致。
4. **改前改后连读防钟摆**：遵守 `docs/runtime.md` §3——多轮改稿时对照前版已成立的交锋密度、喜剧停顿、反转张力与情绪落点，确保越改越活、不缩水也不趋平庸。

## 4. 因果自洽、张力保护与质量优先的最小修复

- **片场排练三问（成稿后独立现实扫疤）**：初稿放飞写完后，切回严苛导演与挑剔观众视角把全戏当成明天开机默演一遍，逐一扫除最易出戏的三类硬伤：
  1. **现实物理、工具/软件与法理常识**：涉及日常通信软件功能、电子设备交互、物件材质燃烧/破坏、现实继承/办公/快递/职场制度流程时，必须核对真实世界能不能这样操作，绝不把核心反转建立在不存在的假功能或荒诞物理上（奇幻卡通则按已立世界契约成立）；
  2. **时间算术、动作耗时、物件连贯与空间视线**：逐一算清具体时刻与班次先后（防分钟倒挂）、核对大串操作在对手逼近的真实秒数内能不能做完、查清每个承重物件在哪出场在哪收尾（无隔空瞬移、无前后改口）、核对透明隔断/灯光/门缝下对手的真实视线能否看见；
  3. **对手知情边界与现场真实智商**：严禁角色说出按前文他不可能知道的秘密或私下变动；按对手此刻眼里真看到（如已清空的通知、异样的摆放）、耳里真听到的信息，反问他真会乖乖降智配合拖延，还是早该当场起疑反制。同步核对出入场、持物、称谓与民俗节令常识，做到暗埋巧接而非提前透底。
- **声源标法与正文洁净核查**：核对声源标法遵循 [声源三分真源](script-format-and-delivery.md#声音文字与主观时空的标法)（通用影视默认无点 `OS`/`VO` 及设备传声；若本作已选定中文`（画外）`/`（内心）`或项目既有制式，确认前后不混用）；核查正文代码块内**零行内反引号（`` ` ``）、零加粗斜体修饰与多余装饰引号**。
- **质量高于模糊参考时长**：日常按 [场面开发估时口径](scene-development.md#1-用极薄白描场面卡立盘) 核对自然播放区间；仅在需精确压秒或多轨并行核算时才读取 [Video 共享估时](../../laohu-video/references/segmentation-and-handoff.md#逐字预算估时与并行事件核算)（不因此触发 P 分段）。区分**硬性卡秒要求**与**作者大致参考时长**：成片质量、人物魅力与节奏呼吸永远优先；自然体量明显超出模糊参考时，先如实报出估时供作者取舍，确需控时再优先合并重复过场，保住饱满对白与必要反应。
- **诊断呈现与最小充分修复**：按锁住已成立资产 → 决定优化层级（能靠画面演出与气口解决的，不动剧情底盘） → 回查上下游依赖 → 整段通读的顺序落笔。交付**审稿诊断或多方案对比**时，放块外以通俗清晰的 Markdown 呈现——先亮一句话核心判断，按致命度分层分条（关键结论加粗），2 个以上方向配简明对照表并标明推荐优先级与代价，结尾收 1–3 个真正待拍板项，严禁大段文字墙；同时交付**修订正文**时，块外简明交代“原问题 → 改法”，块内交一字不混批注的干净正文。
