# 专门创作路径：为材料选方法，不为方法找故事

作品进入类型混合、片段摸轴、群像、观察关系、悬疑谜题、互动分支、情景喜剧或跨媒介改编时读取本文件。先按瓶颈定主路，辅路只管各自职责；系列与国产剧集转 [系列与国产剧集实践](series-and-production.md)，具名与地域流派转 [具名剧作方法](named-dramaturgy.md) 或 [具名地域实践](regional-practices.md)。

<a id="类型骨架与混合为明确承诺逐拍选用"></a>
## 类型骨架与混合：为明确承诺逐拍选用

承接 John Truby 六步类型混合工作单，先经 [类型速览](genre-anatomy.md#十二类模型速览) 调取参与类型的完整拍表；类型拍接入幕—序列—场纲，不替代场内相邻动作 beat。

1. **确定主类型并查全拍**：按观看承诺、主行动与结局定主类型；逐拍登记候选事件及采用或舍弃理由，舍弃某拍时写明观众损失的期待与代偿行动。
2. **选 1–3 个副类型**：写清各副类型新增的观看体验，对照全拍表逐项标采用、合并或舍弃。
3. **逐对核查互斥拍并当场裁决**：两两排查冲突拍，写清两边拍名、冲突位点（事件序、结局、节奏或世界建设）、能否调序共存、最终取舍及剧情后果。重点查 Horror 无自我揭露 vs Love 双重反转、Action 高速推进 vs Fantasy 完整世界探索；两拍并留不算裁决。
4. **定底层结构**：按本作终点选定主导推进形状（线性、漫游、螺旋、汇聚或上升—衰落），不默认神话之旅。
5. **指定主题主导者**：由主类型人生哲学定调核心主题，副类型供拍与技法；世界观打架回第 1 步重判。
6. **落表接入纲稿**：交付拍表状态、裁决记录、舍弃理由、底层结构与主题主导者，分配到具体幕、序列与场景。

追求超越类型常规时走三条路径：改拍序或实现方式而不删拍；写主类型哲学的具体变体或反面；用该类型独有形式承载更大议题。

## 人物/片段先行：从零散材料发现故事轴

1. **分清原材与假设**：保留原句与意象，补推动机与连接时明确区分新增假设。
2. **片段转卡片**：记人物、时空、眼前观察或动作、潜企图、限制与场尾状态变化。
3. **筛重复与偏移**：追踪反复出现的物件、动作、关系或空间，紧盯偏移处逼近共同压力。
4. **试排 2–3 种观看次序**：按时间、地点、问题显影或先果后因试排，标清观众先知与晚知。
5. **提炼候选故事轴**：写出可能核心问题、行动与片段关联；多轴导向不同作品时并列拍板。
6. **材料稳固后选结构**：按已显影的行动或观察轴选线性、交织、分段或回环，让结构解释材料。

## 群像交织：让交会改变各自的故事

1. **各自成戏**：按 [人物与关系](character-and-relationships.md) 给每位主角立独立利益、价值排序、知情与行动。
2. **锁定共同接触面**：明确哪项压力或场域迫使众人相遇，谁能绕开及绕开代价。
3. **画交会矩阵**：行列排人物或行动线，交叉格只填相遇后谁改写了判断、关系、资源、风险或观众知情；无影响留空。
4. **非平均切线**：每次切换提供新视点、对照、后果或等待，按局势推进不均分戏份。
5. **交会重验立场**：相遇可合作、误读、利用、拒绝或改造，每条线须带走不可替代的后果。

## 观察与关系型：让重复、空间和余波构成推进

具名流派转 [具名剧作方法](named-dramaturgy.md)；通用观察型按六步推进：

1. **定观察轴**：写明观众盯谁、看什么重复、等哪项变化或留意谁缺席，落到动作、空间或声音。
2. **立日常基线**：确立人物平时如何使用空间、处理事务、称呼彼此或分享沉默。
3. **放偏离证据**：用动作变慢、漏步、移物、空座、答非所问或日常声中断显露关系位移。
4. **排重复与间隔**：借重复建可比刻度，借间隔显时间流逝与心理距离。
5. **让空间承载权限**：突出门、走廊、座位与出入路线怎样改变可见性、接近权与归属。
6. **留场尾余波**：离场者留下的物件、未完家务、空位或声响带入下场，变化不说破亦可追踪。

<a id="悬念惊奇与谜题安排观众和人物的知情差"></a>
## 悬念、惊奇与谜题：安排观众和人物的知情差

联动 [叙述视角、知识与信息路径](narrative-and-structure.md#叙述视角知识与信息路径) 管理全局知情，按四步控悬疑节奏：

1. **三类体验定主次**：**悬念**让观众预见危险而人物未察；**惊奇**借揭示瞬间改写理解；**谜题**追问原因或真凶。需层层钩子与高频反转时选**惊奇递进**：每次关键兑现越出前段主要预期、重组人物动机或因果理解，令前文线索回看成立并生出新问题。
2. **锚定赌注**：写清不行动或真相落地谁受何损；倒计时从故事内部自然长出。
3. **排揭示序**：悬念先交危险证据给观众；惊奇藏核心事实但先埋回看线索；谜题逐次释可比证据，使误导有据且谜底解释全部旧事实。
4. **揭示必改行动**：每条线索、误导或揭示落地后须改写计划、信任、风险或关系。

<a id="four-part-suspense-scene"></a>
### 四构件悬疑场面：熟悉地点、时间锁、私人物件、熟人异常

把日常异常收紧为个人危险时按四步组场：①熟悉地点执行日常任务立常态；②带截止时间与现实后果的责任与查探形成两难；③主角私人物件出现在按权限或因果不应现身之处，明示关联与核验人；④熟悉关系对象以异常言行现身，迫使主角重估危险来源，场尾留线索支持的新问题。

<a id="interactive-choice-state-branches"></a>
## 互动叙事：让选择改变状态、策略和后果

仅在交付含读者或玩家分支选择时启用：

1. **可执行差异选项**：亮明玩家已知事实、压力与资源，每个选项用具体动作代表不同策略与代价，无同义改写或单边最优假分支。
2. **最少必要状态**：为每项变量定义初值、更新条件、读取点与重置范围；不在后续改变信息、行动、关系、资源或结局的变量直接删掉。
3. **逐项分支后果**：记即时结果、状态更新、新知信息与下轮可选行动，选项严格基于玩家已知信息。
4. **汇合保差或分道结局**：汇合时只并共同事件，必须保留各路带回的状态、信息与关系差，确保汇合场承接所有合法状态；不汇合则明示退出或结局条件。
5. **逐线推演**：沿可达路径核验状态更新可见、无死锁、结局全由已追踪状态触发。

## 情境喜剧：从真实需要和规则制造升级

局部喜剧困境、组合与笑点直接查本节；完整半小时制式、七步单集、单多机排版、悲喜剧与装置短季，进入 [情景喜剧专项](../skills/laohu-script-sitcom/SKILL.md)。

### 经典困境与人物组合速查

困境只在未解决时持续供能；一旦解决，须换新困境或让旧结果改写关系继续发酵。

| 困境（Smith） | 核心机制 | 经典案例 | 选型与防失效点 |
|---|---|---|---|
| **Big Lie** | 小谎→更大谎→崩盘或险脱 | 《南方公园》Cartman 装病反吐真言 | 升级须推成连环大谎，不原样复述 |
| **Big Secret** | 守密→漏嘴圆谎→秘密反噬关系 | 《办公室》Michael 守密反生交友义务 | 单藏信息撑不满戏，须生第二层关系义务 |
| **Misunderstanding** | 可见证据→合理误读→错判行动 | 《我为喜剧狂》Liz 误举报试镜地图 | 误解必由已知证据与偏见推出，不降智 |
| **Rock and a Hard Place** | 两项不可兼得且皆有代价逼抉择 | 《愚人善事》两难道歉或赴险约会 | 一边明显占优则选择张力即失 |
| **Surefire Scheme** | 自信奇招按自身逻辑狂奔放大灾难 | 《南方公园》染红发反煽动群体报复 | 方案贴合性格，当场走理智捷径则熄火 |
| **Rock the Boat** | 外来者破常态→常驻人物摊牌应对 | 《我为喜剧狂》Devon Banks 搅局 | 外来麻烦须迅速转为常驻主角的故事 |
| **Time Bomb** | 截止前补救不可能任务，压力递进 | 父母提前返家前收拾派对残局 | 期限伴可感后果，行动切实受时间挤压 |
| **Trapped in a Space** | 不相容人物密闭共处、急欲脱身 | 《伦敦生活》静修营密闭禁言整集 | 空间一解封压力即止，长戏须关系接棒 |
| **Sex Tension** | 彼此吸引却被规则、时机或关系阻断 | 《干杯酒吧》Sam/Diane；《办公室》Jim/Pam | 关系兑现即耗尽引擎，须结束、拆开或换压 |
| **Dead Body** | 藏尸、被疑谋杀或被迫收拾身后残局 | 《玛丽·泰勒·摩尔秀》小丑葬礼忍笑 | 依赖喜剧安全契约，写实过重即滑向正剧 |

| 人物组合 | 摩擦机制 | 参照与要点 |
|---|---|---|
| **Role Reversal** | 被迫承担与本性相反的身份责任 | 《辛普森一家》反转理想家庭；适应后张力衰减需递进新局 |
| **Fish Out of Water** | 带旧世界规则闯入陌生秩序 | 《单身毒妈》《明星伙伴》；靠规则错位产笑，不写蠢人 |
| **Odd Coupling** | 不相容生活方式长期绑定共处 | 《我为喜剧狂》Liz/Jack；双方各自有理、互不降维 |
| **Sex** | 欲望明确而阻碍反复 | 《办公室》职场双线；靠时机、身份与克制拉扯 |
| **Pretense** | 伪装高阶身份或立场终遭曝光 | 《消消气》Larry、《我为喜剧狂》Liz 反被揭旧账 |

<a id="逐拍写笑点setup发展转折反应后果"></a>
### 逐拍写笑点：setup—发展—转折—反应—后果

先锚定当场动作目的，再按五拍展开：**setup** 立可信预期；**development** 用一两拍复杂化局面并定关系声口（如《我为喜剧狂》烤箱戏借追问刻画 Jack 的掌控欲）；**转折**给意外但回看成立的结果，关键词或动作压句尾；**反应**由对手贴合关系接招；**后果**推向下步行动。加码或回扣须每次改意义或人物位置；删掉包袱后行动、关系、信息与声口皆不变则删或重建。

<a id="comedy-scene-mechanism"></a>
## 喜剧场面：让人物确信、现实反驳与反应形成笑点

单场喜剧、讽刺、荒诞或悲喜剧需要局部笑点机制时轻量启用：①定观众笑点、同情或不安落点，给主角由眼前处境长出的认真目标与确信；②用客观事实或对手有效行动正面反驳；③角色按自身性格给可见反应（收着演、迟半拍、过度自圆其说或固守错判），在信息或权力错位处留停顿；④以对手回应或局势变化兑现笑点并推进关系（悲喜剧中笑作防御或回避，不抵消痛感）。

<a id="情绪与空间地域类型和具名方法的深化"></a>
## 情绪与空间：地域、类型和具名方法的深化

在 [场面开发：空间权限与环境情绪](scene-development.md#空间权限与环境情绪景语即情语) 基线上叠加四项专项深化：

- **具名手法**：从 [具名剧作方法](named-dramaturgy.md) 或 [具名地域实践](regional-practices.md) 抽取观察位、空间与节奏变量。
- **地域秩序**：把居住、劳作、气候、制度与公共规矩转成人物通行、停留、发声与用物条件。
- **类型声画**：用光影、声音、距离、材质与节奏兑现类型期待，主动偏离须留清晰新落点。
- **跨场偏移**：追踪复用空间或物件的初义、人物知情变化与每次重现的偏移。

<a id="professional-skill-risk-and-mutual-benefit"></a>
### 专业能力、风险与群体互惠场面

角色在共享空间靠专业能力换取合作与资源时走四拍：①**具体需要**——群体或对方说出眼下难题，主角合理听见；②**风险接近**——主角主动靠近发问，对方有现实理由误读为挑战并构成身体、权力或关系风险（处境支持才保留）；③**专业解法与交易**——以可核实专业知识解难题，顺势提双方可权衡的交换条件；④**群体回报与立场**——交换落地为共同收益，借主角是否参与、担何代价或守何边界显其立场。

<a id="flirtation-four-and-six-stage-route"></a>
### 暧昧关系：四阶段动作路线与短剧六阶段

呈现关系由未确认走向可辨暧昧时走四阶段：①**入场位置**（关系距离、各自目标与边界）；②**试探靠近**（可见靠近或关照动作）；③**带目标改线**（对方不顺话尾，按自身意图扭转互动方向）；④**离场位移**（具体行为、留物或状态显关系偏移）。长剧留白转短剧提速时，保留起止，在第 ② 步后加一处可见拉扯推进节点、末尾加本场因果生出的后续问题，形成六阶段策略骨架（不替代微观 beat）。

## 跨媒介改编：迁移戏剧功能，不逐字搬运表面

1. **抽承重项**：列源作核心事件、人物选择、关系、主题、关键意象及不可改事实，分清必留事实与原媒介功能。
2. **功能通道映射**：写清每项让受众知道、感受或等待什么，转入目标媒介最有效的通道（行动、对白、声画、空间、剪辑、旁白或交互）。
3. **定去留查下游**：标保留、转化、合并、删减或新增，追查删改对动机、伏笔、知情与结局的依赖。
4. **试改核心序列**：先重写一段完整序列对照源作，核验立场、因果与情绪力度无损。

<a id="novel-to-commercial-short-drama"></a>
### 小说转商业短剧

重在按集重排戏剧功能，不逐句缩写：①抽出小说事实、视角、知情、目标阻碍与期待，重配为每集可见动作、声画与对白并补全被删内心戏的因果依据；②参考练习规格 60–100 集、约 90 秒/集（合同规格优先），首集走五功能点（强视觉冲击→受阻处境→优势显现→首次有效反击→强钩子），此后每集 ≥3 功能点（目标、障碍、策略变化、代价、情绪转向、下集问题）；③每次加压均须给出可调动的事实、关系或资源反制，后续升级抬高风险、换手段或揭新信息，胜败皆留连续后果；④先试改前段完整序列核验知情与因果，正文仍按本地场次与相邻 beat 写作。

完成专项后按层回接主流程：故事轴回 [故事开发](story-development.md)，人物回 [人物与关系](character-and-relationships.md)，转折、类型混合与序列回 [叙事与结构](narrative-and-structure.md)，场次与空间回 [场面开发](scene-development.md)，声口与视听回 [对白与视听](dialogue-and-audiovisual.md)，格式回 [格式与交付](script-format-and-delivery.md)。
