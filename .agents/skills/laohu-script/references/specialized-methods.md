# 专门创作路径：为材料选方法，不为方法找故事

当作品进入系列、喜剧、悬疑、观察式叙事、群像、跨媒介改编等有特殊组织难点的路径时读取。本文件提供跨题材通用方法和情境喜剧的完整执行链；先依当前瓶颈选择主路径，正交辅助方法只处理各自负责的决定。明确要求系列开发或国产剧集方法时，按需读取[系列开发与国产剧集实践](series-and-production.md)；明确选择契诃夫、小津或权力群像方法时，读[具名戏剧方法](named-dramaturgy.md)相应章节；明确要求日本、韩国或法国具名编剧实践时，读[具名地域实践](regional-practices.md)对应路径。Reference 按方法缺口读取，不因作品里出现相关题材/地点/人物而自动加载专项。返回所选方法、关键步骤和可继续创作的结构产物；具体场次回到 [场次展开](scene-development.md)，人物选择回到 [人物与关系](character-and-relationships.md)，整体走向回到 [叙事与结构](narrative-and-structure.md)。

## 路径选择：识别故事现在卡在哪里

| 当前材料或难题 | 优先路径 | 先形成的产物 |
|---|---|---|
| 核心行动、主角目标或结局大致清楚，需要组织阶段 | 结构先行 | 行动主线、因果节点、阶段功能与转向 |
| 起点是零散灵感、人物、场景、对白或某个画面 | 人物/片段先行 | 材料卡、重复与差异、可能的故事轴 |
| 多个人物共同面对一个局势，视点互相改变 | 群像交织 | 人物立场图、交会点、关系与信息变化 |
| 主要价值在日常观察、关系余波、空间或时间感 | 通用观察/关系型；若用户明确选择小津或契诃夫，另读[具名戏剧方法](named-dramaturgy.md) | 观察对象、重复与偏离、观看次序 |
| 故事可持续产生新一集，同时又有长期变化 | 通用系列引擎；若要试播集、季弧、series bible 或国产剧集创作/生产文件，按需读[系列开发与国产剧集实践](series-and-production.md) | 可重复的故事来源、单集闭合、季节变化 |
| 笑点来自人物目标、身份差、规则或反复失控 | 情境喜剧 | 喜剧前提、场内升级链、反复变化规则 |
| 观众需等待危险、答案或误认揭开 | 悬念/谜题 | 知情表、线索表、揭示次序 |
| 改编已有小说、文章、回忆、游戏或其他媒介作品 | 跨媒介改编 | 保留/转化/删减表、目标媒介表达方案 |

类型标签不是分路的充分条件。同一悬疑故事也可能以家庭群像或观察式场面推进；先确定各方法的职责，避免让所有方法同时控制同一个选择。需要两条路径时，先写清主方法负责的故事问题，辅助方法只处理其专长。

## 结构先行：从完整行动推出阶段

**适用条件：**用户已确认故事要处理的核心行动，或已有大致目标、主要阻力和结局；主要困难是先后次序与转折位置。若仅有一个有力画面或人物声音，先走人物/片段先行，避免用结构模板替用户补造故事。

1. 用一句话写出谁要完成什么、什么力量妨碍他、失败或成功会损失什么。若这句话改变了用户原本的立场或核心，不把推断当定稿，回到故事开发核对。
2. 按 Aristotle《Poetics》第 VI—VIII 章的完整行动观，列出会改变主行动的事件。逐项问：删掉它是否会改变行动方向或后果？如果只因同一人物经历过它才留在表里，它还没有证明自己属于主线。
3. 用 Syd Field 的建立—对抗—解决作为一种阶段地图：建立人物、关系和行动前提；找出使主角进入新行动方向的转折；安排策略与阻力持续相遇；找出迫使故事进入最终行动的第二次转向；最后兑现选择的结果与代价。
4. 逐段写“人物此时想做什么—遇到什么新条件—采用什么办法—结果使下一段成为可能”。段落边界以目标、计划、关系、知情或局势的实质变化为证，不按幕名或百分比硬切。
5. 检查高潮是否由此前的选择和代价逼出；结尾回应开篇建立的故事承诺。若没有唯一解，给出少数结构方案，并说明各方案会改变什么观看体验。

**交付与验收：**交付主行动、因果事件链、各阶段作用、关键转向、高潮选择和结尾状态。每一段都能指出其前因与后果；Field 的阶段名没有取代具体事件；三幕式未被误当成必选比例。若事件有顺序但没有因果，返回故事核心或人物选择；若核心清楚但观看信息次序不清，转到 [叙事与结构](narrative-and-structure.md) 的视角与知识路径。

## 人物/片段先行：从零散材料发现故事轴

**适用条件：**用户提出的是灵感片段、人物、关系、场景、梦境、对白、情绪或观察，尚不能确定中心行动。结构先行与人物/片段先行是两种可选工作流，按材料成熟度选择；具体创作者的方法只用于解释其作品或已说明的个人实践，不从国籍推定创作规则。

1. **保留输入，允许创作推演。** 在内部整理用户给出的片段，辨认已确认事实、用户判断、未定灵感和创作假设；保留重要原句与意象。可以主动补出人物动机、因果连接和场景假设供故事发展，但要让用户能看出哪些是原始材料、哪些是新增构想，不把新增设定说成用户已经确认的事实。整理材料不等于自动建立新的素材文件或资料库。
2. **把片段写成可检查的卡片。** 记录人物、时空、眼前行动或观察对象、人物当时注意什么、可能希望什么、遇到什么限制，以及片段结束时哪项状态改变或保持。对缺失处可提出一两个能推动剧情的假设，比较它们产生的不同结果，不把未知永久冻结成空栏。
3. **寻找反复出现的东西。** 比较重复的物件、关系、动作、空间、愿望或矛盾；追踪重复中哪处发生偏移。问这些片段是否围绕同一压力、选择、问题或观看经验，而不只看它们是否有相同主题词。
4. **试排不同的观看顺序。** 可按时间、关系、地点、问题逐渐显影、重复与变奏、先结果后理解等方式排出两三个小样。每个顺序写明它让读者先知道什么、晚知道什么，片段之间靠因果、对照、累积还是空缺相连。
5. **从材料提出故事轴，而非宣布主题。** 写出“可能的核心问题”“人物可能采取的行动”“片段间已看见的关系”和仍然未定之处。若多个故事轴都能解释材料且会导向不同作品，保留选项并只追问改变创作方向的那一项。
6. **在材料支持后再定结构。** 当行动、关系或观察轴清楚，才选线性、交织、分段、回环或其他组织方式。可借用 Aristotle 的行动整体或 Field 的阶段地图检查因果型故事；无法解释材料时换框架，不删掉材料去迁就框架。若多个方向会改变作品核心承诺或人物结局，再并列方案或追问用户；若差别只在可继续创作的普通细节，选更能承接现有材料的方案并继续。

**交付与验收：**按用户要求的层级交付整理后的片段、重复/偏离图、备选次序或暂定故事轴。用户原始材料仍能辨认；新增因果作为创作方案呈现而非冒称既定事实；所选结构解释了材料之间的关系而非只为填满幕数。只有未决选择会改变核心方向时才停下来并列选择；否则按合理推演继续完成本轮产物。

## 群像交织：让交会改变各自的故事

**适用条件：**多个主要人物各自有目标、知识或生活路线，并在同一事件、空间、制度或关系网络中互相影响。人物数量多本身不构成群像结构；若只有一个主角的多名配角，先按主角行动链组织。

1. 每位主要人物写出独立的利益、价值排序、感知偏向、掌握信息、可用资源和当下行动。使用 [人物与关系](character-and-relationships.md) 的人物模型，不让角色沦为同一事件的不同解说员。
2. 选一个真实的共同压力或接触面：每人为何必须面对它，谁可以绕开，绕开的代价是什么？若人物只是轮流出场却不改变彼此的处境，先确定是否真的需要交织。
3. 做交会表：行列为人物或行动线，格子记录相遇后谁改变了判断、关系、可用资源、风险或观众知情。空格代表线之间尚无戏剧关系，不需要为了形式硬填交叉。
4. 按局势和观看目标安排交替。每次切换给出新的视点、对照、因果后果或等待结果；避免平均轮流。如果交叉线让观众知道角色暂时不知道的事，记下信息差并选择要制造的期待。
5. 在交汇点重新检查双方的独立立场。相遇可以合作、误读、利用、拒绝或彼此改造；奉俊昊在 2019 年 BAFTA 编剧讲座中谈《寄生虫》时，将人物互动作为其人物发展的重要来源，具体群像操作和该方法的边界已列在 [对白与视听](dialogue-and-audiovisual.md)。这是一位作者的创作说明，不是国别公式。

**交付与验收：**交付人物立场图、交叉点、切换顺序、每条线对共同局势的贡献及结尾各人的状态。每条保留的线都带来无法由另一条线替代的观察、行动或后果；删掉交会后若剧情与关系一概不变，回查交织的必要性。

## 观察与关系型：让重复、空间和余波构成推进

**适用条件：**作品有意把日常动作、关系温度、离场后的空缺、空间、等待或时间经验当作主要观看对象。它不是缺少剧情的代称：先说清观众要观察什么，以及重复、停顿或缺席会怎样改变理解。

### 从作品推方法，不从作者名字套模板

通用观察路径从当前作品的具体日常和关系事实出发：指出哪项行为、空间、等待或缺席值得比较，再看它怎样改变观众理解。分析特定作品时区分作品中可见的选择、作者确曾说明的实践、评论者术语和本地创作推演；不把个案提升为国别风格。用户明确选择小津或契诃夫时，关于其专门的方法判断和出处边界以[具名戏剧方法](named-dramaturgy.md)为准；本节以下六步仍完整适用于未选具名方法的观察/关系型故事。

### 操作过程

1. 写出观察轴：观众此刻看谁、看什么重复、等待哪种变化，或留意谁不在场。只写“孤独”“克制”还不够，需落实到能被感知的行为、空间或声音。
2. 设定日常基线：人物平时如何使用空间、完成任务、称呼彼此、处理物件或分享沉默。基线来自用户材料和文本，不从年龄、国籍或家庭身份推定。
3. 选偏离证据：某次动作变慢、少做一步、物件换了位置、座位空着、回应错开、日常声中断，或一个人离开后其余人的路线改变。偏离须使观众多理解一点，不能只负责好看。
4. 组织重复与间隔：重复动作之间建立可比较性；间隔让人感到时间、缺席或关系距离。选择重复次数、停留长度和切换位置时，分别问观众因此注意什么、需要记住什么、会不会失去判断依据。
5. 用空间承载选择：门、走廊、座位、桌面、距离和出入路线只有改变人物可见性、接近能力、归属或行动选择时才突出。静止画面和空景可使用，但不设为风格必备项。
6. 给场尾一个可延续的余波：离开者留下的动作、声音、空位、物件、未完成家务或关系状态如何进入下一场？允许人物不说破，但读者要能追踪观众为何会感受到变化。

**交付与验收：**交付观察轴、日常基线、重复/偏离序列、空间变化和段落间余波。静场明确提供了观看所得；若删去该场不会损失观察、关系、时间或情绪证据，调整其长度或位置。若作者的意图只靠抽象词陈述，返回场次动作和视听证据，不用解释性旁白替代场面。

## 系列与分集：同时建立本集闭合和长期变化

**适用条件：**用户要创作多集作品，或正在判断一个点子是否可以持续成为系列。先判明作品是单元剧/选集、角色重复而事件闭合的分集剧、长线连续剧，还是混合型；平台、集数和分钟数服从用户已给条件。

1. 写一句系列引擎：哪些人物在什么反复出现的场域里，持续遇到哪一类新问题；他们为何不能一次解决后离开？若回答只能是“他们每天都会遇到事”，发动机仍过宽。
2. 分开**可重复**与**会累积**的元素。可重复项包括固定关系、场域、职业流程、社群规则或目标冲突；累积项包括秘密、承诺、损失、技能、身份和权力变化。两类如何平衡由连续性类型决定。
3. 写单集承诺：本集独有的触发、问题、人物策略、主要阻力和结果是什么？单元型可在本集结算主要问题；连续型可以留下答案未完，但本集仍要有一次完成的决定、关系变化或局部代价。
4. 为 A/B 线或多线分别写问题、行动和结果，只在交叉能制造对照、相互改变选择或丰富主题时交织；不为表格齐全新增副线。
5. 写季节弧的起点、关键积累、改变引擎的节点和终点状态。弧线应改变后续集能发生什么，不是只在片尾追加一条秘密。每个悬念断点都由具体选择或未尽后果产生；分集剧不必每集靠 cliffhanger。
6. 检查生成能力：更换本集问题时，系列仍保有相同的故事承诺和关系动力吗？若每个新故事都要引入新世界规则或重置人物，先修系列引擎；若引擎成立但季弧压过单集故事，重排每集承载比例。

**交付与验收：**交付系列引擎、类型形态、可重复/累积要素、试播集故事、分集接口与季节终点。单集既让观众体验本集特有的问题，也证明同一系列还能生成新的问题；长线变化留下可追踪后果，不把所有集写成同一故事换案名。需要开发级校准时，读取[系列开发](series-and-production.md#series-development)；国产长篇人物命运线、单集戏眼和跨集段落安排读取[国产剧集创作路径](series-and-production.md#chinese-series-practice)；面向接收方整理项目文件时读取[国产剧集生产路径](series-and-production.md#production-path-document-chain-and-current-requirements)。本节仍是通用多集故事的可执行路径，不依赖新增子级才能工作。

## 情境喜剧：从真实需要和规则制造升级

**适用条件：**人物关系、共同生活规则或稳定困境会反复制造小而重要的问题，观众期待每集看常驻人物如何应对。若用户要的是讽刺、荒诞、黑色喜剧、滑稽动作或有连续情感弧的 dramedy，先保留其观看承诺，不把 sitcom 的两幕/三幕、笑点密度和结尾套进去。

**源方法边界：**以下核心分层与笑点修订法来自 Jim Smith《Writing Television Sitcoms》（2009）；Landau 的七步单集公式与多机/单机差别是其 2014 年版的模板；Blum 的布景和拍摄例为 2001 年材料；Fleabag 的装置案例来自 Waller-Bridge《The Scriptures》（2019）。数字在所列格式/年代内使用，不把它们写成所有喜剧的当代行业标准。

### 先选笑点原料，再定人物机制

第一步把笑点来源写成一条可重复的 premise：角色要什么、哪条规则/困境持续阻止、角色为什么不能直接离开。可从长期未解决的 Big Lie、Big Secret、Misunderstanding、两难、必胜计划、外来者打破现状、Time Bomb、Trapped in a Space、Sex tension 等 predicament 中选；“尸体”是 Smith 另列的第十项，不必为使用清单凑数。只有困境仍未解决时，它才继续供给同一种系列压力；若解决，需替换困境或让旧结果改变关系与后续事件。

然后选人物组合，而不是先给每人一个笑话标签：角色反转、局外人进入新世界、Odd Couple、欲望受阻、假扮身份都能提供摩擦。每个角色要贡献不重复的欲望、观点、惹祸方法或反应；一对关系中双方都须有各自有效的理由。人物组合失效的典型信号是两人只做同一件事、同一种反应，或来访角色抢走了常驻人物的故事。

**有真实机制的案例：**

- *30 Rock* pilot 的烤箱对话：Jack 问 Liz 会不会用 GE Tri-vection 烤箱，Liz 回 “I don’t cook very much.”；Jack 接着长篇解读她的生活，Pete 认同，Liz 再问他是否要猜体重。Smith 的删减对照认为，砍掉这段 development 仍好笑，却让 Jack 更公开敌意、较不符合人物（2009，第71页）。这说明 development 不只堆笑点，也在决定攻击性和关系声口；使用时要保留当前角色有理由说、另一人有理由接的那几拍，不把机锋平均给全员。
- *The Office* “The Secret”：Michael 答应替 Jim 保密他喜欢 Pam，却说漏嘴。可用机制不止“秘密差点泄露”：Jim 的保密请求让 Michael 误以为两人成了朋友，Jim 又被迫花时间陪他，困境因此从信息风险扩成了关系义务。适合选择“大秘密”且角色关系本身能产生第二层代价的集型。
- *30 Rock* 的误解案例：Liz 看到邻居墙上的地图，误以为他可能是恐怖分子并向国土安全部门举报；地图实际为 *The Amazing Race* 试镜材料。能迁移的是“证据→错误解释→按错误结论行动→行动造成更大后果”，误解需可理解，不能让人物无缘无故变笨。
- *Modern Family* pilot：人物介绍使用正面特质；不同人物配对都能形成冲突；每人的观点有可理解的正当性。适合群像人物网需要兼顾亲密与摩擦的前提，不能由此推导所有家庭喜剧都须相同家庭结构。
- *Cheers* 的 Sam/Diane：教材把二人关系真正兑现后张力减弱、再拆开并以 Rebecca 重建类似拉扯作为例子。若“想在一起却受阻”就是系列发动机，兑现会耗尽该发动机；应决定结局、替换压力或转到另一种引擎，不要无代价地拖延。

### 旧教材的困境与人物组合菜单：机制、例子和失效点

Smith 2009 的原书称“九种经典 predicament”，另把 Dead Body 列作第十项。使用它们是为找到可持续的新鲜组合，不是逐项打勾。通用前提：观众已经知道是喜剧，并相信角色不会遭受真实伤害；困境未解决时才持续产笑；重复旧型须忠于人物并给它新行动后果。原笔记未给专门失效条件的项目标成“未记载”，不从别处替作者补成原话。

| 困境 | 可直接执行的机制 | 旧书真实例子 | 选择条件/已知失效 |
|---|---|---|---|
| Big Lie | 一次软弱撒谎→更大的谎→崩盘或意外脱身 | *South Park* Cartman 假装有 Tourette's 后无法控制自己说真话；*The Simpsons* Bart 假装英雄后来信了自己的宣传 | Smith 未列单独失效规则；sequence 可把 Big Lie 变成 Bigger Lies，不要只原样再撒一次 |
| Big Secret | 知道不能说→漏嘴/圆谎→让秘密影响当事人 | *The Office* “The Secret”：Michael 替 Jim 保密暗恋 Pam，却漏嘴；Jim 被迫陪 Michael，秘密变成关系义务 | 单纯藏信息撑不满一集；把守密带来的新义务/接触写成第二层困境 |
| Misunderstanding | 可观察证据→错误因果解释→人物按误解行动 | *30 Rock* Liz 把邻居的 *Amazing Race* 试镜地图误认成恐怖分子证据并举报 | 误解须能从角色已知证据与偏见推导；笔记未记书中专限，不制造无根据愚蠢 |
| Rock and a Hard Place | 两个相近/不可兼得选项迫使人物选择 | *My Name Is Earl* 为道歉穿流苏上台，或为保命与仇人的母亲约会 | 两选项若一边明显优越，选择张力消失。Smith 2009 明确不再要求结局总是选高尚一边；此为当年价值判断，不能写成今天所有 sitcom 结局律 |
| Surefire Scheme | 自信计划按自身逻辑推进，意外结果放大损失 | *South Park* 把 Cartman 染成红发以惩罚歧视，却让他煽动红发儿童攻击非红发者 | 人物采用合乎其性格但荒谬的方案；若人物当场走最合理捷径，前提的喜剧压力会熄灭 |
| Something That Rocks the Boat | 外来者短暂威胁常态→常驻人物摊牌/反应→外来者离开或改变现状 | *30 Rock* Devon Banks；*Everybody Hates Chris* Greg 来住一周，全家宠他而忽略 Chris | 来访者不得盖过常驻角色；其问题须迅速变成常驻人物的故事，不让客串角色长期夺走发动机 |
| Time Bomb | 截止前完成不可能任务，时间逼迫逐步可见 | 旧书举例：父母外出开派对、花瓶打碎、父母提前回家；这不是书中点名的电视集 | 期限须有可感后果，人物行动能受时间影响；原笔记未给更多专限 |
| Trapped in a Space | 不相容人物被困在同一空间，每人都必须离开 | 旧书给电梯、孕妇/幽闭恐惧者、赶婚礼者的场景构想；*Fleabag* S1E4 静修营把密闭/静默禁令扩为一整集 | “被锁在门外且裸体”在 Smith 笔记中只够一场戏；空间压力一旦有人离开就结束，除非另一个关系/规则接棒 |
| Sex tension | 彼此吸引但被具体关系/规则/时机阻止，或亲密关系持续受打断 | *The Office* Dwight/Angela、Pam/Jim；*The King of Queens* 的性生活被打扰 | 若“不能在一起”是引擎，兑现会结束这台机器；*Cheers* Sam/Diane 的旧案例说明需选择结束、拆开或由新关系压力接棒 |
| Dead Body（第十项） | 藏尸、被疑谋杀、冒充死者，或被迫照料与死者有关的后果 | *The Mary Tyler Moore Show* “Chuckles Bites the Dust”：小丑因大象踩踏死亡，同事们压住笑意 | 最依赖观众相信没人真受伤；若伤害写实到压过喜剧契约，前提变成正剧 |

人物组合是第二张菜单，也不是配额：

| Mix | 作用机制 | 书中举例/使用边界 |
|---|---|---|
| Role Reversal | 被迫承担与本性不合的责任/身份 | 单身父亲照料三个幼儿；*Married with Children*、*The Simpsons* 反转理想化家庭。人物适应后，原反转张力会减弱 |
| Fish Out of Water | 人物带着旧规则进入陌生世界 | *The Beverly Hillbillies*、*Entourage*、*Weeds*。差异来自生活规则/身份，不靠口音把外来者写成笨人 |
| Odd Coupling | 不相容生活方式被迫共处 | *The Odd Couple*、*Two and a Half Men* Charlie/Alan、*30 Rock* Liz/Jack。来访角色需要满足上表“不过度抢常驻戏”两条 |
| Sex | 欲望明确、阻碍反复，关系满足会改变引擎 | *The Office* 两对办公室关系；*Cheers* 的兑现/拆分是发动机失压样本 |
| Pretense | 人物伪装成另一个身份/地位，最终遭曝光 | *The Office* Michael、*Entourage* Johnny Drama、*Curb Your Enthusiasm* Larry David、Bart 进资优班。Smith 的同学会假装有钱/瘦/订婚是套路反例；*30 Rock* Liz 发现自己曾是霸凌者，是把曝光转回主角的翻转 |
| “身份即机会” | Smith 2009 将同性身份/关系列成当年市场空缺 | 这是旧市场判断而无足够写法机制或当代依据，不作可操作的硬分类；当代项目须以人物具体欲望和关系机制判断 |

### 从 premise 复合到场景升级

写每集前先回答“这集扩展了本剧的什么期待”，再按下面的顺序破故事：

1. **给人物一个认真需要。**选一个对人物重要、对外部世界看似很小的目标（保住面子、隐瞒失误、赶走访客、争一个位置）；让观众清楚他为什么在意。
2. **从 series premise 派生本集触发。**触发可以新，但麻烦必须能从常驻人物的缺陷/关系/规则长出来。先确认这仍是同一部剧。
3. **给人物分配彼此冲突的策略。**角色按自己的利益与信息行动。短暂的 unnatural alliance 可以让观众同时等待问题解决和结盟破裂。
4. **复合困境而非重复困境。**叠加同类麻烦（一个谎言逼出更大的谎言）或让另一条线改变主角解决问题的方式。每次升级改变赌注、知情、地位、资源或策略。
5. **选主导笑点机制并设置喜剧高潮。**场景机制可以是误解、字面执行、身份倒置、计划失败、重复但变形、局促共处、预期反转。一个 sequence 可以以 comedy block 达到峰值；副线只在改变主线、人物关系或本集节奏时保留。
6. **写出可见的局部结算。**人物得到了/失去了什么？原始需要是否解决？关系是否变了？tag 只有在回到熟悉世界能再揭示一次人物缺陷时才加。

**案例—联盟同时生成两种期待。** Smith 用 *Seinfeld* 中 Jerry 与 Newman 临时互相求助说明 unnatural alliance：观众既等眼前问题，又等两人恢复原本互相排斥的位置。迁移条件是角色本来就有稳定对立，联盟需由当集共同利益造成，结尾恢复或改写原关系；不能为了一个笑话硬让敌人合作。

### 逐拍写笑点：setup—发展—转折—反应—后果

局部笑点先写动作目的，再修台词。Setup 建立可信预期，至少有话题和一两拍 development（复杂化/反差）；punchline 从观众预期之外给出能回看理解的转折；人物反应能加深关系，场尾后果再改变下一步行动。Setup 可以在同场拆开，也能隔几场铺；Punch 通常放在一句或一段末尾，别解释笑点或再补一句削弱它。

- **调试顺序：**先检查观众理解 setup 与人物立场；笑点没响时回查 setup/development，而非无限改同一句 punchline。
- **位置：**关键词/动作常放句末或段尾；若角色的啰嗦本身就是笑法，可故意延迟，但须由人物节奏支持。
- **Topper：**同一 setup 可追加一至两次加码；Smith 2009 的限定是最多两次，过多会显露套路；dramedy 通常不靠 topper。
- **Running gag/callback：**Smith 的旧模板常以2–3次变化做回扣。每次需换意义、承担新信息或改变人物位置；第三次以后若只是原样重复，删除或升级。
- **人物声线：**一个角色可以主要靠钝拙、过度自信、反讽、急于证明、字面理解等一两种细节出笑；不是让全员共享机锋。场景句法/表演调度回父级场面和对白方法。

若用户指定 Smith 2009 格式并需要密度审查，可用红笔逐页圈出确实预期观众发笑的点；该书约2–4个实笑点/page 的数字只作所选模板的诊断值，笑点的类型也须稳定。单机可留尴尬停顿，单机靠剪辑与短场变奏；多机沉默可能成为 dead air，要通过走位、出入场或演员反应让静默仍在表演。任何格式都不应为了数字毁掉角色声线。

### 结构公式与条件模板

Landau 七步（半小时单集）按结构而非逐页照抄：①日常世界被一个 tremendous trifle 打破；②第一幕后主角定计划，配角线进入；③一个主题/压力把各线连起来；④在两幕剧第一幕末、三幕剧第二幕末，以中点反转令解法产生更大问题；⑤后半抵达 all-is-lost；⑥末段以真相、沟通或弥补兑现本集问题；⑦可选一个短 tag 让人物回归熟悉日常。中点后不能只是更多同义误会，要增加代价并迫使策略更新。

结构数字须跟着格式选，不能混用：

| 选定模板 | 可用旧规格 | 约束 |
|---|---|---|
| Smith 2009 单机 film-format、约30页、单主线、非pilot三幕 | 第一幕1–5页、第二幕约15–20页、第三幕约5–10页；beat主线5–9、副线3–5 | 人物/世界已建立；pilot第一幕通常要更长；不得把这套页码套在两幕多机 |
| 多机两幕 sitcom | cold open + 两幕 + 可选tag；Blum 2001常见每幕约10–12分钟 | 页数不是分钟数，tape双倍行距；指定剧本的真实模板优先 |
| 多机长场样本 | Landau 2014 记录15–20场、每幕约3–5场 | 是舞台共演的参考，不适合剪辑式单机的场数 |
| Smith 2009 三种格式页数 | 单机27–30页；多机45–50页；动画40–50页 | 这是英文稿的格式/排版口径，不可直接换成中文长剧字数 |
| 多机棚景经济 | Blum 2001记录3个理想、5个上限；Smith记常设布景与摆动景 | 只对固定棚拍/多机布景成本有意义；单机外景不套“场地数上限” |

格式模板的物理排版也随分支切换。Smith《Writing Television Sitcoms》2009 Appendix A 的英文字稿模板如下；只在仿写该时代/目标剧本时逐项照用：

| 项目 | Film/single-camera | Tape/multi-camera | Animation |
|---|---|---|---|
| 页面与对白 | 约27–30页；动作/场景说明单倍，对白单倍；新人物名大写；通常不编号场景，多数转场省略 | 约45–50页；对白双倍；动作提示全大写；角色名/进出场动作下划线；除cold open/tag外场景可编号并以字母或数字排序 | 约40–50页；接近film格式，对白双倍；动作提示单倍、约70字符宽；各剧幕数不同 |
| 12pt Courier New（按原稿字符位） | 全页右移6位装订；正文16–75、对白28–63、cue34–57、角色名从40位起、转场从60位起 | 正文16–70、对白（含cue）26–60、角色名40位、转场60位 | 接近film列宽；动作提示止于70字符位 |
| 场尾/幕标 | 依目标剧样本；spec通常不加镜头指示 | `CUT TO` / `DISSOLVE TO` 等按样本大写并下划线；幕尾标记后换页 | 标题/转场可加粗，按目标动画剧本 |

Tape/multi-camera的`END OF COLD OPEN`、`END OF ACT ONE`、下一幕另起页、`TAG`和`END OF EPISODE`照目标剧稿；Smith 的 spec 样本省略场景号、page header revision、场景下cast list、独立音效/特效slug、镜头命令、稿次和日期，以便顺读。production draft 需要这些字段时按制作方要求加回。多机布景的旧经济模板：3个standing set（1主+2辅）理想、5个上限，另可1–2个swing set；spec尽量只加1–2个新布景。它不适用于单机实景剧。

多机页数有来源差异：Smith 2009记录45–50页；Landau 2014的一种多机模板为teaser 1–2、Act One/Two各17–20、tag1–3、总40–48；Blum 2001记多机录像约40–50页，并给2幕《Frasier》约50页、teaser+2幕+tag的《Friends》约50页、4幕《Ally McBeal》50–55页。页数差异不能平均成新标准；角色对白双倍行距导致页/分钟率不同，最终以目标剧本/接收格式为准。

如果剧本是三幕单主线与两幕 multi-cam 之间难选，先依据拍摄方式和目标样本定幕制，再安排 beats。戏剧结构的幕与广告 break 容器并非同一概念；场景目标、动作升级、价值转折等通用方法仍由父级场面方法负责。

### Dramedy、装置喜剧与真实案例

**Dramedy 条件：**角色/故事有连续 backstory 和情感弧，笑主要是 wry/ironic 而不是每段固定 punchline。Douglas 的旧提醒是“超过三分钟的材料不能只靠 joke-to-joke 推进”，用作这种写法的来源边界；这不等于按计时器强制每三分钟切一次情绪。喜剧副线若不改变主线因果或关系，就是填充。

**Fleabag 的 to-camera：**Waller-Bridge 的创作回忆把它说成人物的心理防御与“表演”，而不是任意打破第四面墙。若当前角色需要借观众回避/管理与他人的亲密，可按以下顺序试：①拍一小段检验装置可演；②先建立角色对镜头的惯例；③让惯例偶尔被他人揭穿，装置因此进入剧情；④把镜头由共谋转为压力，并在结尾让角色决定是否告别。*Fleabag* 第一季是共谋，季末镜头追到她并逼出记忆；第二季神父察觉她“消失”，装置引起两人关系变化。迁移的是装置的关系弧，不是每集对镜或六集结构。

**Succession 的黑色幽默：**在 Kendall 讲出车祸事实后，Roman/Shiv 用残忍笑话承接罪责，笑的功能是这家人可表达的接纳，不是抚慰受害者；Greg 的王位支线调节沉重段落，最终又推动 Tom 作出决定。迁移条件：黑笑必须符合人物关系/语言习惯，喜剧副线仍需剧情功能，不能只作“调温插科打诨”。

**真实案例的用途：**案例事实、作者自述、从剧本归纳出的机制分开写。不要拿美国电影案例库的黑色喜剧或怀尔德电影对白证明电视剧幕数、场景数或制作格式。

**Fleabag 的六集季案例（仅在短季/单作者/装置与主题共同驱动时借用）：**旧剧本分析观察到每季6集、每集约25分钟；S1每集可见 `cold open（约1–3分钟）→titles→数个段落→button`。其六位置骨架是：①铺开人物与悬念；②将人物情绪变为欲望；③在家庭/社交处境揭第一次底牌；④封闭空间+禁令（静修营）逐次被违反，最后一次转成情感爆点；⑤伪胜利；⑥让人物聚回一个封闭社交场合、逐线关门。它是该剧结构观察，不是普遍六集模板。两条可迁移手法：季终 button 可回答作品主题而不消灭仍有效的情节问题；贯穿全季的物件每次易手都应改变人物对过去的理解。Waller-Bridge 文本中雕像经偷/卖/礼物/坦白/归还等多次转手，最终揭示母亲来源；不需要有相同物件才可用。

装置写作顺序：先用手机等轻量方式拍五分钟，检查对镜是否能演；惯例可由旁白、说话中插一句、无声眼神组成；同一装置不能每次只提供解释，它要在某次诚实交流中失效，随后被其他人物注意并改变关系。*Fleabag* 的一次长告解不对镜头说，情感峰值因此与日常共谋方式形成反差；Boo 站在车流对面等视觉句子直接呈现创伤，不靠角色复述。可迁移的是形式装置与人物防御相互咬合、且有退出方式，不是复制镜头梗。

在 *Fleabag* 的情感场面中，旧分析把节拍概括为“痛→笑→痛”：先让人物说出真实痛处，再以视觉笑点/贱话显示其防御，最后回到尚未解决的痛处；笑不负责取消痛。创作回忆还记录了主角常在辩论中输掉立场、由道具或配角的短回应揭开主题。可借此观察笑如何承担防御/反应，不把该情绪顺序规定给所有喜剧。

**交付与验收：**产物至少可见：本剧 premise、所选格式与模板条件、人物组合、该集触发/目标/策略、困境叠加、中点升级、笑点setup与反应、场尾后果。验证观众能先理解人物期待、再理解哪里出错；升级来自角色行为；笑点改变关系/局面或确实兑现角色声音/节奏。若场景删掉包袱后动作、关系、信息与节奏都不变，且笑点不承担声音功能，删掉或重建场景机制。

## 悬念、惊奇与谜题：安排观众和人物的知情差

**适用条件：**用户希望观众等待危险、结果、身份或原因揭晓。若作品并不需要这些效果，不额外添加威胁、倒计时或秘密。

1. 先选主要观看问题：**悬念**让观众预期可能发生什么；**惊奇**让新揭示立刻改写理解；**谜题**让观众追问原因、身份或真实过程。可混合，但需指定当前段落优先实现哪一个。若用户明确要层层钩子、每次揭示打破预期、反复带来新鲜感或爽感，选“惊奇递进”主路：每个关键兑现都必须带来与此前主要预期实质不同的新理解或后果，再由这次兑现生出有依据的新问题。
2. 为关键事件建知情表：观众、主角、对手和其他关键人物分别何时知道什么、误解什么、从哪项证据得知。没有证据来源的“误会”不能控制行动。
3. 写清赌注：若不及时行动/若揭示为真，谁会失去什么？期限只有在故事内自然存在时才设定。
4. 决定揭示顺序。要悬念时，可先给观众足以预期危险的证据，让人物暂时未察觉；要惊奇时，保留关键事实，但先埋能让答案回看成立的线索；要谜题时，逐次提供可比较证据，让错误答案也有根据、最终答案能解释旧事实。
5. 将线索、假线索、隐瞒理由和揭示结果逐项连回人物选择。揭示不只让观众知道真相，还要改变计划、信任、危险或关系，否则只是信息补充。对“惊奇递进”路线逐个核验：兑现是否真正越出该段落建立的主要预期，是否重组观众对人物动机、事件因果、关系或代价的理解，前面的线索能否因此回看成立；不要以“确认猜测也算兑现”为由削弱用户明确选择的新鲜感。悬念、关系确认、共同探索等其他路线按各自承诺选择结果与余波，不强制套用惊奇结构。

希区柯克在 1963 年戛纳访谈中借“观众知道炸弹在那里”解释信息差；引文与译法见 [叙事与结构](narrative-and-structure.md)。把这个例子转成知情表，不转成每部戏都得有炸弹的剧情规定。

**交付与验收：**交付知情矩阵、线索顺序、揭示节点、误认依据和揭示后的行动后果。观众知道得早/晚符合预期效果；惊奇有前置证据可回看；谜底解释已给线索；人物按自身信息行动。若观众无法判断人物为何此刻行动，补最小必要证据或调整揭示位置。

## 情绪与空间：地域、类型和具名方法的深化

**适用条件：**用户明确要以特定地域/生活秩序、类型契约或具名导演/编剧方法控制场景空间与氛围，或普通场景已有清楚的环境方向但需要跨场次深化。普通场景中观察重心、空间权限、环境细节、感受轨迹与声画实现的通用方法，只在[场面开发：环境、观察与情绪轨迹](scene-development.md#环境观察与情绪轨迹从感受方向到可执行声画)维护；本节在这个底稿上增加专项选择，不重复通用步骤。

1. **具名实践先核来源。** 用户点名导演、编剧或作品时，从[具名剧作方法](named-dramaturgy.md)或[地域编剧实践](regional-practices.md)读取能改变本场的具体做法，标出其观察位置、空间安排、感官组织或节奏签名，再判断哪些变量适合当前作品。具名方法是创作选择，不把某位作者的手法改写成无来源的普遍规律。
2. **地域与生活秩序落到条件。** 若用户选择具体地域，将当地的居住、劳动、制度、气候、家庭规矩、资源和公共空间使用等材料，转成角色实际拥有的通行、停留、发声或使用物件条件。只采用有材料或用户设定支持、会影响本场观察和行动的细节；地域本身不替人物指定性格、口音或价值观。
3. **类型方法落到声画承诺。** 判断该类型在本场让观众期待怎样的空间感和信息感，再决定用什么光影、声音、距离、材质和节奏兑现。作者主动偏离已建立的类型预期时，明确偏离产生的新意义、关系效果或代价，并保留观众能辨认的落点。
4. **跨场环境保持有变化的连续性。** 若空间、物件或感官线索跨场重复，记录其初始意义、每次出现时的人物关系/知情状态、发生的偏移及后续回声；重复只有在变化能被观众感受到时才承担结构工作。系列、具名作者或区域方法的固定项依相应子级执行，不能把它们稀释成统一的“氛围风格”。

**交付与验收：**说明本次选择的专项来源与固定变量、用到的具体生活/类型条件、它如何改变各场观察与观众经验，以及哪些通用场景规则由[场面开发](scene-development.md#环境观察与情绪轨迹从感受方向到可执行声画)承接。若本轮没有用户指定的地域、类型或具名路径，使用通用方法即可，不为调用专项而制造专属风格。

## 跨媒介改编：迁移戏剧功能，不逐字搬运表面

**适用条件：**用户要求把小说、散文、真实经历、游戏、漫画、舞台作品或既有剧本改成另一媒介。先确认用户拥有/提供了哪些材料，以及不可改变的事实与授权范围；需要原文而当前上下文没有时，索取必要文本或先只做基于现有材料的方案。

1. 列源材料里的承重项：事件、人物选择、关系、主题问题、关键意象/对白、事实限制、用户明确希望保留的体验。区分“必须照留的事实”和“它在源媒介里承担的功能”。
2. 做功能映射：对每个承重项写明它让读者/观众知道、感受、等待或重新理解什么，再写目标媒介有哪些可用表达通道。示例维度包括叙述视角、行动、对白、画面、声音、空间、交互和时间安排；只选当前媒介可用且真的有帮助的通道。
3. 给每项标记**保留、转化、合并、删减或新增**，并写理由和对全篇因果的影响。内心叙述可由行为、台词、旁白或视听组合承担，但不规定一律“展示不要说”；画外信息也可以由合适的叙述声承担。
4. 先改写一段完整序列作为试片：保留同一戏剧功能，对照源材料，确认目标媒介表达有无丢失人物立场、因果证据或作者要的情绪力度。
5. 更新目标媒介的大纲和场次后，追查被删改内容的下游依赖：动机、伏笔、关系、信息和结局是否仍成立。忠实度以用户锁定项与体验目标为准，不以字数相似或逐句对应衡量。

**交付与验收：**交付保留/转化/合并/删减表、目标媒介表达方案、试改序列及对全篇的影响。读者能理解哪些变动是有意选择；改编后的事件仍有因果，人物行动不靠原媒介特有信息却未重新建立；用户明确锁定内容得到保留。若转化需要改变结局或事实，说明改变点和影响，按授权范围推进。

## 方法产物如何接回主流程

将方法产物转成主流程当前所需的层级：故事雏形回到主 Skill 第一步；分段大纲或系列引擎回到整体结构步骤；阶段内场次回到场次展开；台词、视听与版式分别回到 [对白与视听](dialogue-and-audiovisual.md) 和 [格式与交付](script-format-and-delivery.md)。先完成当前分支的验收，再决定是否需要切换方法；切换时保留已确认的事实、立场和用户取舍，不能因换框架自动清空。
