# 对白与视听：台词是行动，潜台词是暗流，心声是真推演

起草正文台词、破解对白发平、设计潜台词与情绪表演，或处理 `VO` 与声画分工时读取本文件。人物底层性格与声音七维承接 [character-and-relationships.md](character-and-relationships.md)。

## 1. 台词是当场对人采取的行动

每一轮承重对话只沿一条活人链条生发：**刚发生的刺激或上一句话 → 说话人此刻想影响谁做什么 → 他按自身声口、关系风险与当下筹码说出的话 → 对方针对真实听见的话和看见的动作作出的回应 → 关系、控制权或下一步的改变**。

### 正向起草五步与后台逻辑隔离
1. **接住现场，不留悬空指代**：从上一句或动作直接起笔；首次驱动行动的对象先靠可见物件、屏幕或行动给观众落点，人物再用共同生活里的简称，绝不把只有角色懂的基本句意留在作者脑里。
2. **先定交际动作，再选活人母语**：明确这一句是在回答、追问、安抚、拒绝、讲条件、试探还是回避。劝说防御或羞耻中的人时，先认准对方真正在护什么与改口代价，再递出对方能自由接受或拒绝的具体做法；专业汇报先说结论再补限制；急迫保护先喊行动再说危险。
3. **真话语序、写活完整一轮，再删无用垫话**：把每句台词拿掉标点平声念给对面坐着的人听——必须像此人此景真会开口说出的自然汉语（**八成素净白话底配两成点睛**，清掉翻译腔、话剧宣讲腔与四字压扁书面词，同时完整尊重刻意立住的学者腔、专业汇报或古风语域）；选常用精准动词承载施受关系（分清发现、核对、确认、证明等真实证据跨度），不抽干虚词压成怪电报，也不事后把生硬拗口的句子洗白成风格。
4. **后台逻辑校准与前台人物声口自然分轨**：权限规则、证据链与结构推理留在作者后台核严；一进台词立刻切回该角色此刻的真实身份、关系语域与鲜明性格底色（医生对同事用专业语，亲属问安危直说活人话；若角色本身带有拟人 AI 播报感、温暖话痨、学者腔或毒舌傲娇等刻意人设，则顺着其独立职责与性格自然放大，让风趣从处境里长出来）。
5. **对方只接真听见的话**：下一句绝不按大纲清单轮流发言，而是顺着上一轮的压迫、漏洞、称呼微变或沉默给出真实反应。

## 2. 六种对白冲突模式、多人交谈与权力签名

### 打破千场一律的六种对白组织模式（McKee）
当对白变平或每场都在正面硬吵时，按本场关系切换打法：
- **均衡冲突**：双方筹码与目的清晰，逐轮争控制权，每轮改写下一轮策略（如《黑道家族》医患边界拉锯）；
- **喜剧冲突**：双方各用弱点与虚荣互相拆台，升级至失态或身体动作（如《欢乐一家亲》截稿互揭）；
- **不对称冲突**：一方步步紧逼追问，另一方回避、敷衍、转移或让步，压迫感落在节奏落差里；
- **间接冲突**：借礼貌、闲谈、敬称或第三人掩护敌意与操控，表层礼节与暗中博弈并行（如《了不起的盖茨比》晚宴）；
- **自反性冲突**：人物借对白或倾诉与自己的记忆、旧承诺或自我形象交锋；
- **微限冲突**：不靠强攻，靠极短问答、迟疑、停顿与细微承认累积孤独、亲近或失落（如《迷失东京》酒吧初谈）。

### 多人交谈与共同生活材料
三人以上同场绝不轮流汇报或齐声点题：先定各自手头正在干的事与私心，找一件大家共享的任务、物件或现场打断（如一起收拾、做饭、修物、核账），让人物一边干活一边顺着刚听到的话或动作插嘴、偏题或借物施压，自然显出各自注意力与关系远近。

### 权力动作签名与留白重复
- **权力落在交谈控制上**（如曹禺《雷雨》逼药）：谁定话题、变换命令对象、打断发言、逼人重复、拒绝称呼、拖延或提前离场，谁就握着主动权；打断须让观众听清被截断的是哪项主张或选择，不拿破折号装张力。
- **有道理的长句与克制留白并存**：角色确有知识与压力逼迫时，完整推理、专业陈述或诗性独白同样有力，只需给足听者反应与落点。留白区分愿直说、知而不愿直说（落进言行反差）与尚未成形的需要（从回避与代价透出）。刻意重复同一句话或动作时，第二次必须改变听者、压力、语气或含义，绝不原地复读。

## 3. 潜台词与迂回对白（Mamet / Pinter 技法）

当直接说出真实目的会付出尊严、安全或关系代价时，用两层行动写活潜台词：
1. **找一件两人眼下真要办的实事**：手边的物件、一顿饭、修补旧物、一份手续或找一把剪刀——把表层事务的问答写完整，把不敢明说的关系请求压在其中一个小决定上（借小事发问、只答边缘、反问施压、复述对方用词改义，或冷不丁岔开话题）。
2. **给观众可观察的暗流证据**：靠前文承诺、一次有对象的停顿、话面客气与动作躲闪的反差，或听者突然改换态度，让观众听懂言外之意；选沉默时写清沉默里谁在等什么、手上在做什么。
3. **把暗流落到场尾变化**：遮掉作者解释后，表层事务线、暗流依据与回应留下的关系位移仍清清楚楚。需要直说、命令或坦白的时刻仍干脆直说。

## 4. 可说性、节奏交替与 Button Line 场尾收口

- **急促短打（Staccato）与铺陈长句（Legato）交替**：时间紧迫、抢话、隐瞒或亮底线时走短打；试探、周旋、撑体面或铺推理时走长句；当对方一句话或停顿改变筹码时果断换速，把重音落到真正改义的词上。
- **Button Line 场尾实词锤与 2–3 处戏眼名场面**：重要场次收尾前，先认清本场最后一个可见或可听的变化，把最能一锤定音的一句台词、一个选择动作或一段有对象的沉默立作场尾，删光戏已演完后的解释补话，留足演员表演与镜头呼吸的空白。写场尾锤或戏眼金句时，**先钉死落尾那个扎实的具体物件、动作或大白话硬词，再往前顺前半句**，绝不端着架子喊空洞文艺口号。全片集中部署 **2–3 处过目难忘的戏眼金句或名场面**（主高潮 1 处 + 前后转折 1–2 处），借同词回扣改义、表里双轨、前扬后劈反转、客气冷刀或标志性动作回响出彩；严守绝不句句抖机灵毁真气，每处必过第一遍顺滑零门槛、回味半秒直戳情绪痛点的快检。

## 5. 情绪表演因果与声画分工

情绪不是贴在台词旁的形容词，而是可演的六环因果：**起始状态 → 现场具体触发 → 当下想影响谁的目的 → 身体呼吸/目光/距离的微泄露 → 采取的台词策略或沉默 → 句后可见后果**。需着重强调情绪突变或言行反差时，按 [台词行与表演括注](script-format-and-delivery.md#台词行与表演括注) 给一句短小可演信号。

- **画面与声音互补**：画面优先交付主体、空间位置、环境光声、物件状态与行动变化（遵守 [画面描述写什么](script-format-and-delivery.md#画面描述写什么)）。声音用来补画外事实、延续离场行动、反衬画面或撑起等待；动作目光已演透时绝不补台词复述，声源严守 `OS`、`VO` 与设备传声标法。

## 6. 让观众听见人物怎样想（`VO` 真思考流三分法）

**无声顿悟永远高于嘴说解释**：凡能靠眼神切换、物件照面、前后证据同框对照与微动作停顿让观众自己拼出真相的瞬间，**坚决省掉 `VO`**——让观众比主角早半拍或同步自己悟出答案，张力远胜过听主角把推理念出来。只有当人物内心的逻辑反转、隐秘偏见或反讽态度靠纯声画完全猜不出时，才启用 `VO`，并严守三分判据：

| `VO` 形态 | 观众体验 | 写作处理 |
|---|---|---|
| **零增量复述 / 辩论说明书（删）** | 像作者替观众做阅读理解、念规则或背流程 | 删除重复刚看见/听见事实的话；把“不是 A 而是 B”辩论腔、自我播报口号和工整 `if...else` 排比改回此人此刻真实的念头。 |
| **过度压缩电报（禁）** | 貌似简练，实则含混突跳，掐断推演代入感 | 凡观众说不清人物在想哪件具体事、凭什么转念、下一步干嘛，立刻补回触发转念的证据桥梁与自然呼吸。 |
| **高增量真实思考流（目标）** | 跟着主角一步步排雷、打破直觉、暗爽屏息 | 从刚收到的反常反馈或矛盾起笔，写出人物如何排除死路、拿不准什么、决定如何试探，落回下一问、动作或等待；全程严守该角色基准声口与真实知情边界。 |

交付前逐句试着遮掉 `VO` 连读相邻声画：遮掉后意思与情绪照样成立的删去，真正承载转念增量、情绪反差或节奏韵律的留足分量。
