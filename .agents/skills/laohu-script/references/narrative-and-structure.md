# 叙事与结构：用专业戏剧力学搭出抓人的故事骨架

本文件是剧本宏观结构、预期落差、信息控制、高潮建构与可选工业长片口径的武器库。按当前创作瓶颈直取对应章节，不机械填满全部模型。

## 1. 先定观众体验，再选组织形态

把**题材**、**类型承诺**、**基调风格**、**视角聚焦**、**时序**、**结构**、**节奏**与**媒介时长**分开判断，不拿一个风格标签糊弄所有决定。先钉死观众从头到尾要经历什么情绪或认知变化，并把每项核心卖点落到具体场次和行动结果上，绝不让卖点只停在口号介绍里。

### 完整因果故事的五项宏观功能

组织完整行动因果故事时，按 Robert McKee 五项宏观功能打透全篇脊柱（它们是全故事层面的功能，可跨幕也可同场相邻完成，不等于死板的幕数或场数配比）。**务必双向咬合推演**：先从拟议终局倒推它成立所需的必经选择、认知、资源与前置铺垫，再按各方当时实际掌握的信息和利益正推可行反应；两路接不上时，修未锁定的路径或前提，不硬逼人物违背常识配合剧情。

| 宏观功能 | 正向造戏动作 | 成立判据 |
|---|---|---|
| **激励事件** | 由既有世界条件触发，打破主角原本赖以运转的平衡，逼出不得不应对的核心问题（事件发生与主角得知可分开铺设）。 | 原状态、失衡点、被迫回应者与观众开始追问的利害一清二楚。 |
| **进展纠葛** | 人物依当时证据试法，对手与世界按自身目标、资源与限制回应，让旧办法逐渐不够用、选择更难、代价更重。 | 每次承重回应都改写下一策略；不靠凭空加大灾难或无后果倒计时造假紧张；抽去无后效的一环就删或并。 |
| **危机** | 常规路径耗尽后，人物站在前文铺出的真实两难前，必须权衡保住什么、牺牲什么，且此刻无法再拖。 | 看清选项、依据与真实代价；危机是决断时刻，不等于最喧闹的大场面（无真两难则写清唯一路下的承担方式）。 |
| **高潮** | 人物将危机决定付诸行动或亲身承受后果，动用前文铺出的认知、能力或选择，使核心局势发生不可逆变化。 | 区分危机决定与高潮行动（如《末路狂花》决定开下去是危机，驶向峡谷才是高潮）；不靠临时外挂救场。 |
| **结局/收束** | 结算主问题、人物代价与副线余波，兑现或有据改释开场承诺。 | 完整短片/单集本次必须实质兑现主要回报，不拿续集预告抵债；开放结局也要让观众看清已结与留白之处。 |

### 构造有效落差：人物预期、世界回应、下一策略

只要一场承重戏需要制造冲突、反差、悬念、策略转向或命运改道，就用 McKee 的 Gap 机制造出一轮硬核咬合（普通日常、观察或陪伴场不强套）：
1. **锁死行动者的当时依据**：主角凭此刻真正掌握的信息、资源与盲区出手策略 A，预期得到结果 B（绝不把作者上帝视角塞进角色脑里）。
2. **推导出人意料又情理之中的回应 C**：从对手或环境自身的目标、信息、权限与局限出发，推演为什么实际回应 C 在方向、力度或时机上撞碎了 B。若 C 是人物主动坦白或露底，须有此刻想赢或想避开的现实理由，绝不只因观众需要知道答案。
3. **落差逼出改策与真代价 D**：人物重新消化 C，发现旧判断失灵或退路被封，被迫付新代价换策略 D（若 C 没有改写任何处境、选择或关系，这场戏只是动作陈列）。
4. **向上承重复核**：确认这一轮 A→B→C→D 真实推动了场景状态、序列问题或全片可行路径，且观众回看能认出 C 的前文依据。

### 幕、序列、场、beat 的拆分和回查

仅当篇幅与任务需要多层级规划时向下拆解，切忌把不同尺度混为一谈：
- **幕 / 阶段**：改变全篇主行动的大方向与可行路径（普通完整影视剧本默认建置—对抗—结局三幕；已定其他结构或观察/片段形态按实际依据组织）。
- **序列（Sequence）**：围绕一个局部目标展开的连续行动单元；从上一段留下的成果、损失或新条件起步，经策略与阻力形成局部结算，再把新局面交给下一序列（不靠换地点重复同一套受阻打法）。
- **场（Scene）**：以真实连续时空为边界（地点或时段改变另起场头），承担明确的入场直觉、场内转向或观察任务与离场把手，交 [scene-development.md](scene-development.md) 落实。
- **节拍（Beat）**：场内相邻的动作与回应转向，用于编剧内部把握攻防与情绪起伏（节拍不等于镜头 `M`、`△` 段落或视频 `P`，普通正文不标节拍号）。

**向上回查铁律**：不要把同一个主角能不能成功的问题在幕、序列、场三个尺度重复提问——全篇问终局命运，序列问眼前阶段能否做成，场内问这一回合谁抢下主动权。

## 2. 按症状调用经典结构大师武器库

以下大师方法各自专治不同结构难题；用户点名或症状对口时直接调取对应抓手，不要求全篇齐用：

| 遇到什么结构难题 | 选用哪位大师武器 | 核心可执行动作 |
|---|---|---|
| 事件松散、像日记流水账 | **Aristotle 行动整体与逆转发现** | 逐一做删场检验：拿掉这件事后主行动和结局若原样成立，它就没接上因果；让反转与发现从前事必然或大概率生出。 |
| 整片方向模糊、不知何时转入新局 | **Syd Field 双转向范式** | 用建立—对抗—解决定大骨架；用 Plot Point I 把主角推入回不去的新对抗方向，用 Plot Point II 逼进终局决战（看行动是否真改道，不死守页码百分比）。 |
| 短篇或单集要写出清晰蜕变闭环 | **Dan Harmon 八环（Story Circle）** | 走完八态：You（常态）→ Need（缺口）→ Go（越界进陌生处境）→ Search（试探适应）→ Find（得到或自以为得到）→ Take（付代价）→ Return（回原处境）→ Change（以可见对照显出改变或固守代价）。 |
| 商业类型长片需严丝合缝兑现娱乐节点 | **Blake Snyder 15 拍职责** | 按职责核对 Opening Image、Theme Stated、Set-Up、Catalyst、Debate、Break into Two、B Story（承载主题关系）、Fun and Games（兑现核心看点）、Midpoint（改风险与胜负观）、Bad Guys Close In、All Is Lost、Dark Night of the Soul、Break into Three（A/B 线汇合新法）、Finale、Final Image（前后镜像对照）。 |
| 传统人物蜕变片主题浮在台词表面 | **Craig Mazin 论点信念弧** | 把中心主题写成一句可争辩的判断；开场显出主角起初坚信的反面信条及靠什么维持现状；用直击其恐惧的失衡事件与一连串反例、挫败、短暂试行逐步松动信条，终局用高代价选择活出新立场。 |
| 序列推进无力、观众中途走神 | **Paul Gulino 序列与四种等待引擎** | 从主角当下最顺手可行的办法起手碰壁再升压；按段选配四种观众注意抓手——**Telegraphing（预告将至之事）**、**Dangling Cause（悬置警告/企图延迟兑现）**、**Dramatic Irony（观众先知危险形成焦虑）**、**Dramatic Tension（欲求受阻等待成败）**。 |
| 中段第二幕散架、主角与对手缺深层咬合 | **John Truby 7 步因果与 22 步中段诊断** | 先锁七项因果弧（弱点/需求 → 外在欲望 → 对手与计划 → 主角计划 → 决战 → 自我揭露 → 新平衡；多主线则每条线各自完整）。若第二幕发散，定点查其关键中段零件：**幽灵旧伤放大弱点**、**假盟友背刺**、**三次改变欲望与策略的揭露抉择**、**对手独立计划与主动反击**、**盟友攻击主角越界手段**、**看似落败**、**通向决战的窄门/象征性死亡**。 |
| 单个反派压不出主角的多面性格 | **Truby 四角对立** | 设主角 + 主对手 + 两名次要对手：四方从不同侧面猛攻主角同一核心弱点；给每角定一组价值观的正向形态与压力下滑向的负向形态（如坚决/专断、诚实/冷酷），且四角两两之间各有具体利益冲突，绝不把同一阻碍换三张脸。 |
| 作品追问为达目的可以怎样待人 | **Truby 道德行动链** | 把伦理拷问全写成行为阶梯：起始价值与伤人弱点 → 为追目标首次越界 → 盟友/受害者点破伤害 → 主角自我合理化并扩大伤害 → 盟友再攻击 → 决战中价值定胜负 → 严酷考验催生道德自我揭露 → 用可见行动证明选择，把主题留给观众自行领悟。确保对手强度与主角势均力敌，伦理选择才成立。 |
| 场次排好却觉得节奏别扭、冗余缠绕 | **Truby Scene Weave 编织重排** | 把每场压成一句话（一个核心行动及其结果），标所属故事线与结构职责；检查跨线交叉是否形成信息差或情绪对照，果断合并重复功能的两场、删掉无后效赘场、只在主线断裂处补场。 |

## 结构形态如何适配故事

| 结构形态 | 适配的叙事任务 | 大纲必须钉死的关系 |
|---|---|---|
| 经典因果/目标推进 | 主体追目标受阻，选择改写计划 | 处境 → 尝试与落差 → 危机决断 → 高潮结果与余波 |
| 序列/单元式 | 任务、案件或阶段片段持续累积 | 各单元局部结算 + 对主线的持续改变 |
| 群像/交织线 | 多人同处一局势，彼此碰撞改道 | 各线独立目标 + 交会如何改写彼此状态 |
| 连续剧/分集式 | 单集满足与长线累积并行 | 单集闭合结果 + 跨集不可逆变化 + 下集真实理由 |
| 非线性/回环 | 记忆重释、延迟揭示或对照结构 | 呈现次序如何改写前段理解 |
| 观察/状态/开放式 | 日常微差、离场余波、空间时间体验 | 观察轴、重复偏离、空间距离与情绪余味落点 |

## 叙述视角、知识与信息路径

严格分开三层信息：**创作者掌握的全貌**、**人物当下能接触到的证据与判断**、**观众在正式成片中实际看见听见的顺序**。关键信息可拆成事件、原因、来源、机制、限制、代价与结果分次揭示，不压缩成全知或全盲两极。

| 人物知情 | 观众知情 | 产生的观看体验 | 写作铁律 |
|---|---|---|---|
| 不知 | 已知 | **焦虑与戏剧反讽**（炸弹就在桌下） | 人物严格按自己有限所知行动；观众先知的证据来源必须清清楚楚。 |
| 已知 | 不知 | **好奇与谜面**（人物藏着底牌或隐情） | 人物隐瞒须有现实代价与动机；先给可观察的行为反常，避免全黑箱。 |
| 不知 | 不知 | **共同探索与发现** | 共享观察位置与线索来源，让每次误读与修正真实改写下一步。 |
| 已知 | 已知 | **煎熬与等待表态** | 写出人物拖延、沉默或装傻的切身利害与关系压力。 |

- **钩子与兑现**：钩子必须连着人物会得到或失去什么，单扔一个谜面不算钩子。选定**层层钩子 / 惊奇递进**路线时，每次关键兑现须实质改写观众此前的主要预期，同时经得起前文线索回看，并由新局势自然长出下一期待。
- **后台规则、权限与调查证据校准（四条简则，严禁把审核术语带进正文台词）**：
  1. **动机与权限闭环**：对手行动须合自身利益；职位或技术名词不自动等于权限，谁能批准、查阅、读取须由既有设定或当场操作反馈支撑。
  2. **区分能力边界与单次状态**：摄像头被遮挡、系统未同步或这次没查到，只说明本次未取得，不等于通道永久不可用；未核查过的日志与画面一律留在未知，角色只能凭自己真拿到手的证据推理。
  3. **有限问答与有界请求统一口径**：若剧情涉及限次问答、配额请求或状态转换，在后台锁死计数与受理边界（一个独立求知目标算一问，明确成组受理按组计；请求前后状态须真实改变）；倒计时区分故事经过时间与银幕播放时长。
  4. **行动前先让观众看清真实选择**：高代价决断前，先露出可行方案、执行条件、风险期限与不可逆代价，再走决定 → 执行 → 后果，绝不靠一句台词或弹窗宣布这是唯一选择。

## 3. 高潮、悲剧、死亡与结尾专项路径

### 主角奋斗型高潮：收紧资源、假败与经验兑现
适用于主角凭行动博胜负的终局序列：
1. **盘清筹码并逐步收紧**：用对手反制、环境限制或主角先前选择逐一封死外援、工具与退路，每次损失逼出新策略。
2. **高潮约三分之二处落入假败**：让主角此前押注的方案在有铺垫的前提下真实失效，局面肉眼可见跌到谷底（若前段缺铺垫则先补铺垫；不需要假败的作品退出此路）。
3. **真实取舍**：亮出残存的艰难选择及必付代价，让行动直接显出人物把什么放在第一位。
4. **前文经验破局**：调用此前已铺出的观察、技能、关系或旧物新用翻盘，承担真实后果，绝不临时空降外挂。

### 悲剧压力累积与死亡四情绪路径
- **悲剧跨场累积**：跨场叠加不同性质的冒犯、损失或背叛，每次真实削弱人物维护尊严与关系的能力，最终击穿一项不可撤回的行动、关系破裂或自我判断崩塌，不靠原地加音量重复羞辱。
- **死亡的四条情绪兑现路**（按需单选或组合，死亡本身不自动催泪）：① **愿望将成未成时骤断**（先让具体可信的未来愿望触手可及，再骤然截断）；② **延迟真相改写名声**（死后由前文埋下的可靠线索翻案，保留人物复杂性不强洗白）；③ **日常痕迹显出空缺**（生前建立重复生活动作与照料习惯，死后让生者撞上空位与无回应）；④ **后继者带代价接续信念**（先由死者行动践行，再由后继者在新险境中用行动接棒）。
- **结尾目标校准**：回核开场承诺与最初欲望——达成、失去、有前因支撑的目标转化、坚守失败或有意开放均可成立，须让观众看清核心问题的回应与人物代价。

## 可选：工业长片开发口径

> 仅在用户明确要求工业长片开发流程、固定字数档、只扩第二幕、按第二幕比例配场或四批连续写作时启用；短片、动画、单场与常规创作**完全跳过本节**。

1. **开发材料字数档**（只计汉字、字母与数字，不含标点、空白、标题编号与附件；概念 500 字档允许 ±50 字，其余允许 ±10%，用户指定优先）：
   - 至少 60 分钟（或未定片长早期概念/三幕纲默认）：概念 500 / 三幕纲 1000 / 结构纲 1500 / 扩纲 2500；
   - 20 至不足 60 分钟或对应单集：概念 350 / 三幕纲 700 / 结构纲 1000 / 扩纲 1700；
   - 超过 5 且不足 20 分钟：概念 250 / 三幕纲 400 / 结构纲 600 / 扩纲 1000；
   - 5 分钟及以下：概念 150 / 三幕纲 200 / 结构纲 300 / 扩纲 500。
   - 起稿转折/序列参考数：≤5 分钟 3 转折 3 序列；5–20 分钟 3 转折 4 序列；20–60 分钟 4 转折 6 序列；≥60 分钟 6 转折（激励事件、进主对抗、中点改向、重大受挫、终局选择、高潮结果）8 序列（第一幕 2 / 第二幕 4 / 第三幕 2）。因果优先，不为凑数加水。
2. **只扩第二幕的三幕字数预算**：工业结构纲阶段即按扩纲总目标 $E$ 倒算第一、三幕合计占 $30\%\text{–}40\%$（默认 $35\%$），实计结构纲一二三幕字数 $a, b, c$；扩纲锁定一、三幕不变，只将第二幕按前段、中点改向、后段扩至 $E - a - c$（占总纲 $60\%\text{–}70\%$），并核算汇报各幕字数与占比；若已锁定的一、三幕超区间则实报差额并询问取舍，不偷扩凑数。
3. **第二幕配场比例与不可行处理**：按确认总时长与各场播放预算定总场数 $N$；在 $N_1 + N_2 + N_3 = N$、各幕至少一场且 $N_1 > N_3$ 的硬约束下枚举可行解（中点场计入 $N_{2a}$ 一次），核对 $N_2 / N$ 与 $N_{2a} / N_2$ 是否同落 $60\%\text{–}70\%$。有达标解取距双 $65\%$ 总距离最小者；无整数达标解则报告可行范围、实报超出区间的百分点偏差之和，推荐最小偏差方案（并列同列），绝不拆碎真实连续时空凑比例。
