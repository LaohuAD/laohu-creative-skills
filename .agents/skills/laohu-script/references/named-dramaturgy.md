# 具名剧作方法：契诃夫、小津/野田与权力群像

用户只比较几种方法时，先用这一页回答。说明各方法观察什么、怎样组织事件及其后果、从哪处真实文本看出差异，再落到待比较的场面。只有用户明确选择作者、作品办法或具名机制并要求应用时，父级才启动相应专项。普通家庭、慢节奏、多人日常或商战按其实际创作任务处理。

| 方法 | 比较材料时看什么 | 可以援引的文本位置 |
|---|---|---|
| 契诃夫 | 共同生活怎样让各有理由的人妨碍彼此，谁错过什么机会，环境如何留下后果。中心事件可画内或画外，关键是消息、反应及后续行动。 | 《樱桃园》中分租机会逐次关闭，拍卖结果进入仍在进行的舞会。《海鸥》第四幕以声响、遮挡和定向告知改变知情关系。 |
| 小津/野田 | 家庭位置改变前后的日常行为怎样变义。完整创作方法把承重事件放画外，让前因、反应和余波留在场内。 | 《东京物语》143–145 场以守夜、空站台与遗体覆盖呈现丧失。《晚春》的婚礼画外，以家中物件和独处收束。研究语料也包括《浮草》的画内事件，具体归属看相应文本。 |
| 权力群像 | 谁能定或解释规则，谁握有信息、资源和最后决定，哪一次交换产生公开／私人后果。 | 《继承之战》S2E5 的祖宅礼仪反复被越过，私下交谈再各自结账。S3E9 的婚礼空主位将礼仪改成搜寻和结盟。 |

比较同一家庭场时，分别问房间和生活物件怎样改变人物的选择、关系转折前后哪一项日常变了、以及议程与发言权由谁控制。契诃夫与小津/野田都可借用画外信息；前者可选择场内事件，后者的完整方法以画外事件连起家庭基线与余波。权力群像也使用声音和日常动作，但要求它们进入能被后场消费的控制权或关系结果。如果用户后来要组合，先确定各方法负责的不同决定。同一事件的画内外位置须统一，按既定事实和用户选择处理，记录最终采用的分支。

说明作品来源时，区分作者自述、正式文本或开拍稿能直接观察到的事实、评论者解释，以及本地写作对它的适配。比较结论成立后即可交付，实际写作的次数、条件和操作进入下列专项。
