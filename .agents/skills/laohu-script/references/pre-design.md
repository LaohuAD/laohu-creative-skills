# 剧本前置设计：先拆透时间线与人设，再进场拍戏

本文件承接完整新作、复杂口述成稿、整体重写，或重定故事内核与承重人物的前置设计。局部台词润色、单场微调、纯格式整理或按已批完整设计包/分场纲成稿跳过本文件；承接已确认的 Story 构想时，只补缺失的时间线、人物选择或声口依据。

## 1. 协同 `laohu-analysis` 做前置深挖

面对长段压缩口述、多线因果断点、重大方案取舍或整体重写，且用户未禁止调用其他入口时，先读取 [laohu-analysis 主入口](../../laohu-analysis/SKILL.md)，借其根因调查、竞争方案权衡与承重事实核查能力，配合本文件四道工序共同产出《剧本前置设计包》交回 Script 分场成稿。

- **用户明禁跨入口**：严格留在 Script 内部按本文件独立完成。
- **用户保留的立场与结局**：绝不代用户拍板；仅说明各分支改变的因果、代价与观众体验，问最小必要取舍，其余无依赖设计照常推进。
- **分析与写戏严格切脑**：设计包只留在制作内部或供审纲，一进入分场与正文立刻卸下分析词，全心切回摄影机与演员视角。

## 2. 四道前置核心工序

### 工序一：高阶定音、解构物理时间线与双向动机压测
动笔前先辨来稿所处状态：陌生类型、风格未定或日常素材容易写土写散时，先在后台默调 **1–2 部公认同类顶级真品**做四维快校（立意与声口、切入切面、戏核载体、视听质地），吃透规律即刻合上，彻底换成本作血肉，零抄壳与原句。遇到字面夹带反视听或狗血俗壳的口述，守住不变的核心情绪、真实事实与合法锁定项，果断剥掉烂壳再拆时间线。

口述灵感极易把数月铺垫、数日发酵与几分钟对峙压在同一场里。拆解分两步：
1. **剥离前置准备期与现场实时期**：把早已完成的手续、埋伏、查账、约人、知情积累，与本集/本场短短几分钟内实际能发生的动作彻底拆开。凡口述一句话跨过的路程、等待、审批或传递，按作品规则与真实耗时复核；超出现场时间窗的移回前置或留作后场结果。再分别标明**事件真实发生顺序**与**观众实际看见顺序**（区分作者全貌、人物当时所知与观众所见，结构与信息路径详见 [narrative-and-structure.md](narrative-and-structure.md#叙述视角知识与信息路径)）。
2. **双方反事实动机压测与配角承重核查**：分别站在主角与主要阻力方位置，核对各自手里当时掌握的信息、资源、权限、想守住的利益与可行退路，代入更省事的替代方案反问：
   - **久忍与现场闭合**：主角若已暗中隐忍或布局多年，凭他此前手头已有之物为什么一直动不了手？今夜这场到场交锋到底补上了哪块之前绝对缺位的现场铁证、对手自曝或行动契机？（绝不出现早有全套铁证却无故空忍多年、单靠发图就能赢的逻辑黑洞。）
   - **对手同等智商与警觉**：站在老辣对手的视线扫一遍全场——如果他多疑谨慎或要求清场，绝不会无视视野内明显的监控、异常摆设或主角自己先说漏的话柄；他面对不利局面会如何第一时间拆招、反咬或止损？
   - **配角承重位**：核对用户输入中给出的核心配角是否真正参与关键转折或信息推进，避免走个过场就被提前支开退场。
   > 示例：口述把清空老屋、找搬家车、布置新家全挤在交钥匙前五分钟。拆解后，把打包与搬运移回交房前几天，最后五分钟只留父女处置旧木柜与交钥匙——女儿早量过新家放不下，回来是接不肯起身的父亲；父亲放不下柜侧刻着孙女身高的三道痕，直到女儿递上一条空木尺请他亲手挪过去，才松手交钥匙。双方各有真理由，五分钟内改变的是共同离开的条件。

### 工序二：立住题材质地、戏核载体与观众情绪曲线
1. **题材质地分流与立意海拔轻自检**：先按流派定清骨相——商业短剧、动作喜剧、国漫或悬疑爽片痛快保留本流派的锋芒、情绪张力与通俗冲击力，绝不拿文艺片克制去磨平戏味；严肃写实或克制片型再收向凝练含蓄。同时自检一句：能否不止于流水账写事或靠宏大场面硬拔高，借眼前这桩具体冲突顺带照见真人心、真尊严或真处境。
2. **钉死 1–2 个经得住拍的戏核载体**：宁可砍掉五六个互不咬合的闲散道具，优先选出 **1 个（至多 2 个）** 满足以下条件的实体物件、生活习惯或共同动作——**① 单独抽出来干净耐看、经得住时间冲刷；② 本身就绑定着人物命运与共通情感，无需旁白解说象征；③ 能在镜头里发出声响、被拿放抢夺或随局势变形**——贯穿出场、承压变形与场尾收口，果断淘汰用完即弃的干瘪杂物。
3. **全片/本集情绪走势**：标清观众入场的直觉期待、关系或处境的温差撕裂点、改写前事理解的揭示点、人物付出代价的情绪峰值，以及结尾兑现或自然生出的新问题。给对手之间的试探、停顿、接招与反击留出饱满来回空间。

### 工序三：定死人物底色、价值张力与基准声口
与 [character-and-relationships.md](character-and-relationships.md) 协同，只为影响行动、阻力、知情、关系或结局的承重角色建底盘：
1. **Egri 三维底色**：挑出真正会改戏的生理条件、社会处境与内在信念，追看哪段过往烙印决定了他常态与受压后的同一底色反应。
2. **核心价值张力（可选五常棱镜）**：写清两件大事相撞时角色先保哪一样、哪股执念或面具会在受压时反噬自己，并落到某一场宁肯付代价也要守住的取舍。遇到伦理纠葛深、家族权谋、传统关系或强反差复杂主角时，可选用**仁、义、礼、智、信**追查哪一维过载伤人、哪一维枯竭或异化成防御面具；轻喜剧、纯科幻或萌系卡通按题材自身规则立人物反差，不生硬硬套五常。
3. **用词双禁红线 + 跨情境切频 + 3–5 句基准声口**：
   - 划清两条用词边界：既禁作者公文、论文与规则术语替角色开口，也禁违背角色身份、教养与关系的油腻市井吐槽；行话、方言与礼数只在人物真会说且当下有用时保留。
   - 写清角色在日常、办正事/危机、独处思考与情绪破防处的切频方式（拟人 AI 等非人角色须明确日常紧扣对方处境的情感梳理、正事高信息量直报与绝境触及底线时的断裂，严守其真实能力与知情边界）。
   - 从零建立或重塑主角时，先写 **3–5 句带具体听者、情境与目的的基准声口**，放回关系中试读——换人说会失真、同人跨情境仍听得出是同一副骨头，即为过关。

### 工序四：核查承重现实事实与视觉画风基线
- **承重事实核查**：只查会改变行动能否成立、耗时多久或观众能否看懂的制度、职业、年代、技术与地点条件；依可靠依据标清适用边界与仍未知部分，虚构世界核对规则自洽。
- **视觉媒介与画风基线**：用一句定清本作媒介与画风基调（如克制写实真人电影、强冲突商业短剧、夸张弹性国漫喜剧、奇幻特效动作等），对接 [script-format-and-delivery.md](script-format-and-delivery.md#按风格写可见过程)，供正文随场调节表现力度。

## 3. 极薄白描交回与局部断点回修

默认在当前对话上下文轻量交回 Script，含六项能直接落戏的硬决定：**作品承诺与保护项**、**因果时间线与三方知情**、**情感支点与戏核载体**、**核心角色底色与基准声口**、**视觉画风基线**、**现实依据与待决取舍**。

- **极薄白描交接防污染**：设计包写给后续写戏用，只用大白话情感核 ＋ 纯具体人、物、地点、动作与知情事实，**物理剥光文艺气氛形容词与分析黑话**，避免前置简报把散文腔或报告腔带进正文；进入写戏时只需择最咬合的支点吃透，绝不把设计包当清单逐条硬塞满。

写作或审稿中若暴露必需证据到得太晚、行动时长冲突、核心动机断开或选择违背锁定底色，带具体场次与冲突证据回到本文件（必要时请 `laohu-analysis` 协同定位最早失效前提），只修正受影响的设计及直接依赖场次；台词气口、潜台词、调度、节奏与 `△` 画面描述留在 Script 正文路径就地修，不回退前置。
