# 场面开发：把段落任务拍成可演的现场博弈

扩写场次链、规划分场或把大纲落成鲜活场面时读取本文件。每场戏的根本判断遵循 McKee 场景设计原理：**比较进场与离场时人物的关系、知情、筹码、期待或处境是否真正发生价值转向**（静观、等待、日常仪式与余波场则按观众持续观察到的微差与情绪沉淀验收，不强造冲突）。

<a id="用场面卡写清过程"></a>
## 1. 用极薄白描场面卡立盘

对承重场次用精炼九字段立盘（**一律用极薄白描短语**写人、物、动作与知情，剥离文艺气氛形容词和分析长句，避免反噬正文；过场通行场一句交代起止即过，简纲可并作内容、作用、承接三栏）：

| 字段 | 写清这一场的核心决定 |
|---|---|
| **入场状态** | 固定地点、时段、前场遗留条件；观众此刻已知什么、直觉以为什么、心情停在哪？ |
| **目标 / 观察重心** | 谁要做成什么；观察场则定观众要持续留意哪项动作、关系或微差。 |
| **阻力与条件** | 人、利益、空间、规则、时间或内心矛盾怎样卡住去路。 |
| **触发与声画分工** | 哪个可见刺激引出变化；哪块证据交画面 `△`，哪块交对白、现场声或 `VO`。 |
| **人物策略** | 角色凭当前所知如何试探、隐瞒、施压、求援或退让。 |
| **对方回应与预算** | 对手按自身逻辑接招、误读、反制或沉默；给足改变局面的来回、停顿与反应时间。 |
| **关键转向拍** | 观众在哪一可见动作或反馈处改写理解、感受情绪起落（承重策略转向走 [预期落差 Gap](narrative-and-structure.md#构造有效落差人物预期世界回应下一策略)）。 |
| **场末新状态** | 人物留下的决定、新知、失势或关系位置；观众相对入场直觉多懂或改看了什么？ |
| **离场把手** | 哪个动作、声响、物件或新悬念把戏自然递进下一场。 |

- **日常播放预算估时（唯一口径）**：常规分场按片种节奏选对白语速档（慢文戏约 3 字/秒、常规影视约 4 字/秒、动画喜剧/短视频约 4.5–5.5 字/秒），再叠加“动作→反应”视觉节拍与停顿估算自然播放区间；仅在需精确压秒或多轨并行核算时，才读取 [Video 共享估时](../../laohu-video/references/segmentation-and-handoff.md#逐字预算估时与并行事件核算)（不触发 P 分段）。

### 开场抓人、单场聚焦与放下提纲写全场（John August 场景写作法）
1. **开场第一场抓人法**：无论商业爽片、喜剧还是安静观察戏，第一场绝不从无事发生的起床、通勤、客套寒暄或大段旁白念设定起笔——直接落进**正在进行中的具体动作、一眼可辨的微小反常或关系温差**，十秒内立住观众的好奇钩子与全片真正基调。
2. **一场打透一件事，切忌信息塞爆**：先用白描场面卡钉死本场任务、必须在场的人物、地点为何改变行动与播放预算；尤其在 1–10 分钟短片或紧凑单场里，宁可围绕一轮核心博弈把试探、停顿和反应演透，也不硬塞三四个赶进度的情节转折把戏味挤干。
3. **晚进早出但护足余震**：挑观众最该入戏的一刻进场，砍掉无用垫话；但场尾必须给足观众看清结果、反应与下一步条件的时间，绝不为了硬追求早出而掐断余震。
4. **放下提纲从头写完整场面**：把人物调度、刺激、解释、策略与回应在脑子里顺一遍后直接活写，绝不把提纲逐行翻译成摘要句和每拍一句功能台词。
5. **先铸高潮落刀，再回写低水位铺垫（有核心高潮的作品适用）**：面对成败系于一场重头反转、情绪破防或绝境反杀的剧集/短片，后台先单独铸硬高潮落刀那一刻的行动、抉择与收口句——**高潮爆发处绝不竖防御盾牌、不停下来解释设定，也不切回理性结案口吻泼冷水**；再退回克制状态倒推前段的低水位蓄压与步步加压，拉出高对比释放张力。纯静观观察场或局部润色不强套。
6. **高潮服从真实求生与处境逻辑，不硬凑正面摊牌**：在悬疑、孤身险境或强弱悬殊的博弈里，身处劣势的角色察觉危险时，不会违背常理留在现场主动亮底牌或硬怼对手——**借故脱身、借物延时触发、借第三者或公共空间反制，或让核心物件独有的声光物理特性替人拆穿谎言**，往往比硬凑面对面质问更紧张、更可信，也更有视听余震。

## 2. 从人物经历次序写成鲜活场面

落笔把场面卡变正文时，按观众亲历的先后落子：**先给观众看见刺激与环境证据 → 再显人物怎样解读（含合理误判）与压住或亮出选择 → 落到具体动作、物件互动与有目的的台词 → 对方按自身处境接招 → 留下可见后果与新状态**。

- **物件改写权力与榨干感官物理特性（梅峰《双虎屠龙》机制）**：让人物动用场内已有物件直接改写现场权力与风险（例如拾起餐盘打断对峙、摔杯重启暴力威胁），物件成为行动杠杆而非摆设；同时充分调用核心物件本身独有的物理声光属性（如发声、计时、反光、渗色、卡顿或气味），让它的感官特质真正介入转折，而不只是个可随意替换的静态容器。
- **攻防动作链**：涉及冲突、躲避或撤退时，按位置、视线、掩护与防护条件写出出手 → 接触/被挡/避开 → 损伤或失势 → 对方回应 → 改策，伤损与权限丧失直接延续到后拍。重头追逐、闯关或大段喜剧动作调用 [喜剧与重头动作模块](../skills/laohu-script-setpiece/SKILL.md)。
- **能力、身份或特殊联系的首次实质变化**：分清观众当下必须看懂的可见触发与可留后揭示的完整机制；按前置线索 → 触发行动 → 即时可见反馈与当事人反应 → 持续后果与下一选择写实过程，用实效而非术语或光效说明书让人物和观众认清变化。跨场能力规则对接 [世界规则模块](../skills/laohu-script-world/SKILL.md)。
- **展现真聪明**：先让难题、规则、时限与常见办法的死角对观众透明，再让主角凭可获线索采取别人未用的有据办法并承受结果，对手按各自合理逻辑应对。

## 3. 六组高杠杆场面专项武器（按场景任务择用）

### 显能场的四步：对比、行为结果、见证者变化、败者回应
要让观众亲眼信服角色在技艺、智谋或地位上压过对手时，按四步落戏：
1. **可比对照**：先亮出对手占上风的姿态、工具或权限，以及主角表面的劣势与手头真实筹码；
2. **可见行为结果**：写出出手动作与对手应对的直接碰撞，用攻势落空、空间物件受创或位置翻转直接证明差距，绝不靠旁白宣布；
3. **见证者反应强化**：只选真看见结果的在场者，用停顿、收回动作、让路或改换称呼显示原判断崩塌，不搞全员轮流鼓掌惊叹；
4. **败者刺激与新局**：让受挫方立刻以反击、改口、求饶、撤退或隐瞒回应，迅速落到关系、筹码或下一步行动变化。

### 大刺激后的迟发反应：让日常动作承受余震
人物遭逢噩耗、羞辱或关系断裂却仍须把眼前小事做完时，先不命名悲痛，直接写他接着做那件与损失或日常相连的手头事——让震动打断、放慢、弄错或机械重复这个动作，再写旁人察觉的细节及这股余震如何改写下一步决定。

### 情绪场景的八种可选建法
要写出真正击中人心的失去、尊严、和解、催泪或时代共鸣时，按关系前提单选对口一法（不堆叠）：
1. **反差式牺牲**：先用一两拍让观众看清人物触手可及的具体愿望，再让它与更重责任相撞；人物默默放弃、台词不抱怨，末尾留一个细节泄出对原愿望的留恋。
2. **迟来的和解**：先把积年尖锐矛盾铺足，再由信物或变故撬开缺口；当下让人物按自己声口笨拙靠近或承接，停在动作余波或空镜，不用模板道歉敷衍。
3. **小人物的尊严**：绝境与以底线换生机的交易同时摆上台面，写人物凭前文已立底线拒绝并另谋出路，再给旁观者看见后的微动作与拒绝的真实代价。
4. **信物承载记忆**：实物首次出场立来历，中段再现改写注意或选择，高潮特写承接情绪落点——每次回返必须因处境变化产生新含义。
5. **动作代替重复的情绪说明**：当“我很难过”只复述画面时删去水句，改用一个由当下刺激引发、演员可做且能读出关系的克制动作（需看清细节时留足停顿与音乐气口）。
6. **集体记忆个人化（年代戏）**：挑一件经核实的时代节点，落到普通人一件日常小事或抉择的改道上，带一两笔不抢戏的年代质感，让个体命运承载时代。
7. **情绪留白**：主行动与承诺已经结清后，在情绪峰值处干脆止笔，不再替观众解释人生后续，以远景、空镜与渐淡环境声留住余韵。
8. **欢乐中显出离别**：先铺满聚会、节庆的真实热乎劲，暗埋离别前因；在最欢快的一刻露出离别实情，让人物在保持原有笑意或动作的瞬间完成喜悲对撞。

### 地点替换练习（Richard Walter 替代地点法）
当一场戏顺手落在办公室、餐桌、车内或电话里显得扁平时，强迫自己跳出惯性，快速试想数个截然不同的真实空间（例如把警督向苛刻上司汇报从办公室搬到泳池边——上司按医嘱来回游，警督沿池边小跑汇报，水花溅湿皮鞋），比较**谁掌握进出权限、谁占物理优势、新增或拿走什么物件与视点**，只选真正改写权力关系与行动路径的地点。

### 贯穿物件变化链（孔尚任《桃花扇》机制）
选用一件实物贯穿全篇承载命运时，让物件的每一次身份蜕变都由**持有者之外的第二行动者**通过具体动作促成（如题诗、染血、转赠、夺走、当众撕裂），且每次变义都压在一次价值转折上；删掉某次露面若不断因果，就砍掉那次出场。

### 空间权限与环境情绪（景语即情语）
环境不是静止布景墙，而是可演的权力与情绪场：
1. **定观察重心与情绪基线**：观众跟谁看、期待压迫、亲昵、荒诞还是人物浑然不觉的反差；
2. **划空间权限**：谁能推门进入、占主位、越门槛、动桌上的物，把抽象压迫落成可见的通行与越界；
3. **挑承重感官细节并安排偏移**：选与当下关系相连的光源、声响、距离、材质或天气，让细节随行动发生偏移或在场末留出空位与余波。

## 4. 场间连接依据

决定下一场前，先看上一场留下的未竟任务、新筹码、知情变化或情绪余波，顺因果、物件、动作或声画自然切入（避免先硬定场头再凑过场桥段）。快切蒙太奇可直接跳进下一站，保住人物与物件状态不突兀跳变即可；需做时间压缩、双线交替汇合、视觉母题三态弧或 Match/J-L/Contrast/Smash Cut 剧作转场时，调用 [视听蒙太奇与转场模块](../skills/laohu-script-montage/SKILL.md)。
