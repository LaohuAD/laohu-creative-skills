# 场面开发：从段落功能到场内行动

用户已有整体故事，正在扩写某段、某场、场次链或转场时读取。返回可接续的场次安排，或按用户要求写出剧本正文。

## 先识别本场要给观众什么

场面可推进外部目标、暴露性格、改变关系、更新观众认识、兑现信息、建立声音或节奏，也可提供观察与停留。先标本场的主要作用及必要的次要作用，再检查它怎样服务整体故事。一个场景不必负担所有功能。

Robert McKee 在《Story》“Scene Design”将场景理解为改变人物生活中的价值状态。他写道：“turns the value-charged condition of a character’s life”（自译：改变人物生活中带有价值判断的处境）。具体操作是比较场景开头与结尾的关系、知情、期待、情绪或现实处境。若这些都没改变，再判断本场是否有意承担关系僵持、观看时间、信息等待、情绪余波或节奏功能；安静场面按其实际作用评价，不套正负翻转。

## 用场面卡写清过程

剧情承重场景按需记录这些字段：

| 字段 | 场面问题 |
|---|---|
| 进入状态 | 地点/时间、人物在做什么、前场留了什么 |
| 当前目标或观看重心 | 谁试图完成什么；观察场希望观众持续看什么 |
| 阻力与条件 | 人、关系、时间、空间、规则、资源或内部矛盾如何限制行动 |
| 触发证据 | 哪个动作、信息或感受使行为开始或改变 |
| 人物策略 | 角色如何试探、推进、隐瞒、拒绝、等待或退出；为何选此方法 |
| 对方回应 | 接受、误读、反击、拖延、沉默或转换策略 |
| 场内节拍 | 哪项回应改变了策略、局势或观众判断 |
| 场末状态 | 新决定、关系位置、情绪/信息变化或刻意保持的状态 |
| 离场把手 | 何种动作、声响、空间、时间或期待引出下一场 |

简纲可压缩为“内容—作用—承接”；详细场面再写人物行动和反应。Stanislavski 的目标/行动/回应分析帮助把心理说明转为演员可执行的意图；John Truby 的计划与对手关系帮助检查行动如何受阻。选择这些工具是为了让当前场景的行为和后果具体，不为完成字段而添加戏。

### 场面卡是简记，不是待扩写的对白骨架

John August 在〈How to write a scene〉（2007）展示了一条场景写作路径：先判断这场是否承担当前叙事任务，确定谁在何处、从哪个时刻进入，再用简短 brief 记下必要事实；随后把 brief 放下，重新完整写出场景。应用时，先用一两句说明本场要让观众经历什么以及关键条件；写正文时从场景真正开始的动作、观察或对话进入，把人物的回应、停顿、空间和可感知事实写成完整的剧本场面。不要给简记逐条补台词，把它扩成“动作摘要＋每一拍一句台词”。

这是一种把计划与成稿分开的工作法，不是删场或制造转折的通用定律。场面若承担观察、等待、日常节律或有意维持关系的作用，仍可保留它；只需能指出这种停留给观众什么，正文就按实际观看过程写完整。场景必要性按本作目标判断，不把 John August 的叙事条件推广成要求每场改变人物价值。

### 把人物卡落到场内动作

写新场或展开场次前，先调用第一步已建、或从现稿提取的人物卡。选取会影响本场的一两项稳定倾向与关系权力，再从场内实际发生的刺激出发：人物先注意到什么，把它解释成什么，想对谁造成什么改变，因而采用什么动作或说法；对方如何接住，谁因此控制了话题、时间、空间、信息或物件。用动作、停顿、称呼、语速/句长或对物件的处理让这种倾向可见，随后写出选择的即时后果。只细化承重因素，不必把人物卡逐项抄成每场的说明。

同一人物面对亲人、同事和权威时可以采取不同办法；先回到各关系中的欲望、限度与风险，判断是稳定底色的不同表现，还是本故事有因果的改变。观察、等待或共同劳动的场面，也可让人物的注意方式、回避或动作差异成为观看重心；不为了证明人物独特或有冲突而制造争吵。动作必须由人物当时可感知的事触发，不能靠作者掌握的秘密直接驱使人物反应。

场末写清本场哪项状态会留到下一场：新知道的事实、关系中的控制权、未完成的行动、物件位置、仍在持续的情绪，或刚出现的行为偏移。只把持续影响人物选择的变化写回人物卡，并标为暂时状态还是新基线；下一场沿用这一条实际变化，不把人物卡从头重编。没有持久变化时，也不必为了卡片更新而虚构弧光。

### 从人物经验编写场面正文

场景卡只准备写作，不是成品。落笔时先锁住本场要完成的事情和不能改掉的故事事实；再对每个关键节拍逐一确定：人物当下知道/不知道什么、正在做什么、最在意或不愿失去什么；眼前哪项可感知的动作、说法、空间变化、物件或声音触发了他；他怎样解释它（包括有证据的误读）；他现在想让谁/什么发生什么变化；在可选办法里为什么采用这一种，而不是另一种。

把选定的解释和目的变成具体表现：安排人物注意的先后、动作从哪里起、是否继续/中断/改向、对方何时看见或听见、如何回应，关系、信息或行动权因此有什么变化。需要物件、环境或礼仪时，让人物实际使用、忽略、等待、交接或受它限制；它可以是触发点，但不能只承担“回扣、象征或流程”功能，再由作者补贴人物感情。观察、共同劳动、闲谈和刻意静止也可成立；按已选观看目的写出时间、微差和各自的注意，不为制造冲突强添动作。

随后按人物实际经历的次序写成剧本正文：观众先得到什么事实，人物看见/误解什么，身体或空间如何显出选择，台词怎样回应刚才的刺激，对方如何接住并改变下一步。重要对白再依[对白与视听](dialogue-and-audiovisual.md#从目的写出说法)写成完整回合：先有说话人的当场目标和策略，再有属于这个人的词句、句法、称呼、停顿或沉默；不要先写好一句金句/回扣，再让角色去解释它为什么会说。若本场确实从一个预设笑点、物件或结尾开始，也可保留为写作起点，但必须把它还原成某个角色会看到/听到的刺激，追出人物自己的解释、选择、风险、回应和后果，不能用预设效果替代这些中间经验。

写完正文后暂时离开场景卡和作者说明，按成品顺序读/演一遍：前一动作或台词是否给下一反应真实依据；每个人是在回应自己可感知的事实还是在配合大纲；动作与词句能否从当前人物的习惯、关系和情境中发生；观众无需事后解释能否感到该场的变化/停留。若不成立，回到最早断开的“刺激—解释—目的—选择—回应”位置，改写实际动作或句子，再读完整回合和相邻场；不要用再加一个道具、表情、括注或检查问句遮住断点。此顺序只在承重选择处展开，不要求每个普通动作都写成完整分析表。

梅峰对《双虎屠龙》餐馆一场的分析显示，价值立场会经由具体行动反复改写：兰塞姆拾起牛排放到桌上打断对峙，利伯蒂之后扔出酒瓶、重新以暴力威胁现场。物件与动作不是装饰，而是改变行动权、风险和观众对“文明/暴力”关系的判断。迁移此机制时，选本故事里已有、可被人物控制的物件和动作；不要照搬牛排、酒瓶或把每个场面都做成价值翻转。

## 节拍之间要有可追踪的连接

剧情型场面可按以下动作链写：进入处境 → 提出/执行策略 → 对方或环境回应 → 新证据/新阻力 → 人物改变办法 → 决定/失败/发现/退出 → 形成新状态。后一个节拍承接前一个节拍，避免场内只罗列彼此无因果的事情。

偶然可以让人物相遇、打开困局或暴露证据；人物接下来怎样解释、是否利用、承担何种风险，仍由人物选择完成。写角色行动时核对其当场能感知的事实和可选办法。角色可误判，误判要有证据来源并影响行动。

观察型场景按其观看机制组织：重复动作出现微差；有人离开后空间和其他人的做法改变；生活节律暴露关系位置；熟悉声音换了意义；等待改变期待；观众看见人物没有承认的举止。场末可停在发现、持续、消耗、回避或未解决处境，不以人为冲突作为唯一出口。

## 场与场之间说明连接依据

相邻场次可通过因果行动、共同目标、关系变化、信息揭示、时空移动、道具状态、声画联系或重复差异衔接。选出实际承载此处连接的那个依据，核对前场结束与后场开始的人物位置、时间、物件、目标、知识和关系。

跳切可省略行程与闲置过程；只要后场事件仍可理解，跳过的时间与位置不制造矛盾。突然断裂若是作者所选形式，给观众可辨的段落/意象关系，使形式本身成为连接。

## 空间行动与物件状态

按观众能跟上的观察位置画清人物入口、站位、视线、距离、障碍、出口和路径；主要动作的触发、执行者、对象、方向、结果及对方反应应可辨。抽象的空间或情绪判断先作为构思线索，正文给出会影响人物行动的可见、可听关系证据，不用背景百科解释替代当前场面。保留文学性的感知细节时，也让读者知道它落在什么对象、声音或动作上。需连续追踪的道具写清持有者、数量、使用状态、位置与下一步去向；只有会影响后续选择的物件需要详记。

## 环境、观察与情绪轨迹：从感受方向到可执行声画

王国维《人间词话·删稿》写道：“不知一切景语，皆情语也。”场面环境不是待填满的背景格。展开普通场次时先确定观众观察谁、注意什么，并定下场面情绪/感官基线；再按场面功能决定环境要承担多少。若环境承担关系、情绪、生活秩序或观看节奏，按以下步骤把选择落到声画中。光、声、色、材质和气味都是可选工具，不设每场配额，也不要求每个 `△` 各自复述全场情绪。

1. **确定观察重心与情绪方向。** 观众此刻跟着谁看什么？场面希望留下的是压迫、亲昵、羞耻、倦怠、荒诞，还是人物自己感受不到而观众看见的反差？从人物关系、当场行为和作者已选的观察方向确定基线；允许保留暧昧，不用形容词代替可感方向。
2. **检查空间权限。** 若场景的行动或关系涉及空间权力，画清谁能进入、停留、穿过门槛、移动物件或使用资源，谁握有许可；空间如何使一方便利、暴露、受阻或被排除。把权限落实为人物实际能做或做不到的事，不只写“压迫感”标签。
3. **挑选承重的感官细节。** 从光线的来源与落点、颜色、可辨声源与远近、空间距离、表面材质、冷热、气味和人物使用的物件中，选与本场关系、生活条件或观众观察方向相连的细节。环境可映照人物，也可反衬人物、制造感受落差，或建立持续观看的生活秩序。给导演与演员看得见、听得见、可调度的条件；不为“丰富”而罗列感官。
4. **安排场面中的基线、偏移与余波。** 决定细节何时出现，人物行动、关系或知情变化怎样改变它的意义，场末是回到基线、留下差异还是停在未完成处。氛围可由重复、细微偏差与持续时间形成；需要行动因果时再让环境直接改变人物选择，不把所有环境都改造成情节机关。
5. **让环境、动作、对白与表演共同工作。** 角色的玩笑、回避、请求、命令或闲谈可以从侧面显出空间规则和关系；人物名后的表演提示与环境声也可以承接动作和感受。若台词只是编剧替观众复述已经呈现的景物，改成该人物有目的的表达或删掉复述。影响人物选择的社会规则、历史事实和理解，要在角色实际可做/可说的行动或作品适合的叙述通道中交代。
6. **核对类型承诺与作者方向。** 所选光影、声音、空间、语言和节奏是否把这部作品的观看方式带到观众面前？作者若要偏离已经建立的类型预期，明确偏离带来的新意义、关系效果或代价，让观众能在作品里感到这次偏离；不以“更顺”抹掉反衬、错位或不舒适。

**产物：**场面的观察重心与情绪/感官基线、需要时的空间权限图、所选环境细节及其出现位置与关系、偏移和余波，以及可供导演/演员实现的条件。普通场景保留本场真正起作用的选择；完整的环境方法只在场面需要时展开。

检查动作是否可发生：角色到不到得了、能不能看见/听见、需要多少时间、现场有何阻碍、对方会如何反应。人物行动的能力/资格、空间通路或物件持有若是剧情关键，就把前置证据写入场次链。

## 交付适合当前请求的细化层级

- **分段大纲**：每段内容、功能、推进和承接。
- **场次大纲**：地点/时间、人物、主要动作及场末状态。
- **场面细化**：节拍、目标、策略、行动/回应、声画证据。
- **剧本正文**：按选定格式写场景标头、可表演动作、必要对白和声音。
- **普通影视剧本**：新稿默认用 `△` 标出清楚的画面/分镜单位，以观察主体、空间关系或信息重心变化为边界；同一观察重心下连续发生的动作可留在一个 `△`，不逐动词拆分。只有用户明确要求逐镜编号，或已确认的工程格式要求时才加 `M`；沿用原稿时保留已有 `M`。
- **文学剧本、舞台剧或普通分场稿**：按用户指定体例或项目已确认格式处理，不把普通影视剧本的画面单位规则强加给它们。

完成后把场次链及尚未决定的关键条件交回整体编剧。常规分场剧本不自动添加摄影机路径；视频镜头、运动与提示词制作归 $laohu-video，镜头版需进一步生产时再按用户目标交接。
