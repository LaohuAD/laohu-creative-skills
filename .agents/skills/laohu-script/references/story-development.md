# 故事开发：把闪念打磨成经得起检验的戏核

当输入只有一句灵感、宽泛主题、零散人物画面，或写到一半发现故事只是流水账、戏核发虚时读取本文件；故事核心已经成立或已有批准 Story 构想时跳过，直接补缺项。

## 1. 先立故事发动机：凭什么让观众一直看下去？

- **行动推进型**：先找人物原本依赖的生活秩序或顺手办法，再给一个让旧办法失效或代价暴涨的变化，逼出人物非保不可之物、不得不采取的行动、真实阻力与可见代价。取舍看**本作独有的关系、处境或规则是否真正改写了这条行动与结果**；换层皮仍是一模一样的通用套路，就回材料深挖差异。
- **观察、关系与形式型**：不靠外部灾难硬撑，而是写清观众持续追踪的观察轴——重复动作在哪一次出现细微偏离、谁离开后空间和其余人的做法变了、何种等待或迟到消息改变了关系温度，让停留与微差本身成为观看回报。

## 2. 五把高杠杆戏核锻造刀

按眼前卡点选用对应武器，不把所有步骤机械跑成一张表单：

| 卡在什么地方 | 调用哪把武器 | 直接落地的造戏动作 |
|---|---|---|
| 只有抽象主题词（如背叛、成长、体面），立不起戏 | **Egri 戏剧命题（Premise）** | 把主题压成一条可被剧情检验的因果句：人物特质 → 由此引发的行动与对抗 → 不可逆结果。区分主题领域、戏剧命题、作者立场与观众结论，让人物用有代价的选择去验证或反驳命题，不把人削成传声筒。 |
| 主角行动缺内在拉扯，总像被情节推着走 | **Lisa Cron 欲望×错误信念轨道** | 写清主角具体想要什么（外在欲望）、它对他意味着什么，以及哪条因某次旧伤生根的错误信念正在暗中阻拦他；安排三个逐步升级的节点——每次向欲望前进一步，都被错误信念逼退或扭曲策略，使欲望与执念同时加压。 |
| 点子花哨，但说不清到底哪件才是真正的戏核 | **戏核移除测试** | 假想抽掉这个核心设定、物件、关系或奇观，看故事主问题与人物选择是否瞬间坍塌；抽完一切照旧，说明它只是表面装饰，立刻换更承重的戏核。 |
| 有了高潮画面，却不知前文该铺什么意味 | **McKee 主控思想** | 先钉死高潮中人物做了什么、付出什么代价、核心价值怎样翻转（或坚守/坠落），用价值变化加原因倒推全篇真正要让观众体会的脊柱；多义或开放结尾则保留真实张力，不硬下道德判决。 |
| 冲突软绵绵、假大空或中途泄气 | **陆军八种冲突病快诊** | 逐一扫除最伤戏的病根：**只争观点不压关系**（无戏剧特征）、**前提虚假硬造**、**违背现实制度与利益常识**、**毫无依据的听错猜错**（随意误会）、**中途退回廉价和解**（避重就轻）、**迈出大步又无代价撤回**（虚晃一枪）、**冲突方向中途换轨**（缺乏张力）。同时警惕硬拔高、标语说教与好坏人贴脸标签。 |

**补齐戏剧张力的两项快查**：
- **核心五问（Hicks）**：谁在行动？谁在阻拦？为何双方目标不能共存？成败会改变什么？为何必须此刻动手？
- **态度立场阵（Hoxter）**：围绕同一个核心议题，写出主角、对手与关键关系人物截然不同的态度与切身利害，防止配角全站同一边当复读机。

## 3. 快速故事大纲接口：帽子、衣服、鞋子

当核心材料已经具备、用户要快速排出主角带路的短剧或紧凑故事大纲时，可用这套直观接口（不替代明确要求的概念或工业三幕纲）：
1. **帽子（起点与目标）**：锁定主角、具体时空处境和可检验成败的外在目标，背景只留会改变行动的部分。
2. **衣服（困难 → 希望 → 新困难）**：每轮写清主角凭当前所知出手、对手/环境按自身逻辑反制、阶段结果打开了哪条有据的新希望或新策略，同时把风险、代价或关系推到新高度；绝不拿同一种压迫原地重复充数。
3. **鞋子（行动结果 × 内心结果双结算）**：分别交代外在目标最终达成、失去、变形还是开放，以及人物历经代价后的内在变化（坚守、倒退、妥协或拒变均可，须由行动挣得）。
4. **单线因果直写**：大纲阶段用主角视点与事件结果串起全链，不提前塞对白或逐场环境描写；完成快纲后回 [narrative-and-structure.md](narrative-and-structure.md) 核查因果与信息顺序。

- **短片与单集聚焦铁律（1–15 分钟高发痛点）**：短片绝不是 90 分钟长片的压缩版——切忌硬塞多条支线、三轮世界观说明和五六件闲散道具。短片赢在极简人物与空间（常由 2–3 人、1–2 处核心空间撑起），把一个高密度切面和 1–2 件贯穿戏核载体拍穿拍透，把宝贵篇幅留给有来有回的博弈、反应停顿与场尾余震。

## 4. 收束交付：可进入结构的雏形

形成可交阶段二或概念交付的清晰内核，包含：**故事核心与主要观看体验**（写清体验落在哪些具体行动与关系结果上）、**带具体姓名与自然说话质感的关键人物关系与各自欲望**、**核心因果链或观察轴**、**结局方向与开放度**、**必保风格与锁定项**，以及**真正会改方向的极少数待决项**。需做提案或一句话卖点时，压出反讽钩子、具体时空画面与核心赌注。

- **隐忍/误解类大纲双检**：凡涉及多年积怨、藏私苦衷或最终翻案的故事，动笔交纲前核对两点——① **护住双向共情底盘**：受委屈一方的怨气必须有站得住脚的人情依据，绝不为洗白隐忍方而把委屈方写成理亏活该的亏心人；② **核验核心物件与现实可行性**：大纲里推动反转的关键证物藏放位置、触发动作与现实法理/物理常识须严丝合缝，不留隔空瞬移或强行送人头硬伤。
