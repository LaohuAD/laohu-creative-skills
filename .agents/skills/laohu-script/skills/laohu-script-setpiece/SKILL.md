# 喜剧场面与重头动作

从宿主接收本场要兑现的体验、人物当前目的、已知关系、虚构空间或规则、前文铺垫及允许改变的范围。喜剧分支处理确需靠行动、反应和节奏兑现的场次。动作分支处理追逐、闯关、脱险、对峙等需要一连串处境变化的虚构重头场面。两者都影响场面时，先决定各拍的主任务及应保留的代价，然后由宿主组合。

明确按半小时情景喜剧开发整集时，整集引擎、困境和格式交由宿主选择的 sitcom 专项。只润色现实戏里已有的两句干幽默，按原人物声口处理。动作分支专门设计虚构场面的空间关系、观众所得、前置条件和戏剧后果。涉及现实可执行的攻防、伤害或侵入时，使用舞台动作、虚构障碍、保持距离的反应、画外结果或非写实规则承接剧情功能。

## 场面靠喜剧兑现时

1. **让人物认真解决自己的问题。**先写他在当场想赢得什么、为什么原办法在他看来可行。挑出与任务不相称的一项能力、看法或自保习惯。让他继续作出在自身处境下合理的努力，行动结果逐次显出这项错位。让他即使没得到原想要的结果，也真正在乎结果。
2. **确定观众的参照。**对于同一个发现，谁首先按寻常规则理解，谁把眼前情况推向荒诞？让参照者有自己的实际目标，有理由接话、插手或迟疑，避免只为吐槽而在场。同一个人随处境改变可换位。观众须先看得懂两人在哪条判断上分开。
3. **用重复建立可打破的期待。**同一模式确需三次时，第一拍立规则，第二拍加重或确认该期待，第三拍从同一条件生出有因的破格结果。三次改变的对象、压力或代价必须可辨。笑点已经成立时，保留实际需要的次数。
4. **让动作本身给答案。**先让观众认出物件、动作或成功条件，善用郑重起势或夸张摆 Pose 抬高期待，再精确写尝试后的空落、一秒破功或意外结果。必要时给一次短静场、迟来的二次反应或反向接话，长度按结果辨认与基调判断。在作品画风许可内用弹性、变形和倒霉结果兑现狼狈，后续行动承接真正持续的状态，把动作末端落在最能结算笑点的一拍。

Steve Kaplan 的 Winning、Non-Hero、Straight Line/Wavy Line 用于前两项的本地改编。第三、四项采用重复、破格和可见反应等通行的喜剧编排手法。必要的短静场可先按一至两秒试读，具体长度保留给表演和播放预算。

## 场面靠虚构追逐、脱险或对峙兑现时

1. **先让观众看明白空间与成败。**选择一两处可见行动或 `△`，给出角色相对位置、必须到达的地方、会改变路线的障碍和已知可用物件。写清这一轮真正要赢得什么，初始有多少可见余量，及怎样看出失败。超出角色所知的事实只有在所选观众视角需要时呈现。
2. **让一条具体计划推进并失效。**按角色与世界已知条件写有效尝试。对手或环境的可见回应使原办法失去关键前提，并真实改变局面，例如一条路断掉、一件物件换手、一种能力失去使用条件或合作关系改变。让角色先收到反馈再更换策略。每轮至少交代一个会被后续接住的状态变化。效果略过过程时，也要保留承重选择、触发与后果。
3. **用已立条件作出代价明确的应变。**让角色想起、重新看见或尝试前文已有的能力、地方、关系或物件，从不同用途取得机会。若委托已锁定某件道具用于应变，早段可铺设用法与限制，把兑现留给原计划失效后的改策，并检查两者之间的因果。写出为什么此刻能做到、还有什么会失败、完成了哪一项成败条件，以及人物失去或必须承担什么。由已选结局决定兑现为险胜、有代价地退出或失败。

若与自然转场、跨区交替或奇幻能力合用，把需要保持的场内地理、时序和规则结果交回宿主协调。已确定静默观察、出入场范围或明确声画格式时，按作品方向调整压力和反应长度。

**回接宿主。**喜剧分支交出认真目的、错位依据、动作与对象、有作用的重复或停顿、笑点及关系结果。动作分支交出空间初态、成败条件、三段行动、每轮有效变化及结局代价。阶段二据此安排重头序列、场界、离场状态与播放预算，阶段三落笔写实际画面、对白和可见后果。通读时确认读者可从画面辨认在哪里、为什么换办法、笑点或结果落在何处。
