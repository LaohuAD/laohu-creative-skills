# 日本编剧实践：选一条具名路径，按它写成稿

日本材料里有多种彼此不相同的创作实践：有人先定行动框架或结尾，有人从两种材料组合、人物、生活片段、声音、演员、委托 brief 或制作限制出发。它们不构成一个统一的“日式结构”。用户选定或本轮选出一条路径后，该路径必须决定创作从哪里开始、先后做什么、哪些结果优先，并能在大纲、场次或剧本里看见；不能把方法列成一组最后都不执行的选项。

## 触发与选路

用户说“按日本编剧的写法”“想试日本编剧那种创作路子”，或点名本配置中的作者、作品及其方法时启用；不要求知道作者姓名或剧作术语。仅有日本背景、日语对白、人物国籍、发生地点或题材不触发。只比较方法时说明差异，不替作品选风格。

- 用户点名作者或作品方法：直接按对应路径工作；其他方法不得覆盖它在同一变量上的优先级。
- 用户只说日本实践但不知道作者：先看其材料和当前创作瓶颈，按下表选一条具名主路，说明为什么贴合，继续写，不反复追问作者名。
- 两个材料信号都成立时，先判断它们是否作用于不同变量。能兼容就写清谁负责哪一轴；同一决定上相斥时，根据用户已确认的结尾、主题、类型和声音选主路。只有不同选择会实质改变作品方向且现有材料无法支持判断时才问。
- 选定路径后将其固定在本轮实际产物中。下文列出的顺序、创作起点、人物 / 主题 / 台词 / 结尾优先级不得被其他路径或父级通用方法暗中换掉。场景素材和具体措辞仍由作者决定。

## 快速选路表

| 当前材料或瓶颈 | 选择的具名路径 |
|---|---|
| 事件和人物已明确，缺全篇顺序、多线组织或有效跳跃 | 古泽良太：行动框架和观众信息顺序 |
| 结尾 / 目标决定已明确，或多人同日行动与时间因果不稳 | 内田贤治：目的地先行、人物日记与时间线 |
| 两个各自不足的念头需要合成一个可持续故事 | 筧昌也：“如果 + 而且”组合 premise |
| 有许多小观察 / 物件 / 怪念头，却没有故事轴或主题 | 三木聪：素材并置，关系与主题后生 |
| 强人物、亲历材料或有力首尾画面先于情节 | 园子温：人物和作者材料先熟成 |
| 两条经历或片段难以自然衔接 | 横浜聪子：保留不均衡，处理变形和搭桥 |
| 人物像身份标签，或结尾只有抽象漂亮话 | 高桥泉：从品性与动作写人，以指针聚焦 |
| 明确选择台词驱动喜剧、演员声口或观众捧哏 | 福田雄一：角色关系和台词发动喜剧情境 |
| 项目给了主题、调性或委托 brief | 大宫艾丽：brief / 主题先定，再配置人物 |
| 预算、空间、道具或制作合作是核心约束 | 行定勋：把限制变成关系，以剧本作为协作坐标 |
| 明确是改编，且要求日本实践 | 荒井晴彦：先找个人视点，再重组原作 |

## 具名路径：触发后按固定动作工作

### 古泽良太：先排观众必须经历的行动与信息

**何时选：** 已有题材和主要行动，但事件顺序、多线交错、伏笔或节奏跳跃还不成立。

**固定动作：**
1. 列出人物关系、主要矛盾，以及观众必须先知道 / 后知道的事件；按行动因果和观看顺序画框架，不先套分钟比例。
2. 让“承”段持续产生变化。每场至少推进目标、信息、关系或情绪中的一项；转与合由前面行动逼出。
3. 多线先各自列行动，再安排切换。反差、前后句相反、跳过两三级过程可以制造速度，但不能跳掉理解结果必需的证据。
4. 无新变化的场面删去或补入能改变意义的行动；不以更难懂或跳得更快冒充好结构。

**材料中的作品证据：**《怪胎刑警》第一集工作框架先列主人公梦境 / 心理状态、被迫回警署、新人女警登场、朋友丢失小提琴、嫌疑人改名等观众必需信息，再安排交错场面；它证明的是信息顺序和多线编排，不要求新作复制同一案件。《外事警察》用误入陌生组织的新人女警作观众入口，是另一项具体视点选择。

### 内田贤治：结尾或目标决定先行，日记和时间线反向验证

**何时选：** 用户已有结尾方向 / 主人公要追求的目标，或故事跨多人同日行动、时间错位与伏笔因果难以成立。

**固定动作：**
1. 先写终点状态，或主人公真正决定开始追求目标的瞬间；它构成情节点。若结局仍未知，且不同结局会改写作品承诺，不替用户伪造结尾，先说明需要决定的方向。
2. 从终点反推必要行动和前置证据。用一两句话概括主要事件，确认作品究竟讲了什么事；再按需要使用四段框架整理材料，而不是把四段当固定分钟配额。
3. 写人物履历，并从主人公视点写故事覆盖数日的日记，检查每个选择在当时为何合理、关键伏笔是否已进入人物经验。
4. 多人物同日行动画逐人日程，检查交通、等待、先后与物理时间。变换时间轴虽不必增加制作成本，但观众 / 人物各自知道什么必须清楚。
5. 对“临场刚好”逐项追因果；手机没电、人物恰巧错过等若决定高潮，前文必须有可见原因。

**归属与案例：**内田课堂用《E.T.》藏起 E.T.、《虎胆龙威》拿起机关枪讲“决定采取目标行动”；再用《洛奇》（三流拳击手获得冠军挑战机会，并与对手打成平局）和《放课后》（男子帮助初恋）练一两句概括。这些都是课堂借来分析的作品；前三部是美国影片，均非内田原创或执导，《放课后》也不是内田作品。

### 筧昌也：“如果 + 而且”把两个念头变成一个处境

**何时选：** 已有两个吸引人的设定 / 灵感，但单独都不足以生成完整行动。

**固定动作：**
1. 分别写出材料 X 与材料 Y；用“如果 X，而且 Y”组成一个命题。“而且”必须让 Y 改变 X 中人物能做什么、要承担什么或如何理解处境；只把两件事先后放进情节，不算合成。
2. 从组合设定逆推什么身份、职业、性格或处境会让人物可信地进入故事；再列出连续的选择与后果，证明这条 premise 能持续生成情节。
3. 找一个可以把两项材料扣在一起的物件、期限或行动，但每个线索都必须影响后续人物选择。反转出现后回头检查前置暗示；若设定只剩奇观名词，重做组合。
4. 用户已明确要分开的素材不强行混合。

**材料中的作品证据：**《美女罐头》从美女与罐头开始，普通青年雄太偷走沙纪后与她相处；罐头保质期把关系变成限时行动，结尾发现雄太也有期限，再回补伏笔。《人生补时》把临死前的时间与足球直播补时结合，两位熟人因同一电车事故得到不同余时。《恋爱部屋》把房间互换、前住客恋人和职业摔跤手搬家队连成处境，短裤、手机挂件、杯子和入场券存根继续承载人物线索。旧材料还用《水男孩》的“男性 + 花样游泳”作为跨材料提案；它是构想实例，不要求复刻题材。这些例子说明第二项要改变故事条件，而非装饰第一项。

### 三木聪：从小素材的重复与差异中等故事轴、主题浮现

**何时选：** 主要输入是生活观察、小物件、怪念头、笑料或不均衡片段，传统主题句与完整大纲尚未出现。

**固定动作：**
1. 先倒出素材，可记笔记、列清单，也可凭记忆保留笑料；不因材料零散就强迫先写主题句和完整情节构想。
2. 依据重复出现的物件、关系、语调和变化重排素材，找出相邻片段为何相连，再看故事轴如何形成。
3. 允许主题在写作过程中浮现。主题认出来后，删掉重复解释和没有帮助行动的台词；情况说明尽快结束。
4. 空转、重复、脱力或看似无用的偏差，只有改变期待、形成对照或增加观看趣味才保留。主人公不必按通用成长弧疗愈，但日常和“不发生大事”仍要有具体观看支点。
5. 不把笔记设为每个作者都必须执行的作业；福田的记忆式笑料游戏和三木的素材整理属于不同创作入口。

**材料中的作品证据：**《速成沼泽》的旧工作单从 41 条材料反复排序，留下硬币、仓库泥土、巧克力牛奶和“把水龙头拧开”等奇异连接，逐渐形成故事轴；开场约两分半、108 个镜头的巧克力牛奶独白展示了如何尽快结束情况说明、同时保留脱力语气。这些是构思和版本材料，不等于完成稿逐条照搬。《乌龟意外之速游》借用《原野奇侠》“陌生人到来、离开后生活复常”的骨架，做成“什么也没发生”的故事；它说明可以不让主角成长，但仍要有观看关系。旧教材记载“写到约七八集后才发现人物都在等待、留萌在等待鲱鱼”的主题浮现经验，但未指明具体作品与唯一作者，不补作品归属。

### 园子温：先让人物、个人材料或强画面熟成，再搭结构

**何时选：** 作品动力来自强烈人物、难以启齿的亲历材料或已能支撑作者继续创作的终场 / 关键画面。

**固定动作：**
1. 先找人物的具体选择和场面，不用华丽文字掩饰人物尚未形成；有力量的配角可以抢走原定主角位置。
2. 若一两幅场景比情节完整，可先写清其情绪、人物关系与不可替代之处，再倒推能容纳它们的行动和结构。
3. 亲历材料先转为虚构人物的处境和行动，不能直接复写私人生活。挑衅、极端、延长或强烈作者表达只在用户选定这种力度时采用，不将它设为日本方法通用门槛。

**材料中的作品证据：**《爱的曝光》据旧访谈先出现海边劝妹妹、精神病院妹妹来救两个场景，再从这些锚点倒推前半；同一材料提到园子温把加入宗教团体、逃离据点的经历转成创作材料。它们证明场景 / 经验可以先于完整结构，不要求其他作品复刻极端题材。

### 横浜聪子：经历不是电影；保留两端的不均衡，认真搭桥

**何时选：** 用户给出自身经历，或两条具体故事片段有力量却难以按常规结构自然接合。

**固定动作：**
1. 先分别写清每条经历 / 片段里发生了什么、人物如何选择、哪些感受不可丢；标明事实、记忆、观察和推演。
2. 把经历变成虚构关系，不按原样复演。试出几个连接方式，逐一说明桥梁为何存在、两端被怎样改变、删掉它会损失什么。
3. 允许成品保留不均衡和跳跃，但不可用无关桥段掩盖断裂。对白可多义，优先听声音、看动作和实际发生的事，不用情绪词替观众解释。

**材料中的作品证据：**《奇迹爱情物语》有两条差异很大的初始线索：阳人经历农药后死而复生、后来被熊吃掉；幼儿园教师町子与阳人生活并带孩子进森林。旧材料明确记录把两条线接起来很困难。方法要求不是抹平差异，而是找到值得保留的不均衡以及能承担关系变化的桥。

### 高桥泉：从具体品性写人，用指针性台词 / 画面聚焦

**何时选：** 人物只剩职业和身份说明，或终场只剩漂亮句子、情绪却没有被行动挣得。

**固定动作：**
1. 以人物生活痕迹、偏执、羞耻、热情及对同一事件的反应替代职业标签，写出“这是什么样的人”。
2. 可让演员在明确限制下即兴，观察动作与人物反应；即兴是素材，不把正式台词的作者责任交给演员。
3. 选一句指针性台词或一个画面作为情绪顶点，先确定它要改变 / 揭示什么关系，再从前文铺出人物选择和具体行动，使它挣得这个位置。
4. 用台词之后的动作、物件与声音检查情绪是否落地；不让漂亮句子代替关系变化。

**材料中的作品证据：**“研究者房间里放两本《哆啦 A 梦》”比“满屋文献”更能表现具体人的品性。《清晨之汤》的早期结尾以樱花和骑车告别，完成稿把“别人”放在末句，随后只留嚼咸菜声并转暗；旧教材把它解释为承认对方是“别人”后才能离别。落笔时让终句之后不再由人物解释，声音把告别留在日常动作里；若删掉前文关系铺垫或把含义说破，这个短句就只剩漂亮字眼。此例是该片结尾选择，不是所有结尾都要用省略号或生活声。

### 福田雄一：让人物声口和逗 / 捧关系先发动喜剧

**何时选：** 用户明确选择台词驱动喜剧、演员声音和角色互动，或喜剧依赖观众看见角色偏差。

**固定动作：**
1. 先确定角色声口、弱点、谁夸大 / 误解 / 装镇定 / 插话，以及演员带来的表现可能；由人物关系和试写台词生成喜剧情境。
2. 可以让观众而非场内角色承担捧哏，但必须让场面事实足够清楚，观众能自行看出偏差。
3. 固定形式和节奏可以反复；每次重复都要因新行动麻烦、角色错位或关系变化产生不同笑点。不要逐句解释笑点，也不要把逗 / 捧写成机械轮班。
4. 重点检查人物摆脱困境时是否制造更糟的新局面；若只是台词机灵而没有场面后果，继续写行动。

**材料中的作品证据：**《33分侦探》重复报案、侦探承诺用足 33 分钟、先抓嫌疑人、失衡推理与移动镜头等形式。制作反馈发现原先的逗 / 捧位置似乎倒置，后来让大田原深信侦探、助手插话纠正；位置变化让观众看到人物的错位。保留的是角色分工如何改变笑料机制，不要求复制节目形式。

### 大宫艾丽：brief、主题与调性先定，再配置人物

**何时选：** 用户已有委托 brief、明确主题，或项目需要先确定作品的人文调性。

**固定动作：**
1. 先弄清委托要什么，再明确作者要表达的主题、色调和声音；主题在本路中先定，不等待它从素材中偶然浮现。
2. 像布置花坛 / 火锅食材一样配置不同人物，让他们的立场、行为和反应体现主题；台词可以从作者与自己长谈中找词，但必须改成角色在当下能说的话。
3. 已定主题通过人物关系和行动实现，不让角色只在结尾解释道理；遇到制作困难时先找可行做法，但不替用户承诺预算、排期或制作权限。

**材料中的作品证据：**《木下部长和我》把效率主义公司、撞钟部长和不同部员放在一起；企画材料先定主题、人物口头禅、关系与集数安排。“休业是面向开业的准备”由懒散外表和意外行动体现。这一路不能被三木的“等主题浮现”覆盖。

### 行定勋：把限制转成关系，让剧本成为协作坐标

**何时选：** 预算、场地、物件、委托条件或导演 / 剧组合作直接影响故事生成。

**固定动作：**
1. 先把限制改写成角色必须面对的行动、关系或选择；不能只插入一段与剧情无关的展示说明。
2. 重复日常先建立可以比较的基线，再让他人或一个小选择造成偏离；观众要能看见限制如何进入故事。
3. 可为演员 / 工作人员留下讨论空间，但剧本必须守住故事中轴。标明哪些场面、事实、结尾或关系不可被讨论稿的开放性抹掉，哪些具体做法可协商。
4. 合作意见要说明会改变什么观看效果、带来什么损失；“剧本供议论”不等于核心因果全部开放。

**材料中的作品证据：**《奢侈的骨》里搅拌机养金鱼的构想来自朋友新婚住所的观察；小物进入三人秘密和观看关系后成为场面材料。旧材料也举出服装、歌词、香波广告、手机影像等委托限制作为原创刺激。规则是让限制生出故事，不复制金鱼或擅自答应制作条件。

### 荒井晴彦：先找到从原作看见了什么，再重组改编

**何时选：** 当前任务明确是改编，或用户点名荒井晴彦的改编实践。

**固定动作：**
1. 先说清原作哪部分真正打动创作者、从什么视点看见了新电影；喜欢原著不等于逐项保留。
2. 按新视点决定删减、重组人物和行动；新增情节也要服务作品核心，不能把原作题目当成改编已经成立的证据。
3. 用阅读 / 获准采访做准备，先形成改编梗概，再留时间通篇梳理；合写时先分工，再统一全稿。外部采访须在授权范围内。

**材料中的作品证据：**《W的悲剧》将密室题材改写为戏中戏和龙套追梦；培训班女孩、替罪羊与记者会线承担新故事的梦想主题。案例支持围绕个人视点重组，不宣称所有幕后过程已被逐条独立核实。

## 组合裁决与不覆盖边界

只有两条方法能分别处理不同变量时才组合，开写前写明主路和副路各管什么。例如筧先合成 premise，内田随后检验人物日记和物理时间；古泽安排观众信息顺序，高桥负责具体人物动作；崔石焕规定类型体验，福田处理角色逗 / 捧表演轴。

以下同轴冲突必须选一方，不能写成“都可尝试”：
- 内田的结尾 / 目标决定先行，与三木的素材排序、故事轴和主题后生。
- 大宫的委托主题先定，与三木等待主题浮现。
- 古泽先排事件与观众信息，和横浜保留不均衡片段、先解决经验之间的桥。
- 福田以人物声口 / 台词试生成喜剧情境，与奥比坦先定场面结构再写对白。若按阶段并用，要把福田短暂试写限定为探索材料，结构确定后依奥比坦重写正式对白。

父级的因果、格式和质量审查只检查作品，不能把已选路径的创作起点和优先级改成通用做法。用户已确认的结尾、主题、类型、材料和权限优先于任何方法建议。

## 返回父级并验收实际成稿

把所选路径和理由带回父级当前步骤：premise / 故事核心进入故事准备；事件顺序和伏笔进入结构；人物关系与具体行为进入人物 / 场次；台词、声音和读稿进入对白 / 修订。父级负责统一因果与交付体例，本 Skill 负责确保日本具名路径真正改变本轮选择。

验收稿件是否显示所选机制，而不只检查是否提到作者姓名：
- 古泽：事件顺序满足观众信息需要，“承”段有变化，跳切不丢关键因果。
- 内田：目标决定 / 结尾先立，人物履历、日记和时间表能解释选择。
- 筧：两项材料互相改变人物条件，并生成持续行动。
- 三木：由素材关系长出故事轴 / 主题，重复与空转有作用。
- 园子温：具体人物、经验或画面真实驱动结构，私人材料已转成角色行动。
- 横浜：两端不均衡的材料保留下来，连接有明确代价和意义。
- 高桥：人物有可见品性，指针性台词 / 画面由前文挣得，话后动作承接情绪。
- 福田：观众看得到角色错位，固定形式因行动产生变化。
- 大宫：作品兑现 brief 的主题与调性，人物实际体现主题。
- 行定：限制变成故事关系，协作留白仍保护中轴。
- 荒井：新视点实际改变了原作材料的选择与排序。

若验收未通过，回到偏离的步骤修订；不能以选择正确替代成稿效果。详细工作单、案例和来源说明见[地域编剧实践：日本](../../references/regional-practices.md#japanese-practices)。
