# 日本编剧实践：选一条具名路径，按它写成稿

日本编剧实践包含多条起点与优先级迥异的路线，没有统一的日式结构。本级按手头材料与真实瓶颈锁定一条具名主路，并让其起笔顺序与优先级落进大纲、场次和正文，不把方法摊成谁都不执行的菜单。

## 触发与选路原则

用户要求按日本编剧写法创作，或点名下方任一作者、作品及方法时启用；无需先懂作者姓名或术语。仅有日本背景、日语对白、角色国籍、地点或题材不触发；仅比较方法时说明差异，不代选风格。

- **点名直入：** 用户指定作者或作品方法即直接执行，其他路径不得在同一变量上覆盖它。
- **按瓶颈直选主路：** 用户只说日本路子、不知作者时，按手头材料与当前瓶颈直接从下表选一条主路，简述理由即开写，不反复追问作者名。
- **双信号裁决：** 作用于不同轴可组合并明写分工；落于同一决定时依已锁定的结尾、主题、类型与声音定主路，仅在取舍实质改写作品方向且材料无法定夺时才问。

## 快速选路表

| 当前材料或瓶颈 | 选定具名主路 |
|---|---|
| 事件与人物已明，缺全篇顺序、多线编排或有效跳切 | 古泽良太：行动框架与观众信息次序 |
| 结尾或目标决定已明，或多人同日行动与时间因果不稳 | 内田贤治：终点先行、日记与时间线反证 |
| 两个单薄念头需合为一个可持续处境 | 筧昌也：“如果 + 而且”合成处境 |
| 满手小观察、物件、怪念头，尚无故事轴与主题 | 三木聪：素材排序、脱力趣味与主题后生 |
| 强人物、难言亲历或有力关键画面先于情节 | 园子温：人物、亲历与强画面先熟成 |
| 两条亲历或片段各自有力却难自然接合 | 横浜聪子：亲历变形、保留不均衡与搭桥 |
| 人物沦为职业标签，或结尾空留漂亮话未由行动挣得 | 高桥泉：具体品性写人，指针性台词/画面聚焦 |
| 明确走台词驱动喜剧、演员声口或观众捧哏 | 福田雄一：角色声口与逗/捧关系发动喜剧 |
| 项目先定委托 brief、主题或人文调性 | 大宫艾丽：brief、主题与调性先定再配人 |
| 预算、场地、物件或剧组协作是核心制约 | 行定勋：把约束生成关系，剧本成协作坐标 |
| 明确原作改编且选用日本实践 | 荒井晴彦：找到对原作的个人发现再重组 |

## 十一位日本名家的固定创作动作

选定主路后，其起点、顺序与优先级须在成稿中兑现，不得被通用流程暗中替换。

- **古泽良太（行动框架与观众信息次序）：** ①列人物关系、矛盾及观众必先知/后知事件画因果框架，不先套分钟比（《怪胎刑警》先列信息再交错排场，《外事警察》用新人作观众入口）；②承段场场推进目标、信息、关系或情绪，转合由前因逼出；③多线各列行动再切，反差与跳切绝不跳掉理解必需证据；④砍无新变化场，不以晦涩冒充结构。
- **内田贤治（终点先行，日记与时间线反证）：** ①先落终点状态或主角决定追目标的瞬间作情节点（结局未定且改承诺时不擅代定）；②从终点反推必要行动与前置证据，一两句概括全片实事（仅明确指定时分四段，不作默认）；③写改变选择的人物履历，跨日按主角视点逐日写日记（单日按时段）核伏笔入经验；④多人同日行动画逐人日程核交通、等待与物理时间，倒叙变序标清人物与观众各何时知情；⑤追查临场刚好（手机没电、恰巧错过）的前文可见因。
- **筧昌也（“如果 + 而且”合成处境）：** ①分列 X 与 Y 合成“如果 X，而且 Y”——Y 须实改 X 里人物能做什么、担何代价或如何理解处境，不止先后拼贴（《美女罐头》保质期限时关系、《人生补时》电车分余时、《恋爱部屋》换房联动线索）；②从组合逆推可信身份与职业，列连续选择证产能；③用扣紧两材的物件、期限或行动牵动后继，反转必回补前置暗示。
- **三木聪（素材排序、脱力趣味与主题后生）：** ①先倒出生活观察、小物、怪念头与笑料，不强逼先定主题句和大纲；②按物件、关系、语调的重复与差异反复重排，试以时间、因果、人物、空间或变奏组合相邻片段，等故事轴与主题浮现（《速成沼泽》碎材排序、开场速结说明）；③主题显形后删废话与重复解说；④空转、脱力或微小偏差（只下不上的楼梯）须改期待、造对照或增趣味才留，允许主角不疗愈但须有具体观看支点（《乌龟意外之速游》）。
- **园子温（人物、亲历或强画面先熟成）：** ①先找具体选择与场面，不用华丽词句掩饰空壳，强配角可夺主角位；②结局已定先落终点，结局未定且有两幅承重画面（《爱的曝光》海边与精神病院）则先写关键动作再前后推，否则从动作与关系立处境再搭结构；③亲历转为虚构人物行动，不直录私生活；极端力度仅由用户明选。
- **横浜聪子（亲历变形、保留不均衡与搭桥）：** ①分清每条片段的事实、选择与不可丢感受；②将亲历转成虚构关系，试写多套连接桥并逐一检验桥为何存在、如何改两端、删之损什么（《奇迹爱情物语》保留两端反差认真搭桥）；③允许成品留不均衡与跳跃，绝不用无关桥段掩盖断裂，对白留多义而凭声音与动作落地。
- **高桥泉（具体品性写人，指针性台词/画面聚焦）：** ①用生活痕迹、偏执、羞耻、热情与独特反应代职业标签（研究者房里两本《哆啦A梦》胜过满屋文献）；②可在限定条件下借即兴采素材，正式台词责任归作者；③选一句指针性台词或一幅画面作顶点，先定其改写的关系，再从前文铺足行动挣得此位；④话后由动作、物件与声音承接情绪（《清晨之汤》末句“别人”后只留嚼咸菜声转暗）。
- **福田雄一（角色声口与逗/捧发动喜剧）：** ①先定角色声口、弱点、谁夸大/装镇定/插话及演员特质，由互动试写生出喜剧情境；②可让观众当捧哏，前提是场面事实清楚让观众一眼见错位；③固定形式反复须借新麻烦或角色错位产新笑点（《33分侦探》调换大逗哏与助手位），拒机械轮班；④紧盯脱困时是否酿更糟新局，可改造真实荒唐新闻。
- **大宫艾丽（brief、主题与调性先定再配人）：** ①吃透委托需求并当场锁死主题、色调与声音，不等素材浮现；②如搭花坛或火锅食材配置立场各异的人物群像，借行动与反应兑现主题（《木下部长和我》）；③台词可由作者自语找词再转为角色当下口吻，不靠结尾说教，遇限制先找可行写法。
- **行定勋（把约束生成关系，剧本成协作坐标）：** ①把预算、场地、物件、歌词或委托限制直接改成角色必面对的行动与关系，不插无关展示；②借重复日常立基线，再以小选择造偏离（《奢侈的骨》搅拌机养金鱼牵动三人秘密）；③给剧组留讨论空间，同时明标不可动摇的故事中轴（核心场面、事实、关系与结尾）与可商议项。
- **荒井晴彦（找对原作的个人发现再重组）：** ①先说清原作哪处真正打动自己、看见什么新电影，喜欢不等于逐项保留；②按新视点删改重组人物与行动，新增情节服务新核（《W的悲剧》改雪山密室为戏中戏追梦）；③阅读或获准取材后先成改编梗概再通篇统稿，合写先分工再统一。

## 同轴互斥与组合裁决

仅当两条路径分管不同变量时组合（如筧昌也合成 premise + 内田贤治核时间线；古泽良太排信息序 + 高桥泉落品性；崔石焕锁类型 + 福田雄一管逗捧），开写前明写分工。以下四组同轴互斥必须二选一：

- **内田贤治（结尾/目标先行） vs 三木聪（素材排序与主题后生）**
- **大宫艾丽（委托主题先定） vs 三木聪（等主题浮现）**
- **古泽良太（先排事件与观众信息序） vs 横浜聪子（留不均衡片段先搭桥）**
- **福田雄一（台词试生成喜剧情境） vs 奥比坦（先定场面结构再写对白）**（分阶段并用时，福田试写仅作探索原料，结构定后依奥比坦重写对白）

父级审读只核质量，不把已选路径起点改回通用套路；中文成稿守住路径顺序，按当下人物关系说自然中文。

## 共同误区自检、验收与返回父级

- **共同误区自检：** 用标题与一句话梗概检故事对象是否清楚；实讲给读者听只记真实失趣或卡点；分清亲历、新闻、访谈、观察与推演，不把单一作者习惯当全员铁律。
- **逐路成稿验收：** 核机制是否真正落地——古泽看信息序与承段生变；内田看终点先立与日程因果；筧看双材互改条件；三木看素材长主轴与有效空转；园子温看人物/画面驱结构；横浜看不均衡与有效搭桥；高桥看品性与指针由前文挣得；福田看角色错位与脱困酿新祸；大宫看 brief 借行动兑现；行定看约束化关系且中轴不散；荒井看新视点实改原作排序。
