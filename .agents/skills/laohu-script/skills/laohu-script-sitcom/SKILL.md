# 情景喜剧：笑点从人物认真维持的困境里长出来

## 触发边界与固定核心

用户要求按情景喜剧/sitcom/半小时喜剧开发 premise、典型集、喜剧引擎或改写喜剧场景，或想看一组常驻人物如何反复惹出麻烦时启用；无需先说 premise、beat 等术语。普通喜剧电影、讽刺、荒诞、黑色喜剧或正剧里穿插的干幽默不触发本级；悲喜剧（dramedy）须先锁连续人物弧与情感承诺。

核心原则是**建造，不修补**：先把产笑机制造进系列前提，再于段落和场景中层层复合，最后让笑点从人物认真行事与局面错位中自然长出。半小时喜剧绝不是缩水版一小时剧；选定单机、多机或动画后，场数、调度、笑点节奏与停顿即不可互换。

## 第一步：锁定喜剧格式与本剧承诺

### 格式分支

| 选定格式 | 叙事与演出形态 | 不可互换的喜剧节奏差异 |
|---|---|---|
| 真人单机（single-camera） | 逐场实拍、可剪接，短场多，近似小型电影 | 靠剪接、短场并置与视觉反应产笑；可留尴尬停顿（cringe pause）放大错位 |
| 真人多机（multi-camera） | 少量常设棚景、长场、出入场与现场演出节奏 | 靠走位、出入场、演员反应与观众笑声承托节奏；照单机硬拖静默会变冷场（dead air） |
| 动画 | 世界规则与物理可夸张，声画直接兑现荒诞 | 处境再荒诞，人物反应仍须可信，不能把动画当成无因果胡闹许可 |

戏剧结构的幕与广告分段不是同一概念；中文剧本按当前委托与[剧本格式与交付](../../references/script-format-and-delivery.md)组织版式与估时，不照搬英文一页一分钟换算。

### 本剧自身的喜剧类型

开写前先锁本剧的独有期待：主要靠什么发笑（困境、人物关系、规则环境、视觉动作、机锋对白或混合）；追求大笑还是会心一笑；笑声均匀推进还是聚于 comedy block 爆发；结尾落在笑点、情绪时刻还是两者并存。一个点子再好笑，若不扩展已选 premise，即删掉或改回人物关系变体——绝不为一个笑话换一部剧。

局部场面若靠人物坚定误读、自我辩护或反应强度与现场错位出笑，按[喜剧场面机制](../../references/specialized-methods.md#comedy-scene-mechanism)处理并带回本集升级链。

## 第二步：构造持续困境与人物组合

从[困境与人物组合](../../references/specialized-methods.md#情境喜剧从真实需要和规则制造升级)选用适配原料，写定能反复产故事的本剧 premise。逐项确认：人物为何无法一次彻底解决困境或一走了之；若长期困境某天兑现，由什么关系后果或新压力接棒。

将主要常驻人物两两放进同一现场做配对测试：各自想要什么、认定哪条规则合理、谁能牵制谁、为何不能客气退场。每名常驻角色至少须有一组可反复生效的高摩擦配对，差异直接见于行动与反应。

## 第三步：按七步建立单集与升级链

按 Landau 半小时七步搭单集骨架（先把 beat sheet 写成角色行动与反应，绝不写成笑话清单）：

1. **微小重需破日常：** 一个对外部世界微不足道、对人物却至关重大的需要（tremendous trifle）打破稳定日常（冷开场可选）。
2. **定策起行：** 第一幕主角定下自以为可行的计划着手解决；若有副线，为配角设相关问题。
3. **主题串线：** 用同一主题或压力拧紧 A/B/C 线；副线须照亮主线、制造对照或改写主线行动。
4. **中点升险：** 主角的解法酿出更大麻烦，把自己送上更高的树（两幕剧多在第一幕末，三幕剧多在第二幕末），此后持续加障。
5. **最难堪低谷：** 后半段抵达全盘失控或极度窘迫状态，绝不把同一误会干演三遍。
6. **因果高潮：** 以真相、沟通、弥补或承认代价正面回应本集原始需要，不靠天降打断糊弄收场。
7. **短 tag 回常：** 仅在所选格式需要且能再揭人物旧病或新余波时附加短尾声。

Pilot 建立世界时前段可长于常规集；如 *The Big Bang Theory* pilot 所示，可让单集小目标（取回电视）与长期关系变动（新邻居打破平衡）同处一集。

## 第四步：把笑点写成角色化动作

### 从本集前提到场景升级

沿每条承重行动线回查它如何扩展本剧期待，按六步把困境推成可演升级：

1. **给人物认真需要：** 保面子、瞒失误、赶访客、争小位置——观众须看懂他为何拼命在意。
2. **从系列 premise 派生触发：** 麻烦必须长自常驻人物的缺陷、关系或固定规则。
3. **分配互斥策略与临时异己联盟：** 各按自身利益行事；可借**临时异己联盟（unnatural alliance）**把本就稳定对立的两人因当集共利捆在一起（如 *Seinfeld* Jerry 与 Newman），让观众同时等难题解决与同盟破裂，结尾恢复或改写原对立。
4. **复合困境而非重复困境：** 让一个谎言逼出更大谎言，或让副线撞歪主线解法；每次升级必改赌注、知情、地位、资源或策略。
5. **选主导笑点机制推至峰值：** 从误解、字面执行、身份倒置、计划失败、重复变形、局促共处或预期反转中择一主导，在段落内推成 comedy block 峰值。
6. **落实可见局部结算：** 明确原始需要解决否、谁得谁失、关系有何改变。

### 笑点怎么入戏

按[逐拍写笑点](../../references/specialized-methods.md#逐拍写笑点setup发展转折反应后果)把触发、期待、发展、转折、反应与后果落进具体行动。中文对白里的机锋与惯用语，仅在人物拿来掩饰、攻击、拖延或争位且在场内引出真实回应时成立；脱离对象的硬梗回 setup 重写。

- **加码（topper）与回扣（callback）：** 同一 setup 最多加 1–2 个递进加码，dramedy 通常不用 topper；反复回扣以 2–3 次变形为度，若无新义或新代价即删或升级。
- **节奏与密度诊断：** 若笑点稀疏，回查前提困境与段落碰撞，不靠场外贴俏皮话补救；多机借走位与出入场托住反应，单机借剪接、并置或尴尬停顿调节奏。

## 第五步：Pilot、悲喜剧与短季装置弧

### Pilot 选型

- **Typical-episode pilot（默认优先）：** 人物关系已在运转时，直接写一集常规好戏，证明组合、引擎与单集结算可长期重复，背景融于行动（如 *Fleabag* S1E1）。
- **Premise pilot：** 仅在创立前提的事件不可跳过、或观众须借事件懂规则时选用；事件后仍须在当集跑通一遍常规模式。
- **Hybrid：** 前半立新常态变故，后半跑一遍常态下的典型喜剧。

### Dramedy / 喜剧承载悲剧

当人物与故事线强连续、背负深前史与情感弧时，幽默转向反讽与苦笑（wry/ironic），摒弃定时段子排布。笑点须承担真实关系功能而非冲淡悲剧（如 *Succession* 用残忍玩笑承接罪责，喜剧副线在调温同时逼出主线抉择）。情感重场可走**痛 → 笑 → 痛**节拍：先触真实痛处 → 以笑点或自嘲显出防御 → 落回未解之痛，笑揭示防卫却不抹平痛感。

### 短季/装置型喜剧

单作者主导的短季喜剧（如六集季 *Fleabag*）若用形式装置（如对镜独白），须将其锚定在人物心理防御上，并完整设计**建立 → 升级 → 失效 → 退场**的装置弧：初作主角与观众的共谋盾牌 → 诚实亲密来临时装置开始失效或被他人察觉抽离 → 终局由主角主动告别装置完成成长；无心理因果绝不硬破第四面墙。贯穿全季的物件每次易手须改写主角对过去的理解；季终 button 可解答主题同时保留未尽情节。

## 输出、验收与返回父流程

按本轮请求交付相应环节（premise、格式与承诺、困境配对表、beat sheet、升级链、笑点动作或季弧）；不自动附带 pitch、series bible 或 writers’ guidelines。仅当明确要求半小时喜剧销售用 series format 时，读[Smith 十一节卡](../../references/series-document-templates.md#smith-series-format)并交回父级未编号交付接口。

将系列承诺、典型集与升级链带回[父级主流程](../../SKILL.md)：定前提与人物组合回阶段一，搭七步结构、分场与季弧回阶段二，正文台词与节奏回阶段三，自审与交付回阶段四；局部交锋与声口分别衔接[喜剧场面机制](../../references/specialized-methods.md#comedy-scene-mechanism)与[对白与视听](../../references/dialogue-and-audiovisual.md)。

**验收：** 观众能复述本剧独有喜剧规则；常驻人物有互补高摩擦配对；单集由认真小需要驱动、中点翻倍加码、结尾因果结算；删去任何笑点要么影响行动与关系、要么丢掉明确节奏理由；缺笑回 premise 与组合修根。
