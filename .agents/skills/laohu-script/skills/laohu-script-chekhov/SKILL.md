# 契诃夫戏剧方法：让生活中的选择留下后果

## 触发条件与范围

用户点名契诃夫或其作品，或要求写一群人各有理由、在日常里互相错过并留下具体后果时启用；无需先说剧作术语。通用于舞台、电影与剧集，迁移时只换媒介单位，不把舞台幕或舞台版式照搬成影视格式。仅出现日常、慢、群像、无大反派、无高潮等题材词不触发。

## 定义性固定项

1. **共享环境里相互妨碍，共同承责。** 每人各有眼前任务、愿望、限制、自辩与互斥欲望；环境须改变人能做什么、如何相处或将失去什么，不简化成善恶对决，也不把各有道理写成平均无责。
2. **未发生的事也有行动账。** 等待、拒绝、拖延与错过必须落到具体的人、机会、时点与代价，写清谁本可做什么、为何未做、此刻付出何种损失。
3. **注意差落到可演证据。** 错答、转题、沉默或继续劳作必须源于当下欲望、羞耻、策略或注意对象，靠停顿、称呼变化、物件处理或离场兑现。
4. **事件可画内或画外，因果不能缺席。** 画外须给足前因、知情次序、反应与后果；画内暴力同样须由羞耻、对方回应与后续生活承接。

## 结构招式：S1–S10

按需单选或组合，未选不作全篇配额；**重在吃透每招的错位、知情与代价机制，括号内原剧桥段仅为参照，彻底换成本作自己的生活血肉，不照搬原剧固定步数与道具套壳**。

- **S1 四幕先定情调再放事件：** 多幕群像按共同生活演变组织时，先定四幕底色与可见条件再落事件——一幕团聚、晨光与期待；二幕懒散、空谈与暗流；三幕夜晚、荒凉、自私与隔绝；四幕崩溃、绝望与分别。
- **S2 大变化留幕间，首句给时间刻度：** 婚嫁、生子、病死、抵押置幕间；下幕首句或第一轮闲谈直接交代周年、日期或命名日（《海鸥》《三姊妹》），靠变化而非标题卡让观众读懂时间。
- **S3 画外事件靠知情链，画内暴力必承后果：** 画外走三步——回避遮挡 → 声响、缺席或传闻提示 → 核实者定向告知特定接收者，逐一清点谁听见、谁不知、谁照常做事、谁改计划（《海鸥》多尔恩先以乙醚瓶稳住母亲，再借杂志引开特里果林低声报死讯）。画内未遂暴力由羞耻与重回账簿承接（《万尼亚舅舅》）。
- **S4 首尾重现一景或一语，只改关键状态：** 结尾重现观众立辨的房间、文本、物件或动作，至少翻转一项可见状态（《樱桃园》幼儿室变空房堆具、《万尼亚舅舅》问茶酒从拒到受、《海鸥》重念独白听者失焦）。
- **S5 早给可行答案，每次拒绝缩窄窗口：** 首段即抛具体可行解法，后继反复重提并更新拒绝理由、处境与剩余窗口，显出谁关死退路及物质损失（《樱桃园》分租盖别墅）。
- **S6 机械节拍维持群戏，变故插入间隙：** 选牌局报数、算盘、家务、祷文或舞步口令作可定位节拍器，写清发起者与规则，令枪声、拒绝或死讯切入数字间，显出生活程序如何吞咽变故。
- **S7 反复预告的事末尾落空，停顿关死机会：** 全剧反复立起明确期待，末尾因回避、错位或时限落空，紧接停顿、门外召唤或家常请求锁死代价（《樱桃园》瓦里雅与罗巴辛只谈行李天气，门外一唤、停顿、一句“那，就走吧”即定局；另见《大路上》举斧未落、《伊凡诺夫》婚礼不成）。
- **S8 结尾并置希望、虚无与家务，边缘人接末拍：** 依次并排三层抵触却共存的元素——年轻或信仰者的希望、虚无或冷静者的冷语、持续运转的家务动作，末拍交给易被遗忘的边缘人物（索尼雅“我们会休息下来”并置更夫与记账，《三姊妹》活下去并置“反正一样”与推车，《樱桃园》迎新并置被锁的费尔斯与斧声）。
- **S9 庆典照常进行，当事人带回灾难：** 舞会、婚礼等公共仪式与灾难同步；仪式不停，坏消息先作传闻渗透，终由当事人带回改写全场（罗巴辛带狂喜与耻辱闯入舞会报买园，或《伊凡诺夫》婚礼破局）。
- **S10 一处空间一整夜，来客顺序改写关系：** 锁定单空间与一整夜，精确排布出入顺序；前一位留下的决定、忏悔或失败须改变后一位处境，终点由末次出入造成（《没有父亲的人》路基夜、《万尼亚舅舅》雷雨夜、《三姊妹》火灾夜）。

## 人物招式：C1–C10

人物通法由父级承担；以下按关系条件选用，角色位须兑现为行动与后果。

- **C1 空间与物件命令见胜负：** 制度、家务或资源冲突靠谁占房、挪座、熄蜡烛、处置家具显现支配，不靠反派宣言（娜达莎逐间改房、罗巴辛哭着买旧园）。
- **C2 来客各贴标签：** 主角自身难言其详时，配角各抛简单定性，主角只答不知道或不了解，每张标签至少改变一次互动或选择（众人定义伊凡诺夫）。
- **C3 道德家每次正确都伤人：** 保留其成立的道德理由，让宣称正直的时机与方式实际伤人，并由他人点破代价（里沃夫）。
- **C4 角色随身物与语言印记：** 可为承重人物（需要群像质感时可延及核心配角）配一件随身生活物与一句惯常口头短语；情感重处重现变义，结尾令其失灵、反转、碎裂或易手，不为凑齐全员配额硬塞生硬口头禅。
- **C5 清醒者同陷失败：** 最洞明处境者把自己与主角并列在同一滑落里，不站环境外说教（阿斯特罗夫、多尔恩、契布蒂金）；习气传染须落行为。
- **C6 边缘人道主题，主角对听不见者说真话：** 道破整体生活的真话交仆役、打扫者、聋者或被遗忘者（费尔斯）；主角向听不见或不评判者倾吐，保留听错或答非所问的错位（安德烈对聋人费拉彭特诉苦换来薄饼传闻）。
- **C7 身份游离者表演，不合时宜者讲旧笑话：** 分设两位——无根者以戏法、模仿或自问我是谁代倾诉（夏洛蒂）；不合时宜者在紧张顶点讲旧笑话暴露回避（沙姆拉耶夫）。
- **C8 单向爱情链忠于已定关系：** 设定属不对称追求时，按实际关系画清谁爱谁、谁拒绝谁及拒绝如何被误读（《海鸥》单向链），不强改已有双向绑定。
- **C9 真人混型与演员动作生人：** 混合两三处真实观察特征，或先取一个可复现身体动作（垂钓、拍水），由此长出生活、关系与口头语，删纯噱头。
- **C10 体面保住沉沦反差：** 阶层、教养与自尊介入冲突时，不把困顿写成邋遢；用考究衣着、礼仪与用物守住才华沉沦穷乡的反差（万尼亚）。

## 对白与停顿：D1–D12

按场选用，守住触发与落点，不揉成单一含蓄腔。

- **D1 首句人生判断被生活压下：** 首句直抛人生总判，紧接工资、钟点、周年或杂务压平（“我很不幸”紧接二十三卢布月薪），琐事须真实制约说话人。
- **D2 回答偏半格露出注意对象：** 接住上句一词却回答自己的牵挂或算计（离情转狗吃胡桃、危机转台球话），偏移源于当下注意与关系。
- **D3 哲学话落回身体或新闻，再被物件截断：** 宏大论断紧接口渴、疲惫或报闻。完整信念截断链：崇拜者转述 → 本人说一半 → 饮酒或物件打断 → 立即自贬（阿斯特罗夫森林独白）。
- **D4 痛处只留短答或技术追问：** 前文立实痛感后，最深的伤只回短答或技术问题（枪响后问“那是什么？”，临终追问何时说出，回避求婚谈寒暑表）；表层所指须从画面或相邻问答看清。
- **D5 独白只走职业强迫或旧日情感一线：** 二择其一——职业强迫线紧扣笔记、机器、地图等工作物反照本人，听者可露不耐；旧日情感线紧扣错过时点回推未做之选（万尼亚十年前）。
- **D6 忏悔说完，听者以动作拒听：** 关系难容而忏悔非说完不可时，听者走开、躲屏风或掩耳，仍令忏悔完成，靠可见动作兑现拒绝而不靠打断逃责。
- **D7 善意撞破后的寒暄暗语：** 撞见者原本带着善意或照料而来（原作例证为手捧玫瑰），被撞破后双方却转谈天气或眼前闲事，末句表面仍在谈日常，实则暗答刚裂开的关系缝隙。
- **D8 照料起手→撕破体面→短暂靠近与并置反句：** 从亲密日常照料起手（原作例证如换绷带），在情绪挤压下突发阶层或委屈互刺，紧接失控后的尴尬靠近或借共享小事缓和，最终让双方各守一句相反的生存判断并排落尾（按本作关系自然展开，不强套原剧五步动作）。
- **D9 借角色或名言自抬再自贬：** 用高格调名号或引文替彼此或自己撑体面，紧接着自我拆台否认，显出理想与窘境的落差（《天鹅之歌》）。
- **D10 热烈告白接冷旁白露出表演：** 炽烈求爱或投降后紧接冷静旁白或务实动作抵住自我戏剧化（阿尔卡基娜跪抱后低声说“现在我可算把他抓住了”）。
- **D11 诀别落回咖啡、借物或小账：** 诀别者求告别语而对方无言，末句落回没喝咖啡、衣物或小账，以谁还要为谁做什么承接结局。
- **D12 门口收回同意，口哨与停顿有前因：** 临出门低声收回刚给的同意，对方未听清而生活照常推进；口哨、静场、半句、背错诗或放下物件皆由背叛、羞耻或无力承受触发。

## 声音、道具、独幕剧与媒介边界

- **声画与道具：** 舞台选完整声音设计时，每幕配一组有源环境声，末幕以远近双声收窄空间并写清听者；怪声先由众人各解，第二次于无人处重响；反常静默可作反音效。钟表、周年、车次标时间；地图、账簿、钥匙、碎钟、标本等道具须改变持有人或意义。舞台指示只写可见可听；影视化保留声源、节拍与道具机制，场号、`△` 与编号沿父级体例。
- **改写标尺：** 参照《林妖》改《万尼亚舅舅》与《海鸥》删悬置爆点——砍纯凑对人物，让单向情与账簿生后果，删无后文的幕尾惊爆。
- **独幕剧与短片九型：** 守单一空间、连续时间、贯穿物件及身体或报数节拍；闹剧由任务偏离推向身体失控，悲剧落在本欲发生之事未发生。

## 编写顺序、验收与返回父级

1. 锁共享环境、每人眼前任务与限制，确认群像互担后果；选定适配的结构、人物与对白机制并落进本作自身的生活细节。
2. 标清画内外事件、知情链与每次拒绝缩窄的窗口；给重复节拍、声源、道具与停顿配状态变化；核对结尾欠账与受损者，删去无后文爆点。
3. **验收：** 陌生读者能说出每人此刻在做什么、为何没做另一件事、共享环境怎样加重代价、所选错位机制真正在场且未发生之事有明确受损者。

将群体生活、结构与因果带回[父级主流程](../../SKILL.md)：定戏核与人物声口回阶段一，搭结构、信息差与分场回阶段二，正文与声画回阶段三，自审回阶段四；独幕要点见[声音、道具、独幕剧与媒介边界](#声音道具独幕剧与媒介边界)。
