# 世界规则、动画行动与下游锚点

按宿主交来的阶段、关键行动、画风与规则选分支。动作幅度在宿主正文主链调节，本模块解决影响场面与后续选择的虚构规则、动作相位或制作交接。原样排版沿宿主流程。

## 让世界规则进入行动与选择

1. 先找在故事中真正改变行动、可能性、代价或结果的能力、物件或规则。逐项确认可观察的触发、效果、限制、谁知道、观众在什么时候能看懂。材料仍不确定时沿用宿主批准范围和拟案状态。
2. 若能力或物件要解决核心危机，先用一次足以读懂的使用、失败、环境反应或特定痕迹，建立观众理解破局所需的规则。先写到当前选择需要的清晰度。尚未知的来历、完整机制或神秘力量可承担压力和奇观，核心解决须靠此前已有的依据。
3. 给每项承重能力落一条现场能被触及的限制、条件、代价或盲区。让限制实际拿走一个办法、形成笑点或损失、改变谁要合作，或验证一次真正可能失败的尝试。已锁定限制按原作用执行，开放限制只在因果需要处补案。
4. 终局优先改用已有能力，组合已立物件、环境或关系。按初见读者的时间顺序回查铺垫、首次可用反馈、失败或改策依据、破局与代价。若解法靠观众首次才得知的规则，沿宿主授权把必要条件前移到实际发生的行动，或更换解法。

上述判断据 Brandon Sanderson 对魔法使用的三条写作经验作本地适配，适用于观众要凭先前证据理解的解决方案，也可检验一项虚构科技承担的同类行动。

## 让动画的物理和状态在正文中成立

1. 沿本作基调和场面语气调节物理弹性。规则或例外会改变选择时，给可辨的触发与后果。
2. 按[风格与可见过程](../../references/script-format-and-delivery.md#按风格写可见过程)写观众此刻该看到的起势、演变或反馈，沿用揭示时点。保留承担要求、误会、掩饰或关系选择的对白。
3. 后文用到变形、损耗、换手或恢复时，给观众接得上的依据。短暂反应留在当前场，持续状态延至确有变化。

世界规则与动画行动的结果回到阶段二的因果设计、分场和状态预算，以及阶段三的正文落笔。需要组合重头动作或声画转场时，由宿主协调动作次序、信息显露与连续性。

## 在用户需要时整理独立制作附录

用户明确要给资产或视频制作接续时，从已经确认且当前获准交接的正文提取。只有计划或版本未定的地方，写真实所在阶段与待确认事项。清单与剧本正文物理分开，**单独放入一个干净的 Markdown 代码块**（块外只标标题与交接用途，块内剥离寒暄、创作点评与过程说明），**块内优先采用清晰 Markdown 表格**按所需接收方呈现以下四类有实际证据的项目（拒绝难扫读的深层嵌套长列表）：

| 锚点 | 记录的内容 | 实际接收者 |
|---|---|---|
| 角色和持续状态 | 正文姓名或称呼、可辨基础态、影响后续画面的状态变化、引发场次和持续范围。 | Assets 归并身份、判断持续变体，Video 沿用进入与结束状态。 |
| 连续性道具 | 剧情用途、依据、持有人和交接或放置、损耗或消失的场次。 | Assets 确定候选与复用，Video 保持挂接与道具状态。 |
| 固定场景 | 原场头的地点名称、内外与时段，必要的空间辨认和氛围。判断是否同一主地点的依据随本条传递。 | Assets 核对地点身份与复用，Video 继承已确认空间条件。 |
| 高光动作或能力效果 | 场号或可追溯片段、观众应获得的可见／可听信息、前提、触发和末态。 | Video 决定分段与实现，Assets 核对消耗、持续或独立辨认所需对象。 |

- **严格忠实正文、零编造铁律**：所有人物姓名、道具细节、交接动作归属与场景状态 **100% 取自获准剧本正文实据**，严禁在清单里替正文私自添油加醋（正文未写的细节或称呼绝不凭空编造，动作主客体不与正文打架），确有缺口只标“待确认”。
- **屏幕/纸面可读文字核对表（按需附加）**：当剧本包含承重手机消息、电脑页面、招牌或纸质单据等必须让观众看清的关键文字时，在同一个洁净附录代码块内单列一张精炼**屏幕与纸面可读文字核对表**（场号、载体、逐字忠实摘录正文文字与触发节点），方便画面资产与视频后期直接落地。

附录按正文的[首次出场视觉锚点](../../references/script-format-and-delivery.md#首次出场视觉锚点)及表中字段核对，确保下游可一键复制零串位。按授权交由 Assets 定三视图、细部及提示词，Video 定镜头参数、P 边界及视频提示词。
