# 国产剧集实践：长篇关系落到每集行动

## 触发与本级承诺

用户要求按国产长剧/国产剧集方法创作、拆分长篇分集、把原作改编成长剧，或为具体国内接收方组织剧集材料时启用；无需先说戏眼、集—段—场等术语。仅因中文对白、中国人物或中国地点不触发。创作与交付路径可分可合，合同、平台当期模板或用户选定结构优先。

本级以长剧核心观察轴落笔：主要人物在社会、家庭与职业关系网中如何持续作选择；每集**戏眼**是什么、行动怎样改写局部状态；集尾如何收煞并给出有因果的下集理由。

## 第一步：路径分流、一案跨度与结构立场

### 三路分流

- **长线创作：** 开发原创长剧故事、分集与人物命运，直接往下执行。
- **改编扩容：** 既有原作扩长剧，先做[第三步](#第三步改编成长剧时保留承重项重做容量)容量与结构手术，再回分集创作。
- **接收文件：** 制作项目书、分集梗概、分集剧本或制片表，先明接收者、决策用途与模板规定；双修时先定故事选择再填表，绝不让表格替作者做剧情决定。

### 一案占几集：必须选点

按产能与观看形态在跨度光谱上明确选点，杜绝中途摇摆：

| 选点 | 收益 | 代价 | 优先适用 |
|---|---|---|---|
| 1 集结一单元 | 任意集入场、易复看、单元满足稳 | 人物归零则长看生腻 | 强行业流程或情景喜剧；须写清关系与能力累积 |
| 2–3 集一事件 | 兼顾短周期满足与关系长线 | 长剧需备足十余组独立事件源 | 单元收束与长线并行；宜配后果账本 |
| 4–6 集一板块 | 写透事件情感与关系后果 | 开篇易慢，须早立主问与局部扣 | 家庭、群像或长篇改编；须验开篇长线钩 |
| 全季/全剧一案 | 连续追看压迫力最强 | 单集难独立，中途入场门槛高 | 限定剧或巨案持续翻新关系；每集必设局部任务 |

决策四步：①算冲突源产能 → ②估人物转变集数 → ③看隔日等更还是连刷点播 → ④选点明写得失。闭案+后果账本每单元真结案并标欠账兑付集；三轨制逐集标清 A（本集）、B（跨数集）、C（全季）状态变化。

### 结构方法的分歧不能抹平

先按本轮缺口在姚扣根与张巍间择一为主，国产长剧默认用集—段—场与戏眼（仅明确要美式规格时另做 ACT）：

- **姚扣根路径（情境—行动与模式回环）：** 重集—段—场、段落收煞、模式回环及散文/心理形态。落地**情境两步法**先立环境限制规则，再让人物带欲行动，由回应使情境变形，核进入、变形、离开及下步影响；重复环境必改关系、名誉、资源或局势之一。被动主角在被动中保留欲望，写清不能决定什么、仍选何动作（忍耐、辩解、求助、拒绝）并改关系。
- **张巍路径（篇章换局与强关系冲突）：** 商播与紧凑节奏下，以鲜明冲突加速换局、重组主题与做改编手术；非冲突长剧须另明观众追看理由及代价。
- **严防人物顺撇：** 背景与反应雷同的人物易听成一人。逐一对照**利益网与情感网**，把冲突压进最能改写核心关系的场面，拒绝平均摊派压力。

## 第二步：单集戏眼、集段场收煞与悬念延宕

每集按六步编排：

1. **长线状态：** 主要人物所求、相互牵制与上集末至本集初状态。
2. **本集戏眼：** 一句具体问题写清观众本集最想看哪次人物行动或关系判断，不拿主题词、宣传句或大场面代戏眼。
3. **触发与行动：** 冲突同时牵动利益网与情感网，合因果且照见人物核心面向。
4. **集内段落：** 按情境转换分段，每段有局部目标、阻碍、策略变与段末状态或扣子，不套固定幕数。
5. **集尾收煞与承接：** 先结本集戏眼，再从本集行动长出下集理由，不生贴预告（如《北京人在纽约》首集由“美国欢迎你！”落到“你给我打工！”，全集服务同一集义）。
6. **集间账本：** 标明各线推、挫、稳、转及闭案欠账兑付集。

### 采用姚扣根的 45 分钟片段结构时

仅在明确采用 45 分钟单集口径时启用：开场约 **3 分钟**抓人，其后每约 **15 分钟**立一局部扣子与情节段（允许约 1 分钟上下弹性），集尾立大关子；逐段标问题与局部结算，不拖空预告。不选此集长绝不硬套。

### 悬念层级与延宕操作

四级分层控悬，不让同段堆满同等谜团：

1. **全剧问题：** 小问逐层开大问，或先果后因，或靠两人长期吸引与拒斥维系主轴。
2. **集尾问题：** 隔日播重空白与猜测；连看重已解之事留下的明确后果与兑付集；双播兼顾。
3. **段落问题：** 一解即立新问，多线不齐追过多同等谜团；倒计时须实限行动。
4. **开场问题：** 直入进行中事件给足观看理由，背景融进当下行动。

**五种延宕（每次必改风险、选择或预期，不做干拖）：** ①乌云渐聚、越解越糟；②紧张顶点中断并及时回原压点；③大行动拆成连串小难题；④扩社会或心理维度添新人物与阻力；⑤交替调强弱、快慢、范围与明暗，喘息后拉回主线。

## 第三步：改编成长剧时保留承重项、重做容量

先判原作类别再选扩容手术：

| 原作类型 | 扩展重心 | 必查红线 |
|---|---|---|
| 小说/长篇 | 取舍内心独白，外化为命运、关系与行动 | 分清原作事实与新增因果，篇幅不等同集数 |
| 电影 | 有限事件拆为持续选择与关系变迁；仅原跨度与事件链撑不起集数时重做结构 | 逐段标保留/删除/改写；检原高潮能否生发全剧 |
| 传记/真人 | 精选阶段与核心事件，标明必要虚构与合并 | 严格区分史实、推测与虚构 |
| 舞台作品 | 延展台外人物命运、行动空间与关系后果 | 本级只管长篇系列结构，单场转换回父级 |
| 海外剧集 | 提炼跨文化核心承诺，再本地化关系与规则 | 替换后验证原故事引擎仍自转 |

**改编六步手术：** ①一句话概括原作、数清主角/主线/跨度 → ②锁不可弃的主题、人物与关系锚点 → ③做逐段手术表（原段—保留/删除/改写—新因果—下游影响）→ ④容量不足组合四法：扩副线、延人物命运、增主角或关系网、赋次角独立相连功能 → ⑤新增人物须改至少两人选择、具可重复功能且删之断因果 → ⑥双时间线各自成立、篇幅均衡，靠共物/共地/共动作转场，一线新证改写另一线理解。

**改编标尺：** 《杜拉拉升职记》扩职场、爱情、家庭三线并改前女友为前妻立强对抗；《马文的战争》以房子作长期稀缺障碍串多集戏眼；《亮剑》取小说前段拆四板块、李赵楚三角塑人且对手提前出场；《神话》借逐段手术表重造容量与类型承诺。

## 第四步：接收文件链、验收与返回父级

按合同或接收方模板定交付层级，衔接[生产/评审文件链](../../references/series-and-production.md#production-path-document-chain-and-current-requirements)与[剧本格式与交付](../../references/script-format-and-delivery.md)；将第二步的戏眼、行动、结算与下集承接带入分集梗概，确保编号可溯至集场。集长、字数、合规与备案口径以当期接收方与现行要求为准，未核项留待查不阻塞创作。

与[系列开发](../laohu-script-series/SKILL.md)并用时，系列开发管通用形态、引擎、Pilot 与季弧，本级管国产长篇结构、集—段—场、改编扩容与国内接收链。结果带回[父级主流程](../../SKILL.md)：改编缺口与承诺回阶段一，长线结构、单集戏眼与分场回阶段二，正文回阶段三，自审与接收交付回阶段四。

**验收：** 一案选点清晰；每集戏眼、行动与状态变化明确；所选 45 分钟节点与四级悬念落地无空钩；集尾收煞生下集因果；无人物顺撇；改编手术表分清源事实与新增；交付贴合当期接收方。
