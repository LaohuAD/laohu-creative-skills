# 国产剧集实践：长篇关系落到每集行动

## 触发与本级承诺

用户说“按国产长剧的路子写”“用国产剧集的办法拆分集”，或明确要按国产长剧/国产剧集实践创作、安排长篇分集、改编成长剧，或为具体国内接收方组织剧集材料时调用；不要求先懂“戏眼”“集—段—场”等术语。只因中文对白、中国人物或中国故事地点不触发本方法。创作路径和生产交付路径可分开或并用；以合同、平台当期模板或用户明确选择的结构方法为先。

本级固定采用长剧的观察视角：主要人物在社会/家庭/职业关系中怎样持续作选择；本集的**戏眼**是什么、行动如何改变局部状态；集尾如何完成本集的收煞并留下有因果的下集理由。国产剧并非一套唯一配方。本级保留姚扣根、张巍等作者对电视剧结构和接收方式的不同论述，先选择适合当前作品的一支；选定之后，该支适用范围内的步骤和模板固定执行。

## 第一步：选择创作分支、集间容量与结构立场

### 创作还是交付

- 要写故事/分集/人物命运：进入“长线创作”路径。
- 要按原作扩为长剧：先进入“改编扩容”路径，再回创作路径逐集组织。
- 要项目书、分集梗概、分集剧本或制作表：进入“接收文件”路径，先问谁接收、要作什么决定、模板/字数/版本怎么规定。
- 两类都要：先定故事选择，再映射交付字段；不能让文件模板替作者作剧情决定。

### 一案占几集：必须选点

将单元/事件的跨度放在一条具体光谱上；以下是旧实务模板的取舍，不是当代所有项目的集数标准：

| 选择 | 得到 | 代价 | 优先考虑 |
|---|---|---|---|
| 1集结一个单元 | 任意集进入、重复观看和单元满足；适合稳定行业流程、情景喜剧 | 人物若完全归零，长看会重复 | 二轮/单集闭合重要；但需写出关系或能力如何扩展 |
| 2–3集一个事件 | 一个小单元先满足，再留人物/关系长线 | 24集大致只有约十个完整事件，题材来源需够 | 需要单集收束和连续变化并存；可配“后果账本” |
| 4–6集一个板块 | 有空间把事件写到情感后果，适配慢变人物/关系群像 | 开篇容易迟缓，需更早立主问题与局部扣子 | 家庭/群像/长篇改编；先验证开篇是否让观众看懂长线价值 |
| 全季/全剧一案 | 连续压力最强 | 单集单看难成立，重复观看与中途加入不利 | 迷你/限定型或事件本身足以不断改变关系；需逐集有局部任务 |

决定顺序：①算来源能供多少种真实冲突；②估人物改变需要的时间；③看接收/播出形态是否需要任意集进入或连看；④选择跨度并写清收益、代价。若采用“闭案+后果账本”，每个单元先真正结案，再标明留下的关系/资源/承诺欠账在哪一集兑现。若用三轨制，逐集标 A（本集结算）、B（跨若干集）、C（全季）各自状态；不能只列线名不写变化。不要不表态，让 24 集一半像单元剧、一半像纯连续剧。

### 结构方法的分歧不能抹平

姚扣根的材料以“集—段—场”、情境—行动、段落收煞、悬念接力和人物持续处在生活情境中为重要观察法；张巍《电视剧改编教程》强调面向观众的篇章安排、关系冲突、主题表达和改编的结构手术。它们与美式 ACT/广告段落不是同一组单位。按当前文本/接收任务选择：国产长剧写作先用集—段—场与戏眼；用户明确要求美式 broadcast spec/act sheet 才另做 ACT/act out；不把页数当跨语言、跨时长的换算常数。

选择姚式情境方法时，每个情境先建立限制人物的规则，再让人物在规则里持续行动；把若干不同情境复合成全剧，每个新情境须改变旧局面，不能换地点继续同一争吵。书中“复合 4–5 个不同情境、其中一个中途变形”是该写作模型，不是每部剧集数/场景配额。

## 第二步：把人物命运落实成单集戏眼

对每集按以下顺序写：

1. **长线状态：**主要人物各自要什么、依赖/牵制谁、哪条关系不能轻易退出；标出上集末到本集初的状态。
2. **本集戏眼：**用一个具体问题写“本集观众最想看哪一个人物行动/关系判断如何发生”。主题词、宣传句、最大场面都不能替代戏眼。
3. **触发与行动：**事件触动哪些后继事件；谁采取什么具体策略；利益关系和情感关系是否互相牵扯；冲突既合乎因果，也凸显想写的人物面向。
4. **集内段落：**每段有局部目标、阻碍、策略变化、段末状态/扣子。不要先切成固定幕数；按故事从一个情境转到另一个情境的原因分段。
5. **集尾收煞与承接：**先结算本集戏眼，再决定以新压力、决定未竟、关系变化、情绪余波或悬念收尾。下一集理由要从本集行动产生，不能只在最后添一句预告。
6. **集间账本：**标明哪些线推进、受挫、保持、转向；若案件在本集结案，记下哪个后果将在何处兑付。

被动主角不自动等于没有行动。采用姚扣根关于“在被动中保留欲望”的人物路线时，每集写清主角不能决定什么、仍选择了哪一个动作（忍耐、辩解、恐慌、求助、拒绝等）以及它怎样影响关系。若纯被动只承受事件且不改变局部状态，才需要补主动行动或重新审视结构。

### 采用姚扣根的 45 分钟片段结构时

这是明确选用特定长剧时长模板时的固定分支：姚扣根《电视剧写作概论》（2016）提出开场约3分钟抓住观众、其后每约15分钟形成一个局部扣子/情节段，集尾再立一个大关子。其原意不只为旧广告位；姚将约15分钟视为片断戏剧结构的内在节点，并写明45分钟框架下时段“最多一分钟上下”可灵活。选择此模板后，必须逐段标问题与局部结算，不能把段末钩子拖成没有兑现的预告；不选该时长/模板时，不把3/15分钟强加到短剧、半小时喜剧或平台自定义集长。

旧书的45分钟电视集计算包含片头/片尾，正片约41分30秒；片头通常60–90秒、片尾120–150秒。只有项目当轮确实采用该时长口径时，才以约41.5分钟正文分配段落，并将当前委托模板作为最终值。文中所有这些是2014–2016年前后的教材/制片口径，不是现行平台事实。

### 悬念层级与延宕操作

选用姚式片段结构时，按四级检查，而不是每一段同时堆谜团：

1. **全剧问题：**由一串可解决的小问题逐步打开大问题，或先给结果局面再回溯成因；系列型作品也可把两人持续吸引/拒斥作为长期问题。
2. **集尾问题：**先看首播/连看方式。若观众要隔日等待，集尾可利用叙述空白与猜测；若可连续点播，不依赖“隔夜惦记”，而写明本集已解决的事留下哪笔后果、由哪集结算；同步播出两种观看都要顾及时，同时给悬念和后续兑付线。
3. **段落问题：**一条线解决一个问题后立即提出下一个；多线可并存，但不要让观众同时追九个同等谜团。若需倒计时，时间限制必须可见且在行动中起作用。
4. **开场问题：**直接进入事件进行中，先给观众一个明确观看理由；必要背景穿插在行动里解释，不从头讲家史/制度沿革。

五种延宕方法（姚扣根）：①乌云逐渐聚集，让问题越解决越严重；②紧张时中断并及时回到原压力点；③把一个大行动拆成多个小问题；④扩展社会/心理层面，引入新人物或新因素，但每项都须增加阻力；⑤交替改变强弱、快慢、范围或明暗，让观众获得呼吸后仍回到主问题。延宕不是拖延信息：每次都要改变风险、选择或观众预期。

## 第三步：改编成长剧时保留承重项、重做容量

先识别原作是哪一类，再选改法：

| 来源 | 扩展重点 | 不可省略的检查 |
|---|---|---|
| 小说/长篇文字 | 取舍内心叙述；扩展人物命运、关系和外部行动 | 哪些是原作事实，哪些是影视新增因果；不能把篇幅照搬当成集数 |
| 电影 | 将有限时长事件拆成持续人物选择与关系变化；必要时重做时间跨度/结构 | 逐段标保留、删除、改写；原电影高潮是否足以生成全剧而非只被拉长 |
| 传记/真实人物 | 挑时期、事件与人物阶段；必要虚构与合并要有标识 | 史实、推测和虚构分开；权利人与事实边界不冒充戏剧事实 |
| 舞台作品 | 发展舞台外的人物命运、行动空间与关系后果 | 本级只处理系列结构；具体舞台/影视片段转换走父级跨媒介方法 |
| 海外电视剧 | 判断要保留的核心承诺，再本地化人物关系、规则与社会环境 | 不照抄旧书关于播出制度/市场的时代判断；替换后仍能跑原故事机制吗 |

统一改编步骤：①一句话概括原作，数出主角、主线和可用时间跨度；②定不可放弃的主题/人物/关系锚点；③列“原段落—影视保留/删除/改写—新因果—下游影响”；④若容量不足，选择扩副线、延展人物命运、增加主角/关系网、给次要人物独立但相连的功能之一或组合；⑤新增人物要能改变至少两位原有角色的选择、具可重复功能且删掉后会使某条因果消失；⑥双时间线分别能独立成立，长度不过度失衡，转场有共同物/地点/行动母题，且两线内部因果相通。

### 真实改编案例与迁移边界

- **首尾落点与集义：**姚扣根记录《北京人在纽约》首集从王启明听到“美国欢迎你！”开始，到听见“你给我打工！”结束；书中分析两句之间由地点转换逐步抬高、再压低主人公感受（《电视剧写作概论》，2016，第250页）。迁移时先定人物真正听见的起点和终点，再让每段行动为同一个集义服务；不是规定每集都要重复原句式或做反义台词。
- **《杜拉拉升职记》：**张巍记录的30集版本把不足20万字职场小说从“职场宝典”转向杜拉拉成长故事；原作单职场线扩为职场/爱情/家庭三线，并把杜拉拉升职阶段拉长。将黛西由前女友改成前妻，使对抗有社会关系基础；新增人物服务新关系线。可迁移机制是发现原作容量与电视剧容量差距后重写因果和人物关系，不是必须套“三线”或当前市场卖点。
- **《马文的战争》：**3万字中篇、6个角色扩为24集家庭伦理剧、11人关系网；“房子”作为可持续障碍，把再婚、居住和家庭关系绑成事件链。可迁移机制是用一个长期资源冲突连接每集戏眼；新增人应进入既有关系因果。该书删除婚外恋等内容的产业理由属于当年规则环境，不作当前审查指引。
- **《神话》：**90分钟电影改为50集剧版，旧教程以逐段标记“复制/删除/改写”和将现代故事机制迁到古代类型世界为分析重点。可迁移的是先做段落手术表、再检验扩展后的类型承诺；不是电影到剧集必须扩大到特定集数。
- **《铁梨花》：**张巍以原小说为基础重新安排主题表达和人物关系；其讨论可用来检查主题怎样进入人物冲突和事件因果，而不是只写主题宣言。主题替换后要核对哪些关键人物动机随之改变。
- **《亮剑》：**剧版只采用小说前段内容并安排四个时期板块；李云龙、赵刚、楚云飞组成三角关系，工作/敌友、性格/阵营、磨合/熟悉、合作/合作多种连线让两位“反作用力”改变主角；首集直接从战斗行动塑造李云龙，非先讲前史。可迁移的是人物网络结构、重要对手提前出现、按关系重心转移安排板块；旧书记录的审查背景不用于当前法律判断。
- **《梅兰芳》40集方案：**教材讨论主题/性格设计，但该版本未投入制作。可用于分析名人改编的设想和风险，不能列作已验证成功案例或市场结果。

## 第四步：按实际接收者选文件链与版本

国内剧集不存在由这些旧书共同证明的唯一文件链。对方合同/模板优先；没有模板时，按接收者选择一条并标明这是临时采用的项目结构。

| 接收任务 | 可选来源模板 | 关键成品证据 |
|---|---|---|
| 先看项目概念 | 姚扣根的情节概要/创意说明；短项目概念 | logline、主要人物、冲突来源和可持续理由，让读者能判断项目讲什么 |
| 评估整季/全剧 | 张明智的故事大纲/总体梗概；姚的情节流程 | 起点、主要关系、事件因果、关键转折与终点状态；情节流程具体交代时间地点、触发后继事件、人物动机/过程/结果 |
| 决定分集安排 | 张明智的分集梗概，每集有可指认的“戏眼” | 每集戏眼、行动、局部结算、下一集承接；多人合写时能保持同一关系和因果 |
| 审读正文 | 分集剧本或指定集场稿 | 事件、表演行动、台词和版式达到本次收件要求 |
| 进入制作/修订 | 实际合同中的分批剧本、修订/场景表等 | 版本、责任人、修改范围和待定项清楚；分镜头文件只有实际需要时才制作 |

姚扣根书列的策划六件可按委托取用：情节概要、人物设计、主要场景、创意说明、情节流程、样本剧本；书中没有把“分集大纲/分场大纲”规定成同一标准链。张明智的评审链是故事大纲→分集梗概→分集剧本→分镜头本（其书指出当时国产电视剧通常很少正式分镜）；合同样本另有创意→总纲/人物小传→分集梗概→分批剧本→整体定稿。三链并列是为匹配不同接收任务，不得混成一次性全套交付。

若制作需要选中文剧本版式，四种旧书样本是影声分离、舞台剧格式、电影剧本格式、电视小说格式；先按读者与制作流程选择一种，全篇一致。场景表是制片/场记用途，不等同创作分场大纲。修订期间采用具体接收方编号规则；旧张明智样本里的 19A/19B 与删除 66 仅在目标文件兼容时使用。版式通则由父级[剧本格式与交付](../../references/script-format-and-delivery.md)负责。

## 数值、时效与来源标记

下列数值只能在明确采用旧书同一类长剧/交付口径时作为起稿基准；不从历史教材推出当前平台标准：姚/张材料的45分钟上星长剧模型含片头/片尾、正文约41.5分钟；对白为主的旧样本约370–400字/分钟，动作/反应较多约270–330，另一组长剧统计约300–370；单集20–40场、常见25–35及对白占比超过50%属于该教材/长篇制作样本，不覆盖当前剧本合同。每次使用先注明“总时长是否含片头尾、采用哪个字数/场数样本、当前合同字段是什么”。短剧、单机喜剧、电影型项目按实际长度与文本密度重算。

同理，张巍对“30集电视剧至少约40万字”、对白占较大比例的数字，张明智对45分钟集总字数约1.6–1.8万字的例子，也只作为其长篇剧本开发语境下的容量参照；和每分钟字数范围一样，先按真实集长/正文时长换算，当前委托明示字数时不以旧数覆盖。旧书里的法规名称/机构、播出惯例、平台买方、制作期、市场表现、合同范本与版权法版本不作为现行事实。需要当前备案、审查、平台或合同要求时，按当前日期和实际接收方查证；未查证就把它留作待核，不影响已经选定的创作方法。

## 专业来源与返回父流程

本级主要转写姚扣根《电视剧写作概论》（2016）中的情境、行动、戏眼/段落、悬念与策划议题，张巍等《电视剧改编教程》（2014）的长篇改编、人物关系和容量处理，以及张明智、宋培义《电视剧出品人与制片人教程》中开发文件/接收链讨论。作者主张、书中作品事实、对作品的分析和本地综合执行方法分开标注。涉及《梅兰芳》的未投拍稿、旧法规和旧行业数字时，限制所能推出的事实范围，不因此取消本分支的创作选择。

故事材料/改编缺口回父级第一步；系列形态、长线结构和关系组织回第二步；单集戏眼、段落与场次回第三步；仅在用户要求时于第六步组织项目/分集文件。与[系列开发](../laohu-script-series/SKILL.md)并用时，系列开发管通用连续性形态、引擎、pilot和季弧；本级管本土长篇方法、集—段—场与国产接收链；情景喜剧另叠加对应方法。

**验收**：所选连续性和“一案几集”明确；每集能指出戏眼、行动和状态变化；所选45分钟模板的段落节点按条件出现；集尾能结本集并给下集因果；人物命运线有关系后果；改编手术表区分源事实和新增；交付字段有当前接收依据。未满足时回到对应的结构/关系/容量决策，不用增加格式文件掩盖故事缺口。
