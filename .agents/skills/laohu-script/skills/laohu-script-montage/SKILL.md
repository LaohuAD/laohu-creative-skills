# 视听证据、蒙太奇与剧作转场

沿用 laohu-script 传入的范围、观看任务、视角、事实与时间关系。适用于长时段要压缩成有进展的动作、不同线索要交织、反复出现的可见物件要承担关系变化，或前后场的接法会改变观众期待的段落。只做格式、固定单场连续对话且无上述任务时，沿宿主通用路径处理。

接到材料先确认三件事。前段给了观众什么事实或期待，人物各自的行动已走到哪里，后段第一件必须让观众看懂的事是什么。遇到画面只剩听人讲述的段落，先找可以被动作、位置或物件变化提供的证据。台词仍承担只有说出来才能作用于别人的要求、遮掩、试探或决定。

## 用物件或空间状态追踪变化

1. 从故事里选一至两项本来就在被使用、等待或回避的物件或空间状态，写清谁能接触、谁能看见，及它此刻怎样参与人物的事。
2. 用一次有效动作建立初态。中段让使用、归属、位置、完整性或可见方式因行动结果改变。终局在相同的观察依据上兑现变化，可以换人使用、改变原用途，也可以留下观众能辨认的末态。
3. 把变化写在对应场次的行动中。前后只要重复外观却无新影响，就合并重复。身份连续性不清时，回查是谁挪动、取得、丢失或改变了它。

## 按观看需要选取时间组织

| 段落要完成什么 | 写作动作 | 段落应交出的东西 |
|---|---|---|
| 压缩进展、准备或等待 | 写清起态，选三至五个能看出阶段跨越的短动作。每片给一个时间或状态依据与变化结果。相邻切片没有新增进展、代价、能力或关系时合并。按实际幅度调整数量。 | 读者能从中间变化推到末态，末态改变人物下一行动或观众等待。 |
| 对照两方处境或情绪 | 先选共同的比较轴，例如同一任务、物件或行动被怎样处理。分别给出前后可见证据，并决定先露哪一边、后露哪一边，会让观众理解什么。 | 比较由可辨的共同点成立，并置产生新的关系判断或情绪。 |
| 让双线或多线交替接近汇合 | 给每条线独立目标、起态和进度依据。先钉住共享时间、条件或即将抵达的同一事件，再按各轮的时间余量、知情或行动后果决定回到哪条线。最后写清同处一地、信息送达或一线结果改变另一线的确切瞬间。 | 读者能辨认各条线的时空与所知，交替获得新的压力或期待。若时间并非同时，给出足以理解先后的信号。 |

时间压缩和交替可结合。先对齐各线的阶段与汇合标志，再筛各轮片段。任一线只显示相同状态、或者移去整个交替也不改变读法时，删去该切换或重排顺序。

## 写出前后场的接点

| 需要的效果 | 前场末端与后场开端怎样接 |
|---|---|
| 让同一个动作或物形跨过时空变化（Match Cut） | 前场留下可认动作、姿势或形态，后场立即出现足以认出相似之处的动作或物形，并露出人物、地点、时段或用途已经改变的依据。 |
| 先听见后场，或让前场声音留到后场（J-cut / L-cut） | 写清声源属于哪一场、从哪里先听见或停在哪里、画面何时对应到新的时空。若是人物可听见的现场声音，同时交代谁听见、如何回应。 |
| 用前后的可感落差制造对照（Contrast Cut） | 从前场已建立的期待、态度或秩序，直接接后场反向的具体动作或状态。选共同比较轴，使落差本身能传递信息、笑意或判断。 |
| 在高点打断预期（Smash Cut） | 来到断言、动作或声音即将完成的一刻，让紧接的另一场立刻改变观众的预期或情绪。保留理解跳转所需的最小依据。 |

只选对读法有作用的接法。正文写实际发生的声画和场界，摄影机、镜头参数和逐镜实现由制作用途的下游处理。

**回接宿主。**给出涉及的序列或场次、各可见状态、时间或对照依据、交替或转场的具体两端、末端交给下一场的行动或知情。阶段二消费结构与分场预算，阶段三将有效的画面和声画写进正文。复查只读 `△` 时承重画面与前后状态能否接上，有声音接力的地方另查声源与起落。确需与动作场面或世界规则配合时，由宿主统一决定切换次序和规则显露，本模块处理已经交来的行动与状态。
