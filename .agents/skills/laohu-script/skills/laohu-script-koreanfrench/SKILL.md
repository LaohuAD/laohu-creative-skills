# 韩国 / 法国编剧实践：选定讲者路径，按该路径写成稿

本配置汇集同一本大师班材料中的三位讲者，不表示三人共有一套韩法风格。吴胜郁先让日常行为、空间和情绪搭成故事；崔石焕先确定类型对观众的承诺，再用欲望和危机推动质变；弗雷德里克·奥比坦先完成场面与结构，后写对白，并关注读稿、拍摄和剪辑。选择其中一条主路，别把三者平均成一组可选技巧。

## 触发与作者未知时的选择

用户说“韩剧那种写法”“按韩国编剧的路子”“法国编剧那种写法”“法式创作办法”，或点名吴胜郁、崔石焕、弗雷德里克·奥比坦及其作品/方法时启用；普通表达足以表明选用方法，不要求术语或讲者姓名。韩国或法国地点、角色国籍、语言、题材、社会问题本身不触发；用户明确说不要采用该地域方法时尊重排除。比较作者时解释分歧，不替作品选风格。

用户已点名讲者，直接按其分支写；用户只说韩国方法、不知作者时，抽象情绪、空间 / 生活细节或首尾关系不成立，默认吴胜郁；类型承诺、欲望危机、质变、第二次反转搜索或结尾代价不清，默认崔石焕。用户只说法国方法、不知作者时，结构行动、知情次序、对白过早或剧组交接是瓶颈，默认奥比坦。不反复追问人名。信号并列时说明主路及其代价，只在作品方向会因此改变且材料不能定夺时问一项。

## 吴胜郁：生活行为、空间和情绪先行

### 选定信号

用户点名吴胜郁，或所选韩国路径的主要任务是让抽象情绪变成可演、可看的生活细节。只有病痛、悲伤或社会现实题材不足以触发。

### 固定创作顺序

先研究具体生活行为和空间，再写首尾画面，然后用中间行动解释人物为何从首场走到末场。把情绪词换成角色会做 / 不做的事、物件如何处理、谁靠近或避开谁；场景空间的变化必须改变行动可能、生活资源或关系位置。三幕按情绪起伏划分，不平均分配；过渡疲劳先找角色关系和情绪纠纷，不靠加桥段。声音、动作和物件带出情绪，形容词不能代替场面。

若需要真实采风，必须使用公开材料、公开空间或获准访谈。旧讲授材料提到假扮剧组人员、卧底和潜入采访；这是来源叙述，不是本轮授权，也不写成可执行指令。保留“仅靠想象不足以替代生活细节”这一判断，按授权边界适配取材途径，并把未核事实标成待查。

### 作品案例与成稿验收

《八月照相馆》写洗钢笔、给父亲写录像机说明书等日常动作，而非把患病人物写成持续悲伤；访谈中半夜煮拉面、骑车、和妹妹吃西瓜打闹等生活状态帮助修正单一刻板想象。《无赖汉》三次搬家让女主从较好的公寓迁向追击后的住所、再迁往郊区贫民区；空间条件就是处境的骨架。结尾远看像相拥、近看却是女人持刀刺向男人，观众的情绪依赖画面信息而非解释。《双生警贼》先想好雪地中将死男子与跪在旁边者的首尾画面，再拼中间结构。

验收时看情绪是否落实为行为、物件、声音和空间关系；首尾画面是否由中间选择挣得；每次换空间是否改变了人物的处境。首尾画面只是漂亮构图而未被行动支撑时，回去补中间关系，不用情绪旁白代替。

## 崔石焕：类型承诺、欲望和危机的质变

### 选定信号

用户点名崔石焕，或作品主轴是明确类型故事，而观众承诺、主人公欲望、持续危机、人物代价、质变转折或结尾尚未成立。纯现实 / 情绪题材不自动套类型模板。

### 类型承诺与固定创作顺序

1. 先写观众从海报、宣传和买票时进入作品所期待的主要类型体验，再定结尾与高潮解决方式。喜剧不能在结尾无故停止兑现喜剧体验，推理不能忘掉推理主轴；混搭要分别充分履行承诺并维持统一基调。
2. 课堂记录把允许创新讲成约 5–10% 的小幅偏移。这是崔石焕具名教学中的类型约束，不是韩国类型片国别定律；选定此路时，说明哪一项是主类型承诺、哪一项创新仍落在承诺范围内。若创新会改写承诺，指出实际损失，不能称作无代价修饰。
3. 每阶段并列写外部危机性质、人物欲望、持续恐惧、应对策略和选择代价。危机与欲望须一起升级；转折要改变人物能做什么、必须失去什么、对手关系或处境理解。敌人数量 / 规模变大但策略与局面未变，只是量变。
4. 主角即使只过一晚，也要有可见的性格 / 选择质变。标出他愿意冒什么风险、付出什么代价；配角有自己的欲望和生活，不只是给主人公递信息。
5. 高潮后的结尾用动作 / 画面表现主旨，检查是否需要心理余波；不让主人公在咖啡桌旁复述主题。结局应让所得与代价相称，并留下该类型能承受的情绪回味。

### 第二次反转的搜索与比较

旧课堂记录的原意是“只有一个反转不够，竭尽所能挤出想象力让结尾变成两个反转”，同时明确警告不能为反转而反转。采用此路径后，每稿都必须做第二次反转的搜索：在初始危机已有解决方案后，提出可能再次改变局势 / 人物选择理解的转折，比较它是否由前事支持、是否带来质变、是否仍兑现类型承诺，并检查需要在前文埋下什么准备。

这是必须执行的创作工作和强烈的结尾追求，不是机械规定每个成稿都必须出现两个反转。若找到有因果的第二次变化，就补好前置证据并写进结尾；若所有候选都会无因硬造或破坏用户已锁定的类型 / 结尾，不强塞伪反转。仍须说明搜索过的候选、因果缺口和保留单次反转的损失；不能把第二次搜索静默标成可选而跳过。

### 课堂案例与成稿验收

“外婆的童话”中，老虎与糕点的危机从糕点成为祭品质变为母亲也将成为祭品；第一次解围靠天降绳子，随后再落下一根绳子构成第二次转折，最后留下 bittersweet 味道。它展示的是危机质变、两次转折如何被具体因果支撑、解决后的情绪余味，不要求把老虎、绳子照搬到别的故事。《港囧》的癌症父亲帮家人圆梦原型被调整得更喜剧化，说明改变类型承诺会改变观众体验，修改前要写出得失。

成稿验收要看主类型是否从开场到结尾持续兑现；每次危机是否改变处境而非只放大数量；主角是否有可见质变和真实代价；是否完成第二次反转搜索、比较和因果准备。搜索结果可以是不采用候选，但不得跳过过程或把失败候选伪装成成立的结尾。

## 弗雷德里克·奥比坦：场面与结构先行、对白后置、贯穿制作

### 选定信号

用户选择奥比坦 / 法国编剧实践，或对白先写导致行动不清、人物 / 观众知情混乱、场景缺必要性，或本轮确实需要编剧参与读稿与制作协作。法国地点、法语台词或艺术电影题材不够触发。

### 场面结构、视点与对白的固定顺序

先写事件初稿，再按场景检查结构和必要性，最后写对白。每场列清目标、进场条件、动作、阻力、策略变化和离场状态；然后从作者 / 观众 / 主人公三种视点检查隐情、信息来源和知情差；最后写对话和潜台词。先让行动、物件和画面建立场面的事实与关系，再检查对白有没有替作者向观众复述已见内容；人物借相同的物件或空间发出命令、玩笑、回避、试探、拒绝或侧面描写时，对白本身就是行动，按人物目的保留。需要补上的社会事实和人物理解，放进该人物实际会采取的表达或其他合适的叙述通道。给人物制造不幸可以成为喜剧情境来源，但喜剧要靠行动和节奏，不只靠机智台词。

原讲授中的“只要 12 句，不要 13 句”是对白压缩练习，不是对所有场景设的固定句数。高声朗读检查节奏、停顿和可说性；未组织真实围读时，不把单人朗读写成演员反馈。

### 编导协作与围读

需要协作时，编剧工作延续到写作、筹备、拍摄和后期：预判现场问题，保留意图和修改记录，实际围读后再据反馈改稿。意大利式围读可以用 2–3 天逐场读完全稿，连标题、附注和时间场景一起读并录音，按场回听以检查整体结构和声音。导演或制片提出意见时说明它如何改变观看效果及损失；别把结构错误都推给剪辑阶段。全片结尾风格须一致，让人物有尊严，不靠羞辱人物完成道德判决。

### 作品案例与成稿验收

《偷情桥》的早期结尾是妻子跳桥、丈夫救起并以焰火收束，后改为两人各自离开；新结尾更符合全片风格，也让人物保有尊严。《巴黎，我爱你》由 20 位导演各拍一段，初剪过长、接续困难、巴黎和主题不清；奥比坦与剪辑师提炼情绪主线，再经过 82 次排序，先按情绪而非外加故事逻辑寻找全片次序。若使用这种集合式结构，情绪主线是固定骨架；每次改序仍复核人物事实与观众能否理解。《特使》让两名前线记者藏在巴黎朋友家，用噪声使听者误以为他们身在伊拉克，随后又伪造人质录像升级处境。按奥比坦落笔时写清制造声音的人、误听者收到的证据、误信之后采取的行动及场面离场状态；否则误解只是作者扣信息。其观看残酷影像后对伦理边界的反思不能被误作极端表达或现实取材授权。

成稿验收对应实际选择：对白确实晚于场面结构，信息差有来源，读稿反馈是真实发生的制作证据；若采用集合式结构，情绪主线能解释片段排序，结尾与全片风格相配。

## 明确组合与返回

韩国两个分支不是同一风格：吴胜郁负责生活、情绪和空间证据；崔石焕负责类型承诺、欲望 / 危机、质变和结尾搜索。明确要并用时，先说明谁决定全片体验、谁负责场面证据。可组合“崔石焕定类型 / 危机轴，吴胜郁把情绪变成具体行为和空间”，但若结局会破坏类型承诺，不能声称两者自动兼容。

法国方法与韩国方法也只在用户明确要求比较 / 组合时并行。它们处理不同维度时标出工序，例如先按崔石焕确定故事承诺，再由奥比坦做场景行动、信息顺序和对白；同一场戏不要同时遵循福田式先试正式台词与奥比坦对白后置，除非明确把前者限定为探索素材、定稿后重写。

把本轮所选讲者、触发信号、被锁定的创作顺序及来源案例带回父级：故事类型和总体方向回第一 / 二步，场景空间与行动回第三步，视点、对白和声音回第四步；实际读稿修订回第五步，最终格式由父级第六步决定。
