# 韩国 / 法国编剧实践：选定讲者路径，按该路径写成稿

本级汇集三位起点迥异的讲者，绝不平均成泛化韩法风：吴胜郁从生活行为、空间迁移与首尾画面起笔；崔石焕以类型契约、危机欲望质变和二次反转搜索立轴；弗雷德里克·奥比坦先定场面结构与三视点，最后写对白并贯穿围读制作。按材料选定一条主路执行。

## 触发与自动选路

用户要求按韩国或法国编剧写法创作，或点名吴胜郁、崔石焕、弗雷德里克·奥比坦及其作品方法时启用；无需先懂术语或人名。仅有韩法地点、国籍、语言、题材或社会议题不触发；用户明确排除时尊重排除。

- **点名直入：** 指定讲者即直接走对应路径。
- **未指人名按瓶颈自动选路（不追问人名）：**
  - 韩国写法且卡在抽象情绪、生活空间细节或首尾关系不立 → 默认**吴胜郁**。
  - 韩国写法且卡在类型承诺、欲望危机、质变、反转搜索或结尾代价 → 默认**崔石焕**。
  - 法国写法且卡在行动不清、知情混乱、对白过早或剧组协作 → 默认**弗雷德里克·奥比坦**。
- 仅当两路冲突实质改写方向且材料无法定夺时，才向用户确认一项取舍。

## 吴胜郁：生活行为、空间迁移与首尾画面先行

**适用信号：** 需把抽象情绪落成可看可演的日常行为与空间处境。

1. **生活与首尾画面先行：** 先研具体生活行为与空间，再定**首尾画面**，最后用中间行动解释人物如何从首场走到末场（《双生警贼》先定雪地首尾画面再拼中段）。
2. **行为与物件替代情绪词：** 把情绪全部换成角色做或不做的日常小事、物件处理、身体距离与声音（《八月照相馆》借洗钢笔、写录像机说明书、煮拉面与独自落泪立人）。
3. **空间迁移即处境骨架：** 每次换空间必须实改行动可能、资源或关系位置（《无赖汉》三次搬家由公寓迁至郊区贫民区，结尾借观察距离改写观众判断）。
4. **情绪三幕与中段提力：** 三幕按情绪起伏而非等长划分；中后段（约 60–70%）若现过渡疲劳，先从情绪纠纷与新行动找力，不靠堆桥段。结合公开观察、公开资料或获准访谈采细节（未核标待查）；被要求删珍爱场次时，先判能否移位或明示删去的情感损失。

**验收：** 情绪落进具体行为、物件、声音与空间；每次空间迁移改写处境；首尾画面由中段选择挣得。

## 崔石焕：类型契约、危机与欲望质变及二次反转搜索

**适用信号：** 明确类型故事，但观众承诺、欲望危机、质变转折或结尾代价尚未成立。

1. **锁死类型契约：** 先定观众买票期待的核心体验，再定高潮与结局（喜剧不中途熄火，推理不丢主轴；混搭须各自履约并统基调）。创新落在主承诺容忍内（课堂经验约 5–10% 偏移），触及主约须明写体验得失。
2. **危机与欲望同步质变：** 每阶段并列外部危机、人物欲望、持续恐惧、策略与代价；升级须改变人物能做什么、必失什么或处境认知，仅增敌人数不算质变。
3. **角色质变与相称代价：** 主角即便只历一夜也须有可见性格或选择质变与相称风险；配角各有欲望与生活。
4. **心理落点与类型余味：** 先定高潮后心理落点，结尾用动作或画面落主旨并留该类型承受得住的情绪回味；类型信息融进争执与行动。
5. **必做的第二次反转压测：** 初始危机获解后，后台**必须**搜索能二次改写局势或认知的反转候选，逐项比较前因支撑、质变力度与类型履约并查前文埋线（如外婆童话由保糕点质变为保母亲，两根绳落苦甜余味）。有因果支撑即补埋线落地；若候选皆硬造或破已锁结局，不强塞伪反转。大纲、结构或诊断讨论时，简述查过的候选、因果缺口及保留单次反转的代价；仅交付干净正文时留在后台，不污染正文块。

**验收：** 主类型首尾兑现；危机带来处境质变；主角有可见质变与代价；已完成第二次反转压测（讨论层写清取舍，正文层干净落地）。

## 弗雷德里克·奥比坦：场面与三视点先行、对白后置

**适用信号：** 对白先写架空行动、知情混乱、场景缺必要性，或需编剧跟进围读与制作。

1. **事件与逐场结构先行：** 先写事件初稿，逐场核清目标、进场条件、动作、阻力、策略变化与离场状态；舞台转影视按真实三维空间重写调度，强情绪后留呼吸。
2. **三视点严核知情差：** 从**作者 / 观众 / 主人公**三视点逐场核隐情、信息来源与知情差，并追踪关键配角何时获知、误解或隐瞒（《特使》写清听众凭何证据误判及离场状态）。
3. **对白最后落笔：** 先让行动、物件与画面立住场面事实，再写对白与潜台词；台词不复述已见，只留充当命令、试探、回避、玩笑或拒绝的行动对白。喜剧可借不幸处境与身体节奏生发。
4. **压缩与朗读：** 做对白压缩（“只要 12 句，不要 13 句”）须在锁死场面行动与应答功能后仅删真冗余，不伤自然中文；高声朗读核节奏，未围读不伪称演员反馈。
5. **围读制作与集合式情绪轴：** 编剧贯穿筹备、拍摄与剪辑，不把结构错推给后期；协作可用 2–3 天意大利式围读（连场头附注录音回听）核结构与声口。全片结尾守风格统一与人物尊严（《偷情桥》弃跳桥焰火改各自离开）。多片段集合式作品先立**情绪主线骨架**（《巴黎，我爱你》好奇/幽默 → 死亡/漂泊/孤独 → 升华/解决），每次改序仍核事实连贯与理解。

**验收：** 对白晚于场面结构；三视点知情差有源；结尾风格统一且保尊严；集合式作品情绪主线能解释排序。

## 组合裁决与返回父级

- **韩国双路：** 并用先定谁管全片体验、谁管场面证据（如崔定类型与危机质变轴 + 吴落行为与空间）；结局破类型契约时直接裁决，不伪称兼容。
- **韩法与跨路：** 分管不同工序标清先后（如崔锁类型承诺 → 奥比坦排结构、三视点与后置对白）；同场不可同时跑福田式先试正式台词与奥比坦对白后置，除非前者仅作探索原料、定结构后重写。
