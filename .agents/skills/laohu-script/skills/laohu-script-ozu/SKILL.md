# 小津/野田方法：家常照旧，关系已经变了

## 触发条件与范围

用户点名小津安二郎、野田高梧、小津/野田合作文本，或说“按小津/野田那种方式写家庭关系”，要求迁移具体作品的结构、对白或场面机制时启用；不要求用户先说“画外事件”等术语。只说家庭片、代际冲突、安静、日常、东方韵味或慢节奏不触发。方法可用于电影剧本及其他叙事媒介，但低机位、日文柱格式、原片页数和导演现场选择不自动搬入中文剧本。

## 定义性固定项：日常—重大事件画外—反应与余波

完整小津/野田式组织，把家庭关系的承重重大事件留在画外；画内写事件前的共同日常、消息/他人的中转、每个人的反应，以及人物继续生活时留下的空位、物件和行动。先建立谁照料谁、共同用什么空间、谁被留下；再让婚嫁、离家、丧亲、秘密或角色变动改变家庭位置；最后回到吃饭、收拾、通勤、遗物或同一空间的后续生活。观众从行为次序和空间变化读出情感，不由人物替观众总结。

完整风格要求列出所有足以改变核心关系或家庭位置的承重重大事件并移至画外；旧“最大三件事”练习要求至少把最重的三件全移出画面，每一件都写前场如何逼近、后场怎样留出事实。清单外若还有承重重大事件，也不能偷留画内。画内保留生活前因、消息传递、反应和余波。只有用户明确要求某一必要事件画内呈现时，才将那一项标为“完整方法的局部偏离”；其余画外事件与日常—关系—余波链仍按完整模板执行，不能把偏离说成完整实现。

单独选择一项技法不等于选择完整小津/野田风格：只执行该项的完整动作链，不自动强制全片结构。反过来，选择完整风格就不能把重大事件画外化降成一个可随手选择的技巧。旧六片是研究语料，不是每部都无例外遵循这一完整模式：《浮草》92–99场阿芳先打加代再打寿美子、105–117场驹十郎打阿清而阿清还手，都是画内暴力。分析原片时照实记录这些场面；本地完整风格仍须把承重暴力事件放画外，除非用户明示画内例外，并标记为局部偏离。

开放的是本作的关系、时代、家庭规模、事件种类、喜剧比例和具体声画方案；不要强行安排女儿出嫁、死亡、空镜或象征物，除非故事事实支持。低机位、日文柱格式、原片页数和导演现场选择不自动搬进中文剧本。

## 十五种独立技法：选中一项就完成它的完整机制

技法可以单独调用，也可以组合；每项标题表明它解决哪一个叙事判断。选择之后按该项的数量、次序、角色位置和落点写完，不以克制之名删步骤；未选的技法不自动变成整片配额。

### 1. 把每件承重事件放到画外，留出前因与反应

若选“最大事件画外”练习，先列最大三件事件，三件全部移出画面；完整小津/野田风格则把所有承重重大事件都纳入清单并画外化。婚礼、相亲、死亡、决定或暴力不直接演给观众，逐件写出前场如何逼近、后场用空座/空房、消息、人物归来或日常动作留下事实。缺前因或反应就补场，不用解释性台词替代。

### 2. 用一场可辩护的谎言推动离家或改变

选择谎言推力时，让推动者为促成选择说出善意或可辩护的谎；旁观者可以点破，也可以一直不揭。最后的家长表态须让真与假仍能同时成立。谎言必须造成一个具体行动或误解，不能只是反转噱头。《晚春》父亲谎称再婚推动纪子离开；《秋日和》老友替母亲编再婚，女儿把误解当真。

### 3. 连问三次，只让关键承认落成一个音节

选择最小音节练习时，围绕同一事实连续追问三次；关键承认/拒绝只用一个短音节，三问逐步加压，沉默单独占一拍。《晚春》周吉被连续问是否再婚，三次只答“嗯”；《麦秋》全家三轮确认纪子是否肯定。不可先完整剖白心理，再补一个“嗯”。

### 4. 让中转者加工权威指令和亲密消息

选传话练习时，主角与对象之间必须隔一个中转人；权威人物的要求经此人传达，误解、加工或担心说错引出喜剧/压力。每一轮转述都改变至少一人的知情状态。《晚春》姑母翻译纪子的“嗯”；《麦秋》康一躲在纸门后指挥嫂子怎么问。中转不能只作递台词的管道。

### 5. 让缺席对象由三条信息构成

选择“不出场的对象”时，对象不给脸，只给三条具体描述；可由照片、职业信息等承载，但须仍能构成三条可比较的信息。《晚春》佐竹被说成像加里·库珀等三种说法；《麦秋》真锅的照片看不清脸。三条信息应说明主角为何选择/拒绝，不把缺席当神秘装饰。

### 6. 用一两行可见空镜切开情绪段

选择空镜分场时，在情绪段之间放一至两行景物/空间事实，不写情绪形容词，也不解释象征；每一处都须切开时间、地点或关系阶段。空座、田、海、车站、门窗均可。《晚春》空剧场后接纪子独行，《东京物语》用空站台与海浪承接死亡。另起场号遵从当前格式。

### 7. 让一个物件或短语正好回响三次

选择“三次回响”练习时，指定一个小物或短语，安排三次出现，每次语义前进或反转；如“脏脏的”由玩笑走向愧疚，“有福气”从羡慕走向反讽/自嘲，烟斗经数人转手。死者遗物可跨人物流转，结尾清点谁得到、谁没得到；少于三次不能仍称三次回响。

### 8. 由最低身份者说委屈，或让年轻外人质问后落进喜剧

这项技法有两个明确分支。**低位代说分支：**把主角不肯说的委屈交给全场身份/地位最低的角色，主角本人只微笑、看天或以动作承受。《东京物语》老人不直说被冷落，由阿实、京子、沼田分别说出。**权威质问分支：**把质问交给最年轻的外人，质问后立即以醉酒、寿司店等生活尴尬/喜剧动作落地；不能让道理继续演讲。选择哪一支，就保留相应角色位置和尾部节拍；普通配角代说不算完整替代。

### 9. 把最私密的真话交给血缘以外的人

选择“只对外人说”时，把最私密的一句交给旧友、儿媳或其他血缘外的人；年轻人可承担主题辩论，家长与外人之间用一句家常话承担情感结论。周吉对旧友谈父母私欲，对儿媳谈亲生子女与外人的反差。避免事后再安排人物为观众总结同一结论。

### 10. 让镜像人物触发主角当晚作出决定

选镜像人物练习时，先给主角一个已走过其可能未来的人；主角看见对方的生活选择/代价后，当晚或紧邻下一场必须决定。可让次要人物先“试演”主题，再移到主角身上。《秋刀鱼之味》平山看葫芦父女、听其忏悔，当晚回家问女儿是否想嫁。镜像如果不触发行动，就只是一段平行人物介绍。

### 11. 让孩子争一件小物，映出成人主线给错了什么

选儿童副线时，让孩子对一件具体小物发怒或坚持；成人给错物件的事实映照主线冲突，两条线不必互相解释。《麦秋》小实要轨道，父亲给面包，他踢掉、挨打、出走；同一家庭又在为纪子安排“好条件”。孩子的需要须实际改变行动，不只作主题比喻。

### 12. 让群戏短语在三个人之间接力

选群戏接力时，让一句短语明确经过三个人的口中，至少完成一轮传接，用重复显示站队、合谋或压力，不承担信息说明。《麦秋》三个女人接力“对不对”；《秋日和》三人组重复“急不得”。少一人或只作背景复读，不算完成这个三人节拍。

### 13. 围绕小物争吵，把真正问题藏在短句节奏里

选择移置争吵时，先建立真正的问题（婚姻、失望或责任），再让人物只争蛋糕、球杆、白包等小物；对话用短句和重复，节奏逐级变硬，但不说破真正问题。《晚春》68场蛋糕争执实际在争纪子是否出嫁；《麦秋》夫妻争胡萝卜/烟斗。争吵后让关系状态可读，年轻伴侣的小物之争可证明婚后生活，不追加主题演讲。

### 14. 全片只留一段超过150字的独白

选择“一次长独白”练习时，整部作品只允许一段超过150字的台词，放在情绪出口的倒数第二段/最终余波前；此前的短答与沉默为它蓄力。旧片观察有周吉约300字的显著长话；“>150字仅一次”是被选模板的硬限制，不是所有小津作品的普遍篇幅规定。媒介/长度不适配时明示不选，不把唯一一次放宽成多次。

### 15. 结尾从社交空间退到家，再落在无人处

选择结尾递减时，高潮后依次经社交空间、半私密空间、家、无人空间；喜剧线和孤独线各给落点，先笑后空，最后一场无人，只留状态改变的物件/空间，不加解释旁白。《晚春》从酒馆回家到空房/夜海，《秋日和》从餐馆到公寓、空走廊。不得跳过中间层后仍宣称完成递减。

## 角色位置模板

不要求每部作品都凑齐八人；一旦选择“嫁女”“丧亲”或“秘密泄漏”完整模板，按需要落实这些角色位置：

| 角色位 | 必须承担的功能 | 写作时检查 |
|---|---|---|
| 留守者 | 被离开的人，承受家庭空位变化 | 他/她如何继续过日子，而非只哭诉 |
| 离开者 | 通过决定改变家庭结构 | 决定可以突然，但前面要有行为铺垫；理由用具体生活判断 |
| 推动者 | 提亲、催促、撮合或施压，且有自己的私心 | 行动有效但可能办错；不写成纯工具人 |
| 对照者 | 与离开者同龄、选择不同 | 让主角在看似轻松对话中看见另一条生活路 |
| 镜像者 | 显示留守者/主角可能的未来 | 通过一件生活事实，而不是传记说明 |
| 中转者 | 传话或代办 | 误解/加工带来后果，不能只当递台词的管道 |
| 缺席者 | 死者、远方者或失踪者，常由单件物品留在家庭里 | 物件怎样在不同人手中改变关系 |
| 旁观者 | 以开场/结尾框住家庭处境 | 两次观察要因事件而变，不只是重复旁白 |

推动者的动机必须诚实：即便他/她自私、忙碌或失手，也应能解释每一步。最刻薄的话要有现实道理，评价留给其他人物和观众；道德家可在下一步背叛自己刚宣称的规范。缺席者可作家庭粘合剂，让照片、麦穗、被子、手表或称谓带出跨代时间。

## 三个完整结构分支

### “嫁女/家庭成员离开”模板

当故事核心确实是成员离家，按以下顺序设计；需要调整时逐项说明原因，不把流程打散成任意家庭戏：

1. 车站、早饭、忌日或旁观者建立季节和全家关系，离开话题在前段出现。
2. 建立父女/母女的家常依赖：倒茶、麻将、方向问答等闲话里藏关键消息。
3. 安排一个让观众误认的假线索/对象，以喜剧节奏揭穿。
4. 推动者提出对象；对象不出场；离开者以照料父母/家人等理由拒绝。
5. 镜像者让主角/离开者看见未来；先由旁人评价镜像，随后把处境移到主角身上。
6. 推动者提出长辈再婚或其他新安排，触及真正伤口；进入几乎无台词的冷战。
7. 用一次无台词的观察高潮（凝视、隔位行礼、空座）让关系露出来；之后以小物争吵承载移置爆发。
8. 以三次追问逼出一个音节承认；离开者可哭，但不把哭解释成已决定。
9. 对照者让离开者作决定，长辈明确意识到决定可能是勉强的。
10. 告别之旅承担唯一长独白（仅当选择“一次长独白”模板）；之后婚礼不入画，只留镜前一句、合影或空房。
11. 第三人可点破推动者的谎；尾声由社交空间退到家与无人空间，物件/声响显示留守者的后续生活。

变体仍需保持事件画外与家庭余波：可把决定放在错误对象/长辈面前，用陌生人家的送嫁队伍收尾；可让推动者是有私心的喜剧三人组，观众先知道母亲无辜；也可让主角自己的迟疑造成对象错过，由第三者点明损失。

### “丧亲/失去家人”模板

选择该分支时保留两条平行夜线和物件链：开头以旁观者羡慕建立家庭表面；到达子女家后用一句生活观察显示落差；孩子或晚辈先替老人表达不满；老人被安排/“外包”到别处；唯一真诚招待由借来的物件或外卖承担；病情征兆以轻微动作出现并被笑着带过；老人把自己处境轻轻说成“无家可归”；父亲外出说失望、母亲与儿媳夜谈说慈悲，两夜交叉而不相见；死亡在空镜/场外发生；葬礼上悼念和算计同桌；先当笑话的俗语在后文变成悔恨；照片/被子/手表等遗物逐手传递，最后一个物件被认真看/听；结尾回到开头旁观者，但观察已从“有福气”变“冷清”。

死亡三次预告须各自被日常对话打断；不堆三句明确预言。遗物传递链须能指出每一手的接收人及其含义，不能把“物件象征死亡”当成完整结构。

### “秘密分层泄漏”模板

选择该分支后，固定按以下信息顺序组织：观众先知 → 第三人只看到一部分 → 另一个人逼问 → 中间人替秘密辩护 → 通过镜子/格窗等视觉视点再泄一点 → 被利用者被派去接近当事人 → 被利用者主动坦白“起初确实想骗你” → 身世/秘密被揭开，当场只有拒绝 → 和解留在画外，由他人确认而非当事人演说。每环只传一部分，不让主角提前主动全盘交代。

若需要冲突升级，按“恩情账 → 出身 → 血统/身份”逐级靠近最不可收回处；秘密主角最后一次施加的暴力由最想保护的人反击。戏中戏/表演若已出现，台词可预言主线结局，让看戏者也处在被观看的位置。和解若选火柴模板，第一根被拒、第二根被接受，再由受者替对方点燃；全过程不加道歉解释。

## 对白、反应与仪式：八种不同任务

以下是可分别选用的对白/反应技法。选中某一项时保留它规定的次数、顺序或说话位置；不可把所有项合成统一的“小津式闲聊”。

### 1. 用表层“废话”把关键句夹在闲谈中

选择闲话包裹练习时，关键台词放在一段方向、饭菜、麻将、拼写等小话的中间，前后都由闲话包住。《晚春》方向问答之后插入“阿纪怎么样”“差不多该有个着落了”。闲话须像这家人平常会说的，不给关键句加标题或解释。

### 2. 用可执行的语气副词改变一句话的关系温度

选语气标注练习时，从“淡淡地、冷淡地、含混地、开朗地、若无其事地、压低声音、忽然蔫了”等不同动作中选能指导演员的词；“悲伤地、意味深长地”若不能指向声音、脸或行动，就改成具体行为。新词不必模仿原译词表，但情绪温度必须可演。

### 3. 给每个人物一句口头禅，让重复变成性格

选全员口头禅练习时，每个人物各有一句短语，在不同处境中重复以显示习惯或态度变化。《浮草》阿芳的“我早就习惯了”、驹十郎的“这营生真没法子”、周吉的“唔”、志繁的“你可真是的”各有说话位置。口头禅不是标语；重复一次就须改变听感或被情境反用。

### 4. 用一个生活比喻交代动机，不补心理学诊断

选生活比喻练习时，人物只用一件日常经验说明动机，避免随后再用心理分析翻译。《麦秋》纪子把嫁给谦吉比作找不到剪刀、发现就在眼前；绫追问“那就是喜欢”，纪子仍坚持“可以信赖”。比喻要来自角色生活，不能替作者总结。

### 5. 让年轻人说主题，长辈在闲谈里误读转述

选主题转述练习时，由年轻人先提出一句主题判断；长辈不正面辩论，而在闲谈中把它误读/转述成另一层日常经验。《麦秋》绫子说恋爱和结婚应分开考虑，三个老男人随后在高尔夫场复述为世道艰难。两代话语必须有实际差异，不能只是把主题原句重复一遍。

### 6. 接受按微笑、第三人报告哭泣、家长给退路三步完成

选择“接受的三步”练习时，先让当事人微笑说接受，再由第三人报告她正在哭，最后由家长上楼给她反悔的自由后离开。情绪不可由当事人解释成“我已决定”；三步之间的知情差就是成品的压力。

### 7. 用仪式动作替代告白和关系总结

选择仪式动作练习时，使用合影、送别宴、对镜抹口红、折叠外褂或削苹果等具体动作承载“这是最后一次/我要离开”的情感，不用台词说出动作的象征意义。《晚春》纪子请求给父母单独拍照，婚礼不入画而由削苹果皮断收束。仪式动作须在该关系中有实际功能。

### 8. 重大消息后按空间排队反应，不让全家齐声辩论

选择反应排队练习时，每个人回到自己的空间，各自完成一场动作/沉默，再把动作次序排出来；不写成群体齐声争论。《麦秋》118–121场父母无力上楼、纪子对镜抹口红、康一夫妇留在原处；133–134场老两口离开，康一回书桌、史子在灰上划字、纪子吃茶泡饭。成品须让空间和动作说明每个人如何接收消息。

## 真实案例与迁移判据

- 《晚春》62场能乐堂，周吉与秋子隔位行礼，纪子察觉后不断偷看；无台词高潮把嫉妒变成观众可见的视线。68场纪子与绫争奶油蛋糕，短句重复承载“嫁不嫁”；71场连续三问逼出“嗯”；100–103场婚礼不入画，回家削苹果皮断，夜海收尾。迁移时分别复现“观察—被观察”“物件争吵—真实问题”“三问—短答”“离开—余波”，不复刻人物关系。
- 《麦秋》113场纪子在错的人面前作决定，117场谦吉事后才知道，118–121场家人各自反应；145场以别人家的送嫁队伍收尾。迁移时让决定的知情顺序与家人反应排序形成情绪，而不是在决定场一次解释完。
- 《东京物语》143–145场父亲守夜、空站台/海浪、白布覆盖，死亡不被呈现；93–94场“无家可归”把失落放进家常话，164场手表交给儿媳。迁移时可用空镜与遗物追踪缺席者，但必须把物件交接写清。
- 《浮草》27场观众先知父子秘密，48/57场镜子和中间人分段传递，90场加代主动坦白，115场身世揭开后阿清拒绝，119场两根火柴从拒绝到接受。迁移时保留逐层信息和“坦白是转折、揭穿不是转折”的区别。
- 《秋日和》101场母亲最后一夜的说法既可读作真也可读作假；不替人物把这个矛盾判成单一真相。迁移时让最后的言辞与此前行动都成立，观众才有判断空间。

## 专项编写顺序与验收

1. 写出稳定日常的基线：谁与谁如何共同使用空间、时间和物件。
2. 指明关系转折和谁要留下/离开；完整风格把所有承重重大事件放画外，并保留前因、传递、反应和余波；用户明确指定单项画内时标记为局部偏离。
3. 选择并完成相应结构分支/技法，保留它的顺序、次数、角色位与媒介条件。
4. 列观众、当事人、中转者的知情表；按次序安排反应、沉默、家常动作和物件传递。
5. 以离场后的空间或生活动作结尾；每个空镜、重复短语和物件都对应一个明确变化。

成品判据：观众能从基线与偏离说出关系变化；每个画外事件有可追踪的知情/反应链；所选模板的次数、顺序、位置完整；离场之后的家常动作承载新状态。如果稿子只有“克制、安静、留白”，或必须靠作者解释空镜含义，回到场面补可见证据。

本子级只迁移风格方法。当前中文剧本场次、`△` 与用户/项目选定编号以父级格式真源为准；`P` 只表示明确要求的视频内容段。日文柱格式、原片1–1.5页场长和导演镜头处置不迁移。方法来源与更多真实场次见[具名剧作方法](../../references/named-dramaturgy.md#ozu-method)；《东京物语》是小津与野田合作文本，其他规律标为比较归纳，不写成作者宣言。
