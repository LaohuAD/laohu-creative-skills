# 小津/野田方法：家常照旧，关系已经变了

## 触发条件与范围

用户点名小津安二郎、野田高梧及其合作作品，或要求按小津/野田方式写家庭关系、迁移其结构、对白或场面机制时启用；无需先说画外事件等术语。仅出现家庭片、代际冲突、安静、日常、东方韵味或慢节奏不触发。适用于电影及其他叙事媒介；低机位、日文柱格式与导演现场调度不带入中文剧本，场次、`△` 与编号沿父级体例，`P` 仅用于明确视频分段。

## 定义性固定项：日常—重大事件画外—反应与余波

完整小津/野田式组织遵循核心主链：**稳定日常基线 → 承重事件置画外 → 中转与分空间反应 → 空位与家常余波**。先立谁照料谁、共用什么空间、谁被留下；再让婚嫁、离家、丧亲、秘密或角色变动改写家庭位置；最终回到吃饭、收拾、通勤、遗物与空房的后续生活，由行为次序与空间变化透出情感，不由人物总结。

- **画外铁律与局部偏离：** 完整风格须把本作改变核心关系或家庭位置的承重事件置入画外（长片往往涉及多件如婚嫁、离家、丧亲等，短片或单场按本作实际体量确定数量，绝不为凑数硬编事件），画内写足前场逼近、消息中转、各人反应与空座/空房/家常余波。仅当用户明示某件必现画内时，将该项标为完整方法的局部偏离，其余事件与主链照常画外执行。
- **单选边界：** 单选下方某一技法只跑通该技法的核心因果与余波，不强制全片结构；家庭规模、时代、事件与喜剧比例按本作事实开放，不硬塞出嫁、死亡或象征物。

## 十五种独立技法

按需单选或组合，未选不作全篇配额；**重在落地每招的底层节奏、知情与余波机制，次数、篇幅与层级随本作片长自然伸缩，不机械死凑数字**。

1. **承重事件画外化，画内留前因与反应：** 婚礼、相亲、死亡、决定或暴力不直接演出，写清前场逼近，后场借空座、空房、消息、归来或家常动作留下不可逆事实；缺前因或反应即补场。
2. **用可辩护的谎言推动离家或改变：** 推动者为促成选择说出善意谎言，旁人可点破也可不揭，末段家长表态令真假并存（《晚春》《秋日和》）；谎言须引发具体行动或误解。
3. **反复追问，关键承认落成极短回应：** 围绕同一事实逐次加压追问（经典长片常走两三轮），沉默独立占拍，承认或拒绝压成短音节（《晚春》答“嗯”，《麦秋》短确认）；相邻问句或动作保清所指与肯否，不可先剖白心理。
4. **中转者加工权威指令与亲密消息：** 主角与对象间隔一中转人传话、翻译或转嫁责任，借顾虑与误解生喜剧或压力，每轮转述至少改一人知情（《晚春》姑母、《麦秋》纸门后康一、《东京物语》转儿媳）。
5. **缺席对象由侧面具体信息拼出：** 不出场对象不露脸，仅由几条可比较的具体生活信息或模糊照片构成（《晚春》佐竹的几处说法、《麦秋》高尔夫照）；若为强配错选项，这些信息直显抗拒理由。
6. **一两行可见空镜切开情绪段：** 情绪段间插一两行客观景物或空间事实（空座、站台、麦田、海浪、门窗），无情绪词与象征解说，切实切开时间、地点或关系阶段。
7. **物件或短语跨场回响变义：** 选定小物或短语随关系推进前后呼应（原作常经三次从玩笑转愧疚或反讽，短片可按篇幅走两到三次），每次重现须改写语义或归属；遗物流转在结尾清点归属。
8. **低位代说委屈，或年轻外人质问后转喜剧：** 二选一——**低位代说支**让全场地位最低者道出主角委屈，主角微笑、看天或以动作承受（《东京物语》）；**权威质问支**由最年轻外人当面质问，紧接醉酒、小馆等生活尴尬转喜剧，截住说教（另对照《秋刀鱼之味》女儿反问）。
9. **最私密的真话交给血缘以外的人：** 最私密的一句家常结论交给旧友、儿媳等外人，不再复述；年轻人可承担主题辩论（《东京物语》周吉、《浮草》驹十郎）。
10. **镜像人物触发主角当晚决定：** 主角目睹已走过其可能未来的人及代价，当晚或紧邻下一场动手决定（《秋刀鱼之味》平山看葫芦父女当晚问婚事）；亦可先由次角试演主题再移回主角。
11. **孩子争小物映出成人主线给错：** 儿童副线围绕小物发怒或出走，成人错给物件映照主线错配，两线互不点破（《麦秋》要轨道给面包、《东京物语》搬书桌）。
12. **群戏短语多人接力：** 同一短语依次经数人之口传接，靠重复节奏显站队、合谋或压力（《麦秋》《秋日和》的群戏接力）。
13. **围绕小物争吵，短句节奏藏真问题：** 先立实婚姻、失望或责任等真冲突，再只争眼前日常小物，短句重复加速却不说破真问题，吵完令关系状态可读。
14. **克制全篇长独白配额：** 全篇绝大部分保持短答与沉默蓄势，仅在最关键的情绪出口留**唯一一段**较长剖白（原作长片常逾百余字，短片按体量收敛），绝不写成处处长篇倾诉。
15. **结尾由外向内逐层收空：** 高潮后从外在社交或热闹处逐步退回家庭再落向静场或无人空间（按片长自然过渡，不必硬凑四层过场）；先笑后空，终场只留变态物件或空位，无解说旁白。

## 角色位置模板

选完整结构分支时，将八功能位映射至已有角色（行动同时满足方可兼任）；缺位标明缺口或改选局部技法，不为填表造人。

| 角色位 | 核心功能 | 写作检查 |
|---|---|---|
| 留守者 | 承受家庭空位变化 | 写如何继续过日子，不只哭诉 |
| 离开者 | 以决定改写家庭结构 | 决定可突然，前文须有行为铺垫与生活判断 |
| 推动者 | 怀私心提亲、催促或施压 | 动机诚实、有效却可能办错，不做工具人 |
| 对照者 | 同龄却选了别样活法 | 在轻松闲谈里让主角看见另一条路 |
| 镜像者 | 呈现主角或留守者的可能未来 | 靠生活事实显现，不做传记说明 |
| 中转者 | 传话、翻译或代办 | 误解与加工须改变局面 |
| 缺席者 | 死者、远方或失踪者，以物留痕 | 借照片、手表、被子带出跨代时间与关系 |
| 旁观者 | 首尾框住家庭处境 | 两次观察须随变故改口 |

推动者最刻薄的话也须有现实道理；道德家可在下一步背叛自己刚立的规范，评价留给旁人与观众。

## 三个完整结构分支

### 嫁女或家庭成员离开模板

1. 车站、早饭、忌日或旁观者立季节与全家关系，前段带出离开话题。
2. 借倒茶、麻将、问路等闲话立亲子依赖，闲话中埋关键消息。
3. 设令观众误认的假对象或假线索，以喜剧节奏揭穿。
4. 推动者提亲，对象不出场，离开者以照料家人拒绝。
5. 镜像者显露未来，先由旁人议论，再移回主角。
6. 推动者抛长辈再婚或新安排触痛真伤口，转入近无台词冷战。
7. 无台词观察高潮（凝视、隔位行礼、空座）挑明裂痕，紧接小物争吵移置爆发。
8. 连问三轮逼出单音节承认，哭泣不等同决定。
9. 对照者促成决定，长辈心知决定或许勉强。
10. 告别之旅承唯一长独白（若选第 14 技）；婚礼画外，只留镜前一句、合影或空房。
11. 第三人可点破谎言；尾声由社交场退至家与无人空间，留守者以日常物件与声响续命。

变体仍守画外与余波：可把决定说给错的人并以他家送嫁收尾（《麦秋》）；可由喜剧三人组酿误会（《秋日和》）；也可因家长拖延错过良缘由第三者点破（《秋刀鱼之味》）。

### 丧亲或失去家人模板

旁观者羡慕立表象 → 到子女家以细节现落差 → 晚辈代老人吐不满 → 老人被转送外包 → 借物或外卖成唯一真诚招待 → 轻微动作现病兆并笑过 → 老人轻称无家可归 → 两平行夜线不相见（父外出谈失望、母与儿媳夜谈慈悲） → 死亡落空镜或画外（前文三次死亡预告皆被日常打断） → 葬礼悼念与算计同桌 → 昔日玩笑俗语变悔恨 → 照片、被子、手表等遗物逐手流转并查清每手含义，末物被认真端详或倾听 → 结尾回开头旁观者，口风从有福气转冷清。

### 秘密分层泄漏模板

信息按九步渗出，不让主角提前自白：观众先知 → 第三人见一角 → 他人逼问 → 中间人辩护 → 借镜子或格窗视觉再泄 → 被利用者奉命接近 → 被利用者主动坦白初衷本想欺骗 → 身世揭穿当场只留拒绝 → 和解置画外由他人确认。冲突升级可沿恩情账 → 出身 → 血统/身份逼近不可挽回处；戏中戏可预言主线；火柴和解为第一根被拒、第二根被接，再由受者替对方点烟，全程无道歉解说。

## 对白、反应与仪式：八种不同任务

按场单选，守住次数、顺序与说话位置。

1. **表层废话夹关键句：** 核心句埋在问路、饭菜、麻将、拼写等闲话中段，前后自然闲话包住，不加预告。
2. **可演声量与体态调温度：** 用演员听得懂、演得出的细微声量、停顿或手部/目光动作（如压低声音、停半拍、继续手里活不抬头）调节克制温度，对接父级表演括注法则，不贴抽象情绪副词标签。
3. **每人一句口头禅：** 各配一句贴合身份的短语，在不同处境中重复以改变听感或被现实反讽。
4. **生活比喻交代动机：** 人物只用一句日常经验说明决定（找不到剪刀却就在眼前），不补心理学剖析。
5. **年轻人说主题，长辈闲谈误读：** 年轻人抛主题判断，长辈不正面辩驳，在闲谈中误读成另一层世故经验。
6. **三步完成接受：** 当事人微笑接受 → 第三人报告她正在哭 → 家长上楼给反悔自由后离开，靠知情差蓄压。
7. **仪式动作替代告白：** 借合影、送别宴、对镜抹口红、折外褂、削苹果至皮断等实功能仪式承载离别，台词不点破象征。
8. **重大消息后按空间排队反应：** 各回各处单独完成一拍动作或沉默（上楼、抹口红、回书桌、灰上划字、吃茶泡饭），代替全家齐声争吵。

## 编写顺序、验收与返回父流程

1. 立稳定日常基线：谁与谁共用空间、时间与物件。
2. 明关系转折与去留；完整风格将全部承重事件置画外并保前因、中转、反应与余波，用户指定画内单项标明局部偏离。
3. 选用并跑完结构分支与独立技法，列观众、当事人与中转者知情表，排清反应、沉默与物件流转。
4. 以离场后空间或家常动作收束，核对空镜、回响与物件皆对应变化。
5. **验收：** 观众由基线与偏离读出剧变，画外知情链完整，所选技法的底层机制与余波落于具体家常动作。

将日常基线与转折带回[父级主流程](../../SKILL.md)：定戏核与人物回阶段一，搭结构、知情链与分场回阶段二，正文声画与表演回阶段三，成品自审回阶段四。本子级不自动触发其他风格专项。
