# 权力群像：每次争位都改写关系

## 触发条件与适用范围

用户点名《继承之战》/Succession，或明确要求写组织与家族里谁握决定权、谁结盟、谁失势并以此驱动群像时启用；无需先说权力容器、信息筹码等术语。适用于单场会议、短片、长片与连续剧——单场任务只跑场内容器机制，绝不窄化成连续剧；仅明确做多集项目时启用单集、季弧与季终分支，不自动递归调用兄弟子级系列开发。仅有商战、豪门、政治题材、多人同场、尖刻台词或失势情节本身不触发。

## 定义性固定项

1. **权力竞争是主发动机。** 锁清各方争夺什么，以及谁控制决定权、资源、信息、规则解释权或公开说法；每名关键人物各有独立欲望、筹码、信息、羞耻点与说话方式，绝不全员统一机锋腔。
2. **必须放进可见规则容器。** 将相斥欲望压进会议、宴席、听证、婚礼、葬礼、走廊或投票等具象容器，明确谁的地盘与谁能改规则。
3. **每场必有控制权变化账。** 每次交锋要么转移控制权，要么写清谁维持僵局、为何能维持、换来何种收益及卡死谁的下一步；赢家须改策，输家仍有招。
4. **公开结果与私人清算分离。** 公开胜负与私人代价可完全相反；羞辱、仪式与失态只有在改写策略、施加限制或转嫁压力时才承重。

## 单场容器法与多集核心

### 单场、短片与长片通用容器链

先定**谁的地盘**（谁召集、定议程、能离场、解释规则或拍板生效），再设**可见规则**（席次、发言序、投票、外部时钟、礼仪或物理限制），按六步链落地：

`提议目标 → 阻断或转用规则 → 资源或发言权易手 → 公开结果 → 私人结算 → 下一步策略`

若收于僵局，须显出谁握否决权、谁从僵局获利以及它如何拖累下一场。

### 连续剧单集与季弧核心（仅多集项目启用）

- **开发骨架：** 从简单现实冲动扩出家族与制度复杂层 → 写一句气味测试 pitch 筛掉不属于本剧的材料 → 确立跨季难解的权力引擎问题，每季只问今日版本并锁 3–5 个季末锚点（抵达路径保留发现空间）→ 画人物 × 集数状态图（mega-chart），逐格记本集 want → 集末得失、联盟、制度位置与下季债务，核查各线同室互阻 → 每集绑定一个容器、一个当集问题与真实信息/时间限制 → 非终季转胜负为下季债务，终季按物质引擎失压结算。
- **单集问题必答：** 用“今天 X 能不能 Y”立本集主问题并在集末落锤；跨集追看力靠新权力格局与新债务承接。
- **无幕标时间分段：** 按 2–7 个剧情日、交通切换与议题转向划分隐形幕，每段末须有信息或权力转移。

### 高压 Set-Piece：完整公共容器九项机制

以大型仪式或公共场合承载全集冲突时，按以下九项排布（不适配本作事实的部件可裁剪）：

1. **明确地盘：** 决定谁有权立规则或临场撕毁规则（如晚宴作废免罚承诺）。
2. **可见物理约束：** 收手机、禁离场、无信号、座次、着装或安保权限。
3. **被迫发言顺序：** 点名、逐一祝酒、证人排序、投票或讲坛致辞。
4. **局外人或弱者点破规则：** 由低位人物说出代价，让观众立刻看懂筹码。
5. **事前清单逐条违背：** 先给观众仪轨或禁忌清单，靠角色逐项越线生悬念。
6. **礼物或公开表现自曝：** 每份礼物、致辞或定制空间都外化送礼者的权力与情感账。
7. **饮食作服从测试：** 谁供应、谁先动、谁拒绝，直观显示施恩与臣属。
8. **公私空间双轨：** 公共大厅演台词与体面，走廊、厕所、车边、后台与停车场做真交易、结真盟。
9. **羞辱接私人清算：** 公开难堪后必接私下尾声，把名誉损失兑成关系创伤或反击策略。

## 结构装置：S1–S12

按需选用，未选不作全篇配额；选中即走完完整机制。

- **S1 隐形幕时间分段：** 按 2–7 个剧情日或候机、换车、进出空间节点切分段落，每段末必见信息或控制权转移。
- **S2 容器与仪式程序：** 借舞会、家宴、听证、股东会、婚礼、开票夜、葬礼等固定仪轨排节拍；座位图转阵营证据，空主位成搜寻与权力真空，借钟点字幕、仪轨顺序、外部结果或空位推进。
- **S3 压力舱与通讯切断：** 群像锁进同一建筑或孤岛并收手机、无信号、设门禁，信息靠人移动；拒绝交手机或守规矩本身即立场。
- **S4 单集问题本集回答：** 每集抛当日可判胜负的具象问题（卖不卖、谁进屋、谁担责、能否抢在报道前签字），集末落锤，由新债开下集。
- **S5 季终减场加长：** 大节点与季终压成 3–5 根实时感长柱子（谈判、仪式、密谈、对峙），集中结算程序与阵营。
- **S6 季形对称：** 选具体可重复量（收购价、台词、配乐或行动判断），首尾各现并彻底翻转位置与代价。
- **S7 主角缺席的高潮：** 三前提齐备——已积足在场感、缺席者仍借电话/规则/代表施压、本集关乎其缺席；悬念转向能否赶到、谁代言与规则是否失效。
- **S8 外部钟点夹缝：** 设开票、报道上线、董事会表决等真实外部时钟，逼人物在两次节点之间拍板，逐点关掉选项。
- **S9 伏笔调光：** 直说会压死后续时删解释句，只留人名、习惯或微小反常（如只提律师名不提离婚）并于后文实收。
- **S10 被剪戏迁移：** 改稿先辨戏本身无效还是时机未到；早产好戏移入前置压力更足处并重校因果。
- **S11 同场互相污染：** 交易、婚姻、政治与家族并置同一容器，一线善意或胜着自动成另一线筹码（如劝伴侣先回却被读作专注工作）。
- **S12 技术故障延迟动作：** 重大决定前埋 2–3 个递进流程阻碍（断网、门禁、货梯、误入、触屏卡顿），显出谁控流程并抬高代价。

## 人物模式：C1–C8

- **C1 欲望同室：** 列同场每人本集小欲望卡，确保两两碰撞或资源依赖；不碰撞且不加压的线砍掉或改成互污。
- **C2 羞辱向下传导：** 受辱者下场向更弱者转嫁压力，或明拒转嫁并付代价；逐环记录受辱、自解、转嫁/拒绝与后果。
- **C3 家族往事三版本：** 当事人控诉 → 亲属否认 → 第三人补出此前未知的新事实，并直接触发主角改变现实策略。
- **C4 回到让人变小的地方：** 多集长线安排核心人物每季一次回故居、故乡、事故地或旧关系被迫变小；最强版驱车到门前却不入。
- **C5 最可替换的继承者：** 外部接管结局专用——上位者缺独立议程、能扛痛、随时可换，任命理由由敌人或看轻他的人亲口道破。
- **C6 三种逻辑拒援：** 三名潜在盟友各凭成立理由拒援（受托职责、金钱利益、陈年积怨），末击可化作仅目标听见的私语。
- **C7 镜像与外部裁判：** 用镜像家族、同境失能者照见主角；由真伪莫测的外部裁判逼出平时绝口不提之话；由最弱者用笑话戳破规则。
- **C8 身体衰退作计时器：** 设 3–4 个递进可见身体刻度（弯腰吃力、呕吐、短暂失神、意识错乱）作整季倒计时，每次须切实改变行动能力。

## 对白与舞台指示：D1–D13

按人物与场景匹配选用，保持声口分化。

- **D1 潜台词写进动作指示：** 用疑问句或也许并列角色同时渴望与恐惧的两股驱动力，不只写表情结论；被打断后半句按体例标清。
- **D2 一个词反转：** 先说足令观众信服的顺从版本，再陡然改向重夺条件或决定权；中文按关系、筹码与正式度决定单字连词或短分句，关键在听清让了什么、握着什么及随后改变谁的决定权。
- **D3 扣机词换意图：** 前文立住制度黑话或家族词，后文换人或换境重提，令安慰与侮辱同落一句。
- **D4 喜剧伏笔变证据：** 前期内部玩笑或黑话被外部听证逐字重读，越辩称玩笑越坐实体系纵容。
- **D5 格言交给配角：** 直击权力本质的格言优先由配角或局外人从自身立场说出，主角可不听。
- **D6 不同否认就是人物小传：** 共同罪责前，每人按利益与羞耻点给出不同否认、局部承认、改题或冷笑。
- **D7 让主角成功撒谎：** 借可观察赌点（直视不移眼、是否补问）令谎言过关，换取下一步信息、信任或债务。
- **D8 礼貌问句做重大转折：** 将重注包装成留有退路的礼貌问句，靠对方震惊显分量；核实退路真假、提问者兑现能力与决定权变化。
- **D9 对手替主角说内心：** 对手精准道破主角秘而不宣的计算，紧邻以主角行动验证其判断。
- **D10 喜剧承载悲剧：** 以残忍家族玩笑接坦白、大议题降小争执、或喜剧游戏行哀悼，笑后仍付真实情绪代价。
- **D11 争吵靠近最脆弱处：** 逐句逼近最怕曝光的软肋，可叠加观众知情差造成双重刺痛，写出具体撤回或僵住动作。
- **D12 省略成为主题：** 前置事实与关系铺足后，以极短确认、沉默或缺席说明收落点，不拿缺铺垫冒充留白。
- **D13 关系落到身体动作：** 言语无力更新关系时，以触痛旧伤的拥抱、递掌不握、拿放物件收尾，不配解说台词。

## 季终、剧终与画外死亡八步链

- **终局结算：** 先检物质引擎是否失压（交易、职位、继承还能否生出新选择）；终季先锁 3–5 个含外部事实与人物胜负的锚点，暂留多版可能；开放结局须先结清物质目标再留有据的关系缝隙。
- **画外核心掌权者骤逝链（同类场面按本作权力领域适配）：** 核心机制在于**程序与权力本能吞没私人悲痛**——① 唯一且难以核实的信源突传变故 → ② 旁人或亲信第一时间把危机转成实务应对 → ③ 亲属/亲信隔着通道发出无回应的慌乱告别（短促仓促，无暇抒情） → ④ 从怀疑、讨价还价到确认的否认阶梯逐级收紧 → ⑤ “由谁来通知谁”本身立刻变成权力宣示动作 → ⑥ 物理或程序隔离亲属与现场 → ⑦ 应急处置、善后流程与公关/对外口径官方化（按本作所属家族、企业或机构实际体制落地，不生搬上市公司股价） → ⑧ 各岗位机械按职责运转，讽刺从制度惯性里自生。
- **退行游戏、虚拟遗愿与背景层：** 可借短暂合作玩笑测试亲密，再以温情被打断与小背叛预演大背叛；可借虚拟遗愿从嘲讽转入童年未竟承诺；重要情绪收束可先写作独立可删的背景层画面（如屏上录像），前景行动不停，观众从观看反应收束情绪。

## 编写顺序、验收与返回父流程

1. 明确权力主驱动与各方筹码，确保每项资源都能改写选择。
2. 定范围与容器：单场只跑六步场内账；系列再开单集问题、时间分段与季弧状态图。
3. 选配所需的 S/C/D 招式、九项 Set-Piece 或画外死亡链并走完完整链；分化人物声口，确保赢家改策、输家有招、留白有据。
4. **验收：** 单场说清谁立规、谁得利、谁控信息与控制权变账（或僵局成本）；连续剧单集必答主问题并留新债；权力容器绝不止于热闹嘴炮。

将场内筹码与控制转移带回[父级主流程](../../SKILL.md)：定戏核、人物欲望与季弧回阶段一，搭容器结构与交锋分场回阶段二，正文声口与表演回阶段三，硬核自审回阶段四。场号、`△` 与编号沿父级真源，`P` 仅用于明确视频分段。
