# 权力群像：每次争位都改写关系

## 触发条件与适用范围

用户点名《继承之战》/Succession，或说“写一场像《继承之战》那样的争位戏”“让组织/家族里争谁有决定权、结盟和失势成为人物群像的主发动机”时启用；不要求用户先会说权力容器、信息筹码等术语。它可用于一场会议、一段关系、短片、长片或连续剧；单场请求只运行场内机制，不能因参考《继承之战》把任务窄化成连续剧。商战、豪门、政治题材、多人同场、尖刻对白或某人失势本身不触发。一般群像使用父级通法。

系列引擎、单集/季弧、季终和编剧室是按用户当前实际范围启用的条件分支；只有明确在做多集/系列项目才应用系列参数和季弧。此子级不自动递归触发或重启 `series-development` 兄弟子级；父流程需要时再按实际缺口组合。

## 定义性固定项

权力竞争必须是人物群像的主发动机，不能只做题材装饰。先指出各方争什么，以及谁能控制决定、资源、信息、规则或公开说法；再把他们放进一个可见的权力容器（会议、宴席、听证、家族仪式、走廊、投票等）；每个关键场面都要显示一次控制权变化，或说明谁维持僵局、为何能维持、因此限制谁的下一步。结果必须在后续策略、联盟、关系、声誉或行动权中留下账目。人物可输赢不同、可暂时僵持；不能每场都换赢家，也不能让“赢了”不改变之后的行动。

群像人物须各有独立欲望、资源、信息、羞耻点和说话方式。胜负的公开叙事与私人代价可以相反；羞辱、仪式、失态只有在有人据此改变策略、遭受限制或转嫁压力时才承重。不要复制原剧人物、对白、公司原型或场景。

本地方法归纳自 Jesse Armstrong 等编剧署名的 *Succession: The Complete Scripts* 拍摄稿、作者前言/注释及 Lucy Prebble、Frank Rich 等人的记述；剧本是开拍时版本，不是播出终剪。所谓“隐形幕”只是逐场分析推断，不能写成 Armstrong 的结构宣言。需要对应证据时读[具名剧作方法](../../references/named-dramaturgy.md#power-ensemble)。

## 结构方法分支：按任务选用，选后执行完整机制

### 单场、短片、长片都可用的容器方法

先明确“谁的地盘”：谁召集、定议程、能离开、解释规则或让决定生效；再设置可见规则（席次、发言次序、投票、媒体时钟、礼仪或物理限制），使不同欲望被迫相遇。按“提议目标 → 阻断/转用规则 → 资源或发言权改变 → 公开结果 → 私人结算 → 下一步策略”写完整场景链。若结果是僵局，必须写明谁有能力让别人无法行动、僵局给谁带来何种收益、它如何拖累下一场。

**连续剧单集与季弧分支：**

仅在确实写连续剧时启用：

### S4 单集问题要在本集回答

用“今天 X 能不能 Y”写一个主问题，集末给明确答案；跨集悬念由新权力格局和新债务承载，不靠把本集主问题悬着不答。

### S1 隐形幕是分析工具

若采用无幕标记的时间分段，先列2–7个剧情日/时间区段（2–7来自旧分析样本；七日是S2E2观察上限，不是行业定律），再以换日、地点/交通切换、问题转向和信息/权力转移推断段落边界。每个推断段末须发生信息或权力变化，不强求悬念钩。必须标为本地推断。

### 季弧状态图

给每个主要人物记“本集想要什么→集末拥有什么/失去什么”，跨集更新联盟、公开身份、制度位置和下一季债务。角色数量随作品定；七个欲望是 Roy 家具体样本，不是新剧配额。

### S2 系列容器

每集可选会议、宴席、婚礼、听证、生日、葬礼等有固定程序的公共场合；列到场、礼物、致辞、投票等仪式节点，让节点承担冲突节拍。座位图必须转成阵营证据，空主位必须成为搜寻或权力真空。

若用户要从零设计此类连续剧，再用下列来源型构造流程；它只负责本专项的引擎和表达，不重新运行父流程：

1. 先写一个简单冲动/现实问题，再扩出家族与制度的复杂层；把真实世界事实核实后再虚构组合，不能照描单一现实家族。
2. 写一句 pitch 来测试作品气味，再决定角色名是否已能让创作者“住进”人物；pitch 是筛掉不属于本剧的材料，不是宣传口号。
3. 写一个跨季长期难解的权力引擎问题，每季只问它的“今天版本”；把本季最终锚点先定住，抵达路径保持可发现。
4. 画人物×集数 mega-chart，每格写人物本集 want 与集末状态；检查人物线是否在同一场合互相阻挡/污染。
5. 每集绑定一个权力容器、一个可回答的当集问题和一个物理信息限制；必要时把事件时钟/外部结果放入时间区段。
6. 排公开羞辱/联盟转移、缺席者施加意志和角色潜台词；如选系列生产分支再运行 alts、现场与剪辑循环。
7. 终季用少数锚点安排结算；非终季将胜负转成下一季债务。最终一个画面可以留给拍摄现场，但剧本至少交到最后一个人物动作。

**可选结构装置：**

### S2 容器集/仪式表

先列出公共程序，再逐环节安排一次冲突；阴谋从正式空间转入走廊、厕所、停车场等服务空间。可用钟点字幕、仪轨顺序、外部事件字幕或空主位四种方案。

### S3 压力舱与通讯切断

把人物限制在一栋楼/一组空间，再加手机收缴、无信号、安保、出入权限等实际信息限制；随后让信息靠人移动。若人物拒绝交手机/守规矩，拒绝本身要改变局面。

### S5 季终减场加长

选择此模板时压成3–5根长柱子（谈判、仪式、密谈、对峙等），让柱间累积的程序、关系与信息结算；不是把事件清单缩写后仍保持碎场。

### S6 季形对称

找一项具体可重复量（价格、台词、音乐、动作），首尾各出现一次，中间发生意义翻转；不得只回放而不改变位置或代价。

### S7 主角缺席的高潮

仅在缺席者仍通过电话、规则、代表、决定或通报施加意志，且观众已积累足够在场感、此集确实关于其缺席时使用。前提缺一就是结构漏洞；把悬念转为“能否赶到/谁会代言/规则是否仍有效”，不能只是让主角沉默不在。

### S8 外部钟点夹缝

先设开票、报道上线、投票、董事会等真实时钟；人物只能在两次外部节点之间选择，时间节点要实际压缩选项。

### S9 伏笔调光

若直说会提前压住后续，就删掉解释句，只留名字、习惯或一次不一致；后文须确实回收。反向情况是轻描淡写的信息过早兑现，则调整它的显著度或位置。

### S10 被剪戏迁移

改稿时先判断一场戏是“不对”还是“没到位置”；若本身有价值，移到前置压力更足、更贴合问题的位置，并重查其前后因果。

### S11 同场互相污染

把交易、婚姻、政治、家族线放进同一派对/葬礼/走廊，让一条线的善意或胜利自动成为另一条线的筹码；由行动产生，不由作者解释。

### S12 技术故障延迟动作

给宏大决定设置2–3个递进的小障碍（设备、门禁、打印、误入、物件故障）；每个障碍都进一步显示谁能控制流程、使行动代价上升，不能是纯随机笑料。

## 人物方法分支

### C1 欲望同室

选“同一容器中的多线群像”时，把每个主要人物本集的小欲望写在卡上，再检查两两之间至少有明确碰撞或资源依赖；旧剧七个 Roy 家人物只作样本，不强求七人。未相撞且不贡献信息/情绪压力的线，删去或改成和别线相互污染。

### C2 羞辱向下传导

若选择羞辱链，上一场每个被羞辱者须在下一场把压力转给一个更弱者，或明确拒绝转嫁并因此付出代价；逐段写“谁羞辱谁—接收者如何解释—下一场转给谁/如何拒绝—链条后果”。不把它当社会学定律套在每场。

### C3 家族往事三版本

同一记忆按当事人控诉、亲属否认、第三人补充的三个版本出现；第三版必须带出此前无法得到的新事实，并触发一个可见策略变化，不停在主题说明。

### C4 回到让人变小的地方

若采用季节性归返，给每个核心人物每季一次回到旧屋、故乡、旧雇主、学校或旧关系中被迫变小；最强版本可以到门口而不进入。只有系列任务适用，不移植成单场硬规则。

### C5 最可替换的继承者

若结局是家族外人上位，任命者应缺少独立议程、能承受痛苦、可换掉；任命理由由敌人或看不起他的人说出。若故事结局不是公司被外部接管，不套这个答案。

### C6 三种逻辑拒援

设计三名原本可能支持主角的人，各给不同且成立的理由（受托责任、金钱、积怨等）；最后一击可变成仅目标听见的私语。无理由的“反派拒绝”不能代替。

### C7 镜像与外部裁判

可选镜像家族、相同处境却失能者、会逼主角说出平时不说之话的外部裁判、或最弱者点破权力游戏。外部裁判台词的真假要保持不确定；弱者的笑点须同时揭出机制。

### C8 身体衰退作计时器

若采用人物衰弱母题，选择3–4个逐渐加重的具体身体刻度（例如弯腰捡物、走路/呕吐、短时意识错乱、儿童读物中的死亡），按一季递进。这个3–4次是复现旧剧该母题的练习参数，不是所有老年角色的规律；不通过身体行动改变能力就不要加。

## 对白与舞台指示：十三种可复用机制

选取与人物、场景匹配的机制，不能把所有人都写成同一种尖刻机锋：

### D1 潜台词写进动作指示

用疑问句或“也许”说明角色同时想要/害怕什么，不只写眉眼或已确定结论；把被打断的后半句用当前项目格式标出。

### D2 一个词反转

先让角色完整说完观众以为他要服从的版本，再以一个词转向；缺少前面的完整顺从，单词没有反转力。《继承之战》S2E10 Kendall先说完接受父亲安排的顺从版本，再用“But”改向；可迁移的是整段话先建立一种可相信的退让，再让一个词改写目的，不能把“But”单独当机灵包袱。

### D3 扣机词换意图

提前建立一个制度词/家族词，第二次由不同人说、或意图翻转，使安慰与侮辱落在同一句话里。

### D4 喜剧伏笔变证据

让早先被当笑话的词/内部黑话后来由外部机构逐字重读，角色越解释为玩笑越暴露体系容忍。前置笑话必须留下可核对文本。

### D5 格言交给配角

若选择此连续剧对白练习，每集至少一条可被引用的权力格言，优先交给配角；主角可以不听。局外人的话须来自其经验和利益。单场/短片只在用户指定此练习时要求一条，不把“每集”扩成所有作品配额。

### D6 不同否认就是人物小传

群体面对共同罪责时，每个人用不同方式否认、部分承认、改写问题或嘲笑；每种回避必须符合其利益和羞耻点。

### D7 让主角成功撒谎

用一个可观察的赌点（是否移开眼睛、是否补问）让受骗者相信，成功的谎言须换来下一步信息、信任或债务。

### D8 礼貌问句做重大转折

把提议包装成给对方留退路的问句；对方的震惊/拒绝负责暴露赌注，提问者不要先宣布“这是大事”。

### D9 对手替主角说内心

让对手精准说出主角正在计算却不会承认的选择；紧邻主角的行动验证其判断，避免它只是一句聪明台词。

### D10 喜剧承载悲剧

可用黑色家族玩笑承接坦白、把大议题降级为日常小争议，或用喜剧仪式完成哀悼；笑点从人物心理/利益中长出，随后让情绪付出真实代价。

### D11 争吵靠近最脆弱处

每句比上一句更贴近对方最怕被看见的缺陷；观众可以拥有当事人不知的信息，形成双重伤害。演员的反应/撤回动作要具体。

### D12 省略成为主题

前置人物关系和事实后，让一句简短确认、沉默、未播出的说明或缺席的道德解释成为全场落点；无前置不叫留白。

### D13 关系落到身体动作

当语言已不能更新关系，用拥抱中的伤口、递掌但不握紧、拿/放一物等动作完成结尾；动作须承接旧关系，不配解释性台词。

## 高压 set piece：完整模板的九项要求

若选择以公共仪式/重大场面作为本集核心容器，以下九项要完整规划；仅缺一两项的普通场景不必假装是完整 set piece：

1. 有明确“谁的地盘”，地盘决定谁能定/改规则。
2. 有可见物理约束：收手机、不得离场、无信号、座次、宣誓、鞋/服装要求等。
3. 有被迫发言顺序：点名、逐个祝酒、证人次序、投票或致辞名单。
4. 有一个局外人/弱势者说出游戏规则，让观众理解代价。
5. 事前给观众一张规则清单或仪式期待，场面通过逐条违反产生悬念。
6. 礼物或公开表现自我暴露：每份礼物显示送礼者如何看待权力、爱或亲属关系。
7. 食物/饮品是服从测试：谁供应、谁先吃/喝、谁拒绝，体现施恩与臣属关系。
8. 公共空间讲台词，服务空间（厕所、走廊、车边、后台、停车场）说真话/做交易。
9. 公开羞辱后有私人清算尾声，把名誉损失兑换成人际损伤或新策略。

不适合的具体部件可按场面类型裁掉（例如没有礼物就不造礼物）；但不能把裁掉后的部分谎称为九项齐全的完整模板。规则若与既有故事事实冲突，优先保事实并明确变体。

## 季终/剧终分支

只在季终/系列终结任务中选择：

- 先检查物质引擎是否失压（交易、职位、资源、继承是否还能制造新选择），不要因人物情绪写不完就自动延续，也不把作者的具体终季选择当普遍结局答案。
- 若选择终季形状模板，列出2–3种长度/集数方案，由负责者选定后冻结；“2–3”是原项目讨论方法的尺度，不是终季集数。
- 先锁定3–5个叙事锚点，其他转折留给写作过程；锚点应包含外部世界事实与人物胜负，不以精密逐集大纲替代发现。
- **画外死亡链**（只用于相似死亡场面）按八步完成：唯一且不可靠的信源 → 旁人把告别变行动 → 三段无回应的贴耳独白（每段不超过8行）→ 否认阶梯逐级收紧 → 谁来告知也是权力动作 → 物理空间把亲属与遗体分开 → CPR/停止抢救/覆盖/股价/宣告等技术节点完成官方化 → 每个岗位按职责行动，讽刺从流程自己显出。
- 设置、守住基调、造对世界后退一步，让机制自行运行；不要在入口处替观众说破意图。
- 可用“退行游戏”作为人物最终共同/分裂意图的测试：先让合作性笑点显示短暂亲密，再让试图说温情的话被打断，未完成的停顿预告关系结果；小背叛预演更大背叛。
- 可用 ghost phone/虚拟遗愿：同一假电话先拿来嘲笑遗嘱悬案，再承接小时候相信过的承诺；不揭开事实本身，让争执转为承诺怎样塑造人物。
- 终季过程可暂时保留多个结局版本，避免提前把人物锁进一份“预制结尾”；终局开放须已结清物质目标，并留下有证据的关系缝隙，不能拿含糊代替结算。
- 重要情感段可以先作为可删的背景层写，利用观众/角色各自观看的东西完成总结；它不得承担主线结算，若删掉会令故事断裂，就不是背景层。

## 编剧室与制作实践分支

仅当用户明确要分析/借用 Armstrong/Prebble 的具体编剧室与制作流程时使用；这些是旧来源记录的个案做法，不是行业规范，也不是本项目每稿的合同。选定该完整流程时保留其具体尺度：

- 每集目标70页以上；pilot约15稿，后续至少30稿、常见约50稿。写长的目的在于对白页和细小瞬间给剪辑选择，不是鼓励无目标灌水。
- 开拍前一两天可收集0–15条备选台词；3–5位编剧从10–20个候选筛成5–10条；拍完剧本版再录一条自由即兴 take。它是片场合作实验，不拿即兴替代剧本。
- 编剧室案例规模8–12人、每日5–6小时；人物名作墙面横轴，集数作纵轴，存活点进入 mega-chart。若在本地复现，先按实际人力缩放，明确已偏离源实践。
- 可以带确定的季末锚点、不冻结抵达路径；提案先给“粗糙可讨论版”再逐步筛除，Pitch 的用途是发现作品“不是”什么；排序时真实依据优先，最好笑的方案偶尔胜出。
- 每场戏至少完成两件事才留；少于两件先砍，除非有独立的节奏/情绪理由可证明。砍下的戏分辨是“不对”还是“位置不对”，后者可迁移。
- 页面、片场、剪辑三个环节都能修改/否决前一版；剧本的终场画面可以留给拍摄现场决定。只有把人物状态与主线目的护到拍摄和剪辑，showrunner 的权力才发挥作用。
- 咨询/救火按商业、媒体、法律、社交、政治等领域找人；每天2–3名编剧在现场是原组记录，不是普遍必须人数。
- 原制作将编剧室放在伦敦，理由之一是远离纽约权力圈带来的“被遗忘感”；只能作为该组的具体工作环境选择。Showrunner在来源中的关键职责是保护脚本经过构思、重写、表演、拍摄和剪辑的连续性，而不是单纯替人物下结论。
- 配歌建议只是意图声明，终剪可删除；因演员表演增加/改写角色，前提是系列结构承得住，不让一处加戏压弯整体设计。

没有用户明确选择该生产分支时，普通剧本不用执行页数、稿数、alts、即兴、房间人数、顾问配置和终剪制度。

## 真实案例与迁移判据

- S2E5 “Tern Haven”：出发前先给 Roy 家禁区清单，晚宴逐条越线，夜间私聊再分派后果。迁移时写清名单、每条越线与谁承担，不借用原台词或家族。
- S1E8 “Prague”/Dog Pound：Roman控诉童年笼子记忆，Kendall否认，Connor给出第三版；随后Connor无意说出父亲的驯犬办法，Kendall听后改变收购策略。它说明第三版记忆必须触发行动，不是供作者展示主题。
- S2E10季终：Kendall完整说完顺从版本后用“But”反转；此前文件中的NRPI再被父亲用作安慰，意图由赦免滑为侮辱。迁移时先完整建立句子/术语，再改变说话人的目的。
- S4E3 “Connor’s Wedding”：从Tom的不可靠来信起，告别被电话变成动作，亲属轮流贴耳说话且无人回应，否认逐级松动，船把他们与遗体隔开，最后用医疗和公司流程完成死亡。迁移时保留八步链，不复制原台词/具体事件。
- S3E9 “All the Bells Say”：24个场景标题、四根长柱；婚礼空主位把仪式变成搜寻。它证明少场长段可由程序和空位支撑，不证明每个季终都只能24场。
- S4E10 “With Open Eyes”：Tom的职位由Matsson的“可替换/承痛”需求和Shiv对Tom的判断共同解释；结尾递掌没有握紧。迁移时让任命理由来自对手/蔑视者，关系结尾落到身体动作。

四季共39集（S1/S2/S4各10，S3为9）；这组数量只作来源语料边界。需要系列参数时，按每集记录问题、容器、时间标记、转移与集末状态，并跨季比较；不用完整复刻39集情节。更多逐集证据、十个set piece和制作记述见 [named-dramaturgy](../../references/named-dramaturgy.md#power-ensemble)。

## 专项编写顺序与验收

1. 定义权力主驱动及人物筹码：每个资源都要能改变某次选择。
2. 选容器和范围；单场只做场内账，系列才加单集引擎、时间区段和季弧。
3. 写权力账：提出—阻挡—转移/僵持—公开结果—私人代价—后续策略。
4. 若选羞辱链、三版记忆、set piece、季终或制作工作流，按相应完整步骤与数量检查。
5. 给每个关键人分开声音和利益，不让全员都尖刻；对白动作要改变关系/信息。
6. 复核赢家是否改变下一步、输家是否仍有行动、每个所谓留白是否已有事实铺垫。

合格的局部场景能说出谁设规则、谁从规则获益、谁控制信息、这次交锋改变了什么；若僵持，能指出维持它的人和成本。合格的连续剧单集在集内回答核心问题，并留下由新格局带出的债务。权力容器若只剩热闹、胜负不改变后续策略或台词只剩机锋，回到筹码和行动重写。

系列压力复核：剧情日/时间区段是否带来权力或信息变化；容器程序是否替代了无效幕钩；单集问题是否回答；人物want是否彼此相撞；羞辱是否被接收者转嫁或拒绝；最弱者/配角是否点破机制；主角缺席期间是否仍产生动作；季形是否有首尾重复量/家族记忆三版/故地回返（仅在选相应分支时）；对手拒援是否有不同理由；玩笑是否有证据回收；扣机词是否提前建立；关键省略是否已有事实铺垫；关系终点是否落在身体动作；季终是否以少数长柱结算并重画阵营；终局是否让可替换者上位（只在选此结局）；是否靠解释宣布意图。未选择的分支只记为不适用，不补齐成风格配额。
