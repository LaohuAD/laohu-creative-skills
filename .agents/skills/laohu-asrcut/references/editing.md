# 粗剪、精剪与表达流畅梳理

判断录音或录屏该留什么、剪什么、怎么排更顺畅时读取。先把内容讲完整、讲明白，再精修气口与接缝；完成后按[时间线与交接](timeline-and-handoff.md)编译和审阅。

## 1. 盘点录制尝试与挑条顺序

先核实来源、主音轨时钟、已知时长、转写精度与同期画面，详见[输入与识别证据](input-and-asr.md)。有真实原音且具备听审能力时，先实听各遍尝试再下判断；缺少原音时按现有转写做纸面盘点，实听与同期画面记作待核。

沿录制顺序标记试麦、半句重启、录制中断、重来和同期系统声，重点连读每个文件边界前后——上段话头未完、下段重复开头通常是同一句重录。同一表达有多遍重录时，按以下顺序挑条：

1. **完整准确**：先选把条件、对象、否定、数字和结论交代完整的版本，不拿残句换顺嘴。
2. **表达能量与笃定度**：同样完整的两条，优先留语气自然、重音落对位置、语势向前的那条，而非平淡念稿式的一遍过。
3. **流畅度与跨条拼接**：前条开头有劲后半卡壳、后条后半顺畅开头发虚时，经实听确认语调、语速、底噪和同期动作能自然接上，才做强头拼强尾。

## 2. 纸面粗剪定脊梁（先管讲清楚，暂不抠毫秒）

动刀前先定两件事：**一句剪辑承诺**（这版要让哪类观众听懂、相信或做成什么，靠哪些真实片段兑现）和**叙述主线**（讲解常走开场问题 → 最少背景 → 逐步证明 → 收束；叙事/纪录常走问题 → 现场与证据 → 转折难点 → 收束）。本身精彩却服务另一主题的段落，归入支线果断割舍。

把跨 ASR 行的未完句合回完整意思后，逐段过三道自检：

1. **逻辑防断链**：准备删掉一段时，只看留下的前句和后句——观众能否顺畅接住动作前提、限定条件、否定词、代词指代和步骤编号？接不住就留住承重句，或在缺桥梁时登记补录建议，绝不伪造原片没说过的话。删半句后单独重读剩余部分，防漏否定词或留悬空编号。
2. **信息密度去重**：分清误录重来、真正无增量的车轱辘话，与逐步演示、纠错、刻意强调和态度转折。只删语义与表达作用均已由保留段完整承接的内容，留住被删版本里独有的条件、例子或转折。
3. **口语与画面伴随词保护**：白板或录屏里的看这里、点左边、划重点、大家看左上角往往正引导视线看向点击、展开或回执。先核同期画面和动作终点再决定去留，绝不按纯文本改文章的标准顺手删掉。

**冲突裁决优先级**：先守事实、原意与用户授权锁定；再按**情绪 > 叙事主线 > 呼吸节奏 > 画面连续性**取舍。宁可留下可由画面或动画遮蔽的跳剪，也不保留拖垮情绪和逻辑的卡壳重录；绝不为抢紧凑秒数砍掉必要前提或系统反馈声。

## 3. 让表达更顺畅的三类重组与授权隔离

粗糙口播不流畅往往不只靠删废话，还要主动辨认三类高频结构重组机会：

- **开场钩子或核心收益前置**：核查当前留下的第一条完整表达能否在最初几秒立住话题、观看理由与可信依据；若后文确有能独立听懂的结果、反转金句或切身痛点适合前置，提出具体前置方案。
- **散落同主题补丁归拢**：创作者录到后面突然补一句前面漏讲的前提、避坑点或注意事项，放原处会打断后文步骤；把它归拢回对应步骤旁往往立刻顺畅。
- **绕口因果或先碎后总顺流**：把倒装说绕的因果或散落解释理成观众一次听懂的先后顺序。

**硬边界（不越权重排）**：
- 未获本轮重排授权时，主版严格沿原录制顺序交付，把上述重组建议单列为**待授权重排提案**——每条写清原时码、原句、拟移位置、流畅度收益，以及移动后代词指代、步骤序号、声调衔接和同期画面是否会穿帮。
- 已获明确重排授权（如用户要求结论前置、调整顺序让表达更流畅）时，直接写入新顺序并逐处核查指代、序号、语调与画面连续性；重复播放同一片段另需独立授权与用途，每次播放分配独立 `occurrenceId`。

## 4. 闭眼精剪、全源账本与重剪报告

内容主线锁稳后，先不看画面闭眼通听语流，清绕口重启、刺耳吸气与过长死寂，并结合语义主动区分讲者组织语言的思考卡顿（`hesitation`，在不切断连读词的前提下抽顺）与该留足情绪和重音的表达停顿（`emphasis` 及有效分句/整句停顿），按[停顿与情绪节奏](pause-and-pacing.md)打磨情绪起伏与安全谷底切口，再回同期画面核动作、嘴形、指针与跳剪风险。

确定每一刀的连续源样本范围后，通过[声明式编辑操作单](timeline-and-handoff.md#用编辑操作单修订计划)修订计划并交唯一编译器重算时钟。

- **完整覆盖与重复溯源**：每个纳入处理的源在已知范围内由连续无重叠的 `retain` / `delete` / `unresolved` 完整覆盖（含头尾静默）；仅选段或 SRT 时限定实际范围并登记未知缺口。因重复而删必须标 `relation: "repeated-content"` 并指向真正保留该信息的 `keptOccurrenceIds` 与 `keptTokenIds`（句段级词列表留空）。已知词时码的切点不得落在词内。
- **重剪披露**：删除占比超过四分之一时（以本轮纳入处理且已知的总源时长为分母，实际删除区间为分子；总时长未知时只列删段不报比例），单独列明删减清单与理由。
- **口语修正与字幕分层**：识别错字勘误走 `spokenCorrections`（未实听只标候选，核听后才确认），屏显字幕走[字幕设计与编译](captions.md)，各不改写原始 `rawText`。

## 5. 审阅交付与逐缝验收

### 聊天版虚拟审阅结构（无落盘授权或先看方案时）
用真实剪辑师的自然大白话交付，把 64 位 SHA-256 哈希、内部枚举字段与工程参数留在 JSON 回执里，不拿日志和黑话刷屏，固定包含五块清晰内容：
1. **剪辑承诺与节奏档位**：一句主线定位 + 选定节奏档与情绪基调。
2. **原顺序全文对照**：按原录制顺序保留完整原句，拟删内容统一用 `~~删除线~~` 原位标出，旁注简短理由与保留对应；保留段标出起止时码和关键画面依赖。
3. **关键取舍与待授权重组提案**：说明挑条取舍与开头/顺序重组建议（含指代与画面穿帮核查，标明主版是否已按授权执行）。
4. **气口修改单与同期声画待核清单**：逐处列语义级别、原长、建议处理、左右源余量及需回听/回看位置。
5. **五项真实状态**：分别写清虚拟方案、时间线编译、实体导出、逐缝核听（分清 AI 实听与真人听审）和用户批准的实际状态。

### 落盘审阅与实体媒体四遍复核
落盘任务按[审阅页契约](timeline-and-handoff.md#html-视图与反馈)由 `laohu-htmlshow` 生成可打开的 `review.html`。有真实剪后音视频时：
1. **逐缝 2.5 秒复核**：运行 `extract-seams` 导出每个真实接缝前后各 1.25 s 切片（近边界据实裁切）。具备听审能力的多模态模型先逐条实听接缝与成品语流，排查吞字、双词、残句、底噪断层、咔嗒爆音、语气断裂和悬空编号；有硬伤立即微调切点重出再交付，并如实区分 AI 实听复核与待用户终听。获准短窗重转写时可辅查跨界疑似双词（整片重转写会掩盖剪口，不能替代逐缝核查）。
2. **按已有媒介分遍验收**：纯音轨听语意、情绪呼吸、响度与底声连续；静音看画面查嘴形、手势、点击与跳变；纯字幕查分组断行与读完时间；声画合看查解说、画面证据与字幕是否争抢。缺哪类媒介即标未执行，绝不代报通过。
