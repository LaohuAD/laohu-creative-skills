# 粗剪、精剪与语义保真

由 laohu-asrcut 在形成剪辑候选、判断口语是否可删或复核完整性时读取。它产出可追溯的覆盖范围、剪辑决定、疑问与顺序；读完回到主 Skill 编译时间线。

## 从完整表达找剪辑单位

先读取相邻句段和上下文，重建每段完整口语表达：谁在说、对象是什么、前提/条件是什么、说话者在否定或纠正什么、证据与结论落在哪里。ASR 的一句一段、自动标点和换行只帮助定位，不自动代表语义完整边界。跨分段的未完句应先还原成完整表达单元，再判断是否需要剪开。

粗剪的作用是建立一版完整可理解的路线：按主题和录制顺序划分可保留片段，识别录制中断、明确重录、完全无关内容和可能重复表达。粗剪先标记候选，不悄悄删除气口、口头语或句段。结构确有缺失时，以问题标注等待判断；不能为了“像成稿”替作者补说未出现的话。

精剪按实际剪点检查语义和声学边界。删除重复的最小单位必须是一段完整意思；保留版本应含被删版本的全部独特信息。若两次表达各有独到限定、例证、情绪或讲解力度，不能以相似度高为由只留一条。完整恢复被 ASR 切开的短语与重排句子是不同操作：前者可在原序中合并连续的源范围，后者必须另有明确授权。

## 语气词、重启与重复

语气词、吸气、重复和停顿只有在不改变说话者口吻、注意力、现场感、解释节奏或必要留白时才可能删。重复表达须区分：无新增信息的口误重说、纠正前句、逐步演示的操作指令、刻意强调、现场情绪、给观众处理信息的停顿。只第一类适合直接进入删减候选；其余要依据上下文判断，不能被规则自动清除。

相似度、相邻字数、ASR 置信度、停顿长度和 VAD 能提示候选，但不证明语义重复、静默或切点安全。候选须记录依据与人工核对状态。识别器语义平滑或自动去口头语可能已经改变证据，不能把平滑后的稿件当作原始语音识别。

## 段落气口：保源停顿、剪口衔接、无源画面时间

讲述的停顿可能来自不同地方，不能只看到时间轴上的“空”就一律剪掉，也不能把画面停留悄悄藏进源音频。对每个有节奏意义的段落边界，先确认它属于下列哪一种，再决定该不该改时间：

1. **保留原录音已有的停顿。** 它是一个正常 source range 的样本，不新增或另造时间。如果停顿承接呼吸、句法、情绪、强调、现场系统声或观众处理刚出现的信息，就保留其原采样范围。若只有 ASR/SRT 行间隔而没有原音，不能断言实际有静音；句段时码精度也不能支持句内静音切割。
2. **剪掉无功能的原录音静音并衔接两段口播。** 先判定停顿确实无功能且删除在本轮授权内，再试听待删段，保护前词尾音、后词起音、辅音闭塞、爆破音与语义完整性。若工作项目的紧凑气口 profile 明确适用于该录屏口播接缝，读取该项目 profile 的总余量目标；这不是普遍音频 padding。其他场景按实际口语/演示功能决定是否留余量，不套固定毫秒数，也不机械给剪口两侧补边。没有可听音频或边界精度不够时，只把相关切点列为待核，不拿 ASR 缝隙或能量零点伪装已验证安全。
3. **插入独立 source-free presentation 时段。** 完整视频/动画及声音制作授权覆盖时，若一句口播已完成一个真实语义单元，而接下来的画面仍需无口播时间让观众读关系、看证据或等待状态落定，由作者判断所需观看预算。先检查被保留原声里真实可用的停顿；预算分别记录来源证据，但观看预算计入已保留且可用的停顿，仅对不足部分新增 presentation。无需为了常规讲解承接逐段问用户；全任务授权由 `authorization.presentationTiming` 记录，单个 presentation 仍须写稳定 ID、决定与理由、正整数项目样本长度、scene/visual/audio handoff。时长依据实际画面负担，不从 ASR 空隙、麦克风零样本或固定模板秒数推算。Audio handoff 表示配乐延续/让位、需要的 SFX、安静窗口或不安排声音；不等于“麦克风没声音，所以最终混音全静音”。

三种时间事实分别记录，不能混淆证据；对观众所需的观看预算，要把保留原声里确实可用的停顿计入，只新增净不足部分。source 内原停顿随来源裁片保留或经授权剪辑删减；source 间经实听确认无功能的空段可以成为 cut；presentation 是独立时段，插入 target clock 后由 compiler 精确推移后续来源与词。若 source pause 有用且足够，不再加时；若被明确剪短，presentation 预算只补足画面仍需的观看时间。纯音频、锁定原音/整片时长或需要改讲述内容时暂停冲突的插入，继续完成不依赖的工作。Motion 已拿到冻结计划后若发现缺少解释时段，要把具体语义边界、画面任务与净新增预算理由交还计划作者修改；不能自行拉长视频或重算词锚。

## ASR 修正与确认口语

原始 transcript 及 token 的 rawText 永不被改写。需要纠正 ASR 时，把 source、segment、可选 token、原始识别 text、拟确认 spokenText、状态与依据写入 spokenCorrections。未经实际核听的修改只能为 candidate；不能把上下文合理、模型推断或对齐工具结果写成真实口语。确认项要声明 audio-listening、listened，并以源样本范围精确绑定被改词或句；对齐器的词边界可另外标记 alignmentStatus=aligned，它只证明时间定位，不能代替听辨字词。编译器在确认项上保留 raw `text` 并附加 spokenText，候选不进入时间线的已确认 spokenText。屏显文案写在 displayText，不能借 ASR 修正字段表达编辑润色。

音频切点以实际采样或可靠词边界为准。删除片段首尾的静音不能切掉辅音起音、爆破音、齿擦音或尾辅音；呼吸可以承接语气、句法、情绪或镜头节奏。存在系统声演示、音乐、环境声音或画面动作依赖的停顿时，不把“没有人说话”当成“没有信息”。切点不确定时留在原处并列问题，不制作一个声学上听起来干净但语义已经变义的拼接。

## 完整覆盖与决定账本

每个 source 在本轮声明的 sourceScope 内切成连续、不重叠的 coverage 项，并分类为 retain、delete 或 unresolved。已知持续时间且要求处理整源时，coverage 从 0 到 durationSamples 不能有未分类空洞；每个来源都必须有 coverage，缺整段来源也不能报完整。已知的头尾静默也要显式分类，不可遗漏。用户只给某段或某个 SRT 时，将 scope 限定为材料实际覆盖区间，并标记完整媒体范围未知。

每个 delete 项都要有 decisionId、源区间和原因。重复删除项另标 relation=repeated-content，引用承接完整内容的保留 occurrenceId 与对应 tokenIds。没有对应的保留实例时，不得标成“删掉重复”；可以依据其他理由删除，但保留独立审计原因。保留项含完整词区间与原文；有词时间时剪点落在词内部即校验失败。没有词时间时只支持句段级剪切；在句段内部切分必须先补可信时间/原音核听，无法确认时保持整段。

多个源的 scope 或时钟无法对齐时，分别保存其范围，跨源相对顺序标为 unresolved。只有明确的源时间、偏移或用户指定顺序可以形成可编译顺序。缺少录制时长意味着无法证明输入尾部已覆盖；这不阻止只基于 ASR 生成句段级虚拟报告，但媒体导出须阻止，直到映射到实际源媒体并核全范围。

## 重排、合并与授权

用户未要求调整重点或顺序时，sequence 应按源范围原序保留。用户明确授权后，在 plan.authorization.reorder 为 true 且存在对应 decision 时才编译非原序 sequence。计划须记录改前来源顺序、改后顺序或对应 occurrenceId、理由和授权引用。编辑者可提出建议；没有授权时只展示候选，不写成最终 sequence。

相邻保留区间可形成一个输出 clip，但不能丢掉每段 sourceRange、词实例和删除区间。coverage.tokenIds 必须按原 transcript 句/词顺序列出；修改数组顺序不能冒充音频重排。重复使用同一来源范围须创建不同 occurrenceId，且有明确重复/强调目的与授权；相同 tokenId 可出现在不同 occurrence 的目标时间位置，但每个运动绑定必须同时指定 occurrenceId 和 tokenId。

完成后由编译器检查完整覆盖、删除对应、保留文本、整词边界、时钟连续性和重排授权。检查失败时只阻止受影响的剪辑或精度路径，其他来源无依赖部分可继续；报告把未知问题与已完成结果分开呈现。
