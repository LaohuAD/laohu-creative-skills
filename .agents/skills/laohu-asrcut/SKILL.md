# laohu-asrcut

先让源声音在原意上讲得完整，再用真实声画证据收紧气口。以保留的源样本决定统一时间线，让字幕、审阅、视频与动画沿同一讲述节奏继续制作。

## 从任务目标进入工作路径

| 目标 | 当轮加载与动作 | 交付 |
|---|---|---|
| **剪录音、录屏、转写或改旧剪辑** | 读[输入与识别](references/input-and-asr.md)核精度，再按[粗剪与精剪](references/editing.md)确定源片段和取舍。需要修气口时读[停顿与剪口](references/pause-and-pacing.md)，编译、审阅或导出时进[时间线与交接](references/timeline-and-handoff.md)。 | 默认虚拟剪辑，包含 edit-plan、canonical timeline 和可打开的 review.html。有真实源和明确出口时再交新 WAV、视频或 NLE 交换文件。 |
| **只有句段字幕，想调口播节奏** | 查[句段级精度](references/pause-and-pacing.md#6-随真实素材降低精度)，按现有句段时间处理。 | 用「已收到的节奏偏好」转述用户想要的气口。「当前可安排的修改」写整句删留与句间空档候选。例如「你希望逗号处有约 0.4 秒气口。本轮第一句保持原状，句间空档等回听后再定。」 |
| **已有时间线，只做字幕** | 读[字幕](references/captions.md)，将已有或本轮已定的语义分组、显示语种和真锚点编译到同一时间线。 | 字幕 manifest 与同源 SRT。 |
| **只修口播声音** | 直接读[口播声音处理](references/audio-postproduction.md)，用连续原音诊断、试做及复核。纯修音无需 ASR 或虚拟剪辑。 | 独立 audio-plan、新处理 WAV、处理回执与等响度 A/B 审阅页。 |
| **完整口播视频或动画** | 在剪辑路径上锁稳讲述，将真实保留片段、自然呼吸窗、词或句锚和跳剪风险按[动画交接](references/timeline-and-handoff.md#动画交接)给 Analysis 与 Motion。画面需要额外停讲时间时把具体边界和净预算交回同一计划。 | 同版 edit-plan、timeline、可选 animation-handoff 与可审阅媒体。Analysis 承接完整表达设计，Motion 实现视觉、工程应用与最终混音。 |

普通输入可以只有“帮我剪一下”和一份录音。先确定观众要听懂或做成什么、手头证据能支持何种选择、是否需要实际导出。已有可用 ASR 优先复用。原音未附转写时核对现有识别条件，再继续不依赖所缺授权或媒体的部分。来源只提到录音、字幕或修音时，按实际所求成品选择路径。组合交付按需要接对应步骤。

只有用户回听笔记、没有原音时，在停顿修改单直接交一行「证据与落刀条件」。标出量得的时长来自用户笔记还是 ASR 空档。若实际落刀要用自动词时码，先回听核轻辅音是否早于标记。同期声复核只针对笔记没有覆盖且可能影响剪口的位置，已明确无演示声的区间沿用现有记录。

## 六项交付边界

1. **三层文本保护。** 永久保留原始 `rawText`。只有定位到已核听原音的确认修正才能进入 `spokenText`。屏显 `displayText` 与字幕清单另存。只改显示文字仍是显示编辑。
2. **唯一时钟和独立双哈希。** edit-plan 是剪辑决定真源，目标样本由唯一编译器派生。剪辑绑定 `planSha256`、局部旁注绑定 `annotationSha256`，同时核项目、revision、对应源和出现实例。采用原料的句段或词级精度，过期锚点回当前版本重编。
3. **语义与原声双保护。** 保留完整条件、否定、证据、语气、起音和尾音。自然微停顿 ≤ 0.35 s 默认整段保留，功能性停顿先护实际作用。删减与切点要同时有依据和授权，长度、相似度、置信度和 VAD 只提候选。
4. **权限和原件。** 默认制作可审阅的虚拟剪辑，原录制顺序照录。重排、重复、实体导出及新增展示时段按本轮具体权限执行。可用源、相对偏移和真实范围逐一核实。输出写入新路径，保护原媒体、识别证据和已有工程。联网识别须已有上传与费用授权。
5. **分别报告五种实际状态。** 说明虚拟计划、时间线编译、实体导出、逐缝核听及用户批准是否已完成，附已存在文件或实际依据。只在实际运行唯一编译器并核验同版计划与时间线的产物后报告已编译，给出实际文件或哈希。仅作建议或无法运行编译器时，照交有依据的估算或虚拟草表，标注未编译。冻结与哈希表示版本稳定，试听和批准各自需要独立证据。
6. **审阅页先交给人。** 用可打开的 `review.html` 展示原句、删留、理由、原/目标时间、调整前后气口和未决事项。原音和剪后媒体各自核实后提供相应播放入口。反馈核对版本、决定与注释身份后由编辑者处理。

## 普通剪辑的执行顺序

1. **盘点录制尝试。** 核同版源、证据与轨道关系，通读每个 take；有原声时回听并用 `probe-silence` 缩小谷底和原声底噪候选。
2. **先做纸面粗剪。** 定一个剪辑承诺和讲述主线，检查删减后观众能否靠留下的信息走到下一步。清理无功能的试麦、重录和支线，录屏里指向画面操作的伴随词与实际动作一并查。开头有试麦或重录时，审阅表写出保留的当前首句。后文确有能独立说明观看收益的句子时，按[开头检查](references/editing.md#2-做纸面粗剪并保全论证)附原时码、原句、画面依赖与是否建议前置，获准才调整顺序。
3. **再闭眼听语流。** 按真实意思分级气口，按用途选节奏档。定位安全谷底、保声学余量，再回同期画面评估跳剪。按已核实的源范围写声明式编辑操作，编译器负责拆覆盖、保留原词和重算时钟。
4. **生成审阅并验收出口。** 提供原位删留、决定和待核项，实体媒体逐缝检查并按实际范围分遍审看。授权下游读取同版的时窗和锚点。仅有转写时先交其精度可支持的虚拟成果，标出实际媒体的阻断点。

需要作者作一次会改变表达的新决定，且本轮已授权完整声画制作，或用户明确要研究剪辑表达时，按[本地作品方法库检索路径](../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)读取匹配原媒介或方法卡，再回到当前选材。忠实编译、按冻结计划出片、普通转写和锁定清理沿已有决定执行。

## 常用操作

实现入口从 `{SKILL_DIR}/scripts/` 解析，用当前工作项目的实际输入、输出和同盘临时目录。下面列出命令阶段，字段与示例在对应 Reference。普通用户只需提供目标和可用材料。

| 操作 | 命令 | 需要的证据或下一步 |
|---|---|---|
| 接入原始证据 | `asrcut.mjs import`、`merge`；已获准时 `transcribe` | [输入与识别](references/input-and-asr.md)核文件、时钟、来源顺序和上传条件 |
| 找安全气口、试剪、编译 | `probe-silence` → `apply-edits` → `validate` / `compile` | [操作单字段](references/timeline-and-handoff.md#用编辑操作单修订计划)与[停顿证据](references/pause-and-pacing.md) |
| 收到反馈或增加观看时间 | `annotate`、`insert-presentation`，修改后重编 | [审阅页](references/timeline-and-handoff.md#html-视图与反馈)与[无源展示](references/timeline-and-handoff.md#无源展示时段) |
| 导出新音/视频或 NLE 交换件 | `freeze` → `compile` → `export-audio` / `export-video` / `export-nle`，用 `extract-seams` 辅助核听 | [实体导出](references/timeline-and-handoff.md#音频视频与交换导出)核许可、时钟和回执 |
| 交接动画 | `export-handoff` | [动画交接](references/timeline-and-handoff.md#动画交接)绑定冻结版本 |
| 做字幕 | `compile-captions`、`export-srt` | [字幕契约](references/captions.md) |
| 处理口播声音 | `audio-postprocess.mjs create-plan`、`process` | [独立声音处理](references/audio-postproduction.md) |

交付时先核对实际生成、可打开的审阅入口，再给 edit-plan、timeline 或本轮其他已完成文件的准确路径。确认完整覆盖、决定与保留实例、精度、版本、完整原话和同期事件。媒体缺失时说明导出不可用、对应的试听未执行，并给可用虚拟结果。
