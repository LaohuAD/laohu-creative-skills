# 老胡口播与录屏剪辑

先让源声音把话讲完整、讲顺畅，再用真实听感与声画证据打磨情绪起伏和气口。以保留下来的源样本驱动唯一剪后时间轴，让审阅、音视频成片、字幕与下游 `laohu-motion` 沿着同一讲述节奏衔接。

## 多模态实听与保守退回双轨

- **具备真实音视频理解能力且手头有原媒体时**：把耳朵和眼睛作为剪辑主判断。剪前先实听原片（辨认情绪起伏、重音、哪遍重录更有能量、自然换气、笑点或反转蓄力、环境底噪与系统提示声），剪后和修音后实听接缝切片、成品语流或等响度 A/B 对比，听出吞字、发赶、情绪截断或降噪发闷就主动再调一轮。波形探针只负责帮耳朵锁定精确采样坐标和零交叉点，不替代听觉审美。
- **缺原媒体或不具备音视频听看能力时**：按现有素材精度保守推进，交出可核对的虚拟方案与待核清单，绝不把估算写成实听结论。
- **诚实分开两类核验**：脚本导出回执初始状态始终记 `not_auditioned`。AI 多模态实听复核的发现与调整单独说明，绝不冒充用户本人终审或签字批准。

## 六项交付硬边界

1. **三层文本严格隔离**：永久原样保留原始 `rawText`；仅经真实原音核听确认的勘误才写入 `spokenText`；屏显 `displayText` 与字幕清单独立维护，改显示文字不等于剪了音频。
2. **唯一时钟与独立双哈希**：`edit-plan` 是剪辑决定真源，`timeline` 须由唯一编译器派生。剪辑绑定 `planSha256`，局部旁注绑定 `annotationSha256`。重复片段与同名关键词必须同时绑定 `occurrenceId` 与 `tokenId`。精度随素材忠实降级，句段级 SRT 绝不拆字伪造词时码。
3. **取舍优先级与按意图判气口**：冲突裁决按**事实、原意与授权锁定 > 情绪与叙事主线 > 呼吸节奏 > 画面连续性**排序。先听辨文字与语流背后的表达意图，再决定套不套留白表：讲者边想边找词产生的思考停顿（`hesitation`）应在不切断连读词的前提下果断抽紧，绝不生搬常规句停表留出卡顿感；完整命题、重音强调（`emphasis`）、自然流畅微停（≤ 0.35 s）、录屏伴随词及五类功能性停顿则坚决护住。长度、相似度和能量阈值只提候选，不构成自动删减授权。
4. **权限与原件零覆盖**：默认交可审阅虚拟方案并保持原录制顺序。重排、重复播放、实体音视频导出、插入无源展示时段与付费云识别各需本轮明确授权；未要求裁短片尾余量时先保留并征询，不越界先斩后奏。一切产物写新路径，不覆盖原媒体、识别证据与既有工程。
5. **五项真实状态分别报告**：虚拟计划、时间线编译、实体导出、逐缝核听（写清 AI 实听还是真人听审）与用户批准各自独立陈述；只有实跑唯一编译器并核对同版产物后才报已编译，纯纸面建议直说未编译。
6. **审阅先交给人**：落盘时交可打开的 `review.html`；聊天汇报一律用普通人看得懂的大白话，带原位 `~~删除线~~` 对照、改动理由、气口单与简明复核步骤，把 64 位哈希、内部枚举字段与脚本参数留在 JSON 回执里，不拿工程日志刷屏。

## 普通剪辑的四步闭环

1. **盘点与实听探底**：核来源、主音轨时钟、多轨偏移与精度；有原音时先实听各遍录制，并用 `inspect-media` 和 `probe-silence --noise-db auto` 定位底噪、谷底候选和起音偏移风险。
2. **纸面粗剪定脊梁**：先写一句剪辑承诺与讲述主线，挑出最完整且有能量的 take，清试麦、误录重来与跑题支线，检查删后逻辑不链断、不误删录屏伴随词；发现能显著提顺畅的重组机会时按授权决定直接执行或单列待拍板提案。
3. **闭眼听语流修情绪与气口**：先分清哪些空白是讲者组织语言的思考卡顿（`hesitation`，须在不切断词的前提下抽顺），哪些是该主动保留甚至留足的重音与情绪落地拍（`emphasis` 与各级有效停顿）；按用途选节奏档，选真实声学谷底和零交叉落刀，再回同期画面查动作与跳剪风险，通过声明式 `apply-edits` 编译唯一时间轴。
4. **审阅、逐缝复核与交接**：交付清晰审阅入口；实体导出优先采用零漂移交叉淡化消除爆音与底噪掉坑，跑 `extract-seams` 逐缝复核并分遍审看已有媒介；对接动画时派生含情绪节拍、可用呼吸窗与精选视觉词锚的 `animation-handoff.json`。

仅当用户明确要求研究或借鉴外部剪辑手法时，按需调用[作品拆解与方法库](../laohu-benchmark/SKILL.md)；普通按需剪辑、忠实编译和按冻结计划出片直接沿本地方法推进。
