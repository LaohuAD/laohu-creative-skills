# 按位置锻造关键短句与标题

**一切短句都只为最终作品的真实感染力与传播结果服务，先辨输入再精准发力**：用户已在追求高水准并给出了不违背规律的明确方向、切口或风格时，**完全尊重并沿该方向做透**；表达模糊宽泛时，守住基本方向穿透挖出底层情绪与受众关切，主动向本领域顶级标杆补齐升维；字面要求或原始外壳明显偏离好标题／好歌规律（如硬塞狭隘行业词、干瘪流水账或低美感都市杂物）时，严守真实事实底线与逐字锁定项，抽出不变的核心情绪与主张重构换血带回正道。

短句站在不同位置承担完全不同的使命，本入口采用**极简通用定标 + 四大内部三级专项单向分轨**，让每个位置都只用最对路的手艺发力：

- **门外入口（封面、平台发布与搜索/GEO）**：用 100% 顺口的活人大白话与高唤醒情绪，演活半截跟读者有关的微型故事，让读者看完心里自己冒出为什么、忍不住点进来看详情。
- **门内导航与作品命名**：读者已进门，核心是 10–18 纯汉字短促见骨地总结骨架与精准识别母题，按门内阅读逻辑独立构句。
- **篇内文章关键句**：负责下结论、定判断的活人钉子句，18–34 字短准狠、单句立稳前提、兼具社交货币穿透力，嵌回上下文像原作者亲口说出来的下一句。
- **歌词副歌核心句**：整首歌情绪曲线冲上最高点、堤坝决口、情绪失控时的抒情大爆发与最强记忆钩子（歌眼）——灵魂筋骨血肉跨风格不变，表皮语言组织随曲风与 `laohu-lyrics` 灵活变通。

## 1. 先判模式、范围与两阶段解耦协作分工

- **独立创作或重拟**：在材料主题、作者立场与锁定项内放手取最强切口；**仅诊断**先从立意、情绪、信息缺口或前提边界自上而下揪出拉低上限的最早断点，再按位置审词句，不代写整包；**原句改良**守住原对象、受众关切与锁定字面，原切口已成立时优先保住只修疤（不为显摆改稿把好句改平），单平台默认交三层梯度（微调 / 重构 / 换切口）；**纯咨询或无材料**停在当前只索取最小缺项，有真料才落笔。
- **两阶段解耦协作定位**：当与 [laohu-writing](../laohu-writing/SKILL.md) 或 [laohu-lyrics](../laohu-lyrics/SKILL.md) 联合作战时，本入口担任**第一阶段单点爆破大脑**——先独立锻造并锁定核心爆点（封面/发布大钩、文章题眼与钉子句、歌曲副歌核与歌眼），再交回下游切入低水位克制铺垫大脑编织正文或主歌，避免一锅煮引发双向风格污染；若接手下游已写好的铺垫或预副歌来立爆点，专门承接前段制造的悬而未决的紧张蓄压（Tension）完成高对比释放（Contrastive Valence），不在高潮区继续解释前段比喻或竖起理性防御盾牌。
- **跨入口交接**：开放探索若改动文章核心主张或结构，附依据交回 [成稿与标题交接](../laohu-writing/SKILL.md#成稿与标题交接)；视觉出图与审图交 [laohu-cover](../laohu-cover/SKILL.md)；整首歌词多段成稿与曲式展开交 [laohu-lyrics](../laohu-lyrics/SKILL.md)。
- **专项咨询与查库（常规创作不额外加载，保持专注与灵气）**：仅当用户专门问渠道影响、平台证据或虚词边界时，按需读 [entry-psychology-and-platforms.md](references/entry-psychology-and-platforms.md) 或 [language-mechanics.md](references/language-mechanics.md)；仅诊断、复杂竞争复审或正式人类标尺评估按需读 [title-value-and-review.md](references/title-value-and-review.md)；仅做完整 6 平台发布包、开放重拟多路线取舍或用户点名查库时，按 [本地资料库分层检索](../laohu-benchmark/references/library-retrieval.md) 只读查阅本入口旁 `benchmark/`（收录归 [laohu-benchmark](../laohu-benchmark/SKILL.md)）。

## 3. 记忆点六大武器与三秒质检（跨四专项唯一真源）

100% 单层闭合的正确短句往往听完就忘；高传播度的标题、篇内金句与副歌歌眼，核心来自**最优创新假说（熟语微拧半寸）＋ 预期违背顿悟 ＋ 接受美学召唤空白**，留出零点几秒让受众自己接通第二层含义或填进自身经验：

1. **表里双轨 / 语义双关**：用清白体面的日常词面皮，包裹落进语境便一秒意会的私密经验、关系暗流或人性里子（零粗俗，全靠脑补引爆讨论欲）。
2. **熟语微拧 / 同词异义 / 谐音轻转**：借大众闭眼能背的熟语或高频词只拧半寸，或让同一词的两种词义正面对撞（零理解门槛且余味翻倍）。
3. **语意反转 / 前扬后劈**：前半句顺着理性、温和或奇观建预期，后半句急刹翻面亮出扎心真相。
4. **反讽冷刀 / 降格留白**：用极客气克制的语气刺穿最残酷的身份降格或代价，表层风轻云淡、底色见血。
5. **陌生化跨界撞击**：把抽象情绪或老生常谈撞进冷峻的物理、空间或异质动词里，强行打破审美麻木。
6. **人性公理 / 空槽召唤**：用极简对称短句定格人性真相，或搭出仪式感空槽召唤千万受众套入自己的故事。

**三秒质检硬杠（拒烂谐音梗与油腻抖机灵）**：① 第一遍读听顺滑零门槛、停半秒第二层含义咔嗒击中大脑；② 100% 服务核心情绪与主题痛感，不为炫技出戏；③ 单独截出仍自带社交货币与转发传播力。

## 4. 跨场景三条铁底线与洁净交付

1. **先放飞保双向之雅与锋芒，成稿后轻扫疤并单核写实断言**：起草时先立灵魂海拔与情绪张力，放手写出活人锋芒，做到**向内凝练体面、向外零防御直击真相**（去粗鄙戾气，也破温吞防御壳）；遇字数上限或押韵约束时，先逆向敲定现实汉语里完整无歧义的实词核心与句尾落词再往前顺句，从源头杜绝硬凑字截肢名词与空洞形容词填坑；成稿后遮住说明出声扫疤——确保 100% 语义通顺、零断句歧义、动宾人际站位真实、不滥用装饰引号，再逐条单核数字、经历、来源与已发生事实，严禁编造原稿没有的数据或成果，出错只修事实不磨平锋芒。
2. **对内显密、对外全透，严守锁定项与证据边界**：后台按领域原理精准裁决，面向用户的交付文本与说明一律解压为干净人话、零理论黑话；逐字保护锁定作品名、原话与已定立场；无真实点击、排名或配曲试唱数据时如实标明待核，规则与分析中不拿自拟标题冒充真实经典范例。
3. **洁净可直接复制交付**：只交用户要求的字段、准确数量与极简大白话说明，语言清爽克制；独立成品与设计交接单按 `docs/runtime.md` §4 包入干净代码块，用户要求纯净字或指定格式时严格照办。
