# 从材料凝练关键表达

先找值得留下的认识、关系、感受或细节，再把它写成准确、有声口、有分量的表达。具体人物、事件、数字、原句、意象或直接情感本身有价值时保留。句子可以有材料支持的多义与余味。缩短、改写语序或加强修辞，都须让原有信息或体验更清楚、可记。

按[万能造梦框架](../../../references/universal-dream-framework.md)定清成品目的、接收者、材料及实际位置，从里面选内容再成句，最后嵌回、比较和修订。观察方向仅用于内部查缺。保留用户锁定的观点、作品名、引文和原文。可以写出材料支持的情绪、愿望、立场、比喻或力度，也须区分作者推论与可核实事实。规则、Reference、评测和分析说明不得新增 AI 自拟标题作为教学范例，也不得把它们当成真实作品、用户材料或人类标准答案。经授权的作品创作与真实目标执行按正常流程交付。

## 1. 先确认模式、字段与授权

| 模式 | 取材和交付边界 |
| --- | --- |
| 独立创作或重拟 | 在材料主题、作者立场和锁定项内选入口。已有旧题但用户要独立重拟时，可以另找材料切口。 |
| 仅诊断 | 按实际用途读取相应模块的诊断条件与[成品复审](references/title-value-and-review.md)。只审原句。材料缺失时照常检查句面，将兑现、事实或字段中的具体缺口标出来。 |
| 原标题或关键句改良 | 先保住原句已有的核心对象、面向的受众任务/情感、主要关系、查询意图与锁定文字，依次比较局部修词、保关系的结构调整、同目标的不同技法。同一平台未另定数量时按三个层次各交一条，明确数量优先。原句与候选并读，材料仍支持的时间、结果或情绪吸引方向先保留，逐项可核断言在候选确定后检查。 |

用阅读位置和任务决定功能。先确定字段、预期数量、媒介、最终接收者、材料、锁定字面与认识开放度。只补会改变选材、用词、语气或交付接口的缺项。写作交接带实际段落、前后关系、已读背景、句子职责与作者声音。范围只及表达时，整段、全文结构、整首歌词和旋律由原负责人处理。普通过渡、解释和叙述交回 [Writing](../laohu-writing/SKILL.md) 处理。用户明确要点出判断变化的转折定调句时，在原位置做凝练。

用户要先了解拟题方法、材料或字段，或尚无能支撑拟题的材料时，完成当前咨询。用一张清单逐字段说明用途、默认数量和所问的预算证据；有合计需要时，从这张清单的各项数量得到。只问封面与发布字段如何分工且范围尚未定时，交代完整发布包的默认范围和可缩小方式。

需要拟题准备或问成句方法时，在答复写明正常顺序。先从原稿取事实、细节和读者关心的具体处境；选最能承载它的关系或意象，写词成句并炼字；再遮住理由看标题自己是否成立，选定后逐条核具体事实断言。只索取会影响拟题的原稿、受众/字段及锁定项。没有拟题授权或真实材料时停在咨询。

只问搜索、推荐或发布字段的证据边界时，读[标题影响与渠道证据](references/entry-psychology-and-platforms.md#按渠道判断标题能影响什么)和实际需要的字段表。逐个所问渠道先给作者能执行的做法，再交代系统怎样使用标题、哪种效果仍需实测。问到 Google 自然搜索，答复须同时讲清如何准确描述页面并避免关键词堆砌，以及搜索结果为什么可能改写显示标题。问到平台排名，把站内检索的用词和信息流推荐的观看理由分开解释。

旧 AI 候选已被用户拒绝、且本轮没有可承接的正文、作品材料、用户认可的原话或明确选定的表达方向时，暂停拟题，只补真正需要的原稿或材料。用户给出了要保留的原句或明确方向且授权句面改良时，可在该范围先处理，正文兑现和可核实事实仍随材料核验。

## 2. 给表达定标

1. **接收者应得到什么。** 从改变认识、推进任务、建立篇内地图/记住作品、凝定体验中选主要结果，必要时明确次要结果。先在原材料圈出真实动作、事件、细节、分歧、反复出现的选择或关系。读者范围与在意强度分别看，具体小群体也可能很在意。信誉线索只取材料或获准核实的来源。
2. **与位置相配的具体度。** 教程、工具、实用发布字段用具体对象和可见动作、场景、结果或有依据的数字。导航标题对齐本节的实际信息颗粒。原则、观点题眼、思想随笔和情感收束允许抽出判断或立场；留下至少一处原材料支撑的对象、动作或意象作锚点。专名和富有价值的直接情感也可作核心。
3. **读者需要费多少力。** 快速滑屏默认最多用一个对目标读者陌生且确需识别的术语，紧邻熟悉处境或动作。明确的专业受众或精确查询以读者实际需要辨认的术语为准。篇内、歌词可接续已经建立的专名和语境，只留下当前位置需要的线索。读者看不到的事实、作者解释和方法标签不能当成句面已经交代的内容。

作者已锁定主张时，在其范围内凝练。获准开放探索时，可以提出由材料支持的新认识。若它需要改动文章核心主张、证据推导或全文组织，标出新认识、依据和受影响处，返回 Writing 依[成稿与标题交接](../laohu-writing/SKILL.md#成稿与标题交接)核授权后走 Analysis，再由 Writing 返回成文。局部措辞、音步或获准调整的桥句由当前负责人直接处理。

仅咨询关系、配价、虚词、评价力度等成句判断时，直接按需读[语言方法](references/language-mechanics.md)及有必要的原材料，解释所问，成品模块随实际生成或诊断任务启用。

这些模块只由本父级按当前实际字段选择并整合。复合请求按每个字段分别执行，以用途分栏；题材相同可以共享材料，字段判据按用途各用其应读部分。只点名部分平台或字段时只交指定范围。已有明确数量与机器接口优先；单个字段也可只要一条。仅在用户请求独立、完整封面与平台发布包且未缩小范围时，才启用入口模块的默认 21 条。

### 核实需要的作品方法

完整发布包，或独立重拟时有数项真实材料入口，选择会实质改变句法、关系、声口或留白的，起草前定一个具体作品取法。已指定的相关作品或同目的、同版本的新鲜检索与详情可以直接复用。

否则先按[本地资料库分层检索](../laohu-benchmark/references/library-retrieval.md)实际查本入口旁的 `benchmark/`。库可用时，按本轮实际要解决的表达问题有界检索。

1. 先从用户说法或所给材料中圈出一个最能区别本次写法的具体意象、动作或关系词，尽量保留原词，用它作一次短查询。优先取能说明这次要怎样表达的词；概括出来的技法名可以补充，原词仍留在查询里。
2. 找对应作品片段用材料查询，找可迁移的写法用方法查询，先看一页。结果为空或关系弱时，取原话中第二个有辨识度的词再查一页，首轮查方法时补查材料，首轮查材料时补查方法。
3. 有候选确实对应本轮要处理的关系时，打开原作单元或方法详情并核适用条件，按[作品方法回交](../../../references/exemplar-study.md#从本地作品方法库检索并返回决定)落实到实际词句。库不可用或结果仍无相称方法时，使用本地 Reference 中已核且能实际指导写法的作品处理。取法和核验属于内部工作，传播效果另需实证。

仅诊断、原题局部改良、按已定切口交接篇内字段、单独为 Cover 或视觉同事交封面标题文字，以及校对或格式落地时，沿字段所需方法继续。用户明确要求取用实际作品或资料库时按其意图处理。一篇原稿只是材料，是否查库由上述具体创作决定触发。读库和采用方法只读，收录规则见[研究库检索与收录](../../../docs/runtime.md#作品方法库的检索与收录)。

## 4. 复审、修订和定量回交

成句后或仅诊断时，读[标题兑现与竞争复审](references/title-value-and-review.md)的共同复审和实际用途分支。从交付中抽出真实句面，遮住作者解释和技法标签，在它实际所在的标题位、章节、段落或词段比较。核材料能否承接、所用关系和声口是否合适、锁定项是否保住，以及候选在这一用途下是否真正胜任。只有现成句时判断句面能成立的范围。材料不足时只在依赖它的判断处标缺口。

确定候选后再逐项核可验证断言，包括事件、数值、来源、经历、因果、结果。事实改正只动出错的断言及直接依赖，保护成立的体验、观点和表达力度。若用途、取材、词句或字段有误，回到相应的最早决定重做，再以实际最终文本复审。范围和数量按完整可独立使用的表达单元核对。只交用户要求的字段和必要的取舍；精确格式或纯字面交付按原契约输出，制作/证据信息留在允许的附注或交接中。默认在聊天返回，真实点击、传播、搜索或演唱效果须有相应接收证据。
