# 凝练值得表达的内容，不是把句子缩短

本 Skill 的共同工作，是从经历、事实、观点、故事或意象中找出值得表达的认识、感受或关系，再把它凝练成准确、自然、有声口、有分量、有意味的关键表达。凝练不是删长话、压字数、摘摘要或把句子装饰得漂亮；目标是让要留下的内容更清楚、更能成立、更能被记住，必要时也能让不同经验彼此照亮。具体人物、事件、数字、原句、意象或直接情感本身有价值时，就保留它；不把每段材料都抽象成普遍道理。可以保留有材料根据的多义与余味，但不为了含蓄而故意写得看不懂，也不要求每句话都像广告或格言。

标题是这项工作的一个应用位置：文章主标题、封面或发布标题把读者带入整篇内容，须把读者在意之处与文章能提供的认识、经历、后果、故事或审美体验接起来；章内小标题帮助已进入文章的读者辨认本节作用、理解推进或转折，不要求每节都成为独立广告或脱离全文复述整篇主题。其他受托关键表达包括题眼、中心/总结/收束/过渡/原则句，以及歌词副歌核心句；它们分别服务作品或段落的实际位置，不是互不相认的模板。所有位置都须回到材料和语境验收，不能靠作者事后解释补上句面没有承担的作用。

本 Skill 可处理关键表达文字，不代写整篇正文、整首歌词或口播稿，不替作者改定已锁定的观点，不包办旋律；章内或篇内句依据写作负责人给出的所处位置、相关正文/前后关系和句子职责处理，只补会影响判断的最少上下文。歌词副歌核心句只处理本轮委托的单句表达，按可获得的歌词/歌曲材料和声音条件协作，不把无旋律试写说成已验证可唱。它不制作或检查封面视觉，不发布内容，也不保证点击、曝光、搜索排名或传播效果。

保留用户锁定的作品名、引文与原文；不编造数据、来源、作者经历或材料没有提供的结果。愿望、情绪、立场、有力修辞和比喻不自动等于事实承诺。候选确定后再核其中具体可核实的断言；有误时只修那项，保留仍成立的吸引方向和力度。标题业务按用户授权正常创作与交付不受此限；但 Skill、Reference、评测和分析说明不得新增 AI 自拟标题作为教学示例，也不得将其冒充真实作品、用户素材或人类标准答案。

# 从材料到关键表达

下列流程把[万能造梦框架](../../../references/universal-dream-framework.md)落到关键表达职责，不是类别表、问卷或对外报告。正常路径连续完成：理解任务及可达语境 → 从材料发现值得留下的内容 → 选择适合该位置的专业方法与材料 → 成句、炼字 → 放回真实位置比较、复审和修订。作者开放结论时，可以从材料提出有根据的认识；作者已锁定主张时，沿其范围凝练，不偷换观点。16个观察方向只用于内部查缺和选择专业方法，不向用户展示填格表。局部任务跳过无关步骤，但不能跳过真正影响句义的上下文。

## 1. 定清任务、材料、作者开放度和交付

先识别本轮是独立创作/重拟、只诊断原标题、改良原标题，还是为文章/歌词中的特定位置承担一个关键表达；确认已有材料、读者/听者、句子职责、实际嵌入位置、字段/平台、锁定文字、数量和用户已作的选择。复用已有信息，只补会改变取材、用词、语气或字段的缺项。确认作者是否允许从材料提出认识，还是已有必须保留的中心判断；没有正文时仍可诊断句面，但正文承接、事实或平台合规待核的部分应标明，不把诊断扩成完整作品或标题包。

独立创作有权从正文另选入口，即使用户提供了旧题；仍保护实际主题、作者立场和锁定项。原标题改良则先提取核心对象、受众任务、利益/欲望、查询意图与锁定文字，沿同一方向逐步尝试小改、保核心关系的结构调整、再到不同技法，不换题。用户要求仅诊断时只评价给出的句面，不擅自生成候选。用户明确锁定标题或改写范围时，按其边界执行。

调用来自写作任务时，先辨认受托对象是整篇文章主标题、章内小标题，还是题眼/中心/总结/收束/过渡/原则句等篇内关键表达。整篇主标题看文章目的、读者和可兑现内容；章内标题与关键句只处理写作负责人指定的现成/已定文本位置，接收足以判断作用的相关段落、前后关系、句子职责、作者声音和锁定项。必要时只补会改变判断的最少上下文。不得替写作负责人增删章节、重拟正文主张或改动保护项；候选交付后由原负责人嵌回全文并连读。

筛材料不只摘醒目短语：同时找作者真实表达、具体事件/动作/数字/经历/原话、有效强句，以及反复尝试、选择或关系所能带来的新认识。局部切口可以成立，也可能需要把多处经验连成一句认识；只有用户允许开放结论时才提出新判断，并把推论与已知事实分清。信誉线索只能来自材料或获准核实的来源；不编履历，也不默认追问收入、年限或成绩。

独立创作完整封面与平台发布标题包、且用户未缩小范围时，默认交付 21 条：3 个共用封面主标题，以及小红书、抖音、视频号短标题、B站、快手、微信公众号各至少 3 个发布标题。用户点名部分平台时只交这些平台且每个平台至少 3 条；用户只要文章内部标题、关键句、封面、单条、诊断或其他局部结果时遵照该范围，不凑完整包。封面共用，最多 8 个可见字符、默认不加标点；逐条标一个强调词/短语。封面默认是自然完整的陈述句或判断单位，完整行动号召也可成立；发布标题默认陈述，但问句、方法名、叙事或呼告可在材料和读者理由合适时采用，不把标点/形式标签当吸引力。若锁定文字与预算冲突，保留原文并说明冲突。无平台归属的单条发布标题不虚构平台限制。平台预算见[关键词与平台字段](references/keywords-and-platforms.md)。

文章稿件字段与平台发布字段分开。写作负责人委托文章主标题、章内标题或篇内关键句时，只交用户指定的句子、位置和准确数量；不因“文章标题”或单句委托自动启动封面/发布标题的默认21条，也不套封面8字、六平台预算、搜索词、发布技法标签或推荐理由。若用户另行指定封面、平台发布标题或搜索任务，再按相应规则处理；明确要求分次调用时照办。

## 2. 从材料中发现值得留下的内容

每次创作或改良都先决定要让这句话留下什么：在标题中，是这批读者处在什么具体情境、想理解/得到/追看/体验/认出/表达什么，以及材料能提供何种差别、后果、认识或体验；在正文或歌词中的关键句，则是该句需点明、汇聚、承接、转折或留给读者/听者的那一层关系。题眼和中心句可以把分散材料连成认识；总结、过渡和原则句须服务其前后文本，不代替整篇论证；歌词核心句须从歌的材料、说话位置和音乐约束中找其表达重心。

“读者为什么进入”的判断只针对文章主标题、封面和发布标题。受众范围与在意强度分开判断：窄众可以强相关，泛称“所有人”不自动有动力。用户给出的受众优先，其他推断限于材料和当前使用情境；不强行全民化、金钱化或焦虑化。章内小标题服务已经读到该处的人，应依据章节职责和上下文帮助其识别、理解或继续；不要求重新作点击决定，也不要求脱离已读正文独立可懂。题眼、中心/收束/过渡/原则句及歌词核心句不承担统一的“进入理由”，按其在相邻文本或作品中的实际职责处理。

读者是谁、文章谈什么、正文覆盖哪些项目，能说明相关性和内容范围，却不自动说明读者为什么现在值得把注意力交给它。若任务包含吸引或推荐，继续从材料中选出具体进展、卡点、预期差异、选择后果、新认识、故事推进或审美体验；所选关系可以是窄而具体的任务，不需扩成最大抽象目标，并须成为句面的重心。只有用户目的就是目录、索引、准确识别或明确检索时，单独列名称或项目才可能完成任务。

动机由材料决定，不从一张词表挑题材：实际得失/省力/能力、未知与解释、身份尊严/归属、控制/确定、真实冲突/立场、人物经历/故事进展、幽默/审美体验都可能成立。选用时说清什么材料特征和读者处境让它适合、标题可让人感到什么；情绪可由具体处境、关系、动作和后果唤起，也可由准确有力的情绪词表达，不要求每条都具象化成同一格式。强词、欲望、幽默、诗性、作品识别和立场都可以保留。

对基于材料的创作/改良，起草前读取[读者预期与材料入口](references/audience-value-and-structure.md)，按任务深化“材料中什么值得留下”及其与受众/作品的连接；单一路线也适用。仅当用户已锁定表达内容、切口和所需关系，且本轮不需重新判断时，才可略过。若标题主张心理反转，起句前先按该 Reference 的 P→E→Q 判据确认：为什么前提 P 会令这批读者形成预期 E，材料中的 Q 如何违背 E；E 只能来自用户、材料或有边界的公共经验推断，不造“大家都以为”。两个分句、“却”或“越…越…”不自动构成反转。

有搜索意图时，在候选起草前读取[关键词与平台字段](references/keywords-and-platforms.md)的搜索部分；先定与材料一致的查询任务、主词和必要限定，再同时保留浏览者可感的进入理由。无搜索需求不硬塞检索词。标题方法/知识可从路径、差异或选择进入；故事可从真实人物、行动、处境变化或后续进入；抒情审美可由物象、声音、动作、时间和关系成立；身份、立场或作品识别也可独立成立。方法所得和故事承诺可在全文相关位置兑现，不要求标题代表全文或正文开头立即回答。

## 3. 用专业方法把材料关系写成句子

起草、改写或加强关键表达前读取[材料关系、用词与标题生成](references/title-structure-generation.md)。沿用第2组已选的内容关系、材料锚点、句子职责及适用的读者理由/查询意图。先明确这句话在当前位置要让人理解、感受、追看、识别或表达什么，再从材料中选能承载它的参与者、动作、关系、经历、命题、意象或原话，并选与该关系相称的表达形式；不把目标停在“有情绪/有冲突/有价值”等抽象标签。

遇到关键名词、动词或修饰语时，比较熟悉说法能否准确指认所指，并把真实参与者、行动、期待、后果或体验凝练在句面；同时检查读者利害是否清楚、词语公共语感是否自然、情绪由关系唤起还是仅被命名、作者声口是否保留、词义是否超出材料。凝练不以更短为胜，也不删掉承担语义、关系或必要声口的信息；准确标明作品/对象身份、改变判断或确有作品语境需要的术语可保留。比较替换时保持核心意义和关系；同一评价方向内的程度调整，复核其材料依据与语气，不自动重开入口选择；改变对象、事实承诺、核心立场或预期关系时，才作为新路线重判。情绪词本身不禁用，须看它是否准确承载用户所要的体验，或是否有材料关系支持。

任务要求吸引、推荐、鲜明立场或加强表达时，先选定材料中值得强调的所得、代价、差异、体验或判断，以及作者对它的态度。标题任务要让所选读者关切与内容特点接上；其他单句按其位置与职责表达关系，不因此另造读者痛点。方法为何值得了解、观点为何值得了解或故事为何值得追看的具体处理/变化，只有在标题吸引方向需要时才承担这项进入理由；相邻成分仍须推进同一项关系，而非转成作者工作汇报。再用生成 Reference 的 Graduation（级差）方法，把需要表达的评价落实到词语本身、程度表达和整句重心。让取材的分量与成句的力度相接，不只加强开头或在推荐理由里解释价值。既有方向已经成立时，沿该方向写足，不因句子已清楚、相关就停止，也不把所有标题改成强推荐口吻；不规定收益必须在结尾、方法名称必须在某处或标题必须采用双分句。

信息判断、事件叙事、审美/诗性、作品识别、人称、时间、声音、并置、鲜明观点和原创隐喻都是可用路径；不强求问句、双分句、反转、好奇缺口或实用利益。用户要求完整标题包，或开放路线会改变关键表达的句法、关系、声音或留白时，起草前必须选择一项适合当前材料的已核人类作品处理方法，并让它实际改变本篇表达；从[材料关系、用词与标题生成](references/title-structure-generation.md)的本地方法起步，只有本地方法不足以决定关键句面时才按需研究更多作品。无需每条或每个平台具名，也不复刻原句或套固定作者模板。发布候选逐条说明句面实际使用的技法/形式；“利益”“省力”“情绪”等只表示读者关切，不是技法名称。

## 4. 放回真实位置比较、复审并交付

需要平台发布字段时，适配前读取[关键词与平台字段](references/keywords-and-platforms.md)对应平台的预算和表达条件；即使没有搜索任务也要读。只做共用封面沿用 8 字预算，不读平台字段表。章内小标题不属于平台字段：只按用户指定数目写在文章实际位置，允许使用读者已读内容提供的上下文；以导航、区分本节判断或推进关系为主要检验，不补整篇广告承诺。主标题若是文章内部字段，也按整篇正文与明确请求定量，不套默认发布包。平台只能改变本字段适合的句法和信息展开，不能替读者决定关心什么。封面与发布标题各自独立可懂；可以选相同或不同入口，必要主题词可以重复，不为互补而写残句，也不机械裁切。较长字段只有在能添加新路径、情节、理解、体验、观点或识别线索时才展开，不列目录、不换同义词凑长度。分行或压缩后连读，确认主语、动作、对象、否定、条件及修饰关系没有错配。

初稿形成、字段适配后，读取[标题兑现与竞争复审](references/title-value-and-review.md)；仅诊断原标题也读取它。将关键表达放回真实标题字段、文章段落/章节或歌词位置，先排除主旨误解、材料不承接或来源身份有误，再遮住作者解释和技法标签，在其真实位置比较候选：选出更能完成句子职责的，直接修订或淘汰弱句。标题句面要让目标读者看出对象与进入理由；篇内关键句则按其实际功能检查承接、汇聚、推进或留白，不要求它变成广告或箴言。更完整、更长、更有理论名词不自动更好。复审后改字，重读最终版本；发布字段预算与25字编辑检查仍以 Keyword Ref 为准。

用户要求推荐时，内容对应和材料兑现是入围条件，不是胜出理由。若候选只有读者标签加主题/章节清单，而材料另有读者可感的任务进展、选择后果、认识变化或体验理由，不因列项完整就推荐；回第2组比较真实入口、第3组把选中的关系写进句面。目录或索引本身就是用户所求时例外；故事、审美、身份与作品识别仍按本轮用途判断，不强改成实用收益。

候选确定后，按材料及本轮授权逐条核对具体事实断言（如数据、来源、作者经历、已发生事件、因果或结果）。材料入口承接检查不等于重复逐字核事实；事实有误时只修受影响的断言，不先把愿望、态度、体验或有力修辞削弱。没有真实发布数据，不称编辑判断为点击或传播效果验证。默认在聊天中交付，不自行创建、保存或发布文件。
