# 篇内关键句高阶修辞与气口精修

由 [篇内文章关键句专项](../skills/laohu-title-condense/SKILL.md) 在需要精推修辞边界、防比喻反噬、调取本地夸张比例原子或精校朗读气口时按需读取。

## 五种关系构句的精修与防失效

1. **同尺度对照**：两端必须回答同一个问题。若一端谈动作、另一端谈结果，先补齐共同判据再对齐两拍长度与节奏；材料只支持并列或递进时按实直写，不硬凑对仗。
2. **主客或因果交错回环**：核实 `A → B` 与 `B → A` 两条真实关系链都有材料依据，让相同词在不同语义角色里产生回声。若后半句只是调换字序玩文字游戏，立即放弃回环改为直写或时间递进。
3. **动作重释熟悉概念**：先写实谁在什么处境下做了什么，让旧概念落到具体行为上；只要新释义仍是抽象褒义词，立刻换成可观察动作，并把个人经验的适用条件留在句面。
4. **具象映射防连带意味反噬**：先抽出原关系的参与者、动作方向与结果，再找生活物事映射；随后把比喻句和直述句并排核对——**检查借来的物事有没有意外带进支配、敌对、贬损或道德审判等本句无意表达的连带意味**。一旦跑偏立刻换锚点或收窄所指；有材料支撑的含蓄留白保留，不把比喻硬拆成说明书。
5. **不可替代的动作细节定格与比例落差**：当故事或经历里已有压得住场面的动作、物件、数字、时间差或原话，先摘掉情绪形容词和道理总结，只试读动作连着细节能否撑起留白。若本轮材料同样支持把日常小遭遇放进大尺度口吻来造荒诞感，可只读调取本地方法库已登记原子 `ATM-BE71AD8490FA48A7`（日常遭遇与命运式共同问句的比例关系），核对适用条件后迁移比例关系而非照抄强词。

## 气口与重音精修

1. **焦点落位**：出声朗读划出自然停顿与词组边界。需要收束余响时，把最重的实词压在末一个自然停顿前；需要开句钉住对象或守住原声口时，保住句首或原位重音。
2. **清绊嘴、守边界小词**：剔除拖慢气口又不改意思的长定语、赘词和易引起同音歧义的连读；切勿切断完整语义词组，逐个核查只、才、仍、却等边界虚词，改掉意思就必须留住。
3. **自然语序优先于押韵**：韵脚、平行与首尾照应为意思和声音服务；只要押韵或对偶迫使语序别扭、事实走样或作者声口变味，立刻放弃押韵回到自然句法。
