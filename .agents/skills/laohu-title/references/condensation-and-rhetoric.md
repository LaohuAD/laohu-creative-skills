# 关键句的构句、声音和嵌回

关键表达模块在确定本句职责和工作释义后读取。带入真实位置、可用前后文或相邻歌词、材料锚点、作者声口、锁定内容与探索边界。先查素材和关系，按条件选构句动作，成句后按实际媒介复读。留给主文的是可嵌回的候选、它实际承担的作用及必须由上下文补足的条件。

## 留住确实值得写进这句话的内容

用一句日常话说明本句要让人看见、理解或感到什么，标出前文哪处材料使它成立。能改变理解的内容包括两个易混概念的差别、容易漏掉的代价或条件、不同经验之间的同一关系。具体人物、事件、数字、原话、动作、意象或情感也能直接承重，保留它们自身的力量。

题眼和中心句把最能组织段落或全文的关系写明。原则句从材料所支持的选择或关系提炼，留住判断的边界。转折定调句只改变后文实际要改变的看法或情绪方向。总结与收束把已经建立的理解或感受落下来，可留回响。副歌核心句保留歌者的说话位置和本段要反复的情感重心。普通解释与日常衔接交回写作负责人。

遇到只有套话的释义，回原文再找一次具体区别、动作、观察或声音。真实关系依然不足时，保留准确自然的直述，或指出哪一项必要材料缺失。用户允许探索时可提出有材料承接的认识；若采用它会调整既定中心判断、文章主线或承重结构，附材料依据和受影响范围交回 Writing，由 Writing 接入 analysis 判断。已锁定的立场继续作为改写边界。

## 按材料关系选构句方法

优先选一个真正能显出工作释义的动作。有两个方法会实际改变关系、语气或留白时，可用同一材料各试一句并嵌回比较。括号、关系符号和槽位表示内部工作结构。

### 1. 用同一尺度形成对照

两种解释、做法或后果确实争夺同一个判断位置时，先写下共同问题，并标出两端各自回答什么。把旧判断、表象或易错归因放在读者能识别的一端，把材料支持的新判断放在焦点端。删掉不改变差别的修饰，使前后两拍语法和节奏相称。

可用 `[同一问题] → [旧回答 A] / [有据回答 B]`，也可用 `[可见成本] / [隐性损失]` 呈现真实取舍。若两端只是在不同维度各谈一事，补足能成立的共同判据；材料只支持并置、递进或联动时按真实关系成句。只有外部入口要用受众预期制造反转时，回主文交发布入口模块核 P → E → Q。

### 2. 交错主客、因果或手段与目的

先从材料中列出核心两端 `A`、`B` 及各自语义角色。分别解释 `A → 动作或关系 → B` 与 `B → 反馈或重新决定 → A`，写出每端所依据的事实、经验或有边界的比喻。再用短过渡把位置交错，让相同词语在不同角色里形成可听回声。

若第二端只是交换字序，回材料核行动权、归因方向或手段如何变成目的。材料只支持一端时就直写该端；只有两端接续、无相互塑造时可用时间或结果结构。

### 3. 用可观察关系重释熟悉概念

当题眼、原则或中心判断需要重释一个常用词时，标记熟悉概念 `[X]`、本文确实触及的旧用法，以及能修正其理解的动作、选择、关系或条件。先用日常话写出在什么处境、哪些参与者做了什么，使 `[X]` 在本文里有新落点，再压到一句。

只有旧理解真实存在且与本文回答同一问题，才采用显性纠正。新释义仍是抽象褒义词时，换成可观察动作或真实关系。实例只支持某种条件时，让句面留住条件，避免把个人经验扩成所有人的定义。

### 4. 用具象关系组织隐喻

先从目标关系抽出参与者、动作、方向与结果，例如工作槽位 `[谁] → [推动、阻挡或积累什么] → [对谁产生何种变化]`。从读者熟悉的生活动作或物事找一项能承接其中关键关系的映射，核哪些角色和作用真正对应，再决定并置、借代、明喻、隐喻或直述。若已能凭物件和动词理解，可省略多余的说明。

核日常语感的连带意义。把比喻与其解释句分别换回直述，比较双方的参与者、动作方向、所指范围与评价。若借用的物件意外带入支配、敌对、道德判断等本句无意表达的意思，换锚点或限缩映射。只迁移需要的关系，材料支持的含蓄及未被使用的比喻细节可保留。新造关联是本轮创作处理，涉及原作者本意或现实断言时按实际证据表达。

### 5. 留住一个不可替代的动作或细节

当故事、经历或歌词已有压得住情绪的动作、物件、数字、时间差、真实原话或强比例反差，先暂时去掉情绪定性与结论，试读一个动作连着一个具体细节。测试读者能否从实际上下文感到这一瞬间的变化或留白。材料只需一个细节就能定格时可以更短；直接情感本身承担作者声音时可以保留。

如本轮能读取已登记的 `ATM-BE71AD8490FA48A7`，可检查其日常小遭遇怎样承接大尺度命运口吻；只有本轮材料也支持比例或语气落差时才借这一处理。无法直接识别动作对象或处境时补回最小锚点。新添数字、比原文更强的密度感或新的情感因果须有实际材料。

### 6. 让气口和重音完成收束

前五种任一成句后都做一次声音检查。音步本身承载回环、停顿或收束时，可以从原材料的重复、节拍或句尾转折取法。先保住关系，再比较听觉形态。

1. 朗读并标记自然停顿、词组边界与最重的意义。需要余响时，把有效焦点移到末一自然停顿前；要在开头钉住对象、保留原声口或顺着旋律时，保留句首或原处的焦点。
2. 去掉绊住气口却不改变意义的成分，复听长定语、赘词、同音歧义和被切断的语义词组。检验 `只/才/仍/却` 等是否决定条件、范围、时态或反差，保留承担关系的词。
3. 韵脚、平行和首尾相应可以帮助声音成形。换词后还原句义，检查自然语序、作者声音、事实限定及情感强度。若押韵要求改变其中任一项，先回到自然语序或改换音步。

## 放回原位置连读四项

先将候选原样嵌回真实位置，按可得材料读前后各两句或对应歌词行。短段落、开头和结尾只用实际存在的邻文。调用方未提供邻文时，先完成句面检查，并指出哪个位置条件待核。

| 检验 | 观察与修复 |
|---|---|
| 前文托举 | 前文是否给足事实、情绪、物件或推论依据，能托住本句的抽象度和语气。力度跳得太远时，按材料收窄；若候选需另补承重材料，指出位置并交回 Writing 依授权处理。 |
| 后文承接 | 后文如需解说或展开，核参与者、动作、对象和关系方向是否相接。仅共享主题词时重选本句焦点；缺桥在邻文时交回 Writing。收束句到此已完，无需另造后文。 |
| 声口一致 | 把候选和原作者相邻文字一起读出声，核语体、说话距离、人称与判断力度。外来格言腔或突兀训导优先换回原文自然词汇，保留原关系和必要重音。 |
| 职责到位 | 题眼能聚焦、中心能组织、转折能定调、原则有适用边界、收束不再开题。副歌核心句需要回到本段的情感方向和重复位置。发现附带新议题或多句并行任务时，只保留受托单位；普通衔接由 Writing 接回。 |

## 副歌核心句的音节与位置

在相邻行中核说话人、听者、时态、情感推进和原词反复的核心意象。读出实际音节、重读音节、韵脚、延音适合承载的词及换气口。已有旋律、拍点或试唱时，把这句放回对应乐句或按真实拍点过一遍，确认词组完整、关键字有合适落点，且开口和换气可用。缺少旋律或试唱证据时，按实际条件标明核验范围，至少写明仅完成文字节奏、可唱性待配曲或试唱。

将候选及使用条件交回关键表达模块和主文的[位置复审](title-value-and-review.md#篇内与歌词关键句按位置复审)。若 Writing 或 Lyrics 在嵌回时改了上下文、位置或词句，需以实际成品相邻段落或歌词复读。
