# 关键词与平台字段

由主文第2步在每次独立创作或原标题改良的候选起草前读取；标题诊断只有涉及查询词、搜索或字段时才读取。第2步先确定与材料相符的查询意图和词项；平台表达表留到主文第7步，在观众吸引入口已选定后读取。平台表达只能帮助把已选入口写进相应字段，不能反过来替用户决定观众应该关心作者的哪段经历。关键词帮助观众认出对象或表达关切；它们不代替标题吸引入口，也不自动带来排序、引用或点击。

## 让对象词与观众关切相遇

分清三类词：

| 词类 | 从哪里来 | 在标题中的作用 |
|---|---|---|
| 材料词 | 用户材料中的主题、对象、人物、作品名、地点、专业名词和观点 | 让观众认出内容对象，保护作品身份与材料关联 |
| 需求词 | 观众正在处理的任务、疑问、选择、愿望或体验 | 让观众看见内容与自身关切的连接 |
| 查询词 | 用户提供的搜索词、平台建议词、可复核的搜索记录或可靠数据 | 贴近实际检索表达；只有查询候选时不称为高频词 |

只有有搜索量、来源与时间范围等可复核依据时，才把词称为高频或搜索量较大。为候选词记录它从哪里来、对应哪项关切、是否出现在标题字段里。保留能帮助观众认出对象或需求的词；不堆无关词，不用关键词替代吸引理由。作品名、品牌名、人物名等用户锁定原文按保护项处理。

## 选定主查询意图，再让它进入标题

先从用户材料、原标题、用户给出的查询词或平台建议中，辨认一个与内容相符的主搜索任务。按意图区分对象/实体/技术/作品词、任务词（学习、使用或制作某类资产的需求）、结果/差异词和体裁标签；这些是词项来源类别，不是必须填满的清单。围绕同一搜索意图选择一个主查询词组和必要限定，使读者能认出搜索对象及实际任务。

没有搜索量数据时，仍可依据用户给出的词、材料词和任务词整理查询候选，不让缺少数据阻断标题创作；只把它们标作候选，不能称“高频”“热搜”或有排名优势。元标签不是默认标题开头；英文大小写本身不作为排名策略。

主查询词须自然进入有吸引力的句面，适合时放在前25个可见字符内；如果前置它会压掉更重要的受众任务或吸引点，优先保留自然有力的句面，并说明搜索与吸引之间的取舍。不要把同一意图的近义词堆在一条标题里；额外查询词只有在对应另一项真实意图且带来清楚的信息增量时才保留。搜索用词、浏览吸引和平台推荐各自检查，不推断封面文字会被OCR收录或任何单词有权重。

## 按发布入口适配表达

先沿用用户说明的发布计划、搜索需求、账号材料或平台功能。入口不清楚时，标题仍要让浏览中的观众读出观看理由；有搜索需求时也要保留能匹配搜索者对象和任务的词组。不要按平台名字臆测受众画像或排序权重。

标题关键词只是相关性线索之一。Google自然搜索与AI搜索、平台推荐、站内搜索分别判断；未获得可核实的平台依据时，不推断关键词权重或排名，也不把一个平台的规则外推至另一个平台。实际投稿前若字段口径或限额会影响产出，按当前投稿编辑器复核。

Google AI 搜索/GEO只处理标题能支持的部分：准确写出实体、读者主要任务并让标题主题与内容一致。Google Search Central说明AI搜索沿用基础SEO实践、不要求特殊标题；GEO研究评估的是生成式引擎对网页内容的可见性，不能推出某个标题单独带来引用或排名。网页正文、可核实证据和站点等其他范围不由标题技能代写或保证。

## 平台字段与限额证据

下表将官方字段证据与用户指定的本项目编辑预算分开记录。小红书、抖音、视频号短标题、B站、快手和微信公众号的数字是本项目预算，不一概冒称官方上限或统一界面计数。投稿字段更严时从严；界面允许更长时继续遵守本项目预算，除非用户明确要求扩展。当前入口或计数证据未知时，仍按预算拟题并将平台合规标为待核。

| 平台/预算口径 | 字段对应 | 已知字段证据与执行动作 |
|---|---:|---|
| YouTube 普通视频与 Shorts：100 字符 | 视频标题字段 | 官方帮助与 API 均列标题字段上限 100 字符；发布前复核实际入口计数。字段上限不表示首屏完整显示，也不证明具体截断位置、搜索权重或点击效果 |
| 小红书：20 字符 | 本项目小红书发布标题预算 | 作为项目预算直接执行；端内字段名称、当前计数与更严限制仍以真实投稿入口复核 |
| 抖音：30 字符 | 本项目抖音作品标题预算 | 作为项目预算直接执行；公开检索接口不足以证明标题匹配权重或官方长度，按当前投稿入口核字段 |
| 视频号短标题：16 字符 | 仅适用于短标题字段 | 短标题与描述分字段处理；16字预算不延伸为描述长度，实际限制更严时从严 |
| B站：80 字符 | 投稿/编辑标题 | 80同时是用户指定的项目预算，并与已核实投稿/编辑 API 字段上限相符；端内计数、预览截断与搜索权重仍分别核实 |
| 快手：60 字符 | 本项目快手作品标题预算 | 作为项目预算直接执行；API 的 caption 字段可承载作品标题，实际字段口径仍按投稿入口核实 |
| 微信公众号：64 字符 | 本项目公众号发布标题预算 | 作为项目预算直接执行；草稿字段、界面计数及更严限制按实际入口核实 |

优先用真实投稿编辑器的计数和提示验算，并分别记录平台上限、项目预算与最终字符数。暂时没有编辑器时，按可见字符逐个计数：汉字、数字、拉丁字母、空格和标点都计入。emoji 或组合字符在端内怎样计数仍待实际编辑器复核。按相同口径检查标题前缀。

## 标题重点前置与25字编辑判据

所有标题都把主要作用所需的入口放在前面。发布标题不超过25个可见字符时检查整句；超过25个字符时检查前25个字符，确认读者已经能看见与本条作用相称的线索：方法/知识的所得或路径，故事的处境与追看，抒情/审美的具体意象、声音或感受，作品识别的专名/母题，观点/身份的立场。只有对象名称、材料主题或作者经历，不自动满足方法/知识型入口；但用户要识别作品时，专名可以是核心入口。也不要求把所有标题套成“对象＋理由”的同一格式。作者事件只有与本条预期作用相连时，才可承担开头。小红书与视频号等本项目预算低于25字的平台，按完整标题检查即可。25字是本项目用户指定的编辑检查点，不是平台字段上限、折叠线或统一截断位置；不由某个平台的显示经验推断其他平台或设备的显示位置。

每次给出平台标题时，标明平台、具体字段、本项目编辑预算、字符数和当前入口限制的证据状态。没有真实投稿编辑器时按项目预算交付，并把端内合规标为待核；不以项目预算宣称已通过平台校验。超过25字的标题应检查并报告前25字是否已经显出本条作用的入口；短平台标题按完整短句检查。

## 逐平台重新构句

完整标题包默认覆盖六个平台：小红书、抖音、视频号短标题、B站、快手和微信公众号；每个平台至少给出三条发布标题。用户点名部分平台时只做这些平台；只请求封面或一个发布字段时按其范围交付。

先按主文第2、3步选定观众为什么会点开，再让每个平台的字段和表达方法参与成句。每个平台分别判断怎样表达这个已选入口，并独立构思至少三条候选；候选数量不是固定路线表，不把三条封面候选机械复制成六个平台的三条发布路线，也不要求发布标题与封面逐条配对。平台表不能把较宽的观众吸引入口改成作者复盘或窄小材料入口；用户此前明确拒绝的入口，没有新的观众理由时不得恢复成默认。某个吸引点确实适合其他平台时可以沿用并重新组织，但须由材料、字段和可用的平台研究支持，不作默认复用。若有可用的平台研究或用户提供的发布条件，按其证据范围适配；没有时结合实际字段和材料处理，不臆测平台人群、语气或排序规律。无论入口怎样变化，每条具体事实仍须分别有材料依据。

### 以材料条件选择平台表达

下表是依据有限的平台创作与内容材料形成的本项目编辑默认，不是对所有账号和观众的固定画像。先检查材料是否具备触发条件，再采用对应句法；条件不成立时，换成材料确实支持的表达，不补造经历、人物或平台语气。

| 平台 | 材料条件与表达动作 | 条件不成立时 |
|---|---|---|
| 小红书 | 材料包含真实体验、具体选择或熟悉的日常任务时，从任务或场景切入，再落到意外发现、明确判断或由此得到的东西。 | 没有作者亲历时不写成第一人称体验；改从材料支持的选择、问题或发现进入。 |
| 抖音 | 材料能支撑鲜明判断、具体动作或清楚反差时，把判断、动作或反差前置，再接观众所得或可用方法；整句读起来要顺口，能一口气说完。 | 不为制造强度编造冲突；仍优先用材料中最有力的动作、判断或关系，不自动改成泛问句。 |
| 视频号短标题 | 材料支持一个离开上下文仍完整、容易转述的判断时，直接写成独立句；材料确有共同处境时，可用自然的人称让读者认出自己与他人的关系。16字预算不要求把判断写软或写残。 | 共处境不清楚时不猜人群、不硬加“你我”；保留材料里能独立成立的判断。 |
| B站 | 材料支持明确议题和鲜明论点或认知反转时，先点出议题与判断，再用案例、拆解方法或适用范围增加具体内容。 | 没有反转或强论点时不强造；选择材料真实支持的说明重点，并按长字段的增量原则扩展。 |
| 快手 | 材料包含具体人物行动或生活事件时，从人物做了什么、事情怎样变化写起，再接结果和观众能得到的知识。用直接自然的口语。 | 不虚构人物行动、生活细节或结果；不为平台名套“老铁”等刻板方言。 |
| 微信公众号 | 材料包含可讨论、可转述的观点，或能形成冲突的故事时，交代观点/冲突与它对读者的影响，再加入方法、路径或适用范围。可用多层句子承载不同信息。 | 没有相应观点、冲突或方法时不硬套完整结构；只扩展有材料依据且能带来新动机或理解的部分。 |

这些句法是有条件的编辑选择，不是普遍受众或排序规律。每条候选仍要标明它实际使用的表达技法；强陈述、角色力量、梗或夸张语气本身不需要被改成问句，也不因缺少点击率因果证据而自动弱化。仅在标题包含具体可核实断言时，才按主文步骤6后置核查相应断言；不把广告或课堂正文总结规则套到标题上。

对B站80字、快手60字和微信公众号64字等较长预算，材料允许时主动把标题写得更完整，加入服务本条作用的新线索：方法/知识可补路径、差异或适用条件，故事可补真实处境变化或后续，抒情/审美可补有材料来源的意象、动作、时间或声音，作品识别与观点可补清楚的名称、母题或立场；不要默认每条都压成十几个字的短口号。扩写不等于列出课程章节、步骤、术语、场景或器材目录，也不能变成作者复盘。预算提供可用空间，不是必须填满的目标。每增加一个成分，都检查它是否让读者更清楚地得到、理解、追看、体验或识别目标；若只是同义复述，或没有增加这类作用线索，就删掉。缺少材料支撑、句子失去自然度或达到字段预算时停止添加；若新增可核实断言，先保留其吸引方向，完成候选后再单独核对，只修不成立的具体断言。不同平台按字段重新成句，不机械裁切长标题；对象词、重点与自然表达都应先于字符填充。视频号的16字只约束短标题，描述字段独立处理；B站80字预算仍注明其投稿/编辑 API 证据范围。

## 交回主文

返回主文时只交付影响本轮标题的词项、需求或查询意图、计划使用的字段和字段证据状态。标题草拟后再检查关键词是否帮助观众认出对象或关切，是否占空间却没有增加信息；不相关词移出标题。
