# 标题作用、材料关系与表达生成

由主文第4步在标题作用、读者反应和材料入口确定后、起草候选前读取。输入是本条标题的目标作用、预期读者反应、选中的材料锚点、锁定文字及已知字段条件；输出是有材料依据的关系/意象安排、表达形式与标题候选。读完回主文第5步安排封面和发布标题，再交[标题价值与文字复审](title-value-and-review.md)按目标作用验收。这里提供正常生成路径，不是泛劝告失败后才可选的补救菜单。

**标题的作用决定它要抓住材料的哪一面，材料关系再决定句子怎样显形。**标题形式可以是命题、事件、名词短语、意象并置、呼告、声音节奏或作品专名；语法构式只是表达资源，不是所有标题的生成理论。无需把每个标题改成双分句、问句、功利所得或信息缺口。

## 让中间选择接得上

这条链供执行者内部使用，不要求把每一项推导展示给用户：

1. **作用与反应：**确定这条标题首先要让读者体验、理解、追看、识别、认同或表达什么。可以有主作用和相容的其他作用，不限制固定数量，也不必把它改成封闭题材分类。
2. **材料与承载理由：**取能支持该作用的专名、关键物事、动作、参与者、场景、感官、时间、视角、重复意象、观点或真实未解事件；说明它为何承载这项作用。选择局部即可，不总结全文。
3. **意义关系或意象组织：**按材料确认参与者、命名关系、事件变化、感知与情绪的联系、相似映射、邻接/部分关系、反复主题，或信息命题间的条件、转折、让步、比较等关系。关系允许开放和多义，但须能回指原文或公共经验，不靠任意谜语。
4. **文字形式：**根据焦点选择名词短语、事件/动作句、人称判断、时间结构、平行或反复、并置、声音安排、连接骨架或有根据的悬置。形式负责让关系可感，不替材料发明关系。
5. **炼字与删减：**省略读者可恢复且不影响目标的成分；先核动词及其参与者，再调整程度、情绪、指代、词序、节奏和声音。只在事实或语法关系要求时补明，不用解释性文字填掉审美留白。

DBS 中的心理触发维度只作横向的反应检查轴：认知冲突、好奇、损失、身份、数字、结果、社会证明、争议、场景、行动、权威、互动。它们回答“可能唤起哪种心理反应”，不决定材料关系、文学功能或句法形式；彼此可以交叉，也不要求每个标题覆盖全部或匹配一个固定编号。本地运行按已内化的条件使用，不调用或依赖外部 DBS Skill；没有适用触发点时直接沿材料与标题作用生成。

## 沿用户原标题改良，不另起主题

用户给出原标题并要求诊断时，原句本身足以检查对象、任务、读者利益、查询词是否可辨、钩子、表达关系与语言自然度；不以缺少正文为由拒绝句面诊断，也不擅自生成改写候选。事实是否成立、正文是否兑现、平台字段是否合规分别标为待材料或字段核验。

用户要求改良时，先从原标题提取并保护核心对象、受众任务、利益、主查询词和锁定文字；原标题中的时间或结果钩子先作为用户选定的吸引方向保留，事实核对留到候选形成后，不因尚未核验而一概删除。沿同一主题按修改幅度递进：先做最小词序或措辞调整；仍不够时，在保留核心关系与钩子的前提下改造结构；再尝试不同表达技法。默认按用户指定的同一发布平台给三条，依次体现这些层次；每条说明改动和取舍。三条不可只换同义词，也不准换成另一选题或受众任务。锁定文字始终逐字保留，预算冲突时指出并遵守锁定项。

## 按材料关系选择表达路

这些表达形式各有触发条件、操作、读者可感效果和误用修复；可以组合，不构成封闭菜单，也不要求一条标题把它们全用上。

| 形式 | 适用条件与具体操作 | 读者可感特征 | 失效时的修复 |
|---|---|---|---|
| **专名、母题或命名短语** | 标题首先承担识别、记忆、描述作品或指向稳定对象的作用时，保留用户锁定的名称，并从反复物象、核心场景或事件中选必要限定。 | 读者能认出谈的是哪部作品、哪一处场景或哪项对象；名字本身可以成为记忆入口。 | 名称太泛或无法识别时，只添原文支持的具体锚点；若作品名已锁定，不用副标题变相改名。不要为增加利益或悬念而改变作品身份。 |
| **信息命题与连接骨架** | 标题要帮助读者学方法、懂原因、辨区别、做选择时，先确认材料中的命题关系，再从下表选择意义相配的骨架并填语义槽。 | 读者能看见问题、条件、结果或判断如何相连；必要时能看见具体所得或仍待了解之处。 | 若句面只是术语、常识劝告或关系标签，回到材料找行动、对象和结果；关系不被材料支持时换骨架，不靠近义词补强。 |
| **事件句或场景句** | 原文有可定位的人物、行动、处境变化、选择或关键瞬间时，按“谁—做什么/遇到什么—发生何种变化”取必要部分；故事可留下由原文承接的真实后续。 | 读者能进入一个具体时刻，感到人物处境或事件在移动，并知道想追看哪一部分。 | 缺人物、行动或场景锚点时，不补造情节；若只剩剧情概括，回到能承载作用的局部动作或关系。没有真实未解点就交代已知部分，不制造悬念。 |
| **意象或名词短语** | 抒情、作品识别或审美体验依赖具体物事、地点、感官或反复意象时，从原文所处的视角和上下文选取；保留关键名词、动作或相邻关系，必要时并置而不解释全部情绪。 | 读者先看到/听到/感到一个可想象的对象，情绪和联想可从材料关系中浮现；留白仍有锚点。 | 只有泛化景物词、任意符号或漂亮词堆时，回到原文找具体视角、动作、感官和重复关系；若标题必须靠作者讲解才能连上，换成更可感的锚点或直接表达。 |
| **人称、呼告或口吻句** | 原文说话位置、读者关系或身份表达会改变感受时，选择“我/你/我们/他”等人称、称呼或原句语气；使代词所指和说话身份清楚。 | 人与人之间的距离、邀请、对抗、亲密或自我表达在句面可听见。 | 不为亲近而硬加“你/我们”，不虚构第一人称亲历；人称让关系变假或指代不明时，回到原话、第三人称或无主短语。 |
| **时间结构** | 原文真实呈现等待、回忆、前后状态、季节/时刻、反复或迟来的变化时，选择必要的“过去—现在”“到来—离开”或持续关系。 | 读者能感到距离、延宕、循环、失去或变化方向。 | 没有时间证据不补年月、时长或“终于”；若只是两幅并列画面，按并置而非成长/变化表达。 |
| **并置、平行、反复与声音** | 原文已有相邻意象、重复词、句式回环或可听的音节关系，且形式能加强意义或情绪时，保留节奏、呼应、停顿或平行。 | 读者能感到回声、对照、顿挫或语音记忆，形式参与表达。 | 为押韵或整齐而扭曲自然搭配、关系或焦点时，拆掉声韵装饰；音响无材料或语义作用时，用准确词句。声音平行不是质量保证。 |
| **相似映射、借代或象征** | 原文反复建立具体物与情绪、人物或事件的相似/邻接/部分关系时，沿那条可指认的关系压缩表达；只提出读者有条件感知的联想，不宣称唯一作者意图。 | 一个具体事物能带出更大关系，标题保有含蓄而非泛化谜语。 | 若无法说清所选物事与主题的原文联系，或读者只能靠额外解释猜测，就退回原文动作、专名或更直接的关系；不要用通用象征替代材料。 |

这些形式允许同一标题承载不同读者处境下的不同感受，不要求所有读者读出同一种情绪或解出作品全部意义。可感不等于全盘解释：标题至少要凭公共经验、材料锚点或清楚的作品身份，独立建立相关、情绪或追看入口。

## 迁移旧骨架时先核对语义

旧有信息关系骨架只有在新材料与它保持同构关系时才可迁移。先抽出关系的参与者、事实或假设状态、读者预设、事件关系、焦点和命题力度；新材料逐项相合时，才沿用其形式。词性相同或能塞进相同槽位不够。若标题作用转向审美、情绪或作品识别，不强迫它留下收益/信息缺口；只有原文关系与旧骨架仍兼容时才保留，否则从材料锚点另选短语、意象或事件句。不能只替换对象词、改成同义词就称为新结构。

当标题面向读者的功能同时涉及表达态度、指向受众、指称内容、诗性形式等时，可以叠加而不互相排斥。DBS触发轴、标题功能、材料意义关系和文字形式是不同层次，不能混成一张互斥公式表。

## 信息逻辑关系的条件骨架

下表只处理信息命题关系，不替代上面的抒情、叙事、识别、立场或声音路径；用于辨认可用结构，不要求逐项遍历。某条关系可以用连接词、单句、短语、语序或省略表达，只要读者还能恢复必要的对象、关系、焦点和力度。括号是槽位说明，不是成品示例。

| 关系与适用条件 | 连接骨架及需填的语义槽 | 保留项、焦点与力度 | 常见误用与修复 |
|---|---|---|---|
| **缺少条件仍有可能。**材料支持某资源、资格或条件缺席时，仍有可行结果。 | `没有[资源/条件/资格]，也能[动作/结果]` | `没有`说的是条件缺席；`也能`说缺席不排除可能。重心落在仍可行的动作或结果。条件槽须是材料中被视为门槛的东西，结果槽须确实能在它缺席时成立。 | 不把“缺少条件仍可行”偷换成“这个条件根本不需要”。材料只证明存在一种可能时保留`也能`，不要改成人人必成的保证。 |
| **不必付出某步骤即可推得目标可达。**材料支持某行动、投入或步骤并非必要路径；与事实上的“没有”不同。 | `不必[行动/投入]，就能[目标动作/结果]`；来源结构 **#33**：`如何不[讨厌的事/不想承担的代价]，就能在[有依据的时段]达到[结果]` | 固定的是“不需要该投入”与“结果可达”的关系；在此骨架中，`就能`帮助读者从免去的步骤推到结果可达，具体语气强弱由整句、语境与证据共同决定。省力是焦点，结果是所得。时间槽只有材料明确支持才填。 | 不以`不必`描述某条件当前不存在，也不因愿望用此骨架替材料保证结果。若只证明条件缺席时仍有可能，改用“没有…也能”；若只提出建议，把结果写成目标或路径而非已验证保证，并尽量保留省力入口。 |
| **少付代价而保留所得。**材料支持降低某种成本，同时保留某项收益，但不一定证明完全不需要该成本。 | `少付[努力/时间/风险/机会成本]，仍可[所得/目标]`；必要时分成“[较少投入]—[所得]”两端 | 固定的是成本减少和所得保留之间的关系；焦点通常是少付代价或保住所得，可按观众入口调整先后。代价槽必须是具体投入或损失，不能只是坏形容词。 | 不把“少”写成“零”，也不把并存关系说成成本必然换来收益。若材料只支持绕过某步骤，改用“不必”；若实际结果未核实，保留可能、愿望或建议的力度。 |
| **让步后仍成立。**一端承认事实、另一端在该事实成立时仍保持。 | 已成事实：`虽然[已成立的事实P]，但/仍[主张或结果Q]`。假设或极端条件：`即使[假设/极端P]，也[主张或结果Q]` | 让步关系不可丢；焦点在让步之后仍成立的Q。`虽然`通常承接已知事实；`即使`把P放在假设或极端条件下，Q仍成立，突出意外性。 | 不把未发生的情形说成既成事实，也不把已知事实包装成纯假设来逃避承担。根据材料是真实前提还是假设选择连接词；若P与Q没有让步张力，改用更准确的并列或因果关系。 |
| **转折，推翻由P引出的预期。**P本身可以为真，但观众可能由P推断出另一结果，材料中的Q与该推断相反。 | `[事实/现象P]，但/却[与预期相反的Q]` | P 与 Q 的反差及读者可能产生的预期是骨架核心；焦点可落在意外Q。`却`把反常感压得更明显。该结构否定的是“由P必然推出某结论”，不必否定P本身。 | 只把两个不相干事实并排，不足以构成有效转折。补清真实推论或换成并列；不能把P本身造假来制造反差。 |
| **纠正同一判断槽位。**材料或当前对话里确有一个既存判断A，需要明确改成B。 | `不是[旧判断A]，而是[更正B]`；来源结构 **#1** 的本地形式：`为什么[具体预期A]其实[相反判断B]` | A 与 B 必须回答同一问题或占同一语义位置；焦点通常在更正后的B。`其实`提示纠正原先预期，不只是普通转折。 | 没有真实的读者预设或材料中的旧判断，就不要虚构“大家都以为A”；这会制造稻草人。若只反驳P引出的后果而非P本身，改用上一项“P但Q”。 |
| **同维比较后给出辨别任务。**观众确实在混淆或选择两类事物，它们可沿同一维度比较。 | `[类别A]与[类别B]如何区分`；来源结构 **#52**：`[正向特质A] VS [负向特质B]—如何区分` | A、B 要处于同一比较轴，不能一个是行为、另一个是结果却不说明共同尺度；焦点可以是差异，也可以是观众如何判断。`好/坏`是立场判断时须呈现为观点。 | 不把异质材料硬塞成对立，也不凭标签暗示客观优劣。先找到共同判据；没有可比维度时改成分别说明或单一判断。 |
| **递进到新增或更强的一层。**Q 的范围、程度或后果确实超出P，能提供新信息。 | `不只[P]，还[新增Q]`；程度增强：`不只是[P]，更[强一层Q]` | 固定的是递进方向和增量；“还”可以添加另一项，“更”主张程度或重要性更强。焦点通常在新加或更强的Q。 | 仅列并列内容不算递进；Q 若不比P新增或更强，就去掉递进词，改为准确并列。不能为了标题气势擅自扩大范围或严重程度。 |
| **两个量级联动变化。**P和Q各有可比较的程度，材料支持它们在所讨论范围内随彼此增加或减少而呈同向或反向关系。 | `越[可变尺度P]，越[可变尺度Q]`；方向相反时须用准确程度表达，不机械保留两个“越” | 两端都要有量级变化，焦点是变化之间的联动。形容词只有表示可分级尺度时适用；“程度”也可由动词、数量或频度承载。 | 单一状态随时间变多、两个类别差异或没有量级的名词，不构成“越X越Y”。有实际时间阶段时改用时间变化结构；只见同时出现而无联动依据时改为并列或明确标成观察。 |
| **行动者、受益者或控制位置倒置。**材料中确有角色位置交换，或比喻性角色能清楚表达自主权变化。 | `由[原行动者/掌控者]对[对象]做[行动]` → `改由[新行动者]承担[原行动/决定]`；可把两端压成对照或倒置表达 | 固定的是谁行动、谁受影响、谁决定；须先标明参与者和角色，再选词。焦点常落在权力、控制或劳动分配发生了变化。角色比喻可有力度，但不自动变成事实。 | 只有主体与客体交换词序、没有相同动作或权力关系，不算角色倒置。无现实证据时保留隐喻身份；若关系只是人物先后行动，改用时间顺序。 |
| **同一主体随时间发生变化。**材料明确给出可比较的前后状态、行为或能力。 | `[主体]从[先前状态/行为]变到[后续状态/行为]`；时间词可见可省，前后关系须仍清楚 | 两端属于同一主体或同一衡量维度；焦点在变化方向、差异或转变后的状态。是否使用“后来/现在/终于”等词由实际时间证据和语气决定。 | 不为制造故事擅自补出经历、时长或前因。材料只有两种并列选择时不要包装为成长变化；缺少前态或后态时只说材料支持的状态。 |
| **表象与原因/机制分开。**材料支持一个可观察表象及其背后原因；二者不是单纯同时出现。 | `看起来/表面是[可见现象P]，实际影响因素/原因是[有依据的Q]`；若只表达作者解释，标出观点身份 | 表象槽是观察或初步判断，原因槽是能解释该表象的因素；焦点在被揭示的Q。`其实/真正`表示纠正既有理解，不应只为制造反差使用。 | 没有证据只看到相关共现时，不写“原因”；改成“可能相关”“我认为”或描述可观察关系。P若不是读者已有理解，不要假造一个被揭穿的旧认知。 |
| **选择与代价/所得绑定。**材料显示选择A带来明确成本C、放弃项，或换取利益B。 | `选择[A]要付出/可能失去[C]，换来/保住[B]`；也可聚焦“选A还是承担C” | 选择、成本和所得要属于同一决策；焦点按观众最在意的收益或损失安排。`要`表达较强的必然性，`可能`保留不确定，不能混用。 | 没有真实取舍关系，不凭空制造损失或二选一。只有风险时说明可能性；若实际只是多一项好处而无成本，改成收益递进。 |
| **故事暂留一个未解点。**材料中有明确事件、动作或选择的后续，且答案确实存在于用户提供的作品内容。 | `已知[事件/动作/选择]`＋`未揭示但有材料承接的[后续结果/决定/原因]`；可用设问、悬念或截留表达 | 保留能定位故事的对象与处境，只暂缓一个观众有理由追问的结果。焦点是将发生什么、为何如此或如何选择，不必强制问号。 | 不隐去理解对象所必需的前提，不捏造悬念或暗示正文没有的答案。读者无法从已知材料判断在追什么时，补必要对象/动作，或改成直接交代。 |
| **方法连接行动与希望的结果。**观众想学一个材料确实覆盖的具体行动。 | `如何[可执行行动]，好让[受益者][希望的结果]`；来源结构 **#40** | 动作应是可以实行的办法，结果是方法的目的或观众所得；`好让`表达目的，不等同于保证结果已经发生。焦点可先写观众结果，也可先命名方法。 | 泛写“做好/提升/搞懂”而无动作时，把行动落到材料支持的具体行为；只提出建议时不写成已验证成绩。不要因名为“方法”就让标题退回正文目录。 |
| **鲜明立场指向具体行动。**作者材料中确有需要反对、停止或重新考虑的行为，且用户接受明确立场。 | `为什么[对象]应该停止/改变[具体行动]`；来源结构 **#61** | 立场词保留态度与命题力度；行动要明确，焦点在该行为及其理由。它表达作者立场，不天然证明行为有客观危害。 | 不因缺少因果证据而把态度改成温吞问句；但若声称具体危害或结果，留到后置核验。没有明确立场或目标行为时不套用。 |

## 填词：每个词都要满足材料关系

先保住标题作用、材料关系或意象焦点，再为位置挑词。词性可以帮助判断，但不能替代语义和自然搭配；一个短语或结果位置可以由名词、动词短语、状态或完整命题实现。判断以下限制：

- **对象与指代：**名词要能指回材料里的主体、事情、选择或受众目标；代词和省略只能在读者仍知道“谁/什么”时使用。锁定名称、引文及用户原话按主文保护。
- **动作与动词配价：**问清是谁做、作用于谁或什么、是否还有受益者/接收者/结果。选择要求的论元都能在标题或上下文中找到；及物动作补足对象，不及物变化不硬塞对象，给予、传递、教会等涉及受益者或内容时让关系可读。动词还要区别建议、意图、习惯、过程、实际演示和已发生结果。
- **条件、资源与原因：**“没有X”需要X是被讨论的资源或条件且材料允许其缺席；“不必X”表示X不是必要投入；“因为X”主张原因；“伴随X”只承诺同现。槽位语义不同，不靠换个近义词掩饰。
- **代价、所得与结果：**代价应是实际努力、时间、风险、金钱、机会或控制权；结果区分目标、可能、能力、建议与已发生事实。不能从“希望达成”跳成“必然达成”。
- **角色与时间：**角色词能对应实际行动权或明确的比喻关系；时间词能对应材料给出的先后、持续或变化。没有时长/前后状态的依据，不添数字、“终于”或经历线。
- **程度、否定与预期：**程度词须有可比较的尺度；否定词的辖域要清楚；“其实/真正”需有待纠正的预期，“却”需有可理解的反常预期。别让强词修饰到错误的对象或整段命题。

### 信息关系词与命题力度不能互换

| 词语 | 句面承诺 | 选用条件 |
|---|---|---|
| `也能` | 在额外条件或反预期下，结果仍有可能/能力可达 | 材料支持“存在可行路径”；通常弱于直接保证。 |
| `就能` | 在“不必X就能Y”骨架中，帮助读者从省去X推到Y可达；实际语气还受整句范围、语境及其他成分影响 | 只有材料能支撑这种条件推断时使用；不能只因它更有劲就代替`也能`。副词“就”在其他句法环境还有不同解释，不把单一义项套进所有句子。 |
| `才` | 结果受某条件限制，或条件是达到结果的必要门槛 | 需要材料支持必要性；不能仅表达先后或强调就写成唯一条件。 |
| `仍` | 在先前状态、阻碍或相反预期之后，原状态/结果继续成立 | 前后状态或阻碍有依据；焦点常在“没有被改变/依旧成立”。 |
| `却` | 与P引出的预期相反，突出意外Q | P与预期之间可理解；不等同于纠正P本身。 |
| `虽然` / `即使` | 前者通常承认既成P后让步；后者把P置于假设/极端条件下仍主张Q | 按P的事实身份选；不能互换来模糊事件是否发生。 |
| `其实` / `而是` | 标出对先前理解或同一判断槽位的修正 | 有可定位的旧判断；`而是`把焦点转向更正项。 |

## 炼字：在不改作用与材料关系的前提下提高句面力量

把初稿中的关键词逐个替换比较，不先追求“更高级”的词。比较对象是否更准确、搭配是否常见自然、动词要求的参与者是否齐全、情绪或程度词是否有材料支撑、代词能否辨认、语序把哪个信息放在焦点、声音和节奏是否顺、是否可以删掉不增加吸引或体验的字。替换后若改变人物关系、否定范围、可能性、因果、时间、视角或预期，必须重新判断整条关系，不能把它当作同一表达的润色。

保留用户提供的强词、欲望、情绪与比喻。事实检查只在候选形成后处理可核验断言；没有必要的防御性限定就不加。反过来，标题很有力量也不能让读者猜不出对象、动作或对比方向。关系词可省时，读者仍须能从语序、动作搭配或上下文恢复关系；恢复不了就补回最少的连接信息。
