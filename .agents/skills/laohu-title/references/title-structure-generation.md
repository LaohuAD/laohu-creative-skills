# 材料关系、用词与标题生成

由主文第3组在材料中值得留下的内容、句子职责与真实位置确定后、起草前读取；标题还须带入读者进入理由、字段条件和相关正文承接位置。输入包括锁定文字、作者对结论的开放度、实际上下文和本句要显出的关系；本 Reference 负责把选择落成材料关系、用词、形式与候选，不重做授权/受众/平台判断，不代写全文或整首歌词。成句后交回主文第4组放入真实位置比较、适配字段，并送[标题兑现与竞争复审](title-value-and-review.md)。

**选定的表达职责决定材料哪一面要显出来，材料关系再决定句子怎样成立。**标题可以是命题、事件、名词短语、意象并置、呼告、声音节奏或作品专名；语法构式是表达资源，不是统一生成理论。篇内关键句也可在清楚表达判断、连接经验或留住情感时直接成立，不必转成面向陌生读者的“进入理由”。

若调用者指定的是文章内部的章节标题或小标题，先按其提供的篇内位置、实际章节内容、前后推进和作者声音确定该标题承担的局部作用。它面向已经进入文章的读者，负责导航、区别本节判断、引出材料或提示转折；不另选一条独立的点击理由，也不必概括整篇或单独解释完整主题。只据已存在/已定的章节成句，不能因为标题候选更漂亮而另造主张、改正文、扩大承诺或增加分节。按调用者给出的准确字段数量返回，返回后由写作负责人嵌入全文并连读。

## 把已选入口落实为句子

按以下次序作实质决定；它是生成工作，不是要向用户展示的推导表，也不是供用户填写的 16 格流程：

1. **写准句子在当前位置的职责。**对文章主标题、封面或发布标题，判断目标读者要理解、得到、体验、追看、认出或表达什么；对篇内标题或句子，判断它要导航、点明中心、归结经验、连接前后、提示转折、留下原则，还是承担歌曲核心表达。允许标题和篇内句借用各自邻近上下文，不要求关键句独立代表整篇文章或整首歌。
2. **选能承载职责的材料。**从原话、强句、专名、行动者、关键物事、场景、感官、时间、观点、关系、重复意象、证据或故事变化中选必要部分。局部可成入口，整篇方法/过程也可能带来认识；具体人物、事件、数字、原句、意象或情绪本身有价值时不必抽象成通则。
3. **从材料辨出真实关系。**确认谁做什么、谁在意、什么改变、前后/因果/条件/让步/比较/角色关系如何、情绪由何处境或后果承载。标题若把读者处境或强评价接到方法、作者经历或具体行动上，先用内部工作释义确认两端指向的同一项关切，再选能使这种连接可感的具体特点、处理或变化；只有名称、工作动作或范围时，回取材步骤补出值得了解的内容，不先靠程度副词抬高评价。篇内中心/原则句要有当前文本支持，不把局部经验写成普遍真理；过渡句要让前后关系可辨，不凭空加判断。意象可开放多义，但要有原文、任务设定或公共经验锚点；用户委托原创修辞时可发展新映射，不把它伪装成原文含义、作者原意或现实事实。
4. **按关系选择句法和词。**命题型从下方条件骨架选真实匹配项；叙事、诗性、识别、声音、人称、时间或立场沿各自材料路径构句。若标题准备采用心理反转，先按[读者预期与材料入口](audience-value-and-structure.md#用真实预期判断是否构成反转)明确 P、E 的来源和 Q 对 E 的违背，再选择转折表达；不能先凭“却”“其实”或“越…越…”起句后补理由。
5. **先使句子成立，再按职责和字段凝练。**只删去不改变作用且读者可恢复的信息；也可通过重排、换词或重新组织关系让核心更清楚，但要保住对象、必要线索、关系、力度和声音。凝练不是以字更少、摘要更全或辞藻更亮为胜。用户给过原标题、强判断或认可短句时先作为比较基线；新句须在职责、材料支持或展示作用上有实际优势，不能因信息更多、范围更广就默认胜出。

一个标题可以兼有识别、表达态度、指向读者、诗性、悬念或其他功能，不必改成双分句、问句、功利所得或信息缺口。篇内关键句按实际职责表达；不把普通说明句广告化，也不要求句句箴言化。没有适用的心理触发时，直接沿已选材料关系生成，不逐项遍历类别、不套固定视角网格或外部 DBS Skill。

## 按关键表达的位置凝练

- **题眼/中心句：**只表达理解全文或本段所需的核心关系，不复述所有材料，也不擅自补成材料未支持的普遍规律；若作者尚未锁定中心、且允许探索，可先提出有依据的认识供作者确认。
- **总结/收束句：**让前文已建立的认识或感受落下来，可留余味；不因“要有金句”而另起更大的道理，不重复罗列全文。
- **过渡句：**让相邻内容之间真实的递进、转折、因果、对照或聚焦变化可理解；只需完成连接时，不强造高潮或格言。
- **歌词副歌核心句：**在本轮限定的句子范围内找到歌曲的情感/认识重心，兼顾说话位置、原词意象和可得的节奏/音节约束。没有旋律时只能说明文字尝试具备哪些潜在声音特征，不能声称已验证可唱或包办曲调。

成句后把候选嵌回标题字段、文章段落或歌词相邻行中比较。以具体位置判断关系、语气、声口和必要留白是否成立；不把“单独摘出也像标题/名言”设成所有句子的通用标准。

选词从已选材料和态度出发，而不是从固定猛词表倒推内容。遇到决定入口的关键词、动词或情绪词，从作者原话、当前材料中的动作与后果、公共语感中自然的评价和关系表达取得候选；比较所指是否熟悉可辨，能否承载真实参与者、行动、期待、后果或体验，读者利害与作者声口是否显出，精度和材料范围是否保住。这里的“信息量”是关系更快可懂，不是堆名词。情绪词与比喻可直接表达适用的感受或评价，不要求一律改成动作描写，也不等待用户先提供强词。

**把评价的对象、方向和程度写进词句。**任务需要加强或已选态度尚未写足时，运用评价理论的 Graduation（级差）分析语言怎样升高或降低评价。先确定谁在评价什么、沿什么方向、希望表达多大程度；再按本句实际需要比较程度修饰、数量/范围/持续或反复，以及词语本身融合的动作力度和价值判断。态度由处境间接显出、由评价词直接表达或由熟悉比喻压缩，都可采用。该理论的 Force 指强度与量级，Focus 指类别边界的强化或弱化，不能把 Focus 当作句子重心；这里的中文取材与成句步骤是本地适配。只处理会改变本句的资源，不逐类填满，也不把语言分析框架当作点击公式。

将候选放回完整标题，决定具体动词、评价词、语序、停顿和句子重心怎样共同突出同一项价值。按实际阅读顺序组织所选关切、承接它的具体内容和必要身份/方法线索；名称放在读者能辨认其作用的位置，作者经历在承担发现、变化或故事作用时进入，不让来历说明挤断已建立的关系。各成分可以前置、后置或融合，短标题也可压成一个判断单位；不把本步骤固化成“痛点＋方法＋收益”或要求结尾必须写结果。若材料选择成立而句子仍只报名称或工作动作，就把已选的态度与价值关系写进实际措辞；若尚未选出值得强调的内容，回到读者预期 Reference 取材，不靠增加程度副词填空。比较可能改变选择时，在主题、材料范围和已选立场相同的条件下比较完整句面，保留更充分呈现所选态度与价值、同时自然成立的一项；不是只比较孤词，也不默认最强、最短或最含蓄者胜出。同一方向内调整评价程度不自动重开选题；改变对象、事实承诺、核心立场或预期关系时才返回对应判断。评价的强烈不自动提高事实确定性；原有的事实、锁定文字和字段条件继续单独核对。

标题初稿若只有抽象主题、评价词、方法标签或“有价值/有冲突”一类概括，却没有目标读者能识别的进入理由，先不要再加形容词。回到材料，找到读者可能面对的具体时刻、选择、后果或新认识，再看哪种自然说法能把关系呈现出来；保留必要术语和读者关切。抒情、审美、故事或身份标题没有相应任务动作时，沿具体意象、声音、说话位置或关系找入口，不硬改成利益句。篇内关键句则按本句职责复核：若要点明判断，不因其没有标题式“进入理由”就判失败；若只有抽象赞语且没完成句子作用，再回材料取回支撑它的关系、具体细节或声口。

专业术语可用于准确标识主题、对象或作品身份，也可在它确会改变读者判断、选择或操作时保留；只有标题承诺具体方法时，才需检查材料能否说明怎样使用。术语既不帮识别又不改判断时，找日常处境或后果作桥，同时保住必要精度与身份。易读不等于越短越好，也不要求删掉必要专业词。来源对常用词/负面措辞的研究范围留在 `knowledge/标题创作偏好.md`；这些本地选择条件不组成中文热词表或点击公式。

## 区分独立重拟与原标题改良

独立创作或用户明确要求重拟时，原标题若存在，只作为了解当前题目框架和比较句面效果的材料；可从正文重新选择有依据的读者入口，不必沿原标题作最小修改，也不必保留原标题角度。仍须忠于正文主题、作者实际立场与用户锁定项，不能把“换入口”变成换文章主张。只有用户要求改良或明确锁定原标题时，才沿原题保护义务处理。

## 沿用户原标题改良，不另起主题

用户给出原标题并要求诊断时，原句本身足以检查对象、任务、读者利益、查询词是否可辨、钩子、表达关系与语言自然度；不以缺少正文为由拒绝句面诊断，也不擅自生成改写候选。事实是否成立、正文是否兑现、平台字段是否合规分别标为待材料或字段核验。

用户要求改良时，先从原标题提取并保护核心对象、受众任务、利益、主查询词和锁定文字；原标题中的时间或结果钩子先作为用户选定的吸引方向保留，事实核对留到候选形成后，不因尚未核验而一概删除。沿同一主题按修改幅度递进：先做最小词序或措辞调整；仍不够时，在保留核心关系与钩子的前提下改造结构；再尝试不同表达技法。默认按用户指定的同一发布平台给三条，依次体现这些层次；每条说明改动和取舍。三条不可只换同义词，也不准换成另一选题或受众任务。锁定文字始终逐字保留，预算冲突时指出并遵守锁定项。

每轮改良都与原标题并读，而不是只比较改写候选彼此。若标题承诺依赖正文中的方法、结果、经历或事实，标出具体承接位置并检查兑现范围；只凭标题句面无法确认的部分保留为待核。即使原标题不是全文摘要，也不为“更完整”而抹掉原有局部切口、审美或作品识别入口。

新标题候选若没有可说明的进入理由、表现力或字段适配优势，而原标题仍符合本轮目的与限制，就保留原题，不因“做过改写”而默认换新。篇内关键句若已有文字，则以当前句子职责和上下文作基线，不把“更像标题”当作改好的证据。

### 多个主体同时压缩到封面文案

当同一段封面文案同时放入作者自己的经历和对其他人的判断时，压缩前先分别标出“作者做过/发现了什么”与“作者对谁作出什么判断”，再用明确的发现、比较或判断动作把两者连起来。排好行后连续读，确认作者经历没有变成被评价者的修饰语。若短字段放不下两组完整关系，优先留下与本条观看入口最相关的一组完整主体—动作关系，或向用户建议删减/分层；用户锁定文案时只指出断行风险并提供建议，不静默改写。

## 按材料关系选择表达路

这些表达形式各有触发条件、操作、读者可感效果和误用修复；可以组合，不构成封闭菜单，也不要求一条标题把它们全用上。

| 形式 | 适用条件与具体操作 | 读者可感特征 | 失效时的修复 |
|---|---|---|---|
| **专名、母题或命名短语** | 标题首先承担识别、记忆、描述作品或指向稳定对象的作用时，保留用户锁定的名称，并从反复物象、核心场景或事件中选必要限定。 | 读者能认出谈的是哪部作品、哪一处场景或哪项对象；名字本身可以成为记忆入口。 | 名称太泛或无法识别时，只添原文支持的具体锚点；若作品名已锁定，不用副标题变相改名。不要为增加利益或悬念而改变作品身份。 |
| **信息命题与连接骨架** | 标题要帮助读者学方法、懂原因、辨区别、做选择时，先确认材料中的命题关系，再从下表选择意义相配的骨架并填语义槽。 | 读者能看见问题、条件、结果或判断如何相连；必要时能看见具体所得或仍待了解之处。 | 若句面只是术语、常识劝告或关系标签，回到材料找行动、对象和结果；关系不被材料支持时换骨架，不靠近义词补强。 |
| **事件句或场景句** | 原文有可定位的人物、行动、处境变化、选择或关键瞬间时，按“谁—做什么/遇到什么—发生何种变化”取必要部分；故事可留下由原文承接的真实后续。 | 读者能进入一个具体时刻，感到人物处境或事件在移动，并知道想追看哪一部分。 | 缺人物、行动或场景锚点时，不补造情节；若只剩剧情概括，回到能承载作用的局部动作或关系。没有真实未解点就交代已知部分，不制造悬念。 |
| **意象或名词短语** | 抒情、作品识别或审美体验依赖具体物事、地点、感官或反复意象时，从原文所处的视角和上下文选取；保留关键名词、动作或相邻关系，必要时并置而不解释全部情绪。 | 读者先看到/听到/感到一个可想象的对象，情绪和联想可从材料关系中浮现；留白仍有锚点。 | 只有泛化景物词、任意符号或漂亮词堆时，回到原文找具体视角、动作、感官和重复关系；若标题必须靠作者讲解才能连上，换成更可感的锚点或直接表达。 |
| **人称、呼告或口吻句** | 原文说话位置、读者关系或身份表达会改变感受时，选择“我/你/我们/他”等人称、称呼或原句语气；使代词所指和说话身份清楚。 | 人与人之间的距离、邀请、对抗、亲密或自我表达在句面可听见。 | 不为亲近而硬加“你/我们”，不虚构第一人称亲历；人称让关系变假或指代不明时，回到原话、第三人称或无主短语。 |
| **时间结构** | 原文真实呈现等待、回忆、前后状态、季节/时刻、反复或迟来的变化时，选择必要的“过去—现在”“到来—离开”或持续关系。 | 读者能感到距离、延宕、循环、失去或变化方向。 | 没有时间证据不补年月、时长或“终于”；若只是两幅并列画面，按并置而非成长/变化表达。 |
| **并置、平行、反复与声音** | 原文已有相邻意象、重复词、句式回环或可听的音节关系，且形式能加强意义或情绪时，保留节奏、呼应、停顿或平行。 | 读者能感到回声、对照、顿挫或语音记忆，形式参与表达。 | 为押韵或整齐而扭曲自然搭配、关系或焦点时，拆掉声韵装饰；音响无材料或语义作用时，用准确词句。声音平行不是质量保证。 |
| **相似映射、借代或象征** | 忠实承接既有作品时，沿原文、已选构想或公共经验中可辨认的相似/邻接/部分关系压缩表达。用户明确委托原创标题修辞时，可新造隐喻、借代、并置或命名关系，让它发展作品意图；须让读者能从标题或作品材料感知其关联，不能把新关系伪称为原文已有含义、作者原意或现实事实。 | 一个具体事物能带出更大关系，标题可保有含蓄，也可形成作品新的艺术入口；不必复述原文关系。 | 若新关系只有作者解释才能成立，改用更可感的锚点或直接表达；若标题会被读成可核实的现实断言，先核实其事实范围，不能用创作修辞遮掩不实主张。 |

这些形式允许同一标题承载不同读者处境下的不同感受，不要求所有读者读出同一种情绪或解出作品全部意义。标题的可感不等于全盘解释：标题至少要凭公共经验、材料锚点或清楚的作品身份，建立相关、情绪或追看入口。此处的入口要求不用于篇内过渡句或歌词单句；它们按各自相邻文本完成关系与表达职责即可。

## 从真实作品中选取并落实具体处理

主文第2组确认的触发条件成立——用户要求完整标题包，或开放路线会改变标题句法、关系、声音或留白——本节不是可选灵感菜单：起草前须从下面或同样已核的作品处理中选一项适合当前关键表达的方法，让它实际改变成句，并在第4组复审时确认材料确实承接。其他任务也可按需调用；但不要求每次重做外部研究、不要求三种方法同时出现，也不要求每条候选或每个平台具名作者。选法看与当前材料和标题作用是否相称，不按作者名气或流量排序。

- Paul Graham, “How to Do Great Work” (2023)：标题把读者想完成的整体工作命名出来；正文用选领域、走到知识前沿、发现空缺、探索方向等步骤支撑这项工作，而不是把步骤逐一列进标题。可迁移动作：对确有完整过程的材料，先辨认读者要完成的具体整件事、关键选择或希望得到的认识，再判断这件事为什么值得当前读者进入；标题表达这一任务或有材料支持的关系，正文路径负责兑现。整体任务可以窄而具体，不要求最大抽象概括，也不强制“如何……”句式；若用户要目录，清单可直接承担检索任务。边界：不可把单一步骤扩成整件任务或保证结果，正文须确实覆盖标题所指的工作；兑现检查仍与吸引选择分开。
- Paul Graham, “The Age of the Essay” (2004)：开头唤起学校作文的熟悉格式，并以把《白鲸》中的 Ahab 看作类基督人物为例，随后提出要重新说明 essay 是什么、如何写。可迁移动作：用读者熟悉的经验或具体例子打开问题，再由正文建立新的理解框架。边界：只有正文真有这项经验、例子及重新解释时才可用；不能只借反常感或争议感。
- Paul Graham, “The Bus Ticket Theory of Genius” (2019)：标题把巴士票这一具体物件与 genius theory 并置；正文先提出第三个因素，再写收藏者对票据细微差异的非功利兴趣，继而区分 Ramanujan 研究数学级数与巴士票收藏各自的价值。可迁移动作：让具体对象引出抽象判断，并由正文解释对象与论点的关系。边界：不能只靠新奇并置。

三者提供的是不同的取材与成句动作，不是固定句式、作者模仿、质量或点击保证；标题承诺与正文支撑的位置按实际全文判断，不限首段。原题、作者、年份、简要来源说明及网址见 `knowledge/标题创作偏好.md` 的来源台账，运行不依赖外链。

## 迁移旧骨架时先核对语义

旧有信息关系骨架只有在新材料与它保持同构关系时才可迁移。先抽出关系的参与者、事实或假设状态、读者预设、事件关系、焦点和命题力度；新材料逐项相合时，才沿用其形式。词性相同或能塞进相同槽位不够。若标题作用转向审美、情绪或作品识别，不强迫它留下收益/信息缺口；只有原文关系与旧骨架仍兼容时才保留，否则从材料锚点另选短语、意象或事件句。不能只替换对象词、改成同义词就称为新结构。

当标题面向读者的功能同时涉及表达态度、指向受众、指称内容、诗性形式等时，可以叠加而不互相排斥。DBS触发轴、标题功能、材料意义关系和文字形式是不同层次，不能混成一张互斥公式表。

## 信息逻辑关系的条件骨架

下表只处理信息命题关系，不替代上面的抒情、叙事、识别、立场或声音路径；用于辨认可用结构，不要求逐项遍历。某条关系可以用连接词、单句、短语、语序或省略表达，只要读者还能恢复必要的对象、关系、焦点和力度。括号是槽位说明，不是成品示例。

| 关系与适用条件 | 连接骨架及需填的语义槽 | 保留项、焦点与力度 | 常见误用与修复 |
|---|---|---|---|
| **缺少条件仍有可能。**材料支持某资源、资格或条件缺席时，仍有可行结果。 | `没有[资源/条件/资格]，也能[动作/结果]` | `没有`说的是条件缺席；`也能`说缺席不排除可能。重心落在仍可行的动作或结果。条件槽须是材料中被视为门槛的东西，结果槽须确实能在它缺席时成立。 | 不把“缺少条件仍可行”偷换成“这个条件根本不需要”。材料只证明存在一种可能时保留`也能`，不要改成人人必成的保证。 |
| **不必付出某步骤即可推得目标可达。**材料支持某行动、投入或步骤并非必要路径；与事实上的“没有”不同。 | `不必[行动/投入]，就能[目标动作/结果]`；来源结构 **#33**：`如何不[讨厌的事/不想承担的代价]，就能在[有依据的时段]达到[结果]` | 固定的是“不需要该投入”与“结果可达”的关系；在此骨架中，`就能`帮助读者从免去的步骤推到结果可达，具体语气强弱由整句、语境与证据共同决定。省力是焦点，结果是所得。时间槽只有材料明确支持才填。 | 不以`不必`描述某条件当前不存在，也不因愿望用此骨架替材料保证结果。若只证明条件缺席时仍有可能，改用“没有…也能”；若只提出建议，把结果写成目标或路径而非已验证保证，并保留省力入口。 |
| **少付代价而保留所得。**材料支持降低某种成本，同时保留某项收益，但不一定证明完全不需要该成本。 | `少付[努力/时间/风险/机会成本]，仍可[所得/目标]`；必要时分成“[较少投入]—[所得]”两端 | 固定的是成本减少和所得保留之间的关系；焦点通常是少付代价或保住所得，可按观众入口调整先后。代价槽必须是具体投入或损失，不能只是坏形容词。 | 不把“少”写成“零”，也不把并存关系说成成本必然换来收益。若材料只支持绕过某步骤，改用“不必”；若实际结果未核实，保留可能、愿望或建议的力度。 |
| **让步后仍成立。**一端承认事实、另一端在该事实成立时仍保持。 | 已成事实：`虽然[已成立的事实P]，但/仍[主张或结果Q]`。假设或极端条件：`即使[假设/极端P]，也[主张或结果Q]` | 让步关系不可丢；焦点在让步之后仍成立的Q。`虽然`通常承接已知事实；`即使`把P放在假设或极端条件下，Q仍成立，突出意外性。 | 不把未发生的情形说成既成事实，也不把已知事实包装成纯假设来逃避承担。根据材料是真实前提还是假设选择连接词；若P与Q没有让步张力，改用更准确的并列或因果关系。 |
| **与真实预期相违的转折。**P可为真，Q与读者由P形成的预期相反。 | `[事实/现象P]，但/却[与预期相反的Q]` | 句法只实现已经选出的反转关系；起草前先按[读者预期与材料入口](audience-value-and-structure.md#用真实预期判断是否构成反转)找出P、E来源和Q如何违背E。焦点可落在Q，P本身不必为假。 | 不把两个事实并列、递进或量级联动当心理反转；没有可说明的E就改用材料真实支持的关系，不编“大家都以为”。 |
| **纠正同一判断槽位。**材料或当前对话里确有一个既存判断A，需要明确改成B。 | `不是[旧判断A]，而是[更正B]`；来源结构 **#1** 的本地形式：`为什么[具体预期A]其实[相反判断B]` | A 与 B 必须回答同一问题或占同一语义位置；焦点通常在更正后的B。`其实`提示纠正原先预期，不只是普通转折。 | 没有真实的读者预设或材料中的旧判断，就不要虚构“大家都以为A”；这会制造稻草人。若只反驳P引出的后果而非P本身，改用上一项“P但Q”。 |
| **同维比较后给出辨别任务。**观众确实在混淆或选择两类事物，它们可沿同一维度比较。 | `[类别A]与[类别B]如何区分`；来源结构 **#52**：`[正向特质A] VS [负向特质B]—如何区分` | A、B 要处于同一比较轴，不能一个是行为、另一个是结果却不说明共同尺度；焦点可以是差异，也可以是观众如何判断。`好/坏`是立场判断时须呈现为观点。 | 不把异质材料硬塞成对立，也不凭标签暗示客观优劣。先找到共同判据；没有可比维度时改成分别说明或单一判断。 |
| **递进到新增或更强的一层。**Q 的范围、程度或后果确实超出P，能提供新信息。 | `不只[P]，还[新增Q]`；程度增强：`不只是[P]，更[强一层Q]` | 固定的是递进方向和增量；“还”可以添加另一项，“更”主张程度或重要性更强。焦点通常在新加或更强的Q。 | 仅列并列内容不算递进；Q 若不比P新增或更强，就去掉递进词，改为准确并列。不能为了标题气势擅自扩大范围或严重程度。 |
| **两个量级联动变化。**P和Q各有可比较程度，材料支持其在限定范围内随彼此增加或减少而呈同向/反向关系。 | `越[可变尺度P]，越[可变尺度Q]`；方向相反时准确表达，不机械保留两个“越” | 两端都要有量级变化；形容词需可分级，也可由动词、数量或频度承载。 | 单一状态随时间变化、两个类别差异或无量级名词不构成“越X越Y”；量级联动不等于心理反转。若要表达反转，另按读者预期 Ref 核验；无联动依据时改为时间变化、并列或观察。 |
| **行动者、受益者或控制位置倒置。**材料中确有角色位置交换，或比喻性角色能清楚表达自主权变化。 | `由[原行动者/掌控者]对[对象]做[行动]` → `改由[新行动者]承担[原行动/决定]`；可把两端压成对照或倒置表达 | 固定的是谁行动、谁受影响、谁决定；须先标明参与者和角色，再选词。焦点常落在权力、控制或劳动分配发生了变化。角色比喻可有力度，但不自动变成事实。 | 只有主体与客体交换词序、没有相同动作或权力关系，不算角色倒置。无现实证据时保留隐喻身份；若关系只是人物先后行动，改用时间顺序。 |
| **同一主体随时间发生变化。**材料明确给出可比较的前后状态、行为或能力。 | `[主体]从[先前状态/行为]变到[后续状态/行为]`；时间词可见可省，前后关系须仍清楚 | 两端属于同一主体或同一衡量维度；焦点在变化方向、差异或转变后的状态。是否使用“后来/现在/终于”等词由实际时间证据和语气决定。 | 不为制造故事擅自补出经历、时长或前因。材料只有两种并列选择时不要包装为成长变化；缺少前态或后态时只说材料支持的状态。 |
| **表象与原因/机制分开。**材料支持一个可观察表象及其背后原因；二者不是单纯同时出现。 | `看起来/表面是[可见现象P]，实际影响因素/原因是[有依据的Q]`；若只表达作者解释，标出观点身份 | 表象槽是观察或初步判断，原因槽是能解释该表象的因素；焦点在被揭示的Q。`其实/真正`用于纠正既有理解；标题确需承担这项纠正时再选用。 | 没有证据只看到相关共现时，不写“原因”；改成“可能相关”“我认为”或描述可观察关系。P若不是读者已有理解，不要假造一个被揭穿的旧认知。 |
| **选择与代价/所得绑定。**材料显示选择A带来明确成本C、放弃项，或换取利益B。 | `选择[A]要付出/可能失去[C]，换来/保住[B]`；也可聚焦“选A还是承担C” | 选择、成本和所得要属于同一决策；焦点按观众最在意的收益或损失安排。`要`表达较强的必然性，`可能`保留不确定，不能混用。 | 没有真实取舍关系，不凭空制造损失或二选一。只有风险时说明可能性；若实际只是多一项好处而无成本，改成收益递进。 |
| **故事暂留一个未解点。**材料中有明确事件、动作或选择的后续，且答案确实存在于用户提供的作品内容。 | `已知[事件/动作/选择]`＋`未揭示但有材料承接的[后续结果/决定/原因]`；可用设问、悬念或截留表达 | 保留能定位故事的对象与处境，只暂缓一个观众有理由追问的结果。焦点是将发生什么、为何如此或如何选择，不必强制问号。 | 不隐去理解对象所必需的前提，不捏造悬念或暗示正文没有的答案。读者无法从已知材料判断在追什么时，补必要对象/动作，或改成直接交代。 |
| **方法连接行动与希望的结果。**观众想学一个材料确实覆盖的具体行动。 | `如何[可执行行动]，好让[受益者][希望的结果]`；来源结构 **#40** | 把动作写成可实行的办法，结果写成方法的目的或观众所得；`好让`表达目的，不等同于保证结果已经发生。焦点可先写观众结果，也可先命名方法。 | 泛写“做好/提升/搞懂”而无动作时，把行动落到材料支持的具体行为；只提出建议时不写成已验证成绩。不要因名为“方法”就让标题退回正文目录。 |
| **鲜明立场指向具体行动。**作者材料中确有需要反对、停止或重新考虑的行为，且用户接受明确立场。 | `为什么[对象]应该停止/改变[具体行动]`；来源结构 **#61** | 立场词保留态度与命题力度；行动要明确，焦点在该行为及其理由。它表达作者立场，不天然证明行为有客观危害。 | 不因缺少因果证据而把态度改成温吞问句；但若声称具体危害或结果，留到后置核验。没有明确立场或目标行为时不套用。 |

## 句面复核：关系、配价与命题力度

上文负责正向比较词语，下面只检查容易改变命题的语义条件，不是第二张选词表。词性可帮助判断，但不能代替自然搭配；一个位置可由名词、动词短语、状态或完整命题实现。逐句核对：

- **对象与指代：**名词要能指回材料里的主体、事情、选择或受众目标；代词和省略只能在读者仍知道“谁/什么”时使用。锁定名称、引文及用户原话按主文保护。
- **动作与动词配价：**问清是谁做、作用于谁或什么、是否还有受益者/接收者/结果。选择要求的论元都能在标题或上下文中找到；及物动作补足对象，不及物变化不硬塞对象，给予、传递、教会等涉及受益者或内容时让关系可读。动词还要区别建议、意图、习惯、过程、实际演示和已发生结果。
- **条件、资源与原因：**“没有X”需要X是被讨论的资源或条件且材料允许其缺席；“不必X”表示X不是必要投入；“因为X”主张原因；“伴随X”只承诺同现。槽位语义不同，不靠换个近义词掩饰。
- **代价、所得与结果：**让代价落在实际的努力、时间、风险、金钱、机会或控制权上；结果区分目标、可能、能力、建议与已发生事实。不能从“希望达成”跳成“必然达成”。
- **角色与时间：**角色词能对应实际行动权或明确的比喻关系；时间词能对应材料给出的先后、持续或变化。没有时长/前后状态的依据，不添数字、“终于”或经历线。
- **程度、否定与预期：**程度词须有可比较的尺度；否定词的辖域要清楚；“其实/真正”需有待纠正的预期，“却”需有可理解的反常预期。别让强词修饰到错误的对象或整段命题。

### 信息关系词与命题力度不能互换

| 词语 | 句面承诺 | 选用条件 |
|---|---|---|
| `也能` | 在额外条件或反预期下，结果仍有可能/能力可达 | 材料支持“存在可行路径”；通常弱于直接保证。 |
| `就能` | 在“不必X就能Y”骨架中，帮助读者从省去X推到Y可达；实际语气还受整句范围、语境及其他成分影响 | 只有材料能支撑这种条件推断时使用；不能只因它更有劲就代替`也能`。副词“就”在其他句法环境还有不同解释，不把单一义项套进所有句子。 |
| `才` | 结果受某条件限制，或条件是达到结果的必要门槛 | 需要材料支持必要性；不能仅表达先后或强调就写成唯一条件。 |
| `仍` | 在先前状态、阻碍或相反预期之后，原状态/结果继续成立 | 前后状态或阻碍有依据；焦点常在“没有被改变/依旧成立”。 |
| `却` | 与P引出的预期相反，突出意外Q | P与预期之间可理解；不等同于纠正P本身。 |
| `虽然` / `即使` | 前者通常承认既成P后让步；后者把P置于假设/极端条件下仍主张Q | 按P的事实身份选；不能互换来模糊事件是否发生。 |
| `其实` / `而是` | 标出对先前理解或同一判断槽位的修正 | 有可定位的旧判断；`而是`把焦点转向更正项。 |

## 成句与炼字

将初稿放在实际字段中读，不只检查槽位：标题要自然地让读者认出对象、关系和进入理由。需要精修时，再对保义替换、语序、焦点、节奏、声音和可删字作小幅比较；不因字面更短、更高级或更完整就判胜。保留用户提供的强词、欲望、情绪、比喻和作者声口；不加没有必要的防御性限定。关系词可以省略，但读者仍须能恢复动作、参与者、对象和方向；恢复不了就补回最少连接信息。事实断言留给复审 Ref 在候选确定后核查。
