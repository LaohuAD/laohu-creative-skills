# 发布入口、读者预期与平台字段

发布入口模块在选取读者关切与取材时读「从材料确立入口」到「检查句面线索与材料承接」。已选反转时使用 P → E → Q。有拟题搜索需求时先读查询意图，用户问搜索影响或依据时读「按渠道判断标题能影响什么」，需要发布字段时读对应平台预算与写法。仅诊断时按问题读取，单做封面沿用封面专属预算。将所选入口、依据、兑现位置与字段条件交回模块成句，再回主文复审。

## 从材料确立入口

输入为用途、读者及其真实情境、作者态度与开放度、锁定项和可达材料。辨认材料中的可确认事实、作者立场与体验、可指出的关系及仍需解释的推论。人物、事件、数字、原句、意象或直接情感可以独自承载价值。比较读者范围与在意强度时，据用户所述、正文或有限的情境推断分别判断；窄众可以高度相关，广泛话题也可能缺乏进入动机。

在起草前把下列材料记成内部工作锚点，缺项据实留空：

1. **读者此刻的起点。**定位他们遇到标题时正在做的事、熟悉的现行做法、预期或体验。用材料支持的行动、处境或选择定位读者，身份标签只用在确能改变理解时。
2. **偏离起点的有据变化。**可用继续旧办法时的实际代价、有据反转、阻力变化或新路径，以及材料里有意味的数字、时间、原话或比例反差。故事也可以用某一选择与行动后的变化引起追看。审美、抒情、平静说明、作品识别及准确查找，按其作用使用意象、事实、原话、名称或检索对象。
3. **承接入口的具体内容。**在正文里标出支持入口的机制、行动、变化、关系、体验或证据。工作量、新术语与涉及项目本身只说明作者做了什么。它们承担明确的识别、故事或发现作用时，可以进入标题。
4. **作者口吻与读者选择。**确认作者允许的说明、推荐、赞叹、反对或自嘲程度；格式、语气、事实确定性分别核对。

这里用参照点帮助定位一项真实得失，得失方向取决于材料、读者的实际选择和作者目的。唤醒的双侧检查关注入口过平或理解过难两类情况。出现明显的目录腔时，先问是否本来就在服务索引，若要推荐则把有分量的差异、任务进展、体验或识别线索置于重心。出现接连陌生术语、对象难辨时，优先留下必要的核心专名，用紧邻的熟悉处境、动作或后果搭桥；专业窄众和精确查询可保留完成任务所需的术语。术语量与快速扫读只用来发现问题，不作固定心理或平台阈值。

用户未选强警告、而句面用命令或恐吓替受众决定时，回到其实际处境，展示材料支持的代价与选择，或直接呈现第一手结果。真实安全提示、明确行动号召、作者已定的强立场或角色口吻可保留相称的直接语气；核对受众在场景中有何选择，而非仅凭一个词诊断心理。熟悉处境可帮助读者认出与自己相关的任务，不靠硬加人称制造亲近。

## 让读者在句面看见材料中的关系

读者身份、主题名称、方法名称或文章覆盖的项目，能说明“这篇讲什么”，却不自动说明“为什么这批读者值得现在进入”。若任务要吸引或推荐，比较原文中真实可用的进入理由：某件具体任务怎样推进或卡住，一项发现怎样改变理解或选择，材料揭示了什么差别/后果，整段过程或故事带来什么体验，某句强表达或意象怎样帮助读者辨认作品与态度。选择标准是这层关系对当前读者是否有意义、材料是否承接、句面能否显出；不是哪条最容易对应章节，也不要求人为制造多条路线。

若标题只是把读者名称接到主题或步骤清单上，它可以说明内容范围，但不会仅凭“能看出会学什么”就自动胜出。把实际值得进入的那件事或关系放到句面重心；整件任务可以很具体、很窄，既不必提升成最大抽象成果，也不一定采用“如何……”句式。若用户明确要目录、索引、查找某个方法/作品，名称或清单本身可能就是有效入口；抒情、故事、身份与审美标题按其真实体验或识别价值判断，不强行转成实用所得。

按内容和读者的实际关系选择动机路径。若内容帮人推进任务，具体写出某个时刻谁想完成什么、原做法卡在哪里、材料提供何种改变；可读出所得、省力、能力或选择，但不把方法目的改写成已证明的结果。若材料围绕同一事实存在真实的不同解释或处理方向，再比较读者会把它看作定义问题、追问原因、作出评价还是采取行动，以及不同答案会改变谁的哪项选择；有依据的替代解释即使暂时导向相同动作，也可保留，不为制造竞争而发明反方。

当材料涉及群体位置或身份时，不止点身份词；找出真实涉及的规范、待遇、尊严、归属、利益或行动空间，以及它怎样影响当事人的关系和选择。只有材料支持时才把它作为进入理由，不替群体发声、不把局部材料泛化成普遍经历。故事可从人物目标、障碍、选择、行动和实际变化形成追看；作品识别可由锁定名称、母题或专名成立；幽默、审美和诗性可由具体物事、动作、声音、视角、时间或节奏直接成立，不必另添实用收益。

情绪判断与选词一起看，但不诊断真实读者心理。材料足够时，分别辨认目标对当事人的重要程度、是谁或什么造成处境、结果有多确定、当事人能否影响结果；这些关系可能让人感到不值、无奈、期待、安心、失望、被理解或其他体验。随后回到材料，比较哪些动作、关系、后果或处境词能让该方向可感。准确的情绪词可以直接用；它若只给情绪贴名而没有读者可辨的缘由，再寻找更贴合材料的说法。不同读者不必感到完全相同，也不宣称标题必然造成某种心理或提高点击。

**找出陌生方法值得了解的一项具体变化。**分享新方法、作者总结的体系或读者陌生的概念时，区分名称、用途、熟悉做法与新方法的差别，以及读者所得。先选材料真正能回答的关切，例如推进哪项任务、处理哪种反复困难，或带来什么认识与体验。原创身份、作者经历或名称可以交代来历与视角。

沿已选关切，找该方法具体选择、组织、保留或改变了什么，以及它怎样接上读者在意的事。工作规模、覆盖范围和方法标签只有体现本条变化或识别作用时才保留。将最能承接的一项具体特点同材料锚点交给生成步骤。方法目的按目的表达，观察到的结果按实际证据表达。

为陌生名称选择必要的身份、用途或价值线索，既不要求读者先懂完整体系，也不只报名称。结合已确认的作者声音与用途，决定平静说明、明确推荐、强烈赞叹或其他适用态度；把评价对象与程度交给成句步骤，不把“介绍一种方法”自动写成没有态度的课程说明。

选用得失方向时，先从材料确认读者在意的目标、现有做法和比较起点，再找出继续原处理的具体成本、放弃项或希望得到的进展；投入、重复处理、机会或后果均须有当前材料支持。不要凭方法陌生就制造“不学会便落后”的后果。强推荐、机会价值与损失提醒各自承担不同作用，按本题需要选择，不机械叠加。所选价值关系须进入标题句面的重心，由后续生成决定词句，不以情绪名称替代它。

上述路径可以交织，不是题材分类、固定必填项或候选数量表。先找最能解释“这批读者为何会在意”的关系，再用它指导选材；材料只支持一个入口就直接用，不为比较另造路线。事件可沿着“眼前事件→材料已显示的反复处境→相关机制或公共问题”打开；属性也可连到后果、选择或判断。每跨一步都须能指回稿件，找不到联系就停在具体层面。

## 用真实预期判断是否构成反转

只有准备采用“反转、打破认知、原来相反”等吸引角度时，起草前先写清三个实际关系：

1. **P：**句面或材料中的哪个前提、现象或处境作为起点？
2. **E：**为什么这批目标读者会由 P 形成某个可说清的预期？E 必须来自用户明确给出、稿件呈现的认知，或有边界的公共经验推断；若只能写“大家都以为”，就没有真实来源。
3. **Q：**材料实际提供了什么差异、判断或结果，它怎样违背 E，而不只是接在 P 后面？

P 可为真而 Q 推翻由 P 推出的结论；要被改正的对象应是预期，不一定是 P 本身。若 Q 只是更进一步、更多一层或同时出现，就按递进、并列、相关或其他真实关系表达，不以“却”、对比词、两个分句或“越…越…”替代 E。若材料支持有范围的预期与差异，可以保留强烈反转表达，不为牵强的次要反例加限定；无法说明 E 的来源或 Q 的违背关系时，不以反转作为创作理由。

## 检查句面线索与材料承接

用“信息气味”检查目标读者能否从实际显示的词语认出：这谈什么、与何种任务/体验有关、进入后可能看到什么。若唯一入口是目标读者不熟悉的术语，找其对应的日常处境、动作或后果作桥，同时保留改变判断或准确识别主题所需的术语和身份；不为通俗而把题目说错。若熟悉词过于泛泛，回到材料选择具体差异，而不是另造痛点。

只有本条确实需要好奇或悬置时，才检查“已知什么—还未知什么”的差值是否可感、对象线索是否仍足以定位、正文是否会承接。信息缺口不是所有标题的必要条件；不隐去理解主题所必需的前提，不制造正文无答案的悬念。若有搜索任务，查询对象也须可辨，但关键词不代替读者进入理由。

入口可从局部发现、场景、短句、子案例或作品名切入，不要求覆盖全文主旨。比较真实路线时，查看各自的材料锚点、读者处境、句面线索和正文承接位置，选择更贴近本轮用途且读者理由更清楚的一条；信息更全、受众范围更大、情绪更强、更容易列成章节，或更像摘要本身都不构成胜出。选定后把“材料锚点—读者为何在意—句面要显出的线索”交回发布入口模块，按对应的关系与语言成句。

## 让对象词与观众关切相遇

分清三类词：

| 词类 | 从哪里来 | 在标题中的作用 |
|---|---|---|
| 材料词 | 用户材料中的主题、对象、人物、作品名、地点、专业名词和观点 | 让观众认出内容对象，保护作品身份与材料关联 |
| 需求词 | 观众正在处理的任务、疑问、选择、愿望或体验 | 让观众看见内容与自身关切的连接 |
| 查询词 | 用户提供的搜索词、平台建议词、可复核的搜索记录或可靠数据 | 贴近实际检索表达；只有查询候选时不称为高频词 |

只有有搜索量、来源与时间范围等可复核依据时，才把词称为高频或搜索量较大。为候选词记录它从哪里来、对应哪项关切、是否出现在标题字段里。保留能帮助观众认出对象或需求的词；不堆无关词，不用关键词替代吸引理由。作品名、品牌名、人物名等用户锁定原文按保护项处理。

## 选定主查询意图，再让它进入标题

先从用户材料、原标题、用户给出的查询词或平台建议中，辨认一个与内容相符的主搜索任务。按意图区分对象/实体/技术/作品词、任务词（学习、使用或制作某类资产的需求）、结果/差异词和体裁标签；这些是词项来源类别，不是必须填满的清单。围绕同一搜索意图选择一个主查询词组和必要限定，使读者能认出搜索对象及实际任务。

没有搜索量数据时，仍可依据用户给出的词、材料词和任务词整理查询候选，不让缺少数据阻断标题创作；只把它们标作候选，不能称“高频”“热搜”或有排名优势。元标签不是默认标题开头；英文大小写本身不作为排名策略。

主查询词须自然进入有吸引力的句面，适合时放在前25个可见字符内；如果前置它会压掉更重要的受众任务或吸引点，优先保留自然有力的句面，并说明搜索与吸引之间的取舍。不要把同一意图的近义词堆在一条标题里；额外查询词只有在对应另一项真实意图且带来清楚的信息增量时才保留。搜索用词、浏览吸引和平台推荐各自检查，不推断封面文字会被OCR收录或任何单词有权重。

## 按发布入口适配表达

先沿用用户说明的发布计划、搜索需求、账号材料或平台功能。入口不清楚时，标题仍要让浏览中的观众读出观看理由；有搜索需求时也要保留能匹配搜索者对象和任务的词组。不要按平台名字臆测受众画像或排序权重。

实际投稿前，若字段口径或限额会影响产出，按当前投稿编辑器复核。

### 按渠道判断标题能影响什么

用户询问标题对排名、引用或推荐的影响及依据时，按所问渠道说明标题的作用及证据边界。来源见[标题创作偏好台账](../../../../knowledge/标题创作偏好.md#专业方法来源)及其中的平台字段资料。只请求拟题时，将相关判断用于选词和成句，按请求给出候选及必要取舍。

- **Google 自然搜索。**用简明标题准确描述页面，避免关键词堆砌。搜索结果里显示的标题链接由 Google 综合页面 `<title>`、可见主标题、其他页面文字与指向该页的链接等来源自动生成。标题含糊、过时或与页面内容不符时，Google 可能用其他来源改写显示题。以上属于结果呈现依据，无法据此承诺特定排名或点击。
- **Google AI 搜索与 GEO 研究。**Google 的 AI 搜索沿用基础 SEO 实践，无需额外的标题技巧。GEO 研究评估生成式引擎答案中网页内容的可见性，标题能准确标明实体、读者任务并与正文一致。页面的可检索性、正文及证据也影响信息能否被采用，单独改标题无法保证引用或排名。
- **平台推荐与 B 站站内搜索。**推荐场景先检查浏览者能否看出观看理由。站内检索另核对象和任务用词，以及该平台公开的匹配依据。现有 B 站资料能核投稿标题字段上限，标题关键词权重、排序和封面 OCR 收录尚无本轮可核实的官方依据。用各渠道自己的证据判断。

## 平台字段与限额证据

下表将官方字段证据与用户指定的本项目编辑预算分开记录。小红书、抖音、视频号短标题、B站、快手和微信公众号的数字是本项目预算，不一概冒称官方上限或统一界面计数。投稿字段更严时从严；界面允许更长时继续遵守本项目预算，除非用户明确要求扩展。当前入口或计数证据未知时，仍按预算拟题并将平台合规标为待核。

| 平台/预算口径 | 字段对应 | 已知字段证据与执行动作 |
|---|---:|---|
| YouTube 普通视频与 Shorts：100 字符 | 视频标题字段 | 官方帮助与 API 均列标题字段上限 100 字符；发布前复核实际入口计数。字段上限不表示首屏完整显示，也不证明具体截断位置、搜索权重或点击效果 |
| 小红书：20 字符 | 本项目小红书发布标题预算 | 作为项目预算直接执行；端内字段名称、当前计数与更严限制仍以真实投稿入口复核 |
| 抖音：30 字符 | 本项目抖音作品标题预算 | 作为项目预算直接执行；公开检索接口不足以证明标题匹配权重或官方长度，按当前投稿入口核字段 |
| 视频号短标题：16 字符 | 仅适用于短标题字段 | 短标题与描述分字段处理；16字预算不延伸为描述长度，实际限制更严时从严 |
| B站：80 字符 | 投稿/编辑标题 | 80同时是用户指定的项目预算，并与已核实投稿/编辑 API 字段上限相符；端内计数、预览截断与搜索权重仍分别核实 |
| 快手：60 字符 | 本项目快手作品标题预算 | 作为项目预算直接执行；API 的 caption 字段可承载作品标题，实际字段口径仍按投稿入口核实 |
| 微信公众号：64 字符 | 本项目公众号发布标题预算 | 作为项目预算直接执行；草稿字段、界面计数及更严限制按实际入口核实 |

优先用真实投稿编辑器的计数和提示验算，并分别记录平台上限、项目预算与最终字符数。暂时没有编辑器时，按可见字符逐个计数：汉字、数字、拉丁字母、空格和标点都计入。emoji 或组合字符在端内怎样计数仍待实际编辑器复核。按相同口径检查标题前缀。

## 标题重点前置与25字编辑判据

外部发布标题把主要作用所需的入口放在前面。发布标题不超过25个可见字符时检查整句；超过25个字符时检查前25个字符，确认读者已经能看见与本条作用相称的线索：方法/知识的所得或路径，故事的处境与追看，抒情/审美的具体意象、声音或感受，作品识别的专名/母题，观点/身份的立场。只有对象名称、材料主题或作者经历，不自动满足方法/知识型入口；但用户要识别作品时，专名可以是核心入口。不同任务用各自适合的句式。

作者事件只有与本条预期作用相连时，才可承担开头。小红书与视频号等本项目预算低于25字的平台，按完整标题检查即可。25字是本项目用户指定的编辑检查点，不是平台字段上限、折叠线或统一截断位置；不由某个平台的显示经验推断其他平台或设备的显示位置。

每次给出平台标题时，标明平台、具体字段、本项目编辑预算、字符数和当前入口限制的证据状态。没有真实投稿编辑器时按项目预算交付，并把端内合规标为待核；不以项目预算宣称已通过平台校验。标题超过25字时，检查并报告前25字是否已经显出本条作用的入口；短平台标题按完整短句检查。

## 逐平台重新构句

独立完整包和局部发布请求的字段与数量由入口模块确定。YouTube 是按需处理的独立平台。

先按发布入口模块的取材与成句步骤选定观众为什么会点开，再让每个平台的字段和表达方法参与成句。每个平台分别判断怎样表达这个已选入口，并独立构思至少三条候选；候选数量不是固定路线表，不把三条封面候选机械复制成六个平台的三条发布路线，也不要求发布标题与封面逐条配对。

平台表不能把较宽的观众吸引入口改成作者复盘或窄小材料入口；用户此前明确拒绝的入口，没有新的观众理由时不得恢复成默认。某个吸引点确实适合其他平台时可以沿用并重新组织，但须由材料、字段和可用的平台研究支持，不作默认复用。若有可用的平台研究或用户提供的发布条件，按其证据范围适配；没有时结合实际字段和材料处理，不臆测平台人群、语气或排序规律。无论入口怎样变化，每条具体事实仍须分别有材料依据。

实际重构字段时，先圈出发布入口模块的取材与成句步骤交来的、读者辨认对象与进入理由所需的最少线索，再按各字段预算和实际可见上下文重新组织，不机械裁切。压缩或分行后，把各标题放回本字段单独复读；需要时将多行连读，确认主语、动作、对象、条件与修饰关系没有错配。若读者已无法判断所指对象或为何相关，回发布入口模块的取材与成句步骤调整读者线索、材料或句面取舍，不靠堆查询词、强行互补或作者解释补桥。必要主题词可以在封面和发布标题中重复，独立可懂优先于避免重复。

完成各字段后，将最终字面送入[标题兑现与竞争复审](title-value-and-review.md)。复审返工后只重核受影响字段；本 Reference 负责搜索/平台条件与预算，不重复成品质量审查。

### 以材料条件选择平台表达

下表是依据有限的平台创作与内容材料形成的本项目编辑默认，不是对所有账号和观众的固定画像。先检查材料是否具备触发条件，再采用对应句法；条件不成立时，换成材料确实支持的表达，不补造经历、人物或平台语气。

| 平台 | 材料条件与表达动作 | 条件不成立时 |
|---|---|---|
| 小红书 | 材料包含真实体验、具体选择或熟悉的日常任务时，从任务或场景切入，再落到意外发现、明确判断或由此得到的东西。 | 没有作者亲历时，改从材料支持的选择、问题或发现进入。 |
| 抖音 | 材料能支撑鲜明判断、具体动作或清楚反差时，把判断、动作或反差前置，再接观众所得或可用方法；整句读起来要顺口，能一口气说完。 | 不为制造强度编造冲突；仍优先用材料中最有力的动作、判断或关系，不自动改成泛问句。 |
| 视频号短标题 | 材料支持一个离开上下文仍完整、容易转述的判断时，直接写成独立句。材料确有共同处境时，可用自然的人称让读者认出自己与他人的关系。16字预算不要求把判断写软或写残。 | 共处境不清楚时不猜人群、不硬加“你我”；保留材料里能独立成立的判断。 |
| B站 | 材料支持明确议题和鲜明论点或认知反转时，先点出议题与判断，再用案例、拆解方法或适用范围增加具体内容。 | 没有反转或强论点时不强造；选择材料真实支持的说明重点，并按长字段的增量原则扩展。 |
| 快手 | 材料包含具体人物行动或生活事件时，从人物做了什么、事情怎样变化写起，再接结果和观众能得到的知识。用直接自然的口语。 | 从具体问题、材料覆盖的操作及实在结果中选取，保持自然口语。 |
| 微信公众号 | 材料包含可讨论、可转述的观点，或能形成冲突的故事时，交代观点/冲突与它对读者的影响，再加入方法、路径或适用范围。可用多层句子承载不同信息。 | 没有相应观点、冲突或方法时不硬套完整结构；只扩展有材料依据且能带来新动机或理解的部分。 |

这些句法是有条件的编辑选择，不是普遍受众或排序规律。每条候选仍要标明它实际使用的表达技法；强陈述、角色力量、梗或夸张语气本身不需要被改成问句，也不因缺少点击率因果证据而自动弱化。仅在交付候选包含具体可核实断言时，才按主文在材料承接检查之后单独核查相应断言；不把广告或课堂正文总结规则套到标题上。

对B站80字、快手60字和微信公众号64字等较长预算，材料允许时把标题写得更完整，加入服务本条作用的新线索：方法/知识可补路径、差异或适用条件，故事可补真实处境变化或后续，抒情/审美可补有材料来源的意象、动作、时间或声音，作品识别与观点可补清楚的名称、母题或立场；不要默认每条都压成短口号。扩写不等于目录或作者复盘。预算提供可用空间，不是必须填满的目标。每增加一个成分，确认它是否让读者更清楚地理解、追看、体验或识别；若只是同义复述或没有增量就删去。缺少材料支撑、句子失去自然度或达到预算时停止扩写。新增可核实断言先保留表达方向，候选形成后再核验，只修不成立的具体断言。

## 交回发布入口模块与主文

返回主文时只交付影响本轮标题的词项、需求或查询意图、计划使用的字段和字段证据状态。标题草拟后再检查关键词是否帮助观众认出对象或关切，是否占空间却没有增加信息；不相关词移出标题。
