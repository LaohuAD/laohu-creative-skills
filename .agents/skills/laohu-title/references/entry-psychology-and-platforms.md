# 搜索意图、渠道证据与平台字段细则

由 [外部发布与搜索入口](../skills/laohu-title-entry/SKILL.md) 或 [主文](../SKILL.md) 在涉及搜索/GEO 规划、渠道证据咨询或多平台细选时按需读取；单平台常规创作或纯封面任务不需加载。

## 选定主查询意图与三类词筛选

需要兼顾搜索或 GEO 时，先从材料、原标题、用户提供词或平台建议词里区分三类词项：

| 词类 | 来源 | 作用与边界 |
| --- | --- | --- |
| 材料词 | 正文里的实体、技术、作品名、人物、地点与核心观点 | 准确识别对象，保护作品身份与锁定名称。 |
| 需求词 | 目标读者正在处理的任务、疑问、选择、愿望或体验 | 把内容对象连到读者当下的关切。 |
| 查询词 | 用户给的检索词、平台建议词或可核查搜索数据 | 贴近真实搜索表达；无搜索量、来源与时间范围时只称查询候选，不称高频词或热搜。 |

- **围绕单一主查询意图成句**：确定一个核心对象/实体词加读者任务词与必要限定（不要求硬凑结果词或体裁标签）；无搜索量数据不阻断创作，直接用材料词与任务词构建候选。
- **自然融入优先于机械前置**：主查询词适合时自然放入前 25 个可见字符；若强行前置会压垮更强的进入理由，优先保住自然有力的句面并在附注说明取舍。严禁在同一条标题里堆砌近义词，不默认加元标签或把英文大小写当作排名策略。

## 按渠道判断标题能影响什么

用户询问标题对搜索排名、生成式引擎引用或平台推荐的影响边界时，逐个所问渠道先给可执行做法，再交代系统机制与未知边界（完整出处见 [方法与平台来源台账](../SOURCES.md)）：

- **Google 自然搜索**：用简明标题准确描述页面核心内容，避免关键词堆砌。搜索结果展示的标题链接由 Google 综合 `<title>`、页面主标题、页内文本及入站链接文字自动生成；标题含糊、过时或与正文不符时，系统可能自动改写显示题。这是结果呈现机制，不构成排名或点击保证。
- **Google AI 搜索与 GEO**：Google AI 搜索沿用基础 SEO 实践，无需专门的标题奇技。GEO 研究针对网页整体在生成式引擎中的可见性，标题负责准确标明实体、读者任务并与正文一致；页面可检索性、正文结构与证据同样决定是否被采用，单改标题无法保证被引用。
- **平台信息流推荐与 B 站站内搜索**：信息流推荐看浏览者能否瞬间看到观看理由；站内检索另看对象词与任务词匹配。目前仅可核实 B 站投稿 API 标题字段上限为 80 字符，其标题关键词权重、排序算法及封面 OCR 收录均无官方实证，不外推 Google 或 GEO 结论。

## 平台字段与限额证据

除 YouTube 100 字符（官方上限）及 B 站 80 字符（与官方投稿 API 字段上限一致）外，其余 5 项均为用户指定的本项目编辑预算，不冒称平台官方上限。实际投稿端限制更严时从严，界面更宽松时仍守本项目预算（除非用户要求放宽）；未用真实编辑器校验时，端内合规标待核。

| 平台 / 字段 | 编辑预算 | 已知字段证据与执行口径 |
| --- | ---: | --- |
| YouTube 普通视频 / Shorts | 100 字符 | 官方帮助与 API 均定上限 100 字符；首屏显示截断、搜索权重与点击需另核。 |
| B站发布标题 | 80 字符 | 项目预算且符合已核投稿/编辑 API 上限；端内计数、截断与排序权重待核。 |
| 微信公众号发布标题 | 64 字符 | 项目预算；草稿箱字段口径与端内限制以实际发布端为准。 |
| 快手作品标题 | 60 字符 | 项目预算；API `caption` 可承载标题，实际长度上限待投稿端核实。 |
| 抖音作品标题 | 30 字符 | 项目预算；公开文档不构成自然投稿上限或权重证明，按投稿端核字段。 |
| 小红书发布标题 | 20 字符 | 项目预算；端内字段名称、计数规则与更严限制按实际投稿端核实。 |
| 视频号短标题 | 16 字符 | 仅约束短标题字段；视频号描述为独立字段，不延伸套用 16 字限制。 |

- **计数口径**：无真实编辑器时逐个计可见字符（汉字、数字、拉丁字母、空格、标点均计入）；emoji 或组合字符的端内计数标待核。
- **25 字重点前置判据**：这是本项目编辑检查点，不是统一平台截断线。总长 ≤25 字符查整句；>25 字符查前 25 字符是否已露出本条主作用的核心入口与必辨对象（作者经历仅在与该入口直接相连时才放开头）。

## 以材料条件选择平台表达

下表是有条件的本地编辑默认，不是固定人群画像或平台算法铁律。先核对材料是否具备对应条件，成立才选用；条件不成立就按材料真有的关系直写，绝不补造经历、人物或刻板语气：

| 平台 | 材料具备对应条件时的写法 | 条件不成立时 |
| --- | --- | --- |
| 小红书 | 有真实体验、具体选择或日常任务 → 从具体任务/场景切入，落到意外发现、明确判断或实际所得。 | 无作者亲历时，直接从材料支持的选择、问题或发现切入。 |
| 抖音 | 有鲜明判断、具体动作或清楚反差 → 判断/动作/反差前置，后接观众所得或可用做法；整句顺口能一口气读完。 | 不硬造冲突，取材料中最有力的动作、判断或关系，不自动改泛问句。 |
| 视频号短标题 | 有离开上下文仍完整、易转述的独立判断 → 直接写成独立完整句；确有共同处境时可自然用人称。16 字内同样保锐度。 | 共处境不明确时不猜人群、不硬加你我，保留能独立成立的判断。 |
| B站 | 有明确议题与鲜明论点或真反转 → 先立议题与判断，再用案例、拆解方法或适用范围展开增量。 | 无反转或强论点时不硬造，选材料真实支持的重点按长字段增量展开。 |
| 快手 | 有具体人物行动或生活事件 → 从人物做了什么、事情如何变化写起，接实在结果或可学做法，保持直接自然口语。 | 从具体问题、实际操作与结果取材，保持自然口语，不套方言标签。 |
| 微信公众号 | 有可讨论转述的观点或冲突故事 → 交代观点/冲突与对读者的影响，再补方法、路径或适用条件，可用多层句子承接增量。 | 无相应观点或冲突时不硬凑多层，只写有材料依据且带新理解的部分。 |

- **长字段实料增量与呼吸感原则**：对 B 站、快手、公众号等长预算，材料能支撑时主动展开成更有信息量的完整标题（方法补路径/差异/条件，故事补处境变化/后续，抒情补具体意象/动作/时间，观点补立场与适用边界），不要习惯性全压成短口号；**但预算只是上限而非填满指标**，应保持手机列表 2 行一眼扫清的呼吸感（通常 2–3 个最硬信息拍即收手，刻意留一拍给正文兑现），绝不把痛点、动作、细目、结果四层硬塞成 55 字摘要墙。每多写一段都须带来新理解、新追看或新辨识，一旦变成同义复述、剧透光正文或破坏节奏立刻收笔。
