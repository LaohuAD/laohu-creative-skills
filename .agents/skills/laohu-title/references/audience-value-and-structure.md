# 观众反应与标题入口

由主文第3步读取：先接收步骤2已选定的查询意图（若适用），再确定标题要承担的作用和希望唤起的反应，从材料中选出能承载它的入口。完成后把查询意图、标题作用、目标反应、材料锚点及其关联理由带回主文；无需向用户展示完整的内部推导链。

## 先看标题要让读者做什么

标题可能要让人看见某种所得、弄明白原因或区别、追看人物与事件、进入一段情绪或审美经验、认出作品或记住名称、表达态度或确认身份。它们是可以并存的功能轴，不是互斥体裁，也不要求每条标题固定只选一种或机械添加相同数量的副功能。沿用用户的创作目的；目的还不清楚且会改变入口时，再补问最小问题。

读者反应也不总是“这对我有什么实用好处”。方法或知识标题可以唤起想学、想解决或想区分；故事可让人担心、期待或追问人物下一步；抒情和审美标题可由具体意象、动作、声音、语气、节奏或作品关联直接带来感受；观点、身份和作品识别标题可让人认同、辨认、回想或转述。不同读者的联想不必完全相同，只要标题本身有材料支撑且可以感知的入口。

搜索意图与浏览吸引是并行的判断。当任务确有搜索入口，先知道搜索者用什么对象词、任务词或结果/差异词寻找内容，再判断同一标题是否也让浏览者看见值得点开的具体理由；关键词本身不是吸引点。搜索词与吸引力冲突时，结合用户目标说明取舍，不为了保词写成生硬目录。没有搜索需求的歌词、作品名或审美入口继续以材料语言和读者体验为主，不额外塞入实用词。

## 从材料中选择能承载作用的锚点

读原稿、作品名、用户原话和上下文，只摘取会改变标题选择的少量信号：专名、人物与关系、动作、处境、时间与空间、反复意象、感官细节、事件变化、观点、情绪转折或真实未解之处。局部细节可以成为独立包装角度，不必总结或代表全文。

按目标作用选材料：方法/知识看材料实际覆盖的步骤、原因、差异或选择；故事看人物想要什么、遇到什么、如何行动以及处境怎样变化；抒情/审美看情绪怎样在叙述视角和上下文中出现、哪些物事或动作承载它；作品识别和身份看锁定名称、母题、重复线索或说话位置。不要从与作品无关的景物、符号或身份词开始编联想，也不要把作者的解释当作读者已经从标题感到的东西。

区分已知事实、作者观点、创作意图和工作推断。用户给出的受众、用途、锁定名称或原话优先；缺少时只按当前材料作有限判断，不补造普遍需求、人口规模、亲历或平台画像。对需要读者体验的标题，不替读者规定唯一情绪；允许同一具体现象在不同人生处境中产生不同联想。

## 比较标题入口

比较的是哪个材料入口更能完成本条标题作用，而不是哪个候选信息最全、最像摘要或最能代表作者主旨。若标题承担搜索任务，同时检查主查询意图是否可辨认、搜索者期待是否与材料一致，以及句面是否仍然有浏览吸引；查询词与读者利益可相同，也可由标题中相连的不同部分承担。可从这些问题中选与任务有关的少量问题，不必逐项答题或评分：

- 读者会先看见、感到、理解或认出什么？这与用户要它承担的作用是否一致？
- 材料里的哪个专名、动作、处境、关系、意象或声音具体承载这项作用？去掉它会不会变成泛化说法？
- 读者需要哪一项现实路径、原因或区别，或哪一个真实事件的后续？只有方法、知识或故事目的适用时才要求这种明确所得或追问。
- 若标题走抒情、审美或识别路线，句面有没有可感的物事、动作、时间、声音、语气或作品锚点？读者是否必须依赖作者补充解释才能建立关联？
- 读者自身可能会补入哪些联想？这些联想是否由标题用词、原文关系或公共经验支撑，还是标题只留下任意谜语？

日常创作把候选放在一起比较，按标题作用、材料锚点和句面效果作定性取舍；不设固定候选数，也不因没有数字而停止判断。需要正式评分时，只有在标题类型、用途、必要正文上下文和字段条件可比，并选定真实人类标尺与明确等级后，才读取[共享评分与验证规则](../../laohu-analysis/references/validation.md)，逐项给出候选与标尺的句面证据；标题的进入潜力与正文兑现分开判断。不能用搜索量、流量、AI自评或任意分数制造客观性，也不能因为新协议而把每次标题创作都变成评分任务。用户要多角度方案时，保留作用或材料锚点不同的入口；功能不同的候选可以并列，不为制造“统一标准”而让它们都变成同一种利益标题。

## 选择可感的表达方向

先确定本候选主要作用和读者第一反应，再决定标题要露出什么、保留什么。方法标题可说明具体所得；故事标题可给出人物、处境或真实悬念锚点；抒情标题可留下能唤起情绪的意象、动作或关系而不解释尽；作品识别标题可突出专名或母题；观点与身份标题可保留立场和说话位置。它们可以组合，但不要为凑齐功能把同一标题塞满。

保留会影响吸引力、语感和联想的强词、声音、节奏、留白和比喻。具体数据、来源、亲历、事件、因果或结果留到候选形成后的事实核对；愿望、情绪、身份隐喻和审美选择不自动改判为事实承诺，也不因待核事实而预先削弱。

## 交回主文

内部只需确认：这条标题要完成什么作用，适用时要匹配哪个查询意图，预期唤起什么反应，选了哪处材料锚点，为什么它能承载该作用。用户只需要比较候选时，简要说明能帮助取舍的差异即可；作者长解释不能替句面补出缺失的吸引点或体验。
