# 语言力度、语义边界与经典取法

仅在下列情形按需读取对应小节：用户咨询用词/虚词/评价力度区别；短封面同时塞入多主体易错配；创作非命题诗性标题；句面关系词把建议吹成保证；或开放重拟需要参照已核实经典作品取法。

## 把评价对象、方向与力度写进整句

先分清词语各自说的是什么，不把不同维度的词排成单一强弱榜：例如交代来历或新意（原创）、给出使用评价（真好用）、用比喻作强推荐（王炸）分别回答不同问题，需结合说话人、评价对象与语境选用。

强化力度时借评价级差两轴落到句面：
- **力度轴（Force）**：可调程度强度，或用材料支持的具体数量、范围、持续时间、频率取代泛形容词，也可直接换自带力度的准确动词（把动作和程度合进一个词）。
- **边界轴（Focus）**：收紧或放宽类别边界；它不同于靠语序、首尾位置和停顿形成的信息焦点。
- **态度与事实分离**：把推荐态度写足，只改变这句话的立场与感染力，**不改变其中写实断言的确定性**（不可因此把愿望、自述或建议偷写成已验证效果）。

## 场景沟通动作与证据动词边界

- **先定沟通动作再正向成句**：修改生硬、端着或搭配别扭的句子时，先确认这句话在眼前场景里完成什么沟通动作（解释、分享、推荐、反驳、提醒或发问），还原谁对谁做什么的真实关系后正向重组，不靠原地换近义词敷衍。非常规搭配只有在生成前已选定声口、或上下文足以让读者自然辨认时才成立，**绝不在写生硬后事后贴上诗性或陌生化标签强行保稿**。
- **证据动词不越级**：看见线索但未比对用发现/查到；逐项对照用核对（核对本身不等于无误）；信息足以答清有限问题用确认；唯有证据完整覆盖主张链条时才用证明。

## 多主体压缩到短封面防错配

当一条短封面同时装进作者自己的经历和对其他人的判断时，压缩前先拆清两层关系：作者做过或发现了什么、作者对谁作出了什么判断，再用清晰的动作把二者接上。排完行连读，严防作者经历滑成被评价者的定语。若 8 字装不下两组完整主谓关系，优先保留与本条核心入口最直接的一组完整主谓，或向用户建议分层；锁定文案只标出断行风险与建议，不静默改写。

## 非命题表达路径

标题与关键句不必一律写成双分句命题或问句。抒情、审美、叙事、身份与作品识别可直接沿下表成句（可自然组合）：

| 路径 | 适用材料与成句抓手 | 失准时回修 |
| --- | --- | --- |
| 专名与母题短语 | 用锁定名称、反复物象或核心场景建立直接识别与记忆。 | 太泛时补一处有据锚点；锁定名不借补充变相改名。 |
| 事件与场景切面 | 挑真实人物、关键选择、动作或瞬间；后文有答案才留未解点。 | 滑向摘要时缩回单个关键动作；无未解点就直写。 |
| 意象与感官并置 | 取原文视角下的物件、地点、声音或感官细节，保留有据余味。 | 滑向泛景物或空漂亮词时，换回绑定人物与动作的原锚点。 |
| 人称与呼告 | 人我距离、邀请、对抗或自白会改变效果时用真实称呼或原话。 | 所指模糊或虚构亲历时，改回原话、第三人称或无主短语。 |
| 时间结构与声律 | 借等待、前后对比、循环或自然回声/停顿强化感受。 | 无时长依据不添终于或年数；押韵拗口时优先保自然语序。 |
| 借代、象征与映射 | 从材料或公共经验取相似/邻接关系，保留具体物事；获授权虚构时可原创映射。 | 离开作者解释就看不懂时换锚点；新隐喻不冒充现实事实。 |

## 语义同构迁移与关系词承诺边界

复用任何成熟句式前，必须确认新材料与原结构在**参与者、事实/假设状态、读者预设、事件关系与命题力度**上同构，绝不只看词性顺手填槽。高危关系词不能混换：

| 表达或虚词 | 精确句面承诺 | 常见越界与修复 |
| --- | --- | --- |
| `没有 X 也能 Y` vs `不必 X 就能 Y` vs `少付 X 仍可 Y` | `没有…也能` 指条件缺席时仍存在可行路径；`不必…就能` 指免去某非必要投入即可推得目标可达；`少付…仍可` 指降低成本而保留收益。 | 不把条件缺席吹成根本不需要，不把少付写成零成本，不把建议或可能偷换成必然保证。 |
| `虽然` vs `即使` | `虽然` 承接已成立的既成事实；`即使` 把前提放在假设或极端条件下主张后句仍成立。 | 按前提的事实身份选用，不拿假设词替既成事实卸责，也不把未发生的事说成已成事实。 |
| `才` / `仍` / `却` | `才` 承诺必要门槛；`仍` 承诺阻碍或变化后状态继续成立；`却` 承诺与前项可理解预期相反的意外。 | 无唯一门槛不用 `才`；无真实预期 E 不用 `却` 伪装反转。 |
| `其实` / `而是` | 纠正同一判断槽位上真实存在的旧理解。 | 无可定位的旧判断时不虚构稻草人硬拗纠正。 |
| `越 X 越 Y` | 两端均有可分级量级，且材料支持联动变化。 | 类别差异或时间先后不套此式；量级联动不等于心理反转。 |
| `因为` vs 共现 | `因为` 主张因果解释；仅同时出现只写相关、现象或作者推论。 | 有相关无因果证据时不硬写原因。 |

## 已核实真实作品的可迁移取法

开放重拟或完整发布包需要具体取法时，按与当前材料和用途的相称度选用（出处见 [SOURCES.md](../SOURCES.md)，运行不依赖外链）：

- **Paul Graham《How to Do Great Work》(2023)**：标题命名读者想完成的整体工作（可窄而具体），正文用步骤与路径兑现，不把章节清单塞进标题。适用前提：正文确有完整路径，单步不代替整件工作。
- **Paul Graham《The Age of the Essay》(2004)**：先唤起读者熟悉的共同经验或具体例子，再由正文建立新理解框架。适用前提：正文确实完成了这层重新解释，不单靠制造反常感。
- **Paul Graham《The Bus Ticket Theory of Genius》(2019)**：把具体日常物件与抽象判断并置，由正文把二者的隐蔽关系讲透。适用前提：正文真正建起关联，不靠猎奇硬拼。
