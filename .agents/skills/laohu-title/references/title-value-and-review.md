# 标题价值与文字复审

由主文第6步在候选已经成句后读取，或在用户只提供原标题并要求诊断时读取。按主文已确认的标题作用复审读者体验、材料关系、表达形式、字词自然度、事实依据、字段及锁定条件。仅诊断时只给句面诊断，不自动生成候选；用户要求改良时，回主文第2—4步重新读取[标题作用、材料关系与表达生成](title-structure-generation.md)并沿保留核心的改良路径处理。本文件负责审查成品，不提供候选生成公式；预算以[关键词与平台字段](keywords-and-platforms.md)为准。

## 遮住解释，按目标作用验收

先遮住作者解释和技法标签，单独读候选；检查它是否能凭句面、材料锚点或公共经验承担预定作用。不同读者可有不同联想，不要求所有人感到同一种情绪，也不要求标题交代全文或解释完所有含义。若读者必须听作者补桥，回到生成链找是作用、取材、关系组织还是形式选择没有接上。

| 标题主作用（可组合） | 检查标题本身有没有做到 | 没做到时回到哪里 |
|---|---|---|
| **方法、知识或理解** | 读者能认出要理解、学会、选择或区别什么；涉及具体收益时，能看见材料实际提供的路径、原因、区别、步骤或结果，或一个真实且有锚点的待解问题。主题名、抽象能力词、常识劝告或作者道理单独出现不算具体所得。 | 回主文第2—3步重新确认目的、读者反应和材料所得；抽象词有材料支持时落到具体任务、处境或选择。 |
| **故事或叙事追看** | 人物、处境、行动或变化至少有一处可定位，读者知道想追看哪一段关系或后续；悬置的问题由原文真实承接。 | 回到材料找人物目标、阻碍、选择、行动和实际变化；没有未解事件就直接呈现已有场景，不制造悬念。 |
| **抒情、情绪或审美体验** | 有原文支持的具体意象、物事、动作、感官、声音、时间、人称或关系，使读者能从句面感到情绪方向或形成有锚点的联想；留白不必被解释尽。 | 回生成 Reference 的抒情路径，重找叙述视角、情绪变化和承载它的物事；若只剩泛化景物或任意象征，换回有上下文支撑的原文锚点。 |
| **作品识别、描述或记忆** | 锁定的作品名、专名、母题、场景或事件辨识度符合用户目的；当名称本身承担识别时，不要求额外添加利益或信息缺口。 | 回到用户锁定文字和原文，保住名称；只补能准确辨认对象的必要限定，不改作品身份。 |
| **观点、态度或身份表达** | 立场、说话位置、对象与力度清楚；读者能判断它是在表达主张、邀请认同、拒绝某种行为还是确立身份。 | 回材料与用户态度，区分观点、愿望和事实；不要因为待核证据把可保留的态度改成温吞句。 |

功能可以并存，按实际目的检查，不强迫一条标题加入固定数目的副功能。抒情、审美、作品识别、鲜明观点或原句本身能提供体验时，不强造功利所得、问句或信息缺口。反过来，标题若承诺方法或结果，也不能只凭意象含蓄来替代它。

## 同时复审查询匹配与读者吸引

有搜索意图时，检查标题是否保留一个自然、准确的主查询词组，且对象、任务和限定语与材料说的是同一件事；再单独检查浏览者是否能从句面看见值得点击的所得、区别、故事、态度或体验。搜索词出现不等于标题有吸引力，吸引句若抹去主查询对象也可能偏离搜索任务。两者无法同时保留时，按用户的主要目标说明具体取舍，不把编辑判断说成算法排名权重。

无搜索需求时不强制加入查询词。没有来源、时间范围和可复核数据，不称高频词，也不宣称标题改善Google排名、推荐流量或生成式引擎引用。Google自然搜索、站内推荐、B站站内搜索与GEO分别看待；标题只可能承担准确指明实体、主要任务和主题一致性的一部分，引用和内容可见性还取决于网页正文及其他信号。

仅凭原标题进行诊断时，指出句面现有的对象、任务、利益/钩子、查询意图和语言关系，以及哪些判断只能等待正文、来源或平台字段；不要求用户先给正文，也不把诊断请求变成完整21条标题包。若用户明确要求改良，改写动作按生成Reference执行，并保留其核心对象、任务、利益、关键词和锁定项。

封面默认使用自然完整的陈述句或判断单位，最多八个可见字符且不加标点；完整行动号召也可成立。发布标题默认陈述句，也可以使用问句、方法名、叙事或呼告；问号与技法标签本身不能充当吸引理由。封面和发布标题都要完成各自的作用，角度可相同也可不同，不要求逐条配对或让发布标题强行换主题。较长字段增加的内容须为本条作用带来新的理解、追看、情绪、审美或识别线索；无增量的材料目录、近义复述和作者自我解释应删去。

## 对照内部生成选择与实际句面

沿“标题作用/预期反应 → 材料锚点及其承载理由 → 关系或意象组织 → 文字形式 → 炼字”核对前后是否一致。该链是执行依据，不要求向用户报告每个中间步骤。特别检查：

- 对象、人物、作品名、代词和锁定原话能否明确指回材料，专名是否按要求保留；
- 意象、场景、动作、感官或叙述视角是否来自材料且能承载预期情绪，声音、节奏和留白是否自然；
- 若使用事件结构，人物参与者、动作、对象、时间、事实/假设状态及后续是否有材料依据；
- 若使用信息骨架，条件、代价、结果、关系、读者预设、焦点和命题力度是否都与材料相符；连接词、否定、程度、可能性和时态有没有改掉原意；
- 词语搭配与动词配价是否自然，表达技法标签是否准确说明句面真实形式，而不是只写“利益”“情绪”或把主题贴成“反转”。

迁移已知骨架时，须保住关系、参与者、事实或假设、预设、焦点与力度；仅词性相同或填满相同槽位不能通过。抒情标题不必表达完整因果命题，意象短语也可以成立；但物象、动作、视角或作品关联须有材料锚点，读者不必由作者把所有联想解释完。若作用不符或材料锚点失真，回主文第2—4步；若表达不自然但作用和关系成立，先炼字，不用空泛标签掩盖偏差。

## 用户原话与事实断言分开处理

用户给出的“AI干活我躺平”首先表达省力、轻松的愿望，不自动表示观众全程不参与；“做完我还是不会”把任务完成和能力仍不足并置；“当你的主人”表达自主与控制。按本轮吸引方向保留这些原话的语言力度，用户明确锁定时逐字保留。不要将它们自动解释成事实保证或已验证的传播效果。

候选形成后逐条标出可以核实的断言，包括数字、来源、作者亲历、实际发生的事件、因果、方法和结果。仅用用户材料或本轮授权核实的来源检查。发现不成立或证据不足的具体断言，只修正或收窄那一项，并尽量保留原来的欲望、情绪、比喻和表达力度。愿望、观点、立场与修辞夸张若不声称可核实事实，不要先改成平淡陈述。没有真实发布数据，不声称标题已经提高点击或流量。

## 字段与交付复核

对照主文第7步和关键词 Reference 检查封面共用预算、发布字段与项目预算、字符计数、强调词、锁定原文和平台字段证据。标题不超过25个可见字符时检查整句；超过25个字符时检查前25个字符是否已经呈现与本条作用相称的入口：所得/路径、情绪或审美锚点、故事牵引、作品识别或立场。对象名称或作者经历不自动满足方法/知识型入口；当用户要识别作品时，专名可以是核心入口。25字是项目编辑判据，不表示统一平台折叠或截断位置。没有实际投稿编辑器时标明计数口径及端内限制待核。

失败只修对应部分：作用不清回第2步，材料入口不贴合回第3步，关系或形式有误回第4步，字词不自然回第4步炼字，具体事实断言不成立只修该断言；字段或锁定文字有冲突时遵守已确认边界并说明。没有真实受众反馈或发布数据时，不把编辑复审记作效果验证。
