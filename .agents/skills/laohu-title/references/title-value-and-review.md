# 标题兑现与竞争复审

由主文第4组在关键表达候选初次成句后读取；标题字段适配完成后，再以准备交付的最终字面版本复审。任何返工若改动句面，都以更新后的最终版本重核受影响部分，直至可交付。用户只提供原标题并要求诊断时，也读取本 Reference。篇内/歌词关键句先按本页的实际位置方法检查其职责和语境；下方关于读者入口、展示字段、点击/搜索及标题类型的细则只用于标题任务。按本轮已确认的句子职责复审材料关系、表达形式、兑现范围、字词自然度、事实依据、字段及锁定条件。仅诊断原标题时只给句面诊断，不自动生成候选；用户要求改良时，回主文第1—3组重新读取[材料关系、用词与标题生成](title-structure-generation.md)并沿保留核心的改良路径处理。本文件负责审查成品，不提供候选生成公式；标题预算以[关键词与平台字段](keywords-and-platforms.md)为准。

顺序是先排除会改变主旨理解、材料承接、来源身份或实际兑现范围的核心问题，再比较其余成立候选的读者理由与句面强弱。前一检查确认入口能指回材料、相关内容确实存在且作者/来源身份不被编造；它不代替定稿后的逐条事实断言核验。不要将自然口语修辞因牵强次要反例反复加限定，也不要因新句更完整就默认它更有吸引力。

**文章内部标题按其实际位置验收。**对主标题，用整篇文章和用户要求核对入口与内容范围；对章内标题/小标题，读它与前后段落、标题所在章节及紧接内容，判断读者在该处能否看出本节要展开的判断、材料、动作或转折。小标题可以依赖已读正文，不要求每节单独像一则推荐广告，也不要求脱离全文复述主题；但不能因漂亮表达改掉章节论点、暗加正文没有的主张，或让标题与后文错位。其后正文应承接标题所指的章节作用并继续推进，不重启整篇背景。若调用者只要求标题文字，指出并修订标题，不私自重写正文或增删章节；将嵌回稿件和全文连读留给写作负责人完成。

下文关于读者“进入理由”、候选竞争与推荐的细则，只适用于把读者带入整篇内容的主标题、封面和发布标题。题眼、中心/总结/收束/过渡/原则句及歌词核心句，不与发布标题竞争，按前一节所述实际句子职责和相邻语境复审。

## 篇内与歌词关键句按位置复审

对题眼、中心/总结/收束/过渡/原则句，比较它与实际前后文：本句是否完成指定工作，关系是否能从材料还原，是否保留作者已锁定的判断与声口；作者允许开放探索时，推论是否仍有依据、没有把局部经验升级成普遍规律。具体人物、事件、数字、原句、意象或直接情感本身有表达价值时，可以就此成立，不需再抽象成一个更大的道理。凝练可减少理解阻碍或让经验关系更显，不以字数更少为胜；留白可以有据多义，但不能让读者无法判断句子在说什么。需要连接而非总结时，不要把普通说明句改成广告或格言；若只承担过渡，不额外制造高潮。

对歌词副歌核心句，只核本轮单句是否服务现有歌曲材料、说话位置和相邻歌词；不扩写整首词，不替作者确定旋律。没有旋律或歌手试唱结果时，关于音节、节奏和可唱性的判断只能作为文字层面的待配合条件，不写成已验证可唱。改后仍放回完整段落/相邻歌词复读，不从孤立金句感决定胜负。

用户要求推荐或吸引型标题时，把内容对应、能说出读者是谁、或准确列出文章覆盖哪些项目视作基础相关性，不单独当作胜出理由。若一句标题主要由“读者名称＋主题/步骤清单”组成，问它是否让这批读者看见一个材料支持且此刻有意义的任务进展、选择、后果、认识差异、故事或审美体验；再与材料中的其他真实入口相比。如果推荐理由只剩“它对应几章/读者知道会学什么”，回主文第2组重选读者在意的关系、第3组改成让关系显在句面的版本，再比较。只有用户本来要索引、目录或精确查找时，清单完整度才可成为首要胜出依据。

## 遮住解释，按目标作用验收

先遮住作者解释和技法标签，在本轮实际展示字段中单独读每条候选；检查它是否能凭句面、材料锚点或公共经验承担预定作用。限于字段中实际可见的标题文字和确有的邻接上下文，判断目标读者能否辨认对象、关切与进入理由；不把未经材料或情境支持的读者知识当作已知前提。术语和作品专名按目标读者与识别任务判断，不一律删成泛词。若候选采用反转，按[读者预期与材料入口](audience-value-and-structure.md#用真实预期判断是否构成反转)复核起草前所确定的P、E来源与Q关系；两个分句、递进或“越…越…”本身不证明反转。若采用好奇或悬置，确认对象线索仍足以定位，未知差别可感且正文能承接；不靠隐去整个主题制造缺口。

对已选鲜明态度、强推荐或较强表达的标题，指出这种态度由哪些实际词句承担、评价什么，以及材料中选定的价值差异、具体代价或体验是否真正进入句面。按完整标题的实际阅读顺序，核对相邻成分是否继续推进本条选中的关切：开头提出读者的投入、困难或强推荐时，后续提供的具体特点、处理或变化是否使其值得了解，还是转成仅报陌生名称、作者工作动作或覆盖范围。主题相同不等于连接已完成；不以整句相关、语气强烈或字数合格结束复审，也不把名词相近却改变了对象的说法当作承接。取材不足回主文第2组；内容已选而关系或信息次序未呈现，回生成 Reference 的真实关系与整句组织步骤；态度尚未写足，再用级差方法调整，比较可能改变选择时比较完整候选，落实修改后重读终稿。方法名、作者经历或行动本身已承担本条识别、发现或故事作用时可以保留，不要求结尾重复收益或解释完整方法；篇内导航、平静说明及其他未选强口吻的任务仍按其用途验收。推荐说明不能补偿标题缺少的表达；局部事实校正只修受影响断言，不顺带改淡仍成立的态度、比喻与力度。

若候选会显示在卡片、缩略图、搜索结果或发布页，按实际文字长度与预览条件检查，不以作者的上下文解释替代陌生读者的第一眼理解。需要分行展示时，把所有行重新连读成一句，再确认读者不会把主语、动作、对象、否定、条件、数字或修饰语错配到另一部分。命题型句子核对真实主体—动作—对象关系；意象、审美或作品识别标题核对其具体联想入口是否由材料或公共经验承接。不同读者可有不同联想，不要求所有人感到同一种情绪，也不要求标题交代全文或解释完所有含义。

若标题承诺依赖正文中的方法、结果、事件、体验或作者经历，找出全文中实际承接该入口的位置并确认范围；支持点可以在开头以外，不要求首段马上给答案，局部入口也不必代表全文。这是材料兑现和身份来源的承接检查，不替代定稿后的逐条事实核验。若读者必须听作者补桥，按最早断点返回：对象、关切、必要线索或进入理由不成立时回主文第2组；材料关系或表达形式未接上时回第3组；仅字段呈现或长度不合时回第4组。

| 标题主作用（可组合） | 检查标题本身有没有做到 | 没做到时回到哪里 |
|---|---|---|
| **方法、知识或理解** | 读者能认出要理解、学会、选择或区别什么；涉及具体收益时，能看见材料实际提供的路径、原因、区别、步骤或结果，或一个真实且有锚点的待解问题。主题名、抽象能力词、常识劝告或作者道理单独出现不算具体所得；若请求是吸引/推荐，列出文章涵盖的步骤也不自动说明为何值得进入，除非用户要的正是索引或清单。 | 回主文第2—3组重新确认目的、读者反应和材料所得；抽象词有材料支持时落到具体任务、处境或选择。 |
| **故事或叙事追看** | 人物、处境、行动或变化至少有一处可定位，读者知道想追看哪一段关系或后续；悬置的问题由原文真实承接。 | 回到材料找人物目标、阻碍、选择、行动和实际变化；没有未解事件就直接呈现已有场景，不制造悬念。 |
| **抒情、情绪或审美体验** | 有原文支持的具体意象、物事、动作、感官、声音、时间、人称或关系，使读者能从句面感到情绪方向或形成有锚点的联想；留白不必被解释尽。 | 回生成 Reference 的抒情路径，重找叙述视角、情绪变化和承载它的物事；若只剩泛化景物或任意象征，换回有上下文支撑的原文锚点。 |
| **作品识别、描述或记忆** | 锁定的作品名、专名、母题、场景或事件辨识度符合用户目的；当名称本身承担识别时，不要求额外添加利益或信息缺口。 | 回到用户锁定文字和原文，保住名称；只补能准确辨认对象的必要限定，不改作品身份。 |
| **观点、态度或身份表达** | 立场、说话位置、对象与力度清楚；读者能判断它是在表达主张、邀请认同、拒绝某种行为还是确立身份。 | 回材料与用户态度，区分观点、愿望和事实；不要因为待核证据把可保留的态度改成温吞句。 |

功能可以并存，按实际目的检查，不强迫一条标题加入固定数目的副功能。抒情、审美、作品识别、鲜明观点或原句本身能提供体验时，不强造功利所得、问句或信息缺口。反过来，标题若承诺方法或结果，也不能只凭意象含蓄来替代它。

## 搜索条件的复审交接

有搜索意图时，按[关键词与平台字段](keywords-and-platforms.md)的搜索条件复核最终候选：查询对象/任务须和材料一致，同时句面仍要呈现读者进入理由；不能因关键词已出现就判吸引成立，也不能为吸引力抹去用户确有的搜索任务。没有搜索需求时不另塞查询词。数据来源、搜索/推荐/GEO边界及平台字段证据由该 Reference 唯一维护，本文件不再复做一遍关键词与平台审计。

仅凭原标题进行诊断时，只判断当前句面可见的对象、任务/关切、进入理由和语言关系；正文兑现或事实/字段待核不妨碍这项诊断，也不把诊断扩成完整标题包。用户要求改良时回生成 Reference，沿保护的原题方向改写。

## 对照已选理由与实际句面

用主文和生成 Reference 已确定的读者理由、材料锚点与关系，检查它们是否真正在最终候选里出现；不再报告完整内部生成链。特别检查：

用户要求原标题改良或锁定原标题/强句/内容入口时，把原句与每条候选并读：其承诺及材料支撑是什么，新句增加或损失什么读者理由、关系、范围或字段作用。只有新句更贴近本轮目的且材料与句面相接时才替换；具体事实错误、偏离原意或不能兑现时只调受影响部分，保住其余吸引点。独立重拟可另选读者入口，但不得改换正文主题、立场或用户锁定项。

- 对象、人物、作品名、代词和锁定原话能否明确指回材料，专名是否按要求保留；
- 意象、场景、动作、感官或叙述视角是否来自材料且能承载预期情绪，声音、节奏和留白是否自然；
- 若使用事件结构，人物参与者、动作、对象、时间、事实/假设状态及后续是否有材料依据；
- 若使用信息骨架，条件、代价、结果、关系、读者预设、焦点和命题力度是否都与材料相符；连接词、否定、程度、可能性和时态有没有改掉原意；
- 词语搭配与动词配价是否自然，表达技法标签是否准确说明句面真实形式，而不是只写“利益”“情绪”或把主题贴成“反转”。

迁移已知骨架时，须保住关系、参与者、事实或假设、预设、焦点与力度；仅词性相同或填满相同槽位不能通过。抒情标题不必表达完整因果命题，意象短语也可以成立；但物象、动作、视角或作品关联须有材料锚点，读者不必由作者把所有联想解释完。若作用不符或材料锚点失真，回主文第2—3组；若表达不自然但作用和关系成立，先回第3组炼字，不用空泛标签掩盖偏差。

复审未通过时按首个差距返回：读者理由或竞争入口不成立，回主文第2组及读者预期 Reference；材料关系、句法、词义、配价或修辞未落实，回第3组及生成 Reference；仅字段问题回第4组与关键词 Reference；具体事实断言不成立，只修该断言并保留仍成立的吸引方向。

## 用户原话与事实断言分开处理

用户给出的“AI干活我躺平”首先表达省力、轻松的愿望，不自动表示观众全程不参与；“做完我还是不会”把任务完成和能力仍不足并置；“当你的主人”表达自主与控制。按本轮吸引方向保留这些原话的语言力度，用户明确锁定时逐字保留。不要将它们自动解释成事实保证或已验证的传播效果。

核心材料入口与兑现范围检查完成、交付候选确定后，再逐条标出这些候选中可核实的断言，包括数字、来源、作者亲历、实际发生的事件、因果、方法和结果。仅用用户材料或本轮授权核实的来源检查；不用把前一步材料承接检查再做成第二套逐句事实清单。发现不成立或证据不足的具体断言，只修正或收窄那一项，同时保留原来的欲望、情绪、比喻和表达力度。愿望、观点、立场与修辞夸张若不声称可核实事实，不要先改成平淡陈述。没有真实发布数据，不声称标题已经提高点击或流量。

## 正式人类标尺比较（仅在本轮确实需要评分时）

普通标题创作按前文定性比较即可。用户要求正式评分、规则评估需要评分，或本轮明确采用人类作品标尺时，先确认标题类别相同（作品名、章节名、推荐流标题或搜索标题不可混作同类），并给每条候选及标尺提供相同的必要正文上下文、目标受众/使用位置和字段约束。只凭孤立标题评估句面吸引时，结论限于句面；正文兑现必须另看正文证据。

标尺须是真实可核验的人类作品，且与本次用途和条件有可比性；仅有知名度、发表记录或高点击不能证明该标题在当前任务中是顶尖标尺。评分维度与等级定义使用[共享评分与验证规则](../../laohu-analysis/references/validation.md)，本文件不另造百分制或第二套等级。比较时匿名并交换顺序，分别指出本作和标尺的实际词句、入口、材料承接与命题力度，再判断相当、候选更强、标尺更强、两者都未完成任务或不可比；评分不能替代事实核对，也不能用偏离正文的强刺激抵消兑现失败。没有真实受众/发布数据时，不把编辑判断写成点击效果验证。完成后回主文第4组，按最早差距定位第2—3组修订并重读成品。

## 返回修订并核对最终字面

项目预算、字符计数、25字重点前置判据、强调词、端内限制与平台字段证据由关键词 Reference 承载。复审使用已经形成的具体字段，只判断其中对象、入口、语言关系和承诺是否清楚；字段本身有问题时交回主文第4组和关键词 Reference。若作用或读者理由不成立回第2组；材料锚点或句法未接上回第3组；具体事实断言不成立则只修该断言。任何返工改字后都要复读更新后的最终候选，并按实际改动复核字段预算；没有真实受众反馈/发布数据，不把编辑复审称为效果验证。
