# 外部发布与封面入口专项

若先读到本文件，先回 [laohu-title 主文](../../SKILL.md) 确认任务模式、实际字段、数量与锁定项；仅诊断或原句改良时按同等标尺审原句并保住已成立的好切口。

**门外标题属于典型的协同留白媒介——它的本质，是用 100% 顺口的活人大白话与高唤醒情绪，在十几个到三十个字里演活半截跟读者有关的微型故事。** 按**关联理论**追求最高认知效应与最低理解努力，按**信息缺口理论**给读者推开一扇半开的门：滑屏陌生人一秒在主角身上看见自己或身边人，被主角的遭遇、高唤醒情绪与反常转折瞬间点亮神经；而最勾人的那块解法刚好留在门内，读者心里自己冒出为什么、怎么做到的，忍不住像追剧一样点进来拿到答案。

只要正文有真货兑现，理直气壮放出锋芒与情绪张力；红线只划在编造假数据、假经历和正文接不住的空头支票上。

## 1. 第一标准：双向之雅 × 四阶嘴替 × 100% 顺口大白话

**语义绝对通顺、0.3 秒一读就懂、像真人当面脱口而出，永远是好标题的第一门槛。** 动笔前在后台 1 秒完成三支点轻定盘（不输出给用户）：锚定整篇最带劲的**高唤醒情绪主脉**、锁定**全人群零歧义的角色站位**、决定**扣在门里的信息缺口**，随后直接放飞写出鲜活初稿，成稿后再轻度扫疤。

- **立意瞄准做受众嘴替，质地守住双向之雅**：跳出流水账报幕和局域发牢骚，也远离温吞叹气式的防御性鸡汤，更不滑向带人身攻击戾气的粗鄙发泄——**向内保持清醒体面与凝练留白，向外保持零防御姿态直击痛点与爽感**，让情绪基调与原稿最爽、最燃或最扎心的主脉同频共振。
- **激活高唤醒情绪，让情绪从活词与遭遇里自然溢出来**：
  - 优先点燃驱动点击与分享的**高唤醒情绪**（痛快翻盘的解气、惊掉下巴的反差、豁然开朗的惊奇、切身吃亏的警醒）；
  - 用自带好恶联想与生活画面的**情绪负载词**替掉冷中性词与绕弯委婉词，用带身体痛感、人际冲突或掌控爽感的**活动词**演活主角动作，并顺着真实语流选用贴合当下语气的汉语自然口语态度词带出说话火候（随具体语境灵活取词，不机械复读同一套固定虚词套式）；
  - 动宾人际站位贴合双方真实关系；缩字写短标题时，选全人群一眼零歧义的清晰角色称呼；
  - **退掉窄行业词，站上更大的共同遭遇**：把单一细分工种细节退回正文当扎实案例，让门外入口落到更大一圈同样痛的人都能一秒对号入座的共同处境与大母题上（用户锁定窄众、精确检索或抒情识别例外）。

## 2. 发布标题：演活半截主角故事 + 认知空白记忆钩子

- **演故事、立主角、扣解法**：把主角（亲历者自己，或屏幕前踩坑卡住的读者）放进具体遭遇里，用极凝练的几拍演出**切身处境 + 憋屈冲突或极端反差 + 违背常识的转折结果**，同时把具体怎么发生的、靠哪一招搞定的稳稳留在门内当信息缺口。
- **笃定陈述为主，让读者心里自己问为什么**：靠打破常识的反转事实和戛然而止的半截故事，自然激发读者脑中的追问冲动；整组 3 条优先用笃定陈述句，问句最多 0–1 条。
- **借认知空白与最优创新假说（熟语微拧半寸）造强记忆点**：每一条候选都要有让人点开或顺手转发的记忆刀口——按题材真气自然选用**熟语微拧半寸、语意前扬后劈、反讽冷刀（客气表层刺穿残酷落差）、表里双轨或人性公理空槽**，并过**三秒质检**（第一遍 0.3 秒读顺零门槛，半秒咔嗒击中，100% 服务主情绪，单截出来自带社交货币）。
- **三条候选走三种不同切口，按题材主作用自适应选路（条条带追看动力，不拿无反转纯吐槽凑数，也不把所有题材硬拗成苦情翻盘）**：
  - **痛点经验 / 职场成长 / 冲突观点类**：① 惨状反差 → 破局翻盘切片（困境立主角 ＋ 狠心转身后的意外转折，扣住具体破局法）；② 憋屈冲突 → 反常识逆转切片（演一秒最受气的现场冲突 ＋ 违背直觉的痛快结局）；③ 熟语微拧 / 认知突破切片（反讽冷刀、前扬后劈或微拧半寸的规律直戳痛处并留悬念）。
  - **教程工具 / 深度评测 / 人物审美 / 作品首发类**：自然切换为 ① **认知颠覆或反常发现**（打破惯性认知的新事实或关键差异，扣住底层原理）；② **极简省力或鲜活切面**（直给可感知的省力飞跃或人物最动人的瞬间，不编造苦情冲突）；③ **意象留白或母题直击**（守住作品自身气质与专名辨识度，用干净余味勾人点进）。

## 3. 按平台真实语感独立构句与预算速查

每个平台按各自阅读空间和刷屏节奏从头构句，彼此错位互补：

- **微信公众号（硬预算 ≤ 64 字，常规列表呼吸参考 22–34 字）**：一两拍利落短句演完半截微型故事，前 25 字稳稳砸出主角冲突或反差，读完一口气顺畅、意犹未尽。
- **小红书（硬预算 ≤ 20 字含标点）**：像真人刷屏随口甩出的一条追瓜解气短切片，纯活人口语、角色称呼零歧义，跟封面零重字互补且带反差爽感。
- 其他平台按需启用（未点名不展开）：视频号短标题 16 / 抖音作品文案 30（帮正在看的人建立理解框架）/ 快手 60 / B站 80 / YouTube 100。独立完整 6 平台包才启用默认数量（3 封面 + 6 平台各 3 条）；常规单/双平台任务留在当前文件完成，仅在精确搜索/GEO 选词、渠道证据咨询、多主体压缩歧义或细辨虚词边界时，按需查阅 [entry-psychology-and-platforms.md](../../references/entry-psychology-and-platforms.md) 或 [language-mechanics.md](../../references/language-mechanics.md)。

## 4. 封面高密度心法与两拍分工

- **6–8 字电影海报级灵魂大字**：共用封面主标题只装**一句 100% 语义通顺、一气呵成的完整大白话**，起草时先逆向定稳最狠、零歧义的完整实词核心再顺出整句（防为压进 8 字截肢名词）。常规自媒体爆款优先把**一眼认出、零绕弯的人物/性格直白标签或痛快动作**撞上**人人在意的公共大母题（赚钱、尊严、管理、关系、命运等）的反常识冲突**，或借**熟语微拧半寸 / 极致省力反差**在 6–8 个最朴素的字里装进高唤醒情绪与半截命运故事；若本轮是电影、音乐、人物专访或用户已锁定的极简审美海报方向，顺作品自身气质做纯度与意境识别，不硬拗干货爆款口吻。
- **两拍互补、各自成立**：封面砸下最狠的灵魂情绪大字，发布标题演活跟读者强相关的半截微型故事并留住解法；两者错位不撞句，遮住封面单看发布标题同样完整抓人。

## 5. 交付封面主标题与字图分工

共用封面主标题最多 **8 个可见字符**，默认无标点。成稿后扫疤：去换行连成一句出声读，确认零断句歧义、动宾人际站位真实准确、主语清晰不串位、符合双向之雅，陌生人零背景 0.3 秒秒懂且立刻起情绪。遇到逐字锁定的歌名或作品名超 8 字时，原样保留并提示冲突由人拍板（8 字仅约束封面，发布标题另计）。

每条封面候选固定交付下列四项；直接交给人看的设计单使用干净的 `字图互补建议：`，严禁外露 `cover-social` 等内部模块代号（内部交接 `laohu-cover` 需精确核对母题名时，按需参照 [Cover Social 的五种视觉母题](../../../laohu-cover/skills/laohu-cover-social/SKILL.md#五种视觉母题)）：

```markdown
- 封面主标题：[≤8字无标点、绝对通顺且与主调同频的完整大白话]
- 首要强调词：[视觉最突出的 1 个词]
- 语义断行保护：[建议断行与不可拆词组，用 / 标记]
- 字图互补建议：[面向人类设计同事时，作为直接开工的决策级视觉简报，直接拍板唯一清晰方案（不扔二选一甩锅），用平面设计师能建画板开画的语言写清 4 条短项：① 字体与配色气质（硬朗/克制调性、高对比底字配色及首要强调词的放大/换色/划线突出手法）；② 情绪同频的跨行业通用画面反差（主体极度突出、衬托核心情绪而不剧透正文底牌，去掉狭隘行业符号）；③ 构图占位与双端画幅安全区（底图留白占比与字图避让；特别标清公众号头条 2.35:1 转发卡片会居中裁成宽度仅占横图约 42.5% 的 1:1 窄方图，主标题与视觉重心必须稳锁在横版正中 1:1 安全框内、外延只留纯底或氛围，同时兼顾小红书 3:4 顶部状态栏与底部标题互动区避让）；④ 事实底线（严禁私自在图面或道具上添加原稿没有的数据角标）。仅当明确交 AI 生图工具时，转译为下游模型可直接渲染的物理主体、景别、背景、光色、留白与防穿帮提示，剔除抽象心理点评，实际成图验真交 laohu-cover。]
```

同时委托副标题时，补主标题尚未交代的一项关键增量。成稿后轻扫疤（核事实、清跨人群角色歧义、查是否误入粗鄙戾气或温吞鸡汤、查每条是否都有追看转折与零锚词复读）。每条发布标题后只附一句 20 字以内的大白话理由，末尾附干净的纯标题一键复制代码块，预算与待核状态一句带过。
