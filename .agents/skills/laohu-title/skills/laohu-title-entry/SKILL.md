# 外部发布与搜索入口

如果先读到了本文件（包括宿主直接展示或选中它），先返回 [laohu-title 主文](../../SKILL.md)，由父级确定任务模式、实际字段、范围与授权。父级依本轮字段选中本模块后，再从下文取方法并返回统一复审。

沿用父级确定的读者、用途、字段、数量、作者态度与保护项。只诊断时从原题辨认下文适用的入口、关系、字段或承诺问题；回父级做句面复审。创作及改良顺次处理六步，封面和发布字段各执行适用的后半步。

## 1. 取四处材料锚点

读[确立材料入口](../../references/entry-psychology-and-platforms.md#从材料确立入口)：

1. **现行参照点**取读者正在做的事、习惯做法或眼下具体处境。优先用动作和场景定位，比泛人群称呼更容易认出。
2. **有分量的差别**取下列至少一项：沿旧做法实际白费什么；原先预期如何被材料违背；新动作如何减小阻力或改变结果；真实数字、时间、原话或事件比例有什么意外。写反转前落实 [P → E → Q](../../references/entry-psychology-and-platforms.md#用真实预期判断是否构成反转)：P 如何导致 E，E 源自用户、材料或哪项有边界的公共经验，Q 怎样否定 E。递进、并列、量级联动按实写。抒情、审美、识别、目录或索引可直接取核心意象、人物瞬间、锁定名或检索对象。
3. **文章如何兑现**取最能解释前一步的具体机制、区别、处理、经历变化或证据。必要时定位全文实际兑现处，允许正文后来展开。
4. **态度与距离**核作者是在解释、推荐、赞叹、反对还是自嘲，强立场取实际授权和材料。找不到的锚点留空；改走另一个材料成立的入口。

搜索或 GEO 是任务目标时，先按[主查询意图](../../references/entry-psychology-and-platforms.md#选定主查询意图再让它进入标题)锁定一组与材料一致的对象/实体和任务词及必要限定，再起草。优先自然前置；若与主要阅读入口冲突，保住用户确需的查询关系，调整词序并在允许的附注里说明取舍。搜索热度只据可核数据。

## 2. 在平淡、难懂与训导之间找具体入口

- 滑过时若只读得到人群标签、题名或清单，而任务要求吸引或推荐，把第一步的具体差异、体验或可拿走的进展移到前部；方法名在能帮助识别或承接时保留。
- 快速滑屏时对象认不出，或出现两个以上读者陌生的术语时，保留一个确有识别用途的术语，将读者熟悉的处境或动作放在近旁。专业受众已掌握、或明确查询任务必须辨认的词，按真实阅读成本取舍。
- 句面训导读者且任务未要求警告时，改写为读者正在经历的处境、可自行比较的选择与后果，或直接交代材料中的一手发现。作者确实授权鲜明警告时，以真实后果和适用边界承重。

## 3. 把吸引点落实到有分量的词和后半句

有前后两拍时，后一拍交代关键做法、证据、体验或变化，回应前一拍的关切。删去只汇报作者准备了什么却无法承接的部分。已有判断成立时，按[语言方法](../../references/language-mechanics.md)选一两种强化方式：换用贴合材料的动作，补可证量级或范围，或把最重的词放到第一眼或末尾停顿处。作者需要平静、诗性或作品识别时，沿原方向写足。

## 4. 构句并核对参与者与条件

按[信息逻辑关系的条件骨架](../../references/language-mechanics.md#信息逻辑关系的条件骨架)选择同构关系，复核动词的行动者、对象和适用场景，再核条件、范围、否定、因果和虚词强度。短时预读后还应理解同一组主体、动作和对象。把愿望或建议写成保证、把可缺少的条件写成可省的步骤、把可能结果写成已有验证时，按材料修正实际有问题的断言。

## 5. 交付封面主标题与字图分工

共用封面主标题最多 8 个可见字符，默认省标点。写完整的判断、陈述或行动单位。遇到逐字锁定的歌名或作品名，先数完整字面，尚未给出原名时等收到再计。向作者说明八字只管封面，发布标题另按所在平台计。超出八字且两项都须满足时，保留原名，请作者决定放宽封面预算或另行授权调整展示方式；已有明确选择则直接照办。分行或压缩后连读，复核主体、否定、条件和修饰关系。每条候选交回父级四个字段。只受托向 Cover 或视觉同事准备封面标题文字时，下列四项就是完整设计交接。直接按这些字段名返回，每个字段给出实际值：

```markdown
- 封面主标题：[完整字面]
- 首要强调词：[一个优先读的词或短语]
- 语义断行保护：[不可拆词组与建议断行，使用 / 标记；单行成立时可明确推荐单行]
- 字图互补建议（交 cover-social）：[文字已经传达的意思、画面应补的材料线索、相配的一个视觉母题]
```

只读取 [Cover Social 的五种视觉母题](../../../laohu-cover/skills/laohu-cover-social/SKILL.md#五种视觉母题)一节核名称和用途，在第四字段写出选中母题的准确名称，并点出材料中可用的证据、动作或意象。Cover 接到文字后，按实际视觉任务另读视觉方法和试排。标题须能独立读懂。

独立交封面候选时，逐条显式标出首要强调词。用户先要材料比较或取舍、再限定候选数量时，把与各候选按序对应的强调词放在比较说明中，随后只列指定数量的可复制标题。仅限定候选数量时也可把强调词附在对应候选块外。用户明确要求只回净字、禁止任何附释或指定机器接口时，按该格式交付。

用户同时委托副标题时，先对照锁定长标题或刚拟的主标题，从材料找它尚未交代的一项读者所得、可做的下一步或会改变判断的条件，写进副标题。若可做的只是改几个字重复困境，先回材料找上述增量；没有依据就说明缺什么。副标题的作用和实际规格独立判断，保持锁定主标题原样。

## 6. 用同一核心独立构写各发布字段

按[平台字段、编辑预算与差异化方法](../../references/entry-psychology-and-platforms.md#平台字段与限额证据)读取实际平台段落。先圈出识别对象和阅读理由的最少线索，再用该字段的剩余空间增加有依据的路径、证据、变化、观点或适用条件。短字段检查整条，长字段检查前 25 字是否露出最重要的用途线索。只做封面可跳过平台表。无指定平台的单条发布标题按其用途成句；明确平台才应用对应预算。没有证据时不臆测平台口味、推荐或排序。

独立完整包默认交 3 个共用封面主标题和小红书、抖音、视频号短标题、B站、快手、微信公众号各至少 3 条发布标题。点名部分平台的发布包只交点名的平台，各至少 3 条；若同时请求共用封面且未另定数量，交 3 个共用封面主标题。只问准备材料、办法或预算时，说明当前指定字段与对应默认数量，材料到齐再拟题。明确数量优先。各平台独立构句，实际有必要的主题词可重用。以本项目编辑预算核算字符，投稿端更严时从严；已知或待核的字段口径、计数与前置检查随发布字段交回。说明每条实用了什么句面技法，解释不能代替句面本身。按[成品复审](../../references/title-value-and-review.md)交父级比较，再核事实与字段。
