# 门内导航与作品命名专项

若先读到本文件，先回 [laohu-title 主文](../../SKILL.md) 确认任务模式、位置、数量与锁定项。本模块服务已经进门的读者或要认出作品的观众，核心职责是**清晰总结骨架与精准识别**，按门内阅读逻辑独立构句（不套用信息流营销钩子或封面 8 字限制）。仅诊断时按同等标准审原句，缺材料直标缺口；常规任务留在当前文件完成，仅在命题或用词歧义时按需读 [language-mechanics.md](../../references/language-mechanics.md)。

## 1. 文章主标题与章节小标题：短促见骨、连读见骨架

1. **逐节抽唯一增量，一刀见骨**：每条小标题只抓本节独有的核心判断、致病动作或破局机制，默认优先压进 **10–18 纯汉字**、最多两拍一气呵成（不把整段拖成 25 字以上的段意长摘要，也不用多层标点拆成三截碎句）；全篇保持齐整利落的句形节律，转折节可适度变奏。
2. **守住真实力度、范围与分寸**：保住原文最关键的致病机制与痛点力度（不把要害写软、不把起因砍空），同时守住并列要素与有限前提（不为了短促把条件结论夸大成绝对口号），按原小节与作者原主张准确落地。
3. **遮正文裸读 + 嵌回首句四验**：把正文遮掉一口气连读所有小标题——① 病灶、推进、因果或操作顺序 3 秒看清，无同义反复；② **裸读自足**：只用脱离正文也能一秒看懂的实在对象词，把正文才铺垫过的局部隐喻留回正文；③ 出声念顺口，无压字拼出的主客错位或口水腔；④ **嵌回不撞首句**：放回各节开头核对，与正文第一句自然接力推进，不拿正文首句的核心词组原样开头复读。

## 2. 栏目名、作品名与歌名

从全篇或全曲独有的核心母体、真实动作、关系坐标或终局余味里定名，拒绝直白说明书式标签、剧透式解释长名与廉价网文俗名：
- **单部作品名与歌名**：优先凝练兼具**跨时代持久生命力、独立画面光晕（单看名字就浮现一帧无声电影剧照）、人类原型情绪共鸣与公共投射空间**的朴素实词真名（歌名常由副歌强位歌眼或贯穿全曲的核心实景母体自然凝出），把应由剧情或歌曲逐步展开的关键揭示稳稳留到后面；长短完全看能否承住这部作品本身。
- **栏目名与边界**：栏目名重稳定主题识别；用户已给明确好方向或锁定原名时严格尊重保护；`laohu-lyrics` 委托完整新歌时默认只交 1 个歌名，指定多项按数量交付。

交付时直接把可原样替换原稿的干净标题放进代码块，按原顺序与准确数量交回 `laohu-writing` / `laohu-lyrics` 或用户，骨架说明控制在 2–3 句内。
