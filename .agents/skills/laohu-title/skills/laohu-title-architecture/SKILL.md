# 篇内导航与作品命名

如果先读到了本文件（包括宿主直接展示或选中它），先返回 [laohu-title 主文](../../SKILL.md)，由父级确定任务模式、实际字段、范围与授权。父级依本轮字段选中本模块后，再从下文取方法并返回统一复审。

沿用父级确定的模式、文字位置、文章或作品材料、数量和保护项。按实际职责选择导航或命名。诊断模式沿对应判据看原句和已有位置，回父级标明材料和骨架缺口。命题骨架、搭配、词义或级差影响判断时，再读[语言方法](../../references/language-mechanics.md)的适用内容。

## 篇内主标题和章节小标题

1. **看文章给谁什么。** 从主旨、读者需要和正文实际兑现中取全篇承重判断、问题、经历或意象。文章内部主标题以此统摄全稿；用户明确选局部切口时，核后文是否真实承接。语气随体裁：教程落到步骤或结果，观点显示核心判断，叙事可留下空间让读者随文体会。
2. **逐节取唯一增量。** 在内部补齐 `[读者到此已知道什么] → [本节独有的新判断、机制、动作或转折]`。按原有章节范围取材，保留前后关系和作者视角。看不到全篇时，使用已给的主标题、周围标题与可靠的章节关系；未知处不自行增删章节或扩写主张。
3. **按体裁和本节职责成句。** 观点、分析和深度文章优先用短判断，核心对象放前半段。教程和手册用具体动词加操作对象，只有能改变这一节时才加条件或结果。真正承接前一节卡点时，可写准确的实际追问或转折。叙事、经历或随笔可写代表场景、物件或时间切面，保留留白。整篇维持可辨的一致性；确有转折职责时允许调整句形。
4. **只看标题连读。** 抽出主标题和完整章节标题清单。检查读者能否看出并列、递进、因果或动作次序；各标题的承诺是否各有边界；主标题能否统摄各段或兑现已选切口；每条是否准确反映实有内容和作者声口。夸张、无依据数字或虚构卡点改回实际章节作用。只有局部材料时按可见部分检查，并把全文连读交回 Writing。

按原位置、顺序和准确数量回传给父级。Writing 负责嵌回全文与真实成稿终审。

## 栏目名、作品名和歌名

1. **从能认出这部作品的材料里取名。** 比较反复出现的物象/场景、听到最后时的情绪或人物关系，以及决定身份的专名或关键短句。栏目名看持续呈现的主题与稳定识别，单部作品看这部作品自己的母题。
2. **决定名字替作品做什么。** 从辨认并记住作品、以物事留下情绪和主题余味、直接点出相应处境中选一项主作用，可兼顾另一项。用同一作品的实际体裁、核心内容和声音比较候选。保留让人认出的细节，避免拿走应由剧情或歌曲逐步呈现的关键揭示。
3. **按名称契约交回。** 对给出锁定名的作品逐字保留。Lyrics 委托一首完整新歌时交回一个歌名；请求多项时按指定数量。把名称放回作品，检查所暗示的人物关系、中心意象、情感和说话视角能否由材料支撑。

按[成品复审](../../references/title-value-and-review.md)的对应判据回交，字段用途以作品内导航和命名为准。
