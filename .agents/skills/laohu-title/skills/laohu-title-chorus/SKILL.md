# 歌词副歌核心句专项

若先读到本文件，先回 [laohu-title 主文](../../SKILL.md) 确认模式、材料背景、歌者与听话对象、曲风与旋律条件、锁定项及交付范围。整首歌词多段成稿、曲式展开或全篇依曲填词交回 [laohu-lyrics](../../../laohu-lyrics/SKILL.md)；仅诊断或原句改良时按同等标尺审原句并保住已成立的情感钩子。

**辩证造梦定位：对标经受时间与真实数据检验的华语殿堂级传唱特征，三态承接用户输入。** 副歌核心句相当于短剧的爽点、商业文案的卖点，是整首歌情绪曲线冲上顶点、堤坝决口、听众一遍就眼眶发热且脱口跟唱的灵魂核。动手前先辨输入与殿堂级副歌特征的关系：① 用户已在追求高水准且给出了不违背传唱规律的明确方向、具体意象或锁定句，**完全尊重并沿该方向做透**；② 用户表达模糊宽泛（只给一句愿望或粗略情绪），**守住基本方向并穿透挖出底层情绪与人类共通诉求，主动向殿堂级标杆靠拢升维**；③ 输入外壳明显偏离或违背好歌规律（如硬塞狭隘都市杂物与狗血短剧桥段），则只保住**无论怎么变都不会变的跨年代核心情绪、真实事实底线与合法逐字锁定项**，在后台完成物理剥壳换血，唱出配得上殿堂级歌单的核心副歌。

与 [laohu-lyrics](../../../laohu-lyrics/SKILL.md) 两阶段解耦协作时，本专项担任第一阶段单点爆破大脑：先独立锁死全曲情绪核与强位歌眼，再交回下游铺垫主歌与预副歌；若已带着前段预副歌进来，则承接前段拧紧的蓄压（Tension）一刀完成高对比释放（Contrastive Valence），只管痛快决堤，不回头解释比喻，也不竖理性防御壳泼冷水。**灵魂海拔、五维意象纯度与实词稳韵跨曲风一致，表皮语体则严格随当前曲风分轨落地**，不拿现代流行白话尺子卡死古风或其他曲风。

## 1. 后台极轻两步定盘：同曲风定音 × 五维正向意象入场门禁

动笔写第一句副歌前，在后台极轻走清以下两步（仅在后台完成，不吐冗长表单给用户）：

1. **步 1｜公共情感提纯 ＋ 同曲风殿堂真品前置定音**：
   - 将原始输入蒸馏成 **1 句跨越职业、年龄与年代的公共情感核**，并锁定高潮决堤那一刻冲着谁（具体的 `你 / 我们 / 世人 / 天地`）喊出平日拉不下脸、此刻憋不住的滚烫真话；
   - **按当前目标曲风**实调 **1–2 首经受过时间与大众验证的同曲风、同情绪真实殿堂级经典曲目**作为前置音叉（现代流行／抒情／民谣／摇滚只对标本赛道传世经典，古风／国风／戏腔只对标词乐一体、意境与风骨并立的国风戏韵经典，绝不跨曲风混搭），专门校准其 **词汇纯净档位、入画美学海拔与副歌金句锐度**，校准完立刻合上原曲彻底换血、零抄词句。
2. **步 2｜殿堂级意象五维正向入场门禁（入场铁尺，而非强塞风景配额）**：
   - 凡准备进入副歌的具象意象、场景与情绪载体（无论来自粗糙输入还是脑中最先冒出的高频联想要素），**必须同时通过以下五道正向检验；任一维落空即当场打回换血，物理隔断在副歌正文之外**（若用户属于态一，已给出不违背传唱美感、自带温度与情感承载力的独到生活媒介，或明确要求纪实传记／现实讽刺并锁定具体物件，则尊重原方向做透，不机械误杀）：
     1. **跨时代永恒性**：放在 30 年前存在、今天存在、50 年后依然存在，属于人类跨越时代的共通生命底色（自然过滤掉保质期短暂的办公、电子、通讯、消费与事务性杂物）；
     2. **独立审美光晕**：抽掉全部故事与情绪解说、单定格成一帧无声电影剧照或明信片，画面本身依然干净、清澈、耐看、让人愿多停留三秒（即便承载悲伤或荒凉，质地也是清冽、苍茫、凄美或壮美）；
     3. **人类原型情绪频率**：无需作者在旁贴情绪标签解说，载体本身在人类集体经验与汉语诗性记忆里天生自带离合、守望、流逝、渴望、自由或孤勇的情绪重力（自然过滤掉情绪频率为零的干瘪物件与狗血短剧桥段）；
     4. **活态真五感生命力**：在通过前三关的高美感永恒载体之上，唤醒正在发生的听、嗅、味、触、光影与动态生命力，并在点睛处按需叠一笔精准通感，淘汰呆板静止挂历画与用滥的网歌公版伤感风景贴纸；
     5. **千万人的公共投射空间**：具体可感又天然向亿万不同职业、年龄与年代的听众敞开，让听众 1 秒就能把自己人生里的那个人、那段岁月、那条路自动投射进去。
   - **双轨合法（防止为了打卡意象硬塞风景）**：精筛后后台只保留极薄白描核心（1 句公共情感核，剥光散文气氛形容词），按题材真气自由选择其一落笔——① **高美感意象承重路线**：只留 1–2 个全通五维且有新鲜电影切面的纯裸实体与动作原子，彻底切断粗糙原始词的词面引力；② **极简真话直劈路线**：面对极简情感愿望或纯关系错位（无需景物托底时），允许**零风景修饰，直用极清澈的活人关系真话、动作与时间错位一刀劈穿**，不为了凑意象硬塞泛泛风景冲淡刀锋。

## 2. 放飞锻造副歌核：强位六大武器狠歌眼 × 跨曲风底功 × 分轨表皮

带着纯净白描核心直接放飞写出滚烫活稿，把三股力量一次合流：
- **强位必砸 1 记过三秒质检的六大武器狠歌眼**：主动调用 [记忆点六大武器与三秒质检](../../SKILL.md#3-记忆点六大武器与三秒质检跨四专项唯一真源)（熟语微拧半寸、表里双轨、同词异义与首尾呼应、前扬后劈、反讽冷刀降格、人性公理空槽召唤）中的至少一记杀招，把整段最狠、能直接定歌名的灵魂钩子稳稳压在听觉最敏锐的**首句（破门直击）**或**尾句（蓄满决堤、重拍急刹）**强位，过三秒质检——第一遍零门槛直通胸口，回味半秒第二层余劲再刺一刀。
- **80/20 素底点睛与双向之雅**：全段 **75–80% 用极致纯净、契合当前曲风的素底语流**托举，**20–25% 集中投放高美感点睛与真实心境正面碰撞**（嘴硬与心软、想留与放手、祝福与心碎、傲骨与孤勇），向内克制耐嚼、向外零防御直击，第一遍破防、第十遍依然耐听。

三项跨曲风共同底功，从生成源头治 AI 腔、治凑韵、治平推：
- **实词承重**：痛感、冷暖、沧桑与骨气全部藏在通过五维精筛的具体实景、真实动作、赤裸心理事实与心境对撞里，离开单字感觉形容词贴标签、抽象评价词与生僻发力动作词。
- **逆向先定实词韵脚，再自然顺出整句**：每句动笔前，**先按当前曲风最地道的语体，逆向敲定能稳扛重拍与拖音的完整宽亮实词韵脚**，再往前自然顺出前半句——从生成次序上根治行尾凑韵造成的生硬拼词、弱读趋向补语收尾与填字凑律。
- **长短错落与破格落锤**：顺着真实演唱换气与决堤曲线打破四句齐刷刷等长平推，用铺排蓄势撞上一句**破格长呼**或**骤然收短的强拍急刹**砸在歌眼上，为旋律起伏与编曲留白留出呼吸容器。

表皮语体按目标曲风严格分轨落地，脱标盲听一秒辨归属：
- **现代流行抒情／民谣／轻摇滚（含未指定曲风的普通口述或小白愿望）**：走极清澈、去掉旋律也能平声当面说给对面人听的活人自然现代汉语，自然用活实词与日常口语态度词托出说话火候（摇滚重短促直劈与辽阔清醒骨气而非廉价鸡血口号），远离书面总结腔、散文腔与硬压四字伪古风缩写。
- **古风／国风／戏腔**：通篇稳守纯正典雅、词乐一体的诗乐语体与苍凉或清雅风骨，承接前段预副歌时语域无缝统一——以洗练实词、古今皆通实景与超越私怨的气度立骨，守住纯粹诗乐品格、绝不滑回现代民谣白话抱怨腔，也远离堆砌辞藻空壳与死板齐言数来宝（善用长短变奏与收短急刹立定名歌眼）。
- **说唱／R&B／舞曲等其他曲风**：顺该曲风最地道质感展开（说唱重密集切分与内韵狠句、R&B 重成年人私密留白与切分、舞曲重极简洗脑回环）。

## 3. 殿堂专辑盲混放声耳检与两阶段交接接口

活稿放飞后，挡住一切说明，把自己当成站在录音棚高潮处的歌手放声试唱，只做高标尺打回与轻度扫疤：

- **殿堂专辑盲混验真（一票打回机制）**：将这 2–4 句直接放进步 1 调出的同曲风殿堂真曲专辑里连唱——**凡有任何一句滑回狭隘都市杂物、廉价短剧桥段、陈词口号、冷静旁白、理性防御或曲风串味，当场打回重锻**，直到语言纯净度、画面美感与情绪穿透力真正站在同一档位。
- **首拍破门、意象惜字与宽亮实音防黏扫疤**：紧接已有预副歌进来时，第一拍直接承压劈开新格局或新动作，不原地复述前段场面；全曲核心高光意象（尤其是前段尾句刚落过的词）不在平淡过渡处提前用旧或连撞重字，留给强位歌眼一击收网。已有旋律、指定曲风或 `laohu-lyrics` 协同时服从该曲风律动；无旋律常规抒情参考每句约 7–13 字、四句约 32–52 字。高潮推高音与拖长音的句尾优先统一落在宽亮敞口韵母（`a / ia / ua / ang / iang / uang / ao / iao / an / uan / ai / uai`，韵腹偏扁的 `ian` 适合柔和低吟而不冒充最宽爆破韵）及自然实读重音的阴平／阳平／去声完整实词上，四句之内每个韵脚换用不同汉字，相邻句尾也避开同音异调撞韵（如 `huán` 与 `huàn`），守住普通话实音核韵（`-ong/-eng`、`ü/i`、`-n/-ng` 不混押）；放声清理高音区连续上声挤连倒字、短距同音绕口及高潮尾句滑向廉价口水口号的软脚病。
- **面向 `laohu-lyrics` 的两阶段四项按需交接接口**：仅当作为第一阶段爆破核交回 `laohu-lyrics` 编织全曲（或用户明确要全曲衔接）时，顺手附四项极简接口：① 2–4 句副歌核原文（加 1 句终段同拍型加深变奏）；② 1 处明确标出的强位主歌眼；③ 保留给副歌引爆、主歌／预副歌不剧透的核心爆点词；④ 副歌主韵部（供预副歌走收束韵蓄压、进副歌首拍声场绽放）。单点只要副歌核心句时不画蛇添足。

干净可直接复制的副歌核心句单独包入代码块，创作思路控制在 2–3 句大白话内（点出情绪爆发点与核心钩子落位，不甩框架或理论黑话，声韵口径坦诚准确）；尚未配曲时，末尾用一句话如实标明仅核纸面节奏与声韵、实际可唱性待配曲试唱核验即可。
