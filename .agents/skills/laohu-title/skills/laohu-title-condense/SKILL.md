# 篇内文章关键句专项

若先读到本文件，先回 [laohu-title 主文](../../SKILL.md) 确认模式、位置、相邻上下文、句子职责与锁定项。普通逻辑过渡退回 `laohu-writing`，歌词副歌核心句退回父级改派副歌专项。本模块只承接文章、教程、口播或观点稿里能改变判断、定调或收束的关键单句（题眼、中心句、原则句、转折定调句、总结/收束句），核心职责是**精准总结、立住证明、下结论并留下一记值得划线的社交货币钉子**。

## 1. 剖出真骨头，凝成带记忆锚点的双向之雅钉子句

- **先剖差别再放飞成句**：动笔前在后台用大白话定死这一处究竟要留下哪一根骨头——分开了哪两个常被混为一谈的东西、挑明了什么隐性代价或成立前提、还是用一个精准动作定格了真相。立意争取抵达**用朴素切片照见共通真相的四阶高度**，材料不足时直接交回自然直述或指出缺项，只从真料里炼真判断。
- **短促、狠准、单句立稳前提**：真正的好原则句是钉在段里的钉子，成稿呼吸参考控制在 **18–34 字**，靠精准动词、同尺度对照或自然反差拿分量——既一口气顺畅念完（不写成 45 字以上叠满虚词的公文长复句），同一短句尽量守住一套统一的活态隐喻或动作频道（不混拼两三套打架意象），又让前提划界直击原文真正的本质分水岭而非找外围替身，单句单独拎出来时核心适用对象与边界就在句面立得住，收口落在原作者接地气的大白话上。
- **注入一处克制的记忆锚点（双向之雅 × 三秒质检）**：在守住事实与前提边界的前提下，善用**最优创新假说（熟语微拧半寸）、降格反讽冷刀、前扬后劈或人性公理**把清晰结论再磨亮半寸，让读者读完下意识想划线或截图转发；每处锚点必过三秒质检——第一眼读顺零门槛、回味半秒咔嗒击中、100% 服务本节真实判断，不为了抖机灵牺牲分寸，也不滑向端着架子的悬浮格言腔或粗鄙口号。
- 常规任务留在当前文件完成；仅在需要深推比喻防反噬、交错回环、调取本地原子 `ATM-BE71AD8490FA48A7` 或细辨虚词边界时，按需读 [condensation-and-rhetoric.md](../../references/condensation-and-rhetoric.md) 或 [language-mechanics.md](../../references/language-mechanics.md)。

## 2. 原样塞回前后两句连读四验（成稿轻扫疤）

交稿前把候选句原样塞进原文前后各两句之间出声连读：

1. **气口顺着原作者说**：像原作者话赶话自然接出的下一句，用地道口语自然承接，不硬切公文起手、悬浮格言腔或抽象书面缩写；
2. **前提边界单句立稳**：前文铺垫撑得住本句力度，原文核心适用对象与边界前提在句面清晰可见，犀利而不把话说满；
3. **不撞车、不抢戏、不泼冷水**：与紧邻上句或下句错开长分号架子或相同对照句型，把具体做法细节与尾句压轴升华稳稳留给后文；若承接前段情绪或矛盾蓄压，顺势完成有力收口或转折，不竖起冷硬免责盾牌给张力泄气；
4. **位置职责严丝合缝**：题眼聚焦全局、中心句压明本节判断、原则句守稳边界条件、转折定调推向下一层判断、收束句落定余响不再开新题。

交付时把干净可直接复制的单句放进代码块（前缀放块外），并附原样嵌回段落的预览与极简大白话衔接说明（不甩框架术语）；若开放探索会改动文章核心主张或结构，附依据与受影响处交回 `laohu-writing`。
