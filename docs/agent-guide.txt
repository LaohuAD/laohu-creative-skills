老胡造梦技能：Agent 使用指南

这是一份面向能够读取网页或文本 URL 的 Agent 的官方能力说明。用户提供本文件后，你可以用普通问答解释能力、帮用户选择入口、说明需要哪些材料，并给出可直接使用的请求方式。

阅读本文件只说明你了解了这些能力，不代表本机已经安装了技能、当前宿主已经发现它们，或你已经实际调用了某个 Skill。用户希望你执行任务时，按当前环境实际可用的正式定义、工具条件和用户授权行动；无法读取对应定义或没有相应工具时，要说明限制，不要声称已经调用或完成。

聊天中的完整文本交付

当用户需要可以直接复制、保存或转用的独立文字成品本体（作品、文章、剧本、歌词、提示词、标题、改后对照稿、规则文件或结构化文本）时，把本体放入单个 Markdown 围栏代码块，附注与路径放在块外；多个独立结果分别成块。面向用户直接阅读、讨论或拍板的多节诊断、分析、方案比较或选题咨询，直接以自然 Markdown 排版呈现（仅把其中需要一键复制的简报、改稿或提示词本体包入代码块）。

用户本轮指定其他聊天展示方式时，遵从该要求。代码块只用于聊天显示：保存文件、写入文章或调用机器接口时去掉外层聊天围栏。图片、音频、视频和网页预览按其原生媒介展示。

请提供：歌词、旋律、音频或简报、用途与目标交付格式、锁定元素与允许发挥范围。
交付：按目标交付编曲蓝图、平台无关 AI 音乐生成包（或 YuE2 外部谱）、多格式同源乐谱/MIDI 规格，或配合 Motion 的视听声音方案与派生源 WAV 回执。
边界：区分方案、提示词、乐谱、导出文件与真实试听四级证据，未实听项如实标明；视听混音不擅改 ASRcut 冻结语音或另建全片时间线。
公开定义：https://github.com/LaohuAD/laohu-creative-skills/blob/main/.agents/skills/laohu-arrangement/SKILL.md

18. Commander–Luna 跨环境协作执行：laohu-luna

适合：用户希望由当前会话模型担任 Commander（统筹规划、读取所需专业 Skill、派发任务并亲自按实际成品验收），将有界执行委派给适配当前宿主环境与用户选定模型/CLI 的 Luna Worker。
请提供：任务目标、输入材料、允许读写的范围、验收标准与约束；如已选定具体执行载体（宿主原生子 Agent / Swarm、本机 gemini / codex / claude CLI 或显式指定的外部 API）与模型，一并告知。
交付：自包含任务包、实际 Worker 执行结果及 Commander 亲自审查实际成品后的验收结论。
边界：不再写死单一 GPT/Codex 模型；若用户未指定执行载体或模型，先识别当前环境可用能力并向用户明确确认后再派发。绝不在失败或限额时静默降级模型或偷换路线，路由结论以当次实际运行记录为准；Worker 不得自行派发下级 Agent，业务文件不写入安装仓库。
公开定义：https://github.com/LaohuAD/laohu-creative-skills/blob/main/.agents/skills/laohu-luna/SKILL.md

19. 小说创作与成文：laohu-novel

适合：创作、续写、改编或修订小说，将主题、故事构想或分章梗概写成正文，涵盖叙事视角、时间伸缩、人物声口、对白潜台词与长篇连续性，以及连载规划、侦查悬疑、意识运动三个按需专项。
请提供：写作或修改范围、已有构想或原稿、题材受众，以及锁定的核心设定、人物与结局。
交付：复杂新作默认先过前置拆解并交可审章纲，确认后连续成文（明确要求直写或已有批准纲时直出正文）；完整正文默认卷章 Markdown 代码块交付。
边界：剧本改小说彻底拆掉镜头标记以小说现场重写；小说转剧本交 laohu-script；单入口限制时留在 Novel 内完成前置设计。
公开定义：https://github.com/LaohuAD/laohu-creative-skills/blob/main/.agents/skills/laohu-novel/SKILL.md

20. 全品类战略选题策划：laohu-topic

适合：位于故事构思与一切具体创作入口之上的最上位战略选题层，从真实问题、赛道定位、热议事件、零散灵感或已有稿件中拆透根本需求、人性洞察、核心价值、热窗与趋势潜力，确定、比较并重构整条内容选题。
请提供：赛道/问题/灵感/爆款素材或旧稿、内容目标与已有事实限制；不必先备成稿。
交付：开篇结论、决策总览表、聚焦选题卡（带拉开梯度的多维推荐分与待核真料）、唯一首推拍板与纯净交接简报，按需转交故事构思或撰稿/歌词/剧本等专业入口。
边界：只做战略定盘，绝不越界代写完整正文、歌词、分镜或成套标题；严守事实、价格口径与常识算术底线。
公开定义：https://github.com/LaohuAD/laohu-creative-skills/blob/main/.agents/skills/laohu-topic/SKILL.md

21. 原生代码动画设计与制作：laohu-motion

适合：构思、制作、修改或审查原生代码动画、动态图形、动态排版、UI 动效，或把代码动画与口播、ASRcut 时间轴、录屏、实拍混合制作，统一采用本地 Motion Showreel 原生代码与确定性 render(t) 流程。
请提供：动画目标与观众、口播稿/原音/ASRcut 交接或既有工程、画幅时长、锁定内容及本轮要纯方案、完整制作还是审片。
交付：纯构思交人话导演提案与自足 brief.md；完整制作经前期拆骨、两阶段盲构想、工作台代表帧与动态小样确认、确定性代码实渲与混音预览验收后导出成片。
边界：方向确认与导出确认两步独立；静帧不冒充动态、技术检查不冒充真看真听；不编造未核数据与假词时码，一切缓存与成片留在已确认工作目录同卷。
公开定义：https://github.com/LaohuAD/laohu-creative-skills/blob/main/.agents/skills/laohu-motion/SKILL.md

22. 录音与录屏 ASR 智能剪辑：laohu-asrcut

适合：根据粗糙录音、录屏视频、ASR JSON 或 SRT 做可追溯的纸面粗剪、精剪、情绪气口整形与授权重排，编译唯一剪后时间轴和审阅页，按授权导出音视频、剪辑交换文件或交接动画；也支持独立字幕编译与口播修音。
请提供：录音/录屏/转写文件、剪辑目标与允许导出范围（需新建云端语音识别时另须上传与费用授权）。
交付：默认先交可审阅虚拟剪辑（原位删除线对照或 edit-plan、timeline 与 review.html）；获授权后导出新路径 WAV/MOV、逐缝切片、FCPXML/OTIO/EDL、SRT 或 animation-handoff.json。
边界：严格隔离原始/口语/屏显三层文本，原件零覆盖；重排、重复与实体导出各需明确授权；区分虚拟方案、编译、导出、实听与批准五类状态。
公开定义：https://github.com/LaohuAD/laohu-creative-skills/blob/main/.agents/skills/laohu-asrcut/SKILL.md

23. 作品拆解与方法原子：laohu-benchmark

适合：深入拆解具体作品或创作素材、剥离表面元素提炼可迁移底层方法、做高杠杆差异化变招或跨媒介换轨，以及检索或按授权收录本地作品方法库。支持无当前项目的独立资料积累。
请提供：作品、可读材料或出处，以及想看清的处理或目标消费环节；需要收录入库时明示。
交付：按材料身份与接收者体验时序拆透核心机制、适用边界与下游落地动作；要求收录时同轮先交完整分析与可拍板入库方案，确认后写入。
边界：默认只读不写盘，不从热度或名气推技法因果，不复制原作独特表达；新收录的专业研究归实际接收 Skill 同级 benchmark/（兼容根目录旧编号查询），与 works/benchmark/ 作品档案分开。
公开定义：https://github.com/LaohuAD/laohu-creative-skills/blob/main/.agents/skills/laohu-benchmark/SKILL.md

怎样向 Agent 提需求

可以直接提供目标和已有材料，不必先背 Skill 名称。把方括号内容替换为自己的信息；没有的内容可以省略或说明尚未确定。

通用请求：
“我的目标是【希望得到的结果】。我能提供【材料、文件或链接】，用途是【读者或使用场景】。已经确定或必须保留的是【事实、观点、文字、风格或限制】。请先判断适合的能力；如果我已经指定能力，请直接按这个范围处理。需要保存、修改项目文件或发布到外部时，只按我明确授权的范围行动。”

能力选择：
“/laohu 帮我选择入口。目标是【目标】，现有材料是【我提供的材料】，使用场景是【场景】。请说明推荐理由，并给我可以直接发送的任务请求。”

写作：
“/laohu-writing 请根据我提供的【口述、ASR、讨论、初稿或资料】，按【公众号文章 / 教程手册 / 口播讲解 / X 或朋友圈短帖 / 飞书文稿 / 录后复盘】这一目标，为【读者/听众和用途】整理、创作或检查；区分输入材料与期望成品，保留【已确认观点、事实、经历归属或原句】。”

跨环境协作（Luna）：
“/laohu-luna 请由当前会话模型担任 Commander，先确认本环境可用的子 Agent 或 CLI 与模型，再把【有界任务目标与文件范围】派发给 Luna Worker 执行，并亲自按【验收标准】核验实际成品。”

小说 / 剧本 / 视频 / 动画 / 审查 / 选题 / 排版：
直接输入对应入口（如 `/laohu-novel`、`/laohu-script`、`/laohu-video`、`/laohu-motion`、`/laohu-audit`、`/laohu-topic`、`/laohu-htmlshow`）并交代目标、已有材料、锁定项与交付范围即可。

这些模板仅用于说明请求结构，不构成安装、写入、保存或外部发布的授权。

项目内使用与全局安装

需要：Git、Python 3.9 或更新版本，以及能读取本地 Skill 的 Agent。项目检查不需要第三方 Python 依赖。先取得完整仓库，在你选择的父目录执行：

git clone https://github.com/LaohuAD/laohu-creative-skills.git
cd laohu-creative-skills
python3 tools/check_project.py

项目内使用：在完整仓库中打开 Agent。支持 `.agents/skills/` 的宿主可直接发现；其他宿主未显示入口时，让 Agent 读取仓库中的 `.agents/skills/laohu/SKILL.md` 开始。项目内使用无需全局安装。

全局使用：在完整仓库根目录运行 `tools/install.py`。以下命令以 Codex 为例，第一条预览，只有用户明确要求实际安装且预览无冲突后，才加 `--write`：

python3 tools/install.py install --host codex
python3 tools/install.py install --host codex --write

Claude Code 本机使用时，把宿主选项改为 `claude`，同样先预览：

python3 tools/install.py install --host claude
python3 tools/install.py install --host claude --write

当前工具全局直接登记一级和二级正式公开入口，共 23 个（1 个一级总入口 + 22 个二级入口）；三级内部配置由所属二级入口按任务需要读取，不单独创建全局入口。链接指向这份完整仓库，因此仓库须保持在 Agent 可访问的位置。安装不会自动同步到云端或其他设备；不能把“链接已建”说成“宿主已发现”，按宿主方式刷新或新建会话后再确认发现状态。

查看状态、同步与卸载：

python3 tools/install.py status
python3 tools/install.py sync
python3 tools/install.py sync --write
python3 tools/install.py uninstall --host codex
python3 tools/install.py uninstall --host codex --write

`sync` 只维护已登记目标，不替新宿主安装也不更新仓库内容。卸载只移除仍与登记相符且指向本安装的链接，保留仓库、作品与其他技能；搬迁仓库前先卸载再搬迁和重新登记。发生同名冲突时停止说明，不覆盖或删除冲突对象。支持其他宿主时，先确认其真实技能目录和符号链接能力，再传入 `--skills-dir`。

完整项目更新

用户要求取得官方更新、检查更新、升级、发布项目版本或修复入口时，使用 `/laohu-update`。它管理完整 Git 仓库（技能、项目规则、工具与知识），不等于只复制 Skill 文件，也不等于全局 `sync`。更新前核对官方仓库、本地状态与用户修改；有冲突先呈递差异与合并方案等用户拍板。普通更新不自动发布；直接输入 `/laohu-update` 同时授权更新完整项目与发布已审阅的可发布改动。

用户说“请把老胡造梦技能更新到我当前可以使用的最新版本，保留我的个人修改”时，按普通更新处理。先在本机安装根查找 `.agents/skills/laohu-update/scripts/member-update.py`。旧版尚无该脚本时，先按既有公开 Git 更新流程取得官方公开版并保留个人改动，再读取新版 `.agents/skills/laohu-update/SKILL.md`，继续同一个更新请求。

使用新版入口的会员检查和提醒规则。对话里给已有会员可复制的设备配对指令和泠月私聊链接。设备验证通过后，按工具确认的版本试合并。同一功能版本的内测提醒展示一次，可略过或关闭。公开版仍可单独更新，会员服务不可用或权益到期时保留本机现有版本。

作品保存与外部操作

在老胡项目内，经用户明确要求保存或收录时，作品默认归入仓库 `works/`；同一作品沿用已确认目录。项目外且位置未确定时，先建议具体路径并等确认后再保存。创作、命名或讨论本身不等于保存授权。

外部发布、公开分享、账户提交、付费生成、不可恢复删除和跨项目长期写入分别需要明确授权。阅读本文件或 README 不构成执行授权。
