# 万能造梦框架：全仓 Skill 底层构造原理

万能造梦框架是老胡造梦技能仓库**所有 Skill 的底层构造原理、顶级造梦观标尺、大模型执行纠偏机制与规则进化方法论**。它由**纵轴四维（灵魂 / 筋骨 / 血肉 / 表皮）**与**横轴四层（目标 / 判断 / 行动 / 结果）**正交构成 16 个观察交点：纵轴负责全向穿透与层级共振、不漏根只抠皮；横轴负责每条核心规则自成闭环、不丢判断也不缺验真。

> **第一性造梦观（全仓所有创作 Skill 的最高灵魂铁律）**
> - **造梦的根本目标：对标经时间与数据验证的人类殿堂级作品，只做正确的事、只做最好的内容**：所谓**殿堂级作品**，不是闭门臆造的文艺装腔，而是由本领域最顶尖那批创作者做出来、经受时间与真实数据反复验证的标杆——其底层凝结着人类千百年来不变的**人性底层代码、生理舒适感知、情绪共鸣与共同追求**。因此沿着本领域殿堂级作品的特征去走，本质上是顺应人类最深层的共识，永远不会走偏。
> - **需求五层穿透（为什么不能机械停在字面要求上）**：用户很多时候并非想要平庸成品，而是受限于表达能力或专业视野，只能说出表层工具或粗糙素材——就像**用户开口说想要一颗钉子，往深一层其实是想在墙上打洞，再深一层是想挂一幅画，再深一层是想装饰房间，追根究底其实是想让自己办公、学习或居住时的心情更舒畅**。普通模型只停在字面递一颗钉子；造梦框架则要求先穿透表层表述，挖出背后真正不变的人类底层需求与核心情绪，在满足用户基本方向的前提下主动向本领域殿堂级作品靠拢。
> - **辩证三态裁决法（绝不一刀切忽视用户，也绝不盲从偏离正道的字面要求）**：每个 Skill 动手前必须先想清**本领域殿堂级作品到底为了什么、具备哪些不可动摇的核心特征**（例如顶尖歌词讲同一都市故事靠跨时代意象与真情共鸣而非琐碎杂物、顶尖剧本靠戏剧冲突与动作视听化、顶尖封面靠主体极度突出与高对比一眼抓取情绪），再据此把用户输入判入三态、精准区别对待：
>   1. **态一 · 同向且有明确独到方向**：用户本身就在追求高水准，只是具体题材、风格或路径与默认不同，且不违背本领域殿堂级核心特征 → **完全尊重并采用用户的明确方向与具体要求**，顺着这条路帮他做到该方向的殿堂级天花板；
>   2. **态二 · 表达模糊、宽泛或词不达意**：用户只给了粗略愿望（如做个封面、写首爱情歌），未能说清专业标准 → **守住用户的基本方向**，穿透表层挖出底层需求与核心情绪，主动按本领域殿堂级特征补齐、拔高、做透，绝不敷衍交普通平庸成品；
>   3. **态三 · 字面要求明显偏离甚至违背殿堂级本质特征**：用户输入夹带低美感外壳或反常识劣质指示（如歌词硬塞琐碎都市杂物、封面要求背景杂乱主体与字体都不突出）→ **绝不循规蹈矩顺着偏离方向硬做**（真实事实底线与合法逐字锁定项除外），而是**抽出其中无论怎么变都不会变的核心内核——尤其是核心情绪与底层人性诉求**，按本领域经数据与时间验证的殿堂级特征重构换血，带回正确道路。
> - **何时调用本框架**：新建 Skill、整体重构、深度审查（`laohu-audit`）、能力设计分析（`laohu-analysis`）与自进化写回（`laohu-evolution`）时必用；**日常业务运行期不加载**——成熟 Skill 应已把四维四层与底层执行规律内化为本领域自带判断理论的自然工作法，日常创作只按对应 Skill 执行，不把本框架原文灌进运行时上下文。

## 一、纵轴四维：一项能力成立的四重纵深与海拔共振

| 维度 | 核心问题 | 直出作品类 Skill（文本即终稿） | 提示词中继生成类 Skill（驱动下游模型出成品） | 规划简报、诊断审查与工程治理类（上游决策与系统支撑） | 缺失这一维时的典型病症 |
|---|---|---|---|---|---|
| **灵魂** | 为什么做？本领域殿堂级特征是什么？用户需求落入哪一态？ | 先立清本领域经数据与时间验证的殿堂级核心特征，穿透用户表层需求（三态裁决：尊重同向好方向、补齐模糊愿望、对偏离正道的输入提取不变核心情绪与人性诉求向殿堂级重构）、确立立意海拔与活人声口 | 从宏观全局定死终端视听成品的殿堂级风格基因、媒介美学质地、时代语境与唯一核心情绪基调（三态穿透用户需求，锁定下游专用模型不漂移成平庸塑料风） | 一切前置简报、计划、选题构想、分析、找茬与沟通对齐，均以逼近最终殿堂级作品为最高靶心（工程治理则锚定真实痛点与不可突破的红线），绝不僵硬迎合劣质前提走形式 | **方向漂移 / 僵硬交差或风格失控**：停在字面递钉子、一刀切篡改好方向、困在流水账书面腔、下游渲染塑料化，或把简报分析找茬做成走过场填表 |
| **筋骨** | 凭什么专业规律撑起来？ | 真正改变成品的成熟法度、强对标前置定音、阶段物理隔离（剥壳换血与爆点解耦）、媒介时间观、各段不可互换的职责与整体递进转化工艺 | 框死终端成品的构成板块、整体结构与时空骨架——如多视角资产布局、封面主体与文字安全区占比、视频分段运镜起承转合、音乐段落能量与织体分层 | 前置简报与计划负责提前锁死决定最终作品上限的骨架与关键取舍；分析与找茬负责自上而下定位阻碍抵达殿堂级的最早杠杆断点；工程治理守住分层、单向依赖与确定性契约 | **退化为裸跑、构图散架或只抠表皮**：跳过对标滑回均值权重、单锅双向污染、下游成品构图散架，或找茬分析只挑错别字漏掉立意与结构硬伤 |
| **血肉** | 落到眼前这份材料怎么剥壳换血与具象化？ | 对粗糙输入的公共情感提纯、五维正向精筛打回低美感杂物、极薄白描交接防散文修饰词反向污染、钉死极少数核心母体并匹配灵魂海拔 | 填入骨架的下游模型可直接渲染的物理与视听要素——主体外观与具体动作、景别（特写/近景/中景/远景）与机位、前景/中景/背景层次、具体光影色温与景深虚化、材质或乐器音色细节 | 落到眼前真实材料，只给真正改变最终成败的实质判断、硬核取舍依据与可落地换血动作，以及针对真实状态、分支、冲突与异常的精准处理，彻底清除正确废话 | **原则落不到地 / 模型听不懂或满纸空话**：粗糙道具或散文修饰词污染成稿、塞进下游模型无法渲染的抽象心理描写，或简报分析写满不痛不痒的套话 |
| **表皮** | 最终接收者真正看到、听到什么内容肌理与呈现格式？ | 读者、观众或听众直接感知到的现代活人自然母语、实词承重与逆向实词落点、呼吸留白、声律视觉笔触、脱标风格辨识度，以及**媒介原生应有的专业排版与用户明确指定的固定输出格式** | 最终组织交付给下游专用模型或工具字段的提示词文本与参数编码（符合模型注意力语序、单条独立自包含、参考附件对齐、零物理冲突），并最终落实为下游渲染出的真实图／片／音质感 | 面向人类用户沟通、选题、分析或找茬时，**通俗说人话 ＋ 结构化扫读版式**（清晰 Markdown 标题层级、分条罗列、表格对照、推荐排序、核心重点加粗，绝不塞紧凑大段文字墙）；面向下游执行保持洁净定式接口；工程产物确保可复现 | **AI 腔、文字墙或格式错位**：直出文本伪古风凑韵或擅改用户指定格式、中继提示词像散文却渲染穿帮、沟通分析报告挤成一大坨紧凑文字墙让用户翻找重点或晦涩难懂 |

### 立意四阶梯（跨媒介通用海拔标尺）

无论文字论述、小说剧本、词曲创作，还是画面封面与视听动画，作品灵魂的真实海拔沿以下四阶递进——决定成品天花板的从来不是表皮多华丽，而是立意站在哪一阶：

| 阶梯 | 核心形态 | 跨媒介典型表现 | 局限与症结 |
|---|---|---|---|
| **一阶 · 写事** | 流水账打卡 / 素材罗列 | 文章按提纲平铺信息，叙事逐条交代起承转合，视觉把甲方元素逐个摆进画幅，声音按时间点机械配音效 | 只有信息陈列而无视角提炼，受众看完无感、转头即忘 |
| **二阶 · 局域泄情** | 困在单一场景原地宣泄 | 沉溺于私密情绪吐槽、局部冲突叫喊、窄小个人执念或直白情绪标签，视角走不出眼前一隅 | 情绪未完成普遍化升维，局外受众进不去，难以引发跨人群共鸣 |
| **三阶 · 表皮假拔高** | 给普通思想穿龙袍 | 灵魂仍停在浅层常识或陈旧感叹，却靠堆砌宏大词藻、宏大风物、华丽特效、史诗构图或空大概念硬撑气势 | 载体野心远超思想承载力，制造强烈的头重脚轻、装腔作势与感官割裂 |
| **四阶 · 返璞归真** | 一花见世界 / 做受众嘴替 | 用朴素、零装腔、可触摸的寻常切片与克制载体，直接照见人类共通真相或生存处境，替受众说出心底隐隐有感却道不出的那一句话 | 跨媒介高水准归宿：入口极轻极近，余韵极深极远，耐复看、复听、复品 |

### 四维同级共振律

灵魂、筋骨、血肉、表皮必须站在**同一高度层级**协同共振；任何跨层错位都会立刻制造受众肉眼可见的不融洽：
- **严防表皮大于思想（假大空）**：灵魂只有一二阶，却在表皮强行调用三阶以上的宏大词汇、炫目技法、华丽铺陈或史诗运镜；外壳越精致，思想的空洞越刺眼。
- **严防血肉或表皮低于思想（拖垮立意）**：灵魂本已触达深沉的人性真相或锐利洞察，却在血肉或表皮滑向未经提纯的粗鄙发泄、隔靴搔痒的小聪明寓言、廉价说教口号，或像写论文一样做条件推理解释——硬生生把切肤体悟讲成班门弄斧的浅薄道理。

## 二、横轴四层：Skill 规则书写的标准四元闭环

横轴四层不是事后汇报的分类标签，而是**编写每一条核心能力规则的标准闭环方法论**——无论落在灵魂、筋骨、血肉还是表皮，缺任何一环都会触发固定类型的系统故障：

- **目标（守什么）**：这条规则到底要达成、改变或保住什么本质体验；对谁、在什么情境与权限边界内成立。
- **判断（凭什么选）**：依据什么**显式学科理论、第一性原理与领域裁决标尺**识别真实信号、作出取舍或一票否决。
- **行动（具体怎么干）**：由谁在什么先后次序下执行哪些高杠杆选择、创作、转化、交接或轻度纠偏（严格区分事前轻定盘与事后轻修疤）。
- **结果（拿什么验真）**：动作实际产出了什么、交给哪个真实接收者、在真实感官或运行环境中怎样被观察检验（**预期目标与实证结果严格分开**）。

| 规则缺哪一层 | 必然爆发的系统性故障 | 典型反面症状 |
|---|---|---|
| **缺目标** | **手段反客为主、越改越偏初心** | 机械执行技巧动作却丢掉体验本质，例如为求变化把全篇记忆锚点改散、为求规范把生动感与情感电压修死。 |
| **缺判断**<br>（底层理论与标尺） | **信息丢失、换个题材或风格立刻失灵** | 运行态只留下针对某一旧例子的浅层动作、现成示范词或禁词表，底层理论被洗掉或锁进冷归档，换到新题材无法自主推理迁移，瞬间打回原形。 |
| **缺行动**<br>（高杠杆动作与次序） | **要么空喊口号落不了地，要么微操倒挂锁死创造力** | 只有宏大原则却没给可下手的前置支点，或反过来把事后检验动作错写成事前几十条填字数独，把模型算力和灵气消耗殆尽。 |
| **缺结果**<br>（真实接收者感官验真） | **规则全打勾、成品不好看也不好听** | 只核对内部步骤和旧维度的形式合规，不回到人类眼睛看、耳朵听、系统真跑的终端体感验真，导致评测标尺与真实体验脱节，被工整外壳骗过。 |

**两轴的动态关系**：四维不是呆板清单，四层也不是官僚填表。实际构造与创作遵循**顺向定盘、逐层追根、双向校准**——动笔或实施前必须由灵魂和筋骨定死海拔、风骨与结构，再放出血肉与表皮实现同级共振；排障与进化时则由成品表皮的一处体感异样触发，沿灵魂 → 筋骨 → 血肉 → 表皮自上而下逐层追查最早发生错位的底层机制，绝不只在症状出现处打补丁。同一概念在不同判断中可归属不同纵深（例如节奏既可以是筋骨里的结构推进与剪辑架构、血肉里的场面张弛，也可以是表皮上接收者直接感知的声律顿挫与画面韵律），按它当下的功能作用归位，不按词名死归类。故事的幕、场、节拍等叙事尺度由具体创作方法与媒介另行决定，不等同于本框架的四维或四层，也不强加给非叙事任务。

## 三、4×4 十六交点：Skill 构造与深度审查全向透视表

在**新建能力、整体重构或全局审查**时，沿以下 16 个交点逐行逐列做 X 光透视，既查每一纵深有没有缺根或海拔错位，也查每一横行有没有缺环：

| 纵轴 ＼ 横轴 | 目标（守什么） | 判断（凭什么理论与标尺选） | 行动（怎么干且先后有序） | 结果（拿什么真实感官验真） |
|---|---|---|---|---|
| **灵魂**<br>海拔与骨相 | 这个 Skill 解决谁的什么核心痛点？立意应抵达哪一海拔（力求返璞归真、一花见世界），情感电压与声口底线是什么？ | 依据什么跨题材核心原理、审美质地三辨与高阶对标，在风格未定、多目标冲突或模糊需求时做裁决？ | 动笔前用哪几个最轻的前置动作锚定唯一立意海拔、鲜明风格骨相、活人声口与零防御切入角度？ | 脱掉全部说明直面成品，是否立刻呈现清晰风骨、真实电压与共通真相，而非写事打卡、装腔拔高或防御性温吞？ |
| **筋骨**<br>法度与分层 | 相对前沿强模型纯裸跑，本领域靠什么本质法度拉开差距？二级底座与三级专项各自守什么边界？ | 依据什么成熟学科理论与真实信号选法、换法、区分推进与回返，并决定三级子级需对哪些旋钮做非对称强化？ | 核心方法怎样编排为极轻前置骨架、模块按需触发、转化工艺与跨入口接口，同时剔除过时微操？ | 所选法度是否真正改变了结构、呼吸与核心推进，且不同风格子类不再拉平为一个味道？ |
| **血肉**<br>提纯与同级载体 | 眼前具体材料里哪些必须保真、哪些必须审美蒸馏、哪一个核心母体以少总多且配得上灵魂海拔？ | 依据什么审美距离、媒介适配、概念整合与同级共振标尺，剔除零度杂物、解释性胶水、小聪明寓言与论文式推理？ | 如何对原始素材抽魂换壳、围绕唯一核心母体跨时空发散联想并做高对比取舍，严守选材—加工—呈现分界？ | 中间设计与核心母体是否高度集中、自然生情、托得住立意海拔，毫无无关道具清单或生素材硬贴？ |
| **表皮**<br>感官质地与呈现格式 | 最终接收者（读者／观众／听众、拍板用户或下游模型）第一瞬与全程要获得什么双向之雅质感、鲜明辨识度，以及哪种**匹配场景的清晰呈现格式与用户固定格式**？ | 依据什么贴合真实媒介的综合感官判据、流派非对称特征、扫读清晰度标准（说人话、层次分明、重点突出）与格式契约检视成品？ | 如何先把灵感放飞成活稿，再在成稿后做轻度耳检／眼检，并按场景落到**人类易扫读排版、下游模型编码或作品原生／用户指定固定格式**？ | 最终产物在真实媒介、升维标尺盲测、人类 3 秒扫读与感官终审中，是否内容与形式双双达标、零文字墙、零擅改定式且稳定超越纯原生模型？ |

## 四、核心构造律：立盘、质地、大模型纠偏与分层突围

重构 Skill 或操盘高难度创作时，把以下十五条构造律直接落进规则设计与执行机制：

### 1. 判断层理论显式化、内密外透与规则反污染律
前沿强模型在预训练中已掌握大量顶尖学科理论与大师方法。**判断层最省字、跨题材泛化力最强的写法，是把真正管用的核心理论名、核心机制与裁决标尺显式写进运行态 Skill 正文**，同时严防规则文本本身污染生成分布：
- **对内显密、对外全透**：写给模型在后台做判断时，保留高密度核心理论与原理锚点（说清依据什么理论 → 解决什么判断 → 怎么落地），一句即可唤醒深层知识网并自动泛化到一切新题材；交付给普通用户看的作品或说明，绝不甩理论黑话与框架术语，全部解压为自然感官体验与大白话。
- **运行态与 `SOURCES.md` 严格分界**：`SOURCES.md`（平时 0 加载）只存放外部出处、版本核验与证据适用边界；凡直接参与日常决策、防止换题材失灵的核心理论与判断标尺，绝不锁进 `SOURCES.md` 而从运行态抽空。
- **规则反污染（只立判断边界与原理，不喂锚词、不铺禁词表）**：写回规则时只讲清判断边界、底层原理与反面失效机制。**绝不在正文反复投喂高频现成锚词或固定示范词**——强模型极易锚定复读，换再多题材都吐出同一批示例语汇，制造隐蔽的新套路；**也绝不铺陈冗长禁词表**——既触发粉红大象效应把注意力锁死在禁区边缘，又逼迫模型用更怪异蹩脚的同义绕口令敷衍合规。

### 2. 层级决定律与对外极简 ≠ 对内跳过前置定盘
灵魂与筋骨规定了血肉和表皮的成立边界，而横轴四层规定了每条规则能否真正闭环：
- **上层先定盘、四环必咬死**：动手前未钉死立意海拔、情感站位与鲜明风格骨相（灵魂）及符合该媒介时间观的结构职责与递进方式（筋骨），后续在表皮层怎么换词、改构图、调剪辑都救不回中庸四不像或层间割裂；写进 Skill 的每一条高杠杆规则，都须用紧凑自然的工作语言闭合目标 → 判断 → 行动 → 结果四环，不留半截残规。
- **删外部摩擦，不砍后台定盘**：强模型时代为 Skill 做减法，必须果断删掉发给用户的冗长参数问卷、多轮审批门槛与防呆式微观手把手指令；但**绝不能误砍作者在后台必须完成的灵魂立意定骨、筋骨定切面结构、血肉定核心母体这道极轻前置定盘**。最好用的 Skill 永远是对外干脆直出、对内先立魂定骨再下笔。

### 3. 审美质地三辨：去粗、破防御壳、抵双向之雅
松开过时束缚、要求作品直击人性与真相时，创作极易掉入两极陷阱，必须以**双向之雅**作为跨媒介审美质地的统一裁决标尺：

| 审美质地 | 作用方向与特征 | 真实感官后果 |
|---|---|---|
| **粗** | 未经审美提纯的原始发泄、脏乱糙、直白谩骂或粗糙感官轰炸 | 初看可能刺眼或生猛，但质感粗糙、缺乏留白与耐品度，经不起复看复听 |
| **防御性文雅**<br>（文雅防御壳） | 单向向内退缩，靠客气委婉、精致修辞、安全滤镜与廉价和解层层包裹锋芒 | 表面顺滑体面、无懈可击，实则抽干了最珍贵的情感电压与切肤刺痛感 |
| **双向之雅**<br>（高水准归宿） | **向内**做彻底的审美蒸馏，守住材质的克制、凝练与庄严；**向外**保持零防御姿态，像手术刀一样精准直击真相 | 既有直透人心的真切电压，又有经得起反复咀嚼的高级质地与美学留白 |

- **高张力流派保护红线**：去粗入雅去除的是未经提纯的脏乱糙与失控泄洪，**绝不能把文雅误读为温良恭俭让**，更不能把摇滚、尖锐评论、黑色幽默、冷峻现实、硬核动作等高张力风格磨成四平八稳的温吞口号。

### 4. 血肉的审美提纯、核心母体与材料—加工—呈现分界
血肉绝不是把原始故事、背景资料或需求要点当成任务清单逐条塞进成品：
- **冰山原则与审美提纯关**：原始材料很多时候只是冰山底下给情绪和观点供能的燃料，而非必须逐项打卡演完的提纲；选取具体物象与案例时，分清天然自带审美生命力与文化积淀的原型载体、绑定人类命运节点的关系媒介载体，以及实用功利极强且情感零度的干瘪杂物，绝不让零度杂物或无关陈词抢占作品核心。
- **严守材料（血肉）—加工（筋骨）—呈现（表皮）三段分界**：血肉负责选出与灵魂同级的高张力镜头、核心母体与冲突切片作为食材；筋骨里的转化工艺（修辞加工、动作或相似转场、因果与物理逻辑保真、相邻衔接）负责将生食材淬炼成型；表皮负责按目标媒介的专属语言、视觉或声音秩序呈现呼吸与余韵——不跳过加工工艺直接硬贴生素材，也不拿低层级的小聪明寓言或论文式条件推理拖垮灵魂，更不抽空情绪只剩冰冷技巧空壳。
- **核心母体全向发散**：宁可舍弃七八个互不咬合的分散道具，也要钉死极少数（往往唯一一个）有美感、有延展力、托得住四阶立意的核心母体，围绕它的质感、动作与跨时空迁移展开丰富联想，做到以少总多。

### 5. 殿堂真品先行定音律与放飞—修疤物理分离
- **把顶级真品当成对抗均值权重的前置音叉**：强模型在无参照的真空里直接开写，天然会滑向全网平庸语料的平均分布（套话、短剧俗壳、无感汇报）。凡涉及审美上限、传唱与传播穿透力，或遇到小白宽泛愿望、琐碎日常输入时，动笔前须先实调 **1–2 部经受时间与真实受众检验的同品类殿堂真品**做四维定音——专门校准它的**词汇纯净档位与活人呼吸（表皮）、如何切入与制造高潮（筋骨）、怎样把生活原材提纯为高美感母体（血肉）、立在何种海拔（灵魂）**。定音完毕立刻合上对标、彻底换成本作自己的血肉，只学美学海拔与底层机制，零抄袭任何词句、意象组合或结构套壳。
- **物理分开创作放飞与成稿后轻度修疤**：表皮层的综合声律、版式、构图、剪辑与细部规范，是成稿后用真实感官做轻度扫疤的结果标尺，绝不能异化成动笔前的刚性填字网格与几十条事前演算清单。事前条框过密会把强模型算力全耗在合规解题上，引发雕刻伤气，彻底勒死启发性思维、联想力与鲜活语感。

### 6. 二级通用底座 × 三级风格非对称突出律
在包含二级主 Skill 与三级风格/专项子 Skill 的体系里，两层必须严守职责分工，防止高分同质化：
- **二级主 Skill 负责守住通用海拔与底盘**：承担全品类的四维通用海拔、成熟专业法度底盘与双向之雅基准，确保未指定细分风格时即可独立交付高水准成品；但所有风格若只停留在二级通则，不同体裁与流派就会被拉平为一个味道。
- **三级子 Skill 负责有意识的非对称偏移**：三级子 Skill 的核心价值绝不是复读、改写或稀释二级通则，而是在承接二级底座之上，针对该流派、体裁或受众语境的独特基因，**对四维的特定旋钮做有意识的非对称强化与偏移**——往往以**表皮工艺**（语汇肌理、声律颗粒、笔触材质、光影构图、剪辑韵律、配器音色等）作为最锋利的辨识切口，并联动**灵魂站位、筋骨节奏与血肉取象**协同倾斜，放大该风格最不可替代的锋芒。
- **脱标盲辨验收**：摘掉标题、流派名称与制作说明，单凭成品本体让受众直接看或听，能否在第一瞬就辨认出其独特风格归属，而非换了外壳的通用模板。

### 7. 媒介留白容器律与 80/20 素底点睛
不同媒介的信息满载度完全不同，规则设计必须先辨清本领域属于哪一种容器，绝不拿单一文本汇报思维压垮全部品类：
- **区分自足独白媒介与协同留白媒介（他媒体）**：长篇深度文章、技术手册等偏向文字自足承载；而歌词（需留给旋律、编曲与听众自身记忆）、剧本与分镜（需留给演员表演、光影与剪辑呼吸）、封面与标题（需留给画面与好奇心空缺）均属于**协同留白媒介**。在协同留白媒介里，把所有信息、前因后果与心理结论塞满 100% 文本，反而会堵死合作媒介与受众共同参与的呼吸通道，造成假抒情、真汇报的窒息感。
- **80/20 素底点睛 × 100% 地道母语**：无论哪种媒介，成熟作品的黄金质地都是 **75–80% 极致干净、通俗自然的母语素底 × 20–25% 精准克制的点睛之笔**。宁可保持素雅克制再在刀口处给两三记过目难忘的画面或词锋，也绝不为了显得有技巧而生造拗口怪词、硬压生僻缩略语、堆叠流水线塑料道具，或用大批空洞体感形容词充当廉价画面感。

### 8. 爆点区与铺垫区的双脑物理隔离（两阶段解耦律）
凡是存在**核心引爆区**（如标题/封面主视觉、歌词副歌核、短剧/文章高潮转折与钉子句）与**低水位铺垫区**（如开场引入、主歌叙事、预副歌蓄压、背景展开）的创作任务，两个区域需要的其实是截然相反的创作状态：
- **单次一锅煮必然引发双向风格污染**：在同一轮顺写里，一旦强调克制、意象铺垫与冷静分寸，铺垫惯性就会流进高潮区，把最该引爆的核心段写软写平、甚至跌成情绪低点；反之，一旦在同一次生成里猛灌破防、直给与强宣泄指令，高潮区的直白张力又会反向冲垮铺垫区，把整部作品的镜头感、体面与审美格调全线拉低成廉价口水。
- **两阶段解耦与张力—释放曲线**：凡高潮成败决定全篇上限的品类，优先走**两阶段解耦**——**第一阶段**只动用单点爆破大脑（或调用对应单点专项），独立锻造并锁定核心爆点与情绪中心；**第二阶段**彻底切回低水位克制与镜头铺垫大脑，围绕已锁定的爆点倒推设计引入、蓄压与过渡。铺垫段负责制造悬而未决的紧张蓄压（Tension），核心爆点区则负责接住这口气完成高对比效价释放（Contrastive Valence）——**严禁在高潮区竖起冷硬防御盾牌、继续解释前段比喻设定，或切回理性结案脑给高潮泼冷水**，要做到语言向内依然雅致克制、内心防线向外真实破防。

### 9. 认知空白与传播记忆点律（歧义留白 × 六维钩子 × 三秒质检）
情绪真挚与表达工整只解决了好听好看的下限；真正让作品在受众脑海里扎根多年、引发自发截图与口碑传播的**记忆点（社交货币）**，来自**未完全封死的认知空白与精确双轨张力**（最优创新假说：熟语微拧半寸；预期违背与顿悟；良性越界；接受美学召唤空白）：
- **跨品类六大记忆点原型**（按媒介与题材真气自然选用，不搞油腻堆砌）：
  1. **表里双轨 / 语义双关**：用清白体面的日常词面皮，包裹放进特定语境便一秒意会的私密经验、情绪暗流或人性里子（零粗俗，全靠受众自行接通第二层含义）；
  2. **熟语微拧 / 同词异义 / 谐音轻转**：借大众闭眼能背的熟语或高频词只拧半寸，或让同一词的两种词义正面对撞，零门槛又带惊艳回响；
  3. **语意反转 / 前扬后劈**：前半句顺着理性、温和或奇观轨道建预期，后半句急刹劈翻亮出截然相反的真相；
  4. **反讽冷刀 / 降格留白**：用极客气、极克制的语气刺穿最残酷的落差或代价，表层风轻云淡、底色见血；
  5. **陌生化跨界撞击**：把抽象情绪或老生常谈撞进冷峻的物理、空间或异质动词里，强行打破审美麻木；
  6. **人性公理 / 空槽召唤**：用极简对称短句定格普世真相，或搭出仪式感极强的通用空槽，召唤千万受众往里填进自己的人生。
- **黄金分布与三秒质检硬杠**：一部作品集中部署 **2–3 处黄金记忆锚点**（主爆点 1 处核心锚 + 铺垫或转折段 1–2 处隐藏意会刀口），绝不句句抖机灵毁掉真气；每一处必过**三秒质检**——① 第一遍顺滑零门槛，回味半秒第二层含义咔嗒击中（绝非强凑冷笑话烂梗）；② 100% 服务核心情绪与主题痛感，绝不为炫技出戏；③ 单独截出仍自带社交货币与讨论传播力。

### 10. 正向五维筛材与物理换血律（破解双向提示词引力）
单纯在规则里叮嘱提升五感、提高格调，在实际生成中往往依然产出廉价短剧味或文艺散文腔，根源在于大模型的**双向提示词词面引力（Prompt Token Gravity）**：
- **正向污染（粗糙输入引力）**：只要原始提示里的低美感都市杂物、行话账本或琐碎流程词原样留在成稿上下文中，注意力机制就会死死吸附其上，把高级五感与高级技法也一起拽进低维俗套；
- **反向污染（散文简报引力）**：即便清除了粗糙输入，如果前置拆解写成了堆满文艺气氛形容词的长篇散文详案，下游成稿阶段同样会照单全收这些修饰词，写出端着架子的书面散文腔与逐条交作业清单感。

**跨品类通用的物理换血三步机制（100% 正向门禁，零冗长禁词表）**：
1. **辩证三态判输入 ＋ 剥壳提纯核心**：先对照本领域殿堂级核心特征判断输入——若用户本身同向且给出了不违背规律的明确独到方向与具体内容，**完整承接并沿该方向做透**；若输入模糊宽泛，或字面载体明显偏离、违背本领域殿堂级特征（如用琐碎都市杂物讲深情），则穿透表层表述，只保住**无论怎么变都不会变的核心情绪／人类底层需求、真实事实底线与合法锁定项**，把低美感粗糙外壳视作待换血原料。
2. **五维正向精筛与打回门禁**：为作品挑选意象、核心切片、视觉锚点或故事载体时，候选须经受五维正面审验，任一落空当场打回换血（明确要求年代写实、窄众纪实或行业教程的任务按该品类边界调整第 ①、⑤ 项）：
   - **① 跨时代持久生命力**：跳出易过时的时代消费品与界面杂碎，经得住时间冲刷；
   - **② 独立审美光晕**：单独抽出来定格成画面、剧照或金句，依然干净、纯粹、有层次；
   - **③ 人类原型共鸣频率**：载体本身天然共振人类共通情感或处境，无需作者生硬旁白解说象征意义；
   - **④ 活态多感官／真事实生命力**：正在发生声、光、温、嗅、触、动作变化或真实冲突，彻底告别静止挂历画与静态贴纸；
   - **⑤ 千万受众的公共投射空间**：入口开阔，容得下不同职业与年代的受众照见自己的人生。
3. **极薄白描交接卡片（物理隔断双重污染）**：前置环节向成稿环节交接时，只交付一份极薄的**白描卡片**——1 句大白话情感核/核心主张 ＋ 1–2 部对标真品的语感坐标 ＋ 2–3 组**纯裸实体名词与真实动作原子**，**既彻底隔绝被打回的粗糙原始词，也物理剥光全部气氛修饰形容词**；且成稿环节只挑最浑然一体的 1–2 组吃透，绝不把卡片当作业清单硬塞满。

### 11. 活人母语自然语法与实词承重律（根治自回归词类截肢与伪文言压扁）
即使完成了意象换血，强模型在短句、标题、歌词、金句和紧凑台词中仍会高频冒出三类令人出戏的 AI 语言畸形：① **自回归句尾词类截肢**（从左往右写到行尾撞上字数与押韵/对仗双重硬墙，模型为了塞进最后 1 个字，把正常名词硬砍掉、将单音节形容词塞进名词或宾语位凑数）；② **伪古风四字压扁坍缩**（面对齐刷刷的字数方阵，自动滑入中文网文与廉价古风词里压缩率最高的四字半文言胶水短语，删掉主语与口语虚词装深沉）；③ **感觉形容词贴标签偷懒**（直接往纸面贴冷暖轻重散淡等单字结论词替受众宣布感受，替代真实动作与事实）。

**跨品类通用的现代母语四道正向语法门禁（不打地鼠式列禁词表，从生成机制断根）**：
1. **真话语序门禁**：把每句话拿掉排版、标点或旋律，平声念给对面坐着的朋友听——必须像现代活人亲口说出的完整自然汉语，大方使用现代双音节动词与日常口语虚词托起说话气息，凡压扁成伪古风缩写或书面腔短语的一律打回还原成真话（明确指定的古典韵文、古风诗乐或戏曲唱词按对应专项语域执行）。
2. **实词承重门禁**：所有温度、轻重、聚散、好坏、克制与痛感，**100% 藏在具体实体名词、真实人的身体动作与平实事实本身里**，让受众自己从画面和事实里产生体感，绝不往字面贴单字或抽象感觉标签词替受众总结。
3. **逆向实词落点门禁**：凡有字数预算（如 6–8 字短封面、短标题）或押韵／收尾强位约束（如歌词句尾、篇内钉子句），**先敲定现代汉语语法完全站得住脚的完整实词核心与句尾落词（具体名词、完整动词或自然双音节现代词），再往前顺出前半句**——从生成次序上彻底斩断从左往右撞墙后截肢名词塞形容词的畸形句法。
4. **自然呼吸错落门禁**：打破齐刷刷的机器对称方阵，顺着真实说话换气与情绪推进让长短句自由错落，留出人声与思考的呼吸空隙。

### 12. 提示词中继生成律：以终端殿堂成品为靶，四维编码下游模型听得懂的指令
仓库里的创作能力天然分成两种形态，构造与审校必须分清边界、绝不混用同一套文本标准：
- **直出成品类（文本即作品）**：文章、小说、剧本、歌词、标题等，模型写出的文字本身就是直接面对人类读者或听众的终端殿堂级作品；
- **提示词中继生成类（文本是跨模型媒介）**：封面出图、单张画面、多视角视觉资产、AI 视频分段、AI 音乐／声线生成等，文字本身**不是最终作品**，而是中间过渡了一道媒介——用来精准操控下游专用生成模型（生图模型、视频模型、音乐／音频模型等），去渲染出**最终的殿堂级视听成品**。

因此，提示词本身同样完整遵循造梦框架的四维四层，只是每一维的服务对象从直接悦读变为**把终端殿堂级作品的决定性要素无损转译为下游模型可执行、可渲染的控制指令**：
1. **灵魂（宏观风格与气质总控）**：先按三态辩证裁决法穿透用户需求，定死最终成品对标哪一档殿堂级视觉／听觉标杆，从宏观锁住整体艺术风格、媒介材质基因（如胶片摄影、工笔水墨、原生电影实拍、原声乐队还是电子合成）与唯一核心情绪基调，防止下游模型风格漂移或滑向千篇一律的廉价 AI 塑料感；
2. **筋骨（整体构成、布局结构或时间骨架）**：定清最终生成物由哪几大功能部分组成、彼此如何排布或推进——如多视角资产的无缝四宫格视角构成、封面的主视觉与文字安全区占比、单张画面的构图重心与透视关系、视频单段内起承转合的镜头切分与运镜轨迹、音乐的段落能量爬坡与织体分层；
3. **血肉（下游模型可直接渲染的具体物理与视听要素）**：填进骨架里的实打实可渲染内容——主体外观与正在发生的动作状态、景别（特写/近景/中景/远景）与机位高低、前景／中景／背景空间层次、具体光源方向／色温与景深虚化、表面材质纹理，或具体乐器音色、人声唱腔与混音空间。**把终端殿堂级作品的氛围与情绪，全部翻译成可见、可听的物理要素**，彻底剔除下游专用模型无法渲染的抽象心理点评、故事前情与文艺抒情形容词；
4. **表皮（面向下游专用模型的提示词文本与参数编码）**：把前三层组织成最终交给目标模型或工具输入字段的提示词正文——遵循该模型的真实注意力与解析规律（宏观灵魂与核心主体前置、每条独立自包含、参考附件与目标状态清晰绑定、物理逻辑与光影方向零自相矛盾、篇幅精炼避免过载引发变形或串风格）。

**中继类的结果验真铁律（拒绝拿提示词文采冒充成品质量）**：
- 纸面检查只能确认提示词四维齐备、无物理与风格冲突、无下游模型听不懂的空洞文学词；
- **真正的终审结果，永远是下游专用模型实际渲染出来的成图、成片或成音**是否具备终端殿堂级作品的关键要素；一旦渲染结果偏离预期，严禁盲目往提示词里继续堆砌空洞修饰词，必须沿四维反向定位最早断点——整体廉价出戏查**灵魂**、构图散架／视角乱／节奏断查**筋骨**、主体／景别／背景／光影虚化／音色失准查**血肉**、模型漏读关键词或串词冲突查**表皮**编码与语序。

### 13. 过程文档、诊断审查与沟通决策律：一切上游环节皆为终端殿堂级作品服务
除了直出成品与提示词中继生成之外，创作全链路中还有大量**面向用户对齐或承上启下的过程文档与对话环节**——包括动工前的制作简报（如动画或视听作品前置 `brief`）、创作计划、选题与故事构思、深度原因分析、找茬审查报告，以及每一次帮用户拍板方向的关键交流。它们同样不是孤立的文档任务，而是**决定最终能否诞生殿堂级作品的上游方向舵与生死关**。

普通模型处理这类环节时，最容易陷入**僵硬完成任务思维**——用户让写简报就照模板机械填格子，用户让分析就围着表面现象罗列几个四平八稳的折中选项，用户让找茬就只挑表面措辞和格式打勾。造梦框架要求全部过程文档、诊断与沟通死守四条正向准则：
1. **锚定终端殿堂级成品，绝不走形式填表**：哪怕当前交付的只是一份前置 `brief`、方案讨论或找茬清单，心里必须时刻装着最终那件经时间与数据验证的殿堂级成品标准——凡会拉低终稿上限的模糊前提、平庸结构或偏离正道的设定，必须在上游环节直接拦住并提出更高海拔的替代路径，绝不顺着平庸前提把错误写实成计划。
2. **分析与找茬必须自上而下直击最早杠杆断点**：审查作品或剖析卡点时，严禁停留在表面润色或细枝末节，必须沿灵魂（立意、情绪、目标用户真需求）→ 筋骨（结构、冲突、节奏、因果）→ 血肉（选材、意象、镜头、例证）→ 表皮（语言、画面、声律）自上而下追查真正拉垮殿堂级水准的最早根因，并给出直指根因的最小对照或破局方案。
3. **前置简报与计划兼顾人类拍板与下游防污染**：给用户审阅的简报、方案与分析，用直白人话亮明核心判断、利弊代价与拍板项，有立场、不端学术腔；同时凡会直接交接给下游创作或中继生成模型的简报卡片，保持高纯度白描与明确边界，避免夹带冗余散文修饰反向污染下游生成。
4. **每次沟通都在帮用户逼近最好结果**：把用户每一次反馈都放进三态辩证裁决中理解——既尊重用户深思熟虑的独到方向并顺势放大，也敢在发现方案偏离人类共识与殿堂级规律时坦诚说清利害、带回正道，真正做创作者共同造梦的顶级搭档，而不是只会机械点头交差的填表助手。

### 14. 表皮双轨呈现与格式契约律（说人话 × 一眼扫清 × 媒介原生与用户定式）
表皮维度的好坏，不仅取决于词句文采、声律节奏或画面笔触，更直接取决于**信息的呈现形式、版式结构与输出格式是否贴合当前接收对象**。哪怕底层内容极佳，只要呈现方式错了（例如把选题分析挤成一团紧凑文字墙，或把最终作品的固定格式改乱），最终体验依然大打折扣。必须按输出所处的真实阶段严格分轨执行：

1. **中间态沟通、选题灵感、故事构思与分析诊断文档（面向人类决策者：说人话 ＋ 一眼扫清）**：
   - **彻底说人话**：凡交付给用户、观众或读者阅读的说明、选题分析、灵感方案或找茬报告，一律把内部框架术语、学术黑话和压缩词解压成通俗直白、谁都一秒听懂的自然语言；
   - **结构化扫读排版（严禁紧凑文字墙）**：必须主动用清晰的 Markdown 标题层级、分条罗列、对照表格、**推荐优先级排序**、**核心结论与关键词加粗标重点**以及明确拍板选项组织信息，让用户一眼扫过去就能立刻定位最核心的结论、差异与推荐项，绝不把关键信息埋在大段密不透风的文字堆里。
2. **下游交接与提示词中继输出（面向下游模型或接口：洁净定式 ＋ 独立可用）**：
   - 面向生图、视频、音乐等下游专用模型或工具脚本的交接文本，严格按目标模型／字段所需的确定性结构、独立代码块和参考绑定格式输出，剥离多余寒暄与散文废话，确保下游稳定解析、零串位。
3. **最终殿堂级作品本体（媒介原生格式 ＋ 严守用户固定格式契约）**：
   - **遵循作品媒介原生格式**：直接交付的终端殿堂级作品，严格呈现该艺术或内容品类应有的专业原生格式（如规范剧本格式、契合目标平台阅读呼吸的文章排版、纯净独立可复制的歌词正文块），绝不把中间分析框架、打分自查或沟通废话污染进作品本体；
   - **严守用户明确的固定格式要求**：凡用户或该领域已明确约定的固定输出格式——例如歌词乐段采用英文中括号标签（`[Verse 1]`、`[Chorus]` 等）与句内纯空格气口、独立纯文本代码块一键复制、指定 JSON／CSV／表格字段模板等——均属于表皮硬契约，严格照办执行、绝不擅自变造。

### 15. 细拆显式判断替代拍脑袋数字、双阶对撞参考库与资源缺失破局律
真正束缚前沿强模型的从来不是“判断标准写得细”，而是**拿拍脑袋的固定数字冒充细致判断**，以及**在查库与资源缺失时盲目套壳或跨媒介硬扛**。构建含多维审美决策、多工具选型或本地资源库的能力时，必须守住四条底层机制：

1. **严禁用拍脑袋数字掩盖判断层缺位（细判断激发深度思考，拍脑袋数字诱发浅层猜测）**：
   - 凡涉及色彩极数、字族款数、分场或切拍时长、查库次数、工具组合或定妆帧数量等**非物理硬上限**决策，绝不允许凭直觉写死笼统数字区间（如固定几套色、固定几秒一拍、固定查一两次）敷衍过关——拍脑袋数字既会锁死灵活度，又会诱使模型跳过深度思考去机械凑数或浅层盲猜；
   - **细致判断 ≠ 僵硬微操**：必须把判断层拆得足够细，显式写清背后的**学科理论、决策变量、条件分支与工具物理边界**（例如按情绪对比与亲和律决定切不切色、按观看完成点与价值转向决定分场拍长、按各渲染引擎物理特长选工具），充分调动前沿模型的深度推理，针对当前具体作品自己推演出最优解。
2. **参考库／资产库的“先盲起、再自由查库双输入否定升维”机制**：
   - 拥有风格库、动效库、字体库、音频库或方法库的领域，先在不看参考库的状态下按内容本质与显式理论盲起极薄白描初稿（释放模型原生上限与贴题灵气，作为底盘下限）；
   - 再将初稿视作待升维的粗糙输入，**不设查库次数死限、完全服从作品成败自由按需查库**，拿经受验证的高水准真品参考与初稿做双输入对撞——敢直接否定并掀翻初稿平庸处，只借构图尺度、节奏机制与算法换血重构，同步拉高下限与上限。
3. **资源缺失与跨媒介错配时的四条破局底线**：
   - **宁缺毋滥，绝不为凑回执强套不合拍资源**：当本地参考库、素材库、配乐或模板中确实缺少贴合当前作品气质与内容的资源时，绝不允许为了填表或满足形式 ID 强套凑合的风格、贴纸或配乐；
   - **严守媒介主场，拒绝跨媒介硬搬制造断层**：例如原生代码动画不借扩散生图模型代画方向帧，也不用基础画布硬画写实人物或复杂手绘简笔画——资源缺失时优先回归本媒介最擅长的物理主场与显式理论，靠拆件重组、选准最匹配的专业工具栈或纯粹原创补足；
   - **写实原件与事实证据缺失严守诚实边界**：凡缺真实照片、品牌原件、系统日志或一手实测数据，一律诚实标明缺口、索取原件或改用明确标注示意边界的抽象机制表达，绝不凭空造假冒充现实证据。
4. **长体量任务分场独立推进 ＋ 清空包袱独立高维总审**：
   - 长篇或多阶段创作忌一口气在单次超长上下文里硬撑到底（尾段必然因注意力稀释而滑坡）；应先立极薄全局共享总纲守住全片统一性，再按价值转向逐场在轻量聚焦上下文里独立完成盲起与升维、自带首尾交接把手，最后清空过程草稿与查库包袱做一次独立高维总审与场间拼缝，确保全片首尾同级。

## 五、追根溯源、隔离探测与防盲区进化律

审查排障、推翻旧认知或迭代 Skill 时，按以下三条实证进化律闭环推进，杜绝盲打补丁与负进化：

### 1. 逐层追根溯源与反钟摆诊断
- **工艺全过却不对味，必向上追根**：当成品总觉差一档、各处不融洽或味道不对，但所有局部工艺检查（结构完整、格式规范、技法达标、约束无误）竟然全部通过时，说明真病灶绝不在表皮工艺，而在更高维度发生了隐蔽错位。此时严禁继续在表皮层堆补丁、调措辞或加禁词表，必须沿**灵魂（立意海拔/情绪电压/风格骨相）→ 筋骨（媒介时间观/结构职责/转化工艺）→ 血肉（母体层级与审美蒸馏）→ 表皮（质地与非对称工艺）**自上而下逐层追查最早发生错位的底层机制。
- **反钟摆诊断**：一旦出现改掉毛病 A 立刻冒出毛病 B 的钟摆震荡（如去流水账变表皮假拔高、去粗鄙变防御性文雅、求规整变僵硬无魂、跨风格立刻趋同或打回书面腔），说明要么停在表皮打补丁未触及上层错位，要么横轴丢了判断层理论或结果真感标尺，甚至子技能里残留着与新底层原理打架的旧枷锁。此时立即停手局部补丁，按 4×4 十六交点全盘查清根因与残留冲突。

### 2. 单变量隔离探测法：先探真、再融写、后盲测
面对颠覆性理论假设、底层审美转向，或怀疑既有规则本身已成为隐形天花板时，绝不在背负厚重旧包袱的正式 Skill 上边猜边改，必须严格执行三步隔离实证：
1. **纯净单变量探测**：在隔离实验环境中（必要时暂时剥离旧规则包袱，清零干扰），仅改变单一核心假设，直接跑出真实成品；
2. **创作者肉眼 / 真耳确真**：不靠理论听起来多自洽或机器纸面打分自证，先将隔离实验产出的完整原始成品交由创作者用肉眼看、真耳听，确认新假设确实带来真实体感跃升；
3. **干净融写与正式盲测放行**：方向确认对路后，再把提纯后的跨题材规律低熵融写进正式 Skill（同步清除与之打架的旧枷锁，严守规则反污染），最后按 [评估与验证协议](evaluation-protocol.md) 执行正式隔离 A/B/C 盲测（必要时补留出新题 `H` 防过拟合），确认相对纯原生 A 与旧版 B 均有真实净提升才放行完成进化。

### 3. 防评测维度盲区：标尺必须随认知突破同步升维
进化过程中最隐蔽的陷阱，往往不是模型能力不够，而是**评估标尺本身锁死在旧认知维度**——评审清单只给表面合规、工整结构、安全修辞与旧工艺指标打高分，却漏考**立意海拔（是否停在三阶假拔高）、四维同级共振、情感电压（是否滑入防御性文雅）、流派非对称辨识度以及人类真实感官冲击**。
- 每当对本领域的理解实现代际跃升，对应的盲评维度、审查问题与自检标尺必须同步升维（与 [评估与验证协议](evaluation-protocol.md) 的自适应专属标尺合一）；
- 警惕机器评审天然偏爱工整、安全、四平八稳的书面外壳：凡涉及创意与审美上限的重大进化，AI 盲评最高只作 `OBSERVE` 参考，最终必须以未改一字的完整原始对照成品交由人类肉眼与真耳终审定音。

## 六、实战避坑与落地操作指南（优化任意 Skill 必读）

理解纵轴四维与横轴四层的概念并不难，真正决定一个 Skill 改完是**代际跃升**还是**越改越木、越改越弱**的，是落地修改与验证时的操作手艺。以下是多轮跨品类重构与真实肉眼验收中用教训换来的十三大高频深坑、大模型级排障模型与七步落地操作法，优化全仓任何其他 Skill 前必先对照自检。

### 1. 真正吃透框架的三条底层心法

1. **纵轴定先后与海拔，横轴防半截残规**：动手前必须先立住灵魂（立意海拔、情感电压、活人骨相）与筋骨（领域法度、节奏结构、转化工艺），再落血肉与表皮；写进规则的每一条高杠杆能力，都要用紧凑自然的话闭合目标 → 判断 → 行动 → 结果四环，缺哪一环就会爆发对应故障。
2. **规则本身的语感会直接传染给成品**：规则不是给机器判官打分的合规考卷，而是用来激发前沿强模型潜力的指挥棒。规则正文写得端着学术腔、塞满防错禁令，模型产出的成品就会跟着发紧、压缩、不讲人话；规则写得通透、笃定、有呼吸感，成品才能既稳又有灵气。
3. **新感悟进门永远是增量融合，绝不是拆东墙补西墙**：旧版经过验证保留下来的核心长板（例如活人情绪、画面张力、物理节奏、关键边界）是已赚到手的资产；引入新要求时必须先找准它在 4×4 里的归属位，并写清它与既有长板的共存边界，绝不能一拍脑门把旧核心规则覆盖删掉。

### 2. 优化其他 Skill 最易踩中的十三大真实深坑与破局法

| 高频深坑 | 怎么踩进去的（真实病灶） | 直接恶果 | 破局铁律 |

| **深坑 11｜把前置简报、分析报告、找茬或用户沟通当成僵硬填表交差** | 认为简报、计划、分析或找茬只是走流程文档，未将其锚定在最终能否诞生殿堂级作品上，顺着平庸前提机械填字段、只抠表皮错字或给四平八稳无立场的折中建议 | 简报把错误方向写死、分析停在表层症状、找茬漏掉致命硬伤，导致下游无论怎么执行都注定平庸 | **上游环节殿堂靶向 ＋ 最早断点直击**：一切前置 `brief`、选题、分析、找茬与沟通对齐都以最终殿堂级成品为唯一检验标准——前置规划先锁死决定上限的骨架取舍，诊断审查自上而下直击最早根因，对用户坦诚给立场、对下游给洁净白描边界 |
| **深坑 12｜只管内容好坏、忽略表皮呈现形式与格式分轨** | 选题灵感、分析报告或沟通内容堆成密不透风的大段文字墙、夹满黑话且无重点排序；或输出最终作品时混入过程说明、擅改用户指定的固定格式（如擅改英文中括号段标、破坏纯代码块或字段结构） | 内容再好也让用户找不到重点、看不下去，或导致下游工具与一键复制直接报错返工 | **表皮呈现三分轨**：中间态沟通／选题／分析坚持通俗说人话 ＋ 清晰标题、分条、表格、推荐排序与重点加粗让用户一眼扫清；下游交接守洁净定式接口；最终作品严守媒介原生格式与用户明确指定的固定输出格式 |
| **深坑 13｜拿拍脑袋数字冒充细致判断，或资源缺失与跨媒介错配时硬套模板** | 对色彩盘数、字族款数、分场拍长、查库次数或工具选型懒得拆透底层理论，直接拍脑袋写死笼统数字区间；遇到本地库资源缺失或跨媒介不匹配时，又为凑回执强套不合拍模板或硬借错误媒介代工 | 模型被死数字卡成僵硬流水线或浮于表面浅层盲猜；强套错配资源与跨媒介代工导致设计稿和实现两张皮、成品退化成廉价简笔画或模板拼盘 | **细拆显式判断 ＋ 双阶对撞 ＋ 资源缺失本媒介原创兜底**：清零非物理拍脑袋数字，用细致学科理论、决策变量与全栈工具物理边界调动模型深度推理；先盲起白描再不限次数自由查库双输入否定升维；资源缺失宁缺毋滥，回归本媒介物理主场原创补足，缺失写实原件绝不造假 |

### 3. 跨品类造梦破局实证模型：大模型级排障与迁移应用指南

在全仓任意其他 Skill 的优化中，只要反复出现**理论越加越厚、成品依然带 AI 味或低维俗壳**的顽症，一律不要在表皮打补丁，直接按以下**模型执行级四步破局闭环**定位并根治：

1. **从成品症状追查底层大模型机理**（不再用学院派文学批评自说自话）：
   - 总是摆脱不了粗糙琐碎道具与廉价网感 → 病灶是**正向提示词词面引力 ＋ 缺失殿堂真品音叉**；
   - 画面干净了却透着散文作文腔、四字伪古风缩写或句尾怪异单字形容词 → 病灶是**反向散文简报引力 ＋ 自回归句尾撞墙词类截肢 ＋ 感觉标签词偷懒**；
   - 铺垫精彩但核心高潮发软，或高潮直白把前段拉成口水 → 病灶是**爆点大脑与铺垫大脑单锅双向污染**。
2. **用 100% 正向物理机制替换负向禁词表**：
   - 把 `不要写低俗道具` 变成**五维正向精筛打回门禁 ＋ 物理换血**；
   - 把 `不要写书面形容词凑韵` 变成**极薄白描无形容词卡片 ＋ 活人母语四门禁（真话语序 / 实词承重 / 逆向实词落点 / 长短错落呼吸）**；
   - 把 `提高格调与记忆点` 变成**殿堂真品前置定音 ＋ 两阶段爆点先锁 ＋ 六大武器三秒质检**。
3. **跨品类对号入座迁移表（先立本领域殿堂级特征，再行三态裁决与物理换血）**：

| Skill 品类 | 本领域殿堂级核心特征（先立标再判三态） | 粗糙或偏离输入怎么三态换血 | 极薄白描与活人语法门禁怎么用 |
|---|---|---|---|
| **标题 / 封面文案 / 关键句** | 0.3 秒读通零歧义、击中千万人共通痛点或欲望、留出认知空白且正文接得住 | 尊重同向精准切口；遇窄行业流水账或平淡自嗨，穿透挖出核心情绪与公共命运母题，对标一线真爆款升维 | 6–8 字封面与金句先逆向锁定完整无歧义实词核心再补句；零空洞形容词与断句截肢怪词 |
| **歌词 / 词曲创作** | 跨时代高美感活态意象、真情电压与活人说话呼吸、副歌过耳难忘狠歌眼 | 尊重同向独特题材与风格；遇模糊愿望或塞满俗套都市杂物的偏离输入，提取不变核心情绪、实调 1–2 首殿堂真曲定音并五维换血 | 第一环只交 ≤15 行纯裸实体＋真实动作卡片；第二环先调副歌核专项砸狠歌眼，再以活人语序与逆向实词韵脚织全曲 |
| **文章 / 口播 / 教程** | 直击读者真实痛点或认知盲区、逻辑骨力严密、实证扎实、读完有真获得感 | 尊重作者独到洞见与清晰框架；遇散乱素材清单或碎碎念，穿透出底层读者诉求与唯一硬主线，对标顶级深稿定音 | 大纲与卡片拒绝学术形容词堆砌；正文坚持活人当面讲透的真话语序、具体案例实词承重与短行呼吸 |
| **剧本 / 小说 / 故事** | 强戏剧冲突与人物两难抉择、动作与视听化显影、场次推力与潜台词留白 | 尊重不违背戏剧规律的独特题材与结构；遇狗血俗套或平铺流水账，提取不变人性处境与情绪张力，对标影史/文学经典重构戏剧载体 | 人物对白与动作描写严守真话语序与实动作承重，删掉替观众总结情绪的感觉形容词旁白 |

| **规划简报 / 选题构思 / 深度分析 / 找茬审查** | 提前锁死能通往殿堂级成品的决定性方向与结构，或一针见血揪出拉低终稿上限的最早根因（绝非走形式填表） | 尊重用户清晰高水准方向并放大其锋芒；遇模糊诉求主动补齐专业海拔；发现前提偏离殿堂级正道时坦诚点破、提取不变核心情绪并给出更高海拔替代路线 | 给人类拍板的报告用直白人话亮明立场、代价与最小对照；交接下游执行的 `brief` 卡片保持极薄纯净白描，不夹带散文形容词污染下游 |

### 4. 用造梦框架重构或进化一个 Skill 的七步闭环操作法

每次新建、整体重构或深度升级任意领域 Skill 时，按以下七步有序推进，绝不跳步：

1. **先备份与全量摸底**：将待改 Skill 及关联个人偏好完整备份至 `.cache/restore/`；盘点仓库内所有指向该 Skill 的外部 Markdown 锚点、评测夹具（`evals/`）、子技能清单与已知历史痛点，确认零误伤边界。
2. **做 4×4 十六交点 X 光体检**：沿着纵轴（灵魂 → 筋骨 → 血肉 → 表皮）与横轴（目标 → 判断 → 行动 → 结果）逐格定位最早错位层——查清有没有立意掉阶、判断层被抽空锁进 `SOURCES.md`、事前微操过密、子级残留旧枷锁或四处复读。
3. **拿不准先隔离探真，再示范反推动作**：涉及底层方向调整或新手法假设时，先在 `.cache/validation/` 隔离区单变量跑出真实成品交创作者肉眼/真耳确真；一旦创作者对某类效果拍板认可，立刻用**示范反推动作法**提炼出零锚词、可跨题材迁移的实战真动作。
4. **增量融合、单源落位与规则排毒**：严格按四层非对称分工写回正式文件（或先写隔离候选再落正式），必要时引入**爆点区与铺垫区两阶段解耦**及 **2–3 处黄金记忆点锚位**；落笔时逐条核对**三不丢、三必清**——不丢既有验证有效的核心长板、不丢 A×B 共存条件、不丢媒介适用边界；必清运行态学术黑话与示范锚词、必清非物理限制的死数字枷锁与冗长禁词表、必清跨文件残留的相反旧条款。
5. **离线静态校验与防污染自检**：在仓库根目录运行 `python3 tools/check_project.py`（动到工具或发现逻辑加 `--test`），同时检查运行态总体积、外部入链锚点完好度、装饰双引号与锚词污染清零。
6. **纯真受众标尺隔离 A/B/C 盲测**：至少覆盖**回归题（直击旧痛点）＋ 全新零污染留出题（防过拟合）**，用完全隔离的空上下文同台对照纯原生 A / 旧版 B / 新版 C；拉丁方匿名换位、核查盲评包无格式污染、记录白盒读取负载，请独立裁判按纯终端受众体感打分并毫不留情列出第 1 名的真实短板。
7. **一字未改完整原稿交人类终审，并反哺沉淀**：AI 盲测结果一律只记 `QUALITY: OBSERVE`，必须把未改一字的完整成品原文交创作者肉眼/真耳终审定音；确认通过才正式收官记 `QUALITY: PASS`，若暴露出新坑或跨品类通用规律，诚实记 `FAIL` 排障后反哺回写进本框架经验层，让下一个 Skill 直接站上更高的起点。

## 七、使用原则：让框架赋能构造，而非制造官僚负担

1. **按改动规模选深度**：
   - **新建、整体重构、全局审查**：实质穿透全部 16 个交点并逐条核对第四、五节的核心构造与进化律，查清立意海拔、四维共振、审美质地、层级非对称分工与横轴缺环，顺手清扫子技能残留的旧时代紧箍咒。
   - **局部补丁、单点修订**：深审受影响的交点及其直接上下游闭环，其余交点只核对保护项、授权与接口未受损；若局部修订反复引发钟摆震荡，立即升级为追根溯源与单变量隔离探测。
2. **紧凑融合入工作语言，不机械照抄 16 格死标题**：
   - 4×4 十六交点与横轴四元闭环是设计者手里的 X 光透视坐标与规则质检标尺，不是要求每个 Skill 机械套印 16 个重复小节标题。
   - 写进 Skill 正文时，按该领域最自然的工作流编排章节，但在每一核心模块内用精炼高密度、零锚词污染的专业语言把**目标、判断（含显式理论标尺）、行动（含轻重次序）与结果（含真实感官验真）**全部写实闭合。
3. **与强模型时代的定本质 → 除限减负 → 升维增优合一**：
   - **看灵魂与判断**：先锚定四阶立意海拔、双向之雅底线与高密度跨题材判断理论，不被历史防呆规则、禁词表和防御性语体锁死。
   - **看筋骨与行动**：果断清除前沿强模型原生就会的基础常识和事前数独式微操，只保留极轻前置定盘、高阶对标校准、核心母体启发、三级风格非对称突出与成稿后轻度扫疤。
   - **看表皮与结果**：坚持单变量隔离探真与随认知同步升维的盲测标尺，结合跨题材/跨风格隔离留出盲测、脱标风格盲辨与人类真实感官终审，确保每一轮进化都带来经得住肉眼与真耳检验的真实跃升。
