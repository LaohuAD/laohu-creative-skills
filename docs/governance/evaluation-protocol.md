# 评估、盲测与验证协议

本协议是老胡造梦技能仓库**维护验收、A/B 盲测对照、正式人类标尺比较与防污染管理**的唯一顶层真源。仅在仓库维护、能力重构、评测校准或正式质量比较时读取；**普通日常创作任务不加载本协议，也不强制增加评分或外部测试步骤**。

---

## 1. 证据维度与状态口径（全仓统一）

报告任何检查、验证或质量结论时，必须将**四类证据维度**与**四种结论状态**分开标明，不互相替代：

### 四类证据维度
- **`STRUCTURE`（结构）**：文件存在性、frontmatter、路径、相对链接、JSON/Python 语法、展示顺序与版本一致性（如 `python3 tools/check_project.py`）。
- **`ROUTE`（路由）**：真实自然语言请求能否命中最合适的公开入口、正确触发内部子级并加载必要资源。
- **`BEHAVIOR`（行为）**：独立执行者在真实输入和最终文件下，是否按预期做出关键判断、条件切换、边界保护与产物交付。
- **`QUALITY`（质量）**：最终接收者、真实媒介、专家或盲测对照结果证明成品质量真正达到或超越目标。

### 四种结论状态
- **`PASS`**：在所声明的范围与条件下，相称证据满足判据。
- **`OBSERVE`**：已有观察或试跑记录，但证据不足以定论（例如同一修改者的主观自评、未经人类校准的 AI 暂评）。
- **`FAIL`**：在所声明范围内已观察到目标差距或违反判据。
- **`UNKNOWN`**：相关范围未检查，或缺少相称证据。

### 三条铁律
1. **静态检查只证 `STRUCTURE`**：`check_project.py` 通过绝不能宣称 `ROUTE`、`BEHAVIOR` 或 `QUALITY` 通过。
2. **已知失败不被缺证覆盖**：已观察到目标差距必须记 `FAIL`，不得因其他范围未测而改记 `UNKNOWN`；修改者自评最高记 `OBSERVE`。
3. **目标与成绩分开**：把顶尖人类完成度或稳定超越纯原生模型当作设计目标，但必须凭相称成品与接收证据声称达成，不能靠规则写得厚、引用知名理论或一次 AI 自评自证。

## 2. 隔离 A/B/C 盲测、自适应标尺与防负进化门禁

重构或进化 Skill 与规则后，验证新版既不被多余限制拖累、又能稳定超越纯原生模型（杜绝越改越笨的负进化），按以下协议实施：

### 2.1 隔离三向对照与匿名盲评纪律
1. **固定变量**：同一任务提示词、同一份原始材料、同一基础模型与工具条件、同一输出范围；**A 组（纯原生 0 规则）/ B 组（改前旧版）/ C 组（优化新版）**在**彼此隔离的全新会话窗口或独立子 Agent** 中运行（临时导出的改前基线夹具放 `.cache/validation/`，测完即清）。
2. **禁止信息泄漏**：给执行者的输入只含普通用户请求与允许材料，**不得附带本轮重构讨论、设计意图、评分重点、理想答案或 `expected_behavior`**。若运行中临时给了改变核心方法或关键取舍的额外指导，该次结果只能记为有指导表现，不能冒充文件独立能力。
3. **纯终端真实受众体感标尺与同步升维（严禁内部术语打卡）**：盲评维度必须从本次目标的**第一性原理本质标准与挑剔真实受众的直接体感**动态派生，并随对本领域的认知突破同步升维（防评测维度停留在旧合规指标而漏考立意海拔、四维共振、情感电压、脱标辨识度与真实感官冲击），**严禁将新加的内部规则术语塞进打分表充当打卡项**，防止机器评委因天然偏爱工整安全书面稿制造假阳性：
   - **直出创意与传播类**（写作、标题、封面文案、故事、剧本、小说、歌词）：重在首眼钩子与立意海拔、双向之雅与情感电压、活人呼吸感与 80/20 素底点睛、脱标风格盲辨、承诺兑现、**媒介原生格式纯净无过程废话混入及严守用户指定固定格式**；不拿写实新闻标尺误杀合法隐喻、情景故事与心理钩子；
   - **提示词中继生成类**（生图、多视角资产、封面出图、AI 视频、AI 音乐/声线）：纸面盲评只查四维物理转译完整度、零物理/光影冲突与无不可渲染抽象心理词；**最终质量必须以实际渲染出的成图、成片或成音盲评与人类肉眼/真耳终审定音**，严禁拿提示词文采代替真实成品质量；
   - **上游规划简报与精准判断类**（前置 `brief`、选题、找茬、分析、拆解）：重在三态前提穿透、开篇海拔总断与最早根因穿透力、保护好资产不磨锋芒、取舍清晰度、交接下游洁净防反向污染、写实证据边界、自然母语人话与 **3 秒一眼扫清的结构化扫读版式（清晰层级、对照表、推荐排序与重点加粗，无紧凑文字墙）**；
   - **确定性工程与工具类**（归档、脚本、编译、音视频管线、安装更新）：重在零歧义接口、一次跑通率、安全授权/路径隔离/可恢复性、格式严丝合缝；
   - **元治理与规则构建类**（改写其他 Skill/规则）：须做**双阶段验证**（阶段 1 评规则自身四元闭环、理论留运行态、零锚词污染、去棘轮与跨子级扫残；阶段 2 独立执行者拿改后规则实跑全新留出任务，验证下游成品真实变好）。
4. **拉丁方匿名盲评、零格式污染与硬边界一票否决**：打包盲评材料前逐份核查零格式残缺与来源残留，评审时采用**拉丁方乱序换位**消除位置偏置，移去制作解释与自我辩护，先逐维引证具体原句/行为事实打分与挑刺（包括毫不留情指出排名第 1 名的具体短板），再解盲汇总；同步记录白盒客观负载（实际读取字节数、文件数、耗时，必要时查思考字节以排查事前填字数独损耗）。任务范围、锁定项、写实事实边界、安全授权与硬格式（含用户或领域明确约定的固定输出格式契约）属不可抵消项，破损时直接扣判或记 `FAIL`，不以平均分掩盖。
5. **诚实记边界与一字不改原文交人类终审**：保留失败与打回记录，不挑最高分个案冒充稳定水平；AI 盲评最高记 `QUALITY: OBSERVE`，最终质量验收必须将 **A/B/C 一字不改的代表性完整原始输出**交由人类肉眼或真耳终审，确认通过方记 `QUALITY: PASS`。

### 2.2 自适应分级实证与防负进化闭环（进化放行门禁）
- **前置 · 单变量隔离探真（重大底层转向适用）**：面对颠覆性理论假设、审美路线大转向或怀疑旧规则成隐形天花板时，先在 `.cache/validation/` 剥离干扰做单变量隔离实验，交创作者肉眼或真耳确真后，再融写正式文件进入下方对应级别的正式盲测。
- **一级（纯确定性/机械维护）**：改错字、修死链、调脚本/Schema/UI 字数、不改模型判断逻辑 → 跑 `python3 tools/check_project.py`（动工具/发现加 `--test`）及受影响确定性单测，全绿即可放行。
- **二级（局部规则/行为修订）**：增删改关键判断、触发边界或局部方法 → 静检通过 + 隔离定向对照测试（至少 A vs C，改旧规则必含 B，1 道典型真题 + 拉丁方匿名盲评 + 白盒负载）；确认 C 净胜且无明显新束缚方算完成进化。
- **三级（新建 / 整体重构 / 共享规则大改）**：静检通过 + 完整隔离三向盲测（A vs B vs C，至少覆盖回归痛点题 + 全新零污染留出题 `H` 防过拟合；含多风格三级子技能时增做脱标风格盲辨）。
- **不合格必须打回（防负进化铁律）**：若实证表明 **C 未稳胜纯原生 A、核心表现反不如旧版 B，或暴露明显新短板/残余束缚**，**绝不宣称完成进化**——必须打回查明根因、重新优化并复测（最多自主打回迭代 **2 轮**；2 轮后仍存负进化或方向取舍分歧，带完整实测证据暂停，交用户拍板方向或回滚至改前恢复副本）。

## 3. 正式基准评估与 L/C/D/H 防污染规则（仅用于正式评测集建设）

只有在建设长期评测集、校准评分协议或开展正式人类标尺基准测试时启用本节；日常创作与单次盲测无需套用。

| 角色 | 用途 | 可见范围与防污染红线 |
|---|---|---|
| **`L` 学习集** | 提炼方法、讲解典范，可提供日常取法素材 | 建设者与生成者可见；不能据此宣称通过未见测试。 |
| **`C` 校准集** | 校准评分标准，对齐评审者与真实人类判断 | 评审建设者可见；不作为最终能力成绩。 |
| **`D` 开发集** | 暴露规则问题、反复对比调优 | 开发者与审查者可见；一旦用于改规则，即不再属于留出材料。 |
| **`H` 留出集** | 最终检验未参与优化的新任务与泛化能力 | 严格隔离保管；生成者只拿任务输入，绝不可接触留出答案或标尺。 |

- **污染降级原则**：只要某作品或同一作品家族进入生成上下文、检索或被用于修改规则，同一评估中即永久降级为 `L` 或 `D`，不得继续充当 `H`。
- **人类标尺真实性**：称作人类标尺须具备可核验的人类作者来源、完整可读原文/媒介单元与必要上下文；公开发表、高播放、点赞、获奖或模型熟悉度只能作为选入背景，不能单独证明顶尖质量或人类原创身份。
- **行为数据边界**：点击、停留、点赞、分享等指标只在其真实定义与传播窗口内作行为记录，不直接反推唯一因果或替代作品质量本身。
