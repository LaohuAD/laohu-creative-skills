#### 问题 C3【自媒体信息流封面“防低俗有余，抓人武器不足”】：缺少系统化的“0.5 秒滑屏拦截心理学、五大高转化视觉母题与主流平台真实裁切安全核法则”

- **明确批评**：[laohu-cover-social/SKILL.md](../../../.agents/skills/laohu-cover/skills/laohu-cover-social/SKILL.md) 和 [design-composition.md](../../../.agents/skills/laohu-cover/references/design-composition.md) 反复提醒“别套黄白大字/惊讶脸、别承诺提升点击率”，这很好；但作为自媒体封面专家，**不能只讲“什么是俗套”，更必须掌握“不俗套却让人 0.5 秒停下手指”的顶级传播视觉方法论**！当前存在三大盲区：
  1. **缺“0.5 秒滑屏拦截黄金三角 + 拇指眯眼测试（Thumbnail Squint Test）”**：手机信息流里封面往往只有 3–5 厘米宽，设计时必须强制按“**① 一眼视觉钩子拦截（Hook）→ ② 半秒秒懂价值/冲突（Clarity）→ ③ 好奇缺口驱动点开（Curiosity Gap）**”推演，并做“缩小到 1/6 宽度眯眼只看色块与 3–6 个核心大字能否瞬间读懂”的硬检查；
  2. **缺五大非低俗、高传播力的正向封面视觉母题库**（让 AI 面对不同内容立刻选出最狠的高级抓手，而不是千篇一律“上方大字+下方配图”）：
     - **母题 1 — 强反差对照型（Visual Contrast / Before-After）**：好与坏、旧与新、昂贵与低成本、渺小与庞大的同框对照，一眼无需解释即见张力；
     - **母题 2 — 好奇缺口/聚焦揭示型（Curiosity Gap / Spotlight）**：展示 80% 震撼场景或结果，用局部放大镜、高亮圈选、光束或遮挡制造最勾人的 20% 悬念点；
     - **母题 3 — 结果前置实证型（Outcome Proof Hero）**：把最惊艳的成片效果、成品实物、真实对比曲线或惊人数字直接放大成主角，让人先信后看；
     - **母题 4 — 一眼视觉隐喻型（One-Glance Metaphor）**：用一个日常具象物件（如拆开的瑞士军刀、被剪断的绳结、卡住齿轮的回形针）瞬间翻译枯燥抽象的技术/方法概念；
     - **母题 5 — 极简大字权威宣言型（Typography-as-Hero）**：当信息流全都是花哨人脸与杂乱图片时，反向用极大尺度的精炼中文展示字块 + 高反差极简底色/留白形成“降维视觉静音区”，靠力量感与高级感反杀；
  3. **缺主流中文平台真实 UI 遮挡与裁切“安全核”结构法则**：[SKILL.md](../../../.agents/skills/laohu-cover/SKILL.md) L101–111 只泛泛提醒“注意平台裁切、默认 5% 边距”，没有落地中文自媒体创作者每天必踩的真实裁切坑：
     - **微信公众号头图（2.35:1）的双重画幅宿命**：在头条展示 2.35:1，但一旦被分享卡片或放次条/消息列表，会自动**从正中央硬切成 1:1 正方形**！因此必须默认执行 **“中央 1:1 安全核法则”**（最核心大字与视觉钩子锁定在中央正方形安全核内，左右两侧仅延展氛围与次要支撑，确保切完 1:1 依然是完美封面！）；
     - **视频流封面（B站/YouTube/视频号 16:9 或竖版 9:16）**：右下角固定存在**时长角标/进度条遮挡区**，竖版底部 20% 与右侧边缘存在**标题文案与点赞评论按钮遮挡区**，核心文字与主体眼部必须主动避让！
- **本项结论**：`FAIL`（自媒体封面最核心的“0.5 秒滑屏穿透力”与“真实平台裁切存活率”缺少正向行业方法论支撑）。

#### 问题 C4【信息图/知识讲解图过偏“学术图论”，缺少“认知负荷预算、视觉隐喻容器库与 AI 底图/矢量文字双轨交付法”】

- **明确批评**：[relationship-diagrams.md](../../../.agents/skills/laohu-cover/references/relationship-diagrams.md) 与 [laohu-cover-infographic/SKILL.md](../../../.agents/skills/laohu-cover/skills/laohu-cover-infographic/SKILL.md) 非常严谨，但画出来的图容易沦为“干巴巴的矩形框 + 连线箭头 + 密集小字”，缺少让普通读者和专业读者都**过目不忘、秒懂传播**的三大信息设计法度：
  1. **缺认知负荷硬预算（Miller's Chunking & Scannability）**：单张信息图主板块严格控制在 **3–5 个认知组块**，单节点核心标签力争 **≤ 6–10 字**、短解释 **≤ 18–25 字**，杜绝把一整篇 1,500 字文章硬塞成“密密麻麻的 PPT 墙”；
  2. **缺五大高记忆度“视觉隐喻容器（Visual Metaphor Containers）”**：面对常见知识逻辑，优先用人类自带空间直觉的视觉容器替代千篇一律的方框箭头——**冰山模型**（显性表象 vs. 隐性底层）、**漏斗/管道模型**（层层筛选与转化）、**天平/杠杆模型**（利弊权衡与关键支点）、**同心圆/洋葱层模型**（核心本质→外围表现）、**剖面/解剖透视图**（复杂系统内部构件拆解）；
  3. **缺面向 AI 生图局限的“分层交付工作流接口”**：虽然文本提到“模型写复杂中文容易错字，可建议分层后期”，但没有给出真正省事的**可执行双轨方案**：
     - **轻文字概念图（总字数 ≤ 20–30 字、短标签为主）**：直接走 AI 中文生图轨，严格控制短词与大字号留白；
     - **中/重文字结构图与数据图（多节点/精确数值/长说明）**：明确提供**两条可立即执行的落地方案**——① **“AI 无字留白插画底图提示词 + 精确文字图层标注清单”**（供 Canva/Figma/PS 3 分钟贴字）；或 ② **建议转交代码矢量排版渲染**（如联动 `laohu-htmlshow` 用纯净 SVG/HTML 100% 精准渲染零错字矢量信息图！）。
- **本项结论**：`FAIL`（信息图缺乏现代视觉化隐喻、认知负荷限额与切实可行的防错字落地路径）。

#### 问题 C5【海报构成法（`artwork-composition.md`）样本过旧偏窄，缺少现代五大高阶平面海报语法】

- **明确批评**：[artwork-composition.md](../../../.agents/skills/laohu-cover/references/artwork-composition.md)（82 行）思路极好，但仅引述了 1955 年的两张经典案例（Saul Bass 与 Josef Müller-Brockmann），缺少当代作品发布/活动/品牌海报高频且极出片的正向现代平面构成语法：
  1. **字图深度穿插破框（Depth Overlap / Typography Interweaving）**：大标题穿过主体背后、前景局部（如人物手部、飞散物体、烟雾）自然压过部分非关键笔画，一秒制造震撼电影级三维空间感；
  2. **现代瑞士网格与大留白秩序（Swiss Neo-Grid）**：非对称理性分栏 + 极细hairline分割线 + 精准对齐的辅助信息角标，打造极高辨识度的科技/艺术/展览高端感；
  3. **东方留白意境与竖排韵律（Eastern Negative Space & Vertical Rhythm）**：大面积意境留白 + 竖排主标题错落呼吸 + 印章式单点强调色，专克国风、文学、民谣、电影艺术海报；
  4. **当代杂志编辑风（Editorial Magazine Layout）**：全幅高质感影像/插画 + 顶部通栏杂志刊头式标题 + 四角精炼信息锚点；
  5. **视觉双关与负形同构（Figure-Ground Visual Pun）**：主体轮廓内部直接生长出次级场景或意象（如人影剪影里藏着城市夜景或山海），极具收藏与转发欲。
- **本项结论**：`FAIL`（海报正向平面设计语言库偏窄偏旧，制约跨题材创意发挥）。

  - **操作权重分层（Primary CTA 唯一视觉高地 > Secondary 次操作 > Ghost/Text 弱操作）**，防止全页面所有按钮一样亮导致视线迷失；
  - **交互状态真实视觉区分**（默认态 / 悬停聚焦态 / 展开弹层态 / 空状态 / 报错校验态的清晰差异与非遮挡保护）；
  - **防 AI 生成“假精美不可实现 UI”红线**（避免无法响应式的奇异异形布局、不可读的低对比玻璃拟态文字、过度霓虹光污染背景）。
- **本项结论**：`FAIL`（UI 关键帧缺少界面设计专业内核，容易停留在流程合规而界面审美平庸）。

## 第二部分：`laohu-analysis` 四维正向传播视觉升级与零损耗重构方案

### 4. 传播与信息视觉的四维正向约束体系（灵魂 / 筋骨 / 血肉 / 表皮）

紧扣 `laohu-cover` 的本质使命——**在真实传播与阅读场景里，让观者 0.5 秒被钩住、3 秒懂结构、一眼记主题、无痛能落地**：

#### 一、灵魂层（真实传播任务与 0.5 秒视觉钩子）
- **核心铁律**：**用途定战场，材料定钩子**——先精准落位四大战场之一（自媒体封面 / 信息图与篇内图 / 海报 / UI 关键帧），绝不拿信息流套路做学术图，也绝不拿枯燥说明书做信息流封面。
- **四战场灵魂标准**：
  - **自媒体封面**：以五大高传播视觉母题落地“视觉钩子拦截 → 价值秒懂 → 好奇缺口”；
  - **信息图/篇内图**：以“焦点问题 + 认知负荷预算（3–5 组块）”落地“看图比读 1,000 字更快懂本质”；
  - **海报**：以作品/品牌/活动独有锚点落地“一眼辨身份 + 一眼记气质 + 仅在需要时给清晰行动入口”；
  - **UI 关键帧**：以用户操作任务落地“真实可用、状态清晰、组件可复用、审美高级”。
- **硬验收标准（遮盖自明测试）**：遮住解释说明与聊天上下文，只看设计方案的画面主体与文字，观者能否在 3 秒内说出“这是讲什么的 / 为什么值得看 / 关系是什么”？不能则灵魂未过关。

#### 二、筋骨层（信息拓扑、视觉隐喻容器、平台安全核与 UI 空间系统）
- **核心法度 1 — 信息图“视觉隐喻容器 + 认知减法”**：优先用冰山/漏斗/天平/同心圆/解剖透视等空间隐喻承载真实拓扑（包含/筛选/权衡/层级/构造），单张严格守住 3–5 主组块与短节点标签，彻底告别“密密麻麻同款卡片墙”。
- **核心法度 2 — 封面与海报“网格 + 平台安全核”**：保留原有严谨的网格/标题轴与 `layout-typography.md` 容量反算公式，增补**公众号 2.35:1 中央 1:1 安全核**、**视频封面右下角时长区避让**、**竖屏底部 20% 与右侧按钮区避让**三大实战安全核铁律。
- **核心法度 3 — 海报现代五大构成语法**：完整囊括字图深度穿插破框、瑞士理性网格、东方留白与竖排韵律、杂志编辑风 Editorial、负形同构双关（并与原 Saul Bass / Müller-Brockmann 构图体系无缝融合）。
- **核心法度 4 — UI 关键帧空间与层级骨架**：8pt 呼吸节奏、清晰表面层级（背景底面 → 内容卡片 → 悬浮弹层）、唯一 Primary CTA 视觉高地、交互状态零遮挡保护。
- **硬验收标准（缩略图 + 安全核双查）**：缩至手机真实显示宽度无关键笔画粘连、无主副层级崩塌；按目标平台裁切框套入无核心字/主体被切。

#### 三、血肉层（中文展示字形张力、色彩角色分工与图文协同表演）
- **核心法度 1 — 中文排印“可读性底线 × 展示张力上限”双审**：
  - 保留原有 `FP01`–`FP08` / `LD01`–`LD03`、`CLREQ` 中文禁则、语义断行与字号反算真源；
  - 强化**字形轮廓与主体气质同构**（厚重几何黑体配硬核技术、高反差衬线/竖排配人文作品、笔势手写配温度故事、字图共边/穿插咬合增强整体感）。
- **核心法度 2 — 色彩职责三分离**：
  - 保留 `CP01`–`CP12` 与 WCAG 2.2 字底对比核查真源；
  - 严格分离“字底可读对比”、“信息类别区分编码”与“第一注意焦点引导”，且引入 **Gurney 色域收束思想**——即使高冲击封面也通过主底色+点睛强调色建立高级秩序，告别廉价五彩大字报。
- **核心法度 3 — 图文互补与证据诚实**：文字与图像分工协作（不无脑重复同句，也不因追求隐喻导致断联），概念表达与真实实证边界绝对清晰。

#### 四、表皮层（双轨纯净编译、中文默认、正向画面描写与零错字分层指引）
- **核心法度 1 — 双轨纯净编译协议（彻底根治 C2 痛点）**：
  - **轨道 A（AI 生图直出轨，默认中文输出）**：代码块内 100% 为**高视觉权重、纯画面与纯文字呈现的正向描写**，彻底剥离“权限/职责/第一文字层级/待核”等内部管理词汇（全部放回块外“效果说明”），杜绝生图模型把管理词印成乱码！用户硬禁止红线集中清晰表述且与正文兼容；
  - **轨道 B（可编辑精排 / SVG-HTML / 前端制作轨）**：用户明确精控、系列固定规范、多字复杂信息图或前端实现时，展开精确坐标比例、FP 字族、CP RGB、字号与图层规格。
- **核心法度 2 — 复杂中文与精准图表的防错字双出路**：当信息图文字密集（超过 AI 生图可靠渲染上限，如 > 25–30 字或多节点精密数值）时，明确提供：**① “无字留白高质感底图提示词 + 精确叠加文字表”**；或 **② 建议转由 `laohu-htmlshow` 以纯净 SVG/HTML 矢量代码 100% 精准渲染**。
- **硬验收标准（模型输入纯净度测试）**：通读轨道 A 提示词代码块，问“如果生图模型把里面出现的抽象词字面画出来，会不会出事故？”——只要包含“权限/举证职责/非实证概念/第一文字层级”等词，一律不通过，必须移出块外！
