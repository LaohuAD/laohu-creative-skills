## 一、边界与保护铁律（零信息量损失原则）

本轮优化的核心是**「增密视听情绪判断 + 提升有效信噪比 + 补齐混音消费者」**，绝不做以删减细节换篇幅的「假瘦身」。执行 AI 必须严守以下 5 条保护铁律：

1. **零信息丢失**：既有有效的专业条件、参数、反例、例外和边界（包括：用户锁定原声/指定曲目/静音/明确禁止原创优先级最高；真实物理拟音不以粗糙正弦或白噪冒充；共享 `timeline.js` 唯一事件时钟；源内 `hitpoint` 与画面相位分别换算；唯一最终混音链及工作区编辑快照优先；TTS 须用授权原稿；付费外部生成另需授权；纯文本无听审能力模型的防御回退）**全部原样保留，不得删减或弱化为抽象口号**。
2. **分工清晰不越界**：
   - `laohu-arrangement` 继续保持其作为**完整独立歌曲创作、AI 音乐编曲提示词、演唱与乐谱**主阵地的完整信息量；
   - `laohu-motion` 承担**动画视听场景下的音乐与音效情绪设计、参考选库/原创合成决策、多模态实听迭代与最终混音落地**（复用 Arrangement 的底层检索/剪辑工具，不复制整套歌曲编曲文档）。
3. **旧兼容只隔离、不删除**：若触及旧 Remotion / Film `/2` 兼容条款，仅做路径归档或清晰条件标注（旧工程仍可完整读取），绝不删除有效兼容信息，也不让旧包袱稀释新 Showreel 动画的上下文注意力。
4. **受保护原版闭包不动**：`.agents/skills/laohu-motion/templates/runtime/laohu-showreel/`（含 `references/sound.md`）与 `source-lock.json` 保持原字节不变。
5. **修改前先留恢复副本**：所有待改文件写入前先按 `docs/runtime.md` 备份至 `.cache/restore/<task-id>/`。

## 二、问题诊断：当前动画声音链路的 4 个真实短板

基于仓库实测现状（`showreel-sound.md` 14.5 KB、本地 `assets/audio/index.json` 744 KB 含 108 条 SFX 与 15 首 BGM、`laohu-motion/scripts/audio.mjs` 混音消费者）：

1. **缺少贯通「情绪 → 选库/原创 → 同步 → 留白」的统一判断理论**：现有规则把大量精力放在哈希、许可、回执和旧格式门禁上，但在「如何把最终成片情绪辅助到位」「何时该加声、何时该留白」「口播下如何不抢戏」上缺少可操作的专业坐标与判据。
2. **多模态实听自主权已放开，但缺「选库 vs. 原创」决策矩阵与「实听自检标准」**：模型具备真实听审能力后，音频库已定位为「参考库与可选素材池」，但尚缺清晰的专业分工指南（防止滥用合成器做出廉价感，或盲目套用不贴合的成品）和可复查的实听闭环清单。
3. **744 KB 本地音频索引缺少全局 L0 听感星图**：123 条本地音频（108 SFX + 15 BGM）全堆在 744 KB JSON 中，缺乏情绪坐标与分类总览，模型无法像看视觉 L0 星图那样一眼掌握全库声音气质与可用范围。
4. **最终混音消费者存在广播级能力缺口**：`audio-plan/1` 目前仅支持音量增益、淡入淡出和人声窗口 ducking，缺少 **BGM 高通与 `1–4 kHz` 人声口袋微避让（Vocal Pocket EQ）、轻微声像分离（Pan）、以及最终母带两遍式响度标准化（two-pass `loudnorm`）**，导致理论上的「人声清晰不打架」缺少工程抓手。

## 三、引入的核心专业理论与可执行判断标准（全为可落地动作，零空泛术语）

以下 4 套成熟影视/广播/心理声学理论直接转化为动画声音的**选择标准、原创准则与混音动作**，作为 `showreel-sound.md` 的专业核心骨架：

### 1. 视听关系与留白标准（源自 Michel Chion《视听》*Audio-Vision*）
- **三种聆听模式分工（语义 / 因果 / 还原）**：
  - **口播承担词义时先保住承重词**。语义、因果与还原描述听者怎样听，可以同时发生。密集解说先比较无歌词、少主旋律的底床与气口处的短动作声，再从合片验证是否听清。
  - **画面内物件动作走「因果聆听」** → 物件接触、翻页、展开需要**干、近、贴合材质**的真实声音；画外情绪铺底音乐保持**宽、柔、略远的空间感**，两者在纵深上天然分层。
- **声画同步结合（Synchresis）与转折前的留白试听**：
  - 只在**结构转折、核心揭示、物理接触**放高辨识度同步点，禁止逐句/逐元素机械打点（反「米老鼠化」廉价感）；
  - 在全片最重的情绪悬念、沉思或反转句前（如「如果有一天高塔崩塌」），优先评估**提前 0.5–1 秒抽空音乐（本方案的留白试听动作）**——突然的干净寂静往往比砸一个 `impact/boom` 更有重量。
- **附加价值（Added Value）**：声音不只是复述画面已画出的动作，而是补足画面单看缺少的**重量感、温度、材质或潜台词情绪**。

### 2. 同类声音的竞争与跨镜声音剪接（Murch 的混音经验；J/L-Cut 剪接手法）
- **同类声部竞争时给主声让位**。Murch 的“两个半”描述同类声音可能被感知为一组的混音经验。实际判断听众能否辨认本句、本次接触或主旋律。
  - 密集讲解先试 **1 条低密度底床 BGM**，SFX 只在口播气口或核心视觉触点短促切入；禁止「口播 + 强旋律 BGM + 连续 SFX + 明显环境声」四层同时挤在前台。
- **跨段情绪缝合（J-Cut / L-Cut）**：
  - **J-Cut（声先画后）**：下一段新情绪音乐提前 `0.5–1.5s` 在上一段句尾气口柔和渗入，自然牵引情绪转场；
  - **L-Cut（画换声留）**：上一镜自然尾音或混响越过硬切拖尾 `0.3–1.0s`，消除「PPT 切页断层感」。

### 3. 情绪二维坐标与长片弧线（源自 Russell 效价–唤醒度模型 *Valence–Arousal*）
消除「科技感/高级/大气」等不可执行的模糊形容词。规划动画声音时，先为各段落标定 `(Valence 效价/愉悦或不悦, Arousal 唤醒度/能量)` 坐标，再直接驱动选曲与原创编配：

| 维度 | 档位 | 选库筛选特征 & 原创合成参数（`score.mjs` / `Tone.js`） |
|---|---|---|
| **唤醒度 Arousal**（推进与密度） | **低**（沉思/冷静观察/留白） | 无鼓或极稀脉冲、长音/稀疏分解和弦、慢起音（Soft Attack）、低音符密度 |
| | **中**（清晰讲解/稳步展开） | 轻律动或拨弦/马林巴轻脉冲（85–110 BPM）、稳定中低频托底、克制切分 |
| | **高**（核心揭晓/高潮/号召） | 清晰律动骨架、分层累加织体、明确动态起伏与结构重拍 |
| **效价 Valence**（愉悦或不悦；以下配器仅供试听） | **暗/悬念/警醒** | 持续低音 Pedal、小调/Phrygian/半音张力、偏暗低通滤波、深冷空间 |
| | **中性/理性/客观** | Dorian 调式、四度叠置（Quartal）、单和弦音色呼吸、极简电钢/拨弦/轻敲击 |
| | **暖/笃定/共鸣** | 大调 / Lydian / Add9、温暖原声钢琴/柔和铺底、开阔自然混响 |

**长片声音设计**：时长 > 2 分钟且在本轮设计声音的动画必须在 Brief `<direction>` 写出 **3–5 段声音情绪弧线（`audio-arc`）**，明确哪段换曲、哪段增减声部、哪段抽空留白；禁止用同一段短循环平铺整片。

### 4. 人声清晰度口袋与广播响度标准（心理声学频谱掩蔽 + ITU-R BS.1770 / EBU R128）
- **源头保护「人声口袋（Vocal Pocket）」**：
  - `150–400 Hz`（胸腔温暖区）：避免厚重低频 Pad 长期轰鸣；
  - **`1 kHz – 4 kHz`（辅音咬字与可懂度生死线）**：选库和原创编曲时，优先选「两端托、中间空」的织体，避开在 `1–4 kHz` 与人声死磕的亮色连续主旋律；独白通常保持中央声像（也可为立体声中央结像），BGM 适度立体声展宽并可在 `1.5–3.5 kHz` 施加温和微凹（−2 ~ −3 dB）与高通滤除无用超低频（80–120 Hz）。
- **响度与防抽吸（Anti-Pumping）标准**：
  - 本项目网络动画可选的完整节目目标（EBU R128 的广播参考为 −23 LUFS，明确的交付规格优先）：`−14 ± 1 LUFS-I`，真峰值 `≤ −1.0 dBTP`；
  - 口播持续段 BGM 相对人声压低约 **`16–22 dB`**（按实际织体密度实听微调）；
  - **分级停顿避让**：短气口（`< 0.6s`）靠 `holdSec` 保持压低，绝不反复拉高造成抽吸感；仅在 `≥ 1.2s` 真实语义停顿或无口播过渡段，平滑回升 `4–8 dB` 接管情绪。

## 四、选库参考 vs. 自主原创决策矩阵 + 多模态 4 步实听闭环

在遵循本仓既有「按真实听审能力分两条分支」的前提下，给**具备真实音频听审与情绪识别能力的多模态执行者**提供精确操作准则（无听审能力模型维持既有成品优先 + 明确授权保护分支）：

### 1. 选库 vs. 原创决策矩阵（前提：用户未锁定曲目、未禁止原创、不涉未授权付费）

| 声音类别 | 推荐优先路线 | 执行依据与质量底线 |
|---|---|---|
| **真实物理拟音 SFX**（纸滑、木碰、玻璃、布料、翻页、脚步） | **优先实听本地/外部真录成品**（尾音或时长不合用 `audio-edit` 裁切淡变） | 真实麦克风录制的物理瞬态远胜代码滤波；不得用粗糙正弦或白噪敷衍自然 Foley |
| **强卡点 / 设计感定制音效**（逐层升阶谐波、数字滚动 tick、与镜头严丝合缝的 whoosh/riser/pulse） | **可自由原创优先，或与成品比选**（`score.mjs` / `Tone.js`） | 按 `timeline.js` 精确对齐时长与音高变化，实听不顺耳即刻调参重渲，比硬凑素材更贴合 |
| **长片多乐器原声 BGM**（温暖原声钢琴、木吉他、室内弦乐、纪实质感） | **先实听本地/外部成品库**；若缺贴合某段情绪坐标 `(V, A)` 的成品，可参考曲库用 **Tone.js + 高质量采样（如 Salamander 钢琴）+ 柔和铺底原创该段**，或成品与自创按段落混搭 | 发挥真录母带上限，同时补齐曲库情绪空缺；确保 8 分钟长片有完整情绪弧线且不单调 |
| **短片 / 极简电子 / 界面 / 几何抽象 BGM** | **高度自由**：参考曲库与风格声音调色板，选用成品或 `score.mjs` / `Tone.js` / `layer` 原创均可 | 重点看动机辨识度、情绪贴合度与实听舒适度 |
| **重情绪转折 / 密集金句处** | **主动对比「留白抽空」与「铺底」** | 实听哪一种更能托住该句情绪重量，留白更强则坚决留白 |

### 2. 多模态执行者「4 步实听自检闭环」（交付人类前必做）
具备原生音频/视频读取能力的模型，必须实际读取并听审真实音频文件（而非仅看文件名、波形或 LUFS 数值），并在交付说明中如实写明**模型实听覆盖的区间与调整结果**（仍与最终人类品味终审 `QUALITY` 分开记账）：

1. **单轨质感听审**：实听选中的成品或原创 WAV——排查刺耳高频、塑料/玩具感、loop 接缝咔哒声或跳拍、验证情绪坐标 `(V, A)` 真实贴合；
2. **人声口袋听审**：抽听 2–3 处语速较快或语气低沉的混音叠加段——核对首字是否被吞、`1–4 kHz` 咬字是否清晰、短气口 BGM 是否抽吸；
3. **同步点与缝合听审**：结合带声样片实看+实听关键接触/揭示帧与段界——确认 SFX `hitpoint` 精准咬合画面、跨段 J-Cut/L-Cut 顺滑无断崖；
4. **情绪弧线抽听（长片必做）**：抽听「开场建立 / 中段转折 / 结尾收束与尾音」——确认无听觉疲劳、结尾尾音干净收束不被硬切截断。
