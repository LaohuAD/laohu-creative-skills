## 2. 已确认的 7 项核心差距与限制（明确批评—材料依据—本项结论）

### 问题 S1：【严重方法论偏科】最常用的“卡通/动画/风格化人物群像、服装造型、道具工业、场景环境叙事”正面美术法度极度单薄，反被窄众“写实怪物分支”占去半壁江山

- **明确批评**：当创作者要为动画短片（如卡通贺岁片）、二次元/绘本/3D 手作/国风/科幻/现代剧设计真正让人一眼记住的视觉资产时，`laohu-assets` 的核心方法库里**几乎找不到系统的概念设计方法论**；真正写得最细的竟然只是一套面向“写实恐怖/奇幻怪物”的物种拼接流程。
- **材料依据**：
  1. [asset-design-methods.md](../../../.agents/skills/laohu-assets/references/asset-design-methods.md) 全文 71 行：覆盖全类别（人物、服装、道具、场景、材料）的跨类别设计方法一共只占 **L7–29 共 22 行高度概括的条目**（每类仅 1–2 句话）；而 **L31–71（超过 58% 篇幅）** 全部用来讲“原创生物设计分支”（山魈脸、螳螂虾螯、亡灵沼泽保存、70/30 真实解剖、战斗兽甲虫等）。
  2. [reference-image-methods.md](../../../.agents/skills/laohu-assets/references/reference-image-methods.md) 全文 248 行：**L23–179（高达 156 行、占全文件 63%）** 全部用于“写实生物灰色黏土→人类供体→皮肤处理”流程，**L180–248（68 行）** 全部用于“实拍照片级空场景”；留给通用多图参考与跨风格设计的原则只剩开头 **L7–22 共 15 行**。
  3. **缺失的 6 大行业正统美术法度**：
     - 缺**角色形状语言与剪影阵容法**（Shape Language 圆/方/三角性格映射与反差、头身比梯度、Big–Medium–Small 大中小体量节奏、群像全黑剪影身高差检验）；
     - 缺**色彩 60-30-10 配比与黑白灰明度分组法**（James Gurney *Color and Light* / Pixar Color Script 的 1-2-3 Read 明度分层，确保主次一目了然）；
     - 缺**服装叙事造型学**（内/中/外/配饰四层功能、面料重量垂坠逻辑、活动余量与人物生活痕迹）；
     - 缺**道具功能叙事与人机尺度法**（握持尺度锚点、机械/奇幻构造自洽、历史包浆/修补故事层）；
     - 缺**场景环境叙事与电影纵深法**（前中后景三层构图、视觉引导线、无人空场中的“生活痕迹与权力痕迹”叙事）；
     - 缺**非写实/风格化渲染体系控制法**（2D 赛璐珞线稿与硬阴影、绘本笔触肌理、3D 风格化次表面散射与形面简化、国风墨韵留白、奇幻发光特效与主体分离控制）。
- **本项结论**：如果不把这些正面概念设计法度补进来，AI 做普通剧本资产时只能“字段填写完全合规、边界滴水不漏”，但设计出来的人物、道具、场景容易平庸、缺乏记忆点与视觉感染力。

### 问题 S2：【硬编码外部私有模型】核心 Reference 将特定第三方平台模型名与过时怪癖写死，破坏通用性与可维护性

- **明确批评**：核心参考文件 `reference-image-methods.md` 直接硬编码了外部平台私有模型标识和特定版本的生成缺陷对策，使资产设计规则与特定厂商工具强耦合。
- **材料依据**：
  - [reference-image-methods.md](../../../.agents/skills/laohu-assets/references/reference-image-methods.md) L29, L41–42, L49–51, L67, L75, L98, L125, L150, L157–158, L160, L162–163, L186, L194, L242：反复出现 `seedream_5_5`、`recraft_v4_1`、`soul_2`、`soul_cinematic`、`seedance_2_5` 及诸如“`soul_2` 容易画两个转面图”“`recraft_v4_1` 会在雕塑上写字”“用 `soul_cinematic` 生成两张”等强绑定特定平台与旧版本的指令。
- **本项结论**：用户使用 Midjourney、Flux、Imagen、可灵、即梦或更新代模型时，这些硬编码名称既无法执行，又会在编译普通参考图规则时加载大量无关的 28 KB 噪音。必须将其**剥离出核心参考文件、升级为模型无关的通用工艺流程**，仅把原平台名降格为来源注释或可选历史适配注记。

# 第二部分：`laohu-analysis` 四维正向法度升级与零损耗重构方案

## 4. 视觉与声音资产的四维正向专业约束体系（灵魂 / 筋骨 / 血肉 / 表皮）

将 `laohu-assets` 从“严格连续性场记”升级为“**顶级概念美术总监 + 严谨资产统筹**”，在四个维度建立可执行、可验收的正向行业法度：

### 4.1 灵魂层（全作美术宣言、艺术语系与视觉叙事目标）
- **正向法度**：
  1. **艺术指导宣言（Art Direction Thesis）**：首次进入同作多资产或单件原创资产设计前，先立住 4 项顶层决策——**渲染语系**（真人电影写实 / 3D 风格化动画 / 2D 赛璐珞 / 绘本水彩 / 国风工笔水墨 / 定格粘土等）、**世界物理与材质温度**（粗粝做旧 / 温润手作 / 干净几何 / 华丽奇幻）、**核心情绪色彩气候**、**观众第一眼记忆点（Hook）**。
  2. **同作风格锁（Style Lock 四要素）**：面向同作所有视觉资产提炼一组共享视觉锚词（① 媒介与笔触/渲染质感；② 光影对比与冷暖倾向；③ 造型简化程度与线条/块面语言；④ 色彩饱和度区间），后续编译进每条同作提示词，从源头杜绝“人物 3D、场景实拍、道具 2D”的画风撕裂。
  3. **尊严与叙事服务原则**：一切外观选择服务于剧情处境、人物弧光与观看价值，严禁拿贫穷、反派、年龄或职业标签推导刻板丑陋。
- **灵魂层硬验收标准**：把同作人物、道具、场景的描述并排放在一起，是否像出自同一部电影/动画的同一位美术总监之手？

### 4.2 筋骨层（六大硬核影视/动画概念设计法度）
- **正向法度**：
  1. **人物：形状语言（Shape Language）＋头身比＋大中小体量（Big–Medium–Small）**：
     - 依据性格与戏剧职能为每个核心角色选定主/辅基础几何语言（**圆形/弧线**＝亲和、灵动、暖萌；**方形/稳定块面**＝可靠、厚重、固执、压迫；**三角形/锐角**＝机敏、高冷、犀利、危险）并善用**外形—性格反差**；
     - 明确媒介相称的**头身比梯度**（Q 版 2–3 头身 / 卡通 4–5 头身 / 动画写实 6–7 头身 / 真人 7.5–8 头身）；
     - 同作主角群像必须做**剪影与身高差阵容核对（Lineup Silhouette Check）**：涂成全黑剪影后，仅凭身高差、肩臀比例、发型/头饰外轮廓与站姿重心，3 秒内能否区分每个主角？
  2. **色彩：60-30-10 配比法 ＋ 黑白灰明度分组（Value Grouping / 1-2-3 Read）**：
     - 参考 James Gurney《Color and Light》与 Pixar Color Script 原则：每件正式资产与同作色盘须明确 **60% 主导基调色 ＋ 30% 支撑结构色 ＋ 10% 视觉焦点强调色**（把最醒目的 10% 精准落在脸部附近、胸口或标志性道具上）；
     - 核对**黑白灰明度关系**：把整体想象为黑白灰图，确保主体与背景、脸部焦点与躯干之间有清晰明度分离（避免“颜色花哨但糊成一片中灰”）。
  3. **服装：层次功能造型学（Costume Storytelling）**：
     - 按**内层 / 中层 / 外层 / 功能配饰**组织层次，明确面料重量与垂坠行为（飘逸软塌 vs 挺括廓形 vs 硬质护甲）、角色行动余量（跑跳打斗是否成立），并把故事经历落到特定受力/高频接触部位的克制痕迹上。
  4. **道具：三维功能叙事与人机尺度法（Prop Functional Design）**：
     - ① **人机尺度与握持锚点**（相对人手的大小感、握把/接口位置）；② **构造与运作自洽**（即便奇幻魔法道具也要有可信的受力连接、开启方式或能量载体）；③ **个人历史故事层**（专属修补、刻痕、贴饰、包浆，让道具长在角色人生里）。
  5. **场景：环境叙事与空间戏剧调度（Environmental Storytelling）**：
     - 在保持既有“入口—通道—固定物拓扑”硬基础上，补齐电影美术三法：① **前、中、后景三层纵深层次**；② **视觉引导线与情绪焦点地标**（光影、结构线把目光自然引向叙事中心）；③ **无人状态下的生活/权力痕迹叙事**（通过物件摆放秩序、使用磨损、灯光明暗，让空场自己讲出“谁住在这里、刚发生过什么”）。
  6. **声音身份：声学指纹主次法**（完整继承 `laohu-assets-voice` 与 `voice-handoff-and-output.md`，确保群组声部在音高重心、质地、节奏/咬字上可辨区分）。
- **筋骨层硬验收标准**：
  - **3 秒黑剪影测试（人物/道具）**：抹掉一切花纹与颜色，只看轮廓线，角色身份与道具用途能否 3 秒认出？
  - **黑白灰明度测试（全类别）**：去掉色相只看亮暗，视觉焦点是否仍稳稳落在预设部位？
  - **空场讲故事测试（场景）**：画面里没有一个人，观众仅看空间布局与细节，能否立刻判断出这里的用途、时代与主人的性格处境？

### 4.3 血肉层（身份指纹、材质部位映射与多风格渲染控制）
- **正向法度**：

  3. **全剧状态与变体连续性**（完整继承 `identity-continuity-and-variants.md`）。

### 8.1 必须新增的 9 条正向美术能力评测案例（追加至 `evals.json`，共 56 条）

全部采用普通创作者自然口述，不向模型提示模块名或理论术语：

1. `animation-cast-shape-language-and-silhouette`：给出一个 3 人卡通贺岁动画主角群像（如活泼小女孩、学霸大姐、高冷宅女大小姐），要求“为她们设计可复用人物资产和完整提示词” → 验收：自动调用 `laohu-assets-artdirection` + `laohu-assets-stylized`，角色采用清晰差异化的形状语言（圆/方/三角）、头身比与全黑剪影身高差，且**默认采用自然微侧站姿**而非摄影棚坐低背椅。

3. `realistic-human-still-defaults-to-seated-studio`（零回归对照）：要求为现代都市写实短片设计一位普通成年男主角的单格身份图提示词（未指定姿势）→ 验收：仍保持灰棚柔光、微侧身坐无扶手低靠背椅默认，证明站姿分流未破坏现代写实基线。
4. `prop-functional-ergonomics-and-story-layer`：要求为动画主角设计一件“什么都能装但老乱塞东西的百宝肚兜/旧维修工具箱”道具资产 → 验收：体现人机尺度、受力/开合构造自洽与专属生活痕迹故事层，仍守住本体无手部默认展示。
5. `scene-environmental-storytelling-three-layers`：要求设计一间“年迈村长独居但最疼孙女的除夕羊村小屋”无人场景资产 → 验收：守住无人空场边界，同时具备前中后景三层纵深、视觉引导地标与丰富的生活叙事痕迹（不用人物入画也能读出主人性格与过年氛围）。
6. `stylized-2d-cel-and-3d-no-photo-pores`：分别要求设计一套“2D 赛璐珞动画角色”与一套“3D 粘土手作感角色”提示词 → 验收：成像质量控制自动切换到对应非写实语系（线稿分层/二分影或 SSS/手作笔触），不出现写实摄影毛孔、硬闪或胶片颗粒污染。
7. `creature-specialty-model-agnostic-workflow`：用户明确说“帮我设计一只深海寄居蟹融合古老铁匠的写实原创怪物，按专业三阶段参考流程出设计提示词” → 验收：精准触发 `laohu-assets-creature`，落实 70/30 解剖、单主焦点亮色与模型无关的三阶段工艺（灰模→面部参考→多图绑定皮肤照片化），**不将旧平台名 `seedream_5_5` / `soul_2` 硬塞进通用提示词指令**。
8. `story-and-script-seed-seamless-intake`：输入来自 `laohu-story` 视听种子或 `laohu-script` 制片拆解附录的内容，要求“直接整理并出完整视觉资产提示词” → 验收：直接继承既有 ID/场景名/道具状态变更节点，核对一致性后高效出提示词，不要求用户把完整剧本重新粘贴一遍。
9. `identity-fingerprint-survives-costume-and-state`：先为一个角色建立基础身份，再建立“换冬装＋暴雪战损灰脸”的状态变体 → 验收：基础身份明确的 3–5 条不可变视觉指纹在换装与战损变体完整提示词中 100% 保持不变，且只改授权部位。
