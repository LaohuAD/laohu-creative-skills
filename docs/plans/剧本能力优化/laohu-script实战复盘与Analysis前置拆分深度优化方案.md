## 1. 实战全链路复盘：从口述灵感到五轮迭代暴露的真实规律

在第一波 A1–A7 升级刚落地的最新版本 `laohu-script` 上，我们以一段长达数千字、包含完整剧情脉络与局部开放点的真实用户口述（《无尽棋局》第一集：厌世高智商继承人 × 活泼伴侣型 AI × 桥上以身饲饵反杀舅舅反被同归于尽 × 主神空间无提示五分钟三问一求）开展了 5 轮真实连续创作与纠偏。

下表完整还原了**每轮输入/反馈 → 当时产出症状 → 真实发生的断点与钟摆漂移 → 本轮提炼出的核心规律**：

| 轮次 | 用户输入 / 反馈焦点 | 模型当时的实际处理与症状 | 暴露的深层断点 | 提炼出的正向突破 |
|---|---|---|---|---|
| **第 1 轮** | 提供详细第一集口述灵感与 4 处开放设计点，请求“给我做个剧本吧”。 | 跳过前置灵魂/筋骨/人设校验，直接一步输出完整 4 场正文。<br>**症状**：① 节奏原本饱满有来回，但台词/V.O. 充满论文与法务腔（“信息不对称”“这是筛选不是招待”“跨界具现加形态改造”“语义约束”）；② Luna 排查弹窗变成 IT 工单汇报（“进程栈/总线/显存缓冲”）；③ 桥上三分钟硬塞“爆仓+通缉+众叛亲离+发射导弹”，时间线崩塌且与“以身饲饵”自相矛盾；④ 父母回忆成功能做题戏，灵魂空虚。 | `S2-02`（未拆分前置分析即强行成稿）、`S2-03`（规则密文语体吸附 + 防错合规挤占创作）、`S2-07`（未解包口述时间压缩）。 | 必须先剥离“前置潜伏期”与“今夜引爆点”拉直硬时间线；必须先做深度情感锚点，不能用功能做题戏代替亲情温度。 |
| **第 2 轮** | 指出台词像机器说明腔、时间线不合理、灵魂与筋骨不行；追问是否被规则限制。 | 诊断后按“接地气/口语化”重写全集。<br>**症状**：从论文腔直接钟摆滑向**伪俗语 / 硬拟人 / 市井油腻腔**（“往回摸”“躺进邮箱”“连裤衩都保不住”“死护主车”“往根子上挖就拿四个字堵死”）；Luna 平时讲无关段子（建材老板喊错小三）充话多；主神空间 V.O. 依然逐条剧透，像作者替观众做阅读理解。 | `S2-01`（无防钟摆机制）、`S2-04`（人设只贴形容词标签，未立用词边界与 Luna 双频）、`S2-05`（V.O. 写成作者交底说明书）。 | “去公文腔”绝不等于“滑向市井俗语”；Luna 的“话多”是有对象的情感梳理，办正事时必须干脆高效高信息量。 |
| **第 3 轮** | 指出具体别扭词、Luna 情绪价值落空、情绪起伏平，并提出最核心剧作观：**“剧本是给最终观众看、交给 Video 制作的，不能把心理写成替作者全说完，要给观众期待感与增量。”** | 局部对照中**矫枉过正一刀砍光了大量心理描写**；随后经用户提醒补回心理描写时，又立刻退回**辩论句式 + `if...else` 排比程序模板**（“它连句没死都不肯含糊……它不是好心提醒，是在一字不差抠字面”）。 | `S2-01`（再次钟摆：从说明腔→全删→退回辩论模板）、`S2-05`（没分清“零增量复述”与“高增量反直觉推演”）。 | 确立面向视频观众的唯一判据：**删掉零增量复述，写透打破观众直觉、制造危机与爽感的高增量心理博弈**。 |
| **第 4 轮** | 指出“人物底色和说话方式前后分裂、人设设计太粗糙”，并明确指出**以「仁·义·礼·智·信」五维强弱残缺塑造独特人物性格**，要求走完整前置流程。 | 严格按流程走完：**① 灵魂/情感锚点/硬时间线 → ② 仁义礼智信五维人物深度建模与声口控制表 → ③ 面向观众与 Video 的节拍增量分场表 → ④ 逐场成稿**。<br>**突破**：陆沉前后一致性彻底站住，Luna 三频切换与双向死局逻辑严丝合缝。<br>**新暴露症状**：① 为防啰嗦把第 1 轮原本饱满有来回的节奏故意写简、把 V.O. 压成模糊电报（`关于它自己的事，新人碰不到。最后一问，问外面。`）；② `△` 画面动作里混入大量**摄影机拍不出来的小说心理总结与剧情陈述**（`片刻就收回了探问的念头`、`直接拿最核心的问题去试底线`、`仇清了`、`压在心口大半年的沉闷松开了`）。 | `S2-01`（再一次钟摆：为防碎嘴把饱满节奏压薄成电报）、`S2-05`（把“思考”错当成“压缩结论”）、`S2-06`（小说写法入侵剧本 `△` 视听轨）。 | 剧本必须严格双轨分离：**`△` 只写摄影机拍得出、演员演得出的纯视听事实**；**`V.O.` 是有呼吸、清晰把关键信息递给观众的真实思考过程**，绝不是模糊电报；必须保护早期版本已成立的有来有回饱满节奏。 |
| **第 5 轮** | 认可修正后的局部对照（纯可拍 `△` + 清晰饱满真思考 `V.O.`），但点破最顶层的系统命题：**① 根规则缺“辩证看待局部反馈、识别核心意图”的根本限定；② `laohu-script` 应参考 Writing / Motion，把前置灵魂/筋骨/人设分析拆给 `laohu-analysis`。** | 本轮完成根规则 `AGENTS.md` / `docs/runtime.md` 补强，并产出本份完整架构优化方案。 | 上升为跨 Skill 共享治理与 `Analysis ↔ Script` 双层分工升级。 | 形成完整的“根规则护栏 + Analysis 前置设计 + Script 纯粹影视制作”三层闭环。 |

**复盘核心结论**：第一波 A1–A7 解决的是 `laohu-script` 的**文档膨胀、双真源冲突与行业技法盲区**；而本次真实长对话实战暴露出来的，是更深一层的**创作运行机理问题**：
1. **缺少“辩证承接局部反馈”的全局护栏**，导致多轮改稿反复出现钟摆式矫枉过正；
2. **`laohu-script` 自己硬扛了本应属于 `laohu-analysis` 的前置“灵魂 + 筋骨 + 深度人设 + 硬时间线”设计职责**，导致一接到详细口述就急着下场填正文；
3. **规则防错密度与专业成稿生成动作失衡**，缺少把“逻辑核验”与“活人语感/可拍画面/真思考流”隔离开的实操机制。

## 2. 七大深层断点归因（`S2-01` 至 `S2-07`）

以下按 `laohu-analysis` 断点分类法，逐一钉死问题编号、影响级别、真实控制文件位置、作用机制与证据层级：

### `S2-01`【P0 · 跨入口根规则缺口 · 已在本轮修补】缺乏“辩证承接局部反馈 + 防钟摆式矫枉过正”的对称共同规则
* **旧位置与差距**：[AGENTS.md](../../../AGENTS.md) L9 与 [docs/runtime.md](../../runtime.md) L60–70（“以解决问题推进审查与分析”）只防住了“拿例外反驳用户、替旧规则辩护”，却没有防住另一端——**把用户的单点局部批评当成推翻全局的绝对命令**。同类局部保护原则此前只零散写在 [revision-and-review.md](../../../.agents/skills/laohu-writing/references/revision-and-review.md) L17/L21/L74、[laohu-story/SKILL.md](../../../.agents/skills/laohu-story/SKILL.md) L20/L60 与 [laohu-novel/SKILL.md](../../../.agents/skills/laohu-novel/SKILL.md) L186，未升格为跨入口共同真源。
* **实战后果**：4 轮迭代连续发生三次典型钟摆——论文腔 → 油腻市井腔；说明腔 V.O. → 一刀砍光心理描写；防碎嘴 → 把第 1 轮原本饱满的有来有回节奏缩水成干瘪电报。
* **本轮处置**：已作为共同运行真源补入 [AGENTS.md](../../../AGENTS.md) 与 [docs/runtime.md](../../runtime.md#辩证承接局部反馈与保护已成立资产)（结构已校验）。

### `S2-02`【P0 · 架构职责耦合】`laohu-script` 同时承担“前置架构分析”与“中后段影视成稿”，未对齐 Writing / Motion 的 `Analysis → 专业制作` 范式
* **现状对照**：
  * [laohu-writing/SKILL.md](../../../.agents/skills/laohu-writing/SKILL.md) L46 明确规定：完整新写、整体重写或实质深化前，必须调用 `laohu-analysis` 主入口进入 [writing-design.md](../../../.agents/skills/laohu-analysis/references/writing-design.md) 完成内容、事实与讲述设计，再交回 Writing 成文；
  * [laohu-motion/SKILL.md](../../../.agents/skills/laohu-motion/SKILL.md) L18 明确规定：完整新设计或重设主视听语言时，由 `laohu-analysis` 接手 [motion-design.md](../../../.agents/skills/laohu-analysis/references/motion-design.md) 完成视觉方向与导演稿，再交 Motion 落地实现；
  * 反观 [laohu-script/SKILL.md](../../../.agents/skills/laohu-script/SKILL.md)（现行 96 KB），把步骤 1–7（灵魂前提、三幕因果、事实调研、人物底色、转折序列、二幕扩纲、地点核查）与步骤 8–10（连续时空分场、视听动作、对白声口、表演括注、全稿反审、下游交接）**全部耦合在同一个大入口内**。
* **实战后果**：用户带着一段较细的口述灵感调用 `/laohu-script` 并说“给我做个剧本吧”时，模型被“直接交正文”的惯性拉走，把灵魂、硬时间线、深度人设全压成脑内草草带过的几行念头，导致成稿后地基不稳、连续返工 4 轮。

### `S2-03`【P0 · 规则副作用与语体污染】防错/审计型条款密度压过正向成稿路径，诱发“论文腔 / IT 工单腔 / 法务腔”
* **控制位置**：[narrative-and-structure.md](../../../.agents/skills/laohu-script/references/narrative-and-structure.md) L278–309（证据链、有限问答独立求知目标计数、单请求计数）与 [dialogue-and-audiovisual.md](../../../.agents/skills/laohu-script/references/dialogue-and-audiovisual.md) L59–64（设备通道检查、不能声称未查通道已排除）。
* **作用机制**：这两类条款本身在**逻辑审计层面完全正确**，但目前直接混在“写台词前必读”的正文生成路径中，且缺少**“逻辑校验放后台，台词表达回人物”的隔离提示**。结果模型在精读完高密度法务/审计语体的规则后立刻写剧本，既发生严重的**语体吸附**（写出“信息不对称”“语义约束”“单目标绑定”），又为了向规则证明自己没违规，硬让角色把排查通道像 IT 工单一样一条条念出来（“查底层进程栈、车载局域网总线、显存缓冲区”）。

### `S2-04`【P0 · 人物建模方法缺口】缺少“价值五维偏重/残缺（含仁义礼智信）→ 双禁红线 → 跨场景切频 → 基准声口标尺”的强控制链
* **控制位置**：[character-and-relationships.md](../../../.agents/skills/laohu-script/references/character-and-relationships.md) L46–66 与 L121–134。
* **具体缺口**：
  1. 内部人物卡虽列了 8 个维度，但偏静态描述，**把“仁、义、礼、智、信”压在第 63 行末尾作为一句防御性提醒**，缺乏一套成熟、可操作、能直接从“哪一维过载 / 哪一维枯竭 / 哪一维异化为面具或执念”推导独特人物性格与行为边界的建模范式；
  2. 缺少动笔前的**“用词双禁红线（禁论文公文腔 + 禁不符身份的市井吐槽腔）”**与**“跨情境切频表 + 3–5 句基准声口锚点先审后写”**机制；
  3. 拟人化 AI 角色（L65）只强调职责与能力边界，缺少“**平时有对象的情感梳理（而非无关段子） vs 战时极简高信息量 vs 绝境破防**”的多频切换建模。
* **实战后果**：人设表写着“受过极佳教育、克制简练”，正文却滑成市井碎嘴（“说得轻巧”“一样白搭”“连裤衩都保不住”），人物前后精神分裂。

### `S2-05`【P0 · 心理描写方法缺口】`V.O.` 缺乏“面向观众信息增量 + 真实思考流”三分法，导致在“作者说明书”与“模糊电报”间来回失控
* **控制位置**：[dialogue-and-audiovisual.md](../../../.agents/skills/laohu-script/references/dialogue-and-audiovisual.md) L110（仅一句“按实际答复/反馈→人物因此形成的新认识→下一问或行动”）与 [laohu-script/SKILL.md](../../../.agents/skills/laohu-script/SKILL.md) L435。
* **具体缺口**：没有从**最终视频观众的接收体验**出发，区分三类截然不同的 `V.O.`：
  1. **零增量复述 / 作者说明书（必须删）**：复述观众刚听见或看见的事实，或用“不是 A 而是 B”的辩论句替作者讲解设定；
  2. **过度压缩电报（必须禁）**：如`“关于它自己的事，新人碰不到。最后一问，问外面。”`——貌似简练，实则信息模糊、掐断了观众跟着主角一起推演的沉浸与爽感；
  3. **高增量真实思考流（目标写法）**：保留人物自己跟自己一步步消化新信息、排除死路、打破观众第一直觉、把关键判断清清楚楚递给观众的真实思维过程，同时严守人物声口与禁用 `if...else` 机械排比。

### `S2-06`【P1 · 媒介边界失守】`△` 画面动作块缺少“小说心理总结 vs 摄影机可拍视听”的硬性拦截与转换法则
* **控制位置**：[script-format-and-delivery.md](../../../.agents/skills/laohu-script/references/script-format-and-delivery.md) L55–57 与 [scene-development.md](../../../.agents/skills/laohu-script/references/scene-development.md) L125–128、L165–176。
* **具体缺口**：虽原则性写了“写可见画面，不用小说式心理说明替代可演声画”，但没有面向下游 `laohu-video` 建立**可机械识别并强制转化的红线清单**，导致执行者极易顺手在 `△` 里塞入四类拍不出来的小说句：
  * 不可拍的念头动词（`片刻就收回了探问的念头`、`思路彻底收拢`）；
  * 不可拍的意图陈述（`直接拿最核心的问题去试底线`）；
  * 不可拍的抽象局面总结（`仇清了`、`父母没了，最后一个念想也办完了`）；
  * 不可拍的内在情绪抒情（`压在心口大半年的沉闷松开了`、`桥上那股空洞感被劈开了一道口子`）。

### `S2-07`【P1 · 灵感解包与成片视角不足】缺少“口述灵感时间压缩解包”与“面向成片观众的节奏增量分场”前置工序
* **控制位置**：[laohu-script/SKILL.md](../../../.agents/skills/laohu-script/SKILL.md) 步骤 1–2（L143–199）与步骤 8（L303–352）。
* **具体缺口**：

### 3.2 为什么这套拆分完全合理且不增加冗余摩擦？（关键边界设计）

1. **对外入口不变，不折腾用户**：用户依然只管调用 `/laohu-script`，由 `laohu-script` 根据任务类型在内部自动决定是否调用 `laohu-analysis` 主入口走剧本前置设计（与 `laohu-writing` L46 完全一致的无缝体验）。
2. **明确豁免条件，绝不拖慢轻量任务**：
   * 以下请求**不触发** `script-design.md` 完整前置分析，直接由 `laohu-script` 原地处理：
     * 局部台词润色、单场微调、格式/编号整理；
     * 承接 `laohu-story` 已确认且已含完整结构与人物关系的构想（只需核对缺项，若缺硬时间线或声口标尺才做局部补设计）；
     * 用户已有批准的完整分场纲/设计包且明确要求直接写正文。
3. **解决“思考模式互斥”的根本矛盾**：
   * 做**灵魂、硬时间线、反事实因果审查、五维人物架构、现实事实核查**，需要的是高度理性、冷峻、严密的**分析大脑（Analysis 模式）**；
   * 写**有呼吸感的台词、细腻绵密的真实内心独白、极具画面感与节奏张力的 `△` 视听场面**，需要的是完全代入活人与摄像机的**剧作表演大脑（Script 模式）**。
   * 以前把两者全塞在一次调用里，分析大脑的论文词、审计词、逻辑校验条文直接污染了剧作大脑的台词输出；拆成两段接力后，**Analysis 阶段把地基、时间线和声口标尺全部打死，交接完毕后，Script 阶段彻底轻装上阵，只盯“画面可拍、活人说话、观众爽感与节奏饱满”！**
4. **返工闭环防甩锅（对齐 `writing-design.md` L64–70）**：
   * 正文阶段若发现**灵魂立不住、时间线穿帮、核心动机与人物五维底色矛盾** → 带着具体场次与断点退回 `laohu-analysis` 局部修正受影响设计；
   * 若属于**台词别扭、气口不顺、`△` 写成小说、对白不够有来有回** → 留在 `laohu-script` 内部直接按表皮与血肉方法修复，绝不把语言打磨踢回 Analysis。
