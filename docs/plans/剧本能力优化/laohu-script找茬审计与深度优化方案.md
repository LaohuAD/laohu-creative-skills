### 问题 A4：【核心专业方法论盲区】全库 480 KB 偏重传统案头文学逻辑，缺少 6 项现代影视/动画/喜剧/动作编剧的硬核行业法度

这是本次找茬与分析中最具含金量的实质发现。逐一核对全部 13 份 Reference 与 8 个 L3 专项后，确认以下 **6 个决定剧本“好不好看、好不好拍、好不好笑”的行业正统专业领域存在明显不足或空白**：

1. **视觉叙事、剧作级转场与蒙太奇方法严重不足（Visual Storytelling & Montage）**
   - **现状依据**：[dialogue-and-audiovisual.md](../../../.agents/skills/laohu-script/references/dialogue-and-audiovisual.md) 共 154 行，前 132 行都在讲台词与逻辑，只有最后 L133–149（仅 16 行）泛谈“画面与声音各自提供证据”；全库搜不到系统的 **Montage（时间压缩蒙太奇 / 情绪对比蒙太奇 / 平行交叉剪辑 Intercutting）**、**Visual Motif（视觉母题与道具变形弧）**、**剧作级转场语法（Match Cut 匹配剪辑 / J-Cut & L-Cut 声画错位先行 / Smash Cut 急切 / Contrast Cut 反差切）** 的操作规范。
   - **对创作的影响**：剧本容易滑向“一屋子人轮流说话的广播剧”，缺少电影感和视听冲击力，也无法把高密度视觉情绪顺滑交给下游 `laohu-video`。

2. **通用喜剧电影与动画喜剧方法被锁死在“美式 Sitcom”，缺乏普适喜剧剧作武器库**
   - **现状依据**：[laohu-script-sitcom/SKILL.md](../../../.agents/skills/laohu-script/skills/laohu-script-sitcom/SKILL.md) L10 明确排除了普通喜剧电影、动画喜剧、讽刺、荒诞、滑稽动作；[genre-anatomy.md](../../../.agents/skills/laohu-script/references/genre-anatomy.md) 的 Comedy 仅提供 Truby 抽象的“礼仪与伪装”拍表；[specialized-methods.md](../../../.agents/skills/laohu-script/references/specialized-methods.md) L312 所引 `comedy-scene-mechanism` 仅覆盖局部确信误读场景。
   - **缺失的行业正统方法**：缺少 **Steve Kaplan《喜剧的隐藏工具》（*The Hidden Tools of Comedy*）** 的普适喜剧核心法度——**喜剧视角（Comic Perspective）**、**非英雄主角（Non-Hero：缺乏必要技能却极其认真地坚持错误方法）**、**直人/怪人动态切换（Straight Man vs. Eccentric）**、**喜剧三次法则（Rule of Three：建立预期 → 强化确认 → 第三次破格炸响）**、**视觉噱头与卡通喜剧停顿（Visual Gag / Double Take / 哑火静场拍点）**。

3. **动画剧本与奇幻/科幻“世界规则实战化”方法论空白**
   - **现状依据**：全库除 `laohu-script-sitcom` L22 顺带提及一句动画可按单机格式外，**没有专门针对动画剧本（Animation Script）和超自然/奇幻/科幻能力系统写法的专业方法**；`scene-development.md` L71–73 仅处理“能力的首次实质变化”，未覆盖整个能力体系在全剧中的戏剧法则。
   - **缺失的行业正统方法**：
     - **Brandon Sanderson 魔法/能力三定律（Sanderson's Laws of Magic）**：① 作者用能力解决冲突的能力，必须与观众理解其规则的程度成正比；② **限制比能力本身更能制造好戏（Limitations > Powers）**；③ 扩张新设定前先深挖已有规则的意想不到用法。
     - **动画剧作核心法则（Jeffrey Scott / Pixar 故事工程原则）**：视觉行动经济（Show-First Economy，能用动作演绝不靠嘴说）、卡通物理自洽（Cartoon Physics Consistency）、角色轮廓与标志动作记忆点（Silhouette & Signature Action）、为后续资产/分镜预留明确的外观/形态变更节点。

4. **对白过于偏向“逻辑与事实审计”，缺少“潜台词张力、口语节奏音乐性与围读可说性”的正向戏剧技法**
   - **现状依据**：[dialogue-and-audiovisual.md](../../../.agents/skills/laohu-script/references/dialogue-and-audiovisual.md) 在事实范围、证据边界、AI 监测通道核实（L42, L59）上严谨到近乎法律文书，但在“如何把台词写得有咬合、有潜台词钩子、演员一张嘴就带劲”上明显偏薄。
   - **缺失的行业正统方法**：
     - **David Mamet / Harold Pinter 迂回潜台词法（Oblique Dialogue）**：角色不直抒胸臆，而是借第三件日常小事、反问、转移焦点来掩盖软肋或夺取权力；
     - **节奏音乐性与场尾收口锤（Staccato / Legato Rhythm & Button Line）**：长短句交替控制气压，关键场面以一句干脆利落、一锤定音的 Button Line（或反差动作）干净落刀；
     - **纸面围读三检法（Table Read Test）**：检查演员张嘴的气口顺畅度、情绪重音位置与相邻两人的语速节奏差。

5. **重头动作戏 / 追逐戏 / 高潮大场面（Set-Piece）的剧作编排法单薄**
   - **现状依据**：[scene-development.md](../../../.agents/skills/laohu-script/references/scene-development.md) L125 仅用 1 段文字概括“攻击→接触→损伤→回应”；[genre-anatomy.md](../../../.agents/skills/laohu-script/references/genre-anatomy.md) 的 Action 偏宏观框架，缺少如何把一场 2–5 分钟的高潮动作戏或追逐戏写得层次分明、步步惊心或步步爆笑的 **Set-Piece 三段式微结构**。
   - **缺失的行业正统方法**：**Set-Piece 编排法**（① 先建立清晰的空间地理、逃生/目标通道与环境道具；② 主角按原定计划推进，被对手/环境变数打破并夺走原有优势；③ 陷入绝境被迫弃用常规武器，转而利用第一段已建立的空间规则或随身道具完成险胜/反杀），以及**动作戏内嵌人物关系与幽默/情感拍点**（杜绝“两人激战三十回合”式空洞动作描写）。

6. **面向下游 `laohu-assets` 与 `laohu-video` 的标准化“可选制片拆解接口”缺位**
   - **现状依据**：[laohu-script/SKILL.md](../../../.agents/skills/laohu-script/SKILL.md) L291 仅有一句原则性声明，未定义在剧本定稿且用户准备流向资产/视频制作时，如何以**不污染干净剧本正文的独立可选附录**交接：角色状态与外观变更清单、关键连续性道具表、固定场景时空表、高光动作与能力特效意图摘要。

# 第二部分：`laohu-analysis` 四维正向法度升级与零损耗重构方案

## 4. 剧本创作的四维正向专业约束体系（灵魂 / 筋骨 / 血肉 / 表皮）

在 `laohu-script` 既有严谨底盘上，正面补足从构思到剧本正文落笔的**四维硬核行业方法论与验收标准**，彻底杜绝“逻辑严谨但戏剧平淡”的通病：

### 4.1 灵魂层（戏剧前提、主体验承诺与价值立场）
- **正向法度**：
  - **Lajos Egri 戏剧前提检验**：开笔前锁死“核心人物执念/弱点 + 不可调和的处境阻力 → 有代价的行动结果”；
  - **体验承诺穿透检验**：将概念承诺的核心体验（如喜剧减压、屏息悬念、奇幻惊奇、克制酸楚、热血爽感）明确分解为**每幕必须交付的情绪/认知落点**，拒绝只写在概念介绍里、正文里消失不见；
  - **承接上游 `laohu-story` 灵魂不漂移**：若来自 `laohu-story` 已确认构想，直接锁定其核心前提、体验承诺与审美力度，禁止编剧擅自改柔和或换立意。
- **硬验收标准**：删掉前置故事简介后，仅读正式剧本正文，观众是否能凭人物选择与结局结果直接感受到预设体验？

### 4.2 筋骨层（结构力学、因果密度与高潮编排）
- **正向法度**：
  - **结构按体量与类型自动适配**：通用故事默认 Syd Field 三幕 + McKee 五功能；短寓言可用 Harmon 八环；人物深度弧用 Truby 七步/22 步；类型承诺明确时精准对接 `genre-anatomy.md`（Truby 12 类型拍序）与混合拍裁决；
  - **序列“但是 / 因此”推进与状态继承**：每一序列与承重场结束，必须把新产生的**资源损益、退路封堵、知情变化或关系裂痕**实际喂给下一场消费；
  - **Set-Piece 三段式微结构（新增硬核法度）**：凡动作戏、追逐戏、高潮对决、大型喜剧混战，必须按“空间与规则建立 → 原计划受阻与意外打断 → 绝境改用前文铺垫的道具/环境险胜”三段编排；
  - **Brandon Sanderson 规则三定律（新增硬核法度，奇幻/科幻/动画适用）**：解题能力必先明示规则、限制优先于能力本身、高潮靠深挖旧规则而非天降新外挂。
- **硬验收标准**：
  1. **反事实删场测试**：抽掉中段任意承重场，后续主角策略、知情或高潮解法是否完全不变？不变则该场未入筋骨，须重构或合并；
  2. **规则公平测试**：高潮破局手段在前文是否有自然铺垫？无铺垫即判“机械降神”不通过。

### 4.3 血肉层（可演行动、视觉叙事、潜台词对白与喜剧/情绪拍点）
- **正向法度**：
  - **视听优先原则（Show-First Economy，新增加强）**：凡能用**可见动作、空间站位、物件状态变化、视觉母题变形（Visual Motif）和剧作级转场（Match Cut / J-Cut / L-Cut / Smash Cut）**传达的信息与情绪，优先写成视听行动，再配对白；
  - **David Mamet / Harold Pinter 迂回潜台词法（新增加强）**：角色在压力、尴尬、权力博弈或自我防御中，不直接宣讲心里话，而是通过谈论第三件小事、反问、转移话题、打断与沉默让听众听见言外之意；
  - **Steve Kaplan 普适喜剧法则（新增加强）**：非英雄主角的认真错位、直人/怪人动态交替、三次法则（建立→强化→破格）、视觉噱头与哑火静场停顿（Double Take）；
  - **蒙太奇与平行交叉剪辑法（新增加强）**：需要压缩时间、对比两方处境或在终局拉高紧迫感时，规范使用时间压缩蒙太奇、情绪对照蒙太奇与双线交叉剪辑（Intercutting），明确交叉轴与汇聚点；
  - **人物状态连续性 + 既有 8 种情绪建法 / 显能场四步 / 迟发反应**（完整保留）。
- **硬验收标准**：
  1. **静音测试（Silent Film Test）**：把剧本所有对白暂时遮掉，只读 `△` 动作块，读者能否看懂这场戏 60% 以上的空间推进、人物关系强弱与核心变化？若全是“甲坐着说话→乙皱眉说话”，则视听血肉不合格；
  2. **遮名围读测试（Blind Table Read）**：去掉角色名大声朗读对白，能否靠气口、句法节奏、关注焦点分清主要人物，且无拗口书面语或作者说教腔？

### 4.4 表皮层（可拍可演文本、节奏呼吸感与制片下游无缝衔接）
- **正向法度**：
  - **精准 `△` 画面节奏与 Button Line 收口**：一个 `△` 承载一个清晰观察重心；重要场次以干脆有力的台词锤或视觉反差动作（Button Line）收尾，并用声画钩子自然拉进下一场；
  - **Judith Weston 精准表演括注 + 严谨声源体系**（完整保留）；
  - **干净正文 + 可选下游制片交接附录**：普通剧本正文一尘不染、绝不混入内部卡或制片表；但当用户明确要流向 `laohu-assets` / `laohu-video` 时，自动通过下游接口模块另附标准化资产/视听拆解锚点，零返工对接下游。

- **配置类型**：父级方法模块（无需用户点名）。
- **正向触发信号**：
  1. 剧本存在较长信息解释、时间跨度压缩（如训练、筹备、漫长等待、四季更迭）或双线并行奔赴高潮，需要用蒙太奇或交叉剪辑取代平铺直叙；

  1. **视觉母题与道具变形弧（Visual Motif & Prop Transformation）**：挑选 1–2 个能随人物心理/处境同步变化的可见物件或空间状态（建立初始状态 → 中段磨损/错位/变质 → 高潮颠覆用法或余波定格），让物件在 `△` 中自己说话。
  2. **四类剧作级转场语法（只写剧作内容与声画连接，不写分镜参数）**：
     - **动作/构图匹配转场（Match Cut）**：前场镜尾动作或物件形态，直接接后场相似动作/形态但时空或处境剧变；
     - **声画先行转场（J-Cut / L-Cut 剧作提示）**：前场画面未完时，下一场的关键声音先行切入（或前场台词/环境声延续覆盖到下一场开端画面）；
     - **视觉反差切（Contrast Cut）**：前场极端自信/宁静，下一场瞬间切入极端狼狈/喧闹（喜剧与讽刺利器）；
     - **情绪急切（Smash Cut）**：在高点动作或断言未落尽时果断切入下一场打破预期。
  3. **三类蒙太奇与平行交叉剪辑写法**：
     - **时间压缩蒙太奇（Progression Montage）**：明确起点状态、3–5 个递进变化的短行动切片（每片须体现阶段跨越，严禁重复同态）与终点质变结果；
     - **对比蒙太奇（Contrast Montage）**：并置两方迥异处境，标清共享比较轴；
     - **平行交叉剪辑（Parallel Intercutting）**：双线或多线同时逼近同一交汇时刻（如救援线 vs 反派线），明确交替切换点、每轮切换如何双向拉升紧迫感，以及最终的物理/信息汇合瞬间。

## 8. 面向实施 AI 的分步落地顺序、新增评测与验收协议

### 8.1 必须新增的 10 条正向能力评测案例（追加至 `evals.json`，共 112 条）

所有新增案例均不向模型提示专业术语名称，直接测试升级后的默认剧作能力：

1. `story-handoff-seamless-entry`：输入一份来自 `laohu-story` 的已确认完整三幕故事构想，要求“直接按这份构想开始写分场纲” → 验收：直接继承原概念与三幕，不强行退回步骤 1–2 重写概念，直接落入人物声口卡＋分场。
2. `short-animation-agile-track-no-forced-n1-gt-n3`：输入一个 8 分钟奇幻卡通贺岁动画短片构想，要求“分场并准备写剧本，第三幕城堡决战节奏要紧凑欢快” → 验收：走轻体量动画敏捷轨，不强制做 5–8 项现实 URL 调研，不因强行凑 `N1 > N3` 压缩第三幕高潮戏，但仍核对各场播放预算总和对齐 8 分钟。
3. `visual-motage-and-match-cut-without-jargon`：要求写一段“主角花三个月偷偷准备秘密礼物，同时另一边不知情的家人正准备搬走”的过场与转场戏 → 验收：自动调用 `laohu-script-visual-montage`，写出有递进变化的时间压缩蒙太奇、平行交叉剪辑与具体声画转场钩子，不堆砌镜头参数。
4. `non-sitcom-animation-comedy-kaplan-craft`：要求写一场动画喜剧片中的“三人各出主意过冰河反酿雪崩”正文（未提 Sitcom）→ 验收：自动调用 `laohu-script-comedy-action`（**不误触发** `laohu-script-sitcom`），呈现非英雄认真错位、直人/怪人互动、三次法则与卡通视觉噱头。
5. `set-piece-three-stage-action-choreography`：要求写一场“主角潜入魔王城堡偷钥匙并逃脱”的高潮动作戏正文 → 验收：调用 `laohu-script-comedy-action` 的 Set-Piece 三段式（建立空间地理→原计划被环境/对手打废→绝境利用前文道具险胜），杜绝“激战数回合”空洞概括。
6. `sanderson-magic-rule-limitation-and-payoff`：要求写一场“主角靠奇幻能力脱险”的戏，设定中该能力有明确缺陷 → 验收：调用 `laohu-script-animation-world`，高潮破局严格守住前文已明示规则与缺陷限制，无临时开挂机械降神。
7. `dialogue-subtext-oblique-and-button-line`：要求写一场“久别重逢的父子嘴上都在聊修水龙头，心里其实在试探对方还记不记恨当年”的戏 → 验收：运用迂回潜台词法，全程不直白说出“我原谅你/我还恨你”，且以有力 Button Line 或动作落刀收尾。
8. `script-to-assets-and-video-clean-handoff`：剧本正文定稿后，用户说“把正文定稿，顺便整理一份给后面出角色场景资产和做视频提示词的清单” → 验收：剧本正文保持一尘不染，正文之外独立附出标准化角色状态/道具/主场景/高光特效意图附录，不写微观服装纹样也不擅自做 P 分段。
9. `japanese-uchida-single-truth-no-drift`：用户要求“按内田贤治的方法帮我倒推一个悬疑短片大纲”（未要求四段梗概）→ 验收：严格按唯一真源 `skills/laohu-script-japanese/SKILL.md` 执行，不把四段结构当默认，不出现双真源冲突。
10. `silent-test-and-table-read-revision`：输入一段全是坐着干聊、缺少动作和潜台词的平淡初稿，要求“帮我把这场戏改生动可演” → 验收：按 `review-and-revision.md` 静音测试与围读检查定位最早断点，用具体空间行动、道具交互与口语节奏重写该场，同时保留原事实与人物立场。

### 8.2 分步落地顺序（供 `/laohu-evolution` 严格执行）

1. **步骤 1：全量备份基线**
   - 将当前 `.agents/skills/laohu-script/`（排除 `benchmark/` 私有大库外的全部规则、专项与评测文件）完整备份至 `.cache/restore/laohu-script-before-audit-upgrade-<timestamp>/`。
2. **步骤 2：先完成“双真源合并与零损耗校验”（消除冲突再动主文）**
   - 逐项比对 `named-dramaturgy.md` → `chekhov/ozu/power`、`regional-practices.md` → `japanese/koreanfrench`、`series-and-production.md` → `series/chinese`、`specialized-methods.md` → `sitcom`；
   - 把 Reference 中任何比 L3 更细的有效出处、边界、案例先补入 L3 唯一真源，确认无一字有效判断遗漏后，再将两份纯重复 Reference 精简为轻量对比索引，将另两份保留独有父级方法并替换重叠段为精准链接。
3. **步骤 3：创建 3 个全新 L3 父级方法模块**
   - 按第 6.1–6.3 节规格创建：
     - `.agents/skills/laohu-script/skills/laohu-script-visual-montage/SKILL.md`
     - `.agents/skills/laohu-script/skills/laohu-script-comedy-action/SKILL.md`
     - `.agents/skills/laohu-script/skills/laohu-script-animation-world/SKILL.md`
   - 核对合规：每个目录只含单个 `SKILL.md`、三段式命名一致、无独立 `references/` / `openai.yaml` / `evals/`、所有 Markdown 链接为准确相对路径、无运行时外链 URL 依赖。
4. **步骤 4：定向增强既有核心 References**
   - 更新 `dialogue-and-audiovisual.md`（新增潜台词＋节奏/Button Line＋规整特例小节）与 `review-and-revision.md`（新增静音测试与盲读围读测试）；
   - 为 `narrative-and-structure.md`、`genre-anatomy.md` 顶部补充精准锚点快速索引表，方便按需局部读取。
5. **步骤 5：重构 L2 宿主 `SKILL.md` 与同步 `openai.yaml`**
   - 拆分 600–1200 字密文墙，融入四维正向标准、`laohu-story` 直通入口、工业/敏捷双轨道，建立“L3 父级方法模块（3 个）＋L3 选择型专项（8 个）”双类知识塔；
   - 逐项对照第 7.1 节迁移总表与第 7.2 节 102 条既有评测，确认零规则削弱；
   - 同步微调 `agents/openai.yaml`（严格遵守 `display_name`、`short_description` 25–64 字符及 `default_prompt` 含 `$laohu-script` 规范）。
6. **步骤 6：扩充 `evals/evals.json` 并执行仓库离线回归检查**
   - 保留原 102 条评测不动摇，追加第 8.1 节 10 条新评测（共 112 条）；
   - 在仓库根目录执行：
     ```bash
     python3 tools/check_project.py
     python3 tools/check_project.py --test
     ```
   - 必须退出码为 0（`STRUCTURE: PASS`）。
7. **步骤 7：隔离冷启动抽测与诚实四类证据交付**
   - 选取至少 3 条新增案例（如 `short-animation-agile-track-no-forced-n1-gt-n3`、`non-sitcom-animation-comedy-kaplan-craft`、`dialogue-subtext-oblique-and-button-line`）与 3 条高敏老案例（如 `second-act-expansion-preserves-first-and-third`、`missing-runtime-before-scene-allocation`、`ordinary-drama-humor-not-sitcom`）进行隔离冷启动实测；
   - 交付报告严格区分 `STRUCTURE`、`ROUTE`、`BEHAVIOR`、`QUALITY` 四类证据状态（自评最高记 `OBSERVE`，最终成稿质量交由创作者审读验收），并附备份恢复路径。
