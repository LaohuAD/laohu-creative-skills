# 老胡造夢技能

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [繁體中文](README.zh-TW.md)

> AI で夢をつくる人のために、老胡が用意したクリエイティブ Skill です。
>
> テーマ企画、物語、文章、タイトル、カバー、画像・動画プロンプト、歌詞、編曲、脚本、小説、アニメーション、音声編集まで幅広く支えます。自分の美意識で方向を決め、AI と一緒に作品へ仕上げましょう。
>
> **老胡 AI クリエイティブ体系**：本リポジトリは制作の**頭脳とメソッド**を担います。ローカルの無限キャンバスや生成ワークフローには **[老胡画夢枋（Laohu Creative Studio）](https://github.com/LaohuAD/laohu-creative-studio)**、数百モデルを 1 アカウントで低コスト従量利用できる API には **[老胡のモデル小屋](https://api.lao-hu.com)**、実作例やチュートリアル・コミュニティは **[老胡公式サイト](https://lao-hu.com/)** を組み合わせて使えます。

老胡造夢技能は、人を中心に設計したクリエイティブ能力のコレクションです。ひらめきから作品の完成、整理までを、自分で選べる入口としてまとめています。何をつくるか、誰に届けるか、どの判断を守るかはあなたが決め、AI はその方向に沿って制作を進めます。

## プロジェクト内・グローバルでの利用

Git、Python 3.9 以降、ローカル Skill を読める Agent が必要です。完全なリポジトリを一つ保持し、グローバル入口は同じ場所へのリンクにします。開発用・安定版の別コピーは作りません。

```bash
git clone https://github.com/LaohuAD/laohu-creative-skills.git
cd laohu-creative-skills
python3 tools/check_project.py
```

既存の完全なリポジトリはそのまま使います。プロジェクト内だけで使う場合は、このフォルダーを Agent で開きます。入口が表示されない場合は `.agents/skills/laohu/SKILL.md` を読むよう依頼できます。

他のプロジェクトでも使う場合は、登録内容を確認してから適用します。

```bash
python3 tools/install.py install --host codex
python3 tools/install.py install --host codex --write
```

ローカル Claude Code では `codex` を `claude` に変更します。選んだホストには、直接配置された一・二階層の正式入口だけを登録します。予約ディレクトリは対象外です。三階層の内部専用機能（`/laohu-htmlshow` 配下の WeChat 組版を含む）は所属する二階層の入口が必要に応じて読み込み、個別には登録しません。Codex は `~/.agents/skills`、Claude Code は `~/.claude/skills` を使用し、同名の別入口は上書きしません。ホストを再読み込みして確認してください。同じソースを共有するため修正は直接反映され、ソースの場所を維持する必要があります。クラウドや別の PC には自動適用されず、他ホストやリンク権限は別途検証が必要です。

Agent に「README を読み、現在のリポジトリを Codex のグローバル入口として登録して」と依頼できます。README を読むだけではインストールの許可になりません。

Agent 専用ガイド：[開く／ダウンロード](https://raw.githubusercontent.com/LaohuAD/laohu-creative-skills/main/docs/agent-guide.txt)。「老胡造夢技能の Agent 専用ガイドを先に読み、その説明に沿って手伝ってください」と依頼することもできます。

老胡プロジェクト内では作品は `works/` に保存し、個人の好みやメモは `knowledge/` に置きます。どちらもユーザーファイルは `.gitignore` で除外されており、ローカルに留まって GitHub へはアップロードされません。外部で保存先が未定なら具体的な候補を示して確認を待ちます。指定済みの場所や同じ作品のディレクトリは継続使用します。外部フォルダーに本リポジトリの Git 除外は自動適用されません。

どちらも `/laohu-update` で更新し、ローカル変更を保護しながら登録済み入口を同期します。状態確認は `python3 tools/install.py status`。解除は `python3 tools/install.py uninstall --host codex` で確認後、`--write` を追加します。作品とリポジトリは残ります。移動前に解除し、移動後に再登録してください。[操作詳細（中国語）](.agents/skills/laohu-update/references/installation.md)


## できること

- ひとつの発想から、テーマ、物語、企画の方向を育てる。
- 歌詞、文章、脚本などを、構成と表現を考えながらつくる。
- タイトル、カバー、画像、動画プロンプトを設計する。
- 編曲の方向を考え、ビジュアルや制作アセットを整理する。
- 参考作品を分析し、作品の問題を見つけ、完成品を記録する。
- 実際の制作経験を次の創作に活かす。

## 入口を選ぶ

`/laohu` と入力するか、次のモードを選べます。日本語で同じ内容を依頼しても使えます。

- `/laohu 新手入门`：基本の使い方と最初の依頼例を確認する。
- `/laohu 能力目录`：現在利用できる Skill と用途を見る。
- `/laohu 帮我选`：目的や素材から、推薦理由と送信できる依頼文を受け取る。
- `/laohu 更新帮助`：Git でプロジェクト全体を更新する。自分で調整した内容と公式の変更が競合した場合は、統合案を確認してから更新を選べます。

入口は毎回、現在の Skill 情報を読み取ります。同じコレクションに追加された能力は、次回の検索から候補に入ります。実行するかどうかはユーザーが決めます。

目的が決まっているときは対応するコマンドを直接使います。まだ入口が分からないときは /laohu を使ってください。目的、素材、次の判断を整理し、合う入口を選べるようにします。

| コマンド | 用途 |

正式な入口は単独でも、ひとつの作品の中で組み合わせても使えます。`/laohu-topic` で作品全体のテーマを決めたあと、その概要を `/laohu-title` のタイトル作業や `/laohu-cover` のビジュアル設計に渡すか、文章作成へ進むかを選べます。必要な工程だけを使うこともでき、続けるか、直すか、方向を変えるかは毎回あなたが決めます。

## 老胡の AI 制作エコシステム：4 つをつなげて使う

アイデアと生成ツールが分断されていたり、複数クラウドを行き来して試行錯誤のコストが膨らんだりする悩みを減らすため、4 つの要素を連携させています。必要なものだけ単体で使うことも、一気通貫でつなぐこともできます。

| 役割 | プロジェクト／サービス | 解決できること | リンク |
| --- | --- | --- | --- |
| **頭脳とメソッド** | **老胡造夢技能**（本リポジトリ） | 企画・執筆・タイトル・カバー・脚本・歌詞・編曲・映像プロンプト・アニメーション・検収まで 23 の Agent Skill を提供 | [GitHub](https://github.com/LaohuAD/laohu-creative-skills) |
| **手足とローカル作業台** | **老胡画夢枋**（Laohu Creative Studio） | 無限キャンバス・動画クローン・アニメーション制作・各種生成を一つのローカル環境に集約し、素材とパラメータを手元に残す | [GitHub](https://github.com/LaohuAD/laohu-creative-studio) |
| **低コスト統合モデル API** | **老胡のモデル小屋** | 1 アカウントで数百のテキスト・画像・動画・音楽・音声モデルを利用可能。画夢枋にネイティブ対応し、低価格ルートと明確な従量課金で試作コストを抑制 | [モデルと最新料金](https://api.lao-hu.com/pricing) |
| **作品・解説・コミュニティ** | **老胡公式サイト** | 実作ショーケース、[チュートリアルと資料](https://lao-hu.com/learn/)、全オープンソースツール、および[老胡画夢枋コミュニティ](https://lao-hu.com/#community)を案内 | [lao-hu.com](https://lao-hu.com/) |

- **造夢技能**で方向性・構成・プロンプトを固める。
- **老胡画夢枋**と**モデル小屋**で画像・動画・音楽をローカル主導で生成し、素材と設定を保存する。
- `/laohu-audit`・`/laohu-htmlshow`・`/laohu-archive` で推敲・整理・公開へ戻す（画面収録や解説動画編集には [CapMotion](https://github.com/LaohuAD/laohu-CapMotion) も連携可能）。

### 試作コストを抑えたいときは：画夢枋 ＋ モデル小屋

納得のいくカバーやカットを作るには何巡もの試作が必要です。ローカルの**老胡画夢枋**に **[老胡のモデル小屋](https://api.lao-hu.com)** を接続すれば、1 アカウントで数百モデルを切り替えながら、低価格ルートと従量課金で無駄なく試せます（最新単価は [料金ページ](https://api.lao-hu.com/pricing) を確認してください）。オープンソース本体はいずれのサービスにも縛られず、ローカル ComfyUI や他社 API でも自由に動かせます。まずは小さなタスクで品質・速度・料金を比較してから継続判断するのがおすすめです。作品例や解説は **[lao-hu.com](https://lao-hu.com/)** へ。

## 継続的な更新

バージョンの変更は[更新履歴](CHANGELOG.md)で確認できます。更新方法は `/laohu` に質問し、実際に更新するときは `/laohu-update` を使います。メンテナーは `python3 tools/check_project.py --test` で確認できます。公開手順は[保守ガイド](docs/maintenance.md)を参照してください。

このプロジェクトは実際の創作を通じて改善されます。問題や提案があれば、老胡の個人サイトから連絡してください。
