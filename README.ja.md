# 老胡造夢技能

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [繁體中文](README.zh-TW.md)

> AI で夢をつくる人のために、老胡が用意したクリエイティブ Skill です。
>
> 音楽、カバー、動画、タイトルなど、コンテンツ制作と公開に関わる幅広い領域を支えます。自分の美意識で能力を選び、組み合わせ、AI を使った制作と公開を進めましょう。一緒にこの世界に夢を描きます。

老胡造夢技能は、人を中心に設計したクリエイティブ能力のコレクションです。ひらめきから作品の完成、整理までを、自分で選べる入口としてまとめています。何をつくるか、誰に届けるか、どの判断を守るかはあなたが決め、AI はその方向に沿って制作を進めます。

## できること

- ひとつの発想から、テーマ、物語、企画の方向を育てる。
- 歌詞、文章、脚本などを、構成と表現を考えながらつくる。
- タイトル、カバー、画像、動画プロンプトを設計する。
- 編曲の方向を考え、ビジュアルや制作アセットを整理する。
- 参考作品を分析し、作品の問題を見つけ、完成品を記録する。
- 実際の制作経験を次の創作に活かす。

## 入口を選ぶ

目的が決まっているときは対応するコマンドを直接使います。まだ入口が分からないときは /laohu を使ってください。目的、素材、次の判断を整理し、合う入口を選べるようにします。

| コマンド | 用途 |
| --- | --- |
| /laohu | 依頼の整理と創作方向の選択 |
| /laohu-topic | テーマ、企画、シリーズ、創作の種 |
| /laohu-writing | 文章、推敲、口語原稿 |
| /laohu-gzh-design | Markdown と長文の WeChat 向けレイアウト |
| /laohu-lyrics | 歌詞とソングライティング |
| /laohu-title | タイトル、命名、入口の言葉 |
| /laohu-cover | カバーのコンセプトとプロンプト |
| /laohu-script | 脚本、シーン、展開 |
| /laohu-image | 画像の発想と生成プロンプト |
| /laohu-assets | ビジュアル、音声、制作アセット |
| /laohu-story | 物語、登場人物、展開のアイデア |
| /laohu-video | 動画、ショット、動画プロンプト |
| /laohu-arrangement | 編曲、音楽構成、制作メモ |
| /laohu-benchmark | 参考作品の調査と分解 |
| /laohu-diagnosis | テーマ、文章、作品の問題発見 |
| /laohu-archive | 作品の整理とアーカイブ |
| /laohu-update | ツールボックスの確認と更新 |
| /laohu-evolution | 経験の記録と創作方法の改善 |

入口は単独でも、ひとつの作品の中で組み合わせても使えます。選題のあとに歌詞を書くことも、韻、タイトル、カバーだけを扱うこともできます。続けるか、直すか、方向を変えるかは毎回あなたが決めます。

## 老胡画夢枋と使う

老胡画夢枋は、この技能と組み合わせて使う創作ワークスペースです。モデルを使い、方向性をキャンバス、音楽、画像、動画などの具体的な成果へ展開できます。

- 造夢技能で方向、内容、重要な判断を決める。
- 老胡画夢枋で生成、試作、可視化を行う。
- Skill に戻り、修正、診断、整理、公開を進める。
