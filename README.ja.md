# 老胡造夢技能

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [繁體中文](README.zh-TW.md)

> AI で夢をつくる人のために、老胡が用意したクリエイティブ Skill です。
>
> 音楽、カバー、動画、タイトルなど、コンテンツ制作と公開に関わる幅広い領域を支えます。自分の美意識で能力を選び、組み合わせ、AI を使った制作と公開を進めましょう。一緒にこの世界に夢を描きます。

老胡造夢技能は、人を中心に設計したクリエイティブ能力のコレクションです。ひらめきから作品の完成、整理までを、自分で選べる入口としてまとめています。何をつくるか、誰に届けるか、どの判断を守るかはあなたが決め、AI はその方向に沿って制作を進めます。

## プロジェクト内・グローバルでの利用

Git、Python 3.9 以降、ローカル Skill を読める Agent が必要です。完全なリポジトリを一つ保持し、グローバル入口は同じ場所へのリンクにします。開発用・安定版の別コピーは作りません。

```bash
git clone https://github.com/LaohuAD/laohu-creative-skills.git
cd laohu-creative-skills
python3 tools/check_project.py
```

既存の完全なリポジトリはそのまま使います。プロジェクト内だけで使う場合は、このフォルダーを Agent で開きます。入口が表示されない場合は `.agents/skills/laohu/SKILL.md` を読むよう依頼できます。

他のプロジェクトでも使う場合は、登録内容を確認してから適用します。

```bash
python3 tools/install.py install --host codex
python3 tools/install.py install --host codex --write
```

ローカル Claude Code では `codex` を `claude` に変更します。選んだホストだけに、定義済みの全入口を登録します。Codex は `~/.agents/skills`、Claude Code は `~/.claude/skills` を使用し、同名の別入口は上書きしません。ホストを再読み込みして確認してください。同じソースを共有するため修正は直接反映され、ソースの場所を維持する必要があります。クラウドや別の PC には自動適用されず、他ホストやリンク権限は別途検証が必要です。

Agent に「README を読み、現在のリポジトリを Codex のグローバル入口として登録して」と依頼できます。README を読むだけではインストールの許可になりません。

老胡プロジェクト内では `works/` に保存し、実際の場所を通知します。外部で保存先が未定なら具体的な候補を示して確認を待ちます。指定済みの場所や同じ作品のディレクトリは継続使用します。外部フォルダーに本リポジトリの Git 除外は自動適用されません。

どちらも `/laohu-update` で更新し、ローカル変更を保護しながら登録済み入口を同期します。状態確認は `python3 tools/install.py status`。解除は `python3 tools/install.py uninstall --host codex` で確認後、`--write` を追加します。作品とリポジトリは残ります。移動前に解除し、移動後に再登録してください。[操作詳細（中国語）](.agents/skills/laohu-update/references/installation.md)


## できること

- ひとつの発想から、テーマ、物語、企画の方向を育てる。
- 歌詞、文章、脚本などを、構成と表現を考えながらつくる。
- タイトル、カバー、画像、動画プロンプトを設計する。
- 編曲の方向を考え、ビジュアルや制作アセットを整理する。
- 参考作品を分析し、作品の問題を見つけ、完成品を記録する。
- 実際の制作経験を次の創作に活かす。

## 入口を選ぶ

`/laohu` と入力するか、次のモードを選べます。日本語で同じ内容を依頼しても使えます。

- `/laohu 新手入门`：基本の使い方と最初の依頼例を確認する。
- `/laohu 能力目录`：現在利用できる Skill と用途を見る。
- `/laohu 帮我选`：目的や素材から、推薦理由と送信できる依頼文を受け取る。
- `/laohu 更新帮助`：Git でプロジェクト全体を更新する。自分で調整した内容と公式の変更が競合した場合は、統合案を確認してから更新を選べます。

入口は毎回、現在の Skill 情報を読み取ります。同じコレクションに追加された能力は、次回の検索から候補に入ります。実行するかどうかはユーザーが決めます。

目的が決まっているときは対応するコマンドを直接使います。まだ入口が分からないときは /laohu を使ってください。目的、素材、次の判断を整理し、合う入口を選べるようにします。

| コマンド | 用途 |
| --- | --- |
| /laohu | 依頼の整理と創作方向の選択 |
| /laohu-topic | テーマ、企画、シリーズ、創作の種 |
| /laohu-writing | 文章、推敲、口語原稿 |
| /laohu-htmlshow | 文章、プロンプト、脚本などを読みやすく使いやすい HTML に変換 |
| /laohu-htmlshow-gzh | Markdown と長文の WeChat 向けレイアウト |
| /laohu-lyrics | 歌詞とソングライティング |
| /laohu-title | タイトル、命名、入口の言葉 |
| /laohu-cover | カバーのコンセプトとプロンプト |
| /laohu-script | 脚本、シーン、展開 |
| /laohu-image | 画像の発想と生成プロンプト |
| /laohu-assets | ビジュアル、音声、制作アセット |
| /laohu-story | 発想がない状態や断片から、音楽・文章・映像などの創作の方向を探る |
| /laohu-video | 動画、ショット、動画プロンプト |
| /laohu-arrangement | 編曲、音楽構成、制作メモ |
| /laohu-benchmark | 参考作品の調査と分解 |
| /laohu-audit | 目的と資料に照らして作品・プロンプト・Skill・工程の具体的な問題を確認し、根拠を示す |
| /laohu-analysis | 問題の原因を説明し、確定した目標を実行可能な計画にする |
| /laohu-archive | 作品フォルダーを作成・再利用し、関連する制作物をまとめて保存 |
| /laohu-update | ツールボックスの確認と更新 |
| /laohu-evolution | 経験の記録と創作方法の改善 |

入口は能力の完成に合わせて順次公開します。対応するディレクトリに有効な `SKILL.md` がある入口だけを Agent から直接呼び出せます。その他のディレクトリは今後のための予約場所で、実装後に有効化します。

入口は単独でも、ひとつの作品の中で組み合わせても使えます。選題のあとに歌詞を書くことも、韻、タイトル、カバーだけを扱うこともできます。続けるか、直すか、方向を変えるかは毎回あなたが決めます。

## 老胡画夢枋と使う

老胡画夢枋は、この技能と組み合わせて使う創作ワークスペースです。モデルを使い、方向性をキャンバス、音楽、画像、動画などの具体的な成果へ展開できます。

- 造夢技能で方向、内容、重要な判断を決める。
- 老胡画夢枋で生成、試作、可視化を行う。
- Skill に戻り、修正、診断、整理、公開を進める。

## 継続的な更新

バージョンの変更は[更新履歴](CHANGELOG.md)で確認できます。更新方法は `/laohu` に質問し、実際に更新するときは `/laohu-update` を使います。メンテナーは `python3 tools/check_project.py --test` で確認できます。公開手順は[保守ガイド](docs/maintenance.md)を参照してください。

このプロジェクトは実際の創作を通じて改善されます。問題や提案があれば、老胡の個人サイトから連絡してください。
