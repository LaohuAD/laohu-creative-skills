# 老胡造梦技能

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [繁體中文](README.zh-TW.md)

> 老胡为 AI 造梦师准备的创作技能仓库。
>
> 涵盖选题、故事、写作、标题、封面、生图、视频、歌词、编曲、剧本、小说、原生动画与音频剪辑等全链路创作领域。由你定方向、把审美，AI 在清晰边界里帮你推进落地——让我们一起给这个世界画个梦。

> **老胡 AI 创作体系导览**：本仓库负责创作里的**大脑与方法**；需要可视化画布、批量出图出片和本地流程沉淀，直接搭配开源工作台 **[老胡画梦枋](https://github.com/LaohuAD/laohu-creative-studio)**；想用一个账号低成本跑通数百个主流模型，可直连 **[老胡的模型小屋](https://api.lao-hu.com)**；看完整作品、图文/视频教程或进群交流，欢迎来 **[老胡个人网站](https://lao-hu.com)**。

老胡造梦技能是一套以创作者为中心的 AI 能力集合。它把从最初一个模糊念头，到选题拆解、脚本创作、提示词工程、成品审查、整理归档的各个环节，做成了 23 个可以随时单独调用或自由组合的正式入口。

你不被绑死在一条僵硬的流水线上：想做什么、给谁看、哪里必须坚持自己的口味，全部由你拍板；AI 负责顺着你的判断把每一步做深、做扎实。

## 你可以用它做什么

- 从一个模糊念头出发，拆清真正值得做的选题、故事方向或创意切口。
- 写公众号文章、教程手册、口播稿、短帖、歌词、剧本和小说，把结构与人话语感一起立起来。
- 打磨门外标题、封面构图、单图提示词、角色场景资产和分镜视频提示词，直接对接下游模型出成品。
- 规划编曲和声音设计，用本地原生代码生成动画与口播混剪，或基于录屏/ASR 做可追溯的虚拟剪辑。
- 深度拆解优秀标杆作品，给已有稿件或提示词找茬排障，并把同一部作品的全部素材持续归档。
- 把每一次真实创作踩过的坑沉淀成可复用的经验与个人偏好，让下一次出手更快进入状态。

仓库采用三层单向架构：日常创作仅加载极薄的 [docs/runtime.md](docs/runtime.md) 与对应领域 Skill，不拿厚重条框束缚强模型发挥；仓库维护与技能进化则以 [万能造梦框架](docs/governance/universal-dream-framework.md)（灵魂/筋骨/血肉/表皮 × 目标/判断/行动/结果）作为底层构造原理，由 `laohu-audit`、`laohu-analysis`、`laohu-evolution` 协同完成审查、设计与验证。规则改造不等于实际作品质量自动通过，具体变化与边界见 [更新记录](CHANGELOG.md)。

## 安装：项目内使用或全局使用

需要 Git、Python 3.9+，以及能读取本地 Skill 的 Agent（如 Codex、Claude Code、Antigravity 等）。两种方式都只保留一份完整仓库，不另分开发版、安装版或稳定副本。

| 方式 | 适合什么情况 | 好处与限制 |
| --- | --- | --- |
| 项目内使用 | 在本仓库中直接体验、创作或修改技能 | 范围清晰，不改动本机其他目录；其他项目不会自动发现这些入口 |
| 全局使用 | 在多个项目里随时调用老胡全套技能 | 所选 Agent 的本机任务共用同一套技能；符号链接指向同一仓库，修改即时生效，仓库路径须保持可访问 |

**第一步：获取完整仓库。** 在你选定的父目录运行；本地已有完整仓库直接使用，不必重复克隆：

```bash
git clone https://github.com/LaohuAD/laohu-creative-skills.git
cd laohu-creative-skills
python3 tools/check_project.py
```

项目内使用时，直接在这个仓库目录打开 Agent。Codex 可自动发现 `.agents/skills/`；如果当前宿主没有显示斜杠命令，让它直接读取 `.agents/skills/laohu/SKILL.md` 即可开始，不必为此安装到全局。

**第二步（可选）：注册为本机全局入口。** 在仓库根目录运行：

```bash
python3 tools/install.py install --host codex
python3 tools/install.py install --host codex --write
```

第一条仅预览，第二条才实际写入链接。Claude Code 本机使用把 `codex` 换成 `claude`，只安装你选定的宿主。工具只注册直接部署的一级、二级正式入口，跳过预留目录；公众号排版等三级内部专项由所属二级入口按需读取，不单独注册。遇到同名入口指向别处时会停止并提示冲突，绝不覆盖。Codex 注册目标为 `~/.agents/skills`，Claude Code 为 `~/.claude/skills`；它们只是软链接入口，真源仍在当前仓库。注册后按宿主方式重载或新开会话核对可用入口。本机安装不会自动同步到云端或其他电脑；其他宿主与系统的链接权限需实际核验。

也可以直接告诉 Agent：

> 请阅读这个仓库的 README，帮我在当前项目内使用老胡技能。

或：

> 请阅读这个仓库的 README，把当前完整仓库注册为 Codex 的全局技能入口，不另建仓库副本。

Agent 专用指引：[打开或下载](https://raw.githubusercontent.com/LaohuAD/laohu-creative-skills/main/docs/agent-guide.txt)。你也可以对 Agent 说：“请先阅读老胡造梦技能的 Agent 专用指引，并按其中说明协助我。”

README 仅说明可选方式；Agent 不得仅凭阅读安装说明擅自执行全局安装。

**作品与个人偏好保存：** 在老胡仓库内，创作作品默认保存到 `works/` 并告知实际路径；用户的个人偏好、工具说明等私有资料放在 `knowledge/`。`works/` 与 `knowledge/` 中的个人内容均已纳入 `.gitignore` 忽略范围，留在你自己的电脑里，不会随仓库上传到 GitHub。在仓库外且尚未确定目录时，Agent 会给出路径建议，经你确认再写入；外部目录不自动继承本仓库的 Git 忽略规则。

**更新、发布、检查与卸载：** 普通更新会拉取完整仓库并保留你的本地修改；直接输入 `/laohu-update` 是更新项目加发布已审阅改动的合并指令，只想同步官方版本时请明确说“只更新，不发布本地改动”。全局模式会自动同步受管理入口；运行 `python3 tools/install.py status` 可查当前链接状态。卸载 Codex 全局入口时先用 `python3 tools/install.py uninstall --host codex` 预览，再加 `--write`，不会删除仓库和作品。搬迁仓库前请先卸载全局入口，搬完再重新注册。详见 [安装与入口管理](.agents/skills/laohu-update/references/installation.md)。

## 从哪里开始

不知道先点哪一个时，直接输入 `/laohu`，或任选下面一种模式：

- `/laohu 新手入门`：快速摸清用法，拿一条能直接上手的示例请求。
- `/laohu 能力目录`：实时扫描并查看当前所有可用技能及用途。
- `/laohu 帮我选`：丢出你的目标或半成品材料，拿到入口推荐、理由和可直接发送的提示词。
- `/laohu 更新帮助`：通过 Git 同步官方新版本；如果本地自进化修改和官方更新有冲突，由你拍板怎么合并。

入口每次都会实时读取目录里的最新技能定义；新能力加入后，下次推荐自动纳入候选。是否开始执行始终由你决定。

如果你已经清楚眼下要干什么，直接调用下面对应的正式入口即可；如果脑子里只有一个模糊想法，先找 `/laohu` 帮你理清目标、材料和第一步，再决定要不要动手。

## 老胡的 AI 创作体系：四件事连成一条线

一个人做 AI 创作，最容易卡在两个断层上：

有好想法、好提示词，真要出图出片时，得在四五个云平台之间来回切窗口、反复传参考图、冲一堆用不完的余额；过几天想复刻上次那版绝佳效果，连参数和原图都找不着了。反过来，光有生成工具却没方向和方法，抽再多卡也只是堆废片。

所以我把自己的整套创作工具拆成了互相衔接的四块——你可以只拿眼前用得上的一块，也可以把它们串成一套属于自己的本地创作流水线：

| 体系环节 | 承担的角色 | 解决什么真实痛点 | 直达入口 |
| --- | --- | --- | --- |
| **老胡造梦技能**（本仓库） | **大脑与方法** | 把选题、文案、脚本、歌词、编曲、分镜视频提示词、原生动画和审稿进化沉淀成 23 项 Agent 技能，守住作品方向与质量上限 | [GitHub 仓库](https://github.com/LaohuAD/laohu-creative-skills) |
| **老胡画梦枋**（本地工作台） | **手脚与画布** | 把可视化无限画布、视频克隆、动画制作、多模态生成和素材参数库留在自己电脑里，不绑死单一云平台，还支持本机 Agent 与 `laohu-motion` 直接联动 | [GitHub 仓库](https://github.com/LaohuAD/laohu-creative-studio) |
| **老胡的模型小屋** | **高性价比算力** | 一个账号直连数百个主流文本、生图、视频、音乐与配音模型，原生适配画梦枋，多条低价通道透明按量付费，大幅压低多轮试错成本 | [模型与实时价格](https://api.lao-hu.com/pricing) |
| **老胡个人网站** | **作品、教程与社群** | 看完整 AI 作品成品、学 [实战图文与视频教程](https://lao-hu.com/learn/)、找全套工具入口；卡壳时还能进 [老胡画梦枋社群](https://lao-hu.com/#community) 和造梦师们带着作品一起拆解 | [lao-hu.com](https://lao-hu.com/) |

一条典型的协作闭环跑起来非常顺滑：

1. **先用老胡造梦技能定盘**：在你的 Agent 里敲定选题、故事、剧本、封面构思、分镜视频提示词或原生动画方案。
2. **再进老胡画梦枋落地出成品**：把提示词和参考素材拉进本地画布或动画/视频克隆模块，接入模型直接出图、出片、出音乐——满意的一张图顺手接下一个节点转视频，所有素材、参数和历史结果永远留在你本机。
3. **回来复盘打磨、排版发布**：拿不准哪一镜掉链子，回造梦技能用 `/laohu-audit` 找茬，或交给 `/laohu-htmlshow`、`/laohu-archive` 整理交付；做录屏口播教程时，还能顺手搭配姊妹开源项目 [CapMotion](https://github.com/LaohuAD/laohu-CapMotion)。

### 跑图跑视频总心疼试错成本？试试画梦枋 ＋ 模型小屋

真正做出一件自己满意的 AI 作品，封面、分镜、运镜往往要反复试上好几轮。最扫兴的不是没灵感，而是还没试到最对味那一版，各平台账号充了一圈、预算先烧见底了。

我自己日常跑工作流，用的就是 **本地老胡画梦枋 ＋ [老胡的模型小屋](https://api.lao-hu.com)** 这套组合：

- **不用满世界注册和充门槛费**：在模型小屋注册一次，一个账号就能按需调用数百个主流生图、视频、音乐、音频与文本模型；在画梦枋的 API 设置里原生支持 `laohu` 渠道，配一次就能把画布、视频克隆、音乐和文章模块一次跑通。
- **多条低价通道，把试错成本压到真不肉疼**：全部按量透明计费、跑之前先把单价看清楚。比如站内展示的 GPT Image 2.6 低价通道，1K 生图参考价低至约 0.05 元一张，连试 10 版封面也才几毛钱（实际费用随模型、分辨率与视频时长变动，以[模型小屋实时价格页](https://api.lao-hu.com/pricing)为准）。
- **完全自愿，开源工具不绑架选择**：老胡造梦技能和老胡画梦枋都是独立开源项目，你随时可以接本地 ComfyUI、火山、ModelScope、RunningHub 或手头已有的其他 API。如果你正好想把多轮抽卡和试错成本打下来，建议先逛逛[模型小屋价格广场](https://api.lao-hu.com/pricing)，拿一个小任务亲自比一比效果、速度和单价，觉得真划算再继续用。

想先看看这套组合实际能做出什么作品、或者照着完整步骤上手跑一遍，直接来 **[老胡个人网站 · lao-hu.com](https://lao-hu.com/)** 看作品、刷[教程与资料](https://lao-hu.com/learn/)，或者了解一下老胡组织的 AI 创作交流社群 **[老胡画梦枋](https://lao-hu.com/#community)**。
