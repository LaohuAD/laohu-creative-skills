# 从真实作品学习可迁移的方法

本 Reference 分为两条可独立读取的路径。**日常创作取法与方向**供专业 Skill 在创作中选择、理解并落实成熟方法；**正式评估与 L/C/D/H**供能力建设、校准和正式质量比较使用。创作时通常只读第一部分；只有任务明确要求正式比较、评分或样本集管理时才读第二部分。目标 Skill 始终负责领域方法、媒介条件、创作决定与成品验收。本文件不替负责作者作出表达选择，也不把出处、名气或研究过程当作成品质量。

四维与四层的共同定义见[万能造梦框架](universal-dream-framework.md)；本文件保留真实作品研究、方法迁移与正式评价的创作专门规则。

## 日常创作取法与方向

完整独立创作不能只因执行者自认为会写，就跳过对成熟方法的选择。先看用户提供的参考作品、前文和已确认取舍，以及本地专业 Skill/Reference 中现成的作品依据；已有且适用时直接复用，不必为同一方法重复搜索。对于关键审美、声口、节奏、叙述或媒介表现，仅有 Forster/Aristotle 等通用理论、行业底线，或“有动机/有变化/更自然”等抽象判据，不足以代替具体作品或创作者的做法。可复用的成熟依据须让执行者看到相关原作单元或可核方法、必要上下文、实际处理及适用条件，并能转成该部分具体的写法与完成参照。通用理论和专业判据仍可检验作品是否成立，但不代替这类实际参照。若已有材料只有抽象原则而本作关键部分仍缺具体表现依据，才围绕该部分的具体缺口找作品或专业来源。材料整理、格式转换、普通校对、明确局部修改等不承担独立创作决定的任务，不因共用此 Reference 而被强制做文学对标。

取法针对会决定接收体验的关键部分，不给每句话或每条规则配一本书。先确定本作整体主方向，再辨认真正影响它的部分与问题：如故事驱动力、人物选择、读者/观众所知次序、场面行动、角色声音、词句节奏、读者入口、版式或媒介节拍。每部分的判断依据要足以回答“本作采用什么具体做法、它怎样解决眼前问题”，不能只写“自然、有冲突、有情绪”。不同作品/作者可以分工解决不同部分；当多种方法对同一维度给出冲突选择时，以用户已确认的作品目标和整体方向裁决，并保留必要代价，不把相斥做法无解释地拼在一起。无关本作关键选择的部分不需为求完整而找参照。

用户给出指定作家/作品或已确认的前文方法时，优先核对其实际作品单元、具体处理和上下文；用户未给出时，先检查本地 Skill/Reference 是否已有满足上述充分条件的具体作品依据。只有这些依据回答不了一个会改变成品的具体问题，或本地内容只剩通用理论/抽象判据时，才外查相称作品或专业来源。采用具体处理作为本作写法参照，不等于将其设为质量比较基准；有名字或借用一项方法，也不能据此宣称作品“殿堂级”或质量通过。用户明确不想看作品、不要引用或不参与比较时，遵守其边界；仍可使用用户提供的材料和本地专业方法，不借机强迫研究对话。无法取得可靠依据时，标明仅影响哪些来源/方法主张，继续不依赖该证据的工作；不得把模型熟悉感伪装成核验。

### 选择问题与可比材料

先写清本次要解决的具体问题，以及研究结果可能改变哪一个创作决定。问题太宽时缩小到可观察单元，例如一个入口、行动、论证转换、信息揭示、回返、句群、镜头关系或结尾处理。选择作品或片段时，只核对会影响方法的可比条件：体裁、用途、受众、语言与文化语境、篇幅、表演/阅读/聆听方式、协作条件和媒介限制。不要只因题材相似、名气大或模型熟悉就判断作品可比。原作单元要保留足以判断作用的上下文，不能只摘孤立金句或写“像某某”。

若要参照具体语句，选用与本作同语言、同语域且用途相近的完整话语或对话，并连同必要的前后轮次阅读；观察惯用搭配、句法、称呼、应答和停顿怎样服务当下行动，再把可迁移的做法交回对应的生成步骤。若只取结构，观察行动、信息次序和后果怎样衔接；不把结构参照逐句配对，也不要求每句话各找一个范例。写回时说明具体处理与适用条件，不能只留作品或作者名称，也不能把原作的独特表达当成通用配方。

来源、版本、作品身份和创作者身份须能核验；不知道的标 `UNKNOWN`，不从搜索排名、获奖、销量、点赞或流行度推定质量、代表性或作者方法。若现有本地 Reference 已含足够上下文和具体方法，直接用其本地依据即可；需要新来源时只检索回答当前具体问题的部分，不制作无关的完整作品资料表。

### 从原作证据走到本作成品

日常取法沿“原作 → 可观察做法 → 专业方法/适用条件 → 本作决定 → 实际成品”的链条完成。它是内部创作工具，不要求每次向用户提交研究报告或四层表格；用户要选择、比较或了解出处时，再呈现会改变其决定的证据与取舍。

1. **定位原作证据。**记录来源身份、版本、位置、必要上下文和准确原文/媒介片段。只截取足以核对判断的范围，并遵守来源和版权限制。不可取得原文或片段时标缺口，不凭记忆伪造引文。
2. **描述可观察的实现。**在本次判断依赖具体人物、对象、行动或话语的地方，先根据所选原作单元和必要上下文还原谁在何时做了什么、涉及哪个对象及其状态如何变化；遇到同类或相近称呼的对象时，确认它们是同一实体还是不同实体，并标明直接引语、转述、叙述明示心理和本地解释各自归属。只把原文直接呈现或上下文足以确认的内容记作作品事实，解释性推断另行标明；无法确认的身份、时序、归属或状态标为未知，并缩小相应解释。随后写清接收者先获知什么、作品中发生了什么改变、哪些关系或期待建立、维持或打断；把作品实际呈现的形式与对其作用的解释分开。作品能证明它呈现了什么，不能单独证明作者完整意图或未公开的创作过程。只追踪支撑本次方法判断所需的实体和关系，不建立全书对象清单。
3. **核对方法与边界。**将观察与相关专业书籍、原始理论、行业规范或可核验创作者方法对照。说明该方法的必要构成、适用条件、代价与变体；归属不确定时写成有边界的解释。不得把作品中的一件物、一个句架、一种镜头或一种声音误当通用配方。
4. **形成本作决定。**说明当前任务为何适用或不适用，哪些专业构成要保留，哪些表面形式不可照搬。把方法转成目标 Skill 可执行的选择、动作、切换/退出条件和待复查的成品位置。以用户已确认的作品目的、立场、材料与媒介重新创作，不复制可识别措辞、独特排列或未授权内容。
5. **回到实际创作。**由负责的执行 Skill 使用所选方法完成对应部分，并在成品中核对真实位置。若研究只留在解释里、没有改变本作选择，迁移尚未发生；若设计成立而作品没实现，回到专业生成步骤修正。正式评分与盲接收另按本文件下方正式评估部分及 [analysis 验证协议](../.agents/skills/laohu-analysis/references/validation.md)执行，不能让创作者解释替作品证明。

不把“有力量”“高级”“自然”等赏析形容词当成方法。追问它们指向哪项选择、在什么上下文起作用、哪些构成使其成立、替换或拿掉后接收有什么变化。原作证据不足以证明因果时，保留多个解释或标未知，不写成确定规则。

### 让真实作品帮助用户探索作品方向

用户尚未确定方向、但希望开始创作或比较可能性时，可用真实作品作为讨论材料。告诉用户为什么选它、准备看哪一处，以及可核的作品身份；指出具体做法和适用条件，再问哪项处理让用户愿意靠近、排斥或继续探索。提问针对作品的具体选择，不把一次喜欢扩大成长期偏好，也不把 AI 的推荐说成用户已选择。

用户已明确委托直接生成或无需逐步参与时，在有可靠依据的前提下内部完成取法与推荐并继续；不因专业方法选择而反复停下求确认。只有必须由用户或权利人决定的方向、立场或取舍确会改变主要作品且材料不足以判断时，才简要呈现有差异的处理和代价，询问必要选择。样本研究不改变用户原先授权，也不自动扩大交付范围。

### 没有可靠样本或来源时

区分“没有检索到”“来源不可核验”“原作上下文不可用”“范围不可比”和“该方法没有合适典范”。前四者只限制相应来源/效果主张，不自动证明方法不存在。继续使用用户提供的材料与可靠本地专业方法，标出未知，并推进不依赖缺失证据的部分；不得编造作品、引文、访谈、传播数据或人类评价，也不得声称读过未读的章节。

从作品学习方法、结构原则或专业判断，不等于逐字复制作品的独特表达。已授权的独立创作照常推进；只有请求本身依赖复现原作独特句子、标志性表达组合或其他未授权内容时，才把该复制要求改为方法分析或独立新表达，并继续完成不依赖该复制的部分。准确短引、公开方法与独特表达的边界仍按来源和版权规则处理。

## 正式评估与 L/C/D/H

只有在能力开发、规则调试、评审校准、正式人类标尺比较或留出检验时，才使用本节。L/C/D/H 是样本用途角色，不是每次创作都要填写的任务记录；普通创作按上方日常取法完成即可。此处的评测协议不能由普通取法代替，也不能把 L/C/D 样本成绩当成 H 上的最终通过。

| 角色 | 用途 | 能支持什么 |
|---|---|---|
| `L` 学习集 | 建设方法、讲解典范，也可提供已批准的日常取法材料。 | 建设者与获准的生成者可看；不能据此声称新能力通过未见测试。 |
| `C` 校准集 | 调整评分说明，核对评价者与真实人类判断。 | 评分协议建设者与评审者可看；不作为最终新能力成绩。 |
| `D` 开发集 | 发现规则问题、比较修订并调试。 | 开发执行者与审查者可看；一旦用于改规则，就不再是留出材料。 |
| `H` 留出集 | 最终检验未用于规则优化的任务与标尺条件。 | 控制方保管并按角色发放；生成者只拿任务和允许输入，不拿留出标尺答案。 |

“人类标尺/锚点”描述的是作品来源与评价用途，不是第五种数据集角色，也不等于 `H`。标尺原文必须有可核实的人类作者创作依据；仅有人类发布、采用、推荐或认可，不能证明作品由人创作。此类认可可以作为标尺选入理由的一部分，须与作者身份证据分开记录。标尺包还须提供原文或足够完整的可合法核读单元、版本身份、正常理解所需语境、选入理由、适用任务和评价维度，并另外标明属于 `L`、`C`、`D` 还是 `H`。若作品或同一作品家族进入生成上下文或被用于修改规则，它只能作为开放学习或开发材料；同一评估不能再把它或近似改写当作 `H`。同一作品的节选、译本、改写及高度关联内容按作品家族隔离；需要跨作者泛化时，还需留出作者/来源家族。

正式人类标尺须有相称的人类评价或专业依据、明确适用范围和可比条件。公开发表、获奖、销量、点赞、推荐或专家判断可以作为选入证据的一部分，但不自动证明“殿堂级”或普遍优越。称作“顶尖人类标尺”需有可核验作品身份、独立人类判断或相称专业依据；证据未齐时只能作研究性比较，不能给出最终顶尖等级。

正式样本用途和评估仍须同时满足以下条件：来源身份、版本、作者/创作者来源依据、必要上下文、选择理由、目标任务与可比条件、评价维度、作品家族以及 L/C/D/H 状态均可核对；来源或上下文不足时不能支持相应正式评分。生成者不得读取 H 标尺答案，评审者不能根据标题、记忆或制作者摘要补造原文和语境。最终质量评价依 analysis 的[判断、运行与下游产物验证](../.agents/skills/laohu-analysis/references/validation.md)执行；未校准 AI 的暂评仍按证据记 `OBSERVE`，不能以作者解释或 AI 自评分代替真实接收。
