# 语言成文：从具体设计到可读作品

当创作或修订的交付物是文字时，按需读取本 Reference。它负责把已确认的目的、成熟专业方法和具体表现设计落实到真实词句；不代替歌词、标题、剧本、论证、口播等各自的方法，也不要求每项任务机械填满下列检查点。完整独立创作中，关键声口、节奏、叙述或审美处理若仍需作取舍，由负责的专业 Skill 按[真实作品研究方法的日常创作取法与方向](exemplar-study.md#日常创作取法与方向)保留实际作品单元/具体处理、必要语境及适用条件；本 Reference 的通用语言动作不能单独代替该具体依据。委托者、负责作者、直接消费者与最终人类接收者的身份关系按[能力运行约定](../docs/runtime.md#作者表达意图与成品保真)理解；本 Reference 只细化文字成文动作。四维与四层的共同定义见[万能造梦框架](universal-dream-framework.md)；本文件保留文字成文的具体操作。

## 先接到已经作出的决定

起草前沿用已有的表达目的、本作已选定的作者声音或人物声口、最终读者与使用情境、体裁、已选成熟方法、具体表现设计、事实边界、锁定内容和媒介条件；上下文已经交代的，不重复询问或抄成表单。关键部分的成熟做法须能落到本次文字选择及其语境，不能只剩作者/理论名称或“自然、连贯、有力量”等抽象标签；若仍有会改变成品的关键表现缺口，回到负责的专业步骤补足具体依据后再写，不让通用措辞检查冒充已完成取法。

确认一个重要单元要让读者知道、感到或做什么，以及它具体呈现什么。若交接只有“有力量、要克制、营造张力”之类评价词，尚不能直接开始成文：回到表现设计，补清由何种内容或行动承载、不能解释掉什么、与相邻单元如何衔接。专业方法由相应 Skill 的主流程或 Reference 提供；本文件不授权用任意关系替代它。

成文不要求灵魂、筋骨、血肉、表皮相关的决定都先全部完成。可以从已有词句、段落或画面开始，发现目的、专业方法或表现设计缺项时再回到对应判断补齐；这是可往返的工作过程，不是“先设计完才能写”的硬串行要求。

关键语言单元存在会改变表达效果的未决问题时，先从当前任务挑出该问题：例如谁来感知、哪个动作承担变化、哪项信息先让读者知道、态度要明说还是由上下文显出。把“更有力量、更高级、更自然”改写为该处要完成的接收动作和必须保护的意义。已由用户确认或由前文锁定的内容不重新开放。若这个未决变量的不同可行处理可能改变意义、关系、语气、节奏或理解顺序，而且比较可能改变选择，就先写出足以完整判断的候选，再从真实词句和上下文中查明差异；不要求落笔前已预知候选一定不同。比较后若没有可辨认的接收效果差异，合并候选或保留已有稿，不因字数少而给某一写法加分。常规事实句、接口文字或已有明确写法直接成文，不为每句话强行设置待解决问题或候选。

## 选词：看它实际改变什么

对当前关键句，先辨认谁或什么在做什么、作用于谁/什么、结果如何，以及表达者持何态度。若动词或关键词决定表达，先用内部工作释义核准这组关系和必要差别；释义只用来确认意思，不当作最终句式或逐项需明说的提纲。成句时优先选能准确承载这组关系的通行身份称谓、关系词、动作动词或惯用说法，让词本身带出事件参与者及其关系；保留实际对象、结果和态度，删去只重复解释同一词义的文字。没有合适词组时，在已选声口内用自然完整的句子说清，不生造缩略或把关系压没。再把候选放进原句和必要上下文中比较其施受关系、动作是否完成/持续/受阻、因果或意愿、人物距离、语气力度、确定程度及声音效果。具体动作有条件时选能呈现该条件的词；条件不明时不靠更强烈的词臆造事实。只展开会改变本次表达的维度。例如，下令或指使者是发出指令的人，执行者是实际实施行动的人，二者可以重合，也可以分开；“替死鬼”指被推出来替别人承受罪责或灾祸的人，不要求字面死亡。执行某项行动本身不能证明他是下令者或替人顶罪；顶罪者也可能同时是执行者。换称谓时须保留实际关系、对象和后果。

词义相近不代表作用相同。对“没/不/未、只/都、还/再/才、会/要/愿、却/也”等小词，先核对它成立所需的真实前提，再试删、替换或移动，并读回原句和相邻句：“还/仍/再”所表示的延续须有先前状态或可预期的继续；“才”须有达到条件/时间/门槛后才成立的关系；“却/而”所表示的转折须有可辨认的前项预期或对照；“只/都”须说明限制或覆盖的范围；意愿、将来、推测和已经发生须各有事实或话语依据。前提不存在时，不靠虚词制造层次。删改后标出它实际改变的是否定范围、数量范围、时间阶段、条件、意愿、转折、语气还是节奏。若删除导致主张、人物主动性、确定程度或关系变了，它不是可忽略的润色位；若效果不变且声音更顺，可删。不要为展示规则而在没有实际作用的位置补小词。

### 按事实范围选词，不把相邻概念压成一个

先判断材料实际支持到哪一步，再选词。下面这些词不是强弱递进的修辞选项，而是不同的动作或证据关系：

| 已知情况 | 优先用法 | 不能顺带声称什么 |
|---|---|---|
| 看见异常、找到记录或线索，但尚未比较或判定 | “发现”“查到” | 不能由“发现一条记录”推成记录完整、来源可靠或责任人已定。 |
| 把一项说法、身份或状态与现有记录/对象逐项对照 | “核对” | 核对动作本身不等于核对无误，也不证明对照范围之外的事。 |
| 可用信息已足以回答一个明确、有限的问题 | “确认”及其明确对象，如“确认身份/收到/仍有效” | 只确认该问题；不能自动扩大到原因、责任或完整过程。 |
| 证据确实支持某项事实或归责结论 | “证明”及其具体结论 | 证据只覆盖哪一环，就只说到哪一环；单条记录不自动证明整个因果链或某人负责。 |
| 某人向他人发出命令或指使 | “下令者”“指使者”等按实际关系选 | 发出命令不等于亲自实施行动，也不自动证明是主谋、责任人或替人顶罪。 |
| 某人实际实施一项行动 | “执行者/实施者”；“动手的人”用于确实亲自操作、出手的情形 | 实施行动不等于曾下令、是主谋或责任人，也不自动说明其承担了别人的罪责或灾祸。 |
| 某人被推出来替别人承担罪责、灾祸或不利后果 | 涉及顶责时可用“替罪者/替罪羊”；“替死鬼”也可指替人受罪或受灾祸的人，不要求字面死亡 | 不能仅因某人死了、执行了任务或被捕，就认定他替人顶罪；若他还亲自实施行动，可同时是执行者。 |

同一段也可依次包含“发现—核对—确认”，但每一步须有相应材料。只有最终结论达到该主张所需的证据范围时才说“证明”。“检查/核验”用于实际实施的查验动作；“确认”用于查验后的有限结论，不能拿动词替代缺少的查验过程。

语义范围定下后，再按文字用途选语体。报告或记录在测量结果、程序状态、责任边界会影响决定时，保留必要的专业词、数值和限制；面向普通读者的说明按该读者可理解的名称解释；当场交流采用人物此刻实际要完成的交际动作。短句或省略只在对象、动作和转折仍可从上下文辨认时成立；停顿/留白让读者观察已经写出的行为或关系，不遮掉必须理解的基本句意；诗性表达须由选定形式或具体材料支撑。说明腔、报告语、短句、留白、比喻和诗性都有适用场合，不预先改写成统一口语；也不在句子生硬后才用“风格”替它辩护。

词语还可能表达评价、关系、要求或预期，不能给某个词贴永久情绪标签。判断事实意义、表达者立场、称呼距离、句子要做的事和当前语境带出的情感，再读完整句群；一个词在不同位置、对象和压力下可以产生不同态度。

### 句子成立，还要听它是不是这个场景里的话

当用户要求普通自然语气，或读者必须依赖成品外的创作者解释才能识别行动施事、指代对象、时序或因果关系时，按以下顺序成句。句子语法成立、意思也能猜到，却读来生硬、拗口、端着或搭配别扭时，也沿这一路径改写；不因此把所有文体改成口语或短句。

1. **接着上句或当前场景成句。** 对白从对方刚说的对象、行动或问题接起，先写角色此刻要做的回应：回答、询问、要求、拒绝或表态，再补本轮必需的原因、条件和结果。普通说明文字可承接上下文已建立的对象或关系，再给出当前必需的新信息。诗性表达、非现场论述、悬念或其他已选信息顺序沿用其设计，不强制先讲现场事实或把所有关系明说。
2. **先交代首次影响行动的对象。** 新对象第一次要驱动当前行动、决定或结果时，从当前视角给出足以识别它并理解其作用的内容或状态，再沿用已确立的称呼。角色或叙述者尚未知的身份、来历不提前揭露；只有原件/复印件、新旧状态等差异会改变当前行动或后果时，才写明实际区别，不补与行动无关的背景。
3. **放回句群并完成改写。** 将句子连同必要上下文读回，核对施事、指代、时间、因果和转折。若句子生硬，按实际动作对象选能与之搭配的常用动词，用自然的关系词或连接表达接上，并保留必要的介词、补语和助词；行动者改变时重新点明主语，转述他人态度时写明态度属于谁，避免换句架时挪走施事。只删不承担证据、条件、声口或理解作用的无关信息，也不重复解释词语、动作或上下文已经表达的同一关系；保留有意的情绪回返、说话节奏和文体复沓，不压成统一短句、不强加材料没有的事实。声音、发声动作、实体物或信息同时出现时，也分别说明其施事、对象和作用，不混作同一动作。读者仍须依赖成品外解释才能辨认行动者、指代、时序或因果时，补足或重写；作品有意保留的空缺不擅自讲破。

非惯常搭配或句法只有在生成前已选定的声口/方法、可核对的原作处理，或作品上下文连续证据足以支持这一偏离，且读者能辨认其修辞关系、它确实承担本段作用时才保留；不得在生硬句子生成后再把它命名为“诗性”“陌生化”或“角色口癖”来保稿。不要把“自然”改成统一口语，也不要把一切不熟悉的说法都判为错误。

本地方法参考 Fillmore 的框架语义与 ICSI FrameNet、Purdue OWL《Concision》及 John August《Dialogue versus exposition》。上文是面向中文成文的适配，不是来源的逐项原文规则或直接引述。

## 成句：把表达动作写出来

写关键句时，先确定读者到此已经知道什么、此处必须新增什么信息，以及本句要突出的重点，再据此安排实际信息顺序、动词和句法。信息密度看事实、对象、否定/限制、状态变化、态度、关系、感受、节奏或预期是否各有实际作用，不按句子短不短或是否每句都新增事实计算；删掉关键对象、否定或变化，只会把补全意思的工作推给读者。说明或操作段可采用 George Mason University Writing Center 所述的已知—新信息衔接：先让句子承接上下文已经建立的对象或关系，再引入本句要增加的信息；它用于降低解释性文字的连接负担，不要求诗歌、悬念、对照或刻意断裂一律先说已知。对有实质取舍的句子，可在上层目的、方法和事实固定时形成少量功能不同的句法候选：在不改变已定叙述视角和表现设计的前提下，比较语法主语、主动或被动、先因后果或先结果后原因、明说或延后关键信息、完整句或有依据的省略。若改动语法主语会改变谁在感知/行动、责任归属或信息焦点，属于视角或表现设计变化，就回到对应专业决定，而不能伪装成只换句法。每个候选必须实现同一已确认任务并标出不同代价，不能靠说明文字替候选辩护。选择后再定连接、并置、停顿或省略怎样承载关系。说明性文字不能漏掉必要前提和推理；表现性文字可以让动作、视角、节奏和上下文显出关系，不必把所有意味解释成说明书。

逐句检查时，必要的字面对象和关系要能读懂；读者可以从上下文推知的内容须有实际依据；负责作者有意保留的信息、歧义或空缺则不擅自讲破。这三者是成品效果的校准角度，不是每个文本都要分别填入的栏目，也不意味着所有字面关系都必须明说或所有未知都应保持模糊。

当句意容易走样时，可先用内部工作释义确认表达动作与必要关系；释义不等于最终句式，也不要求消除作品需要的多义。句长、分句、标点、分行和停顿按体裁、声口、阅读、演唱或表演条件决定，没有通用短句优先规则。成句后连同前后必要句群读回：信息是否按读者理解所需的次序展开，焦点是否落在该落的位置，事实、态度与声口是否保留，是否出现不必要的解释或读者无法建立的关键联系。相邻句采用相似句架时，判断它是在形成韵律、并列、回声或执念，还是无意落入同一种默认写作者腔；只有后一种才考虑改动，并让整段的声音仍然成立。若文本要被唱、说、演或实际粘贴使用，按目标媒介完整读、唱、演或粘贴检查；纸面顺眼不能代替声音、动作、版式或接口验证。

## 成段：让句子共同完成一项工作

先确认段落在本作中要呈现、推进、解释、累积、维持、回返还是收束什么，再按已选专业结构安排句子。句子之间不必每次新增事实；它可以推进动作、交代必要根据、改变观察位置、积累感受、保持有意的复沓或准备回返。删改重复时，检查它是否承担这些作用，不按次数直接删。

局部句子写完后，连续读完整段落，再看它们是否共同指向段落任务、重心是否清楚、承接是否成立、有没有无功能的复述或被概括掉的必要表现。单句成立而整段松散时，先检查段落职责和句间关系，不继续给每句加修辞。改过一处后重新读回完整段落；关键段落或结构变动还要放回全文检查前后影响。

## 全篇与定向修订

按接收顺序检查入口、后续展开与结尾是否兑现已确认目的，不强制每篇使用钩子、升级、高潮或总结。需要组织全篇时，遵循本作选定的成熟方法；不以一个局部好句替代整篇的价值、声音和结构。

修订从可定位的成品差距开始：引用具体位置，说明读者/使用者在这里实际会看到什么、预定作用为何没有发生；判断最早断点在目的与取舍、所选方法、表现设计，还是实际语言。优先修复造成最大损失的缺口；若多处问题由同一原因造成，或需要一组改动才能成立，可以一并修，不要求把互相依赖的问题拆成孤立单点。保留已成立的事实、意图、声口与上下文条件，只改能修复该缺口的动作词、小词、句法、信息顺序或句群衔接。若具体表现设计成立而文字没有实现，改词句；若文字只能靠成品外说明才成立，补缺失的必要线索或重做表现设计；若目标或方法本身不足以决定写法，回到相应专业判断，不把上层缺口全压给润色。修改后重新读完整句群，结构或关键措辞变动再放回全文/真实媒介检查，并确认保护项仍成立；不得只交改前改后的一句而不回读其影响范围。

## 何时比较候选

在用户普通创作请求的已授权范围内，若存在会影响表达的未决变量，且比较可能改变选择，可内部试写足以判断的候选、比较、筛选并定向修订，无需为不展示的草稿另行确认；不要求每项任务都生成候选，也不设统一数量。实际成文后核对候选是否造成有意义的效果差异；没有可辨认的接收效果差异时合并候选或保留已有稿，不因字数少而给某一版本加分。若本轮只处理文字，保持已确认的目的、方法和表现设计不变，比较实际成文及必要上下文，不让候选说明替成品说服人。裁决后把胜出处理落实到作品，并按受影响范围读回复查，不止交候选清单。额外交付多稿、触及用户锁定内容、超出本轮范围或产生额外成本与外部动作时，按运行约定核对相应边界。

检查者只能在独立会话或确实隔离制作解释时称为盲接收；同一上下文中的自审如实标为自检。模拟接收不等于真实受众，文字内部完成度也不自动证明平台表现或普遍质量。根据任务和证据报告结论，不强制外部流量测试、固定评分或统一格式。
