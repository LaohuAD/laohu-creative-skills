# 老胡造梦技能

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [繁體中文](README.zh-TW.md)

> AI로 꿈을 만드는 사람들을 위해 Laohu가 준비한 창작 Skill입니다.
>
> 음악, 커버, 영상, 제목을 비롯한 여러 콘텐츠 제작 및 발행 영역을 다룹니다. 창작자는 자신의 미적 판단에 따라 능력을 선택하고 조합하여 AI 창작과 발행을 완성합니다. 함께 이 세상에 꿈을 그려 봅시다.

老胡造梦技能은 사람을 중심에 둔 AI 창작 Skill 도구 상자입니다. AI가 다음에 무엇을 할지 대신 결정하는 것이 아니라, 여러 창작 능력을 사람이 선택하고 독립적으로 호출하며 단계적으로 조합할 수 있는 입구로 정리합니다. 사람은 목표, 범위, 중요한 선택을 결정하고 AI는 정해진 범위 안에서 전문 작업을 수행합니다.

## 해결하는 문제

주제 선정, 가사, 커버, 영상 프롬프트, 작품 정리, 완성 작품의 문제 찾기 등 지금 필요한 능력을 직접 선택할 수 있습니다.

어떤 입구를 사용해야 할지 모르겠다면 `/laohu`를 사용하세요. 현재 작업을 정리하고 가능한 능력을 비교한 뒤 선택권을 사용자에게 돌려줍니다.

전체 제작 흐름과 세부 전문 입구는 따로 사용할 수 있습니다. 예를 들어 `laohu-lyrics`는 가사 제작 흐름을 담당하고, 앞으로 만들어질 `laohu-lyrics-rhyme`은 운율 문제만 다룰 수 있습니다. 흐름은 필요한 방법을 읽고, 세부 능력은 단독으로도 사용할 수 있습니다.

## 현재 입구

| 입구 | 용도 |
| --- | --- |
| `laohu` | 최상위 라우팅과 작업 정리 |
| `laohu-topic` | 주제 선정 |
| `laohu-writing` | 글쓰기 |
| `laohu-lyrics` | 가사 |
| `laohu-title` | 제목 |
| `laohu-cover` | 커버 |
| `laohu-script` | 대본 |
| `laohu-image` | 이미지 |
| `laohu-assets` | 시각 및 창작 자산 |
| `laohu-story` | 이야기 아이디어 |
| `laohu-video` | 영상과 영상 프롬프트 |
| `laohu-update` | 도구 상자 업데이트 |
| `laohu-diagnosis` | 작품 문제 찾기 |
| `laohu-archive` | 작품 정리, 수집, 보관 |
| `laohu-arrangement` | 편곡 |
| `laohu-benchmark` | 벤치마크 및 참고작 분석 |
| `laohu-evolution` | 자기 진화와 경험 기록 |

현재 입구는 디렉터리 골격만 갖추고 있습니다. 구체적인 `SKILL.md`는 실제 창작 작업에 맞춰 순차적으로 작성합니다.

## 작동 방식

```text
사람의 목표와 자료
        ↓
/laohu 또는 사용자가 직접 선택한 입구
        ↓
이번 작업의 범위, 보호할 결정, 결과물을 확인
        ↓
필요할 때 방법, 사례, 자산을 읽음
        ↓
현재 결과를 전달하고 수정·계속·종료를 사람이 결정
```

서로 다른 Agent가 독립적으로 발견해야 하는 입구는 등록 가능한 최상위 Skill로 유지합니다. 호스트가 Skill에서 다른 Skill을 호출할 수 없다면 현재 입구에서 같은 Reference를 읽습니다. 실행하지 않은 호출을 실행한 것처럼 말하지 않습니다.

## 프로젝트 구조

```text
laohu-creative-skill/
├── AGENTS.md       프로젝트 규칙, 라우팅 경계, 자산 보호
├── README.md       프로젝트 소개와 입구 안내
├── LICENSE         CC BY-NC 4.0
├── skills/         발견하고 직접 호출할 수 있는 Skill 입구
├── works/          작품, 초안, 확정 파일, 발행 자료
└── knowledge/      재사용 지식, 사례, 경험, 장기 자산
```

`skills/` 아래의 `.gitkeep`은 빈 디렉터리를 Git에 보존하기 위한 파일일 뿐입니다. 해당 능력이 완성되었다는 뜻은 아닙니다. 필요에 따라 `SKILL.md`, `references/`, `templates/`, `scripts/`, 테스트를 추가합니다.

## 설계 원칙

- 무엇을 할지는 사람이 결정하고, AI는 허가된 범위를 수행합니다.
- 목표가 분명하면 해당 입구를 직접 호출하고, 모를 때만 `/laohu`를 사용합니다.
- 독립된 문제만 독립 Skill로 분리하고, 조명·운율·숏 크기 같은 방법은 기본적으로 Reference로 둡니다.
- 작품, 개인 자료, 지식 자산과 도구 상자의 방법을 분리하여 업데이트가 사용자 자산을 덮어쓰지 않게 합니다.
- 모든 Skill은 발동 조건, 입력, 출력, 보호할 내용, 중단 조건을 명시합니다.

## 프로젝트 자료와 창작 결과물

이 프로젝트는 [CC BY-NC 4.0](LICENSE) 라이선스를 사용합니다. 제한 대상은 Skill, 규칙, Reference, 사례, 템플릿, 스크립트 등 저장소 자체의 프로젝트 자료입니다. 별도 허가 없이 이를 상업적 배포, 상업적 서비스, 상업적 제품에 사용할 수 없습니다.

사용자가 이 능력을 사용해 만든 가사, 글, 제목, 이미지, 오디오, 영상, 대본 및 기타 작품은 도구를 사용했다는 이유만으로 자동으로 비상업 제한을 받지 않습니다. 창작자는 자신이 보유한 권리와 허가 범위에서 작품을 사용, 공개, 상업화할 수 있습니다.

작품에 사용된 제3자 자료, 모델 서비스, 플랫폼 콘텐츠, 외부 방법은 각자의 라이선스, 이용 약관 및 관련 법률을 따라야 합니다. 이 프로젝트는 제3자의 권리를 부여하지 않으며, 저장소 자료의 상업적 이용 제한을 창작 결과물에 확대하지도 않습니다.
